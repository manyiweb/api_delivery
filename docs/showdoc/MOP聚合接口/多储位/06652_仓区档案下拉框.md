# 储区列表
 

**请求URL：** 
- `/warehouse/multistorelocation/warehouse/area/select/list/MYSQL `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|keyword|否|String|编号/名称|
|pageNo|是|int| 页码|
|pageSize|是|int| 分页大小|
|id|是|long| 仓库id|

###请求参数Json格式
 
```
{
 "keyword": "",
 "pageIndex": 1,
 "pageSize": 20,
 "sword": "",
 "pageNo": 1,
 "tokenId": "d791fdbc28a440179aa38fd6bdc663cc",
 "id":"1"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|long| id|
|key|是|String| 编码|
|value|是|String| 名称|
