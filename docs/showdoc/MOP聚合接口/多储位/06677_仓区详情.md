# 仓区详情
 

**请求URL：** 
- /warehouse/multistorelocation/warehouse/area/detail `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|long| 仓库id|

###请求参数Json格式
 
```
{
 "id": "1",
 "tokenId": "170442721aa74c28be5201a001386c57"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|long| id|
|warehouseAreaCode|否|String| 仓库编码|
|warehouseAreaName|否|String| 仓区名称|
|status|否|String| 活跃状态|
|statusName|否|String| 活跃状态名称|
|isDefault|否|String| 是否默认|
|createDate|否|String| 创建时间|
|createName|否|String| 创建人|
|modifyDate|否|String| 更新时间|
|modifyName|否|String| 更新人|
|remark|否|String| 备注|

|--logisticsWarehouseDetailResp|否|String| 多储位物流仓库档案详情|
|warehouseCode|否|String| 仓库编码|
|warehouseName|否|String| 仓库名称|
