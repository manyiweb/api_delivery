# 储区列表
 

**请求URL：** 
- `warehouse/multistorelocation/warehouse/save `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|warehouseCode|是|String|物流仓编号|
|warehouseName|是|String| 物流仓名称|
|status|是|boolean| 活跃状态|
|remark|是|String| 备注|
|pageSize|是|int| 分页大小|

###请求参数Json格式
 
```
{
 "warehouseCode": "warehouseCodeTest",
 "warehouseName": "warehouseNameTest",
 "status": true,
 "remark": "remark",
 "tokenId":"dc2f35309f5842fe824e23c49abc1a17"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|code|是|long| 编码|
|data|是|String| 数据|
|exceptionStackInfo|否|String| 异常栈信息|
|msg|否|String| 业务错误信息|
|success|否|String| 是否成功|


###返回参数Json格式
 
```
{
 "code": "200",
 "data": null,
 "exceptionStackInfo": "",
 "msg": "",
 "success": true,
 "traceId": ""
}
```
