# 储区列表
 

**请求URL：** 
- `warehouse/multistorelocation/warehouse/detail`

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|long|物流仓id|

###请求参数Json格式
 
```
{
 "id": "1",
 "tokenId": "170442721aa74c28be5201a001386c57"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|long| id|
|warehouseCode|是|String| 物流仓编码|
|warehouseName|是|String| 物流仓名称|
|status|是|boolean| true 活跃 false 停用|
|remark|是|String| 备注|
|createDate|是|Date| 创建时间|
|createName|是|String| 创建人|
|modifyDate|是|Date| 更新时间|
|modifyName|是|String| 备注|



###返回参数Json格式
 
```
{
 "code": "200",
 "data": {
 "createDate": "2023-05-09 16:37:36",
 "createName": "扬帆",
 "id": "1",
 "modifyDate": "2023-05-09 16:37:36",
 "modifyName": "扬帆",
 "remark": "remark",
 "status": true,
 "warehouseCode": "warehouseCode",
 "warehouseName": "warehouseName"
 },
 "exceptionStackInfo": "",
 "msg": "",
 "success": true,
 "traceId": ""
}
```
