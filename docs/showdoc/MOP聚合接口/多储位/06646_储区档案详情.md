# 储区列表
 

**请求URL：** 
- `/warehouse/multistorelocation/storearea/detail`

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|long|物流仓id|

###请求参数Json格式
 
```
{
 "id": "1",
 "tokenId": "170442721aa74c28be5201a001386c57"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|long| id|
|storeAreaCode|是|String| 储区编码|
|storeAreaName|是|String| 储区名称|
|status|是|boolean| true 活跃 false 停用|
|remark|是|String| 备注|
|createDate|是|Date| 创建时间|
|createName|是|String| 创建人|
|——logisticsWarehouseDetailResp|是|Object| 多储位物流仓库|
|warehouseCode|是|String| 物流仓编码|
|warehouseName|是|String| 物流仓编码|
|——logisticsWarehouseAreaDetailResp|是|Object| 备注|
|warehouseAreaName|是|String| 多储位物流仓仓区名称|
|warehouseAreaCode|是|String| 多储位物流仓仓区编码|
