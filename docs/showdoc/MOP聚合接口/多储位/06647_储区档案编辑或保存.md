# 储区列表
 

**请求URL：** 
- `/warehouse/multistorelocation/storearea/save`

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|long|id|
|warehouseId|是|long| 物流仓库id|
|warehouseAreaId|是|long| 仓区id|
|storeAreaCode|是|String| 储区编码|
|storeAreaName|是|String| 储区名称|
|status|是|boolean| 活跃状态|
|isRetailOut|是|boolean| 是否可零售出库 true 是 false否|
|isRetailIn|是|boolean| 是否可零售退货 true 是 false否|
|remark|是|boolean| String true 是 false否|

###请求参数Json格式
 
```
{
 "id": "",
 "warehouseId": "1",
 "warehouseAreaId": "1",
 "storeAreaCode": "storeAreaCode",
 "storeAreaName": "storeAreaName",
 "status": "true",
 "isRetailOut": "true",
 "isRetailIn": "true",
 "tokenId":"6e679ba471404377886dcb25d666ce23",
 "remark":""
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|code|是|long| 编码|
|data|是|String| 数据|
|exceptionStackInfo|否|String| 异常栈信息|
|msg|否|String| 业务错误信息|
|success|否|String| 是否成功|


###返回参数Json格式
 
```
{
 "code": "200",
 "data": null,
 "exceptionStackInfo": "",
 "msg": "",
 "success": true,
 "traceId": ""
}
```
