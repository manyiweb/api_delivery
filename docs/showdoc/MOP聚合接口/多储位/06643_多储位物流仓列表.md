# 多储位物流仓列表
 

**请求URL：** 
- `warehouse/multistorelocation/warehouse/list/ `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|keyword|否|String|编号/名称|
|pageNo|是|int| 页码|
|pageSize|是|int| 分页大小|

###请求参数Json格式
 
```
{
 "keyword": "",
 "pageIndex": 1,
 "pageSize": 20,
 "sword": "",
 "pageNo": 1,
 "tokenId": "d791fdbc28a440179aa38fd6bdc663cc"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|long| id|
|warehouseName|否|String| 仓库名称|
|warehouseCode|否|String| 物流仓编码|
|status|否|String| 活跃状态|
|statusName|否|String| 活跃状态|
|createDate|否|String| 创建时间|
|createName|否|String| 创建人|
|modifyDate|否|String| 更新时间|
|modifyName|否|String| 更新人|
|remark|否|String| 备注|
