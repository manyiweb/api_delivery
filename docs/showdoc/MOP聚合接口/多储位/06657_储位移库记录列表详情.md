# 储位移库详情

**请求URL：** 
- `/warehouse/multistorelocation/storelocation/relocate/record/detail`

**请求方式：**
- ALL
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||

### 请求参数Json格式
 
```
{
 "id" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long| ID|
|--recordNo|否|String| 记录编码|
|--logisticsWarehouseDetailResp|否|Object| 物流仓信息|
|----id|否|Long| ID|
|----warehouseCode|否|String| 物流仓编码|
|----warehouseName|否|String| 物流仓名称|
|----status|否|Boolean| 活跃状态|
|----statusName|否|String| 活跃状态名称|
|----remark|否|String| 备注|
|----createDate|否|DateTime| 创建时间|
|----createName|否|String| 创建人|
|----modifyDate|否|DateTime| 更新时间|
|----modifyName|否|String| 备注|
|--info|否|Object| 储位移库明细|
|----outOrderNo|否|String| 外部单号|
|--statusCode|否|String| 状态编码|
|--statusName|否|String| 状态名称|
|--totalQuantity|否|Double| 总数量|
|--remark|否|String| 备注|
|--createDate|否|DateTime| 创建时间|
|--createName|否|String| 创建人|
|--whsName|否|String| 仓库名称|
|--whsId|否|String| 仓库Id|
|--modifyDate|否|DateTime| 更新时间|
|--modifyName|否|String| 更新人|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
