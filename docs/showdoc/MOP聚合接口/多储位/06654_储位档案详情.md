# 储位档案详情
 

**请求URL：** 
- `/warehouse/multistorelocation/storelocation/detail`

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|long|物流仓id|

###请求参数Json格式
 
```
{
 "id": "1",
 "tokenId": "170442721aa74c28be5201a001386c57"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|storeLocationCode|是|String| 储位编码|
|storeLocationName|是|String| 储位名称|
|area|是|String| 区|
|column|是|String| 列|
|row|是|String| 行|
|layer|是|String| 层|
|tunnel|是|String| 巷道|
|status|是|boolean| true 活跃 false 停用|
|isDefault|是否默认|boolean| true 是 false 否|
|remark|是|String| 备注|
|createDate|是|Date| 创建时间|
|createName|是|String| 创建人|
|——logisticsWarehouseDetailResp|是|Object| 多储位物流仓库|
|warehouseCode|是|String| 物流仓编码|
|warehouseName|是|String| 物流仓编码|
