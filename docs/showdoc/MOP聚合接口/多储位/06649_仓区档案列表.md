# 储区档案列表
 

**请求URL：** 
- `/warehouse/multistorelocation/warehouse/area/list/MYSQL `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|keyword|否|String|编号/名称|
|pageNo|是|int| 页码|
|pageSize|是|int| 分页大小|

###请求参数Json格式
 
```
{
 "keyword": "",
 "pageIndex": 1,
 "pageSize": 20,
 "sword": "",
 "pageNo": 1,
 "tokenId": "d791fdbc28a440179aa38fd6bdc663cc"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|long| id|
|warehouseAreaName|否|String| 仓区名称|
|warehouseAreaCode|否|String| 多储位物流仓仓区名称|
|status|否|String| 活跃状态|
|statusName|否|String| 活跃状态|
|status|否|String| 活跃状态|
|statusName|否|String| 活跃状态名称|
|isDefault|否|String| 是否默认|
|createDate|否|String| 创建时间|
|createName|否|String| 创建人|
|modifyDate|否|String| 更新时间|
|modifyName|否|String| 更新人|
|remark|否|String| 备注|
