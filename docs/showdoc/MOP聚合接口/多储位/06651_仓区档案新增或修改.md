# 仓区档案新增或修改
 

**请求URL：** 
- `/warehouse/multistorelocation/warehouse/area/save `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|long|仓区id|
|warehouseAreaCode|是|String|多储位物流仓仓区编码|
|warehouseAreaName|是|String| 多储位物流仓仓区名称|
|status|是|boolean| 活跃状态|
|remark|是|String| 备注|
|warehouseId|是|long| 物流仓id|

###请求参数Json格式
 
```
{
 "warehouseAreaName": "warehouseAreaName",
 "warehouseAreaCode": "warehouseAreaCode",
 "status": "true",
 "isDefault": "true",
 "remark": "remark",
 "warehouseId": "1",
 "tokenId": "170442721aa74c28be5201a001386c57"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|code|是|long| 编码|
|data|是|String| 数据|
|exceptionStackInfo|否|String| 异常栈信息|
|msg|否|String| 业务错误信息|
|success|否|String| 是否成功|


###返回参数Json格式
 
```
{
 "code": "200",
 "data": null,
 "exceptionStackInfo": "",
 "msg": "",
 "success": true,
 "traceId": ""
}
```
