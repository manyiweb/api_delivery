# 储位移库详情列表
 

**请求URL：** 
- `/warehouse/multistorelocation/storelocation/relocate/record/list/line/MYSQL `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|keyword|否|String|编号/名称|
|pageNo|是|int| 页码|
|pageSize|是|int| 分页大小|
|recordId|是|long| 记录id|

###请求参数Json格式
 
```
{
 "keyword": "",
 "pageIndex": 1,
 "pageSize": 20,
 "sword": "",
 "pageNo": 1,
 "tokenId": "d791fdbc28a440179aa38fd6bdc663cc"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|itemCode|是|long| 商品编码|
|imgUrl|是|string| 商品图片|
|itemName|否|String| 商品名称|
|skuBarcode|否|String| 规格编码|
|itemUnit|否|String| 实际单位|
|itemUnitQty|否|String| 实际单位数量|
|unit|否|String| 基本单位|
|unitQty|否|String| 基本单位数量|
|fromStoreLocationName|否|从储位名称| 创建人|
|fromStoreLocationCode|否|String| 从储位编码|
|toStoreLocationCode|否|String| 到储位编码|
|toStoreLocationName|否|String| 到储位名称|


###返回参数Json格式

```
{
 "code": "200",
 "data": {
 "content": [],
 "hasNextPage": false,
 "pageNo": 1,
 "pageSize": 20,
 "total": "0",
 "totalPage": 1
 },
 "exceptionStackInfo": "",
 "msg": "",
 "success": true,
 "traceId": ""
}
```
