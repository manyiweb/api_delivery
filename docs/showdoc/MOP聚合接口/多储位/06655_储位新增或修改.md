# 储位新增或修改

**请求URL：** 
- `/warehouse/multistorelocation/storelocation/save `

**请求方式：**
- ALL
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| ID|
|storeLocationCode|否|String| 储位编码|
|storeLocationName|否|String| 储位名称|
|warehouseId|否|Long| 物流仓库|
|storeAreaId|否|Long| 储区(logistics_warehouse_store_area)|
|area|否|Integer| 区|
|column|否|Integer| 列|
|row|否|Integer| 行|
|layer|否|Integer| 层|
|tunnel|否|Integer| 巷道|
|status|否|Boolean| 活跃状态|
|remark|否|String| 备注|
|isDefault|否|Boolean| 是否默认|

###请求参数Json格式
 
```
{
 "id" : 0,
 "storeLocationCode" : "String",
 "storeLocationName" : "String",
 "warehouseId" : 0,
 "storeAreaId" : 0,
 "area" : 0,
 "column" : 0,
 "row" : 0,
 "layer" : 0,
 "tunnel" : 0,
 "status" : true,
 "remark" : "String",
 "isDefault" : true
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
