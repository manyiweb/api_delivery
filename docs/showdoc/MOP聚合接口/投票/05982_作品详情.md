# 报名页详情
 

**请求URL：** 
- `/activity/vote/sign/up/apply/detail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long| id|

### 请求参数Json格式
 
```
{
 "id" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--voteId|否|Long|活动id |
|--email|否|String|邮箱 |
|--signUpDesc|否|String|报名描述 |
|--voteCount|否|Integer|总票数 |
|--voteOrderNo|否|Long|投票人数排行 |
|--auditStatus|否|Integer|审核状态，1：待审核，2：通过，3：不通过 |
|--auditStatusDesc|否|String|审核状态描述 |
|--auditRemark|否|String|审核备注 |
|--activityStatus|否|Boolean|活跃状态 |
|--voteAble|否|Boolean|是否可投票 |
|--images|否|List|图片集合 |
|--videos|否|List|视频集合 |
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : {
 "voteId" : 0,
 "email" : "String",
 "signUpDesc" : "String",
 "voteCount" : 0,
 "voteOrderNo" : 0,
 "auditStatus" : 0,
 "auditStatusDesc" : "String",
 "auditRemark" : "String",
 "activityStatus" : true,
 "images" : null,
 "videos" : null,
 "voteAble" : boolean
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
