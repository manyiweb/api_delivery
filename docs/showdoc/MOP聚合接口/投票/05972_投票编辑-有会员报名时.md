# 投票编辑-有会员报名时

**请求URL：** 
- `/activity/vote/update`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||
|signUpEndTime|是|DateTime|报名结束时间 |
|status|是|Boolean|活跃状态 |
|remark|是|String|备注 |
|activityRuleText|是|String|活动规则 |
|virtuallyItemExchangeStartTime|是|DateTime|虚拟商品兑奖开始时间 |
|virtuallyItemExchangeEndTime|是|DateTime|虚拟商品兑奖结束时间 |
|voteDecorate|是|Object|装修 |
|--id|否|Long||
|--voteId|否|Long|投票id |
|--title|否|String|标题 |
|--backgroundColor|否|String|背景颜色 |
|--shareWord|否|String|转发分享语 |
|--shareImgUrl|否|String|转发分享图 |
|--adImgUrls|否|List|广告图 |

### 请求参数Json格式
 
```
{
 "id" : 0,
 "signUpEndTime" : "DateTime",
 "status" : true,
 "remark" : "String",
 "activityRuleText" : "String",
 "virtuallyItemExchangeStartTime" : "DateTime",
 "virtuallyItemExchangeEndTime" : "DateTime",
 "voteDecorate" : {
 "id" : 0,
 "voteId" : 0,
 "title" : "String",
 "backgroundColor" : "String",
 "shareWord" : "String",
 "shareImgUrl" : "String",
 "adImgUrls" : null
 }
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
