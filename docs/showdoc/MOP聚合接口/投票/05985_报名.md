# 报名

**请求URL：** 
- `/activity/vote/sign/up/apply/saveOrUpdate`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|voteId|是|Long|活动id |
|resources|是|List|报名的作品信息 |
|--name|是|String|字段名称 |
|--type|是|String|字段类型，1文本，2数值，3手机号码，4邮箱，5图片，6视频 |
|--content|是|String|字段内容，如果是多个url则用英文分号隔开 |
|--isShow|是|Boolean|是否展示 |

### 请求参数Json格式
 
```
{
 "voteId" : 0,
 "resources" : [{
 "name" : "String",
 "type" : "String",
 "content" : "String",
 "isShow" : true
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
