# 同步商品
 

**请求URL：** 
- `/dock/third/synchronize/synchronizeProduct`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|platform|是|Integer| 同步平台 0 美团 1 饿了么 6 京东|
|companyId|是|String||

### 请求参数Json格式
 
```
{
 "platform" : 0,
 "companyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--fid|是|Long||
|--companyId|是|String| 门店ID|
|--platformItemId|是|Long| 平台商品ID|
|--platformItemName|否|String| 平台商品名称|
|--platformSku|是|String| 平台商品SKU|
|--platformSpecId|否|String| 平台商品规格ID|
|--platformSpecName|否|String| 平台商品规格名称|
|--price|否|Double| 商品价格|
|--platformQuantity|否|Double| 平台商品数量|
|--saleQuantity|否|Double| 可售数量|
|--itemId|否|String| 商品ID|
|--itemName|否|String| 商品名称|
|--sku|否|String| 商品SKU|
|--sourcePlatform|是|Integer| 来源平台 1 美团 2 饿了么 3 京东|
|--createDate|否|DateTime| 同步时间|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "fid" : 0,

 "platformItemId" : 0,
 "platformItemName" : "String",
 "platformSku" : "String",

 "platformSpecName" : "String",
 "price" : 0,
 "platformQuantity" : 0,
 "saleQuantity" : 0,
 "itemId" : "String",
 "itemName" : "String",
 "sku" : "String",
 "sourcePlatform" : 0,
 "createDate" : "DateTime"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
