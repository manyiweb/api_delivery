# 设置继承品牌
 

**请求URL：** 
- `/hr/trainCurricula/apply/setInherit`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|isInherit|是|Integer||
|companyId|是|String||
|type|是|String||

### 请求参数Json格式
 
```
{
 "isInherit" : 0,
 "companyId" : "String",
 "type" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Boolean||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : true,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
