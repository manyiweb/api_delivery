# 保存司机管理

**请求URL：** 
- `/config/wmc/driver/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long|id |
|driverCode|否|String|司机编码 |
|phone|否|String|手机号 |
|driverName|否|String|司机 |
|activeState|否|Boolean|活跃状态 |
|companyId|否|String|商户id |
|sysChangeDate|否|DateTime|最后修改时间 |

### 请求参数Json格式
 
```
{
 "id" : 0,
 "driverCode" : "String",
 "phone" : "String",
 "driverName" : "String",
 "activeState" : true,
 "companyId" : "String",
 "sysChangeDate" : "DateTime"
}
```
