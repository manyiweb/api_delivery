# 车辆管理获取

**请求URL：** 
- `/config/wmc/vehicle/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long| id|

### 请求参数Json格式
 
```
{
 "id" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long| id|
|--licenseNumber|否|String| 车牌号|
|--driverId|否|String| 司机|
|--driverName|否|String| 司机|
|--activeState|否|Integer| 活跃状态|
|--createDate|否|DateTime| 创建时间|
|--createName|否|String| 创建人|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "licenseNumber" : "String",
 "driverId" : "String",
 "driverName" : "String",
 "activeState" : 0,
 "createDate" : "DateTime",
 "createName" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
