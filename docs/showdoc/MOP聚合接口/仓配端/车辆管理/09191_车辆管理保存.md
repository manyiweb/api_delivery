# 车辆管理保存

**请求URL：** 
- `/config/wmc/vehicle/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|
|licenseNumber|是|String| 车牌号|
|driverId|否|Long| 司机id|
|driverName|否|String| 司机名称|
|activeState|是|Boolean| 活跃状态|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "licenseNumber" : "String",
 "driverId" : 0,
 "driverName" : "String",
 "activeState" : true
}
```
