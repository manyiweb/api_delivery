# 切换-登录角色

**请求URL：** 
- `/manage/app/common/login/changeRole`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|loginType|是|String| 登录平台|
|tokenId|是|String| 令牌|

### 请求参数Json格式
 
```
{
 "loginType" : "String",
 "tokenId" : "String"
}
```

### 返回参数

返回参数与登录接口一致，详情见 http://xiaoyaoji.reabam.com/doc/47OWXhhsg
