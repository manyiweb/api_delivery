# 获取登录品牌

**请求URL：** 
- `/manage/staffGroup/loginGroup`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|userCode|是|String| 用户账号|
|pageIndex|否|Integer||
|pageSize|否|Integer||
|orderField|否|String||
|orderSort|否|String||

### 请求参数Json格式
 
```
{
 "userCode" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--pageIndex|否|Integer||
|--pageSize|否|Integer||
|--pageCount|否|Integer||
|--totalCount|否|Long||
|--first|否|Boolean||
|--last|否|Boolean||
|--content|否|List||
|----sgId|否|String| 用户应用品牌id|
|----status|否|Integer| 是否品牌用户|
|----statusName|否|String| 是否品牌用户|
|----isDefault|否|Integer| 是否当前登录品牌|
|----isActive|否|Integer| 是否活跃 1是0否|
|----roleCode|否|String| 角色编码|
|----roleName|否|String| 角色名称|
|----groupId|否|String| 品牌id|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "pageIndex" : 0,
 "pageSize" : 0,
 "pageCount" : 0,
 "totalCount" : 0,
 "first" : true,
 "last" : true,
 "content" : [{
 "sgId" : "String",
 "status" : 0,
 "statusName" : "String",
 "isDefault" : 0,
 "isActive" : 0,
 "roleCode" : "String",
 "roleName" : "String",
 "groupId" : "String"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
