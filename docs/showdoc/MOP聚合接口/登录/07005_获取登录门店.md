# 获取登录门店
 

**请求URL：** 
- `/manage/staffComp/loginComp`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|userCode|是|String| 用户账号|
|pageIndex|否|Integer||
|pageSize|否|Integer||
|orderField|否|String||
|orderSort|否|String||

### 请求参数Json格式
 
```
{
 "userCode" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--pageIndex|否|Integer||
|--pageSize|否|Integer||
|--pageCount|否|Integer||
|--totalCount|否|Long||
|--first|否|Boolean||
|--last|否|Boolean||
|--content|否|List||
|----isGroupActive|否|Integer| 品牌活跃状态|
|----scId|否|String| 用户关联商户id|
|----groupId|否|String| 品牌id|
|----status|否|String| 状态|
|----statusName|否|String| 状态名称|
|----isDefault|否|Integer| 是否当前门店|
|----isActive|否|Integer| 是否启用|
|----userType|否|String| 用户角色类型|
|----userTypeName|否|String| 用户角色类型名称|
|----companyName|否|String| 商户名称|
|----companyCode|否|String| 商户编码|
|----companyId|否|String| 商户id|
|----province|否|String| 省份|
|----city|否|String| 城市|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
