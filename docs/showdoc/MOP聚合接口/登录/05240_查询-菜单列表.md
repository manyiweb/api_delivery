# 查询-菜单列表

**请求URL：** 
- `/manage/app/menu/list`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|roleCode|是|String| 角色编码|

### 请求参数Json格式
 
```
{
 "roleCode" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--fid|否|String| 菜单id|
|--funCode|否|String| 菜单编码|
|--funName|否|String| 菜单名称|
|--status|否|String| 状态|
|--isDisplay|否|Integer| 是否展示|
|--lineId|否|Integer| 行号|
|--aliasName|否|String| 别名|
|--parentId|否|String| 父菜单id|
|--ftype|否|String| 类型：fun-功能;menu-菜单|
|--childrens|否|List| 子菜单列表|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : [{
 "fid" : "String",
 "funCode" : "String",
 "funName" : "String",
 "status" : "String",
 "isDisplay" : 0,
 "lineId" : 0,
 "aliasName" : "String",
 "parentId" : "String",
 "ftype" : "String",
 "childrens" : null
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
