# 查询-已授权的平台列表

**请求URL：** 
- `/manage/app/available/platform/list`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|mobile|否|String| 手机号|
|loginWord|否|String| 密码|
|workWeixinAuthCode|否|String| 企业微信授权码|
|workWeixinAuthCodeType|否|String| 企业微信授权码类型:AUTH_CODE(小程序授权码)、WEB_AUTH_CODE(桌面应用授权码)、QRCODE_AUTH_CODE(扫码登录授权码)|
|loginMethod|否|Integer| 登录方式:1-账号密码登录(默认);2-企业微信web授权码登录|

### 请求参数Json格式
 
```
{
 "mobile" : "String",
 "loginWord" : "String",
 "workWeixinAuthCode" : "String",
 "workWeixinAuthCodeType" : "String",
 "loginMethod" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--sysNo|否|String| 平台编码|
|--sysName|否|String| 平台名称|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : [{
 "sysNo" : "String",
 "sysName" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
