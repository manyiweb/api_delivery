# 保存自定义页面路由设置
 

**请求URL：** 
- `/reabam-wx/custom/page/route/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|groupId|是|String| 品牌id|
|enableCustomPageRoute|是|Boolean| 是否开启自定义页面路由|
|customPageRouteDetailList|否|List| 配置|
|--id|否|Long| id|
|--code|否|String| 页面编码|
|--name|否|String| 页面名称|
|--pageType|否|Integer| 页面类型 0：小程序页面 1：H5页面|
|--customPage|否|String| 自定义页面路径|
|--isActive|否|Boolean| 活跃状态|

### 请求参数Json格式
 
```
{
 "groupId" : "String",
 "enableCustomPageRoute" : true,
 "customPageRouteDetailList" : [{
 "id" : 0,
 "code" : "String",
 "name" : "String",
 "pageType" : 0,
 "customPage" : "String",
 "isActive" : true
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
