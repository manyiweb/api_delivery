# 中信收款主账户 - 新增|编辑

**请求URL：** 
- `/b2b/citic/main-account/save`

**请求方式：** 
- `POST`
- `RequestBody`


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 主账户ID，新增时为空|
|accountName|是|String| 账户名称|
|bank|否|String| 开户银行|
|bankAccount|是|String| 银行账号|
|active|否|Boolean| 是否启用|
|isDefault|否|Boolean| 是否默认账户|
|remark|否|String| 备注|
|companyId|是|String| 品牌商ID或门店ID|

### 请求参数Json格式
 
```
{
 "id":0,
 "accountName":"String",
 "bank":"String",
 "bankAccount":"String",
 "active":true,
 "isDefault":true,
 "remark":"String",
 "companyId":"String"
}
```

### 响应参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 响应参数Json格式
 
```
{
 "data":null,
 "msg":"String",
 "code":"String",
 "exceptionStackInfo":"String",
 "traceId":"String"
}
```
