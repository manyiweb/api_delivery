# 中台系统配置数据图表排序

**请求URL：** 
- `/report/dynamicDataChart/manager/manage/serialChartApply `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|action|否|Integer| 行为 0-上移 1-下移 2-置顶|
|applyId|否|Long||
|applyIdList|否|List| 报表顺序列表（前端的移动后的列表排序）|

###请求参数Json格式
 
```
{
 "action" : 0,
 "applyId" : 0,
 "applyIdList" : null
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
