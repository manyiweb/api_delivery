# 中台配置查询动态报表列表

**请求URL：** 
- `/report/dynamicDataChart/manager/manage/chartList `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|chartId|否|Long| chartId|
|applyIdList|否|List| applyIdList|
|applyId|否|Long| applyId|
|dynamicChartCategory|否|Integer| 图表数据类型(非必填),0=会员,1=商品,2=库存,3=零售,4=订货,5=供应,6=协同,7=入库,8=出库,9=存货|
|dynamicChartType|否|Integer| 图表类型(非必填),0=数据看板,1=曲线图,2=条形图,3=饼形图,4=指标|
|customerDynamicChartType|否|Integer| h5助手端查询图表类型,0=数据看板,1=除了数据看板之外所有的|
|sword|否|String| 报表关键字,非必填|
|platformType|否|Integer| 应用平台类型, 0=商户端,1=管理端|
|isSubChart|否|Boolean| 是否为子图表|
|applyScope|否|Integer| 应用范围,0=全部品牌,1=指定品牌|
|isEnable|否|Boolean| 是否启用|

###请求参数Json格式
 
```
{
 "chartId" : 0,
 "applyIdList" : null,
 "applyId" : 0,
 "dynamicChartCategory" : 0,
 "dynamicChartType" : 0,
 "customerDynamicChartType" : 0,

 "platformType" : 0,
 "isSubChart" : true,
 "applyScope" : 0,
 "isEnable" : true
}
```
