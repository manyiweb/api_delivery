# 查询当前用户已添加的图表和菜单

**请求URL：** 
- `/dataChart/userChartList `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|moduleId|否|Long| 模块ID|
|chartCategory|否|Integer| 报表类型(非必填),0=会员,1=商品,2=库存,3=零售,4=订货,5=供应,6=协同,7=入库,8=出库,9=存货|
|dynamicChartType|否|Integer| 图表类型(非必填),null=查询全部,0=查询看板,1=查询图表|
|moduleIdList|否|List| 模块IDList|
|platformType|否|Integer| 应用平台类型, 0=商户端(默认),1=管理端|

###请求参数Json格式
 
```
{
 "moduleId" : 0,
 "chartCategory" : 0,
 "dynamicChartType" : 0,
 "moduleIdList" : null,
 "platformType" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--chartId|否|Long| 图表ID|
|--dynamicChartType|否|Integer| 图表类型,0=数据看板,1=曲线图,2=条形图,3=饼形图,4=指标|
|--icon|否|String| 图标|
|--chartName|否|String| 图表名称|
|--chartDesc|否|String| 图表描述|
|--isSubChart|否|Boolean| 是否为子图表|
|--subCartTitle|否|String| 子图表标题|
|--applyScope|否|Integer| 应用范围,0=全部品牌,1=指定品牌|
|--isEnable|否|Boolean| 是否启用|
|--platformType|否|Integer| 应用平台类型, 0=商户端(默认),1=管理端|
|--chartCategory|否|Integer| 图表数据类型,0=会员,1=商品,2=库存,3=零售,4=订货,5=供应,6=协同,7=入库,8=出库,9=存货|
|--dynamicChartTypeName|否|String| 图表类型名称|
|--mainDataChartId|否|Long| 主图表Id|
|--mainDataChartName|否|String| 主图表名称|
|--applyId|否|Long| 应用id|
|--roleCodeList|否|List| 角色权限列表|
|--moduleId|否|Long| 模块ID|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
