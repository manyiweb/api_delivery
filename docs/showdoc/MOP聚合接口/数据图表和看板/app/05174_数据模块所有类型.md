# 数据模块所有类型

**请求URL：** 
- `/reabam-work-weixin-service/dataChart/categoryTypeList `


**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|moduleType|否|Integer| 模块类型,0=常用,1=数据看板,2=数据图表,非必填|
|platformType|否|Integer| 应用平台类型, 0=商户端(默认),1=管理端|

###请求参数Json格式
 
```
{
 "moduleType" : 0,
 "platformType" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--typeCode|否|Integer| 类型code,0=会员,1=商品,2=库存,3=零售,4=订货,5=供应,6=协同,7=入库,8=出库,9=存货|
|--typeName|否|String| 类型名称|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : [{
 "typeCode" : 0,
 "typeName" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
