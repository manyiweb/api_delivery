# 商户首页用户模块列表(包括图表和常用功能)

**请求URL：** 
- `/dataChart/userModule/listAll `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|moduleId|否|Long| 模块ID,非必填|
|moduleType|否|Integer| 模块类型,0=常用.1=数据看板,2=数据图表,非必填|
|platformType|否|Integer| 应用平台类型, 0=商户端(默认),1=管理端|

###请求参数Json格式
 
```
{
 "moduleId" : 0,
 "moduleType" : 0,
 "platformType" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--moduleId|否|Long| 模块ID|
|--moduleType|否|Integer| 模块类型,0=常用.1=数据看板,2=数据图表|
|--typeName|否|String| 模块类型名|
|--moduleName|否|String| 模块名|
|--staffId|否|String| 用户ID|
|--companyId|否|String| 用户门店ID|
|--sortNo|否|Integer| 排序号|
|--remark|否|String| 备注|
|--chartList|否|List| 模块所有图表,模块类型moduleType=1/2时|
|----chartId|否|Long| 图表ID|
|----dynamicChartType|否|Integer| 图表类型,0=数据看板,1=曲线图,2=条形图,3=饼形图,4=指标|
|----icon|否|String| 图标|
|----chartName|否|String| 图表名称|
|----chartDesc|否|String| 图表描述|
|----isSubChart|否|Boolean| 是否为子图表|
|----subCartTitle|否|String| 子图表标题|
|----applyScope|否|Integer| 应用范围,0=全部品牌,1=指定品牌|
|----isEnable|否|Boolean| 是否启用|
|----platformType|否|Integer| 应用平台类型, 0=商户端(默认),1=管理端|
|----chartCategory|否|Integer| 图表数据类型,0=会员,1=商品,2=库存,3=零售,4=订货,5=供应,6=协同,7=入库,8=出库,9=存货|
|----dynamicChartTypeName|否|String| 图表类型名称|
|----mainDataChartId|否|Long| 主图表Id|
|----mainDataChartName|否|String| 主图表名称|
|----applyId|否|Long| 应用id|
|----roleCodeList|否|List| 角色权限列表|
|----moduleId|否|Long| 模块ID|
|--funMenuList|否|List| 常用功能菜单,模块类型moduleType=0时|
|----funId|否|String| 菜单id|
|----aliasName|否|String| 别名|
|----lineId|否|String| 行id|
|----funCode|否|String| 权限编码|
|----isDisplay|否|Integer| 是否显示|
|----funName|否|String| 功能名|
|----parentFunCode|否|String| 父权限编码|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
