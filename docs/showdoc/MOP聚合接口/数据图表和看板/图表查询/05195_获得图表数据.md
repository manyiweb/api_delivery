# 获得图表数据
 

**请求URL：** 
- `/report/dynamic/dataChart/query`

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|chartId|是|Long| 图表ID|
|timeDimension|是|Integer| 时间维度,0=按日,1=按周,2=按月,3=按季|
|params|是|Map| 动态表达式参数|

###请求参数Json格式
 
```
{
 "chartId" : 0,
 "timeDimension" : 0,
 "params" : null
}
```

### 数据看板 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--mainColumnData|否|Object| 主数据标题|
|----columnTitle|否|String| 字段名称|
|----columnValue|否|Object| 字段值|
|--firstAdditionalColumnData|否|Object| 第一行附加数据标题|
|----columnTitle|否|String| 字段名称|
|----columnValue|否|Object| 字段值|
|--secondAdditionalColumnData|否|Object| 第二行附加数据|
|----columnTitle|否|String| 字段名称|
|----columnValue|否|Object| 字段值|
|--chartId|否|Long| 图表ID|
|--chartName|否|String| 图表名称|
|--dynamicChartType|否|Integer| 图表类型 0-数据看板 1-曲线图 2-条形图 3-饼形图 4-指标|
|--dynamicChartCategory|否|Integer| 图表数据类型|
|--chartDesc|否|String| 图表描述|
|--subChartTitle|否|String| 子报表名称|
|--subChartList|否|List| 子报表列表|
|----chartId|否|Long| 图表ID|
|----subChartTitle|否|String| 子图表名称|
|----isSelected|否|Boolean| 是否当前选中|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
