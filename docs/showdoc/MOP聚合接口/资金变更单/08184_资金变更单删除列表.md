# 删除

**请求URL：** 
- `/b2b/fund/change/order/delete`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|isAll|否|Boolean| 是否全部删除|
|idList|是|List||
|fidList|否|List||

### 请求参数Json格式
 
```
{
 "isAll" : true,
 "idList" : null,
 "fidList" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
