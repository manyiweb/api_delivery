# 自定义交易组件-类目审核

**请求URL：** 
- `/wx/component/transaction/spu/shop/audit/category `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|wxSn|否|String| wxSn|
|license|否|List| 营业执照或组织机构代码证，图片url|
|categoryInfo|否|Object| 资质类目信息|
|--level1|否|Integer| 一级类目|
|--level1Name|否|String| 一级类目姓名|
|--level2|否|Integer| 二级类目|
|--level2Name|否|String| 二级类目姓名|
|--level3|否|Integer| 三级类目|
|--level3Name|否|String| 三级类目姓名|
|--certificate|否|List| 资质材料|
|--firstCategoryId|否|Integer| 小程序的一级类目|
|--firstCategoryName|否|String| 小程序的一级类目名|
|--secondCategoryId|否|Integer| 小程序的一级类目|
|--secondCategoryName|否|String| 小程序的一级类目名|
|sceneGroupList|否|List| 商品使用场景,1:视频号，3:订单中|

###请求参数Json格式
 
```
{
 "wxSn" : "String",
 "license" : null,
 "categoryInfo" : {
 "level1" : 0,
 "level1Name" : "String",
 "level2" : 0,
 "level2Name" : "String",
 "level3" : 0,
 "level3Name" : "String",
 "certificate" : null,
 "firstCategoryId" : 0,
 "firstCategoryName" : "String",
 "secondCategoryId" : 0,
 "secondCategoryName" : "String"
 },
 "sceneGroupList" : null
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
