# 自定义交易组件-获取商品类目

**请求URL：** 
- `/wx/component/transaction/spu/shop/cat/get `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|wxSn|否|String| wxSn|

###请求参数Json格式
 
```
{
 "wxSn" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--thirdCatId|否|Integer| 类目ID|
|--thirdCatName|否|String| 类目名称|
|--qualification|否|String| 类目资质|
|--qualificationType|否|Integer| 类目资质类型,0:不需要,1:必填,2:选填|
|--productQualification|否|String| 商品资质|
|--productQualificationType|否|Integer| 商品资质类型,0:不需要,1:必填,2:选填|
|--secondCatId|否|Integer| 二级类目ID|
|--secondCatName|否|String| 二级类目名称|
|--firstCatId|否|Integer| 一级类目ID|
|--firstCatName|否|String| 一级类目名称|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : [{
 "thirdCatId" : 0,
 "thirdCatName" : "String",
 "qualification" : "String",
 "qualificationType" : 0,
 "productQualification" : "String",
 "productQualificationType" : 0,
 "secondCatId" : 0,
 "secondCatName" : "String",
 "firstCatId" : 0,
 "firstCatName" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
