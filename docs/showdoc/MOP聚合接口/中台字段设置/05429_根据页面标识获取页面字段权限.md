# 根据页面标识获取页面字段权限

**请求URL：** 
- `/config/fieldSettingPage/getPageFields/byPageCode`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|pageCode|是|String| 表 field_setting_page 字段 page_code|
|applyGroupId|否|String| 应用的品牌/商户Id(非必填)|

### 请求参数Json格式
 
```
{
 "pageCode" : "String",
 "applyGroupId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--hasPermission|否|Boolean| 用户角色是否有权限|
|--roleCount|否|Integer| 字段设置角色个数|
|--typeId|否|Long| 业务单据类型Id|
|--pageId|否|Long| 页面Id|
|--fieldId|否|Long| 页面字段id|
|--applyId|否|Long| Id|
|--applyGroupId|否|String| 应用的品牌/商户Id|
|--fieldCode|否|String| 字段编码|
|--fieldName|否|String| 字段名称|
|--sortNo|否|Integer| 排序号|
|--isShow|否|Boolean| 是否显示,true=显示,false=不显示|
|--isActive|否|Boolean| 是否活跃,true=显示,false=不显示|
|--allowChangeActive|否|Boolean| 是否允许修改活跃状态,true=允许,false=不允许|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : [{
 "hasPermission" : true,
 "roleCount" : 0,
 "typeId" : 0,
 "pageId" : 0,
 "fieldId" : 0,
 "applyId" : 0,
 "applyGroupId" : "String",
 "fieldCode" : "String",
 "fieldName" : "String",
 "sortNo" : 0,
 "isShow" : true,
 "isActive" : true,
 "allowChangeActive" : true
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
