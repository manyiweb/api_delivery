# 同步商品信息回调

**请求URL：** 
- `/dock/mt/v2/order/synchronizeProduct`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|op_type|否|Integer| 变更类型。1:新增或修改 2:删除|
|business_module|否|Integer| 变更的业务模块。1:菜品类接口，2:门店装修类，3:门店类，4:配送范围类|
|notice_msg|否|String| 提示文案|
|utime|否|Long| 变更时间戳|

### 请求参数Json格式
 
```
{
 "op_type" : 0,
 "business_module" : 0,
 "notice_msg" : "String",
 "utime" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
