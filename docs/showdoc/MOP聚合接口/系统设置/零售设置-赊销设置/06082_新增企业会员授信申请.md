# 新增企业会员授信申请
 服务：config

**请求URL：** 
- `/config/superMember/creditSet/apply/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 门店ID|
|companyCode|是|String| 门店编码|
|companyName|是|String| 门店名称|
|memberId|是|String| 会员ID，关联smember表|
|memberName|否|String| 会员姓名|
|memberPhone|否|String| 手机号
 |
|amount|是|Double| 追加授信金额（单位：元）|
|applyReason|否|String| 申请原因|

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "companyCode" : "String",
 "companyName" : "String",
 "memberId" : "String",
 "memberName" : "String",
 "memberPhone" : "String",
 "amount" : 0,
 "applyReason" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
