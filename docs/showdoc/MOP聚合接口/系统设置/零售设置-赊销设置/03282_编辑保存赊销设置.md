# 功能描述: 编辑保存赊销设置
 

**请求URL：** 
- `/config/creditSet/save `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|allMember|否|Boolean| 应用所有会员（true-是，false-否）|
|creditAmount|否|Double| 授信金额（单位：元）|
|addCreditSetDetails|否|List| 新增赊销账期明细对象集合|
|--id|否|Long| 主键标识|
|--memberId|否|String| 会员ID|
|--memberName|否|String| 会员姓名|
|--memberPhone|否|String| 手机号|
|--amount|否|Double| 授信金额（单位：元）|
|--time|否|Integer| 账期（单位：天） 如果是固定还款日就是日|
|delCreditSetDetailIds|否|List| 删除赊销账期明细ID集合|
|settingType|否|Integer| 赊销类型|
|expireCanCredit|否|Boolean| 未还款是否允许赊销|
|time|否|Integer| 账期（单位：天）|

###请求参数Json格式
 
```
{
 "allMember" : true,
 "creditAmount" : 0,
 "addCreditSetDetails" : [{
 "id" : 0,
 "memberId" : "String",
 "memberName" : "String",
 "memberPhone" : "String",
 "amount" : 0,
 "time" : 0
 }],
 "delCreditSetDetailIds" : null,
 "settingType" : 0,
 "expireCanCredit" : true,
 "time" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
