# 功能描述: 查询赊销设置
 

**请求URL：** 
- `/config/creditSet/list`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|否|String||
|pageIndex|是|Integer||
|pageSize|是|Integer||
|sword|否|String||

### 请求参数Json格式
 
```
{
 "tokenId" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "sword" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--allMember|否|Boolean| 应用所有会员（1-是，0-否）|
|--creditAmount|否|Double| 授信金额（单位：元）|
|--creditSetDetail|否|List| 赊销账期设置(分页)|
|----id|否|Long| 主键标识|
|----memberId|否|String| 会员ID|
|----memberName|否|String| 会员姓名|
|----memberPhone|否|String| 手机号|
|----amount|否|Double| 授信金额（单位：元）|
|----settingType|否|Integer| 赊销类型|
|----time|否|Integer| 账期（单位：天） 如果是固定还款日就是日|
|----cardNo|否|String| 会员卡号|
|----isSuperMember|否|Boolean| 会员卡号|
|----multiplyTime|否|List| 启用指定会员，固定账期时传多个时间
 |
|--memberCreditSetDetail|否|Object| 赊销会员设置(分页)|
|----pageIndex|否|Integer||
|----pageSize|否|Integer||
|----pageCount|否|Integer||
|----totalCount|否|Long||
|----first|否|Boolean||
|----last|否|Boolean||
|----content|否|List||
|------id|否|Long| 主键标识|
|------memberId|否|String| 会员ID|
|------memberName|否|String| 会员姓名|
|------memberPhone|否|String| 手机号|
|------amount|否|Double| 授信金额（单位：元）|
|------settingType|否|Integer| 赊销类型|
|------time|否|Integer| 账期（单位：天） 如果是固定还款日就是日|
|------cardNo|否|String| 会员卡号|
|------isSuperMember|否|Boolean| 会员卡号|
|------multiplyTime|否|List| 启用指定会员，固定账期时传多个时间
 |
|--settingType|否|Integer| 设置类型 (0:按账期设置,1:按固定还款日设置)|
|--expireCanCredit|否|Boolean| 未还款是否允许赊销|
|--time|否|Integer| 账期（单位：天）|
|--openSpecialCreditMember|否|Integer| 启用特殊赊销会员|
|--specialCreditSetDetails|否|Object| 特殊会员赊销账期明细对象集合|
|----pageIndex|否|Integer||
|----pageSize|否|Integer||
|----pageCount|否|Integer||
|----totalCount|否|Long||
|----first|否|Boolean||
|----last|否|Boolean||
|----content|否|List||
|------id|否|Long| 主键标识|
|------memberId|否|String| 会员ID|
|------memberName|否|String| 会员姓名|
|------memberPhone|否|String| 手机号|
|------amount|否|Double| 授信金额（单位：元）|
|------settingType|否|Integer| 赊销类型|
|------time|否|Integer| 账期（单位：天） 如果是固定还款日就是日|
|------cardNo|否|String| 会员卡号|
|------isSuperMember|否|Boolean| 会员卡号|
|------multiplyTime|否|List| 启用指定会员，固定账期时传多个时间
 |
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
