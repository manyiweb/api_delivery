# 产品装修 - 商户列表 - 维护
 

**请求URL：** 
- `/config/meal/mallModuleCompany/edit`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|showTag|是|Integer| 是否显示商户标签 1是0否|
|showBusiness|是|Integer| 是否显示营业状态 1是0否|
|showByLabel|是|Integer| 是否按商户标签分组显示门店列表 1是0否|
|title|是|String| 标题名称|
|logo|否|String| logo|
|showAlias|否|Integer| 是否显示商户别名 1是 0否|

### 请求参数Json格式
 
```
{
 "showTag" : 0,
 "showBusiness" : 0,
 "showByLabel" : 0,
 "title" : "String",
 "logo" : "String",
 "showAlias" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
