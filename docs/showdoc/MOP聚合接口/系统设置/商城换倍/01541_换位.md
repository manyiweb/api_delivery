# 换倍率换位
 

**请求URL：** 
- `/config/mallRedoubled/op `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|String| 订单标识|
|type|是|String| down 下移，up 上移 ，top 置顶|
|companyId|是|String| 门店|

###请求参数Json格式
 
```
{
 "id" : "String",
 "type" : "String",
 "companyId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String"
}
```
