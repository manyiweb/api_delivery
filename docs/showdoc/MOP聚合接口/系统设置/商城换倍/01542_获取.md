# 换倍率换位
 

**请求URL：** 
- `/config/mallRedoubled/get `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 门店|
|pageIndex|否|Integer| 页码值|
|pageSize|否|Integer| 页大小|

###请求参数Json格式
 
```
{
 "companyId" : "String",
 "pageIndex" : 0,
 "pageSize" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--inherit|否|Integer| 是否继承品牌设置 （1启用 0不启用）|
|--openFunction|否|Integer| 是否启用商户返点（1启用 0不启用）|
|--openFunctionMust|否|Integer| 是否必填项（1启用，0停用）|
|--commonDatas|否|Object| 数据|
|----pageIndex|否|Integer| 页码|
|----pageSize|否|Integer| 显示记录数|
|----pageCount|否|Integer| 总页数|
|----totalCount|否|Long| 总记录数|
|----first|否|Boolean| 首页|
|----last|否|Boolean| 尾页|
|----content|否|List| 分页数据|
|------id|否|Long| 主键|
|------companyId|否|String| 门店Id|
|------lineNum|否|Integer| 排序号|
|------value|否|Double| 换倍率|
|------isDefault|否|Integer| 默认（1是 0否）|
|------groupId|否|String| 品牌商Id|
|------createId|否|String| 创建人|
|------createName|否|String| 创建人|
|------createDate|否|DateTime| 创建时间|
|------modifyId|否|String| 修改人|
|------modifyName|否|String| 修改人|
|------modifyDate|否|DateTime| 修改时间|
|msg|否|String| 消息|
|code|否|String| 业务代码|

 "id" : 0,
 "companyId" : "String",
 "lineNum" : 0,
 "value" : 0,
 "isDefault" : 0,

 "createName" : "String",
 "createDate" : "DateTime",
 "modifyId" : "String",
 "modifyName" : "String",

 }]
 }
 },
 "msg" : "String",
 "code" : "String"
}
