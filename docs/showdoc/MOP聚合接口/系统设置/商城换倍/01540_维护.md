# 换倍率新增
 

**请求URL：** 
- `/config/mallRedoubled/add `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|inherit|是|Integer| 是否继承品牌设置 （1启用 0不启用）|
|openFunction|是|Integer| 是否启用商户返点（1启用 0不启用）|
|openFunctionMust|是|Integer| 是否必填项（1启用，0停用）|
|commonDatas|否|List| 数据|
|--value|是|Double| 商户|
|--isDefault|否|Integer| 是否默认|
|--id|否|String| id(存在时为编辑)|
|companyId|是|String| 商户|
|ids|否|List| 删除的id|

###请求参数Json格式
 
```
{
 "inherit" : 0,
 "openFunction" : 0,
 "openFunctionMust" : 0,
 "commonDatas" : [{
 "value" : 0,
 "isDefault" : 0,
 "id" : "String"
 }],
 "companyId" : "String",
 "ids" : null
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String"
}
```
