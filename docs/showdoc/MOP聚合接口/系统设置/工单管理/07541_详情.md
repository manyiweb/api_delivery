# 详情

**请求URL：** 
- `/config/workOrder/info`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||

### 请求参数Json格式
 
```
{
 "id" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long||
|--productPort|否|String| 产品端口|
|--priority|否|String| 优先级（高、中、低）|
|--title|否|String| 工单标题|
|--description|否|String| 问题描述|
|--type|否|int| 问题分类（1需求、2bug、3非系统问题）|
|--iteration|否|String| 迭代|
|--status|否|int| 状态 默认0待处理、1处理中、2已完成、3已关闭|
|--acceptStatus|否|int| 受理状态 默认0待受理、1已受理、2已拒绝|
|--acceptDate|否|DateTime| 受理时间|
|--acceptId|否|String| 受理人ID|
|--acceptName|否|String| 受理人名字|
|--acceptRemark|否|String| 受理备注|
|--attachments|否|List| 附件|
|----attachmentId|否|String||
|----fileName|否|String||
|----fileSize|否|Long||
|----fileUrl|否|String||
|----fileFullUrl|否|String||
|----fileOrgName|否|String||
|----fileSuffix|否|String||
|----sourceId|否|String||
|----sourceTable|否|String||
|----createId|否|String||
|----createName|否|String||
|----createDate|否|DateTime||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
