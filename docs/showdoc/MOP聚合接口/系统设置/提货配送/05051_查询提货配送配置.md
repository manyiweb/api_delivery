# 查询提货配送配置

**请求URL：** 
- `/itemDelivery/info`

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 门店id|
|deliveryType|是|Integer| 0到店自提1快递配送2同城配送|
|sword|否|String| 搜索字|
|pageIndex|否|Integer| 页号|
|pageSize|否|Integer| 页大小|
|orderField|否|String| 商品排序字段【不用】|
|orderSort|否|String| 商品排序方式 desc 倒序 asc 正序【不用】|

###请求参数Json格式
 
```
{
 "companyId" : "String",
 "deliveryType" : 0,
 "sword" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--active|否|Integer| 是否启用1启用0不启用|
|--itemType|否|Integer| 0指定商品1指定品牌系列类别|
|--itemDetailList|否|List| 商品详情信息|
|----id|否|Long||
|----itemName|是|String| 商品名称|
|----itemCode|是|String| 商品编号|
|----itemId|否|String| 商品id|
|----skuBarCode|是|String| 商品sku|
|--cbsDetailList|否|List| 类别品牌系列详情信息|
|----id|否|Long||
|----type|是|Integer| 0类别1品牌2系列|
|----name|是|String| 名称|
|--pageIndex|否|Integer| 页码|
|--pageSize|否|Integer| 显示记录数|
|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|--first|否|Boolean| 首页|
|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
