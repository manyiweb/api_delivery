# 保存提货配送配置

**请求URL：** 
- `/itemDelivery/save`

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|active|是|Integer| 是否启用1启用0不启用|
|itemType|是|Integer| 0指定商品1指定品牌系列类别|
|deliveryType|是|Integer| 0到店自提1快递配送2同城配送|
|companyId|是|String| 门店id|
|itemDetailList|否|List| 指定商品详情|
|--id|否|Long||
|--itemName|是|String| 商品名称|
|--itemCode|是|String| 商品编号|
|--itemId|否|String| 商品id|
|--specId|是|String| 商品specId|
|--skuBarCode|是|String| 商品sku|
|categoryBrandSeriesDetailList|否|List| 指定品牌系列类别详情|
|--id|否|Long||
|--type|是|Integer| 0类别1品牌2系列|
|--name|是|String| 名称|
|--code|是|String| 类别、品牌、系列的唯一标识|
|deleteItemDetailIdList|否|List| 要删除的指定商品id集合|
|deleteCbsDetailIdList|否|List| 要删除的指定品牌系列类别id集合|

###请求参数Json格式
 
```
{
 "active" : 0,
 "itemType" : 0,
 "deliveryType" : 0,
 "companyId" : "String",
 "itemDetailList" : [{
 "id" : 0,
 "itemName" : "String",
 "itemCode" : "String",
 "itemId" : "String",
 "specId" : "String",
 "skuBarCode" : "String"
 }],
 "categoryBrandSeriesDetailList" : [{
 "id" : 0,
 "type" : 0,
 "name" : "String",
 "code" : "String"
 }],
 "deleteItemDetailIdList" : null,
 "deleteCbsDetailIdList" : null
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|String| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : "String",
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
