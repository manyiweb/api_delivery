# 复制保存提货配送配置

**请求URL：** 
- `reabam-config/itemDelivery/copy`

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|fromCompanyId|是|String| 来源门店id|
|toCompanyIds|是|List| 目的地门店id|
|deliveryType|是|Integer| 0到店自提1快递配送2同城配送|

###请求参数Json格式
 
```
{
 "fromCompanyId" : "String",
 "toCompanyIds" : null,
 "deliveryType" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|String| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : "String",
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
