# 商城获取分类类型

**请求URL：** 
- `/b2b/appc/decoration/product/classify/getItemApply`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 微页面id|
|wxSn|否|String| 小程序wxSn|
|companyId|否|String| 门店id|
|groupId|否|String| 品牌id|
|isTemplate|否|Boolean| 用于兼容有模板的模块, 默认为true|
|code|是|String| 模块编码|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "wxSn" : "String",
 "companyId" : "String",
 "groupId" : "String",
 "isTemplate" : true,
 "code" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long||
|--isInherit|否|Integer| 是否继承商户|
|--companyId|否|String| 门店id|
|--templateId|否|Long| 装修模板id|
|--templateCode|否|String| 装修模板编码|
|--templateName|否|String| 装修模板名称|
|--applyType|否|Integer| 应用类型|
|--code|否|String| 模块编码|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "isInherit" : 0,
 "companyId" : "String",
 "templateId" : 0,
 "templateCode" : "String",
 "templateName" : "String",
 "applyType" : 0,
 "code" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
