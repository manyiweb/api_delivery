# 获取指定条件的链接
 

**请求URL：** 
- `/decoration/link/get_by_condition`

**请求方式：**
- POST
- FormData

###链接类型编码UrlTypeCode取值
U100 - 自定义页面

###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|includeUrlTypeCodes|否|String| 包含的链接类型|
|excludeUrlTypeCodes|否|String| 排除的链接类型|

###请求参数Json格式
 
```
{
 "includeUrlTypeCodes" : [],
 "excludeUrlTypeCodes" : ["U100"]
}
```

|----linkQuery|否|String| 链接query|

|--marketingLinks|否|List| 营销相关链接|
|----id|否|String| id|
|----urlTypeCode|否|String| 链接类型编码，与旧的对应|
|----urlTypeName|否|String| 链接名称|
|----url|否|String| 链接url|
|----linkQuery|否|String| 链接query|
|----choose|否|Integer| 是否需要选择内容 0:不需要 1：需要|
|--otherLinks|否|List| 其他链接|
