# 获取导航悬浮链接

**请求URL：** 
- `/meal-decoration/decoration/navigation/levitation/link/get`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
无参数


### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--id|否|String| id|
|--urlTypeCode|否|String| 链接类型编码，与旧的对应|
|--urlTypeName|否|String| 链接名称|
|--url|否|String| 链接url|
|--linkQuery|否|String| 链接query|
|--choose|否|Integer| 是否需要选择内容 0:不需要 1：需要|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "id" : "String",
 "urlTypeCode" : "String",
 "urlTypeName" : "String",
 "url" : "String",
 "linkQuery" : "String",
 "choose" : 0
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
