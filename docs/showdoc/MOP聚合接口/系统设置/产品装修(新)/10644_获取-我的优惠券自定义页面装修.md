# 获取-我的优惠券自定义页面装修
 

**请求URL：** 
- `/meal-decoration/decoration/myCoupon/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||
|templateCode|否|String| 模板编码 企业会员界面传 SuperMember|
|code|是|String| 模块编码|
|templateCode|否|String||
|id|否|Long||

### 请求参数Json格式
 
```
{
 "id" : 0,
 "templateCode" : "String",
 "code" : "String",
 "templateCode" : "String",
 "id" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--showMealCoupon|否|Boolean| 是否展示点单券|
|--showMallCoupon|否|Boolean| 是否展示电商券|
|--code|否|String| 模块编码|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "showMealCoupon" : true,
 "showMallCoupon" : true,
 "code" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
