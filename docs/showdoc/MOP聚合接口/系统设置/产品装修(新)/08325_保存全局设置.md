# 保存全局设置

**请求URL：** 
- `/decoration/group/setting/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|documentReq|否|Object| 购物卡别名|
|--shoppingCardName|否|String| 购物卡别名|
|--integralName|否|String| 积分别名|
|--integralUnitName|否|String| 积分单位别名(默认 分）|
|--couponName|否|String| 优惠券别名|
|--mealCouponName|否|String| 点单券别名|
|--groupCouponName|否|String| 团购券别名|
|--myCardName|否|String| 卡券/我的卡券别名|
|--mentityCardName|否|String| 礼品卡别名|
|--certificateCardName|否|String| 礼品券别名|
|--timesCardName|否|String| 次卡别名|
|--timesCardUnitName|否|String| 次卡单位名称|
|code|是|String| 模块编码|

### 请求参数Json格式
 
```
{
 "documentReq" : {
 "shoppingCardName" : "String",
 "integralName" : "String",
 "integralUnitName" : "String",
 "couponName" : "String",
 "mealCouponName" : "String",
 "groupCouponName" : "String",
 "myCardName" : "String",
 "mentityCardName" : "String",
 "certificateCardName" : "String",
 "timesCardName" : "String",
 "timesCardUnitName" : "String"
 
 },
 "code" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
