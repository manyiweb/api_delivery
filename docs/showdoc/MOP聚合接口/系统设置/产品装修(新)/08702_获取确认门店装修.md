# 获取确认门店装修

**请求URL：** 
- `/meal-decoration/decoration/confirm/store/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||
|templateCode|否|String| 模板编码 企业会员界面传 SuperMember|
|code|是|String| 模块编码|
|id|否|Long||

### 请求参数Json格式
 
```
{
 "id" : 0,
 "templateCode" : "String",
 "code" : "String",
 "id" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--confirmStoreModule|否|Object| 确认门店配置|
|----alertPosition|否|Integer| 确认门店弹出位置 0:去结算 1:确定下单|
|--code|否|String| 模块编码|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "confirmStoreModule" : {
 "alertPosition" : 0
 },
 "code" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
