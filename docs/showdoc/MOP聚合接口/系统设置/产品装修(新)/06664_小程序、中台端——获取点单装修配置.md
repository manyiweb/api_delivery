# 小程序、中台端——获取点单装修配置
 

**请求URL：** 
- `/meal-decoration/decoration/product/classify/config/get`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
无参数


### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|String| 主键|
|--enableTemplate|否|Boolean| 是否启用模板装修|
|--createId|否|String| 创建人id|
|--createName|否|String| 创建人姓名|
|--createDate|否|DateTime| 创建时间|
|--modifyId|否|String| 修改人id|
|--modifyName|否|String| 修改人姓名|
|--modifyDate|否|DateTime| 修改时间|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "id" : "String",
 "enableTemplate" : true,
 "createId" : "String",
 "createName" : "String",
 "createDate" : "DateTime",
 "modifyId" : "String",
 "modifyName" : "String",
 "modifyDate" : "DateTime"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
