# 复制模板内容，多新增一条
 

**请求URL：** 
- `/meal-decoration/decoration/template/copy`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long| id|
|name|否|String| 名称|
|code|是|String| 模块编码|
|templateCode|否|String||

### 请求参数Json格式
 
```
{
 "id" : 0,
 "name" : "String",
 "code" : "String",
 "templateCode" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
