# 点单、电商首页-获取装修首页配置

**请求URL：** 
- `/meal-decoration/decoration/home/page/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|code|是|String| 模块编码|
|companyId|否|String| 门店id 点单主页必传|

### 请求参数Json格式
 
```
{
 "code" : "String",
 "companyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long||
|--code|否|String| 模块编码|
|--isInherit|否|Integer| 是否继承商户|
|--companyId|否|String| 门店id|
|--templateId|否|Long| 装修模板id|
|--templateCode|否|String| 装修模板编码|
|--templateName|否|String| 装修模板名称|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "code" : "String",
 "isInherit" : 0,
 "companyId" : "String",
 "templateId" : 0,
 "templateCode" : "String",
 "templateName" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
