# 获取目录

**请求URL：** 
- `/meal-decoration/decoration/material/folder/get`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
无参数


### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--groupName|否|String| 品牌名称|
|--count|否|Long| 总数量|
|--folders|否|List| 目录|
|----id|否|String| 文件夹id|
|----folderName|否|String| 文件名称|
|----number|否|Long| 文件夹下图片数量|
|----folderLevel|否|Integer| level|
|----childs|否|List| 子分类|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "groupName" : "String",
 "count" : 0,
 "folders" : [{
 "id" : "String",
 "folderName" : "String",
 "number" : 0,
 "folderLevel" : 0,
 "childs" : null
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
