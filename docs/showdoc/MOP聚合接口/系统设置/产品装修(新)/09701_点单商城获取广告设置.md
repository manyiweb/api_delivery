# 点单商城获取广告设置

**请求URL：** 
- `/appc/decoration/advertisement/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long||
|pageType|否|Integer| 1 点单首页 2点单分类 3电商首页|
|companyId|否|String| 1 点单首页 2点单分类 3电商首页|
|groupId|否|String| 品牌id|
|code|是|String| 模块编码|
|templateCode|否|String||
|id|否|Long||

### 请求参数Json格式
 
```
{
 "id" : 0,
 "pageType" : 0,
 "companyId" : "String",
 "groupId" : "String",
 "code" : "String",
 "templateCode" : "String",
 "id" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--thousandFacesActivityInfo|否|Object| 千人千面派券参与活动信息|
|----popUpTitle|否|String||
|----hideTitle|否|Boolean||
|----textColor|否|String||
|----backgroundImage|否|String||
|----coupons|否|List||
|------couponId|否|String||
|------couponCode|否|String||
|------couponName|否|String||
|------couponNum|否|Integer||
|------beginDate|否|DateTime||
|------endDate|否|DateTime||
|------couponType|否|Integer||
|------price|否|String||
|------discount|否|Double||
|------useLimitAmt|否|Double||
|------useLimitType|否|Integer||
|--id|否|String||
|--imageUrl|否|String| 广告链接|
|--linkType|否|String| 链接类型|
|--sourceId|否|String| 关联业务id,商品、优惠券等等id|
|--urlTypeCode|否|String| 链接编码|
|--onlyAuthenticatedMemberCanJump|否|Boolean| 仅认证会员可跳转|
|--advertisementType|否|Integer| 广告类型 1：图片 2：轮播, 默认是1|

|----linkTypeDesc|否|String| 链接类型 photo|
|----sourceId|否|String| 关联业务id,商品、优惠券等等id|
|----sourceName|否|String| 关联业务名称，如商品名称、优惠券名称|
|----url|否|String| 链接|
|----urlTypeCode|否|String| 链接编码|

|--code|否|String| 模块编码|

|exceptionStackInfo|否|String||
|traceId|否|String||
