# 获取页面分享装修
 

**请求URL：** 
- `/meal-decoration/decoration/page/share/module/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|type|否|Integer||
|companyId|否|String||
|pageShareTypes|否|List||
|--type|否|Integer| 页面类型 0：秒杀 1：企微派券|
|--typeName|否|String| 类型名称|
|--content|否|String| 分析语|
|--imageUrl|否|String| 分享图|
|--imageUrlFull|否|String| 分享图全路径|
|--isInherit|否|Integer| 是否继承商户 1是0否|
|--companyId|否|String| 品牌id|
|code|是|String| 模块编码|
|templateCode|否|String||
|id|否|Long||

### 请求参数Json格式
 
```
{
 "type" : 0,
 "companyId" : "String",
 "pageShareTypes" : [{
 "type" : 0,
 "typeName" : "String",
 "content" : "String",
 "imageUrl" : "String",
 "imageUrlFull" : "String",
 "isInherit" : 0,
 "companyId" : "String"
 }],
 "code" : "String",
 "templateCode" : "String",
 "id" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--code|否|String| 模块编码|
|--type|否|Integer| 类型|
|--content|否|String| 分享语|
|--imageUrl|否|String| 分享图|
|--imageUrlFull|否|String| 分享图全路径|
|--code|否|String| 模块编码|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "code" : "String",
 "type" : 0,
 "content" : "String",
 "imageUrl" : "String",
 "imageUrlFull" : "String",
 "code" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
