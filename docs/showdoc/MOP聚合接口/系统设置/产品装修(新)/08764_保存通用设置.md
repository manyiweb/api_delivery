# 保存通用设置

**请求URL：** 
- `/general/setting/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|showStartPage|否|Boolean| 是否显示启动页|
|startPageUrl|否|String| 启动页|
|switchAccountBackgroundImageUrl|否|String| 切换账号背景图|
|myOrderDisplay|否|Object| 我的订单|
|--storeOrder|否|Boolean| 门店订单|
|--rechargeOrder|否|Boolean| 储值订单|
|--giftCardOrder|否|Boolean| 礼品卡订单|
|--integralOrder|否|Boolean| 积分订单|
|--mallOrder|否|Boolean| 电商订单|
|--goToOrderButtonText|否|String| 去下单按钮文案|
|scanCodeUrl|否|String| 扫码点单图|

### 请求参数Json格式
 
```
{
 "showStartPage" : true,
 "startPageUrl" : "String",
 "switchAccountBackgroundImageUrl" : "String",
 "myOrderDisplay" : {
 "storeOrder" : true,
 "rechargeOrder" : true,
 "giftCardOrder" : true,
 "integralOrder" : true,
 "mallOrder" : true,
 "goToOrderButtonText" : "String"
 },
 "scanCodeUrl" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
