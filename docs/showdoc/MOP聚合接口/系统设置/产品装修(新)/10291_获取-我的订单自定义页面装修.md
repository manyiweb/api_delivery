# 获取-我的订单自定义页面装修
 

**请求URL：** 
- `/meal-decoration/decoration/myOrder/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||
|templateCode|否|String| 模板编码 企业会员界面传 SuperMember|
|code|是|String| 模块编码|
|templateCode|否|String||
|id|否|Long||

### 请求参数Json格式
 
```
{
 "id" : 0,
 "templateCode" : "String",
 "code" : "String",
 "templateCode" : "String",
 "id" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--orderModuleList|否|List| 订单模块列表|
|----code|否|String| 订单模块编码|
|----name|否|String| 订单模块名称|
|----enable|否|Boolean| 是否开启|
|----needLink|否|Boolean| 是否需要链接|
|----url|否|String| 链接path|
|----urlTypeCode|否|String| 链接编码|
|----urlTypeName|否|String| 链接名称|
|--goToOrderButtonText|否|String| 去下单按钮文案|
|--code|否|String| 模块编码|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "orderModuleList" : [{
 "code" : "String",
 "name" : "String",
 "enable" : true,
 "needLink" : true,
 "url" : "String",
 "urlTypeCode" : "String",
 "urlTypeName" : "String"
 }],
 "goToOrderButtonText" : "String",
 "code" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
