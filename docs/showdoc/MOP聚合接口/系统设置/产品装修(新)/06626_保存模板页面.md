# 保存模板页面

**请求URL：** 
- `/meal-decoration/decoration/template/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 装修页面模板id，重命名时候要传|
|templateName|是|String| 装修页面模板名称|
|pageType|否|Integer| 页面类型 1：点单首页 2：点单分类 3：电商首页|
|rightsGroupsId|否|Long| 权限组id|
|rightsGroupsName|否|String| 权限组名称|
|code|是|String| 模块编码|
|templateCode|否|String||
|id|否|Long||

### 请求参数Json格式
 
```
{
 "id" : 0,
 "templateName" : "String",
 "pageType" : 0,
 "rightsGroupsId" : 0,
 "rightsGroupsName" : "String",
 "code" : "String",
 "templateCode" : "String",
 "id" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
