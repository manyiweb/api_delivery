# 获取-品牌代言人自定义页面装修
 

**请求URL：** 
- `/meal-decoration/decoration/brandSpokesperson/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||
|templateCode|否|String| 模板编码 企业会员界面传 SuperMember|
|code|是|String| 模块编码|
|templateCode|否|String||
|id|否|Long||

### 请求参数Json格式
 
```
{
 "id" : 0,
 "templateCode" : "String",
 "code" : "String",
 "templateCode" : "String",
 "id" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--inviteFansEnterPage|否|Integer| 被邀请粉丝进入首界面 0:点单首页 1:个人中心 2:用户注册/登录 3:品牌代言人|
|--style|否|Integer| 风格 1：风格一 2：风格二|
|--activityRules|否|String| 活动规则|
|--backgroundImage|否|String| 背景图片|
|--buttonText|否|String| 按钮文案|
|--buttonBackgroundColor|否|String| 按钮底色|
|--buttonTextColor|否|String| 按钮文字颜色|
|--shareGreeting|否|String| 分享语|
|--shareImage|否|String| 分享图|
|--code|否|String| 模块编码|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "inviteFansEnterPage" : 0,
 "style" : 0,
 "activityRules" : "String",
 "backgroundImage" : "String",
 "buttonText" : "String",
 "buttonBackgroundColor" : "String",
 "buttonTextColor" : "String",
 "shareGreeting" : "String",
 "shareImage" : "String",
 "code" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
