# 获取缺省图装修内容
 

**请求URL：** 
- `/meal-decoration/decoration/commom/module/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|code|是|String| 模块编码 PT012|

### 请求参数Json格式
 
```
{
 "code" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--modules|否|List| 模块|
|----code|否|String| 编码|
|----name|否|String| 名称|
|----imageUrl|否|String| 自定义缺省图|
|----imageUrlFull|否|String| 自定义缺省图全路径|
|----tips|否|String| 自定义文案提示|
|--code|否|String| 模块编码|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "modules" : [{
 "code" : "String",
 "name" : "String",
 "imageUrl" : "String",
 "imageUrlFull" : "String",
 "tips" : "String"
 }],
 "code" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
