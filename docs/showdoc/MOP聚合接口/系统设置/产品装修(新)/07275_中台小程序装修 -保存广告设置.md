# 中台小程序装修 -保存广告设置

**请求URL：** 
- `/decoration/advertisement/module/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|infoModule|否|Object| 广告信息|
|--enableAdvertisement|否|Boolean| 是否启用广告管理|
|--imageurlFull|是|String| 广告图地址|
|--advertisementName|否|String| 广告名称|
|--pageType|是|Integer| 1 点单首页 2点单分类 3电商首页|
|--startDate|是|DateTime| 有效期起|
|--endDate|是|DateTime| 有效期止|
|--remark|否|String| 备注|
|--timeCycle|是|String| 执行周期 每日day 每周week 每月month|
|--timeCycleContent|否|String| 周期内容 每周几 每月几号 均为两位数字 00 01 02 字符串数组转字符串|
|--userTarget|是|String| 参与用户配置 all所有用户 grade指定等级|
|--userGrade|否|String| 用户等级|
|--linkType|否|String| 链接类型 photo|
|--companyTarget|是|String| 门店配置 门店名称 门店id 门店编码 数组转字符串|
|--companySet|否|String| 应用门店 集合字符串数组|
|--linkTypeDesc|否|String| 链接类型 photo|
|--sourceId|否|String| 关联业务id,商品、优惠券等等id|
|--sourceName|否|String| 关联业务名称，如商品名称、优惠券名称|
|--urlTypeCode|否|String| 链接编码|
|--urlTypeName|否|String| 链接名称|
|--onlyAuthenticatedMemberCanJump|否|Boolean| 仅认证会员可跳转|
|--advertisementType|否|Integer| 广告类型 1：图片 2：轮播, 默认是1|
|--carousels|否|List| 轮播图集合|
|----imageurlFull|否|String| 广告图地址|
|----linkType|否|String| 链接类型 photo|
|----linkTypeDesc|否|String| 链接类型 photo|
|----sourceId|否|String| 关联业务id,商品、优惠券等等id|
|----sourceName|否|String| 关联业务名称，如商品名称、优惠券名称|
|----url|否|String| 链接|
|----urlTypeCode|否|String| 链接编码|
|----urlTypeName|否|String| 链接名称|
|code|是|String| 模块编码|
|templateCode|否|String||
|id|否|Long||
