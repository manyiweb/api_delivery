# 保存会员认证装修

**请求URL：** 
- `/meal-decoration/decoration/memberCertification/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|certifications|否|List| 列表|
|--fid|否|String||
|--isRequired|否|Integer| 是否必填|
|--isActive|否|Integer| 是否有效|
|--cKey|否|String||
|--cValue|否|String||
|--cAlias|否|String| 别名|
|--cGuideLanguage|否|String| 引导语言|
|code|是|String| 模块编码|
|templateCode|否|String||
|id|否|Long||

### 请求参数Json格式
 
```
{
 "certifications" : [{
 "fid" : "String",
 "isRequired" : 0,
 "isActive" : 0,
 "cKey" : "String",
 "cValue" : "String",
 "cAlias" : "String",
 "cGuideLanguage" : "String"
 }],
 "code" : "String",
 "templateCode" : "String",
 "id" : 0
}
```
