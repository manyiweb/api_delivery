# 获取小程序页面

**请求URL：** 
- `/meal-decoration/decoration/custom/page/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||
|templateCode|否|String| 模板编码 企业会员界面传 SuperMember|
|code|是|String| 模块编码|
|id|否|Long||

### 请求参数Json格式
 
```
{
 "id" : 0,
 "templateCode" : "String",
 "code" : "String",
 "id" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long| id|
|--showBuyNow|否|Boolean| 显示立即购买按钮|
|--showShareButton|否|Boolean| 显示分享按钮|
|--showProgress|否|Boolean| 是否显示进度条|
|--semiScreenPopUp|否|Boolean| 多规格半屏弹窗|
|--enableVideoAtlas|否|Boolean| 启用视频图集|
|--videoAtlasPosition|否|String| 视频图集位置，rightk:靠右 center:居中|
|--enableCarouselIndicator|否|Boolean| 启用轮播图指示器|
|--carouselIndicatorStyle|否|String| 轮播图指示器样式 dot:圆点 capsule:胶囊|
|--code|否|String| 模块编码|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "showBuyNow" : true,
 "showShareButton" : true,
 "showProgress" : true,
 "semiScreenPopUp" : true,
 "enableVideoAtlas" : true,
 "videoAtlasPosition" : "String",
 "enableCarouselIndicator" : true,
 "carouselIndicatorStyle" : "String",
 "code" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
