# 小程序点单商城获取点单分类装修界面框架
 

**请求URL：** 
- `/meal-decoration/appc/decoration/product/classify/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|wxSn|否|String| 小程序wxSn|
|companyId|否|String| 门店id|
|groupId|否|String| 品牌id|

### 请求参数Json格式
 
```
{
 "wxSn" : "String",
 "companyId" : "String",
 "groupId" : "String"
}
```
