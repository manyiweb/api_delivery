# 导航获取装修信息
 

**请求URL：** 
- `/meal-decoration/decoration/commom/module/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|code|是|String| 模块编码 PT009|

### 请求参数Json格式
 
```
{
 "code" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--isNew|否|Boolean| 是否是新的|
|--backgroundColor|否|String| 背景色|
|--textColor|否|String| 文字颜色|
|--textSelectedColor|否|String| 文字选中颜色|
|--showDivider|否|Boolean| 是否显示分割线|
|--navigationType|否|String| 导航模板类型 0标准 1悬浮 2主图|
|--navigationTemplate|否|String| 模板类型 0模板1 1模板2 2模板3|
|--enableCustomMenu|否|Boolean| 是否启用自定义配置|
|--bottomNavigationModuleList|否|List| 导航列表|
|----isActive|否|Boolean| 是否启用|
|----text|否|String| 导航名称|
|----customText|否|String| 自定义导航名称|
|----pagePath|否|String| 路径|
|----iconPath|否|String| 未选中|
|----selectedIconPath|否|String| 已选择图片效果图|
|--code|否|String| 模块编码|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{

 "isNew" : true,

 "enableCustomMenu" : true,
 "bottomNavigationModuleList" : [{
 "isActive" : true,
 "text" : "String",
 "customText" : "String",
 "pagePath" : "String",
 "iconPath" : "String",
 "selectedIconPath" : "String"
 }],
 "code" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
