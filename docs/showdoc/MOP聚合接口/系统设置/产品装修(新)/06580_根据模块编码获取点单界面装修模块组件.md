# 根据模块编码获取点单界面装修模块组件

**请求URL：** 
- `/meal-decoration/decoration/module/component/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|code|是|String| 模块编码|
|templateCode|否|String||
|id|否|Long||

### 请求参数Json格式
 
```
{
 "code" : "String",
 "templateCode" : "String",
 "id" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--baseComponents|否|List| 基础组件|
|----icon|否|String| 图标|
|----componentCode|否|String| 组件编码|
|----componentName|否|String| 组件名称|
|--productComponents|否|List| 产品组件|
|----icon|否|String| 图标|
|----componentCode|否|String| 组件编码|
|----componentName|否|String| 组件名称|
|--marketComponents|否|List| 营销组件|
|----icon|否|String| 图标|
|----componentCode|否|String| 组件编码|
|----componentName|否|String| 组件名称|
|--promotionComponents|否|List| 推广组件|
|----icon|否|String| 图标|
|----componentCode|否|String| 组件编码|
|----componentName|否|String| 组件名称|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "baseComponents" : [{
 "icon" : "String",
 "componentCode" : "String",
 "componentName" : "String"
 }],
 "productComponents" : [{
 "icon" : "String",
 "componentCode" : "String",
 "componentName" : "String"
 }],
 "marketComponents" : [{
 "icon" : "String",
 "componentCode" : "String",
 "componentName" : "String"
 }],
 "promotionComponents" : [{
 "icon" : "String",
 "componentCode" : "String",
 "componentName" : "String"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
