# 获取分销中心模块




### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--pageName|否|String| 别名|
|--showWithdraw|否|Boolean| 是否显示去提现|
|--enable|否|Boolean| 是否开启累计奖励|
|--alias|否|String| 别名|
|--iconUrl|否|String| 自定义图标|
|--subModuleList|否|List| 子模块|
|----enable|否|Boolean| 是否开启累计奖励|
|----alias|否|String| 别名|
|--customModuleList|否|List| 自定义模块|
|----enable|否|Boolean| 是否开启累计奖励|
|----alias|否|String| 别名|
|----iconUrl|否|String| 自定义图标|
|----urlTypeCode|否|String| 链接编码|
|----urlTypeName|否|String| 链接名称|
|----url|否|String| 链接path|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "pageName" : "String",
 "showWithdraw" : true,
 "enable" : true,
 "alias" : "String",
 "iconUrl" : "String",
 "subModuleList" : [{
 "enable" : true,
 "alias" : "String"
 }],
 "customModuleList" : [{
 "enable" : true,
 "alias" : "String",
 "iconUrl" : "String",
 "urlTypeCode" : "String",
 "urlTypeName" : "String",
 "url" : "String"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
