# 根据模块编码，获取对应模块应用的装修框架

**请求URL：** 
- `/meal-decoration/appc/decoration/module/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|wxSn|否|String| 小程序wxSn|
|companyId|否|String| 门店id|
|groupId|否|String| 品牌id|
|code|是|String| 模块编码|

### 请求参数Json格式
 
```
{
 "wxSn" : "String",
 "companyId" : "String",
 "groupId" : "String",
 "code" : "String"
}
```
