# 点单商城获取广告设置

**请求URL：** 
- `/meal-decoration/appc/decoration/advertisement/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|pageType|否|String| 页面类型 1 点单首页 2点单分类 3电商首页 4支付成功|
|code|是|String| 模块编码|

### 请求参数Json格式
 
```
{
 "pageType" : "String",
 "code" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|String||
|--url|否|String| 广告名称|
|--code|否|String| 模块编码|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "id" : "String",
 "url" : "String",
 "code" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
