# 获取 品牌资讯自定义页面装修

**请求URL：** 
- `/meal-decoration/decoration/brandInformation/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||
|templateCode|否|String| 模板编码 企业会员界面传 SuperMember|
|code|是|String| 模块编码|
|templateCode|否|String||
|id|否|Long||

### 请求参数Json格式
 
```
{
 "id" : 0,
 "templateCode" : "String",
 "code" : "String",
 "templateCode" : "String",
 "id" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--pageTitle|否|String| 页面标题|
|--showSearch|否|Boolean| 显示搜索|
|--informationClassifyModules|否|List| 资讯文章分类|
|----name|否|String| 分类名称|
|----informations|否|List| 资讯文章列表|
|------fid|否|String| 资讯文章id|
|------imageUrl|否|String| 图片|
|------title|否|String| 标题|
|------author|否|String| 作者|
|------createDate|否|DateTime| 创建时间|
|--code|否|String| 模块编码|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "pageTitle" : "String",
 "showSearch" : true,
 "informationClassifyModules" : [{
 "name" : "String",
 "informations" : [{
 "fid" : "String",
 "imageUrl" : "String",
 "title" : "String",
 "author" : "String",
 "createDate" : "DateTime"
 }]
 }],
 "code" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
