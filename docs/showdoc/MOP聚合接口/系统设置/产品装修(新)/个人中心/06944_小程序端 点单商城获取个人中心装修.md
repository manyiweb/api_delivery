# 点单商城获取个人中心装修

**请求URL：** 
- `/appc/decoration/personal/center/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 微页面id|
|wxSn|否|String| 小程序wxSn|
|companyId|否|String| 门店id|
|groupId|否|String| 品牌id|
|code|是|String| 模块编码|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "wxSn" : "String",
 "companyId" : "String",
 "groupId" : "String",
 "code" : "String"
}
```
