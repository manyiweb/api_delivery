# 获取销量排行榜

**请求URL：** 
- `/b2b/decoration/b2b/product/rank`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String||
|groupId|否|String||
|searchType|否|Integer| 0按周 1按月|
|month|否|Integer| 月份|
|year|否|Integer| 年份|
|limit|否|Integer||

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "groupId" : "String",
 "searchType" : 0,
 "month" : 0,
 "year" : 0,
 "limit" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--itemId|否|String| 商品id|
|--itemName|否|String| 商品名称|
|--itemCode|否|String| 商品编码|
|--specId|否|String| 商品规格id|
|--colourId|否|String| 规格一id|
|--b2bPrice|否|String| 订货价|
|--imageUrl|否|String| 商品主图|
|--salePrice|否|String| 零售价|
|--quantity|否|Integer| 销量|
|--invQtyCompany|否|Double| 门店库存|
|--invQtyStock|否|Double| 发货仓库存|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "itemId" : "String",
 "itemName" : "String",
 "itemCode" : "String",
 "specId" : "String",
 "colourId" : "String",
 "b2bPrice" : "String",
 "imageUrl" : "String",
 "salePrice" : "String",
 "quantity" : 0,
 "invQtyCompany" : 0,
 "invQtyStock" : 0
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
