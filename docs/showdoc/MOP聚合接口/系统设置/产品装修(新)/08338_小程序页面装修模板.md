# 小程序页面装修模板

**请求URL：** 
- `/decoration/template/custom`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|code|是|String| 模块编码|

### 请求参数Json格式
 
```
{
 "code" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--id|否|Long| 模板id|
|--code|否|String| 模板编码|
|--templateId|否|String| 模板id|
|--templateCode|否|String| 模板code|
|--templateName|否|String| 模板名称|
|--isActive|否|Boolean| 活跃状态|
|--publishDate|否|DateTime| 发布日期|
|--createName|否|String| 创建人|
|--createDate|否|DateTime| 创建时间|
|--apply|否|Boolean| 是否被应用|
|--pageType|否|Integer| 应用页面|
|--pageTypeDesc|否|String| 应用页面描述|
|--classifyPattern|否|Integer| 分类模式 0:点单模式 1:商城模式|
|--classifyPatternDesc|否|String| 分类模式描述|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "id" : 0,
 "code" : "String",
 "templateId" : "String",
 "templateCode" : "String",
 "templateName" : "String",
 "isActive" : true,
 "publishDate" : "DateTime",
 "createName" : "String",
 "createDate" : "DateTime",
 "apply" : true,
 "pageType" : 0,
 "pageTypeDesc" : "String",
 "classifyPattern" : 0,
 "classifyPatternDesc" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
