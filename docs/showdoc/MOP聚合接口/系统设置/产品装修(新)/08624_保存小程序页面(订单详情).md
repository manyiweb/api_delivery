# 保存小程序页面(订单详情)

**请求URL：** 
- `/meal-decoration/decoration/custom/page/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||
|showBuyNow|否|Boolean| 显示立即购买按钮|
|icons|否|List| icons|
|--code|否|String| icon code|
|--name|否|String| icon名称|
|--iconUrl|否|String| icon图半路经|
|--iconUrlFull|否|String| icon图全路径|
|--showEnable|否|Boolean| 是否展示开启开关|
|--enable|否|Boolean| 是否开启|
|code|是|String| 模块编码|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "showBuyNow" : true,
 "icons" : [{
 "code" : "String",
 "name" : "String",
 "iconUrl" : "String",
 "iconUrlFull" : "String",
 "showEnable" : true,
 "enable" : true
 }],
 "code" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
