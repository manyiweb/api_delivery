# 点单商城，分类标签获取商品装修信息
 

**请求URL：** 
- `/appc/decoration/cake/product/classify/label/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 模板id|
|wxSn|否|String| 小程序wxSn|
|companyId|否|String| 门店id|
|groupId|否|String| 品牌id|
|mongoId|否|String| 分类标签mongoid|
|pageType|否|Integer| 页面类型|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "wxSn" : "String",
 "companyId" : "String",
 "groupId" : "String",
 "mongoId" : "String",
 "pageType" : 0
}
```
