# 获取商品分类共用模板装修

**请求URL：** 
- `/meal-decoration/decoration/productClassify/common/template/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||
|code|是|String| PT011|
|templateCode|否|String||
|id|否|Long||

### 请求参数Json格式
 
```
{
 "id" : 0,
 "code" : "String",
 "templateCode" : "String",
 "id" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |

|--showTitle|否|Boolean| 显示标题|

|--showCoupon|否|Boolean| 显示结算栏优惠券|
|--customCouponTips|否|String| 可用优惠券自定义文案|
|--settleBackgroundColor|否|String| 结算栏背景色|

|--tabSelectColor|否|String| 页签选择颜色|
|--tabUnSelectColor|否|String| 页签未选中颜色|
|--titleColor|否|String| 标题颜色|
|--backgroundColor|否|String| 背景色|
|--topBarBackgroundImage|否|String| 背景图|
|--searchColor|否|String| 搜索颜色|

|--mealWaySelectBackgroundColor|否|String| 取餐方式选中底色|

|--mealWaySelectTextColor|否|String| 取餐方式选中文字颜色|
|--code|否|String| 模块编码|
