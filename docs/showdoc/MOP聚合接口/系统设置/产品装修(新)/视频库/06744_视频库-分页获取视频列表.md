# 分页获取视频列表
 

**请求URL：** 
- `/meal-decoration/decoration/material/video/page`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|folderId|否|String| 文件id|
|sword|否|String| 关键词|
|pageIndex|否|Integer||
|pageSize|否|Integer||
|orderField|否|String||
|orderSort|否|String||

### 请求参数Json格式
 
```
{
 "folderId" : "String",
 "sword" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--pageIndex|否|Integer||
|--pageSize|否|Integer||
|--pageCount|否|Integer||
|--totalCount|否|Long||
|--first|否|Boolean||
|--last|否|Boolean||
|--content|否|List||
|----id|否|String| id|
|----videoName|否|String| 图片名称|
|----videoUrl|否|String| 图片链接|
|----videoUrlFull|否|String| 图片链接|
|----videoSize|否|Long| 图片大小|
|----videoSizeStr|否|String| 图片大小|
|----createDate|否|DateTime| 创建时间|
|----modifyDate|否|DateTime| 修改时间|
|----remark|否|String| 备注|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "pageIndex" : 0,
 "pageSize" : 0,
 "pageCount" : 0,
 "totalCount" : 0,
 "first" : true,
 "last" : true,
 "content" : [{
 "id" : "String",
 "videoName" : "String",
 "videoUrl" : "String",
 "videoUrlFull" : "String",
 "videoSize" : 0,
 "videoSizeStr" : "String",
 "createDate" : "DateTime",
 "modifyDate" : "DateTime",
 "remark" : "String"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
