# 保存零售导购归属配置

**请求URL：** 
- `/retail/config/orderGuide/action/save `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|isCustomizeServiceGuide|否|Boolean| 是否开启商城订单归属设置|
|isInheirt|否|Boolean| 是否继承|
|companyId|否|String| 门店id|
|xcthServiceGuideId|否|String| 到店自提服务导购id|
|xcthServiceGuideName|否|String| 到店自提服务导购名称|
|isXcthRedirectExclusiveGuide|否|Boolean| 到店自提服务导购归属为专属导购|
|smsServiceGuideId|否|String| 快递配送服务导购id|
|smsServiceGuideName|否|String| 快递配送服务导购名称|
|isSmsRedirectExclusiveGuide|否|Boolean| 快递配送服务导购归属为专属导购|
|scdServiceGuideId|否|String| 同城配送服务导购id|
|scdServiceGuideName|否|String| 同城配送服务导购名称|
|isScdRedirectExclusiveGuide|否|Boolean| 同城配送服务导购归属为专属导购|

###请求参数Json格式
 
```
{
 "isCustomizeServiceGuide" : true,
 "isInheirt" : true,
 "companyId" : "String",
 "xcthServiceGuideId" : "String",
 "xcthServiceGuideName" : "String",
 "isXcthRedirectExclusiveGuide" : true,
 "smsServiceGuideId" : "String",
 "smsServiceGuideName" : "String",
 "isSmsRedirectExclusiveGuide" : true,
 "scdServiceGuideId" : "String",
 "scdServiceGuideName" : "String",
 "isScdRedirectExclusiveGuide" : true
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
