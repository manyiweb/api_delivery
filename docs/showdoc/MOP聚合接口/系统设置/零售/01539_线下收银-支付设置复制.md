# 零售设置 支付设置 复制
 

**请求URL：** 
- `/config/underline/copy `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 |参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyIdG|否|Object| 从门店|
|companyIdT|否|String| 到门店|
 
```
{"tokenId":"fff32fb14b8f42d9bf0306b13aeb4209", "companyIdG":"12328a8d132c4e7a8580d9965dfab8c0", "companyIdT":"5f95bee07ed44bb3a4be9e8a50004390"}
```


###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String"
}
```
