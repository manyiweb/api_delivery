# 获取商城营业时间信息(会员商城、点餐商城)
 

**请求URL：** 
- `/app/mall/business/hours/info `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|groupId|否|String| 品牌标识|
|companyId|否|String| 商户标识|
|sysNo|否|String| 端口|
|throwException|否|Boolean| 是否抛错(为ture时，不营业会直接抛错误信息)|

###请求参数Json格式
 
```
{
 "groupId" : "String",
 "companyId" : "String",
 "sysNo" : "String",
 "throwException" : true
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--openBusiness|否|Boolean| 是否开启营业|
|--companyId|否|String| 门店标识|
|--inBusiness|否|Boolean| 是否营业中
 |
|--businessHours|否|String| 营业时间段(多个用;隔开)|
|--nonBusinessBuy|否|Boolean| 非营业时间不允许下单|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "openBusiness" : true,
 "companyId" : "String",
 "inBusiness" : true,
 "businessHours" : "String",
 "nonBusinessBuy" : true
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
