# 保存商城营业时间设置
 

**请求URL：** 
- `/app/mall/business/hours/save `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|mallType|否|String| 商城类型 mall会员商城 mealMall点餐商城|
|companyId|否|String| 门店id|
|openBusiness|否|Boolean| 是否开启营业 true营业 false休息|
|nonBusinessBuy|否|Boolean| 非营业时间不允许下单 true允许下单 false不允许下单|
|businessHoursWeeks |是|object | 无 |
| - weekDay |是|Array | 设置的星期，取值：["SUNDAY","MONDAY","TUESDAY","WEDNESDAY","THURSDAY","FRIDAY","SATURDAY"] |
| - typeWay | 是|string| 营业时间方式，取值：ALL_DAY - 全天; CUSTOMIZED - 自定义 |
| - businessHoursInfos|否|List| 营业时间段(多个用;隔开)|
| - - startTime|否|String| 开始时间|
| - - endTime|否|String| 结束时间|

```
 {
 "isInherit": 0,

 "businessHoursWeeks": [

 "SUNDAY",
 "MONDAY",
 "TUESDAY",

 "THURSDAY",

} 

```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
