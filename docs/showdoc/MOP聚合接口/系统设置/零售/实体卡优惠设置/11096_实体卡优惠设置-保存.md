# 实体卡优惠设置-保存
 

**请求URL：** 
- `/mem/entitycard/discount/setting/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 方案 id，新增时为空|
|companyId|是|String| 门店 id（按门店级别维护）|
|settingName|是|String| 方案名称|
|entitycardId|是|String| 关联实体卡 fid|
|status|是|Boolean| 启用状态：true=启用，false=停用；新增时默认 true|
|discountCondition|是|String| 折扣条件：none=支付任意金额可享受折扣，firstAll=仅首次金额支付可享受折扣|
|discountCycleType|是|String| 折扣周期类型：day=每天，week=每周，month=每月|
|discountCycleContent|否|String| 折扣周期内容：day 时传空；week 时传 1-7（1=周一）；month 时传 1-31|
|isAllItem|是|Integer| 优惠商品范围：0=指定商品，1=所有商品，2=排除商品，3=指定品牌/系列/类别|
|discount|否|Double| 全局折扣率（isAllItem=1 或 2 时必填），范围 0~100|
|itemList|否|List| 商品规格列表（isAllItem=0 或 2 时使用）|
|--specId|否|String| 规格 id|
|--itemId|否|String| 商品 id|
|--itemName|否|String| 商品名称|
|--itemCode|否|String| 商品编码|
|--skuCode|否|String| SKU 码|
|--discount|否|Double| 折扣率（isAllItem=0 时必填）|
|delSpecIds|否|List| 需要删除的商品规格 id 列表（isAllItem=0 或 2 时，前端传入需要移除的规格）|
|brandList|否|List| 品牌/系列/类别列表（isAllItem=3 时使用）|
|--type|否|String| 类型：1=品牌，2=系列，3=类别|
|--typeId|否|String| 类型 id|
|--code|否|String| 编码|
|--name|否|String| 名称|
|--discount|否|Double| 折扣率|
