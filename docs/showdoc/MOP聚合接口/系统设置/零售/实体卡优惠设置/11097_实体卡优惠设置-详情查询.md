# 实体卡优惠设置-详情查询
 

**请求URL：** 
- `/mem/entitycard/discount/setting/detail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long| 规则id|

### 请求参数Json格式
 
```
{
 "id" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long| 方案 id|
|--settingNo|否|String| 方案编码|
|--settingName|否|String| 方案名称|
|--companyId|否|String| 门店 id|
|--entitycardId|否|String| 关联实体卡 fid|
|--entitycardName|否|String| 关联实体卡名称|
|--entitycardNo|否|String| 关联实体卡编号|
|--status|否|Boolean| 启用状态：true=启用，false=停用|
|--discountCondition|否|String| 折扣条件：none=支付任意金额可享受折扣，firstAll=仅首次金额支付可享受折扣|
|--discountCycleType|否|String| 折扣周期类型：day=每天，week=每周，month=每月|
|--discountCycleContent|否|String| 折扣周期内容|
|--isAllItem|否|Integer| 优惠商品范围：0=指定商品，1=所有商品，2=排除商品，3=指定品牌/系列/类别|
|--discount|否|Double| 全局折扣率（isAllItem=1 或 2 时有效）|
|--createName|否|String| 创建人|
|--createDate|否|DateTime| 创建时间|
|--modifyName|否|String| 更新人|
|--modifyDate|否|DateTime| 更新时间|
|--itemList|否|List| 商品规格明细列表（isAllItem=0 或 2 时返回）|
|----id|否|Long| 明细 id|
|----itemId|否|String| 商品 id|
|----itemName|否|String| 商品名称|
|----itemCode|否|String| 商品编码|
|----specId|否|String| 规格 id|
|----skuCode|否|String| SKU 码|
|----discount|否|Double| 折扣率|
|--typeList|否|List| 品牌/系列/类别明细列表（isAllItem=3 时返回）|
|----id|否|Long| 明细 id|
|----typeCode|否|String| 类型编码：1=品牌，2=系列，3=类别|
|----typeName|否|String| 类型名称：品牌/系列/类别|
|----typeId|否|String| 类型 id|
|----code|否|String| 编码|
|----name|否|String| 名称|
|----discount|否|Double| 折扣率|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
