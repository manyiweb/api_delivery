# 保存实体卡优惠配置

**请求URL：** 
- `/mem/entitycard/discount/setting/config/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 门店ID|
|enableDiscount|否|Boolean| 是否启用实体卡支付优惠|
|isInherit|否|Boolean| 是否继承品牌设置|

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "enableDiscount" : true,
 "isInherit" : true
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
