# 查询该店铺是否已授权

**请求URL：** 
- `/dock/third/shop/ifAuthorize`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 门店id|
|poiId|否|String| poiId|
|poiName|否|String| 商户id|
|token|否|String| token|
|expireIn|否|DateTime| token|
|platformType|是|String| 平台 douyinRetail 抖音即时零售|

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "poiId" : "String",
 "poiName" : "String",
 "token" : "String",
 "expireIn" : "DateTime",
 "platformType" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--ifAuthorize|否|Boolean| 店铺是否已授权标识|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "ifAuthorize" : true
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
