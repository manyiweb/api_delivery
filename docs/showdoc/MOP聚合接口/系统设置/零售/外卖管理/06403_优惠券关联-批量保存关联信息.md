# 批量保存关联信息

**请求URL：** 
- `/dock/coupon/link/batchSave `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|itemId|否|String| 商品id|
|itemCode|否|String| 商品编码|
|itemName|否|String| 商品名称|
|specId|否|String| 商品规格id|
|skuBarcode|否|String| sku|
|couponInfos|否|List| 关联的优惠券详情|
|--dealId|否|Integer| 券id|
|--dealTitle|否|String| 券名称|
|--dealValue|否|Double| 市场价格|
|--dealPrice|否|Double| 售卖价格|
|--beginTime|否|DateTime| 项目开始时间|
|--endTime|否|DateTime| 项目结束时间|
|--beginTime2|否|DateTime| 项目开始时间2|
|applyType|否|Integer| 应用门店类型 0:全部 1：指定 2：按条件|
|companyIds|否|List| 门店id列表|
|sword|否|String||

|id|否|String||
|orderField|否|String| 排序字段|

|----isCustom|否|String||

|----isSelect|否|String||
|--current|否|Object||
|----itemName|否|String||
|----itemValue|否|String||
|----minValue|否|String||
|----maxValue|否|String||
|----isCustom|否|String||

|--sword|否|String||
|--pageIndex|否|Integer||
|--pageSize|否|Integer||
|--curPageNum|否|Integer||
|--totalPage|否|Integer||

|status|否|Integer| 状态|
