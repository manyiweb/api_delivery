# 根据门店获取商品列表

**请求URL：** 
- `/dock/coupon/link/productlist `

**请求方式：**
- POST
- RequestBody

|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String||

|----minValue|否|String||
|----maxValue|否|String||
|----isCustom|否|String||
|----isRange|否|String||
|----isSelect|否|String||
|--current|否|Object||
|----itemName|否|String||
|----itemValue|否|String||
|----minValue|否|String||
|----maxValue|否|String||
|----isCustom|否|String||
|----isRange|否|String||
|----isSelect|否|String||
|--sword|否|String||

###返回参数
