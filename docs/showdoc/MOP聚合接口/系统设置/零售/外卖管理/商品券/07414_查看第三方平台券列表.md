# 查看第三方平台券列表

**请求URL：** 
- `/dock/third/coupon/query`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 门店id|
|dealStatus|否|Integer| 套餐状态，可选的值为：-1、全部状态（含以下所有） 0、结束售卖 1、正在售卖 2、隐藏单，前台通过POI列表及deal列表都不可见，但是通过收藏或url可以直接访问并购买 4、未开始售卖 5、不可购买|
|sword|否|String||
|channel|是|String| 平台 meituan("美团"),douyin("抖音"),zhifubao("支付宝"),beijixing("点评");|

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "dealStatus" : 0,
 "sword" : "String",
 "channel" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--dealId|否|Integer||
|--dealTitle|否|String||
|--dealValue|否|Double||
|--dealPrice|否|Double||
|--beginTime|否|Long||
|--beginTime2|否|DateTime||
|--dealEndTime|否|Long||
|--endTime|否|DateTime||
|--dealStatus|否|Integer||
|--isVoucher|否|Boolean||
|--dealMenu|否|String||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||

 "isVoucher" : true,

 }],

 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
