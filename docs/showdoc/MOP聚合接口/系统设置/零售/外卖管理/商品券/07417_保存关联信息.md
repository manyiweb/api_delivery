# 保存关联信息

**请求URL：** 
- `/dock/third/coupon/link/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 门店id|
|itemId|否|String| 商品id|
|specId|是|String| 商品规格id|
|itemCode|否|String| 商品编码|
|skuCode|否|String| 商品sku|
|itemName|否|String| 商品名称|
|channel|是|String| 平台 meituan("美团"),douyin("抖音"),zhifubao("支付宝"),beijixing("点评");|
|couponInfos|否|List| 关联的优惠券详情|
|--dealId|否|Integer| 券id|
|--dealTitle|否|String| 券名称|
|--dealValue|否|Double| 市场价格|
|--dealPrice|否|Double| 售卖价格|
|--beginTime|否|DateTime| 项目开始时间|
|--endTime|否|DateTime| 项目结束时间|
|--beginTime2|否|DateTime| 项目开始时间2|

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "itemId" : "String",
 "specId" : "String",
 "itemCode" : "String",
 "skuCode" : "String",
 "itemName" : "String",
 "channel" : "String",
 "couponInfos" : [{
 "dealId" : 0,
 "dealTitle" : "String",
 "dealValue" : 0,
 "dealPrice" : 0,
 "beginTime" : "DateTime",
 "endTime" : "DateTime",
 "beginTime2" : "DateTime"
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
