# 获取商品和第三方平台券关联详情

**请求URL：** 
- `/dock/third/coupon/link/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|specId|是|String| 商品规格id，对应的是每一个sku|
|companyId|是|String| 门店id|
|channel|是|String| 平台 meituan("美团"),douyin("抖音"),zhifubao("支付宝"),beijixing("点评");|

### 请求参数Json格式
 
```
{
 "specId" : "String",
 "companyId" : "String",
 "channel" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--itemId|否|String| 商品id|
|--specId|否|String| 商品规格id|
|--itemCode|否|String| 商品编码|
|--skuCode|否|String| 商品sku|
|--itemName|否|String| 商品名称|
|--couponInfos|否|List| 关联的优惠券详情|
|----dealId|否|Integer| 券id|
|----dealTitle|否|String| 券名称|
|----dealValue|否|Double| 市场价格|
|----dealPrice|否|Double| 售卖价格|
|----beginTime|否|DateTime| 项目开始时间|
|----endTime|否|DateTime| 项目结束时间|
|----beginTime2|否|DateTime| 项目开始时间2|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "itemId" : "String",
 "specId" : "String",
 "itemCode" : "String",
 "skuCode" : "String",
 "itemName" : "String",
 "couponInfos" : [{
 "dealId" : 0,
 "dealTitle" : "String",
 "dealValue" : 0,
 "dealPrice" : 0,
 "beginTime" : "DateTime",
 "endTime" : "DateTime",
 "beginTime2" : "DateTime"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
