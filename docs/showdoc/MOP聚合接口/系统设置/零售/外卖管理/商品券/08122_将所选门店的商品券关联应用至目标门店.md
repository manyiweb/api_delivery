# 将所选门店的商品券关联应用至目标门店
 

**请求URL：** 
- `/dock/third/coupon/link/copy`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 门店id|
|companyIdFrom|是|List| 要复制到的门店id|
|channel|是|String| 平台 meituan("美团"),douyin("抖音"),zhifubao("支付宝"),beijixing("点评");|

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "companyIdFrom" : null,
 "channel" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
