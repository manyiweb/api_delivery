# 根据品牌获取商品列表

**请求URL：** 
- `/dock/third/coupon/link/all/productlist`

**请求方式：**
- POST
- RequestBody

|type|否|Integer||

|----isSelect|否|String||
|--current|否|Object||
|----itemName|否|String||
