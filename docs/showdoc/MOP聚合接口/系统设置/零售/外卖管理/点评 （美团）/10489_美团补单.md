# 美团补单

**请求URL：** 
- `/dock/mt/v2/order/supplement`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|是|String||
|companyId|是|String| 门店id|

### 请求参数Json格式
 
```
{
 "orderId" : "String",
 "companyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|String||


### 返回参数Json格式
 
```
{
 "data" : "String"
}
```
