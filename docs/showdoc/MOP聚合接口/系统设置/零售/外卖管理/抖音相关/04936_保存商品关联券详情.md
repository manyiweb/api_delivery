# 保存商品关联券详情

**请求URL：** 
- `/dock/douyin/coupon/save `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|specId|否|String| 规格id|
|companyId|否|String| 门店id|
|groupons|否|List| 保存的优惠券信息|
|--grouponId|否|String||
|--actualGrouponId|否|String| 实际团购id，用于查看|
|--title|否|String| 团购标题|
|--originalAmount|否|Double| 原价（单位分）|
|--actualAmount|否|Double| 抖音团购价（单位分）|
|--validTimeType|否|Integer| 券码有效期类型 1-指定时间段 2-购后天数|
|--postPurchaseDay|否|Integer| valid_time_type=2时有效，购后天数|
|--orderValidEndTime|否|Long| valid_time_type=1时有效，券码有效期开始时间|
|--orderValidStartTime|否|Long| valid_time_type=1时有效，券码有效期结束时间|

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
