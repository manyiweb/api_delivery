# 店铺商品与抖音商品进行关联

**请求URL：** 
- `/dock/douyin/product/bind`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 门店id|
|bindProduct|否|List| 待绑定商品|
|--itemId|否|String| 商品id|
|--itemName|否|String| 商品名称|
|--specName|否|String| 规格名称|
|--specId|否|String| 商品规格id|
|--douyinTakeOutProduct|否|Object| 需要绑定的饿了么商品|
|----onlineStatus|否|Integer| 在线状态 1-在线 2-下线3-封禁|
|----productId|否|String| 商品ld|
|----outId|否|String| 外部商品id|
|----productName|否|String| 商品名|
|----categoryFullName|否|String| 品类全名|
|----categoryId|否|String| 折扣列表|
|----productType|否|String| 商品类型14-外卖|
|----accountId|否|String| 商家ID|
|----poiCount|否|Integer| 适用门店数量|
|----skuId|否|String| sku id|
|----skuName|否|String| sku名|
|----originAmount|否|Long| 原价，单位:分|
|----actualAmount|否|Long| 实际支付价格，单位:分|
|----ifBind|否|Boolean| 是否已绑定|
|----extendCode|否|String| 商品扩展码（erp itemId）|

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "bindProduct" : [{
 "itemId" : "String",
 "itemName" : "String",
 "specName" : "String",
 "specId" : "String",
 "douyinTakeOutProduct" : {
 "onlineStatus" : 0,
 "productId" : "String",
 "outId" : "String",
 "productName" : "String",
 "categoryFullName" : "String",
 "categoryId" : "String",
 "productType" : "String",
 "accountId" : "String",
 "poiCount" : 0,
 "skuId" : "String",
 "skuName" : "String",
 "originAmount" : 0,
 "actualAmount" : 0,
 "ifBind" : true,
 "extendCode" : "String"
 }
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
