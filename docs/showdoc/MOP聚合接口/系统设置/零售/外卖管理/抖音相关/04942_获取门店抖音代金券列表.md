# 获取门店抖音代金券列表
 

**请求URL：** 
- `/dock/douyin/groupon/list `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 门店id|
|pageIndex|否|Integer| 页号|
|pageSize|否|Integer| 页大小|
|orderField|否|String| 商品排序字段|
|orderSort|否|String| 商品排序方式 desc 倒序 asc 正序|

###请求参数Json格式
 
```
{
 "companyId" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String"
}
```

|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--pageIndex|否|Integer| 页码|

|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|--first|否|Boolean| 首页|
|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|
|----id|否|Long||
|----grouponId|否|String| 团购id|
|----actualGrouponId|否|String| 实际团购id|
|----merchantName|否|String| 商户名称|
|----serviceNumber|否|String| 联系电话|
|----title|否|String| 团购标题|
|----coverImages|否|String| 封面图|
|----originalAmount|否|Double| 原价|
|----actualAmount|否|Double| 抖音团购价|
|----notification|否|String| 团购须知|
|----orderLimit|否|Integer| 单用户购买上限|
|----startTime|否|DateTime| 项目开始时间|
|----endTime|否|DateTime| 项目结束时间|
|----companyId|否|String| 门店id|
|----createId|否|String| 创建人id|
|----createName|否|String| 创建人|
|----createDate|否|DateTime| 创建时间|
|----modifyId|否|String| 修改人id|
|----modifyName|否|String| 修改人|
|----modifyDate|否|DateTime| 修改时间|
|----dbKey|否|Integer| 分库标识|
|----groupId|否|String| 品牌商id|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
