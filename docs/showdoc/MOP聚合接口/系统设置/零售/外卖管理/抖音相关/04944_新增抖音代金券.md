# 新增抖音代金券

**请求URL：** 
- `/dock/douyin/groupon/save `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 门店id|
|groupons|否|List| 抖音代金券|
|--grouponId|否|String||
|--actualGrouponId|否|String| 实际团购id，用于查看|
|--useType|否|Integer| 团购使用方式 1-到底核销|
|--codeType|否|Integer| 券码生成方式 1-抖音码 2-三方码 3-预留码|
|--merchantName|否|String| 商户名称|
|--serviceNumber|否|String| 联系电话|
|--title|否|String| 团购标题|
|--coverImages|否|List| 封面图|
|--originalAmount|否|Double| 原价（单位分）|
|--actualAmount|否|Double| 抖音团购价（单位分）|
|--notification|否|String| 团购须知|
|--orderLimit|否|Integer| 单用户购买上限|
|--stock|否|Integer| 总库存|
|--poiIds|否|List| 绑定的POI列表|
|--startTime|否|Long| 售卖开始时间|
|--endTime|否|Long| 售卖结束时间|
|--h5Url|否|String| 团购活动详情页链接|
|--status|否|Integer| 活动状态，创建时忽略 1-已上线 2-审核中 3-审核失败 4-下架|
|--soldCount|否|Integer| 已售数（退款不回滚），创建时忽略|
|--auditMsg|否|String| 审核失败原因，创建时忽略|
|--appointment|否|Boolean| 是否需要预约|
|--supplierExtIdList|否|List| 接入方店铺ID列表|
|--validTimeType|否|Integer| 券码有效期类型 1-指定时间段 2-购后天数|
|--postPurchaseDay|否|Integer| valid_time_type=2时有效，购后天数|
|--orderValidEndTime|否|Long| valid_time_type=1时有效，券码有效期开始时间|
|--orderValidStartTime|否|Long| valid_time_type=1时有效，券码有效期结束时间|
|--contactTelephoneList|否|List| 联系人列表|
|--takeRate|否|Integer| 抽佣率（万分数）|
|--categoryId|否|String| 商品品类ID|

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
