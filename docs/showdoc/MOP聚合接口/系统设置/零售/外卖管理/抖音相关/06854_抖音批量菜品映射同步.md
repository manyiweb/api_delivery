# 抖音批量菜品映射同步
 

**请求URL：** 
- `/dock/douyin/product/mapping/sync`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|comapnyIds|否|List| 门店ID列表|
|operationType|否|Integer| 操作类型 0全部 1仅清理失效商品 2仅同步映射相同菜品名称商品|

### 请求参数Json格式
 
```
{
 "comapnyIds" : null,
 "operationType" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--mappingProductCount|否|Integer| 本次映射成功商品数量|
|--delMappingProductCount|否|Integer| 本次删除失效映射商品数量|
|--notMappingProductCount|否|Integer| 本次未映射商品数量|
|--syncItems|否|List| 同步商品信息|
|----companyId|否|String| 门店ID|
|----groupId|否|String| 品牌id|
|----companyCode|否|String| 门店名称|
|----companyName|否|String| 门店名称|
|----successful|否|Boolean| 是否执行成功|
|----errorMsg|否|String| 失败原因|
|----mappingProductNames|否|List| 同步成功的菜品名称(返回商品+规格名称)|
|----delMappingProductNames|否|List| 删除失效的菜品映射关系(返回商品+规格名称)|
|----notMappingProductNames|否|List| 未映射的商品列表|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "mappingProductCount" : 0,
 "delMappingProductCount" : 0,
 "notMappingProductCount" : 0,
 "syncItems" : [{
 "companyId" : "String",
 "groupId" : "String",
 "companyCode" : "String",
 "companyName" : "String",
 "successful" : true,
 "errorMsg" : "String",
 "mappingProductNames" : null,
 "delMappingProductNames" : null,
 "notMappingProductNames" : null
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
