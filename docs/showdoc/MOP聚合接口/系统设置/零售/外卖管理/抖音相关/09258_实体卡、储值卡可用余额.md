# 实体卡、储值卡可用余额

**请求URL：** 
- `/mem/benefit/amount`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|memberId|是|String| 购物卡余额|
|companyId|是|String| 门店id|

### 请求参数Json格式
 
```
{
 "memberId" : "String",
 "companyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--shoppingAmount|否|Double| 购物卡余额|
|--mentityCardAmount|否|Double| 可用实体卡余额|
|--companyId|否|String| 门店id|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "shoppingAmount" : 0,
 "mentityCardAmount" : 0,
 "companyId" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
