# 代金券批量新增

**请求URL：** 
- `/dock/voucher/batch/add`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyIds|否|List| 门店id列表|
|applyType|是|Integer| 应用门店类型 0:全部 1：指定 2：按条件|
|vouchers|是|List| 美团代金券|
|--dealId|是|Integer| 券编码|
|--dealTitle|是|String| 券名称|
|--dealValue|是|Double| 市场价格|
|--dealPrice|是|Double| 售卖价格|
|--endTime|否|DateTime| 结束时间|
|--beginTime2|否|DateTime| 开始时间|

### 请求参数Json格式
 
```
{
 "companyIds" : null,
 "applyType" : 0,
 "vouchers" : [{
 "dealId" : 0,
 "dealTitle" : "String",
 "dealValue" : 0,
 "dealPrice" : 0,
 "endTime" : "DateTime",
 "beginTime2" : "DateTime"
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",

}
```
