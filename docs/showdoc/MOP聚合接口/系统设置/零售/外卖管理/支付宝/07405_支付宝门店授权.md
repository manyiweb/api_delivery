# 支付宝门店授权
 

**请求URL：** 
- `/dock/zhifubao/shop/authorization`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 门店id|
|shopId|是|String| poiId|
|appId|是|String| poiId|
|shopName|是|String| 支付宝门店名称|

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "shopId" : "String",
 "appId" : "String",
 "shopName" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
