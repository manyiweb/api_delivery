# 获取商品和美团券关联详情

**请求URL：** 
- `/dock/coupon/link/get `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|specId|否|String| 商品规格id，对应的是每一个sku|
|companyId|否|String| 门店id|

###请求参数Json格式
 
```
{
 "specId" : "String",
 "companyId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--itemId|否|String| 商品id|
|--specId|否|String| 商品规格id|
|--itemCode|否|String| 商品编码|
|--skuCode|否|String| 商品sku|
|--itemName|否|String| 商品名称|
|--couponInfos|否|List| 关联的优惠券详情|
|----dealId|否|String| 券id|
|----dealTitle|否|String| 券名称|
|----dealValue|否|Double| 市场价格|
|----dealPrice|否|Double| 售卖价格|
|----beginTime|否|DateTime| 项目开始时间|
|----endTime|否|DateTime| 项目结束时间|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "itemId" : "String",
 "specId" : "String",
 "itemCode" : "String",
 "skuCode" : "String",
 "itemName" : "String",
 "couponInfos" : [{
 "dealId" : "String",
 "dealTitle" : "String",
 "dealValue" : 0,
 "dealPrice" : 0,
 "beginTime" : "DateTime",
 "endTime" : "DateTime"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
