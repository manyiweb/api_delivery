# 门店套餐映射 -----> 获取美团券列表

**请求URL：** 
- `/dock/tg/coupon/querySetMealList2 `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 门店id|
|dealStatus|否|Integer| 套餐状态，可选的值为：-1、全部状态（含以下所有） 0、结束售卖 1、正在售卖 2、隐藏单，前台通过POI列表及deal列表都不可见，但是通过收藏或url可以直接访问并购买 4、未开始售卖 5、不可购买|

###请求参数Json格式
 
```
{
 "companyId" : "String",
 "dealStatus" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--dealId|否|Integer| 项目id|
|--dealTitle|否|String| 项目名称|
|--dealValue|否|Double| 市场价格|
|--dealPrice|否|Double| 售卖价格|
|--beginTime|否|Long| 项目开始时间戳,单位是秒|
|--beginTime2|否|DateTime| 项目开始时间|
|--dealEndTime|否|Long| 项目结束时间戳，单位是秒|
|--endTime|否|DateTime| 项目结束时间|
|--dealStatus|否|Integer| 请求的套餐状态|
|--isVoucher|否|Boolean| 是否是代金券，true为代金券，false为套餐|
|--dealMenu|否|String| json字符串数组|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : [{
 "dealId" : 0,
 "dealTitle" : "String",
 "dealValue" : 0,
 "dealPrice" : 0,
 "beginTime" : 0,
 "beginTime2" : "DateTime",
 "dealEndTime" : 0,
 "endTime" : "DateTime",
 "dealStatus" : 0,
 "isVoucher" : true,
 "dealMenu" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
