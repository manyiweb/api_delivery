# 新增分账规则应用

**请求URL：** 
- `/app/retail/splitRuleApply/save `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|retailSplitRuleApplyId|否|Long| 应用规则id（修改时需要带上）|
|companyId|否|String| 门店id|
|applyFromDate|否|DateTime| 开始有效期|
|applyToDate|否|DateTime| 结束有效期|
|splitRuleId|否|Long| 分账规则id|
|splitRuleName|否|String| 分账规则名称|
|isOpenItemGroup|否|Integer| 是否开启特殊商品组 0不开启 1开启|
|retailSplitRuleApplyExtends|否|List| 规则应用特殊商品分组|
|--id|否|Long| 主键id|
|--splitRuleApplyId|否|Long| 分账规则应用id|
|--splitRuleId|否|Long| 分账规则id|
|--splitRuleName|否|String| 分账规则名称|
|--splitItemGroupId|否|Long| 特殊商品组id|
|--splitItemGroupName|否|String| 特殊商品分组名称|
|--splitItemGroupSn|否|String| 特殊商品分组编码|
|isInherit|否|Integer| 是否继承商户 1是 0否|

###请求参数Json格式
 
```
{
 "retailSplitRuleApplyId" : 0,
 "companyId" : "String",
 "applyFromDate" : "DateTime",
 "applyToDate" : "DateTime",
 "splitRuleId" : 0,
 "splitRuleName" : "String",
 "isOpenItemGroup" : 0,
 "retailSplitRuleApplyExtends" : [{
 "id" : 0,
 "splitRuleApplyId" : 0,
 "splitRuleId" : 0,
 "splitRuleName" : "String",
 "splitItemGroupId" : 0,
 "splitItemGroupName" : "String",
 "splitItemGroupSn" : "String"
 }],
 "isInherit" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
