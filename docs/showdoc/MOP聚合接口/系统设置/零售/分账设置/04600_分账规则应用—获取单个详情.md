# 获取单个的详情

**请求URL：** 
- `/app/retail/splitRuleApply/get `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long| 主键|


###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long| 主键|
|--splitRuleId|否|Long| 分账规则id|
|--splitRuleName|否|String| 分账规则名称|
|--companyId|否|String| 门店id|
|--applyFromDate|否|DateTime| 有效期开始|
|--applyToDate|否|DateTime| 有效期结束|
|--isOpenRuleGroup|否|Integer| 开启特殊商品组分账百分比 (0-不开启 1-开启)|
|--retailSplitRuleApplyExtends|否|List| 特殊商品组|
|----id|否|Long| 主键id|
|----splitRuleApplyId|否|Long| 分账规则应用id|
|----splitRuleId|否|Long| 分账规则id|
|----splitRuleName|否|String| 分账规则名称|
|----splitItemGroupId|否|Long| 特殊商品组id|
|----splitItemGroupName|否|String| 特殊商品分组名称|
|----splitItemGroupSn|否|String| 特殊商品分组编码|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "splitRuleId" : 0,
 "splitRuleName" : "String",
 "companyId" : "String",
 "applyFromDate" : "DateTime",
 "applyToDate" : "DateTime",
 "isOpenRuleGroup" : 0,
 "retailSplitRuleApplyExtends" : [{
 "id" : 0,
 "splitRuleApplyId" : 0,
 "splitRuleId" : 0,
 "splitRuleName" : "String",
 "splitItemGroupId" : 0,
 "splitItemGroupName" : "String",
 "splitItemGroupSn" : "String"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
