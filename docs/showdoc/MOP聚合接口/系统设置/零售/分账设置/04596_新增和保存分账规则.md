# 新增和保存分账规则

**请求URL：** 
- `/app/retail/splitRule/save `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|splitRuleId|否|Long| 分账规则id（修改的时候需要带上）|
|splitRuleName|否|String| 分账规则名称|
|isActive|否|Integer| 活跃状态(0-停用 1-启用)|
|remark|否|String| 备注|
|hostStoreSplitPercent|否|Double| 订单所属门店金额分账百分比|
|hostDistributorSplitPercent|否|Double| 门店所属经销商金额分账百分比|
|hostShareFreightPercent|否|Double| 主运费占比|
|hostDistributorFreightPercent|否|Double| 经销商运费|
|retailSplitRuleDetails|否|List| 指定经销商百分比|
|--distributorId|否|Long| 经销商id|
|--distributorName|否|String| 经销商全称|
|--distributorCode|否|String| 经销商编码|
|--shareProductPercent|否|Double| 商品分账百分比|
|--shareFreightPercent|否|Double| 运费分摊百分比(%)|

###请求参数Json格式
 
```
{
 "splitRuleId" : 0,
 "splitRuleName" : "String",
 "isActive" : 0,
 "remark" : "String",
 "hostStoreSplitPercent" : 0,
 "hostDistributorSplitPercent" : 0,
 "hostShareFreightPercent" : 0,
 "hostDistributorFreightPercent" : 0,
 "retailSplitRuleDetails" : [{
 "distributorId" : 0,
 "distributorName" : "String",
 "distributorCode" : "String",
 "shareProductPercent" : 0,
 "shareFreightPercent" : 0
 }]
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
