# 查询库存设置

**请求URL：** 
- `/inventoryLimit/info`

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 商户ID或品牌ID|
|tokenId|否|String| 用户标识|
|pageIndex|是|Integer| 分页页码|
|pageSize|是|Integer| 分页大小|
|sword|否|String| 搜索关键字|

###请求参数Json格式
 
```
{
 "companyId" : "String",
 "tokenId" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "sword" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long| 主键id|
|--companyId|否|String| 门店id|
|--productType|否|Integer| 0所有商品1指定商品|
|--active|否|Integer| 0不活跃1活跃|
|--items|否|List| 指定的商品|
|----id|否|Long| 主键id|
|----itemCode|否|String| 商品编码|
|----itemId|否|String| item_id|
|----itemName|否|String| 商品名称|
|----skuBarCode|否|String| sku码|
|----specId|否|String| spec_id|
|--pageIndex|否|Integer| 页码|
|--pageSize|否|Integer| 显示记录数|
|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "companyId" : "String",
 "productType" : 0,
 "active" : 0,
 "items" : [{
 "id" : 0,
 "itemCode" : "String",
 "itemId" : "String",
 "itemName" : "String",
 "skuBarCode" : "String",
 "specId" : "String"
 }],
 "pageIndex" : 0,
 "pageSize" : 0,
 "pageCount" : 0,
 "totalCount" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
