# 保存库存设置

**请求URL：** 
- `/inventoryLimit/save`

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 主键id|
|companyId|是|String| 门店id|
|productType|是|Integer| 0所有商品1指定商品|
|active|是|Integer| 0不启用1启用|
|items|否|List| 指定的商品|
|--id|否|Long| 主键id|
|--itemCode|否|String| 商品编码|
|--itemId|否|String| item_id|
|--itemName|否|String| 商品名称|
|--skuBarCode|否|String| sku码|
|--specId|否|String| spec_id|

###请求参数Json格式
 
```
{
 "id" : 0,
 "companyId" : "String",
 "productType" : 0,
 "active" : 0,
 "items" : [{
 "id" : 0,
 "itemCode" : "String",
 "itemId" : "String",
 "itemName" : "String",
 "skuBarCode" : "String",
 "specId" : "String"
 }]
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|String| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : "String",
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
