# 行优惠方式-更新
 

**请求URL：** 
- `/config/customDiscountWay/update `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
```
{"companyId":"6c7b5b7bb3d64e85b5634c24e5d24f4c","tokenId":"74f8cfea42bf49a99f214b2a338a09f0","isInherit":1, "id":"563295681111472267", "isOpen":0}
```


###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|Object| 主数据|
|isInherit|否|String| 消息|
|isEnable|否|String| 业务代码|
|id|否|String| id|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
