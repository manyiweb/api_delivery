# 行优惠方式-移动
 

**请求URL：** 
- `/config/customDiscountWay/move `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
```
{"companyId":"61FF8013A1FA494DBDCF718CBCB8E05B",
"tokenId":"74f8cfea42bf49a99f214b2a338a09f0",
"id":"563295681111472267", "moveType":"down"}
```


###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String|品牌商传groupId|
|id|是|String| id|
|moveType|是|String|up、 down、 top|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
