# 行优惠方式-列表
 

**请求URL：** 
- `/config/customDiscountWay/info `

**请求方式：**
- POST
- FormData


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|sword|否|String||
|companyId|是|String|店铺id|
|pageIndex|否|Integer| 页号|
|pageSize|否|Integer| 页大小|

###请求参数Json格式
 
```
{
 "sword": "",
 "pageIndex": 1,
 "pageSize": 20,
 "companyId": "6c7b5b7bb3d64e85b5634c24e5d24f4c",
 "tokenId": "74f8cfea42bf49a99f214b2a338a09f0"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|isOpen|否|int| 1启用 0停用|
|wayAlias|否|String| 优惠方式名称|
|sort|否|String| 优惠方式排序|
|targetType|否|int| 1行优惠 2整单优惠|
