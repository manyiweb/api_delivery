# 储值卡优惠设置-获取详细配置
 

**请求URL：** 
- `/config/svc/config/detail/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||
|sword|否|String||

### 请求参数Json格式
 
```
{
 "id" : 0,
 "sword" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--storedValueCardConfig|否|Object| 储值卡优惠设置 配置|
|----id|否|Long| id|
|----itemType|否|Integer| 商品类型 0：指定品牌、系列、分类 1：商品|
|----discountType|否|Integer| 优惠类型 0折扣 1立减 2立减（按数量倍减） 3:价格清单优惠|
|----openDate|否|Boolean| 是否开启有效期|
|----beginDate|否|DateTime| 开始日期|
|----endDate|否|DateTime| 结束日期|
|----activityTimeType|否|Integer| 活动时间类型 -1长期有效 0固定有效期 1固定周期|
|----cycle|否|Integer| 周期 0：每日 1：每周 2：每月|
|----day|否|String| 日期 取值 每周 1-7, 1,2,3,4,5,6,7 每月 1,2,3,4,5,6 多个用,号隔开|
|----nonSupportPromotion|否|Boolean| 不参与促销|
|----nonSupportCustomDiscount|否|Boolean| 不参与手工折扣|
|----nonSupportCoupon|否|Boolean| 不参与优惠券优惠|
|----lessMoneySupportDiscount|否|Boolean| 当购物卡余额小于订单应付金额，第一种支付方式选择购物卡支付，且一次性把余额支付完也能享受折扣优惠|
|----gradeId|否|String| 等级id|
|----gradeCode|否|String| 等级编码|
|----gradeName|否|String| 等级名称|
|----priceListId|否|String| 价格清单id|
|----priceListName|否|String| 价格清单名称|
|----planName|否|String| 方案名称|
|----status|否|Boolean| 启用状态|
|----isDefault|否|Boolean| 是否是默认方案|
|----priority|否|Integer| 优先级|
|----enableGrade|否|Boolean| 是否启用会员等级|
|--storedValueCardConfigGrades|否|List| 应用等级|
|----gradeId|否|String| 等级id|
|----gradeCode|否|String| 等级编码|
|----gradeName|否|String| 等级名称|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
