# 储值卡优惠设置-保存基础设置（继承和等级）

**请求URL：** 
- `/config/svc/config/base/set`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|isInherit|否|Boolean| 是否是继承|
|storedValueCardSet|否|Object| 储值卡优惠是否按等级设置|
|--enableGradeSet|否|Boolean| 是否开启按会员等级|
|--enableCardDiscount|否|Boolean| 是否启用储值卡支付优惠|
|companyId|是|String||
|tokenId|否|String||

### 请求参数Json格式
 
```
{
 "isInherit" : true,
 "storedValueCardSet" : {
 "enableGradeSet" : true,
 "enableCardDiscount" : true
 },
 "companyId" : "String",
 "tokenId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
