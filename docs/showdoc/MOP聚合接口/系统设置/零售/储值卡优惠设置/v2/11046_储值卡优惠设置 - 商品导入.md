# 储值卡优惠设置 - 商品导入
 

**请求URL：** 
- `/config/svc/config/item/import`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
无参数


### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--items|否|List| 导入成功并已匹配到商品档案的数据。|
|----id|否|Long||
|----itemId|否|String| 商品id|
|----specId|否|String| 规格id|
|----itemCode|否|String| 商品编码|
|----itemName|否|String| 商品名称|
|----sku|否|String| 商品sku|
|----rate|否|Double| 折扣|
|--downloadUrl|否|String| 导入失败数据下载地址。|
|--failCount|否|Integer| 失败数量。|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "items" : [{
 "id" : 0,
 "itemId" : "String",
 "specId" : "String",
 "itemCode" : "String",
 "itemName" : "String",
 "sku" : "String",
 "rate" : 0
 }],
 "downloadUrl" : "String",
 "failCount" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
