# 保存储值卡优惠设置

**请求URL：** 
- `/config/svc/config/set`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|isInherit|否|Boolean| 是否是继承|
|storedValueCardSet|否|Object| 储值卡优惠是否按等级设置|
|--enableGradeSet|否|Boolean| 是否开启按会员等级|
|--enableCardDiscount|否|Boolean| 是否启用储值卡支付优惠|
|storedValueCardConfig|否|Object| 储值卡优惠设置|
|--id|否|Long| id|
|--itemType|否|Integer| 商品类型 0：指定品牌、系列、分类 1：商品|
|--discountType|否|Integer| 优惠类型 0折扣 1立减 2立减（按数量倍减） 3:价格清单优惠|
|--openDate|否|Boolean| 是否开启有效期|
|--beginDate|否|DateTime| 开始日期|
|--endDate|否|DateTime| 结束日期|
|--activityTimeType|否|Integer| 活动时间类型 -1长期有效 0固定有效期 1固定周期|
|--cycle|否|Integer| 周期 0：每日 1：每周 2：每月|
|--day|否|String| 日期 取值 每周 1-7, 1,2,3,4,5,6,7 每月 1,2,3,4,5,6 多个用,号隔开|
|--nonSupportPromotion|否|Boolean| 不参与促销|
|--nonSupportCustomDiscount|否|Boolean| 不参与手工折扣|
|--nonSupportCoupon|否|Boolean| 不参与优惠券优惠|
|--lessMoneySupportDiscount|否|Boolean| 当购物卡余额小于订单应付金额，第一种支付方式选择购物卡支付，且一次性把余额支付完也能享受折扣优惠|
|--gradeId|否|String| 等级id|
|--gradeCode|否|String| 等级编码|
|--gradeName|否|String| 等级名称|
|--priceListId|否|String| 价格清单id|
|--priceListName|否|String| 价格清单名称|
|delIds|否|List| 要删除的品牌分类id|
|storedValueCardConfigTypes|否|List| 新增的品牌分类系列|
|--id|否|Long||
|--type|否|Integer| 0：类别 1：品牌 2：系列|
|--categoryId|否|String| 类型id|
|--categoryCode|否|String| 类型编码|
|--categoryName|否|String| 类型名称|
|--rate|否|Double| 折扣|
|storedValueCardConfigItems|否|List| 商品|
|--id|否|Long||
|--itemId|否|String| 商品id|
|--specId|否|String| 规格id|
|--itemCode|否|String| 商品编码|
|--itemName|否|String| 商品名称|
|--sku|否|String| 商品sku|
|--rate|否|Double| 折扣|
|companyId|是|String||
|tokenId|否|String||
