# 获取储值卡优惠设置
 

**请求URL：** 
- `/config/svc/config/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|gradeId|否|String| 会员等级id|
|isInherit|否|Boolean| 是否是继承|
|companyId|是|String||
|tokenId|否|String||

### 请求参数Json格式
 
```
{
 "gradeId" : "String",
 "isInherit" : true,
 "companyId" : "String",
 "tokenId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--isInherit|否|Boolean| 是否继承品牌|
|--storedValueCardSet|否|Object| 储值卡优惠设置 是否按会员等级设置|
|----enableGradeSet|否|Boolean| 是否开启按会员等级|
|----enableCardDiscount|否|Boolean| 是否启用储值卡支付优惠|
|--storedValueCardConfig|否|Object| 储值卡优惠设置 配置|
|----id|否|Long| id|
|----itemType|否|Integer| 商品类型 0：指定品牌、系列、分类 1：商品|
|----discountType|否|Integer| 优惠类型 0折扣 1立减 2立减（按数量倍减）|
|----openDate|否|Boolean| 是否开启有效期|
|----beginDate|否|DateTime| 开始日期|
|----endDate|否|DateTime| 结束日期|
|----activityTimeType|否|Integer| 活动时间类型 0固定有效期 1固定周期|
|----cycle|否|Integer| 周期 0：每日 1：每周 2：每月|
|----day|否|String| 日期 取值 每周 1-7, 1,2,3,4,5,6,7 每月 1,2,3,4,5,6 多个用,号隔开|
|----nonSupportPromotion|否|Boolean| 不参与促销|
|----nonSupportCustomDiscount|否|Boolean| 不参与手工折扣|
|----nonSupportCoupon|否|Boolean| 不参与优惠券优惠|
|----lessMoneySupportDiscount|否|Boolean| 当购物卡余额小于订单应付金额，第一种支付方式选择购物卡支付，且一次性把余额支付完也能享受折扣优惠|
|----gradeId|否|String| 等级id|
|----gradeCode|否|String| 等级编码|
|----gradeName|否|String| 等级名称|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "isInherit" : true,
 "storedValueCardSet" : {
 "enableGradeSet" : true,
 "enableCardDiscount" : true
 },
 "storedValueCardConfig" : {
 "id" : 0,
 "itemType" : 0,
 "discountType" : 0,
 "openDate" : true,
 "beginDate" : "DateTime",
 "endDate" : "DateTime",
 "activityTimeType" : 0,
 "cycle" : 0,
 "day" : "String",
 "nonSupportPromotion" : true,
 "nonSupportCustomDiscount" : true,
 "nonSupportCoupon" : true,
 "lessMoneySupportDiscount" : true,
 "gradeId" : "String",
 "gradeCode" : "String",
 "gradeName" : "String"
 }
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
