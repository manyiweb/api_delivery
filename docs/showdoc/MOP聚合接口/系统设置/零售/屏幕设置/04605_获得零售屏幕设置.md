# 获得零售屏幕设置
 

**请求URL：** 
- `/config/retail/screen/getScreenSetting`

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 门店ID|

###请求参数Json格式
 
```
{
 "companyId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--companyId|否|String| 门店ID|
|--inherit|否|Boolean| 是否继承|
|--doubleScreenSetting|否|Object| 双屏配置|
|----status|否|Object| 是否启用双屏显示 1 - 启用, 0 - 停用|
|----stencilId|否|String| 模板id|
|----screenImages|否|List| 双屏轮播图|
|------type|是|Object| 类型|
|------url|是|String| url|
|------fullUrl|否|String| 图片全路径|
|--queueNumberBoardSetting|否|Object| 叫号屏配置|
|----id|否|Long| ID|
|----enable|否|Boolean| 是否启用叫号屏|
|----companyId|否|String| 门店ID|
|----template|否|Integer| 模板类型|
|----imageList|否|List| 图片列表|
|------id|否|Long| ID|
|------url|否|String| 图片URL|
|------fullUrl|否|String| 图片全路径|
|------lineNo|否|Integer| 序号|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "companyId" : "String",
 "inherit" : true,
 "doubleScreenSetting" : {
 "status" : null,
 "stencilId" : "String",
 "screenImages" : [{
 "type" : null,
 "url" : "String",
 "fullUrl" : "String"
 }]
 },
 "queueNumberBoardSetting" : {
 "id" : 0,
 "enable" : true,
 "companyId" : "String",
 "template" : 0,
 "imageList" : [{
 "id" : 0,
 "url" : "String",
 "fullUrl" : "String",
 "lineNo" : 0
 }]
 }
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
