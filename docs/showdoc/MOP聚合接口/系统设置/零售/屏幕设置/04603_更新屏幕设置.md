# 更新屏幕设置
 

**请求URL：** 
- `/config/retail/screen//updateScreenSetting`

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|isInherit|是|Boolean| 继承|
|companyId|是|String| 门店ID|
|queueNumberBoardConfig|是|Object| 叫号屏配置|
|--enable|是|Boolean| 是否启用叫号屏|
|--template|否|Integer| 模板类型|
|--imageUrlList|否|List| 叫号屏轮播图|
|doubleScreenConfig|是|Object| 双屏配置|
|--status|是|Integer| 状态|
|--stencilKey|是|String| stencilKey|
|--screenImages|否|List| 双屏轮播图|
|----type|是|Integer| 类型|
|----url|是|String| url|

###请求参数Json格式
 
```
{
 "isInherit" : true,
 "companyId" : "String",
 "queueNumberBoardConfig" : {
 "enable" : true,
 "template" : 0,
 "imageUrlList" : null
 },
 "doubleScreenConfig" : {
 "status" : 0,
 "stencilKey" : "String",
 "screenImages" : [{
 "type" : 0,
 "url" : "String"
 }]
 }
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
