# 订单/线下 收银（系统收银和新自定义收银)
 

**请求URL：** 
- `/config/order/pay/type/list`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String||
|sword|否|String||

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "sword" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--id|否|Long||
|--imgUrl|否|String| 图片|
|--payTypeCode|否|String| 收银编码|
|--payTypeName|否|String| 收银名称|
|--isActive|否|Integer| 活跃状态 0：停用 1：启用|
|--isGroup|否|Boolean| 是否收银分组|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : [{
 "id" : 0,
 "imgUrl" : "String",
 "payTypeCode" : "String",
 "payTypeName" : "String",
 "isActive" : 0,
 "isGroup" : true
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
