# 保存读卡器设置
 

**请求URL：** 
- `/readCardSettings/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|icCardType|否|String| ic卡类型 common通用 mwrf dcrf dcr|
|readMode|否|String| 读卡模式 sector扇区 serial序列号 commonSerial通用序列号|
|sectorNo|否|Integer| 扇区号|
|blockNo|否|Integer| 块号|


### 请求参数Json格式
 
```
{
 "icCardType" : "String",
 "readMode" : "String",
 "sectorNo" : 0，
 "blockNo" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
