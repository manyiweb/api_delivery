# 查看读卡器设置
 

**请求URL：** 
- `/readCardSettings/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|

|tokenId|否|String||


### 请求参数Json格式
 
```
{
 "sword" : "String",
 "tokenId" : "String",
 
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|
|icCardType|否|String| ic卡类型 common通用 mwrf dcrf dcr|
|readMode|否|String| 读卡模式 sector扇区 serial序列号 commonSerial通用序列号|
|sectorNo|否|Integer| 扇区号|
|blockNo|否|Integer| 块号|
|createId|否|String||
|createName|否|String||
|createDate|否|DateTime||
|modifyId|否|String||
|modifyName|否|String||
|modifyDate|否|DateTime||
|dbKey|否|Integer||
|groupId|否|String||


### 返回参数Json格式
 
```
{
 "id" : 0,
 "icCardType" : "String",
 "readMode" : "String",
 "sectorNo" : 0,
 "blockNo" : 0,
 "createId" : "String",
 "createName" : "String",
 "createDate" : "DateTime",
 "modifyId" : "String",
 "modifyName" : "String",
 "modifyDate" : "DateTime",
 "dbKey" : 0,
 "groupId" : "String"
}
```
