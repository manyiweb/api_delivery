# 查看门店设备配置
 

**请求URL：** 
- `/config/machine/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|machineCode|是|String| 机器编码|
|companyId|否|String| 门店id|

### 请求参数Json格式
 
```
{
 "machineCode" : "String",
 "companyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--machineCode|否|String| 机器码|
|--printFlag|否|Boolean| 是否接单打印|
|--hasOpenPrintFlag|否|Boolean| 是否有设备开启接单打印|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : {
 "machineCode" : "String",
 "printFlag" : true,
 "hasOpenPrintFlag" : true
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
