# 保存点单商城必选商品

**请求URL：** 
- `/config/mealMall/requiredItem/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|config|否|Object| 配置|
|--id|否|Long| id|
|--companyId|否|String| 门店id|
|--enableRequiredItem|否|Boolean| 是否启用必须商品|
|items|否|List| 商品|
|--id|否|Long||
|--itemId|否|String| 商品id|
|--itemCode|否|String| 商品编码|
|--itemName|否|String| 商品名称|

### 请求参数Json格式
 
```
{
 "config" : {
 "id" : 0,
 "companyId" : "String",
 "enableRequiredItem" : true
 },
 "items" : [{
 "id" : 0,
 "itemId" : "String",
 "itemCode" : "String",
 "itemName" : "String"
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
