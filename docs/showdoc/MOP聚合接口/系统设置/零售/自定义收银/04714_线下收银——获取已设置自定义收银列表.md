# 获取线下收银已设置自定义收银列表
 

**请求URL：** 
- `/config/underline/cashierApply/list`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 门店id|
|offlineCashierType|否|Integer| 线下收银类型 0：订单收银 1：充值收银|

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "offlineCashierType" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--id|否|Long||
|--imgUrl|否|String| 图片|
|--cashierCode|否|String| 收银编码|
|--outerCode|否|String| 外部编码|
|--cashierName|否|String| 收银名称|
|--isActive|否|Integer| 活跃状态 0：停用 1：启用|
|--isGroup|否|Boolean| 是否收银分组|
|--lineNum|否|Integer| 排序|
|--autoCheck|否|Boolean| 是否自动对账|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : [{
 "id" : 0,
 "imgUrl" : "String",
 "cashierCode" : "String",
 "outerCode" : "String",
 "cashierName" : "String",
 "isActive" : 0,
 "isGroup" : true,
 "lineNum" : 0,
 "autoCheck" : true
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
