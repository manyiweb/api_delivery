# 保存自定义收银列表

**请求URL：** 
- `retail-pay-manager/app/pay/batch/company/set`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long| 编辑需要带上id|
|compList|否|List| 添加的关联门店集合|
|--companyId|是|String| 门店id|
|--companyCode|是|String| 门店编码|
|--companyName|否|String| 门店名称|
|orderCashierType|是|Boolean| 是否开启下单收银|
|rechargeCashierType|是|Boolean| 是否开启充值收银|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "compList" : [{
 "companyId" : "String",
 "companyCode" : "String",
 "companyName" : "String"
 }],
 "orderCashierType" : true,
 "rechargeCashierType" : true
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
