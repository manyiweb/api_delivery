# 保存自定义收银列表

**请求URL：** 
- `/app/pay/custom/cashier/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 编辑需要带上id|
|cashierCode|是|String| 收银编号|
|cashierName|是|String| 收银名称|
|outerCode|否|String| 外部编号|
|beginDate|否|DateTime| 有效期开始|
|endDate|否|DateTime| 有效期结束|
|payType|是|Integer| 支付类型，0:无 1：固定金额 2：固定比例|
|amount|否|String| 金额或比例|
|payAmount|否|Double| 实收金额|
|isInternal|是|Boolean| 是否内部核算，false不是 true是|
|isActive|是|Integer| 活跃状态 0：停用 1：启用|
|roundingAmount|否|Boolean| 是否抹零|
|imgUrl|否|String| 图片地址|
|enableApplyProduct|否|Integer| 是否启用应用商品 0停用 1启用|
|applyType|否|Integer| 应用类型，1：所有商品，2：指定商品 3：指定品牌、系列、类别|
|customCashierDetails|否|List| 应用商品列表|
|--id|否|Long||
|--parentId|否|Long| 自定义收银表主键|
|--itemId|否|String| 商品id|
|--itemCode|否|String| 商品编码|
|--itemName|否|String| 商品编码|
|--specId|否|String| 商品规格id|
|--skuCode|否|String| sku码|
|--categoryType|否|Integer| 类别类型，1：品牌，2：系列 3：类别|
|--categoryId|否|String| 通用指定id 可以是品牌，系列或类别|
|--categoryCode|否|String| 通用指定编码 可以是品牌，系列或类别|
|--categoryName|否|String| 通用指定名称 可以是品牌，系列或类别|
|enablePayDiscount|否|Boolean| 是否开启支付优惠|
|settlementAmount|否|Double| 结算金额|
|compList|否|List| 添加的关联门店集合|
|--companyId|是|String| 门店id|
|--companyCode|是|String| 门店编码|
|--companyName|否|String| 门店名称|
|deleteCompIdList|否|List| 当前删除的应用门店集合|
|offlineCashierType|否|Integer| 收银类型 0 不开启 1 订单 2充值 3全部|
|remark|否|String| 备注|
|billingKind|否|String| 财务属性编码|
|enablePlatformCoupon|否|Boolean| 是否开启平台券支付|
|notIncludedInInvoice|否|Boolean| 是否不计入发票金额|
|giveIntegral|否|Boolean| 是否支持积分赠送|
|openPremium|否|Boolean| 是否开启溢价|
|payChannel|否|Integer| 支付通道：0-系统默认 1-三方平台|
|ability|否|String| 关联能力（实体卡、实体券等）|
|platform|否|String| 对接平台（美欣、熊猫、企迈等）|
|limitTimesFlag|否|Boolean| 是否使用次数限制|
|limitTimes|否|Integer| 限制次数|
|needRemark|否|Boolean| 备注是否必填|
|notWithCoupon|否|Boolean| 不可与优惠券共用|
|notWithPromotion|否|Boolean| 不可与促销同享|
|openLimitTime|否|Boolean| 开启时间限制|
|notDisplay|否|Boolean| 不显示在收银界面|
|orderType|否|Integer| 订单类型 0 全部类型 1 指定类型|
|specialTypeList|否|List| 开启指定类型时 Retail 零售 CreditSale 赊销 Booking 预售|
|--type|否|String| 指定类型时 Retail 零售 CreditSale 赊销 Booking 预售，传英文|
|--value|否|String| 这个字段用于获取自定义收银列表时传输的中文字符串|
|--active|否|Boolean| 判断是否开启，true开启 false关闭|
