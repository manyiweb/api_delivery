# 获取单个自定义收银分组详情
 

**请求URL：** 
- `retail-pay-manager/app/pay/custom/cashier/group/findOne `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 对应的主键|

###请求参数Json格式
 
```
{
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long||
|--cashierCode|否|String| 收银编码|
|--cashierName|否|String| 收银名称|
|--outerCode|否|String| 外部编码|
|--imgUrl|否|String| 图片地址|
|--isActive|否|Integer| 是否启用 0停用 1启用|
|--combinePay|否|Integer| 是否启用合并支付 0停用 1启用
|--createId|否|String| 创建人id|
|--createName|否|String| 创建人名称|
|--createDate|否|DateTime| 创建日期|
|--customCashiers|否|List| 收银方式|
|----id|否|Long| Id|
|----cashierCode|否|String| 收银编码|
|----cashierName|否|String| 收银名称|
|----outerCode|否|String| 外部编码|
|----beginDate|否|DateTime| 有效期开始|
|----endDate|否|DateTime| 有效期结束|
|----payType|否|Integer| 支付类型，0：无，1：固定金额，2：固定比例|
|----amount|否|Double| 金额或比例|
|----imgUrl|否|String| 图片地址|
|----isActive|否|Integer| 是否启用 0停用 1启用|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
