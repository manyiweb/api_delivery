# 授权接口
 

**请求URL：** 
- `/manage/operation/function/auth`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|sysNo|是|String| 账号 手机号|
|funCode|是|String| 密码|
|mobile|是|String| 请求授权用户id|
|loginWord|否|String| 操作类型类型|
|companyId|是|String| 操作类型类型|
|orderId|否|String| 操作类型类型|
|specId|否|String| 操作类型类型|
|verifyType|否|String| 验证类型 password 密码 verificationCode 验证码|
|verificationCode|否|String| 验证码|

### 请求参数Json格式
 
```
{
 "sysNo" : "String",
 "funCode" : "String",
 "mobile" : "String",
 "loginWord" : "String",
 "companyId" : "String",
 "orderId" : "String",
 "specId" : "String",
 "verifyType" : "String",
 "verificationCode" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
