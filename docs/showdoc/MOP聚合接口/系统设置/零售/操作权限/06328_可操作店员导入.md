# 可操作店员导入

**请求URL：** 
- `/operator/staff/import`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|operationType|是|String| 操作类型|
|companyId|是|String| 门店id|
|tokenId|否|String| 登录标识|
|file|是|Object| 导入文件|

### 请求参数Json格式
 
```
{
 "operationType" : "String",
 "companyId" : "String",
 "tokenId" : "String",
 "file" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|resultInt|否|Integer||
|resultString|否|String||
|resultError|否|String||
|dataLine|否|Object||
|pageData|否|Object||
|--curPageNum|否|Integer||
|--totalPage|否|Integer||
|--totalCount|否|Integer||
|--pageSize|否|Integer||
|--items|否|List||
|--sortValues|否|Object||
|otherData|否|Map||
|lastCacheData|否|String| 最后缓存时间|


### 返回参数Json格式
 
```
{
 "resultInt" : 0,
 "resultString" : "String",
 "resultError" : "String",
 "dataLine" : null,
 "pageData" : {
 "curPageNum" : 0,
 "totalPage" : 0,
 "totalCount" : 0,
 "pageSize" : 0,
 "items" : null,
 "sortValues" : null
 },
 "otherData" : null,
 "lastCacheData" : "String"
}
```
