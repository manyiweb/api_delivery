# 采购交接班检查

**请求URL：** 
- `/config/check/goodOrder/handover`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 门店id|
|workDate|是|DateTime| 开班日期|
|shiftDate|是|DateTime| 交班日期|

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "workDate" : "DateTime",
 "shiftDate" : "DateTime"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
