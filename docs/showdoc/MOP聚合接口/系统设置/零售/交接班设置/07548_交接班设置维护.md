# 交接班设置维护
 

**请求URL：** 
- `/api/bmg/config/changeshifts/add`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数|类型|描述|
|:-------|:-------|:-------|
| changeShifts | number| 无 |
| shiftType | number| 无 |
| companyId | string| 无 |
| - changeJson |object | 无 |
| startTime | string| 无 |
| endTime | string| 无 |
| name | string| 无 |
| fid | string| 无 |
| notPayPendOrder | number| 无 |
| notPayOrder | number| 无 |
| partPayPendOrder | number| 无 |
| notAllotOrder | number| 无 |
| notMealOrder | number| 无 |
| - delIdArr |object | 无 |
| notSubmitDailyStatment | number| 无 |
| notIssuingStoreMachining | number| 无 |
| enableCreateVirtualHandover | number| 无 |
| needTodayFinishPickup | boolean|是否开启 - 提货时间为当天的预订单,未完成提配不允许交班 |
| notAllotOrderType | boolean|未完成的转入的调拨单类型 comp门店调拨 head总部 all都选 |
| notAllotOrderTime | boolean|未完成的转入的调拨单范围条件 create创建时间 reach到货时间 |
| tokenId | string| 无 |
| unableExistPayErrorOrder | boolean|是否开启 - 存在未退款的支付异常记录，不允许交班 |
| unableExistNotPushOrder | boolean|是否开启 - 对应班次存在未上传订单不允许交班 |
| unableExistNotReceiptsB2border | boolean|存在未完成收货的订货单不允许交班，取值：true - 开启，false - 关闭，默认不开启|
