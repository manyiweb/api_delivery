# 门店支付打印配置查询
 

**请求URL：** 
- `/config/print/payType/config/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 门店id|

### 请求参数Json格式
 
```
{
 "companyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long| ID|
|--companyId|否|String| 门店ID|
|--companyName|否|String| 门店名称|
|--payTypeList|否|List| 支付方式集合|
|----id|否|Long| id|
|----payTypeId|否|String| 支付方式id|
|----payTypeCode|否|String| 支付方式编码|
|----payTypeName|否|String| 支付方式名称|
|--printPayType|否|Boolean| 是否启用指定支付方式打印|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "companyId" : "String",
 "companyName" : "String",
 "payTypeList" : [{
 "id" : 0,
 "payTypeId" : "String",
 "payTypeCode" : "String",
 "payTypeName" : "String"
 }],
 "printPayType" : true
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
