# 获取当前用户所应用权限组
 

**请求URL：** 
- `/config/rightsGroups/find `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|moduleCode|是|String| 模块编码 product - 商品，user - 用户|

###请求参数Json格式
 
```
{
 "moduleCode" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--id|否|Long| id|
|--code|否|String| 组编码|
|--name|否|String| 组名称|
|msg|否|String| 消息|
|code|否|String| 业务代码|


###返回参数Json格式
 
```
{
 "data" : [{
 "id" : 0,
 "code" : "String",
 "name" : "String"
 }],
 "msg" : "String",
 "code" : "String"
}
```
