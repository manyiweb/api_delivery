# 获取权限组开关设置
 

**请求URL：** 
- `/config/rightsGroups/set/get`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
无参数


### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--rightsGroupsProductSet|否|Integer||
|--rightsGroupsProductListSet|否|Integer||
|--rightsGroupsUserSet|否|Integer||
|--rightsGroupB2bOrderType|否|Integer||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "rightsGroupsProductSet" : 0,
 "rightsGroupsProductListSet" : 0,
 "rightsGroupsUserSet" : 0,
 "rightsGroupB2bOrderType" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
