# 维护权限组开关设置
 

**请求URL：** 
- `/config/rightsGroups/set/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|rightsGroupsProductSet|否|Integer| 权限组开关 1 - 开启商品角色权限组设置，0 - 关闭|
|rightsGroupsProductListSet|否|Integer| 权限组开关 1 - 开启商品价格清单角色权限组设置，0 - 关闭|
|rightsGroupsUserSet|否|Integer| 权限组开关 1 - 开启用户角色权限组设置，0 - 关闭|
|rightsGroupB2bOrderType|否|Integer| 权限组开关 1 - 开启订货订单类型权限，0 - 关闭|

### 请求参数Json格式
 
```
{
 "rightsGroupsProductSet" : 0,
 "rightsGroupsProductListSet" : 0,
 "rightsGroupsUserSet" : 0,
 "rightsGroupB2bOrderType" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
