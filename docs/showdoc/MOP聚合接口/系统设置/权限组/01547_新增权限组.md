# 新增权限组
 

**请求URL：** 
- `/config/rightsGroups/add `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|code|是|String| 组编码|
|name|是|String| 组名称|
|status|否|Integer| 活跃状态 1 - 启用，0 - 不启用|

###请求参数Json格式
 
```
{
 "code" : "String",
 "name" : "String",
 "status" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Long| id|
|msg|否|String| 消息|
|code|否|String| 业务代码|


###返回参数Json格式
 
```
{
 "data" : 0,
 "msg" : "String",
 "code" : "String"
}
```
