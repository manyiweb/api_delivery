# 获取权限组详情
 

**请求URL：** 
- `/config/rightsGroups/detail `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|

###请求参数Json格式
 
```
{
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long| id|
|--code|否|String| 组编码|
|--name|否|String| 组名称|
|--status|否|Integer| 活跃状态 1 - 启用，0 - 不启用|
|--statusName|否|String| 活跃状态|
|--createId|否|String| 创建人id|
|--createName|否|String| 创建人|
|--createDate|否|DateTime| 创建时间|
|--modifyId|否|String| 修改人id|
|--modifyName|否|String| 修改人|
|--modifyDate|否|DateTime| 修改时间|
|--lineId|否|Integer| 行号|
|msg|否|String| 消息|
|code|否|String| 业务代码|


###返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "code" : "String",
 "name" : "String",
 "status" : 0,
 "statusName" : "String",
 "createId" : "String",
 "createName" : "String",
 "createDate" : "DateTime",
 "modifyId" : "String",
 "modifyName" : "String",
 "modifyDate" : "DateTime",
 "lineId" : 0
 },
 "msg" : "String",
 "code" : "String"
}
```
