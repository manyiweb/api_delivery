# 维护角色应用的权限组
 

**请求URL：** 
- `/config/rightsGroups/save `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|roleId|是|String| 角色id|
|sysNo|是|String| 平台标识|
|data|是|List| 维护的数据|
|--id|是|Long| id|
|--moduleCode|是|String| 模块编码|
|--isShow|是|Integer| 是否勾选 1 - 是,0 - 否|

###请求参数Json格式
 
```
{
 "roleId" : "String",
 "moduleCode" : "String",
 "sysNo" : "String",
 "data" : [{
 "id" : 0,
 "isShow" : 0
 }]
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String"
}
```
