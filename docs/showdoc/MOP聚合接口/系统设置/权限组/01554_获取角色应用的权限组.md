# 获取角色应用的权限组
 

**请求URL：** 
- `/config/rightsGroups/get `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|roleId|是|String| 角色id|
|sysNo|是|String| 平台标识|

###请求参数Json格式
 
```
{
 "roleId" : "String",
 "moduleCode" : "String",
 "sysNo" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Map| 主数据|
|--key|否|String| 模块|
|--value|否|String| 数据|
|----id|否|Long| id|
|----code|否|String| 组编码|
|----name|否|String| 组名称|
|----isShow|否|Integer| 是否勾选 1 - 是,0 - 否|
|msg|否|String| 消息|
|code|否|String| 业务代码|
