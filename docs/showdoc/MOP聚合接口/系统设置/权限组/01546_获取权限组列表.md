# 获取权限组列表
 

**请求URL：** 
- `/config/rightsGroups/list `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|
|sword|否|String| 搜素关键字 支持编码和名称进行模糊搜素|

###请求参数Json格式
 
```
{
 "id" : 0,
 "sword" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--id|否|Long| id|
|--code|否|String| 组编码|
|--name|否|String| 组名称|
|--status|否|Integer| 活跃状态 1 - 启用，0 - 不启用|
|--statusName|否|String| 活跃状态|
|--lineId|否|Integer| 行号|
|msg|否|String| 消息|
|code|否|String| 业务代码|


###返回参数Json格式
 
```
{
 "data" : [{
 "id" : 0,
 "code" : "String",
 "name" : "String",
 "status" : 0,
 "statusName" : "String",
 "lineId" : 0
 }],
 "msg" : "String",
 "code" : "String"
}
```
