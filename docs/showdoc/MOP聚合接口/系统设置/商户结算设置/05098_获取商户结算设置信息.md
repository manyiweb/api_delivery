# 获取商户结算设置信息

**请求URL：** 
- `/config/merchantSettlementSetting/getByCompanyId`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 商户id|

### 请求参数Json格式
 
```
{
 "companyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--enableTransferSettlement|否|Boolean| 启动调拨结算|
|--transferPriceListId|否|String| 调拨结算价格清单id|
|--transferPriceListName|否|String| 调拨结算价格清单名称|
|--enableConsignmentSettlement|否|Boolean| 启动代发结算|
|--consignmentPriceListId|否|String| 代发结算价格清单id|
|--consignmentPriceListName|否|String| 代发结算价格清单名称|
|--inherit|否|Boolean| 是否继承品牌|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : {
 "enableTransferSettlement" : true,
 "transferPriceListId" : "String",
 "transferPriceListName" : "String",
 "enableConsignmentSettlement" : true,
 "consignmentPriceListId" : "String",
 "consignmentPriceListName" : "String",
 "inherit" : true
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
