# 获取是否拥有指定数据权限
 

**请求URL：** 
- `/config/privateField/status/get `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|dataRightCode|否|String| 数据权限编码，取值：product_costPrice("商品成本单价");product_inventory_quantity("系统库存");purchase_tax_rate("税率");|

###请求参数Json格式
 
```
{
 "dataRightCode" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--status|否|Integer| 数据权限开启状态, 取值：0 - 否，1 -是|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : {
 "status" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
