# 维护数据权限
 

**请求URL：** 
- `/config/privateField/add `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|roleId|是|String| 角色id|
|sysNo|是|String| 平台标识|
|privateFieldIds|是|List| 数据权限id|

###请求参数Json格式
 
```
{
 "roleId" : "String",
 "sysNo" : "String",
 "privateFieldIds" : []
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String"
}
```
