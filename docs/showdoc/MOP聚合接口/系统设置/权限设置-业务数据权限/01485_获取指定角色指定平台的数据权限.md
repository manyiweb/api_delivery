# 获取指定角色指定平台的数据权限
 

**请求URL：** 
- `/config/privateField/list `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|roleId|是|String| 角色id|
|sysNo|是|String| 平台标识|
|fieldCodes|否|Object| 字段编码|

###请求参数Json格式
 
```
{
 "roleId" : "String",
 "sysNo" : "String",
 "module" : "String",
 "fieldCodes" : null
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--id|否|Long| id|
|--fieldCode|否|String| 字段编码|
|--fieldName|否|String| 字段名称|
|--aliasName|否|String| 别名|
|--parentId|否|Long| 上级id|
|--isDisplay|否|Integer| 是否显示|
|--children|否|List| 子集|
|----id|否|Long| id|
|----fieldCode|否|String| 字段编码|
|----fieldName|否|String| 字段名称|
|----aliasName|否|String| 别名|
|----parentId|否|Long| 上级id|
|----isDisplay|否|Integer| 是否显示|
|msg|否|String| 消息|
|code|否|String| 业务代码|


###返回参数Json格式
 
```
{
 "data" : [{
 "id" : 0,
 "fieldCode" : "String",
 "fieldName" : "String",
 "aliasName" : "String",
 "parentId" : 0,
 "isDisplay" : 0,
 "children" : [{
 "id" : 0,
 "fieldCode" : "String",
 "fieldName" : "String",
 "aliasName" : "String",
 "parentId" : 0,
 "isDisplay" : 0
 }]
 }],
 "msg" : "String",
 "code" : "String"
}
```
