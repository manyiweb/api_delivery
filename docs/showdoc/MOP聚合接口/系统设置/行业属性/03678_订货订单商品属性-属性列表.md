# 订货订单商品属性-属性列表


 
**简要描述：** 

- 用户管理

**请求URL：** 
- ` api/config/attributes/list `
 
**请求方式：**
- POST 

**参数：** 
```
{"typeCode":"B2bOrderItemProperty","tokenId":"{{tokenId}}"}
```

 **返回示例**

 


|字段|类型|空|默认|注释|
|:---- |:------- |:--- |-- -|------ |
|valueType |int |否 | | 0 任何值 1 序列 2业务对象|
