# 订单商品唯一码属性
 

**请求URL：** 
- `/app/Business/order/uniqueCodeAttr`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
无参数


### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--items|否|List||
|----uniqueCode|否|String||
|----attrs|否|List||
|------id|否|Long| 主键标识|
|------code|否|Integer| 属性（比如1-30）|
|------value|否|String| 属性值|
|------alias|否|String| 属性别名|
|------valueType|否|Integer| 0 任何值 1 序列|
|------content|否|String| 内容值,多个值时以分号“;”隔开|
|------isUpdated|否|Integer| 值为1不能变更 0可以变更|
|------isRequired|否|Integer| 必填状态(0非必填 1必填)|
|------contentArr|否|Object||
|----remark|否|String||
|----salesAdvice|否|Double| 建议售价|
|----denomination|否|Double| 面额|
|--mentityCardUnifiedPrice|否|Boolean| 实体卡是否统一售价 false 否 true是|
|--salesAmount|否|Double| 小计|
|--totalCount|否|Integer| 总数|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|

```
 "content" : "String",

 "contentArr" : null
 }],
 "remark" : "String",
 "salesAdvice" : 0,
 "denomination" : 0,
 }],
 "mentityCardUnifiedPrice" : true,
 "salesAmount" : 0,
 "totalCount" : 0
 },

 "code" : "String",

 "traceId" : "String"
}
```
