# 订货订单商品属性-保存属性


 
**简要描述：** 

- 订货订单属性保存

**请求URL：** 
- ` /api/config/attributes/set `
 
**请求方式：**

 
- POST 

 "isApplyAll" : "应用所有商品",
 

**参数：** 
```
{
 "tokenId": "6e7198b1766e4cbe84f9085513963b85",
 "dataList": [
 {
 "id": "185",
			"isEnable": 1,
 "valueType": 1,
 "content": "455345",
 "alias": "zheshiwogaide",
			"isApplyAll" : 1,
 }
 ]
}
```

 **返回示例**

``` 
 {
	"ErrorCode":"",
	"ResultString":"操作成功",
	"ResultInt":0
}
```

 **返回参数说明** 

|参数名|类型|说明|
|:----- |:-----|----- |
|groupid |int |用户组id，1：超级管理员；2：普通用户 |

 **备注** 

- 更多返回错误代码请看首页的错误代码描述
