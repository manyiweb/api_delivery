# 保存行业属性指定商品
 

**请求URL：** 
- `/config/v1/industryAttr/item/action/save `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|attrId|否|Long| 行业属性id|
|isApplyAll|否|Integer| 应用所有商品 1是 0否|
|addItemIds|否|List| 新增商品id|
|delItemIds|否|List| 移除商品id|

###请求参数Json格式
 
```
{
 "attrId" : 0,
 "isApplyAll" : 0,
 "addItemIds" : null,
 "delItemIds" : null
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
