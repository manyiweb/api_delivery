# 新建

**请求URL：** 
- `/config/customize/business/add`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 业务对象Id|
|objCode|否|String| 业务对象编码|
|objName|否|String| 对象名称|
|isActive|否|Integer| 活跃状态|
|editItems|否|List| 新增/修改业务对象内容|
|--id|否|Long| 对象内容Id，新增不传|
|--objItemName|是|String| 名称|
|delIds|否|List| 删除业务对象内容|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "objCode" : "String",
 "objName" : "String",
 "isActive" : 0,
 "editItems" : [{
 "id" : 0,
 "objItemName" : "String"
 }],
 "delIds" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|String| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : "String",
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
