# 会员收益和粉丝数

**请求URL：** 
- `/appc/member_spokesman/v2/incomeAndFans `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|否|String| token标识|

###请求参数Json格式
 
```
{
 "tokenId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--monthIncomeAmount|否|Double| 本月累计收益金额|
|--waitCashbackAmount|否|Double| 待入账金额|
|--cashbackAmount|否|Double| 可提现金额|
|--cashIncome|否|Double| 累计现金收益|
|--integralIncome|否|Double| 累计积分收益|
|--fansCount|否|Integer| 累计积分收益|
|--fansConsumptionAmount|否|Double| 粉丝消费金额|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "monthIncomeAmount" : 0,
 "waitCashbackAmount" : 0,
 "cashbackAmount" : 0,
 "cashIncome" : 0,
 "integralIncome" : 0,
 "fansCount" : 0,
 "fansConsumptionAmount" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
