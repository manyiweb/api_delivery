# 获取会员管理信息
 

**请求URL：** 
- `/config/member/management/function/get`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
无参数


### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--enableMemberTag|否|Boolean| 启用按智能标签显示会员|
|--tagList|否|List| 智能标签集合|
|----tagId|否|Long| 标签id|
|----tagName|否|String| 标签名称|
|----memberNums|否|Long| 会员数|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "enableMemberTag" : true,
 "tagList" : [{
 "tagId" : 0,
 "tagName" : "String",
 "memberNums" : 0
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
