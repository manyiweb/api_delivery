# 产品装修-收银-购物车
 

**请求URL：** 
- `/config/cart/set`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|productQuantityType|否|Integer| 收益商品数量显示 1按主商品 2按子商品|
|showTypeNum|否|Boolean| 清空按钮旁显示商品种类数量|

### 请求参数Json格式
 
```
{
 "productQuantityType" : 0,
 "showTypeNum" : true
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
