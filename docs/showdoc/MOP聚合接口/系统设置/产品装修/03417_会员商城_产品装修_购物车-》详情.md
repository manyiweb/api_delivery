# 会员商城/产品装修/购物车-》详情

**请求URL：** 
- `/config/shoppingCartDecorateMail/info`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|groupId|否|String||

### 请求参数Json格式
 
```
{
 "groupId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--title|否|String||
|--ifShowRecommend|否|Boolean| 是否显示推荐商品|
|--recommendTitle|否|String| 推荐商品标题|
|--shareWords|否|String| 购物车分享语|
|--placeholderImage|否|String| 占位图|
|--placeholderImageFull|否|String| 占位图全路径|
|--tips|否|String| 提示语|
|--buttonWords|否|String| 按钮文案|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "title" : "String",
 "ifShowRecommend" : true,
 "recommendTitle" : "String",
 "shareWords" : "String",
 "placeholderImage" : "String",
 "placeholderImageFull" : "String",
 "tips" : "String",
 "buttonWords" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
