# 

**请求URL：** 
- `/appc/member_spokesman/v2/fansRank `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|否|String| token标识|
|rankDate|否|DateTime||

###请求参数Json格式
 
```
{
 "tokenId" : "String",
 "rankDate" : "DateTime"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--totalMoney|否|Double| 消费金额|
|--cardMoney|否|Double| 返利金额|
|--userName|否|String| 用户名称|
|--phone|否|String| 手机号|
|--fansName|否|String| 粉丝名称|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : [{
 "totalMoney" : 0,
 "cardMoney" : 0,
 "userName" : "String",
 "phone" : "String",
 "fansName" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
