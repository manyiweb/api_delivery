# 查询产品装修详情
 

**请求URL：** 
- `/config/productDecoration/get `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|type|是|String| 产品装修类型 Member_Add("添加会员"),Member_Certification("会员认证"),Confirm_Dorder("确认订单"),QR_Code("扫码入会")|
|sysNo|是|String| 平台标识|

###请求参数Json格式
 
```
{
 "type" : "String",
 "sysNo" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--id|否|Long| id|
|--code|否|String| 字段编码|
|--name|否|String| 字段名称|
|--isShow|否|Integer| 是否展示 1 - 展示, 0 - 不展示|
|--isRequired|否|Integer| 是否必填 1 - 必填, 0 - 不必填|
|msg|否|String| 消息|
|code|否|String| 业务代码|


###返回参数Json格式
 
```
{
 "data" : [{
 "id" : 0,
 "code" : "String",
 "name" : "String",
 "isShow" : 0,
 "isRequired" : 0
 }],
 "msg" : "String",
 "code" : "String"
}
```
