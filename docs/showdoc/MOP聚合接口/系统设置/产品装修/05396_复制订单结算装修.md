# 复制订单结算装修
 

**请求URL：** 
- `/config/SettlementSet/copy `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 要复制的门店ID或者品牌商ID|
|toCompanyIds|否|List| 复制到门店|

###请求参数Json格式
 
```
{
 "companyId" : "String",
 "toCompanyIds" : null
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long| id|
|--uploadFile|否|Boolean| 开启上传附件|
|--tips|否|String| 描述|
|--isInherit|否|Boolean| 是否继承|
|--companyId|否|String| 门店标识|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "uploadFile" : true,
 "tips" : "String",
 "isInherit" : true,
 "companyId" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
