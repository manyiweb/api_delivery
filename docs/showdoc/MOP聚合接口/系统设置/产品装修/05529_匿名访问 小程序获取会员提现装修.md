# 匿名访问 小程序获取会员提现装修
 

**请求URL：** 
- `/config/withdrawalSet/get `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|groupId|否|String||

###请求参数Json格式
 
```
{
 "groupId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long| id|
|--openWithdrawalWx|否|Integer| 可提现账户到微信|
|--openConditions|否|Integer| 开启提现条件|
|--threshold|否|Double| 提现门槛|
|--openExplain|否|Integer| 启用说明|
|--withdrawalContent|否|String| 提现说明|
|--openWithdrawalCard|否|Integer| 可提现账户到购物卡|
|--openWithdrawalEntitycard|否|Integer| 可提现账户到实体卡|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "openWithdrawalWx" : 0,
 "openConditions" : 0,
 "threshold" : 0,
 "openExplain" : 0,
 "withdrawalContent" : "String",
 "openWithdrawalCard" : 0,
	 "openWithdrawalEntitycard" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
