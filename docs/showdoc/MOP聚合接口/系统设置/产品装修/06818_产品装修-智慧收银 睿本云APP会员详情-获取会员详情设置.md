# 产品装修-智慧收银 睿本云APP会员详情-获取会员详情设置
 

**请求URL：** 
- `/config/member/info/function/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|sysNo|是|String| 系统 checkstand:智慧收银 guide:睿本云app|

### 请求参数Json格式
 
```
{
 "sysNo" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--memberInfoFunctionSetting|否|Object| 会员详情设置|
|----enableCustomSetting|是|Boolean| 是否启用自定义设置|
|--memberInfoFunctions|否|List| 功能列表|
|----id|否|Long| 主键|
|----functionCode|是|String| 功能编码|
|----functionName|是|String| 功能名称|
|----alias|否|String| 别名|
|----customIconUrl|否|String| 自定义图标url|
|----enable|是|Boolean| 是否启用|
|----lineNum|是|Integer| 排序号|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "memberInfoFunctionSetting" : {
 "enableCustomSetting" : true
 },
 "memberInfoFunctions" : [{
 "id" : 0,
 "functionCode" : "String",
 "functionName" : "String",
 "alias" : "String",
 "customIconUrl" : "String",
 "enable" : true,
 "lineNum" : 0
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
