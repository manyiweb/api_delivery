# 保存订单结算配置
 

**请求URL：** 
- `/config/SettlementSet/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|
|uploadFile|否|Boolean| 开启上传附件|
|tips|否|String| 描述|
|isInherit|否|Boolean| 是否继承|
|companyId|否|String| 门店标识|
|inherit|否|Boolean| 是否继承|
|showOtherRemarkFlag|否|Boolean| 是否启用其他备注|
|otherRemarkName|否|String| 其他备注别名|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "uploadFile" : true,
 "tips" : "String",
 "isInherit" : true,
 "companyId" : "String",
 "inherit" : true,
 "showOtherRemarkFlag" : true,
 "otherRemarkName" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long| id|
|--uploadFile|否|Boolean| 开启上传附件|
|--tips|否|String| 描述|
|--isInherit|否|Boolean| 是否继承|
|--companyId|否|String| 门店标识|

|--otherRemarkName|否|String| 其他备注别名|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
