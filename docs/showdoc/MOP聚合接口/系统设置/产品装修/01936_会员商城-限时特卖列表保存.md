###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 商户id|
|title|否|String| 标题名称|
|isInherit|否|Integer| 是否继承 1 - 继承, 0 - 不继承|
|isActive|否|Integer| 是否启用 1 - 启用, 0 - 不启用|
|stencliId|否|String| 模板id|
|stencilId|否|String| 前端传错兼容|
|mallModules|否|List| 维护的模块|
|--code|否|String| 模块编码|
|--color|否|String| 颜色/背景色 例如#F9F9F9|
|--fontColor|否|String| 字体色|
|--height|否|Integer| 高度|
|--id|否|Long| id|
|--imageGap|否|Object| 图片间隙|
|--isHiddenBorder|否|Object| 是否隐藏边框 0 - 否, 1 - 是|
|--isShowShopCartShortcutIcon|否|Object| 是否显示购物车快捷图标 0 - 不显示, 1 - 显示|
|--mallType|否|String| 模块类型|
|--position|否|String| 显示位置|
|--showNumber|否|Integer| 展示数量|
|--stencilId|否|String| 模板id|
|--title|否|String| 模块名称、标题名|
|--typographyStyles|否|String| 排版样式|
|--width|否|Integer| 宽度|
|--mallModuleFunctions|否|List| 子模块内容|
|----id|否|String| id|
|----title|否|String| 标题、导航名称|
|----urlTypeCode|否|String| 链接类型编码|
|----sourceId|否|String| 来源id 例如 商品id、场景id|
|----typographyStyles|否|String| 排版样式|
|----position|否|String| 位置|
|----imageUrlFull|否|String| imgurl with host|
|----imageUrl|否|String| img url|
|----url|否|String| link url|
|----urlTypeName|否|String| such 附近门店|
|----carouselMaps|否|List||
|------urlTypeCode|否|String| 链接类型编码|
|------sourceId|否|String| 来源id|
|------imageUrl|否|String| 图片链接|
|------url|否|String| 跳转链接|
|----itemImgList|否|List| 兼容前端 =carouselMaps|
|------urlTypeCode|否|String| 链接类型编码|
|------sourceId|否|String| 来源id|
|------imageUrl|否|String| 图片链接|
|------url|否|String| 跳转链接|
|isShowQtyLeftInSeckill|否|Integer| 是否显示特卖商品剩余数量轴 值为 1 或 0， 与isActive参数同一级|
|isShowCountdown|否|Integer| 是否显示特卖倒计时 显示起订量 值为1或0 与isActive同一级|
