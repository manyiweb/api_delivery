# 获取维护会员返利

**请求URL：** 
- `/config/memberRebateSet/getByGroupId `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|groupId|否|String||

###请求参数Json格式
 
```
{
 "groupId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long| id|
|--showTotalCommission|否|Boolean| 显示累计佣金|
|--showTotalIntegral|否|Boolean| 显示累计积分|
|--showTotalFans|否|Boolean| 显示累计粉丝数|
|--showFansConsumption|否|Boolean| 显示粉丝累计消费金额|
|--showRebateDetail|否|Boolean| 显示返利详情|
|--showRebateRank|否|Boolean| 显示返利排名|
|--title|否|String| 标题|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "showTotalCommission" : true,
 "showTotalIntegral" : true,
 "showTotalFans" : true,
 "showFansConsumption" : true,
 "showRebateDetail" : true,
 "showRebateRank" : true,
 "title" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
