# 商品-点餐标签-导入

**请求URL：** 
- `/file/mitemlabel/import `

**请求方式：**
- POST
- FormData


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|file|是|steam| 导入文件(流)|


###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--mTotalCount|否|Long| 标签总条数|
|--mSuccessCount|否|Long| 标签成功条数|
|--mFailedCount|否|Long|标签失败条数|
|--apTotalCount|否|Long|应用商品总条数|
|--apSuccessCount|否|Long|应用商品成功条数|
|--apFailedCount|否|Long|应用商品失败条数|
|--asTotalCount|否|Long|关联商品总条数|
|--asSuccessCount|否|Long|关联商品成功条数|
|--asFailedCount|否|Long|关联商品失败条数|
|--fileUrl|否|String||
|--downloadURL|否|String|错误表格下载地址|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "mTotalCount" : 0,
 "mSuccessCount" : 0,
 "mFailedCount" : 0,
 "apTotalCount" : 0,
 "apSuccessCount" : 0,
 "apFailedCount" : 0,
 "asTotalCount" : 0,
 "asSuccessCount" : 0,
 "asFailedCount" : 0,
 "fileUrl" : "String",
 "downloadURL" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
