# 保存商品设置
 

**请求URL：** 
- `/config/product/costset/save `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|status|否|Integer| 是否启用自动计算商品档案成本价，取值：0 - 否，1 - 是|
|deleteIds|否|List| 删除记录ID集合|
|items|否|List| 请求参数|
|--brandCode|否|String| 品牌编码|
|--brandName|否|String| 品牌名称|
|--discountRate|否|Double| 折扣率(%)|

###请求参数Json格式
 
```
{
 "status" : 0,
 "deleteIds" : null,
 "items" : [{
 "brandCode" : "String",
 "brandName" : "String",
 "discountRate" : 0
 }]
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
