# 商品默认车间-获取品牌/类别/系列操作明细

**请求URL：** 
- `/config/mitemWorkshop/getCategoryRecord`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 主键|
|pageIndex|否|Integer||
|pageSize|否|Integer||
|orderField|否|String||
|orderSort|否|String||

### 请求参数Json格式
 
```
{
 "id" : 0,
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--pageIndex|否|Integer||
|--pageSize|否|Integer||
|--pageCount|否|Integer||
|--totalCount|否|Long||
|--first|否|Boolean||
|--last|否|Boolean||
|--content|否|List||
|----workshopIdBefore|否|Long| 修改前车间id|
|----workshopNameBefore|否|String| 修改前车间|
|----workshopIdAfter|否|Long| 修改后车间id|
|----workshopNameAfter|否|String| 修改后车间|
|----createName|否|String| 操作人|
|----createDate|否|String| 操作时间|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "pageIndex" : 0,
 "pageSize" : 0,
 "pageCount" : 0,
 "totalCount" : 0,
 "first" : true,
 "last" : true,
 "content" : [{
 "workshopIdBefore" : 0,
 "workshopNameBefore" : "String",
 "workshopIdAfter" : 0,
 "workshopNameAfter" : "String",
 "createName" : "String",
 "createDate" : "String"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
