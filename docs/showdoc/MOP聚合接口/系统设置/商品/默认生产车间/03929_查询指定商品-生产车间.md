# 查询指定商品-生产车间

**请求URL：** 
- `/config/mitemWorkshop/item/workshop/map `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|itemIds|否|List| 商品ids|
|companyId|否|String| 门店id|
|groupId|否|String| groupId|

###请求参数Json格式
 
```
{
 "itemIds" : null,
 "companyId" : "String",
 "groupId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 主键标识|
|companyId|否|String| 门店商户ID，与商户表syscompany相关联|
|whsId|否|String| 仓库id,关联mwhs|
|isActive|否|Integer| 活跃状态,1=启用,0=启用|
|workshopCode|否|String|车间编码|
|workshopName|否|String|车间名称|
|remark|否|String| 备注|
|createId|否|String| 创建人id|
|createName|否|String| 创建人|
|createDate|否|DateTime| 创建时间|
|modifyId|否|String| 修改人id|
|modifyName|否|String| 修改人|
|modifyDate|否|DateTime| 修改时间|
|dbKey|否|Integer| 分库标识|
|groupId|否|String| 品牌商id|


###返回参数Json格式
 
```
{
"itemId":{
 "id" : 0,
 "companyId" : "String",
 "whsId" : "String",
 "isActive" : 0,
 "workshopCode" : "String",
 "workshopName" : "String",
 "remark" : "String",
 "createId" : "String",
 "createName" : "String",
 "createDate" : "DateTime",
 "modifyId" : "String",
 "modifyName" : "String",
 "modifyDate" : "DateTime",
 "dbKey" : 0,
 "groupId" : "String"
}}
```
