# 新增

**请求URL：** 
- `/config/mitemWorkshop/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 复制源商户|
|itemList|否|List| 商品集合|
|--itemId|是|String| 商品id|
|--specId|否|String| 规格id|
|--workshopId|是|Long| 生产车间id|
|specifyType|否|Integer| 指定类型 1 指定商品 2 品牌/类别/系列|
|categoryItems|否|List| 品牌/类别/系列 信息|
|--id|否|Long| 主键|
|--categoryType|否|Integer| 类型 1-品牌、2-类别、3-系列|
|--categoryId|否|String| 类别id|
|--categoryCode|否|String| 类别编码|
|--categoryName|否|String| 类别名称|
|--workshopId|是|Long| 生产车间id|
|specifySpecialItem|否|Boolean| 指定特殊商品|
|specialItems|否|List| 特殊商品|
|--itemId|是|String| 商品id|
|--specId|否|String| 规格id|
|--workshopId|是|Long| 生产车间id|

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "itemList" : [{
 "itemId" : "String",
 "specId" : "String",
 "workshopId" : 0
 }],
 "specifyType" : 0,
 "categoryItems" : [{
 "id" : 0,
 "categoryType" : 0,
 "categoryId" : "String",
 "categoryCode" : "String",
 "categoryName" : "String",
 "workshopId" : 0
 }],
 "specifySpecialItem" : true,
 "specialItems" : [{
 "itemId" : "String",
 "specId" : "String",
 "workshopId" : 0
 }]
}
```

|code|否|String||
|exceptionStackInfo|否|String||
