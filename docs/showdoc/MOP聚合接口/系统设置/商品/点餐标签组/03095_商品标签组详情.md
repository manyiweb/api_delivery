# 功能描述: 商品标签组详情
 

**请求URL：** 
- `/config/itemLabelGroup/detail `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|

###请求参数Json格式
 
```
{
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long| 主键标识|
|--labelGroupCode|否|String| 标签组编码|
|--labelGroupName|否|String| 标签组名称|
|--lineNum|否|Long| 行号|
|--status|否|Integer| 活跃状态(0-停用,1-启用)|
|--isMultiple|否|Integer| 是否允许多选(0-单选;1-多选)|
|--remark|否|String| 备注|
|--createId|否|String| 创建人|
|--createName|否|String| 创建人名称|
|--createDate|否|DateTime| 创建时间|
|--modifiedId|否|String| 修改人|
|--modifiedName|否|String| 修改人名称|
|--modifiedDate|否|DateTime| 修改时间|
|--dbKey|否|Integer| 分库标识|
|--groupId|否|String| 品牌商id|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "labelGroupCode" : "String",
 "labelGroupName" : "String",
 "lineNum" : 0,
 "status" : 0,
 "isMultiple" : 0,
 "remark" : "String",
 "createId" : "String",
 "createName" : "String",
 "createDate" : "DateTime",
 "modifiedId" : "String",
 "modifiedName" : "String",
 "modifiedDate" : "DateTime",
 "dbKey" : 0,
 "groupId" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
