# 功能描述: 新增/编辑商品标签组
 

**请求URL：** 
- `/config/itemLabelGroup/edit `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 主键标识|
|labelGroupName|是|String| 标签组名称|
|status|是|Integer| 活跃状态(0-停用,1-启用)|
|isMultiple|是|Integer| 是否允许多选(0-单选;1-多选)|
|remark|是|String| 备注|

###请求参数Json格式
 
```
{
 "id" : 0,
 "labelGroupName" : "String",
 "status" : 0,
 "isMultiple" : 0,
 "remark" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
