# 活动标签新增/编辑
 

**请求URL：** 
- `/product/activitylabel/edit `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|
|labelName|否|String| 标签名称|
|itemType|否|Integer| 0指定商品 1分类类别品牌|
|applicationPort|否|String| 应用端口 0会员商城，1订货小程序 多选逗号隔开|
|status|否|Integer| 状态|
|activityLabelAddItemTypeReqs|否|List| 指定商品或者指定类别/品牌/系列|
|--oId|否|String| id|
|delTypeIds|否|List| 删除类型Id|
|delItemIds|否|List| 删除商品Id|
|isAllCompany|否|Integer| 所有门店|
|companyIds|否|List| 新增门店id|
|delCompanyIds|否|List| 删除门店|
|fromTime|否|DateTime| 开始时间|
|toTime|否|DateTime| 结束时间|
|remark|否|String| 备注|

###请求参数Json格式
 
```
{
 "id" : 0,
 "labelName" : "String",
 "itemType" : 0,
 "applicationPort" : "String",
 "status" : 0,
 "activityLabelAddItemTypeReqs" : [{
 "oId" : "String"
 }],
 "delTypeIds" : null,
 "delItemIds" : null,
 "isAllCompany" : 0,
 "companyIds" : null,
 "delCompanyIds" : null,
 "fromTime" : "DateTime",
 "toTime" : "DateTime",
 "remark" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
