# 活动标签详情
 

**请求URL：** 
- `/product/activitylabel/get `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|

###请求参数Json格式
 
```
{
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long||
|--labelCode|否|String| 标签编码|
|--labelName|否|String| 标签名称|
|--status|否|Integer| 状态1启用 0停用|
|--statusName|否|String| 状态|
|--applicationPort|否|String| 应用端口 0会员商城，1订货小程序 多选逗号隔开|
|--createDate|否|DateTime| 创建时间|
|--createName|否|String| 创建人|
|--modifyName|否|String| 修改人|
|--itemType|否|Integer| 0指定商品 1指定类别/品牌/系列|
|--isAllCompany|否|Integer| 应用所有门店|
|--fromTime|否|DateTime| 开始时间|
|--toTime|否|DateTime| 结束时间|
|--remark|否|String| 备注|
|--isMarketplanInit|否|Integer| 是否从促销方案生成|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "labelCode" : "String",
 "labelName" : "String",
 "status" : 0,
 "statusName" : "String",

 "createDate" : "DateTime",
 "createName" : "String",
 "modifyName" : "String",
 "itemType" : 0,
 "isAllCompany" : 0,
 "fromTime" : "DateTime",
 "toTime" : "DateTime",
 "remark" : "String",
 "isMarketplanInit" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
