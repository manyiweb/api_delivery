# 活动标签商品
 

**请求URL：** 
- `/product/activitylabel/getItem `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|
|sword|否|String| 搜素关键字,支持单号和仓库名称进行搜索|
|pageIndex|否|Integer| 页号|
|pageSize|否|Integer| 页大小|

###请求参数Json格式
 
```
{
 "id" : 0,
 "sword" : "String",
 "pageIndex" : 0,
 "pageSize" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--pageIndex|否|Integer| 页码|
|--pageSize|否|Integer| 显示记录数|
|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|--first|否|Boolean| 首页|
|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|
|----id|否|Long||
|----itemId|否|String| 商品id|
|----itemCode|否|String| 商品编码|
|----itemName|否|String| 商品编码|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : {
 "pageIndex" : 0,
 "pageSize" : 0,
 "pageCount" : 0,
 "totalCount" : 0,
 "first" : true,
 "last" : true,
 "content" : [{
 "id" : 0,
 "itemId" : "String",
 "itemCode" : "String",
 "itemName" : "String"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
