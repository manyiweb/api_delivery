# 会员商城获取商品活动标签

**请求URL：** 
- `/product/appc/product/activitylabel/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|itemIds|否|List| 商品Id|
|type|否|Integer| 标识|
|groupId|否|String| 品牌标识ID|
|tokenId|否|String| 登录标识tokenId|
|companyId|否|String| 门店id|

### 请求参数Json格式
 
```
{
 "itemIds" : null,
 "type" : 0,
 "groupId" : "String",
 "tokenId" : "String",
 "companyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--itemId|否|String| 商品id|
|--labelTitle|否|String| 标签|
|--labelTitles|否|List| 标签名称集合|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : [{
 "itemId" : "String",
 "labelTitle" : "String",
 "labelTitles" : null
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
