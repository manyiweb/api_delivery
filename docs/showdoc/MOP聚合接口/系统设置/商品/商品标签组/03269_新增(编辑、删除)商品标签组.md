# 新增(编辑、删除)商品标签组

**请求URL：** 
- `/config/product/label/group/save `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|parentId|否|Long| 商品标签组ID|
|id|否|Long| 编辑id|
|status|否|Integer| 状态|
|isDelete|否|Integer| 是否删除|
|sword|否|String| 搜索关键字|
|code|否|String| 编码|
|name|否|String| 名称|
|pageIndex|否|Integer| 页号|
|pageSize|否|Integer| 页大小|
|orderField|否|String| 商品排序字段|
|orderSort|否|String| 商品排序方式 desc 倒序 asc 正序|

###请求参数Json格式
 
```
{
 "parentId" : 0,
 "id" : 0,
 "status" : 0,
 "isDelete" : 0,
 "sword" : "String",
 "code" : "String",
 "name" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String"
}
```
