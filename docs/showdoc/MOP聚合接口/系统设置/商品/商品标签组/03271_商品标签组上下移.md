# 商品标签组上下移

**请求URL：** 
- `/config/product/label/group/move `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|parentId|否|Long| 商品标签组ID|
|id|否|Long| 编辑id|
|type|否|String| 操作类型 up、down、top|

###请求参数Json格式
 
```
{
 "parentId" : 0,
 "id" : 0,
 "type" : "String"
}
```
