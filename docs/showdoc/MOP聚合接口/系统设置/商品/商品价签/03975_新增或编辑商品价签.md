# 新增或编辑商品价签

**请求URL：** 
- `/config/mitemPriceTag/save `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 主键标识|
|companyId|否|String| 门店商户ID|
|companyCode|否|String| 门店商户code|
|companyName|否|String| 门店商户名称|
|tagName|否|String| 价签名称|
|remark|否|String| 备注|
|priceListId|否|String| 价格清单id|
|priceListName|否|String| 价格清单名称|
|itemReqList|否|List| 价签明细|
|--id|否|Long| 主键标识,有传值时更新|
|--itemId|否|String| 商品ID|
|--itemCode|否|String| 商品编码|
|--itemName|否|String| 商品名称|
|--skuBarcode|否|String| 商品条码|
|--specId|否|String| 规格ID|
|--specName|否|String| 规格名称|
|--unit|否|String| 单位|
|--specPrice|否|Double| 建议零售价|
|--listPrice|否|Double| 清单价|
|--specifyListPrice|否|Double| 指定清单价|
|--customizePrice1|否|Double| 自定义价格1|
|--customizePrice2|否|Double| 自定义价格2|
|--customizePrice3|否|Double| 自定义价格3|
|--printNumber|否|Double| 打印份数|
|--specType|否|Integer| 商品规格维度|
|--validDays|否|Double| 保质期(天)|
|--productionDate|否|DateTime| 生产日期|
|deleteItemIdList|否|List| 删除的明细id集合|

```
{

 "itemReqList" : [{
 "id" : 0,
 "itemId" : "String",
 "itemCode" : "String",
 "itemName" : "String",
 "skuBarcode" : "String",
 "specId" : "String",
 "specName" : "String",
 "unit" : "String",
 "specPrice" : 0,
 "listPrice" : 0,
 "specifyListPrice" : 0,
 "customizePrice1" : 0,
 "customizePrice2" : 0,
 "customizePrice3" : 0,
 "printNumber" : 0,
 "specType" : 0,
 "validDays" : 0,
 "productionDate" : "DateTime"
 }],
 "deleteItemIdList" : null
}
```

|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
