# 商品价签详情

**请求URL：** 
- `/config/mitemPriceTag/info `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|priceTagId|否|Long| 价签id|

###请求参数Json格式
 
```
{
 "priceTagId" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--priceListId|否|String| 价格清单id|
|--priceListName|否|String| 价格清单id|
|--id|否|Long| 主键标识|
|--tagNo|否|String| 价签编号|
|--companyId|否|String| 门店商户ID|
|--companyCode|否|String| 门店商户code|
|--companyName|否|String| 门店商户名称|
|--remark|否|String| 备注|
|--createName|否|String| 创建人|
|--createDate|否|DateTime| 创建时间|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : {
 "priceListId" : "String",
 "priceListName" : "String",
 "id" : 0,
 "tagNo" : "String",
 "companyId" : "String",
 "companyCode" : "String",
 "companyName" : "String",
 "remark" : "String",
 "createName" : "String",
 "createDate" : "DateTime"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
