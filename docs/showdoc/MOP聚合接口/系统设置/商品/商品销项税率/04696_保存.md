# 保存

**请求URL：** 
- `/config/mitemCompTaxRate/save `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 关联商户id|
|items|否|List| 关系商品|
|--itemId|否|String| 关系商品id|
|--outputTaxRate|否|Double| 销项税税率|

###请求参数Json格式
 
```
{
 "companyId" : "String",
 "items" : [{
 "itemId" : "String",
 "outputTaxRate" : 0
 }]
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Long| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : 0,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
