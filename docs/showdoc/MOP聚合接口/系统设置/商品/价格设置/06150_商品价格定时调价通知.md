# 继承-保存

**请求URL：** 
- `/config/item/price/saveInherit`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 商户标识|
|isInherit|是|String|是否继承|
|tokenId|是|String| ||

### 请求参数Json格式
 
```
{
 "companyId": "42c3fd3c127b4fd6970e6796cd86008e",
 "isInherit": "1",
 "tokenId": "6d676392e5494adea82ad0f67e5290ad"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|code|否|String| 业务代码|
|data|否|Object| 主数据|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|msg|否|String| 消息|
|success|否|String| |
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "code": "200",
 "data": null,
 "exceptionStackInfo": "",
 "monitorRequestId": "",
 "msg": "",
 "success": true,
 "traceId": ""
}
```
