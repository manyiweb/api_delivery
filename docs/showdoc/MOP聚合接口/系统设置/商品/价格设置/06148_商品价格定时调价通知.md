# 保存
 

**请求URL：** 
- `/config/item/price/save `

**请求方式：**
- POST

###请求参数<业务参数>
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|isEnable|是|Integer| 是否开启定时通知|
|scheduleTime|是|Integer|定时每天几点，0~6|
|companyId|是|String|商户id|
|tokenId|是|String| | |
### 请求参数Json格式
 
```
{
 "is_Enable": 1,
 "scheduleTime": 4,
 "companyId": "42c3fd3c127b4fd6970e6796cd86008e",
 "tokenId": "2056cd0fe132481b97241ad2bfa8470f"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|code|否|String| 业务代码|
|data|否|Object| 主数据|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|msg|否|String| 消息|
|success|否|String|处理成功与否|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "code": "200",
 "data": null,
 "exceptionStackInfo": "",
 "monitorRequestId": "",
 "msg": "",
 "success": true,
 "traceId": ""
}
```
