# 查询

**请求URL：** 
- `/config/item/price/query`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 商户标识|
|tokenId|是|String| | |

### 请求参数Json格式
 
```
{
 "companyId": "42c3fd3c127b4fd6970e6796cd86008e",
 "tokenId": "2056cd0fe132481b97241ad2bfa8470f"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|code|否|String| 业务代码|
|data|否|Object| 主数据|
|--isInherit|否|Integer| 是否继承|
|--isEnable|否|Integer|是否开启定时通知 0否,1是|
|--scheduleTime|否|Integer|定时每天通知时间 0~6点|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|msg|否|String| 消息|
|success|否|String| |
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "code": "200",
 "data": {
 "isEnable": 1,
 "isInherit": 0,
 "scheduleTime": 4
 },
 "exceptionStackInfo": "",
 "monitorRequestId": "",
 "msg": "",
 "success": true,
 "traceId": ""
}
```
