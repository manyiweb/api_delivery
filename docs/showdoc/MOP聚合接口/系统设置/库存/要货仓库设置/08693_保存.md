# 保存

**请求URL：** 
- `/config/need/whs/set/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long||
|companyId|是|String| 商户ID或品牌ID|
|enableSetWhs|否|Boolean||
|whsList|否|List||
|--id|否|Long||
|--needWhsSetId|否|Long||
|--whsId|否|String||
|--whsCode|否|String||
|--whsName|否|String||
|--isDefault|否|Boolean||

### 请求参数Json格式
 
```
{
 "id" : 0,
 "companyId" : "String",
 "enableSetWhs" : true,
 "whsList" : [{
 "id" : 0,
 "needWhsSetId" : 0,
 "whsId" : "String",
 "whsCode" : "String",
 "whsName" : "String",
 "isDefault" : true
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
