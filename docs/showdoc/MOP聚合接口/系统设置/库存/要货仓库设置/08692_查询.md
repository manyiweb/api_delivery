# 查询

**请求URL：** 
- `/config/need/whs/set/query`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String||
|sword|否|String||
|tokenId|否|String||

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "sword" : "String",
 "tokenId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--isInherit|否|Integer| 是否继承品牌，取值：0 - 否， 1 - 是|
|--id|否|Long||
|--enableSetWhs|否|Boolean||
|--whsList|否|List||
|----id|否|Long||
|----needWhsSetId|否|Long||
|----whsId|否|String||
|----whsCode|否|String||
|----whsName|否|String||
|----isDefault|否|Boolean||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "isInherit" : 0,
 "id" : 0,
 "enableSetWhs" : true,
 "whsList" : [{
 "id" : 0,
 "needWhsSetId" : 0,
 "whsId" : "String",
 "whsCode" : "String",
 "whsName" : "String",
 "isDefault" : true
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
