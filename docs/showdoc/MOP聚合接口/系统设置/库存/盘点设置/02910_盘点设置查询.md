# 查询
 

**请求URL：** 
- `/config/checkvouch/set/list`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String||

### 请求参数Json格式
 
```
{
 "companyId" : "String"
}
```
