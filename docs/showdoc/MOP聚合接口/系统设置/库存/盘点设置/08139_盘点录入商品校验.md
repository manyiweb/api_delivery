# 盘点录入商品校验

**请求URL：** 
- `/inventory/check/checkvouch/inventoryEnterCheck `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|specId|否|String| 规格id|
|companyId|否|String| 门店id|
|inventoryId|否|String| 模板id|

###请求参数Json格式
 
```
{
 "specId" : "String",
 "companyId" : "String",
 "inventoryId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Boolean||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


###返回参数Json格式
 
```
{
 "data" : true,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
