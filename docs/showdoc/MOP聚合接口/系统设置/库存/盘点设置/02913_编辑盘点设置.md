# 保存设置

**请求URL：** 
- `/config/checkvouch/set/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 配置记录Id|
|isShelf|否|Integer| 启用货架盘点|
|companyId|是|String| 商户ID或品牌ID|
|isNotAllowPurchase|否|Integer| 存在未收货完成的采购订单时不允许新建盘点单|
|isNotAllowAllot|否|Integer| 存在未收货完成的商品调拨单时不允许新建盘点单|
|isNotAllowOutIn|否|Integer| 存在未确认出入库的商品出入库单时不允许新建盘点单（统计范围：当月内）|
|allotDelayReceivingType|否|Integer| 调拨单延迟收货类型，0默认1每天时间点|
|delayReceivingDate|否|String| 调拨延迟收货每天时间点（03:21:00）|
|isAllowPostingLtBegin|否|Integer| 允许过账时间小于开始盘点时间(最多168小时) 1是，0否|
|isAllowPostingLtNow|否|Integer| 允许过账时间小于当前时间(最多168小时) 1是，0否|
|allowLtHour|否|Integer| 允许过账时间小于当前多少小时|
|inventoryHandoverRuleReqs|否|List| 保存盘点模板交接班设置|
|--id|否|Long| 规格明细id|
|--inventoryId|否|String| 模板id|
|--type|否|Integer| 类型|
|isTemplateRule|否|Boolean| 是否开启盘点模板交接班设置|
|qtyDefaultZero|否|Boolean| 盘点过账时,盘点数为空的物料默认为0|
|delTemplateRules|否|List||
|inventoryQtyRealTimePosting|否|Boolean| 按盘点数实时过账 true开启 false不开启 默认不开启启用按当前实时库存和盘点数的差异过账（说明：启用后，过账时按当前实时库存和盘点数的差异调整库存。过账日期不允许编辑，默认等于当前时间）|
|templateItemRemind|否|Boolean| 启用盘点录入非模板内商品二次提醒（端口：门店端App）|
|defaultStockQuantity|否|Boolean| 开始盘点后，盘点数支持默认根据系统库存带出，支持手动修改|
|isNotAllowAllotDiffAndInStoreMachining|否|Integer| 存在待受理的调拨差异单，生产中、待发料的店内加工单时，不允许新建盘点单（统计范围：当月内）|
|isNotAllowLtZero|否|Integer| 开始盘点后，若商品行的系统库存为负，则控制必须录入盘点数|
|inventoryInputPop|否|Boolean| 开始盘点后，录入盘点数量时(包括批量盘点)，支持在盘点界面直接录入，无需弹出弹窗(盘点数量走“覆盖”模式即可)|
|preSaleControlInventoryAdd|否|Boolean| 存在未完结的预售类型的门店订单时，不允许新建盘点单(统计范围:当月内)|
