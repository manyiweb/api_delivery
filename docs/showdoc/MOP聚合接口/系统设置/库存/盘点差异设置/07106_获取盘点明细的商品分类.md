# 获取盘点明细的商品分类

**请求URL：** 
- `/inventory/check/checkvouch/item/type`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|ckvId|否|String| 盘点单Id|

### 请求参数Json格式
 
```
{
 "ckvId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--typeCode|否|String| 分类编码|
|--typeName|否|String| 分类名称|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "typeCode" : "String",
 "typeName" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
