# 保存设置
 

**请求URL：** 
- `/config/checkvouch/diffset/save `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|deleteIds|否|List| 删除记录ID集合|
|items|否|List| 盘点商品差异设置参数|
|--specId|否|String| 商品规格ID|
|--calculationMode|否|Integer| 计算方式，取值：1 - 按数值；2 - 按百分比|
|--diffNum|否|Double| 差异正负值（数值/百分比）|
|--itemCode|否|String| 商品编码|
|--skuBarcode|否|String| 商品SKU码|

###请求参数Json格式
 
```
{
 "items" : [{
 "specId" : "String",
 "calculationMode" : 0,
 "diffNum" : 0,
 "itemCode" : "String",
 "skuBarcode" : "String"
 }]
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
