# 编辑指定商品
 

**请求URL：** 
- `/config/product/shelf/item/edit `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|shelfId|是|long| 货架id|
|addSpecIds|否|list| 添加的商品规格id|
|delIds|否|String| 需要删除的货架商品id|
|isAllItem|否|boolean| 选中所有商品 1 是 0否 |

###请求参数Json格式
 
```
{
 "shelfId": "1488442803585930459",
 "addSpecIds": [
 "081f041f1eb04935b89b81a07128ce28"
 ],
 "delIds": [],
 "isAllItem": false,
 "tokenId": "7e5d2236a0fd42adb3c3e05bc69cdd6a"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|ResultString|否|String| 消息|
|ErrorCode|否|String| 业务代码|
|ResultInt|否|int| | |


###返回参数Json格式
 
```
{
 "ResultString" : "String",
 "ErrorCode" : "String",
 "ResultInt" : "int"
}
```
