# 覆盖、追加、扣减货架商品

**请求URL：** 
- `/config/product/shelf/item/operate `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|operate|是|Integer| 1 覆盖、2 追加、3 扣减|
|shelfId|是|Long| 货架id|
|specId|是|String| 规格id|

###请求参数Json格式
 
```
{
 "operate" : 0,
 "shelfId" : 0,
 "specId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|ResultString|否|String| 消息|
|ErrorCode|否|String| 业务代码|
|ResultInt|否|int| | |


###返回参数Json格式
 
```
{
 "ErrorCode": "",
 "ResultString": "操作成功",
 "ResultInt": 0
}
```
