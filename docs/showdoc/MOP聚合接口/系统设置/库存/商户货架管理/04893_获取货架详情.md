# 获取货架详情
 

**请求URL：** 
- `/config/product/shelf/detail `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|long| 货架id|
|sword|否|String| 搜索|
|pageSize|否|String| 页面大小|
|pageIndex|否|String| 页码 |
|searchBeans|否|List| 高级筛选 |

###请求参数Json格式
 
```
{
 "id" : "String",
 "sword" : "String",
 "pageSize" : "int",
 "pageIndex" : "int",
 "searchBeans" : "List"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|productShelf|否|Object| 货架配置信息|
|----id|否|Long| 主键标识|
|----code|否|string| 货架编码|
|----name|否|String| 货架名称|
|----companyId|否|String| 商户ID（或品牌商ID）|
|----isActive|否|int| 活跃状态 1 是 0否|
|----isItemSet|否|boolean| 启用货架指定商品设置 1 是 0否|
|----isAllItem|否|boolean| 选中所有商品 1 是 0否|
|ResultString|否|String| 消息|
|ErrorCode|否|String| 业务代码|
|ResultInt|否|int| |
|TotalCount|否|int| 总记录数|
