# 查询
 

**请求URL：** 
- `/config/product/shelf/list `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 商户ID或品牌ID|
|sword|否|String| 搜索|
|pageSize|否|String| 页面大小|
|pageIndex|否|String| 页码 |
|searchBeans|否|List| 高级筛选 |

###请求参数Json格式
 
```
{
 "companyId" : "String",
 "sword" : "String",
 "pageSize" : "int",
 "pageIndex" : "int",
 "searchBeans" : "List"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|DataLine|否|Object| 主数据|
|----id|否|Long| 主键标识|
|----isActive|否|int| 活跃状态 取值：0 - 否， 1 - 是|
|----name|否|String| 货架名称|
|----code|否|String| 货架编码|
|----createDate|否|Date| 创建时间|
|----createName|否|String| 创建人|
|ResultString|否|String| 消息|
|ErrorCode|否|String| 业务代码|
|ResultInt|否|int| |
|TotalCount|否|int| 总记录数|


###返回参数Json格式
 
```
{
 "DataLine" : [{
				"docTypeName": "订货发货出库",
				"id": "857354053006137060",
				"name": 1,
				"code": ""
			}],
 "ResultString" : "String",
 "ErrorCode" : "String",
 "ResultInt" : "int"
}
```
