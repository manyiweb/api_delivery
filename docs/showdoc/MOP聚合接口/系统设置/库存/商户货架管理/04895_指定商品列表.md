# 指定商品列表

**请求URL：** 
- `/reabam-config/config/product/shelf/item/list`

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|shelfId|是|Long| 货架id|
|pageIndex|否|Integer| 页号 默认1|
|pageSize|否|Integer| 页大小 默认20|

###请求参数Json格式
 
```
{
 "shelfId" : 0,
 "pageIndex" : 0,
 "pageSize" : 0,
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|DataLine|否|Object| 主数据|
|--shelfId|否|Long| 货架id|
|--specId|否|string| 规格id|
|--specName|否|String| 规格名称|
|--itemCode|否|String| 商品编码|
|--itemId|否|String| 商品id|
|--itemName|否|String| 商品名称|
|--skuBarcode|否|String| sku|
|--unit|否|String| 单位|
|--listPrice|否|double| 价格|
|--imageUrl|否|String| 图片地址|
|pageIndex|否|Integer| 页码|
|pageSize|否|Integer| 显示记录数|
|totalCount|否|Long| 总记录数|
|pageCount|否|Integer| 总页数|
|ResultString|否|String| 消息|
|ErrorCode|否|String| 异常代码|
|ResultInt|否|String| 返回状态 0 成功 非0失败|
