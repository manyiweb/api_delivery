# 规格库存

**请求URL：** 
- `/warehouse/stock/getSpecOnHandQty`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|specIds|是|List| 规格id|
|companyId|是|String| 门店id|

### 请求参数Json格式
 
```
{
 "specIds" : null,
 "companyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--specId|否|String| 规格id|
|--onHandQty|否|Double| 库存数量|
|--bookingQty|否|Double| 订购量|
|--availableQty|否|Double| 可用量|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "specId" : "String",
 "onHandQty" : 0,
 "bookingQty" : 0,
 "availableQty" : 0
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
