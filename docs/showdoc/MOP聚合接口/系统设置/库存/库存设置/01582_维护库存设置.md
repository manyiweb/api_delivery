# 维护库存设置
 

**请求URL：** 
- `/config/inventorySet/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|isControlDealer|否|Integer||
|isControlDepartment|否|Integer||
|onlyOutCheckUniqueCodeEnable|否|Integer||
|isControlReceiptNegative|否|Integer||
|acceptanceEntry|否|Integer||
|enableSalesman|否|Integer||
|isSoldOut|否|Integer||
|allotGroupStock|否|Integer||
|cancellationAcrossMonths|否|Integer||
|requiredPickingInfo|否|Integer||
|isControlWhsOutAttachment|否|Integer||
|canOverflowWaitPickingQuantity|否|Integer||

### 请求参数Json格式
 
```
{
 "isControlDealer" : 0,
 "isControlDepartment" : 0,
 "onlyOutCheckUniqueCodeEnable" : 0,
 "isControlReceiptNegative" : 0,
 "acceptanceEntry" : 0,
 "enableSalesman" : 0,
 "isSoldOut" : 0,
 "allotGroupStock" : 0,
 "cancellationAcrossMonths" : 0,
 "requiredPickingInfo" : 0,
 "isControlWhsOutAttachment" : 0,
 "canOverflowWaitPickingQuantity" : 0
}
```

|:---- |:---|:----- |----- |
|data|否|Object||
|--isControlDealer|否|Integer||
|--isControlDepartment|否|Integer||
|--onlyOutCheckUniqueCodeEnable|否|Integer||
|--isControlReceiptNegative|否|Integer||
|--acceptanceEntry|否|Integer||
|--enableSalesman|否|Integer||
|--isSoldOut|否|Integer||
|--allotGroupStock|否|Integer||
|--cancellationAcrossMonths|否|Integer||
|--isControlWhsOutAttachment|否|Integer||
|--requiredPickingInfo|否|Integer||
|--canOverflowWaitPickingQuantity|否|Integer||
|--pickProcess|否|Integer| 拣配订单流程配置 1、拣货-分货-发货 2、分货-发货 3、拣货-分货-验货-发货 4、分货-验货-发货|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
