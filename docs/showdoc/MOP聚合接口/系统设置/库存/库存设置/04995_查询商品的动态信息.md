# 查询商品的动态信息
 

**请求URL：** 
- `/retail/app/Product/getItemDynamicInfo `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|list|否|List|商品id列表 |

###请求参数Json格式
 
```
{
 "companyId" : "String",
 "groupId" : "String",
 "sysNo" : "String",
 "list" : null
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--itemId|否|String|商品id |
|--stockQuantity|否|Double|库存数 |
|--isShelves|否|Boolean|是否上架 |
|--minPrice|否|Double|最小价格 |
|--maxPrice|否|Double|最大价格 |
|--priceType|否|Integer|价格类型 0：档案价 1：清单价 2：会员价 3：特卖价 |
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : [{
 "itemId" : "String",
 "stockQuantity" : 0,
 "isShelves" : true,
 "minPrice" : 0,
 "maxPrice" : 0,
	 "priceType" : 0
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
