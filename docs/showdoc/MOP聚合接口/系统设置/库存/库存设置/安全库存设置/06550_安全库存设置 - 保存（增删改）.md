# 安全库存设置 - 保存（增删改）

**请求URL：** 
- `/product/safety/stock/save`

**请求方式：**
- ALL
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 门店Id|
|companyName|否|String| 门店名称可不传|
|items|否|List| 商品设置|
|--id|否|Long| 主键|
|--specId|是|String| 规格id|
|--isSafetyStock|否|Boolean| 是否启用安全库存 0-否，1-是|
|--minSafeQty|否|Double| 最小安全库存|
|--maxSafeQty|否|Double| 最大安全库存|
|--safetyCycleDay|否|Integer| 安全周期天数|
|--addSafetyCycleDay|否|Integer| 追加安全周期天数|
|--usageCountDay|否|Integer| 用量统计天数|
|--displayQuantity|否|Double| 陈列量|
|--itemId|否|String| 商品Id|
|--itemCode|否|String| 商品编码|
|--specName|否|String| 商品规格名称|
|--skubarcode|否|String| sku|
|--itemName|否|String| sku|
|delIds|否|List| 删除的行id|

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "companyName" : "String",
 "items" : [{
 "id" : 0,
 "specId" : "String",
 "isSafetyStock" : true,
 "minSafeQty" : 0,
 "maxSafeQty" : 0,
 "safetyCycleDay" : 0,
 "addSafetyCycleDay" : 0,
 "usageCountDay" : 0,
 "displayQuantity" : 0,
 "itemId" : "String",
 "itemCode" : "String",
 "specName" : "String",
 "skubarcode" : "String",
 "itemName" : "String"
 }],
 "delIds" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||

```
{
 "data" : null,
```
