# 保存行为奖励
 

**请求URL：** 
- `/config/rehaviorReward/save`

**请求方式：** 
- `POST`
- `RequestBody`


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long||
|rewardType|是|Integer| 奖励类型|
|openSendIntegral|否|Integer| 开启赠送积分|
|integralNum|否|Double| 积分数量|
|giveType|否|Integer| 奖励类型|
|openSendCoupon|否|Integer| 是否开启赠送优惠券 0否 1是|
|couponList|否|List| 优惠券列表（最多5张，每张数量最多20）|
|--couponId|否|String| 优惠券ID|
|--couponCode|否|String| 优惠券编码|
|--couponName|否|String| 优惠券名称|
|--giveNum|否|Integer| 赠送数量（最大20）|
|--couponType|否|Integer| 优惠券类型（0-现金券，1-折扣券，2-兑换券）|
|--couponTypeName|否|String| 优惠券类型名称（0-现金券，1-折扣券，2-兑换券）|

### 请求参数Json格式
 
```
{
 "id":0,
 "rewardType":0,
 "openSendIntegral":0,
 "integralNum":0,
 "giveType":0,
 "openSendCoupon":0,
 "couponList":[{
 "couponId":"String",
 "couponCode":"String",
 "couponName":"String",
 "giveNum":0,
 "couponType":0,
 "couponTypeName":"String"
 }]
}
```
