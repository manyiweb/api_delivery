# 保存提醒设置

**请求URL：** 
- `/config/warningSet/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|isQuantity|否|Integer| 启用提醒数量，0否1是|
|saleQuantity|否|Double| 零售物料商品控制数量|
|notSaleQuantity|否|Double| 非零售物料商品控制数量|

### 请求参数Json格式
 
```
{
 "isQuantity" : 0,
 "saleQuantity" : 0,
 "notSaleQuantity" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
