# 更新-个人中心设置

**请求URL：** 
- `/core/mealmall/personal/center/setting/update `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|setting|否|Object| 主设置|
|--id|否|Long| 主键|
|--title|否|String| 标题名称|
|--backgroundImage|否|String| 背景图|
|functions|否|List| 功能列表|
|--id|否|Long| 主键|
|--functionCode|否|String| 功能编码|
|--functionName|否|String| 功能名称|
|--alias|否|String| 别名|
|--customIconUrl|否|String| 自定义图标url|
|--enable|否|Boolean| 是否启用|
|--lineNum|否|Integer| 排序号|

###请求参数Json格式
 
```
{
 "setting" : {
 "id" : 0,
 "title" : "String",
 "backgroundImage" : "String"
 },
 "functions" : [{
 "id" : 0,
 "functionCode" : "String",
 "functionName" : "String",
 "alias" : "String",
 "customIconUrl" : "String",
 "enable" : true,
 "lineNum" : 0
 }]
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|String| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : "String",
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
