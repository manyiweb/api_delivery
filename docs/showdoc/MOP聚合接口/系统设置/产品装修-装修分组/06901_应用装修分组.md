# 应用装修分组

**请求URL：** 
- `/decoration/template/applyCompanyGroup`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long| 模板id|
|chainList|否|List| 装修分组集合|
|--chainId|否|String| 装修分组id|
|--chainCode|否|String| 装修分组编码|
|--chainName|否|String| 装修分组名称|
|--companyNumber|否|Double| 装修分组商户数量|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "chainList" : [{
 "chainId" : "String",
 "chainCode" : "String",
 "chainName" : "String",
 "companyNumber" : 0
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
