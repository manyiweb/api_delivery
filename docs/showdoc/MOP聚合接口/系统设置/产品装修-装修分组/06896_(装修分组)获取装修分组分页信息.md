# 获取门店组分页

**请求URL：** 
- `/meal-decoration/decorationGroup/getPage`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|pageIndex|是|Integer| 页码|
|pageSize|是|Integer| 显示记录数|
|keyword|否|String| 查询信息|
|isOpen|否|Integer| 门店组查询启用状态标识 1-查询启用状态 0-全显|

### 请求参数Json格式
 
```
{
 "pageIndex" : 0,
 "pageSize" : 0,
 "keyword" : "String",
 "isOpen" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--pageIndex|否|Integer||
|--pageSize|否|Integer||
|--pageCount|否|Integer||
|--totalCount|否|Long||
|--first|否|Boolean||
|--last|否|Boolean||
|--content|否|List||
|----id|否|Long| 主键|
|----groupCode|否|String| 分组编码|
|----groupName|否|String| 分组名称|
|----status|否|Boolean| 状态 0-停用 1-启用|
|----lineNum|否|Long| 排序|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "pageIndex" : 0,
 "pageSize" : 0,
 "pageCount" : 0,
 "totalCount" : 0,
 "first" : true,
 "last" : true,
 "content" : [{
 "id" : 0,
 "groupCode" : "String",
 "groupName" : "String",
 "status" : true,
 "lineNum" : 0
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
