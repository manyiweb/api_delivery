# 根据装修分组id查询门店

**请求URL：** 
- `/decorationGroupCompany/getCompanys`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||

### 请求参数Json格式
 
```
{
 "id" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--id|否|Long| 主键|
|--decorationGroupId|否|Long| 分组id|
|--companyId|否|String| 门店id|
|--companyName|否|String| 门店名称|
|--companyCode|否|String| 门店编码|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "id" : 0,
 "decorationGroupId" : 0,
 "companyId" : "String",
 "companyName" : "String",
 "companyCode" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
