# 导入门店接口

**请求URL：** 
- `/meal-decoration/decorationGroupCompany/companysImport`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|file|是|excel文件|门店导入文件|
|tokenId|是|String||
|decorationGroupId|是|String|装修分组id|


### 返回参数Json格式
 
```
{
 "downloadURL": "",
 "successCount": 0,
 "ErrorCode": "",
 "ResultString": "操作成功",
 "totalCount": 0,
 "errorCount": 0,
 "ResultInt": 0
}
```
