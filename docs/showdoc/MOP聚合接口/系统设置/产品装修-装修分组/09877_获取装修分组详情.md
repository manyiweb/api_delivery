# 获取装修分组详情

**请求URL：** 
- `/meal-decoration/decorationGroup/getDetail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||

### 请求参数Json格式
 
```
{
 "id" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--companyList|否|List| 门店列表|
|----id|否|Long| 主键|
|----decorationGroupId|否|Long| 分组id|
|----companyId|否|String| 门店id|
|----companyName|否|String| 门店名称|
|----companyCode|否|String| 门店编码|
|--templateId|否|Long| 点单模板id|
|--templateName|否|String| 点单模板名称|
|--reserveTemplateId|否|Long| 预定模板id|
|--reserveTemplateName|否|String| 预定模板名称|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "companyList" : [{
 "id" : 0,
 "decorationGroupId" : 0,
 "companyId" : "String",
 "companyName" : "String",
 "companyCode" : "String"
 }],
 "templateId" : 0,
 "templateName" : "String",
 "reserveTemplateId" : 0,
 "reserveTemplateName" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
