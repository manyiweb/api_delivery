# 根据操作模式处理

**请求URL：** 
- `/meal-decoration/decorationGroup/editGroup`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|mode|是|Integer| 1-添加，2-编辑，3-删除|
|id|否|Long| 分组id (添加不用传)|
|status|是|Boolean| 活跃状态 默认启用|
|groupName|否|String| 分组名称|

### 请求参数Json格式
 
```
{
 "mode" : 0,
 "id" : 0,
 "status" : true,
 "groupName" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
