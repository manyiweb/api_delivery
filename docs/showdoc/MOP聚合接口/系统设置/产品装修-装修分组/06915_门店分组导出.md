# 门店分组导出

**请求URL：** 
- `/meal-decoration/decorationGroupCompany/export`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|否|String||
|decorationGroupId|否|String| 门店分组id|
|pageIndex|否|Integer||
|pageSize|否|Integer||
|isDownload|是|String|前端需要传入Y字符串|


### 请求参数Json格式
 
```
{
 "tokenId" : "String",
 "decorationGroupId" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "isDownload" : "Y",
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
