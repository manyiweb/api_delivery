# 社群推广-根据品牌查出所有(点单商城开启的并且状态为开启的)

**请求URL：** 
- `/decoration/social/appc/getcompany`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|否|String||
|pageIndex|是|Integer||
|pageSize|是|Integer||
|sword|否|String||

### 请求参数Json格式
 
```
{
 "tokenId" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "sword" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--pageIndex|否|Integer||
|--pageSize|否|Integer||
|--pageCount|否|Integer||
|--totalCount|否|Long||
|--first|否|Boolean||
|--last|否|Boolean||
|--content|否|List||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "pageIndex" : 0,
 "pageSize" : 0,
 "pageCount" : 0,
 "totalCount" : 0,
 "first" : true,
 "last" : true,
 "content" : null
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
