# 维护-社群推广装修

**请求URL：** 
- `/decoration/social/module/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|modules|否|Object| 社群模板内容|
|--contentModule|否|Object| 模块内容|
|----title|否|String| 页面标题标题|
|----backgroundImage|否|String| 背景图|
|----backgroundImageFull|否|String| 背景图全路径|
|----position|否|String| 位置、对齐方式 居左：left 居中：center 居右：right|
|----fontColor|否|String| 文字颜色|
|----fontSize|否|String| 文字大小|
|----fontWeight|否|String| 文字粗细|
|----fontStyle|否|String| 字体样式 加粗、倾斜|
|----backgroundColor|否|String| 背景颜色|
|----xs|否|Double| x轴起点(用于热区)|
|----ys|否|Double| y轴起点(用于热区)|
|----xe|否|Double| x轴终点(用于热区)|
|----ye|否|Double| y轴终点(用于热区)|
|----width|否|String| 宽度|
|----height|否|String| 高度|
|----borderRadius|否|String| 圆角|
|----borderWidth|否|String| 边框宽度|
|----opacity|否|String| 不透明度|
|----borderType|否|String| 边框类型|
|----borderColor|否|String| 边框颜色|
|----borderTopRadius|否|String| 上圆角|
|----borderBottomRadius|否|String| 下圆角|
|----lineHeight|否|String| 行高|
|----isBolder|否|Boolean| 字体是否加粗|
|----isIncline|否|Boolean| 字体是否倾斜|
|----numIsBolder|否|Boolean| 数值是否加粗|
|----numIsIncline|否|Boolean| 数值是否倾斜|
|----unitIsBolder|否|Boolean| 单位是否加粗|
|----unitIsIncline|否|Boolean| 单位是否倾斜|
|----numFontSize|否|String| 数值字体大小|
|----unitFontSize|否|String| 单位字体大小|
|----numUnitPosition|否|String| 数值、单位对齐方式|
|----numFontColor|否|String| 数值颜色|
|----unitFontColor|否|String| 单位颜色|
|----pointType|否|Integer| 点类型 0 圆 1 矩|
|----bottomDistance|否|String| 底部距离|
|----carouselInterval|否|String| 轮播间隔时常|
|--cssModule|否|Object| css代码模块，模块样式以这个为主，若这个为空则以内容模块中的样式为主|
|----css|否|String| css代码段|
|companyList|否|List| 应用门店|
|--id|否|Long||
|--templateId|否|String| 模板id|
|--companyName|是|String| 门店名称|
|--companyCode|是|String| 门店编码|
|--companyId|否|String| 门店id|
|--isAdd|否|Boolean| 是否已添加企微码|
|--wecomCodeUrl|否|String| 企微码图|
|--wecomCodeFullUrl|否|String| 企微码图片全路径|
|code|是|String| 模块编码|
