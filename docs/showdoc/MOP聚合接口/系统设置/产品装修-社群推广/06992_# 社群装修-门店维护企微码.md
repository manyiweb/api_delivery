# 社群装修-门店维护企微码

**请求URL：** 
- `/decoration/social/module/wecomcode/company/defend`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long| 门店id|
|wecomCodeFullUrl|否|String| 企微码图片全路径|
|handleType|是|String| 操作类型 CT001-为删除门店, CT002为维护门店|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "wecomCodeFullUrl" : "String",
 "handleType" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
