# 社群装修-导入企微码

**请求URL：** 
- `/decoration/social/module/wecomcode/import`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
无参数


### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|是|String|
|file|是|文件||

### 返回参数Json格式
 
```
{
 "downloadURL": "",
 "successCount": 0,
 "ErrorCode": "",
 "ResultString": "",
 "totalCount": 0,
 "errorCount": 0,
 "ResultInt": 0
}

```
