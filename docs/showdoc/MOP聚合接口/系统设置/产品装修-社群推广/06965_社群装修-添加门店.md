# 社群装修-添加门店

**请求URL：** 
- `/decoration/social/module/companys/add`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|String| 模板id|
|companyList|否|List| 门店信息|
|--id|否|Long||
|--templateId|否|String| 模板id|
|--companyName|是|String| 门店名称|
|--companyCode|是|String| 门店编码|
|--companyId|否|String| 门店id|
|--isAdd|否|Boolean| 是否已添加企微码|
|--wecomCodeUrl|否|String| 企微码图|
|--wecomCodeFullUrl|否|String| 企微码图片全路径|

### 请求参数Json格式
 
```
{
 "id" : "String",
 "companyList" : [{
 "id" : 0,
 "templateId" : "String",
 "companyName" : "String",
 "companyCode" : "String",
 "companyId" : "String",
 "isAdd" : true,
 "wecomCodeUrl" : "String",
 "wecomCodeFullUrl" : "String"
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
