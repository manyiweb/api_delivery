# 查询
 

**请求URL：** 
- `/config/taxrate/list `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 商户ID或品牌ID|

###请求参数Json格式
 
```
{
 "companyId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--isInherit|否|Integer| 是否继承品牌，取值：0 - 否， 1 - 是|
|--items|否|List| 税率集合数据|
|----id|否|Long| 主键标识|
|----taxRate|否|Double| 税率|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : {
 "isInherit" : 0,
 "items" : [{
 "id" : 0,
 "taxRate" : 0
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
