# 替代料管理列表

**请求URL：** 
- `/config/produce/substitute/list/{source}`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|keyword|否|String| 模糊搜索|
|status|否|List| 状态|
|createDate|否|Object| 创建日期|
|--start|否|DateTime||
|--end|否|DateTime||
|id|否|String||
|pageSize|否|Integer||
|pageNo|否|Integer||
|sortField|否|String||
|sortDirection|否|String||
|viewId|否|String||

### 请求参数Json格式
 
```
{
 "keyword" : "String",
 "status" : null,
 "createDate" : {
 "start" : "DateTime",
 "end" : "DateTime"
 },
 "id" : "String",
 "pageSize" : 0,
 "pageNo" : 0,
 "sortField" : "String",
 "sortDirection" : "String",
 "viewId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--content|否|List||
|----id|否|Long| 主键id|
|----itemCode|否|String| 物料编码|
|----skuBarcode|否|String| SKU码|
|----itemName|否|String| 物料名称|
|----statusString|否|String| 活跃状态|
|----status|否|Integer| 状态|
|----typeCodeName|否|String| 类型|
|----remark|否|String| 备注|
|----createDate|否|DateTime| 创建时间|
|----createName|否|String| 创建人|
|--pageSize|否|Integer||
|--pageNo|否|Integer||
|--total|否|Long||
|--totalPage|否|Integer||
|--hasNextPage|否|Boolean||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
