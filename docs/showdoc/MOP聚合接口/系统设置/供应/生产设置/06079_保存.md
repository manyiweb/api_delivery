# 保存

**请求URL：** 
- `/config/produce/set/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 商户ID或品牌ID|
|isFinishCanReturn|是|Integer| 开启店内加工单生产完成后继续生产退货 0否1是|
|returnTimeType|否|Integer| 生产退货时间类型 0当月1没有限制2按天|
|dayLimitSet|否|Integer| 生产退货天数设置，需为非负整数|
|isHqItemAutoOrder|否|Boolean| 启用代发订单代发商品自动生成生产计划单|
|isLossAutoOut|否|Boolean| 启用生产收货损耗数量自动出库|
|brandSubstitute|否|Boolean| 品牌级别替代料|
|outboundType|否|String| 出库类型|
|outboundTypeName|否|String| 出库名称|
|isAutoAllotCompany|否|Boolean| 启用生产收货损耗数量自动出库|
|allotType|否|String| 调拨类型|
|allotTypeName|否|String| 调拨类型名称|
|allotReason|否|String| 调拨原因|
|produceDate|否|Long| 生产时长|
|deliveryDate|否|Long| 配送时长|
|isFirstReceivingAfterDelivery|否|Boolean| 是否先收货后发货|
|productionReceiptDecimalPlaces|否|Integer| 生产收货小数位 0-4 品牌设置|
|isAllowModifyDeliveryType|否|Boolean| 启用订单收货时，允许修改生产配送方式（说明：适用生产端）|
|openBeforeReceiving|否|Boolean| 启用子物料库存不足时，先收货后发料|
|planOrderBefore|否|Boolean| 生产计划单|
|orderBefore|否|Boolean| 生产订单|
|openReceivingBefore|否|Boolean| 生产收货单按钮|
|waitPhotographGroup|否|Boolean| 待拍照分组 true/false|
|orderAutoPrintBeginTime|否|String| 来单自动打印开始时间|
|orderAutoPrintEndTime|否|String| 来单自动打印结束时间|
|receiptProducer|否|Boolean| 启用订单收货时，必须选择制作师|
|planProducer|否|Boolean| 制作师-计划|
|orderProducer|否|Boolean| 制作师-订单|
|receivingProducer|否|Boolean| 制作师-收货|
|updateProduceBillItem|否|Boolean| 支持对待生产的订单详情》物料清单内的子物料进行增删修改|
|addPlanProductionWorkshop|否|Boolean| 新建生产计划时，支持指定订单的生产车间（说明：使用门店端Web新建生产计划的场景）|
|openWorkshopManage|否|Boolean| 启用工作车间管理|
|openDumpAllotType|否|Boolean| 开启转储调拨类型|
|dumpAllotType|否|String| 转储类型|
|dumpAllotTypeName|否|String| 转储类型名称|
|dumpAllotReason|否|String| 转储原因|
|dumpAllotReasonName|否|String| 转储原因名称|
|autoDeductWorkshopInventory|否|Boolean| 自动扣减生产车间库存|
|materialReceiveDeductInventory|否|Boolean| 领料自动扣减库存|
|autoMaterialReceive|否|Boolean| 自动领料|
|enableLossQuantity|否|Boolean| 启用生产收货填写损耗数量|
