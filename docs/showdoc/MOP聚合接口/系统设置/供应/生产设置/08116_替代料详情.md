# 替代料详情

**请求URL：** 
- `/config/produce/substitute/detail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long|主键id|


### 请求参数Json格式
 
```
{
 "id" : 0,
 "sword" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long| 主键id|
|--specId|否|String| 物料规格id|
|--itemCode|否|String| 物料编码|
|--skuBarcode|否|String| 物料sku|
|--itemName|否|String| 物料名称|
|--status|否|Integer| 状态 0关闭 1启用|
|--typeCodeName|否|String| 类型|
|--remark|否|String| 备注|
|--substituteList|是|List| 替代商品|
|----substituteSpecId|否|String| 替代商品的规格id|
|----substituteCode|否|String| 替代商品编码|
|----substituteSkuBarCode|否|String| 替代商品SKU码|
|----substituteName|否|String| 替代商品名称|
|----num|否|Double| 替代商品数量|
|----unit|否|String| 替代商品单位|
|----orderNo|否|Integer| 排序号|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "specId" : "String",
 "itemCode" : "String",
 "skuBarcode" : "String",
 "itemName" : "String",
 "status" : 0,
 "typeCodeName" : "String",
 "remark" : "String",
 "substituteList" : [{
 "substituteSpecId" : "String",
 "substituteCode" : "String",
 "substituteSkuBarCode" : "String",
 "substituteName" : "String",
 "num" : 0,
 "unit" : "String",
 "orderNo" : 0
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
