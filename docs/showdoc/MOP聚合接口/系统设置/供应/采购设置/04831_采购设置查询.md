# 采购设置-查询

**请求URL：** 
- `/config/purchaseSet/query`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 商户ID或品牌ID|

### 请求参数Json格式
 
```
{
 "companyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--isInherit|否|Integer| 是否继承|
|--isNotAllow|否|Integer| 是否允许多收|
|--notAllowZeroPrice|否|Integer| 是否不支持采购价为0的商品,0-否 1-是|
|--requiredAttachment|否|Boolean| 是否必选附件|
|--isSpecificPriceList|否|Boolean| 若供应商采购价格清单为指定品牌价格清单，则新建采购相关单据时(包括基于采购收货单退货场景)，控制不允许修改采购价、小计、税率、无税单价字段只能根据默认带出的采购价、税率等计算得出|
|--multipleSku|否|Boolean| 新建采购订单、导入生成采购订单时，同一SKU允许添加多行(说明:仅适用于品牌端Web新建采购订单场景)|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "isInherit" : 0,
 "isNotAllow" : 0,
 "notAllowZeroPrice" : 0,
 "requiredAttachment" : true,
 "isSpecificPriceList" : true,
 "multipleSku" : true
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
