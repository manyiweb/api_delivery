# 生产车间详情
 

**请求URL：** 
- `/config/productionWorkshop/info `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|

###请求参数Json格式
 
```
{
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long| 主键标识|
|--companyId|否|String| 门店商户ID，与商户表syscompany相关联|
|--whsId|否|String| 仓库id,关联mwhs|
|--whsName|否|String| 仓库|
|--isActive|否|Integer| 活跃状态,true=启用,false=启用|
|--workshopCode|否|String|车间编码|
|--workshopName|否|String|车间名称|
|--remark|否|String| 备注|
|--createName|否|String| 创建人姓名|
|--createDate|否|DateTime| 创建时间|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "companyId" : "String",
 "whsId" : "String",
 "whsName" : "String",
 "isActive" : 0,
 "workshopCode" : "String",
 "workshopName" : "String",
 "remark" : "String",
 "createName" : "String",
 "createDate" : "DateTime"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
