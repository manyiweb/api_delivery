# 新增代发分类 特殊商品设置

**请求URL：** 
- `/config/supplier/item/comp/category/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 商户id|
|type|是|Integer| 类型 0-零售|
|supplyingType|否|Integer| 代发类型：0 代发，1寄售|
|categoryDtoList|否|List| 商品ids|
|--categoryType|否|Integer| 类别类型,1：品牌,2：系列 3：类别|
|--categoryId|否|String| 通用指定id 可以是品牌,系列或类别|
|--categoryCode|否|String| 通用指定编码 可以是品牌,系列或类别|
|--categoryName|否|String| 通用指定名称 可以是品牌,系列或类别|
|--isAutoSend|否|Integer| 是否自动代发 1是， 0 否|
|--supplyingType|否|Integer| 代发类型：0 代发，1寄售|
|--proxy|否|Integer| 代发方 0供应商,1品牌商|
|--isAllComp|否|Integer| 是否所有门店 1是， 0 否|
|--companyIds|否|List| 新增门店Ids|
|--retailDefaultCompanyId|否|String| 零售默认门店|
|--companys|否|List| 新增门店Ids|
|----id|否|Long| ID|
|----supplierMitemCompId|否|Long| supplier_mitem_comp表id|
|----companyId|否|String| 关联商户id|
|----companyName|否|String| 商户名称|
|----companyCode|否|String| 商户编码|
|----logisticsId|否|String| 物流商Id|
|----logisticsName|否|String| 物流商名称|
|--delIds|否|List| 删除Ids|
|--settlementRate|否|Double| 结算比例|
|--supCode|否|String| 供应商code|
|--supName|否|String| 供应商Name|
|itemIds|否|List| 商品ids|
|specialItem|否|Object||
|--supplyingType|否|Integer| 代发类型：0 代发，1寄售|
|--items|否|List| 商品ids|
|----itemId|否|String| 商品id|
|----isAutoSend|否|Integer| 是否自动代发 1是， 0 否|
|----supplyingType|否|Integer| 代发类型：0 代发，1寄售|
|----proxy|否|Integer| 代发方 0供应商,1品牌商|
|----isAllComp|否|Integer| 是否所有门店 1是， 0 否|
|----companyIds|否|List| 新增门店Ids|
|----retailDefaultCompanyId|否|String| 零售默认门店|
|----companys|否|List| 新增门店Ids|
|------id|否|Long| ID|
|------supplierMitemCompId|否|Long| supplier_mitem_comp表id|
|------companyId|否|String| 关联商户id|
|------companyName|否|String| 商户名称|
|------companyCode|否|String| 商户编码|
|------logisticsId|否|String| 物流商Id|
|------logisticsName|否|String| 物流商名称|
|----delIds|否|List| 删除Ids|
|----settlementRate|否|Double| 结算比例|
|----supCode|否|String| 供应商code|
|----supName|否|String| 供应商Name|
|--itemIds|否|List| 商品ids|
