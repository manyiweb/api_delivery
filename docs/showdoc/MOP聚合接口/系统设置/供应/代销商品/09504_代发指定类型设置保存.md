# 代发指定类型设置保存

**请求URL：** 
- `/config/supplier/item/comp/set/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long||
|companyId|是|String| 商户id|
|type|是|Integer| 类型：0零售,1订货|
|pointType|是|Integer| 代发设置指定类型 0指定商品 1指定品牌分类系列|
|specialItem|否|Integer| '指定品牌分类系列是否开启特殊商品'|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "companyId" : "String",
 "type" : 0,
 "pointType" : 0,
 "specialItem" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
