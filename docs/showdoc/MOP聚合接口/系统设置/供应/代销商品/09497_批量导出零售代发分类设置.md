# 批量导出零售代发分类设置

**请求URL：** 
- `/config/supplier/item/comp/batchExportCategoryByExcel`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyIds|是|List| 商户ID|
|type|是|Integer| 类型 0-零售|
|sword|否|String| 搜索关键字|
|supplyingType|否|Integer| 代发类型：0 代发，1寄售|

### 请求参数Json格式
 
```
{
 "companyIds" : null,
 "type" : 0,
 "sword" : "String",
 "supplyingType" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--totalCount|否|Long||
|--successCount|否|Long||
|--errorCount|否|Long||
|--fileUrl|否|String||
|--downloadURL|否|String||
|--data|否|List||
|--isTask|否|Boolean||
|--code|否|Integer||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "totalCount" : 0,
 "successCount" : 0,
 "errorCount" : 0,
 "fileUrl" : "String",
 "downloadURL" : "String",
 "data" : null,
 "isTask" : true,
 "code" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
