# 代发方保存

**请求URL：** 
- `/config/supplier/item/comp/proxy/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|supplierMitemCompId|否|Long| supplier_mitem_comp表id|
|isAutoSend|否|Integer| 是否自动代发 1是， 0 否|
|companys|否|List| 关联商户id|
|--isDefault|否|Integer| 是否默认 0否1是|
|--prices|否|List| 代发结算价|
|----id|否|Long| ID|
|----smcpId|否|Long| supplier_mitem_comp_proxy表id|
|----settlementPrice|否|Double| 结算价|
|----beginDate|否|String| 有效期起|
|----endDate|否|String| 有效期至|
|----listPriceId|否|String| 清单价id|
|----listPriceName|否|String| 清单价|
|--deleteIds|否|List| 删除Ids|
|--id|否|Long| ID|
|--supplierMitemCompId|否|Long| supplier_mitem_comp表id|
|--companyId|否|String| 关联商户id|
|--companyName|否|String| 商户名称|
|--companyCode|否|String| 商户编码|
|--logisticsId|否|String| 物流商Id|
|--logisticsName|否|String| 物流商名称|
|deleteIds|否|List| 删除Ids|
