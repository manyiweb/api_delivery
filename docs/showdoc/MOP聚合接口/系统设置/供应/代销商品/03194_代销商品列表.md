# 代销商品列表

**请求URL：** 
- `/config/supplier/item/comp/list `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 商户ID|
|type|否|Integer| 类型 0-零售，1订货|
|sword|否|String| 搜索关键字|
|pageIndex|否|Integer| 页号|
|pageSize|否|Integer| 页大小|
|orderField|否|String| 商品排序字段|
|orderSort|否|String| 商品排序方式 desc 倒序 asc 正序|

###请求参数Json格式
 
```
{
 "companyId" : "String",
 "type" : 0,
 "sword" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--isInherit|否|Integer| 是否继承品牌，取值：0 - 否， 1 - 是|
|--items|否|Object| 模板集合数据|
|----pageIndex|否|Integer| 页码|
|----pageSize|否|Integer| 显示记录数|
|----pageCount|否|Integer| 总页数|
|----totalCount|否|Long| 总记录数|
|----first|否|Boolean| 首页|
|----last|否|Boolean| 尾页|
|----content|否|List| 分页数据|
|------itemId|否|String| 商品id|
|------itemCode|否|String| 商品编码|
|------itemName|否|String| 关联mitem商品 商品名称|
|------isAutoSend|否|Integer| 是否自动代发 1是， 0 否|
|------createName|否|String| 创建人|
|------createDate|否|DateTime| 创建时间|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : {
 "isInherit" : 0,
 "items" : {
 "pageIndex" : 0,
 "pageSize" : 0,
 "pageCount" : 0,
 "totalCount" : 0,
 "first" : true,
 "last" : true,
 "content" : [{
 "itemId" : "String",
 "itemCode" : "String",
 "itemName" : "String",
 "isAutoSend" : 0,
 "createName" : "String",
 "createDate" : "DateTime"
 }]
 }
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
