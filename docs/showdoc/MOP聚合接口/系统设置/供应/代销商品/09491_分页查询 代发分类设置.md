# 分页查询 代发分类设置

**请求URL：** 
- `/config/supplier/item/comp/category/list`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 商户ID|
|type|是|Integer| 类型 0-零售|
|sword|否|String| 搜索关键字|
|supplyingType|否|Integer| 代发类型：0 代发，1寄售|
|pageIndex|否|Integer||
|pageSize|否|Integer||
|orderField|否|String||
|orderSort|否|String||

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "type" : 0,
 "sword" : "String",
 "supplyingType" : 0,
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--isInherit|否|Integer| 是否继承品牌，取值：0 - 否， 1 - 是|
|--items|否|Object| 模板集合数据|
|----pageIndex|否|Integer||
|----pageSize|否|Integer||
|----pageCount|否|Integer||
|----totalCount|否|Long||
|----first|否|Boolean||
|----last|否|Boolean||
|----content|否|List||
|------id|否|Long| id|
|------categoryType|否|Integer| 1：品牌,2：系列 3：类别|
|------categoryTypeName|否|String| 1：品牌,2：系列 3：类别|
|------categoryId|否|String| 通用指定id 可以是品牌,系列或类别|
|------categoryCode|否|String| 通用指定编码 可以是品牌,系列或类别|
|------categoryName|否|String| 通用指定名称 可以是品牌,系列或类别|
|------isAutoSend|否|Integer| 是否自动代发 1是， 0 否|
|------supplyingType|否|Integer| 代发类型：0 代发，1寄售|
|------proxy|否|Integer| 代发方 0供应商,1品牌商|
|------proxyName|否|String| 代发方|
|------createName|否|String| 创建人|
|------createDate|否|DateTime| 创建时间|
|------companyCode|否|String| 门店编码|
|------companyName|否|String| 门店名称|
|------proxyCompCode|否|String| 代发方门店|
|------proxyCompName|否|String| 代发方门店|
|------settlementRate|否|Double| 结算比例|
|------supCode|否|String| 供应商code|
|------supName|否|String| 供应商Name|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
