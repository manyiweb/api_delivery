# 查询

**请求URL：** 
- `/config/proxyWhsSet/query`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 商户ID或品牌ID|

### 请求参数Json格式
 
```
{
 "companyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--isInherit|否|Integer| 是否继承|
|--whsId|否|String| 仓库id|
|--whsName|否|String| 仓库|
|--openAutoReceiptRefund|否|Boolean| 订货退货自动收货退款|
|--openDistributorSettlement|否|Boolean| 启用经销商线上结算|
|--openOnlineBankPay|否|Integer| 是否开启网银支付|
|--onlinePayConfig|否|String| 网银支付参数|
|--defaultPayType|否|Integer| 默认支付方式|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : {
 "isInherit" : 0,
 "whsId" : "String",
 "whsName" : "String",
 "openAutoReceiptRefund" : true,
 "openDistributorSettlement" : true,
 "openOnlineBankPay" : 0,
 "onlinePayConfig" : "String",
 "defaultPayType" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
