# 保存 代发总部仓库设置

**请求URL：** 
- `/config/proxyWhsSet/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 商户ID或品牌ID|
|whsId|是|String| 仓库id|
|whsName|是|String| 仓库|
|openDistributorSettlement|否|Boolean| 开启经销商线上先算|
|openAutoReceiptRefund|否|Boolean| 订货退货自动收货退款|
|openOnlineBankPay|否|Integer| 是否开启网银支付|
|onlinePayConfig|否|String| 网银银行支付参数|
|defaultPayType|否|Integer| 默认类型0线下支付 银联支付参数|

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "whsId" : "String",
 "whsName" : "String",
 "openDistributorSettlement" : true,
 "openAutoReceiptRefund" : true,
 "openOnlineBankPay" : 0,
 "onlinePayConfig" : "String",
 "defaultPayType" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
