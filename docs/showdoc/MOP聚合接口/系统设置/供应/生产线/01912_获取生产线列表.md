# 获取生产线列表
 

**请求URL：** 
- `/product/productionLine/list `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|status|否|Integer| 活跃状态 1 - 活跃, 0 - 不活跃|
|companyId|是|String| 商户id|
|sword|否|String||
|tokenId|否|String||
|id|否|String||
|pageIndex|否|Integer| 页号|
|pageSize|否|Integer| 页大小|

###请求参数Json格式
 
```
{
 "status" : 0,
 "companyId" : "String",
 "sword" : "String",
 "tokenId" : "String",
 "id" : "String",
 "pageIndex" : 0,
 "pageSize" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--inherit|否|Integer| 是否继承|
|--productions|否|Object| 生产线|
|----pageIndex|否|Integer| 页码|
|----pageSize|否|Integer| 显示记录数|
|----pageCount|否|Integer| 总页数|
|----totalCount|否|Long| 总记录数|
|----first|否|Boolean| 首页|
|----last|否|Boolean| 尾页|
|----content|否|List| 分页数据|
|------id|否|Long||
|------code|否|String| 生产线编码|
|------name|否|String| 生产线名称|
|------status|否|Integer| 活跃状态 1 - 活跃, 0 - 不活跃|
|------isDefault|否|Integer| 是否默认 1 - 是,0 - 否|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : {
 "inherit" : 0,
 "productions" : {
 "pageIndex" : 0,
 "pageSize" : 0,
 "pageCount" : 0,
 "totalCount" : 0,
 "first" : true,
 "last" : true,
 "content" : [{
 "id" : 0,
 "code" : "String",
 "name" : "String",
 "status" : 0
 }]
 }
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
