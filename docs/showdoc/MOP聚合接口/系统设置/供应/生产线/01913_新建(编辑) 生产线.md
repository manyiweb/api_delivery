# 新建(编辑) 生产线
 

**请求URL：** 
- `/product/productionLine/add `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long||
|code|是|String| 生产线编码|
|name|是|String| 生产线名称|
|companyId|是|String| 商户id|
|status|否|Integer| 活跃状态 1 - 活跃, 0 - 不活跃|
|isDefault|否|Integer| 是否默认 1 - 是,0 - 否|

###请求参数Json格式
 
```
{
 "id" : 0,
 "code" : "String",
 "name" : "String",
 "status" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long| id|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : {
 "id" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
