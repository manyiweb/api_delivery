# 保存设置

**请求URL：** 
- `/config/codingRule/itemCode/save `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long||
|type|否|Integer| 编码前缀类型 0按固定前缀，1按分类编码前缀|
|typeStartSerialNumber|否|String| 分类编码起始流水号|
|typeLevel|否|Integer| 分类编码级别 1一级，2二级，3三级|
|fixedPrefix|否|String| 固定前缀|
|startSerialNumber|否|String| 起始流水号|
|companyId|否|String| 门店商户ID|

###请求参数Json格式
 
```
{
 "id" : 0,
 "type" : 0,
 "typeStartSerialNumber" : "String",
 "typeLevel" : 0,
 "fixedPrefix" : "String",
 "startSerialNumber" : "String",
 "companyId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
