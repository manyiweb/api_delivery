# 保存设置

**请求URL：** 
- `/config/codingRule/company/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||
|isSystemAuto|否|Integer| 启用系统自动生成编码 0否1是|
|fixedPrefix|否|String| 固定前缀|
|startSerialNumber|否|String| 起始流水号|
|companyId|是|String| 门店商户ID|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "isSystemAuto" : 0,
 "fixedPrefix" : "String",
 "startSerialNumber" : "String",
 "companyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
