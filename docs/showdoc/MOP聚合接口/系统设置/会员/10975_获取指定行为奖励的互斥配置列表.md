# 获取指定行为奖励的互斥配置列表



 根据行为奖励ID查询其互斥配置，返回互斥的行为奖励编码和名称列表。
 前端在编辑行为奖励时，可通过此接口按需加载互斥配置，避免影响列表接口性能。
 </p>
 

**请求URL：** 
- `/config/actionAward/mutex/list`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|fid|否|String|行为奖励id|


### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--mutexBehavirCode|否|String| 互斥的行为奖励编码（对应 BaseConstantList.DActionAward 枚举的 name()）

示例：FocusGive、Birthday、BrandMemberDay</p>|
|--mutexBehavirName|否|String| 互斥的行为奖励名称（对应 BaseConstantList.DActionAward 枚举的 getCname()）

示例：首次关注、会员生日消费、品牌会员日</p>|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "mutexBehavirCode" : "String",
 "mutexBehavirName" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
