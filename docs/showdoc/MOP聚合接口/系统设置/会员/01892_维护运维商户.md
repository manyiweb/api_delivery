# 维护运维商户
 

**请求URL：** 
- `/hr/staff/editOperate `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|userId|是|String| 用户Id|
|operateJson|是|List| 运营商户|
|--companyId|是|String| 门店|
|--status|是|String| 状态|


###请求参数Json格式
 
```
{
 "userId" : "String",
 "authenJson" : [{
 "companyId" : "String",
 "status" : "String",
 "roleId" : "String"
 }],
 "operateJson" : [{
 "companyId" : "String",
 "status" : "String",
 "roleId" : "String"
 }]
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
