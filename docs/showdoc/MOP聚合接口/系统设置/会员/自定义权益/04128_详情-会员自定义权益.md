# 详情-会员自定义权益

**请求URL：** 
- `/mem/custom/benefit/detail `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|

###请求参数Json格式
 
```
{
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long| id|
|--code|否|String| 权益编码|
|--name|否|String| 权益名称|
|--status|否|Boolean| 活跃状态|
|--statusName|否|String| 活跃状态名称|
|--iconUrl|否|String| 权益图标url|
|--description|否|String| 权益简介|
|--createId|否|String| 创建人标识|
|--createName|否|String| 创建人|
|--createDate|否|DateTime| 创建时间|
|--memberGrades|否|List| 关联会员等级列表|
|----memberGradeId|否|String| 会员等级id|
|----memberGradeCode|否|String| 会员等级编码|
|----memberGradeName|否|String| 会员等级名称|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "code" : "String",
 "name" : "String",
 "status" : true,
 "statusName" : "String",
 "iconUrl" : "String",
 "description" : "String",
 "createId" : "String",
 "createName" : "String",
 "createDate" : "DateTime",
 "memberGrades" : [{
 "memberGradeId" : "String",
 "memberGradeCode" : "String",
 "memberGradeName" : "String"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
