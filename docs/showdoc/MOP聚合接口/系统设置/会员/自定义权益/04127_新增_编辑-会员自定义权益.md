# 新增/编辑-会员自定义权益

**请求URL：** 
- `/mem/custom/benefit/edit `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|
|name|否|String| 权益名称|
|status|否|Boolean| 活跃状态|
|iconUrl|否|String| 权益图标url|
|description|否|String| 权益简介|
|memberGradeIds|否|List| 关联会员等级列表|

###请求参数Json格式
 
```
{
 "id" : 0,
 "name" : "String",
 "status" : true,
 "iconUrl" : "String",
 "description" : "String",
 "memberGradeIds" : null
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long| id|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : {
 "id" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
