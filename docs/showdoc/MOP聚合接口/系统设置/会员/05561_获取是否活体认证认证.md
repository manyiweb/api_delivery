#

获取是否认证

**请求URL：** 
- `/app/livingThingAuth/getAuthByMember `

**请求方式：**
- undefined
- FormData


###请求参数<业务参数>
 
无参数


###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Boolean| 是否认证|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : true,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
