# 维护会员设置
 

**请求URL：** 
- `/config/smemberset/set `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|memberSettlementIntegralSet|否|String| 用户Id|
|--retailIntegralSettlementSet|否|int| 零售会员积分结算开关|
|--unMemberConsumptionChannelIntegralAscriptionCompanyId|否|String| 非消费渠道积分归属商户id|
|--enableEnterpriseAutoCredit|否|Boolean| 是否启用企业会员授信申请自动审核|


###请求参数Json格式
 
```
{
	"tokenId": "c4138aaf26664c0691dd39f5da617b30",
	"memberSettlementIntegralSet": {
		"retailIntegralSettlementSet": 0,
		"unMemberConsumptionChannelIntegralAscriptionCompanyId": "51a26034fb444eb1a6af740b0be362e1"
	}
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|ResultInt|否|Object| 错误码|
|ResultString|否|String| 错误消息|
|ErrorCode|否|String| 业务代码|

###返回参数Json格式
 
```
{
 "ErrorCode": "",
 "ResultString": "success",
 "ResultInt": 0
}
```
