# 获取会员设置
 

**请求URL：** 
- `/config/smemberset/get `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>



###请求参数Json格式
 
```
{
	"tokenId": "c4138aaf26664c0691dd39f5da617b30"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|参数|类型|描述|
|:-------|:-------|:-------|
| memberSetting |object | 无 |
|--enableEnterpriseAutoCredit | boolean| 是否启用企业会员授信申请自动审核 - 企业会员 |
|memberSettlementIntegralSet|否|String| 用户Id|
|--retailIntegralSettlementSet|否|int| 零售会员积分结算开关|
|--unMemberConsumptionChannelIntegralAscriptionCompanyId|否|String| 非消费渠道积分归属商户id|
|--unMemberConsumptionChannelIntegralAscriptionCompanyName|否|String| 非消费渠道积分归属商户名称|
|--unMemberConsumptionChannelIntegralAscriptionCompanyId|否|String| 非消费渠道积分归属商户编码|
|ResultInt|否|Object| 错误码|
|ResultString|否|String| 错误消息|
|ErrorCode|否|String| 业务代码|
