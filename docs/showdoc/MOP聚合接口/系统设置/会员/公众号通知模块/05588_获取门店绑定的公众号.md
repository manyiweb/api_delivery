# 获取门店绑定的公众号
 

**请求URL：** 
- `/config/memberWxNotice/get `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|String| 门店id|

###请求参数Json格式
 
```
{
 "id" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Integer||
|--wxSn|否|String| wxSn|
|--wxName|否|String| 公众号名称|
|--companyId|否|String| 门店id|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "wxSn" : "String",
 "wxName" : "String",
 "companyId" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
