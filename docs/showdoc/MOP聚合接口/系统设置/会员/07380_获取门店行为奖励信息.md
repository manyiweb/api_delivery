# 获取门店行为奖励信息
 

**请求URL：** 
- `/config/actionAward/single/company`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String|门店id|
|behavirCode|否|String|行为奖励code|
