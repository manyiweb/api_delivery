#

活体认证接口

**请求URL：** 
- `/app/livingThingAuth/auth `

**请求方式：**
- undefined
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|imageId|是|String| 视频id|
|openId|是|String| 会员openId|
|identityCard|是|String| 身份证|
|identityCardName|是|String| 身份证名称|

###请求参数Json格式
 
```
{
 "imageId" : "String",
 "openId" : "String",
 "identityCard" : "String",
 "identityCardName" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Boolean| 是否认证成功|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : true,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
