# 积分设置 分账比例 修改/新增

**请求URL：** 
- `/config/mem/integralSeparateAccountsSet/mergeSet `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|否|String||
|companyId|否|String| 门店id|
|id|否|Long||
|separateAccountsDay|否|Integer| 积分到账天数|
|levelCode|否|String| 会员等级编码|
|levelName|否|String| 会员等级名称|
|isOpenSeparateAccounts|否|Integer| 是否启用积分分账比例设置|
|spokesmanSysstaffId|否|String| 代言人默认分帐方|
|spokesmanSysstaffName|否|String| 代言人默认分帐方 名称|
|spokesmanSysstaffCode|否|String| 代言人默认分帐方 手机号码|
|exclusiveSysstaffId|否|String| 专属导购默认分账方|
|exclusiveSysstaffName|否|String| 专属导购默认分账方 名称|
|exclusiveSysstaffCode|否|String| 专属导购默认分账方 手机号码|
|items|否|List||
|--id|否|Long||
|--levelCode|否|String| 代言人等级|
|--levelContent|否|String| 代言人等级描述|
|--memberPercentage|否|Double| 消费会员 积分赠送百分比|
|--companyPercentage|否|Double| 专属门店 积分赠送百分比|
|--spokesmanPercentage|否|Double| 代言人 积分赠送百分比|
|--exclusivePercentage|否|Double| 专属导购 积分赠送百分比|
|--hostDistributoPercentage|否|Double| 所属经销商 积分赠送百分比|

###请求参数Json格式
 
```
{
 "tokenId" : "String",
 "companyId" : "String",
 "id" : 0,
 "separateAccountsDay" : 0,
 "levelCode" : "String",
 "levelName" : "String",
 "isOpenSeparateAccounts" : 0,
 "spokesmanSysstaffId" : "String",
 "spokesmanSysstaffName" : "String",
 "spokesmanSysstaffCode" : "String",
 "exclusiveSysstaffId" : "String",
 "exclusiveSysstaffName" : "String",
 "exclusiveSysstaffCode" : "String",
 "items" : [{
 "id" : 0,
 "levelCode" : "String",
 "levelContent" : "String",
 "memberPercentage" : 0,
 "companyPercentage" : 0,
 "spokesmanPercentage" : 0,
 "exclusivePercentage" : 0,
 "hostDistributoPercentage" : 0
 }]
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
