# 运维商户列表
 

**请求URL：** 
- `/hr/staff/operate/detail `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|sword|否|String||
|tokenId|否|String||
|id|否|String|用户id|
|pageIndex|否|Integer| 页号|
|pageSize|否|Integer| 页大小|

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--pageIndex|否|Integer| 页码|
|--pageSize|否|Integer| 显示记录数|
|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|--first|否|Boolean| 首页|
|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|
|----scId|否|String| 主键|
|----companyId|否|String| 门店Id|
|----companyCode|否|String| 门店编码|
|----companyName|否|String| 门店名称|
|----status|否|String| 状态|
|----statusName|否|String| 状态名称|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
