# 行为奖励-入账说明-保存
 

**请求URL：** 
- `/config/actionAward/saveExplain `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
{"tokenId":"5f556634d0e94e6db1ea450e4457421a", "content":"2222"}


###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String"
}
```
