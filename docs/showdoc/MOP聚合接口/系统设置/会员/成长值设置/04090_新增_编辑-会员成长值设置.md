# 新增/编辑-会员成长值设置表

**请求URL：** 
- `/mem/growthValue/setting/edit`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|isInherit|是|Boolean| 是否继承品牌|
|amountValue|是|Double| 消费金额|
|growthValue|是|Double| 成长值|
|roundingMode|是|Integer| 成长值取值|
|specifiedMode|是|Integer| 指定成长值设置|
|addItems|否|List| 成长值设置-指定商品更新列表|
|--id|否|Long| ID|
|--specId|是|String| 规格id|
|--salePrice|是|Double| 零售价|
|--growthValue|是|Double| 获取成长值|
|--beginDate|是|DateTime| 开始时间|
|--endDate|是|DateTime| 结束时间|
|--calculationMethod|是|Integer| 计算方式编码:0-固定值;1-倍数|
|deleteItemIds|否|List| 成长值设置-指定商品删除标识列表|
|addTypes|否|List| 成长值设置-指定分类更新列表|
|--id|否|Long| id|
|--amountValue|是|Double| 消费金额|
|--growthValue|是|Double| 成长值|
|--type|是|Integer| 类型（类别 0/品牌 1/系列 2）|
|--typeId|是|String| 类型/品牌/系列标识|
|deleteTypeIds|否|List| 成长值设置-指定分类删除标识列表|
|superNotGiveGrowth|否|Boolean| 企业会员不参与成长值赠送| true为不赠送
|isInherit|否|Boolean| 继承品牌设置|
|companyId|是|String| 门店标识|
|isSetByMemberGrade|否|Boolean| 按会员等级设置|
|gradeId|否|String| 会员等级标识|
