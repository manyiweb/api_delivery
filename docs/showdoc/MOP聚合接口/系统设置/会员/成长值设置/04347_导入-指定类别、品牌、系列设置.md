# 导入-指定类别、品牌、系列设置

**请求URL：** 
- `/file/member/growth/value/setting/type/import `

**请求方式：**
- POST
- FormData


###请求参数<业务参数>
 
无参数


###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--dataSource|否|List||
|----name|否|String| 类型|
|----fullTypeCode|否|String| 类型编码|
|----amountValue|否|Double| 消费金额每满|
|----growthValue|否|Double| 成长值|
|----type|否|Integer| 类型（类别 0/品牌 1/系列 2）|
|----typeId|否|String| 类型/品牌/系列标识|
|----status|否|Boolean| 状态|
|----statusName|否|String| 状态|
|----msg|否|String| 错误信息|
|--downloadURL|否|String| 错误数据下载地址|
|--totalCount|否|Long| 总数|
|--successCount|否|Long| 成功数|
|--errorCount|否|Long| 错误数|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : {
 "dataSource" : [{
 "name" : "String",
 "fullTypeCode" : "String",
 "amountValue" : 0,
 "growthValue" : 0,
 "type" : 0,
 "typeId" : "String",
 "status" : true,
 "statusName" : "String",
 "msg" : "String"
 }],
 "downloadURL" : "String",
 "totalCount" : 0,
 "successCount" : 0,
 "errorCount" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
