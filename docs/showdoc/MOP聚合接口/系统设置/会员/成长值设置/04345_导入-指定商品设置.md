# 导入-指定商品设置

**请求URL：** 
- `/file/member/growth/value/setting/item/import `

**请求方式：**
- POST
- FormData

###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 门店id|
|file|是|Multipart| 导入文件|

###请求参数Json格式
 
```
{
 "companyId" : "String",
 "file" : (binary)
}
```


###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--dataSource|否|List||
|----isSetByMemberGrade|否|Boolean| 是否按会员等级设置|
|----calculationMethod|否|Integer| 计算方式：0-固定成长值/1-按倍数|
|----specId|否|String| 规格id|
|----itemCode|否|String| 商品编码|
|----skuBarcode|否|String| SKU码|
|----calculationMethodName|否|String| 计算方式：固定成长值/按倍数|
|----growthValue|否|Double| 成长值|
|----beginDate|否|DateTime| 开始日期|
|----endDate|否|DateTime| 结束日期|
|----status|否|Boolean| 状态|
|----statusName|否|String| 状态|
|----msg|否|String| 错误信息|
|--downloadURL|否|String| 错误数据下载地址|
|--totalCount|否|Long| 总数|
|--successCount|否|Long| 成功数|
|--errorCount|否|Long| 错误数|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{

 "dataSource" : [{
 "isSetByMemberGrade" : true,
 "calculationMethod" : 0,
 "specId" : "String",
 "itemCode" : "String",

 "calculationMethodName" : "String",
 "growthValue" : 0,
 "beginDate" : "DateTime",
 "endDate" : "DateTime",
 "status" : true,
 "statusName" : "String",
 "msg" : "String"
 }],
 "downloadURL" : "String",
 "totalCount" : 0,
 "successCount" : 0,
 "errorCount" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
