# 详情-会员成长值设置

**请求URL：** 
- `/mem/growthValue/setting/detail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|isInherit|否|Boolean| 继承品牌设置|
|companyId|是|String| 门店标识|
|isSetByMemberGrade|否|Boolean| 按会员等级设置|
|gradeId|否|String| 会员等级标识|

### 请求参数Json格式
 
```
{
 "isInherit" : true,
 "companyId" : "String",
 "isSetByMemberGrade" : true,
 "gradeId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long| 主键ID|
|--isSetByMemberGrade|否|Boolean| 按会员等级设置|
|--gradeId|否|String| 会员等级标识|
|--gradeCode|否|String| 会员等级编码|
|--gradeName|否|String| 会员等级名称|
|--amountValue|否|Double| 消费金额|
|--growthValue|否|Double| 成长值|
|--roundingMode|否|Integer| 成长值取值|
|--roundingModeName|否|String| 成长值取值名称|
|--specifiedMode|否|Integer| 指定成长值设置|
|--specifiedModeName|否|String| 指定成长值设置名称|
|--superNotGiveGrowth|否|Boolean| 企业会员不参与成长值赠送|
|--isInherit|否|Boolean| 继承品牌设置|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "isSetByMemberGrade" : true,
 "gradeId" : "String",
 "gradeCode" : "String",
 "gradeName" : "String",
 "amountValue" : 0,
 "growthValue" : 0,
 "roundingMode" : 0,
 "roundingModeName" : "String",
 "specifiedMode" : 0,
 "specifiedModeName" : "String",
 "superNotGiveGrowth" : true,
 "isInherit" : true
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
