# 积分设置 分账比例 详情

**请求URL：** 
- `/config/mem/integralSeparateAccountsSet/getSetInfo `

**请求方式：**
- POST
- FormData


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|levelCode|否|String||
|companyId|否|String||

###请求参数Json格式
 
```
{
 "levelCode" : "String",
 "companyId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--set|否|Object||
|----id|否|Long||
|----levelCode|否|String| 会员等级编码（会员等级升级奖励）|
|----isOpenSeparateAccounts|否|Integer| 是否启用积分分账比例设置|
|----spokesmanSysstaffId|否|String| 代言人默认分帐方|
|----spokesmanSysstaffName|否|String| 代言人默认分帐方 名称|
|----exclusiveSysstaffId|否|String| 专属导购默认分账方|
|----exclusiveSysstaffName|否|String| 专属导购默认分账方 名称|
|----modifyId|否|String| 修改人id|
|----modifyName|否|String| 修改人|
|----modifyDate|否|DateTime| 修改时间|
|----createId|否|String| 创建人id|
|----createName|否|String| 创建人|
|----createDate|否|DateTime| 创建时间|
|----companyId|否|String| 门店商户ID，与商户表syscompany相关联|
|----dbKey|否|Integer| 分库标识|
|----groupId|否|String| 品牌商id|
|--setItem|否|List||
|----id|否|Long||
|----companyId|否|String| 门店商户ID，与商户表syscompany相关联|
|----levelCode|否|String| 会员等级编码（会员等级升级奖励）|
|----memberPercentage|否|Double| 消费会员 积分赠送百分比|
|----companyPercentage|否|Double| 专属门店 积分赠送百分比|
|----spokesmanPercentage|否|Double| 代言人 积分赠送百分比|
|----exclusivePercentage|否|Double| 专属导购 积分赠送百分比|
|----hostDistributoPercentage|否|Double| 所属经销商 积分赠送百分比|
|----modifyId|否|String| 修改人id|
|----modifyName|否|String| 修改人|
|----modifyDate|否|DateTime| 修改时间|
|----createId|否|String| 创建人id|
|----createName|否|String| 创建人|
|----createDate|否|DateTime| 创建时间|
|----dbKey|否|Integer| 分库标识|
|----groupId|否|String| 品牌商id|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
