# 详情-成长值有效期设置

**请求URL：** 
- `/mem/growthValue/period/setting/detail `

**请求方式：**
- POST
- FormData


###请求参数<业务参数>
 
无参数


###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long| id|
|--status|否|Boolean| 是否启用会员成长值有效期|
|--mode|否|Integer| 有效期模式(0-指定失效日;1-固定时长;2-指定会员等级有效期)|
|--name|否|String| 有效期模式(0-指定失效日;1-固定时长;2-指定会员等级有效期)|
|--year|否|Integer| 指定失效日-年|
|--month|否|Integer| 指定失效日-月|
|--day|否|Integer| 指定失效日-日|
|--fixedMonths|否|Integer| 固定时长-月|
|--gradeSettings|否|Object| 列表-指定会员等级有效期|
|----gradeId|否|Integer| 会员等级id|
|----gradeCode|否|String| 会员等级编码|
|----gradeName|否|String| 会员等级名称|
|----fixedDays|否|String| 有效期(天)|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
	 "status":false,
	 "mode":0,
	 "name":"String",
	 "year":0,
	 "month":0,
	 "day":0,
	 "fixedMonths":0,
	 "gradeSettings":[
	 	{
			"gradeId:"String",
			"gradeCode:"String",
			"gradeName:"String",
			"fixedDays:0
		}
	 ]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
