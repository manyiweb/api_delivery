# 零售分账设置详情

**请求URL：** 
- `/config/retail/integralRetailProfitSplit/setSplitInfo `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|否|String||

###请求参数Json格式
 
```
{
 "tokenId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--splitType|否|Integer| 1、按当天总利润分账 2、品牌商代发分账|
|--splitProportion|否|Double| 分账总额比例%|
|--splitTime|否|String| 每天固定分账时间|
|--levelSet|否|List| 等级配置|
|----levelCode|否|String| 等级|
|----levelContent|否|String| 等级名称|
|----isActive|否|Integer| 是否启用|
|--isSet|否|Integer| 是否已经配置|
|--autoSplitDays|否|Integer| 自动分账天数|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "splitType" : 0,
 "splitProportion" : 0,
 "splitTime" : "String",
 "levelSet" : [{
 "levelCode" : "String",
 "levelContent" : "String",
 "isActive" : 0
 }],
 "isSet" : 0,
 "autoSplitDays" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
