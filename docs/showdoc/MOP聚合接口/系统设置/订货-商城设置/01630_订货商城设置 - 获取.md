# 获取订货商城设置
 

**请求URL：** 
- `/b2b/mallSet/get `

**请求方式：**
- POST
- FormData


###请求参数<业务参数>
 
无参数


###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--status|否|Integer| 启用非登录模式，1是0否|
|--defaultCompanyId|否|String| 默认门店标识|
|--defaultCompanyName|否|String| 默认门店名称|
|--openRegisterEntrance|否|Integer| 启用立即注册入口 1是0否|
|--sellOutAlias|否|String|商城售罄别名|
|--openSellOutAlias|否|Integer|是否开启自定义售罄别名|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "status" : 0,
 "defaultCompanyId" : "String",
 "defaultCompanyName" : "String",
 "openRegisterEntrance" : 0,
 "sellOutAlias" : "String",
 "openSellOutAlias" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
