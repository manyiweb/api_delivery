# 产品装修(商城通用设置)- 结果集(商城使用,支持匿名访问)
 

**请求URL：** 
- `/config/decoration/common/mall/get/result`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 商户标识|
|groupId|否|String| 品牌标识|

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "groupId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--isInherit|否|Integer| 是否继承商户 1是0否|
|--noShowPrice|否|Integer| 不显示划掉的档案零售价 1是0否|
|--showStartPage|否|Boolean| 是否显示启动页|
|--startPageUrl|否|String| 启动页地址|
|--startPageUrlFull|否|String| 启动页地址完整路径|
|--loadingImageUrl|否|String| 页面加载图地址|
|--loadingImageUrlFull|否|String| 页面加载图完整路径|
|--showMutiSpecOneImg|否|Integer| 多规格商品显示规格一缩略图 0否 1是|
|--switchAccountBackgroundImageUrl|否|String| 切换账号背景图|
|--switchAccountBackgroundImageUrlFull|否|String| 切换账号背景图全路径|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "isInherit" : 0,
 "noShowPrice" : 0,
 "showStartPage" : true,
 "startPageUrl" : "String",
 "startPageUrlFull" : "String",
 "loadingImageUrl" : "String",
 "loadingImageUrlFull" : "String",
 "showMutiSpecOneImg" : 0,
 "switchAccountBackgroundImageUrl" : "String",
 "switchAccountBackgroundImageUrlFull" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
