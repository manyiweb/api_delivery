# 产品装修（点单商城通用配置）（支持匿名访问）

**请求URL：** 
- `/config/decoration/common/mealmall/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 商户标识|
|groupId|是|String| 品牌标识|
|isCake|否|Boolean| 是否蛋糕预定|

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "groupId" : "String",
 "isCake" : true
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--notShowArchPrice|否|Integer| 是否启用显示划线价格(0不启用 1启用)|
|--shareTitle|否|String| 分享语|
|--shareUrl|否|String| 小程序分享图|
|--shareUrlFull|否|String| 小程序分享图完整路径|
|--takeOutAlias|否|String| 外卖别名|
|--selfTakeAlias|否|String| 预约自取别名|
|--expressAlias|否|String| 快递别名|
|--ifShowMealWay|否|Boolean| 是否展示取餐类型|
|--scanCodeOrder|否|Boolean| 启用扫码点单|
|--scanCodeUrl|否|String| 扫码点单封面图|
|--showStartPage|否|Boolean| 是否显示启动页|
|--startPageUrl|否|String| 启动页地址|
|--startPageUrlFull|否|String| 启动页地址完整路径|
|--loadingImageUrl|否|String| 页面加载图地址|
|--loadingImageUrlFull|否|String| 页面加载图完整路径|
|--noShowPrice|否|Integer| 不显示划掉的档案零售价 1是0否|
|--star|否|Integer| 门店是否收藏|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式

```
 "shareUrl" : "String",
 "shareUrlFull" : "String",

 "expressAlias" : "String",
 "ifShowMealWay" : true,
 "scanCodeOrder" : true,
 "scanCodeUrl" : "String",
 "showStartPage" : true,
 "startPageUrl" : "String",
 "startPageUrlFull" : "String",
 "loadingImageUrl" : "String",
 "loadingImageUrlFull" : "String",
 "noShowPrice" : 0,
 "star" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
