# 获取点餐商城通用配置

**请求URL：** 
- `/config/mealMall/common/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 门店id|

### 请求参数Json格式
 
```
{
 "companyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--notShowArchPrice|否|Integer| 是否启用显示划线价格(0不启用 1启用)|
|--isInherit|否|Integer| 是否继承商户 1是0否|
|--shareTitle|否|String| 小程序分享语|
|--shareUrl|否|String| 小程序分享图|
|--shareUrlFull|否|String| 小程序分享图完整路径|
|--showStartPage|否|Boolean| 是否显示启动页|
|--startPageUrl|否|String| 启动页地址|
|--startPageUrlFull|否|String| 启动页地址完整路径|
|--loadingImageUrl|否|String| 页面加载图地址|
|--loadingImageUrlFull|否|String| 页面加载图完整路径|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : {
 "notShowArchPrice" : 0,
 "isInherit" : 0,
 "shareTitle" : "String",
 "shareUrl" : "String",
 "shareUrlFull" : "String",
 "showStartPage" : true,
 "startPageUrl" : "String",
 "startPageUrlFull" : "String",
 "loadingImageUrl" : "String",
 "loadingImageUrlFull" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
