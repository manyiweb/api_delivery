# 产品装修启动页
 

**请求URL：** 
- `/config/decoration/common/mall/getStartPageUrlMealMallResult `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|groupId|否|String| 品牌标识|

###请求参数Json格式
 
```
{
 "groupId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--notShowArchPrice|否|Integer| 是否启用显示划线价格(0不启用 1启用)|
|--shareTitle|否|String| 分享语|
|--shareUrl|否|String| 小程序分享图|
|--shareUrlFull|否|String| 小程序分享图完整路径|
|--takeOutAlias|否|String| 外卖别名|
|--selfTakeAlias|否|String| 预约自取别名|
|--ifShowMealWay|否|Boolean| 是否展示取餐类型|
|--scanCodeOrder|否|Boolean| 启用扫码点餐|
|--scanCodeUrl|否|String| 扫码点餐封面图|
|--showStartPage|否|Boolean| 是否显示启动页|
|--startPageUrl|否|String| 启动页地址|
|--startPageUrlFull|否|String| 启动页地址完整路径|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "notShowArchPrice" : 0,
 "shareTitle" : "String",
 "shareUrl" : "String",
 "shareUrlFull" : "String",
 "takeOutAlias" : "String",
 "selfTakeAlias" : "String",
 "ifShowMealWay" : true,
 "scanCodeOrder" : true,
 "scanCodeUrl" : "String",
 "showStartPage" : true,
 "startPageUrl" : "String",
 "startPageUrlFull" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
