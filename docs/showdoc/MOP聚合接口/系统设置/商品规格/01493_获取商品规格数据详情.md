# 获取商品规格数据详情
 

**请求URL：** 
- `/config/mitemSpecTypeData/detail `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long| id|

###请求参数Json格式
 
```
{
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long| id|
|--specCode|否|String| 规格编号|
|--specName|否|String| 规格名称|
|--specType|否|String| 规格类型|
|--specTypeId|否|String|规格类型id|
|--status|否|Integer| 活跃状态 0 - 停用,1 - 启用|
|--createName|否|String| 创建人|
|--createDate|否|DateTime| 创建时间|
|msg|否|String| 消息|
|code|否|String| 业务代码|


###返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "specCode" : "String",
 "specName" : "String",
 "specType" : "String",
 "status" : 0,
 "createName" : "String",
 "createDate" : "DateTime"
 },
 "msg" : "String",
 "code" : "String"
}
```
