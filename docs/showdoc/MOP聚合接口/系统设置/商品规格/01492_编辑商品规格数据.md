# 编辑商品规格数据
 

**请求URL：** 
- `/config/mitemSpecTypeData/modify `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|
|specCode|是|String| 规格编号|
|specName|是|String| 规格名称|
|specTypeId|是|String| 规格类型id|
|status|是|Integer| 活跃状态 0 - 停用,1 - 启用|

###请求参数Json格式
 
```
{
 "id" : 0,
 "specCode" : "String",
 "specName" : "String",
 "specTypeId" : "String",
 "status" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String"
}
```
