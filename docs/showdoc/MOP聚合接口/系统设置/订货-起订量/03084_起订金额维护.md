# 起订金额维护

**请求URL：** 
- `/config/b2b/moa/action/save `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|groupId|否|String| 品牌id|
|companyId|否|String| companyId|
|eXTVALUE|否|Integer| 是否继承品牌设置|
|eXTVALUE2|否|Integer| 启用订单起订金额|
|eXTVALUE3|否|Double| 订单起订金额|
|eXTVALUE6|否|Double| 启用每天满足一次就不限制（0不开启 1开启）|
|addSpecIds|否|List| 新增排除商品|
|delSpecIds|否|List| 删除排除商品|

###请求参数Json格式
 
```
{
 "groupId" : "String",
 "companyId" : "String",
 "eXTVALUE" : 0,
 "eXTVALUE2" : 0,
 "eXTVALUE3" : 0,
 "addSpecIds" : null,
 "delSpecIds" : null
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
