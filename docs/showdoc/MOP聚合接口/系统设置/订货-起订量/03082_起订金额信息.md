# 起订金额信息

**请求URL：** 
- `/config/b2b/moa/action/get `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 商户标识|
|tokenId|否|String||

###请求参数Json格式
 
```
{
 "companyId" : "String",
 "tokenId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--eXTVALUE|否|Integer| 是否继承品牌设置|
|--eXTVALUE2|否|Integer| 启用订单起订金额|
|--eXTVALUE3|否|Double| 订单起订金额|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : {
 "eXTVALUE" : 0,
 "eXTVALUE2" : 0,
 "eXTVALUE3" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
