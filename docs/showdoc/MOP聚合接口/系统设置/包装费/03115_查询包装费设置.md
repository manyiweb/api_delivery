# 功能描述: 查询包装费设置（商品支持关键字搜索和分页）
 

**请求URL：** 
- `/config/packingCharge/list`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|String||
|orderField|否|String||
|orderSort|否|String||
|tokenId|否|String||
|pageIndex|是|Integer||
|pageSize|是|Integer||
|sword|否|String||

### 请求参数Json格式
 
```
{
 "id" : "String",
 "orderField" : "String",
 "orderSort" : "String",
 "tokenId" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "sword" : "String"
}
```

### 返回参数

|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long| 主键标识|

|--packingChargeLadders|否|List| 阶梯|
|----quantity|否|Double| 数量|
|----amount|否|Double| 金额|
|--packingChargeItems|否|List| 包装费商品列表|
|----id|否|Long||
|----packingChargeId|否|Long||
|----specId|否|String||
|----skuBarcode|否|String||
|----itemId|否|String||
|----itemCode|否|String||
|----itemName|否|String||
|----fee|否|Double||
|----enaleLadder|否|Boolean||

|----createName|否|String||

|----packingChargeLadders|否|List||
|------id|否|Long||
|------packingChargeItemId|否|Long||
|------quantity|否|Double||
|------amount|否|Double||
|------dbKey|否|Integer||
|------groupId|否|String||
|----dbKey|否|Integer||
|----groupId|否|String||
|--packingChargeCategorys|否|List| 包装费应用类别品牌系列列表|
|----id|否|Long||
|----packingChargeId|否|Long||
|----fee|否|Double||
|----enableLadder|否|Boolean||
|----categoryType|否|Integer||
|----categoryId|否|String||
|----categoryCode|否|String||

|------id|否|Long||

|----createId|否|String||

|----modifyId|否|String||
|----modifyName|否|String||

|----dbKey|否|Integer||
|----groupId|否|String||
|--pageIndex|否|Integer| 页码|
|--pageSize|否|Integer| 显示记录数|
|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|--first|否|Boolean| 首页|

|msg|否|String||

|exceptionStackInfo|否|String||
