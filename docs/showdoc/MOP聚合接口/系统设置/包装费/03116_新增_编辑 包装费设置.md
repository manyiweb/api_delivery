# 功能描述: 新增/编辑 包装费设置
 

**请求URL：** 
- `/config/packingCharge/edit`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long||
|status|否|Integer||
|isInherit|否|Integer||
|companyId|是|String||
|addSpecIds|否|List| 商品列表|
|--specId|是|String| 规格id|
|--fee|否|String| 包装费|
|--enableLadder|否|Boolean| 是否启用阶梯|
|--packingChargeLadders|否|List| 阶梯列表|
|----quantity|否|Double| 数量|
|----amount|否|Double| 金额|
|delSpecIds|否|List||
|delCategoryIds|否|List| 要删除的类别品牌系列id|
|packingChargeCategorys|否|List| 分类列表|
|--id|否|Long| 主键标识|
|--fee|否|Double| 费用|
|--enableLadder|否|Boolean| 是否启用阶梯|
|--categoryType|否|Integer| 类别类型，1：品牌，2：系列 3：类别|
|--categoryId|否|String| 通用指定id 可以是品牌，系列或类别|
|--categoryCode|否|String| 编码|
|--categoryName|否|String| 名称|
|--packingChargeLadders|否|List| 阶梯列表|
|----quantity|否|Double| 数量|
|----amount|否|Double| 金额|
|itemType|否|Integer| 应用商品类型 0按商品 1按类别品牌系列|
|enabledGeneralLadder|否|Boolean| 是否启用总阶梯|
|packingChargeLadders|否|List| 阶梯|
|--quantity|否|Double| 数量|
|--amount|否|Double| 金额|
