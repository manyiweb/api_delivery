# 会员权益卡详情
 

**请求URL：** 
- `/config/memberEntitlementCard/detail `

**请求方式：**
- ALL
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long||

###请求参数Json格式
 
```
{
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--cardName|否|String| 权益卡名称|
|--cardNo|否|String| 权益卡名称|
|--expireDay|否|Integer| 有效天数|
|--status|否|Boolean| 活跃状态 false停用 true启用|
|--cardPicUrl|否|String| 权益卡封面图|
|--cardDescription|否|String| 权益说明|
|--buyDescription|否|String| 购买说明|
|--effectiveWay|否|Integer| 生效方式 0：购买后生效、1：指定生效日|
|--effectiveDate|否|DateTime| 生效日期|
|--enableConsumeLimit|否|Boolean| 是否启用消费限制|
|--consumeLimitType|否|Integer| 限制类型 0：按天、1：按月、2：按年|
|--consumeLimit|否|Double| 消费限制|
|--createId|否|String||
|--createName|否|String| 创建人|
|--createDate|否|DateTime| 创建时间|
|--modifyName|否|String| 修改人|
|--modifyDate|否|DateTime| 修改时间|
|--sale|否|Boolean| 是否已经售卖|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|

 "effectiveDate" : "DateTime",

 "consumeLimit" : 0,

 "createName" : "String",
 "createDate" : "DateTime",
 "modifyName" : "String",
 "modifyDate" : "DateTime",
 "sale" : true
 },

 "traceId" : "String"
}
