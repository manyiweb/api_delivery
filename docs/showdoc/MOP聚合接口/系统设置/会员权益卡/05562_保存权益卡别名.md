# 保存权益卡别名

**请求URL：** 
- `/config/equityAlias/save `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long||
|openShoppingCardAlias|否|Integer| 启用购物卡别名|
|openServiceCardAlias|否|Integer| 启用服务卡别名|
|shoppingCardAlias|否|String| 购物卡别名|
|serviceCardAlias|否|String| 服务卡别名|

###请求参数Json格式
 
```
{
 "id" : 0,
 "openShoppingCardAlias" : 0,
 "openServiceCardAlias" : 0,
 "shoppingCardAlias" : "String",
 "serviceCardAlias" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Integer| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : 0,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
