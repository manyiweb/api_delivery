# 编辑会员权益卡
 

**请求URL：** 
- `/config/memberEntitlementCard/edit `

**请求方式：**
- ALL
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 权益卡名称|
|cardName|否|String| 权益卡名称|
|expireDay|否|Integer| 有效天数|
|status|否|Boolean| 活跃状态 false停用 true启用|
|cardPicUrl|否|String| 权益卡封面图|
|cardDescription|否|String| 权益说明|
|buyDescription|否|String| 购买说明|
|effectiveWay|否|Integer| 生效方式 0：购买后生效、1：指定生效日|
|effectiveDate|否|DateTime| 生效日期|
|enableConsumeLimit|否|Boolean| 是否启用消费限制|
|consumeLimitType|否|Integer| 限制类型 0：按天、1：按月、2：按年|
|consumeLimit|否|Double| 消费限制|

###请求参数Json格式
 
```
{
 "id" : 0,
 "cardName" : "String",
 "expireDay" : 0,
 "status" : true,
 "cardPicUrl" : "String",
 "cardDescription" : "String",
 "buyDescription" : "String",
 "effectiveWay" : 0,
 "effectiveDate" : "DateTime",
 "enableConsumeLimit" : true,
 "consumeLimitType" : 0,
 "consumeLimit" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Long| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : 0,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
