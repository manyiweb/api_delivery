# 获取微信隐私设置

**请求URL：** 
- `/wx/privacy/getprivacysetting `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|wxSn|否|String||

###请求参数Json格式
 
```
{
 "wxSn" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--errcode|否|Integer| 返回码|
|--errmsg|否|String| 错误信息|
|--codeExist|否|Integer| 代码是否存在 0 不存在， 1 存在 。如果最近没有通过commit接口上传代码，则会出现 code_exist=0的情况。|
|--privacyList|否|List| 代码检测出来的用户信息类型（privacy_key）|
|--settingList|否|List| 要收集的用户信息配置|
|----privacyKey|否|String| 用户信息类型的英文名称|
|----privacyText|否|String| 该用户信息类型的用途|
|----privacyLabel|否|String| 用户信息类型的中文名称|
|--updateTime|否|Long| 更新时间戳|
|--ownerSetting|否|Object| 收集方（开发者）信息配置|
|----contactEmail|否|String| 信息收集方（开发者）的邮箱|
|----contactPhone|否|String| 信息收集方（开发者）的手机号|
|----contactQq|否|String| 信息收集方（开发者）的qq|
|----contactWeixin|否|String| 信息收集方（开发者）的微信号|
|----noticeMethod|否|String| 通知方式，指的是当开发者收集信息有变动时，通过该方式通知用户|
|----storeExpireTimestamp|否|String| 存储期限，指的是开发者收集用户信息存储多久|
|----extFileMediaId|否|String| 自定义 用户隐私保护指引文件的media_id|
|--privacyDesc|否|Object| 用户信息类型对应的中英文描述|
|----privacyDescList|否|List||
|------privacyDesc|否|String| 用户信息类型的中文描述|
|------privacyKey|否|String| 用户信息类型的英文key|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式

```
{

 "codeExist" : 0,
 "privacyList" : null,
 "settingList" : [{
 "privacyKey" : "String",
 "privacyText" : "String",
 "privacyLabel" : "String"
 }],
 "updateTime" : 0,
 "ownerSetting" : {
 "contactEmail" : "String",
 "contactPhone" : "String",
 "contactQq" : "String",
 "contactWeixin" : "String",
 "noticeMethod" : "String",
 "storeExpireTimestamp" : "String",
 "extFileMediaId" : "String"
 },
 "privacyDesc" : {
 "privacyDescList" : [{
 "privacyDesc" : "String",
 "privacyKey" : "String"
 }]
 }
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
