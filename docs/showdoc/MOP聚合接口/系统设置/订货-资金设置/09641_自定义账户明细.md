#

**请求URL：** 
- `/config/customSet/funds/getDetail`

**请求方式：** 
- `POST`
- `RequestBody`


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||
|sword|否|String||

### 请求参数Json格式
 
```
{
 "id":0,
 "sword":"String"
}
```

### 响应参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long| id|
|--mid|否|String| 主键业务ID|
|--logoUrl|否|String| 图片|
|--logoUrlFull|否|String| 图片URL|
|--accountCode|否|String| 账号编码|
|--accountName|否|String| 账号名称|
|--status|否|Integer| 状态 1启用0停用|
|--myStatus|否|Boolean| 个人中心状态 1启用0停用|
|--recharge|否|Boolean| 是否可充值|
|--deduct|否|Boolean| 是否可抵扣货款|
|--deductRate|否|Double| 抵扣比例|
|--isAllItem|否|Integer| 0指定商品 1应用所有商品 2指定品牌/分类/系列|
|--lineNum|否|Long| 行号|
|--rebate|否|Boolean| 是否为返利账户|
|--accountBalance|否|Double| 自定义账户金额|
|--rebateBalance|否|Double| 返利账户金额|
|--image|否|String||
|--imageFull|否|String||
|--promotion|否|Boolean| 是否参与促销|
|--deductionExpressFee|否|Boolean| 是否抵扣运费|
|--isWithdrawAble|否|Boolean| 是否可提现|
|--withdrawRate|否|Double| 提现费率|
|--fundChangeSelectSubject|否|Boolean| 启用资金变更单科目必选|
|--openPreferentialAmount|否|Boolean| 是否开启优惠金额|
|--remark|否|String| 说明|
|--openWithdrawTime|否|Boolean| 开启提现时间配置|
|--withdrawTime|否|List| 1,2,3,4.... 表示日|
|--freezeAmount|否|Double| 冻结金额|
|--canCombinationPay|否|Boolean|允许多次支付 |
|--applyAllCompany|否|Boolean| 是否应用所有门店|
|--applyCompanyIds|否|List| 应用的门店ID列表|
|--applyCompanyList|否|List| 应用的门店信息列表|
|----companyId|否|String| 门店ID|
|----companyCode|否|String| 门店编码|
|----companyName|否|String| 门店名称|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
