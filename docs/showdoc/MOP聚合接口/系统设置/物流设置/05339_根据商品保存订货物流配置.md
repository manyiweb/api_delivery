# 根据商品保存订货物流配置
 

**请求URL：** 
- `/b2b/logistics/config/action/saveLogisticsItem `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 门店id|
|specId|是|String| 规格id|
|itemId|是|String| 商品id|
|logisticsItems|否|List| 物流信息|
|--id|否|Long||
|--logisticsProviderCode|是|String| 订货物流商编码|
|--logisticsProviderName|是|String| 订货物流商名称|
|--logisticsProviderPhone|否|String| 订货物流商电话|
|--logisticsProviderAddress|否|String| 订货物流商地址|
|--logisticsProviderId|是|String| 订货物流id|
|--def|否|Boolean| 是否默认|
|removeItems|否|List| 删除的物流信息|

###请求参数Json格式
 
```
{
 "companyId" : "String",
 "specId" : "String",
 "itemId" : "String",
 "logisticsItems" : [{
 "id" : 0,
 "logisticsProviderCode" : "String",
 "logisticsProviderName" : "String",
 "logisticsProviderPhone" : "String",
 "logisticsProviderAddress" : "String",
 "def" : true
 }],
 "removeItems" : null
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
