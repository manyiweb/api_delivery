# 获取物流商配置
 

**请求URL：** 
- `/config/logistics/get `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 商户id|

###请求参数Json格式
 
```
{
 "companyId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--inherit|否|Integer| 是否继承商户 1是 0否|
|--logisticsActive|否|Integer| 是否启用物流商|
|--logisticsJson|否|String| 物流商配置|
|--b2bOrderStatus|否|Integer|订货发货物流|
|--orderStatus|否|Integer|零售商城物流|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "inherit" : 0,
 "logisticsActive" : 0,
 "logisticsJson" : "String",
 "b2bOrderStatus" : 0,
 "orderStatus" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
