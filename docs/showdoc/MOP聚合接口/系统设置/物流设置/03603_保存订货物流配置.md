# 保存订货物流配置
 

**请求URL：** 
- `/b2b/logistics/config/action/save `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long||
|companyId|否|String| 门店id|
|isInherit|否|Boolean| 是否继承|
|openLogistics|否|Boolean| 启用订货物流商|
|logisticsType|否|String| 物流商配置类型 0整单 1商品|
|changeLogisticsProviders|否|List| 新增或编辑订货物流商|
|--id|否|Long||
|--logisticsProviderCode|否|String| 订货物流商编码|
|--logisticsProviderName|否|String| 订货物流商名称|
|--def|否|Boolean| 是否默认|
|removeLogisticsProviders|否|List| 删除订货物流商|

###请求参数Json格式
 
```
{
 "id" : 0,
 "companyId" : "String",
 "isInherit" : true,
 "openLogistics" : true,
 "changeLogisticsProviders" : [{
 "id" : 0,
 "logisticsProviderCode" : "String",
 "logisticsProviderName" : "String",
 "def" : true
 }],
 "removeLogisticsProviders" : null
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
