# 货币-分页

**请求URL：** 
- `/config/v1/finance/currency/action/page `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|sword|否|String||
|tokenId|否|String||
|id|否|String||
|pageIndex|否|Integer| 页号|
|pageSize|否|Integer| 页大小|

###请求参数Json格式
 
```
{
 "sword" : "String",
 "tokenId" : "String",
 "id" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--pageIndex|否|Integer| 页码|
|--pageSize|否|Integer| 显示记录数|
|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|--first|否|Boolean| 首页|
|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|
|----currencyCode|否|String| 货币代码|
|----currencyName|否|String| 货币名称|
|----currencySymbol|否|String| 货币符号|
|----isDef|否|bool| 是否默认|
|----scale|否|int| 货币换算保留小数位|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : {
 "pageIndex" : 0,
 "pageSize" : 0,
 "pageCount" : 0,
 "totalCount" : 0,
 "first" : true,
 "last" : true,
 "content" : [{
 "currencyCode" : "String",
 "currencyName" : "String",
 "currencySymbol" : "String"、
		 "isDef": false,
 "scale": 2
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
