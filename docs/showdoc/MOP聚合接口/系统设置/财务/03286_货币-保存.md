# 货币-保存

**请求URL：** 
- `/config/v1/finance/currency/action/save `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|currencyCode|否|String| 货币代码|
|currencyName|否|String| 货币名称|
|currencySymbol|否|String| 货币符号|
|isDef|否|bool| 是否默认|
|scale|否|int| 货币换算保留小数位|
###请求参数Json格式
 
```
{
 "currencyCode" : "String",
 "currencyName" : "String",
 "currencySymbol" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
