# BankCardController 接口文档

## 接口汇总

|序号|接口名称|请求URL|请求方式|请求体类型|响应体类型|
|:----|:----|:----|:----|:----|:----|
|1|银行卡列表|`/b2b/bankcard/list`|POST|`BankCardPageReq`|`Response>`|
|2|获取银行账户信息|`/b2b/bankcard/account-info`|POST|无|`Response`|
|3|申请银行卡|`/b2b/bankcard/apply`|POST|`ApplyBankCardReq`|`Response`|
|4|注销银行卡|`/b2b/bankcard/cancel`|POST|`CancelBankCardReq`|`Response`|
|5|设置收款卡|`/b2b/bankcard/set-receive-card`|POST|`SetReceiveCardReq`|`Response`|
|6|设置默认收款卡|`/b2b/bankcard/set-default`|POST|`SetDefaultReceiveCardReq`|`Response`|
|7|银行卡详情|`/b2b/bankcard/detail`|POST|`QueryDetailReq`|`Response`|
|8|查询交易明细|`/b2b/bankcard/transactions`|POST|`QueryTransactionsReq`|`Response>`|
|9|下载电子回单|`/b2b/bankcard/receipt`|POST|`QueryReceiptReq`|`ResponseEntity`|
|10|手工匹配流水|`/b2b/bankcard/manual-match`|POST|`ManualMatchReq`|`Response`|
|11|获取线下支付银行卡信息|`/b2b/bankcard/offline-pay-confirm`|POST|`OfflinePayConfirmReq`|`Response`|
|12|新增订货订单银行卡支付|`/b2b/bankcard/order-payment-snapshot/add`|POST|`CreateOrderPaymentSnapshotReq`|`Response`|
|13|新增账单银行卡支付信息|`/b2b/bankcard/bill-payment-snapshot/add`|POST|`CreateBillPaymentSnapshotReq`|`Response`|

## 1. 银行卡列表

#**请求URL：**
- `/b2b/bankcard/list`

**请求方式：**
- `POST`
- `RequestBody`

### 请求参数<业务参数>

|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String|商户/门店ID|
|pageIndex|否|Integer|页码|
|pageSize|否|Integer|每页条数|
|sword|否|String|搜索关键字，按卡号模糊搜索|

### 请求参数Json格式

```json
{
 "companyId":"String",
 "pageIndex":1,
 "pageSize":10,
 "sword":"String"
}
```

### 响应参数

|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--pageIndex|否|Integer||
|--pageSize|否|Integer||
|--pageCount|否|Integer||
|--totalCount|否|Long||
|--first|否|Boolean||
|--last|否|Boolean||
|--content|否|List||
|----id|否|Long|银行卡主键ID|
|----cardNo|否|String|卡号|
|----accountName|否|String|收款户名|
|----accountNo|否|String|主账户账号|
|----bankName|否|String|开户行名称|
|----accountType|否|String|账户类型/卡类型|
|----companyId|否|String|归属商户或门店ID|
|----companyName|否|String|归属商户或门店名称|
|----isReceiveCard|否|Boolean|是否为收款卡|
|----isDefaultReceive|否|Boolean|是否为默认收款卡|
|----enabled|否|Boolean|是否启用, 否为注销|
|----cardStatus|否|String|银行卡状态编码|
|----cardStatusName|否|String|银行卡状态名称|
|----openDate|否|String|开卡日期|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||

### 响应参数Json格式

```json
{
 "data":{
 "pageIndex":1,
 "pageSize":10,
 "pageCount":1,
 "totalCount":1,
 "first":true,
 "last":true,
 "content":[{
 "id":1,
 "cardNo":"String",
 "accountName":"String",
 "accountNo":"String",
 "bankName":"String",
 "accountType":"String",
 "companyId":"String",
 "companyName":"String",
 "isReceiveCard":true,
 "isDefaultReceive":true,
 "enabled":true,
 "cardStatus":"String",
 "cardStatusName":"String",
 "openDate":"String"
 }]
 },
 "msg":"String",
 "code":"String",
 "exceptionStackInfo":"String",
 "traceId":"String"
}
```

## 9. 下载电子回单

- `/b2b/bankcard/receipt`

**请求方式：**
- `POST`
- `RequestBody`

### 请求参数<业务参数>

|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tranNo|是|String|流水号|
|accountNo|是|String|主账户账号|

### 请求参数Json格式

```json
{
 "tranNo":"String",
 "accountNo":"String"
}
```

### 响应参数

|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|body|否|byte[]|PDF二进制文件流|
|Content-Type|否|String|固定为 `application/pdf`|
|Content-Disposition|否|String|文件名格式 `attachment; filename=receipt_{tranNo}.pdf`|

### 响应参数Json格式

```text
该接口直接返回 PDF 文件流，不返回 Response JSON。
```
