# 分页查询待匹配订货订单

**请求URL：** 
- `/b2b/citic/internal/pending-order/list`

**请求方式：** 
- `POST`
- `RequestBody`


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|payStatus|否|String||
|beginCreateDate|否|DateTime||
|endCreateDate|否|DateTime||

### 请求参数Json格式
 
```
{
 "payStatus":"String",
 "beginCreateDate":"DateTime",
 "endCreateDate":"DateTime"
}
```

### 响应参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--pageIndex|否|Integer||
|--pageSize|否|Integer||
|--pageCount|否|Integer||
|--totalCount|否|Long||
|--first|否|Boolean||
|--last|否|Boolean||
|--content|否|List||
|----orderId|否|String|订单ID |
|----orderStatus|否|String|订单状态 |
|----orderStatusName|否|String|订单状态名称 |
|----orderNo|否|String|订单号 |
|----companyId|否|String|商户ID |
|----companyCode|否|String|商户编码 |
|----orderType|否|String|订单类型 |
|----payStatus|否|String|支付状态 |
|----createDate|否|DateTime|创建日期 |
|----totalAmt|否|Double|订单总金额 |
|----paidAmt|否|Double|已付金额 |
|----unpaidAmt|否|Double|未付金额 |
|----receiveCardNo|否|String|收款卡号 |
|----createTime|否|String|创建时间 |
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 响应参数Json格式
 
```
{
 "data":{
 "pageIndex":0,
 "pageSize":0,
 "pageCount":0,
 "totalCount":0,
 "first":true,
 "last":true,
 "content":[{
 "orderId":"String",
 "orderStatus":"String",
 "orderStatusName":"String",
 "orderNo":"String",
 "companyId":"String",
 "companyCode":"String",
 "orderType":"String",
 "payStatus":"String",
 "createDate":"DateTime",
 "totalAmt":0,
 "paidAmt":0,
 "unpaidAmt":0,
 "receiveCardNo":"String",
 "createTime":"String"
 }]
 },
 "msg":"String",
 "code":"String",
 "exceptionStackInfo":"String",
 "traceId":"String"
}
```
