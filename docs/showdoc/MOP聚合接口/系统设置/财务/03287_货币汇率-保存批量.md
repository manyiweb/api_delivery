# 货币汇率-保存

**请求URL：** 
- `/config/v1/finance/currency/exchangeRate/action/save `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|fromDate|否|String| 开始日期|
|toDate|否|String| 结束日期|
|currencyExchangeRates|否|List| 货币汇率|
|--currencyId|否|String| 货币id|
|--conversionRate|否|Double| 货币汇率|

###请求参数Json格式
 
```
{
 "fromDate" : "String",
 "toDate" : "String",
 "currencyExchangeRates" : [{
 "currencyId" : "String",
 "conversionRate" : 0
 }]
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
