# 获取存在已应用于该商户的其他订货类型中的商品

**请求URL：** 
- `/b2b/orderTypeConfig/exist/item`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|itemIds|是|List| 应用商品列表 当claimItemType为2时传|

### 请求参数Json格式
 
```
{
 "itemIds" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--itemId|否|String||
|--itemCode|否|String| 商品编码|
|--itemName|否|String| 商品名称|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : [{
 "itemId" : "String",
 "itemCode" : "String",
 "itemName" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
