# 查询
 

**请求URL：** 
- `/config/printer/template/optionName/list `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 商户ID或品牌ID|
|optionName|是|String| 业务单据|

###请求参数Json格式
 
```
{
 "tokenId": "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--optionName|否|String| 业务单据名称|
|--optionValue|否|String| 业务单据编码|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : [
		{
			"optionName": "商品入库",
			"optionValue": "WhsInType"
		},
		{
			"optionName": "商品出库",
			"optionValue": "WhsOutType"
		}
	],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
