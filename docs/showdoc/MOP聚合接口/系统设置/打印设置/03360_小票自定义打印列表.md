# 小票自定义打印列表

**请求URL：** 
- `/config/printer/ticket/custom/list `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 商户ID或品牌ID|
|optionName|否|String| 业务单据|

###请求参数Json格式
 
```
{
 "companyId" : "String",
 "optionName" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--docType|否|String| 单据类型|
|--docTypeName|否|String| 单据类型名称|
|--optionName|否|String| 业务单据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : [{
 "docType" : "String",
 "docTypeName" : "String",
 "optionName" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
