# 云打印-明细

**请求URL：** 
- `/config/cloud/printer/detail `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long||

###请求参数Json格式
 
```
{
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long| 主键|
|--serialNumber|否|String| 序列号|
|--printerName|否|String| 打印机名称|
|--status|否|Boolean| 状态|
|--isActive|否|Boolean| 是否启用|
|--printerType|否|Integer| 打印机类型 1-小票 2-标签|
|--companyId|否|String| 门店id|
|--companyCode|否|String| 门店编码|
|--companyName|否|String| 门店名称|
|--deviceKey|否|String| 设备密钥|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


###返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "serialNumber" : "String",
 "printerName" : "String",
 "status" : true,
 "isActive" : true,
 "printerType" : 0,
 "companyId" : "String",
 "companyCode" : "String",
 "companyName" : "String",
 "deviceKey" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
