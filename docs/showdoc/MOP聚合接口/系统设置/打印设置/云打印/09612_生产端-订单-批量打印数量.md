# 生产端-订单-批量打印数量

**请求URL：** 
- `/product/productionPlan/getProduceOrderPrintCount`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|sword|否|String| 搜索条件|
|date|否|DateTime| 时间|
|type|否|Integer| 类型 1:待生产 2.生产完成|
|receiptPrint|否|Boolean| 小票是否已打印 空是全部 true false|

### 请求参数Json格式
 
```
{
 "sword" : "String",
 "date" : "DateTime",
 "type" : 0,
 "receiptPrint" : true
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--receiptPrint|否|Integer| 是否打印 0否 1是 2全部|
|--count|否|Integer| 数量|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "receiptPrint" : 0,
 "count" : 0
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
