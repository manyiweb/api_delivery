# 生产端-批量打印-确认打印

**请求URL：** 
- `/product/productionPlan/produceOrderBatchPrint`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|ids|否|List| 计划单id|
|docType|否|String| 订单类型 小票：MadeToOrder("按订单生产"),ProduceAccordingToPlan("按计划单生产") 标签：Plan("计划"),Order("订单"),Receipt("收货")|
|optionName|否|String| 业务类型 小票：ProduceOrders("生产接单") 标签：ProduceFinish("生产完成")|
|printType|否|Integer| 打印类型 0-小票，1-标签|

### 请求参数Json格式
 
```
{
 "ids" : null,
 "docType" : "String",
 "optionName" : "String",
 "printType" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
