# 是否启用打印

**请求URL：** 
- `/config/getIsPrint `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 门店id|
|groupId|否|String| 品牌id|
|optionName|否|String| 业务类型|
|docType|否|String| 订单类型|

###请求参数Json格式
 
```
{
 "companyId" : "String",
 "groupId" : "String",
 "optionName" : "String",
 "docType" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Boolean||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


###返回参数Json格式
 
```
{
 "data" : true,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
