# 云打印组-添加打印机

**请求URL：** 
- `/config/cloud/printer/group/printer/add `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|cloudPrinterGroupId|否|Long| 云打印组id|
|cloudPrinterIds|否|List| 云打印机id|

###请求参数Json格式
 
```
{
 "cloudPrinterGroupId" : 0,
 "cloudPrinterIds" : null
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
