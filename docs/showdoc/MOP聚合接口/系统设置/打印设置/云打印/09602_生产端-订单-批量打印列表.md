# 生产端-订单-批量打印列表

**请求URL：** 
- `/product/productionPlan/produceOrderBatchPrintList`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|sword|否|String| 搜索条件|
|date|否|DateTime| 时间|
|type|否|Integer| 类型 1:待生产 2.生产完成|
|receiptPrint|否|Integer| 小票是否已打印 0否 1是 2全部|
|tripTimeName|否|String| 生产趟次|
|deliveryTimeSlotStart|否|String| 提货配送时间段-开始|
|deliveryTimeSlotEnd|否|String| 提货配送时间段-结束|

### 请求参数Json格式
 
```
{
 "sword" : "String",
 "date" : "DateTime",
 "type" : 0,
 "receiptPrint" : 0,
 "tripTimeName" : "String",
 "deliveryTimeSlotStart" : "String",
 "deliveryTimeSlotEnd" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--id|否|Long| 计划单id|
|--planNo|否|String| 计划单号|
|--itemId|否|String| 商品id|
|--itemCode|否|String| 商品编码|
|--itemName|否|String| 商品名称|
|--specId|否|String| 规格id|
|--skuBarcode|否|String| sku|
|--specName|否|String| 规格名称|
|--receiptPrint|否|Boolean| 小票是否已打印|
|--receiptPrintQty|否|Integer| 小票打印次数|
|--sourceNo|否|String| 外部单号|
|--itemImage|否|String| 商品图片|
|--tripTimeName|否|String| 配送趟次|
|--sourceOrderNo|否|String| 销售单号|
|--deliveryType|否|String| 配送方式|
|--deliveryDate|否|String| 配送时间范围|
|--pickupDate|否|String| 提货时间|
|--deliveryTimeSlot|否|String| 提货/配送时间|
|--productionPlanDate|否|DateTime| 生产计划时间|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
