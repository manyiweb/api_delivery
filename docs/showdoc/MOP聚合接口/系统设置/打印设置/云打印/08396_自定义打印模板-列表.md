# 自定义打印模板-列表

**请求URL：** 
- `/config/customPrintTemplate/list `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|sword|否|String| 搜索条件|
|pageIndex|否|Integer||
|pageSize|否|Integer||
|orderField|否|String||
|orderSort|否|String||

###请求参数Json格式
 
```
{
 "sword" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--pageIndex|否|Integer||
|--pageSize|否|Integer||
|--pageCount|否|Integer||
|--totalCount|否|Long||
|--first|否|Boolean||
|--last|否|Boolean||
|--content|否|List||
|----templateId|否|Long| 自定义模板ID|
|----templateName|否|String| 模板名称|
|----templateFilePath|否|String| 模板文件路径|
|----templateFileName|否|String| 模板文件名称|
|----defaultTemplate|否|Boolean| 是否为默认模板|
|----type|否|String| 模板类型|
|----parentPrinterTemplateId|否|Long| 父打印模板|
|----count|否|Integer| 打印次数|
|----onlineTemplateId|否|String| 在线模板ID|
|----templateFileUrl|否|String| 模板文件url|
|----docType|否|String| 订单类型|
|----docTypeName|否|String| 订单类型|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


###返回参数Json格式
 
```
{
 "data" : {
 "pageIndex" : 0,
 "pageSize" : 0,
 "pageCount" : 0,
 "totalCount" : 0,
 "first" : true,
 "last" : true,
 "content" : [{
 "templateId" : 0,
 "templateName" : "String",
 "templateFilePath" : "String",
 "templateFileName" : "String",
 "defaultTemplate" : true,
 "type" : "String",
 "parentPrinterTemplateId" : 0,
 "count" : 0,
 "onlineTemplateId" : "String",
 "templateFileUrl" : "String",
 "docType" : "String",
 "docTypeName" : "String"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
