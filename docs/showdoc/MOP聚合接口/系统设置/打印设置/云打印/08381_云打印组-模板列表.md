# 云打印组-模板列表

**请求URL：** 
- `/config/cloud/printer/group/template/list `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|cloudPrinterGroupId|否|Long| 打印组id|
|pageIndex|否|Integer||
|pageSize|否|Integer||
|orderField|否|String||
|orderSort|否|String||

###请求参数Json格式
 
```
{
 "cloudPrinterGroupId" : 0,
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--pageIndex|否|Integer||
|--pageSize|否|Integer||
|--pageCount|否|Integer||
|--totalCount|否|Long||
|--first|否|Boolean||
|--last|否|Boolean||
|--content|否|List||
|----id|否|Long| 主键|
|----cloudPrinterGroupId|否|Long| 打印机组id|
|----customPrintTemplateId|否|Long| 模板id|
|----onlineTemplateId|否|String| 在线模板id|
|----templateName|否|String| 模板名称|
|----type|否|String| 类型|
|----typeName|否|String| 类型|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


###返回参数Json格式
 
```
{
 "data" : {
 "pageIndex" : 0,
 "pageSize" : 0,
 "pageCount" : 0,
 "totalCount" : 0,
 "first" : true,
 "last" : true,
 "content" : [{
 "id" : 0,
 "cloudPrinterGroupId" : 0,
 "customPrintTemplateId" : 0,
 "onlineTemplateId" : "String",
 "templateName" : "String",
 "type" : "String",
 "typeName" : "String"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
