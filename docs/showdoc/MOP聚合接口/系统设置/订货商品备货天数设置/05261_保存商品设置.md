# 保存
 

**请求URL：** 
- `/b2b/item/leadTime/save `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 门店id|
|isInherit|否|Boolean| 是否继承|
|enableStockSet|否|Boolean| 是否启用按商品设置预计备货天数|
|items|否|List| 保存的商品行|
|--id|否|Long| 主键|
|--expectedDays|否|Integer| 天数|

###请求参数Json格式
 
```
{
 "companyId" : "String",
 "isInherit" : true,
 "enableStockSet" : true,
 "items" : [{
 "id" : 0,
 "expectedDays" : 0
 }]
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
