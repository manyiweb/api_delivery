# 编辑会员服务卡
 

**请求URL：** 
- `/mem/servicecard/edit`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long||
|serviceCardName|是|String| 服务卡名称|
|cardType|是|Integer| 服务卡类型 1、次卡 2、日卡|
|activeType|是|Integer| 生效方式 1、购买后生效 2、使用后生效 3、指定生效时间|
|serviceCount|否|Integer| 服务次数|
|expireDay|否|Integer| 有效天数|
|expireTimeBegin|否|DateTime| 生效日|
|status|是|Integer| 活跃状态|
|useDaily|否|Integer| 每天最大可使用次数|
|useExpire|否|Integer| 有效期内最大可使用次数|
|canntUseWeekly|否|String| 每周不可使用时间 格式 1,2,3,4,5,6,7|
|canUseOtherCom|是|Integer| 是否可以跨店使用|
|description|否|String| 服务卡说明|
|useDailyEnable|否|Boolean| 启用限制每天最大可使用次数|
|imgUrl|否|String| 服务卡图片url|
|useInfo|否|String| 使用说明|
|autoWriteOff|否|Boolean| 是否每日自动核销|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "serviceCardName" : "String",
 "cardType" : 0,
 "activeType" : 0,
 "serviceCount" : 0,
 "expireDay" : 0,
 "expireTimeBegin" : "DateTime",
 "status" : 0,
 "useDaily" : 0,
 "useExpire" : 0,
 "canntUseWeekly" : "String",
 "canUseOtherCom" : 0,
 "description" : "String",
 "useDailyEnable" : true,
 "imgUrl" : "String",
 "useInfo" : "String",
 "autoWriteOff" : true
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
