# 会员服务卡详情
 

**请求URL：** 
- `/mem/servicecard/info`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||

### 请求参数Json格式
 
```
{
 "id" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long||
|--serviceCardNo|否|String| 服务卡编号|
|--serviceCardName|否|String| 服务卡名称|
|--cardType|否|Integer| 服务卡类型 1、次卡 2、日卡|
|--activeType|否|Integer| 生效方式 1、购买后生效 2、使用后生效 3、指定生效时间|
|--serviceCount|否|Integer| 服务次数|
|--expireDay|否|Integer| 有效天数|
|--expireTimeBegin|否|DateTime| 生效日|
|--status|否|Integer| 活跃状态|
|--opRestrict|否|Integer| 启用限制|
|--useDaily|否|Integer| 每天最大可使用次数|
|--useExpire|否|Integer| 有效期内最大可使用次数|
|--canntUseWeekly|否|String| 每周不可使用时间 格式 1,2,3,4,5,6,7|
|--canUseOtherCom|否|Integer| 是否可以跨店使用|
|--description|否|String| 服务卡说明|
|--statusName|否|String||
|--activeTypeName|否|String||
|--cardTypeName|否|String||
|--createName|否|String| 创建人|
|--createDate|否|DateTime| 创建时间|
|--useDailyEnable|否|Boolean| 启用限制每天最大可使用次数|
|--imgUrl|否|String| 服务卡图片url|
|--useInfo|否|String| 使用说明|
|--autoWriteOff|否|Boolean| 是否每日自动核销|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
