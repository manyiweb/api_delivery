# 配送范围详情

**请求URL：** 
- `/config/deliveryscope/get `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String|门店|

###请求参数Json格式
 
```
{
 "companyId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--isInherit|否|Integer| 是否继承|
|--deliveryAreaSet|否|Object| 主表信息|
|----id|否|Long| id|
|----open|否|Integer| 启用配送范围设置1是0否|
|----rangeKilometer|否|Double| 可配送范围(公里) |
|----appWay|否|Integer| 应用方式 0指定商品 1指定分类/品牌/系列|
|----companyId|否|String| 门店标识，与syscompany关联|
|----createId|否|String| 创建人id|
|----createName|否|String| 创建人|
|----createDate|否|DateTime| 创建时间|
|----modifyId|否|String| 修改人id|
|----modifyName|否|String| 修改人|
|----modifyDate|否|DateTime| 修改时间|
|----dbKey|否|Integer| 分库标识|
|----groupId|否|String| 品牌商id|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : {
 "isInherit" : 0,
 "deliveryAreaSet" : {
 "id" : 0,
 "open" : 0,
 "rangeKilometer" : 0,
 "appWay" : 0,
 "companyId" : "String",
 "createId" : "String",
 "createName" : "String",
 "createDate" : "DateTime",
 "modifyId" : "String",
 "modifyName" : "String",
 "modifyDate" : "DateTime",
 "dbKey" : 0,
 "groupId" : "String"
 }
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
