# 

**请求URL：** 
- `/config/vehicle/save `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|
|licenseNumber|否|String| 车牌号|
|driver|否|String| 司机|
|activeState|否|Integer| 活跃状态|
|platoonVolume|否|Double| 排车体积|
|lineVolumeUnit|否|String| 体积单位|

###请求参数Json格式
 
```
{
 "id" : 0,
 "licenseNumber" : "String",
 "driver" : "String",
 "activeState" : 0,
 "platoonVolume" : 0,
 "lineVolumeUnit" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long| id|
|--licenseNumber|否|String| 车牌号|
|--driver|否|String| 司机|
|--activeState|否|Integer| 活跃状态|
|--platoonVolume|否|Double| 排车体积|
|--companyId|否|String| 商户id|
|--lineVolumeUnit|否|String| 排车体积单位|
|--createId|否|String| 创建人id|
|--createName|否|String| 创建人|
|--createDate|否|DateTime| 创建时间|
|--modifyId|否|String| 修改人id|
|--modifyName|否|String| 修改人|
|--modifyDate|否|DateTime| 修改时间|
|--dbKey|否|Integer| 分库标识|
|--groupId|否|String| 品牌商id|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
