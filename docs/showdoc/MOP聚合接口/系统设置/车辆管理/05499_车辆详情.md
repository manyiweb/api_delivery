# 

**请求URL：** 
- `/config/vehicle/get `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|

###请求参数Json格式
 
```
{
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long| id|
|--licenseNumber|否|String| 车牌号|
|--driver|否|String| 司机|
|--activeState|否|Integer| 活跃状态|
|--platoonVolume|否|Double| 排车体积|
|--createDate|否|DateTime| 创建时间|
|--createName|否|String| 创建人|
|--lineVolumeUnit|否|String| 体积单位|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "licenseNumber" : "String",
 "driver" : "String",
 "activeState" : 0,
 "platoonVolume" : 0,
 "createDate" : "DateTime",
 "createName" : "String",
 "lineVolumeUnit" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
