# 

**请求URL：** 
- `/config/vehicle/page `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|sword|否|String|关键字|
|tokenId|否|String|token|

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--pageIndex|否|Integer| 页码|
|--pageSize|否|Integer| 显示记录数|
|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|--first|否|Boolean| 首页|
|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|
|----id|否|Long| id|
|----licenseNumber|否|String| 车牌号|
|----driver|否|String| 司机|
|----activeState|否|Integer| 活跃状态|
|----platoonVolume|否|Double| 排车体积|
|----createDate|否|DateTime| 创建时间|
|----createName|否|String| 创建人|
|----lineVolumeUnit|否|String| 体积单位|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
