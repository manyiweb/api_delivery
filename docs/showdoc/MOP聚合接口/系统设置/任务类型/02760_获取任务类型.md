# 获取任务类型
 

**请求URL：** 
- `/mct/config/tasktype/get `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|String| 主键|
|tokenId|否|String| 登录令牌|

###请求参数Json格式
 
```
{
 "id" : "String",
 "tokenId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--fid|否|String||
|--version|否|Integer| 版本号(未使用)|
|--ckey|否|String| 键|
|--cvalue|否|String| 值|
|--ctypeCode|否|String| 类型编码|
|--ctypeName|否|String| 类型名称|
|--isActive|否|Integer| 是否可用 1是0否|
|--createTime|否|DateTime| 创建时间|
|--createId|否|String| 创建人ID|
|--createName|否|String| 创建人名称|
|--remark|否|String| 备注|
|--linNum|否|Integer| 行号|
|--parentId|否|String| 父标识，一般关联本表|
|--companyId|否|String| 门店商户ID，与商户表syscompany相关联|
|--typeCode|否|String| 分类编码|
|--typeName|否|String| 分类名称|
|--defaultValue|否|Integer| 是否为默认值 1是0否|
|--modifyDate|否|DateTime| 修改时间|
|--modifyId|否|String| 修改人标识|
|--modifyName|否|String| 修改人|
|--dbKey|否|Integer| 分库标识|
|--groupId|否|String| 品牌商id|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
