# 初始化注册界面装修
 

**请求URL：** 
- `/hr/init/group/registerView `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|否|String| token|

###请求参数Json格式
 
```
{
 "tokenId":"String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
	"code": "200",
	"data": null,
	"exceptionStackInfo": "",
	"msg": ""
}
```
