# 获取订货助手通用配置
 

**请求URL：** 
- `/config/v1/b2b/setting/common/action/get `

**请求方式：**
- POST
- FormData


###请求参数<业务参数>
 
无参数


###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--companyId|否|String| 商户id|
|--isInherit|否|Integer| 是否继承 1 - 继承, 0 - 不继承|
|--isShowInvQty|否|Integer| 是否显示库存数 1 - 显示, 0 - 不显示|
|--showSaleUnitPrice|否|Integer| 是否显示订货单价 1显示 0不显示|
|--loadingImageUrl|否|String| 页面加载图地址|
|--showStartPage|否|Boolean| 是否显示启动页|
|--startPageUrl|否|String| 启动页地址|
|--showB2bOrderPrice|否|Integer| 是否显示订货单价 1显示 0不显示|
|--showB2bRefundPrice|否|Integer| 是否显示退货价 1显示 0不显示|
|--showB2bExchangeRealMoney|否|Integer| 是否显示换货价 1显示 0不显示|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "companyId" : "String",
 "isInherit" : 0,
 "isShowInvQty" : 0,
 "showSaleUnitPrice" : 0,
 "loadingImageUrl" : "String",
 "showStartPage" : true,
 "startPageUrl" : "String",
 "showB2bOrderPrice" : 0,
 "showB2bRefundPrice" : 0,
 "showB2bExchangeRealMoney" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
