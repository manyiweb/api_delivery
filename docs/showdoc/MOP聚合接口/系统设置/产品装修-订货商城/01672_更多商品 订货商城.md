# 更多商品 订货商城
 

**请求URL：** 
- `/product/mall/moreProducts/itemList/b2bMall `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 商城首页模块id|
|orderField|否|String| 排序字段 newProduct 新品,salePrice - 销售价,saleQty 销售数量|
|orderSort|否|String| 排序方式 desc 升序,asc降序|
|sword|否|String| 搜索关键字|
|pageIndex|否|Integer| 页号|
|pageSize|否|Integer| 页大小|

###请求参数Json格式
 
```
{
 "id" : 0,
 "orderField" : "String",
 "orderSort" : "String",
 "sword" : "String",
 "pageIndex" : 0,
 "pageSize" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--pageIndex|否|Integer| 页码|
|--pageSize|否|Integer| 显示记录数|
|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|--first|否|Boolean| 首页|
|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|
|----salePrice|否|Double| 销售价|
|----memberPrice|否|Integer| 会员价|
|----itemCode|否|String| 商品编码|
|----dealPrice|否|Double| 零售价|
|----itemId|否|String||
|----unit|否|String||
|----itemName|否|String||
|----skuBarcode|否|String||
|----imageUrlFull|否|String||
|----invQty|否|Double||
|----isNegativeStock|否|Integer||
|----isStock|否|Integer||
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
