# 获取注册界面装修详情
 

**请求URL：** 
- `/config/productDecoration/get `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|否|String| token|
|type|否|String| 产品装修类型 Register("注册界面")|
|sysNo|否|String| 平台标识 mall|

###请求参数Json格式
 
```
{
 "tokenId" : "String",
 "type" : "String",
 "sysNo" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--id|否|Long| id|
|--code|否|String| 字段编码|
|--name|否|String| 字段名称|
|--name2|否|String| 别名字段|
|--name3|否|String| 引导语字段|
|--name2Content|否|String| 别名内容|
|--name3Content|否|String| 引导语内容|
|--isShow|否|Integer| 是否展示 1 - 展示, 0 - 不展示|
|--isRequired|否|Integer| 是否必填 1 - 必填, 0 - 不必填|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : [{
 "id" : 0,
 "code" : "String",
 "name" : "String",
 "name2" : "String",
 "name3" : "String",
 "name2Content" : "String",
 "name3Content" : "String",
 "isShow" : 0,
 "isRequired" : 0
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
