# 匿名访问拿数据
 

**请求URL：** 
- `/config/common/action/getCommonSetting/app `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|groupId|否|String| 品牌商标识|
|companyId|否|String||
|tokenId|否|String||
|openId|否|String||

###请求参数Json格式
 
```
{
 "groupId" : "String",
 "companyId" : "String",
 "tokenId" : "String",
 "openId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--companyId|否|String| 商户id|
|--isInherit|否|Integer| 是否继承 1 - 继承, 0 - 不继承|
|--isShowInvQty|否|Integer| 是否显示库存数 1 - 显示, 0 - 不显示|
|--showSaleUnitPrice|否|Integer| 是否显示订货单价 1显示 0不显示|
|--loadingImageUrl|否|String| 页面加载图地址|
|--showStartPage|否|Boolean| 是否显示启动页|
|--startPageUrl|否|String| 启动页地址|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "companyId" : "String",
 "isInherit" : 0,
 "isShowInvQty" : 0,
 "showSaleUnitPrice" : 0,
 "loadingImageUrl" : "String",
 "showStartPage" : true,
 "startPageUrl" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
