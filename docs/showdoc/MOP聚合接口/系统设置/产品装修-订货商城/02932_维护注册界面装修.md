# 维护注册界面装修
 

**请求URL：** 
- `/config/productDecoration/save `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List|请求对象|
|--id|否|String|装修表id|
|--isRequired|否|Integer|是否必填 1 - 必填, 0 - 不必填|
|--isShow|否|Integer|是否展示 1 - 展示, 0 - 不展示|
|--name2Content|否|String|别名内容|
|--name3Content|否|String|引导语内容|
|code|否|String|模块编码|
|tokenId|否|String|tokenId|

###请求参数Json格式
 
```
{
 "data":[
 {
			"id": "885790292738916423",
			"isRequired": 1,
			"isShow": 1,
			"name2Content": "连锁店名别名",
			"name3Content": "请输入连锁店名引导语"
 }
 ],
	"code":"M0034",
 "tokenId":"461512142969488896b38ad178b2066a"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
	"code": "200",
	"data": null,
	"exceptionStackInfo": "",
	"msg": ""
}
```
