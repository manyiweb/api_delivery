# 功能描述: 主题设置-编辑
 

**请求URL：** 
- `/config/mall/theme/edit `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|colorType|否|Integer| 色系类型（1-橙色系，2-蓝色系，3-绿色系，4-自定义色系）|
|color1Hex|否|String| 色板1(16进制)|
|color2Hex|否|String| 色板2(16进制)|
|color3Hex|否|String| 色板3(16进制)|
|color4Hex|否|String| 色板4(16进制)|
|productType|否|String| 产品类型:mall(会员商城),b2b_mall(订货商城),meal_mall(点餐商城)|

###请求参数Json格式
 
```
{
 "colorType" : 0,
 "color1Hex" : "String",
 "color2Hex" : "String",
 "color3Hex" : "String",
 "color4Hex" : "String",
 "productType" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
