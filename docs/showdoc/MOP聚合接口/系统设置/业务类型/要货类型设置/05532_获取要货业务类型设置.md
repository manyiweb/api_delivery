# 获取要货业务类型设置

**请求URL：** 
- `/b2b/need/orderType/config/detail `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderTypeId|否|String| 要货业务类型id|
|appCodeId|否|String| appCOdeId|

###请求参数Json格式
 
```
{
 "orderTypeId" : "String",
 "appCodeId" : "String"
}
```

###返回参数

|:---- |:---|:----- |----- |

|--orderTypeCode|否|String| 业务类型编码|

|--orderTypeName|否|String| 业务类型名称|
