# 获取要货业务类型列表

**请求URL：** 
- `/b2b/need/orderType/config/list`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 商户id|

### 请求参数Json格式
 
```
{
 "companyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--isInherit|否|Integer| 是否继承|
|--isOpen|否|Integer| 是否开启业务类型要货|
|--needOrderTypeList|否|List| 要货业务类型|
|----orderTypeCode|否|String| 业务类型编码|
|----orderTypeId|否|String| 业务类型id|
|----orderTypeName|否|String| 业务类型名称|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : {
 "isInherit" : 0,
 "isOpen" : 0,
 "needOrderTypeList" : [{
 "orderTypeCode" : "String",
 "orderTypeId" : "String",
 "orderTypeName" : "String"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
