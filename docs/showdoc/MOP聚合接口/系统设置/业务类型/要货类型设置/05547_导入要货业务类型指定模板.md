# 导入要货业务类型指定模板

**请求URL：** 
- `/file/need/order/type/import`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String||
|request|否|Object||
|file|否|file|导入的文件|

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "request" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--templateId|否|String| 模板id|
|--inventoryCode|否|String| 模板编码|
|--inventoryName|否|String| 模板名称|
|--status|否|Boolean| 状态|
|--statusName|否|String| 状态|
|--msg|否|String| 错误信息|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : [{
 "templateId" : "String",
 "inventoryCode" : "String",
 "inventoryName" : "String",
 "status" : true,
 "statusName" : "String",
 "msg" : "String",
 "cellStyleMap" : null
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
