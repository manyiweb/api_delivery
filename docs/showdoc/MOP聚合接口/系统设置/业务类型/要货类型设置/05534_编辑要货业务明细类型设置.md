# 编辑要货业务明细类型设置

**请求URL：** 
- `/b2b/need/orderType/config/editDetail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderTypeId|是|String| 业务类型id|
|companyId|否|String| 商户id|
|applyItemType|否|Integer| 应用商品类型 0 - 所有, 1 - 指定商品, 2 - 指定模板|
|addDayCount|否|Integer| 限制每天下单数|
|openAddDayCountSet|否|Boolean| 是否限制每天下单数 true是false否|
|itemIds|否|List| 应用商品列表 当applyItemType为3时传|
|deleteItemIds|否|List| 删除应用商品列表|
|specifyTemplateList|否|List| 指定模板|
|--templateId|否|String| 模板id|
|--templateCode|否|String| 模板编码|
|--templateName|否|String| 模板名称|
|addTimeSetList|否|List| 按月设置可要货日|
|--beginDate|否|Object| 开始时间|
|--endDate|否|Object| 结束时间|
|isAllDayCanAdd|否|Boolean| 是否是全天|
|days|否|String| 天|
|settingPurchasingDaysBymonth|否|Boolean| 启用按月设置可要货日后|
|needChangeOrder|否|Boolean| 启用改单模式|
|functionType|否|String| 类型|
|isNeedQuantitySet|否|Boolean| 是否开启要货数量设置默认不开启|
|items|否|List| 要货数量设置 商品|
|--id|否|Long||
|--specId|是|String| specId|
|--minQuantity|否|Double| 最小要货量|
|--maxQuantity|否|Double| 最大要货量|
|--upperLimitType|否|Integer| 要货上限类型 0固定数量,1安全库存|
|--canExcess|否|Boolean| 是否可超量要货 1是,0否|
|deleteItemQuantityIds|否|List| 删除的要货数量明细ID|
