# 获取当前要货业务类型设置

**请求URL：** 
- `/b2b/need/orderType/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderTypeId|是|String| 要货业务类型id|

### 请求参数Json格式
 
```
{
 "orderTypeId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--isOpen|否|Integer| 是否开启业务类型要货|
|--applyItemType|否|Integer| 应用商品类型 0 - 所有, 1 - 指定商品, 2 - 指定模板|
|--needOrderTypeDetailId|否|Long| 要货业务类型明细id|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : {
 "isOpen" : 0,
 "applyItemType" : 0,
 "needOrderTypeDetailId" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
