# 获取单据业务类型受理开启状态

**请求URL：** 
- `/config/orderType/accept/get `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderType|否|String| 单据类别，取值：PurchaseReturnType - 采购退货|
|docType|否|String| 单据业务类型|
|companyId|否|String| 商户ID|

###请求参数Json格式
 
```
{
 "orderType" : "String",
 "docType" : "String",
 "companyId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--startAccept|否|Boolean| 是否开启受理|
|--acceptLevel|否|Integer| 受理级别|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : {
 "startAccept" : true,
 "acceptLevel" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
