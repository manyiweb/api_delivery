# 详情 同城配送设置
 

**请求URL：** 
- `/config/mealMallSameCityDelivery/info`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String||
|payType|否|Integer| 收费方式 1、按距离收费 2、按区域收费 (如果不传且没有历史数据默认1，如果不传且有历史数据取历史数据)|
|templateType|否|Integer| 划分方式 1、按半径 2、自定义 (如果不传且没有历史数据默认1，如果不传且有历史数据取历史数据)|
|sameCityDeliveryType|否|Integer|同城配送类型，1：当日达，2：次日达 |

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "payType" : 0,
 "templateType" : 0,
 "sameCityDeliveryType" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--mid|否|Long||
|--payType|是|Integer| 收费方式 1、按距离收费 2、按区域收费|
|--templateType|是|Integer| 划分方式 1、按半径 2、自定义 （需求目前是要么所有划分方式是按半径，要么按自定义，所以该字段放在这层而不是放在templateDtoList）|
|--openArea|否|Boolean| 开启地区计算运费|
|--areaScope|否|Integer| 地区配送范围 openArea = true时生效1全市 2全区/县|
|--areaCodes|否|String| 地区配送范围 openArea = true时生效1全市 指定区域编码 ，只要末端编码，多个用;隔开|
|--startingPrice|否|Double| 区域起送价|
|--companyId|是|String| 门店id|
|--templateDtoList|是|List| 模板列表|
|----templateId|否|Long||
|----startingPrice|否|Double| 起送价|
|----templateName|否|String| 模板名称|
|----multiCoordinate|否|Object| 多边形区域经纬度（划分方式是自定义时传 ）|
|----centerCoordinate|否|Object| 圆中心经纬度（划分方式是半径时传 ）|
|----radius|否|Double| 半径长度 单位元（划分方式是半径时传 ）|
|--minDistance|否|Double| 起始公里 单位km|
|--minPay|否|Double| 起始公里收取配送费 单位元|
|--eachExceedDistance|否|Double| 每超出公里 单位km|
|--eachExceedPay|否|Double| 每超出公里收取配送费 单位元|
|--freeKg|否|Double| 免费重量 单位kg|
|--eachKg|否|Double| 超出每kg 单位kg|
|--eachPay|否|Double| 超出的重量分别额外收取费用 单位元|
|--companyName|否|String||
|--longitude|否|Double| 商户经纬度|
|--latitude|否|Double||
|--assignItemType|否|Integer| 指定商品类型，0为所有商品，1为指定分类|
|--distanceDeliveryFeeDtos|否|List| 配送类型|
|--setStartingPriceByDistance|否|Boolean| 按距离设置起送价|
|--startingPriceList|否|List| 起送价列表|
|----distance|否|Double| 起始公里 单位km|
|----expressFee|否|Double| 起始公里收取配送费 单位元|
|----startingPrice|否|Double| 起送价|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
