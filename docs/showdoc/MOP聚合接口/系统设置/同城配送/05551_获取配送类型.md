# 获取配送类型 
 

**请求URL：** 
- `/config/deliveryset/getSalesDeliverySetType `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 门店id|

###请求参数Json格式
 
```
{
 "companyId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--openTodayArrive|否|Integer| 开启当日达|
|--openTomorrowArrive|否|Integer| 开启次日达|
|--sameCityDeliveryType|否|String| 同城配送类型|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "openTodayArrive" : 0,
 "openTomorrowArrive" : 0,
 "sameCityDeliveryType" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
