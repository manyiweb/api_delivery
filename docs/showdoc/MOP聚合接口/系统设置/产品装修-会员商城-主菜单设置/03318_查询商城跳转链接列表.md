# 功能描述: 查询商城跳转链接列表
 

**请求URL：** 
- `/config/mall/urlType/list `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|optionName|否|String| 类型编码（会员商城：mallMenuUrlType，订货商城：b2bMallMenuUrlType，点餐商城：mealMallMenuUrlType）|

###请求参数Json格式
 
```
{
 "optionName" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--code|否|String| 跳转类型编码|
|--content|否|String| 跳转类型中文|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : [{
 "code" : "String",
 "content" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
