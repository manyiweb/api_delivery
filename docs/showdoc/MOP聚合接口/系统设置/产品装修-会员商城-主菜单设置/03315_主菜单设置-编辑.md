# 功能描述: 主菜单设置-编辑
 

**请求URL：** 
- `/config/mall/menu/edit `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|productType|否|String| 产品类型:mall(会员商城),b2b_mall(订货商城),meal_mall(点餐商城)|
|enableCustomSetting|否|Boolean| 是否启用自定义设置|
|mallMenuDetailDTOs|否|List| 子菜单列表|
|--title|否|String| 标题|
|--selectedIcon|否|String| 已选中图标|
|--unselectedIcon|否|String| 未选中图标|
|--sourceId|否|Long| 微页面ID，关联micro_page表|
|--url|否|String| 跳转链接|
|--urlTypeCode|否|String| 链接类型|
|--urlTypeName|否|String| 链接名称|
|--iconType|否|Integer| 图标类型（0-系统图标，1-自定义图标）|
|--iconTypeName|否|String| 图标类型（0-系统图标，1-自定义图标）|
|--systemIconCode|否|Integer| 系统图标编码（0-首页，1-商品分类，2-购物车，3-个人中心）|
|--systemIconCodeName|否|String| 系统图标编码（0-首页，1-商品分类，2-购物车，3-个人中心）|

###请求参数Json格式
 
```
{
 "productType" : "String",
 "enableCustomSetting" : true,
 "mallMenuDetailDTOs" : [{
 "title" : "String",
 "selectedIcon" : "String",
 "unselectedIcon" : "String",
 "sourceId" : 0,
 "url" : "String",
 "urlTypeCode" : "String",
 "urlTypeName" : "String",
 "iconType" : 0,
 "iconTypeName" : "String",
 "systemIconCode" : 0,
 "systemIconCodeName" : "String"
 }]
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
