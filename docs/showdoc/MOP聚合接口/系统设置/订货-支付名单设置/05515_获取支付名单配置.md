# 获取支付名单配置

**请求URL：** 
- `/b2b/payment/list/config/get `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 商户标识|
|tokenId|否|String|用户token|


###请求参数Json格式
 
```
{
 "companyId" : "String",
 "tokenId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--isInherit|否|Boolean| 是否继承|
|--enableWhiteListPay|否|Boolean| 是否启用白名单支付|
|--enableBlackListPay|否|Boolean| 是否启用黑名单支付|
|--whiteListDescription|否|String| 白名单描述|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "isInherit" : true,
 "enableWhiteListPay" : true,
 "enableBlackListPay" : true,
 "whiteListDescription" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
