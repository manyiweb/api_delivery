# 保存支付名单设置（中台）

**请求URL：** 
- `/b2b/payment/list/save `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 当前门店id|
|config|否|Object| 支付配置|
|--isInherit|否|Boolean| 是否继承|
|--enableWhiteListPay|否|Boolean| 是否启用白名单支付|
|--enableBlackListPay|否|Boolean| 是否启用黑名单支付|
|--whiteListDescription|否|String| 白名单描述|
|blackLists|否|List| 添加黑名单人员|
|--id|否|Long| id|
|--companyId|否|String| 门店id|
|--type|否|Integer| 类型|
|--phone|否|String| 电话|
|--name|否|String| 姓名|
|--relation|否|Integer| 关系 先默认为1|
|--attachments|否|List| 附件列表|
|--attachment1|否|String| 附件1|
|--attachment2|否|String| 附件2|
|--attachment3|否|String| 附件3|
|--relationName|否|String| 关系内容|
|--remark|否|String| 备注|
|delIds|否|List| 要删除的黑名单id|

###请求参数Json格式
 
```
{
 "companyId" : "String",
 "config" : {
 "isInherit" : true,
 "enableWhiteListPay" : true,
 "enableBlackListPay" : true,
 "whiteListDescription" : "String"
 },
 "blackLists" : [{
 "id" : 0,
 "companyId" : "String",
 "type" : 0,
 "phone" : "String",
 "name" : "String",
 "relation" : 0,
 "attachments" : null,
 "attachment1" : "String",
 "attachment2" : "String",
 "attachment3" : "String",
 "relationName" : "String",
 "remark" : "String"
 }],
 "delIds" : null
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
