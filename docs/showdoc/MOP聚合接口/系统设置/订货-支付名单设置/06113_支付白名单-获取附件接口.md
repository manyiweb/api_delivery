# 获取附件接口

**请求URL：** 
- `/b2b/payment/list/getAttachment `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|

###请求参数Json格式
 
```
{
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--attachmentId|否|String| 主键标识|
|--fileName|否|String| 文件名称|
|--fileSize|否|Long| 文件大小|
|--fileUrl|否|String| 文件路径|
|--fileFullUrl|否|String| 文件完整路径|
|--fileOrgName|否|String| 文件原名|
|--fileSuffix|否|String| 文件后缀名|
|--sourceId|否|String| 来源单据ID|
|--sourceTable|否|String| 来源单据所属表|
|--companyId|否|String| 门店商户ID，与商户表syscompany相关联|
|--createId|否|String| 创建人ID|
|--createName|否|String| 创建人名称|
|--createDate|否|DateTime| 创建时间|
|--dbKey|否|Integer| 分库标识|
|--groupId|否|String| 品牌商id|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|

```
 "companyId" : "String",
 "createId" : "String",
 "createName" : "String",
 "createDate" : "DateTime",
 "dbKey" : 0,
 "groupId" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
