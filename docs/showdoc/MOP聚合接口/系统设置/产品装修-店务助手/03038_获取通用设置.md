# 通用设置
 

**请求URL：** 
- `/config/v1/decorate/guide/common/action/get `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 商户标识|
|tokenId|否|String||

###请求参数Json格式
 
```
{
 "companyId" : "String",
 "tokenId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--companyId|否|String| 商户id|
|--isInherit|否|Integer| 是否继承 1 - 继承, 0 - 不继承|
|--isShowInvQty|否|Integer| 是否显示库存数 1 - 显示, 0 - 不显示|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : {
 "companyId" : "String",
 "isInherit" : 0,
 "isShowInvQty" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
