# 获取短信发送分页信息
 

**请求URL：** 
- `/mem/sys/marketing/sms/sendRecordList`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|sendStatus|否|String| 发送状态|
|startDate|否|DateTime| 开始日期|
|endDate|否|DateTime| 结束日期|
|sword|否|String||
|tokenId|否|String||
|id|否|String||
|orderField|否|String| 排序字段|
|orderSort|否|String| 排序方式|
|--sword|否|String||
|--pageIndex|否|Integer||
|--pageSize|否|Integer||
|--curPageNum|否|Integer||
|--totalPage|否|Integer||
|--totalCount|否|Integer||
|status|否|Integer| 状态|
|pageIndex|否|Integer| 页号|
|pageSize|否|Integer| 页大小|
|orderField|否|String| 商品排序字段|
|orderSort|否|String| 商品排序方式 desc 倒序 asc 正序|

### 请求参数Json格式
 
```
{
 "sendStatus" : "String",
 "startDate" : "DateTime",
 "endDate" : "DateTime",
 "sword" : "String",
 "tokenId" : "String",
 "id" : "String",
 "orderField" : "String",
 "orderSort" : "String",
 "status" : 0,
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--info|否|Long||
|--page|否|Object||
|----pageIndex|否|Integer| 页码|
|----pageSize|否|Integer| 显示记录数|
|----pageCount|否|Integer| 总页数|
|----totalCount|否|Long| 总记录数|
|----first|否|Boolean| 首页|
|----last|否|Boolean| 尾页|
|----content|否|List| 分页数据|
		|--mobile|否|String|手机号 |
		|--userName|否|String|会员名称 |
		|--msgTypeDesc|否|String|短信状态 A注册 R身份认证 F找回密码 M会员注册 C核销优惠券 R代运营商户注册 V会员储值卡消费验证码 S门店电话验证码 TS系统消息—任务中心报警 |
		|--msgContent|否|String|短信内容 |
		|--sendDate|否|DateTime|发送时间 |
		|--sendStatusDesc|否|String|发送状态 Y成功 N失败 |
		|--createName|否|String|操作用户 |
		|--errorMsg|否|String|异常原因 |
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|

```
 "content" : null
 }
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
