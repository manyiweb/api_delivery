# 经销商结算商品获取
 

**请求URL：** 
- `/config/dealer/item/get `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|distributorId|否|String| 经销商|
|pageIndex|否|Integer| 页码|
|pageSize|否|Integer| 每页多少数据|

###请求参数Json格式
 
```
{
 "distributorId" : "String",
 "pageIndex" : 0,
 "pageSize" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--pageIndex|否|Integer| 页码|
|--pageSize|否|Integer| 显示记录数|
|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|--first|否|Boolean| 首页|
|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|
|----id|否|Long||
|----itemId|否|String| 商品id|
|----itemCode|否|String| 商品编码|
|----specId|否|String| 规格id|
|----skuBarcode|否|String| sku码|
|----distributorId|否|Long| 经销商id|
|----calculationMethod|否|Integer| 计算方式 1按固定金额 0按百分比|
|----calculationValue|否|Double| 金额/百分比%|
|----price|否|Double| 零售价|
|----specName|否|String| 商品名称|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : {
 "pageIndex" : 0,
 "pageSize" : 0,
 "pageCount" : 0,
 "totalCount" : 0,
 "first" : true,
 "last" : true,
 "content" : [{
 "id" : 0,
 "itemId" : "String",
 "itemCode" : "String",
 "specId" : "String",
 "skuBarcode" : "String",
 "distributorId" : 0,
 "calculationMethod" : 0,
 "calculationValue" : 0,
 "price" : 0,
 "specName" : "String"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
