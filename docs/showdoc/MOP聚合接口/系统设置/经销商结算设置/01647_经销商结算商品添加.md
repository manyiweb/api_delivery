# 经销商结算商品添加
 

**请求URL：** 
- `/config/dealer/item/edit `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|distributorId|否|String| 经销商|
|reqDistributorItemInfos|否|List| 添加，修改|
|--id|否|Long| 编辑|
|--specId|否|String| 规格Id|
|--calculationMethod|否|Integer| 计算方式 1按固定金额 0按百分比|
|--calculationValue|否|Double| 金额/百分比%|
|delIds|否|List| 删除|

###请求参数Json格式
 
```
{
 "distributorId" : "String",
 "reqDistributorItemInfos" : [{
 "id" : 0,
 "specId" : "String",
 "calculationMethod" : 0,
 "calculationValue" : 0
 }],
 "delIds" : null
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
