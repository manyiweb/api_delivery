# 经销商结算获取
 

**请求URL：** 
- `/config/dealer/get `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|distributorId|否|String| 经销商|


###请求参数Json格式
 
```
{
 "distributorId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--distributorId|否|String| 经销商|
|--inSettlementSetting|否|Integer| 经销商结算设置继承商户 1是0否|
|--settlementRatio|否|Double| 经销商结算倍率（%）|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : {
 "distributorId" : "String",
 "inSettlementSetting" : 0,
 "settlementRatio" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
