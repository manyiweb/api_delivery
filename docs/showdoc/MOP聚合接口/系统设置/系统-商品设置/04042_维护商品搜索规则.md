# 维护条码搜索规则
 

**请求URL：** 
- `/config/barcodeSearchRule/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 商户id|
|isInherit|否|Object| 是否继承 1 - 继承, 0 - 不继承|
|barcodeSearchRuleVos|否|List| 维护的条码搜索规则|
|--status|否|Object| 是否启用 0 - 停用,1 - 启用|
|--ruleType|否|Object| 规则类型 1 - 搜索码, 2 - 重量码, 3 - 金额码, 4 - 正则表达式|
|--skuPrefix|否|String| sku码前缀|
|--skuStartDigit|否|Object| sku起始位数|
|--skuEndDigit|否|Object| sku结束位数|
|--customizeStartDigit|否|Object| 自定义规则起始位数|
|--customizeEndDigit|否|Object| 自定义规则结束位数|
|--amountStartDigit|否|Object| 金额起始位数|
|--amountEndDigit|否|Object| 金额结束位数|
|--amountDecimalCount|否|Integer| 金额码小数位|
|--weightDecimalCount|否|Integer| 重量码小数位|
|--regularSku|否|String| SKU编码正则表达式|
|--regularUnique|否|String| 唯一码正则表达式|
|--regularQuantity|否|String| 数量码正则表达式|
|--reverseDecimalCount|否|Integer| 反算小数位|
|searchRuleList|否|List| 商品搜索规则列表|
|--ruleName|否|String| 规则名称|
|--searchType|是|Integer| 搜索内容之间的关系, 1="且"关系,0="或"关系|
|--searchRuleDetailList|是|List| 搜索内容明细列表|
|----isLikeSearch|是|Boolean| 是否模糊搜索,true=是,false=否|
|----isSplitSearch|是|Boolean| 是否拆词搜索,true=是,false=否|
|----contextType|是|String| 搜索内容类型|
|productRule|否|Object| 商品规则|
|--notRepeatSku|否|Boolean| sku是否重复 true允许 false 不允许|
|--productAccept|否|Boolean| 开启商品受理|
|--openCostType|否|Boolean| 启用默认成本评估方法 true/false|
|--costType|否|Integer| 成本类型 1 标准成本，2 移动平均|
