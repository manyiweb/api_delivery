# 获取商品设置

**请求URL：** 
- `/config/productRule/get`

**请求方式：**
- ALL
- RequestBody


### 请求参数<业务参数>
 
无参数


### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--notRepeatSku|否|Boolean| sku不允许重复 true 否 false 是|
|--productAccept|否|Boolean| 是否开启商品受理 True 是 false 否|
|--openCostType|否|Boolean| 启用默认成本评估方法 true/false|
|--costType|否|Integer| 成本类型 1 标准成本，2 移动平均|
|--defaultOrderStatus|否|Integer| 默认点单上下架状态 0 下架 1 上架|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "notRepeatSku" : true,
 "productAccept" : true,
 "openCostType" : true,
 "costType" : 0,
 "defaultOrderStatus" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
