# 获取新增商品规则

**请求URL：** 
- `/config/getProductRule`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
无参数


### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--notRepeatSku|否|Boolean| sku是否重复 true允许 false 不允许|
|--productAccept|否|Boolean| 开启商品受理|
|--openCostType|否|Boolean| 启用默认成本评估方法 true/false|
|--costType|否|Integer| 成本类型 1 标准成本，2 移动平均|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "notRepeatSku" : true,
 "productAccept" : true,
 "openCostType" : true,
 "costType" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
