# 新增/编辑消息模板
 

**请求URL：** 
- `/config/wxTemple/add`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|
|isActive|是|Boolean| 是否活跃|
|wxsn|是|String| 小程序appid|
|mealMallWxsn|否|String| 点单小程序appid|
|usedInMemberApp|否|Boolean| 应用会员小程序|
|usedInMealApp|否|Boolean| 应用点单小程序|
|templateId|否|String| 模板消息id|
|actionType|是|String| 行为类型|
|items|否|List| 字段|
|--cKey|是|String| 字段编码|
|--cValue|否|String| 推送关键字|
|--customValue|否|String| 自定义内容|
|noticeTime|否|String| 通知时间点|
|expireNoticeDays|否|Integer| 过期通知天数|
|relatedSurveyTemplateName|否|String| 调查模板名称|
|relatedSurveyTemplateId|否|String| 调查模板id|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "isActive" : true,
 "wxsn" : "String",
 "mealMallWxsn" : "String",
 "usedInMemberApp" : true,
 "usedInMealApp" : true,
 "templateId" : "String",
 "actionType" : "String",
 "items" : [{
 "cKey" : "String",
 "cValue" : "String",
 "customValue" : "String"
 }],
 "noticeTime" : "String",
 "expireNoticeDays" : 0,
 "relatedSurveyTemplateName" : "String",
 "relatedSurveyTemplateId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
