# 产品列表
 

**请求URL：** 
- `/config/wxTemple/appList`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
无参数


### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--name|否|String| 微信账号名称|
|--accountId|否|String| appId，就是wxSn|
|--accountType|否|String| 账号类型 Wx公众号 WxApp小程序|
|--platformType|否|Integer| 0商城 1订货商城 2点餐商城 3点餐和商城2合一 4导购助手小程序 5小商店 6管理助手|
|--openAppid|否|String| 开放平台标识|
|--actionTypeList|否|List| 行为，如订货订单发货|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : [{
 "name" : "String",
 "accountId" : "String",
 "accountType" : "String",
 "platformType" : 0,
 "openAppid" : "String",
 "actionTypeList" : null
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
