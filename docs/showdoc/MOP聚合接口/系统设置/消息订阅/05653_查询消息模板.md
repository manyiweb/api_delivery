# 查询消息模板
 

**请求URL：** 
- `/config/wxTemple/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|wxsn|是|String| 模板消息类型: GUIDE|
|actionType|是|String| 行为|

### 请求参数Json格式
 
```
{
 "wxsn" : "String",
 "actionType" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long| id|
|--isActive|否|Boolean| 是否活跃|
|--templateId|否|String| 模板消息id|
|--actionType|否|String| 行为类型|
|--items|否|List| 详情|
|----cKey|否|String| 键|
|----cValue|否|String| 值|
|----customValue|否|String| 自定义内容|
|--noticeTime|否|String| 通知时间点|
|--expireNoticeDays|否|Integer| 过期通知天数|
|--mealMallWxsn|否|String| 点单小程序appid，零售小程序时有值|
|--usedInMemberApp|否|Boolean| 应用会员小程序|
|--usedInMealApp|否|Boolean| 应用点单小程序|
|--relatedSurveyTemplateName|否|String| 调查模板名称|
|--relatedSurveyTemplateId|否|String| 调查模板id|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "isActive" : true,
 "templateId" : "String",
 "actionType" : "String",
 "items" : [{
 "cKey" : "String",
 "cValue" : "String",
 "customValue" : "String"
 }],
 "noticeTime" : "String",
 "expireNoticeDays" : 0,
 "mealMallWxsn" : "String",
 "usedInMemberApp" : true,
 "usedInMealApp" : true,
 "relatedSurveyTemplateName" : "String",
 "relatedSurveyTemplateId" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
