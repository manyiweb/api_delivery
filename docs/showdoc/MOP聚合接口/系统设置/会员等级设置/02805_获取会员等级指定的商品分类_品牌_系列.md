# 分页获取会员等级指定的商品分类/品牌/系列
 

**请求URL：** 
- `/config/member/gradeset/types `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 业务ID|
|pageIndex|否|Integer| 分页页码|
|pageSize|否|Integer| 分页大小|
|sword|否|String| 搜索关键字|

###请求参数Json格式
 
```
{
 "id" : 0,
 "pageIndex" : 0,
 "pageSize" : 0,
 "sword" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--pageIndex|否|Integer| 页码|
|--pageSize|否|Integer| 显示记录数|
|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|--first|否|Boolean| 首页|
|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|
|----id|否|Long| id|
|----typeId|否|String| 分类/品牌/系列标识|
|----typeCode|否|String| 分类/品牌/系列编码|
|----typeName|否|String| 分类/品牌/系列名称|
|----typeCodeFull|否|String| 选项编码 完整|
|----gradeId|否|Long| 会员等级ID|
|----createId|否|String| 创建人标识|
|----createName|否|String| 创建人|
|----createDate|否|DateTime| 创建时间|
|----modifyId|否|String| 修改人标识|
|----modifyName|否|String| 修改人|
|----modifyDate|否|DateTime| 修改时间|
|----type|否|Integer| 类型（分类0/品牌1/系列2）|
|----dbKey|否|Integer| 分库标识|
|----groupId|否|String| 品牌商id|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
