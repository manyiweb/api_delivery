# 维护售后维修设置
 

**请求URL：** 
- `/config/aftersale/set `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List|数据|
|--type|否|Integer| 处理类型1，外观现象2，质检情况3，回访情况4，维修网点5|
|--afterSale|否|List| 数据|
|----id|否|Long||
|----name|否|String| 名称|
|delIds|否|List| 删除Id|

###请求参数Json格式
 
```
{
 "data" : [{
 "type" : 0,
 "afterSale" : [{
 "id" : 0,
 "name" : "String"
 }]
 }],
 "delIds" : null
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
