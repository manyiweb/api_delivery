# 保存-传输失败通知信息

**请求URL：** 
- `/config/transfer/failed/notice/saveTransferFailedInfo `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|noticeReqs|否|List| 传输异常通知列表|
|--id|否|Long| 主键|
|--taskTypeCode|否|String| 任务类型编码|
|--taskTypeName|否|String| 任务类型名称|
|--status|否|Boolean| 活跃状态 true启用 false停用|
|--noticeUsers|否|List| 通知用户列表|
|----staffId|否|String| 用户id,与表sysstaff关联|
|----userCode|否|String| 用户编码|
|----userName|否|String| 用户名称|
|--webhookIds|否|List| 通知webhook列表|

###请求参数Json格式
 
```
{
 "noticeReqs" : [{
 "id" : 0,
 "taskTypeCode" : "String",
 "taskTypeName" : "String",
 "status" : true,
 "noticeUsers" : [{
 "staffId" : "String",
 "userCode" : "String",
 "userName" : "String"
 }],
 "webhookIds" : null
 }]
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|String| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : "String",
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
