# 传输失败通知用户-保存

**请求URL：** 
- `/config/transfer/failed/notice/user/save `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|noticeId|否|Long| 传输失败通知id|
|noticeUserReqs|否|List| 保存通知用户集合|
|--id|否|Long| 通知用户id|
|--staffId|否|String| 用户id,与表sysstaff关联|
|--userCode|否|String| 用户编码|
|--userName|否|String| 用户名称|

###请求参数Json格式
 
```
{
 "noticeId" : 0,
 "noticeUserReqs" : [{
 "id" : 0,
 "staffId" : "String",
 "userCode" : "String",
 "userName" : "String"
 }]
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|String| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : "String",
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
