# 品牌业务员详情
 

**请求URL：** 
- `/config/brandSalesman/info `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|

###请求参数Json格式
 
```
{
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long| 主键标识|
|--companyId|否|String| 门店商户ID，与商户表syscompany相关联|
|--companyCode|否|String| 门店编码|
|--companyName|否|String| 门店名称|
|--brandId|否|String| 品牌id|
|--brandCode|否|String| 品牌code|
|--brandName|否|String| 品牌名称|
|--staffId|否|String| 业务员 id|
|--staffCode|否|String| 业务员 登录名|
|--staffName|否|String| 业务员 名称|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "companyId" : "String",
 "companyCode" : "String",
 "companyName" : "String",
 "brandId" : "String",
 "brandCode" : "String",
 "brandName" : "String",
 "staffId" : "String",
 "staffCode" : "String",
 "staffName" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
