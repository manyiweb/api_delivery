# 更新品牌业务员
 

**请求URL：** 
- `/config/brandSalesman/update `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 主键标识|
|companyId|否|String| 门店商户ID，与商户表syscompany相关联|
|brandId|否|String| 品牌id|
|staffId|否|String| 业务员 id|
|staffCode|否|String| 业务员 登录名|
|staffName|否|String| 业务员 名称|

###请求参数Json格式
 
```
{
 "id" : 0,
 "companyId" : "String",
 "brandId" : "String",
 "staffId" : "String",
 "staffCode" : "String",
 "staffName" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
