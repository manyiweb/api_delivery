# 新增 品牌业务员
 

**请求URL：** 
- `/config/brandSalesman/add `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 门店商户ID，与商户表syscompany相关联|
|brandSalesmanList|否|List| 品牌业务员list|
|--id|否|Long| 主键标识|
|--brandId|否|String| 品牌id|
|--staffId|否|String| 业务员 id|
|--staffCode|否|String| 业务员 登录名|
|--staffName|否|String| 业务员 名称|
|deleteList|否|List|需要删除的id集合|

###请求参数Json格式
 
```
{
 "companyId" : "String",
 "brandSalesmanList" : [{
 "id" : 0,
 "brandId" : "String",
 "staffId" : "String",
 "staffCode" : "String",
 "staffName" : "String"
 }],
 "deleteList" : null
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
