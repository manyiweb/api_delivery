# 

**请求URL：** 
- `/hr/invoiceHeaderr/add `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 主键id|
|type|否|String| 发票类型（Special/General）|
|unitCode|否|String| 开票单位编码|
|name|否|String| 开票名称|
|taxpayerNumber|否|String| 纳税人识别号|
|address|否|String| 单位地址|
|phone|否|String| 电话号码|
|bank|否|String| 开户银行|
|bankAccount|否|String| 银行账号|
|isDefault|否|Integer| 是否默认项|
|email|否|String| 邮箱|
|receivingAdress|否|String| 收件地址|
|receivingName|否|String| 收件人|
|receivingPhone|否|String| 手机号|
|taxpayerCertificateImage|否|String| 一般纳税人凭证图片URL|
|tokenId|否|String| 登录令牌|

###请求参数Json格式
 
```
{
 "id" : 0,
 "type" : "String",
 "unitCode" : "String",
 "name" : "String",
 "taxpayerNumber" : "String",
 "address" : "String",
 "phone" : "String",
 "bank" : "String",
 "bankAccount" : "String",
 "isDefault" : 0,
 "email" : "String",
 "receivingAdress" : "String",
 "receivingName" : "String",
 "receivingPhone" : "String",
 "taxpayerCertificateImage" : "String",
 "tokenId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
