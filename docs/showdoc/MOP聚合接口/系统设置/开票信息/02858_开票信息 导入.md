# 发票信息导入
 

**请求URL：** 
- `/file/import/invoiceHeaderr `

**请求方式：**
- POST
- FormData


**获取模板**
invoiceHeaderrAdd /Template/开票信息导入模板.xlsx



###请求参数<业务参数>

tokenId
file


###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|DataLine|否|Integer||
|downloadURL|否|String|错误数据的下载地址|
|successCount|否|Integer|成功总数量|
|ErrorCode|否|String|错误码|
|ResultString|否|String|返回结果|
|totalCount|否|Integer|导入总数|
|errorCount|否|Integer|错误总数量|


###返回参数Json格式
 
```
{
	"DataLine": null,
	"downloadURL": "https://upaiyun.reabam.com/export/开票信息错误数据导出1155efab8cd0435d8850510a73e71ef1.xlsx",
	"successCount": 2,
	"ErrorCode": "",
	"ResultString": "操作成功",
	"totalCount": 3,
	"errorCount": 1,
	"ResultInt": 0
}

```
