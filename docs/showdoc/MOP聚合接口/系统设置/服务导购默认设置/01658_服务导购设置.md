# 服务导购设置
 

**请求URL：** 
- `/config/guideset/edit`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 门店id|
|inGuideSetType|是|Integer| 是否继承品牌商|
|serviceGuideSetVos|是|List||
|--type|否|Integer| 类型|
|--guideSetDTO|否|Object| 服务核销导购默认|
|----cashDefault|是|Integer| 收银导购默认|
|----cancelDefault|是|Integer| 服务核销导购默认|
|----rechargeDefault|是|Integer| 充值默认服务导购|
|----deliveryDefault|是|Integer| 提货默认服务导购|
|isMultipleGuides|否|Integer| 是否允许选择多个服务导购，且支持分别设置计提比例|
|isSyncUpdateGuides|否|Integer| 是修改订单导购时同步修改购物车商品导购|
|guideMode|否|Integer| 导购模式 0：按订单 1：按商品|
|enableServiceGuideAlias|否|Boolean| 启用服务导购别名|
|serviceGuideAlias|否|String| 服务导购别名|

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "inGuideSetType" : 0,
 "serviceGuideSetVos" : [{
 "type" : 0,
 "guideSetDTO" : {
 "cashDefault" : 0,
 "cancelDefault" : 0,
 "rechargeDefault" : 0,
 "deliveryDefault" : 0
 }
 }],
 "isMultipleGuides" : 0,
 "isSyncUpdateGuides" : 0,
 "guideMode" : 0,
 "enableServiceGuideAlias" : true,
 "serviceGuideAlias" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
