# 新增/编辑 客服设置
 

**请求URL：** 
- `/config/customerservice/edit`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|type|是|Integer| 客服类型，0-微信小程序客服;1-店务助手导购客服;2-智齿客服;3-企微客服|
|roleId|否|String| 商户角色ID，对应srole表，TypeCode='R001'|
|alias|否|String| 客服别名|
|isPhone|否|Integer| 是否显示手机号(0-不显示;1-显示)|
|phone|否|String| 客服手机号|
|isInherit|否|Boolean| 是否继承品牌|
|companyId|是|String| 门店ID|
|sobotUrl|否|String| 智齿客服url|
|sobtConfig|否|String| 智齿配置参数|
|wecomCustomerServiceUrl|否|String| 企微客服链接|
|wecomId|否|String| 企微ID|

### 请求参数Json格式
 
```
{
 "type" : 0,
 "roleId" : "String",
 "alias" : "String",
 "isPhone" : 0,
 "phone" : "String",
 "isInherit" : true,
 "companyId" : "String",
 "sobotUrl" : "String",
 "sobtConfig" : "String",
 "wecomCustomerServiceUrl" : "String",
 "wecomId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
