# 智齿客服页面获取会员信息

**请求URL：** 
- `/mem/member/info/zhichi`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
无参数


### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--memberId|否|String| 会员id|
|--memberName|否|String| 会员名称|
|--companyName|否|String| 专属门店|
|--gradeName|否|String| 会员等级|
|--birthday|否|String| 会员生日|
|--bindCompanyName|否|String| 绑定门店|
|--phone|否|String| 会员手机号|
|--memberServices|否|List| 会员服务|
|--memberBenefits|否|List| 会员权益卡|
|--addressName|否|String| 地址信息 -- 收件人|
|--addressPhone|否|String| 地址信息 -- 电话|
|--address|否|String| 地址信息|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||

 },

}
