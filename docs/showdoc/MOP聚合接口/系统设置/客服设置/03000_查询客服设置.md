# 功能描述: 查询客服设置
 

**请求URL：** 
- `/config/customerservice/get `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 商户标识|

###请求参数Json格式
 
```
{
 "companyId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--type|否|Integer| 客服类型，0-微信小程序客服;1-店务助手导购客服;2-智齿客服|
|--roleId|否|String| 公共客户角色ID，商户角色对应 srole表 TypeCode=‘R001’|
|--roleCode|否|String| 角色编码|
|--roleName|否|String| 角色名称|
|--alias|否|String| 客服别名|
|--isPhone|否|Integer| 是否显示手机号(0-不显示;1-显示)|
|--phone|否|String| 客服手机号|
|--isInherit|否|Boolean| 是否继承品牌|
|--sobotUrl|否|String| 智齿客服url|
|--sobtConfig|否|String| 智齿客服配置参数|
|--wecomCustomerServiceUrl|否|String| 企微客服链接|
|--wecomId|否|String| 企微ID|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "type" : 0,
 "roleId" : "String",
 "roleCode" : "String",
 "roleName" : "String",
 "alias" : "String",
 "isPhone" : 0,
 "phone" : "String",
 "isInherit" : true,
 "sobotUrl" : "String",
 "sobtConfig" : "String",
	 "wecomCustomerServiceUrl" : "String",
 "wecomId" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
