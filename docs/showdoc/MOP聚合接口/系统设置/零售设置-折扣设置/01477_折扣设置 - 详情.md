# 折扣设置 - 详情

**请求URL：** 
- `/config/discount_set/get `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|roleId|是|String| 角色ID|
|discountTypeCode|是|String| 折扣类型 商品行折扣-ItemDiscount 整单折扣-OrderDiscount|

###请求参数Json格式
 
```
{
 "roleId" : "String",
 "discountTypeCode" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--roleId|否|String| 角色ID|
|--id|否|Long| 折扣设置标识|
|--discountWay|否|Double| 折扣方式编码 折扣方式 0-固定金额范围 1-固定百分比|
|--amount|否|Double| 固定金额|
|--percentage|否|Double| 固定比值(%)|
|--createId|否|String| 创建人|
|--createName|否|String| 创建人名称|
|--createDate|否|DateTime| 创建时间|
|--modifyId|否|String| 修改人|
|--modifyName|否|String| 修改人名称|
|--modifyDate|否|DateTime| 修改时间|
|--groupId|否|String| 品牌商标识|
|--discountTypeCode|否|String| 折扣类型编码 商品行折扣-ItemDiscount 整单折扣-OrderDiscount|
|--discountTypeName|否|String| 折扣类型描述|
|--status|否|Integer| 启用状态 1启用 0停用|
|msg|否|String| 消息|
|code|否|String| 业务代码|


###返回参数Json格式
 
```
{
 "data" : {
 "roleId" : "String",
 "id" : 0,
 "discountWay" : 0,
 "amount" : 0,
 "percentage" : 0,
 "createId" : "String",
 "createName" : "String",
 "createDate" : "DateTime",
 "modifyId" : "String",
 "modifyName" : "String",
 "modifyDate" : "DateTime",
 "groupId" : "String",
 "discountTypeCode" : "String",
 "discountTypeName" : "String",
 "status" : 0
 },
 "msg" : "String",
 "code" : "String"
}
```
