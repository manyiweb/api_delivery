# 功能描述: 编辑商品限购量
 

**请求URL：** 
- `/config/purchaseLimit/edit `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|addPurchaseLimits|否|List| 新增的商品Sku集合|
|--specId|否|String| 商品规格码ID|
|--amount|否|String| 商品限购数量（支持4位小数，必须大于0）|
|--beginDate|否|DateTime| 开始时间|
|--endDate|否|DateTime| 结束时间|
|delSpecIds|否|List| 删除的商品Sku码集合|
|companyId|否|String|门店id |
|itemLimitEnable|否|Boolean|商品限购是否启用 |
|limitBy|否|Integer|0：按人限购，1：按单限购 |

###请求参数Json格式
 
```
{
 "addPurchaseLimits" : [{
 "specId" : "String",
 "amount" : "String",
 "beginDate" : "DateTime",
 "endDate" : "DateTime"
 }],
 "delSpecIds" : null,
 "companyId" : "String",
 "itemLimitEnable" : true,
 "limitBy" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
