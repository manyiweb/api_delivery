# 功能描述: 查询商品限购量设置（商品支持关键字搜索和分页）
 

**请求URL：** 
- `/config/purchaseLimit/list `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String|门店id |
|sword|否|String|查询关键字 |
|pageIndex|否|Integer| 页号|
|pageSize|否|Integer| 页大小|
|orderField|否|String| 商品排序字段|
|orderSort|否|String| 商品排序方式 desc 倒序 asc 正序|

###请求参数Json格式
 
```
{
 "companyId" : "String",
 "sword" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--itemLimitEnable|否|Boolean|商品限购是否启用 |
|--limitBy|否|Integer|0：按人限购，1：按单限购 |
|--items|否|Object||
|----pageIndex|否|Integer| 页码|
|----pageSize|否|Integer| 显示记录数|
|----pageCount|否|Integer| 总页数|
|----totalCount|否|Long| 总记录数|
|----first|否|Boolean| 首页|
|----last|否|Boolean| 尾页|
|----content|否|List| 分页数据|
|------id|否|Long| 主键标识|
|------companyId|否|String| 门店id|
|------specId|否|String| 规格id，关联mitemspec表|
|------skuBarcode|否|String| 商品码|
|------amount|否|Double| 限购数量|
|------beginDate|否|DateTime| 开始时间|
|------endDate|否|DateTime| 结束时间|
|------itemId|否|String| 商品标识，对应mitem表ItemID|
|------itemCode|否|String| 商品编码|
|------itemName|否|String| 商品名称[规格名称]|
|------unit|否|String| 商品基本单位|
|------modifyId|否|String| 修改人id|
|------modifyName|否|String| 修改人|
|------modifyDate|否|DateTime| 修改时间|
|------createId|否|String| 创建人id|
|------createName|否|String| 创建人|
|------createDate|否|DateTime| 创建时间|
|------limitBy|否|Integer|0：按人限购，1：按单限购 |
|------dbKey|否|Integer| 分库标识|
|------groupId|否|String| 品牌商id|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
