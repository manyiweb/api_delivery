# 获取商户邀请奖励设置
 

**请求URL：** 
- `/hr/company/invite/set/detail `

**请求方式：**
- ALL
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|gradeCode|否|String| 商户等级编码|
|openGradeN|否|Integer| 是否读取非会员等级的设置(从开启等级切换到关闭等级时取数可用) 1是0否|

###请求参数Json格式
 
```
{
 "gradeCode" : "String",
 "openGradeN" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--openReward|否|Integer| 启用商户奖励 1是0否|
|--openGrade|否|Integer| 按商户等级设置信息 1是0否|
|--rewardSet|否|Object| 商户邀请奖励设置|
|----days|否|Long| 奖励到账天数|
|----openIntegral|否|Integer| 赠送积分|
|----openIntegralLadder|否|Integer| 开启积分阶梯 1是0否(不开启为每满)|
|----integralSets|否|List| 积分设置|
|------id|否|Long| id|
|------amount|否|Double| 金额|
|------integral|否|Double| 送积分|
|----gradeCode|否|String| 商户等级编码|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : {
 "openReward" : 0,
 "openGrade" : 0,
 "rewardSet" : {
 "days" : 0,
 "openIntegral" : 0,
 "openIntegralLadder" : 0,
 "integralSets" : [{
 "id" : 0,
 "amount" : 0,
 "integral" : 0
 }],
 "gradeCode" : "String"
 }
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
