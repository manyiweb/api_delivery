# 按路线分货报表
 

**请求URL：** 
- `/b2b/orderSplit/report/list`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|delivery_whs_id|否|List||
|company_id|否|List||
|spec_id|否|List||
|line_id|否|List||
|order_doc_type_code|否|List||
|seller_model|否|List||
|createDate|否|Object||
|--start|否|DateTime||
|--end|否|DateTime||
|dimension|否|Integer| 维度 1 仓库物料 2路线 3门店|
|id|否|String||
|pageSize|否|Integer||
|pageNo|否|Integer||
|sortField|否|String||
|sortDirection|否|String||
|viewId|否|String||

### 请求参数Json格式
 
```
{
 "delivery_whs_id" : null,
 "company_id" : null,
 "spec_id" : null,
 "line_id" : null,
 "order_doc_type_code" : null,

 "createDate" : {
 "start" : "DateTime",
 "end" : "DateTime"
 },
 "dimension" : 0,
 "id" : "String",
 "pageSize" : 0,
 "pageNo" : 0,
 "sortField" : "String",
 "sortDirection" : "String",
 "viewId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--companyList|否|List| 门店列表|
|----companyId|否|String||
|----companyCode|否|String||
|----companyName|否|String||
|--specList|否|List| 门店商品信息|
|----lineId|否|String| 路线|
|----deliveryWhsId|否|String| 发货仓id|
|----deliveryWhsName|否|String| 仓库|
|----companyId|否|String| 门店id|
|----companyCode|否|String| 门店编码|
|----companyName|否|String| 门店名称|
|----itemCode|否|String| 物料编码|
|----itemName|否|String| 物料名称|
|----specId|否|String| 规格名称|
|----skuBarcode|否|String| 规格名称|
|----specName|否|String| 规格名称|
|----itemUnit|否|String| 大单位|
|----itemQuantity|否|Double| 大单位|
|----quantity|否|Double| 总数|
|----companyItemMap|否|Map| 门店商品信息/或路线商品信息|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
