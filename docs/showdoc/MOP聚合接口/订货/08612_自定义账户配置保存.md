# 自定义账户配置保存

**请求URL：** 
- `/config/b2b/custom/account/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|String| 主键|
|accountId|否|Long| 自定义账户id|
|openWithdrawTime|否|Boolean| 开启提现时间配置|
|withdrawTime|否|List| 1,2,3,4.... 表示日|

### 请求参数Json格式
 
```
{
 "id" : "String",
 "accountId" : 0,
 "openWithdrawTime" : true,
 "withdrawTime" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
