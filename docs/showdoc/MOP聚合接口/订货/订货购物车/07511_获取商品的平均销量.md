# 获取商品的平均销量

**请求URL：** 
- `/b2b/mall/shopCart/getItemAverageSale`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|averageSalesDay|否|Integer| 天平均销量 (天数)|
|itemId|否|String| 商品id|
|specId|否|String| 规格id|
|companyId|否|String| 门店id|

### 请求参数Json格式
 
```
{
 "averageSalesDay" : 0,
 "itemId" : "String",
 "specId" : "String",
 "companyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--itemId|否|String| 商品id|
|--averageSales|否|Double| 平均销量|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "itemId" : "String",
 "averageSales" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
