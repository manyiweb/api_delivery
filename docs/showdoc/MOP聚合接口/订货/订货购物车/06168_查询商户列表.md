# 查询资金管理账户列表
 

**请求URL：** 
- `/b2b/findCompanyList `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>

|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|auditStatus|是|String| 审核状态|
|pageIndex|是|String| 页码|
|pageSize|是|String| 容量|
|sword|否|String| 关键字|

###请求参数Json格式
 
```
{
 "pageIndex": 1,
 "pageSize": 20,
 "sword": "",
 "auditStatus": "Y",
 "tokenId": "0eb66be65b1a414fa318baca392de217"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|TotalCount|否|Int| 数据数量|
|PageSize|否|String| 页码|
|PageCount|否|String| 页容量|
|DataLine|否|String| 数据|
|ErrorCode|否|String| 链路跟踪id|
|PageIndex|否|String| 链路跟踪id|
|ResultString|否|String| 链路跟踪id|
|ResultInt|否|String| 链路跟踪id|
