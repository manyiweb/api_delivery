# 获得防呆设置

**请求URL：** 
- `/b2b/foolproof/setting`

**请求方式：** 
- `POST`
- `RequestBody`


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 门店ID|

### 请求参数Json格式
 
```
{
 "companyId":"String"
}
```

### 响应参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--enableB2bOrderFoolproof|否|Boolean| 启用订货数量防呆|
|--enablePurchaseFoolproof|否|Boolean| 启用采购数量防呆|
|--enableCheckvouchFoolproof|否|Boolean| 启用盘点数量防呆|
|--enableWhsinoutFoolproof|否|Boolean| 启用出入库数量防呆|
|--enableAllotFoolproof|否|Boolean| 启用调拨数量防呆|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 响应参数Json格式
 
```
{
 "data":{
 "enableB2bOrderFoolproof":true,
 "enablePurchaseFoolproof":true,
 "enableCheckvouchFoolproof":true,
 "enableWhsinoutFoolproof":true,
 "enableAllotFoolproof":true,
 "companyId":"String",
 },
 "msg":"String",
 "code":"String",
 "exceptionStackInfo":"String",
 "traceId":"String"
}
```
