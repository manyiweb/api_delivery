# 订单下单前防呆检查-V2

**请求URL：** 
- `/b2b/foolproof/check`

**请求方式：** 
- `POST`
- `RequestBody`


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 门店ID|
|items|是|List| 需要检查的商品|
|--specId|是|String| 规格ID|
|--quantity|是|Double| 订货数量|
|type|否|String| purchase(采购) b2bOrder(订货) checkvouch(盘点) whsinout(出入库) allot(调拨)|

### 请求参数Json格式
 
```
{
 "companyId":"String",
 "items":[{
 "specId":"String",
 "quantity":0
 }],
 "type":"String"
}
```

### 响应参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--pass|否|Boolean| 是否通过|
|--invalidItems|否|List| 异常商品|
|----itemCode|否|String| 商品编码|
|----sku|否|String| 商品sku|
|----itemName|否|String| 商品名称|
|----unit|否|String| 单位|
|----quantityLimitPerOrder|否|Double| 订货量每单上限|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 响应参数Json格式
 
```
{
 "data":{
 "pass":true,
 "invalidItems":[{
 "itemCode":"String",
 "sku":"String",
 "itemName":"String",
 "unit":"String",
 "quantityLimitPerOrder":0
 }]
 },
 "msg":"String",
 "code":"String",
 "exceptionStackInfo":"String",
 "traceId":"String"
}
```
