# 获得订货数量防呆设置详情
 

**请求URL：** 
- `/b2b/order/foolproof/manage/getFoolproofSettingDetail/{companyId}`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| |

### 请求参数Json格式
 
```
{
 "companyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long||
|--inheritByGroup|否|Boolean| 是否继承品牌|
|--enableFoolproof|否|Boolean| 是否启用防呆|
|--companyId|否|String| 配置门店ID或者品牌ID|
|--items|否|List| 商品限制配置明细项|
|----id|否|Long||
|----itemId|否|String| 商品ID|
|----specId|否|String| 规格ID|
|----itemCode|否|String| 商品编码|
|----sku|否|String| 商品sku|
|----itemName|否|String| 商品名称|
|----quantityLimitPerOrder|否|Double| 订货量每单上限|
|----unit|否|String| 商品单位|
|----companyId|否|String| 设置门店|
|----modifyName|否|String| 更新人|
|----modifyDate|否|DateTime| 更新时间|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "inheritByGroup" : true,
 "enableFoolproof" : true,
 "companyId" : "String",
 "items" : [{
 "id" : 0,
 "itemId" : "String",
 "specId" : "String",
 "itemCode" : "String",
 "sku" : "String",
 "itemName" : "String",
 "quantityLimitPerOrder" : 0,
 "unit" : "String",
 "companyId" : "String",
 "modifyName" : "String",
 "modifyDate" : "DateTime"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
