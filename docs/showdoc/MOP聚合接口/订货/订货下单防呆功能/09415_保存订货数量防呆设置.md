# 保存订货数量防呆设置
 

**请求URL：** 
- `/b2b/order/foolproof/manage/saveFoolproofSetting`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 配置门店ID或者品牌ID|
|inheritByGroup|是|Boolean| 是否继承品牌|
|enableFoolproof|是|Boolean| 是否启用防呆|
|items|否|List| 商品限制列表|
|--itemId|是|String| 商品ID|
|--specId|是|String| 规格ID|
|--quantityLimitPerOrder|是|Double| 订货量每单上限|

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "inheritByGroup" : true,
 "enableFoolproof" : true,
 "items" : [{
 "itemId" : "String",
 "specId" : "String",
 "quantityLimitPerOrder" : 0
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
