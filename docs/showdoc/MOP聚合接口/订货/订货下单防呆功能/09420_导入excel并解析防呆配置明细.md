# 导入excel并解析防呆配置明细
 

**请求URL：**
- `/b2b/order/foolproof/excel/explainExcel`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|file|否|文件|文件|


### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--id|否|Long||
|--itemId|否|String| 商品ID|
|--specId|否|String| 规格ID|
|--itemCode|否|String| 商品编码|
|--sku|否|String| 商品sku|
|--itemName|否|String| 商品名称|
|--quantityLimitPerOrder|否|Double| 订货量每单上限|
|--unit|否|String| 商品单位|
|--companyId|否|String| 设置门店|
|--modifyName|否|String| 更新人|
|--modifyDate|否|DateTime| 更新时间|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "id" : 0,
 "itemId" : "String",
 "specId" : "String",
 "itemCode" : "String",
 "sku" : "String",
 "itemName" : "String",
 "quantityLimitPerOrder" : 0,
 "unit" : "String",
 "companyId" : "String",
 "modifyName" : "String",
 "modifyDate" : "DateTime"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
