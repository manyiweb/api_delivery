# 复制订货数量防呆设置
 

**请求URL：** 
- `/b2b/order/foolproof/manage/copyFoolproofSetting`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|sourceCompanyId|是|String| 源门店ID|
|targetCompanyId|是|String| 目标门店ID|

### 请求参数Json格式
 
```
{
 "sourceCompanyId" : "String",
 "targetCompanyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
