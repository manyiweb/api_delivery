# 龙存管提现
 

**请求URL：** 
- `/b2b/Withdraw/save/lcg`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 商户id|
|withdrawBalance|是|Double| 提现金额|
|accountType|是|Integer| 1余额 2账号|
|accountId|否|Long| 提现账户id|

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "withdrawBalance" : 0,
 "accountType" : 0,
 "accountId" : 0
}
```
