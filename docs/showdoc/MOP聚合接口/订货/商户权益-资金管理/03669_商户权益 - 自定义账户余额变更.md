# 商户权益 - 自定义账户余额变更
 

**请求URL：** 
- `/b2b/funds/custom/account/change `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|lineId|否|Long| 导入行id|
|accountId|否|Long| 账户ID|
|companyId|否|String| 门店ID|
|money|否|Double| 变更金额|
|type|否|String| 交易类型|
|remark|否|String| 交易备注|
|sourceCode|否|String| 来源单号|
|createId|否|String| 创建人id|
|createName|否|String| 创建人名称|
|createDate|否|DateTime| 创建时间|
|posingDate|否|DateTime| 过账日期|
|activeDate|否|DateTime| 有效日期|
|transCodeList|否|List| 要扣减的流水号|

###请求参数Json格式
 
```
{
 "lineId" : 0,
 "accountId" : 0,
 "companyId" : "String",
 "money" : 0,
 "type" : "String",
 "remark" : "String",
 "sourceCode" : "String",
 "createId" : "String",
 "createName" : "String",
 "createDate" : "DateTime",
 "posingDate" : "DateTime",
 "activeDate" : "DateTime",
 "transCodeList" : null
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
