# 返利账户费用类型列表

**请求URL：** 
- `/b2b/funds/custom/account/rebateTransType`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|changeTypeCode|否|String| 变更类型编码 recharge-充值, deduction-扣款|

### 请求参数Json格式
 
```
{
 "changeTypeCode" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--transType|否|String| 费用类型|
|--transTypeCode|否|String| 费用类型编码|
|--changeTypeCode|否|String| 变更类型编码|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "transType" : "String",
 "transTypeCode" : "String",
 "changeTypeCode" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
