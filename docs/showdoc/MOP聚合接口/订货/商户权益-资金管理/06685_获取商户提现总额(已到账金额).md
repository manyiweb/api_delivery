# 获取商户提现总额(已到账金额)
 

**请求URL：** 
- `/b2b/Withdraw/balance/sum`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 商户id|
|pageIndex|否|Integer||
|pageSize|否|Integer||
|orderField|否|String||
|orderSort|否|String||

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "withdrawOrderId" : "String",
 "withdrawBankName" : "String",
 "withdrawBalance" : 0,
 "withdrawServePay" : 0,
 "withdrawApplyState" : 0,
 "withdrawApplyTime" : "DateTime",
 "examineRemark" : "String",
 "attachmentPath" : "String",
 "serverRate" : 0,
 "withdrawType" : 0,
 "accountId" : 0,
 "withdrawBankCardNum" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Double||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : 0,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
