# 获取商户提现流水
 

**请求URL：** 
- `/b2b/Withdraw/detail/all`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 商户id|
|withdrawApplyState|否|Integer| 订单申请状态 0为待审核 1为已到账 -1为已拒绝|
|beginDate|否|DateTime| 范围查询 起始时间|
|endDate|否|DateTime| 范围查询 截至时间|
|pageIndex|否|Integer||
|pageSize|否|Integer||
|orderField|否|String||
|orderSort|否|String||

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "withdrawApplyState" : 0,
 "beginDate" : "DateTime",
 "endDate" : "DateTime",
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--respPage|否|Object||
|----pageIndex|否|Integer||
|----pageSize|否|Integer||
|----pageCount|否|Integer||
|----totalCount|否|Long||
|----first|否|Boolean||
|----last|否|Boolean||
|----content|否|List||
|------id|否|Long| 提现明细主键id|
|------companyId|否|String| 商户id|
|------withdrawOrderId|否|String| 提现单号|
|------withdrawBankName|否|String| 提现银行名|
|------withdrawBalance|否|Double| 实际到账的金额|
|------withdrawServePay|否|Double| 提现所需的服务费|
|------withdrawSum|否|Double| 总提现金额 （服务费+实际到账金额）|
|------withdrawApplyState|否|Integer| 订单申请状态 0为待审核 1为已到账 -1为已拒绝|
|------withdrawApplyStateStr|否|String| 订单申请的状态文字|
|------withdrawApplyTime|否|DateTime| 提现申请的时间|
|------examineRemark|否|String| 审核备注|
|------attachmentPath|否|String| 附件路径|
|------withdrawType|否|Integer| 提现类型 1为 余额提现 2为 返利账号提现|
|------accountId|否|Long| 提现账号id|
|------withdrawBankCardNum|否|String| 提现银行卡号|
|------withdrawPastTime|否|DateTime| 到账时间|
|--withdrawBalance|否|Double||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
