# 获取当前返利账户可用金额

**请求URL：** 
- `/b2b/funds/custom/account/rebateBalance `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 商户标|
|TransTypeCode|否|String| 类型，前端写好的参数给的大写开头|
|StarDate|否|DateTime| 开始日期|
|EndDate|否|DateTime| 结束日期|
|accountId|否|Long| 账户标识|
|allAccount|否|Boolean| 是否读取全部内容|
|status|否|Integer| 0:生效中 1：已失效|
|sword|否|String||
|tokenId|否|String||
|id|否|String||
|orderField|否|String| 排序字段|
|orderSort|否|String| 排序方式|
|searchBeans|否|List| 高级筛选条件|
|--typeCode|否|String||
|--typeName|否|String||
|--dataType|否|String||
|--isSingle|否|String||

|--items|否|List||

|----itemValue|否|String||
|----minValue|否|String||
|----maxValue|否|String||
|----isCustom|否|String||
|----isRange|否|String||
|----isSelect|否|String||
|--current|否|Object||
|----itemName|否|String||
|----itemValue|否|String||
|----minValue|否|String||
|----maxValue|否|String||
|----isCustom|否|String||
|----isRange|否|String||
|----isSelect|否|String||
|--sword|否|String||
|--pageIndex|否|Integer||
|--pageSize|否|Integer||
|--curPageNum|否|Integer||
|--totalPage|否|Integer||

|status|否|Integer| 状态|

|orderField|否|String| 商品排序字段|
|orderSort|否|String| 商品排序方式 desc 倒序 asc 正序|

###返回参数

|:---- |:---|:----- |----- |
