# 审核列表

**请求URL：** 
- `/b2b/datatable/withdraw/list/{source}`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyIds|否|List| 商户|
|keyword|否|String| 模糊搜索|
|withdrawApplyState|否|List| 订单申请状态|
|withdrawApplyTime|否|Object| 提现申请时间|
|--start|否|DateTime||
|--end|否|DateTime||
|withdrawPastTime|否|Object| 提现通过时间|
|--start|否|DateTime||
|--end|否|DateTime||
|joiningTraderCode|否|List| 所属加盟商|
|companyGID|否|List| 商户组|
|merchantsAreafCodes|否|String| 所属区域|
|distributorCode|否|List| 所属经销商|
|merchantsTypeCode|否|List| 商户类型|
|id|否|String||
|pageSize|否|Integer||
|pageNo|否|Integer||
|sortField|否|String||
|sortDirection|否|String||
|viewId|否|String||

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--content|否|List||
|----id|否|Long| 主键|
|----companyId|否|String| 门店id|
|----companyCode|否|String| 商户编码|
|----companyName|否|String| 商户名称|
|----withdrawOrderId|否|String| 提现订单id|
|----withdrawBankName|否|String| 提现银行名|
|----withdrawBalance|否|Double| 提现金额|
|----withdrawServePay|否|Double| 服务费金额|
|----withdrawApplyState|否|String| 订单申请状态 0待审核 1已到账 -1已拒绝|
|----withdrawApplyTime|否|DateTime| 提现申请的时间|
|----examineRemark|否|String| 审核备注|
|----attachmentPath|否|String| 附件路径|
|----accountId|否|String| 提现账户id|
|----withdrawBankCardNum|否|String| 提现银行卡号|
|----accountType|否|String| 账号类型|
|----withdrawPastTime|否|DateTime| 到账时间|
|----withdrawType|否|String| 提现类型 0线下 1线下|
|--pageSize|否|Integer||
|--pageNo|否|Integer||
|--total|否|Long||
|--totalPage|否|Integer||
|--hasNextPage|否|Boolean||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
