# 获取提现配置

**请求URL：** 
- `/config/b2b/withdraw/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 门店id|

### 请求参数Json格式
 
```
{
 "companyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|String| 主键|
|--isInherit|否|Integer| 是否继承品牌|
|--ifOpenWithdraw|否|Integer| 是否开启提现支付设置 0否 1是|
|--configStr|否|String| 参数配置|
|--createDate|否|DateTime| 创建时间|
|--groupId|否|String| 品牌id|
|--companyId|否|String| 门店id|
|--createId|否|String||
|--createName|否|String||
|--modifyId|否|String||
|--modifyName|否|String||
|--modifyDate|否|DateTime||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "id" : "String",
 "isInherit" : 0,
 "ifOpenWithdraw" : 0,
 "configStr" : "String",
 "createDate" : "DateTime",
 "groupId" : "String",
 "companyId" : "String",
 "createId" : "String",
 "createName" : "String",
 "modifyId" : "String",
 "modifyName" : "String",
 "modifyDate" : "DateTime"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
