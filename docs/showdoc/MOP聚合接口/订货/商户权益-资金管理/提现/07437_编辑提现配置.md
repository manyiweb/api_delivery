# 编辑提现配置

**请求URL：** 
- `/config/b2b/withdraw/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|String| 主键|
|isInherit|否|Integer| 是否继承品牌|
|ifOpenWithdraw|否|Integer| 是否开启提现支付设置|
|configStr|否|String| 参数配置|
|companyId|否|String| 门店id|

### 请求参数Json格式
 
```
{
 "id" : "String",
 "isInherit" : 0,
 "ifOpenWithdraw" : 0,
 "configStr" : "String",
 "companyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
