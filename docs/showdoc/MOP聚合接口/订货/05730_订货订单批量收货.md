# 订货订单批量收货

**请求URL：** 
- `/b2b/order/batch/receiving2`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|items|是|List| 明细|
|--itemId|是|String| 商品Id|
|--specId|是|String| 规格Id|
|--quantity|是|Double| 收货数量|
|--unit|否|String| 收货单位|
|--remark|否|String| 备注|
|--bomItems|否|List| bom商品|
|--barCodes|否|List| 唯一码|
|--batchList|否|List| 批次信息|
|orderIds|是|List| 订货单Id|

### 请求参数Json格式
 
```
{
 "items" : [{
 "itemId" : "String",
 "specId" : "String",
 "quantity" : 0,
 "unit" : "String",
 "remark" : "String",
 "bomItems" : null,
 "barCodes" : null,
 "batchList" : null
 }],
 "orderIds" : null
}
```
