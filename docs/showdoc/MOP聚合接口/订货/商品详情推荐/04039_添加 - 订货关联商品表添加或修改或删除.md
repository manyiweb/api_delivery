# 零售发票表添加或修改

**请求URL：** 
- `/hr/retail/invoice/saveOrUpdate`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long|id |
|invoiceType|是|String|发票类型 |
|titleType|是|String|抬头类型 |
|invoiceTitle|是|String|发票抬头 |
|taxNo|否|String|税号 |
|openAccountBank|否|String|开户银行 |
|bankAccount|否|String|银行账号 |
|companyAddress|否|String|企业地址 |
|companyPhone|否|String|企业电话 |
|status|否|String|发票状态 |
|invoiceContent|否|String|发票内容 |
|noticePhone|否|String|通知手机号 |
|noticeEmail|否|String|通知邮箱 |
|makeOutType|否|String|开票类型，see |
|orderIds|是|List| 订单列表|
|applyType|否|Integer| 申请类型 默认蓝票 1 红冲2|
|companyId|否|String|开票的门店id |
|orderNos|否|List|订单编号s |

### 请求参数Json格式
 
```
{
 "id" : 0,
 "invoiceType" : "String",
 "titleType" : "String",
 "invoiceTitle" : "String",
 "taxNo" : "String",
 "openAccountBank" : "String",

 "companyAddress" : "String",
 "companyPhone" : "String",
 "status" : "String",
 "invoiceContent" : "String",
 "noticePhone" : "String",
 "noticeEmail" : "String",
 "makeOutType" : "String",
 "orderIds" : null,
 "applyType" : 0,
 "companyId" : "String",
 "orderNos" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--successCount|否|Integer||
|--errorCount|否|Integer||
|--errorInfoList|否|List||
|----msg|否|String||
|----orderNo|否|String||
|----fullErrorMsg|否|String||
|--orderIds|否|List||
|--invoiceId|否|Long|此次开票id |
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
