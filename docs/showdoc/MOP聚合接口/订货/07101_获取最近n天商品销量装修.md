# 获取配置
 

**请求URL：** 
- `/b2b/itemSales/config/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|groupId|否|String||
|companyId|否|String||
|tokenId|否|String||
|openId|否|String||

### 请求参数Json格式
 
```
{
 "groupId" : "String",
 "companyId" : "String",
 "tokenId" : "String",
 "openId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long||
|--openShowItemSales|否|Boolean| 是否显示|
|--days|否|Integer| 天数|
|--createId|否|String||
|--createName|否|String||
|--createDate|否|DateTime||
|--modifyId|否|String||
|--modifyName|否|String||
|--modifyDate|否|DateTime||
|--dbKey|否|Integer||
|--groupId|否|String||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "openShowItemSales" : true,
 "days" : 0,
 "createId" : "String",
 "createName" : "String",
 "createDate" : "DateTime",
 "modifyId" : "String",
 "modifyName" : "String",
 "modifyDate" : "DateTime",
 "dbKey" : 0,
 "groupId" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
