# 订单行使用的优惠券列表

**请求URL：** 
- `/b2b/sales/order/product/coupon/use `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderItemid|否|String| 订单行标识|
|orderId|否|String| 订单标识|

###请求参数Json格式
 
```
{
 "orderItemid" : "String",
 "orderId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--couponId|否|String| 优惠券ID|
|--couponCode|否|String| 优惠券编码|
|--couponName|否|String| 优惠券名称|
|--couponType|否|Integer| 优惠类型 ： 0为现金劵，1为折扣劵 ,2为兑换券|
|--couponTypeName|否|String| 优惠券类型|
|--useScene|否|Integer| 使用场景 0全场券 1商品券|
|--useQty|否|Long| 使用数量|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : [{
 "couponId" : "String",
 "couponCode" : "String",
 "couponName" : "String",
 "couponType" : 0,
 "couponTypeName" : "String",
 "useScene" : 0,
 "useQty" : 0
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
