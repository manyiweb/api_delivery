# 获得购物车项目详情
 

**请求URL：** 
- `/b2b/shopCart/getShopCartItemDetail `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|itemKey|否|String| 购物车ItemKey|
|levelIds|否|List| 促销ID|

###请求参数Json格式
 
```
{
 "itemKey" : "String",
 "levelIds" : null
}
```
