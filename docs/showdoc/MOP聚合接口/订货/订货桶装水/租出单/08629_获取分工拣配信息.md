# 

**请求URL：** 
- `/b2b/picking/order/getDivideTheWorkInfo`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|String||

### 请求参数Json格式
 
```
{
 "id" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--pickingOrderId|否|String| 拣配单id|
|--pickingName|否|String| 拣配名称|
|--totalQuantity|否|Double| 总数|
|--itemDtos|否|List| 商品|
|----pickingQuantity|否|Double| 拣配数量|
|----itemId|否|String| 商品id|
|----itemName|否|String| 商品名称|
|----specId|否|String| 规格id|
|----totalQuantity|否|Double| 总数|
|----unit|否|String| 单位|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "pickingOrderId" : "String",
 "pickingName" : "String",
 "totalQuantity" : 0,
 "itemDtos" : [{
 "pickingQuantity" : 0,
 "itemId" : "String",
 "itemName" : "String",
 "specId" : "String",
 "totalQuantity" : 0,
 "unit" : "String"
 }]
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
