# 拣配单批量新建

**请求URL：** 
- `/b2b/picking/order/batchCreate`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|isAll|否|Boolean| 是否全部|
|lines|否|List| 明细|
|--orderId|否|String| 订单id|
|--ordCode|否|String| 订单编码|
|--orderItemId|否|String| 商品明细id|
|--companyId|否|String| 门店id|
|--companyCode|否|String| 门店编码|
|--companyName|否|String| 门店名称|
|--itemId|否|String| 商品id|
|--itemCode|否|String| 商品编码|
|--itemName|否|String| 商品名称|
|--specId|否|String| 商品sku|
|--pickIngQuantity|否|Double| 拣配数量|
|--deliveryPersonnelId|否|String| 配送员id|
|source|否|Integer| 来源|
|pickTypeId|否|String| 拣配类型|
|pickTypeCode|否|String| 拣配类型|
|whsId|否|String| 仓库id|
|whsCode|否|String| 仓库id|
|remark|否|String| 备注|
|whsOutTypeId|否|String| 单据类型|
|whsOutTypeCode|否|String| 单据类型|
|postingDate|否|DateTime| 过账日期|
|beginDeliveryDate|否|DateTime| 开始日期|
|endDeliveryDate|否|DateTime| 结束日期|
|companyId|否|String| 门店id|
|isSingleOrder|否|Boolean| 是否是单张订单|
|logisticsProviders|否|String| 物流商编码|
|logisticsProvidersName|否|String| 物流商名称|
|logisticsNumber|否|String| 物流单号|
|conAddress|否|String| 收货地址|
|consignee|否|String| 收货人|
|consiPhone|否|String| 收货号码|
