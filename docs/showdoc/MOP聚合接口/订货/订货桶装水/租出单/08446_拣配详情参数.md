# 拣配详情参数



### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|否|String| 订单id|
|ordCode|否|String| 订单编码|
|companyId|否|String| 门店id|
|companyCode|否|String| 门店编码|
|companyName|否|String| 门店名称|
|createDate|否|DateTime| 创建日期|
|deliveryDate|否|DateTime| 到货日期|
|itemId|否|String| 商品id|
|itemCode|否|String| 商品编码|
|itemName|否|String| 商品名称|
|barCode|否|String| 商品sku|
|quantity|否|Double| 已拣配数量|
|unPickIngQuantity|否|Double| 未拣配数量|
|specId|否|String| 规格id|
|orderItemId|否|String| 商品sku|
|unit|否|String| 单位|

 "barCode" : "String",
 "quantity" : 0,
 "unPickIngQuantity" : 0,

 "orderItemId" : "String",
 "unit" : "String"
}
