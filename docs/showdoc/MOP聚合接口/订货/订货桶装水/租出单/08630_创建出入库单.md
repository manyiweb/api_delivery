# 创建出入库单

**请求URL：** 
- `/warehouse/picking/createOutOrIn`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|whsOutId|否|String| 出库单草稿ID|
|source|是|Integer| 单据来源 1-中台 2-前台 3-店务助手 4-POS|
|pickTypeCode|否|String| 拣配类型编码|
|whsTypeCode|否|String| 出入库单据类型|
|remark|否|String| 备注|
|pickOrderItems|是|List| 出库单明细|
|--itemId|是|String| 商品ID|
|--quantity|是|Double| 数量|
|--specId|是|String| 规格ID|
|--unit|是|String| 单位|
|--orderItemId|否|String| 原单明细Id|
|--barcodeList|否|List| 唯一码列表|
|----attachBarcode|否|String| 唯一码附加码|
|----barcode|是|String| 唯一码|
|--barcodes|否|List||
|--batchList|否|List| 批次信息|
|----batchCode|否|String| 批次号|
|----quantity|是|Double| 数量|
|----productionDate|否|DateTime| 生产日期|
|--itemUnit|否|String| 单位组单位|
|--itemQuantity|否|Double| 单位组单位数量|
|--unitRate|否|Double| 换算率|
|--unitGroupId|否|Long| 单位组标识|
|--unitGroupName|否|String| 单位组名称|
|--remark|否|String| 备注|
|b2BPickingOrderDivideTheWorkDtos|否|List| 拣配分工信息|
|--pickingOrderId|否|String| 拣配单id|
|--pickingName|否|String| 拣配名称|
|--totalQuantity|否|String| 总数|
|--itemDtos|否|List| 商品|
|----pickingQuantity|否|Double| 拣配数量|
|----itemId|否|String| 商品id|
|----itemName|否|String| 商品名称|
|----specId|否|String| 规格id|
|----totalQuantity|否|String| 总数|
|----unit|否|String| 单位|
