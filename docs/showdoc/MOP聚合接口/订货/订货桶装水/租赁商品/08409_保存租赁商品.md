# 保存租赁商品

**请求URL：** 
- `/b2b/lease/item/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 门店id|
|enableLeaseItem|是|Boolean| 是否启用租赁商品管理|
|deleteIds|否|List| 要删除的商品id列表|
|leaseItems|否|List| 要保存的商品列表|
|--id|否|Long| 主键|
|--isActive|否|Boolean| 是否启用|
|--leaseItemId|否|String| 租赁商品id|
|--leaseSpecId|否|String| 租赁商品规格id|
|--leaseItemName|否|String| 租赁商品名称|
|--leaseSkuBarcode|否|String| 租赁sku|
|--leaseItemCode|否|String| 租赁商品编码|
|--mainItemId|否|String| 主商品id|
|--mainSpecId|否|String| 主商品规格id|
|--mainItemName|否|String| 主商品名称|
|--mainItemCode|否|String| 主商品编码|
|--mainSkuBarcode|否|String| 主商品sku|

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "enableLeaseItem" : true,
 "deleteIds" : null,
 "leaseItems" : [{
 "id" : 0,
 "isActive" : true,
 "leaseItemId" : "String",
 "leaseSpecId" : "String",
 "leaseItemName" : "String",
 "leaseSkuBarcode" : "String",
 "leaseItemCode" : "String",
 "mainItemId" : "String",
 "mainSpecId" : "String",
 "mainItemName" : "String",
 "mainItemCode" : "String",
 "mainSkuBarcode" : "String"
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
