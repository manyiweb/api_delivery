# 修改配送员
 

**请求URL：** 
- `/b2b/shopping/cart/item/updateDeliveryPersonne`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|deliveryPersonnelName|否|String| 配送人名称|
|deliveryPersonnelId|否|String| 配送员id|
|shopCartKey|否|String| 如果是立即购买输入对应的立即购买cartKey|

### 请求参数Json格式
 
```
{
 "deliveryPersonnelName" : "String",
 "deliveryPersonnelId" : "String",
 "shopCartKey" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
