# 批量设置配送员

**请求URL：** 
- `/b2b/order/update/batch/deliveryPersonne`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|deliveryPersonnelName|是|String| 配送人名称|
|deliveryPersonnelId|是|String| 配送员id|
|lineLicensePlateNumber|是|String| 排车车牌号|
|lineDriverName|是|String| 排车司机|
|lineVolume|是|Double| 排车体积|
|lineVolumeUnit|是|String| 排车体积单位|
|orderIds|否|List| 配送员id|

### 请求参数Json格式
 
```
{
 "deliveryPersonnelName" : "String",
 "deliveryPersonnelId" : "String",
 "lineLicensePlateNumber" : "String",
 "lineDriverName" : "String",
 "lineVolume" : 0,
 "lineVolumeUnit" : "String",
 "orderIds" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
