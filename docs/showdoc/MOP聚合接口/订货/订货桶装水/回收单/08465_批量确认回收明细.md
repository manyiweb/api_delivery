# 批量确认回收明细

**请求URL：** 
- `/b2b/receive/batchConfirm/list`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|idList|是|List||

### 请求参数Json格式
 
```
{
 "idList" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--orderCode|否|String|单据编码 |
|--companyName|否|String|门店名称 |
|--deliveryPersonnelName|否|String|配送员名称 |
|--id|否|Long| 主键id|
|--reviceingOrderId|否|Long| 关联的回收单id|
|--itemId|否|String|商品id |
|--itemName|否|String|商品名称 |
|--itemCode|否|String|商品名称 |
|--sourceItemId|否|String|关联来源单id |
|--specId|否|String|规格id |
|--skuBarCode|否|String|商品名称 |
|--imgUrl|否|String|商品图片 |
|--unit|否|String|单位 |
|--rate|否|Double|单位换算比例 |
|--quantity|否|Double|数量 |
|--reviceQuantity|否|Double|收货数量 |
|--brokenQuantity|否|Double| 破损数量|
|--UnReceiveQuantity|否|Double| 待收数量|
|--itemUnitQuantity|否|Double|商品单位数量 |
|--remark|否|String|备注 |
|--realPrice|否|Double|金额 |
|--totalRealPrice|否|Double|累计金额 |
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
