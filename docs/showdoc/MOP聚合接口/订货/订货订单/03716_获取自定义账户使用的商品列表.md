# 获取自定义账户使用的商品列表
 

**请求URL：** 
- `/b2b/sales/order/product/ca/products `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|否|String| 订单ID|
|accountId|否|String| 账户ID，对应收银表记录的paySubcategoryId|
|tokenId|否|String| 用户标识|
|pageIndex|否|Integer| 分页页码|
|pageSize|否|Integer| 分页大小|
|sword|否|String| 搜索关键字|

###请求参数Json格式
 
```
{
 "orderId" : "String",
 "accountId" : "String",
 "tokenId" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "sword" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--pageIndex|否|Integer| 页码|
|--pageSize|否|Integer| 显示记录数|
|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|--first|否|Boolean| 首页|
|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|
|----id|否|Long| id|
|----itemId|否|String| 商品ID|
|----itemCode|否|String| 商品编码|
|----itemName|否|String| 商品名称|
|----unit|否|String| 基本单位|
|----quantity|否|Double| 数量|
|----specId|否|String| 规格标识|
|----specName|否|String| 规格名称|
|----skuBarcode|否|String| sku码|
|----headImage|否|String| 商品图片|
|----orderId|否|String| 订单ID|
|----customAccountAmount|否|Double| 使用的自定义账户金额|
|----deductRate|否|Double| 账户抵扣比例|
|----accountId|否|Long| 账户标识|
|----createId|否|String| 创建人id|
|----createName|否|String| 创建人|
|----createDate|否|DateTime| 创建时间|
|----modifyId|否|String| 修改人id|
|----modifyName|否|String| 修改人|
|----modifyDate|否|DateTime| 修改时间|
|----dbKey|否|Integer| 分库标识|
|----groupId|否|String| 品牌商id|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
