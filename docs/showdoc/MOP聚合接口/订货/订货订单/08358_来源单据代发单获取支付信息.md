# 来源单据代发单获取支付信息
 

**请求URL：** 
- `/b2b/order/getProxyOrderPayData`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|否|String| 订单id|
|supplyIngOrderId|否|Long| 代发单id|

### 请求参数Json格式
 
```
{
 "orderId" : "String",
 "supplyIngOrderId" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--needPay|否|Boolean| 需要支付|
|--orderId|否|String| 订单id|
|--payAmount|否|Double| 支付金额|
|--transId|否|String| 支付流水id|
|--proxyDeliveryId|否|String| 记录id|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "needPay" : true,
 "orderId" : "String",
 "payAmount" : 0,
 "transId" : "String",
 "proxyDeliveryId" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
