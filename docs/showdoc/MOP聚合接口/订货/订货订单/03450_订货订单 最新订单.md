# 订货订单 最新订单

**请求URL：** 
- `/b2b/lately/order/list `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|否|String||
|limit|否|Integer| 条数|

###请求参数Json格式
 
```
{
 "tokenId" : "String",
 "limit" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--receivingProvinces|否|String| 省份|
|--consiPhone|否|String| 号码|
|--realTotal|否|Double| 金额|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : [{
 "receivingProvinces" : "String",
 "consiPhone" : "String",
 "realTotal" : 0
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
