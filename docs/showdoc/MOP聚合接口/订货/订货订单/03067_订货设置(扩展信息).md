# 订货设置(扩展信息)
 

**请求URL：** 
- `/config/b2b/orderset/get/expand `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String||

###请求参数Json格式
 
```
{
 "companyId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--b2BSetInvoice|否|Object| 开票相关信息|
|----openInvoice|否|Integer| 是否开发票 1是0否|
|----generalInvoice|否|Integer| 开启增值税电子普通发票 1是0否|
|----specialInvoice|否|Integer| 开启增值税电子专用发票 1是0否|
|----validDays|否|Long| 开票有效天数|
|----orderStatus|否|Integer| 按订单状态显示申请开票按钮 1是0否|
|----orderStatusList|否|String| 按订单状态显示申请开票按钮(状态集合)|
|----spanYear|否|Integer| 是否允许跨年开票 1是0否|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : {
 "b2BSetInvoice" : {
 "openInvoice" : 0,
 "generalInvoice" : 0,
 "specialInvoice" : 0,
 "validDays" : 0,
 "orderStatus" : 0,
 "orderStatusList" : "String",
 "spanYear" : 0
 }
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
