# 订货订单发货导入
 

**请求URL：** 
- `/file/b2bOrder/deliveryList/import `

**请求方式：**
- POST
- FormData


###请求参数<业务参数>
 
无参数


###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--dataSource|否|List| 导入的数据|
|----id|否|String| 商品行标识|
|----itemCode|否|String| 商品编码|
|----skuBarcode|否|String| SKU码|
|----itemName|否|String|商品名称|
|----itemQuantity|否|String|订货数量|
|----itemUnit|否|String|订货单位|
|----quantity|否|String|订货总数|
|----unit|否|String|基本单位|
|----realPrice|否|String|订货价|
|----realPriceLineTotal|否|String|小计|
|----baseDeQuantity|否|String| 已发数量|
|----deQuantity|否|Double|现发数量|
|----deUnit|否|String|发货单位|
|----deliveryRemark|否|String|行备注|
|----status|否|Integer| 状态 1通过 0不通过|
|----statusName|否|String| 状态描述|
|----msg|否|String| 备注|
|--downloadURL|否|String| 错误数据下载地址|
|--totalCount|否|Long| 总数|
|--successCount|否|Long| 成功数|
|--errorCount|否|Long| 错误数|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
