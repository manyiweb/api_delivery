# 订货单-商品详情

**请求URL：** 
- `/b2b/orderDetail/b2bOrderItemInfo`

**请求方式：** 
- `POST`
- `RequestBody`


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|是|String| 订单id|
|isOrderRefund|否|Boolean| 路径-》基于订货订单退货|
|onlyAcceptable|否|Boolean||
|itemTypefCodes|否|List| 商品分类编码|
|orgins|否|List| 产地|
|preferredSupplierNames|否|List| 首选供应商|
|brandCodes|否|List| 所属品牌|
|seriesCodes|否|List| 系列|
|refundTypeId|否|String| 退货类型id|
|isChangePrice|否|Boolean| 是否改单|
|isOrderOrderChange|否|Boolean| 是否改单|
|defaultUnit|否|Boolean| 是否默认单位|
|isDelivery|否|Boolean| 是否是发货|
|whsOutId|否|String| 出库单id|

### 请求参数Json格式
 
```

 "orderId":"String",
```
