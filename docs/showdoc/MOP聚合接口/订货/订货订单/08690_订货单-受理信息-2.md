# 订货单-受理信息

**请求URL：** 
- `/b2b/orderDetail/b2bOrderAcceptInfo`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|否|String| 订货单id|
|isDistributor|否|Boolean||

### 请求参数Json格式
 
```
{
 "orderId" : "String",
 "isDistributor" : true
}
```

|----lastAccept|否|Integer||
|--acceptRecords|否|List| 受理记录|
|----id|否|Long||
|----acceptId|否|Long||
