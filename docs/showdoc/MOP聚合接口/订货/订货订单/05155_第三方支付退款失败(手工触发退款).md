# 第三方支付退款失败(手工触发退款)
 

**请求URL：** 
- `/b2b/refund/th/refresh`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|refundTraceNos|是|List| 退款单号|

### 请求参数Json格式
 
```
{
 "refundTraceNos" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--refundRefreshItems|否|List||
|----refundTraceNo|否|String| 退款单单号|
|----success|否|Boolean| 是否成功|
|----message|否|String| 失败原因|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : {
 "refundRefreshItems" : [{
 "refundTraceNo" : "String",
 "success" : true,
 "message" : "String"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
