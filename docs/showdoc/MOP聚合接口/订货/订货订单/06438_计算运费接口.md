# 计算运费接口
 

**请求URL：** 
- `/b2b/sales/order/calculateFreight`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderTypeId|否|Long| 订货类型id|
|addressId|否|String| 地址Id|
|companyId|否|String| 门店id|
|orderAmount|否|Double| 订单金额|
|items|否|List| 商品信息|
|--itemId|否|String| 规格id|
|--specId|否|String| 规格id|
|--quantity|否|Double| 数量|
|--totalPrice|否|Double| 总价格|
|--expressFee|否|Double| 运费|

### 请求参数Json格式
 
```
{
 "orderTypeId" : 0,
 "addressId" : "String",
 "companyId" : "String",
 "orderAmount" : 0,
 "items" : [{
 "itemId" : "String",
 "specId" : "String",
 "quantity" : 0,
 "totalPrice" : 0,
 "expressFee" : 0
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--expressFee|否|Double| 总运费|
|--plusUrgentExpressFee|否|Object| 加急运费相关|
|----plusUrgentExpressFeeAmount|否|Double| 加急运费金额|
|----plusUrgentDeliveryEnable|否|Boolean| 是否启用加急配送 1是0否|
|----plusUrgentDeliveryRemark|否|String| 加急配送说明|
|----plusUrgentDeliverySel|否|Boolean| 用户是否选中加急配送|
|--itemExpress|否|List| 商品运费|
|----specId|否|String| 规格id|
|----expressFee|否|Double| 运费|
|----totalExpressFee|否|Double| 总运费|
|--plusUrgentExpressFeeAmount|否|Double| 总运费|
|--freightExplain|否|String| 运费说明|
|--schemeType|否|Integer| 0-按订货商品计算 1-按订单金额计算 2-按运输类型计算 3-按重量计算|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式

```
 "data" : {

 "plusUrgentExpressFeeAmount" : 0,

 },
 "itemExpress" : [{
 "specId" : "String",
 "expressFee" : 0,
 "totalExpressFee" : 0
 }],
 "plusUrgentExpressFeeAmount" : 0,
 "freightExplain" : "String",
 "schemeType" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
