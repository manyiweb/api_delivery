# 批量关闭订货单

**请求URL：** 
- `/b2b/order/batchCloseOrder`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|closeType|否|Integer| 关闭类型 1原路返回|
|orderIds|否|List| 订货单id|
|needReturnGiveIntegral|否|Boolean| 是否需要返回赠送的积分|

### 请求参数Json格式
 
```
{
 "closeType" : 0,
 "orderIds" : null,
 "needReturnGiveIntegral" : true
}
```
