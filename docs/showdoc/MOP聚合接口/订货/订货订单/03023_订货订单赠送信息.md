# 订货订单赠送信息
 

**请求URL：** 
- `/b2b/sales/order/getGiveInfo `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|否|String| 订单标识|

###请求参数Json格式
 
```
{
 "orderId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--couponTotal|否|Long| 优惠券总数量|
|--couponUesdTotal|否|Long| 已使用的优惠券数量|
|--giveBack|否|Integer| 订单是否已退优惠券 1是0否|
|--giveBackIntegral|否|Integer| 是否可退积分 1是0否|
|--deductIntegralReturn|否|Integer| 是否可退抵扣积分 1是0否|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : {
 "couponTotal" : 0,
 "couponUesdTotal" : 0,
 "giveBack" : 0,
 "giveBackIntegral" : 0,
 "deductIntegralReturn" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
