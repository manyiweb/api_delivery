# 查询订单支付状态
 

**请求URL：** 
- `/b2b/order/findOrderPayStatus `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|String| id|

###请求参数Json格式
 
```
{
 "id" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--payStatusCode|否|String| 支付状态|
|--advAmount|否|Double| 付款金额|
|--realTotal|否|Double| 订单金额|
|--needPay|否|Boolean| 是否需要支付|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "payStatusCode" : "String",
 "advAmount" : 0,
 "realTotal" : 0,
 "needPay" : true
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
