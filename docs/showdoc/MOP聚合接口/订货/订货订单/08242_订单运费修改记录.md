# 

**请求URL：** 
- `/b2b/order/getB2bOrderChangeLog`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|String||

### 请求参数Json格式
 
```
{
 "id" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--id|否|Long||
|--orderId|否|String| 等级id|
|--orderCode|否|String| 等级名称|
|--isChangeExpressFee|否|Boolean| 是否更改运费|
|--beforeExpressFee|否|Boolean| 之前运费金额|
|--createDate|否|DateTime| 时间|
|--createName|否|Boolean| 变更人|
|--beforeDeliveryDate|否|DateTime| 之前运费金额|
|--isChangeDeliveryDate|否|Boolean| 之前运费金额|
|--changeType|否|String| 变更类型|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "id" : 0,
 "orderId" : "String",
 "orderCode" : "String",
 "isChangeExpressFee" : true,
 "beforeExpressFee" : true,
 "createDate" : "DateTime",
 "createName" : true,
 "beforeDeliveryDate" : "DateTime",
 "isChangeDeliveryDate" : true,
 "changeType" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
