# 

**请求URL：** 
- `/b2b/sales/order/getStockItemInvQty`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|stockInfo|是|Object| 仓库id|
|--whsId|否|String| 仓库ID|
|--bCheckStock|否|Boolean| 是否需要验证库存|
|--bStartBooking|否|Boolean| 是否开启库存订购量|
|--openTransit|否|Boolean| 是否开启在途数控制|
|--addOrderBookingControl|否|Integer| 0不启用 1启用下单订购量控制,2启用拣配订购量控制|
|--isUserSelectWhs|否|Boolean|是否用户选择的仓库，如果是用户选择的，那么仓库id就不会被刷新掉 |
|--whsName|否|String|仓库名称 |
|specIds|是|List| 规格id列表|

### 请求参数Json格式
 
```
{
 "stockInfo" : {
 "whsId" : "String",
 "bCheckStock" : true,
 "bStartBooking" : true,
 "openTransit" : true,
 "addOrderBookingControl" : 0,
 "isUserSelectWhs" : true,
 "whsName" : "String"
 },
 "specIds" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Map||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
