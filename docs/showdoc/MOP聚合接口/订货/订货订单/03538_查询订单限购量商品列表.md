# 查询订单限购量商品列表
 

**请求URL：** 
- `/b2b/sales/order/limit/product/list `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|否|String| 订单标识|

###请求参数Json格式
 
```
{
 "orderId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--totalOverbookAmount|否|Double| 限购量超额摊分总金额|
|--totalOverbookQty|否|Double| 限购量超额摊分总数量|
|--overBookProducts|否|List| 限购商品明细|
|----id|否|Long| id|
|----productQty|否|Double| 商品总数|
|----overbookQty|否|Double| 超额数量|
|----baseOverbookQty|否|Double| 超额数量 基本单位|
|----overbookAmount|否|Double| 超额总金额|
|----overbookPrice|否|Double| 超额单价|
|----overbookUnit|否|String| 超额单位|
|----unit|否|String| 基本单位|
|----itemId|否|String| 商品ID|
|----itemCode|否|String| 商品编码|
|----itemName|否|String| 商品名称|
|----specId|否|String| 规格标识|
|----specName|否|String| 规格名称|
|----skuBarcode|否|String| sku码|
|----headImage|否|String| 商品图片|
|----orderId|否|String| 订单ID|
|----createId|否|String| 创建人id|
|----createName|否|String| 创建人|
|----createDate|否|DateTime| 创建时间|
|----modifyId|否|String| 修改人id|
|----modifyName|否|String| 修改人|
|----modifyDate|否|DateTime| 修改时间|
|----dbKey|否|Integer| 分库标识|
|----groupId|否|String| 品牌商id|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
