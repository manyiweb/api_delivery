# 获取订货下单展示字段设置

**请求URL：** 
- `/b2b/showFieldSet/get`

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|codeId|否|String| 订单类型id|
|companyId|否|String| 商户id|

###请求参数Json格式
 
```
{
 "codeId" : "String",
 "companyId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--isShowAvailableQty|否|Integer| 是否显示可订量 0 - 否, 1 - 是|
|--isBooking|否|Integer| 是否开启了订购量|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "isShowAvailableQty" : 0,
 "isBooking" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
