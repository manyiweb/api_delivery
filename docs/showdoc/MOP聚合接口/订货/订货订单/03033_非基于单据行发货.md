# 非基于单据行发货
 

**请求URL：** 
- `/b2b/order/delivery/with_out_orderitem `

**请求方式：**
- undefined
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderNo|否|String| 订货单号|
|deductionStock|否|Integer| 是否扣减库存，取值：1 - 扣减库存，0 - 不扣减，默认 1|
|isMinimumUnit|否|Integer| 	是否按最小单位发货，取值：1 - 是，0 - 否，默认 0|
|logisticsProvidersNo|否|String| 物流商编码|
|logisticsProvidersName|否|String| 物流商名称|
|logisticsNumber|否|String| 物流单号|
|deliveryDate|否|String| 发货时间|
|outOrderNo|否|String| 外部单号|
|remark|否|String| 备注|
|lines|否|List| 发货明细|
|--itemCode|否|String| 商品编码|
|--skuBarcode|否|String| SKU码|
|--quantity|否|Double| 数量|
|--unit|否|String| 单位|
|--barCodes|否|List| 唯一码|
|--batchList|否|List| 批次信息|
|----batchCode|否|String| 批次号|
|----quantity|否|Double| 数量|
|----productionDate|否|DateTime| 生产日期|
|productCodeType|否|Integer| 商品获取方式|
|tokenId|否|String| token标识|

###请求参数Json格式
 
```
{
 "orderNo" : "String",

 "isMinimumUnit" : 0,
 "logisticsProvidersNo" : "String",
 "logisticsProvidersName" : "String",
 "logisticsNumber" : "String",
 "deliveryDate" : "String",
 "outOrderNo" : "String",
 "remark" : "String",
 "lines" : [{
 "itemCode" : "String",
 "skuBarcode" : "String",
 "quantity" : 0,
 "unit" : "String",
 "barCodes" : null,
 "batchList" : [{
 "batchCode" : "String",
 "quantity" : 0,
 "productionDate" : "DateTime"
 }]
 }],
 "productCodeType" : 0,
 "tokenId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|ResultInt|否|Integer| 业务代码|
|ResultString|否|String| 消息|


###返回参数Json格式
 
```
{
 "ResultString" : "String",
 "ResultInt" : "Integer"
}
```
