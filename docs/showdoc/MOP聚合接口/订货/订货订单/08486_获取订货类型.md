# 获取类型配置
 

**请求URL：** 
- `/b2b/sales/order/getOfflineOrderType`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|是|String| 订单ID|

### 请求参数Json格式
 
```
{
 "orderId" : "String",
 "editDraftOrder" : true,
 "clearGift" : true
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--orderTypeId|否|Long| 订单类型id|
|--appcodeId|否|String| appcod id|
|--orderDocTypeName|否|String| 类型名称|
|--orderDocTypeCode|否|String| 类型编码|
|--orderTypeCode|否|String| 订单类型编码|
|--isControlStock|否|Boolean| 控制库存|
|--isAllItem|否|Boolean| 应用所有商品|
|--applyItemType|否|Integer| 应用所有商品|
|--estimateDeliveryDays|否|Integer| 预计配送天数|
|--lineId|否|String| 配送线路|
|--lineName|否|String| 配送线路名称|
|--openPromotion|否|Boolean| 是否参与促销|
|--openPayAccount|否|Boolean| 是否开启了支付|
|--minimumSet|否|Integer| 是否启用订货类型起订量 0否 1是|
|--minimumItemQuantity|否|Integer| 商品起订数量 0否 1是|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式

```
 "lineName" : "String",
 "openPromotion" : true,
 "openPayAccount" : true,
 "minimumSet" : 0,
 "minimumItemQuantity" : 0
 },

 "code" : "String",

 "traceId" : "String"
}
```
