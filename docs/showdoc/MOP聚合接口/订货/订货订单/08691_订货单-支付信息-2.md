# 订货单-支付信息

**请求URL：** 
- `/b2b/orderDetail/b2bOrderPayInfo`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|否|String| 订货单id|

### 请求参数Json格式
 
```
{
 "orderId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--needPay|否|Integer| 是否需要支付|
|--payTypeName|否|String| 支付类型名称|
|--isOpenOrderPay|否|Integer| 开启订货支付 1需要支付 0不需要支付
 (说明:如不开启订货支付,则提交订单后,订单收款状态默认为已收款,用于直营店订货场景)|
|--payStatus|否|String| 支付状态|
|--payment|否|List| 收银信息|
|----fid|否|String||
|----payTypeCode|否|String||
|----payTypeName|否|String||
|----payAmount|否|Object||
|----payDate|否|DateTime||
|----transCode|否|String||
|----orderNo|否|String||
|----payInterfaceOutTradeNo|否|String||
|----customPay|否|Boolean| 是否为自定义付款方式|
|----paySubcategoryId|否|String||
|----paySubcategoryCode|否|String||
|----paySubcategoryName|否|String||
|----deductionExpressFeeAmount|否|String| 自定义付款的金额|
|----useCustomAmount|否|String||
|----creditAmount|否|String||
|----acctName|否|String| 银联付款名称|
|----payType|否|String||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
