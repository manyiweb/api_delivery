# 获取订单体积

**请求URL：** 
- `/b2b/order/getAllVolume`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|String||

### 请求参数Json格式
 
```
{
 "id" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--allVolume|否|Double| 体积 单位厘米|
|--allVolumeByM|否|Double| 体积 单立方米|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "allVolume" : 0,
 "allVolumeByM" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
