# 极速下单优惠券计算

**请求URL：** 
- `/b2b/shopping/cart/offline/coupon/calculate`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|couponGetIds|是|List| 优惠券用户获取ID|
|actualPaidAmount|否|Double| 实付金额|
|expressFee|否|Double| 运费|
|companyId|否|String| 门店id|
|selectCouponGetId|否|String|本次新增选择的优惠券id|
|productList|否|List| 商品列表|
|--itemId|否|String| 商品ID|
|--specId|否|String| 商品规格ID|
|--quantity|否|Double| 商品数量|
|--brandCode|否|String| 品牌编码|
|--seriesCode|否|String| 系列编码|
|--itemTypeId|否|String| 商品分类ID|
|--dealPriceAmount|否|Double| 商品实际价小计（实付）|

### 请求参数Json格式
 
```
{
 "couponGetIds" : null,
 "actualPaidAmount" : 0,
 "expressFee" : 0,
 "companyId" : "String",
 "productList" : [{
 "itemId" : "String",
 "specId" : "String",
	 "brandCode" : "String",
	 "seriesCode" : "String",
	 "itemTypeId" : "String",
 "quantity" : 0,
 "dealPriceAmount" : 0
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--discountAmount|否|Double| 优惠金额|
|--expressDiscount|否|Double| 运费优惠金额|
|--couponGetIds|否|List| 实际使用的优惠券用户获取ID|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "discountAmount" : 0,
 "expressDiscount" : 0,
 "couponGetIds" : null
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
