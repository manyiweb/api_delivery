# 根据分类获取商品
 

**请求URL：** 
- `/b2b/order/findOrderItemGroupByItemType`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|String||

### 请求参数Json格式
 
```
{
 "id" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--itemTypeName|否|String| 类型名称|
|--shortNum|否|Integer| 排序号|
|--items|否|List| 商品分类|
|----orderItemId|否|String| 明细id|
|----itemCode|否|String| 商品编码|
|----itemName|否|String| 商品名称|
|----quantity|否|Double| 数量|
|----itemQuantity|否|String| 单位数量|
|----listPrice|否|Double| 清单价|
|----listPriceLineTotal|否|Double| 清单价合计|
|----realPrice|否|Double| 实际成交价|
|----realPriceLineTotal|否|Double| 行小计|
|----barCodes|否|String| 商品sku|
|----specName|否|String| 规格名称|
|----itemUnti|否|String| 订货单位|
|----remark|否|String| 备注|
|----specId|否|String| 规格id|
|----itemId|否|String| 商品id|
|----itemTypeName|否|String| 类型名称|
|----imageUrl|否|String| 商品图片|
|----imageFull|否|String| 商品图片|
|----saleUnitNumber|否|String| 单位系数|
|----itemTypeId|否|String| 分类id|
|----typeOrderNo|否|Integer| 商品分类号|
|----shortNum|否|Integer| 排序号|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
