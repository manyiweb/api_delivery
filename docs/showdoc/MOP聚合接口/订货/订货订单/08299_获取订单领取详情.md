# 获取领取记录

**请求URL：** 
- `/b2b/orderGiftPools/receiveOrderRecords`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|String||

### 请求参数Json格式
 
```
{
 "id" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--orderCode|否|String| 订单编码|
|--quantity|否|String| 数量|
|--planTypeName|否|Integer| 促销类型名称|
|--itemCode|否|String| 商品编码|
|--itemSku|否|String| 商品sku|
|--itemName|否|DateTime| 商品名称|
|--amountAmount|否|DateTime| 支付金额|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "orderCode" : "String",
 "quantity" : "String",
 "planTypeName" : 0,
 "itemCode" : "String",
 "itemSku" : "String",
 "itemName" : "DateTime",
 "amountAmount" : "DateTime"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
