# 修改订单赠品
 

**请求URL：** 
- `/b2b/sales/order/product/update `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|否|String| 订货订单标识|
|b2bord1ChangeReqs|否|List| 明细变更记录|
|--orderItemId|否|String| 订货订单商品行标识，为空时新增|
|--itemId|否|String| 商品itemId|
|--specId|否|String| 商品规格ID|
|--quantity|否|Double| 商品数量，删除数量填0即可。|
|--remark|否|String| 行备注|

###请求参数Json格式
 
```
{
 "orderId" : "String",
 "b2bord1ChangeReqs" : [{
 "orderItemId" : "String",
 "itemId" : "String",
 "specId" : "String",
 "quantity" : 0,
 "remark" : "String"
 }]
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
