# 查询本次订货订单批量导入发货结果

**请求URL：** 
- `/file/b2bOrder/batch/delivery/import/result `

**请求方式：**
- POST
- FormData


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|

###请求参数Json格式
 
```
{
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--errorData|否|List| 导入失败信息|
|--isFinish|否|Boolean| 是否处理完成|
|--id|否|Long| 导入记录id,前端用来定时查询导入结果|
|--totalCount|否|Long| 总数|
|--successCount|否|Long| 成功数|
|--errorCount|否|Long| 失败数|
|--fileUrl|否|String| 导出文件相对路径|
|--downloadURL|否|String| 导出文件下载路径|
|--data|否|List| 返回数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "errorData" : null,
 "isFinish" : true,
 "id" : 0,
 "totalCount" : 0,
 "successCount" : 0,
 "errorCount" : 0,
 "fileUrl" : "String",
 "downloadURL" : "String",
 "data" : null
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
