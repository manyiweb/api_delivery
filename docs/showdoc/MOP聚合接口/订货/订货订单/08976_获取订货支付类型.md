# 获取订货支付类型
 

**请求URL：** 
- `/b2b/pay/v2/getPayTypeByTakeOrder`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|否|String||
|companyId|否|String||
|payType|是|String||
|orderId|否|String||

### 请求参数Json格式
 
```
{
 "tokenId" : "String",
 "companyId" : "String",
 "payType" : "String",
 "orderId" : "String"
}
```
