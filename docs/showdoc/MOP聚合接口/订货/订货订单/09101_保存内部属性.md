# 保存内部属性
 

**请求URL：** 
- `/b2b/orderDetail/saveInnerOrderAttr`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|否|String||
|attrList|否|List||
|--attrId|否|Long|唯一id |
|--code|否|Integer|编码 |
|--alias|否|String|别名 |
|--value|否|String|值 |
|--isRequired|否|Integer|是否必填 1 - 必填, 0 - 不必填 |
|--valueType|否|Integer|0 任何值 1 序列 |
|--content|否|String|内容值,多个值时 |
|--subTypeCode|否|String|二级属性类型 |
|--contentArr|否|Object||
|--isInnerField|否|Integer| 是否内部字段|
|--customObjectFullList|否|List||
|----itemCode|否|String| 自定义对象编码|
|----itemName|否|String| 自定义对象名称|

### 请求参数Json格式
 
```
{
 "orderId" : "String",
 "attrList" : [{
 "attrId" : 0,
 "code" : 0,
 "alias" : "String",
 "value" : "String",
 "isRequired" : 0,
 "valueType" : 0,
 "content" : "String",
 "subTypeCode" : "String",
 "contentArr" : null,
 "isInnerField" : 0,
 "customObjectFullList" : [{
 "itemCode" : "String",
 "itemName" : "String"
 }]
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
