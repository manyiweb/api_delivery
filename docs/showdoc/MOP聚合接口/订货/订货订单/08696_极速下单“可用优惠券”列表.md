# 极速下单“可用优惠券”列表

**请求URL：** 
- `/b2b/shopping/cart/offline/coupon/list`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|actualPaidAmount|否|Double| 实付金额|
|expressFee|否|Double| 运费|
|companyId|否|String| 门店id|
|productList|否|List| 商品列表|
|--itemId|否|String| 商品ID|
|--specId|否|String| 商品规格ID|
|--brandCode|否|String| 品牌编码|
|--seriesCode|否|String| 系列编码|
|--itemTypeId|否|String| 商品分类ID|
|--quantity|否|Double| 商品数量|
|--dealPriceAmount|否|Double| 商品实际价小计（实付）|

### 请求参数Json格式
 
```
{
 "actualPaidAmount" : 0,
 "expressFee" : 0,
 "companyId" : "String",
 "productList" : [{
 "itemId" : "String",
 "specId" : "String",
	 "brandCode" : "String",
	 "seriesCode" : "String",
	 "itemTypeId" : "String",
 "quantity" : 0,
 "dealPriceAmount" : 0
 }]
}
```
