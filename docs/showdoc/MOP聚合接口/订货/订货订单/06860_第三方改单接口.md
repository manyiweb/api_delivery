# 订单变更
 

**请求URL：** 
- `/b2b/sales/order/rpc/change `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|否|String||
|orderItemReqs|否|List|订单变更商品明细 |
|--itemId|否|String| 商品itemId|
|--specId|否|String| 商品规格ID|
|--quantity|否|Double| 商品数量，删除数量填0即可。|
|--remark|否|String| 行备注|
|--itemUnit|否|String|单位组单位 |
|--changeType|否|Integer| 变更类型 0 新增 1覆盖 2删除|
|--oldSpecId|否|String| 被覆盖的规格id|
|--oldItemId|否|String| 被覆盖的ItemId|

###请求参数Json格式
 
```
{
 "orderId" : "String",
 "orderItemReqs" : [{
 "itemId" : "String",
 "specId" : "String",
 "quantity" : 0,
 "remark" : "String",
 "unit" : "String",
 "itemUnit" : "String",
 "unitGroupId" : 0,
 "unitRate" : 0,
 "changeType" : 0,
 "oldSpecId" : "String",
 "oldItemId" : "String"
 }]
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
