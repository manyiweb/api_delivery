# 检查订单地址是否商户档案内已维护的地址
 

**请求URL：** 
- `/api/b2b/order/check/checkOrderAddressIsCompanyAddress/{orderId}`

**请求方式：** 
- `POST`
- `FormData`


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|否|String| |

### 请求参数Json格式
 
```
{
 "orderId":"String"
}
```

### 响应参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Boolean||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 响应参数Json格式
 
```
{
 "data":true,
 "msg":"String",
 "code":"String",
 "exceptionStackInfo":"String",
 "traceId":"String"
}
```
