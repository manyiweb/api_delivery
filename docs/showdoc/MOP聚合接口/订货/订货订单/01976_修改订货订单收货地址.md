# 修改订货订单收货地址
 

**请求URL：** 
- `/b2b/sales/order/address/update `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|否|String| 订货订单标识|
|provinceName|否|String| 省|
|cityName|否|String| 市|
|regionName|否|String| 区|
|address|否|String| 收货地址|
|name|否|String| 收货人|
|phone|否|String| 联系电话|

###请求参数Json格式
 
```
{
 "orderId" : "String",
 "provinceName" : "String",
 "cityName" : "String",
 "regionName" : "String",
 "address" : "String",
 "name" : "String",
 "phone" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
