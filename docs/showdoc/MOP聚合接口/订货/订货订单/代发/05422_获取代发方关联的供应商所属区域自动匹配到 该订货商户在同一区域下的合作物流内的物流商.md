# 获取代发方关联的供应商所属区域自动匹配到 该订货商户在同一区域下的合作物流内的物流商

**请求URL：** 
- `/b2b/sales/order/logisticsList `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|否|String| 订单id|
|supplierId|否|String| 代发供应商id|

###请求参数Json格式
 
```
{
 "orderId" : "String",
 "supplierId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--logisticsId|否|String| 物流id|
|--logisticsCode|否|String| 物流编码|
|--logisticsName|否|String| 物流名称|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : [{
 "logisticsId" : "String",
 "logisticsCode" : "String",
 "logisticsName" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
