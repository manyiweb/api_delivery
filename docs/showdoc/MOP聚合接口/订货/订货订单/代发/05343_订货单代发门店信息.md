# 订货单代发门店信息

**请求URL：** 
- `/b2b/sales/order/product/proxy/info/v2`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|是|String| 订货单标识|
|companyId|是|String| 订货单所在门店的标识|

### 请求参数Json格式
 
```
{
 "orderId" : "String",
 "companyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--proxyInfos|否|Map| KEY为规格ID，value为适用的代发商户信息|
|--openOfflinePayOrderAccept|否|Boolean||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "proxyInfos" : null,
 "openOfflinePayOrderAccept" : true
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
