# 订货单代发信息

**请求URL：** 
- `/b2b/sales/order/product/proxy/info`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|是|String| 订货单标识|
|companyId|是|String| 订货单所在门店的标识|
|proxyCompanyId|是|String| 选择代发的门店|

### 请求参数Json格式
 
```
{
 "orderId" : "String",
 "companyId" : "String",
 "proxyCompanyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--proxyInfo|否|Map||
|----companyId|否|String| 门店ID|
|----companyName|否|String| 门店名称|
|----supplierId|否|String| 供应商id,没值返回空或""|
|----supplierName|否|String| 供应商名称,没值返回空或""|
|----logisticsId|否|String| 建议物流商Id,没值返回空或""|
|----logisticsName|否|String| 建议物流商名称,没值返回空或""|
|----hasSettlementPrice|否|Boolean| 是否有结算单价|
|----settlementPrice|否|Double| 结算单价|
|----auto|否|Boolean| 是否自动代发|
|----invQty|否|Double| 库存数|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : {
 "proxyInfo" : { "MapKey" : {
 "companyId" : "String",
 "companyName" : "String",
 "supplierId" : "String",
 "supplierName" : "String",
 "logisticsId" : "String",
 "logisticsName" : "String",
 "hasSettlementPrice" : true,
 "settlementPrice" : 0,
 "auto" : true,
 "invQty" : 0
 }}
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
