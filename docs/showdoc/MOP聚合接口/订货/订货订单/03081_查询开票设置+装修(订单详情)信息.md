# 查询开票设置+装修(订单详情)信息
 

**请求URL：** 
- `/b2b/invoice/set/info `

**请求方式：**
- POST
- FormData


###请求参数<业务参数>
 
无参数


###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--b2BSetInvoice|否|Object| 订货开票设置信息|
|----openInvoice|否|Integer| 是否开发票 1是0否|
|----generalInvoice|否|Integer| 开启增值税电子普通发票 1是0否|
|----specialInvoice|否|Integer| 开启增值税电子专用发票 1是0否|
|----validDays|否|Long| 开票有效天数|
|----openOrderStatus|否|Integer| 按订单状态显示申请开票按钮 1是0否|
|----orderStatusList|否|String| 按订单状态显示申请开票按钮(状态集合)|
|----spanYear|否|Integer| 是否允许跨年开票 1是0否|
|--orderDetailSet|否|Object| 订货订单详情设置信息|
|----showCustomerService|否|Integer| 显示客服咨询入口 1是0否|
|----showOpenInvoice|否|Integer| 显示开票按钮 1是0否|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : {
 "b2BSetInvoice" : {
 "openInvoice" : 0,
 "generalInvoice" : 0,
 "specialInvoice" : 0,
 "validDays" : 0,
 "openOrderStatus" : 0,
 "orderStatusList" : "String",
 "spanYear" : 0
 },
 "orderDetailSet" : {
 "showCustomerService" : 0,
 "showOpenInvoice" : 0
 }
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
