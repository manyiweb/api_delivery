# 转调拨单
 

**请求URL：** 
- `/b2b/order/toDallot/create`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|outWhsId|否|String| 调拨发货出库仓ID，与仓库表mwhs关联|
|outWhsName|否|String| 调拨发货出库仓名称|
|inWhsId|否|String| 调拨收货入库仓ID，与仓库表mwhs关联|
|inWhsName|否|String| 调拨收货仓名称|
|typeCode|否|String| 调拨单类型，取值：G - 总部调拨，C - 门店调拨|
|typeName|否|String| 调拨单类型，取值：G - 总部调拨，C - 门店调拨|
|companyId|否|String| 门店商户ID，与商户表syscompany相关联|
|companyName|否|String| 商户名称|
|remark|否|String| 备注|
|allotType|否|String| 调拨类型 临时字段不存数据库|
|allotTypeName|否|String| 调拨类型|
|reason|否|String| 调拨原因|
|reasonId|否|String| 调拨原因Id|
|arrivedDate|否|DateTime| 到货日期|
|inCompanyDepartmentCode|否|String| 到部门编码|
|inCompanyDepartmentName|否|String| 到部门名称|
|inCompanyDepartmentId|否|Long| 到部门id|
|outCompanyDepartmentName|否|String| 从部门名称|
|outCompanyDepartmentId|否|Long| 从部门id|
|items|否|List||
|--orderItemId|否|String| 订单明细id|
|--itemId|否|String| 商品id|
|--itemName|否|String| 商品id|
|--specId|否|String| 规格id|
|--quantity|否|Double| 数量|
|--itemQuantity|否|Double| 数量|
|--dealPrice|否|Double| 实际成交金额|
|--remark|否|String| 备注|
|--unitName|否|String| 单位|
|--bomId|否|String| bomId|
|--unitRate|否|String| bomId|
|--batchList|否|List| 批次|
|----batchCode|否|String||
|----productionDate|否|DateTime||
|----validDays|否|Integer||
|----quantity|是|Double||
|--barCodes|否|List| 唯一码|
|--whsItemDtos|否|List| 仓库对应的商品信息|
|----orderItemId|否|String| 订单明细id|
|----itemId|否|String| 商品id|
|----specId|否|String| 规格id|
|----quantity|否|Double| 数量|
|----itemQuantity|否|Double| 数量|
|----unitName|否|String| 单位|
|----bomId|否|String| bomId|
|----unitRate|否|String| bomId|
|----inWhsId|否|String| 调拨收货入库仓ID，与仓库表mwhs关联|
|----inCompanyId|否|String| 入的仓库id|
|----inWhsName|否|String| 调拨收货仓名称|
|--inWhsId|否|String| 调拨收货入库仓ID，与仓库表mwhs关联|
|--inWhsName|否|String| 调拨收货仓名称|
|totalQuantity|否|Double| 总的数量|
