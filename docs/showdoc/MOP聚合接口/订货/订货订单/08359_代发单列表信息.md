# 代发单列表信息
 

**请求URL：** 
- `/b2b/order/getProxyList`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|否|String| 订单id|

### 请求参数Json格式
 
```
{
 "orderId" : "String",
 "supplyIngOrderId" : 0
}
```
