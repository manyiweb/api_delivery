# 自定义账户金额使用
 

**请求URL：** 
- `/b2b/shopping/cart/custom/account/update `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|useAmount|否|Double| 使用金额，金额为0则取消选中|
|accountId|否|Long| 自定义账户ID|
|combinationPayment|否|Boolean| 是否使用普通账户支付账户|
|useType|否|Integer| 使用类型0 代表抵扣订单金额 1代表抵扣运费|
|shopCartKey|否|String| 如果是立即购买输入对应的立即购买cartKey|

###请求参数Json格式
 
```
{
 "useAmount" : 0,
 "accountId" : 0,
 "combinationPayment" : true,
 "useType" : 0,
 "shopCartKey" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--removedAccountNames|否|String| 计算金额被踢掉的账户列表，前台提示例子：本次抵扣总额已大于应付金额，系统将按账户抵扣顺序取消[B账户、C账户]的选择，您可重新选择和调整账户的抵扣金额|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "removedAccountNames" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
