# 订货单-主表详情

**请求URL：** 
- `/b2b/orderDetail/b2bOrderInfo`

**请求方式：**
- POST

|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|是|String| 订单id|
|isOrderOrderChange|否|Boolean| 是否改单|

```
{
```
