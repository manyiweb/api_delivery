# 订货改单获取时间接口
 

**请求URL：** 
- `/b2b/orderChange/set/info `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 商户标识|

###请求参数Json格式
 
```
{
 "companyId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--canOrder|否|Boolean| 是否能下单|
|--changeOrderType|否|Integer| 类型|
|--timeList|否|List| 自定义下单时间列表|
|----customStartTime|否|Object| 自定义下单时间——开始|
|----customEndTime|否|Object| 自定义下单时间——结束|
|--timeStrList|否|List| 自定义下单时间列表|
|----customStartTime|否|String| 自定义下单时间——开始|
|----customEndTime|否|String| 自定义下单时间——结束|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "canOrder" : true,
 "changeOrderType" : 0,
 "timeList" : [{
 "customStartTime" : null,
 "customEndTime" : null
 }],
 "timeStrList" : [{
 "customStartTime" : "String",
 "customEndTime" : "String"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
