# 改价
 

**请求URL：** 
- `/b2b/order/batch/changePrice `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderIds|否|List| 订单id列表|
|items|否|List| 要修改的商品列表|
|--specId|否|String| 规格id|
|--quantity|否|Double||
|--fid|否|String||
|--itemId|否|String||
|--realPrice|否|Double||
|--productType|否|String||
|--itemUnit|否|String| 本次单位|
|--unitPrice|否|Double| 改价后单位价|
|--unitRate|否|String| 单位换算|
|--unitId|否|String||
|--unitGroupDetails|否|List||
|----unitId|否|String| 转换单位标识|
|----unitName|否|String| 转换单位名称|
|----unitRate|否|Double| 系数|
|----itemId|否|String| 商品id|
|--index|否|Integer|前端的商品序号 后端一一对应用|
|changeType|否|Integer| 变更类型 3按商品替换类型|
|addItems|否|List| 要新增的商品列表|
|--specId|否|String| 规格id|
|--quantity|否|Double||
|--fid|否|String||
|--itemId|否|String||
|--realPrice|否|Double||
|--productType|否|String||
|--itemUnit|否|String| 本次单位|
|--unitPrice|否|Double| 改价后单位价|
|--unitRate|否|String| 单位换算|
|--unitId|否|String||
|--unitGroupDetails|否|List||
|----unitId|否|String| 转换单位标识|
|----unitName|否|String| 转换单位名称|
|----unitRate|否|Double| 系数|
|----itemId|否|String| 商品id|
|--index|否|Integer|前端的商品序号 后端一一对应用|
