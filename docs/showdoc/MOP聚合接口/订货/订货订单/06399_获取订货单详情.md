# 获取订货单详情

**请求URL：** 
- `/b2b/orderDetail/detail `

**请求方式：**
- undefined
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|否|String| 订单id|
|isOrderRefund|否|Boolean| 是否是退货|
|isOrderOrderChange|否|Boolean| 是否是改单|
|isChangePrice|否|Boolean| 是否是改价|
|defaultUnit|否|Boolean| 是否默认单位|
|isPrint|否|Boolean| 是否是打印|
|sword|否|String| 订单id|
|pageIndex|否|Integer| 页号|
|pageSize|否|Integer| 页大小|
|orderField|否|String| 商品排序字段|
|orderSort|否|String| 商品排序方式 desc 倒序 asc 正序|

###请求参数Json格式
 
```
{
 "orderId" : "String",
 "isOrderRefund" : true,
 "isOrderOrderChange" : true,
 "isChangePrice" : true,
 "defaultUnit" : true,
 "isPrint" : true,
 "sword" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,

 "orderSort" : "String"
}
```
