# 协商退货

**请求URL：** 
- `/b2b/order/negotiate/refund `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|否|String| 订单id|
|refundTypeCode|否|String| 单据类型编码|
|refundTypeName|否|String| 单据类型名称|
|refundWay|否|Integer| 退货方式 0：部分退货 1：整单|
|attachmentUrl|否|String| 附件|
|refundReasonId|否|Long| 退货原因|
|remark|否|String| 备注|
|items|否|List| 协商退货商品行|
|--orderItemId|否|String| 商品行id|
|--refundAmount|否|Double| 商品退货价|
|--refundQuantity|否|Double| 商品退货数量|
|--expressAmount|否|Double| 商品运费|

###请求参数Json格式
 
```
{
 "orderId" : "String",
 "refundTypeCode" : "String",
 "refundTypeName" : "String",
 "refundWay" : 0,
 "attachmentUrl" : "String",
 "refundReasonId" : 0,
 "remark" : "String",
 "items" : [{
 "orderItemId" : "String",
 "refundAmount" : 0,
 "refundQuantity" : 0,
 "expressAmount" : 0
 }]
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
