# 极速下单商品项获取指定商品促销列表 -- 极速下单

**请求URL：** 
- `/b2b/shopping/cart/item/offline/findProductPromotionPlan`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|itemList|否|List| 商品列表|
|--itemId|否|String| 商品id|
|--specId|否|String| 规格id|
|companyId|否|String| 商户id|

### 请求参数Json格式
 
```
{
 "itemList" : [{
 "itemId" : "String",
 "specId" : "String"
 }],
 "companyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--itemId|否|String| 商品id|
|--specId|否|String| 规格id|
|--planList|否|List| 应用的限时特卖|
|----planId|否|String| 促销标识|
|----projectId|否|String| 方案标识|
|----planType|否|String| 促销类型|
|----planTypeName|否|String| 促销类型名称|
|----planName|否|String| 促销名称|
|----planTitle|否|String| 促销标题|
|----spType|否|String| 促销规则类型|
|----spTypeName|否|String| 促销规则类型描述|
|----boolCurrent|否|Boolean| 是否为当前选中商品|
|----hasGifts|否|Integer| 是否有赠品: 0-无；1-一个促销品清单；2-多个促销品清单|
|----planNickname|否|String| 规则别名|
|----promotionItemTimed|否|Object| 限时特卖商品价格和限购数量|
|------limitPurchases|否|Double| 限购数量|
|------specialPrice|否|Double| 指定价格|
|------itemId|否|String| 商品标识|
|------specId|否|String| 规格标识|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||

```
 "data" : [{

 "planList" : [{
 "planId" : "String",
 "projectId" : "String",
 "planType" : "String",
 "planTypeName" : "String",
 "planName" : "String",
 "planTitle" : "String",
 "spType" : "String",
 "spTypeName" : "String",
 "boolCurrent" : true,
 "hasGifts" : 0,
 "planNickname" : "String",
 "promotionItemTimed" : {
 "limitPurchases" : 0,
 "specialPrice" : 0,
 "itemId" : "String",
 "specId" : "String"
 }
 }]
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
