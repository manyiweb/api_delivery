# 订货单-按钮信息

**请求URL：** 
- `/b2b/orderDetail/b2bOrderButton`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|否|String| 订货单id|

### 请求参数Json格式
 
```
{
 "orderId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--canNegotiateOrder|否|Integer| 是否可以协商退货|
|--refundAccept|否|Integer| 退货受理|
|--canChangeOrder|否|Integer| 是否可以改单|
|--mayDeliver|否|Integer| 是否可以发货|
|--mayPicking|否|Integer| 是否可以拣配|
|--supplyingOrder|否|Integer| 是否是代发单|
|--maySupplyingOrder|否|Integer| 是否能代发商品|
|--canRefund|否|Boolean| 是否可退货|
|--isNegotiate|否|Integer| 是否协商退货|
|--isSync|否|Integer| 是否已经同步订单信息 0:未同步 1:已同步|
|--mayClose|否|Boolean| 是否允许关闭订货单|
|--manualDeliveryComplete|否|Integer| 手工发货完成 1是0否|
|--mayComplete|否|Boolean| 是否可以关闭|
|--isShortDelivery|否|Boolean| 差异标识 是否发货大于收货|
|--canDiffRefund|否|Boolean| 是否可以差异退款|
|--mayApplyRefund|否|Boolean| 是否退款过|
|--printStatus|否|Integer| 打印状态|
|--canTakePlanMode|否|Integer| 是否可以提货|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||

```
 "isSync" : 0,
 "mayClose" : true,
 "manualDeliveryComplete" : 0,
 "mayComplete" : true,
 "isShortDelivery" : true,
 "canDiffRefund" : true,
 "mayApplyRefund" : true,
 "printStatus" : 0,
 "canTakePlanMode" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
