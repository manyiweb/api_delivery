# 获取批量新增数据

**请求URL：** 
- `/b2b/wmc/order/getBatchList`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyList|否|List| 商户列表|
|--companyId|否|String| 商户ID|
|--companyCode|否|String| 商户code|
|--companyName|否|String| 商户名称|
|--merchantsTypeName|否|String| 商户名称|
|itemList|否|List| 商品列表|
|--itemUnit|否|String| 单位|
|--unitRate|否|Double| 单位|
|--quantity|否|Double| 基本数量|
|--itemQuantity|否|Double| 单位数量|
|--itemId|否|String||
|--itemCode|否|String||
|--itemName|否|String||
|--skuBarcode|否|String||
|--specId|否|String||
|--specName|否|String||
|--validDays|否|Integer||
|--itemTypeId|否|String||
|--unit|否|String||
|--brandName|否|String||
|--isStartBatch|否|Integer||
|--isStartBatch|否|Integer||
|--referenceCostPrice|否|Double||

|--colourName|否|String||
