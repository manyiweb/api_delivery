# 第三方支付退款失败信息
 

**请求URL：** 
- `/b2b/refund/th/detail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|refundTraceNos|是|List| 退款单号|

### 请求参数Json格式
 
```
{
 "refundTraceNos" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--hasRefundFailed|否|Boolean| 是否退款异常|
|--reason|否|String| 退款失败原因|
|--refundTraceNos|否|List| MOP第三方退款单号列表|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : {
 "hasRefundFailed" : true,
 "reason" : "String",
 "refundTraceNos" : null
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
