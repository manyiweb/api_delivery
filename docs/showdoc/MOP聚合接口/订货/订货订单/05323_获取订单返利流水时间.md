# 获取返利账户流水

**请求URL：** 
- `/b2b/funds/custom/account/getRecord `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 门店Id|
|orderId|否|String| 订单id|
|type|否|Integer| 单据类型 0订货订单，1订货退货单|

###请求参数Json格式
 
```
{
 "companyId" : "String",
 "orderId" : "String",
 "type" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--accountId|否|Long| 返利账户时间|
|--b2BFundsCustomAccountDays|否|List||
|----recordId|否|Long| 返利流水id|
|----date|否|String| 返利账户时间|
|----accountId|否|Long| 返利账户id|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : [{
 "accountId" : 0,
 "b2BFundsCustomAccountDays" : [{
 "recordId" : 0,
 "date" : "String",
 "accountId" : 0
 }]
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
