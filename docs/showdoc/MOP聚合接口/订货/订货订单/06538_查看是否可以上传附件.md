# 查看是否可以上传附件
 

**请求URL：** 
- `/config/order/attchments/set/get `

**请求方式：**
- POST
- FormData


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|groupId|否|String| 品牌商标识|
|companyId|否|String||
|tokenId|否|String||
|openId|否|String||

###请求参数Json格式
 
```
{
 "groupId" : "String",
 "companyId" : "String",
 "tokenId" : "String",
 "openId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long||
|--required|否|Integer| 是否必填0不必填1必填|
|--openAttachments|否|Integer| 是否开启上传附件0不开启 1开启|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "required" : 0,
 "openAttachments" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
