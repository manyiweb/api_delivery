# 订货订单单据类型列表
 

**请求URL：** 
- `/b2b/order/orderTypeList `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String||

###请求参数Json格式
 
```
{
 "companyId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--orderTypeList|否|List||
|----orderType|否|String| 单据类型 RoutineOrder常规订单、BookOrder预订订单|
|----orderTypeName|否|String| 单据类型 RoutineOrder常规订单、BookOrder预订订单|
|----docTypeList|否|List||
|------id|否|String||
|------orderDocTypeCode|否|String| 订单文档类型|
|------orderDocTypeName|否|String| 订单文档类型名称|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "orderTypeList" : [{
 "orderType" : "String",
 "orderTypeName" : "String",
 "docTypeList" : [{
 "id" : "String",
 "orderDocTypeCode" : "String",
 "orderDocTypeName" : "String"
 }]
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
