# 是否指定品牌价格清单

**请求URL：** 
- `/config/taxrate/SpecificPriceListResp`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 商户id|
|supplierId|否|String| 供应商id|

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "supplierId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--canModifyPrice|否|Boolean| 能否手动修改价格|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "canModifyPrice" : true
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
