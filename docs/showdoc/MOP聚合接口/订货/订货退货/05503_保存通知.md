# 保存通知

**请求URL：** 
- `/b2b/notice/save/notice`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|actionTypes|否|List| 信息类型|
|sourceId|否|String| 源id|
|openId|否|String| openId|
|wxSn|否|String| 微信sn|

### 请求参数Json格式
 
```
{
 "actionTypes" : null,
 "sourceId" : "String",
 "openId" : "String",
 "wxSn" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
