# 退货订单补录
 

**请求URL：** 
- `/b2b/refund/refundAppendRemark`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|否|String| 退货单id|
|refundRemark|否|String| 备注|
|refundObjUrl|否|List| 附件|
|attachmentIds|否|List| 附件id|
|orderItemReqs|否|List||
|--id|否|String||
|--remark|否|String||

### 请求参数Json格式
 
```
{
 "orderId" : "String",
 "refundRemark" : "String",
 "refundObjUrl" : null,
 "attachmentIds" : null,
 "orderItemReqs" : [{
 "id" : "String",
 "remark" : "String"
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
