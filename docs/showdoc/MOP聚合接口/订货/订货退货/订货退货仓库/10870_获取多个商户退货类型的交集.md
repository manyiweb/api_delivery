# 获取多个商户退货类型的交集
 

**请求URL：** 
- `/b2b/refund/warehouse/config/refundType/intersection`

**请求方式：** 
- `POST`
- `RequestBody`


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyIds|是|List||

### 请求参数Json格式
 
```
{
 "companyIds":null
}
```

### 响应参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--typeId|否|String| 类型id|
|--typeName|否|String| 类型名称|
|--typeCode|否|String| 类型编码|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 响应参数Json格式
 
```
{
 "data":[{
 "typeId":"String",
 "typeName":"String",
 "typeCode":"String"
 }],
 "msg":"String",
 "code":"String",
 "exceptionStackInfo":"String",
 "traceId":"String"
}
```
