# 获取退货仓库详情
 

**请求URL：** 
- `/b2b/refund/warehouse/config/detail`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String|公司ID |

### 请求参数Json格式
 
```
{
 "companyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long| 配置ID|
|--enabledRefundWarehouse|否|Boolean| 是否启用退货仓库功能|
|--companyId|否|String| 门店ID|
|--properties|否|List| 仓库配置列表|
|----id|否|Long||
|----whsId|否|String| 仓库id|
|----whsName|否|String| 仓库名称|
|----whsCode|否|String| 仓库编码|
|----defaultWarehouse|否|Boolean| 是否默认仓库|
|----refundTypeList|否|List| 退货类型列表|
|------typeId|否|String| 类型id|
|------typeName|否|String| 类型名称|
|------typeCode|否|String| 类型编码|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "enabledRefundWarehouse" : true,
 "companyId" : "String",
 "properties" : [{
 "id" : 0,
 "whsId" : "String",
 "whsName" : "String",
 "whsCode" : "String",
 "defaultWarehouse" : true,
 "refundTypeList" : [{
 "typeId" : "String",
 "typeName" : "String",
 "typeCode" : "String"
 }]
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
