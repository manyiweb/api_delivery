# 退货单变更日志-汇总

**请求URL：** 
- `/b2b/refund/changeOrder/getLog `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|否|String| 订单标识|

###请求参数Json格式
 
```
{
 "orderId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--logId|否|String| 日志id|
|--operatorName|否|String| 变更人|
|--modifyTime|否|DateTime| 变更时间|
|--content|否|String| 变更内容|
|--beforeVal|否|String| 变更前|
|--afterVal|否|String| 变更后|
|--hasDetail|否|Integer| 是否有变明细|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


###返回参数Json格式
 
```
{
 "data" : [{
 "logId" : "String",
 "operatorName" : "String",
 "modifyTime" : "DateTime",
 "content" : "String",
 "beforeVal" : "String",
 "afterVal" : "String",
 "hasDetail" : 0
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
