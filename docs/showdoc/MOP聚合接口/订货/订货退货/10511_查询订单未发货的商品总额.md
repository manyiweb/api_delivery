# 查询订单未发货的商品总额
 

**请求URL：** 
- `/b2b/order/surplus/itemAmount`

**请求方式：** 
- `POST`
- `RequestBody`


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|String||

### 请求参数Json格式
 
```
{
 "id":"String"
}
```

### 响应参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--totalRefundAmount|否|Double| 总退款金额（包含了需要退的运费）|
|--refundExpressFeeAmount|否|Double| 退款运费金额|
|--enableRefundExpressFee|否|Boolean| 是否开启退款运费|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 响应参数Json格式
 
```
{
 "data":{
 "totalRefundAmount":0,
 "refundExpressFeeAmount":0,
 "enableRefundExpressFee":true
 },
 "msg":"String",
 "code":"String",
 "exceptionStackInfo":"String",
 "traceId":"String"
}
```
