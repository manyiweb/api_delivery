# 退货订单改单

**请求URL：** 
- `/b2b/refund/changeOrder `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|remark|否|String| 备注|
|refundTypeCode|否|String| 退货类型code|
|applicationAmount|否|String| 获批金额|
|attachmentIds|否|List| 附件图片|
|refundGoodReasonId|否|String| 退货类型id|
|totalActualExpressFee|否|Integer| 累计运费|
|companyId|否|String| 门店id|
|sourceId|否|String| 开源单号id|
|refundId|否|String| 退货单id|
|items|否|List| 商品明细|
|--specId|否|String| 规则id|
|--quantity|否|String| 数量|
|--remark|否|String| 备注|
|--unit|否|String| 单位|
|--actualExpressFee|否|String| 获批运费|
|--refundMoney|否|Integer| 退货价|
|--sourceId|否|String| 来源id|
|--orderItemId|否|String| 来源id|

###请求参数Json格式
 
```
{
 "remark" : "String",
 "refundTypeCode" : "String",
 "applicationAmount" : "String",
 "attachmentIds" : null,
 "refundGoodReasonId" : "String",
 "totalActualExpressFee" : 0,
 "companyId" : "String",
 "sourceId" : "String",
 "refundId" : "String",
 "items" : [{
 "specId" : "String",
 "quantity" : "String",
 "remark" : "String",
 "unit" : "String",
 "actualExpressFee" : "String",
 "refundMoney" : 0,
 "sourceId" : "String",
 "orderItemId" : "String"
 }]
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|String||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


###返回参数Json格式
 
```
{
 "data" : "String",
 "msg" : "String",
 "code" : "String",

 "traceId" : "String"
}
```
