# 审核单据

**请求URL：** 
- `/b2b/order/itemAudit/audit `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|refundItemAudits|否|List| 审核的单据|
|--orderId|否|String| 订单id|
|--orderItemId|否|String| 订单明细id|
|--allowRefundQty|否|Double| 允许退货数量|
|--auditRemark|否|String| 审核备注|
|auditStatus|否|Integer| 审核的单据|

###请求参数Json格式
 
```
{
 "refundItemAudits" : [{
 "orderId" : "String",
 "orderItemId" : "String",
 "allowRefundQty" : 0,
 "auditRemark" : "String"
 }],
 "auditStatus" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Integer| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : 0,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
