# 退货单变更日志-明细

**请求URL：** 
- `/b2b/refund/changeOrder/getLogDetail `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|否|String||
|logId|否|String||

###请求参数Json格式
 
```
{
 "orderId" : "String",
 "logId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--beforeItems|否|List||
|----itemName|否|String|商品名称 |
|----itemCode|否|String|商品编码 |
|----barCode|否|String|sku |
|----qty|否|Double|数量 |
|----fid|否|String|fid |
|----specId|否|String|规格id |
|----itemUnit|否|String|单位 |
|----totalQuantity|否|Double|总数 |
|----itemId|否|String|商品id |
|----refundMoney|否|Double|商品id |
|----lineNum|否|Integer|单位组变更信息 |
|--afterItems|否|List||
|----itemName|否|String|商品名称 |
|----itemCode|否|String|商品编码 |
|----barCode|否|String|sku |
|----qty|否|Double|数量 |
|----fid|否|String|fid |
|----specId|否|String|规格id |
|----itemUnit|否|String|单位 |
|----totalQuantity|否|Double|总数 |
|----itemId|否|String|商品id |
|----refundMoney|否|Double|商品id |
|----lineNum|否|Integer|单位组变更信息 |
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
