# 订单类型列表
 

**请求URL：** 
- `/b2b/refundTypeConfig/refundList `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|否|String| tokenId|
|companyId|否|String| 门店id|
|itemIds|否|List| 商品ids|

###请求参数Json格式
 
```
{
 "tokenId" : "String",
 "companyId" : "String",
 "itemIds" : null
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--isOpen|否|Integer||
|--refundTypes|否|List| 订单类型列表|
|----codeId|否|String| appcode id|
|----refundTypeId|否|Long| 订单类型id|
|----refundTypeName|否|String| 业务类型|
|----refundTypeCode|否|String| 功能类型编码|
|----isDef|否|Integer| 是否默认|
|----applyItemType|否|Integer| 指定类型|
|----notHasItemIds|否|List| 当前类型不存在的itemId|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "isOpen" : 0,
 "refundTypes" : [{
 "codeId" : "String",
 "refundTypeId" : 0,
 "refundTypeName" : "String",
 "refundTypeCode" : "String",
 "isDef" : 0,
 "applyItemType" : 0,
 "notHasItemIds" : null
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
