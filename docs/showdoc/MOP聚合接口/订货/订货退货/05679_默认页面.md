#

@Title: findOrder </p>


@Description: 查询退货单</p>
 

**请求URL：** 
- `/b2b/refund/auditOrderItemList `

**请求方式：**
- undefined
- RequestBody


###请求参数<业务参数>
 
无参数


###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--pageIndex|否|Integer| 页码|
|--pageSize|否|Integer| 显示记录数|
|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|--first|否|Boolean| 首页|
|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|
|----orderId|否|String| 订单id|
|----orderItemId|否|String| 订单明细id|
|----orderType|否|String| 单据类型|
|----companyCode|否|String| 商户编码|
|----companyName|否|String| 商户名称|
|----orderNo|否|String| 订单编号|
|----auditStatus|否|Integer| 审核状态|
|----auditName|否|String| 审核状态名称|
|----itemType|否|String| 商品主分类|
|----applyRefQty|否|Double| 申请退货数量|
|----refundUnit|否|String| 退货单位|
|----baseRefundQty|否|Double| 退货总数|
|----allowRefundQty|否|Double| 允许退货数量|
|----itemName|否|String| 商品名称|
|----itemCode|否|String| 商品编码|
|----itemSku|否|String| 商品sku|
|----allowRefundTotalQty|否|Double| 允许退货总数|
|----orderItemRemark|否|String| 原商品明细备注|
|----auditRemark|否|String| 审核备注|
|----openItemAudit|否|Integer| 是否开启行审核|
|----itemUnit|否|Integer| 基本单位|
|----unitName|否|Integer| 当前单位|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
