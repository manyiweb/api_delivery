# 退货收货仓库列表

**请求URL：** 
- `/b2b/refund/receive/whs/list`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|refundId|是|String| 退货单id|
|sword|否|String||
|tokenId|否|String||
|pageIndex|否|Integer||
|pageSize|否|Integer||

### 请求参数Json格式
 
```
{
 "refundId" : "String",
 "sword" : "String",
 "tokenId" : "String",
 "pageIndex" : 0,
 "pageSize" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--pageIndex|否|Integer||
|--pageSize|否|Integer||
|--pageCount|否|Integer||
|--totalCount|否|Long||
|--first|否|Boolean||
|--last|否|Boolean||
|--content|否|List||
|----whsId|否|String| 仓库id|
|----whsName|否|String| 仓库名称|
|----whsCode|否|String| 仓库名称|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "pageIndex" : 0,
 "pageSize" : 0,
 "pageCount" : 0,
 "totalCount" : 0,
 "first" : true,
 "last" : true,
 "content" : [{
 "whsId" : "String",
 "whsName" : "String",
 "whsCode" : "String"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
