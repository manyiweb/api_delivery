# 订货订单批量申请退款

**请求URL：** 
- `/b2b/order/refund/batch/apply`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderIds|是|List| 申请退款的订单id|
|description|否|String| 退款原因|
|refundReasonCode|否|String| 退款原因编码|

### 请求参数Json格式
 
```
{
 "orderIds" : null,
 "description" : "String",
 "refundReasonCode" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
