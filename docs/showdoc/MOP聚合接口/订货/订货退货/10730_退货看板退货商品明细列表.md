# 退货看板退货商品明细列表

**请求URL：** 
- `/b2b/refund/receiving/item/query/v2`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|是|String||

### 请求参数Json格式
 
```
{
 "orderId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--content|否|List||
|----refundId|否|String| 退货单id|
|----refundItemId|否|String| 退货单明细id|
|----bomRecordId|否|String| 如果是bom这里是bom记录id,为空则不是bom|
|----itemCode|否|String| 商品编码|
|----itemId|否|String| 商品id|
|----skuBarcode|否|String| SKU码|
|----itemName|否|String| 商品名称|
|----specId|否|String| 规格id|
|----refundQuantity|否|Double| 退货数量|
|----itemUnit|否|String| 退货单位|
|----unit|否|String| 退货基本单位|
|----totalQuantity|否|Double| 退货总数|
|----returnedQuantity|否|Double| 已退数量|
|----baseReQuantity|否|Double| 已收数量|
|----unitRate|否|Double| 单位换算系数|
|----unitList|否|List| 收货单位|
|------itemId|否|String||
|------specId|否|String||
|------unitId|否|String||
|------unitName|否|String||
|------unitRate|否|Double||
|------costExpressFee|否|Double||
|------expressFee|否|Double||
|------isOrder|否|Object||
|------itemUnitPrice|否|Double|单位清单价 |
|------distributionPickingUnit|否|Boolean||
|------standardUnit|否|Boolean| 是否是标准单位|
|----referenceCostPrice|否|Double| 成本价|
|----memberPrice|否|Double| 会员价|
|----preReQuantity|否|Double| 预收货数量|
|----actualRefundAmount|否|Double| 实退金额|
|--pageSize|否|Integer||
|--pageNo|否|Integer||
|--total|否|Long||
|--totalPage|否|Integer||
|--hasNextPage|否|Boolean||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
