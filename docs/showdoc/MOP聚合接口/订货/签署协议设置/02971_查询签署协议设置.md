# 功能描述: 查询签署协议设置
 

**请求URL：** 
- `/config/b2b/agreementset/list `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 商户ID或品牌ID|

###请求参数Json格式
 
```
{
 "companyId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--isInherit|否|Integer| 是否继承品牌，取值：0 - 否， 1 - 是|
|--id|否|Long| 主键标识|
|--companyId|否|String| 商户ID（或品牌商ID）|
|--isUserAgreement|否|Integer| 启用用户协议(1-开启，0-不开启)|
|--isRequiredUserAgreement|否|Integer| 必须签署用户协议(1-开启，0-不开启)|
|--isPrivacyPolicy|否|Integer| 启用隐私政策(1-开启，0-不开启)|
|--isRequiredPrivacyPolicy|否|Integer| 必须签署隐私政策(1-开启，0-不开启)|
|--isCustomAgreement|否|Integer|启用补充协议(1-开启，0-不开启)|
|--isRequiredCustomAgreement|否|Integer|必须签署补充协议(1-开启，0-不开启)|
|--customAgreementName|否|String|补充协议名称|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : {
 "isInherit" : 0,
 "id" : 0,
 "companyId" : "String",
 "isUserAgreement" : 0,
 "isRequiredUserAgreement" : 0,
 "isPrivacyPolicy" : 0,
 "isRequiredPrivacyPolicy" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
