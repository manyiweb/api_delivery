# 功能描述: 保存设置
 

**请求URL：** 
- `/config/b2b/agreementset/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long|主键标识|
|companyId|是|String|商户ID（或品牌商ID）|
|isInherit|是|Integer|是否继承品牌，取值：0 - 否， 1 - 是|
|isUserAgreement|否|Integer|启用用户协议(1-开启，0-不开启)|
|isRequiredUserAgreement|否|Integer|必须签署用户协议(1-开启，0-不开启)|
|isPrivacyPolicy|否|Integer|启用隐私政策(1-开启，0-不开启)|
|isRequiredPrivacyPolicy|否|Integer|必须签署隐私政策(1-开启，0-不开启)|
|isCustomAgreement|否|Integer|启用补充协议(1-开启，0-不开启)|
|isRequiredCustomAgreement|否|Integer|必须签署补充协议(1-开启，0-不开启)|
|customAgreementName|否|String|补充协议名称|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "companyId" : "String",
 "isInherit" : 0,
 "isUserAgreement" : 0,
 "isRequiredUserAgreement" : 0,
 "isPrivacyPolicy" : 0,
 "isRequiredPrivacyPolicy" : 0,
 "isCustomAgreement" : 0,
 "isRequiredCustomAgreement" : 0,
 "customAgreementName" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
