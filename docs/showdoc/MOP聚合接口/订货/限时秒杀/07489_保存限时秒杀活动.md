# 保存限时秒杀活动
 

**请求URL：** 
- `/b2b/seckill/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|
|activityName|是|String| 活动名称|
|beginDate|是|DateTime| 开始时间|
|endDate|是|DateTime| 结束时间|
|rule|否|String| 活动规则|
|isActive|是|Boolean| 活跃状态|
|activityRestrict|是|Integer| 活动限制限制类型 0：不限制 1：限制|
|num|否|Integer| 活动限制限制数量|
|applyCompType|否|Integer| 应用门店类型 0：所有门店 1：指定门店|
|seckillActivityItems|是|List| 秒杀商品|
|--itemId|是|String| 商品id|
|--specId|是|String| 规格id|
|--seckillPrice|是|Double| 秒杀价|
|--seckillStock|是|Integer| 秒杀库存|
|--activityRestrict|否|Integer| 限制类型 0：不限制 1：限制|
|--num|否|Integer| 限制数量|
|companys|否|List| 应用门店列表|
|--companyCode|否|String||
|--companyName|否|String||
|--companyId|否|String||

### 请求参数Json格式
 
```
{
 "id" : 0,
 "activityName" : "String",
 "beginDate" : "DateTime",
 "endDate" : "DateTime",
 "rule" : "String",
 "isActive" : true,
 "activityRestrict" : 0,
 "num" : 0,
 "applyCompType" : 0,
 "seckillActivityItems" : [{
 "itemId" : "String",
 "specId" : "String",
 "seckillPrice" : 0,
 "seckillStock" : 0,
 "activityRestrict" : 0,
 "num" : 0
 }],
 "companys" : [{
 "companyCode" : "String",
 "companyName" : "String",
 "companyId" : "String"
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
