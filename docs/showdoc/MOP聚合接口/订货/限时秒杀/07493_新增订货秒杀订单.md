# 新增订货秒杀订单
 

**请求URL：** 
- `/b2b/sales/order/salesSeckillOrderAdd`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|否|String||
|openId|否|String| 小程序openId|
|wxSn|否|String| wxSn|
|itemId|否|String||
|specId|否|String||
|seckillId|否|String||
|companyId|否|String||
|shopCartKey|否|String| 如果是立即购买输入对应的立即购买cartKey|

### 请求参数Json格式
 
```
{
 "tokenId" : "String",
 "openId" : "String",
 "wxSn" : "String",
 "itemId" : "String",
 "specId" : "String",
 "seckillId" : "String",
 "companyId" : "String",
 "shopCartKey" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--orderId|否|String| 订货订单标识|
|--orderNo|否|String| 订货订单编号|
|--needPay|否|Integer| 订货是否需要支付|
|--amountActuallyPaid|否|Double| 需要支付的金額|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "orderId" : "String",
 "orderNo" : "String",
 "needPay" : 0,
 "amountActuallyPaid" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
