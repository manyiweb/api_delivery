# 小程序查询秒杀信息
 

**请求URL：** 
- `/b2b/seckill/query`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long| 活动id|
|companyId|是|String| 门店id|
|groupId|是|String| 品牌id|
|sword|否|String| 搜索关键词|
|pageIndex|否|Integer||
|pageSize|否|Integer||
|orderField|否|String||
|orderSort|否|String||

### 请求参数Json格式
 
```
{
 "id" : 0,
 "companyId" : "String",
 "groupId" : "String",
 "sword" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long| 活动id|
|--activityName|否|String| 活动名称|
|--rule|否|String| 活动规则|
|--beginDate|否|DateTime| 活动开始时间|
|--endDate|否|DateTime| 活动结束时间|
|--isActive|否|Boolean| 活跃状态|
|--activityRestrict|否|Integer| 活动限制类型 0：不限制 1：限制，前端需要先判断一道|
|--num|否|Integer| 活动限制每人数量|
|--seckillItems|否|Object| 秒杀商品|
|----pageIndex|否|Integer||
|----pageSize|否|Integer||
|----pageCount|否|Integer||
|----totalCount|否|Long||
|----first|否|Boolean||
|----last|否|Boolean||
|----content|否|List||
|------itemId|否|String| 商品id|
|------specId|否|String| 规格id|
|------imageUrl|否|String| 商品图片|
|------itemName|否|String| 商品名称|
|------seckillPrice|否|Double| 秒杀价|
|------seckillStock|否|Integer| 设置的秒杀库存|
|------seckillNum|否|Integer| 已经秒杀的数量|
|------originPrice|否|Double| 原始价格|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
