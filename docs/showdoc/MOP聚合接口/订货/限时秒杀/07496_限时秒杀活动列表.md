# 限时秒杀活动列表
 

**请求URL：** 
- `/b2b/seckill/list/{source}`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|keyword|否|String| 关键词(模糊搜索)|
|activityDate|否|Object| 有效期|
|--start|否|DateTime||
|--end|否|DateTime||
|isActive|否|List| 是否启用|
|activeCodes|否|List| 活跃状态-编号|
|createDate|否|Object| 创建日期|
|--start|否|DateTime||
|--end|否|DateTime||
|createIds|否|List| 创建人|

### 请求参数Json格式
 
```
{
 "keyword" : "String",
 "activityDate" : {
 "start" : "DateTime",
 "end" : "DateTime"
 },
 "isActive" : null,
 "activeCodes" : null,
 "createDate" : {
 "start" : "DateTime",
 "end" : "DateTime"
 },
 "createIds" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--content|否|List||
|----id|否|Long| 活动id|
|----activityCode|否|String| 活动编号|
|----activityName|否|String| 活动名称|
|----beginDate|否|String| 有效期开始|
|----endDate|否|String| 有效期结束|
|----isActive|否|Boolean| 是否启用|
|----isActiveName|否|String| 是否启用-中文|
|----activeStatus|否|String| 活动状态|
|----activeStatusName|否|String| 活动状态-中文|
|----createDate|否|DateTime| 创建时间|
|----createName|否|String| 创建人|
|--pageSize|否|Integer||
|--pageNo|否|Integer||
|--total|否|Long||
|--totalPage|否|Integer||
|--hasNextPage|否|Boolean||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
