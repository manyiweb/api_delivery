# 商品详情新增字段返回格式


### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long||
|activityName|否|String||
|beginDate|否|DateTime| 开始时间|
|endDate|否|DateTime| 结束时间|
|activityRestrict|否|Integer| 限制类型 0：不限制 1：限制|
|num|否|Integer| 限制数量|
|itemId|否|String||
|specId|否|String||
|seckillPrice|否|Double| 秒杀价|
|seckillStock|否|Integer| 设置的秒杀库存|
|seckillNum|否|Integer| 已经秒杀的数量|


### 返回参数Json格式
 
```
{
 "id" : 0,
 "activityName" : "String",
 "beginDate" : "DateTime",
 "endDate" : "DateTime",
 "activityRestrict" : 0,
 "num" : 0,
 "itemId" : "String",
 "specId" : "String",
 "seckillPrice" : 0,
 "seckillStock" : 0,
 "seckillNum" : 0
}
```
