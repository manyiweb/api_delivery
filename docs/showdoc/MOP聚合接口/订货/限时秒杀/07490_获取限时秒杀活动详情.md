# 获取限时秒杀活动详情

**请求URL：** 
- `/b2b/seckill/detail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||
|sword|否|String||

### 请求参数Json格式
 
```
{
 "id" : 0,
 "sword" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long| id|
|--activityCode|否|String| 活动编码|
|--activityName|否|String| 活动名称|
|--beginDate|否|DateTime| 开始时间|
|--endDate|否|DateTime| 结束时间|
|--rule|否|String| 活动规则|
|--isActive|否|Boolean| 活跃状态|
|--activityRestrict|否|Integer| 活动限制限制类型 0：不限制 1：限制|
|--num|否|Integer| 活动限制限制数量|
|--applyCompType|否|Integer| 应用门店类型 0：所有门店 1：指定门店|
|--createName|否|String| 创建人|
|--createDate|否|DateTime| 创建时间|
|--companys|否|List| 指定门店列表|
|----id|否|Long| 主键|
|----seckillActivityId|否|Long| 秒杀活动id|
|----companyId|否|String| 门店id|
|----companyCode|否|String| 门店编码|
|----companyName|否|String| 门店名称|
|----dbKey|否|Integer||
|----groupId|否|String||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||

 }]
 },

}
