# 订货账户充值表添加或修改

**请求URL：** 
- `/b2b/account/recharge/saveOrUpdate`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long|id |
|accountType|是|String|账户类型，BASE：基础账户,CUSTOM：自定义账户 |
|customAccountId|否|Long|自定义账户id |
|amount|是|Double|充值面额 |
|remark|否|String|备注 |
|isActive|是|Boolean|是否活跃 |
|giveType|否|String|活动赠送类型，COUPON：优惠券 |
|applyType|是|Integer|应用类型，0：所有门店，1：指定门店 |
|applyIds|否|List|应用id列表 |
|gives|否|List|赠品列表 |
|--giveId|是|String|赠品id |
|--giveAmount|是|Double|赠品数量 |
|giveAmount|否|Boolean|是否赠送金额 |
|amountGiveDto|否|Object| 金额赠送类型|
|--id|否|Long| 主键|
|--accountRechargeId|否|Long| 账户id|
|--giveAmountType|否|Integer| 赠送类型 0固定金额 1比例|
|--giveAmount|否|Double| 赠送金额或比例|
|--accountId|否|Long| 账户id|
|--accountName|否|String| 账户名称|
|--dateType|否|Integer| 日期类型 0 指定天数 1 指定有效期 2指定截止日期|
|--validDays|否|Integer| 有效天数|
|--startActiveDate|否|String| 有效期开始日期|
|--activeDate|否|String| 有效期结束日期|

```
 }

```
