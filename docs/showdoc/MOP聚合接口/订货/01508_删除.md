# 删除

**请求URL：** 
- `/b2b/reserve/removeProduct `

**请求方式：**
- POST
- RequestBody


### 请求示例
请求参数
```
{
 "tokenId":"beeca8c2caf147c28a5992082a071ed9",
 "itemIds": ["99fa2e080dce415a934ef11b4c05ff15", "ea5409cb02a143db92e509a689813841"]
}
```
返回结果
```
{
"data": null,
"msg": null,
"code": "200"
}
```

###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|itemIds|否|List| 商品id集合|

###请求参数Json格式
 
```
{
 "itemIds" : []
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String"
}
```
