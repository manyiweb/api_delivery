# 结算单详情
 

**请求URL：** 
- `/b2b/Db2bOrderBill/detail `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|String| 单据标识|
|sword|否|String| 搜索|
|groupId|否|String| 品牌商Id|

###请求参数Json格式
 
```
{
 "id" : "String",
 "sword" : "String",
 "groupId" : "String"
}
```
