# 新增结算订单
 

**请求URL：** 
- `/b2b/Db2bOrderBill/addGOrder `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 商户|
|payTypeCode|是|String|付款方式|
|payDate|是|String| 收款日期|
|remark|否|String| 订单备注|
|ReqDb2bOrderBillDetail|是|List| 详情|
|--type|是|Integer| 单据类型(1订单,0退货)|
|--sourceId|是|String| 订单Id|
|--money|否|Double| 本次收款金额|
|--preferentialMoney|否|Double| 优惠金额|
|--remark|否|String| 备注|
|orderStatus|是|Integer| 订单状态|
|id|否|String| 主键（编辑）|
|delIds|否|List| 删除id|

###请求参数Json格式
 
```
{
 "companyId" : "String",
 "payTypeCode" : "String",
 "payDate" : "String",
 "remark" : "String",
 "ReqDb2bOrderBillDetail" : [{
 "type" : 0,
 "sourceId" : "String",
 "money" : 0,
 "remark" : "String"
 }],
 "orderStatus" : 0,
 "id" : "String",
 "delIds" : null
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String"
}
```
