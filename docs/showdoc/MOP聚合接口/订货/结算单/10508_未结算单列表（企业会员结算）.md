# 未结算单列表（企业会员结算）
 

**请求URL：** 
- `/b2b/Db2bOrderBill/unliquidated/order/member`

**请求方式：** 
- `POST`
- `RequestBody`


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|pageIndex|否|Integer| 页码值|
|pageSize|否|Integer| 页大小|
|memberId|否|String| 会员Id|
|companyIds|否|List| 门店Id列表|

### 请求参数Json格式
 
```
{
 "pageIndex":0,
 "pageSize":0,
 "memberId":"String",
 "companyIds":null
}
```

### 响应参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--pageIndex|否|Integer| 页码|
|--pageSize|否|Integer| 显示记录数|
|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|--first|否|Boolean| 首页|
|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|
|----orderId|否|String| 单据id|
|----orderNo|否|String| 单号|
|----orderType|否|String| 单据类型|
|----orderTypeName|否|String| 单据类型(名称)|
|----companyName|否|String| 门店名称|
|----amountReceivable|否|String|应收金额|
|----amountReceived|否|String| 已收金额|
|----unpaidAmount|否|String| 未收金额|
|----refundAmount|否|String| 退款金额|
|----remark|否|String| 备注|
|----createDate|否|DateTime| 创建时间|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 响应参数Json格式
 
```
{
 "data":{
 "pageIndex":0,
 "pageSize":0,
 "pageCount":0,
 "totalCount":0,
 "first":true,
 "last":true,

 "orderId":"String",
 "orderNo":"String",
 "orderType":"String",
 "orderTypeName":"String",
 "companyName":"String",
 "amountReceivable":"String",
 "amountReceived":"String",
 "unpaidAmount":"String",
 "refundAmount":"String",
 "remark":"String",
 "createDate":"DateTime"
 }]
 },
 "msg":"String",
 "code":"String",
 "exceptionStackInfo":"String",
 "traceId":"String"
}
```
