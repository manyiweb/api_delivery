# 结算单列表
 

**请求URL：** 
- `/file/Db2bOrderBill/export `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|pageIndex|否|Integer| 页码值|
|pageSize|否|Integer| 页大小|
|sword|否|String| 单据编码|
|remark|否|String|备注|
|statusCodes|否|List|状态|
|payTypeCodes|否|List| 付款方式|
|payDateStart|否|String| 收款日期 开始|
|payDateEnd|否|String| 收款日期 到|
|createDateStart|否|String| 创建时间 开始|
|createDateEnd|否|String| 创建时间 到|
|id|否|String| 主键|
|orderSort|否|String| 排序方式 asc 升序/ desc 降序|
|orderField|否|String| 排序字段 companyId 商户id, totalMoney 金额, payDate 付款日期;|
|type|否|String| 3 - 整单导出, 1 - 导出明细|
###请求参数Json格式
 
```
{
 "pageIndex" : 0,
 "pageSize" : 0,
 "sword" : "String",
 "remark" : "String",
 "statusCodes" : null,
 "payTypeCodes" : null,
 "payDateStart" : "String",
 "payDateEnd" : "String",
 "createDateStart" : "String",
 "createDateEnd" : "String",
 "id" : "String",
 "orderSort" : "String",
 "orderField" : "String",
 "type" : "String",
}
```
