# 可添加结算单的单据
 

**请求URL：** 
- `/b2b/Db2bOrderBill/unliquidated/order`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|pageIndex|否|Integer| 页码值|
|pageSize|否|Integer| 页大小|
|orderType|否|List| 单据类型|
|sword|否|String| 搜索|
|companyId|是|String| 商户Id|
|sendWhsName|否|List| 发货仓|
|startDate|否|DateTime| 开始日期|
|endDate|否|DateTime| 结束日期|

### 请求参数Json格式
 
```
{
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderType" : null,
 "sword" : "String",
 "companyId" : "String",
 "sendWhsName" : null,
 "startDate" : "DateTime",
 "endDate" : "DateTime"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--pageIndex|否|Integer| 页码|
|--pageSize|否|Integer| 显示记录数|
|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|--first|否|Boolean| 首页|
|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|
|----orderId|否|String| 单据id|
|----orderNo|否|String| 单号|
|----orderTypeName|否|String| 单据类型|
|----companyName|否|String| 门店名称|
|----amountReceivable|否|String|应收金额|
|----amountReceived|否|String| 已收金额|
|----unpaidAmount|否|String| 未收金额|
|----remark|否|String| 备注|
|----type|否|Integer| 单据类型(0退货,1订单,2订货差异单)|
|----sendWhsName|否|String| (退货,订单)发货仓|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
