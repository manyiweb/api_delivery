# 查询结算单开票记录
 

**请求URL：** 
- `/hr/invoice/b2b/statement/records/{statementId}`

**请求方式：** 
- `POST`
- `FormData`


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|statementId|否|Long| |

### 请求参数Json格式
 
```
{
 "statementId":0
}
```

### 响应参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--type|否|String| 发票类型（Special/General）|
|--typeName|否|String| 发票类型（增值税专用发票/增值税普通发票）|
|--invoiceTitle|否|String| 发票抬头|
|--taxNo|否|String| 纳税人识别号|
|--openAccountBank|否|String| 开户银行|
|--bankAccount|否|String| 银行账号|
|--companyAddress|否|String| 企业地址|
|--companyPhone|否|String| 企业电话|
|--noticePhone|否|String| 通知手机号|
|--noticeEmail|否|String| 通知邮箱|
|--receivingAddress|否|String| 收件人地址|
|--receivingName|否|String| 收件人|
|--invoiceType|否|Integer| 开票类型1,正票;2,红票|
|--integrateType|否|Integer| 0单张开票 1合并开票|
|--status|否|String| 状态|
|--statusDesc|否|String| 状态描述|
|--applyInvoiceDate|否|DateTime| 申请开票日期|
|--invoiceCode|否|String| 开票记录编码|
|--invoiceApplyId|否|Long| 开票申请记录id|
|--thirdInvoiceDetailId|否|Long| 第三方开票记录id|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
