# 查询结算单第三方开票明细
 

**请求URL：** 
- `/hr/invoice/b2b/statement/third-party-detail/{b2bInvoiceApplyId}`

**请求方式：** 
- `POST`
- `FormData`


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|b2bInvoiceApplyId|否|Long| |

### 请求参数Json格式
 
```
{
 "b2bInvoiceApplyId":0
}
```

### 响应参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--electronicInvoiceNo|否|String| 全电发票号码|
|--invoiceDate|否|DateTime| 开票时间|
|--outNo|否|String| 外部单号|
|--url|否|String| 发票url|
|--errorMsg|否|String| 错误信息|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 响应参数Json格式
 
```
{
 "data":{
 "electronicInvoiceNo":"String",
 "invoiceDate":"DateTime",
 "outNo":"String",
 "url":"String",
 "errorMsg":"String"
 },
 "msg":"String",
 "code":"String",
 "exceptionStackInfo":"String",
 "traceId":"String"
}
```
