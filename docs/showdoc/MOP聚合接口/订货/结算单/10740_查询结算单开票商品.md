# 查询结算单开票商品
 

**请求URL：** 
- `/hr/invoice/b2b/statement/products/{b2bInvoiceApplyId}`

**请求方式：** 
- `POST`
- `FormData`


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|b2bInvoiceApplyId|否|Long| |

### 请求参数Json格式
 
```
{
 "b2bInvoiceApplyId":0
}
```

### 响应参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--itemCode|否|String| 商品编码|
|--skuBarcode|否|String| 商品条码|
|--itemName|否|String| 商品名称|
|--invoiceableAmount|否|Double| 可开票金额|
|--invoicedAmount|否|Double| 已开票金额|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 响应参数Json格式
 
```
{
 "data":[{
 "itemCode":"String",
 "skuBarcode":"String",
 "itemName":"String",
 "invoiceableAmount":0,
 "invoicedAmount":0
 }],
 "msg":"String",
 "code":"String",
 "exceptionStackInfo":"String",
 "traceId":"String"
}
```
