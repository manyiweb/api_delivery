# 更新-结算单发票抬头

**请求URL：** 
- `/super/statement/update/invoiceHeader`

**请求方式：** 
- `POST`
- `RequestBody`


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|superStatementId|是|Long| 结算单ID|
|invoiceHeaderId|是|Long| 发票头ID|

### 请求参数Json格式
 
```
{
 "superStatementId":0,
 "invoiceHeaderId":0
}
```

### 响应参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 响应参数Json格式
 
```
{
 "data":null,
 "msg":"String",
 "code":"String",
 "exceptionStackInfo":"String",
 "traceId":"String"
}
```
