# 添加商品到购物车

**请求URL：** 
- `/b2b/shopping/cart/item/addShopCartItem `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|specId|否|String| 规格ID|
|itemQuantity|否|Double| 商品数量|
|itemUnit|否|String| 选择单位|
|balanceDue|否|Boolean| 付尾款|
|attrs|否|List| 属性值|
|--industryAttrId|否|Long||
|--value|否|String||
|remark|否|String| 备注|
|shopCartKey|否|String| 如果是立即购买输入对应的立即购买cartKey|

###请求参数Json格式
 
```
{
 "specId" : "String",
 "itemQuantity" : 0,
 "itemUnit" : "String",
 "balanceDue" : true,
 "attrs" : [{
 "industryAttrId" : 0,
 "value" : "String"
 }],
 "remark" : "String",
 "shopCartKey" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--itemKey|否|String| ItemKey|
|--totalQuantity|否|Double| 包含赠品或套餐内商品、换购的Item总量|
|--targetProductQuantity|否|Double| 目标修改商品的数量|
|--isBomItem|否|Integer| 是否为模板BOM 0-否 1-是|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "itemKey" : "String",
 "totalQuantity" : 0,
 "targetProductQuantity" : 0,
 "isBomItem" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
