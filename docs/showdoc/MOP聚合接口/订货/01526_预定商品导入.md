# Excel 导入预定商品 
 

**请求URL：** 
- `/file/import/reserve/excelAddProduct`

**请求方式：**
- POST
- FormData


###请求参数<业务参数>
 
![](http://192.168.1.72:8888/server/../Public/Uploads/2019-08-22/5d5e5b2528671.png)


###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--totalCount|否|Integer| 导入总数量|
|--successCount|否|Integer| 成功导入数量|
|--errorCount|否|Integer| 失败数|
|--dataJson|否|List| 返回数据|
|--downloadURL|否|String| 失败数据下载地址|
|msg|否|String| 消息|
|code|否|String| 业务代码|


###返回参数Json格式
 
```
{
 "data" : {
 "totalCount" : 0,
 "successCount" : 0,
 "errorCount" : 0,
 "dataJson" : null,
 "downloadURL" : "String"
 },
 "msg" : "String",
 "code" : "String"
}
```
