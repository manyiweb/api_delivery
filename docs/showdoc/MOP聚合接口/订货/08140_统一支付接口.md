# 支付
 

**请求URL：** 
- `/b2b/pay/v2/{payType}`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|否|String||
|orderType|是|String||
|paySubcategory|否|String||
|orderId|是|String||
|payAmount|是|Double||
|quickPayParameter|否|Object||
|--smsCode|是|String||
|--agreeid|是|String||
|--thpinfo|否|String||
|--bizType|否|Integer||
|isBatch|否|Boolean||
|openId|否|String||
|phone|否|String||
|companyId|否|String||
|ifLaterPay|否|Integer||
|sessionKey|否|String||

### 请求参数Json格式
 
```
{
 "tokenId" : "String",
 "orderType" : "String",
 "paySubcategory" : "String",
 "orderId" : "String",
 "payAmount" : 0,

 "smsCode" : "String",
 "agreeid" : "String",

}
```
