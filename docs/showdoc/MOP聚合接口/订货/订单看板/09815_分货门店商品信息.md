# 分货门店商品信息
 

**请求URL：** 
- `/b2b/picking/order/userSplitInfo`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|taskId|否|Long| 任务id|


### 请求参数Json格式
 
```
{
 "taskId" : 0,
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--taskId|否|Long|商品id|
|--itemName|否|String|商品编码 |
|--splitDate|否|DateTime|分配时间 |
|--invQuantity|否|Double|库存数 |
|--quantity|否|Double|订货数 |
|--unSplitQuantity|否|Double|剩余数量 |
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "taskId" : 0,
 "itemName" : "String",
 "splitDate" : "DateTime",
 "invQuantity" : 0,
 "quantity" : 0,
 "unSplitQuantity" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
