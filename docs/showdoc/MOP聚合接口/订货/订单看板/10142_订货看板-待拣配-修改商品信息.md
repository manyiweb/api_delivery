# 订货看板-待拣配-修改商品信息

**请求URL：** 
- `/b2b/need/distributionDashboard/updateB2bOrderItemList`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderItemIds|否|String| 订单明细id集合多个用“,”隔开|
|bomItemIds|否|String| 订单明细id集合多个用“,”隔开|
|distributionUnit|否|String| 配货单位|
|distributionQuantity|否|Double| 配货数量|
|distributionUnitRate|否|Double| 配货单位换算率|

### 请求参数Json格式
 
```
{
 "orderItemIds" : "String",
 "bomItemIds" : "String",
 "distributionUnit" : "String",
 "distributionQuantity" : 0,
 "distributionUnitRate" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
