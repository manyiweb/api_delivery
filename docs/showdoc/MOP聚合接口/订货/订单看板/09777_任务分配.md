# 任务分配
 

**请求URL：** 
- `/b2b/picking/order/taskAssignment`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|items|否|List| 商品列表|
|--id|否|Long| 任务id 更新的时候传入|
|--itemId|否|Double|商品id|
|--itemCode|否|String|商品编码 |
|--itemName|否|String|商品名称 |
|--specId|否|String|规格id |
|--pickingSplitIds|否|String|分货id列表 |
|--pickingOrderIds|否|String|拣配单ids |
|userIds|否|List| 分配人列表|
|isUpdate|否|Boolean||

### 请求参数Json格式
 
```
{
 "items" : [{
 "id" : 0,
 "itemId" : 0,
 "itemCode" : "String",
 "itemName" : "String",
 "specId" : "String",
 "pickingSplitIds" : "String",
 "pickingOrderIds" : "String"
 }],
 "userIds" : null,
 "isUpdate" : true
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--pageIndex|否|Integer||
|--pageSize|否|Integer||
|--pageCount|否|Integer||
|--totalCount|否|Long||
|--first|否|Boolean||
|--last|否|Boolean||
|--content|否|List||
|----itemId|否|Double|商品id|
|----itemCode|否|String|商品编码 |
|----itemName|否|String|商品名称 |
|----specId|否|String|规格id |
|----invQuantity|否|String|库存数 |
|----quantity|否|String|订货数 |
|----diffQuantity|否|String|差异数 |
|----pickingSplitIds|否|String|分货id列表 |
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
