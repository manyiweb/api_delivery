# 订单看板-订货-按商品

**请求URL：** 
- `/b2b/need/distributionDashboard/test`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|items|否|List||
|--distributionQuantity|否|Double| 配货数量|
|--orderId|否|String||
|--orderItemId|否|String||
|--specId|否|String| 规格id|
|--itemUnit|否|String| 规格id|
|--companyId|否|String| 门店id|
|--itemQuantity|否|Double| 数量|
|--rate|否|Double| 比例|
|--totalQuantity|否|Double| 总数|
|--bomId|否|String||
|--component|否|Integer||
|createTye|否|Integer||

### 请求参数Json格式
 
```
{
 "items" : [{
 "distributionQuantity" : 0,
 "orderId" : "String",
 "orderItemId" : "String",
 "specId" : "String",
 "itemUnit" : "String",
 "companyId" : "String",
 "itemQuantity" : 0,
 "rate" : 0,
 "totalQuantity" : 0,
 "bomId" : "String",
 "component" : 0
 }],
 "createTye" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
