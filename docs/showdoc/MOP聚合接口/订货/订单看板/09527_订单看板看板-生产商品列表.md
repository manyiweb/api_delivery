# 订单看板看板-生产商品列表

**请求URL：** 
- `/b2b/need/distributionDashboard/b2bOrder/produceItemList`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|batchProduce|否|Boolean| 点击批量生产时传true，后面传false，用于清除上次生成的数据|
|orderIds|否|List| 订货单ids|
|itemTypeIds|否|List| 单据类型|
|brandIds|否|List| 品牌id|
|seriesCodes|否|List| 系列编码|
|itemId|否|String||
|onHandQtyLteZero|否|Boolean| 仅显示配货后库存数小于等于0的记录|
|pageIndex|否|Integer||
|pageSize|否|Integer||
|orderField|否|String||
|orderSort|否|String||

### 请求参数Json格式
 
```
{
 "batchProduce" : true,
 "orderIds" : null,
 "itemTypeIds" : null,
 "brandIds" : null,
 "seriesCodes" : null,
 "itemId" : "String",
 "onHandQtyLteZero" : true,
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String"
}
```
