# 订单看板-订货-按商品

**请求URL：** 
- `/b2b/need/distributionDashboard/whc/saveItemCompanyPickQuantity`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 门店id|
|specId|否|String| 规格id|
|distributionTotalQuantity|否|Double| 配货总数|
|unit|否|String| 单位|
|rate|否|Double| 比例|
|distributionQuantity|否|Double| 现配数量|
|itemUnit|否|String| 单位|
|status|否|String| 状态|
|description|否|String||
|orderItemIds|否|String| 订单明细ids|
|bomItemIds|否|String| bom明细ids|

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "specId" : "String",
 "distributionTotalQuantity" : 0,
 "unit" : "String",
 "rate" : 0,
 "distributionQuantity" : 0,
 "itemUnit" : "String",
 "status" : "String",
 "description" : "String",
 "orderItemIds" : "String",
 "bomItemIds" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
