# 订单看板-订货-按商品

**请求URL：** 
- `/b2b/need/distributionDashboard/b2bOrderItemCompanyInfoList`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|specIds|否|List||
|specId|否|String||
|component|否|Integer||
|orderIds|否|String||
|companyId|否|String||
|orderIdsList|否|List||
|status|否|String||

### 请求参数Json格式
 
```
{
 "specIds" : null,
 "specId" : "String",
 "component" : 0,
 "orderIds" : "String",
 "companyId" : "String",
 "orderIdsList" : null,
 "status" : "String"
}
```
