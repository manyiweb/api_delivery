# 分货
 

**请求URL：** 
- `/b2b/picking/order/splitByUserTask`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|
|taskId|否|Long| 任务id|
|companyId|否|String| 门店id|
|splitQuantity|否|Double| 分货数量|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "taskId" : 0,
 "companyId" : "String",
 "splitQuantity" : 0
}
```
