# 订单看板-批量设置数量

**请求URL：** 
- `/b2b/need/distributionDashboard/whc/batchSetItemCompanyPickQuantity`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyIds|否|List| 门店id|
|specId|否|String| 规格id|
|distributionTotalQuantity|否|Double| 配货总数|
|status|否|String| 状态|

### 请求参数Json格式
 
```
{
 "companyIds" : null,
 "specId" : "String",
 "distributionTotalQuantity" : 0,
 "status" : "String"
}
```
