# 验货门店商品列表列表
 

**请求URL：** 
- `/b2b/picking/order/inspectionCompanyItemList`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|
|itemMTypes|否|List| 主分类|
|itemTypes|否|List| 次分类|
|pageIndex|否|Integer| 页码|
|pageSize|否|Integer| 页大小|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "itemMTypes" : null,
 "itemTypes" : null,
 "pageIndex" : 0,
 "pageSize" : 0
}
```
