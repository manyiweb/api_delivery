# 订单看板-订货-按单拣配

**请求URL：** 
- `/b2b/need/distributionDashboard/b2bOrderItemList`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|canPicking|否|Boolean| 可拣配数量>待拣配数量|
|wmcLineIds|否|List| 可拣配数量>待拣配数量|
|wmcCompanyIds|否|List| 配送门店|
|requestDate|否|Object| 到货日期|
|--start|否|DateTime||
|--end|否|DateTime||
|whsId|否|String| 仓库id|
|status|否|String| 仓库id|
|batchDistribution|否|Boolean| 点击批量配货时传true，后面传false，用于清除上次生成的数据|
|wmcLineIds|否|List| 可拣配数量>待拣配数量|
|orderIds|否|List| 订货单id|
|orderNo|否|String| 订货单号|
|orderDocTypeName|否|List| 单据类型|
|lineId|否|List| 订货路线|
|companyIds|否|List| 门店id|
|itemTypefCodes|否|List| 商品分类 路径编码|
|specIds|否|List| 规格id|
|pickingStatus|否|List| 规格id|
|onHandQtyLteZero|否|Boolean| 仅显示配货后库存数小于等于0的记录|
|onHandQtyBeginGteSafeQty|否|Boolean| 仅显示配货前库存数>=最小安全库存数的行|
|pageIndex|否|Integer||
|pageSize|否|Integer||
|orderField|否|String||
|orderSort|否|String||
