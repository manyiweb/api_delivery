# 购物车优惠券满足条件查询
 

**请求URL：** 
- `/b2b/shopping/cart/useCouponLimit`

**请求方式：** 
- `POST`
- `RequestBody`


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|couponGetId|是|String||

### 请求参数Json格式
 
```
{
 "couponGetId":"String"
}
```

### 响应参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--satisfyCondition|否|Boolean| 是否满足条件|
|--conditionType|否|Integer| 0 金额 1数量|
|--couponName|否|String| 优惠券名称|
|--msg|否|String| 提示语|
|--diffValue|否|Double| 差额|
|--availableItemsAmount|否|Double| 可用商品的总金额|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 响应参数Json格式
 
```
{
 "data":{
 "satisfyCondition":true,
 "conditionType":0,
 "couponName":"String",
 "msg":"String",
 "diffValue":0,
 "availableItemsAmount":0
 },
 "msg":"String",
 "code":"String",
 "exceptionStackInfo":"String",
 "traceId":"String"
}
```
