# 编辑

**请求URL：** 
- `/b2b/reserve/edit `

**请求方式：**
- POST
- RequestBody

### 请求示例
请求参数
```
{
 "tokenId": "beeca8c2caf147c28a5992082a071ed9",
 "itemId": "123",
 "onShelve": false,
 "openTimeLimit": false,
 "price": "123",
	"openStarQuantity": 0,
 "specList": [
 {
 "id": "1001",
 "price": "11"
 },
 {
 "id": "1002",
 "price": "112"
 }
 ],
 "beginTime": "11",
 "endTime": "22"
}
```
返回结果
```
{
"data": null,
"msg": null,
"code": "200"
}
```

###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|itemId|是|String||
|onShelve|否|Boolean||
|openTimeLimit|否|Boolean||
|beginTime|否|String||
|openStarQuantity|否|Boolean|是否启用起订量(1是 0否)|
|endTime|否|String||
|price|否|String||
|specList|否|List||
|--id|否|String||
|--price|否|String||
|--starQuantity|否|String|起订量|

###请求参数Json格式
 
```
{
 "itemId" : "String",
 "onShelve" : true,
 "openTimeLimit" : true,
 "beginTime" : "String",
 "endTime" : "String",
 "price" : "String",
 "specList" : [{
 "id" : "String",
 "price" : "String"
 }]
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String"
}
```
