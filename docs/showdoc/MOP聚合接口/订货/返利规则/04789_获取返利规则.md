# 

**请求URL：** 
- `/config/rebateRule/getById `

**请求方式：**
- ALL
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|

###请求参数Json格式
 
```
{
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--Id|否|Long||
|--ruleName|否|String| 返利规则名称|
|--description|否|String| 返利规则说明|
|--activeState|否|Integer| 活跃状态|
|--type|否|Integer| 类型，按订单金额/商品数量|
|--ladder|否|Integer| 启用阶梯|
|--productType|否|Integer| 指定商品设置 0所有商品 1指定商品 2指定类别品牌系列|
|--ruleCode|否|String||
|--ladderDTOList|否|List| 阶梯式返利规则设置|
|----id|否|Long||
|----couponNames|否|String| 所有优惠卷拼接总名|
|----couponDTOList|否|List| 优惠卷列表|
|------id|否|Long||
|------couponName|否|String| 优惠卷名称|
|------couponId|否|String| 优惠卷id|
|------couponCode|否|String| 优惠卷编码|
|------couponQuantity|否|Integer| 优惠卷数量|
|------ladderId|否|Long| 阶梯的id|
|----credit|否|Integer| 积分|
|----minimum|否|Integer| 下限（最少的元或单位数量）|
|----isIntegral|否|Integer| 是否启用积分|
|----isCoupon|否|Integer| 是否启用优惠卷|
|----isAccount|否|Boolean| 是否启用自定义账户|
|----accountId|否|Long| 返利账户|
|----dateType|否|Integer| 有效期类型 0：自定义有效期 1：长期有效|
|----validDays|否|Integer| 自定义有效期天数|
|----amountType|否|Integer| 金额类型 0：按固定比例 1：按固定金额|
|----amount|否|Double| 返利金额|
|--itemDTOList|否|List| 与返利规则关联的所有商品|
|----id|否|Long||
|----itemId|否|String| 商品id|
|----itemName|否|String| 商品名称|
|----itemCode|否|String| 商品编码|
|----itemQuantity|否|Integer| 商品数量|
|----unit|否|String| 计量单位|
|----specId|否|String| 规格标识|
|----specName|否|String| 规格名称|
|----skuBarcode|否|String| 商品条码|
|----salesPrice|否|Double| 售价|
|--itemExclDTOList|否|List| 与返利规则关联的所有排除商品|
|----id|否|Long||
|----itemId|否|String| 商品id|
|----itemName|否|String| 商品名称|
|----itemCode|否|String| 商品编码|
|----itemQuantity|否|Integer| 商品数量|
|----unit|否|String| 计量单位|
|----specId|否|String| 规格标识|
|----specName|否|String| 规格名称|
|----skuBarcode|否|String| 商品条码|
|----salesPrice|否|Double| 售价|
|--categoryBrandSeriesDTOList|否|List| 指定品牌、系列、分类|
|----id|否|Long||
|----itemId|否|String| 选项id|
|----itemCode|否|String| 选项编码|
|----itemName|否|String| 选项名称|
|----type|否|Integer| 选项名称 0分类、1品牌、2系列|
|--categoryBrandSeriesExclDTOList|否|List| 指定品牌、系列、分类 [或排除]|
|----id|否|Long||
|----itemId|否|String| 选项id|
|----itemCode|否|String| 选项编码|
|----itemName|否|String| 选项名称|
|----type|否|Integer| 选项名称 0分类、1品牌、2系列|
|--createName|否|String| 创建人名称|
|--createDate|否|DateTime| 创建时间|
|--excl|否|Integer| 是否排除 0不排除 1排除|
|--rewardType|否|Integer| 返利到账方式 0：自动审核到账 1：人工审核到账|
|--rebateType|否|Integer| 返利维度 0:满返 1：每满返|
|--ruleOrderType|否|Integer| 返利维度 0:全部 1：常规 2月结|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
