# 订货价格应用 - 编辑

**请求URL：** 
- `/product/pricelist/b2b/edit `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|fid|否|String| 清单ID|
|companyId|否|String| 门店ID|
|companyGradeId|否|Long| 门店等级id|
|companyGradeCode|否|String| 门店等级编码|
|priceListId|否|String| 价格清单ID|
|benginDate|否|DateTime| 开始时间|
|endDate|否|DateTime| 结束时间|
|tokenId|否|String| 用户标识|
|openDiscount|否|Integer| 启用清单折扣 1是0否|
|discountType|否|Integer| 折扣方式 0按分类 1按品牌|
|types|否|List| 品牌/分类 列表|
|--typeId|否|String| 品牌ID/分类ID|
|--discountRate|否|Double| 折扣率|
|delTypeIds|否|List| 需要删除的类型id|

###请求参数Json格式
 
```
{
 "fid" : "String",
 "companyId" : "String",
 "companyGradeId" : 0,
 "companyGradeCode" : "String",
 "priceListId" : "String",
 "benginDate" : "DateTime",
 "endDate" : "DateTime",
 "tokenId" : "String",
 "openDiscount" : 0,
 "discountType" : 0,
 "types" : [{
 "typeId" : "String",
 "discountRate" : 0
 }],
 "delTypeIds" : null
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|String| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : "String",
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
