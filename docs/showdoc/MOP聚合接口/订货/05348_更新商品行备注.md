# 更新商品行备注

**请求URL：** 
- `/b2b/order/update/itemRemark`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|是|String|订单id|
|orderItemId|是|String|行id|
|orderRemark|否|String|整单备注 |
|remark|否|String|商品备注|

### 请求参数Json格式
 
```
{
 "orderId" : "String",
 "expectedDate" : "DateTime",
 "orderItemId" : "String",
 "orderRemark" : "String",
 "logisticsProviderId" : "String",
 "logisticsProviderCode" : "String",
 "logisticsProviderName" : "String",
 "remark" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
