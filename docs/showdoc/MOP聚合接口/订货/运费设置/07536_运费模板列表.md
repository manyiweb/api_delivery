# 运费模板列表

**请求URL：** 
- `/config/b2b/freight/template/list/{source}`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|keyword|否|String| 订单编号|
|status|否|List| 启用状态|
|logisticsName|否|List| 物流商|
|createDate|否|Object| 创建日期|
|--start|否|DateTime||
|--end|否|DateTime||
|createId|否|List| 创建人|
|id|否|String||
|pageSize|否|Integer||
|pageNo|否|Integer||
|sortField|否|String||
|sortDirection|否|String||
|viewId|否|String||

### 请求参数Json格式
 
```
{
 "keyword" : "String",
 "status" : null,
 "logisticsName" : null,
 "createDate" : {
 "start" : "DateTime",
 "end" : "DateTime"
 },
 "createId" : null,
 "id" : "String",
 "pageSize" : 0,
 "pageNo" : 0,
 "sortField" : "String",
 "sortDirection" : "String",
 "viewId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--content|否|List||
|----id|否|Long||
|----templateName|否|String| 模板名称|
|----status|否|Integer| 状态|
|----statusString|否|Integer| 状态|
|----logisticsName|否|String| 物流商名称|
|----createDate|否|DateTime| 创建时间|
|----createName|否|DateTime| 创建人|
|--pageSize|否|Integer||
|--pageNo|否|Integer||
|--total|否|Long||
|--totalPage|否|Integer||
|--hasNextPage|否|Boolean||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
