# 运费模板应用

**请求URL：** 
- `/config/b2b/freight/template/apply`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|lineId|是|String| 路线id|
|templates|否|List| 区域 (编辑时没有变动可以不传)|
|--templateId|否|Long| 模板id|

### 请求参数Json格式
 
```
{
 "lineId" : "String",
 "templates" : [{
 "templateId" : 0,
 "templateName" : "String",
 "templateCode" : "String",
 "logisticsName" : "String",
 "logisticsCode" : "String",
 "createDate" : "String",
 "createName" : "String"
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
