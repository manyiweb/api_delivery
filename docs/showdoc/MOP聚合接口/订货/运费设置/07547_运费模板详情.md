# 运费模板详情

**请求URL：** 
- `/config/b2b/freight/template/detail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||
|sword|否|String||

### 请求参数Json格式
 
```
{
 "id" : 0,
 "sword" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long| 主键id|
|--templateName|否|String| 模板名称|
|--status|否|Integer| 状态 0关闭 1启用|
|--logisticsName|否|String| 物流商名称|
|--logisticsCode|否|String| 物流商编码|
|--regions|否|List| 区域 (编辑时没有变动可以不传)|
|----areas|否|List| 区域|
|------areaName|否|String| 配送区域|
|------areaCode|否|String| 区域编码|
|------level|否|Integer| 区域级别|
|----firstWeight|否|Double| 首重|
|----firstFreight|否|Double| 首重运费|
|----continuedWeight|否|Double| 续重|
|----continuedFreight|否|Double| 续重运费|
|--createDate|否|DateTime| 创建时间|
|--createName|否|String| 创建人|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "templateName" : "String",
 "status" : 0,
 "logisticsName" : "String",
 "logisticsCode" : "String",
 "regions" : [{
 "areas" : [{
 "areaName" : "String",
 "areaCode" : "String",
 "level" : 0
 }],
 "firstWeight" : 0,
 "firstFreight" : 0,
 "continuedWeight" : 0,
 "continuedFreight" : 0
 }],
 "createDate" : "DateTime",
 "createName" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
