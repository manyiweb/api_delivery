# 功能描述: 订货限购量明细维护
 

**请求URL：** 
- `/b2b/order/limit/product/edit `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 商户标识，与syscompany关联|
|addProducts|否|List| 新增/编辑限购量明细|
|--id|否|Long| ID|
|--itemId|否|String| 商品ID|
|--itemCode|否|String| 商品编码|
|--itemName|否|String| 商品名称|
|--specId|否|String| 规格ID|
|--specName|否|String| 规格名称|
|--skuBarcode|否|String| SKU码|
|--beginDate|否|DateTime| 开始时间|
|--endDate|否|DateTime| 结束时间|
|--limitQty|否|Double| 限购数量|
|--purchasedQty|否|Double| 已订货数量|
|--remainingQty|否|Double| 剩余可订货数量|
|--overbook|否|Boolean| 是否开启超订|
|--limitOverbookQty|否|Double| 超订限购量|
|--overbookPrice|否|Double| 超订单价|
|--overbookUnit|否|String| 超订单位|
|--overbookRemark|否|String| 超订描述|
|--modifyId|否|String| 修改人id|
|--modifyName|否|String| 修改人|
|--modifyDate|否|DateTime| 修改时间|
|delProductIds|否|List| 删除限购量明细ID|

###请求参数Json格式
 
```
{
 "companyId" : "String",
 "addProducts" : [{
 "id" : 0,
 "itemId" : "String",
 "itemCode" : "String",
 "itemName" : "String",
 "specId" : "String",
 "specName" : "String",
 "skuBarcode" : "String",
 "beginDate" : "DateTime",
 "endDate" : "DateTime",
 "limitQty" : 0,
 "purchasedQty" : 0,
 "remainingQty" : 0,
 "overbook" : true,
 "limitOverbookQty" : 0,
 "overbookPrice" : 0,
 "overbookUnit" : "String",
 "overbookRemark" : "String",
 "modifyId" : "String",
 "modifyName" : "String",
 "modifyDate" : "DateTime"
 }],
 "delProductIds" : null
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
