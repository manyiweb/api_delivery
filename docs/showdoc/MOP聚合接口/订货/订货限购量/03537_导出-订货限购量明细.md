# 功能描述: 导出-订货限购量
 

**请求URL：** 
- `/b2b/order/limit/product/export `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 门店ID|
|tokenId|否|String| 用户标识|

###请求参数Json格式
 
```
{
 "companyId" : "String",
 "tokenId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--fileUrl|否|String| 导出文件相对路径|
|--downloadURL|否|String| 导出文件下载路径|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : {
 "fileUrl" : "String",
 "downloadURL" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
