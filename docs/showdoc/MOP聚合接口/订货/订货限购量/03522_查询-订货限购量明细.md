# 功能描述: 获取订货限购量设置明细
 

**请求URL：** 
- `/b2b/order/limit/product/detail `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 门店ID|
|tokenId|否|String| 用户标识|
|pageIndex|否|Integer| 分页页码|
|pageSize|否|Integer| 分页大小|
|sword|否|String| 搜索关键字|

###请求参数Json格式
 
```
{
 "companyId" : "String",
 "tokenId" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "sword" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--inherit|否|Boolean| 是否继承品牌|
|--companyId|否|String| 商户标识，与syscompany关联|
|--enableB2bOrderLimit|否|Boolean| 是否启用订货限购量|
|--products|否|Object| 限购量明细（分页）|
|----pageIndex|否|Integer| 页码|
|----pageSize|否|Integer| 显示记录数|
|----pageCount|否|Integer| 总页数|
|----totalCount|否|Long| 总记录数|
|----first|否|Boolean| 首页|
|----last|否|Boolean| 尾页|
|----content|否|List| 分页数据|
|------id|否|Long| ID|
|------itemId|否|String| 商品ID|
|------itemCode|否|String| 商品编码|
|------itemName|否|String| 商品名称|
|------specId|否|String| 规格ID|
|------specName|否|String| 规格名称|
|------skuBarcode|否|String| SKU码|
|------beginDate|否|DateTime| 开始时间|
|------endDate|否|DateTime| 结束时间|
|------limitQty|否|Double| 限购数量|
|------purchasedQty|否|Double| 已订货数量|
|------remainingQty|否|Double| 剩余可订货数量|
|------overbook|否|Boolean| 是否开启超订|
|------limitOverbookQty|否|Double| 超订限购量|
|------overbookPrice|否|Double| 超订单价|
|------overbookUnit|否|String| 超订单位|
|------overbookRemark|否|String| 超订描述|
|------modifyId|否|String| 修改人id|
|------modifyName|否|String| 修改人|
|------modifyDate|否|DateTime| 修改时间|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
