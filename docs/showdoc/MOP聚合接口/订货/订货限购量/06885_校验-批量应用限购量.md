# 校验-批量应用限购量
 

**请求URL：** 
- `/b2b/order/limit/product/checkBatchItemsApply`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyIds|是|List| 商户标识，需要应用到的门店,必传|
|addProducts|否|List| 限购量订货商品,必传|
|--id|否|Long| ID|
|--itemId|是|String| 商品ID ,必传|
|--itemCode|是|String| 商品编码 ,必传|
|--itemName|是|String| 商品名称 ,必传|
|--specId|是|String| 规格ID ,必传|
|--specName|否|String| 规格名称 ,必传|
|--skuBarcode|是|String| SKU码 ,必传|
|--beginDate|是|DateTime| 开始时间 ,必传|
|--endDate|是|DateTime| 结束时间 ,必传|
|--limitQty|是|Double| 限购数量 ,必传|
|--purchasedQty|否|Double| 已订货数量|
|--remainingQty|否|Double| 剩余可订货数量|
|--overbook|是|Boolean| 是否开启超订|
|--limitOverbookQty|否|Double| 超订限购量|
|--overbookPrice|否|Double| 超订单价|
|--overbookUnit|否|String| 超订单位|
|--overbookRemark|否|String| 超订描述|
|mode|是|Integer| 模式 0：追加 1：覆盖 2：删除 必传|

### 请求参数Json格式
 
```
{
 "companyIds" : null,
 "addProducts" : [{
 "id" : 0,
 "itemId" : "String",
 "itemCode" : "String",
 "itemName" : "String",
 "specId" : "String",
 "specName" : "String",
 "skuBarcode" : "String",
 "beginDate" : "DateTime",
 "endDate" : "DateTime",
 "limitQty" : 0,
 "purchasedQty" : 0,
 "remainingQty" : 0,
 "overbook" : true,
 "limitOverbookQty" : 0,
 "overbookPrice" : 0,
 "overbookUnit" : "String",
 "overbookRemark" : "String",
 }],
 "mode" : 0
}
```
