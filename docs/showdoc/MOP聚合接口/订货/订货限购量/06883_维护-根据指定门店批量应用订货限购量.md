# 维护-根据指定门店批量应用订货限购量
 

**请求URL：** 
- `/b2b/order/limit/product/batchApplayItemCompany`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyIds|是|List| 商户标识，需要应用到的门店,必传|
|addProducts|否|List| 限购量订货商品,必传|
|--id|否|Long| ID|
|--itemId|是|String| 商品ID|
|--itemCode|是|String| 商品编码|
|--itemName|是|String| 商品名称|
|--specId|是|String| 规格ID|
|--specName|否|String| 规格名称|
|--skuBarcode|是|String| SKU码|
|--beginDate|是|DateTime| 开始时间|
|--endDate|是|DateTime| 结束时间|
|--limitQty|是|Double| 限购数量|
|--purchasedQty|否|Double| 已订货数量|
|--remainingQty|否|Double| 剩余可订货数量|
|--overbook|是|Boolean| 是否开启超订|
|--limitOverbookQty|否|Double| 超订限购量|
|--overbookPrice|否|Double| 超订单价|
|--overbookUnit|否|String| 超订单位|
|--overbookRemark|否|String| 超订描述|
|--modifyId|否|String| 修改人id|
|--modifyName|否|String| 修改人|
|--modifyDate|否|DateTime| 修改时间|
|mode|是|Integer| 模式 0：追加 1：覆盖 2：删除 必传|
|companyType|否|Integer| 模式 0指定1按条件|
|sword|否|String||
|tokenId|否|String||

|----maxValue|否|String||
|----isCustom|否|String||
