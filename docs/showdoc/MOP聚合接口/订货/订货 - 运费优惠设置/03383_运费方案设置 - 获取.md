# 获取运费方案设置
 

**请求URL：** 
- `{{config}}/config/v1/b2b/freightset/scheme/action/get `

**请求方式：**
- POST{
 "tokenId": "{{auth_token}}",
 "sword": "demoData"
}

- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|sword|否|String| 搜索关键字|

###请求参数Json格式
 
```
{
 "tokenId": "{{auth_token}}",
 "sword": "demoData"
}

```

###返回参数
 
 
- 用户表，储存用户信息

|字段|类型|空|默认|注释|
|:---- |:------- |:--- |-- -|------ |
|id |int(10) |否 | | |
|lineId |String |否 | | 线路id |
|lineName |String |否 | | 线路名称 |
|provinceName |String |是 | | 省份名称 |
|schemeType |String |是 | | 1按详细收货地址指定路线 2按地址省份指定路线 |


- 备注：无

```
 }

 },

 "monitorRequestId": "",
 "msg": ""
}

```
