# 获取运费方案删除线路
 

**请求URL：** 
- `{{config}}/config/v1/b2b/freightset/scheme/action/removeProvinceLine`

**请求方式：**
- POS

- RequestBody


###请求参数<业务参数>
 
 
- 用户表，储存用户信息

|字段|类型|空|默认|注释|
|:---- |:------- |:--- |-- -|------ |
|provinceName|否|String| 省份名称|
|lineId|否|String| 线路id|
|lineName|否|String| 线路名称|

###请求参数Json格式
 
```

{
 "tokenId": "{{auth_token}}",
 "ids": ["1052468301230393075"]
}

```

###返回参数
{
 "code": "200",
 "data": null,
 "exceptionStackInfo": "",
 "monitorRequestId": "",
 "msg": ""
}

```
 {
 "tokenId": "{{auth_token}}",
 "sword": "demoData"
}
```
