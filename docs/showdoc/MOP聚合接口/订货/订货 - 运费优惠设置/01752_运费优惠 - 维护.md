# 运费优惠 - 维护
 

**请求URL：** 
- `/b2b/freight/discount/set `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|lineId|否|String| 线路标识，与dlineset关联|
|openFreightDiscount|否|Integer| 启用运费优惠 1是0否|
|firstFree|否|Integer| 首次下单免邮 1是0否|
|openInterval|否|Integer| 启用区间运费优惠 1是0否|
|intervals|否|List| 运费优惠区间请求参数|
|--freightDiscountIntervalId|否|Long| ID|
|--beginDate|否|String| 开始时间|
|--endDate|否|String| 结束时间|
|--openFrequency|否|Integer| 开启下单次数设置 1是0否|
|--rules|否|List| 运费优惠区间规则|
|----id|否|Long| 运费优惠区间规则ID|
|----frequency|否|Integer| 第几次下单|
|----orderAmount|否|Double| 订单金额|
|----freight|否|Double| 运费|
|--delRuleIds|否|List| 需要删除的运费优惠区间规则id列表|
|delIntervalIds|否|List| 需要删除的区间运费优惠列表|

###请求参数Json格式
 
```
{
 "lineId" : "String",
 "openFreightDiscount" : 0,
 "firstFree" : 0,
 "openInterval" : 0,
 "intervals" : [{
 "freightDiscountIntervalId" : 0,
 "beginDate" : "String",
 "endDate" : "String",
 "openFrequency" : 0,
 "rules" : [{
 "id" : 0,
 "frequency" : 0,
 "orderAmount" : 0,
 "freight" : 0
 }],
 "delRuleIds" : null
 }],
 "delIntervalIds" : null
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
