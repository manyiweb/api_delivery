# 运费优惠 - 详情

**请求URL：** 
- `/b2b/freight/discount/get `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|lineId|否|String| 线路标识|

###请求参数Json格式
 
```
{
 "lineId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long| 运费优惠ID|
|--openFreightDiscount|否|Integer| 启用运费优惠 1是0否|
|--firstFree|否|Integer| 首次下单免邮 1是0否|
|--openInterval|否|Integer| 启用区间运费优惠 1是0否|
|--lineId|否|String| 线路标识，与dlineset关联|
|--createId|否|String| 创建人标识|
|--createName|否|String| 创建人|
|--createDate|否|DateTime| 创建时间|
|--modifyId|否|String| 修改人标识|
|--modifyName|否|String| 修改人名称|
|--modifyDate|否|DateTime| 修改时间|
|--dbKey|否|Integer| 分库标识|
|--groupId|否|String| 品牌商id|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "openFreightDiscount" : 0,
 "firstFree" : 0,
 "openInterval" : 0,
 "lineId" : "String",
 "createId" : "String",
 "createName" : "String",
 "createDate" : "DateTime",
 "modifyId" : "String",
 "modifyName" : "String",
 "modifyDate" : "DateTime",
 "dbKey" : 0,
 "groupId" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
