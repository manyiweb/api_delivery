# 订货运费-复制
 

**请求URL：** 
- `{{config}}/config/v1/b2b/freightset/action/copy`

**请求方式：**
- POS

- RequestBody


###请求参数<业务参数>
 
 
- 用户表，储存用户信息

|字段|类型|空|默认|注释|
|:---- |:------- |:--- |-- -|------ |
|provinceName|否|String| 省份名称|
|lineId|否|String| 线路id|
|lineName|否|String| 线路名称|

###请求参数Json格式
 
```

{
 "tokenId": "d597e02964ae4ce3a2a3cd6e6ac05a02",
 "fromLineId": "01a48e3da10640568ee180c8330ffd59",
 "toLines": [{
 "lineId": "142290bf15344b2eb09fc118d01a2f54",
 "lineName": "demoData",
 "lineCode": "demoData"
 },{
 "lineId": "d597e02964ae4ce3a2a3cd6e6ac05a02",
 "lineName": "demoData",
 "lineCode": "demoData"
 }]
}

```


###返回参数Json格式
 
 
- 用户表，储存用户信息

|字段|类型|空|默认|注释|
|:---- |:------- |:--- |-- -|------ |
|fromLineId |String |否 | | 从线路|
|toLines |String |否 | | 复制到线路 |
|lineId |String |否 | | 线路id |
|lineName |String |否 | | 线路名称 |
|lineCode |String |否 | | 线路编码 |

- 备注：无
