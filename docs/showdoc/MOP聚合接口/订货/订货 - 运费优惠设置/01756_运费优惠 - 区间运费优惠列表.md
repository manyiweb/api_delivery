# 运费优惠 - 区间运费优惠列表
 

**请求URL：** 
- `/b2b/freight/discount/interval/list `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 运费优惠标识，先从路线里拿到运费标识再读取区间运费优惠。如果id=null，本接口不用调用|
|pageIndex|否|Integer| 分页页码|
|pageSize|否|Integer| 分页大小|
|sword|否|String| 搜索关键字|

###请求参数Json格式
 
```
{
 "id" : 0,
 "pageIndex" : 0,
 "pageSize" : 0,
 "sword" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--pageIndex|否|Integer| 页码|
|--pageSize|否|Integer| 显示记录数|
|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|--first|否|Boolean| 首页|
|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|
|----id|否|Long| ID|
|----beginDate|否|DateTime| 开始时间|
|----endDate|否|DateTime| 结束时间|
|----createId|否|String| 创建人标识|
|----createName|否|String| 创建人|
|----createDate|否|DateTime| 创建时间|
|----modifyId|否|String| 修改人标识|
|----modifyName|否|String| 修改人名称|
|----modifyDate|否|DateTime| 修改时间|
|----freightDiscountId|否|Long| 运费优惠ID|
|----frequencys|否|List||
|------frequency|否|Integer| 第几次下单|
|------rules|否|List| 运费优惠间隔次数优惠规则列表|
|--------id|否|Long| 运费优惠区间规则ID|
|--------orderAmount|否|Double| 订单金额|
|--------freight|否|Double| 运费|
|--------frequency|否|Integer| 次数|
|----openFrequency|否|Integer| 开启下单次数设置 1是0否|
|----dbKey|否|Integer| 分库标识|
|----groupId|否|String| 品牌商id|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
