# 保存运费方案设置
 

**请求URL：** 
- `{{config}}/config/v1/b2b/freightset/scheme/action/update `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>

 
- 用户表，储存用户信息

|字段|类型|空|默认|
|:---- |:------- |:--- |-- -|------
|参数名|必选|类型|说明|
|type|是|int| 1按详细收货地址指定路线 2按地址省份指定路线 3按订货类型方案|


###请求参数Json格式
 
```
{
 "tokenId": "{{auth_token}}",
 "type": 2
}


```

###返回参数
 
 {
 "code": "200",
 "data": null,
 "exceptionStackInfo": "",
 "monitorRequestId": "",
 "msg": ""
}


###返回参数Json格式
 
```
 {
 "tokenId": "{{auth_token}}",
 "sword": "demoData"
}

```
