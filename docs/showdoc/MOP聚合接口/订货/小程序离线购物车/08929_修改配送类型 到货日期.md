# 修改配送类型 到货日期
 

**请求URL：** 
- `/b2b/mall/shopCart/offline/offlineShopCartDeliverySelection`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|deliveryType|是|String| 提货配送方式编码|
|expectedDate|否|DateTime| 提货日期/到货日期|
|companyId|否|String| 提货门店|
|expectDeliveryDate|否|DateTime| 发货日期|
|expectLogisticsProviderId|否|Long| 配送物流商id|
|expectLogisticsProviderName|否|String| 配送物流商|
|expectLogisticsProviderCode|否|String| 配送物流商|
|isSplitDelivery|否|Boolean| 启用订货拆单发货|
|isManualSelectDate|否|Boolean| 是否手动选择到货日期 true是，false为不是|
|openExpressFee|否|Boolean| 是否计算运费|
|shopCartKey|否|String| 如果是立即购买输入对应的立即购买cartKey|

### 请求参数Json格式
 
```
{
 "deliveryType" : "String",
 "expectedDate" : "DateTime",
 "companyId" : "String",
 "expectDeliveryDate" : "DateTime",
 "expectLogisticsProviderId" : 0,
 "expectLogisticsProviderName" : "String",
 "expectLogisticsProviderCode" : "String",
 "isSplitDelivery" : true,
 "isManualSelectDate" : true,
 "openExpressFee" : true,
 "shopCartKey" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
