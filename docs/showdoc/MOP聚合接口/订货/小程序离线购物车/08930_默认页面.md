# 新增订货订单
 

**请求URL：** 
- `/b2b/sales/order/mall/offline/add`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|否|String||
|openId|否|String| 小程序openId|
|wxSn|否|String| wxSn|
|combinationPayment|否|Boolean| 是否使用了主支付默认是true不计算自定义账户抵扣运费|
|draftOrder|否|Boolean| 草稿单号|
|refundOrderId|否|String| 关联的退货订单id(退货转订货才需要带上)|
|isB2bAfterCreateOrder|否|Boolean||
|calculateExpFee|否|Boolean| 是否计算运费|
|isOffLineOrder|否|Boolean| 是否离线订单|
|shopCartKey|否|String| 如果是立即购买输入对应的立即购买cartKey|

### 请求参数Json格式
 
```
{
 "tokenId" : "String",
 "openId" : "String",
 "wxSn" : "String",
 "combinationPayment" : true,
 "draftOrder" : true,
 "refundOrderId" : "String",
 "isB2bAfterCreateOrder" : true,
 "calculateExpFee" : true,
 "isOffLineOrder" : true,
 "shopCartKey" : "String"
}
```
