# 刷新离线购物车
 

**请求URL：** 
- `/b2b/mall/shopCart/offline/refReshOffLineShopCart`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|changeType|否|Integer| 变更类型（0 什么都不做 1修改备注 2修改地址 3修改配送方式 4修改到货日期 5使用积分抵扣 6修改物流商 7选择开票地址 8选择促销 9 使用优惠券 10 计算自定义账户）|
|shopCartKey|否|String| 如果是立即购买输入对应的立即购买cartKey|

### 请求参数Json格式
 
```
{
 "changeType" : 0,
 "shopCartKey" : "String"
}
```
