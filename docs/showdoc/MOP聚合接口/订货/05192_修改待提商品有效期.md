# 更改有效期

**请求URL：** 
- `/b2b/orderGiftPools/setValidityDate `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|activeDate|是|DateTime| 有效期|
|tokenId|是|String|token|
|id|是|String|提货明细id|
