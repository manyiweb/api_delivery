# 商品批量代发
 

**请求URL：** 
- `/b2b/sales/order/proxy/delivery/batch`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|是|String| 订单标识|
|remark|否|String| 代发备注|
|tokenId|否|String||
|orderItems|是|List| 代发商品，里面暂时只要一个orderItemId|
|--orderItemId|是|String| 订单行标识|
|--proxyCompanyId|是|String| 代发门店|
|--quantity|否|Double| 代发数量|
|--unit|否|String| 发货单位|
|--unitRate|否|Double| 单位换算|
|--logisticsId|否|String| 修改的物流|
|--remark|否|String||
|--settlementPrice|否|Double| 代发结算价|
|--bomItems|否|List|bom商品集合 |
|----proxyCompanyId|是|String||
|----quantity|否|Double||
|----bomQuantity|否|Double||
|----bomItemId|否|String||
|----deliveryRemark|否|String||
|----itemRemark|否|String||
|----unit|否|String||
|----unitRate|否|Double||
|----batchList|否|List||
|------batchCode|否|String||
|------productionDate|否|DateTime||
|------validDays|否|Integer||
|------quantity|是|Double||
|----barCodes|否|List||
|----itemName|否|String||
|----specName|否|String||
|----logisticsId|否|String||
|----itemId|否|String||
|----specId|否|String||
|billMoneyId|否|String| 打款单id|
|gatheringId|否|String| 打款单id|

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--needPay|否|Boolean| 需要支付|
|--orderId|否|String| 订单id|
|--payAmount|否|Double| 支付金额|
|--transId|否|String| 支付流水id|
|--proxyDeliveryId|否|String| 记录id|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
