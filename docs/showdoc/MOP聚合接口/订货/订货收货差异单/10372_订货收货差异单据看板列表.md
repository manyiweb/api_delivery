# 订货收货差异单据列表

**请求URL：** 
- `/b2b/receive/difference/kanban/list`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|sword|否|String| 订单编号|
|companyIds|否|String| 商户|
|status|否|String| 订单状态|
|sourceDocTypeNames|否|String| 来源单据类型|
|createIds|否|String| 创建人|
|createDate|否|Object| 创建日期|
|--start|否|DateTime||
|--end|否|DateTime||
|pageSize|否|Integer| 分页大小|
|pageNo|否|Integer| 页码|
|sortField|否|String| 排序字段|
|sortDirection|否|String| 排序方向|

### 请求参数Json格式
 
```
{
 "sword" : "String",
 "companyIds" : "String",
 "status" : "String",
 "sourceDocTypeNames" : "String",
 "createIds" : "String",
 "createDate" : {
 "start" : "DateTime",
 "end" : "DateTime"
 },
 "pageSize" : 0,
 "pageNo" : 0,

}
```
