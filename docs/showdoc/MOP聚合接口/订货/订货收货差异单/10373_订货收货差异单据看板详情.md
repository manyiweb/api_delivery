# 订货收货差异单据详情

**请求URL：** 
- `/b2b/receive/difference/kanban/detail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|是|Long| 订单id|

### 请求参数Json格式
 
```
{
 "orderId" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--content|否|List||
|----itemCode|否|String| 商品编码|
|----skuBarcode|否|String| SKU 码|
|----itemName|否|String| 商品名称|
|----quantity|否|Double| 总数|
|----realPrice|否|Double| 订货单价|
|----totalRealPrice|否|Double| 商品总额|
|--pageSize|否|Integer||
|--pageNo|否|Integer||
|--total|否|Long||
|--totalPage|否|Integer||
|--hasNextPage|否|Boolean||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "content" : [{
 "itemCode" : "String",
 "skuBarcode" : "String",
 "itemName" : "String",
 "quantity" : 0,
 "realPrice" : 0,
 "totalRealPrice" : 0
 }],
 "pageSize" : 0,
 "pageNo" : 0,
 "total" : 0,
 "totalPage" : 0,
 "hasNextPage" : true
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
