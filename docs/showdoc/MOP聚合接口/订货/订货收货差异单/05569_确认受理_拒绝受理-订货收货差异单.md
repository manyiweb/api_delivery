# 确认受理/拒绝受理-订货收货差异单

**请求URL：** 
- `/b2b/receive/difference/order/accept`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|sourceId|是|String| 订货订单id|
|responsibleParty|否|Integer| 差异责任方:3-品牌方;4-代发方;5-订货方|
|whsId|否|String| 退回仓库id|
|id|是|Long| 订货收货差异单id|
|statusCode|是|Integer| 审核状态：1-待受理，2-确认受理，3-拒绝受理|
|remark|否|String| 审核备注|

### 请求参数Json格式
 
```
{
 "sourceId" : "String",
 "responsibleParty" : 0,
 "whsId" : "String",
 "id" : 0,
 "statusCode" : 0,
 "remark" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|String| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : "String",
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
