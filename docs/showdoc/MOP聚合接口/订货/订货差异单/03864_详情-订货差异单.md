# 详情-订货差异单

**请求URL：** 
- `/b2b/difference/detail `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|

###请求参数Json格式
 
```
{
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--b2BDifferenceOrderDTO|否|Object| 订货差异单详情|
|----id|否|Long| 主键ID|
|----orderNo|否|String| 单据编码|
|----type|否|String| 单据类型|
|----typeName|否|String| 单据类型名称|
|----sourceId|否|String| 来源ID|
|----sourceNo|否|String| 来源单据编码|
|----sourceOrderType|否|String| 订货单据类型(RoutineOrder-常规订单、BookOrder-预订订单、MonthlyOrder-月结订货)|
|----sourceOrderTypeName|否|String| 订货单据类型(RoutineOrder-常规订单、BookOrder-预订订单、MonthlyOrder-月结订货)|
|----status|否|Integer| 状态；0待受理，1已完成，2已拒绝|
|----statusName|否|String| 状态名称|
|----statusRemark|否|String| 受理备注|
|----outWarehouseId|否|String| 发货仓id|
|----outWarehouseName|否|String| 发货仓名称|
|----inCompanyId|否|String| 收货门店ID|
|----inCompanyName|否|String| 收货门店名称|

|----processingTypeName|否|String| 差异处理类型名称(0-退还货款,1-追加货款)|

|----totalMoney|否|Double| 差异金额|
|----remark|否|String| 备注|
|----createId|否|String| 创建人id|
|----createName|否|String| 创建人|
|----createDate|否|DateTime| 创建时间|
|----modifyId|否|String| 修改人id|
|----modifyName|否|String| 修改人|
|----modifyDate|否|DateTime| 修改时间|
|----payStatusCode|否|String| 支付状态编码,取值：NP("未结算"),YP("已结算");|
|----payStatusName|否|String| 支付状态名称,取值：NP("未结算"),YP("已结算");|
|----payDate|否|DateTime| 支付时间|
|--acceptInfo|否|Object| 受理信息|
|----id|否|Long| id|
|----level|否|Integer| 审核总级数|
|----currentLevel|否|Integer| 当前审核级|
|----status|否|Integer| 流程状态 0待开始 1流转中 2已结束|
|----orderStatusRemark|否|String| 订单状态备注|
|----hasAuthority|否|Integer| 是否拥有审核权限 1是0否|
|----lastAcceptDate|否|DateTime| 最后受理时间|
|----lastAccept|否|Integer| 是否为最后一级审核 1是0否|
|--acceptRecords|否|List| 受理记录|
|----totalMoney|否|Double| 差异结算金额|
|----processingTypeName|否|String| 差异处理类型名称(0-退还货款,1-追加货款)|
|----id|否|Long| id|
|----acceptId|否|Long| 单据受理标识，与order_accept表关联|
|----orderId|否|String| 单据标识|
|----level|否|Integer| 当前审核级|
|----statusCode|否|String| 受理状态|
|----statusName|否|String| 受理状态描述|
|----remark|否|String| 受理备注|
|----createId|否|String| 创建人标识|
|----createName|否|String| 创建人名称|
|----createDate|否|DateTime| 创建时间|
|----modifyId|否|String| 修改人标识|
|----modifyName|否|String| 修改人|
|----modifyDate|否|DateTime| 修改时间|
|----dbKey|否|Integer| 分库标识|
|----groupId|否|String| 品牌商id|
|--sourceOrder|否|List| 关联业务|
|----orderType|否|String| 单据类型|
|----orderTypeName|否|String| 单据类型|
|----docTypeName|否|String| 单据业务类型名称|
|----companyId|否|String| 商户id|
|----orderNo|否|String| 单号|
|----quantity|否|Object| 数量|
|----orderId|否|String| 单据id|
|----companyName|否|String| 商户名称|
|----statusName|否|String| 单据状态|
|----createName|否|String| 创建人名称|
|----createDate|否|DateTime| 创建时间|
|----remark|否|String| 备注|
|----outOrderNo|否|String| 外部单号|
|----logisticsProviders|否|String| 物流商|
|----logisticsNumber|否|String| 物流单号|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
