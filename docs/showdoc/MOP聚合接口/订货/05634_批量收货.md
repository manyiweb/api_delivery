# 批量收货

**请求URL：** 
- `/b2b/order/batch/receiving`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|intelligenceDistributionId|是|Long| 配货单Id|
|items|是|List| 明细|
|--itemId|否|String| 商品Id|
|--specId|否|String| 规格Id|
|--quantity|否|Double| 收货数量|
|--unit|否|String| 收货单位|
|--remark|否|String| 备注|
|--bomItems|否|List| bom商品|
|--barCodes|否|List| 唯一码|
|--batchList|否|List| 批次信息|

### 请求参数Json格式
 
```
{
 "intelligenceDistributionId" : 0,
 "items" : [{
 "itemId" : "String",
 "specId" : "String",
 "quantity" : 0,
 "unit" : "String",
 "remark" : "String",
 "bomItems" : null,
 "barCodes" : null,
 "batchList" : null
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|resultInt|否|Integer||
|resultString|否|String||
|resultError|否|String||
|dataLine|否|Object||
|pageData|否|Object||
|--curPageNum|否|Integer||
|--totalPage|否|Integer||
|--totalCount|否|Integer||
|--pageSize|否|Integer||
|--items|否|List||
|--sortValues|否|Object||
|otherData|否|Map||
|lastCacheData|否|String| 最后缓存时间|


### 返回参数Json格式
 
```
{
 "resultInt" : 0,
 "resultString" : "String",
 "resultError" : "String",
 "dataLine" : null,
 "pageData" : {
 "curPageNum" : 0,
 "totalPage" : 0,
 "totalCount" : 0,
 "pageSize" : 0,
 "items" : null,
 "sortValues" : null
 },
 "otherData" : null,
 "lastCacheData" : "String"
}
```
