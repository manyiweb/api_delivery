# 商户智能标签添加或修改

**请求URL：** 
- `/b2b/company/intelligence/label/saveOrUpdate`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long||
|labelName|是|String|标签名称 |
|activity|否|Boolean|活跃状态 |
|enableDistributor|否|Boolean|是否启用所属经销商 |
|enableAssignItemConsumerCondition|否|Boolean|是否启用指定商品消费情况 |
|enableDays|否|Boolean|是否启用最近多少天内 |
|days|否|Long|最近多少天内 |
|enableCustomDate|否|Boolean|是否启用自定义日期 |
|customStartDate|否|DateTime|自定义开始时间 |
|customEndDate|否|DateTime|自定义结束时间 |
|consumerAmountStart|是|Double|起始消费金额 |
|consumerAmountEnd|是|Double|终止消费金额 |
|distributorList|否|List|经销商集合 |
|--distributorId|否|String|经销商id |
|--distributorName|否|String|经销商编码 |
|assignItemList|否|List|指定商品集合 |
|--itemId|否|String|商品id |
|--itemCode|否|String|商品编码 |
|--itemName|否|String|商品名称 |
|delAssignItemList|否|List|要删除的指定商品集合 |

### 请求参数Json格式
 
```
{
 "id" : 0,
 "labelName" : "String",
 "activity" : true,
 "enableDistributor" : true,
 "enableAssignItemConsumerCondition" : true,
 "enableDays" : true,
 "days" : 0,
 "enableCustomDate" : true,
 "customStartDate" : "DateTime",
 "customEndDate" : "DateTime",
 "consumerAmountStart" : 0,
 "consumerAmountEnd" : 0,
 "distributorList" : [{
 "distributorId" : "String",
 "distributorName" : "String"
 }],
 "assignItemList" : [{
 "itemId" : "String",
 "itemCode" : "String",
 "itemName" : "String"
 }],
 "delAssignItemList" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
