# 查询标签匹配的门店信息
 

**请求URL：** 
- `/b2b/company/intelligence/label/getLabelCompanyMappingByLabelIds `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|sword|否|String| 搜索关键字|
|list|否|List||

###请求参数Json格式
 
```
{
 "sword" : "String",
 "list" : null
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--id|否|Long||
|--labelId|否|Long||
|--companyId|否|String||
|--labelCode|否|String||
|--labelName|否|String||
|--companyCode|否|String||
|--companyName|否|String||
|--dbKey|否|Integer||
|--groupId|否|String||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


###返回参数Json格式
 
```
{
 "data" : [{
 "id" : 0,
 "labelId" : 0,
 "companyId" : "String",
 "labelCode" : "String",
 "labelName" : "String",
 "companyCode" : "String",
 "companyName" : "String",
 "dbKey" : 0,
 "groupId" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
