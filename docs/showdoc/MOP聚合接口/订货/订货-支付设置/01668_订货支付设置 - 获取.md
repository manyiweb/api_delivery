# 订货支付设置 - 获取
 

**请求URL：** 
- `/b2b/payconfig/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String||
|tokenId|否|String||

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "tokenId" : "String"
}
```
