# 添加发票信息
 

**请求URL：** 
- `/hr/invoiceHeader/add `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long||
|type|否|String| 发票类型（Special/General）|
|typeName|否|String| 发票类型（增值税专用发票/增值税普通发票）|
|unitCode|否|String| 开票单位编码|
|name|否|String| 开票名称|
|taxpayerNumber|否|String| 纳税人识别号|
|address|否|String| 单位地址|
|phone|否|String| 电话号码|
|bank|否|String| 开户银行|
|bankAccount|否|String| 银行账号|
|isDefault|否|Integer| 是否默认项|
|companyId|否|String| 商户id|
|createId|否|String| 创建人id|
|createName|否|String| 创建人|
|createDate|否|DateTime| 创建时间|
|email|否|String| 邮箱|
|receivingAdress|否|String| 收件地址|
|receivingName|否|String| 收件人|
|receivingPhone|否|String| 手机号|
|taxpayerCertificateImage|否|String| 一般纳税人凭证图片URL|
|isOnlyDefault|否|Integer||
|dbKey|否|Integer| 分库标识|
|groupId|否|String| 品牌商id|
