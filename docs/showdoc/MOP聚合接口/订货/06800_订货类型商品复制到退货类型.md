# 

**请求URL：** 
- `/b2b/orderTypeConfig/applyItemCopy`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|list|是|List|复制的来源于目标集合|

### 请求参数Json格式
 
```
{
 "list" : [
 {
 "id":订货类型id,
 "targetId":退货类型id
 }
 ]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
