# 

**请求URL：** 
- `/b2b/rebateTask/show`

**请求方式：**
- ALL
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 门店id|
|taskStatus|是|Integer| 返利任务状态(0进行中1已结束)|
|pageIndex|否|Integer| 页号|
|pageSize|否|Integer| 页大小|
|orderField|否|String| 商品排序字段|
|orderSort|否|String| 商品排序方式 desc 倒序 asc 正序|

###请求参数Json格式
 
```
{
 "companyId" : "String",
 "taskStatus" : 0,
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--endQty|否|Long| 已结束数量|
|--activityQty|否|Long| 进行中数量|
|--pageIndex|否|Integer| 页码|
|--pageSize|否|Integer| 显示记录数|
|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|--first|否|Boolean| 首页|
|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|
|----rebateRuleName|否|String|返利规则名称|
|----daysLeft|否|Integer| 剩余天数|
|----nextGoal|否|Integer| 下一级目标|
|----curValue|否|Double| 目标当前值|
|----totalValue|否|Double| 当前目标总值|
|----nextPrize|否|String| 下一级奖品|
|----planId|否|Long| 跳转的方案id|
|----ruleId|否|Long| 跳转的规则id|
|----type|否|Integer| 类型，按订单金额/商品数量|
|----percent|否|Double| 进度百分比|
|----ladder|否|Integer| 是否开启阶梯（0不开、1开）|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
