# 汇总展示所选订单的所有商品

**请求URL：** 
- `/b2b/order/batch/receiving/getItems`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long| id|

### 请求参数Json格式
 
```
{
 "id" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--items|否|List| 汇总明细|
|----itemId|否|String| 商品Id|
|----itemCode|否|String| 商品编码|
|----itemName|否|String| 商品名称|
|----specId|否|String| 规格Id|
|----barCodes|否|String| SKU码|
|----baseDeliveryQuantity|否|Double| 发货总数（基本单位）|
|----description|否|String| 规格说明|
|----materialMsg|否|String| 订货摘要|
|----notDeQuantity|否|Double| 待收总数（即已发未收数量）|
|----baseReceQuantity|否|Double| 现收数量|
|----unit|否|String| 收货单位（最小单位）|
|----location|否|String| 库位（商品档案属性字段）|
|----isBatch|否|Integer| 是否批次商品1是，0否|
|----isUniqueCode|否|Integer| 是否唯一码商品 1是，0否|
|----isFixedBomItem|否|Integer| 是否为固定商品BOM 1-是，0 - 否|
|----component|否|Integer| 是否开启组件 1-是，0 - 否|
|----mitemAttributes|否|List| 商品属性|
|--notAllowModifyReceiptQty|否|String| 是否不允许修改商品数量|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
