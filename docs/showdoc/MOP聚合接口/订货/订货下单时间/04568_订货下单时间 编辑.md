# 订货下单时间 编辑
 

**请求URL：** 
- `/b2b/paytime/manage/edit `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String||
|isInherit|否|Integer| 是否继承品牌|
|payTimeType|否|Integer| 订货下单时间类型 0全天 1自定义可下单时间|
|restActive|否|Integer| 启用休息时间 0不启用 1启用|
|restDateRangeStart|否|DateTime| 指定休息日期范围——开始|
|restDateRangeEnd|否|DateTime| 指定休息日期范围——开始|
|restDateType|否|Integer| 指定休息日类型 0按周 1按月|
|restWeek|否|String| 指定休息日(周) 以逗号隔开|
|restMonth|否|String| 指定休息日(月) 以逗号隔开|
|restTimeRangeBegin|否|Object| 指定休息时间段——开始|
|restTimeRangeEnd|否|Object| 指定休息时间段——结束|
|customPayTimeRangeList|否|List| 自定义下单时间列表|
|--customStartTime|否|String| 自定义下单时间——开始|
|--customEndTime|否|String| 自定义下单时间——结束|

###请求参数Json格式
 
```
{
 "companyId" : "String",
 "isInherit" : 0,
 "payTimeType" : 0,
 "restActive" : 0,
 "restDateRangeStart" : "DateTime",
 "restDateRangeEnd" : "DateTime",
 "restDateType" : 0,
 "restWeek" : "String",
 "restMonth" : "String",
 "restTimeRangeBegin" : null,
 "restTimeRangeEnd" : null,
 "customPayTimeRangeList" : [{
 "customStartTime" : "String",
 "customEndTime" : "String"
 }]
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
