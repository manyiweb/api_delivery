# 小程序查询顺手买
 

**请求URL：** 
- `/b2b/conveniently/buy/query`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 门店id|
|groupId|是|String| 品牌id|
|sword|否|String| 搜索关键词|
|acitvityId|否|Long| 活动id|
|pageIndex|否|Integer||
|pageSize|否|Integer||
|orderField|否|String||
|orderSort|否|String||

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "groupId" : "String",
 "sword" : "String",
 "acitvityId" : 0,
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long| 活动id|
|--customTitle|否|String| 活动名称|
|--pageType|否|Integer| 页面类型|
|--itemDtos|否|List| 顺手买|
|----itemId|否|String| 商品id|
|----unit|否|String| 单位|
|----specId|否|String| 规格id|
|----imageUrl|否|String| 商品图片|
|----itemName|否|String| 商品名称|
|----specName|否|String| 商品名称|
|----isSelect|否|Boolean| 是否选中|
|----listPrice|否|Double| 清单价|
|----description|否|String|最后修改时间 |
|----lineNo|否|Integer|排序号 |
|----rate|否|Double| 比例|
|----itemQuantity|否|Double| 数量|
|----quantity|否|Double| 比例|
|--activityIds|否|List| 活动ids|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
