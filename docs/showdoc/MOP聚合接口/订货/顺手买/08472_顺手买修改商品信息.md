# 修改商品信息

**请求URL：** 
- `/b2b/conveniently/buy/updateItems`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 活动id|
|deleteRows|否|List| 删除的行|
|b2BConvenientlyBuyItems|是|List| 秒杀商品|
|--itemId|是|String| 商品id|
|--specId|是|String| 规格id|
|--itemSku|否|String|sku吗 |
|--itemCode|否|String|商品编码 |
|--itemName|否|String|商品编码 |
|--lineNo|否|Integer|排序号 |
|--unit|否|String| 单位|
|--rate|否|Double| 比例|
|--itemQuantity|否|Double| 数量|
|--quantity|否|Double| 比例|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "deleteRows" : null,
 "b2BConvenientlyBuyItems" : [{
 "itemId" : "String",
 "specId" : "String",
 "itemSku" : "String",
 "itemCode" : "String",
 "itemName" : "String",
 "lineNo" : 0,
 "unit" : "String",
 "rate" : 0,
 "itemQuantity" : 0,
 "quantity" : 0
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
