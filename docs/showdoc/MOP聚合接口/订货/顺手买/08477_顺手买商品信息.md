# 分页商品信息

**请求URL：** 
- `/b2b/conveniently/buy/items`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||
|sword|否|String||

### 请求参数Json格式
 
```
{
 "id" : 0,
 "sword" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--lineNo|否|Integer| 序号|
|--itemId|否|String||
|--specId|否|String| 规格id|
|--itemCode|否|String| 商品编码|
|--itemName|否|String| 商品名称|
|--unit|否|String| 单位|
|--itemSku|否|Double| 秒杀价|
|--specName|否|String| 商品名称|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "lineNo" : 0,
 "itemId" : "String",
 "specId" : "String",
 "itemCode" : "String",
 "itemName" : "String",
 "unit" : "String",
 "itemSku" : 0,
 "specName" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
