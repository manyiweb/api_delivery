# 获取订货支付类型
 

**请求URL：** 
- `/b2b/pay/v2/getPayType `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|否|String| 登陆标识|
|payType|否|String| 支付单据类型，Deposit("充值"), Consume("订单扣款")|
|orderId|否|String||

###请求参数Json格式
 
```
{
 "tokenId" : "String",
 "payType" : "String",
 "orderId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--accountInfo|否|Object| 商户资金信息，请求类型为订货订单时返回|
|----advTotal|否|Double| 账户余额|
|----creditTotal|否|Double| 授信额度|
|----temporaryCreditTotal|否|Double| 临时授信金额|
|----freeze|否|Boolean||
|----recharge|否|Integer|是否可充值 |
|----showCreditMoney|否|Boolean||
|--payTypes|否|List| 支付类型|
|----payType|否|String| 支付类型|
|----payTypeName|否|String| 支付类型描述|
|----paySubcategory|否|String| 支付子类型编码|
|----paySubcategoryName|否|String| 支付子类型名称|
|----isDefault|否|Integer| 是否为默认值 1是0否|
|--allowMultiplePayments|否|Boolean| 启用订货支付时允许分多次支付（仅适用于订货助手端）|
|--openPaymentCode|否|Integer| 开启线下支付二维码|
|--paymentCodeUrl|否|String| 二维码链接|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|

 "payType" : "String",

 }],

 },

}
