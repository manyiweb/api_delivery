# 订货账户充值详情
 

**请求URL：** 
- `/b2b/account/recharge/detail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||

### 请求参数Json格式
 
```
{
 "id" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long|id |
|--code|否|String|编码 |
|--accountType|否|String|账户类型，BASE：基础账户,CUSTOM：自定义账户 |
|--accountTypeDesc|否|String|账户类型描述 |
|--customAccountId|否|Long|自定义账户id |
|--customAccountName|否|String|自定义账户名称 |
|--amount|否|Double|充值面额 |
|--remark|否|String|备注 |
|--isActive|否|Boolean|是否活跃 |
|--isActiveDesc|否|String|是否活跃描述 |
|--giveType|否|String|活动赠送类型，COUPON：优惠券 |
|--giveTypeDesc|否|String|活动赠送类型描述 |
|--applyType|否|Integer|应用类型，0：所有门店，1：指定门店 |
|--applyTypeDesc|否|String|应用类型描述 |
|--createId|否|String|创建人id |
|--createDate|否|DateTime|创建时间 |
|--createName|否|String|创建人 |
|--giveAmount|否|Boolean||
|--applies|否|Object|应用信息列表 |
|--gives|否|Object|赠品列表 |
|--amountGiveDto|否|Object|赠品列表 |
|----id|否|Long| 主键|
|----accountRechargeId|否|Long| 账户id|
|----giveAmountType|否|Integer| 赠送类型 0固定金额 1比例|
|----giveAmount|否|Double| 赠送金额或比例|
|----accountId|否|Long| 账户id|
|----accountName|否|String| 账户名称|
|----dateType|否|Integer| 日期类型 0 指定天数 1 指定有效期 2指定截止日期|
|----validDays|否|Integer| 有效天数|
|----startActiveDate|否|String| 有效期开始日期|
|----activeDate|否|String| 有效期结束日期|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
