# 保存配置

**请求URL：** 
- `/b2b/orderType/roleConfig/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|String| 主键id|
|isConfigInherit|否|Integer| 是否继承: 建单权限配置|
|ifOpenOrderTypeConfig|否|Integer| 是否启用建单权限设置 0否 1是|
|typeCode|是|String| 区分业务单据类型|
|orderTypeRoleDetail|否|List| 订货类型权限详情|
|--orderTypeId|否|String| 订货类型id 或 退货类型id|
|--orderTypeName|否|String| 订货类型名称|
|--roles|否|List| 角色编码|
|----roleCode|否|String| 角色编码|
|----roleName|否|String| 角色名称|
|companyId|否|String| 门店|

### 请求参数Json格式
 
```
{
 "id" : "String",
 "isConfigInherit" : 0,
 "ifOpenOrderTypeConfig" : 0,
 "typeCode" : "String",
 "orderTypeRoleDetail" : [{
 "orderTypeId" : "String",
 "orderTypeName" : "String",
 "roles" : [{
 "roleCode" : "String",
 "roleName" : "String"
 }]
 }],
 "companyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
