# 保存小程序门店认证信息

**请求URL：** 
- `/b2b/wx/company/authenticateSave `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|isGrantRetailInfo|否|Boolean| 该小程序是否已被授权|
|businessId|否|String| 门店注册号|
|storeAddress|否|String| 门店地址|
|businessName|否|String| 门店名称|
|storeType|否|String| 门店类型|
|phone|否|String| 门店登记手机号|
|managerAuditStatus|否|Integer| 法人验证状态 1、仍在30天内，法人等待验证 2、超过30天，法人验证已超时 3、法人验证已拒绝 4、法人验证已验证|
|openId|否|String| 用于发信息的openid|
|managerName|否|String| 经营者名称|
|isEnableUsePlugin|否|Boolean| 该小程序是否允许使用此插件|
|status|否|Boolean| 若未授权则为 false|

###请求参数Json格式
 
```
{
 "isGrantRetailInfo" : true,
 "businessId" : "String",
 "storeAddress" : "String",
 "businessName" : "String",
 "storeType" : "String",
 "phone" : "String",
 "managerAuditStatus" : 0,
 "openId" : "String",
 "managerName" : "String",
 "isEnableUsePlugin" : true,
 "status" : true
}
```
