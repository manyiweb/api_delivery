# 根据供应商id查询该供应商自定义属性集合

**请求URL：** 
- `/b2b/msupplierAttributes/list `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|String| id|

###请求参数Json格式
 
```
{
 "id" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--id|否|Long| id|
|--name|否|String| 属性名称（一到三十）|
|--alias|否|String| 属性别名|
|--valueType|否|Integer| 0 任何值 1 序列 2业务对象|
|--content|否|String| 内容值,多个值时以分号“;”隔开|
|--value|否|String| 属性值|
|--code|否|Integer| 属性（比如1-30）|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : [{
 "id" : 0,
 "name" : "String",
 "alias" : "String",
 "valueType" : 0,
 "content" : "String",
 "value" : "String",
 "code" : 0
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
