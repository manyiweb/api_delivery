# 获取打款账户信息

**请求URL：** 
- `/config/payment/account/findById `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|

###请求参数Json格式
 
```
{
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long| 主键|
|--code|否|String| 编号|
|--accountName|否|String| 账户名称|
|--bank|否|String| 开户银行|
|--bankAccount|否|String| 银行账号|
|--active|否|Boolean| 活跃状态 1启用，0停用|
|--def|否|Boolean| 默认账号 1默认 0非默认|
|--remark|否|String| 备注|
|--companyId|否|String| 门店id|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "code" : "String",
 "accountName" : "String",
 "bank" : "String",
 "bankAccount" : "String",
 "active" : true,
 "def" : true,
 "remark" : "String",
 "companyId" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
