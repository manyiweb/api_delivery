# 获取导入模板下载URL
 

**请求URL：** 
- `http://192.168.1.42:8089/api/product/getImportTemplateUrl `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
```
{
 "tokenId":"7f8bab0bf3be4c9483115f90ff3e9363",
 "typeCode":"reserve"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |


###返回参数Json格式
 
```
{
"ErrorCode": "",
"ResultString": "操作成功",
"ResultInt": 0,
"templateUrl": "http://upaiyun.reabam.com/Template/预定商品导入模版190820.xlsx"
}
```
