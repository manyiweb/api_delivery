# 购物车商品项赠品检查

**请求URL：** 
- `/b2b/mall/shopCart/checkMinReceive `

**请求方式：**
- POST
- FormData


###请求参数<业务参数>
 
无参数


###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--isOk|否|Boolean| 商品key|
|--shopCartMinReceiveDto|否|List| 没达到最小领取数量的促销|
|----itemKey|否|String| 商品key|
|----quantity|否|Double| 数量|
|----minQuantity|否|Double| 最小领取数量|
|----ruleName|否|String| 规则名称|
|----ruleId|否|String| 规则id|
|----levelId|否|String| 阶梯id|
|----itemName|否|String| 商品名称|
|----calculatorWay|否|Integer| 计算法方式 0按数量 1按金额|
|----selTotalQuantity|否|Double| 已选择数量|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "isOk" : true,
 "shopCartMinReceiveDto" : [{
 "itemKey" : "String",
 "quantity" : 0,
 "minQuantity" : 0,
 "ruleName" : "String",
 "ruleId" : "String",
 "levelId" : "String",
 "itemName" : "String",
 "calculatorWay" : 0,
 "selTotalQuantity" : 0
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
