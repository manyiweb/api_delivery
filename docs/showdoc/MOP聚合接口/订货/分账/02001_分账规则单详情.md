# 分账规则单详情
 

**请求URL：** 
- `/finance/splitRule/detail `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
无参数


###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long| 主键|
|--splitRuleName|否|String| 分账规则名称|
|--splitRuleSn|否|String| 分账规则编号|
|--isActive|否|Integer| 活跃状态(0-停用 1-启用)|
|--remark|否|String| 备注|
|--createName|否|String| 创建人|
|--createDate|否|DateTime| 创建时间|
|--hostSplitPercent|否|Double| 所属经销商分账百分比|
|--hostShareFreightPercent|否|Double| 所属经销商运费分摊百分比(%)|
|--splitRuleLines|否|List| 指定经销商百分比|
|----distributorId|否|Long| 经销商id|
|----distributorName|否|String| 经销商全称|
|----splitPercent|否|Double| 分账百分比|
|----shareFreightPercent|否|Double| 运费分摊百分比(%)|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "splitRuleName" : "String",
 "splitRuleSn" : "String",
 "isActive" : 0,
 "remark" : "String",
 "createName" : "String",
 "createDate" : "DateTime",
 "hostSplitPercent" : 0,
 "hostShareFreightPercent" : 0,
 "splitRuleLines" : [{
 "distributorId" : 0,
 "distributorName" : "String",
 "splitPercent" : 0,
 "shareFreightPercent" : 0
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
