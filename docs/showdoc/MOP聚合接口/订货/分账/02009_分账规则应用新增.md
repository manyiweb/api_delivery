# 生成分账规则应用
 

**请求URL：** 
- `/finance/splitRuleApply/add `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|splitRuleApplyId|否|Long||
|splitRuleId|否|Long| 分账规则id|
|splitRuleName|否|String| 分账规则名称|
|applyFromDate|否|DateTime| 规则有效期-开始|
|applyToDate|否|DateTime| 规则有效期-结束|
|chainCompanyId|否|String| 商户组表关联|
|isOpenItemGroup|否|Integer| 开启特殊商品组分账百分比|
|extendDtos|否|List| RuleApplyExtend's id|
|--extendId|否|Long| 主键|
|--splitRuleId|否|Long| 分账规则id|
|--splitRuleName|否|String| 分账规则名称|
|--splitItemGroupName|否|String| 特殊商品分组名称|
|--splitItemGroupId|否|Long| 特殊商品分组id|
|--splitItemGroupSn|否|String| 特殊商品分组编码|

###请求参数Json格式
 
```
{
 "splitRuleApplyId" : 0,
 "splitRuleId" : 0,
 "splitRuleName" : "String",
 "applyFromDate" : "DateTime",
 "applyToDate" : "DateTime",
 "chainCompanyId" : "String",
 "isOpenItemGroup" : 0,
 "extendDtos" : [{
 "extendId" : 0,
 "splitRuleId" : 0,
 "splitRuleName" : "String",
 "splitItemGroupName" : "String",
 "splitItemGroupId" : 0,
 "splitItemGroupSn" : "String"
 }]
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
