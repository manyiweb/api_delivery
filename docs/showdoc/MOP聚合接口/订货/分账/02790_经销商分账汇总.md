# 经销商分账汇总
 

**请求URL：** 
- `/b2b/v1/order/split/action/get `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|否|String||
|id|否|String||

###请求参数Json格式
 
```
{
 "tokenId" : "String",
 "id" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--hostDistributor|否|Boolean| 是否专属经销商|
|--shareFreightPercent|否|Double| 运费分摊百分比(%)|
|--splitRuleApplyId|否|Long| 分账规则应用id|
|--companyId|否|String| 店铺id|
|--chainCompanyId|否|String| 商户组id|
|--splitRuleDetailId|否|Long| 运费分账规则详情id|
|--id|否|Long| 主键|
|--splitAmount|否|Double| 分账金额|
|--splitFreightAmount|否|Double| 运费分账金额|
|--distributorId|否|Long| 经销商id|
|--distributorName|否|String| 经销商全称|
|--distributorCode|否|String| 经销商编码|
|--settlePayStatus|否|Integer| 代付状态 1未清 2已清 3代付中|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
