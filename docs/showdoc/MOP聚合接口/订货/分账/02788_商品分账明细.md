# 商品分账明细
 

**请求URL：** 
- `/b2b/v1/order/split/item/action/get `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|否|String||
|id|否|String||

###请求参数Json格式
 
```
{
 "tokenId" : "String",
 "id" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--itemCode|否|String| 商品编码|
|--skuBarcode|否|String| sku码|
|--itemName|否|String| 商品名称|
|--distributorCode|否|String| 经销商编码|
|--distributorName|否|String| 经销商全称|
|--lineSplitAmount|否|Double| 分账金额|
|--parentItemName|否|String| bom主商品名称|
|--b2bOrderItemId|否|String| 订货订单项id|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : [{
 "itemCode" : "String",
 "skuBarcode" : "String",
 "itemName" : "String",
 "distributorCode" : "String",
 "distributorName" : "String",
 "lineSplitAmount" : 0,
 "parentItemName" : "String",
 "b2bOrderItemId" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
