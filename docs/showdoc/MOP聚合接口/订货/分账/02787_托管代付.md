# 批量托管代付
 

**请求URL：** 
- `/b2b/sales/order/yunst/batchAgentPay `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderNos|否|List| 分账代付订单列表|

###请求参数Json格式
 
```
{
 "orderNos" : null
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--totalQty|否|Integer| 总数|
|--successQty|否|Integer| 成功数|
|--failQty|否|Integer| 失败数|
|--successOrders|否|List| 成功列表|
|----orderNo|否|String| 订单号|
|----fail|否|Integer| 是否失败|
|----errorMsg|否|String| 错误信息|
|--failOrders|否|List| shi白|
|----orderNo|否|String| 订单号|
|----fail|否|Integer| 是否失败|
|----errorMsg|否|String| 错误信息|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : {
 "totalQty" : 0,
 "successQty" : 0,
 "failQty" : 0,
 "successOrders" : [{
 "orderNo" : "String",
 "fail" : 0,
 "errorMsg" : "String"
 }],
 "failOrders" : [{
 "orderNo" : "String",
 "fail" : 0,
 "errorMsg" : "String"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
