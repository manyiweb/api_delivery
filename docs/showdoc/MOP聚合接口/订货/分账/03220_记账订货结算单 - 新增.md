# 记账订货结算单 - 新增

**请求URL：** 
- `/finance/v1/split/settleOrder/action/add `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|paymentWay|否|Integer| 付款方式|
|paymentData|否|DateTime| 付款日期|
|remark|否|String| 备注|
|orderIds|否|List| 结算订货单据|
|--orderId|否|String| 订单id|
|--remark|否|String| 备注|

###请求参数Json格式
 
```
{
 "paymentWay" : 0,
 "paymentData" : "DateTime",
 "remark" : "String",
 "orderIds" : [{
 "orderId" : "String",
 "remark" : "String"
 }]
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
