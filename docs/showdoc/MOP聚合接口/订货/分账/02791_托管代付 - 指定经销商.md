# 托管代付 - 指定经销商
 

**请求URL：** 
- `/b2b/sales/order/yunst/batchAgentPayByDistributor `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderNo|否|String||
|distributorId|否|Long||

###请求参数Json格式
 
```
{
 "orderNo" : "String",
 "distributorId" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--orderNo|否|String| 订单号|
|--fail|否|Integer| 是否失败|
|--errorMsg|否|String| 错误信息|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : {
 "orderNo" : "String",
 "fail" : 0,
 "errorMsg" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
