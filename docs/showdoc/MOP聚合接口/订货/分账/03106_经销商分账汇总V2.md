# 经销商分账汇总
 

**请求URL：** 
- `/b2b/v2/order/split/action/get `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|否|String||
|id|否|String||

###请求参数Json格式
 
```
{
 "tokenId" : "String",
 "id" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--sharerCode|否|String| 分账方编码|
|--sharerType|否|String| 分账方账户类型|
|--sharerName|否|String| 分账方名称|
|--splitAmount|否|Double| 商品分账金额|
|--splitFreightAmount|否|Double| 运费分账金额|
|--totalAmount|否|Double| 分账总额|
|--promotionAmount|否|Double| 促销金额|
|--couponAmount|否|Double| 优惠金额|
|--pointAmount|否|Double| 积分金额|
|--arrivalDate|否|Object| 到账时间|
|--settlePayStatus|否|Integer| 代付状态|
|--cellStyleMap|否|Map||
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : [{
 "sharerCode" : "String",
 "sharerType" : "String",
 "sharerName" : "String",
 "splitAmount" : 0,
 "splitFreightAmount" : 0,
 "totalAmount" : 0,
 "promotionAmount" : 0,
 "couponAmount" : 0,
 "pointAmount" : 0,
 "arrivalDate" : null,
 "settlePayStatus" : 0,
 "cellStyleMap" : null
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
