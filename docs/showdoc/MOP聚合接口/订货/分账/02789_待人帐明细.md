# 待人帐明细
 

**请求URL：** 
- `/b2b/v1/order/split/distributor/action/get `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|sword|否|String||
|tokenId|否|String||
|id|否|String|经销商id|
|pageIndex|否|Integer| 页号|
|pageSize|否|Integer| 页大小|
|orderField|否|String| 商品排序字段|
|orderSort|否|String| 商品排序方式|

###请求参数Json格式
 
```
{
 "tokenId": "e106eb991d714914b3cad51d316e3586",
 "id": "518999398465152388",
 "pageSize": 20,
 "pageIndex": 1
 }
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--orderId|否|String| 订单号|
|--orderNo|否|String| 订单号|
|--orderStatusName|否|String| 订单状态|
|--waitCashbackAmount|否|Double| 待入账金额|
|--createDate|否|Object| 创建时间|
|--createName|否|String| 创建人|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
