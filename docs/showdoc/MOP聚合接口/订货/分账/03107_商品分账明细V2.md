# 商品分账明细
 

**请求URL：** 
- `/b2b/v2/order/split/item/action/get `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|否|String||
|id|否|String||

###请求参数Json格式
 
```
{
 "tokenId" : "String",
 "id" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--itemCode|否|String| 商品编码|
|--skuBarcode|否|String| SKU码|
|--itemName|否|String| 商品名称|
|--distributorCode|否|String| 经销商编码|
|--distributorName|否|String| 经销商名称|
|--lineSplitAmount|否|Double| 分账金额|
|--parentItemName|否|String| 主商品名称|
|--b2bOrderItemId|否|String| 订货订单项id|
|--supplierCode|否|String| 供应商名称|
|--supplierName|否|String| 供应商编码|
|--supplierLineSplitAmount|否|String| 供应商分账金额|
|--inviterCode|否|String| 邀请商户名称|
|--inviterName|否|String| 邀请商户编码|
|--inviterLineSplitAmount|否|String| 邀请商户分账金额|
|--linetSplitPercent|否|String| 分账百分比|
|--cellStyleMap|否|Map||
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : [{
 "itemCode" : "String",
 "skuBarcode" : "String",
 "itemName" : "String",
 "distributorCode" : "String",
 "distributorName" : "String",
 "lineSplitAmount" : 0,
 "parentItemName" : "String",
 "b2bOrderItemId" : "String",
 "supplierCode" : "String",
 "supplierName" : "String",
 "supplierLineSplitAmount" : "String",
 "inviterCode" : "String",
 "inviterName" : "String",
 "inviterLineSplitAmount" : "String",
 "cellStyleMap" : null
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
