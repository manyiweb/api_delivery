# 购物车商品项赠品列表

**请求URL：** 
- `/b2b/mall/shopCart/checkPromotionList `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|checkType|否|Integer||

###请求参数Json格式
 
```
{
 "checkType" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--isOk|否|Boolean| 商品key|
|--shopCartPromotionList|否|List| 没达到最小领取数量的促销|
|----itemKey|否|String| 商品key|
|----ruleName|否|String| 规则名称|
|----ruleId|否|String| 规则id|
|----levelId|否|String| 阶梯id|
|----specId|否|String| 阶梯id|
|----hasSuperimposedPromotion|否|Integer| 是否叠加促销，取值：0 - 否，1 - 是|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "isOk" : true,
 "shopCartPromotionList" : [{
 "itemKey" : "String",
 "ruleName" : "String",
 "ruleId" : "String",
 "levelId" : "String",
 "specId" : "String",
 "hasSuperimposedPromotion" : 0
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
