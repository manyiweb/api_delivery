# 获取支付状态
 

**请求URL：** 
- `/b2b/order/getProxyPayList`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|String||

### 请求参数Json格式
 
```
{
 "id" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--status|否|String| 状态|
|--supplyingOrderCode|否|String| 代发单号|
|--fid|否|String||
|--payTypeCode|否|String||
|--payTypeName|否|String||
|--payAmount|否|Object||
|--payDate|否|DateTime||
|--transCode|否|String||
|--orderNo|否|String|单据编号|
|--payInterfaceOutTradeNo|否|String||
|--customPay|否|Boolean| 是否为自定义付款方式|
|--paySubcategoryId|否|String||
|--paySubcategoryCode|否|String||
|--paySubcategoryName|否|String||
|--deductionExpressFeeAmount|否|String| 自定义付款的金额|
|--useCustomAmount|否|String||
|--creditAmount|否|String||
|--acctName|否|String| 银联付款名称|
|--remark|否|String| 备注|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
