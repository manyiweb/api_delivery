# 修改开票信息

**请求URL：** 
- `/hr/invoice/b2bOrder/update`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 开票id|
|titleType|否|String|抬头类型 PERSONAL("个人") ENTERPRISE("单位")|
|type|否|String| 发票类型Special 增值税普通发票 /General 增值税专用发票|
|typeName|否|String| 发票类型Special 增值税普通发票 /General 增值税专用发票|
|name|否|String| 发票抬头|
|taxpayerNumber|否|String| 税号|
|bank|否|String| 开户银行|
|bankAccount|否|String| 银行账户|
|address|否|String| 注册地址|
|phone|否|String| 注册电话|
|email|否|String| 邮箱|
|receivingAdress|否|String| 收货地址|
|receivingName|否|String| 收货人|
|receivingPhone|否|String| 手机号|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "titleType" : "String",
 "type" : "String",
 "typeName" : "String",
 "name" : "String",
 "taxpayerNumber" : "String",
 "bank" : "String",
 "bankAccount" : "String",
 "address" : "String",
 "phone" : "String",
 "email" : "String",
 "receivingAdress" : "String",
 "receivingName" : "String",
 "receivingPhone" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
