- `/hr/invoice/b2bOrder/redPunchAll`

**请求方式：**
- POST
- RequestBody

|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||
|sword|否|String||

```
{
 "id" : 0,
 "sword" : "String"
}
```
