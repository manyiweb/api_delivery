# 自定义账户配置查询

**请求URL：** 
- `/config/b2b/custom/account/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|String|主键id|

### 请求参数Json格式
 
```
{
 "id" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|String| 主键|
|--accountId|否|Long| 自定义账户id|
|--openWithdrawTime|否|Boolean| 开启提现时间配置|
|--withdrawTime|否|List| 1,2,3,4.... 表示日|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "id" : "String",
 "accountId" : 0,
 "openWithdrawTime" : true,
 "withdrawTime" : null,
 "groupId" : "String",
 "createId" : "String",
 "createName" : "String",
 "createDate" : "DateTime",
 "modifyId" : "String",
 "modifyName" : "String",
 "modifyDate" : "DateTime"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
