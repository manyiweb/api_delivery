# 购物车商品项赠品列表

**请求URL：** 
- `/b2b/shopping/cart/item/giftList `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|itemKey|否|String| 购物车ItemKey|
|levelId|否|String| 阶梯id|
|page|否|Integer| 分页页码|
|size|否|Integer| 分页大小|
|sword|否|String| 搜索关键字|
|shopCartKey|否|String| 如果是立即购买输入对应的立即购买cartKey|

###请求参数Json格式
 
```
{
 "itemKey" : "String",
 "levelId" : "String",
 "page" : 0,
 "size" : 0,
 "sword" : "String",
 "shopCartKey" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--itemKey|否|String| ItemKey|
|--calculatorWay|否|Integer| 计算法方式 0按数量 1按金额|
|--quantity|否|Double| 赠送/换购数量|
|--priceAmount|否|Double| 可选金额|
|--selTotalQuantity|否|Double| 已选 赠送/换购数量|
|--selTotalPriceAmount|否|Double| 已选 赠送/换购金额|
|--planId|否|String| 促销标识|
|--planStatus|否|Integer| 是否达标 0未达标 1达标|
|--planTitle|否|String| 促销标题|
|--itemsPage|否|Object| 赠品列表|
|----number|否|Integer| 页码|
|----numberOfElements|否|Integer| 当前页记录数|
|----size|否|Integer| 每页记录数|
|----totalElements|否|Long| 总记录数|
|----totalPages|否|Integer| 总页数|
|----sort|否|Object| 排序信息|
|----pageIndex|否|Integer| 页码|
|----pageSize|否|Integer| 显示记录数|
|----pageCount|否|Integer| 总页数|
|----totalCount|否|Long| 总记录数|
|----first|否|Boolean| 首页|
|----last|否|Boolean| 尾页|
|----content|否|List| 分页数据|
|--minReceiveNum|否|Double| 最小领取数量|
|--giftMustQty|否|Double| 赠品必选数量|
|--isInstallmentTake|否|Boolean| 是否开启分期提货|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
