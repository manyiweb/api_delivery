# 

**请求URL：** 
- `/b2b/b2bOrderSet/getB2bOrderSet`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|groupId|是|String||
|companyId|是|String||
|tokenId|是|String||

### 请求参数Json格式
 
```
{
 "groupId" : "String",
 "companyId" : "String",
 "tokenId" : "String",
 "openId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--monthly|否|Integer| 是否开启月结 1是0否|
|--dealerSettlement|否|Integer| 是否开启按经销商结算 1是 0否|
|--dealerSettlementWay|否|Integer| 经销商结算方式 0结算 1分账 2记账|
|--deliverySavePrint|否|Integer| 订货发货支持保存并打印 1是 0否|
|--overcharge|否|Integer| 是否允许超收|
|--overchargeRate|否|Double| 超收比例|
|--allowMultiplePayments|否|Boolean| 启用订货支付时允许分多次支付（仅适用于订货助手端）|
|--allowChangeDeliveryDate|否|Boolean| 是否启用允许用户下达定会订单时修改默认到货日期|
|--overabundanceChange|否|Integer| 是否订允许 货发货数量大于订货数量时变更订货数量并补差额|
|--chooseSaleMan|否|Boolean| 订货下单时，控制必须选择所属业务员|
|--sameSpecMultipleLineEnable|否|Boolean| 同一SKU允许添加多行|
|--deliveryNoStockOut|否|Boolean| 发货不扣减库存|
|--noAllowedCancelOrderTime|否|Boolean| 非订货时间不允许取消|
|--autoDifferenceRefund|否|Boolean| 自动差异退款|
|--openOfflineAudit|否|Boolean| 线下支付对金额审核|
|--requiredWarehouse|否|Boolean| 必选发货仓|
|--unCommitOrderDays|否|Integer| 未提交订单天数|
|--openNegativeInvUsage|否|Boolean| 负库存订购量占用|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||

 },
