# 查询昨日订货数量
 

**请求URL：** 
- `/b2b/product/findYesterday/orderQuantity`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 门店id|
|specIds|是|List| 规格id|

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "specIds" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|是|List||
|--specId|是|String||
|--totalQuantity|是|Double||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "specId" : "String",
 "totalQuantity" : 0
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
