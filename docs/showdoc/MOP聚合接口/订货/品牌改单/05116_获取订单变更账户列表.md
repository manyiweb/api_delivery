# 获取订单变更账户列表
 

**请求URL：** 
- `/b2b/sales/order/change/accountList `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|String| id|

###请求参数Json格式
 
```
{
 "id" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--paySubcategoryId|否|String|账户id |
|--paySubcategoryCode|否|String|账户编码 |
|--paySubcategoryName|否|String|账户名称 |
|--amount|否|Double|账户余额 |
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : [{
 "paySubcategoryId" : "String",
 "paySubcategoryCode" : "String",
 "paySubcategoryName" : "String",
 "amount" : 0
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
