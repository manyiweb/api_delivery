# 订货优惠券 - 派发
 

**请求URL：** 
- `/b2b/coupon/get/delivery `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|couponId|否|String||
|deliveryCoupons|否|List||
|--companyId|否|String||
|--quantity|否|Integer||
|--remark|否|String||

###请求参数Json格式
 
```
{
 "couponId" : "String",
 "deliveryCoupons" : [{
 "companyId" : "String",
 "quantity" : 0,
 "remark" : "String"
 }]
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Long| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : 0,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
