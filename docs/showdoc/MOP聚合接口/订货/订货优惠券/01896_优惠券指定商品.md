# 优惠券指定商品
 

**请求URL：** 
- `/b2b/coupon/items `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|couponId|否|String| 优惠券标识|
|pageIndex|否|Integer| 分页页码|
|pageSize|否|Integer| 分页大小|
|sword|否|String| 搜索关键字|

###请求参数Json格式
 
```
{
 "couponId" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "sword" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|pageIndex|否|Integer| 页码|
|pageSize|否|Integer| 显示记录数|
|pageCount|否|Integer| 总页数|
|totalCount|否|Long| 总记录数|
|first|否|Boolean| 首页|
|last|否|Boolean| 尾页|
|content|否|List| 分页数据|
|--itemId|否|String||
|--itemCode|否|String||
|--itemName|否|String||
|--brandName|否|String||
|--dealPrice|否|Double||
|--unit|否|String||
|--createName|否|String||


###返回参数Json格式
 
```
{
 "pageIndex" : 0,
 "pageSize" : 0,
 "pageCount" : 0,
 "totalCount" : 0,
 "first" : true,
 "last" : true,
 "content" : [{
 "itemId" : "String",
 "itemCode" : "String",
 "itemName" : "String",
 "brandName" : "String",
 "dealPrice" : 0,
 "unit" : "String",
 "createName" : "String"
 }]
}
```
