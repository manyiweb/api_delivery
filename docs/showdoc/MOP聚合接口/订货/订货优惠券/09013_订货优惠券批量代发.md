# 订货优惠券 - 派发
 

**请求URL：** 
- `/b2b/coupon/get/batch/delivery`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 门店id|
|couponDeliverys|否|List| 优惠券列表|
|--couponId|是|String||
|--quantity|是|Integer||
|--remark|否|String||

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "couponDeliverys" : [{
 "couponId" : "String",
 "quantity" : 0,
 "remark" : "String"
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Long||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : 0,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
