# 删除派发优惠券
 

**请求URL：** 
- `/b2b/coupon/get/remove `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|couponId|否|String| 优惠券标识|
|couponGetId|否|String| 优惠券领取行ID|

###请求参数Json格式
 
```
{
 "couponId" : "String",
 "couponGetId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String"
}
```
