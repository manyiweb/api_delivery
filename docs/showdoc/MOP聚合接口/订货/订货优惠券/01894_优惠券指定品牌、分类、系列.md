# 优惠券指定品牌、分类、系列
 

**请求URL：** 
- `/b2b/coupon/types `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|couponId|否|String| 优惠券标识|
|pageIndex|否|Integer| 分页页码|
|pageSize|否|Integer| 分页大小|
|sword|否|String| 搜索关键字|

###请求参数Json格式
 
```
{
 "couponId" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "sword" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|pageIndex|否|Integer| 页码|
|pageSize|否|Integer| 显示记录数|
|pageCount|否|Integer| 总页数|
|totalCount|否|Long| 总记录数|
|first|否|Boolean| 首页|
|last|否|Boolean| 尾页|
|content|否|List| 分页数据|
|--fid|否|String||
|--version|否|Integer||
|--typeName|否|String| 类型：类别、系列、品牌|
|--typeCode|否|String| 类型|
|--name|否|String| 对应名称|
|--code|否|String| 对应编码|
|--typeId|否|String| 对应ID|
|--createName|否|String| 创建人名称|
|--createId|否|String| 创建人ID|
|--createDate|否|DateTime| 创建时间|
|--dbKey|否|Integer| 分库标识|
|--groupId|否|String| 品牌商id|


###返回参数Json格式
 
```
{
 "pageIndex" : 0,
 "pageSize" : 0,
 "pageCount" : 0,
 "totalCount" : 0,
 "first" : true,
 "last" : true,
 "content" : [{
 "fid" : "String",
 "version" : 0,
 "typeName" : "String",
 "typeCode" : "String",
 "name" : "String",
 "code" : "String",
 "typeId" : "String",
 "createName" : "String",
 "createId" : "String",
 "createDate" : "DateTime",
 "dbKey" : 0,
 "groupId" : "String"
 }]
}
```
