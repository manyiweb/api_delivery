# 订货优惠券 - 新增/编辑
 

**请求URL：** 
- `/b2b/coupon/add`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|否|String| 登陆标识|
|couponId|否|String| 优惠券ID|
|dateTypeCode|是|String| 有效期类型编码|
|couponType|是|Integer| 优惠类型 ： 0为现金劵，1为折扣劵 ,2为兑换券,3运费券|
|title|是|String| 优惠券名称|
|price|否|Double| 价格|
|discount|否|Double| 折扣|
|qty|是|Integer| 数量|
|useLimitAmt|否|Double| 使用订单最小金额|
|detail|否|String| 优惠券使用描述|
|isActive|否|Integer| 活跃状态 1活跃0不活跃|
|isOpen|否|Integer| 商城领取 1开启0关闭|
|isAllItem|否|Integer| 应用到所有商品，1是0否|
|allowGet|否|Integer| 允许领用次数|
|limitCycle|否|Integer| 0每天 1每周 2每月|
|restriction|否|Integer| 是否开启领用限制 1是否|
|useLimit|否|Integer| 最低限额3是每满叠加|
|beginDate|否|String| 优惠券有效时间始|
|endDate|否|String| 优惠券有效时间至|
|days|否|Integer| 固定有效天数|
|itemList|否|List| 应用的商品列表|
|brandList|否|List| 应用的品牌、系列、分类列表、商品标签|
|--type|否|Integer| 1 - 品牌,2 - 系列,3 - 类别, 4 - 商品标签|
|--typeId|否|String| 其ID|
|useScene|否|Integer| 使用场景 0全场券 1商品券|
|delItems|否|List| 需要删除商品的行ID，不是ITEM ID是优惠券商品行ID|
|delTypes|否|List| 需要删除品牌、系列、分类的行ID|
|businessTypeCode|是|String| 业务类型编码|
|undertakerSetItem|否|List| 承担信息设置|
|--openUndertaker|否|Integer||
|--undertakerWay|否|Integer||
|--calculateWay|否|Integer||
|--profitFactor|否|Double||
|--mid|否|Object||
|--businessType|否|Integer||
|--detailList|否|List||
|----calculateWay|否|Integer||
|----calculateWayNew|否|Integer||
|----profitFactor|否|Double||
|----productTypeCode|否|String||
|----productTypeName|否|String||
|----itemId|否|String||
|----itemName|否|String||
|----objectTypeCode|否|String||
|----objectTypeName|否|String||
|----objectId|否|String||
|----objectName|否|String||
|----undertakerTypeCode|否|String||
|----undertakerTypeName|否|String||
|----undertakerValue|否|Double||
|----enableActiveDate|否|Boolean||
|----beginDate|否|DateTime||
|----endDate|否|DateTime||
|exchangeLimitType|否|Integer| 兑换券使用限制 0按金额 1按数量|
|exchangeLimitValue|否|Double| 兑换券使用限制额度|
|eliminateType|否|Integer| 是否有排除类型 0：没有 1：排除商品 2：排除指定类别/品牌/系列/商品标签（仅当IsAllItem=3时有效）|
|eliminateItemList|否|List| 排除商品列表|
|eliminateTypeList|否|List| 排除的品牌、系列、分类列表、商品标签|
|--type|否|Integer| 1 - 品牌,2 - 系列,3 - 类别, 4 - 商品标签|
|--typeId|否|String| 其ID|
|limitItems|否|List| 指定的门槛|
|--itemCode|否|String| 商品编码/标签编码|
|--itemName|否|String| 商品名称/标签id|
|--itemId|否|String| 商品id/标签id 关联 mitem商品表|
|limitItemLabels|否|List| 指定的门槛标签|
|--itemCode|否|String| 商品编码/标签编码|
|--itemName|否|String| 商品名称/标签id|
|--itemId|否|String| 商品id/标签id 关联 mitem商品表|
|remark|否|String| 优惠券备注|
|openLimitItem|否|Integer| 启用指定门槛商品|
|limitItemType|否|Integer| 指定门槛商品类型 0商品 1标签|
|appointGrade|否|Integer| 指定等级 0不开启 1开启|
|compGrades|否|List| 优惠券等级|
|--id|否|Long||
|--compGradeId|否|String| 等级id|
|--compGradeName|否|String| 等级名称|
|--b2bMcouponId|否|String| 优惠券iD|
