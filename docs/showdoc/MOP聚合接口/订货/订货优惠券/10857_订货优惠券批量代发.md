# 订货优惠券 - 多优惠券批量派发
 支持同时派发多个优惠券到多个门店
 

**请求URL：** 
- `/b2b/coupon/get/multi/batch/delivery`

**请求方式：** 
- `POST`
- `RequestBody`


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|deliveryItems|是|List| 派发项列表（每个优惠券对应多个门店的派发信息）|
|--couponId|是|String| 优惠券ID|
|--companyDeliveries|是|List| 门店派发列表（单个优惠券最多派发200家门店）|
|globalRemark|否|String| 全局备注（可选，会应用到所有派发记录）|

|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
