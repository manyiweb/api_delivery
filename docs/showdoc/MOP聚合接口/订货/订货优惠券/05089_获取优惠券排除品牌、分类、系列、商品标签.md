# 获取优惠券排除品牌、分类、系列、商品标签

**请求URL：** 
- `/b2b/coupon/eliminateTypes `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|couponId|否|String| 优惠券标识|
|tokenId|否|String| 用户标识|
|pageIndex|否|Integer| 分页页码|
|pageSize|否|Integer| 分页大小|
|sword|否|String| 搜索关键字|

###请求参数Json格式
 
```
{
 "couponId" : "String",
 "tokenId" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "sword" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--pageIndex|否|Integer| 页码|
|--pageSize|否|Integer| 显示记录数|
|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|--first|否|Boolean| 首页|
|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|
|----fid|否|String| id|
|----version|否|Integer| 版本|
|----mCouponId|否|String| 优惠券ID|
|----typeName|否|String| 类型：类别、系列、品牌|
|----typeCode|否|String| 类型|
|----name|否|String| 对应名称|
|----code|否|String| 对应编码|
|----typeId|否|String| 对应ID|
|----createName|否|String| 创建人名称|
|----createId|否|String| 创建人ID|
|----createDate|否|DateTime| 创建时间|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
