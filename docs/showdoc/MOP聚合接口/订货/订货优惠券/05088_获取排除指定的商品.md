# 获取排除指定的商品

**请求URL：** 
- `/b2b/coupon/eliminateItems `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|couponId|否|String| 优惠券标识|
|tokenId|否|String| 用户标识|
|pageIndex|否|Integer| 分页页码|
|pageSize|否|Integer| 分页大小|
|sword|否|String| 搜索关键字|

###请求参数Json格式
 
```
{
 "couponId" : "String",
 "tokenId" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "sword" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--pageIndex|否|Integer| 页码|
|--pageSize|否|Integer| 显示记录数|
|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|--first|否|Boolean| 首页|
|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|
|----id|否|String||
|----itemId|否|String||
|----itemCode|否|String||
|----itemName|否|String||
|----brandName|否|String||
|----dealPrice|否|Double||
|----unit|否|String||
|----createName|否|String||
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "pageIndex" : 0,
 "pageSize" : 0,
 "pageCount" : 0,
 "totalCount" : 0,
 "first" : true,
 "last" : true,
 "content" : [{
 "id" : "String",
 "itemId" : "String",
 "itemCode" : "String",
 "itemName" : "String",
 "brandName" : "String",
 "dealPrice" : 0,
 "unit" : "String",
 "createName" : "String"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
