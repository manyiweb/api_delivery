# 新增订货订单
 

**请求URL：** 
- `/b2b/sales/order/add `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|否|String||
|openId|否|String| 小程序openId|
|wxSn|否|String| wxSn|
|combinationPayment|否|Boolean| 是否使用了主支付默认是true不计算自定义账户抵扣运费|
|draftOrder|否|Boolean| 草稿单号|
|shopCartKey|否|String| 如果是立即购买输入对应的立即购买cartKey|

###请求参数Json格式
 
```
{
 "tokenId" : "String",
 "openId" : "String",
 "wxSn" : "String",
 "combinationPayment" : true,
 "draftOrder" : true,
 "shopCartKey" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--orderId|否|String| 订货订单标识|
|--orderNo|否|String| 订货订单编号|
|--needPay|否|Integer| 订货是否需要支付|
|--monthlyOrder|否|Integer| 是否为月结订单|
|--settleWayDefault|否|Integer| 是否为经销商结算订单|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "orderId" : "String",
 "orderNo" : "String",
 "needPay" : 0,
 "monthlyOrder" : 0,
 "settleWayDefault" : 0,
	 }，
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
