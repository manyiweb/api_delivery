# 查询对应打款日期/打款金额的打款单是否已经存在（线下充值）
 

**请求URL：** 
- `/b2b/billmoney/checkTodayBillMoney `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|否|String||
|money|否|Double||
|payDate|否|DateTime||

###请求参数Json格式
 
```
{
 "tokenId" : "String",
 "money" : 0,
 "payDate" : "DateTime"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--isPaySameMoneyToday|否|Integer| 是否已存在一笔相同付款日期和金额的打款单|
|--orderNos|否|List||
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : {
 "isPaySameMoneyToday" : 0,
 "orderNos" : null
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
