# 功能描述: 幸运大转盘-新增/编辑活动
 

**请求URL：** 
- `/activity/b2b/wheel/edit `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|type|否|Integer| 活动类型 1、会员 2、订货|
|id|否|Long| id|
|name|否|String| 活动名称|
|beginDate|否|DateTime| 有效期起|
|endDate|否|DateTime| 有效期至|
|status|否|Integer| 活跃状态|
|allComp|否|Integer| 是否应用到所有门店 1是0否|
|appComps|否|List| 应用门店列表，allComp = 1时必填|
|delComps|否|List| 删除应用门店ID列表，是应用门店的行ID|
|appGrade|否|Integer| 是否指定会员等级 1是0否|
|appGrades|否|List| 应用会员等级,覆盖更新，每次传最新的进来|
|rule|否|String| 活动规则|
|points|否|Integer| 每次消耗积分 0表示不消耗积分抽奖|
|times|否|Integer| 每日抽奖次数限制 0表示不限制抽奖次数|
|amount|否|Long| 抽奖板式格数，默认8个|
|title|否|String| 抽奖标题|
|bgImage|否|String| 抽奖背景图|
|bgImageWidth|否|Integer| 背景图宽度|
|bgImageHeight|否|Integer| 背景图高度|
|btnImage|否|String| 抽奖按钮图片|
|btnImageWidth|否|Integer| 按钮图宽度|
|btnImageHeight|否|Integer| 按钮图高度|
|fontColor|否|String| 字体颜色|
|bgColor|否|String| 背景图颜色|
|prizes|否|List| 设置的奖品|
|--id|否|Long| id 主键|
|--probability|否|Double| 中奖概率|
|--type|否|Integer| 奖品类型标识，0-无；1-积分；2-优惠券；3-服务商品|
|--prizeId|否|String| 奖品标识|
|--prizeName|否|String| 奖品名称|
|--prizeAmount|否|Long| 奖品数量|
|--image|否|String| 奖品图片|
|--imageWidth|否|Integer| 奖品图宽度|
|--imageHeight|否|Integer| 奖品图高度|
