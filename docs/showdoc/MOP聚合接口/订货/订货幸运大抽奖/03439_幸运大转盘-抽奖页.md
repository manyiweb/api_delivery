# 功能描述: 幸运大转盘-抽奖页
 

**请求URL：** 
- `/activity/b2b/wheel/mall/page `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|

###请求参数Json格式
 
```
{
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--wheelId|否|Long| 转盘活动id|
|--amount|否|Long| 抽奖板式格数，默认8个|
|--title|否|String| 抽奖标题|
|--bgImage|否|String| 抽奖背景图|
|--bgImageWidth|否|Integer| 背景图宽度|
|--bgImageHeight|否|Integer| 背景图高度|
|--btnImage|否|String| 抽奖按钮图片|
|--btnImageWidth|否|Integer| 按钮图宽度|
|--btnImageHeight|否|Integer| 按钮图高度|
|--fontColor|否|String| 字体颜色|
|--bgColor|否|String| 转盘背景色|
|--wheelPrizeResps|否|List| 奖品设置|
|----id|否|Long| id 主键|
|----probability|否|Double| 中奖概率|
|----type|否|Integer| 奖品类型编码：0-未中奖；1-积分；2-优惠券；3-服务商品|
|----typeName|否|String| 奖品类型名称|
|----prizeId|否|String| 奖品标识|
|----prizeName|否|String| 奖品名称|
|----prizeAmount|否|Long| 奖品数量|
|----image|否|String| 奖品图片|
|----imageWidth|否|Integer| 奖品图宽度|
|----imageHeight|否|Integer| 奖品图高度|
|--points|否|Integer| 单次消耗积分|
|--balance|否|Double| 会员积分余额|
|--isLimited|否|Integer| 是否限制抽奖次数:0-不限制，1-限制|
|--leftTimes|否|Integer| 当日剩余抽奖次数|
|--rule|否|String| 活动规则|
|--beginDate|否|DateTime| 有效期起|
|--endDate|否|DateTime| 有效期至|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
