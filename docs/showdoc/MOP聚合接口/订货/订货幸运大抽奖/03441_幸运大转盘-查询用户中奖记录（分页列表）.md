# 功能描述: 幸运大转盘-查询用户中奖记录（分页列表）
 

**请求URL：** 
- `/activity/b2b/wheel/mall/reward `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 业务ID|
|tokenId|否|String| 用户标识|
|pageIndex|否|Integer| 分页页码|
|pageSize|否|Integer| 分页大小|
|sword|否|String| 搜索关键字|

###请求参数Json格式
 
```
{
 "id" : 0,
 "tokenId" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "sword" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--pageIndex|否|Integer| 页码|
|--pageSize|否|Integer| 显示记录数|
|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|--first|否|Boolean| 首页|
|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|
|----id|否|Long| id|
|----wheelId|否|Long| 转盘活动标识,对应wheel表id|
|----memberId|否|String| 会员标识,对应smember表id|
|----wheelPrizeId|否|Long| 转盘活动奖品标识，对应wheel_prize表id|
|----type|否|Integer| 奖品类型编码：0-未中奖；1-积分；2-优惠券；3-服务商品|
|----prizeId|否|String| 奖品标识|
|----prizeName|否|String| 奖品名称|
|----prizeAmount|否|Long| 奖品数量|
|----createDate|否|DateTime| 中奖时间|
|----image|否|String| 奖品图片Url|
|----imageWidth|否|Integer| 奖品图片宽度|
|----imageHeight|否|Integer| 奖品图片高度|
|----beginDate|否|DateTime| 奖品有效期起|
|----endDate|否|DateTime| 奖品有效期止|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
