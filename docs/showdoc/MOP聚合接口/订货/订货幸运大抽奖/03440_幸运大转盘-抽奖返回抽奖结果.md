# 功能描述: 幸运大转盘-抽奖返回抽奖结果
 

**请求URL：** 
- `/activity/b2b/wheel/mall/result `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long||
|type|否|Integer| 活动类型 1、会员 2、订货|

###请求参数Json格式
 
```
{
 "id" : 0,
 "type" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long| id 主键|
|--probability|否|Double| 中奖概率|
|--type|否|Integer| 奖品类型编码：0-未中奖；1-积分；2-优惠券；3-服务商品|
|--typeName|否|String| 奖品类型名称|
|--prizeId|否|String| 奖品标识|
|--prizeName|否|String| 奖品名称|
|--prizeAmount|否|Long| 奖品数量|
|--image|否|String| 奖品图片|
|--imageWidth|否|Integer| 奖品图宽度|
|--imageHeight|否|Integer| 奖品图高度|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "probability" : 0,
 "type" : 0,
 "typeName" : "String",
 "prizeId" : "String",
 "prizeName" : "String",
 "prizeAmount" : 0,
 "image" : "String",
 "imageWidth" : 0,
 "imageHeight" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
