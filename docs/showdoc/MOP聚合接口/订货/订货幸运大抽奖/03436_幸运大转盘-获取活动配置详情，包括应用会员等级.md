# 功能描述: 幸运大转盘-获取活动配置详情，包括应用会员等级
 

**请求URL：** 
- `/activity/b2b/wheel/detail `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|

###请求参数Json格式
 
```
{
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long| id 主键|
|--code|否|String| 活动编号|
|--name|否|String| 活动名称|
|--beginDate|否|DateTime| 有效期起|
|--endDate|否|DateTime| 有效期至|
|--status|否|Integer| 活跃状态：0-未启用；1-启用|
|--statusName|否|String| 活跃状态名称|
|--allComp|否|Integer| 是否应用到所有门店 1是0否|
|--appGrade|否|Integer| 是否指定会员等级 1是0否|
|--rule|否|String| 活动规则|
|--points|否|Integer| 每次消耗积分 0表示不消耗积分抽奖|
|--times|否|Integer| 每日抽奖次数限制 0表示不限制抽奖次数|
|--createId|否|String| 创建人标识|
|--createName|否|String| 创建人|
|--createDate|否|DateTime| 创建时间|
|--modifyId|否|String| 修改人标识|
|--modifyName|否|String| 修改人名称|
|--modifyDate|否|DateTime| 修改时间|
|--wheelGrades|否|List| 指定会员等级|
|----id|否|Long| id|
|----gradeId|否|String| 会员等级标识|
|----gradeCode|否|String| 会员等级编码|
|----gradeName|否|String| 会员等级名称|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
