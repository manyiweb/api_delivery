# 修改积分商品
 

**请求URL：** 
- `/b2b/item/gift/update `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|
|status|否|Integer| 状态|
|integral|否|Integer| 积分|
|money|否|Double| 积分|
|quantity|否|Integer| 数量|
|isRestriction|否|Integer| 是否开启限制条件 1 - 开启， 0 - 关闭|
|restrictedPeriod|否|Integer| 限制周期类型,0 - 天，1 - 月|
|restrictedPeriodDays|否|Integer| 限制周期数|
|restrictedQuantity|否|Integer| 限制兑换次数|
|allowExchangePeriod|否|Integer| 启用兑换生效时间段|
|exchangePeriodBegin|否|DateTime| 兑换生效时间段开始时间|
|exchangePeriodEnd|否|DateTime| 兑换生效时间段结束时间|
|giftSpecList|否|List| 规格数量|
|--expressFee|否|Double| 运费|
|--id|否|Long| id|
|--specName|否|String| 规格名称|
|--money|否|Double| 金额|
|--invQty|否|Double| 数量|
|--alreadyQuantity|否|Double| 兑换数量|
|--integral|否|Integer| 积分|
|--skuBarCode|否|String| 商品sku|
|--isActive|否|Integer| 是否活跃|

###请求参数Json格式
 
```
{
 "id" : 0,
 "status" : 0,
 "integral" : 0,
 "money" : 0,
 "quantity" : 0,
 "isRestriction" : 0,
 "restrictedPeriod" : 0,
 "restrictedPeriodDays" : 0,
 "restrictedQuantity" : 0,
 "allowExchangePeriod" : 0,
 "exchangePeriodBegin" : "DateTime",
 "exchangePeriodEnd" : "DateTime",
 "giftSpecList" : [{
 "expressFee" : 0,
 "id" : 0,
 "specName" : "String",
 "money" : 0,
 "invQty" : 0,
 "alreadyQuantity" : 0,
 "integral" : 0,
 "skuBarCode" : "String",
 "isActive" : 0
 }]
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
