# 订货商品详情
 

**请求URL：** 
- `/b2b/item/gift/detail `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|giftId|否|Long| 积分商品id|

###请求参数Json格式
 
```
{
 "giftId" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--allowExchangePeriod|否|Integer| 启用兑换生效时间段|
|--exchangePeriodBegin|否|DateTime| 兑换生效时间段开始时间|
|--exchangePeriodEnd|否|DateTime| 兑换生效时间段结束时间|
|--isRestriction|否|Integer| 是否开启限制条件 1 - 开启， 0 - 关闭|
|--restrictedPeriod|否|Integer| 限制周期类型,0 - 天，1 - 月|
|--restrictedPeriodDays|否|Integer| 限制周期数|
|--restrictedQuantity|否|Integer| 限制兑换次数|
|--expressFee|否|Double| 运费|
|--specDetails|否|List||
|----expressFee|否|Double| 运费|
|----id|否|Long| id|
|----specName|否|String| 规格名称|
|----money|否|Double| 金额|
|----invQty|否|Double| 数量|
|----alreadyQuantity|否|Double| 兑换数量|
|----integral|否|Integer| 积分|
|----skuBarCode|否|String| 商品sku|
|----isActive|否|Integer| 是否活跃|
|--isMutiSpec|否|Integer| 是否多规格|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|

 }],
