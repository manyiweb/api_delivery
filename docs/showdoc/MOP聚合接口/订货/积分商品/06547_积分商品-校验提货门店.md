# 积分商品-校验提货门店

 服务 ： retail
 

**请求URL：** 
- `/appc/Gift/giftTakeCompanyCheck`

**请求方式：**
- undefined
- RequestBody


### 请求参数<业务参数>
 
 入参与积分商品-去兑换商品接口一样（/retail/appc/Gift/ToExchange）


### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--msg|否|String||
|--canExchange|否|Boolean||
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : {
 "msg" : "String",
 "canExchange" : true
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
