# 

**请求URL：** 
- `/b2b/sales/order/gift/add `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|否|String||
|openId|否|String| 小程序openId|
|wxSn|否|String| wxSn|
|itemId|否|String||
|specId|否|String||
|giftId|否|Long||
|companyId|否|String||
|shopCartKey|否|String| 如果是立即购买输入对应的立即购买cartKey|

###请求参数Json格式
 
```
{
 "tokenId" : "String",
 "openId" : "String",
 "wxSn" : "String",
 "itemId" : "String",
 "specId" : "String",
 "giftId" : 0,
 "companyId" : "String",
 "shopCartKey" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--orderId|否|String| 订货订单标识|
|--orderNo|否|String| 订货订单编号|
|--needPay|否|Integer| 订货是否需要支付|
|--amountActuallyPaid|否|Double| 需要支付的金額|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "orderId" : "String",
 "orderNo" : "String",
 "needPay" : 0,
 "amountActuallyPaid" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
