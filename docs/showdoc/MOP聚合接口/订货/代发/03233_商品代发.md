# 商品代发
 

**请求URL：** 
- `/app/sales/order/proxy/delivery `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|否|String| tokenId|
|orderId|否|String| 订单标识|
|remark|否|String| 代发备注|
|orderItems|否|List| 代发商品，里面暂时只要一个oItemId|
|--oItemId|否|String| 订单行标识|
|supplyingCompanyId|否|String| 代发门店标识|
|supplyingCompanyCode|否|String| 代发门店编码|
|supplyingCompanyName|否|String| 代发门店名称|

###请求参数Json格式
 
```
{
 "tokenId" : "String",
 "orderId" : "String",
 "remark" : "String",
 "orderItems" : [{
 "oItemId" : "String"
 }],
 "supplyingCompanyId" : "String",
 "supplyingCompanyCode" : "String",
 "supplyingCompanyName" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
