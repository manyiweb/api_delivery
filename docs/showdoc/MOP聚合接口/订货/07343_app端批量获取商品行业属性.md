# app端批量获取商品行业属性

**请求URL：** 
- `/config//attr/item/batch/list`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|itemIds|是|List| 商品id|

### 请求参数Json格式
 
```
{
 "itemIds" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--itemId|否|String| 商品id|
|--attrs|否|List| 商品所应用的行业属性|
|----industryAttrId|否|Long| 行业属性id|
|----attrId|否|String| 唯一id|
|----code|否|Integer| 编码|
|----alias|否|String| 别名|
|----value|否|String| 值|
|----isRequired|否|Integer| 是否必填 1 - 必填, 0 - 不必填|
|----valueType|否|Integer| 0 任何值 1 序列|
|----content|否|String| 内容值,多个值时|
|----isApplyAll|否|Integer| 应用所有|
|----contentId|否|String| 自定义关联id|
|----contentArr|否|List||
|----customObjectFullList|否|List| 自定义对象|
|------itemCode|否|String| 自定义对象编码|
|------itemName|否|String| 自定义对象名称|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "itemId" : "String",
 "attrs" : [{
 "industryAttrId" : 0,
 "attrId" : "String",
 "code" : 0,
 "alias" : "String",
 "value" : "String",
 "isRequired" : 0,
 "valueType" : 0,
 "content" : "String",
 "isApplyAll" : 0,
 "contentId" : "String",
 "contentArr" : null,
 "customObjectFullList" : [{
 "itemCode" : "String",
 "itemName" : "String"
 }]
 }]
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
