# 查询订单是否允许抽奖，仅做订单与门店配置的检验，当前不处于活动时间、门店未应用、活动未启用等问题这里不会校验，抽奖接口再校验
 

**请求URL：** 
- `/activity/b2b/wheel/orderWheelInfo `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|String| id|

###请求参数Json格式
 
```
{
 "id" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--canLottery|否|Boolean|是否能抽奖，true or false |
|--wheelId|否|Long|抽奖活动id |
|--notCanMsg|否|String|不能抽奖的原因 |
|--entryImg|否|String|入口图片 |
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "canLottery" : true,
 "wheelId" : 0,
 "notCanMsg" : "String",
 "entryImg" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
