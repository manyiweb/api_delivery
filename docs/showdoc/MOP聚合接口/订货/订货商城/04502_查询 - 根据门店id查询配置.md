# 根据门店id查询配置
 

**请求URL：** 
- `/b2b/mallSet/company/get `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|String| id|

###请求参数Json格式
 
```
{
 "id" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--companyId|否|String|门店id |
|--payAfterWheelEnable|否|Boolean|是否开启支付后抽奖 |
|--wheelId|否|Long|关联的抽奖id |
|--wheelName|否|String|关联的抽奖名称 |
|--enterImageUrl|否|String|抽奖入口图片url |
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "companyId" : "String",
 "payAfterWheelEnable" : true,
 "wheelId" : 0,
 "wheelName" : "String",
 "enterImageUrl" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
