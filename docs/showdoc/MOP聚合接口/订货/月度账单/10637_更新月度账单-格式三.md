# 更新账单 - 修改各返利账户的期末可提返利余额

**请求URL：** 
- `/api/mct/company/reconciliation-statement/monthly/type3/save`

**请求方式：** 
- `POST`
- `RequestBody`


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|statementId|是|Long| 账单ID|
|rebateAccountUpdates|否|List| 返利账户更新列表|
|--statementAccountId|是|Long| 明细ID|
|--closingWithdrawableBalance|否|Double| 期末可提返利余额|
|--manualModifyReason|否|String| 手动修改原因|

### 请求参数Json格式
 
```
{
 "statementId":0,
 "rebateAccountUpdates":[{
 "statementAccountId":0,
 "closingWithdrawableBalance":0,
 "manualModifyReason":"String"
 }]
}
```

### 响应参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 响应参数Json格式
 
```
{
 "data":null,
 "msg":"String",
 "code":"String",
 "exceptionStackInfo":"String",
 "traceId":"String"
}
```
