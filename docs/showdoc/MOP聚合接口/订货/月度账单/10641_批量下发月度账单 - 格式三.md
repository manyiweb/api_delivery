# 批量下发月度账单 - 格式三

**请求URL：** 
- `/api/mct/company/reconciliation-statement/monthly/type3/batch-issue`

**请求方式：** 
- `POST`
- `FormData`


### 请求参数<业务参数>
 
无参数


### 响应参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 响应参数Json格式
 
```
{
 "data":null,
 "msg":"String",
 "code":"String",
 "exceptionStackInfo":"String",
 "traceId":"String"
}
```
