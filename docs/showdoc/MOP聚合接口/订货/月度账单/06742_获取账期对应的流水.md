# 获取账期对应的流水
 

**请求URL：** 
- `/b2b/monthAccount/order/trans/list`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|monthAccountMainId|是|Long| 账单主键|
|sword|否|String| 来源单号/支付流水号|
|pageIndex|否|Integer||
|pageSize|否|Integer||
|orderField|否|String||
|orderSort|否|String|asc 顺序 desc 倒序|

### 请求参数Json格式
 
```
{
 "monthAccountMainId" : 0,
 "sword" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--pageIndex|否|Integer||
|--pageSize|否|Integer||
|--pageCount|否|Integer||
|--totalCount|否|Long||
|--first|否|Boolean||
|--last|否|Boolean||
|--content|否|List||
|----transId|否|Long| 该流水对应中间表记录的主键|
|----accountId|否|String| 余额流水主键|
|----fundsCustomId|否|Integer| 自定义账户流水主键|
|----accountType|否|String| 支付流水类型 0为余额支付 1为自定义账户支付|
|----transCode|否|String| 支付流水单号|
|----accountName|否|String| 账户名称|
|----changeType|否|String| 变更类型|
|----transType|否|String| 流水类型|
|----transAmount|否|Double| 流水金额|
|----createDate|否|DateTime| 创建日期|
|----createName|否|String| 创建人姓名|
|----posingDate|否|DateTime| 过账日期|
|----sourceCode|否|String| 来源单号|
|----externalOrderNo|否|String| 外部单号|
|----remark|否|String| 摘要|
|----rowRemark|否|String| 行备注|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
