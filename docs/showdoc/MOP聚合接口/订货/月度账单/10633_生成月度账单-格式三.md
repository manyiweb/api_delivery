# 生成月度账单

**请求URL：** 
- `/hr/reconciliation/rebate-statement/generate`

**请求方式：** 
- `POST`
- `RequestBody`


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 公司ID|
|beginTime|否|DateTime| 开始时间|
|endTime|否|DateTime| 结束时间|
|companyName|否|String| 公司名称|

### 请求参数Json格式
 
```
{
 "companyId":"String",
 "beginTime":"DateTime",
 "endTime":"DateTime",
 "companyName":"String"
}
```

### 响应参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 响应参数Json格式
 
```
{
 "data":null,
 "msg":"String",
 "code":"String",
 "exceptionStackInfo":"String",
 "traceId":"String"
}
```
