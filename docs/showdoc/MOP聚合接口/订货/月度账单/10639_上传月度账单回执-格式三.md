# 上传账单回执

**请求URL：** 
- `/api/mct/company/reconciliation-statement/monthly/type3/receipt`

**请求方式：** 
- `POST`
- `RequestBody`


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|statementId|是|Long| 账单ID|
|receiptId|否|Long| 回执id|
|receiptFileUrl|否|String| 回执文件|
|receiptFileName|否|String| 文件名|

### 请求参数Json格式
 
```
{
 "statementId":0,
 "receiptId":0,
 "receiptFileUrl":"String",
 "receiptFileName":"String"
}
```

### 响应参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 响应参数Json格式
 
```
{
 "data":null,
 "msg":"String",
 "code":"String",
 "exceptionStackInfo":"String",
 "traceId":"String"
}
```
