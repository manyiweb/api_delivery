# 获取账单分页列表

**请求URL：** 
- `/hr/reconciliation/rebate-statement/page`

**请求方式：** 
- `POST`
- `RequestBody`


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 公司ID|
|statementStatus|否|Integer| 账单状态（0-待确认，1-已确认）|
|beginTime|否|DateTime| 开始时间|
|endTime|否|DateTime| 结束时间|

### 请求参数Json格式
 
```
{
 "companyId":"String",
 "statementStatus":0,
 "beginTime":"DateTime",
 "endTime":"DateTime"
}
```

### 响应参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--pageIndex|否|Integer||
|--pageSize|否|Integer||
|--pageCount|否|Integer||
|--totalCount|否|Long||
|--first|否|Boolean||
|--last|否|Boolean||
|--content|否|List||
|----id|否|Long| 主键ID|
|----statementNo|否|String| 账单编号|
|----statementPeriod|否|String| 账期|
|----beginTime|否|DateTime| 开始时间|
|----endTime|否|DateTime| 结束时间|
|----companyName|否|String| 代理客户|
|----companyId|否|String| 代理客户id|
|----statementStatus|否|Integer| 账单状态|
|----statementStatusDesc|否|String| 账单状态描述|
|----issueStatus|否|Integer| 下发状态|
|----issueStatusDesc|否|String| 下发状态描述|
|----baseAccountId|否|Long| 基础账号ID|
|----baseAccountBalanceId|否|Long| 账号余额ID|
|----baseAccountBalance|否|Double| 基础账号余额|
|----depositAccountId|否|Long| 保证金账号ID|
|----depositAccountBalanceId|否|Long| 保证金账号ID余额ID|
|----depositAccountName|否|String| 保证金账号名称|
|----depositAccountBalance|否|Double| 保证金账号账号余额|
|----openingBalance|否|Double| 期初余额|
|----closingBalance|否|Double| 期末余额|
|----deliveryAmount|否|Double| 本月已发货金额|
|----refundAmount|否|Double| 本月已退款金额|
|----receivedAmount|否|Double| 本月已收款金额|

|----receiptList|否|List| 回执|

|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
