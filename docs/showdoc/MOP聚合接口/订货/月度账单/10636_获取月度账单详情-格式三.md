# 获取账单详情

**请求URL：** 
- `/hr/reconciliation/rebate-statement/detail`

**请求方式：** 
- `POST`
- `RequestBody`


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long||

### 请求参数Json格式
 
```
{
 "id":0
}
```

### 响应参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long| 主键ID|
|--statementNo|否|String| 账单编号|
|--statementPeriod|否|String| 账期|
|--beginTime|否|DateTime| 开始时间|
|--endTime|否|DateTime| 结束时间|
|--companyName|否|String| 代理客户|
|--companyId|否|String| 代理客户id|
|--statementStatus|否|Integer| 账单状态|
|--statementStatusDesc|否|String| 账单状态描述|
|--issueStatus|否|Integer| 下发状态|
|--issueStatusDesc|否|String| 下发状态描述|
|--baseAccountId|否|Long| 基础账号ID|
|--baseAccountBalanceId|否|Long| 账号余额ID|
|--baseAccountBalance|否|Double| 基础账号余额|
|--depositAccountId|否|Long| 保证金账号ID|
|--depositAccountBalanceId|否|Long| 保证金账号ID余额ID|
|--depositAccountName|否|String| 保证金账号名称|
|--depositAccountBalance|否|Double| 保证金账号账号余额|
|--openingBalance|否|Double| 期初余额|
|--closingBalance|否|Double| 期末余额|
|--deliveryAmount|否|Double| 本月已发货金额|
|--refundAmount|否|Double| 本月已退款金额|
|--receivedAmount|否|Double| 本月已收款金额|
|--remark|否|String| 备注|
|--confirmTime|否|DateTime| 确认时间|
|--confirmName|否|String| 确认人姓名|
|--issueTime|否|DateTime| 下发时间|
|--issueName|否|String| 下发人姓名|
|--createDate|否|DateTime| 创建时间|
|--createName|否|String| 创建人姓名|
|--accountList|否|List| 返利账号明细列表|
|----id|否|Long| 主键ID|
|----statementId|否|Long| 主表ID|
|----rebateAccountBalanceId|否|Long| 返利账号余额ID|
|----rebateAccountBalance|否|Double| 返利账号余额|
|----rebateAccountId|否|Long| 返利账号ID|
|----rebateAccountName|否|String| 返利账号名称|
|----rebateAccountCode|否|String| 返利账号编码|
|----openingWithdrawableBalance|否|Double| 期初可提返利余额|
|----closingWithdrawableBalance|否|Double| 期末可提返利余额|
|----withdrawnRebate|否|Double| 本月已提返利金额|
|----newRebate|否|Double| 本月新增返利金额|
|----refundAmount|否|Double| 本月已退款金额|
|----remark|否|String| 备注|
|----isManualModified|否|Integer| 是否手动修改期末余额|
|----isManualModifiedDesc|否|String| 是否手动修改期末余额描述|
|----manualModifyName|否|String| 手动修改人姓名|
|----manualModifyTime|否|DateTime| 手动修改时间|
|----manualModifyReason|否|String| 手动修改原因|
|--receiptList|否|List| 回执|
|----id|否|Long| 主键ID|
|----receiptFileUrl|否|String| 回执文件URL|
|----receiptFileName|否|String| 回执文件名|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
