# 获取账单流水

**请求URL：** 
- ` /api/mct/company/reconciliation-statement/monthly/type3/trans/list`

**请求方式：** 
- `POST`
- `RequestBody`

|:---- |:---|:----- |----- |
|sword|否|String||

|orderField|否|String||
|orderSort|否|String||
|searchBeans|否|List||
|--typeCode|否|String||
|--typeName|否|String||
|--dataType|否|String||
|--isSingle|否|String||
|--isLikeSearch|否|String||
|--items|否|List||
|--current|否|Object||

|----minValue|否|String||
|----maxValue|否|String||

|----isSelect|否|String||
|--sword|否|String||
|--pageIndex|否|Integer||
