# 获取品牌月度账单配置信息
 

**请求URL：** 
- `/config/b2b/MonthAccount/get`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|groupId|是|String||

### 请求参数Json格式
 
```
{
 "groupId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--accountStatisticDate|否|Integer| 月度账单统计时间|
|--accountAutoCheckDate|否|Integer| 月度账单自动确定天数|
|--accountCheckState|否|Integer| 月度账单启用状态 1为启用 -1为不启用|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "accountStatisticDate" : 0,
 "accountAutoCheckDate" : 0,
 "accountCheckState" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
