# 功能描述: appCode查询
 

**请求URL：** 
- `/core/appCode/company/optionName `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|optionName|是|String| appcode类型|
|inheritCode|是|String| 品牌继承类型|
|companyId|是|String|门店id|
|groupId|是|String|品牌id|

###请求参数Json格式
 
```
{
 "optionName" : "String"
}
```
