# 保存退款单
 

**请求URL：** 
- `/b2b/billMoney/refund/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|refundAmount|否|Double| 付款金额|
|userId|否|String| 用户ID|
|userName|否|String| 用户名|
|companyId|否|String| 公司ID|
|distributorId|否|String| 分销商ID|
|companyCode|否|String| 公司编码|
|companyName|否|String| 公司名称|
|groupId|否|String| 品牌商ID|
|groupCode|否|String| 品牌商编码|
|groupName|否|String| 品牌商名称|
|payType|否|String| 支付方式|
|bankAccount|否|String| 银行账户|
|bankName|否|String| 银行名称|
|receivableAccount|否|String| 收款账户|
|refundDate|否|String| 付款日期|
|remark|否|String| 备注|
|orderId|否|String| 订单ID|
|type|否|String| 类型0|
|money|否|Double| 付款金额|
|offlinePayAmount|否|Double| 线下支付付款金额|
|autoCreate|否|Boolean| 自动创建|
|attachmentIds|否|List| 电子回单|
