# 经销商退款单列表

**请求URL：** 
- `/b2b/billMoney/refund/list/distor/{source}`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|keyword|否|String| 模糊搜索|
|companyIds|否|List| 商户|
|typeName|否|List| 单据类型|
|orderStatus|否|List| 单据状态|
|refundStatus|否|List| 单据状态|
|sourceAcceptMsg|否|List| 单据状态|
|sourceAcceptLevel|否|List| 单据状态|
|sourceAcceptDate|否|List| 单据状态|
|cancelDate|否|Object| 创建日期|
|--start|否|DateTime||
|--end|否|DateTime||
|createDate|否|Object| 创建日期|
|--start|否|DateTime||
|--end|否|DateTime||
|id|否|String||
|pageSize|否|Integer||
|pageNo|否|Integer||
|sortField|否|String||
|sortDirection|否|String||
|viewId|否|String||
