# 退款单详情
 

**请求URL：** 
- `/b2b/billMoney/refund/detail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||
|sword|否|String||

### 请求参数Json格式
 
```
{
 "id" : 0,
 "sword" : "String"
}
```

|:---- |:---|:----- |----- |
|data|否|Object||

|----sourceAcceptDate|否|DateTime| 受理时间|
