#

**请求URL：** 
- `/config/customSet/funds/save`

**请求方式：** 
- `POST`
- `RequestBody`


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 自定义账户ID（编辑时传入，新增时不传）|
|logoUrl|否|String| 账户图标URL|
|accountCode|否|String| 账户编码（唯一标识）|
|accountName|否|String| 账户名称|
|fundChangeSelectSubject|否|Integer| 启用资金变更单科目必选（0-否，1-是）|
|lineNum|否|Long| 行号（用于排序）|
|status|否|Integer| 账户状态（0-禁用，1-启用）|
|recharge|否|Boolean| 是否允许充值|
|deduct|否|Boolean| 是否允许抵扣|
|rebate|否|Boolean| 是否为返利账户|
|promotion|否|Boolean| 是否支持促销|
|deductRate|否|Double| 抵扣比例（0-1之间的小数）|
|deductionExpressFee|否|Boolean| 是否抵扣运费|
|isAllItem|否|Integer| 是否全部商品（0-指定商品，1-全部商品）|
|openWithdrawTime|否|Boolean| 是否开启提现时间限制|
|withdrawTime|否|List| 提现时间段列表（如：[9, 10, 11, 14, 15, 16]表示9-11点和14-16点可提现）|
|canCombinationPay|否|Boolean| 是否支持组合支付|
|isWithdrawAble|否|Boolean| 是否允许提现|
|withdrawRate|否|Double| 提现手续费比例（0-1之间的小数）|
|openPreferentialAmount|否|Boolean| 是否开启优惠金额|
|remark|否|String| 备注说明|
|types|否|List| 品牌/分类/系列类型设置列表
 每个Map包含typeId（类型ID）和type（类型，如：1-品牌，2-分类，3-系列）|
|specIds|否|List| 指定商品规格ID列表|
|ids|否|List| 指定商品ID列表|
|applyAllCompany|否|Boolean| 是否应用所有门店|
|applyCompanyIds|否|List| 应用门店ID列表|
