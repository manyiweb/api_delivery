# 获取请单价对应的品牌、系列、类别

**请求URL：** 
- `/config/b2b/listPrice/getCategoryList`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|String||

### 请求参数Json格式
 
```
{
 "id" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--id|否|String| 主键|
|--categoryId|否|String| 类型id|
|--categoryName|否|String| 类型名称|
|--categoryCode|否|String| 类型编码|
|--categoryType|否|Integer| 类型类型 0品牌 1系列 2类别|
|--calType|否|Integer| 计算方式 0按固定金额 1按成本价固定加价 2按成本价比例加价|
|--amount|否|Double| 金额|
|--priceListId|否|String| 清单价id|
|--groupId|否|String| 品牌id|
|--createId|否|String||
|--createName|否|String||
|--createDate|否|DateTime||
|--modifyId|否|String||
|--modifyName|否|String||
|--modifyDate|否|DateTime||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||

```
 "data" : [{
 "id" : "String",

 "categoryCode" : "String",

 "createDate" : "DateTime",

 "modifyName" : "String",
 "modifyDate" : "DateTime"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
