# 校验订货起订量商品数量

**请求URL：** 
- `/config/checkB2bMoqItemQuantity`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 门店id|
|specDetails|是|List| 规格信息|
|--itemId|否|String| 商品id|
|--specId|否|String| 规格id|
|--spec1|否|String| 规格一|
|--quantity|否|Double| 规格一数量|

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "specDetails" : [{
 "itemId" : "String",
 "specId" : "String",
 "spec1" : "String",
 "quantity" : 0
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--moqDimension|否|Integer| 起订量维度 1按sku 2按规格维度|
|--extvalue4|否|Integer| 启用商品起订量|
|--errorList|否|List| 异常信息|
|----itemId|否|String| 商品id|
|----specId|否|String| 规格id|
|----spec1|否|String| 规格一|
|----quantity|否|Double| 规格一数量|
|----spec1LeastQuantity|否|Double| 规格一最小起订量|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "moqDimension" : 0,
 "extvalue4" : 0,
 "errorList" : [{
 "itemId" : "String",
 "specId" : "String",
 "spec1" : "String",
 "quantity" : 0,
 "spec1LeastQuantity" : 0
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
