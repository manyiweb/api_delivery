# 获取起订量数据

**请求URL：** 
- `/config/getB2bMoqItem`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 门店id|
|itemId|是|String| 商品id|

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "itemId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--moqDimension|否|Integer| 起订量维度 1按sku 2按规格维度|
|--skuMoqList|否|List| sku起订量列表|
|----id|否|Long| 主键标识|
|----itemId|否|String| 商品标识|
|----itemCode|否|String| 商品编码|
|----itemName|否|String| 商品名称|
|----skuBarCode|否|String| 商品条码|
|----specId|否|String| 规格标识|
|----specName|否|String| 规格名称|
|----itemTypeName|否|String| 商品分类描述|
|----unit|否|String| 单位|
|----quantity|否|Double| 商品起订数量|
|----mid|否|String| 关联主表标识，与app_code关联|
|----multipleMinimumQuantity|否|Integer| 是否开启倍数起订 0否 1是|
|--specMoqList|否|List| 规格维度起订量列表|
|----id|否|Long| 主键|
|----specDimensionId|否|Long| 规格维度id|
|----spec1|否|String| 规格一|
|----quantity|否|Double| 规格一起订量|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
