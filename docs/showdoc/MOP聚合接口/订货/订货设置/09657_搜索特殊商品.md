# 搜索特殊商品

**请求URL：** 
- `/config/b2b/listPrice/specialGoods/search`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|priceListId|否|String| 价格清单ID|
|sword|否|String|关键字|
|tokenId|否|String||

### 请求参数Json格式
 
```
{
 "priceListId" : "String",
 "sword" : "String",
 "tokenId" : "String",
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--id|否|String| 主键|
|--itemId|否|String| 商品id|
|--itemCode|否|String| 商品编码|
|--itemName|否|String| 商品名称|
|--skuCode|否|String| SKU码|
|--calType|否|Integer| 计算方式 0按固定金额 1按成本价固定加价 2按成本价比例加价|
|--amount|否|Double| 金额|
|--priceListId|否|String| 清单价id|
|--groupId|否|String| 品牌id|
|--createId|否|String||
|--createName|否|String||
|--createDate|否|DateTime||
|--modifyId|否|String||
|--modifyName|否|String||
|--modifyDate|否|DateTime||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||

```
 "id" : "String",

 "itemCode" : "String",
 "itemName" : "String",

 "createName" : "String",
 "createDate" : "DateTime",
 "modifyId" : "String",
 "modifyName" : "String",
 "modifyDate" : "DateTime"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
