# 获取商品单位组

**请求URL：** 
- `/b2b/wmc/order/getUnitList`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|itemId|否|String| 商品id|
|specId|否|String| 规格id|

### 请求参数Json格式
 
```
{
 "itemId" : "String",
 "specId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--itemId|否|String||
|--specId|否|String||
|--unitId|否|String||
|--unitName|否|String||
|--unitRate|否|Double||
|--costExpressFee|否|Double||
|--expressFee|否|Double||
|--isOrder|否|Object||
|--itemUnitPrice|否|Double|单位清单价 |
|--distributionPickingUnit|否|Boolean||
|--standardUnit|否|Boolean| 是否是标准单位|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "itemId" : "String",
 "specId" : "String",
 "unitId" : "String",
 "unitName" : "String",
 "unitRate" : 0,
 "costExpressFee" : 0,
 "expressFee" : 0,
 "isOrder" : null,
 "itemUnitPrice" : 0,
 "distributionPickingUnit" : true,
 "standardUnit" : true
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
