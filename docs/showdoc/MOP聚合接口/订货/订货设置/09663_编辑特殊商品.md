# 编辑特殊商品

**请求URL：** 
- `/config/b2b/listPrice/specialGoods/edit`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|String| 主键|
|itemId|否|String| 商品id|
|itemCode|否|String| 商品编码|
|itemName|否|String| 商品名称|
|skuCode|否|String| SKU码|
|calType|否|Integer| 计算方式 0按固定金额 1按成本价固定加价 2按成本价比例加价|
|amount|否|Double| 金额|
|priceListId|否|String| 清单价id|

### 请求参数Json格式
 
```
{
 "id" : "String",
 "itemId" : "String",
 "itemCode" : "String",
 "itemName" : "String",
 "skuCode" : "String",
 "calType" : 0,
 "amount" : 0,
 "priceListId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
