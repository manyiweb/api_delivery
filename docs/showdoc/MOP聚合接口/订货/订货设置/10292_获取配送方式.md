# 获取到货日期

**请求URL：** 
- `/b2b/wmc/order/getDeliveryType`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String||

### 请求参数Json格式
 
```
{
 "companyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--deliveryType|是|String| 配送方式：xcth-自提，shsm-配送,custom自定义|
|--deliveryTypeName|否|String| 配送方式名称：xcth-自提，shsm-配送|
|--status|是|Boolean| 是否启用|
|--defaultValue|是|Boolean| 是否默认|
|--enableExpectedDays|否|Boolean| 是否按预配送时间交货|
|--expectedDays|否|Integer| 预配送时间(天)|
|--enableOrderCut|否|Boolean| 是否启用截单设置|
|--orderCutTime|否|String| 截单时间|
|--enableSelectableDeliveryDays|否|Boolean| 是否启用可选配货天数|
|--selectableDeliveryDays|否|Integer| 可选配货天数|
|--enableWeeks|否|Boolean| 是否启用可配送日|
|--weeks|否|String| 可配送日|
|--enableWeeksExcludeCurrentDay|否|Boolean| 启用可配送日下单当天不可配送|
|--openExpressFee|否|Boolean| 是否计算运费|
|--aliasDeliveryName|否|String| 自定义配送方式别名|
|--openDeliveryPersonnel|否|Boolean| 启用配送员|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
