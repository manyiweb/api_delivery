# 保存运费模板

**请求URL：** 
- `/config/b2b/expressfee/template/save`

**请求方式：** 
- `POST`
- `RequestBody`


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|String| 主键|
|templateName|否|String| 模板名称|
|templateCode|否|String| 模板编码|
|logisticsCode|否|String| 物流商编码|
|logisticsName|否|String| 物流商名称|
|calculateWay|否|Integer| 计费方式 0按订单金额 1按订货商品 2按运输类型 3按订单重量 4按订单体积 5按商品数量|
|isActive|否|Boolean| 是否活跃|
|urgentFee|否|Double| 加急运费|
|expressFeeRemark|否|String| 运费说明|
|calWayOrderAmount|否|Object| 按订单金额|
|--isSpecial|否|Boolean| 是否指定特殊商品|
|--isOrderTotalAmount|否|Boolean| 按订单总金额计算|
|--templateIntervals|否|List| 区间|
|----orderAmount|否|Double| 订单总额|
|----dimension|否|Integer| 计算维度 0固定金额 1固定比例|
|----expressFee|否|Double| 运费|
|----expressFeeRate|否|Double| 运费比例|
|--specialGoods|否|List| 特殊商品|
|----itemId|否|String| 商品id|
|----specId|否|String| 规格id|
|----itemCode|否|String| 商品编码|
|----itemName|否|String| 商品名称|
|----skuCode|否|String| sku码|
|----expressFeeCost|否|Double| 运费成本|
|----minUnitExpressFee|否|Double| 最小单位运费|
|calWayB2bProduct|否|Object| 按订货商品|
|--b2bProductList|否|List||
|----itemId|否|String| 商品id|
|----specId|否|String| 规格id|
|----itemCode|否|String| 商品编码|
|----itemName|否|String| 商品名称|
|----skuCode|否|String| sku码|
|----expressFeeCost|否|Double| 运费成本|
|----minUnitExpressFee|否|Double| 最小单位运费|
|calWayTransport|否|Object| 按运输类型|
|--subTransportDtos|否|List||
|----transportTypeId|否|Long| 运输类型id|
|----transportTypeCode|否|String| 运输类型编码|
|----transportTypeName|否|String| 运输类型名称|
|----calWayType|否|Integer| 计费类型 0按固定金额 1按固定比例|
|----amount|否|Double| 最小单位计费规则|
|calWayOrderWeight|否|Object| 按订单重量|
|--logisticsCode|否|String| 物流商编码|
|--logisticsName|否|String| 物流商名称|
|--regions|否|List| 区域 (编辑时没有变动可以不传)|
|----areas|否|List| 区域|
|----firstWeight|否|Double| 首重|
|----firstFreight|否|Double| 首重运费|
|----continuedWeight|否|Double| 续重|
|----continuedFreight|否|Double| 续重运费|
|calWayOrderVolumeDto|否|Object| 按订单体积|
|--expressFee|否|Double| 当前路线运费单价|
|--volume|否|Double| 订单体积|
|calWayProductQuantity|否|Object| 按商品数量|
|--regionRules|否|List| 配送区域规则|
|----area|否|Object| 配送区域|
|------areaName|否|String| 配送区域|
|------areaCode|否|String| 区域编码|
|------level|否|Integer| 区域级别|
|----firstQuantity|否|Double| 首件数量|
|----firstFee|否|Double| 首件运费|
|----continueQuantity|否|Double| 续件数量|
|----continueFee|否|Double| 续件加收运费|
|--feeProductApplyRecord|否|Object| 运费计算商品应用记录|
|----applyType|否|Integer| 申请类型 1 全部商品 2 指定商品 3 指定品牌、系列、类型|
|----brandSeriesTypes|否|List| 品牌、系列、类型|
|------specifiedType|否|Integer| 具体的类型 1 品牌 2 系列 3 类型|
|------name|否|String| 名称 (品牌名称/系列名称/类型名称)|
|------id|否|String| 品牌id/系列id/类型id|
|------code|否|String| 品牌code/系列code/类型code|
|----products|否|List| 商品|
|------itemCode|否|String| 商品编码|
|------skuBarcode|否|String| SKU码|
|------itemName|否|String| 商品名称|
|------itemId|否|String| 商品ID|
|------specId|否|String| 规格ID|
|createId|否|String| 创建人|
|createName|否|String| 创建人名称|
|createDate|否|DateTime| 创建时间|
