# 订单类型 --运费模板获取

**请求URL：** 
- `/config/b2b/expressfee/template/apply/orderType/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|String|门店id|

### 请求参数Json格式
 
```
{
 "id" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|String| 主键|
|--lineId|否|String| 线路id|
|--isInherit|否|Boolean| 是否继承|
|--openApply|否|Boolean| 按订货类型应用运费模板|
|--isInheritOrderType|否|Boolean| 是否继承品牌订货类型|
|--templateList|否|List| 订单类型运费模板列表|
|----templateId|否|String| 模板id|
|----templateName|否|String| 模板名称|
|----templateCode|否|String| 模板编码|
|----orderTypeId|否|String| 订货类型id|
|----orderTypeName|否|String| 订货类型名称|
|----orderTypeCode|否|String| 订货类型编码|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "id" : "String",
 "lineId" : "String",
 "isInherit" : true,
 "openApply" : true,
 "isInheritOrderType" : true,
 "templateList" : [{
 "templateId" : "String",
 "templateName" : "String",
 "templateCode" : "String",
 "orderTypeId" : "String",
 "orderTypeName" : "String",
 "orderTypeCode" : "String"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
