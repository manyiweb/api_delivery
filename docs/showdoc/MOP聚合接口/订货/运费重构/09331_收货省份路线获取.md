# 收货省份路线获取

**请求URL：** 
- `/config/b2b/expressfee/province/line/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||
|sword|否|String||

### 请求参数Json格式
 
```
{
 "id" : 0,
 "sword" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long| 主键id|
|--lineId|否|String|路线id |
|--provinceId|否|String|省份id |
|--provinceName|否|String|省份名称 |
|--lineName|否|String|路线名称 |
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "lineId" : "String",
 "provinceId" : "String",
 "provinceName" : "String",
 "lineName" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
