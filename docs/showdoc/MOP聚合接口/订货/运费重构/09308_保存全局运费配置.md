# 保存全局运费配置

**请求URL：** 
- `/config/b2b/expressfee/globalSet/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|String| 主键id|
|calWayAddress|否|Integer| 0按收货地址计费 1按收货省份计费 2按订货类型计费|

### 请求参数Json格式
 
```
{
 "id" : "String",
 "calWayAddress" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
