# 运费模板列表

**请求URL：** 
- `/config/b2b/expressfee/template/list/MYSQL`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|keyword|否|String||
|calculateWay|否|List| 0按订单金额 1按订货商品 2按运输类型 3按订单重量|
|logisticsCode|否|String| 物流商|
|createDate|否|Object| 创建日期|
|--start|否|DateTime||
|--end|否|DateTime||
|createId|否|List| 创建人|
|id|否|String||
|pageSize|否|Integer||
|pageNo|否|Integer||
|sortField|否|String||
|sortDirection|否|String||
|viewId|否|String||

### 请求参数Json格式
 
```
{
 "keyword" : "String",
 "calculateWay" : null,
 "logisticsCode" : "String",
 "createDate" : {
 "start" : "DateTime",
 "end" : "DateTime"
 },
 "createId" : null,
 "id" : "String",
 "pageSize" : 0,
 "pageNo" : 0,
 "sortField" : "String",
 "sortDirection" : "String",
 "viewId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--content|否|List||
|----id|否|Long|主键标识 |
|----templateName|否|String|模板名称 |
|----templateCode|否|String|模板编码 |
|----isActive|否|Integer|活跃状态 0不启用 1启用 |
|----isActiveString|否|String|活跃状态 0不启用 1启用 |
|----calculateWay|否|Integer|计费方式 0按订单金额 1按订货商品 2按运输类型 3按订单重量 |
|----calculateWayString|否|Integer|计费方式 0按订单金额 1按订货商品 2按运输类型 3按订单重量 |
|----logisticsCode|否|String|物流商编码 |
|----logisticsName|否|String|物流商名称 |
|--pageSize|否|Integer||
|--pageNo|否|Integer||
|--total|否|Long||
|--totalPage|否|Integer||
|--hasNextPage|否|Boolean||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
