# 保存模板应用 --路线

**请求URL：** 
- `/config/b2b/expressfee/template/apply/line/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|String| 主键|
|lineId|否|String| 线路id|
|calculateWay|否|Integer| 计费方式 0按订单金额 1按订货商品 2按运输类型 3按订单重量|
|templateList|否|List| 应用的模板|
|--templateId|否|String| 模板id|
|--templateName|否|String| 模板名称|
|--templateCode|否|String| 模板编码|
|--logisticsCode|否|String| 物流商编码|
|--logisticsName|否|String| 物流商名称|

### 请求参数Json格式
 
```
{
 "id" : "String",
 "lineId" : "String",
 "calculateWay" : 0,
 "templateList" : [{
 "templateId" : "String",
 "templateName" : "String",
 "templateCode" : "String",
 "logisticsCode" : "String",
 "logisticsName" : "String"
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
