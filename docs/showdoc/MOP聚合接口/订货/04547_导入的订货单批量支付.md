# 导入的订货单批量支付
 

**请求URL：** 
- `/b2b/batch/pay `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|payType|否|Integer| 支付方式 1、账户余额 2、自定义账户|
|orderIds|否|List| 订单标识|
|accountId|否|Long| 自定义账户id|

###请求参数Json格式
 
```
{
 "payType" : 0,
 "orderIds" : null,
 "accountId" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--isAllSuccess|否|Boolean| 是否全部成功|
|--isAllFail|否|Boolean| 是否全部失败|
|--errorMsg|否|List| 错误数据（只有错误信息）|
|--errorInfos|否|List| 完整错误数据|
|----isSuccess|否|Boolean||
|----orderNo|否|String||
|----msg|否|String||
|----fullMsg|否|String||
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "isAllSuccess" : true,
 "isAllFail" : true,
 "errorMsg" : null,
 "errorInfos" : [{
 "isSuccess" : true,
 "orderNo" : "String",
 "msg" : "String",
 "fullMsg" : "String"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
