# 订货助手 签到列表
 

**请求URL：** 
- `/b2b/act/signinlist `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 商户id|
|tokenId|否|String||

###请求参数Json格式
 
```
{
 "companyId" : "String",
 "tokenId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--point|否|Double| 当前积分|
|--todaySignined|否|Integer| 当日是否已经签到|
|--signinRule|否|String| 签到奖励规则|
|--countSignin|否|Integer| 连续签到次数|
|--list|否|List| 奖励记录|
|----date|否|String| 日期|
|----isSignin|否|Integer| 是否已经签到|
|----points|否|Double| 赠送积分|
|----isToday|否|Integer| 是否今日|
|----isGiftPackage|否|Integer| 赠送包裹|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : {
 "point" : 0,
 "todaySignined" : 0,
 "signinRule" : "String",
 "countSignin" : 0,
 "list" : [{
 "date" : "String",
 "isSignin" : 0,
 "points" : 0,
 "isToday" : 0,
 "isGiftPackage" : 0
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
