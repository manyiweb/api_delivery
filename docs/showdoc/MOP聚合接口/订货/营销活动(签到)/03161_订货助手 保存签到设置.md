# 订货助手 保存签到设置
 

**请求URL：** 
- `/b2b/act/saveSigninAct `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|actName|否|String| 活动名称|
|modifyTime|否|String| 更新时间|
|modifierName|否|String| 更新人|
|isGiftPoint|否|Integer| 开启日签奖励送积分-是 否|
|giftPointOneDay|否|Double| 日签奖励积分|
|signinRule|否|String| 签到奖励规则|
|isOpen|否|Integer| 是否启用|
|list|否|List| 连签奖励|
|--serialDay|否|Integer| 连续签到天数|
|--openGiftPoint|否|Integer| 开启赠送积分|
|--openGiftCoupon|否|Integer| 开启赠送优惠券|
|--openGiftServiceGoods|否|Integer| 开启赠送服务商品|
|--point|否|String| 赠送积分|
|--couponList|否|List| 赠送优惠券|
|----giftItemId|否|String| 赠送项目id|
|----giftItemName|否|String| 赠送项目名称|
|----giftItemQty|否|Integer| 赠送项目数量|
|--serviceGoodsList|否|List| 赠送商品|
|----giftItemId|否|String| 赠送项目id|
|----giftItemName|否|String| 赠送项目名称|
|----giftItemQty|否|Integer| 赠送项目数量|
