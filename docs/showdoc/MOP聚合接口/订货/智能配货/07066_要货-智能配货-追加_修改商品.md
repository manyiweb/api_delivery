# 要货-智能配货-追加/修改商品

**请求URL：** 
- `/b2b/intelligenceDistribution/item/detial/list/edit`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|intelligenceDistributionId|是|Long| 智能补货Id|
|itemDetails|否|List| 商品明细|
|--intelligenceDistributionDetailId|否|Long| 明细行Id|
|--specId|是|String| 规格id|
|--sku|是|String| sku; 用于提示语|
|--unit|否|String| 基本单位|
|--quantity|是|Double| 基本单位商品数量|
|delIds|否|List| 删除行Id|

### 请求参数Json格式
 
```
{
 "intelligenceDistributionId" : 0,
 "itemDetails" : [{
 "intelligenceDistributionDetailId" : 0,
 "specId" : "String",
 "sku" : "String",
 "unit" : "String",
 "quantity" : 0
 }],
 "delIds" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
