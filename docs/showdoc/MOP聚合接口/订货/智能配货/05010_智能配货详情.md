# 智能配货详情

**请求URL：** 
- `/b2b/intelligenceDistribution/info `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long| id|

###请求参数Json格式
 
```
{
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--distributionRemark|否|String| 配货描述|
|--turnPlanFlag|否|Boolean| 是否已转生产计划单|
|--allCompanyFlag|否|Boolean| 所有门店标记，true为所有门店，false为非所有门店|
|--showUpdateFlag|否|Boolean| 修改按钮展示标记|
|--showTurnPlanFlag|否|Boolean| 转生产计划单按钮展示标记|
|--showCancelFlag|否|Boolean| 取消按钮展示标记|
|--showDistributionFlag|否|Boolean| 配货按钮展示标记|
|--showDistributionCompletedFlag|否|Boolean| 配货完成按钮展示标记|
|--showRefreshSchemeStatusFlag|否|Boolean| 刷新方案状态按钮展示标记|
|--associatedDocumentList|否|List| 关联单据集合|
|----documentId|否|Long| 单据id|
|----documentCode|否|String| 单据编码|
|----businessTypeName|否|String| 业务类型|
|----statusName|否|String| 单据状态名|
|----createName|否|String| 创建人|
|----createDate|否|DateTime| 创建时间|
|--id|否|Long| id|
|--schemeNo|否|String| 方案编号|
|--schemeName|否|String| 方案名称|
|--schemeStatus|否|Integer| 方案状态;1:已计划;2:部分配货;3:已配货;4:已取消,5:已关闭|
|--schemeStatusName|否|String| 方案状态名|
|--distributionDate|否|DateTime| 配货日期|
|--createName|否|String| 创建人|
|--createDate|否|DateTime| 创建时间|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
