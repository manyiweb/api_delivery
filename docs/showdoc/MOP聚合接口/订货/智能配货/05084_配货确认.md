# 配货确认

**请求URL：** 
- `/b2b/intelligenceDistribution/confirm`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long| 智能配货id|
|items|是|List| 商品明细|
|--itemId|否|String| 商品id|
|--itemName|否|String| 商品|
|--itemCode|否|String||
|--specId|是|String| 规格id|
|--skuBarcode|否|String| SKU码|
|--companyId|否|String| 门店id|
|--companyName|否|String| 门店|
|--quantity|否|Double| 商品数量|
|--unit|否|String| 单位|
|--itemQuantity|否|Double| 商品数量|
|--unitRate|否|Double| 转换率|
|--itemUnit|否|String| 单位|
|--whsId|否|String| 仓库id|
|--isUniqueCode|是|Integer| 商品是否开启唯一码，取值：0 - 否，1- 是|
|--isBatch|是|Integer| 是否批次商品，取值：0 - 否，1- 是|
|--batchType|否|Integer| 批次管理类型：0-出入库，1-仅出库，2-自动出入库|
|--isFixedBomItem|否|Integer| 是否为固定商品BOM 1-是，0 - 否|
|--component|否|Integer| 按组件发货 1是0否|
|--uniqueCodeList|否|List| 唯一码集合|
|--batchItemList|否|List| 批次码集合|
|----batchCode|否|String||
|----productionDate|否|DateTime||
|----validDays|否|Integer||
|----quantity|是|Double||
|whsId|否|String| 配货仓库|
|merchantId|否|Long| 门店配货单id|
|arrivalDate|否|DateTime| 要货-配货-产生调拨单：到货日期|
|remark|否|String| 要货-配货-产生调拨单：备注|
|reasonId|否|String| 调拨原因id|
|reason|否|String| 调拨原因|
