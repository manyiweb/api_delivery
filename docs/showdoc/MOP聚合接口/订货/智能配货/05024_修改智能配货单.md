# 修改智能配货单

**请求URL：** 
- `/b2b/intelligenceDistribution/update `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long| 智能配货单id;仅修改时需传入|
|schemeName|是|String| 方案名称|
|distributionDate|是|DateTime| 配货日期|
|distributionRemark|否|String| 配货描述|
|allCompanyFlag|否|Boolean| 所有门店标记，true为所有门店，false或不传则为非所有门店|
|companyIdList|否|List| 门店id集合|
|db2borderIdList|是|List| 订货订单id集合|
|dneedorderIdList|否|List| 要货订单id集合|

###请求参数Json格式
 
```
{
 "id" : 0,
 "schemeName" : "String",
 "distributionDate" : "DateTime",
 "distributionRemark" : "String",
 "allCompanyFlag" : true,
 "companyIdList" : null,
 "db2borderIdList" : null,
 "dneedorderIdList" : null
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
