# 保存配货配置

**请求URL：** 
- `/b2b/intelligenceDistribution/set/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|sendWhsType|否|Integer| 发货仓设置，0按商品默认车间1按门店发货仓|
|sourceType|否|Integer| 配货来源单据设置，1订货2要货|
|b2b|否|Integer| 配货来源 - 订货|
|need|否|Integer| 配货来源 - 要货|
|retailMall|否|Integer| 配货来源 - 商城订单|
|b2bRefund|否|Integer| 配货来源 - 订货退货|
|createWhsoutAllot|否|Integer| 是否生成已发货的商品调拨：0-否，1-是|
|createWhsoutAllotType|否|Integer| 0-按门店+生产车间+部门生成调拨单,1-按门店生成调拨单；默认0|

### 请求参数Json格式
 
```
{
 "sendWhsType" : 0,
 "sourceType" : 0,
 "b2b" : 0,
 "need" : 0,
 "retailMall" : 0,
 "b2bRefund" : 0,
 "createWhsoutAllot" : 0,
 "createWhsoutAllotType" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
