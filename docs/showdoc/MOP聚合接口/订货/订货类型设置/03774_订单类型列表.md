# 订单类型列表
 

**请求URL：** 
- `/b2b/orderTypeConfig/b2bOrderTypeList`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|是|String||
|companyId|是|String||
|ifCopyList|否|Integer| 复制类型设置调用的标识 0否 1是|

### 请求参数Json格式
 
```
{
 "tokenId" : "String",
 "companyId" : "String",
 "ifCopyList" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--isOpen|否|Integer||
|--isInherit|否|Integer| 是否继承品牌|
|--configId|否|Long| 设置id 编辑时传|
|--b2bOrderTypeList|否|List| 订单类型列表|
|----codeId|否|String| appcode id|
|----isControlStock|否|Integer| 是否启用库存控制|
|----estimateDeliveryDays|否|Integer| 预计配送天数|
|----orderTypeId|否|Long| 订单类型id|
|----lineId|否|String| 线路id|
|----lineName|否|String| 线路id|
|----orderTypeName|否|String| 业务类型|
|----orderTypeCode|否|String| 功能类型编码|
|----isDef|否|Boolean| 是否默认|
|----code|否|String| 订货类型编码|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "isOpen" : 0,
 "isInherit" : 0,
 "configId" : 0,
 "b2bOrderTypeList" : [{
 "codeId" : "String",
 "isControlStock" : 0,
 "estimateDeliveryDays" : 0,
 "orderTypeId" : 0,
 "lineId" : "String",
 "lineName" : "String",
 "orderTypeName" : "String",
 "orderTypeCode" : "String",
 "isDef" : true,
 "code" : "String"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
