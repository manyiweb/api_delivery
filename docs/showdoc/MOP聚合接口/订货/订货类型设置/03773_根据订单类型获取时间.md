# 根据订单类型获取时间
 

**请求URL：** 
- `/b2b/orderTypeConfig/orderTypePayTime `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderTypeId|否|Long||
|tokenId|否|String||

###请求参数Json格式
 
```
{
 "orderTypeId" : 0,
 "tokenId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--payTimeType|否|Integer| 订货下单时间类型 0全天 1自定义可下单时间|
|--customPayTimeRangeList|否|List| 自定义下单时间列表|
|----customStartTime|否|String| 自定义下单时间——开始|
|----customEndTime|否|String| 自定义下单时间——结束|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "payTimeType" : 0,
 "customPayTimeRangeList" : [{
 "customStartTime" : "String",
 "customEndTime" : "String"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
