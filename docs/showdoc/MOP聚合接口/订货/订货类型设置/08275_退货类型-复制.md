# 退货类型-复制

**请求URL：** 
- `/b2b/refundTypeConfig/b2bRefundTypeCopy `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|sourceCompanyId|否|String| 源数据门店id|
|targetCompanyIds|否|List| 目标门店id|

###请求参数Json格式
 
```
{
 "sourceCompanyId" : "String",
 "targetCompanyIds" : null
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
