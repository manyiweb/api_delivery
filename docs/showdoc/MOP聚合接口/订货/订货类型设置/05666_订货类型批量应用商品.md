# 订货类型批量应用商品

**请求URL：** 
- `/b2b/orderTypeConfig/batchApplyItem `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|pattern|否|Integer| 模式 0：追加 1：覆盖 2：删除|
|items|否|List| 应用的商品列表|
|--id|否|Long||
|--itemCode|否|String| 商品编码|
|--itemName|否|String| 商品名称|
|--itemId|否|String| 商品id 关联 mitem商品表|
|companys|否|List| 应用门店列表|
|--companyId|否|String| 门店id|
|--companyCode|否|String| 门店编码|
|--companyName|否|String| 门店名称|
|--orderTypeList|否|List| 订货类型列表|
|----orderTypeId|否|String| 订货类型id|
|----orderTypeCode|否|String| 订货类型编码|
|----orderTypeName|否|String| 订货类型名称|

###请求参数Json格式
 
```
{
 "pattern" : 0,
 "items" : [{
 "id" : 0,
 "itemCode" : "String",
 "itemName" : "String",
 "itemId" : "String"
 }],
 "companys" : [{
 "companyId" : "String",
 "companyCode" : "String",
 "companyName" : "String",
 "orderTypeList" : [{
 "orderTypeId" : "String",
 "orderTypeCode" : "String",
 "orderTypeName" : "String"
 }]
 }]
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
