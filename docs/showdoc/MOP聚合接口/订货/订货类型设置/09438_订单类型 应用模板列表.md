# 订单类型 应用模板列表

**请求URL：** 
- `/b2b/orderTypeConfig/page/b2bOrderTypeTemplateList`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderTypeId|是|Long||
|tokenId|是|String||
|sword|否|String| 关键词|
|pageIndex|否|Integer||
|pageSize|否|Integer||
|orderField|否|String||
|orderSort|否|String||

### 请求参数Json格式
 
```
{
 "orderTypeId" : 0,
 "tokenId" : "String",
 "sword" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--templateId|否|String| 模板ID|
|--templateName|否|String| 模板名称|
|--templateCode|否|String| 模板编码|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "templateId" : "String",
 "templateName" : "String",
 "templateCode" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
