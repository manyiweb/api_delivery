# 订单类型明细
 

**请求URL：** 
- `/b2b/orderTypeConfig/b2BOrderTypeInfo`

**请求方式：** 
- `POST`
- `RequestBody`


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderTypeId|是|Long||
|tokenId|是|String||

### 请求参数Json格式
 
```
{
 "orderTypeId":0,
 "tokenId":"String"
}
```

|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
