# 汇总展示订货订单的所有商品-按订单级别聚合-列表

**请求URL：** 
- `/b2b/order/batch/receiving/getItems/MYSQL`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|keyword|否|String| 模糊查询商品|
|brandCodes|否|List|品牌 |
|seriesCodes|否|List|系列 |
|itemTypeCode|否|String| 商品分类id|
|orgins|否|List|产地 |
|orderIds|是|List| 订货订单Ids|
|pageSize|否|Integer||
|pageNo|否|Integer||

### 请求参数Json格式
 
```
{
 "keyword" : "String",
 "brandCodes" : null,
 "seriesCodes" : null,
 "itemTypeCode" : "String",
 "orgins" : null,
 "orderIds" : null,
 "id" : "String",
 "pageSize" : 0,
 "pageNo" : 0
}
```
