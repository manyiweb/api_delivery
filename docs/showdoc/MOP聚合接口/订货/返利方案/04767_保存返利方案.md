# 保存返利方案

**请求URL：** 
- `/config/rebatePlan/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 主键 编辑的时候带上|
|planName|是|String| 方案名称|
|beginDate|是|DateTime| 有效期开始|
|endDate|是|DateTime| 有效期结束|
|activeState|是|Integer| 活跃状态 0：停用 1：启用|
|description|否|String| 方案说明|
|ruleList|是|List| 应用的规则|
|--id|否|Long| 主键|
|--ruleId|否|Long||
|--ruleCode|否|String| 规则编号|
|--ruleName|否|String| 规则名称|
|--activeState|否|Integer| 活跃状态 0|
|--createId|否|String| 创建人id|
|--createName|否|String| 创建人名称|
|--createDate|否|DateTime| 创建日期|
|--rewardType|否|Integer| 到账方式 0：自动审核到账 1：人工审核到账|
|--addDate|否|DateTime| 添加时间|
|planType|否|String| 方案类型|
|planTypeName|否|String| 方案类型|
|applyCompType|是|Integer| 应用门店类型 1：所有门店 2：指定门店 3:排除门店 4:指定标签 5:排除标签|
|compList|否|List| 应用的门店|
|--companyId|否|String| 门店id|
|--companyCode|否|String| 门店编码|
|--companyName|否|String| 门店名称|
|--addDate|否|DateTime| 添加时间|
|labelList|否|List| 【应用/排除】的商户标签|
|--labelId|否|Long| 商户标签id|
|--labelName|否|String| 商户标签名称|
|--labelCode|否|String| 商户标签编码|
|intelligenceLabelList|否|List| 【应用/排除】的智能商户标签|
|--intelligenceLabelId|否|Long| 智能商户标签id|
|--intelligenceLabelName|否|String| 智能商户标签名称|
|--intelligenceLabelCode|否|String| 智能商户标签编码|
