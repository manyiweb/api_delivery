# 获取单个详情

**请求URL：** 
- `/config/rebatePlan/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long| id|
|planStatus|否|Integer| 方案状态 2为关闭， 默认为2,|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "planStatus" : 0
}
```

|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long| 主键 编辑的时候带上|

|--planStatus|否|Integer| 方案状态|

|----createName|否|String||
