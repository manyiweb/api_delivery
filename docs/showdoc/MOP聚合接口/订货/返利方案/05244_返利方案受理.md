# 返利方案受理

**请求URL：** 
- `/config/rebatePlan/accept `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 返利id|
|status|否|Integer| 受理状态（6 同意受理 5已拒绝）|
|remark|否|String| 备注|

###请求参数Json格式
 
```
{
 "id" : 0,
 "status" : 0,
 "remark" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long| 主键 编辑的时候带上|
|--planName|否|String| 方案名称|
|--planCode|否|String| 方案编码|
|--beginDate|否|DateTime| 有效期开始|
|--endDate|否|DateTime| 有效期结束|
|--activeState|否|Integer| 活跃状态 0：停用 1：启用|
|--description|否|String| 方案说明|
|--createDate|否|DateTime| 创建时间|
|--createName|否|String| 创建人|
|--ruleList|否|List| 应用的规则|
|----id|否|Long| 主键|
|----ruleId|否|Long||
|----ruleCode|否|String| 规则编号|
|----ruleName|否|String| 规则名称|
|----activeState|否|Integer| 活跃状态 0|
|----createId|否|String| 创建人id|
|----createName|否|String| 创建人名称|
|----createDate|否|DateTime| 创建日期|
|--applyCompType|否|Integer| 应用门店类型 1：所有门店 2：指定门店|
|--compList|否|List| 应用的规则|
|----companyId|否|String| 门店id|
|----companyCode|否|String| 门店编码|
|----companyName|否|String| 门店名称|
|--planStatus|否|Integer| 方案状态|
|--acceptVo|否|Object| 审核状态|
|----id|否|Long| id|
|----level|否|Integer| 审核总级数|
|----currentLevel|否|Integer| 当前审核级|

|----lastAcceptDate|否|DateTime| 最后受理时间|
|----lastAccept|否|Integer| 是否为最后一级审核 1是0否|
|--acceptRecords|否|List| 审核记录|
|----id|否|Long| id|
|----acceptId|否|Long| 单据受理标识，与order_accept表关联|
|----orderId|否|String| 单据标识|
|----level|否|Integer| 当前审核级|
|----statusCode|否|String| 受理状态|
|----statusName|否|String| 受理状态描述|
|----remark|否|String| 受理备注|
|----createId|否|String| 创建人标识|
|----createName|否|String| 创建人名称|
|----createDate|否|DateTime| 创建时间|
|----modifyId|否|String| 修改人标识|
|----modifyName|否|String| 修改人|
|----modifyDate|否|DateTime| 修改时间|
|----dbKey|否|Integer| 分库标识|
|----groupId|否|String| 品牌商id|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
