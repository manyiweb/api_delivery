# 订货退货_收货完成
 

**请求URL：** 
- `/b2b/refund/receiving/finish`

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|是|String| 身份标识|
|orderId|是|String| 订货退货单id|

###请求参数Json格式
 
```
{
 "orderId": "0a2984b286224a1ebefea00f19be05a1",
 "tokenId": "23e71b3468ca49789c37f3e4582ad94c"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|--resultInt|否|Integer| 返回的状态 0成功，非0失败|
|--resultString|否|String| 返回的信息|
|--resultError|否|String| 返回的错误信息|
|--dataLine|否|json| 返回数据|



###返回参数Json格式
 
```
{
 "ErrorCode": "500",
 "ResultString": "当前状态不支持收货完成操作",
 "ResultInt": 500
}
```
