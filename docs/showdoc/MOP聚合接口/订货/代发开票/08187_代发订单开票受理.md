# 代发订单开票受理

**请求URL：** 
- `/hr/invoice/supplying/accept`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|b2bInvoiceId|是|Long|发票id |
|accept|否|Boolean|受理是否通过 |
|remark|否|String|备注 |
|status|否|String| 受理状态 YA:受理 YR:拒绝受理|

### 请求参数Json格式
 
```
{
 "b2bInvoiceId" : 0,
 "accept" : true,
 "remark" : "String",
 "status" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
