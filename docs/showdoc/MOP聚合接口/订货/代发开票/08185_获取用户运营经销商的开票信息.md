# 获取用户运营经销商的开票信息

**请求URL：** 
- `/hr/distributor/getInvoiceList`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||
|sword|否|String||

### 请求参数Json格式
 
```
{
 "id" : 0,
 "sword" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--invoiceList|否|List| 经销商发票|
|----id|否|Long||
|----distributorId|否|Long||
|----invType|是|Integer||
|----invTitle|是|String||
|----invCode|是|String||
|----invRegBname|是|String||
|----invRegBaccount|是|String||
|----invRegAddr|是|String||
|----invRegPhone|是|String||
|----invRegEmail|否|String||
|----invGotoAddr|否|String||
|----invRecName|否|String||
|----invRecMobphone|否|String||
|----isDel|否|Integer||
|----isDefault|否|Integer||
|----createId|否|String||
|----createName|否|String||
|----modifyId|否|String||
|----modifyName|否|String||
|----createDate|否|DateTime||
|----modifyDate|否|DateTime||
|----dbKey|否|Integer||
|----groupId|否|String||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
