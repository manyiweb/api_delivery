# 自定义账户金额使用
 

**请求URL：** 
- `/b2b/shopping/cart/pay/later/custom/account/update`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|是|String| 订单ID|
|combinationPayment|否|Boolean| 是否使用普通账户支付账户|
|useType|否|Integer| 使用类型0 代表抵扣订单金额 1代表抵扣运费|
|useAmount|是|Double| 使用金额，金额为0则取消选中|
|accountId|是|Long| 自定义账户ID|
|combinationPayment|否|Boolean| 是否使用普通账户支付账户|
|useType|否|Integer| 使用类型0 代表抵扣订单金额 1代表抵扣运费|
|shopCartKey|否|String| 如果是立即购买输入对应的立即购买cartKey|

### 请求参数Json格式
 
```
{
 "orderId" : "String",
 "b2BOrderPayLaterShopCartId" : 0,
 "combinationPayment" : true,
 "useType" : 0,
 "useAmount" : 0,
 "accountId" : 0,
 "combinationPayment" : true,
 "useType" : 0,
 "shopCartKey" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--b2BOrderPayLaterShopCartId|否|Long| 稍后支付购物车标识|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "b2BOrderPayLaterShopCartId" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
