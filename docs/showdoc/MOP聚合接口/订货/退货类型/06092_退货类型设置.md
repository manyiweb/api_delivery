# 编辑对应订单类型是否启用库存控制 并且保存对应订单类型的应用商品
 

**请求URL：** 
- `/b2b/refundTypeConfig/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|refundTypeId|是|Long||
|codeId|是|String||
|companyId|是|String||
|applyItemType|是|Integer| 应用商品 0所有 1指定商品|
|itemIds|否|List| 应用商品列表 当claimItemType为2时传|
|deleteItemIds|否|List| 删除应用商品列表|
|openAutoReceiptAndRefund|否|Boolean| 自动完成确认收货、差异退款流程|
|receiptWhsId|否|String| 自动收货仓库id|
|receiptWhsName|否|String| 自动收货仓库名称|
|refundWayList|否|List| 退款方式|
|--refundWayName|否|String| 退款方式名称|
|--refundWayCode|否|String| 退款方式编码|
|--isApply|否|Boolean| 是否应用 true:是 false:否|
|--customAccountApplyType|否|Integer| 0应用所有 1指定自定义账户 (自定义账户选项才传)|
|--customAccountDetail|否|List| 自定义账户明细|
|----accountId|否|Long| 账户id|
|----accountCode|否|String| 账户编码|
|----accountName|否|String| 账户名称|
|----headImage|否|String| 账户头像|
|openRefundWay|否|Boolean| 是否开启订货退货类型退款方式|

### 请求参数Json格式
 
```
{
 "refundTypeId" : 0,
 "codeId" : "String",
 "companyId" : "String",
 "applyItemType" : 0,
 "itemIds" : null,
 "deleteItemIds" : null,
 "openAutoReceiptAndRefund" : true,
 "receiptWhsId" : "String",
 "receiptWhsName" : "String",
 "refundWayList" : [{
 "refundWayName" : "String",
 "refundWayCode" : "String",
 "isApply" : true,
 "customAccountApplyType" : 0,
 "customAccountDetail" : [{
 "accountId" : 0,
 "accountCode" : "String",
 "accountName" : "String",
 "headImage" : "String"
 }]
 }],
 "openRefundWay" : true
}
```

|exceptionStackInfo|否|String||
|traceId|否|String||
