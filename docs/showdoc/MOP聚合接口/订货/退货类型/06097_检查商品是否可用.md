# 检查商品是否可用
 

**请求URL：** 
- `/b2b/refundTypeConfig/checkItem `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|codeId|否|String| 类型codeId|
|itemIds|否|List| 商品id|
|companyId|否|String| 商户id|

###请求参数Json格式
 
```
{
 "codeId" : "String",
 "itemIds" : null,
 "companyId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--isOk|否|Boolean||
|--errorMsg|否|List| 错误信息列表|
|----itemId|否|String||
|----itemName|否|String||
|----itemCode|否|String||
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "isOk" : true,
 "errorMsg" : [{
 "itemId" : "String",
 "itemName" : "String",
 "itemCode" : "String"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
