# 退货类型列表
 

**请求URL：** 
- `/b2b/refundTypeConfig/typeList `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|否|String||
|companyId|否|String||

###请求参数Json格式
 
```
{
 "tokenId" : "String",
 "companyId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--isOpen|否|Integer||
|--isInherit|否|Integer| 是否继承品牌|
|--configId|否|Long| 设置id 编辑时传|
|--refundTypeListDtos|否|List| 订单类型列表|
|----codeId|否|String| appcode id|
|----refundTypeId|否|Long| 订单类型id|
|----refundTypeName|否|String| 业务类型|
|----code|否|String| 功能类型编码|
|----isDef|否|Boolean| 是否默认|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "isOpen" : 0,
 "isInherit" : 0,
 "configId" : 0,
 "refundTypeListDtos" : [{
 "codeId" : "String",
 "refundTypeId" : 0,
 "refundTypeName" : "String",
 "code" : "String",
 "isDef" : true
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
