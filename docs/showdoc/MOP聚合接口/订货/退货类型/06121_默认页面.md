# 列表-订货退货单单据类型

**请求URL：** 
- `/b2b/refund/type/refundTypeList `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 门店id|

###请求参数Json格式
 
```
{
 "companyId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--list|否|List||
|----code|否|String| 单据编码|
|----content|否|String| 单据名称|
|----defaultValue|否|Boolean| 是否默认值|
|----enableAcceptanceProcess|否|Boolean| 是否启用受理流程|
|----codeId|否|String| 订货退货类型codeId|
|----refundTypeId|否|Long| 订货退货类型id|
|----applyItemType|否|Integer| 应用商品 0所有 1指定商品|
|----isOpenType|否|Integer| 是否开启订货类型|
|--isOpen|否|Integer||
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "list" : [{
 "code" : "String",
 "content" : "String",
 "defaultValue" : true,
 "enableAcceptanceProcess" : true,
 "codeId" : "String",
 "refundTypeId" : 0,
 "applyItemType" : 0,
 "isOpenType" : 0
 }],
 "isOpen" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
