# 退货方式列表

**请求URL：** 
- `/b2b/refundTypeConfig/refundWay/list`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||
|sword|否|String||

### 请求参数Json格式
 
```
{
 "id" : 0,
 "sword" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--refundWayName|否|String| 退款方式名称|
|--refundWayCode|否|String| 退款方式编码|
|--isApply|否|Boolean| 是否应用 true:是 false:否|
|--customAccountApplyType|否|Integer| 0应用所有 1指定自定义账户 (自定义账户选项才传)|
|--customAccountDetail|否|List| 自定义账户明细|
|----accountId|否|Long| 账户id|
|----accountCode|否|String| 账户编码|
|----accountName|否|String| 账户名称|
|----headImage|否|String| 账户头像|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "refundWayName" : "String",
 "refundWayCode" : "String",
 "isApply" : true,
 "customAccountApplyType" : 0,
 "customAccountDetail" : [{
 "accountId" : 0,
 "accountCode" : "String",
 "accountName" : "String",
 "headImage" : "String"
 }]
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
