# 根据门店id查询可充值列表
 

**请求URL：** 
- `/b2b/account/recharge/rechargeable/list`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|accountId|否|Long|账户id |
|id|是|Object||

### 请求参数Json格式
 
```
{
 "accountId" : 0,
 "id" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--fixedRechargeInfoList|否|List|固定的充值列表 |
|----id|否|Long|充值id |
|----accountType|否|String|账户类型 |
|----giveType|否|String|赠送类型 |
|----accountName|否|String|账户名称 |
|----rechargeAmount|否|Double|充值金额 |
|----balance|否|Double|账户余额 |
|----gives|否|List|赠品列表 |
|------giveId|否|String|赠品id |
|------giveName|否|String|赠品名称 |
|------giveCode|否|String|赠品编码 |
|------giveAmount|否|Double|赠品数量 |
|----giveCount|否|Integer|总赠品数量 |
|----remark|否|String|备注 |
|----giveAmount|否|Boolean|是否赠送金额 |
|----amountGiveDto|否|Object| 金额赠送类型|
|------id|否|Long| 主键|
|------accountRechargeId|否|Long| 账户id|
|------giveAmountType|否|Integer| 赠送类型 0固定金额 1比例|
|------giveAmount|否|Double| 赠送金额或比例|
|------accountId|否|Long| 账户id|
|------accountName|否|String| 账户名称|
|------dateType|否|Integer| 日期类型 0 指定天数 1 指定有效期 2指定截止日期|
|------validDays|否|Integer| 有效天数|
|------startActiveDate|否|String| 有效期开始日期|
|------activeDate|否|String| 有效期结束日期|
|--customRechargeInfo|否|Object|自定义充值信息 |
|----b2bAccountRechargeAmountRangeEnable|否|String|自定义充值范围 - 是否启用 |
|----b2bAccountRechargeAmountRangeStart|否|String|自定义充值范围 - 起始 |
|----b2bAccountRechargeAmountRangeEnd|否|String|自定义充值范围 - 结束 |
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
