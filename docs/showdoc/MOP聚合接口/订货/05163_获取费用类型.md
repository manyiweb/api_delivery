# 获取费用类型

**请求URL：** 
- `/config/changeTypeFee`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|sword|否|String| 模糊搜索名称|

### 请求参数Json格式
 
```
{
 "sword" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--typeName|否|String| 费用类型名称|
|--type|否|String| 费用类型编码|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : [{
 "typeName" : "String",
 "type" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
