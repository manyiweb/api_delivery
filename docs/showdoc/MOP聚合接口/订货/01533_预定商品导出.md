# Excel 导出预定商品 2019年8月23日21:01:23
 

**请求URL：** 
- `/file/export/b2b/reserveProduct `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|pageIndex|否|Integer| 页码值|
|pageSize|否|Integer| 页大小|
|keyWord|否|String| 搜索关键字|
|onShelve|否|Integer| 是否上架|

###请求参数Json格式
 
```
{
 "pageIndex" : 0,
 "pageSize" : 0,
 "keyWord" : "String",
 "onShelve" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|


###返回参数Json格式
 
```
{
 "data" : "下载url",
 "msg" : "String",
 "code" : "String"
}
```
