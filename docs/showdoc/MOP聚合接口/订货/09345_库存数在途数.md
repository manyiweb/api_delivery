# 

**请求URL：** 
- `/b2b/sales/order/getTransitQtyAndInvQuantity`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|whsId|是|String| 仓库id|
|companyId|是|String| 仓库id|
|specIds|是|List| 规格id列表|

### 请求参数Json格式
 
```
{
 "whsId" : "String",
 "companyId" : "String",
 "specIds" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--stockItemInvQty|否|Map||
|--transitDtoMap|否|Map||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "stockItemInvQty" : null,
 "transitDtoMap" : null
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
