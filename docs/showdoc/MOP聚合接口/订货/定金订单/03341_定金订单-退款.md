# 定金订单 -退款

**请求URL：** 
- `/b2b/v1/depositOrder/action/refund `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|否|String||
|id|否|Long||

###请求参数Json格式
 
```
{
 "tokenId" : "String",
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--orderId|否|String| 订单id|
|--orderNo|否|String| 订单编号|
|--orderTypeName|否|String| 单据类型|
|--orderStatusName|否|String| 单据状态|
|--payStatusName|否|String| 付款状态|
|--companyName|否|String| 商户|
|--deposit|否|Double| 定金|
|--payWayName|否|String| 支付方式|
|--createName|否|String| 创建时间|
|--createDate|否|DateTime| 创建人|
|--remark|否|String| 备注|
|--balanceBeginTime|否|DateTime| 付尾款开始时间|
|--balanceEndTime|否|DateTime| 付尾款结束时间|
|--refundable|否|Boolean| 可退款|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : {
 "orderId" : "String",
 "orderNo" : "String",
 "orderTypeName" : "String",
 "orderStatusName" : "String",
 "payStatusName" : "String",
 "companyName" : "String",
 "deposit" : 0,
 "payWayName" : "String",
 "createName" : "String",
 "createDate" : "DateTime",
 "remark" : "String",
 "balanceBeginTime" : "DateTime",
 "balanceEndTime" : "DateTime",
 "refundable" : true
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
