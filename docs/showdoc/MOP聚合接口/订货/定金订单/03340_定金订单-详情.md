# 定金订单 -详情

**请求URL：** 
- `/b2b/v1/depositOrder/action/detail `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|否|String||
|id|否|String||

###请求参数Json格式
 
```
{
 "tokenId" : "String",
 "id" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--payWayList|否|List| 支付方式|
|----payWayName|否|String| 支付方式|
|----payAmount|否|Double| 支付金额|
|----payDate|否|DateTime| 支付时间|
|--associateOrders|否|List| 关联单据|
|----orderId|否|String| 订货订单id|
|----orderNo|否|String| 订货订单编号|
|----orderStatusName|否|String| 单据状态|
|----orderTypeName|否|String| 单据名称|
|----qty|否|Integer| 数量|
|----orderRealAmount|否|Double| 实付金额|
|----createName|否|String| 创建时间|
|----createDate|否|DateTime| 创建人|
|----remark|否|String| 备注|
|--goodsList|否|List| 关联商品|
|----imgUrl|否|String| 商品图片|
|----itemName|否|String| 商品名称|
|----reservePrice|否|Double| 预定价格|
|----itemUnit|否|String| 下单单位|
|----itemQuantity|否|Integer| 下单数量|
|----quantity|否|Integer| 基本数量|
|----unit|否|String| 基本单位|
|----specId|否|String| 规格id|
|--orderInfo|否|Object| 订单信息|
|----orderId|否|String| 订单id|
|----orderNo|否|String| 订单编号|
|----orderTypeName|否|String| 单据类型|
|----orderStatusName|否|String| 单据状态|
|----payStatusName|否|String| 付款状态|
|----companyName|否|String| 商户|
|----deposit|否|Double| 定金|
|----payWayName|否|String| 支付方式|
|----createName|否|String| 创建时间|
|----createDate|否|DateTime| 创建人|
|----remark|否|String| 备注|
|----balanceBeginTime|否|DateTime| 付尾款开始时间|
|----balanceEndTime|否|DateTime| 付尾款结束时间|
|----refundable|否|Boolean| 可退款|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
