# 订货订单类型列表
 

**请求URL：** 
- `/b2b/shopping/cart/orderType/action/list/v2 `

**请求方式：**
- POST
- FormData


###请求参数<业务参数>
 
无参数


###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--orderPayControl|否|Boolean| 启用订货订单下单订购量控制(订货设置)|
|--isStock|否|Boolean| 启用库存控制(订货设置)|
|--orderTypeControl|否|Boolean| 启用业务类型订货|
|--b2bOrderTypeListDto|否|List||
|----codeId|否|String| appcode id|
|----isControlStock|否|Integer| 是否启用库存控制|
|----orderTypeId|否|Long| 订单类型id|
|----orderTypeName|否|String| 业务类型|
|----orderTypeCode|否|String| 功能类型编码|
|----isDef|否|Boolean| 是否默认|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "orderPayControl" : true,
 "isStock" : true,
 "orderTypeControl" : true,
 "b2bOrderTypeListDto" : [{
 "codeId" : "String",
 "isControlStock" : 0,
 "orderTypeId" : 0,
 "orderTypeName" : "String",
 "orderTypeCode" : "String",
 "isDef" : true
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
