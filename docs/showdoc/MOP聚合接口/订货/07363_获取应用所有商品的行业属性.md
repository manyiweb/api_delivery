# 获取应用所有商品的行业属性

**请求URL：** 
- `/config/item/industrAttr/action/applyAllList`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|isB2bRefund|否|Boolean| 是否为订货退货|

### 请求参数Json格式
 
```
{
 "isB2bRefund" : true
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--industryAttrId|否|Long| 行业属性id|
|--attrId|否|String| 唯一id|
|--code|否|Integer| 编码|
|--alias|否|String| 别名|
|--value|否|String| 值|
|--isRequired|否|Integer| 是否必填 1 - 必填, 0 - 不必填|
|--valueType|否|Integer| 0 任何值 1 序列|
|--content|否|String| 内容值,多个值时|
|--contentId|否|String| 自定义关联id|
|--isApplyAll|否|Integer| 是否应用所有商品|
|--customObjectFullList|否|List| 自定义对象|
|----itemCode|否|String| 自定义对象编码|
|----itemName|否|String| 自定义对象名称|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "industryAttrId" : 0,
 "attrId" : "String",
 "code" : 0,
 "alias" : "String",
 "value" : "String",
 "isRequired" : 0,
 "valueType" : 0,
 "content" : "String",
 "contentId" : "String",
 "isApplyAll" : 0,
 "customObjectFullList" : [{
 "itemCode" : "String",
 "itemName" : "String"
 }]
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
