# 智能配货收货 查询批次信息

**请求URL：** 
- `/b2b/order/batch/receiving/getBatchRecord`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|specId|是|String| 商品规格Id|
|id|是|Long| 智能配货id|

### 请求参数Json格式
 
```
{
 "specId" : "String",
 "id" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--id|否|Long| id|
|--docItemId|否|String| 单据明细行ID|
|--specId|否|String| 商品规格id|
|--batchCode|否|String| 批次号|
|--productionDate|否|String| 生产日期|
|--validDays|否|Integer| 保质期|
|--quantity|否|Double| 数量|
|--barcodeList|否|List| 商品唯一码数据|
|--barcodes|否|List||
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : [{
 "id" : 0,
 "docItemId" : "String",
 "specId" : "String",
 "batchCode" : "String",
 "productionDate" : "String",
 "validDays" : 0,
 "quantity" : 0,
 "barcodeList" : null,
 "barcodes" : null
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
