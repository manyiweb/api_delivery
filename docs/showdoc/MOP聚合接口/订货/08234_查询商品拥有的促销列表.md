# 查询商品拥有的促销列表

**请求URL：** 
- `/b2b/mall/shopCart/findItemPromotionPlan`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|itemId|是|String| 商品标识|

### 请求参数Json格式
 
```
{
 "itemId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--itemId|否|String| 规格标识|
|--specId|否|String| 规格标识|
|--plans|否|List| 促销列表|
|----projectId|否|String| 促销方案ID|
|----planId|否|String| 促销标识|
|----planType|否|String| 促销类型|
|----planTypeName|否|String| 促销类型名称|
|----planName|否|String| 促销名称|
|----planTitle|否|String| 促销标题|
|----planNickname|否|String| 规则别名|
|----spType|否|String| 促销规则类型|
|----spTypeName|否|String| 促销规则类型描述|
|----itemKey|否|String| 购物车KEY，仅组合促销时返回|
|----closestStartTime|否|Long| 促销有效时间段 - 开始|
|----closestEndTime|否|Long| 促销有效时间段 - 结束|
|----hasGifts|否|Integer| 是否有赠品: 0-无；1-一个促销品清单；2-多个促销品清单|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "itemId" : "String",
 "specId" : "String",
 "plans" : [{
 "projectId" : "String",
 "planId" : "String",
 "planType" : "String",
 "planTypeName" : "String",
 "planName" : "String",
 "planTitle" : "String",
 "planNickname" : "String",
 "spType" : "String",
 "spTypeName" : "String",
 "itemKey" : "String",
 "closestStartTime" : 0,
 "closestEndTime" : 0,
 "hasGifts" : 0
 }]
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
