# 获取启用按门店指定订货仓库

**请求URL：** 
- `/b2b/orderWhs/getConfig`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String|商户ID |

### 请求参数Json格式
 
```
{
 "companyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long|主键标识 |
|--enableSetWhs|否|Boolean|启用按门店指定订货仓库 |
|--companyId|否|String|商户ID |
|--sysChangeDate|否|DateTime|最后修改时间 |
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "enableSetWhs" : true,
 "companyId" : "String",
 "sysChangeDate" : "DateTime"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
