# 保存发货仓列表

**请求URL：** 
- `/b2b/orderWhs/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|whsList|否|List| 发货仓列表|
|--id|否|Long|主键标识 |
|--companyId|否|String|仓库设置id |
|--whsName|否|String|仓库名称 |
|--whsCode|否|String|仓库编码 |
|--whsId|否|String|仓库id |
|--isDefault|否|Boolean|是否默认 |
|--sysChangeDate|否|DateTime|最后修改时间 |
|--orderTypes|否|List| 类型设置|
|----id|否|Long|主键标识 |
|----orderTypeId|否|String|要货业务类型id |
|----orderTypeName|否|String|要货业务类型id |

### 请求参数Json格式
 
```
{
 "whsList" : [{
 "id" : 0,
 "companyId" : "String",
 "whsName" : "String",
 "whsCode" : "String",
 "whsId" : "String",
 "isDefault" : true,
 "sysChangeDate" : "DateTime",
 "orderTypes" : [{
 "id" : 0,
 "orderTypeId" : "String",
 "orderTypeName" : "String"
 }]
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
