# 订货 - 商户注册 - 维护
 

**请求URL：** 
- `/hr/company/register `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|groupId|否|String| 商户标识|
|msgCode|否|String| 短信编码|
|applyName|否|String| 申请人|
|applyPhone|否|String| 申请人手机号|
|companys|否|List| 门店列表|
|--applyBrand|否|String| 申请品牌|
|--companyName|否|String| 门店名称|
|--province|否|String| 省|
|--city|否|String| 市|
|--region|否|String| 区|
|--address|否|String| 详细地址|
|--companyImgUrl|否|String| 营业执照|
|--authCertificate|否|String| 铺头照片|
|--invitationCode|否|String| 邀请码|
|--foodBusinessLicense|否|String| 食品经营许可证|
|--corporateIdCardFront|否|String| 法人身份证正面|
|--corporateIdCardBack|否|String| 法人身份证反面|
|--distributorId|否|Long| 所属经销商ID|
|--distributorCode|否|String| 所属经销商编码|
|--distributorName|否|String| 所属经销商名称|
|paymentListAddSlips|否|List| 门店列表|
|--id|否|Long| id|
|--companyId|否|String| 门店id|
|--type|否|Integer| 类型|
|--phone|否|String| 电话|
|--name|否|String| 姓名|
|--relation|否|Integer| 关系 先默认为1|
|--attachments|否|List| 附件列表|
|--attachment1|否|String| 附件1|
|--attachment2|否|String| 附件2|
|--attachment3|否|String| 附件3|

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|
