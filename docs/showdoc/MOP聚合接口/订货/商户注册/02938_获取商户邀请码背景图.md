# 获取商户邀请码背景图

**请求URL：** 
- `/b2b/invitationCode/background `

**请求方式：**
- POST


###请求参数<业务参数>
 
{
 "tokenId":"93b0d880777247d7a1b154f9c5670e00"
}


###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--imgUrl|否|String|图片地址|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
	"code": "200",
	"data": {
		"imgUrl": "String"
	},
	"exceptionStackInfo": "",
	"msg": ""
}
```
