# 获取退货商品行业属性
 

**请求URL：** 
- `/b2b/refund/getRefundItemAttr`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|String||

### 请求参数Json格式
 
```
{
 "id" : "String"
}
```


### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|map|key对应itemId value 对应属性列表|
|--industryAttrId|否|Long| 行业属性id|
|--attrId|否|String| 唯一id|
|--code|否|Integer| 编码|
|--alias|否|String| 别名|
|--value|否|String| 值|
|--isRequired|否|Integer| 是否必填 1 - 必填, 0 - 不必填|
|--valueType|否|Integer| 0 任何值 1 序列|
|--content|否|String| 内容值,多个值时|
|--customObjectFullList|否|List||
|----itemCode|否|String| 自定义对象编码|
|----itemName|否|String| 自定义对象名称|
|--isApplyAll|否|Integer| 是否应用所有商品|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" :{
 "itemId": [{
 "industryAttrId" : 0,
 "attrId" : "String",
 "code" : 0,
 "alias" : "String",
 "value" : "String",
 "isRequired" : 0,
 "valueType" : 0,
 "content" : "String",
 "customObjectFullList" : [{
 "itemCode" : "String",
 "itemName" : "String"
 }],
 "isApplyAll" : 0
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
