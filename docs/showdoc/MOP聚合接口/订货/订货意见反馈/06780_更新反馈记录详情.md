# 更新反馈记录详情
 

**请求URL：** 
- `/config/feedbackRecord/updateRecord`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long| 反馈id|
|status|是|Integer| 状态|
|result|否|String| 处理结果|
|imgUrl|否|List| 图片|
|recordDetailsDtos|是|List||
|--itemCode|是|String|商品编码 |
|--skuCode|是|String|SKU码 |
|--itemName|是|String|商品名称 |
|--qgpDay|否|Integer|保质期天数 |
|--feedbackNum|是|Integer|反馈数量 |
|--unint|是|String| 单位|
|--generateDate|否|DateTime|生产日期 |
|--supName|否|String|供应商 |
|--feedbackInfo|否|String|反馈内容 |
|--processing|否|String|处理过程 |
|--remark|否|String|备注 |

### 请求参数Json格式
 
```
{
 "id" : 0,
 "status" : 0,
 "result" : "String",
 "imgUrl" : null,
 "recordDetailsDtos" : [{
 "itemCode" : "String",
 "skuCode" : "String",
 "itemName" : "String",
 "qgpDay" : 0,
 "feedbackNum" : 0,
 "unint" : "String",
 "generateDate" : "DateTime",
 "supName" : "String",
 "feedbackInfo" : "String",
 "processing" : "String",
 "remark" : "String"
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
