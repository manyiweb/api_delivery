# 门店添加反馈
 

**请求URL：** 
- `/config/feedbacks/add `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 主键|
|typeCode|否|String|反馈编码 |
|itemName|否|String|反馈商品 |
|feedbackInfo|否|String|反馈内容 |
|feedbackName|否|String|反馈人姓名 |
|feedbackPhone|否|String|反馈人手机号 |
|imgUrl|否|List| 图片|
|companyId|否|String| 门店id|
|companyName|否|String| 门店名称|

###请求参数Json格式
 
```
{
 "id" : 0,
 "typeCode" : "String",
 "itemName" : "String",
 "feedbackInfo" : "String",
 "feedbackName" : "String",
 "feedbackPhone" : "String",
 "imgUrl" : null,
 "companyId" : "String",
 "companyName" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
