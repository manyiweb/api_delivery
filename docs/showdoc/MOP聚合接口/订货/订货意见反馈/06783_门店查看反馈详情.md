# Web品牌查看反馈详情
 

**请求URL：** 
- `/config/feedbacks/details`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||

### 请求参数Json格式
 
```
{
 "id" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long||
|--feedbackCode|否|String| 反馈编码|
|--feedbackType|否|String| 反馈类型|
|--applyType|否|String| 申请类型|
|--applyTypeName|否|String| 申请类型字段中文|
|--itemName|否|String| 反馈商品|
|--feedbackInfo|否|String| 反馈内容|
|--feedbackName|否|String| 反馈人姓名|
|--feedbackPhone|否|String| 反馈人手机号|
|--companyId|否|String| 店铺id|
|--companyName|否|String| 店铺名称|
|--result|否|String| 处理结果|
|--status|否|Integer| 状态，1-已提交，2-处理中，3-已处理|
|--statusName|否|String| 状态中文|
|--createDate|否|DateTime| 创建时间|
|--createName|否|String| 创建人姓名|
|--createId|否|String| 创建人id|
|--ImgUrl|否|List| 图片|
|--handleTips|否|List| 处理提示集合|
|----handleTip|否|String| 处理提示|
|----handleTime|否|DateTime| 提示时间|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
