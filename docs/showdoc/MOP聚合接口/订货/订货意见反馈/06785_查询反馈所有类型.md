# 查询反馈所有类型
 

**请求URL：** 
- `/config/feedbacktype/list`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
无参数


### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--pageIndex|否|Integer|分页页数|
|--pageSize|否|Integer|分页大小|
|--pageCount|否|Integer||
|--totalCount|否|Long||
|--first|否|Boolean||
|--last|否|Boolean||
|--content|否|List||
|----id|否|Long|反馈类型id|
|----typeCode|是|String| 类型编码|
|----feedbackType|是|String| 反馈类型|
|----applyType|否|String|申请类型 |
|----isDefault|否|Boolean|是否默认 |
|----lineNum|否|Integer|行号 |
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "pageIndex" : 0,
 "pageSize" : 0,
 "pageCount" : 0,
 "totalCount" : 0,
 "first" : true,
 "last" : true,
 "content" : [{
 "id" : 0,
 "typeCode" : "String",
 "feedbackType" : "String",
 "applyType" : "String",
 "isDefault" : true,
 "lineNum" : 0
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
