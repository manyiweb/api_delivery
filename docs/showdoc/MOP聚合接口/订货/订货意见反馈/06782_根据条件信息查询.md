# 根据条件信息查询
 

**请求URL：** 
- `/config/feedbacks/list/{source}`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|keyword|否|String| 反馈编号(模糊)|
|applyType|否|List| 申请类型|
|feedbackType|否|List| 反馈类型|
|companyIds|否|List| 商户|
|status|否|List| 状态，1-已提交，2-处理中，3-已处理|
|createDate|否|Object| 创建日期|
|--start|否|DateTime||
|--end|否|DateTime||
|createId|否|List| 创建人|
|id|否|String||
|pageSize|否|Integer||
|pageNo|否|Integer||
|sortField|否|String||
|sortDirection|否|Object||

### 请求参数Json格式
 
```
{
 "keyword" : "String",
 "applyType" : null,
 "feedbackType" : null,
 "companyIds" : null,
 "status" : null,
 "createDate" : {
 "start" : "DateTime",
 "end" : "DateTime"
 },
 "createId" : null,
 "id" : "String",
 "pageSize" : 0,
 "pageNo" : 0,
 "sortField" : "String",
 "sortDirection" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--content|否|List||
|----id|否|Long| 反馈id|
|----feedbackCode|否|String| 反馈编码|
|----applyType|否|String| 申请类型|
|----applyTypeName|否|String| 申请类型字段中文|
|----feedbackType|否|String| 反馈类型|
|----companyName|否|String| 店铺名称|
|----status|否|Integer| 反馈状态|
|----statusName|否|String| 状态中文|
|----createDate|否|DateTime| 创建时间|
|----createName|否|String| 创建人|
|--pageSize|否|Integer||
|--pageNo|否|Integer||
|--total|否|Long||
|--totalPage|否|Integer||
|--hasNextPage|否|Boolean||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
