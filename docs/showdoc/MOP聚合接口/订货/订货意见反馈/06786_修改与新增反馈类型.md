# 修改与新增
 

**请求URL：** 
- `/config/feedbacktype/add`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long|反馈类型id|
|typeCode|是|String|类型编码 |
|feedbackType|是|String|反馈类型 |
|applyType|是|String|申请类型 |
|isDefault|否|Boolean| 是否默认|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "typeCode" : "String",
 "feedbackType" : "String",
 "applyType" : "String",
 "isDefault" : true
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
