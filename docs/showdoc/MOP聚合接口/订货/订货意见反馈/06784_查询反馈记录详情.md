# 查询反馈记录详情
 

**请求URL：** 
- `/config/feedbackRecord/details`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|status|是|Integer| 状态|
|id|是|Long||

### 请求参数Json格式
 
```
{
 "status" : 0,
 "id" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--result|否|String||
|--imgUrl|否|List||
|--details|否|List||
|----id|否|Long||
|----recordId|否|Long|处理过程记录表id |
|----skuCode|否|String|SKU码 |
|----itemCode|否|String|商品编码 |
|----itemName|否|String|商品名称 |
|----generateDate|否|DateTime|生产日期 |
|----qgpDay|否|Integer|保质期 |
|----feedbackNum|否|Integer|反馈数量 |
|----unit|否|String|单位 |
|----supName|否|String|供应商 |
|----feedbackInfo|否|String|反馈内容 |
|----processing|否|String|处理过程 |
|----companyId|否|String|店铺id |
|----companyName|否|String|店铺名称 |
|----remark|否|String|备注 |
|----createId|否|String||
|----createName|否|String||
|----createDate|否|DateTime||
|----modifyId|否|String||
|----modifyName|否|String||
|----modifyDate|否|DateTime||
|----dbKey|否|Integer||
|----groupId|否|String||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
