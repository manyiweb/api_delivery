# 查询明细
 

**请求URL：** 
- `/b2b/itemSales/config/findItemSalesGroupByDate`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 门店id|
|specId|否|String| 规格id|
|itemId|否|String| 商品id|
|groupId|否|String| 品牌id|

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "specId" : "String",
 "itemId" : "String",
 "groupId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--quantity|否|Double||
|--specId|否|String||
|--date|否|String||
|--dateWeek|否|String||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "quantity" : 0,
 "specId" : "String",
 "date" : "String",
 "dateWeek" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
