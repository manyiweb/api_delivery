# 批量查询订单商品最新历史价格
 

**请求URL：** 
- `/api/b2b/order/history/price/batchGetOrderLastHistoryPrice`

**请求方式：** 
- `POST`
- `RequestBody`


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|specIds|是|List| 商品规格ID列表|

### 请求参数Json格式
 
```
{
 "specIds":null
}
```

### 响应参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--specId|否|String| 规格ID|
|--itemUnitPrice|否|Double| 商品单价|
|--itemUnit|否|String| 商品单位|
|--createDate|否|DateTime| 创建时间|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 响应参数Json格式
 
```
{
 "data":[{
 "specId":"String",
 "itemUnitPrice":0,
 "itemUnit":"String",
 "createDate":"DateTime"
 }],
 "msg":"String",
 "code":"String",
 "exceptionStackInfo":"String",
 "traceId":"String"
}
```
