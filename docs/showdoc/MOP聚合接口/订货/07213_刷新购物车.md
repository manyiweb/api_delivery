# 刷新购物车
 

**请求URL：** 
- `/b2b/shopCart/refreshShopCart`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|withCoupon|否|Integer| 带优惠券|
|customAccountCalculate|否|Boolean| 自定义账户金额计算|
|orderId|否|String| 订单标识|
|b2BOrderPayLaterShopCartId|是|Long| 订单稍后支付购物车标识|
|combinationPayment|否|Boolean| 是否使用普通账户支付账户|
|notCheckItem|否|Boolean| 不检查item库存|
|shopCartKey|否|String| 如果是立即购买输入对应的立即购买cartKey|

### 请求参数Json格式
 
```
{
 "withCoupon" : 0,
 "customAccountCalculate" : true,
 "orderId" : "String",
 "b2BOrderPayLaterShopCartId" : 0,
 "combinationPayment" : true,
 "notCheckItem" : true,
 "shopCartKey" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
