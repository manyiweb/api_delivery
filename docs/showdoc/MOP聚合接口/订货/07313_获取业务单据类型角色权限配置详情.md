# 获取业务单据类型角色权限配置详情

**请求URL：** 
- `/b2b/orderType/roleConfig/getDetail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|typeCode|是|String| 类型编码 B2bOrder("订货订单"), B2BRefundType("订货退货")|
|companyId|是|String| 门店id|

### 请求参数Json格式
 
```
{
 "typeCode" : "String",
 "companyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|String| 主键id|
|--isConfigInherit|否|Integer| 是否继承: 建单权限配置|
|--isOrderTypeInherit|否|Integer| 是否继承: 订单业务类型|
|--ifOpenOrderTypeConfig|否|Integer| 是否启用建单权限设置 0否 1是|
|--typeCode|否|String| 区分业务单据类型|
|--orderTypeRoleDetail|否|List| 订货类型权限详情|
|----orderTypeId|否|String| 订货类型id 或 退货类型id|
|----orderTypeName|否|String| 订货类型名称|
|----roles|否|List| 角色编码|
|------roleCode|否|String| 角色编码|
|------roleName|否|String| 角色名称|
|--companyId|否|String| 门店|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "id" : "String",
 "isConfigInherit" : 0,
 "isOrderTypeInherit" : 0,
 "ifOpenOrderTypeConfig" : 0,
 "typeCode" : "String",
 "orderTypeRoleDetail" : [{
 "orderTypeId" : "String",
 "orderTypeName" : "String",
 "roles" : [{
 "roleCode" : "String",
 "roleName" : "String"
 }]
 }],
 "companyId" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
