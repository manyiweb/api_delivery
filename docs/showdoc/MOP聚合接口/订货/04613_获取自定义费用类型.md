# 获取自定义费用类型
 

**请求URL：** 
- `/config/customizeAccountChgType`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|type|否|Integer| 0充值 1扣款|
|sword|否|String| 模糊搜索名称|

### 请求参数Json格式
 
```
{
 "type" : 0,
 "sword" : "String"
}
```
