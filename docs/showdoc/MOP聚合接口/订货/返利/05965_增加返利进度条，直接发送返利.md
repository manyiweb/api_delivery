# 增加返利进度条，直接发送返利
 

**请求URL：** 
- `/b2b/rebate/progress/calculateRebate `

**请求方式：**
- POST
- RequestBody

注:接口需要传token 最好是对应品牌中台的token

###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 门店id|
|amount|是|Double| 金额|
|ruleId|是|Long| 规则id|
|planId|是|Long| 方案id|
|groupId|是|String| 品牌id|

###请求参数Json格式
 
```
{
 "companyId" : "String",
 "amount" : 0,
 "ruleId" : 0,
 "planId" : 0,
 "groupId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Boolean| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : true,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
