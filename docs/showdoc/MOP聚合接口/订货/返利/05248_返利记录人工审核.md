# 人工受理
 

**请求URL：** 
- `/b2b/rebateRewardRecord/accept `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|recordId|是|Long| 记录id|
|status|是|Integer| 受理状态（7：确认受理 4已拒绝）|
|remark|否|String| 备注|

###请求参数Json格式
 
```
{
 "recordId" : 0,
 "status" : 0,
 "remark" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--rebateRewardRecordDto|否|Object| 返利记录|
|----id|否|Long| id|
|----rebateRecordCode|否|String| 返利规则单号|

|----sourceRuleName|否|String| 返利规则名称|

|----rebateCompanyName|否|String| 返利商户名称|
|----rebateStatusCode|否|Long| 返利状态|
|----rebateStatusName|否|String| 返利状态名称|
|----rebateArrivalTime|否|DateTime| 返利到账时间|
|----createDate|否|DateTime| 返利到账时间|
|--rebateRewardRecordDetails|否|List| 返利详情|
|----id|否|Long| 主键|
|----rewardRecordId|否|Long| 返利记录id|
|----rewardType|否|Long| 奖励类型|
|----objId|否|Long| 奖励详情id|
|----objValue|否|Double| 奖励详情id|
|----rewardItemName|否|String| 返利详情名称|
|----status|否|String| 返利状态|
|----entryTime|否|DateTime| 入账时间|
|----exceptionInformation|否|String| 异常信息|
|--acceptVo|否|Object| 审核状态|

|----level|否|Integer| 当前审核级|
|----statusCode|否|String| 受理状态|
|----statusName|否|String| 受理状态描述|
|----remark|否|String| 受理备注|
|----createId|否|String| 创建人标识|
|----createName|否|String| 创建人名称|
|----createDate|否|DateTime| 创建时间|
|----modifyId|否|String| 修改人标识|
|----modifyName|否|String| 修改人|
|----modifyDate|否|DateTime| 修改时间|
|----dbKey|否|Integer| 分库标识|
|----groupId|否|String| 品牌商id|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
