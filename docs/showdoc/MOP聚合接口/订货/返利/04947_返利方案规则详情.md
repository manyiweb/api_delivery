# 返利方案规则详情
 

**请求URL：** 
- `/b2b/rebate/info `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|ruleId|否|Long||
|planId|否|Long||

###请求参数Json格式
 
```
{
 "ruleId" : 0,
 "planId" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--planName|否|String| 返利方案名称|
|--planDescription|否|String| 返利说明|
|--ruleDescription|否|String| 返利规则说明|
|--beginDate|否|DateTime| 返利方案开始日期|
|--endDate|否|DateTime| 返利方案结束日期|
|--value|否|Double| 当前进度标件/元|
|--totalValue|否|Double| 目标件/元|
|--type|否|Integer| 按订单金额/商品数量|
|--ruleName|否|String| 返利规则名称|
|--couponName|否|List| 赠送优惠券|
|--integral|否|Double| 赠送积分|
|--remainderDay|否|Integer| 剩余天数|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "planName" : "String",
 "planDescription" : "String",
 "ruleDescription" : "String",
 "beginDate" : "DateTime",
 "endDate" : "DateTime",
 "value" : 0,
 "totalValue" : 0,
 "type" : 0,
 "ruleName" : "String",
 "couponName" : null,
 "integral" : 0,
 "remainderDay" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
