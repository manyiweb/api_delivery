# 批量通用更新购物车Item接口 (失败的条目跳过(返回失败原因)，成功的加入购物车)

**请求URL：** 
- `/b2b/shopping/cart/item/batchAddToShopCart`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|updateRequestList|是|List| 批量请求列表|
|--itemKey|否|String| 购物车ItemKey|
|--specId|是|String| 商品规格ID|
|--itemQuantity|是|Double| 调整数量|
|--itemUnit|是|String| 选择的订货单位|
|--itemName|否|String||
|--itemCode|否|String| 商品编码|
|--skuBarcode|否|String| sku码|

### 请求参数Json格式
 
```
{
 "updateRequestList" : [{
 "itemKey" : "String",
 "specId" : "String",
 "itemQuantity" : 0,
 "itemUnit" : "String",
 "itemName" : "String",
 "itemCode" : "String",
 "skuBarcode" : "String"
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--totalCount|否|Integer||
|--successCount|否|Integer||
|--errorCount|否|Integer||
|--errorItems|否|List||
|----itemName|否|String| 商品名称|
|----reason|否|String| 原因|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : {
 "totalCount" : 0,
 "successCount" : 0,
 "errorCount" : 0,
 "errorItems" : [{
 "itemName" : "String",
 "reason" : "String"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
