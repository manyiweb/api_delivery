# 

**请求URL：** 
- `/hr/invoice/b2b/apply/search/{source}`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|keyword|否|String| 订单编号|
|status|否|List| 拣配状态|
|createDate|否|Object| 创建日期|
|--start|否|DateTime|起始对象 |
|--end|否|DateTime|结束对象 |
|createId|否|List| 创建人|
|id|否|String| id|
|pageSize|否|Integer| 分页大小|
|pageNo|否|Integer| 页码|
|sortField|否|String| 排序字段|
|sortDirection|否|Object| 排序方向|

### 请求参数Json格式
 
```
{
 "keyword" : "String",
 "status" : null,
 "createDate" : {
 "start" : "DateTime",
 "end" : "DateTime"
 },
 "createId" : null,
 "id" : "String",
 "pageSize" : 0,
 "pageNo" : 0,
 "sortField" : "String",
 "sortDirection" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--content|否|List| 数据内容|
|--pageSize|否|Integer| 分页大小|
|--pageNo|否|Integer| 分页页码|
|--total|否|Long| 数据总数|
|--totalPage|否|Integer| 总页数|
|--hasNextPage|否|Boolean| 是否有下一页|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : {
 "content" : null,
 "pageSize" : 0,
 "pageNo" : 0,
 "total" : 0,
 "totalPage" : 0,
 "hasNextPage" : true
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
