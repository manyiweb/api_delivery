# 

**请求URL：** 
- `/hr/invoice/b2b/apply/detail/byOrderId`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|String| 订单id|

### 请求参数Json格式
 
```
{
 "id" : "String"
}
```
