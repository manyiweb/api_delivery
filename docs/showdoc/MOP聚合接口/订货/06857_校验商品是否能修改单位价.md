# 校验商品是否能修改单位价

**请求URL：** 
- `/b2b/order/check/ModifyUnitPrice`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|itemIdList|是|List| 商品id|

### 请求参数Json格式
 
```
{
 "itemIdList" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--itemId|否|String| 商品id|
|--canModifyUnitPrice|否|Boolean| 能否修改单位价 true是 false否|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "itemId" : "String",
 "canModifyUnitPrice" : true
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
