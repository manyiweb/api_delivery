# 批量新增物流仓关联商户仓记录

**请求URL：** 
- `/warehouse/mlogiWhsComp/addBatch `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|mlogiWhsId|是|Long| 物流仓库id|
|whsIdList|是|List| 商户仓id集合|
|idList|是|List| 主键id集合|

###请求参数Json格式
 
```
{
 "mlogiWhsId" : 0,
 "whsIdList" : null,
 "idList" : null
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|String| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : "String",
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
