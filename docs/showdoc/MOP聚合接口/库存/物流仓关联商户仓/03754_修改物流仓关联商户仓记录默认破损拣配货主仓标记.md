# 修改物流仓关联商户仓记录默认破损拣配货主仓标记

**请求URL：** 
- `/warehouse/mlogiWhsComp/updateIsDefDamagedWhs `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long| id|

###请求参数Json格式
 
```
{
 "id" : 0
}
```

|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|String| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|

```
{
 "data" : "String",
 "msg" : "String",
 "code" : "String",

 "monitorRequestId" : "String"
}
```
