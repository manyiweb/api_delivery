# 通过批次号集合查询批次库存信息

**请求URL：** 
- `/warehouse/batch/queryListBybatchCodeIn `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|specId|是|String| 商品规格ID|
|whsId|是|String| 仓库ID|
|batchNoList|是|List| 批次号集合|

###请求参数Json格式
 
```
{
 "specId" : "String",
 "whsId" : "String",
 "batchNoList" : null
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--batchCode|否|String| 批次号|
|--productionDate|否|String| 生产日期|
|--validDays|否|Integer| 保质期（天）|
|--quantity|否|Double| 数量|
|--specId|否|String| 商品规格ID|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : [{
 "batchCode" : "String",
 "productionDate" : "String",
 "validDays" : 0,
 "quantity" : 0,
 "specId" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
