# 查询单据商品录入的批次信息
 

**请求URL：** 
- `/warehouse/batch/doc/item/record `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|docItemId|否|String| 单据明细行ID|
|docType|否|String| 单据类型，取值：GoodsIn - 采购；Purchase - 采购收货；PurchaseReturn - 采购退货；Allot - 调拨；WhsIn - 入库；WhsOut - 出库；B2BOrder - 订货订单；B2BRefund - 订货退货；CheckVouch - 盘点单；DOrder - 销售单；MitemDisassembly - 商品拆装单|
|isDraft|否|Integer| 是否草稿单据，取值：1 - 是；0 - 否|
|inOrOut|否|Integer| 出入库类型，取值：1 - 入库；2 - 出库|
|tokenId|否|String| token标识|

###请求参数Json格式
 
```
{
 "docItemId" : "String",
 "docType" : "String",
 "isDraft" : 0,
 "inOrOut" : 0,
 "tokenId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--items|否|List| 商品批次信息|
|----docItemId|否|String| 单据明细行ID|
|----batchCode|否|String| 批次号|
|----productionDate|否|String| 生产日期|
|----validDays|否|Integer| 保质期|
|----quantity|否|Double| 数量|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : {
 "items" : [{
 "docItemId" : "String",
 "batchCode" : "String",
 "productionDate" : "String",
 "validDays" : 0,
 "quantity" : 0
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
