# 查询单据商品录入的批次信息
 

**请求URL：** 
- `/warehouse/batch/doc/record `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|docId|否|String| 单据ID|
|isDraft|否|Integer| 是否草稿单据，取值：1 - 是；0 - 否|
|tokenId|否|String| token标识|

###请求参数Json格式
 
```
{
 "docId" : "String",
 "isDraft" : 0,
 "tokenId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Map| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
