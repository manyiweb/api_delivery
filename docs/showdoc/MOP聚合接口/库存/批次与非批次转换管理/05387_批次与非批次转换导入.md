# 批次与非批次转换导入

**请求URL：** 
- `/file/batchConversion/importItem `

**请求方式：**
- POST
- FormData


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|conversionType|否|Integer| 转换类型,1=非批次转批次,2=批次转非批次|
|tokenId|否|String| 登录标识|
|file|否|Object| 导入文件|

###请求参数Json格式
 
```
{
 "conversionType" : 0,
 "tokenId" : "String",
 "file" : null
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--errorData|否|List| 导入失败信息|
|--itemData|否|List| 导入成功的行|
|----itemCode|否|String| 商品编码|
|----itemName|否|String| 商品名称|
|----skuBarcode|否|String| SKU码|
|----unit|否|String| 单位|
|----specId|否|String| 规格ID|
|----itemId|否|String| 商品id|
|----batchCode|否|String| 转换后批次|
|----validDays|否|Integer| 保质期|
|----productionDate|否|String| 转换后生产日期|
|----productionDateStr|否|String| 转换后生产日期|
|--totalCount|否|Long| 总数|
|--successCount|否|Long| 成功数|
|--errorCount|否|Long| 失败数|
|--fileUrl|否|String| 导出文件相对路径|
|--downloadURL|否|String| 导出文件下载路径|
|--data|否|List| 返回数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
