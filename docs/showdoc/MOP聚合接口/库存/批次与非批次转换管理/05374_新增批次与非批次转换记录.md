# 新增批次与非批次转换记录

**请求URL：** 
- `/warehouse/batchConversion/add `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|groupId|否|String| 品牌id,加锁用|
|conversionType|否|Integer| 转换类型,1=非批次转批次,2=批次转非批次|
|remark|否|String| 备注|
|itemReqList|否|List| 明细行|
|--itemId|否|String| 商品ID|
|--itemCode|否|String| 商品ID|
|--itemName|否|String| 商品ID|
|--skuBarcode|否|String| sku条码|
|--specId|否|String| 规格ID|
|--batchCode|否|String| 转换后批次号|
|--productionDate|否|DateTime| 转换后生产日期|
|--expireDate|否|DateTime| 到期日期,服务端计算|
|--validDays|否|Integer| 保质期天数,服务端取商品的|
|--remark|否|String| 备注|

###请求参数Json格式
 
```
{
 "groupId" : "String",
 "conversionType" : 0,
 "remark" : "String",
 "itemReqList" : [{
 "itemId" : "String",
 "itemCode" : "String",
 "itemName" : "String",
 "skuBarcode" : "String",
 "specId" : "String",
 "batchCode" : "String",
 "productionDate" : "DateTime",
 "expireDate" : "DateTime",
 "validDays" : 0,
 "remark" : "String"
 }]
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--isSuccess|否|Boolean| 是否新增成功|
|--id|否|Long| 新增成功的记录id|
|--errorMsgList|否|Object| 新增失败的提示行|
|--downloadUrl|否|String| 下载异常数据url|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "isSuccess" : true,
 "id" : 0,
 "errorMsgList" : null,
 "downloadUrl" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
