# 批次与非批次转换记录详情

**请求URL：** 
- `/warehouse/batchConversion/info `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|

###请求参数Json格式
 
```
{
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--relateOrderInfoList|否|List| 关联单据|
|----orderType|否|String| 单据类型|
|----settlementStatusName|否|String| 状态|
|----orderNo|否|String| 单据号|
|----quantity|否|Double| 数量|
|----orderId|否|String| 单据id|
|----companyName|否|String| 门店|
|----itemCode|否|String| 商品编码|
|----remark|否|String| 备注|
|----outOrderNo|否|String| 外部单号|
|----orderTypeName|否|String| 单据类型名|
|----docTypeName|否|String| docTypeName|
|----companyId|否|String| 门店id|
|----itemName|否|String| 商品名称|
|----statusName|否|String| 状态名|
|----createName|否|String| 创建人|
|----createDate|否|DateTime| 创建时间|
|--id|否|Long| ID|
|--recordNo|否|String| 转换记录编号|
|--conversionType|否|Integer| 转换类型|
|--conversionTypeName|否|String| 转换类型名|
|--status|否|Integer| 转换状态,1=成功,0=异常|
|--statusName|否|String| 转换状态名|
|--remark|否|String| 备注|
|--createName|否|String| 创建人|
|--createDate|否|DateTime| 创建时间|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
