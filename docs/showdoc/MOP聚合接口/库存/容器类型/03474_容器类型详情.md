# 容器类型详情

**请求URL：** 
- `/warehouse/mlogiWhsContainerType/info `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|

###请求参数Json格式
 
```
{
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--containerTypeCode|否|String| 容器类型编码|
|--containerTypeName|否|String| 容器类型名称|
|--isActive|否|Integer| 状态 0失效1生效|
|--isActiveName|否|String| 状态名|
|--bearing|否|Double| 额定承重|
|--volume|否|Double| 额定体积|
|--length|否|Double| 长|
|--width|否|Double| 宽|
|--height|否|Double| 高|
|--remark|否|String| 备注|
|--createName|否|String| 创建人|
|--createDate|否|DateTime| 创建时间|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : {
 "containerTypeCode" : "String",
 "containerTypeName" : "String",
 "isActive" : 0,
 "isActiveName" : "String",
 "bearing" : 0,
 "volume" : 0,
 "length" : 0,
 "width" : 0,
 "height" : 0,
 "remark" : "String",
 "createName" : "String",
 "createDate" : "DateTime"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
