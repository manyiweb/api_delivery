# 新增入库通知单

**请求URL：** 
- `/warehouse/logiWhsInNotice/add `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|logiWhsStorId|否|Long| 物流仓ID(open api传入)|
|sourceNo|否|String| 来源单号|
|whsInTypeCode|否|String| 单据类型编码|
|whsInTypeName|否|String| 单据类型名称|
|shipperName|否|String| 发货方名称|
|remark|否|String| 备注|
|itemList|否|List| 商品明细|
|--companyId|否|String| 货主门店id|
|--itemStatusId|否|Long| 商品状态ID|
|--receivingType|否|String| 收货类型|
|--packagingServices|否|String| 包装服务|
|--specId|否|String| 规格ID|
|--planQty|否|Double| 计划数量|
|--remark|否|String| 备注|
|--outOrderLineId|否|String| 外部订单行号1|
|--outOrderLineIdTwo|否|String| 外部订单行号2|
|sourceNoTwo|否|String| 来源单号2|
|docDate|否|DateTime| 送货单创建日期|
|preDueDate|否|DateTime| 预计到货日期|
|applicant|否|String| 申请人|
|isCross|否|Integer| 是否越库,0 否 1 是|
|freightPayType|否|String| 运费支付方式|
|totalBoxQuantity|否|Integer| 总箱数|
|totalQuantity|否|Double| 总数量|
|totalVolume|否|Double| 总体积|
|supplierCode|否|String| 供应商编码|
|supplierName|否|String| 供应商名称|
|purchaser|否|String| 采购员|
|driverPhone|否|String| 司机联系方式|
|receivingArea|否|String| 收货区|
|sourceType|否|String| 来源单类型|
|sourceSystem|否|String| 来源系统|
|sourceId|否|String| 来源id|
