# 修改物流仓库档案

**请求URL：** 
- `/warehouse/mlogiWhs/update `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long| id|
|logiWhsCode|是|String| 物流仓编码|
|logiWhsName|否|String| 物流仓名称|
|isActive|否|Integer| 活跃状态 0停用1启用|
|logiContact|否|String| 联系人|
|logiPhone|否|String| 电话|
|logiAddress|否|String| 仓库地址|
|defaultReceivingWorkAreaId|否|Long| 默认收货工作区id|
|defaultShelvesWorkAreaId|否|Long| 默认上架工作区id|
|remark|否|String| 备注|

###请求参数Json格式
 
```
{
 "id" : 0,
 "logiWhsCode" : "String",
 "logiWhsName" : "String",
 "isActive" : 0,
 "logiContact" : "String",
 "logiPhone" : "String",
 "logiAddress" : "String",
 "defaultReceivingWorkAreaId" : 0,
 "defaultShelvesWorkAreaId" : 0,
 "remark" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Long| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : 0,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
