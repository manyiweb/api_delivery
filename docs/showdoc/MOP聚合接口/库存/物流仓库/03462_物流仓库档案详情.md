# 物流仓库档案详情

**请求URL：** 
- `/warehouse/mlogiWhs/info `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long| id|

###请求参数Json格式
 
```
{
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long| id|
|--logiWhsCode|否|String| 物流仓编码|
|--logiWhsName|否|String| 物流仓名称|
|--isActive|否|Integer| 活跃状态 0停用1启用|
|--isActiveName|否|String| 仓库状态名|
|--logiContact|否|String| 联系人|
|--logiPhone|否|String| 电话|
|--logiAddress|否|String| 仓库地址|
|--defaultReceivingWorkAreaId|否|Long| 默认收货工作区id|
|--defaultReceivingWorkAreaName|否|String| 默认收货工作区名|
|--defaultShelvesWorkAreaId|否|Long| 默认上架工作区id|
|--defaultShelvesWorkAreaName|否|String| 默认上架工作区名|
|--remark|否|String| 备注|
|--createName|否|String| 创建人|
|--createDate|否|DateTime| 创建时间|
|--modifyName|否|String| 修改人|
|--modifyDate|否|DateTime| 修改时间|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
