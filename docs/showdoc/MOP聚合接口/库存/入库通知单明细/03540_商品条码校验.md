# 商品条码校验

**请求URL：** 
- `/warehouse/logiWhsInNoticeItem/skuBarcodeCheck `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|code|是|String| 条码|
|logiWhsInId|是|Long| 入库通知单id|

###请求参数Json格式
 
```
{
 "code" : "String",
 "logiWhsInId" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--kindQty|否|Integer| 种数|
|--receivingCountQty|否|Double| 已收件数|
|--itemList|否|List| 商品集合|
|----validDays|否|Integer| 保质期(天)|
|----planQty|否|Double| 计划数量|
|----receivingQty|否|Double| 收货数量|
|----dueInQty|否|Double| 待收数量|
|----shelvesQty|否|Double| 上架数量|
|----itemStatusName|否|String| 商品状态名称|
|----outOrderLineId|否|String| 外部订单行号1|
|----outOrderLineIdTwo|否|String| 外部订单行号2|
|----receivingType|否|String| 收货类型|
|----id|否|Long| 明细记录id|
|----itemCode|否|String| 商品编码|
|----itemName|否|String| 商品名称|
|----skuBarcode|否|String| 条码|
|----specId|否|String| 规格ID|
|----unit|否|String| 单位|
|----brandName|否|String| 商品品牌名称|
|----isBatch|否|Boolean| 是否为批次商品,true:是;false:否|
|----remark|否|String| 备注|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
