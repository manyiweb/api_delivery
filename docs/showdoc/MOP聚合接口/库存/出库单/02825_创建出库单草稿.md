# 创建出库单草稿
 

**请求URL：** 
- `/warehouse/createOrUpdateOutboundOrderDraft `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|whsOutId|否|String| 出库单草稿ID|
|whsId|否|String| 仓库ID|
|postingDate|否|DateTime| 过账日期|
|whsOutTypeCode|否|String| 出库类型编码|
|remark|否|String| 备注|
|outboundOrderItems|否|List| 出库单明细|
|--itemId|否|String| 商品ID|
|--quantity|否|Double| 数量|
|--specId|否|String| 规格ID|
|--unit|否|String| 单位|
|--barcodeList|否|List| 唯一码列表|
|--batchList|否|List| 批次信息|
|----batchCode|否|String| 批次号|
|----quantity|否|Double| 数量|
|----productionDate|否|DateTime| 生产日期|
|attachmentFileURLList|否|List| 入库单附件|
|source|否|Integer| 单据来源 1-中台 2-前台 3-店务助手 4-POS|

###请求参数Json格式
 
```
{
 "whsOutId" : "String",
 "whsId" : "String",
 "postingDate" : "DateTime",
 "whsOutTypeCode" : "String",
 "remark" : "String",
 "outboundOrderItems" : [{
 "itemId" : "String",
 "quantity" : 0,
 "specId" : "String",
 "unit" : "String",
 "barcodeList" : null,
 "batchList" : [{
 "batchCode" : "String",
 "quantity" : 0,
 "productionDate" : "DateTime"
 }]
 }],
 "attachmentFileURLList" : null,
 "source" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
