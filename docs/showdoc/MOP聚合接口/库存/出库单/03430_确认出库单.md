# 确认出库单

**请求URL：** 
- `/warehouse/confirm/outboundOrder `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|whsOutId|否|String| 出库单草稿ID|
|whsId|否|String| 仓库ID|
|outboundOrderItems|否|List| 出库单明细|
|--whsOutItemId|否|String| 出库单明细ID|
|--barcodeList|否|List| 唯一码列表|
|--batchList|否|List| 批次信息|
|----batchCode|否|String| 批次号|
|----quantity|否|Double| 数量|
|----productionDate|否|DateTime| 生产日期|

###请求参数Json格式
 
```
{
 "whsOutId" : "String",
 "whsId" : "String",
 "outboundOrderItems" : [{
 "whsOutItemId" : "String",
 "barcodeList" : null,
 "batchList" : [{
 "batchCode" : "String",
 "quantity" : 0,
 "productionDate" : "DateTime"
 }]
 }]
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
