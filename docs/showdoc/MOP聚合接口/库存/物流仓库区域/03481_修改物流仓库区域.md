# 修改物流仓库区域

**请求URL：** 
- `/warehouse/mlogiWhsArea/update `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long| id|
|areaName|否|String| 仓区名称|
|areaCode|是|String| 区域编码|
|mlogiWhsId|否|Long| 物流仓id|
|isActive|否|Integer| 活跃状态 0失效1生效|
|remark|否|String| 备注|

###请求参数Json格式
 
```
{
 "id" : 0,
 "areaName" : "String",
 "areaCode" : "String",
 "mlogiWhsId" : 0,
 "isActive" : 0,
 "remark" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Long| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : 0,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
