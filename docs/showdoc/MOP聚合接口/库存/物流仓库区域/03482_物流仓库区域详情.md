# 物流仓库区域详情

**请求URL：** 
- `/warehouse/mlogiWhsArea/info `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|

###请求参数Json格式
 
```
{
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long| id|
|--areaCode|否|String| 仓区编码|
|--areaName|否|String| 区域名称|
|--mlogiWhsId|否|Long| 物流仓库ID|
|--logiWhsName|否|String| 物流仓名称|
|--isActive|否|Integer| 活跃状态 0失效1生效|
|--isActiveName|否|String| 活跃状态名|
|--remark|否|String| 备注|
|--createName|否|String| 创建人|
|--createDate|否|DateTime| 创建时间|
|--modifyName|否|String| 修改人|
|--modifyDate|否|DateTime| 修改时间|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "areaCode" : "String",
 "areaName" : "String",
 "mlogiWhsId" : 0,
 "logiWhsName" : "String",
 "isActive" : 0,
 "isActiveName" : "String",
 "remark" : "String",
 "createName" : "String",
 "createDate" : "DateTime",
 "modifyName" : "String",
 "modifyDate" : "DateTime"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
