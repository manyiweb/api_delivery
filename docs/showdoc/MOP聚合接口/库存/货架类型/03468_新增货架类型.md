# 新增货架类型

**请求URL：** 
- `/warehouse/mlogiWhsShelvesType/add `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|
|shelvesTypeCode|否|String| 货架类型编码|
|shelvesTypeName|否|String| 货架类型名称|
|isActive|否|Integer| 活跃状态 0失效1生效|
|bearing|否|Double| 承重|
|volume|否|Double| 额定体积|
|length|否|Double| 长|
|width|否|Double| 宽|
|height|否|Double| 高|
|remark|否|String| 备注|
|containerTypeId|否|Long| 容器类型id|
|containerTypeName|否|String| 容器类型名称|
|containerQty|否|Integer| 容器数量|

###请求参数Json格式
 
```
{
 "id" : 0,
 "shelvesTypeCode" : "String",
 "shelvesTypeName" : "String",
 "isActive" : 0,
 "bearing" : 0,
 "volume" : 0,
 "length" : 0,
 "width" : 0,
 "height" : 0,
 "remark" : "String",
 "containerTypeId" : 0,
 "containerTypeName" : "String",
 "containerQty" :0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Long| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : 0,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
