# 获取要货业务类型列表

**请求URL：** 
- `/b2b/need/orderType/config/list`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 商户id|
|ifCopyList|否|Integer| 复制类型设置调用的标识 0否 1是|

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "ifCopyList" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--isInherit|否|Integer| 是否继承|
|--isOpen|否|Integer| 是否开启业务类型要货|
|--needOrderTypeList|否|List| 要货业务类型|
|----orderTypeCode|否|String| 业务类型编码|
|----orderTypeId|否|String| 业务类型id|
|----orderTypeName|否|String| 业务类型名称|
|----functionType|否|String||
|----needChangeOrder|否|Boolean| 是否启用要货改单模式(0:不启用,1:启用)|
|----addDayCount|否|Integer| 限制每天下单数|
|----openAddDayCountSet|否|Boolean| 是否限制每天下单数 true是false否|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "isInherit" : 0,
 "isOpen" : 0,
 "needOrderTypeList" : [{
 "orderTypeCode" : "String",
 "orderTypeId" : "String",
 "orderTypeName" : "String",
 "functionType" : "String",
 "needChangeOrder" : true,
 "addDayCount" : 0,
 "openAddDayCountSet" : true
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
