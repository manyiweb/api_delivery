# 工作区详情

**请求URL：** 
- `/warehouse/mlogiWhsWorkArea/info `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|

###请求参数Json格式
 
```
{
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long| id|
|--workAreaCode|否|String| 工作区编码|
|--workAreaName|否|String| 工作区名称|
|--isActive|否|Integer| 状态 0失效1生效|
|--isActiveName|否|String| 状态名|
|--workTypeCode|否|String| 工作区类型编码|
|--workTypeName|否|String| 工作区类型名称（上架工作区、拣货工作区、复核工作区）|
|--floor|否|Integer| 所在楼层|
|--mlogiWhsId|否|Long| 物流仓库Id|
|--logiWhsName|否|String| 物流仓名称|
|--recheckWorkAreaId|否|Long| 复核工作区id|
|--recheckWorkAreaName|否|String| 复核工作区名|
|--remark|否|String| 备注|
|--createName|否|String| 创建人|
|--createDate|否|DateTime| 创建时间|
|--modifyName|否|String| 更新人|
|--modifyDate|否|DateTime| 更新时间|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
