# 修改工作区

**请求URL：** 
- `/warehouse/mlogiWhsWorkArea/update `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long| id|
|workAreaCode|是|String| 工作区编码|
|workAreaName|是|String| 工作区名称|
|isActive|是|Integer| 活跃状态 0失效1生效|
|floor|是|Integer| 所在楼层|
|mlogiWhsId|是|Long| 物流仓库Id|
|workTypeCode|是|String| 工作区类型编码|
|workTypeName|是|String| 工作区类型名称（上架工作区、拣货工作区、复核工作区）|
|recheckWorkAreaId|否|Long| 复核工作区id；工作区类型为拣配工作区时必填|
|remark|否|String| 备注|

###请求参数Json格式
 
```
{
 "id" : 0,
 "workAreaCode" : "String",
 "workAreaName" : "String",
 "isActive" : 0,
 "floor" : 0,
 "mlogiWhsId" : 0,
 "workTypeCode" : "String",
 "workTypeName" : "String",
 "recheckWorkAreaId" : 0,
 "remark" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Long| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : 0,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
