# 入库商品收货
 

**请求URL：** 
- `/warehouse/logiWhsShelvesJob/acceptShelvesItem `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|whsInNoticeId|否|Long| 入库通知单ID|
|passageType|否|Integer| 通道类型 0-正常通道 1-特殊通道|
|containerCode|否|String| 箱码|
|whsId|否|String| 货主ID|
|itemStatusId|否|Long| 指定商品状态ID|
|brokenItem|否|Boolean| 是否为破损商品收货|
|skuBarcode|否|String| SKU条码|
|quantity|否|Double| 收货数量|
|productionDate|否|DateTime| 生产日期|
|expireDate|否|DateTime| 到期日期|
|batchCode|否|String| 批次号|
|remark|否|String| 备注|

###请求参数Json格式
 
```
{
 "whsInNoticeId" : 0,
 "passageType" : 0,
 "containerCode" : "String",
 "whsId" : "String",
 "itemStatusId" : 0,
 "brokenItem" : true,
 "skuBarcode" : "String",
 "quantity" : 0,
 "productionDate" : "DateTime",
 "expireDate" : "DateTime",
 "batchCode" : "String",
 "remark" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
