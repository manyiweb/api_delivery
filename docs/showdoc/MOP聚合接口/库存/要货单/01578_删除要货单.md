# 删除要货单
 

**请求URL：** 
- `/b2b/needOrder/delete `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|String| 单据id|

###请求参数Json格式
 
```
{
 "id" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String"
}
```
