# 智能配货 - 门店配货单分页列表查询

- `/b2b/intelligenceDistributionMerchant/pageByIntelligenceDistributionId`

**请求方式：**
- POST
- RequestBody

|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|intelligenceDistributionId|是|Long| 智能配货id|
|sword|否|String||

|id|否|String||
|orderField|否|String| 排序字段|

|--current|否|Object||
|----itemName|否|String||

|----maxValue|否|String||
|----isCustom|否|String||
|----isRange|否|String||
|----isSelect|否|String||
|--sword|否|String||
|--pageIndex|否|Integer||
|--pageSize|否|Integer||
|--curPageNum|否|Integer||
|--totalPage|否|Integer||

|status|否|Integer| 状态|

|--pageCount|否|Integer| 总页数|

|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|

|----orderNo|否|String| 编号|
