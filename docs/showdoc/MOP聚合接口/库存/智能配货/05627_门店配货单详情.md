# 门店配货单详情

**请求URL：** 
- `/b2b/intelligenceDistributionMerchant/info`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long| id|

### 请求参数Json格式
 
```
{
 "id" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--associatedDocumentList|否|List| 关联单据集合|
|----documentId|否|String| 单据id|
|----documentCode|否|String| 单据编码|
|----businessTypeName|否|String| 业务类型|
|----businessType|否|String| 业务类型|
|----statusName|否|String| 单据状态名|
|----createName|否|String| 创建人|
|----createDate|否|DateTime| 创建时间|
|--id|否|Long| ID|
|--intelligenceDistributionId|否|Long| 智能配货id|
|--orderNo|否|String| 编号|
|--status|否|Integer| 状态;1:已计划;2:部分配货;3:已配货;4:已取消;5:配货完成|
|--statusName|否|String| 状态名|
|--finishFlag|否|Boolean| 是否已配货完成|
|--sourceType|否|Integer| 配货来源单据设置，0订货1要货|
|--companyId|否|String| 门店id|
|--companyCode|否|String| 门店编码|
|--companyName|否|String| 门店名称|
|--createName|否|String| 创建人|
|--createDate|否|DateTime| 创建时间|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
