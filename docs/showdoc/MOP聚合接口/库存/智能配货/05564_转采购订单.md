# 转采购订单

**请求URL：** 
- `/b2b/intelligenceDistribution/turn/goodInOrder`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long| 智能配货id|
|companyId|是|String| 转采购单的商户|
|goodsInOrderType|是|String| 单据类型|
|remark|否|String| 备注|
|arrivalDate|是|DateTime| 到货日期|
|saveType|否|String| ND:草稿|
|itemReqs|是|List| 生成采购单请求明细|
|--specId|是|String| 规格id|
|--itemId|是|String| 商品id|
|--quantity|是|Double| 采购数量|
|--purchasePrice|是|Double| 采购价|
|--amountTotal|是|Double| 采购价小计|
|--unit|是|String| 采购价单位|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "companyId" : "String",
 "goodsInOrderType" : "String",
 "remark" : "String",
 "arrivalDate" : "DateTime",
 "saveType" : "String",
 "itemReqs" : [{
 "specId" : "String",
 "itemId" : "String",
 "quantity" : 0,
 "purchasePrice" : 0,
 "amountTotal" : 0,
 "unit" : "String"
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
