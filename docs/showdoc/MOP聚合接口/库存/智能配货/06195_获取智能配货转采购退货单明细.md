# 获取智能配货转采购退货单明细

**请求URL：** 
- `/b2b/intelligenceDistribution/turnPurchaseReturn/distributionDetail`

**请求方式：**
- POST
- RequestBody

|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--itemId|否|String| 商品ID|

|--itemName|否|String| 商品名称|

|--quantity|否|Double| 最小单位组单位数量|

|--itemUnit|否|String| 单位组单位|
