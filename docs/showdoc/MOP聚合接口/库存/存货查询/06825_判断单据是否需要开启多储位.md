# 判断单据是否需要开启多储位

**请求URL：** 
- `/warehouse/location/location/isOpen`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|businessType|是|String| 单据类型（BusinessType） DorderType("销售订单"), RGType("销售退货"), AllotOrderType("商品调拨"), WhsInType("商品入库"), WhsOutType("商品出库"), ckvType("库存盘点"), NeedOrderType("要货订单"), PurchaseType("采购订单"), PurchaseGoodsType("采购收货"), PurchaseReturnType("采购退货"), B2bOrder("订货订单"), B2BRefundType("订货退货"), ExchangeType("订货换货"), CostOrder("费用管理"), SupplierBill("供应商结算单"), InfoType("资讯文章"), MessageTtemplate("短信模板"), AnnounceMent("公告类型"), recycle("回收单"), AfterSaleType("售后维修"), PromotionProject("促销方案"), SpecType("规格类型"), RetailCoupon("零售优惠券"), B2bCoupon("订货优惠券"), WhsInNotice("入库通知单"), WhsOutNotice("出库通知单"),DOrderSet("订货设置"),CreditStatement("赊销结算单"),ChangeAndMergeCard("换卡/合并卡");|
|orderTypeCode|否|String| 单据类型编码|
|companyId|否|String| 门店Id|

### 请求参数Json格式
 
```
{
 "businessType" : "String",
 "orderTypeCode" : "String",
 "companyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Boolean||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : true,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
