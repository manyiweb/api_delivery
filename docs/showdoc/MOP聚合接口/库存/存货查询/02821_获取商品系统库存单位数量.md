# 获取商品系统库存单位数量
 

**请求URL：** 
- `/product/stock/unit/quantity `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|specId|否|String| 商品规格ID|
|quantity|否|Double| 系统库存数量 - 基本单位|
|tokenId|否|String| token标识|

###请求参数Json格式
 
```
{
 "itemId" : "String",
 "quantity" : 0,
 "tokenId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--stockUnitGroup|否|List| 系统库存单位数量|
|----unit|否|String| 单位名称|
|----quantity|否|Double| 数量|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : {
 "stockUnitGroup" : [{
 "unit" : "String",
 "quantity" : 0
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
