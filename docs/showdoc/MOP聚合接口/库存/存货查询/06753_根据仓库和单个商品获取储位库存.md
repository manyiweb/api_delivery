# 根据仓库和商品获取储位库存

**请求URL：** 
- `/warehouse/location/single/item/stock/detail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|whsId|是|String| 仓库Id|
|specId|是|String| 规格Id|
|isDefault|否|Boolean| 是否默认|
|isRetailOut|否|Boolean| 是否可零售出库|
|isRetailIn|否|Boolean| 是否可零售退货|
|sword|否|String||
|tokenId|否|String||
|id|否|String||
|orderField|否|String||
|orderSort|否|String||
|searchBeans|否|List||
|--typeCode|否|String||
|--typeName|否|String||
|--dataType|否|String||
|--isSingle|否|String||
|--isLikeSearch|否|String||
|--items|否|List||
|--current|否|Object||
|----itemName|否|String||
|----itemValue|否|String||
|----minValue|否|String||
|----maxValue|否|String||
|----isCustom|否|String||
|----isRange|否|String||
|----isSelect|否|String||
|--sword|否|String||
|--pageIndex|否|Integer||
|--pageSize|否|Integer||
|--curPageNum|否|Integer||
|--totalPage|否|Integer||
|--totalCount|否|Integer||
|status|否|Integer||
|pageIndex|否|Integer||
|pageSize|否|Integer||
|orderField|否|String||
|orderSort|否|String||
