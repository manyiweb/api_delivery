# 详情
 

**请求URL：** 
- `/config/orderDeliveryType/info `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|

###请求参数Json格式
 
```
{
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long| 主键标识|
|--companyId|否|String| 门店商户ID，与商户表syscompany相关联|
|--deliveryCode|否|String| 配送方式编码|
|--deliveryName|否|String| 配送方式名称|
|--isDefault|否|Integer| 是否默认 1是0否|
|--createName|否|String| 创建人姓名|
|--createDate|否|DateTime| 创建时间|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "companyId" : "String",
 "deliveryCode" : "String",
 "deliveryName" : "String",
 "isDefault" : 0,
 "createName" : "String",
 "createDate" : "DateTime"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
