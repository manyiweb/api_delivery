# 获取商品拆装单详情

**请求URL：** 
- `/product/mitemDisassembly/detail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|mitemDisassemblyId|是|Long| id|
|sword|否|String| 搜素关键字,支持商品编码或商品名称进行搜索|
|pageIndex|否|Integer||
|pageSize|否|Integer||
|orderField|否|String||
|orderSort|否|String||

### 请求参数Json格式
 
```
{
 "mitemDisassemblyId" : 0,
 "sword" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String"
}
```
