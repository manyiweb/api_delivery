# 商品拆装设置保存

**请求URL：** 
- `/product/mitemDisassembly/set/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|
|itemCostMethod|否|Integer| 子商品成本价的分摊逻辑
 0按子商品数量分摊主商品成本
 1按子商品零售价分摊主商品成本|
|addBomNotAuto|否|Boolean| 启用新建拆装单时,主商品选择bom商品,不自动带出子物料 false停用，true启用|
|requireReason|否|Boolean| 启用新建拆装单时,需要选择原因|
|reasonList|否|List| 原因|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "itemCostMethod" : 0,
 "addBomNotAuto" : true,
 "requireReason" : true,
 "reasonList" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
