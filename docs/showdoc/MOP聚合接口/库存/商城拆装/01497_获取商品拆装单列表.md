# 获取商品拆装单列表

**请求URL：** 
- `/product/mitemDisassembly/list`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|
|sword|否|String| 搜素关键字,支持单号和仓库名称进行搜索|
|whsIds|否|List| 仓库id列表|
|mitemDisassemblyTypeCodes|否|List| 单据类型编码列表|
|masterItemIds|否|List| 主商品id|
|createIds|否|List| 创建人id|
|beginDate|否|DateTime| 创建时间 起始时间|
|endDate|否|DateTime| 创建时间 结束时间|
|type|否|String| 导出 3 整单导出 , 1 明细导出|
|searchBeans|否|List| 高级筛选条件|
|--typeCode|否|String||
|--typeName|否|String||
|--dataType|否|String||
|--isSingle|否|String||
|--isLikeSearch|否|String||
|--items|否|List||
|----itemName|否|String||
|----itemValue|否|String||
|----minValue|否|String||
|----maxValue|否|String||
|----isCustom|否|String||
|----isRange|否|String||
|----isSelect|否|String||
|--current|否|Object||
|----itemName|否|String||
|----itemValue|否|String||
|----minValue|否|String||
|----maxValue|否|String||
|----isCustom|否|String||
|----isRange|否|String||
|----isSelect|否|String||
|--sword|否|String||
|--pageIndex|否|Integer||
|--pageSize|否|Integer||
|--curPageNum|否|Integer||
|--totalPage|否|Integer||
|--totalCount|否|Integer||
|reasonList|否|List| 拆装原因|
|pageIndex|否|Integer||
|pageSize|否|Integer||
|orderField|否|String||
|orderSort|否|String||
