# 根据单据获取批量拆装数据

**请求URL：** 
- `/product/disassembly/source/order/get/items`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|sourceOrderTypeCode|是|String| 单据类型|
|sourceOrderIds|是|List| 单据Id|
|sword|否|String| 搜索关键字，商品名称，sku，名称|

### 请求参数Json格式
 
```
{
 "sourceOrderTypeCode" : "String",
 "sourceOrderIds" : null,
 "sword" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--specId|否|String| 商品规格|
|--itemId|否|String| 商品Id|
|--quantity|否|Double| 商品数量（基本单位）|
|--salesPrice|否|Double| 零售价|
|--costPrice|否|Double| 成本价|
|--itemName|否|String| 商品名称|
|--unit|否|String| 基本数量单位|
|--totalCostPrice|否|Double| 成本总额|
|--totalSalesPrice|否|Double| 零售价总额|
|--bomItems|否|List| bom-子物料|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "specId" : "String",
 "itemId" : "String",
 "quantity" : 0,
 "salesPrice" : 0,
 "costPrice" : 0,
 "itemName" : "String",
 "unit" : "String",
 "totalCostPrice" : 0,
 "totalSalesPrice" : 0,
 "bomItems" : null
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
