# 新建商品拆装单
 

**请求URL：** 
- `/product/mitemDisassembly/add`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|mitemDisassemblyTypeCode|是|String| 商品拆装类型编码 Unpacking("拆包"),Assembly("组装")|
|whsId|是|String| 仓库id|
|specId|是|String| 商品规格id|
|itemId|是|String| 商品id|
|quantity|是|Double| 主商品数量|
|unit|否|String| 单位|
|storeLocations|否|List| 储位及对应数量|
|--storeLocationId|是|Long||
|--storeLocationName|是|String||
|--itemUnit|是|String||
|--itemUnitQty|是|Double||
|--unitRate|是|Double||
|--unit|是|String||
|--unitQty|是|Double||
|batchList|否|List| 主商品批次集合|
|--quantity|否|Double||
|--batchCode|否|String||
|--productionDate|否|DateTime||
|--validDays|否|Integer||
|remark|否|String| 备注|
|mitemDisassemblyItemAddReqs|否|List| 子商品|
|--specId|是|String| 商品规格id|
|--itemId|是|String| 商品id|
|--quantity|否|Double| 商品数量|
|--costPrice|是|Double| 成本价|
|--storeLocations|否|List| 储位及对应数量|
|----storeLocationId|是|Long||
|----storeLocationName|是|String||
|----itemUnit|是|String||
|----itemUnitQty|是|Double||
|----unitRate|是|Double||
|----unit|是|String||
|----unitQty|是|Double||
|--batchList|否|List| 子商品批次集合|
|----quantity|否|Double||
|----batchCode|否|String||
|----productionDate|否|DateTime||
|----validDays|否|Integer||
|costPrice|是|Double| 成本价|
|reason|否|String| 原因|
