# 获取仓库(商户端使用)
 

**请求URL：** 
- `/product/mwhs/getMwhs `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
无参数


###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|String||
|--companyId|否|String| 门店商户ID，与商户表syscompany相关联|
|--whsCode|否|String| 仓库编码|
|--whsName|否|String| 仓库名称|
|--isActive|否|Integer| 是否启用 1是 0否|
|--createDate|否|DateTime| 创建时间|
|--updateDate|否|DateTime| 更新时间|
|--creator|否|String| 创建人|
|--modifiedBy|否|String| 修改人|
|--isDefault|否|String| 默认 Y是 N否|
|--version|否|Integer||
|--typeCode|否|String| 类型 G总部仓 C门店仓|
|--typeName|否|String| 类型 G总部仓 C门店仓|
|--whsLevel|否|String| 仓库等级|
|--whsTypeCode|否|String| （未使用）|
|--whsTypeName|否|String| （未使用）|
|--createId|否|String| 创建人ID|
|--mainWhs|否|Integer| 是否为总仓 1是0否|
|--externalNo|否|String| 外部编码|
|--isBatch|否|Integer| 是否启用批次，1是 0否|
|--isUniqueCode|否|Integer| 是否启用唯一码，1是 0否|
|--tokenId|否|String||
|--editType|否|String||
|--apiVersion|否|String||
|--dbKey|否|Integer| 分库标识|
|--groupId|否|String| 品牌商id|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
