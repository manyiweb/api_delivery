# 导出商品拆装单
 

**请求URL：** 
- `/file/mitemDisassembly/export `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|否|String||
|id|否|Long| id|
|sword|否|String| 搜素关键字,支持单号和仓库名称进行搜索|
|whsIds|否|List| 仓库id列表|
|mitemDisassemblyTypeCodes|否|List| 单据类型编码列表|
|beginDate|否|String| 创建时间 起始时间|
|endDate|否|String| 创建时间 结束时间|
|type|否|String| 导出 3 整单导出 , 1 明细导出|
|pageIndex|否|Integer| 页号|
|pageSize|否|Integer| 页大小|

###请求参数Json格式
 
```
{
 "tokenId" : "String",
 "id" : 0,
 "sword" : "String",
 "whsIds" : null,
 "mitemDisassemblyTypeCodes" : null,
 "beginDate" : "String",
 "endDate" : "String",
 "type" : "String",
 "pageIndex" : 0,
 "pageSize" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String"
}
```
