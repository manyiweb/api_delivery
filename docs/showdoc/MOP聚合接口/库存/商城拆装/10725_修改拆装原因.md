# 修改拆装原因

**请求URL：** 
- `/product/mitemDisassembly/reason/modify`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|mitemDisassemblyId|是|Long| 拆装单ID|
|reason|是|String| 拆装原因|

### 请求参数Json格式
 
```
{
 "mitemDisassemblyId" : 0,
 "reason" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
