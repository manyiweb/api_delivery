# 获取商户仓库
 

**请求URL：** 
- `/product/warehouse/default `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 商户ID，如果传空则返回登录商户的默认仓|
|tokenId|否|String| token标识|

###请求参数Json格式
 
```
{
 "companyId" : "String",
 "tokenId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|String||
|--companyId|否|String| 门店商户ID，与商户表syscompany相关联|
|--whsCode|否|String| 仓库编码|
|--whsName|否|String| 仓库名称|
|--typeCode|否|String| 类型 G总部仓 C门店仓|
|--typeName|否|String| 类型 G总部仓 C门店仓|
|--isBatch|否|Integer| 是否启用批次，1是 0否|
|--isUniqueCode|否|Integer| 是否启用唯一码，1是 0否|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : {
 "id" : "String",
 "companyId" : "String",
 "whsCode" : "String",
 "whsName" : "String",
 "typeCode" : "String",
 "typeName" : "String",
 "isBatch" : 0,
 "isUniqueCode" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
