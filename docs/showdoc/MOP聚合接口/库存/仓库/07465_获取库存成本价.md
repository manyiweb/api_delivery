# 获取库存成本价

**请求URL：** 
- `/warehouse/stock/getItemStockCostPrice `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 门店id|
|specIds|否|List| 规格id|

###请求参数Json格式
 
```
{
 "companyId" : "String",
 "specIds" : null
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--companyId|否|String| 门店id|
|--specId|否|String| 规格id|
|--costPrice|否|Double| 成本价|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


###返回参数Json格式
 
```
{
 "data" : [{
 "companyId" : "String",
 "specId" : "String",
 "costPrice" : 0
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
