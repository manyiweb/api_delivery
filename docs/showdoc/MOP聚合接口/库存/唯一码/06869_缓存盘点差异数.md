# 缓存盘点差异数

**请求URL：** 
- `/product/doc/barcodes/halfway/difference/cache`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|String| 盘点单id|
|barcodes|否|List| 唯一码|
|command|是|String| 执行类型 cache:更新缓存 clear：清空缓存 |

### 请求参数Json格式
 
```
{
 "id" : "String",
 "barcodes" : null,
 "command" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
