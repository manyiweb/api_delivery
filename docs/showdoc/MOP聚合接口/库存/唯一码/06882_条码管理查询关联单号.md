# 条码管理关联id

**请求URL：** 
- `/product/itembarcode/list`

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|barcodeId|否|String| 唯一码id|

###请求参数Json格式
 
```
{
 "barcodeId" : "String",
}
```


### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--recordId|否|String||
|--docId|否|String| 关联订单id|
|--docNo|否|String| 关联单号|
|--docType|否|String| 关联单号类型|
|--docTypeName|否|String| 关联单号类型名称|
|--barcode|否|String| 唯一码|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "recordId" : "String",
 "docId" : "String",
 "docNo" : "String",
 "docType" : "String",
 "docTypeName" : "String",
 "barcode" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
