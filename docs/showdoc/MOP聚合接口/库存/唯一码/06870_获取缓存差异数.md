# 获取缓存差异数

**请求URL：** 
- `/product/get/cache/doc/barcodes/halfway/difference`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|String| 盘点单id|
|docItemId|是|String| 盘点单商品详情id|

### 请求参数Json格式
 
```
{
 "id" : "String",
 "docItemId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--barcode|否|String| 唯一码|
|--skuBarcode|否|String| sku码|
|--differenceNum|否|Integer| 差异数|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "barcode" : "String",
 "skuBarcode" : "String",
 "differenceNum" : 0
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
