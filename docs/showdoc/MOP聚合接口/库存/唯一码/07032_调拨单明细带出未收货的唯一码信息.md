# 调拨单明细带出未收货的唯一码信息

**请求URL：** 
- `/product/doc/barcodes/final`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|docId|否|String| 单据id|
|docItemId|否|String| 明细id|

### 请求参数Json格式
 
```
{
 "docId" : "String",
 "docItemId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|barcode|否|String| 唯一码|
|attachBarcode|否|String| 唯一码附加码|
|costPrice|否|Double||
|skuBarcode|否|String| sku码|


### 返回参数Json格式
 
```
{
 "barcode" : "String",
 "attachBarcode" : "String",
 "costPrice" : 0,
 "skuBarcode" : "String"
}
```
