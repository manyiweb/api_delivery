# 获取在仓库的唯一码
 

**请求URL：** 
- `/product/barcode/stock/barcodes `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|whsId|否|String| 仓库id|
|specId|否|String| 商品规格id|

###请求参数Json格式
 
```
{
 "whsId" : "String",
 "specId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--barcode|否|String| 商品唯一码|
|--attachBarcode|否|String| 唯一码附加码|
|msg|否|String| 消息|
|code|否|String| 业务代码|


###返回参数Json格式
 
```
{
 "data" : [{
 "barcode" : "String",
 "attachBarcode" : "String"
 }],
 "msg" : "String",
 "code" : "String"
}
```
