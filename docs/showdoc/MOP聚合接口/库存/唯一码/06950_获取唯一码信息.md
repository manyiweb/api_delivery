# 获取唯一码信息
 

**请求URL：** 
- `/product/doc/barcodes `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|docId|否|String| 订单id|
|docItemId|否|String| 订单商品明细id|
|isYT|否|int| 1 - 采购收货单查看已退唯一码, 2 - 销售单查看已退唯一码,3 - 销售订单已提唯一码,4 - 提货单已退唯一码 5调拨发货唯一码，6调拨 收货唯一码, 7 采购单 已收数量，8 出库|

###请求参数Json格式
 
```
{
 "docId" : "String",
 "docItemId" : "String"
 "isYT" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--barcode|否|String| 商品唯一码|
|--attachBarcode|否|String| 唯一码附加码|
|msg|否|String| 消息|
|code|否|String| 业务代码|


###返回参数Json格式
 
```
{
 "data" : [{
 "barcode" : "String",
 "attachBarcode" : "String"
 }],
 "msg" : "String",
 "code" : "String"
}
```
