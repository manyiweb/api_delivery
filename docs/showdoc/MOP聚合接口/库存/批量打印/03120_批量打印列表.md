# 批量打印列表

**请求URL：** 
- `/product/print/batch/list `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|typeCode|否|String| 打印单据类型：WhsOut("出库单"), WhsOutPicking("拣配单")|
|printStatus|否|Integer| 打印状态：0未打印，1已打印|
|whsOutTypeCode|否|String| 出库单据类型：CK001("调拨发货出库"),CK002("其他出库"),CK007("采购退货出库"),CK009("订货发货出库")|
|beginDate|否|String| 开始时间|
|endDate|否|String| 结束时间|
|sword|否|String| 搜素关键字|
|searchBeans|否|List| 高级筛选条件|
|merchantsAreafCodes|否|List| 所属区域|
|tokenId|否|String| tokenId|
|pageIndex|否|Integer| 页号|
|pageSize|否|Integer| 页大小|
|orderField|否|String| 商品排序字段|
|orderSort|否|String| 商品排序方式 desc 倒序 asc 正序|

###请求参数Json格式
 
```
{
 "typeCode" : "String",
 "printStatus" : 0,
 "beginDate" : "String",
 "endDate" : "String",
 "whsOutTypeCode" : "String",
 "sword" : "String",
 "searchBeans" : null,
 "merchantsAreafCodes" : null,
 "tokenId" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--pageIndex|否|Integer| 页码|
|--pageSize|否|Integer| 显示记录数|
|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|--first|否|Boolean| 首页|
|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|
|----orderNo|否|String| 单据编码|
|----sourceNo|否|String| 关联单号(指生成该单据的上级单据编号)|
|----typeName|否|String| 单据类型|
|----status|否|String| 单据状态|
|----statusName|否|String| 状态名称|
|----quantity|否|Object| 数量|
|----whsName|否|String| 仓库名称|
|----inCompanyName|否|String| 下单商户|
|----remark|否|String| 备注|
|----createName|否|String| 创建人名称|
|----createDate|否|String| 创建时间|
|----printDate|否|String| 上一次打印时间|
|----printStatus|否|Integer| 打印状态 0未打印，1已打印|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
