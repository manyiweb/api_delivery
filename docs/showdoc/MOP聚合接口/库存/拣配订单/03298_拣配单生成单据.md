# 手机端（店务助手，拣配助手） - 拣配单生成单据

**请求URL：** 
- `/warehouse/picking/mobile/create/order `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|whsOutId|否|String| 拣配单ID|
|pickTypeCode|否|String| 拣配类型编码 WhsIn("拣配入库"), WhsOut("拣配出库")|
|whsOutTypeCode|否|String| 出库类型编码 CK004("提货配送出库"),CK010("订货退货出库")|
|logisticsProvidersNo|否|String| 物流商编码（有变更时需传）|
|logisticsName|否|String| 物流名称（有变更时需传）|
|logisticsNumber|否|String| 物流单号|
|pickOrderItems|否|List| 拣配单明细|
|--itemId|否|String| 商品ID|
|--itemCode|否|String| 商品ID|
|--quantity|否|Double| 数量|
|--specId|否|String| 规格ID|
|--skuBarcode|否|String| sku码|
|--unit|否|String| 单位|
|--orderItemId|否|String| 原单明细Id|
|--barcodeList|否|List| 唯一码列表|
|----attachBarcode|否|String| 唯一码附加码|
|----barcode|否|String| 唯一码|
|--barcodes|否|List||
|--batchList|否|List| 批次信息|
|----batchCode|否|String| 批次号|
|----quantity|否|Double| 数量|
|----productionDate|否|DateTime| 生产日期|
|--itemUnit|否|String| 单位组单位|
|--itemQuantity|否|Double| 单位组单位数量|
|--unitRate|否|Double| 换算率|
|--unitGroupId|否|Long| 单位组标识|
|--unitGroupName|否|String| 单位组名称|
|--remark|否|String| 备注|

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
