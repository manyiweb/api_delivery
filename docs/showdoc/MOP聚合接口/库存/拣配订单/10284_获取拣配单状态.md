# 获取拣配单状态

**请求URL：** 
- `/api/b2b/picking/status/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|whsOutId|否|String| 拣配单id|

### 请求参数Json格式
 
```
{
 "whsOutId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--pickingStatus|否|String| 拣配状态 编码|
|--pickingStatusName|否|String| 拣配状态 名称|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "pickingStatus" : "String",
 "pickingStatusName" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
