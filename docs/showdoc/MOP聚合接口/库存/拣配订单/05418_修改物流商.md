# 修改拣配订单物流商信息

**请求URL：** 
- `/product/picking/logistics/update`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|whsOutId|是|String| 拣配单ID|
|logisticsNumber|否|String| 物流单号|
|logisticsName|否|String| 物流名称|
|logisticsProviders|否|String| 物流商Id|

### 请求参数Json格式
 
```
{
 "whsOutId" : "String",
 "logisticsNumber" : "String",
 "logisticsName" : "String",
 "logisticsProviders" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
