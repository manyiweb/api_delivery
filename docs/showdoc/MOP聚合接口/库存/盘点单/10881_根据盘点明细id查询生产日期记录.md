# 根据盘点明细id查询生产日期记录

**请求URL：** 
- `/inventory/check/checkvouch/productionDate/list`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|ckvItemId|是|String| 盘点明细id|

### 请求参数Json格式
 
```
{
 "ckvItemId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--id|否|Long| 记录id|
|--ckvItemId|否|String| 盘点明细id|
|--batchCode|否|String| 批次号|
|--productionDate|否|DateTime| 生产日期|
|--quantity|否|Double| 数量|
|--lineNum|否|Integer| 行号|
|--createDate|否|DateTime| 创建时间|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "id" : 0,
 "ckvItemId" : "String",
 "batchCode" : "String",
 "productionDate" : "DateTime",
 "quantity" : 0,
 "lineNum" : 0,
 "createDate" : "DateTime"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
