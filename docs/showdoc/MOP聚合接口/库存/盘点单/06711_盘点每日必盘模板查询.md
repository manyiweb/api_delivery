# 盘点每日必盘模板查询

**请求URL：** 
- `/config/checkvouch/set/inventory/handover/list`

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 商户ID|

###请求参数Json格式
 
```
{
 "companyId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|templateName|否|String| 模板名称|
|id|否|String| 模板列表行id|
|inventoryId|否|String| 模板id|
