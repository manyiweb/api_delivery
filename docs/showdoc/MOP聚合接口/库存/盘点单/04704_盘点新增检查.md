# 盘点新增检查

**请求URL：** 
- `/config/checkvouch/set/addCheck`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String||

### 请求参数Json格式
 
```
{
 "companyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--isAllowAdd|否|Boolean| 允许新建|
|--companyName|否|String||
|--errorList|否|List| 错误信息|
|--errorOrders|否|List| 异常订单|
|----orderId|否|String| 订单id|
|----orderNo|否|String| 订单号|
|----orderStatus|否|String| 订单状态|
|----orderStatusName|否|String| 订单状态名称|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "isAllowAdd" : true,
 "companyName" : "String",
 "errorList" : null,
 "errorOrders" : [{
 "orderId" : "String",
 "orderNo" : "String",
 "orderStatus" : "String",
 "orderStatusName" : "String"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
