# 模板导入生成盘点单
 

**请求URL：** 
- `/inventory/check/checkvouch/checkvouch/exceladd`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|importType|否|Integer| 导入类型 1 根据导入、2 根据模板，默认根据导入 3根据类型|
|inventoryId|否|String| 模板id|
|docType|否|String| 单据类型|
|checkType|否|String| 盘点类型|
|itemCategorys|否|List| 品牌系列分类列表|
|--id|否|String| 品牌 分类 系列名称|
|--name|否|String| 名称|
|--code|否|String| 编码|
|--type|否|String| 类型 1系列2品牌3分类|
|whsCodes|否|List||
|isMoreThan0|否|Integer||
|tokenId|否|String||
|file|是|Object||

### 请求参数Json格式
 
```
{
 "importType" : 0,
 "inventoryId" : "String",
 "docType" : "String",
 "checkType" : "String",
 "itemCategorys" : [{
 "id" : "String",
 "name" : "String",
 "code" : "String",
 "type" : "String"
 }],
 "whsCodes" : null,
 "isMoreThan0" : 0,
 "tokenId" : "String",
 "file" : null
}
```
