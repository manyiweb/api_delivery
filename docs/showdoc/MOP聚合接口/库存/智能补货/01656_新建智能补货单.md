# 新建智能补货单
 

**请求URL：** 
- `/product/smartReplenishment/add`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|
|tokenId|否|String| token|
|programName|是|String| 方案名称|
|pickingWarehouseWhsId|否|String| 配货总仓id|
|replenishmentType|否|Integer| 补货方式 0 - 按自定义商品数量补货, 1 - 按商品安全库存上限补货, 2 - 按商品的安全库存周期补货, 3 - 按商品陈列量|
|oldReplenishmentType|否|Integer| 旧的补货方式 用于商户前台所有逻辑走自定义商品补货|
|isAllComp|否|Integer| 是否应用所有商户 0 - 指定商户, 1 - 所有商户|
|designatedItemType|否|List| 指定商品分类|
|--code|否|String| code|
|--name|否|String| name|
|designatedItemSeries|否|List| 指定商品系列|
|--code|否|String| code|
|--name|否|String| name|
|designatedItemBrand|否|List| 指定商品品牌|
|--code|否|String| code|
|--name|否|String| name|
|designatedItemSupplier|否|List| 指定商品首选供应商|
|--code|否|String| code|
|--name|否|String| name|
|stockConditions|否|Integer| 指定库存条件 0 - 小于等于0 , 1 - 小于最小安全库存数, 2 - 小于最大安全库存数|
|remark|否|String| 补货说明|
|proposalToGenerateOrder|否|Integer| 建议生成单据 0 - 商品调拨单, 1 - 商品要货单, 2 - 采购订单, 3-订货订单|
|allCompAvgDaySold|否|Integer|所有门店：前N天的平均销量|
|b2bOrderDocTypeName|否|Integer| 订货功能类型：|
|comps|否|List| 指定商户|
|--companyId|是|String| 商户id|
|--companyName|否|String| 商户名称|
|--avgDaySold|否|Integ| 前N天的平均销量|
|items|否|List| 指定商品|
|--itemId|是|String| 商品id|
|--specId|是|String| 规格id|
|--itemName|否|String| 商品名称|
|--itemCode|否|String| 商品名称|
|--skuBarcode|否|String| sku|
|--quantity|否|Double| 补货数量|
|ntypeCode|否|String| 单据类型编码|
|orderTypeId|否|String| 要货单类型Id|
|ntypeName|否|String| 单据类型描述|
|arrivalDate|否|String| 到货日期|
|buildType|否|Integer| 创建执行类型(0立即执行,1指定时间,2循环执行)|
|buildParams|否|String| 创建参数|
|beginDate|否|String| 发送有效期起|
|endDate|否|String| 发送有效期至|
|assignSendDate|否|String| 发送日期|
|assignSendTiem|否|String| 发送时间|
|cycleType|否|Integer| 循环类型(0每月 1每周 2每日)|
|cycleWeek|否|String| 星期几(cycle_type=1) 1,2,3,4,5|
|cycleDay|否|String| 几号(cycle_type=0) 1,2,3,4,5|
|isSendWhsAutoPick|否|Integer| 启用按发货仓的可用量自动补货 （0否，1是）|
|reasonId|否|String| 调拨原因id（app_code表id）|
|reason|否|String| 调拨原因|
|itemSupplierType|否|Integer| 商品设置供应商类型 0商品默认,1商户商品默认|
