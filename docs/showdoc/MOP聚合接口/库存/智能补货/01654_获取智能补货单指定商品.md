# 获取智能补货单指定商品
 

**请求URL：** 
- `/product/smartReplenishment/list/item `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 智能补货单id|
|sword|否|String| 搜索关键字 支持搜索商品编码/商品名称/商品sku|
|pageIndex|否|Integer| 页号|
|pageSize|否|Integer| 页大小|

###请求参数Json格式
 
```
{
 "id" : 0,
 "sword" : "String",
 "pageIndex" : 0,
 "pageSize" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--pageIndex|否|Integer| 页码|
|--pageSize|否|Integer| 显示记录数|
|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|--first|否|Boolean| 首页|
|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|
|----itemId|否|String| 商品id|
|----specId|否|String| 商品规格id|
|----itemCode|否|String| 商品编码|
|----itemName|否|String| 商品名称|
|----specName|否|String| 商品规格名称|
|----skubarcode|否|String| sku码|
|----unit|否|String| 单位|
|----quantity|否|Double| 补货数量|
|----salePrice|否|Double| 零售价|
|----lineTotal|否|Double| 行小计|
|msg|否|String| 消息|
|code|否|String| 业务代码|


###返回参数Json格式
 
```
{
 "data" : {
 "pageIndex" : 0,
 "pageSize" : 0,
 "pageCount" : 0,
 "totalCount" : 0,
 "first" : true,
 "last" : true,
 "content" : [{
 "itemId" : "String",
 "specId" : "String",
 "itemCode" : "String",
 "itemName" : "String",
 "specName" : "String",
 "skubarcode" : "String",
 "unit" : "String",
 "quantity" : 0,
 "salePrice" : 0,
 "lineTotal" : 0
 }]
 },
 "msg" : "String",
 "code" : "String"
}
```
