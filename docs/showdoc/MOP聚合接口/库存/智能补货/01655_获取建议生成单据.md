# 获取建议生成单据
 

**请求URL：** 
- `/mct/product/smartReplenishment/list/detail `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|否|String| token|
|id|否|Long| 智能补货单id|
|pageIndex|否|Integer| 页号|
|pageSize|否|Integer| 页大小|

###请求参数Json格式
 
```
{
 "tokenId" : "String",
 "id" : 0,
 "pageIndex" : 0,
 "pageSize" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--pageIndex|否|Integer| 页码|
|--pageSize|否|Integer| 显示记录数|
|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|--first|否|Boolean| 首页|
|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|
|----orderId|否|String| 单据id|
|----orderNo|否|String| 订单编号|
|----typeName|否|String| 单据类型|
|----statusName|否|String| 单据状态|
|----outWhsName|否|String| 从仓库|
|----inWhsName|否|String| 到仓库|
|----whsName|否|String| 要货仓库 (要货单)|
|----totalQuantity|否|Double| 数量|
|----createName|否|String| 创建人|
|----createDate|否|DateTime| 创建时间|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : {
 "pageIndex" : 0,
 "pageSize" : 0,
 "pageCount" : 0,
 "totalCount" : 0,
 "first" : true,
 "last" : true,
 "content" : [{
 "orderId" : "String",
 "orderNo" : "String",
 "typeName" : "String",
 "statusName" : "String",
 "outWhsName" : "String",
 "inWhsName" : "String",
 "whsName" : "String",
 "totalQuantity" : 0,
 "createName" : "String",
 "createDate" : "DateTime"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
