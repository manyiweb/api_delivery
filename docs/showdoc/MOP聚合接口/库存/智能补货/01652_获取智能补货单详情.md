# 获取智能补货单详情
 

**请求URL：** 
- `/product/smartReplenishment/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|否|String| token|
|id|是|Long| 智能补货单id|

### 请求参数Json格式
 
```
{
 "tokenId" : "String",
 "id" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long||
|--smartReplenishmentNo|否|String| 智能补货单单号|
|--programName|否|String| 方案名称|
|--pickingWarehouseName|否|String| 配货总仓|
|--pickingWarehouseWhsId|否|String| 配货总仓id|
|--nTypeCode|否|String|	要货单单据类型编码 门店001,分销002,追加003,外进品004,直营调拨ZYDB|
|--nTypeName|否|String| 要货单单据类型描述|
|--replenishmentType|否|Integer| 补货方式 0 - 按自定义商品数量补货, 1 - 按商品安全库存上限补货, 2 - 按商品的安全库存周期补货, 3 - 按商品陈列量|
|--isAllComp|否|Integer| 是否应用所有商户 0 - 指定商户, 1 - 所有商户|
|--designatedItemTypeList|否|List| 指定商品分类|
|----code|否|String| code|
|----name|否|String| name|
|--designatedItemSeriesList|否|List| 指定商品系列|
|----code|否|String| code|
|----name|否|String| name|
|--designatedItemBrandList|否|List| 指定商品品牌|
|----code|否|String| code|
|----name|否|String| name|
|--designatedItemSupplierList|否|List| 指定商品首选供应商|
|----code|否|String| code|
|----name|否|String| name|
|--stockConditions|否|Integer| 指定库存条件 0 - 小于等于0 , 1 - 小于最小安全库存数, 2 - 小于最大安全库存数|
|--proposalToGenerateOrder|否|Integer| 建议生成单据 0 - 商品调拨单, 1 - 商品要货单, 2 - 订货订单|
|--remark|否|String| 补货说明|
|--createName|否|String| 创建人|
|--createDate|否|DateTime| 创建时间|
|--itemQty|否|Integer| 商品种数|
|--totalQuantity|否|Double| 补货数量|
|--totalMoney|否|Double| 总计|
|--buildType|否|Integer| 创建执行类型(0立即执行,1指定时间,2循环执行)|
|--beginDate|否|DateTime| 发送有效期起|
|--endDate|否|DateTime| 发送有效期至|
|--assignSendDate|否|DateTime| 发送日期|
|--assignSendTiem|否|String| 发送时间|
|--cycleType|否|Integer| 循环类型(0每月 1每周 2每日)|
|--cycleWeek|否|String| 星期几(cycle_type=1) 1,2,3,4,5|
|--cycleDay|否|String| 几号(cycle_type=0) 1,2,3,4,5|
|--statusCode|否|Integer| 运行状态编码 0已完成、1已计划、2执行中、3已取消|
|--statusName|否|String| 运行状态名称|
|--reasonId|否|String| 调拨原因id（app_code表id）|
|--reason|否|String| 调拨原因|
|--isSendWhsAutoPick|否|Integer| 启用按发货仓的可用量自动补货 （0否，1是）|
|--allCompAvgDaySold|否|Integer| 所有门店：前N天的平均销量(天数)|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|
