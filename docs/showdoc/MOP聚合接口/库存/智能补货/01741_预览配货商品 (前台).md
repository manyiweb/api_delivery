# 预览配货商品
 

**请求URL：** 
- `/product/smartReplenishment/preview `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|否|String| token|
|replenishmentType|否|Integer| 补货方式|
|stockConditions|否|Integer| 指定库存条件 0 - 小于等于0 , 1 - 小于最小安全库存数, 2 - 小于最大安全库存数|
|designatedItemType|否|List| 指定商品分类|
|--code|否|String| code|
|--name|否|String| name|
|designatedItemSeries|否|List| 指定商品系列|
|--code|否|String| code|
|--name|否|String| name|
|designatedItemBrand|否|List| 指定商品品牌|
|--code|否|String| code|
|--name|否|String| name|
|designatedItemSupplier|否|List| 指定商品首选供应商|
|--code|否|String| code|
|--name|否|String| name|
|pageIndex|否|Integer| 页号|
|pageSize|否|Integer| 页大小|

###请求参数Json格式
 
```
{
 "tokenId" : "String",
 "replenishmentType" : 0,
 "stockConditions" : 0,
 "designatedItemType" : [{
 "code" : "String",
 "name" : "String"
 }],
 "designatedItemSeries" : [{
 "code" : "String",
 "name" : "String"
 }],
 "designatedItemBrand" : [{
 "code" : "String",
 "name" : "String"
 }],
 "designatedItemSupplier" : [{
 "code" : "String",
 "name" : "String"
 }],
 "pageIndex" : 0,
 "pageSize" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--itemId|否|String| 商品id|
|--specId|否|String| 规格id|
|--itemCode|否|String| 商品编码|
|--itemName|否|String| 商品名称|
|--specName|否|String| 商品规格名称|
|--skubarcode|否|String| sku码|
|--quantity|否|Double| 单位|
|--unit|否|String| 单位|
|--specPrice|否|Double| 建议零售价|
|--onHandQty|否|Double| 库存|
|--minSafeQty|否|Double| 最小安全库存|
|--maxSafeQty|否|Double| 最大安全库存|
|--safetyCycleDay|否|Integer| 最大安全库存|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
