# 预览配货商品
 

**请求URL：** 
- `/product/smartReplenishment/preview `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|designatedItemType|否|List| 指定商品分类|
|--code|否|String| code|
|--name|否|String| name|
|designatedItemSeries|否|List| 指定商品系列|
|--code|否|String| code|
|--name|否|String| name|
|designatedItemBrand|否|List| 指定商品品牌|
|--code|否|String| code|
|--name|否|String| name|
|designatedItemSupplier|否|List| 指定商品首选供应商|
|--code|否|String| code|
|--name|否|String| name|
|pageIndex|否|Integer| 页号|
|pageSize|否|Integer| 页大小|

###请求参数Json格式
 
```
{
 "designatedItemType" : [{
 "code" : "String",
 "name" : "String"
 }],
 "designatedItemSeries" : [{
 "code" : "String",
 "name" : "String"
 }],
 "designatedItemBrand" : [{
 "code" : "String",
 "name" : "String"
 }],
 "designatedItemSupplier" : [{
 "code" : "String",
 "name" : "String"
 }],
 "pageIndex" : 0,
 "pageSize" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--pageIndex|否|Integer| 页码|
|--pageSize|否|Integer| 显示记录数|
|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|--first|否|Boolean| 首页|
|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|
|----itemCode|否|String| 商品编码|
|----itemName|否|String| 商品名称|
|----specName|否|String| 商品规格名称|
|----skubarcode|否|String| sku码|
|msg|否|String| 消息|
|code|否|String| 业务代码|


###返回参数Json格式
 
```
{
 "data" : {
 "pageIndex" : 0,
 "pageSize" : 0,
 "pageCount" : 0,
 "totalCount" : 0,
 "first" : true,
 "last" : true,
 "content" : [{
 "itemCode" : "String",
 "itemName" : "String",
 "specName" : "String",
 "skubarcode" : "String"
 }]
 },
 "msg" : "String",
 "code" : "String"
}
```
