# 出库单批次补录唯一码

**请求URL：** 
- `/warehouse/createBatchBarcodeByOutbount `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|whsOutId|否|String| 出库单ID|
|docItemId|否|String| 出库单明细行ID|
|batchCode|否|String| 批次编码|
|addBarcodeList|否|List| 唯一码列表|
|--barcode|否|String| 唯一码|
|delBarcodeList|否|List| 唯一码列表|
|--barcode|否|String| 唯一码|

###请求参数Json格式
 
```
{
 "whsOutId" : "String",
 "docItemId" : "String",
 "batchCode" : "String",
 "addBarcodeList" : [{
 "barcode" : "String"
 }],
 "delBarcodeList" : [{
 "barcode" : "String"
 }]
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
