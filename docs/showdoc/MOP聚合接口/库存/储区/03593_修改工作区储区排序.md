# 修改工作区储区排序

**请求URL：** 
- `/warehouse/mlogiWhsStorArea/updateWorkAreaSn `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|workAreaId|是|Long| 工作区id|
|storAreaIdList|是|List| 储区id集合|

###请求参数Json格式
 
```
{
 "workAreaId" : 0,
 "storAreaIdList" : null
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|String| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : "String",
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
