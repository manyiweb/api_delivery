# 储区详情

**请求URL：** 
- `/warehouse/mlogiWhsStorArea/info `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long| id|

###请求参数Json格式
 
```
{
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long| id|
|--storAreaId|否|Long| 储区ID|
|--mlogiWhsId|否|Long| 物流仓库ID|
|--logiWhsName|否|String| 物流仓名称|
|--logiWhsAreaId|否|Long| 物流仓库区域ID|
|--areaName|否|String| 仓区名称|
|--workAreaId|否|Long| 工作区id|
|--workAreaName|否|String| 工作区名称|
|--workAreaCode|否|String| 工作区编码|
|--storeAreaCode|否|String| 储区编码|
|--storeAreaName|否|String| 储区名称|
|--storeAreType|否|Integer| 储区类型;1:收货, 2:发货, 3:存货, 4:虚拟, 5:其它|
|--storeAreTypeName|否|String| 储区类型名|
|--shelvesTypeId|否|Long| 货架类型id|
|--shelvesTypeName|否|String| 货架类型名称|
|--putOnLineType|否|Integer| 上架路径类型;1:M型,2:逆向M型,3:S型,4:逆向S型|
|--putOnLineTypeName|否|String| 上架路径类型名|
|--pickingLineType|否|Integer| 拣货路径类型;1:M型,2:逆向M型,3:S型,4:逆向S型|
|--pickingLineTypeName|否|String| 拣货路径类型名|
|--isActive|否|Integer| 活跃状态 0停用1启用|
|--isActiveName|否|String| 活跃状态名|
|--remark|否|String| 备注|
|--createName|否|String| 创建人|
|--createDate|否|DateTime| 创建时间|
|--modifyName|否|String| 修改人|
|--modifyDate|否|DateTime| 修改时间|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
