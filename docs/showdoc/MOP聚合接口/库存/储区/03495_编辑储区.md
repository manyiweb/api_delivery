# 编辑储区

**请求URL：** 
- `/warehouse/mlogiWhsStorArea/update `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long| id|
|mlogiWhsId|是|Long| 物流仓库id|
|logiWhsAreaId|是|Long| 物流仓库区域id|
|workAreaId|是|Long| 工作区id|
|storeAreaCode|是|String| 储区编码|
|storeAreaName|是|String| 储区名称|
|storeAreType|是|Integer| 储区类型|
|shelvesTypeId|是|Long| 货架类型id|
|putOnLineType|是|Integer| 上架路径类型|
|pickingLineType|是|Integer| 拣货路径类型|
|isActive|是|Integer| 活跃状态 0停用1启用|
|remark|否|String| 备注|

###请求参数Json格式
 
```
{
 "id" : 0,
 "mlogiWhsId" : 0,
 "logiWhsAreaId" : 0,
 "workAreaId" : 0,
 "storeAreaCode" : "String",
 "storeAreaName" : "String",
 "storeAreType" : 0,
 "shelvesTypeId" : 0,
 "putOnLineType" : 0,
 "pickingLineType" : 0,
 "isActive" : 0,
 "remark" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Long| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : 0,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
