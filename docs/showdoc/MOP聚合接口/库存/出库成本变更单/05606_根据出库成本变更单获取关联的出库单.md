# 根据出库成本变更单获取关联的出库单
 

**请求URL：** 
- `/warehouse/outcostchangeitem/getOutByChangeItem `

**请求方式：**
- ALL
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 货主商户id|
|changeStartDate|否|DateTime| 变更单据开始时间|
|changeEndDate|否|DateTime| 变更单据结束时间|
|itemId|否|String| 商品id|
|specId|否|String| 规格id|

###请求参数Json格式
 
```
{
 "companyId" : "String",
 "changeStartDate" : "DateTime",
 "changeEndDate" : "DateTime",
 "itemId" : "String",
 "specId" : "String"
}
```
