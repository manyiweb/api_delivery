# 出库成本变更单详情页
 

**请求URL：** 
- `/warehouse/outCostChange/info `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|

###请求参数Json格式
 
```
{
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long| 主键|
|--outCostChangeNo|否|String| 出库成本变更单号|
|--companyId|否|String| 货主商户id|
|--companyName|否|String| 货主商户名|
|--changeStartDate|否|DateTime| 变更单据开始时间|
|--changeEndDate|否|DateTime| 变更单据结束时间|
|--changeStatus|否|Integer| 变更单状态;1:已完成|
|--changeStatusName|否|String| 变更单状态名称|
|--remark|否|String| 备注|
|--createId|否|String| 创建人id|
|--createName|否|String| 创建人|
|--createDate|否|DateTime| 创建时间|
|--modifyId|否|String| 修改人id|
|--modifyName|否|String| 修改人|
|--modifyDate|否|DateTime| 修改时间|
|--dbKey|否|Integer| 分库标识|
|--groupId|否|String| 品牌商id|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
