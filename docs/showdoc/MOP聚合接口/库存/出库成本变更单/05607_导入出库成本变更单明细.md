# 导入出库成本变更单明细
 

**请求URL：** 
- `/warehouse/outcostchangeitem/import `

**请求方式：**
- POST
- FormData


###请求参数<业务参数>
 
无参数


###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--totalCount|否|Integer| 导入总数量|
|--successCount|否|Integer| 成功导入数量|
|--errorCount|否|Integer| 失败数|
|--downloadURL|否|String| 失败数据下载地址|
|--errorList|否|List| 失败记录|
|--successList|否|List| 成功记录|
|--dataJson|否|List| 兼容前端旧|
|--totalCountSheet1|否|Integer| 成功导入数量|
|--totalCountSheet2|否|Integer||
|--totalCountSheet3|否|Integer||
|--errorCountSheet1|否|Integer| 失败数|
|--errorCountSheet2|否|Integer||
|--errorCountSheet3|否|Integer||
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "totalCount" : 0,
 "successCount" : 0,
 "errorCount" : 0,
 "downloadURL" : "String",
 "errorList" : null,
 "successList" : null,
 "dataJson" : null,
 "totalCountSheet1" : 0,
 "totalCountSheet2" : 0,
 "totalCountSheet3" : 0,
 "errorCountSheet1" : 0,
 "errorCountSheet2" : 0,
 "errorCountSheet3" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
