# 新增出库成本变更单
 

**请求URL：** 
- `/warehouse/outCostChange/add `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 主键|
|outCostChangeNo|否|String| 出库成本变更单号|
|companyId|否|String| 货主商户id|
|companyName|否|String| 货主商户名|
|changeStartDate|否|DateTime| 变更单据开始时间|
|changeEndDate|否|DateTime| 变更单据结束时间|
|changeStatus|否|Integer| 变更单状态;1:已完成|
|changeStatusName|否|String| 变更单状态名称|
|remark|否|String| 备注|
|outCostChangeItems|否|List| 明细|
|--id|否|Long| 主键|
|--outCostChangeId|否|Long| 出库成本变更单主键|
|--itemId|否|String| 商品id|
|--specId|否|String| 规格id|
|--changeCostPrice|否|Double| 变更成本价|

###请求参数Json格式
 
```
{
 "id" : 0,
 "outCostChangeNo" : "String",
 "companyId" : "String",
 "companyName" : "String",
 "changeStartDate" : "DateTime",
 "changeEndDate" : "DateTime",
 "changeStatus" : 0,
 "changeStatusName" : "String",
 "remark" : "String",
 "outCostChangeItems" : [{
 "id" : 0,
 "outCostChangeId" : 0,
 "itemId" : "String",
 "specId" : "String",
 "changeCostPrice" : 0
 }]
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Boolean| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : true,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
