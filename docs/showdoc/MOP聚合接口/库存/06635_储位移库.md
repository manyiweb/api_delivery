# 储位移库

**请求URL：** 
- `/warehouse/multistorelocation/storelocation/relocate`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|warehouseId|是|Long| 物流仓ID|
|remark|否|String| 备注|
|lines|是|List| 行明细|
|--itemId|是|String| 商品ID|
|--itemName|是|String| 商品名称|
|--specId|是|String| 规格ID|
|--itemUnit|是|String| 实际单位|
|--itemUnitQty|是|Double| 实际单位数量|
|--unitRate|是|Double| 单位转换率|
|--unit|是|String| 基本单位|
|--unitQty|是|Double| 基本单位数量|
|--fromStoreLocationId|是|Long| 从储位ID|
|--fromStoreLocationName|是|String| 从储位名称|
|--toStoreLocationId|是|Long| 到储位ID|
|--toStoreLocationName|是|String| 从储位名称|
|info|否|Object| 储位明细|
|--id|否|Long| 明细id 注意:新增不用传值|
|--outOrderNo|否|String| 外部单号|

### 请求参数Json格式
 
```
{
 "warehouseId" : 0,
 "remark" : "String",
 "lines" : [{
 "itemId" : "String",
 "itemName" : "String",
 "specId" : "String",
 "itemUnit" : "String",
 "itemUnitQty" : 0,
 "unitRate" : 0,
 "unit" : "String",
 "unitQty" : 0,
 "fromStoreLocationId" : 0,
 "fromStoreLocationName" : "String",
 "toStoreLocationId" : 0,
 "toStoreLocationName" : "String"
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
