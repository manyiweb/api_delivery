# 创建实体卡批量入库单
 

**请求URL：** 
- `/warehouse/createMentityWarehouseReceiptWithAccept`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|cardItemList|否|List| 批次信息|
|--itemId|是|String| 商品ID|
|--specId|是|String| 规格ID|
|--unit|是|String| 单位|
|--quantity|是|Double| 数量|
|--receiptItems|是|List| 入库单明细|
|----whsInId|否|String||
|----whsId|否|String| 仓库ID|
|----quantity|是|Double| 数量|
|--barcodeList|否|List| 唯一码列表|
|----attachBarcode|否|String| 唯一码附加码|
|----barcode|是|String| 唯一码|
|--cardName|是|String||
|source|是|Integer| 单据来源 1-中台 2-前台 3-店务助手 4-POS 5-WMS仓库系统|
|remark|否|String| 备注|
|whsInTypeCode|是|String| 入库类型编码|
|whsInTypeName|否|String| 入库类型名称|

### 请求参数Json格式
 
```
{
 "cardItemList" : [{
 "itemId" : "String",
 "specId" : "String",
 "unit" : "String",
 "quantity" : 0,
 "receiptItems" : [{
 "whsInId" : "String",
 "whsId" : "String",
 "quantity" : 0
 }],
 "barcodeList" : [{
 "attachBarcode" : "String",
 "barcode" : "String"
 }],
 "cardName" : "String"
 }],
 "source" : 0,
 "remark" : "String",
 "whsInTypeCode" : "String",
 "whsInTypeName" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
