# 验证实体卡商品唯一码
 

**请求URL：** 
- `/product/checkMentityCardProductUCode`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|barCodes|否|List| 唯一码集合|
|itemId|是|String| 商品id|
|specId|否|String| 规格id|
|docType|否|String| 类型|
|cardId|是|String| 实体卡id|
|cardName|是|String| 实体卡名称|
|whsId|否|String| 仓库id|

### 请求参数Json格式
 
```
{
 "barCodes" : null,
 "itemId" : "String",
 "specId" : "String",
 "docType" : "String",
 "cardId" : "String",
 "cardName" : "String",
 "whsId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--msg|否|String| 错误信息|
|--barcodes|否|List| 唯一码|
|--barcodeList|否|List| 唯一码实体集合|
|----barcode|否|String| 唯一码|
|----attachBarcode|否|String| 附加码|
|----costPrice|否|Double| 唯一码成本价|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : {
 "msg" : "String",
 "barcodes" : null,
 "barcodeList" : [{
 "barcode" : "String",
 "attachBarcode" : "String",
 "costPrice" : 0
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
