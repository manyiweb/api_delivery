# 创建入库单
 

**请求URL：** 
- `/warehouse/createWarehouseReceipt `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|whsInId|否|String||
|whsId|否|String| 仓库ID|
|whsInTypeCode|否|String| 入库类型编码|
|whsInTypeName|否|String| 入库类型名称|
|remark|否|String| 备注|
|sourceId|否|String| 来源ID|
|sourceType|否|String| 来源类型|
|sourceNo|否|String| 来源单号|
|outOrderNo|否|String| 外部单号|
|isAsyncUpdateStorage|否|Boolean| 是否异步更新库存数量|
|postingDate|否|DateTime| 过账日期|
|attachmentFileURLList|否|List| 入库单附件|
|receiptItems|否|List| 入库单明细|
|--itemId|否|String| 商品ID|
|--specId|否|String| 规格ID|
|--itemName|否|String| 商品名称|
|--unit|否|String| 单位|
|--quantity|否|Double| 数量|
|--orderItemId|否|String| 原单明细Id|
|--barcodeList|否|List| 唯一码列表|
|----attachBarcode|否|String| 唯一码附加码|
|----barcode|否|String| 唯一码|
|--batchList|否|List| 批次信息|
|----batchCode|否|String| 批次号|
|----quantity|否|Double| 数量|
|----productionDate|否|DateTime| 生产日期|
|--itemUnit|否|String| 单位组单位|
|--itemQuantity|否|Double| 单位组单位数量|
|--unitRate|否|Double| 换算率|
|--unitGroupId|否|Long| 单位组标识|
|--unitGroupName|否|String| 单位组名称|
|--remark|否|String| 行明细|
|--isFixedBomItem|否|Integer| 是否为固定BOM 1 - 是, 0 - 否|
|--isBomItem|否|Boolean| 是否为BOM|
|--processingType|否|Integer| 加工类型 0 - 倒冲, 1 - 手工|
|--bomId|否|String| BOM ID|
|--bomType|否|Integer| -1非bom 类型，取值：0 - 生产， 1 - 模板， 2 - 固定|
|--batchType|否|Integer| 批次管理类型，0出入库，1仅出库，2-自动出入库|
|--storeLocations|否|List| 储位及对应数量|
|----storeLocationId|否|Long| 储位ID|
|----storeLocationName|否|String| 储位名称|
|----itemUnit|否|String| 实际选择单位|
|----itemUnitQty|否|Double| 实际选择单位数量|
|----unitRate|否|Double| 单位转换率|
|----unit|否|String| 基本单位|
|----unitQty|否|Double| 基本单位数量|
|source|否|Integer| 单据来源 1-中台 2-前台 3-店务助手 4-POS 5-WMS仓库系统|
|sourceOrderType|否|Integer| 来源单据类型 -1 未知, 1 - 盘点|
|uniqueCodeScene|否|String| 唯一码场景类型
 |
|refundOrder|否|Boolean||
|msg|否|String| 错误信息 用于批量入库
 |
|salesman|否|String| 业务员|
