# 校验商品是否应用至此门店
 

**请求URL：** 
- `/warehouse/checkWarehouseReceiptIsAppointCompany `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|whsInId|否|String||
|whsId|否|String| 仓库ID|
|whsInTypeCode|否|String| 入库类型编码|
|remark|否|String| 备注|
|whsInStatus|否|String| 状态编码|
|postingDate|否|DateTime| 过账日期|
|attachmentFileURLList|否|List| 入库单附件|
|receiptItems|否|List| 入库单明细|
|--itemId|否|String| 商品ID|
|--specId|否|String| 规格ID|
|--unit|否|String| 单位|
|--quantity|否|Double| 数量|
|--barcodeList|否|List| 唯一码列表|
|----attachBarcode|否|String| 唯一码附加码|
|----barcode|否|String| 唯一码|
|--batchList|否|List| 批次信息|
|----batchCode|否|String| 批次号|
|----quantity|否|Double| 数量|
|----productionDate|否|DateTime| 生产日期|
|source|否|Integer| 单据来源 1-中台 2-前台 3-店务助手 4-POS|

###请求参数Json格式
 
```
{
 "whsInId" : "String",
 "whsId" : "String",
 "whsInTypeCode" : "String",
 "remark" : "String",
 "whsInStatus" : "String",
 "postingDate" : "DateTime",
 "attachmentFileURLList" : null,
 "receiptItems" : [{
 "itemId" : "String",
 "specId" : "String",
 "unit" : "String",
 "quantity" : 0,
 "barcodeList" : [{
 "attachBarcode" : "String",
 "barcode" : "String"
 }],
 "batchList" : [{
 "batchCode" : "String",
 "quantity" : 0,
 "productionDate" : "DateTime"
 }]
 }],
 "source" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|

 "success": true,

}
