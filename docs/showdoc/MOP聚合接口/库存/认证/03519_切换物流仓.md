# 切换品牌商

**请求URL：** 
- http://ht.reabam.com:50005/reabam-manage/app/Common/changeLoginWarehouse

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>

|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
