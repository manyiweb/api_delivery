# WMS用户登录

**请求URL：** 
- http://ht.reabam.com:50005/reabam-manage/app/Common/Login

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>

|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|mobile|true|string|登录账号，默认为用户手机号|
|loginWord|true|string|登录密码，需要MD5加密一次|
|loginType|false|string|登录来源，取值： guide - 店务助手、checkstand - 智慧收银台、 merchant - 商户前台、mgr - 管理助手、mgd - 运营中台, wms-仓库前台,wmspda-仓库助手|
|appType|false|string|登录来源设备，取值： phone_android - 安卓手机、pad_android - 安卓平板、phone_ios - 苹果手机、pad_ios - 苹果平板、pc - 电脑|
|appVersion|false|string|当前应用版本号|
