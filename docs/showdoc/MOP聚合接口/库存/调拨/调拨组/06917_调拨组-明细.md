# 调拨组-明细

**请求URL：** 
- `/product-front/allot/group/detail `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long||

###请求参数Json格式
 
```
{
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long| 主键|
|--allotGroupCode|否|String| 调拨组编码|
|--allotGroupName|否|String| 调拨组名称|
|--active|否|Boolean| 活跃状态 true活跃, false不活跃, 默认活跃|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


###返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "allotGroupCode" : "String",
 "allotGroupName" : "String",
 "active" : true
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
