# 上架策略详情

**请求URL：** 
- `/warehouse/mlogiWhsShelvesScript/info `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long| id|

###请求参数Json格式
 
```
{
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long| id|
|--scriptCode|否|String| 上架策略编码|
|--scriptName|否|String| 上架策略名|
|--mlogiWhsId|否|Long| 物流仓库id|
|--logiWhsName|否|String| 物流仓名称|
|--whsId|否|String| 商户仓库id|
|--whsName|否|String| 商户仓名称|
|--docCode|否|String| 单据类型|
|--docName|否|String| 单据名称|
|--optionName|否|String| 业务单据名称|
|--itemStatusId|否|Long| 商品状态id|
|--statusName|否|String| 商品状态名称|
|--containerTypeId|否|Long| 容器类型id|
|--containerTypeName|否|String| 容器类型名称|
|--remark|否|String| 备注|
|--createName|否|String| 创建人|
|--createDate|否|DateTime| 创建时间|
|--modifyName|否|String| 更新人|
|--modifyDate|否|DateTime| 更新时间|
|--isActive|否|Integer| 状态 0失效1生效|
|--isActiveName|否|String| 状态名|
|--companyId|否|String| 门店商户id|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
