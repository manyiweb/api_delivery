# 修改上架策略

**请求URL：** 
- `/warehouse/mlogiWhsShelvesScript/update `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long| id|
|scriptCode|是|String| 上架策略编码|
|scriptName|否|String| 上架策略名称|
|mlogiWhsId|否|Long| 物流仓库Id|
|whsId|否|String| 商户仓库ID|
|docCode|否|String| 单据类型|
|docName|否|String| 单据名称|
|itemStatusId|否|Long| 商品状态id|
|containerTypeId|否|Long| 容器类型id|
|isActive|否|Integer| 活跃状态 0失效1生效|
|remark|否|String| 备注|
|storAreaIdList|是|List| 关联储区id集合|

###请求参数Json格式
 
```
{
 "id" : 0,
 "scriptCode" : "String",
 "scriptName" : "String",
 "mlogiWhsId" : 0,
 "whsId" : "String",
 "docCode" : "String",
 "docName" : "String",
 "itemStatusId" : 0,
 "containerTypeId" : 0,
 "isActive" : 0,
 "remark" : "String",
 "storAreaIdList" : null
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Long| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : 0,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
