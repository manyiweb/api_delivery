# 新增商品状态

**请求URL：** 
- `/warehouse/mlogiWhsItemStatus/add `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|
|companyId|否|String| MOP商户ID|
|statusCode|否|String| 状态编码|
|statusName|否|String| 状态名称|
|isActive|否|Integer| 活跃状态 0失效1生效|
|isReceiving|否|Integer| 是否可以收货|
|isDeliver|否|Integer| 是否可以发货|
|isQc|否|Integer| 是否质检|
|remark|否|String| 备注|
|whsId|否|String| MOP商户仓库ID 货主|

###请求参数Json格式
 
```
{
 "id" : 0,
 "companyId" : "String",
 "statusCode" : "String",
 "statusName" : "String",
 "isActive" : 0,
 "isReceiving" : 0,
 "isDeliver" : 0,
 "isQc" : 0,
 "remark" : "String",
 "whsId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Long| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : 0,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
