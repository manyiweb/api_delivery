# 商品状态详情

**请求URL：** 
- `/warehouse/mlogiWhsItemStatus/info `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|

###请求参数Json格式
 
```
{
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long| id|
|--companyId|否|String| 商户ID|
|--companyName|否|String| 商户|
|--statusCode|否|String| 状态编码|
|--statusName|否|String| 状态名称|
|--isReceiving|否|Integer| 是否可以收货|
|--isReceivingName|否|String| 是否可以收货|
|--isDeliver|否|Integer| 是否可以发货|
|--isDeliverName|否|String| 是否可以发货|
|--isQc|否|Integer| 是否质检|
|--isQcName|否|String| 是否质检|
|--isActive|否|Integer| 活跃状态 0失效1生效|
|--isActiveName|否|String| 活跃状态名|
|--remark|否|String| 备注|
|--createName|否|String| 创建人|
|--createDate|否|DateTime| 创建时间|
|--modifyName|否|String| 修改人|
|--modifyDate|否|DateTime| 修改时间|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
