# 编辑储位

**请求URL：** 
- `/warehouse/mlogiWhsStorLocation/update `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long| id|
|mlogiWhsId|否|Long| 物流仓库id|
|storeAreaId|否|Long| 储区id|
|locationCode|是|String| 储位编码|
|storeLocationType|否|Integer| 储位类型|
|lArea|否|Integer| 区|
|lColumn|否|Integer| 列|
|lRow|否|Integer| 行(排)|
|lLayer|否|Integer| 层(格)|
|tunnel|否|Integer| 巷道|
|pickingPathNum|否|Integer| 拣货路径号|
|putOnPathNum|否|Integer| 上架路径号|
|isActive|否|Integer| 活跃状态 0停用1启用|
|isInventory|否|Boolean| 是否存货;FALSE:否;TRUE:是|

###请求参数Json格式
 
```
{
 "id" : 0,
 "mlogiWhsId" : 0,
 "storeAreaId" : 0,
 "locationCode" : "String",
 "storeLocationType" : 0,
 "lArea" : 0,
 "lColumn" : 0,
 "lRow" : 0,
 "lLayer" : 0,
 "tunnel" : 0,
 "pickingPathNum" : 0,
 "putOnPathNum" : 0,
 "isActive" : 0,
 "isInventory" : true
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Long| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : 0,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
