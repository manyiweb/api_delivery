# 储位详情

**请求URL：** 
- `/warehouse/mlogiWhsStorLocation/info `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long| id|

###请求参数Json格式
 
```
{
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long| id|
|--locationCode|否|String| 储位编码|
|--mlogiWhsId|否|Long| 物流仓库ID|
|--logiWhsName|否|String| 物流仓名称|
|--storeAreaId|否|Long| 储区ID|
|--storeAreaName|否|String| 储区名称|
|--storeLocationType|否|Integer| 储位类型|
|--storeLocationTypeName|否|String| 储位类型名|
|--isActive|否|Integer| 活跃状态 0停用1启用|
|--isActiveName|否|String| 活跃状态名|
|--lArea|否|Integer| 区|
|--lColumn|否|Integer| 列|
|--lRow|否|Integer| 行|
|--lLayer|否|Integer| 层|
|--tunnel|否|Integer| 巷道|
|--pickingPathNum|否|Integer| 拣货路径号|
|--putOnPathNum|否|Integer| 上架路径号|
|--remark|否|String| 备注|
|--createName|否|String| 创建人|
|--createDate|否|DateTime| 创建时间|
|--modifyName|否|String| 修改人|
|--modifyDate|否|DateTime| 修改时间|
|--isInventory|否|Boolean| 是否存货;FALSE:否;TRUE:是|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
