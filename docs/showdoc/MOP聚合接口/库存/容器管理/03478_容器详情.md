# 容器详情

**请求URL：** 
- `/warehouse/mlogiWhsContainer/info `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|

###请求参数Json格式
 
```
{
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--containerCode|否|String| 容器编码|
|--containerName|否|String| 容器名称|
|--isActive|否|Integer| 状态 0失效1生效|
|--isActiveName|否|String| 状态名|
|--containerTypeId|否|Long| 容器类型id|
|--containerTypeName|否|String| 容器类型名称|
|--mlogiWhsId|否|Long| 物流仓库Id|
|--logiWhsName|否|String| 物流仓名称|
|--remark|否|String| 备注|
|--createName|否|String| 创建人|
|--createDate|否|DateTime| 创建时间|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : {
 "containerCode" : "String",
 "containerName" : "String",
 "isActive" : 0,
 "isActiveName" : "String",
 "containerTypeId" : 0,
 "containerTypeName" : "String",
 "mlogiWhsId" : 0,
 "logiWhsName" : "String",
 "remark" : "String",
 "createName" : "String",
 "createDate" : "DateTime"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
