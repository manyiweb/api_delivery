# 获得参数建议列表值
 

**请求URL：** 
- `/config/datatable/user/definition/getSelectorItems/{serviceId}`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|datatableId|是|String| 数据表ID,| 订货订单:mgr_b2b_order_list 商品出库:product_whs_out_list 商品入库:product_whs_in_list 要货订单:product_inventory_need 采购订单:b2b_goods_in_order 采购收货:b2b_purchase 采购退货:b2b_purchase_return 订货退货:b2b_refund 库存盘点:check_vouch_list 代发订单:mgr_order_hq_list储位移库:mgr_store_location_relocate_record 储位管理:mgr_logistics_warehouse_store_location 储区档案:mgr_Logistics_warehouse_store_area 多储位物流仓档案:mgr_Logistics_warehouse 仓区管理:mgr_Logistics_warehouse_area 
|serviceId|是|String|服务id,| 订货订单:reabam-b2b 商品出库:reabam-product 商品入库:reabam-product 要货订单:reabam-b2b 采购订单:reabam-b2b 采购收货:reabam-b2b 采购退货:reabam-b2b 订货退货:reabam-b2b 库存盘点:reabam-product 代发订单:reabam-retail 储位移库: warehouse储位管理: warehouse 储区档案: warehouse多储位物流仓档案: warehouse仓区管理 :warehouse 
|parameterName|是|String| 参数名称|
|keyword|否|String| 关键字|
|pageNo|是|Integer| 页码|

### 请求参数Json格式
 
```
{
 "datatableId" : "String",
 "parameterName" : "String",
 "keyword" : "String",
 "pageNo" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--name|否|String| 名称|
|--value|否|String| 值|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : [{
 "name" : "String",
 "value" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
