# 代发订单列表

**请求URL：** 
- `/retail/datatable/orderhq/{source} `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|keyword|否|String||
|hqStatus|否|Integer||
|hqSettlementStatus|否|Integer||
|sendAddress|否|String||
|printBatchModifyDate|否|Object| 创建日期|
|--start|否|DateTime|起始对象 |
|--end|否|DateTime|结束对象 |
|createDate|否|Object| 创建日期|
|--start|否|DateTime|起始对象 |
|--end|否|DateTime|结束对象 |
|pageSize|否|Integer| 分页大小|
|pageNo|否|Integer| 页码|
|sortField|否|String| 排序字段|
|sortDirection|否|Object| 排序方向|
|companyIds|否|List| 商户|
|joiningTraderCode|否|List| 所属加盟商|
|companyGID|否|List| 商户组|
|merchantsAreafCodes|否|String| 所属区域|
|distributorCode|否|List| 所属经销商|
