# 更新用户自定义字段配置
 

**请求URL：** 
- `/config/datatable/user/definition/updateCustomizeColumn/{serviceId}`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|datatableId|是|String| 数据表ID|
|columns|是|List| 用户自定义字段排序|
|--columnFieldName|否|String| 数据列字段名|
|--displayable|否|Boolean| 是否展示|
|--sequenceNumber|否|Integer| 序号|

### 请求参数Json格式
 
```
{
 "datatableId" : "String",
 "columns" : [{
 "columnFieldName" : "String",
 "displayable" : true,
 "sequenceNumber" : 0
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
