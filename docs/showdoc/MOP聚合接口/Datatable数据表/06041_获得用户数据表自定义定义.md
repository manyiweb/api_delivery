# 获得用户数据表定义
 

**请求URL：** 
- `/config/datatable/user/definition/getDatatableDefinition/{serviceId}`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|datatableId|否|String| 数据表ID|
|targetId|否|String||
|viewId|否|String||

### 请求参数Json格式
 
```
{
 "datatableId" : "String",
 "targetId" : "String",
 "viewId" : "String"
}
```
