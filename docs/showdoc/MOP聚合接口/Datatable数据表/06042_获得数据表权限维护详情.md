# 获得品牌字段配置详情

**请求URL：** 
- `/config/datatable/group/getColumnSettingDetail/{serviceId}`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|targetId|是|String| 数据表ID|
|companyId|否|String| 门店ID或者品牌ID（如果是中台则品牌ID，如果是前台的品牌配置则使用品牌ID 否则都使用门店ID）|

### 请求参数Json格式
 
```
{
 "targetId" : "String",
 "companyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--targetId|否|String| 数据表ID或者导出ID|
|--name|否|String| 数据表名称|
|--companyId|否|String| 门店ID或者品牌ID|
|--inheritGroup|否|Boolean| 是否继承品牌|
|--columns|否|List| 字段列表|
|----columnName|否|String| 列名称|
|----fieldName|否|String| 字段名称|
|----alias|否|String| 字段展示别名|
|----sequenceNumber|否|Integer| 排序号|
|----displayable|否|Boolean| 是否展现|
|----roles|否|List| 权限角色列表|
|------roleName|是|String| 角色名称|
|------roleCode|是|String| 角色编码|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : {
 "targetId" : "String",
 "name" : "String",
 "companyId" : "String",
 "inheritGroup" : true,
 "columns" : [{
 "columnName" : "String",
 "fieldName" : "String",
 "alias" : "String",
 "sequenceNumber" : 0,
 "displayable" : true,
 "roles" : [{
 "roleName" : "String",
 "roleCode" : "String"
 }]
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
