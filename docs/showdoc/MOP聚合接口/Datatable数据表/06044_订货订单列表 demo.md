# 订货订单列表

**请求URL：** 
- `/b2b/datatable/order/{source}`

{source} 为 MSYQL 则查数据库
{source} 为 ELASTICSEARCH 则查询 ES

可以根据Coordinator 动态更改查询映射 实现切换查询源

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 商户|
|orderStatus|否|String| 订单状态|
|pageSize|否|Integer| 分页大小|
|pageNo|否|Integer| 页码|
|sortField|否|String| 排序字段|
|sortDirection|否|Object| 排序方向|

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "orderStatus" : "String",
 "pageSize" : 0,
 "pageNo" : 0,
 "sortField" : "String",
 "sortDirection" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--content|否|List| 数据内容|
|--pageSize|否|Integer| 分页大小|
|--pageNo|否|Integer| 分页页码|
|--total|否|Long| 数据总数|
|--totalPage|否|Integer| 总页数|
|--hasNextPage|否|Boolean| 是否有下一页|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : {
 "content" : null,
 "pageSize" : 0,
 "pageNo" : 0,
 "total" : 0,
 "totalPage" : 0,
 "hasNextPage" : true
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
