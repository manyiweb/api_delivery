# 获得数据表列表【前台】
 

**请求URL：** 
- `/config/datatable/group/getDatatableList/company`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
无参数


### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--serviceId|否|String| 服务ID|
|--targetId|否|String| 数据表ID 即 datatableId|
|--datatableName|否|String| 数据表名称|
|--exportInfoList|否|List| 导出功能|
|----serviceId|否|String| 服务|
|----exportId|否|String| 导出ID|
|----targetId|否|String| datatableId#exportId 的组合|
|----name|否|String| 展现名称|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : [{
 "serviceId" : "String",
 "targetId" : "String",
 "datatableName" : "String",
 "exportInfoList" : [{
 "serviceId" : "String",
 "exportId" : "String",
 "targetId" : "String",
 "name" : "String"
 }]
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
