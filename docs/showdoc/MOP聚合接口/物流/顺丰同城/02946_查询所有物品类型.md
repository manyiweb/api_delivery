# 功能描述: 查询所有物品类型
 

**请求URL：** 
- `/logistics/sftc/type `

**请求方式：**
- POST
- FormData


###请求参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|是|String| 认证标识|

###请求参数Json格式
 
```
{
 "tokenId":"1e34a4554ebd4af5b5395989dd7997fe"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Map| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
