# 功能描述: 查询订单关联的所有物流单
 

**请求URL：** 
- `/logistics/sftc/logistics `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|String| 订单id|

###请求参数Json格式
 
```
{
 "id" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--sfOrderId|否|String| 顺丰订单ID|
|--sfBillId|否|String| 顺丰运单号|
|--shopOrderId|否|String| 外部订单ID|
|--orderId|否|String| 内部订单ID|
|--orderStatus|否|Long| 订单状态,2-订单异常;10-配送员确认;12:配送员到店;15:配送员配送中|
|--statusDesc|否|String| 状态描述|
|--cancelReason|否|String| 取消原因|
|--isError|否|Integer| 是否异常.0-无异常;1-订单异常|
|--errorContent|否|String| 异常详情|
|--expectTime|否|String| 新的期望送达时间,如果发生期望送达时间的更新此字段有值|
|--pushTime|否|String| 状态变更时间|
|--remark|否|String| 备注|
|--logisticsDetail|否|List| 物流详情|
|----operatorName|否|String| 配送员姓名|
|----operatorPhone|否|String| 配送员电话|
|----riderLng|否|String| 配送员位置经度|
|----riderLat|否|String| 配送员位置纬度|
|----orderStatus|否|Long| 订单状态,10-配送员确认;12:配送员到店;15:配送员配送中|
|----statusDesc|否|String| 状态描述|
|----pushTime|否|String| 状态变更时间|
|----remark|否|String| 备注|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
