# 功能描述: 根据地址查询顺丰订单费用
 

**请求URL：** 
- `/logistics/sftc/fee `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|userLng|否|String| 用户地址经度，非必填|
|userLat|否|String| 用户地址纬度，非必填|
|userAddress|是|String| 用户详细地址，必填|
|cityName|否|String| 发单城市，非必填|
|weight|是|Long| 物品重量（单位：克），必填|
|productType|是|Long| 物品类型，必填|
|totalPrice|否|Long| 用户订单总金额（单位：分），非必填|
|isAppoint|是|Integer| 是否是预约单：0：非预约单；1：预约单，必填|
|expectTime|否|Long| 期望送达时间,预约单需必传，非必填|
|lbsType|否|Integer| 坐标类型，1：百度坐标，2：高德坐标，非必填|
|payType|是|Long| 用户支付方式：1、已支付 0、货到付款，必填|
|receiveUserMoney|否|Long| 代收金额(单位：分)，非必填|
|isInsured|是|Long| 是否保价，0：非保价；1：保价，必填|
|declaredValue|否|Long| 保价金额，非必填|
|gratuityFee|否|Long| 订单小费（单位分），不传或者传0为不加小费，加小费最低不能少于100分，非必填|
|riderPickMethod|否|Long| 物流流向，1：从门店取件送至用户；，2：从用户取件送至门店，非必填，默认1|
|shop|否|Object| 发货店铺，非必填|
|--shopName|否|String| 店铺姓名，非必填|
|--shopPhone|否|String| 店铺电话，非必填|
|--shopAddress|否|String| 店铺地址，非必填|
|--shopLng|否|String| 店铺经度，非必填|
|--shopLat|否|String| 店铺纬度，非必填|

###请求参数Json格式
 
```
{
 "userLng" : "String",

 "userAddress" : "String",

 "weight" : 0,
 "productType" : 0,
 "totalPrice" : 0,
 "isAppoint" : 0,
 "expectTime" : 0,
 "lbsType" : 0,
 "payType" : 0,
 "receiveUserMoney" : 0,
 "isInsured" : 0,
 "declaredValue" : 0,
 "gratuityFee" : 0,
 "riderPickMethod" : 0,
 "shop" : {
 "shopName" : "String",
 "shopPhone" : "String",
 "shopAddress" : "String",
 "shopLng" : "String",
 "shopLat" : "String"
 }
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--deliveryType|否|Integer| 0：预约送达单 1：立即单 3：预约上门单|
|--expectTime|否|String| 预计送达（上门）时间|
|--promiseDeliveryTime|否|Integer| 预计配送时间（单位: 分）|
|--totalPrice|否|Long| 配送费总额，单位分（值为计算出来此单总价）|
|--pushTime|否|String| 推单时间|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : {
 "deliveryType" : 0,

 "promiseDeliveryTime" : 0,
 "totalPrice" : 0,
 "pushTime" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
