# 添加修改商品信息

**请求URL：** 
- `/config/peeling/preset/edit/goods`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|wgId|否|Long| 称重商品去皮id|
|weighingProductList|否|List| 商品信息|
|--id|否|Long| id|
|--specId|否|String| 规格id|
|--weighingNumber|否|Double| 默认去皮重量|
|--presetGoodsWeighingList|否|List| 预设重量|
|----id|否|Long| 主键ID|
|----weighingName|否|String| 重量名称|
|----weighingNumber|否|Double| 重量值|
|----isDefault|否|Boolean| 是否是默认值|
|----remark|否|String| 描述|

### 请求参数Json格式
 
```
{
 "wgId" : 0,
 "weighingProductList" : [{
 "id" : 0,
 "specId" : "String",
 "weighingNumber" : 0
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
