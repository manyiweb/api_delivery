# 去皮预设详情

**请求URL：** 
- `/config/peeling/preset/info`

**请求方式：**
- ALL
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 门店传门店id 品牌->不传|

### 请求参数Json格式
 
```
{
 "companyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long|id|
|--companyId|否|String|门店id|
|--companyName|否|String|门店名称|
|--companyCode|否|String|门店编码|
|--remark|否|String|备注|
|--isRemovePeel|否|Boolean|是否设置称重去皮|
|--createId|否|String|创建人id|
|--createName|否|String|创建人名称|
|--createDate|否|DateTime|创建人时间|
|--modifyId|否|String|修改人id|
|--modifyName|否|String|修改人名称|
|--modifyDate|否|DateTime|修改人时间|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
