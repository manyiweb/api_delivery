# 称重商品去皮预设编辑

**请求URL：** 
- `/config/peeling/preset/edit`

**请求方式：**
- ALL
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 主键ID|
|isRemovePeel|否|Boolean| 启用设置称重商品默认去皮重量 1:去皮 0:不去皮|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "isRemovePeel" : true
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
