# 查询商品

**请求URL：** 
- `/config/peeling/preset/list/goods`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|wgId|是|Long| 称重去皮预设id|
|sword|否|String||
|pageIndex|否|Integer||
|pageSize|否|Integer||

### 请求参数Json格式
 
```
{
 "wgId" : 0,
 "sword" : "String",
 "tokenId" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--pageIndex|否|Integer||
|--pageSize|否|Integer||
|--pageCount|否|Integer||
|--totalCount|否|Long||
|--first|否|Boolean||
|--last|否|Boolean||
|--content|否|List||
|----id|否|Long| 主键ID|
|----wgId|否|Long| 称重商品去皮id|
|----itemId|否|String| 商品id|
|----itemName|否|String| 商品名称|
|----specId|否|String| 商品规格id|
|----itemCode|否|String| 商品编码|
|----skuCode|否|String| 商品sku编码|
|----weighingNumber|否|Double| 默认去皮重量|
|----remark|否|String| 描述|
|----presetGoodsWeighingList|否|List| 商品预设重量|
|------id|否|Long| 主键ID|
|------wggId|否|Long| 称重商品去皮预设商品id|
|------weighingName|否|String| 重量名称|
|------weighingNumber|否|Double| 重量值|
|------isDefault|否|Boolean| 是否是默认值|
|------remark|否|String| 描述|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
