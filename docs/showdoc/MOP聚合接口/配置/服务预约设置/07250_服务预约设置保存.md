# 服务预约设置保存

**请求URL：** 
- `/config/server/appointment/settings/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 编辑传id 新增不传|
|isStart|否|Boolean| 启用预约护理业务|
|validityDateType|否|Integer| 有效期类型 1:长期有效 2:指定有效期|
|startDate|否|date| 有效期开始时间 格式(年月日)|
|endDate|否|date| 有效期结束时间 格式(年月日)|
|appointmentIntervalDuration|否|Integer| 预约时间间隔时长(分钟)|
|minAppointmentDuration|否|Integer| 最小预约时长(分钟)|
|earliestAppointmentTime|否|Integer| 最早可预约时间(小时)|
|appointmentsPerDateSlot|否|Integer| 每个时段可预约次数|
|deleteAsIds|否|List| 可预约时间删除（id）|
|appointmentScheduleList|否|List| 可预约时间|
|--id|否|Long| 编辑传id 新增不传|
|--appointmentSettingsId|否|Long| 服务预约设置id|
|--startDate|否|String| 有效期开始时间 格式(年月日)|
|--endDate|否|String| 有效期结束时间 格式(年月日)|

### 请求参数Json格式
 
```
{
 "id" : 0,

 "appointmentScheduleList" : [{
 "id" : 0,
 "appointmentSettingsId" : 0,
 "startData" : "String",
 "endData" : "String"
 }]
}
```
