# 服务预约设置查询列表 （停用）

**请求URL：** 
- `/config/settings/get/List`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
无参数


### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--id|否|Long| 编辑传id 新增不传|
|--isStart|否|Boolean| 启用预约护理业务|
|--validityDataType|否|Integer| 有效期类型 1:长期有效 2:指定有效期|
|--startData|否|String| 有效期开始时间 格式(年月日)|
|--endData|否|String| 有效期结束时间 格式(年月日)|
|--appointmentIntervalDuration|否|Integer| 预约时间间隔时长(分钟)|
|--minAppointmentDuration|否|Integer| 最小预约时长(分钟)|
|--earliestAppointmentData|否|Integer| 最早可预约时间(小时)|
|--appointmentsPerDataSlot|否|Integer| 每个时段可预约次数|
|--companyId|否|String| 门店id|
|--companyName|否|String| 门店名称|
|--companyCode|否|String| 门店编码|
|--appointmentScheduleListResp|否|List| 可预约时间|
|----id|否|Long| 编辑传id 新增不传|
|----appointmentSettingsId|否|Long| 服务预约设置id|
|----startData|否|String| 有效期开始时间 格式(年月日)|
|----endData|否|String| 有效期结束时间 格式(年月日)|
|----createId|否|String||
|----createName|否|String||
|----createDate|否|DateTime||
|----modifyId|否|String||
|----modifyName|否|String||
|----modifyDate|否|DateTime||
|----dbKey|否|Integer||
|----groupId|否|String||
|--createId|否|String||
|--createName|否|String||
|--createDate|否|DateTime||
|--modifyId|否|String||
|--modifyName|否|String||
|--modifyDate|否|DateTime||
|--dbKey|否|Integer||
|--groupId|否|String||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
