# 订货代发受理通知目标明细表添加或修改

**请求URL：** 
- `/config/proxy/notify/target/saveOrUpdate`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|users|否|List| 用户集合|
|--itemId|否|String|选项id |
|--itemCode|否|String|选项编码 |
|--itemName|否|String|选项名称 |
|appUsers|否|List| app用户集合|
|--itemId|否|String|选项id |
|--itemCode|否|String|选项编码 |
|--itemName|否|String|选项名称 |
|webhooks|否|List| webhooks集合|
|--itemId|否|String|选项id |
|--itemCode|否|String|选项编码 |
|--itemName|否|String|选项名称 |
|notifyType|否|Integer|通知功能类型，1、代发单取消，2、代发单拒绝 3、新建订货订单 4、新建打款单 |
|ifSpecifyPlatform|否|Integer| 是否指定端口|
|isMgr|否|Integer| 中台app|
|isGuide|否|Integer| 门店端app|
|isB2bmgrapp|否|Integer| 订货端app|

### 请求参数Json格式
 
```
{
 "users" : [{
 "itemId" : "String",
 "itemCode" : "String",
 "itemName" : "String"
 }],
 "appUsers" : [{
 "itemId" : "String",
 "itemCode" : "String",
 "itemName" : "String"
 }],
 "webhooks" : [{
 "itemId" : "String",
 "itemCode" : "String",
 "itemName" : "String"
 }],
 "notifyType" : 0,
 "ifSpecifyPlatform" : 0,
 "isMgr" : 0,
 "isGuide" : 0,
 "isB2bmgrapp" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
