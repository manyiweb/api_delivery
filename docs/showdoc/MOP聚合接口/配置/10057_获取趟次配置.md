# 获取

**请求URL：** 
- `/config/product/trip/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|String||

### 请求参数Json格式
 
```
{
 "id" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|String| 主键|
|--isInherit|否|Boolean| 是否继承品牌|
|--tripList|否|List| 趟次列表|
|----tripTimeName|否|String| 趟次名称|
|----subTripTimeList|否|List| 订单提配时间|
|------startTime|否|String| 开始时间|
|------endTime|否|String| 结束时间|
|--companyId|否|String| 门店id|
|--groupId|否|String| 品牌id|
|--createId|否|String||
|--createName|否|String||
|--createDate|否|DateTime||
|--modifyId|否|String||
|--modifyName|否|String||
|--modifyDate|否|DateTime||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "id" : "String",
 "isInherit" : true,
 "tripList" : [{
 "tripTimeName" : "String",
 "subTripTimeList" : [{
 "startTime" : "String",
 "endTime" : "String"
 }]
 }],
 "companyId" : "String",
 "groupId" : "String",
 "createId" : "String",
 "createName" : "String",
 "createDate" : "DateTime",
 "modifyId" : "String",
 "modifyName" : "String",
 "modifyDate" : "DateTime"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
