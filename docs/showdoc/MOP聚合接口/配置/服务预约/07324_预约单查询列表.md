# 预约单查询列表
**请求URL：** 
- `/orderfast/server/appointment/list/{source}`

**请求方式：**
- ALL
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|keyword|否|String| 单号|
|createDate|否|Object| 创建日期|
|--start|否|DateTime||
|--end|否|DateTime||
|appointmentDate|否|Object| 预约时间|
|--start|否|DateTime||
|--end|否|DateTime||
|status|否|List| 获取状态 状态编码 NA:待接单 YA:已接单 YF:已完成 YS:已取消 YR:拒绝|
|id|否|String||
|pageSize|否|Integer||
|pageNo|否|Integer||
|sortField|否|String||
|sortDirection|否|String||

### 请求参数Json格式
 
```
{
 "keyword" : "String",
 "createDate" : {
 "start" : "DateTime",
 "end" : "DateTime"
 },
 "appointmentDate" : {
 "start" : "DateTime",
 "end" : "DateTime"
 },
 "status" : null,
 "id" : "String",
 "pageSize" : 0,
 "pageNo" : 0,
 "sortField" : "String",
 "sortDirection" : "String"
}
```
