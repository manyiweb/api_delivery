# 查询服务预约商品

**请求URL：** 
- `/product/server/appointment/item/list`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|mitemTypeIds|否|List| 商品类型|
|sword|否|String||
|pageIndex|否|Integer||
|pageSize|否|Integer||
