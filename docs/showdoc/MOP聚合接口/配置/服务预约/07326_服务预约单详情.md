# 服务预约单详情

**请求URL：** 
- `/orderfast/server/appointment/detail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long||

### 请求参数Json格式
 
```
{
 "id" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long||
|--orderNo|否|String| 订单编码|
|--statusCode|否|String| 状态编码 NA:待接单 YA:已接单 YF:已完成 YS:已取消 YR:拒绝|

|--dateStr|否|String| 时间范围 时:分|
|--dateRange|否|String| 时间范围 时:分 ~ 时:分|
|--duration|否|Double| 时长 (小时)|
|--staffId|否|String| 服务人员id|
|--staffCode|否|String| 服务人员编码|
|--staffName|否|String| 服务人员名称|
|--serverItemId|否|String| 服务商品id|
|--serverItemCode|否|String| 服务商品编码|
|--serverItemName|否|String| 服务商品名称|
|--appointmentUserId|否|String| 预约人id(会员id)|
|--appointmentUserName|否|String| 预约人名称|
|--appointmentUserPhone|否|String| 预约手机号|
|--companyId|否|String| 门店id|
|--companyCode|否|String| 门店名称|
|--companyName|否|String| 门店名称|
|--remark|否|String| 备注|
|--reason|否|String| 原因|
|--appointmentDateRange|否|String| 时间范围|
|--price|否|Double| 价格|
|--itemImage|否|String| 商品图片|
|--createId|否|String| 创建人id|
|--createName|否|String| 创建人|
|--createDate|否|DateTime| 创建时间|
|--modifyId|否|String| 修改人id|
|--modifyName|否|String| 修改人|
|--modifyDate|否|DateTime| 修改时间|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
