# 服务设置获取当前门店的时间段 点单小程序
服务:config

**请求URL：** 
- `/config/server/appointment/schedule/date`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|appointmentDate|否|DateTime| 预约时间|
|dateRange|否|String| 预约点（弃用）|

### 请求参数Json格式
 
```
{
 "appointmentDate" : "DateTime"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--dateStr|否|String| 日期|
|--num|否|Integer| 数量|
|--isAppointment|否|Boolean| 是否可预约|
|--isStartArriveEnd|否|Boolean| 是否Start到End 是True|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "dateStr" : "String",
 "num" : 0,
 "isAppointment" : true
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
