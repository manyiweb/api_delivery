# 预约单保存 

**请求URL：** 
- `/orderfast/server/appointment/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyAddress|否|String| 门店地址|
|appointmentDate|否|DateTime| 预约时间 年月日|
|dateStr|否|String| 时间范围 时:分（开始时间）|
|dateStrs|否|List| 时间范围 时:分（开始时间~结束时间）|
|dateRange|否|String| 时间范围 时:分~时:分|
|duration|否|Double| 服务时长|
|staffId|否|String| 服务预约人员|
|staffCode|否|String| 服务人员编码|
|staffName|否|String| 服务人员名称|
|serverItemId|否|String| 预约服务|
|serverItemCode|否|String| 预约编码|
|serverItemName|否|String| 预约名称|
|price|否|String| 价格|
|appointmentName|否|String| 预约人|
|appointmentPhone|否|String| 预约手机号|
|remark|否|String| 备注|

### 请求参数Json格式
 
```
{
 "companyAddress" : "String",
 "appointmentDate" : "DateTime",
 "dateStr" : "String",
 "dateRange" : "String",
 "duration" : 0,
 "staffId" : "String",
 "staffCode" : "String",
 "staffName" : "String",
 "serverItemId" : "String",
 "serverItemCode" : "String",
 "serverItemName" : "String",
 "appointmentName" : "String",
 "appointmentPhone" : "String",
 "remark" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
