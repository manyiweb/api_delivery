# 保存预约护理取消原因配置

**请求URL：** 
- `/config/cance/reason/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 新增预约护理取消原因id|
|isStart|否|Boolean| 是否开启其他原因|
|cancelReasonList|否|List| 取消原因|
|--id|否|Long| 原因id 新增：不传 编辑: 传|
|--cancelReason|否|String| 取消原因|
|deleteIds|否|List| 删除id|
|serviceStaffShow|否|Boolean| 服务人员是否显示|
|autoCancelTime|否|Integer| 取消时间|
|canAutoCancel|否|Boolean| 是否设置预约订单取消时间|
|rejectReasonList|否|List| 拒绝原因|
|enableRejectOtherReason|否|Boolean| 是否开启其他原因|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "isStart" : true,
 "cancelReasonList" : [{
 "id" : 0,
 "cancelReason" : "String"
 }],
 "deleteIds" : null,
 "serviceStaffShow" : true,
 "autoCancelTime" : 0,
 "canAutoCancel" : true,
 "rejectReasonList" : null,
 "enableRejectOtherReason" : true
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
