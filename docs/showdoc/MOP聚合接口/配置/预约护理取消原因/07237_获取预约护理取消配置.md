# 获取预约护理取消原因配置

**请求URL：** 
- `/config/cance/reason/get`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
无参数


### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--appointmentCareCancelReasonId|否|Long| id|
|--isStart|否|Boolean| 是否开启其他原因|
|--serviceStaffShow|否|Boolean| 是否展示服务人员|
|--cancelReason|否|List| 原因|
|----id|否|Long||
|----appointmentCareId|否|Long| 预约护理取消原因id|
|----cancelReason|否|String| 取消原因|
|----createId|否|String||
|----createName|否|String||
|----createDate|否|DateTime||
|----modifyId|否|String||
|----modifyName|否|String||
|----modifyDate|否|DateTime||
|----dbKey|否|Integer||
|----groupId|否|String||
|--autoCancelTime|否|Integer||
|--canAutoCancel|否|Boolean||
|--rejectReasonList|否|List| 拒绝原因|
|--enableRejectOtherReason|否|Boolean| 是否开启其他原因|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "appointmentCareCancelReasonId" : 0,
 "isStart" : true,
 "serviceStaffShow" : true,
 "cancelReason" : [{
 "id" : 0,
 "appointmentCareId" : 0,
 "cancelReason" : "String",
 "createId" : "String",
 "createName" : "String",
 "createDate" : "DateTime",
 "modifyId" : "String",
 "modifyName" : "String",
 "modifyDate" : "DateTime",
 "dbKey" : 0,
 "groupId" : "String"
 }],
 "autoCancelTime" : 0,
 "canAutoCancel" : true,
 "rejectReasonList" : null,
 "enableRejectOtherReason" : true
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
