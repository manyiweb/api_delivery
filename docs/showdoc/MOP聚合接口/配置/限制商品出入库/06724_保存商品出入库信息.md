# 保存商品出入库信息

**请求URL：** 
- `/config/restrict/outin/stock/company/goods/save`

**请求方式：**
- ALL
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|goodsSaveReqList|否|List| 指定商品信息|
|--id|否|Long| id 新增不传id 更新传id |
|--itemId|否|String| 商品id|
|--specId|否|String| 规格id|
|--isCompanyAllot|否|Boolean| 禁止门店调拨 0:禁止 1:允许|
|--isOutinStock|否|Boolean| 禁止出入库 0:禁止 1:允许|
|rsId|否|Long| 限制商品出入库id|
|companyId|否|String| 门店id|

### 请求参数Json格式
 
```
{
 "goodsSaveReqList" : [{
 "id" : 0,
 "itemId" : "String",
 "specId" : "String",
 "isCompanyAllot" : true,
 "isOutinStock" : true
 }],
 "rsId" : 0,
 "companyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
