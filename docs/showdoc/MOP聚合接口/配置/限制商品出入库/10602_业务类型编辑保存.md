# 编辑

**请求URL：** 
- `/config/restrict/outin/stock/business/type/save`

**请求方式：**
- ALL
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|businessTypes|否|List||
|--id|否|Long| 主键ID|
|--rsId|否|Long||
|--businessRestrictType|否|Integer||
|--businessTypeCode|否|String||
|--businessTypeName|否|String||
|--addGoodsList|否|List||
|----id|否|Long| id|
|----itemId|否|String| 商品id|
|----specId|否|String| 商品规格id|
|----itemCode|否|String| 商品编码|
|----itemName|否|String| 商品名称|
|----skuBarcode|否|String| sku条码|
|--deleteGoodsList|否|List||
|--addCategoryList|否|List| 类别信息|
|----id|否|Long| 主键ID|
|----categoryType|否|Integer| 类别类型，1：品牌，2：系列 3：类别|
|----categoryId|否|String| 通用指定id 可以是品牌，系列或类别|
|----categoryCode|否|String| 通用指定编码 可以是品牌，系列或类别|
|----categoryName|否|String| 通用指定名称 可以是品牌，系列或类别|
|----isCompanyAllot|否|Boolean| 禁止门店调拨 0:禁止 1:允许|
|----isOutinStock|否|Boolean| 禁止出入库 0:禁止 1:允许|
|--deleteCategoryList|否|List||
