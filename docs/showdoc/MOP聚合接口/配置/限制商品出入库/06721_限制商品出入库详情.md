# 限制商品出入库详情

**请求URL：** 
- `/config/restrict/outin/stock/company/detail`

**请求方式：**
- ALL
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 门店id|

### 请求参数Json格式
 
```
{
 "companyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long||
|--companyId|否|String|门店id|
|--companyName|否|String|门店名称|
|--companyCode|否|String|门店编码|
|--remark|否|String|备注|
|--restrictType|否|Integer|限制类型 0-指定商品,1-指定类别、品牌、系列|
|--sysChangeDate|否|DateTime||
|--createId|否|String||
|--createName|否|String||
|--createDate|否|DateTime||
|--modifyId|否|String||
|--modifyName|否|String||
|--modifyDate|否|DateTime||
|--dbKey|否|Integer||
|--groupId|否|String||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
