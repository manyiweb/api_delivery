# 商品出入库限制保存校验

**请求URL：**
- `/product/restrict/outin/stock/beforsave/check`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|outCompanyId|否|String| 商品出库id 商品出库 商品调拨传|
|inCompanyId|否|String| 商品入库id 商品入库 商品调拨传|
|specids|否|List| 商品规格id|
|type|否|String| ALLOT_ORDER 商品调拨是传入次参数 商品出入库可以不传递|

### 请求参数Json格式
 
```
{
 "outCompanyId" : "String",
 "inCompanyId" : "String",
 "specids" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--msgStr|否|List| 提示信息|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String|||


### 返回参数Json格式
 
```
{
 "data" : {
 "msgStr" : null
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
