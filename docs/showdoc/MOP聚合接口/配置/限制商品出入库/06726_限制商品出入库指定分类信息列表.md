# 限制商品出入库指定分类信息列表

**请求URL：** 
- `/config/restrict/outin/stock/company/category/list`

**请求方式：**
- ALL
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|rsId|否|Long| 限制商品出入库id|
|tokenId|否|String||
|pageIndex|否|int||
|pageSize|否|int|||

### 请求参数Json格式
 
```
{
 "rsId" : 0,
 "pageIndex" : 0,
 "pageSize" : 0,
}
```
