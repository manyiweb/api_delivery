# 出入库业务类型列表

**请求URL：** 
- `/config/restrict/outin/stock/business/type/list`

**请求方式：**
- ALL
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|rsId|否|Long||
|businessRestrictType|否|Integer||

### 请求参数Json格式
 
```
{
 "rsId" : 0,
 "businessRestrictType" : 0
}
```

|:---- |:---|:----- |----- |
|data|否|List||
|--id|否|Long||
|--rsId|否|Long||
|--businessTypeName|否|String||
|--businessTypeCode|否|String||
|--businessRestrictType|否|Integer||
|--createId|否|String||
|--createName|否|String||
|--createDate|否|DateTime||

|--groupId|否|String||
|msg|否|String||
|code|否|String||
