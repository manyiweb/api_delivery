# 保存限制商品出入库分类信息

**请求URL：** 
- `/config/restrict/outin/stock/company/category/save`

**请求方式：**
- ALL
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|categorySaveList|否|List| 类别信息|
|--id|否|Long| 主键ID 新增不传id 编辑传id|
|--categoryType|是|Integer| 类别类型，1：品牌，2：系列 3：类别|
|--categoryId|是|String| 通用指定id 可以是品牌，系列或类别|
|--categoryCode|是|String| 通用指定编码 可以是品牌，系列或类别|
|--categoryName|是|String| 通用指定名称 可以是品牌，系列或类别|
|--isCompanyAllot|否|Boolean| 禁止门店调拨 false:禁止 true:允许|
|--isOutinStock|否|Boolean| 禁止出入库 false:禁止 true:允许|
|rsId|是|Long| 限制商品出入库id|
|companyId|否|String| 门店id|

### 请求参数Json格式
 
```
{
 "categorySaveReqs" : [{
 "id" : 0,
 "categoryType" : 0,
 "categoryId" : "String",
 "categoryCode" : "String",
 "categoryName" : "String",
 "isCompanyAllot" : true,
 "isOutinStock" : true
 }],
 "rsId" : 0,
 "companyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|

|exceptionStackInfo|否|String||
|traceId|否|String||
