# 域名切换查询接口
 匿名访问，返回是否需要切换到新域名
 

**请求URL：** 
- `/public/domain-switch`

**请求方式：** 
- `POST`
- `RequestBody`


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|groupCode|是|String| 品牌编码用于标识需要查询域名切换规则的业务分组，必填|
|currentBaseUrl|是|String| 当前域名POS 客户端当前使用的 API 基础域名，必填，用于匹配域名切换规则|
|clientVersion|否|String| 客户端版本POS 客户端的版本号，可选，用于版本级别的灰度切换匹配|

### 请求参数Json格式
 
```
{
 "groupCode":"String",
 "currentBaseUrl":"String",
 "clientVersion":"String"
}
```

### 响应参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--switchRequired|否|Boolean| 是否需要切换域名 true 表示需要切换到 targetBaseUrl，false 表示保持当前域名|
|--targetBaseUrl|否|String| 目标域名当 switchRequired=true 时，POS 客户端应切换到此域名|
|--switchOnce|否|Boolean| 是否只切换一次 true 表示客户端切换后应持久化标记，后续不再询问|
|--configVersion|否|String| 配置版本用于客户端缓存校验，判断配置是否发生变化|
|--ttlSeconds|否|Integer| 缓存有效期（秒） 建议客户端在此时间内不再重复查询|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 响应参数Json格式
 
```
{
 "data":{
 "switchRequired":true,
 "targetBaseUrl":"String",
 "switchOnce":true,
 "configVersion":"String",
 "ttlSeconds":0
 },
 "msg":"String",
 "code":"String",
 "exceptionStackInfo":"String",
 "traceId":"String"
}
```
