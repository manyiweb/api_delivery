# 新增预约单
 服务：retail-order-front
 

**请求URL：** 
- `/reserve/store/add`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|setId|是|Long||
|startDate|是|DateTime||
|endDate|是|DateTime||
|remark|否|String||
|specId|是|String||
|reserveName|是|String||
|reserveOrderFieldReqs|否|List||
|--id|是|Long||
|--fieldName|是|String| 字段名称|
|--fieldValue|是|String| 字段值|
|--fieldType|是|String| 字段类型|
|--fieldNumber|否|Integer| 字段数量|
|--isRequired|是|Integer| 是否必填|

### 请求参数Json格式
 
```
{
 "setId" : 0,
 "startDate" : "DateTime",
 "endDate" : "DateTime",
 "remark" : "String",
 "specId" : "String",
 "reserveName" : "String",
 "reserveOrderFieldReqs" : [{
 "id" : 0,
 "fieldName" : "String",
 "fieldValue" : "String",
 "fieldType" : "String",
 "fieldNumber" : 0,
 "isRequired" : 0
 }]
}
```
