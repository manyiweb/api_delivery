# 获取预约到店规则
 服务 config

**请求URL：** 
- `/config/retail/reserveStore/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long| id|

### 请求参数Json格式
 
```
{
 "id" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long| id|
|--name|否|String| 项目名称|
|--beginDate|否|DateTime| 有效期起|
|--endDate|否|DateTime| 有效期至|
|--reserveTimeRange|否|String| 可预约时间,fmt=HH:mm~HH:mm,英文逗号相隔|
|--reserveMinute|否|Integer| 预约时间间隔 ,单位:分钟|
|--minReserveTime|否|Integer| 最小预约时间,单位:分钟|
|--status|否|Boolean| 活跃状态|
|--reserveStoreFields|否|List| 预约模板字段|
|----id|否|Long| id|
|----fieldName|否|String| 字段名称|
|----fieldType|否|String| 字段类型|
|----fieldTip|否|String| 字段提示|
|----fieldNumber|否|Integer| 字段数量|
|----isRequired|否|Integer| 是否必填|
|--createName|否|String| 创建人|
|--createDate|否|DateTime| 创建时间|
|--online|否|Boolean| 项目已经有顾客预约或者开台，只允许修改项目名称和状态|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|
