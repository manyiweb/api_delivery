# 预约订单列表页查询
 服务：order-front

**请求URL：** 
- `/reserve/store/list/{source}`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|keyword|否|String||
|orderType|否|List||
|status|否|List||
|reserveDate|否|Object| 创建日期|
|--start|否|DateTime|起始对象 |
|--end|否|DateTime|结束对象 |
|createDate|否|Object| 创建日期|
|--start|否|DateTime|起始对象 |
|--end|否|DateTime|结束对象 |
|companyIds|否|List| 商户|
|joiningTraderCode|否|List| 所属加盟商|
|companyGID|否|List| 商户组|
|merchantsAreafCodes|否|String| 所属区域|
|distributorCode|否|List| 所属经销商|
|merchantsTypeCode|否|List| 商户类型|
|id|否|String| id|
|pageSize|否|Integer| 分页大小|
|pageNo|否|Integer| 页码|
|sortField|否|String| 排序字段|
|sortDirection|否|Object| 排序方向|

```
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--content|否|List| 数据内容|
|--pageSize|否|Integer| 分页大小|
|--pageNo|否|Integer| 分页页码|
|--total|否|Long| 数据总数|
|--totalPage|否|Integer| 总页数|
|--hasNextPage|否|Boolean| 是否有下一页|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|
