# 编辑预约单时间
 服务：retail-order-front
 

**请求URL：** 
- `/reserve/store/editTime`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||
|startDate|否|DateTime| 开台时间|
|consumptionTime|否|Integer| 消费时长（分钟）|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "startDate" : "DateTime",
 "consumptionTime" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
