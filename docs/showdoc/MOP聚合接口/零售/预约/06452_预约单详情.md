# 预约单详情
 服务：order-front
 

**请求URL：** 
- `/reserve/store/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long| id|
|sword|否|String| 指定商品搜索关键字|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "sword" : "String"
}
```
