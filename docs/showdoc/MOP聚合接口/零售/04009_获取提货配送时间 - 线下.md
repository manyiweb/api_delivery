# 获取提货配送时间 - 线下
 

**请求URL：** 
- `/app/shopping/cart/docTypeTakeDate `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 门店id|
|docType|否|String| 销售类型编码（不是购物车场景的要传该字段）|
|deliveryType|否|String| 提货配送方式编码（不是购物车场景的要传该字段）|
|shopCartKey|否|String| 如果是立即购买输入对应的立即购买cartKey|

###请求参数Json格式
 
```
{
 "companyId" : "String",
 "docType" : "String",
 "deliveryType" : "String",
 "shopCartKey" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--takeDateList|否|List||
|----takeDate|否|String| 提货配送日期|
|----takeTimeQuantums|否|String| 提货配送时间段|
|----showTakeDate|否|String| 提货配送时间显示|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : {
 "takeDateList" : [{
 "takeDate" : "String",
 "takeTimeQuantums" : "String",
 "showTakeDate" : "String"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
