# 获取商场日结单列表
 

**请求URL：** 
- `/app/shopping/daily/statement/list `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 主键|
|sword|否|String| 关键词|
|searchBeans|否|List| 高级筛选条件|
|--typeCode|否|String||
|--typeName|否|String||
|--dataType|否|String||
|--isSingle|否|String||
|--isLikeSearch|否|String||
|--items|否|List||
|----itemName|否|String||
|----itemValue|否|String||
|----minValue|否|String||
|----maxValue|否|String||
|----isCustom|否|String||
|----isRange|否|String||
|----isSelect|否|String||
|--current|否|Object||
|----itemName|否|String||
|----itemValue|否|String||
|----minValue|否|String||
|----maxValue|否|String||
|----isCustom|否|String||
|----isRange|否|String||
|----isSelect|否|String||
|--sword|否|String||
|--pageIndex|否|Integer||
|--pageSize|否|Integer||
|--curPageNum|否|Integer||
|--totalPage|否|Integer||
|--totalCount|否|Integer||
|pageIndex|否|Integer| 页号|
|pageSize|否|Integer| 页大小|
|orderField|否|String| 商品排序字段|
|orderSort|否|String| 商品排序方式 desc 倒序 asc 正序|

|--pageIndex|否|Integer| 页码|

|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|

|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|

|----orderNo|否|String| 单据编码|
|----status|否|Integer| 单据状态 0：已提交 1：已取消|
|----settlementDate|否|DateTime| 结算日期|
|----orderNumber|否|Integer| 订单总数|
