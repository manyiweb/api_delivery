# 新增日结单

**请求URL：** 
- `/app/shopping/daily/statement/save `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 如果保存的话需要传id|
|settlementDate|否|DateTime| 结算日期|
|remark|否|String| 备注|
|orderList|否|List| 订单列表|
|--orderId|否|String| 订单id|
|--orderNo|否|String| 订单号|
|--orderDate|否|DateTime| 单据日期|
|--realMoney|否|Double| 实付金额|
|--payStatus|否|String| 支付状态编码：NP("未收银"),BP("部分收银"),YP("已收银"),NR("待退款"),YR("已退款")|
|--payStatusName|否|String| 支付状态：NP("未收银"),BP("部分收银"),YP("已收银"),NR("待退款"),YR("已退款")|
|--docType|否|String| 功能类型编码: Booking("预售"),Retail("零售"),Wx("商城销售"),Integral("积分兑换"),CreditSale("赊销")|
|--docTypeName|否|String| 功能类型名称: Booking("预售"),Retail("零售"),Wx("商城销售"),Integral("积分兑换"),CreditSale("赊销")|
|--orderDocType|否|String| 订单类型编码|
|--orderDocTypeName|否|String| 订单类型名称|
|--orderStatus|否|String| 单据状态编码|
|--orderStatusName|否|String| 单据状态名称|

###请求参数Json格式
 
```
{
 "id" : 0,
 "settlementDate" : "DateTime",
 "remark" : "String",
 "orderList" : [{
 "orderId" : "String",
 "orderNo" : "String",
 "orderDate" : "DateTime",
 "realMoney" : 0,
 "payStatus" : "String",
 "payStatusName" : "String",
 "docType" : "String",
 "docTypeName" : "String",
 "orderDocType" : "String",
 "orderDocTypeName" : "String",
 "orderStatus" : "String",
 "orderStatusName" : "String"
 }]
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
