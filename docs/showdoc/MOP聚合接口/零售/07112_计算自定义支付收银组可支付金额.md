# 计算自定义支付收银组可支付金额
 

**请求URL：** 
- `/appc/custompay/group/customAmount`

**请求方式：**
- ALL
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|cashierGroupId|是|Long| 收银组id|
|companyId|否|String| 门店id|
|code|否|String| 支付编码|
|orderId|否|String| 用于二次支付|
|shopCartKey|否|String| shopCartKey|
|replaceSysNo|否|String| 用于支持点单商城访问会员商城接口|

### 请求参数Json格式
 
```
{
 "cashierGroupId" : 0,
 "companyId" : "String",
 "code" : "String",
 "orderId" : "String",
 "shopCartKey" : "String",
 "replaceSysNo" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--dataList|否|List||
|----id|否|Long||
|----code|否|String| 收银编码|
|----name|否|String| 收银名称|
|----logo|否|String| 图片地址|
|----isNew|否|Boolean||
|----amountInfo|否|Object| 金额设置|
|------canPayValue|否|Double| 客付款|
|------roundingValue|否|Double| 抹零金额|
|------itemsAmountActuallyPaid|否|Double| 总需要支付金额|
|------itemsAmountActuallyPaidRoundingAmount|否|Double| 抹零取整金额|
|------canChangeValue|否|Boolean| 是否可编辑金额|
|------openPremium|否|Boolean| 是否开启溢价|
|------canUseQuantity|否|Integer| 可使用的自定义支付数量|
|------storedValueCardDiscountCalculateResult|否|Object| 储值卡计算结果|
|--------enableCardDiscount|否|Boolean| 是否开启储值卡优惠|
|--------canPay|否|Boolean| 能否通过支付|
|--------originActuallyAmount|否|Double| 原先的实付金额|
|--------storedValueCardDiscountAmount|否|Double| 储值卡优惠金额|
|--------currentActuallyAmount|否|Double| 当前订单实付金额|
|--------lessMoney|否|Boolean| 是否少钱，储值卡余额小于打折后的金额就为false|
|--------cardPayAmount|否|Double| 购物卡支付的金额|
|--------orderProducts|否|List| 商品列表|
|----------orderItemId|否|String| 订单行id|
|----------actuallyPaid|否|Double| 商品订单实付金额(小计)|
|----------itemId|否|String| 商品ID|
|----------seriesId|否|String| 系列ID|
|----------itemTypeId|否|String| 分类id|
|----------brandId|否|String| 品牌ID|
|----------calcAmount|否|Double| 储值卡计算金额|
|----------storedValueCardDiscountAmount|否|Double| 储值卡优惠金额|
|----------inOrderCustomDiscount|否|Boolean| 是否参与订单自定义折扣|
|----------inCustomDiscount|否|Boolean| 是否参与行自定义折扣|
|----------inOrderCoupon|否|Boolean| 是否参与优惠券金额|
|----------inPromotion|否|Boolean| 是否参与促销优惠|
|----------itemTypeIds|否|List| 商品分类|
|----------totalRealPrice|否|Double||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
