# 获取储值订单详情

**请求URL：** 
- `retail-order-manager/stored/value/order/detail `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|

###请求参数Json格式
 
```
{
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--storedValueOrder|否|Object| 储值订单|
|----id|否|Long||
|----orderNo|否|String| 订单编号|
|----storedValueName|否|String| 储值名称|
|----storedValueAmount|否|Double| 储值金额|
|----salesDate|否|DateTime| 下单日期|
|----companyId|否|String| 门店id|
|----companyCode|否|String| 门店编码|
|----companyName|否|String| 门店名称|
|----memberPhone|否|String| 会员手机号码|
|----memberName|否|String| 会员名称|
|----invoiceStatus|否|Integer| 开票状态|
|----invoiceStatusName|否|String| 开票状态名称|
|----invoiceDate|否|DateTime| 开票日期|
|----createDate|否|DateTime| 创建日期|
|--invoiceList|否|List| 开票列表|
|----id|否|Long||
|----type|否|String| 发票类型|
|----typeName|否|String| 发票类型名称|
|----titleType|否|String| 抬头类型|
|----invoiceTitle|否|String| 发票抬头|
|----invoiceType|否|Integer| 开票类型1,正票;2,红票|
|----invoiceStatus|否|Integer| 开票状态 0未开票 1已开票 2 开票中 3已作废|
|----redPunch|否|Integer| 是否红冲 0否 1是|
|----taxpayerNumber|否|String| 税号|
|----bank|否|String| 开户银行|
|----bankAccount|否|String| 银行账号|
|----address|否|String| 地址|
|----phone|否|String| 电话|
|----remark|否|String| 失败原因|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
