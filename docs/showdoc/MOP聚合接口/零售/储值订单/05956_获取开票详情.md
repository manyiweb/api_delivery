# 获取开票详情

**请求URL：** 
- `/hr/retail/invoice/invoiceDetail `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|

###请求参数Json格式
 
```
{
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--id|否|String| 主键标识|
|--invoiceOrderRecordId|否|Long| 关联invoice_order_record订单发票记录表id|
|--lineNum|否|Long| 行号|
|--invoiceNumber|否|String| 发票号码|
|--invoiceDate|否|DateTime| 开票时间|
|--type|否|String| 发票类型（Special/General）|
|--typeName|否|String| 发票类型（增值税专用发票/增值税普通发票）|
|--thirdInvoiceLink|否|String| 第三方开票链接|
|--createId|否|String| 创建人id|
|--createName|否|String| 创建人|
|--createDate|否|DateTime| 创建时间|
|--dbKey|否|Integer| 分库标识|
|--groupId|否|String| 品牌商id|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : [{
 "id" : "String",
 "invoiceOrderRecordId" : 0,
 "lineNum" : 0,
 "invoiceNumber" : "String",
 "invoiceDate" : "DateTime",
 "type" : "String",
 "typeName" : "String",
 "thirdInvoiceLink" : "String",
 "createId" : "String",
 "createName" : "String",
 "createDate" : "DateTime",
 "dbKey" : 0,
 "groupId" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
