# 获取单个

**请求URL：** 
- `/retail/valuationItem/get `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|
|itemCode|否|String| 商品编码|
|itemName|否|String| 物品名称|
|itemType|否|String| 物品类型|
|itemId|否|String| 商品id|
|dailyInventory|否|Double| 每日限量|
|soldInventory|否|Double| 已售数量|
|lastInventory|否|Double| 剩余数量|
|itemSku|否|String| 商品sku|
|specId|否|String| 规格id|
|usePos|否|Integer| 使用到pos|
|useMall|否|Integer| 使用到商城|
|useMealMall|否|Integer| 使用到点餐商城|

###请求参数Json格式
 
```
{
 "id" : 0,
 "itemCode" : "String",
 "itemName" : "String",
 "itemType" : "String",
 "itemId" : "String",
 "dailyInventory" : 0,
 "soldInventory" : 0,
 "lastInventory" : 0,
 "itemSku" : "String",
 "specId" : "String",
 "usePos" : 0,
 "useMall" : 0,
 "useMealMall" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long| id|
|--itemCode|否|String| 商品编码|
|--itemName|否|String| 物品名称|
|--itemType|否|String| 物品类型|
|--itemId|否|String| 商品id|
|--dailyInventory|否|Double| 每日限量|
|--soldInventory|否|Double| 已售数量|
|--lastInventory|否|Double| 剩余数量|
|--specId|否|String| 规格id|
|--itemSku|否|String| 商品sku|
|--salePrice|否|Double| 销售价|
|--headImage|否|String| 商品图片|
|--headImageUrl|否|String| 商品全路径图片|
|--unit|否|String| 规格|
|--usePos|否|Integer| 使用到pos|
|--useMall|否|Integer| 使用到商城|
|--useMealMall|否|Integer| 使用到点餐商城|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
