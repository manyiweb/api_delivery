# 查询-根据订单查询同城配送时间

**请求URL：** 
- `/retail-shoppingcart-front/appc/shopping/cart/getMealTakeDates/order`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|否|String||
|shopCartKey|否|String| 如果是立即购买输入对应的立即购买cartKey|
|replaceSysNo|否|String| 用于支持点单商城访问会员商城接口|

### 请求参数Json格式
 
```
{
 "orderId" : "String",
 "shopCartKey" : "String",
 "replaceSysNo" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--sameCityDeliveryTimeSet|否|Boolean| 是否设置配送时间|
|--leadTimeRemark|否|String| 配货说明|
|--takeDates|否|List| 提货配送时间|
|----takeDate|否|String| 提货配送日期|
|----takeTimeQuantums|否|String| 提货配送时间段|
|----showTakeDate|否|String| 提货配送时间显示|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "sameCityDeliveryTimeSet" : true,
 "leadTimeRemark" : "String",
 "takeDates" : [{
 "takeDate" : "String",
 "takeTimeQuantums" : "String",
 "showTakeDate" : "String"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
