# 点餐退款详情（虎头局定制版接口）
 

**请求URL：** 
- `/appc/Refund/mealDetailRefund `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|否|String||

###请求参数Json格式
 
```
{
 "orderId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--mealWay|否|Integer||
|--totalMoney|否|Double| 总金额|
|--refundReason|否|String| 退货原因|
|--refundNo|否|String| 退货单号|
|--refundId|否|String| 退货单|
|--statusName|否|String| 退款单状态|
|--time|否|DateTime| 时间|
|--quantity|否|Double| 数量|
|--actionRecords|否|List| 退款流程|
|----orderId|否|String| 订单id|
|----actionType|否|Integer| 行为类型|
|----actionName|否|String| 行为名称|
|----recordType|否|Integer| 流程类型|
|----recordName|否|String| 流程名称|
|----recordTime|否|DateTime| 流程时间|
|--gatherings|否|List||
|----payType|否|String| 支付类型|
|----payTypeName|否|String| 支付类型描述|
|--mealRefundItemDtos|否|List||
|----itemName|否|String| 关联mitem商品 商品名称|
|----specName|否|String| 商品规格名称|
|----quantity|否|Double| 退货数量|
|----price|否|Double| 价格|
|----labelLines|否|List||
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
