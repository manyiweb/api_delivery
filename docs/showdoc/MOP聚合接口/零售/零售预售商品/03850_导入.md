# Excel 导入预定商品
 

**请求URL：** 
- `/retail/reserve/excelAddProduct `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|rowData|否|List| 行数据|
|companyId|否|String|门店id |

###请求参数Json格式
 
```
{
 "rowData" : null,
 "companyId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--totalCount|否|Integer| 导入总数量|
|--successCount|否|Integer| 成功导入数量|
|--errorCount|否|Integer| 失败数|
|--dataJson|否|List| 返回数据|
|--downloadURL|否|String| 失败数据下载地址|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : {
 "totalCount" : 0,
 "successCount" : 0,
 "errorCount" : 0,
 "dataJson" : null,
 "downloadURL" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
