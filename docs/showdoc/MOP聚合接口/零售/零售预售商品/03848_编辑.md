# 编辑
 

**请求URL：** 
- `/retail/reserve/edit `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long||
|onShelve|否|Boolean||
|openTimeLimit|否|Boolean||
|beginTime|否|String||
|endTime|否|String||
|price|否|String||
|specList|否|List||
|--id|否|String|规格id |
|--price|否|String|预定价格 |
|--reservePriceEnable|否|String|启用预定价格 |
|--startQuantity|否|String|起订量 |
|openStartQuantity|否|Boolean||
|startQuantity|否|String||
|openQuantityLimit|否|Integer| 是否启用预定数量控制(1是/0否)|
|totalQuantity|否|Double| 预定总数|
|openDeposit|否|Integer| 启用预付定金(1是/0否)|
|depositAmount|否|Double| 定金金额|
|balanceBeginTime|否|DateTime| 付尾款开始时间|
|balanceEndTime|否|DateTime| 付尾款结束时间|
|isAbleInShopCart|否|Boolean| 能否加入购物车|
|reservePriceEnable|否|Boolean|启用预定价格 |
|endTimeAutoOffShelveEnable|否|Boolean|启动预定时间结束自动下架 |
|noSurplusQuantityAutoOffShelveEnable|否|Boolean|启动剩余可用预订数量为0自动下架 |

###请求参数Json格式
 
```
{
 "id" : 0,
 "onShelve" : true,
 "openTimeLimit" : true,
 "beginTime" : "String",
 "endTime" : "String",
 "price" : "String",
 "specList" : [{
 "id" : "String",
 "price" : "String",
 "reservePriceEnable" : "String",
 "startQuantity" : "String"
 }],
 "openStartQuantity" : true,
 "startQuantity" : "String",
 "openQuantityLimit" : 0,
 "totalQuantity" : 0,
 "openDeposit" : 0,
 "depositAmount" : 0,
 "balanceBeginTime" : "DateTime",
 "balanceEndTime" : "DateTime",
 "isAbleInShopCart" : true,
 "reservePriceEnable" : true,
 "endTimeAutoOffShelveEnable" : true,
 "noSurplusQuantityAutoOffShelveEnable" : true
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
