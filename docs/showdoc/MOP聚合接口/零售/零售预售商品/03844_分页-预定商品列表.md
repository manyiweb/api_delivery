# 预定商品列表
 

**请求URL：** 
- `/retail/reserve/listProduct `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|pageIndex|否|Integer| 页码值|
|pageSize|否|Integer| 页大小|
|keyWord|否|String| 搜索关键字|
|onShelve|否|Integer| 是否上架|
|companyId|否|String|门店id |

###请求参数Json格式
 
```
{
 "pageIndex" : 0,
 "pageSize" : 0,
 "keyWord" : "String",
 "onShelve" : 0,
 "companyId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--pageIndex|否|Integer| 页码|
|--pageSize|否|Integer| 显示记录数|
|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|--first|否|Boolean| 首页|
|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|
|----itemId|否|String| 商品Id|
|----itemNo|否|String| 商品编号|
|----itemName|否|String| 商品名称|
|----reservePrice|否|String| 预定价格|
|----onShelve|否|Integer| 是否上架|
|----openTimeLimit|否|Integer| 启动预定时间|
|----beginTime|否|String| 开始时间|
|----endTime|否|String| 结束时间|
|----singleSpec|否|Integer| 是否单规格|
|----openStartQuantity|否|Integer| 是否启用起订量|
|----startQuantity|否|String| 起订量|
|----colorSizeMap|否|Object| 规格|
|----openQuantityLimit|否|Integer| 是否启用预定数量控制(1是/0否)|
|----totalQuantity|否|Double| 预定总数|
|----usedQuantity|否|Double| 占用量|
|----openDeposit|否|Integer| 启用预付定金(1是/0否)|
|----depositAmount|否|Double| 定金金额|
|----balanceBeginTime|否|DateTime| 付尾款开始时间|
|----balanceEndTime|否|DateTime| 付尾款结束时间|
|----isAbleInShopCart|否|Boolean| 能否加入购物车|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
