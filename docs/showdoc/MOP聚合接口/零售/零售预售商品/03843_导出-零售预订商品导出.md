# 预订商品列表-导出用
 

**请求URL：** 
- `/file/export/b2b/retailReserveProduct`

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|pageIndex|否|Integer| 页码值|
|pageSize|否|Integer| 页大小|
|keyWord|否|String| 搜索关键字|
|onShelve|否|Integer| 是否上架|
|companyId|否|String|门店id |

###请求参数Json格式
 
```
{
 "pageIndex" : 0,
 "pageSize" : 0,
 "keyWord" : "String",
 "onShelve" : 0,
 "companyId" : "String"
}
```
