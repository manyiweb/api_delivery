# 获取预定商品定金信息

**请求URL：** 
- `/retail/reserve/product/action/depositInfo `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long|预定商品id|

###请求参数Json格式
 
```
{
 "tokenId" : "String",
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--openDeposit|否|Boolean| 启用预付定金(1是/0否)|
|--depositAmount|否|Double| 定金金额|
|--balanceBeginTime|否|DateTime| 付尾款开始时间|
|--balanceEndTime|否|DateTime| 付尾款结束时间|
|--reserveSpecIdMap|否|Map| key-规格id， value下单用id|
|--beginTime|否|DateTime| 启动预定时间开始|
|--endTime|否|DateTime| 启动预定时间结束|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : {
 "openDeposit" : true,
 "depositAmount" : 0,
 "balanceBeginTime" : "DateTime",
 "balanceEndTime" : "DateTime",
 "reserveSpecIdMap" : null,
 "beginTime" : "DateTime",
 "endTime" : "DateTime"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
