# 代发单-调拨 -获取订单调拨跑腿状态一周汇总订单数

**请求URL：** 
- `/hq/transfer/date/count`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|startDate|否|DateTime| 开始时间|
|endDate|否|DateTime| 结束时间|
|companyId|否|String| 门店id|
|layOut|否|Integer| 版式 版式二传 2|
|transferErrandStatus|否|Integer| 代发单调拨跑腿状态 0待配送 1配送中 2已配送 (null代表全部)|

### 请求参数Json格式
 
```
{
 "startDate" : "DateTime",
 "endDate" : "DateTime",
 "companyId" : "String",
 "layOut" : 0,
 "transferErrandStatus" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--date|否|DateTime| 信息描述|
|--weekDay|否|String| 信息内容|
|--count|否|Double|关联config_retail_order_sup_value.id，用于编辑重现 |
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "date" : "DateTime",
 "weekDay" : "String",
 "count" : 0
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
