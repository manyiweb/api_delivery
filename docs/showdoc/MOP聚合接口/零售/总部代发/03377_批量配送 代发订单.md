# 批量配送 - 代发订单

**请求URL：** 
- `/app/sales/hq/batch/delivery `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|ms|否|List| 代发订单|
|--id|否|Long| 总部代发订单标识|
|--sourceOrderId|否|String| 原单标识|
|--companyId|否|String| 门店id|
|whsId|否|String| 发货仓库|
|items|否|List| 发货商品|
|--id|否|Long| 发货行|
|--mid|否|Long| 配送订单编号|
|--expressCompany|否|String| 物流商|
|--expressNumber|否|String| 物流单号|
|--quantity|否|Double| 发货数量|
|--remark|否|String| 备注|
|remark|否|String| 备注|

###请求参数Json格式
 
```
{
 "ms" : [{
 "id" : 0,
 "sourceOrderId" : "String",
 "companyId" : "String"
 }],
 "whsId" : "String",
 "items" : [{
 "id" : 0,
 "mid" : 0,
 "expressCompany" : "String",
 "expressNumber" : "String",
 "quantity" : 0,
 "remark" : "String"
 }],
 "remark" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--totalQty|否|Integer| 总数|
|--successQty|否|Integer| 成功数|
|--failQty|否|Integer| 失败数|
|--successOrders|否|List| 成功列表|
|----id|否|Long| 总部代发订单标识|
|----orderNo|否|String| 总部订单编码|
|----fail|否|Integer| 是否失败|
|----errorMsg|否|String| 错误信息|
|--failOrders|否|List| shi白|
|----id|否|Long| 总部代发订单标识|
|----orderNo|否|String| 总部订单编码|
|----fail|否|Integer| 是否失败|
|----errorMsg|否|String| 错误信息|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|

 },

}
