# 代发单-调拨 - 获取订单调拨跑腿状态汇总订单数 一天

**请求URL：** 
- `/hq/transfer/status/count`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|startDate|否|DateTime| 开始时间|
|endDate|否|DateTime| 结束时间|
|companyId|否|String| 门店id|
|layOut|否|Integer| 版式 版式二传 2|
|transferErrandStatus|否|Integer| 代发单调拨跑腿状态 0待配送 1配送中 2已配送 (null代表全部)|

### 请求参数Json格式
 
```
{
 "startDate" : "DateTime",
 "endDate" : "DateTime",
 "companyId" : "String",
 "layOut" : 0,
 "transferErrandStatus" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--waitDeliveryCount|否|Double| 待配送数量 (status=0)|
|--deliveringCount|否|Double| 配送中数量 (status=1)|
|--deliveredCount|否|Double| 已配送数量 (status=2)|
|--totalCount|否|Double| 总数 (三者之和)|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "waitDeliveryCount" : 0,
 "deliveringCount" : 0,
 "deliveredCount" : 0,
 "totalCount" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
