# 获取订单当天不同配送类型汇总订单数

**请求URL：** 
- `/hq/status/count`

**请求方式：**
- POST
- RequestBody

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--date|否|DateTime| 信息描述|
|--notAcceptCount|否|Double| 待结单数量|
|--acceptCount|否|Double| 已接单数量|
|--turnCount|否|Double| 已转单数量|
|--cancelCount|否|Double| 已取消数量|
|--totalCount|否|Double| 全部|
|--hideNotAcceptItem|否|Boolean| 隐藏待接单选项|
|--productionNotAllocationCount|否|Double| 待调拨收货数量|
|--productionAllocationCount|否|Double| 已调拨收货数量|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
