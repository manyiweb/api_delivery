# 商户前台——查询总部代发订单详情
 

**请求URL：** 
- `/mct/retail/hq/order/detail `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|

###请求参数Json格式
 
```
{
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long| 总部订单标识|
|--orderNo|否|String| 总部订单编码|
|--status|否|Integer| 状态 0-待发货 1-部分发货 2-已发货 3-已取消|
|--statusName|否|String| 状态名称|
|--sourceOrderId|否|String| 原单标识|
|--sourceOrderNo|否|String| 原单编码|
|--totalQuantity|否|Double| 总数|
|--totalAmount|否|Double| 合计金额|
|--totalRealAmount|否|Double| 实付金额|
|--remark|否|String| 总部订单备注|
|--orderType|否|Integer| 订单类型 0零售代发订单|
|--orderTypeName|否|String| 订单类型名称|
|--cancelName|否|String| 取消人名称|
|--cancelDate|否|DateTime| 取消时间|
|--orderDetail|否|Object| 原订单明细|
|----orderId|否|String| 订单标识|
|----orderNo|否|String| 订单号|
|----comapnyName|否|String| 门店名称|
|----docType|否|String| 单据类型编码|
|----docTypeName|否|String| 单据类型名称|
|----orderDocType|否|String| 功能类型编码|
|----orderDocTypeName|否|String| 功能类型名称|
|----orderStatus|否|String| 订单状态编码|
|----orderStatusName|否|String| 订单状态|
|----payStatus|否|String| 支付状态编码|
|----payStatusName|否|String| 支付状态|
|----memberName|否|String| 会员名称|
|----memberPhone|否|String| 会员手机号|
|----userName|否|String| 服务导购名称|
|----cashierName|否|String| 收银员|
|----remark|否|String| 备注|
|----refundApplyDate|否|DateTime| 申请退款时间|
|----refundAcceptName|否|String| 退款受理人|
|----refundAcceptDate|否|DateTime| 退款受理时间|
|----cancelDate|否|DateTime| 取消时间|
|----cancelName|否|String| 取消人|
|----postingDate|否|DateTime| 过账时间|
|----createDate|否|DateTime| 创建时间|
|----createName|否|String| 创建人名称|
|--deliverys|否|Object| 提货配送单列表|
|----first|否|Object||
|----last|否|Object||
|--sourceOrders|否|Object| 来源订单列表|
|----first|否|Object||
|----last|否|Object||
|--address|否|Object| 收货地址|
|----deliveryType|否|String| 配送方式编码|
|----deliveryTypeName|否|String| 配送方式名称|
|----deliveryDate|否|String| 预配送时间|
|----deliveryDateStr|否|String| 配送时间段|
|----consignee|否|String| 收货人|
|----address|否|String| 收货地址|
|----phone|否|String| 手机号|
|--companyName|否|String| 门店名称|
|--companyId|否|String| 门店标识|
|--pickedQuantity|否|Double| 已拣配数量|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
