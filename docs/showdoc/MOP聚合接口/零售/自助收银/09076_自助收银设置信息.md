# 自助收银设置信息

**请求URL：** 
- `/retail-order-fast/retail/self/checkout/get/info`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String||

### 请求参数Json格式
 
```
{
 "companyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--selfCheckoutSet|否|Object||
|----cartEnableOptionalItems|否|Boolean| 是否启用选配商品|
|----cartRelatedItemId|否|String| 关联商品ID|
|----cartRelatedItemName|否|String| 关联商品名称|
|----cartRelatedItemAlias|否|String| 关联商品别名|
|----orderDefaultTypeEnabled|否|Boolean| 是否启用默认订单类型|
|----orderTypeCode|否|String| 订单类型编码|
|----orderTypeName|否|String| 订单类型名称|
|----companyId|否|String| 门店标记|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "selfCheckoutSet" : {
 "cartEnableOptionalItems" : true,
 "cartRelatedItemId" : "String",
 "cartRelatedItemName" : "String",
 "cartRelatedItemAlias" : "String",
 "orderDefaultTypeEnabled" : true,
 "orderTypeCode" : "String",
 "orderTypeName" : "String",
 "companyId" : "String"
 }
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
