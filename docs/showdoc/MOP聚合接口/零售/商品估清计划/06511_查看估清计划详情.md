# 查看计划详情

**请求URL：** 
- `/retail/valuation/plan/detail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||
|pageIndex|否|Integer||
|pageSize|否|Integer||
|orderField|否|String||
|orderSort|否|String||
|sword|否|String||

### 请求参数Json格式
 
```

 "pageIndex" : 0,
 "pageSize" : 0,
```
