# 新自定义收银组退款
 

**请求URL：** 
- `/app/Business/Refund/Group/PayType `

**请求方式：**
- undefined
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|cashierGroupId|否|Long||
|orderId|否|String||

###请求参数Json格式
 
```
{
 "cashierGroupId" : 0,
 "orderId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--infoList|否|List||
|----cardNo|否|String||
|----code|否|String||
|----id|否|Long||
|----isNew|否|Boolean||
|----isSystem|否|Integer||
|----logo|否|String||
|----name|否|String||
|----payAmount|否|Double||
|----status|否|String||
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "infoList" : [{
 "cardNo" : "String",
 "code" : "String",
 "id" : 0,
 "isNew" : true,
 "isSystem" : 0,
 "logo" : "String",
 "name" : "String",
 "payAmount" : 0,
 "status" : "String"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
