# 新增/编辑-赊销结算单

**请求URL：** 
- `/app/Business/creditStatement/edit `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| ID|
|orderNo|否|String| 单据编码|
|orderDocTypeId|否|String| 单据类型id|
|orderDocType|否|String| 单据类型编码|
|orderDocTypeName|否|String| 单据类型名称|
|status|否|Integer| 单据状态(0-草稿，1-已完成，2-已取消,3-待结算)|
|statusName|否|String| 单据状态名称：0-草稿；1-已完成|
|companyId|否|String| 门店标识|
|companyCode|否|String| 门店编码|
|companyName|否|String| 门店名称|
|staffId|否|String| 导购标识|
|staffCode|否|String| 导购编码|
|staffName|否|String| 导购名称|
|memberId|否|String| 会员标识|
|memberPhone|否|String| 会员手机号|
|memberName|否|String| 会员名称|
|totalPaidAmount|否|Double| 收款总额|
|totalDiscountAmount|否|Double| 优惠总额|
|totalRealAmount|否|Double| 实际应收总额|
|totalRealPaidAmount|否|Double| 实际已支付总额|
|pcId|否|String| 支付配置标识，关联dpayconfig表|
|payType|否|String| 支付方式编码|
|payTypeName|否|String| 支付方式名称|
|payDate|否|DateTime| 付款日期|
|remark|否|String| 备注|
|createDate|否|DateTime| 创建日期|
|addBills|否|List| 新增/修改单据列表|
|--id|否|Long| ID|
|--creditStatementId|否|Long| 赊销结算单标识，关联credit_statement表|
|--orderId|否|String| 单据标识|
|--orderNo|否|String| 单据编号|
|--orderType|否|String| 单据类型：dorder(零售订单)，drefund(零售退货单)|
|--docType|否|String| 功能类型编码|
|--docTypeName|否|String| 功能类型名称|
|--orderDocType|否|String| 订单类型编码|
|--orderDocTypeName|否|String| 订单类型名称|
|--postingDate|否|DateTime| 过账日期|
|--payableAmount|否|Double| 应收金额|
|--paidAmount|否|Double| 已收金额|
|--unpaidAmount|否|Double| 未收金额|
|--thisPaidAmount|否|Double| 本次收款金额|
|--preferentialMoney|否|Double| 优惠金额|
|--thisPayableAmount|否|Double| 本次实际应收金额|
|--refundAmount|否|Double| 已退款金额|
|--remark|否|String| 备注|
|delBillIds|否|List| 删除关联单据Id集合|
|companyIds|否|List| 门店id集合|
