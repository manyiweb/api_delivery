# 功能描述: 分页查询-赊销结算单关联单据
 

**请求URL：** 
- `/app/Business/creditStatement/bill/list `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 业务ID|
|tokenId|否|String| 用户标识|
|pageIndex|否|Integer| 分页页码|
|pageSize|否|Integer| 分页大小|
|sword|否|String| 搜索关键字|

###请求参数Json格式
 
```
{
 "id" : 0,
 "tokenId" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "sword" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--pageIndex|否|Integer| 页码|
|--pageSize|否|Integer| 显示记录数|
|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|--first|否|Boolean| 首页|
|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|
|----id|否|Long| ID|
|----creditStatementId|否|Long| 赊销结算单标识，关联credit_statement表|
|----orderId|否|String| 单据标识|
|----docType|否|String| 功能类型编码|
|----docTypeName|否|String| 功能类型名称|
|----orderDocType|否|String| 订单类型编码|
|----orderDocTypeName|否|String| 订单类型名称|
|----postingDate|否|DateTime| 过账日期|
|----payableAmount|否|Double| 应收金额|
|----paidAmount|否|Double| 已收金额|
|----unpaidAmount|否|Double| 未收金额|
|----thisPaidAmount|否|Double| 本次收款金额|
|----preferentialMoney|否|Double| 优惠金额|
|----thisPayableAmount|否|Double| 本次实际应收金额|
|----remark|否|String| 备注|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
