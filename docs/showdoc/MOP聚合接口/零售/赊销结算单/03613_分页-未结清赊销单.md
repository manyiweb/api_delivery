# 分页-未结清赊销单

**请求URL：** 
- `/app/Business/creditSale/list `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|memberId|否|String| 会员标识|
|companyId|否|String| 门店标识|
|orderSort|否|String| 排序方式：desc(默认)/asc|
|companyIds|否|List| 门店id集合|
|tokenId|否|String| 用户标识|
|pageIndex|否|Integer| 分页页码|
|pageSize|否|Integer| 分页大小|
|sword|否|String| 搜索关键字|

###请求参数Json格式
 
```
{
 "memberId" : "String",
 "companyId" : "String",
 "orderSort" : "String",
 "companyIds" : null,
 "tokenId" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "sword" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--pageIndex|否|Integer| 页码|
|--pageSize|否|Integer| 显示记录数|
|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|--first|否|Boolean| 首页|
|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|
|----orderId|否|String| 单据标识|
|----orderNo|否|String| 单据编号|
|----orderType|否|String| 单据类型：dorder(零售订单)，drefund(零售退货单)|
|----docType|否|String| 功能类型|
|----docTypeName|否|String| 功能类型名称|
|----orderDocType|否|String| 订单类型|
|----orderDocTypeName|否|String| 订单类型名称|
|----createDate|否|DateTime| 过账日期|
|----payableAmount|否|Double| 应收金额|
|----paidAmount|否|Double| 已收金额|
|----refundAmount|否|Double| 退款金额|
|----unpaidAmount|否|Double| 未收金额|
|----orderStatus|否|String| 单据状态编码|
|----orderStatusName|否|String| 单据状态名称|
|----payStatus|否|String| 支付状态编码|
|----payStatusName|否|String| 支付状态名称|
|----remark|否|String| 备注|
|----postingDate|否|DateTime| 过账日期|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
