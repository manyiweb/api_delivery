# 功能描述: 查询-赊销结算单支付方式
 

**请求URL：** 
- `/app/Business/creditStatement/payType `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 商户标识|
|tokenId|否|String||

###请求参数Json格式
 
```
{
 "companyId" : "String",
 "tokenId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--pcId|否|String| 支付配置标识|
|--ptype|否|String| 支付方式编码|
|--ptypeName|否|String| 支付方式名称|
|--status|否|String| 活跃状态, 1 - 启用,0 - 停用|
|--statusName|否|String| 活跃状态|
|--version|否|Integer| 版本号|
|--stCode|否|String| 支付方式代码|
|--stName|否|String| 支付方式名称|
|--lineNum|否|Integer| 排序号|
|--img|否|String| 图片|
|--outsideCode|否|String| 外部编码|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : [{
 "pcId" : "String",
 "ptype" : "String",
 "ptypeName" : "String",
 "status" : "String",
 "statusName" : "String",
 "version" : 0,
 "stCode" : "String",
 "stName" : "String",
 "lineNum" : 0,
 "img" : "String",
 "outsideCode" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
