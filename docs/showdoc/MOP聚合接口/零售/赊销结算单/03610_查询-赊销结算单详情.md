# 详情-赊销结算单

**请求URL：** 
- `/app/Business/creditStatement/detail `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|

###请求参数Json格式
 
```
{
 "id" : 0
}
```

|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long| ID|

|--memberPhone|否|String| 会员手机号|
|--memberName|否|String| 会员名称|
|--totalPaidAmount|否|Double| 收款总额|
|--totalDiscountAmount|否|Double| 优惠总额|
|--totalRealAmount|否|Double| 实际应收总额|
|--totalRealPaidAmount|否|Double| 实际已支付总额|
|--pcId|否|String| 支付配置标识，关联dpayconfig表|
|--payType|否|String| 支付方式编码|
|--payTypeName|否|String| 支付方式名称|
|--payDate|否|DateTime| 收款日期|
|--remark|否|String| 备注|
|--payStatus|否|String| 支付状态:NP("未收银"),BP("部分收银"),YP("已收银")|
|--payStatusName|否|String| 支付状态名称:NP("未收银"),BP("部分收银"),YP("已收银")|
|--expireDate|否|DateTime| 找人代付支付过期时间|
|--creditStatementCompanyList|否|List||

|----creditStatementId|否|Long| 赊销结算单id|

|----companyName|否|String| 门店名称|

|----groupId|否|String| 品牌商id|
|--isSync|否|Integer| 是否已同步 1是 0否|
|--outOrderNo|否|String| 外部系统单号|
|--outSysName|否|String| 外部系统名称|
|--orderStatusRemark|否|String| 受理结果|
|--acceptRecords|否|List| 受理记录|
|----id|否|Long| id|
|----acceptId|否|Long| 单据受理标识，与order_accept表关联|
|----orderId|否|String| 单据标识|
|----level|否|Integer| 当前审核级|
|----statusCode|否|String| 受理状态|
|----statusName|否|String| 受理状态描述|
|----remark|否|String| 受理备注|
|----createId|否|String| 创建人标识|
|----createName|否|String| 创建人名称|
|----createDate|否|DateTime| 创建时间|
|----modifyId|否|String| 修改人标识|
|----modifyName|否|String| 修改人|
|----modifyDate|否|DateTime| 修改时间|
|----dbKey|否|Integer| 分库标识|
|----groupId|否|String| 品牌商id|
|--createId|否|String| 创建人id|
|--createName|否|String| 创建人|
|--createDate|否|DateTime| 创建时间|
|--modifyId|否|String| 修改人id|
|--modifyName|否|String| 修改人|
|--modifyDate|否|DateTime| 修改时间|
|--dbKey|否|Integer| 分库标识|
|--groupId|否|String| 品牌商id|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|
