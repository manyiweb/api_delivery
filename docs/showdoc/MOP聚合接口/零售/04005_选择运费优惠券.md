# 选择运费优惠券

**请求URL：** 
- `/app/shopping/cart/expressFeeCouponSelection `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|expressFeeCoupon|否|List||
|--expressFeeCouponId|否|String| 运费券优惠券ID|
|--expressFeeSku|否|String| 运费券优惠券唯一码，单个SKU|
|shopCartKey|否|String| 如果是立即购买输入对应的立即购买cartKey|

###请求参数Json格式
 
```
{
 "expressFeeCoupon" : [{
 "expressFeeCouponId" : "String",
 "expressFeeSku" : "String"
 }],
 "shopCartKey" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--errorTitleList|否|List||
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : {
 "errorTitleList" : null
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
