# 获取优惠券记录
 

**请求URL：** 
- `/report/couponGetRecord/getRecord `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|mcouponGetId|否|String| 优惠券获取id|

###请求参数Json格式
 
```
{
 "mcouponGetId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--id|否|Long| id|
|--couponId|否|String| 优惠券id|
|--couponGetId|否|String| 优惠券获取id|
|--changeCode|否|String| 变更类型|
|--changeCodeName|否|String| 变更名称|
|--changeDate|否|DateTime| 变更时间|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : [{
 "id" : 0,
 "couponId" : "String",
 "couponGetId" : "String",
 "changeCode" : "String",
 "changeCodeName" : "String",
 "changeDate" : "DateTime"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
