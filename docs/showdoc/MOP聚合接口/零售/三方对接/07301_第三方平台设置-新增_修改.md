# 第三方平台设置-新增/修改
 服务：reabam-extension-front
 

**请求URL：** 
- `/extension/platform/app/edit`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|platformCode|否|String||
|abilities|否|List||
|--abilityCode|否|String||
|--abilityName|否|String||

### 请求参数Json格式
 
```
{
 "platformCode" : "String",
 "abilities" : [{
 "abilityCode" : "String",
 "abilityName" : "String"
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long||
|--platformCode|否|String||
|--platformName|否|String||
|--logo|否|String||
|--createId|否|String||
|--createName|否|String||
|--createDate|否|DateTime||
|--modifyId|否|String||
|--modifyName|否|String||
|--modifyDate|否|DateTime||
|--abilities|否|List||
|----abilityCode|否|String||
|----abilityName|否|String||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "platformCode" : "String",
 "platformName" : "String",
 "logo" : "String",
 "createId" : "String",
 "createName" : "String",
 "createDate" : "DateTime",
 "modifyId" : "String",
 "modifyName" : "String",
 "modifyDate" : "DateTime",
 "abilities" : [{
 "abilityCode" : "String",
 "abilityName" : "String"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
