# 第三方平台授权(品牌端)-能力spi编辑
 

**请求URL：** 
- `/extension/platform/app/brand/spi/edit`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|platformCode|否|String||
|abilitys|否|List| 能力|
|--abilityCode|否|String| 能力编码|
|--abilityName|否|String| 能力名称|
|--abilityDes|否|String| 能力描述|
|--abilityScene|否|String| 能力使用场景，例如：会员、收银|
|--abilitySingle|否|String| 能力单选，为true时，仅只支持单平台对接|
|--active|否|Boolean| 是否活跃|
|--customizeSPIs|否|List||
|----abilityCode|否|String| 能力编码|
|----spiCode|否|String| spi编码|
|----spiName|否|String| spi名称|
|----spiUrl|否|String| spi访问地址|
|----modifyDate|否|DateTime| 修改时间|

### 请求参数Json格式
 
```
{
 "platformCode" : "String",
 "abilitys" : [{
 "abilityCode" : "String",
 "abilityName" : "String",
 "abilityDes" : "String",
 "abilityScene" : "String",
 "abilitySingle" : "String",
 "active" : true,
 "customizeSPIs" : [{
 "abilityCode" : "String",
 "spiCode" : "String",
 "spiName" : "String",
 "spiUrl" : "String",
 "modifyDate" : "DateTime"
 }]
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
