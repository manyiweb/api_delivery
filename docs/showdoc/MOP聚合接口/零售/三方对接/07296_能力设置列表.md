# 能力设置列表
 服务：reabam-extension-front
 

**请求URL：** 
- `/ability/setting/list`

**请求方式：**
- ALL
- FormData


### 请求参数<业务参数>
 
无参数


### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--code|否|String| 能力编码|
|--name|否|String|能力名称|
|--scene|否|String|系统场景|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "code" : "String",
 "name" : "String",
 "scene" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
