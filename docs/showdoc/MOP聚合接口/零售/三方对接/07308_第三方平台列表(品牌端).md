# 第三方平台列表(品牌端)
 

**请求URL：** 
- `/extension/platform/app/brand/list`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
无参数


### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--id|否|Long||
|--platformCode|否|String||
|--platformName|否|String||
|--appId|否|String| 应用id|
|--appSecret|否|String| 应用秘钥(前端需加密)|
|--logo|否|String||
|--config|否|String||
|--active|否|Boolean| 是否活跃|
|--customize|否|Boolean||
|--createId|否|String||
|--createName|否|String||
|--createDate|否|DateTime||
|--modifyId|否|String||
|--modifyName|否|String||
|--modifyDate|否|DateTime||
|--groupId|否|String||
|--customizeSPIs|否|List||
|----abilityCode|否|String||
|----abilityName|否|String||
|----spiCode|否|String||
|----spiName|否|String||
|----spiUrl|否|String||
|----modifyDate|否|DateTime||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
