# 新增第三方平台授权(品牌端)
 

**请求URL：** 
- `/extension/platform/app/brand/add`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|platformCode|是|String||
|appId|否|String| 应用id|
|appSecret|否|String| 应用秘钥(前端需加密)|
|config|否|String| 集成配置参数，以json格式保存|
|customize|否|Boolean| 是否自定义|

### 请求参数Json格式
 
```
{
 "platformCode" : "String",
 "appId" : "String",
 "appSecret" : "String",
 "config" : "String",
 "customize" : true
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long||
|--platformCode|否|String| 平台编码|
|--platformName|否|String| 平台名称|
|--appId|否|String| 应用id|
|--appSecret|否|String| 应用秘钥(前端需加密)|
|--logo|否|String| Logo|
|--config|否|String| 配置|
|--customize|否|Boolean||
|--abilitys|否|List| 能力|
|----abilityCode|否|String| 能力编码|
|----abilityName|否|String| 能力名称|
|----abilityDes|否|String| 能力描述|
|----abilityScene|否|String| 能力使用场景，例如：会员、收银|
|----abilitySingle|否|String| 能力单选，为true时，仅只支持单平台对接|
|----active|否|Boolean| 是否活跃|
|----customizeSPIs|否|List||
|------abilityCode|否|String| 能力编码|
|------spiCode|否|String| spi编码|
|------spiName|否|String| spi名称|
|------spiUrl|否|String| spi访问地址|
|------modifyDate|否|DateTime| 修改时间|
|--createId|否|String||
|--createName|否|String||
|--createDate|否|DateTime||
|--modifyId|否|String||
|--modifyName|否|String||
|--modifyDate|否|DateTime||
|--groupId|否|String||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
