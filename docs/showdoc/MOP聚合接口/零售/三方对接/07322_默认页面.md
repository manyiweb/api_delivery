# 第三方平台授权(品牌端) - 查询可用的能力+平台
 

**请求URL：** 
- `/extension/platform/app/brand/ability/platform/map`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
无参数


### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--items|否|List| 可用的能力列表|
|----abilityCode|否|String||
|----abilityName|否|String||
|--platformMap|否|Map| 平台映射数据，key为能力编码，值为平台编码+平台名称|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "items" : [{
 "abilityCode" : "String",
 "abilityName" : "String"
 }],
 "platformMap" : null
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
