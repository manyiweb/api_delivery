# 能力SPI查询列表
 服务：reabam-extension-front
 

**请求URL：** 
- `/ability/setting/spi/search`

**请求方式：**
- ALL
- FormData


### 请求参数<业务参数>
 
无参数


### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--code|否|String| SPI编码|
|--name|否|String| SPI名称|
|--ability|否|String| 关联能力|
|--expire|否|Long| 超时时间（ms）|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "code" : "String",
 "name" : "String",
 "ability" : "String",
 "expire" : 0
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
