# 第三方平台设置 - 根据平台编码查询明细
 服务：reabam-extension-front
 

**请求URL：** 
- `/extension/platform/app/getByCode`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
无参数


### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long||
|--platformCode|否|String||
|--platformName|否|String||
|--logo|否|String||
|--createId|否|String||
|--createName|否|String||
|--createDate|否|DateTime||
|--modifyId|否|String||
|--modifyName|否|String||
|--modifyDate|否|DateTime||
|--abilities|否|List||
|----abilityId|否|String||
|----abilityCode|否|String||
|----abilityName|否|String||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
