# 分组自定义支付列表
 

**请求URL：** 
- `/appc/custompay/groupCustomPay`

**请求方式：**
- ALL
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|cashierGroupId|是|Long| 收银组id|

### 请求参数Json格式
 
```
{
 "cashierGroupId" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--dataList|否|List||
|----id|否|Long||
|----code|否|String| 收银编码|
|----name|否|String| 收银名称|
|----logo|否|String| 图片地址|
|----isNew|否|Boolean||
|----payChannel|否|Integer||
|----ability|否|String||
|----platform|否|String||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "dataList" : [{
 "id" : 0,
 "code" : "String",
 "name" : "String",
 "logo" : "String",
 "isNew" : true,
 "payChannel" : 0,
 "ability" : "String",
 "platform" : "String"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
