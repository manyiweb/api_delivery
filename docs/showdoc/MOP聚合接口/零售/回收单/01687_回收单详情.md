# 回收单详情
 

**请求URL：** 
- `/product/recycle/get `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|
|sword|否|String| 搜素关键字|
|pageIndex|否|Integer| 页号|
|pageSize|否|Integer| 页大小|
