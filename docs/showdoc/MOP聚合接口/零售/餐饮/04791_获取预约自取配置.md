# 获取预约自取配置
 

**请求URL：** 
- `/catering/reserve/set `

**请求方式：**
- POST
- FormData


###请求参数<业务参数>
 
无参数


###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--reserveTimeType|否|Integer| 可预约自取时间类型 0、仅当天 1、指定天数|
|--reserveAfterDay|否|Integer| 可预约天数 填0则只开放下单时间当天，填1则开放到下单时间后一天|
|--reserveMinuteAfterOrder|否|Integer| 预约时间间隔 (相对订单时间)|
|--minutePeriod|否|Integer| 可选时间段间隔|
|--kitchenPrintAtTime|否|Boolean| 按指定时间打印后厨小票|
|--printBeforeReserve|否|Integer| 取餐时间x分钟前打印|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "reserveTimeType" : 0,
 "reserveAfterDay" : 0,
 "reserveMinuteAfterOrder" : 0,
 "minutePeriod" : 0,
 "kitchenPrintAtTime" : true,
 "printBeforeReserve" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
