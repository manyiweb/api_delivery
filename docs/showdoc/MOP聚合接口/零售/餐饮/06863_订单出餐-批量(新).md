# 订单出餐-批量
 

**请求URL：** 
- `/catering/kitchenOrder/kitchenOrderFinish/batch`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 门店ID|
|status|是|List| 查询状态|
|sortDirection|否|Integer| 数据排序 0-正序 1-倒序|
|orderType|否|Integer| 查看订单的类型（版式二才需要传）
 0——自取
 1——外卖
 2——全部
 3.线上自提
 4.线上配送|
|styleType|否|Integer| 版式|
|spOrderNo|否|String| 指定订单号(指定订单号后上述条件失效)|
|pageIndex|否|Integer| 页号|
|pageSize|否|Integer| 页大小|

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "status" : null,
 "sortDirection" : 0,
 "orderType" : 0,
 "styleType" : 0,
 "spOrderNo" : "String",
 "pageIndex" : 0,
 "pageSize" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
