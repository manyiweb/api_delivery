# 订单出餐结果校验
 

**请求URL：** 
- `/catering/kitchenOrder/kitchenOrderFinish/getOrderVerifyStatus`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderNos|否|List||

### 请求参数Json格式
 
```
{
 "orderNos" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--orderVerifyStatusMap|否|Map| 单号和审核状态的map
 map字段：
 status: 状态
 statusName: 状态中文描述
 sendOutError: 出餐异常
 status注释：
 40: "已下单"
 0: "待制作"
 5: "制作中"
 10: "待取餐"
 11: "出餐中"
 20: "已完成"
 30: "已取消"|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "orderVerifyStatusMap" : null
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
