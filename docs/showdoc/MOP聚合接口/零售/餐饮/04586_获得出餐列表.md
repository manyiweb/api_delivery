# 获得出餐列表
 

**请求URL：** 
- `/catering/kitchenOrder/listKitchenOrder `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 门店ID|
|status|否|List| 查询状态|
|sortDirection|否|Integer| 数据排序 0-正序 1-倒序|
|orderType|否|Integer| 查看订单的类型（版式二才需要传）0自取 1外卖 2全部| 4现取 5预定 6美团 7饿了么 8抖音 9京东
|styleType|否|Integer| 版式 0版式一 1版式二|
|pageIndex|否|Integer| 页号|
|pageSize|否|Integer| 页大小|

###请求参数Json格式
 
```
{
 "companyId" : "String",
 "status" : null,
 "sortDirection" : 0,
 "orderType" : 0,
 "pageIndex" : 0,
 "pageSize" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--pageIndex|否|Integer| 页码|
|--pageSize|否|Integer| 显示记录数|
|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|--first|否|Boolean| 首页|
|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|
|----id|否|Long| Id|
|----companyId|否|String| 门店ID|
|----orderNo|否|String| 订单号|
|----orderId|否|String| 订单id|
|----itemNames|否|String| 订单商品名称列表|
|----tableNumber|否|String| 牌号或桌号|
|----queueNumber|否|String| 取餐码|
|----status|否|Integer| 订单状态 0-待制作 10-待取餐 20-已完成 30-已取消|
|----statusName|否|String| 订单状态描述|
|----totalQuantity|否|Double| 总数|
|----retailOrderCreateDate|否|DateTime| 订单时间|
|----ifNotice|否|Integer| 是否可以发送点餐提醒|
|----mealWay|否|Integer| 取餐方式 0自取 1外卖|
|----interval|否|Integer| 间隔时间|
|----kitchenItems|否|List| 后厨订单商品行|
|------orderItemId|否|Long| 后厨订单明细ID|
|------itemName|否|String| 商品名称|
|------skuBarcode|否|String| sku码|
|------specId|否|String| 规格ID|
|------quantity|否|Double| 数量|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
