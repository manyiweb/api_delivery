# 批量出餐
 服务：reabam-retail
 把当前列表的订单全部出餐，参数参考 http://showdoc.reabam.com//web/#/6?page_id=4586

**请求URL：** 
- `/catering/kitchenOrder/kitchenOrderFinishV3`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 门店ID|
|status|是|List| 查询状态|
|sortDirection|否|Integer| 数据排序 0-正序 1-倒序|
|orderType|否|Integer| 查看订单的类型（版式二才需要传）
 0——自取
 1——外卖
 2——全部
 3.线上自提
 4.线上配送|
|styleType|否|Integer| 版式|
|pageIndex|否|Integer| 页号|
|pageSize|否|Integer| 页大小|

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "status" : null,
 "sortDirection" : 0,
 "orderType" : 0,
 "styleType" : 0,
 "pageIndex" : 0,
 "pageSize" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--pageIndex|否|Integer| 页码|
|--pageSize|否|Integer| 显示记录数|
|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|--first|否|Boolean| 首页|
|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : {
 "pageIndex" : 0,
 "pageSize" : 0,
 "pageCount" : 0,
 "totalCount" : 0,
 "first" : true,
 "last" : true,
 "content" : null
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
