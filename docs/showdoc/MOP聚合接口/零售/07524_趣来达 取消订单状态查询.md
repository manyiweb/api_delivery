# 趣来达 取消订单状态
retail 服务

**请求URL：** 
- `/app/sales/hq/qld/cancel/status`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|dhOrderId|否|Object| 代发订单id|

### 请求参数Json格式
 
```
{
 "dhOrderId" : null
}
```
