# 保存推荐商品设置

**请求URL：** 
- `/config/recommend/item/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 门店id|
|isInherit|是|Integer| 是否继承品牌|
|enableRecommendItemManagement|是|Boolean| 启用推荐商品管理|
|deleteIds|否|List| 要删除的商品行id|
|recommendItems|否|List| 商品列表|
|--id|否|Long||
|--itemId|否|String| 商品id|
|--itemCode|否|String| 商品编码|
|--itemName|否|String| 商品名称|
|--specId|否|String| 规格id|
|--sku|否|String| sku|
|--isActive|否|Boolean| 活跃状态|
|--relevanceItemNum|否|Integer| 关联商品数量|
|--relevanceItems|否|List| 关联商品信息|
|----itemId|否|String| 商品id|
|----itemCode|否|String| 商品编码|
|----itemName|否|String| 商品名称|
|----specId|否|String| 规格id|
|----sku|否|String| sku|

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "isInherit" : 0,
 "enableRecommendItemManagement" : true,
 "deleteIds" : null,
 "recommendItems" : [{
 "id" : 0,
 "itemId" : "String",
 "itemCode" : "String",
 "itemName" : "String",
 "specId" : "String",
 "sku" : "String",
 "isActive" : true,
 "relevanceItemNum" : 0,
 "relevanceItems" : [{
 "itemId" : "String",
 "itemCode" : "String",
 "itemName" : "String",
 "specId" : "String",
 "sku" : "String"
 }]
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
