# 获取推荐商品设置

**请求URL：** 
- `/config/recommend/item/config/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String||

### 请求参数Json格式
 
```
{
 "companyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--companyId|否|String| 门店id|
|--isInherit|否|Integer| 是否继承品牌|
|--enableRecommendItemManagement|否|Boolean| 启用推荐商品管理|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "companyId" : "String",
 "isInherit" : 0,
 "enableRecommendItemManagement" : true
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
