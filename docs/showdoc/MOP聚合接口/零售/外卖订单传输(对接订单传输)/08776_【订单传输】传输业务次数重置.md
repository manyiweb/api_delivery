# 【订单传输】传输业务次数重置
 接口前缀为：/reabam-retail-fast/
 

**请求URL：** 
- `/dock/order/task/push/reset/batch`

**请求方式：**
- undefined
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|ids|是|List| 传输任务id|
|groupId|是|String| 品牌标识|

### 请求参数Json格式
 
```
{
 "ids" : null,
 "groupId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--retrySuccess|否|Boolean| 是否重试成功|
|--retryResult|否|String| 重试结果备注|
|--id|否|Long| id|
|--fastOrderNo|否|String| 单号|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "retrySuccess" : true,
 "retryResult" : "String",
 "id" : 0,
 "fastOrderNo" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
