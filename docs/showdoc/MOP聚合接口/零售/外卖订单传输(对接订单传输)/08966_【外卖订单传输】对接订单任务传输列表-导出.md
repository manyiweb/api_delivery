# 【外卖订单传输】对接订单任务传输列表-导出
 接口前缀为：/reabam-retail-fast/

**请求URL：** 
- `/dock/order/task/list/export`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|keyword|否|String| 订单编号|
|typeCodes|否|List| 传输类型|
|companyIds|否|List| 商户|
|executeStatus|否|List| 处理状态|
|deleteFlag|否|List| 处理状态|
|executeDate|否|Object|执行时间 |
|--start|否|DateTime||
|--end|否|DateTime||
|createDate|否|Object|执行时间 |
|--start|否|DateTime||
|--end|否|DateTime||
|taskId|否|Long| 任务id|
|client|否|String| 操作系统|
|id|否|String||
|pageSize|否|Integer||
|pageNo|否|Integer||
|sortField|否|String||
|sortDirection|否|String||
|viewId|否|String||

### 请求参数Json格式
 
```
{
 "keyword" : "String",
 "typeCodes" : null,
 "companyIds" : null,
 "executeStatus" : null,
 "deleteFlag" : null,
 "executeDate" : {
 "start" : "DateTime",
 "end" : "DateTime"
 },
 "createDate" : {
 "start" : "DateTime",
 "end" : "DateTime"
 },
 "taskId" : 0,
 "client" : "String",
 "id" : "String",
 "pageSize" : 0,
 "pageNo" : 0,
 "sortField" : "String",
 "sortDirection" : "String",
 "viewId" : "String"
}
```

|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
