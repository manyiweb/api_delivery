# 新增或编辑结算单收银方式

**请求URL：** 
- `/superStatement/payConfig/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id，编辑的时候要传|
|cashierCode|是|String| 收银编码|
|cashierName|是|String| 收银名称|
|status|否|Boolean| 状态|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "cashierCode" : "String",
 "cashierName" : "String",
 "status" : true
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
