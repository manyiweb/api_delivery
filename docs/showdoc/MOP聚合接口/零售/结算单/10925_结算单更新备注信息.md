# 结算单更新收款方式

**请求URL：** 
- `/super/statement/updatePay`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|payType|是|String| 备注|
|payTypeName|是|String| 支付方式名称|
|id|是|Object||

### 请求参数Json格式
 
```
{
 "payType" : "String",
 "payTypeName" : "String",
 "id" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
