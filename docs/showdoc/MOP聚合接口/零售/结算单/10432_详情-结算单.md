# 详情-结算单

**请求URL：** 
- `/super/statement/detail`

**请求方式：** 
- `POST`
- `RequestBody`


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||

### 请求参数Json格式
 
```
{
 "id":0
}
```

### 响应参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long| id|
|--orderNo|否|String| 单据编码|
|--orderDocType|否|String| 单据类型编码|
|--orderDocTypeName|否|String| 单据类型名称|
|--status|否|Integer| 单据状态(draft-草稿,finish-已完成,cancel-已取消)|

|--acceptStatus|否|Integer| 受理状态|
|--memberId|否|String| 会员标识|
|--memberPhone|否|String| 会员手机号|
|--memberName|否|String||
|--superMemberId|否|String| 会员标识|
|--superMemberPhone|否|String| 会员手机号|
|--superMemberName|否|String||
|--totalPaidAmount|否|Double| 本次收款总额|
|--totalDiscountAmount|否|Double| 优惠总额|
|--totalRealAmount|否|Double| 本次实际应收总额|
|--pcId|否|String| 支付配置标识,关联dpayconfig表|
|--payType|否|String| 支付方式编码|

|--acceptRecords|否|List| 受理记录|

|----orderId|否|String||
|----level|否|Integer||
|----statusCode|否|String||

|----createId|否|String||
|----createName|否|String||
|----createDate|否|DateTime||
|----modifyId|否|String||
|----modifyName|否|String||
|----modifyDate|否|DateTime||
|--superStatementCompanyList|否|List||
|----id|否|Long| 主键|
|----superStatementId|否|Long| 赊销结算单id|
|----companyId|否|String| 门店id|
