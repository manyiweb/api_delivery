# 获取结算单结算详情

**请求URL：** 
- `/super/statement/payDetail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||

### 请求参数Json格式
 
```
{
 "id" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--creditStatement|否|Object| 赊销单信息|
|----id|否|Long| ID|
|----orderNo|否|String| 单据编码|
|----orderDocTypeId|否|String| 单据类型id|
|----orderDocType|是|String| 单据类型编码|
|----orderDocTypeName|是|String| 单据类型名称|
|----status|否|Integer| 单据状态(0-草稿，1-已完成，2-已取消,3-待结算)|
|----statusName|否|String| 单据状态名称：0-草稿；1-已完成|
|----superMemberId|是|String| 会员标识|
|----superMemberPhone|否|String| 会员手机号|
|----superMemberName|否|String| 会员名称|
|----totalPaidAmount|否|Double| 收款总额|
|----totalDiscountAmount|否|Double| 优惠总额|
|----totalRealAmount|否|Double| 实际应收总额|
|----totalRealPaidAmount|否|Double| 实际已支付总额|

|----payType|否|String| 支付方式编码|
|----payTypeName|否|String| 支付方式名称|
|----payDate|否|DateTime| 付款日期|
|----remark|否|String| 备注|

|------superStatementId|否|Long| 结算单标识，关联credit_statement表|
|------orderId|否|String| 单据标识|
|------orderNo|否|String| 单据编号|

|------payableAmount|否|Double| 应收金额|
|------paidAmount|否|Double| 已收金额|
|------unpaidAmount|否|Double| 未收金额|
|------thisPaidAmount|否|Double| 本次收款金额|
|------preferentialMoney|否|Double| 优惠金额|
|------thisPayableAmount|否|Double| 本次实际应收金额|
|------refundAmount|否|Double| 已退款金额|
|------remark|否|String| 备注|
|----delBillIds|否|List| 删除关联单据Id集合|
|----companyIds|否|List| 门店id集合|
|----attachment|否|List| 附件集合|
|--creditStatementBills|否|List| 赊销单单据列表|
|----id|否|Long| ID|
|----superStatementId|否|Long| 结算单标识，关联credit_statement表|
|----orderId|否|String| 单据标识|
|----orderNo|否|String| 单据编号|
|----orderType|是|String| 单据类型：dorder(门店订单)，cardSale(卡券销售)，cardSaleRefund(卡券退货)|
|----docType|否|String| 功能类型编码，卡券类型|
|----docTypeName|否|String| 功能类型名称 卡券类型名称|
|----orderDocType|否|String| 订单类型编码|
|----orderDocTypeName|否|String| 订单类型名称，卡券名称|
|----postingDate|否|DateTime| 过账日期|
|----payableAmount|否|Double| 应收金额|
|----paidAmount|否|Double| 已收金额|
|----unpaidAmount|否|Double| 未收金额|
|----thisPaidAmount|否|Double| 本次收款金额|
|----preferentialMoney|否|Double| 优惠金额|
|----thisPayableAmount|否|Double| 本次实际应收金额|
|----refundAmount|否|Double| 已退款金额|
|----remark|否|String| 备注|
|--expireDate|否|DateTime| 付款到期时间|
|--openWxPay|否|Boolean| 是否开启微信支付|
|--openAlipay|否|Boolean| 是否开启支付宝支付|
|--shareUrl|否|String| 分享链接|
|--alipayConfig|否|Object| 支付宝配置|
|----appId|否|String| appid|
|----webPageUrl|否|String| 网页地址|
|----title|否|String| 标题|
|----description|否|String| 描述|
|----thumbUrl|否|String| 封面图url|
|----shareUrl|否|String| 分享链接的url|
|--wxPayConfig|否|Object| 微信配置|
|----appId|否|String| appid|
|----miniProgramName|否|String| 小程序名称|
|----miniProgramPath|否|String| 分享的路径|
|----title|否|String| 标题|
|----description|否|String| 描述|
|----shareUrl|否|String| 分享链接|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
