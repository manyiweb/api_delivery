# 分页-结算单关联单据

**请求URL：** 
- `/retail/super/statement/bill/list`

**请求方式：** 
- `POST`
- `RequestBody`


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long||
|orderField|否|String||
|orderSort|否|String||

### 请求参数Json格式
 
```
{
 "id":0,
 "orderField":"String",
 "orderSort":"String"
}
```

### 响应参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--pageIndex|否|Integer||
|--pageSize|否|Integer||
|--pageCount|否|Integer||
|--totalCount|否|Long||
|--first|否|Boolean||
|--last|否|Boolean||
|--content|否|List||
|----id|否|Long| ID|
|----superStatementId|否|Long| 结算单标识，关联credit_statement表|
|----orderId|否|String| 单据标识|
|----orderNo|否|String| 单据编号|
|----orderType|是|String| 单据类型：Dorder(门店订单)，Drefund 退货单 SuperCardSale(卡券销售)，SuperCardRefund(卡券退货), B2BOrder(订货订单)|
|----orderTypeName|是|String| 单据类型：Dorder(门店订单)，Drefund 退货单 SuperCardSale(卡券销售)，SuperCardRefund(卡券退货), B2BOrder(订货订单)|
|----docType|否|String| 功能类型编码，卡券类型|
|----docTypeName|否|String| 功能类型名称 卡券类型名称|
|----orderDocType|否|String| 订单类型编码|
|----orderDocTypeName|否|String| 订单类型名称，卡券名称|
|----postingDate|否|DateTime| 过账日期|
|----payableAmount|否|Double| 应收金额|
|----paidAmount|否|Double| 已收金额|
|----unpaidAmount|否|Double| 未收金额|
|----thisPaidAmount|否|Double| 本次收款金额|
|----preferentialMoney|否|Double| 优惠金额|
|----thisPayableAmount|否|Double| 本次实际应收金额|
|----refundAmount|否|Double| 已退款金额|
|----remark|否|String| 备注|
|----attachmentId|否|String| 附件ID|
|----attachmentUrl|否|String| 附件相对地址|
|----attachmentFullUrl|否|String| 附件完整地址|
|----staffName|否|String| 服务导购名称|
|----cardType|否|String| 卡类型|
|----cardTypeName|否|String| 卡类型|
|----companyId|否|String| 门店id|
|----companyCode|否|String| 门店编码|
|----companyName|否|String| 门店名称|
|----thisInvoiceableAmount|否|Double| 本次可开票金额|
|----thisInvoiceAmount|否|Double| 本次已开票金额|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
