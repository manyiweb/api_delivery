# 快捷优惠设置

**请求URL：** 
- `/config/b2b/fastWayDiscount/fastWay/update`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 快捷优惠 每一项的id|
|fastWayDiscountType|否|Integer| 优惠类型 1、固定金额 2、固定折扣|
|discountValue|否|Double| 优惠值（金额/折扣）|
|discountRemark|否|String| 优惠说明|
|customDiscountWayId|否|Long| 快捷优惠id|
|companyId|否|String| 门店id|
|sort|否|Long| 排序|
|enableUseCondition|否|Boolean| 是否开启使用条件|
|enableLadder|否|Boolean| 是否启用阶梯|
|orderAmount|否|Double| 订单额度满，默认金额|
|canUseQty|否|Integer| 最多可使用数量|
|isEffective|否|Boolean| 有效期是否有效|
|effectiveStartDate|否|DateTime| 有效期开始时间|
|effectiveEndDate|否|DateTime| 有效期结束时间|
|notAccumulationOtherCoupon|否|Boolean| 不可叠加其他优惠(优惠券、促销、平台券) 使用|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "fastWayDiscountType" : 0,
 "discountValue" : 0,
 "discountRemark" : "String",
 "sort" : 0,
 "enableUseCondition" : true,
 "enableLadder" : true,
 "orderAmount" : 0,
 "canUseQty" : 0,
 "isEffective" : true,
 "effectiveStartDate" : "DateTime",
 "effectiveEndDate" : "DateTime",
 "notAccumulationOtherCoupon" : true
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
