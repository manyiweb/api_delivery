# 批量按规格级别上下架

**请求URL：** 
- `/product/mitem/batch/spec/opt`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|itemId|是|String| 商品id|
|specIds|是|List| 规格id|
|companyIds|是|List| 门店id|
|isUpAndDowm|否|Boolean| 是否上架还是下架 默认的批量下架|

### 请求参数Json格式
 
```
{
 "itemId" : "String",
 "specIds" : null,
 "companyIds" : null,
 "isUpAndDowm" : true
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
