# pos零售订单-修改提货人信息
 

**请求URL：** 
- `/order/updatePickupPerson`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|否|String| 订单id|
|pickupName|否|String| 提货人姓名|
|pickupPhone|否|String| 提货人手机号|

### 请求参数Json格式
 
```
{
 "orderId" : "String",
 "pickupName" : "String",
 "pickupPhone" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
