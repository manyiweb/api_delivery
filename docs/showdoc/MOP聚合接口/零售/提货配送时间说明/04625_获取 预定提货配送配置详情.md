# 获取 预定提货配送配置详情
 

**请求URL：** 
- `/product/retail/reserve/get/reserveItemRetailDeliveryConfig `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|reserveItemRetailId|否|Long| 零售预定商品ID|

###请求参数Json格式
 
```
{
 "reserveItemRetailId" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--isSchduled|否|Boolean| 按预定方式配送(1是 0否)|
|--lastDay|否|Integer| 截单时间，例如 1 = 周一|
|--lastTime|否|Object| 截单具体时间点，例如20:00:00|
|--deliveryDay|否|Integer| 预配送日|
|--preDeliveryMethod|否|Integer| 预配送时间（0 按天数 1 按固定日）|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "isSchduled" : true,
 "lastDay" : 0,
 "lastTime" : null,
 "deliveryDay" : 0,
 "preDeliveryMethod" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
