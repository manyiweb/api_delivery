# 订单评价查询
 

**请求URL：** 
- `/config/evaluation/set/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 门店id|

### 请求参数Json格式
 
```
{
 "companyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long| ID|
|--companyId|否|String| 门店id|
|--questionnaireId|否|Long| 问卷id|
|--questionnaireName|否|String| 问卷名称|
|--validateDay|否|Integer| 评价有效天数|
|--orderType|否|List| 可评价订单类型 offlineOrder线下 onlineOrder线上|
|--evaluateTarget|否|String| 评价类型（商品，订单）|
|--anonymousFlag|否|Boolean| 是否匿名|
|--ruleFlag|否|Boolean| 规则开关|
|--rule|否|String| 规则|
|--rewardFlag|否|Boolean| 是否奖励|
|--evaluateRewardCycle|否|String| 评价周期|
|--rewardIntegralFlag|否|Boolean| 积分奖励开关|
|--rewardIntegral|否|Double| 积分奖励|
|--rewardCouponFlag|否|Boolean| 积分奖励开关|
|--awardList|否|List| 奖励集合|
|----id|否|Long| ID|
|----evaluationSetId|否|Long| 评论配置id|
|----couponId|否|String| 优惠券id|
|----couponCode|否|String| 优惠券编码|
|----couponName|否|String| 优惠券名称|
|----couponType|否|String| 优惠券类型|
|----couponTypeName|否|String| 优惠券类型描述|
|----quantity|否|Integer| 数量|
|----createId|否|String| 创建人id|
|----createName|否|String| 创建人|
|----createDate|否|DateTime| 创建时间|
|----modifyId|否|String| 修改人id|
|----modifyName|否|String| 修改人|
|----modifyDate|否|DateTime| 修改时间|
|----dbKey|否|Integer| 分库标识|
|----groupId|否|String| 品牌商id|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|
