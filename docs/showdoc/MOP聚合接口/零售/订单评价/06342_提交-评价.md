# 提交-问卷

**请求URL：** 
- `/mem/evaluation/submit`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|questionnaireId|是|Long| 调查问卷标识|
|orderId|是|String| 订单标识|
|evaluationType|是|String| 页签类型 word("文字"), file("视频/图片")|
|itemAnswer|否|List| 订单标识|
|--itemId|是|String| 关联mitem商品 商品id|
|--itemCode|否|String| 关联商品mitem 商品编码|
|--itemName|否|String| 关联mitem商品 商品名称|
|--specId|否|String| 关联mitemSpec 商品规格表 规格id|
|--specName|否|String| 商品规格名称|
|--headImage|否|String| 商品图片路径|
|--questions|是|List| 评价列表|
|----questionId|是|Long| 问题标识|
|----questionOptionIds|否|List| 选项标识|
|----answer|否|String| 答案 多个文件用分号分割|
|--anonymousFlag|否|Boolean| 是否匿名|

### 请求参数Json格式
 
```
{
 "questionnaireId" : 0,
 "orderId" : "String",
 "evaluationType" : "String",
 "itemAnswer" : [{
 "itemId" : "String",
 "itemCode" : "String",
 "itemName" : "String",
 "specId" : "String",
 "specName" : "String",
 "headImage" : "String",
 "questions" : [{
 "questionId" : 0,
 "questionOptionIds" : null,
 "answer" : "String"
 }],
 "anonymousFlag" : true
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
