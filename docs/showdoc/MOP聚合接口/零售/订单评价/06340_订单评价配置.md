# 订单评价配置
 

**请求URL：** 
- `/config/evaluation/set/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| ID|
|companyId|否|String| 门店id|
|questionnaireId|否|Long| 问卷id|
|questionnaireName|否|String| 问卷名称|
|validateDay|否|Integer| 评价有效天数|
|orderType|否|List| 可评价订单类型 0线下 1线上 01线上和线下|
|evaluateTarget|否|String| 评价类型（商品，订单）|
|anonymousFlag|否|Boolean| 是否匿名|
|ruleFlag|否|Boolean| 规则开关|
|rule|否|String| 规则|
|rewardFlag|否|Boolean| 是否奖励|
|evaluateRewardCycle|否|String| 评价周期|
|rewardIntegralFlag|否|Boolean| 积分奖励开关|
|rewardIntegral|否|Double| 积分奖励|
|rewardCouponFlag|否|Boolean| 积分奖励开关|
|awardList|否|List| 奖励集合|
|--couponId|否|String| 优惠券id|
|--couponCode|否|String| 优惠券编码|
|--couponName|否|String| 优惠券名称|
|--couponType|否|String| 优惠券类型|
|--couponTypeName|否|String| 优惠券类型描述|
|--quantity|否|Integer| 数量|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "companyId" : "String",
 "questionnaireId" : 0,
 "questionnaireName" : "String",
 "validateDay" : 0,
 "orderType" : null,
 "evaluateTarget" : "String",
 "anonymousFlag" : true,
 "ruleFlag" : true,
 "rule" : "String",
 "rewardFlag" : true,
 "evaluateRewardCycle" : "String",
 "rewardIntegralFlag" : true,
 "rewardIntegral" : 0,
 "rewardCouponFlag" : true,
 "awardList" : [{
 "couponId" : "String",
 "couponCode" : "String",
 "couponName" : "String",
 "couponType" : "String",
 "couponTypeName" : "String",
 "quantity" : 0
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Integer| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : 0,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
