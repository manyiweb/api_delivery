# 查看评价列表列表

**请求URL：** 
- `/mem/evaluation/detail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|batchId|是|String| 批次id|

### 请求参数Json格式
 
```
{
 "batchId" : "String"
}
```
