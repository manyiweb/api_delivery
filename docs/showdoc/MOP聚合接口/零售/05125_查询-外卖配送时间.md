# 查询-外卖配送时间

**请求URL：** 
- `/appc/shopping/cart/getMealTakeDates `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|shopCartKey|否|String| 如果是立即购买输入对应的立即购买cartKey|
|pageType|否|Integer| 页面类型|

###请求参数Json格式
 
```
{
 "shopCartKey" : "String",
 "pageType" : "Integer"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--leadTimeRemark|否|String| 配货说明|
|--takeDates|否|List| 提货配送时间|
|----takeDate|否|String| 提货配送日期|
|----takeTimeQuantums|否|String| 提货配送时间段|
|----showTakeDate|否|String| 提货配送时间显示|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "leadTimeRemark" : "String",
 "takeDates" : [{
 "takeDate" : "String",
 "takeTimeQuantums" : "String",
 "showTakeDate" : "String"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
