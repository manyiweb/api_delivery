# 修改订单信息 配送时间 收货地址 下单信息 备注 附件
 

**请求URL：** 
- `/order/detail/update`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|是|String| 订单id|
|timeUpdateReq|否|Object| 配送时间|
|--chooseImmediateDelivery|否|Boolean| 是否为立即配送或立即自取|
|--deliveryType|否|String| xcth("到店自提"),shsm("快递配送");|
|--takeDate|否|DateTime| 配送时间|
|--takeTimeQuantums|否|String| 配送时间段|
|addressUpdateReq|否|Object| 配送地址|
|--orderId|否|String| 订单id|
|--consignee|否|String| 收货人|
|--address|否|String| 收货地址|
|--phone|否|String| 收货人手机号|
|--provinceCode|否|String| 省编码|
|--provinceName|否|String| 省|
|--cityCode|否|String| 城市编码|
|--cityName|否|String| 市|
|--regionCode|否|String| 区编码|
|--regionName|否|String| 区|
|--houseNumber|否|String| 门牌号|
|--xpoint|否|Double| XPoint|
|--ypoint|否|Double| YPoint|
|giverPhone|否|String| 下单人手机号|
|giverName|否|String| 下单人|
|giverGreeting|否|String| 祝福语|
|remark|否|String| 备注|
|storeRemark|否|String| 商家备注|
|orderItemUpdateReqs|否|List| 商品明细|
|--sourceOrderItemId|否|String| 订单明细id|
|--greeting|否|String| 祝福语|
|action|否|String| 操作 changeDelivery:自提转配送 changeTakeDate:修改自提时间 changeDeliveryTime:修改配送时间, changeTake:配送转自提 changeAddress:修改地址|
|addressId|否|String| 收货地址id|
|amount|否|Double| 金额|
|distance|否|Double| 距离|
|takeDateInfo|否|Object| 时间信息|
|--takeDate|否|DateTime| 自取时间|
|--takeTimeQuantums|否|String| 自提时间段|
|--pickupName|否|String| 提货人|
|--pickupPhone|否|String| 提货手机|
|uploadFileUrls|否|List| 附件|
