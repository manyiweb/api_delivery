# 商品周期购 - 新增

**请求URL：** 
- `/retail/order/cycleSale/add`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|
|companyId|是|String| 门店id|
|specId|是|String| 规格id|
|openValidDay|是|Integer| 启用有效期|
|beginDate|否|DateTime| 开始时间|
|endDate|否|DateTime| 结束时间|
|openQuantityLimit|是|Integer| 启用数量控制|
|totalQuantity|否|Double| 订购总数|
|tagGroupName|是|String| 订购标签组名|
|deliveryDays|是|List| 每期配送日|
|orderCutLastDay|是|Integer| 截单提前天数|
|orderCutLastTime|是|String| 截单时间|
|deliveryTypes|是|List| 配送方式：xcth-自提，shsm-配送|
|tags|是|List| 标签|
|--lineNo|是|Integer| 排序字段|
|--alias|是|String| 选项别名|
|--intervalCycle|是|Integer| 间隔周期|
|--deliveryCount|是|Double| 每次配送数量|
|--totalDeliveryCount|是|Integer| 总配送次数|
|--originPrice|否|Double| 划线价|
|--salePrice|是|Double| 正价|

```
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
