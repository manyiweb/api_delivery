# 去提货配送页面
 

**请求URL：** 
- `/order/delivery/toDelivery`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|否|String||
|needCombo|否|Boolean||

### 请求参数Json格式
 
```
{
 "orderId" : "String",
 "needCombo" : true
}
```
