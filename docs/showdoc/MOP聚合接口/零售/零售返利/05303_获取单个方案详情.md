# 获取单个方案详情

**请求URL：** 
- `/mem/rebatePlan/get `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long| id|

###请求参数Json格式
 
```
{
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long| 主键|
|--planName|否|String| 方案名称|
|--beginDate|否|DateTime| 有效期开始|
|--endDate|否|DateTime| 有效期结束|
|--activeState|否|Integer| 活跃状态 0：停用 1：启用|
|--info|否|String| 方案备注|
|--createDate|否|DateTime| 创建时间|
|--createName|否|String| 创建人|
|--applyCompType|否|Integer| 应用门店类型 1：所有门店 2：指定门店|
|--planStatus|否|Integer| 方案状态|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "planName" : "String",
 "beginDate" : "DateTime",
 "endDate" : "DateTime",
 "activeState" : 0,
 "info" : "String",
 "createDate" : "DateTime",
 "createName" : "String",
 "applyCompType" : 0,
 "planStatus" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
