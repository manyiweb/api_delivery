# 保存返利方案

**请求URL：** 
- `/mem/rebatePlan/saveOrUpdate `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 存在修改,不存在新增|
|planName|是|String| 方案名称|
|beginDate|是|DateTime| 有效期开始,格式"yyyy-MM-dd HH:mm"|
|endDate|是|DateTime| 有效期结束,格式"yyyy-MM-dd HH:mm"|
|activeState|是|Integer| 活跃状态 0：停用 1：启用|
|info|否|String| 方案说明|
|ruleList|是|List| 添加的关联规则集合|
|--id|否|Long| 主键|
|--ruleId|是|Long| 规则编号id|
|--ruleCode|是|String| 规则编号|
|--ruleName|是|String| 规则名称|
|deleteRuleIdList|否|List| 当前删除的规则集合|
|applyCompType|是|Integer| 应用门店类型 1：所有门店 2：指定门店|
|compList|否|List| 添加的关联门店集合|
|--companyId|是|String| 门店id|
|--companyCode|是|String| 门店编码|
|--companyName|是|String| 门店名称|
|deleteCompIdList|否|List| 当前删除的应用门店集合|

###请求参数Json格式
 
```
{
 "id" : 0,
 "planName" : "String",
 "beginDate" : "DateTime",
 "endDate" : "DateTime",
 "activeState" : 0,
 "info" : "String",
 "ruleList" : [{
 "id" : 0,
 "ruleId" : 0,
 "ruleCode" : "String",
 "ruleName" : "String",
 "createId" : "String",
 "createName" : "String",
 "createDate" : "DateTime"
 }],
 "deleteRuleIdList" : null,
 "applyCompType" : 0,
 "compList" : [{
 "companyId" : "String",
 "companyCode" : "String",
 "companyName" : "String"
 }],
 "deleteCompIdList" : null
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
