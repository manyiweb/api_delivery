# 维修单新增
 

**请求URL：** 
- `/product/aftersale/add`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 主键|
|orderType|是|String| 单据类型id|
|customerName|是|String| 顾客姓名|
|customerPhone|是|String| 顾客手机|
|addRemark|否|String| 接单备注|
|inSpecId|是|String| 维修规格id|
|inBarcode|否|String| 维修商品唯一码|
|inAttachBarcode|否|String| 维修商品附加码|
|appearanceId|是|Long| 外观现像|
|processingTypeId|是|Long| 处理类型|
|firstFaultDescription|否|String| 初检故障描述|
|maintenanceNetworkId|是|Long| 维修网点|
|estimateTakeDate|否|DateTime| 预取货时间|
|inkAbsorber|否|Integer| 是否有吸墨器 （1是 0否）|
|buyDate|否|DateTime| 购买日期|
|uploadFiles|否|List| 上传附件|
|sourceNo|否|String| 关联单号|
|tokenId|否|String| token标识|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "orderType" : "String",
 "customerName" : "String",
 "customerPhone" : "String",
 "addRemark" : "String",
 "inSpecId" : "String",
 "inBarcode" : "String",
 "inAttachBarcode" : "String",
 "appearanceId" : 0,
 "processingTypeId" : 0,
 "firstFaultDescription" : "String",
 "maintenanceNetworkId" : 0,
 "estimateTakeDate" : "DateTime",
 "inkAbsorber" : 0,
 "buyDate" : "DateTime",
 "uploadFiles" : null,
 "sourceNo" : "String",
 "tokenId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
