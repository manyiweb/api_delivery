# 维修单详情
 

**请求URL：** 
- `/mct/product/aftersale/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long| 主键|
|tokenId|否|String| token标识|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "tokenId" : "String"
}
```
