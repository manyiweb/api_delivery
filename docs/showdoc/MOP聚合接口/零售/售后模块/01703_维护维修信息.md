# 维护维修信息
 

**请求URL：** 
- `/product/aftersale/repair/edit `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 主键|
|maintenanceAmount|否|Double| 维修价格|
|remark|否|String| 备注|
|maintainerId|否|Long| 维修商id|
|maintenanceEngineer|否|String| 维修工程师|
|faultDescription|否|String| 最终故障描述|
|treatmentProcess|否|String| 处理过程描述|
|isChange|否|Integer| 是否启用换货（1是 0否）|
|newBarcode|否|String| 新序列号|
|newAttachBarcode|否|String| 新附加码|
|qualitySituationId|否|Long| 质检情况|
|orderType|否|String| 订单类型|

###请求参数Json格式
 
```
{
 "id" : 0,
 "maintenanceAmount" : 0,
 "remark" : "String",
 "maintainerId" : 0,
 "maintenanceEngineer" : "String",
 "faultDescription" : "String",
 "treatmentProcess" : "String",
 "isChange" : 0,
 "newBarcode" : "String",
 "newAttachBarcode" : "String",
 "qualitySituationId" : 0,
 "orderType" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
