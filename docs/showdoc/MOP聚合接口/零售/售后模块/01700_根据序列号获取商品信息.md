# 根据序列号获取商品信息
 

**请求URL：** 
- `/product/aftersale/barCode `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|barcode|否|String| 序列号|
|specId|否|String| 规格id(如果传了规格Id,将会验证 specId和barCode的关系)|
|stockStatus|否|Integer| 1查询在库 0查询不在库|
 
###请求参数Json格式
 
```
{
 "barcode" : "String"
}
```
