# 订单详情分页
 

**请求URL：** 
- `/wx/smallstore/order/detail/page `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|否|Long| 订单ID|
|tokenId|否|String| 用户标识|
|pageIndex|否|Integer| 分页页码|
|pageSize|否|Integer| 分页大小|
|sword|否|String| 搜索关键字|

###请求参数Json格式
 
```
{
 "orderId" : 0,
 "tokenId" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "sword" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--productPrice|否|Double| 商品金额|
|--orderPrice|否|Double| 实付金额|
|--freight|否|Double| 运费|
|--discountedPrice|否|Double| 订单优惠|
|--goodsPage|否|Object| 商品信息|
|----pageIndex|否|Integer| 页码|
|----pageSize|否|Integer| 显示记录数|
|----pageCount|否|Integer| 总页数|
|----totalCount|否|Long| 总记录数|
|----first|否|Boolean| 首页|
|----last|否|Boolean| 尾页|
|----content|否|List| 分页数据|
|------productId|否|Integer| 小商店内部商品ID|
|------skuId|否|Integer| 小商店内部skuID|
|------title|否|String| 商品名称|
|------skuCnt|否|Integer| sku数量|
|------salePrice|否|Double| 售卖价格|
|------productCnt|否|Integer| 已发货数量|
|------onAftersaleSkuCnt|否|Integer| 正在售后/退款流程中的sku数量|
|------finishAftersaleSkuCnt|否|Integer| 完成售后/退款的sku数量|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "productPrice" : 0,
 "orderPrice" : 0,
 "freight" : 0,
 "discountedPrice" : 0,
 "goodsPage" : {
 "pageIndex" : 0,
 "pageSize" : 0,
 "pageCount" : 0,
 "totalCount" : 0,
 "first" : true,
 "last" : true,
 "content" : [{
 "productId" : 0,
 "skuId" : 0,
 "title" : "String",
 "skuCnt" : 0,
 "salePrice" : 0,
 "productCnt" : 0,
 "onAftersaleSkuCnt" : 0,
 "finishAftersaleSkuCnt" : 0
 }]
 }
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
