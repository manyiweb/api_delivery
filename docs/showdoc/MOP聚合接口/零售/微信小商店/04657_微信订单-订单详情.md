# 订单详情
 

**请求URL：** 
- `/wx/smallstore/order/detail `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|否|Long| 订单ID|

###请求参数Json格式
 
```
{
 "orderId" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--companyName|否|String| 门店名称|
|--orderType|否|String| 单据类型|
|--status|否|String| 单据状态|
|--detil|否|Object| 基本信息|
|----companyName|否|String| 门店名称|
|----orderId|否|Long| 单据编号|
|----orderType|否|String| 单据类型|
|----status|否|String| 单据状态|
|----customerNotes|否|String| 备注|
|----wxCreateTime|否|DateTime| 创建时间|
|----returnId|否|String| 退货单号|
|--payInfo|否|Object| 支付信息|
|----productPrice|否|Double| 商品金额|
|----orderPrice|否|Double| 实付金额|
|----freight|否|Double| 运费|
|----discountedPrice|否|Double| 订单优惠|
|--payMethodInfos|否|List| 支付方式|
|----payMethod|否|String| 收款方式（目前只有"微信支付"）|
|----amount|否|Double| 收取金额|
|----transactionId|否|String| 交易单号|
|--deliveryInfo|否|Object| 配送信息|
|----deliveryMethod|否|String| 配送方式（目前只有"快递"）|
|----deliveryTime|否|DateTime| 发货时间|
|----userName|否|String| 收货人姓名|
|----address|否|String| 收货地址|
|--logisticsInfos|否|List| 物流信息|
|----deliveryId|否|String| 快递公司编号|
|----waybillId|否|String| 快递单号|
|----deliveryTime|否|DateTime| 发货时间|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
