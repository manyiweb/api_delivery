# 添加模板商品

**请求URL：** 
- `/product-front/product/template/detail/add`

**请求方式：**
- undefined
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 主键id|
|detailList|否|List| 商品|
|--itemId|否|String| 关联mitem商品 商品id|
|--itemCode|否|String| 关联商品mitem 商品编码|
|--itemName|否|String| 关联mitem商品 商品名称|
|--skuBarcode|否|String| 商品码|
|--specId|否|String| 关联mitemSpec 商品规格表 规格id|
|--specName|否|String| 商品规格名称|
|--itemType|否|String| 物品类型|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "detailList" : [{
 "itemId" : "String",
 "itemCode" : "String",
 "itemName" : "String",
 "skuBarcode" : "String",
 "specId" : "String",
 "specName" : "String",
 "itemType" : "String"
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
