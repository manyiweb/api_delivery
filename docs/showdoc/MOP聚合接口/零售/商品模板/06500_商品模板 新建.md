# 新建 修改商品模板(修改只修改模板,不修改模板商品）

**请求URL：** 
- `/product/template/save`

**请求方式：**
- undefined
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 主键id|
|templateName|是|String| 模板名称|
|templateType|是|Integer| 模板类型：0-商品沽清|
|status|否|Integer| 活跃状态 0关闭 1启用|
|remark|否|String| 备注|
|productType|否|String| 模板类型指定商品类型 item商品 type分类|
|detailList|否|List| 商品|
|--id|否|Long| id|
|--itemId|否|String| 关联mitem商品 商品id|
|--itemCode|否|String| 关联商品mitem 商品编码|
|--itemName|否|String| 关联mitem商品 商品名称|
|--skuBarcode|否|String| 商品码|
|--specId|否|String| 关联mitemSpec 商品规格表 规格id|
|--specName|否|String| 商品规格名称|
|--itemType|否|String| 物品类型|
|--quantity|是|Double| 数量|
|typeDetailList|否|List| 商品|
|--id|否|Long| id|
|--itemTypeId|否|String| 商品分类id|
|--itemTypeCode|否|String| 关联商品分类编码|
|--itemTypeName|否|String| 关联商品分类名称|
|--itemTypefcode|否|String| 分类编码|
|--quantity|否|Double| 数量|
|deleteIds|否|List| 删除id|

```
}
```
