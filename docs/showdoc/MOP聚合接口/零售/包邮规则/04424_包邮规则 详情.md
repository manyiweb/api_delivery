# 包邮规则 详情
 

**请求URL：** 
- `/app/manage/freeshippingrule/freeshippingruleinfo`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||

### 请求参数Json格式
 
```
{
 "id" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--isInheirt|否|Integer| 是否继承 0否 1是 同城配送的包邮规则不能继承|
|--id|否|Long||
|--deliveryType|否|Integer| 快递配送方式 0默认快递配送 1同城配送|
|--companyId|否|String| 门店id|
|--ruleNo|否|String| 规则编号 可以不传，不传默认生成，传不传看需求|
|--ruleName|是|String| 规则名称|
|--ruleStart|是|DateTime| 规则生效时间开始|
|--ruleEnd|是|DateTime| 规则生效时间结束|
|--ruleStatus|否|Boolean| 活跃状态 默认true|
|--enableEffectiveCycle|否|Boolean| 是否启用生效周期|
|--cycleType|否|Integer| 生效周期类型 0：按周 1：按月|
|--cycle|否|String| 周期 1,2,3,4,5,6,7 多选逗号隔开|
|--businessType|否|Integer| 1会员商城 2点单商城 默认会员商城|
|--applyType|否|Integer| 0所有商品 1指定商品 2指定分类 默认所有商品|
|--createName|否|String| 创建人|
|--createDate|否|DateTime| 创建时间|
|--calcAmountCondition|否|Integer| 计算运费订单金额条件，0：按整单金额、1：按包邮商品金额|
|--isExcludeItemType|否|Boolean| 是否排除分类|
|--billingMode|否|Integer| 计费方式 0:商品数量 1:商品重量 2:订单金额|
|--ruleItems|否|List| 应用商品|
|----itemId|否|String| 商品id|
|----itemCode|否|String| 商品编码|
|----itemName|否|String| 商品名称|
|----skuBarcode|否|String| sku|
|----specId|否|String| 规格id|
|----specName|否|String| 规格名称|
|--categorys|否|List| 指定品牌分类系列|
|----categoryType|否|Integer| 类别类型，1：品牌，2：系列 3：类别|
|----categoryId|否|String| 通用指定id 可以是品牌，系列或类别|
|----categoryCode|否|String| 编码|
|----categoryName|否|String| 名称|
|--specAttributes|否|List| 应用商品规格属性|
|----code|否|String| 属性值编号 例如 0、1、2|
|----name|否|String| 属性值名称|
|----values|否|List| 属性值|
|----content|否|String| 内容|
|----valueType|否|Integer| 类型|
|----contentId|否|String| 自定义内容id|
|--areaSets|是|List| 包邮区域|
|----id|否|Long||
|----amount|是|Double| 订单金额满X包邮|
|----free|否|Boolean| 是否包邮|
|----derateAmount|否|Double| 减免运费|
|----freeKm|否|Double| 包邮距离|
|----areas|否|List|区域列表 |
|------templateName|否|String| 模板名称|
|------templateId|否|Long| 模板名称|
|------level|是|Integer|区域等级 0广泛区域 1省 2市 3区 |
|------areaName|是|String|区域名称 |
|------areaId|是|String|区域id |
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
