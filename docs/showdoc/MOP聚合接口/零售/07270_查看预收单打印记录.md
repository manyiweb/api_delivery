# 查看预收单打印记录
 

**请求URL：** 
- `retail-order-front/order/print/query`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|sword|否|String||
|orderId|否|String| 单据id|
|dockOrderId|否|String| 商户ID或品牌ID|
|orderNo|否|String| 业务单据|

### 请求参数Json格式
 
```
{
 "sword" : "String",
 "orderId" : "String",
 "dockOrderId" : "String",
 "orderNo" : "String"
}
```
