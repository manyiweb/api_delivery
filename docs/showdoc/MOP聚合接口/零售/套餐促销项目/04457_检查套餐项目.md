# 检查套餐项目
 

**请求URL：** 
- `/app/shopping/cart/item/checkAddPromotionItem `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|itemId|否|String||
|specId|否|String| 规格ID|

###请求参数Json格式
 
```
{
 "itemId" : "String",
 "specId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--promotionCanUse|否|Boolean| 套餐促销是否能用|
|--containSpecialItem|否|Boolean| 是否有批次/标签/唯一码商品|
|--typeCode|否|Integer| 1组合 0固定|
|--projectId|否|String||
|--planId|否|String||
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : {
 "promotionCanUse" : true,
 "containSpecialItem" : true,
 "typeCode" : 0,
 "projectId" : "String",
 "planId" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
