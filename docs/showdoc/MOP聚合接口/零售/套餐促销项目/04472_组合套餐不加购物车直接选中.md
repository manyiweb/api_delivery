# 组合套餐不加购物车直接选中（如果有唯一码、批次、标签，调用该接口）
 

**请求URL：** 
- `/app/shopping/cart/item/addSpecialCombinationPackagePromotionItem`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|virtualSpecId|是|String||
|projectId|是|String||
|planId|是|String||
|quantity|否|Double| 套餐套数|
|customSuitPrice|否|Double| 套装总价-自定义|
|productList|否|List| 选中的商品列表|
|--bomId|是|String| 组合促销 - 商品促销清单ID|
|--specId|是|String| 规格ID|
|--quantity|是|Double| 商品数量|
|--labelGroups|否|List| 标签组|
|----labelSet|否|List| 标签ID组|
|----quantity|否|Double| 标签组数量|
|--uniqueCodeSet|否|List| 唯一码列表|
|--barcodeList|否|List| 唯一码|
|----barcode|否|String| 唯一码|
|----attachBarcode|否|String| 附加码|
|----attrs|否|List| 唯一码属性|
|------attrId|否|String| 唯一id|
|------code|否|Integer| 编码|
|------alias|否|String| 别名|
|------value|否|String| 值|
|------isRequired|否|Integer| 是否必填 1 - 必填, 0 - 不必填|
|------valueType|否|Integer| 0 任何值 1 序列|
|------content|否|String| 内容值,多个值时|
|------contentArr|否|Object||
|----isOpenUniqueCodeAttr|否|Integer| 启用唯一码属性- 行业属性|
|----specId|否|String| 规格ID|
|----remark|否|String| 唯一码备注|
|----mentityCardsResult|否|Object||
|------mid|否|String||
|------denomination|否|Double| 面额|
|------salesAdvice|否|Double| 售价|
|--batchList|否|List| 批次集合|
|----batchCode|否|String| 批次号|
|----productionDate|否|DateTime| 生产日期|
|----quantity|否|Double| 出库数量|
|----specId|否|String| 商品规格ID|
|----validDays|否|Integer| 保质期|
|----sourceDocItemId|否|String| 来源单据明细行ID|
|couponCode|否|String| 团购券券码|
|shopCartKey|否|String| 如果是立即购买输入对应的立即购买cartKey|
