# 用户接口请求次数

**请求URL：** 
- `/app/maipinpei/requestCountList `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|url|否|String| 地址|
|sword|否|String| 搜索条件|
|beginDate|否|DateTime| 开始日期|
|endDate|否|DateTime| 结束日期|

###请求参数Json格式
 
```
{
 "url" : "String",
 "sword" : "String",
 "beginDate" : "DateTime",
 "endDate" : "DateTime"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--userId|否|String| 用户id|
|--userCode|否|String| 用户编码|
|--userName|否|String| 用户名称|
|--currentDate|否|DateTime| 当前时间|
|--reqNum|否|Integer| 请求次数|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


###返回参数Json格式
 
```
{
 "data" : [{
 "userId" : "String",
 "userCode" : "String",
 "userName" : "String",
 "currentDate" : "DateTime",
 "reqNum" : 0
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
