# 获取配送方式列表
 

**请求URL：** 
- `/appc/shopCart/meal/way/delivery/list `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 取餐方式ID mealWay.id|
|shopCartKey|否|String| 如果是立即购买输入对应的立即购买cartKey|

###请求参数Json格式
 
```
{
 "id" : 0,
 "shopCartKey" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--deliveryWay|否|Integer| 配送方式 1同城配送 （目前点餐只有1）|
|--deliveryWayName|否|String| 默认用餐方式名称|
|--deliveryWayAlias|否|String| 点餐方式别名|
|--deliveryDefault|否|Integer| 是否为默认值 1是0否|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : [{
 "deliveryWay" : 0,
 "deliveryWayName" : "String",
 "deliveryWayAlias" : "String",
 "deliveryDefault" : 0
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
