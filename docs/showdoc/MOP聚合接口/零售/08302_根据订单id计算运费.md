# 根据订单id计算运费

**请求URL：** 
- `/retail-shoppingcart-front/appc/sales/order/expressFee/calculate`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|是|String| 订单ud|
|addressId|是|String| 地址id|

### 请求参数Json格式
 
```
{
 "orderId" : "String",
 "addressId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--distance|否|Double| 距离|
|--expressFee|否|Double| 运费|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "distance" : 0,
 "expressFee" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
