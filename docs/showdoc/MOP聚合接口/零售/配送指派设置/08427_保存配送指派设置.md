# 保存配送指派设置
 

**请求URL：** 
- `/config/delivery/assign/config/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|enableDeliveryAssign|是|Boolean| 是否启用配送指派能力|
|assignMode|否|Integer| 指派模式 0：手动指派 1：自动指派|
|companyId|是|String||

### 请求参数Json格式
 
```
{
 "enableDeliveryAssign" : true,
 "assignMode" : 0,
 "companyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
