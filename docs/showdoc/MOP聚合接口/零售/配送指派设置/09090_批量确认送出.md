# 批量确认送出

**请求URL：** 
- `/retail-order-front/order/batch/confirm/delivery`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderIds|是|List| 订单id|
|priorityDelivery|否|Boolean| 优先送订单确认送出，如果为true，则操作所有优先送的订单|
|longitude|否|Double| 经度|
|latitude|否|Double| 纬度|

### 请求参数Json格式
 
```
{
 "orderIds" : null,
 "priorityDelivery" : true,
 "longitude" : 0,
 "latitude" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
