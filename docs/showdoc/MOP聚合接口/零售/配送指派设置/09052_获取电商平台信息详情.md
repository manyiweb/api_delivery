# 获取电商平台信息详情
 

**请求URL：** 
- `/retail-order-front/e-commerce/platform/order/orderInfo`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|是|String| 订单id|

### 请求参数Json格式
 
```
{
 "orderId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--deliveryStatus|否|String| 配送状态 0：待分配门店、1：待指派、ND：待配送、ID：配送中、R4：已退款、AR：待退款、YF：已完成|
|--deliveryStatusName|否|String| 配送状态 中文名|
|--rejectRemark|否|String| 驳回备注|
|--errorMessage|否|String| 订单异常信息|
|--attachments|否|List| 附件|
|--companyDistributionRecords|否|List| 门店分配记录|
|----type|否|Integer| 类型 -1:自动分配门店失败 0:手动分配 1:自动分配 2:门店驳回 3已完成 4：订单生成 5:待分配门店 6：订单回退到上一级 7：配送中 8：配送完成 9：待退款 10：拒绝退款 11：已退款 12：标记异常 13：自动分配配送员失败 14:分配配送员,15:更改配送员|
|----typeName|否|String||
|----companyName|否|String| 分配/驳回门店|
|----createName|否|String| 操作人|
|----createDate|否|DateTime| 时间|
|----remark|否|String| 备注|
|----groupName|否|String| 区域公司|
|----userId|否|String| 导购id|
|----userCode|否|String| 导购编码|
|----userName|否|String| 导购名称|
|----attachments|否|List| 附件|
|----description|否|String| 补充说明|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
