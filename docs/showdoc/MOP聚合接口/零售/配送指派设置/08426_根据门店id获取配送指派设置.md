# 根据门店id获取配送指派设置
 

**请求URL：** 
- `/config/delivery/assign/config/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String||

### 请求参数Json格式
 
```
{
 "companyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--enableDeliveryAssign|否|Boolean| 是否启用配送指派能力|
|--assignMode|否|Integer| 指派模式 0：手动指派 1：自动指派|
|--staffId|否|String| 默认导购id|
|--staffName|否|String| 默认导购名称|
|--enableXnPlatform|否|Boolean| 启用对接新鸟平台订单|
|--assignCompanyType|否|Integer| 指派门店类型 0：指定门店 1:按最近门店分配|
|--assignCompanyId|否|String| 指定门店id|
|--assignCompanyName|否|String| 指定门店名称|
|--distance|否|Double| 距离|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "enableDeliveryAssign" : true,
 "assignMode" : 0,
 "staffId" : "String",
 "staffName" : "String",
 "enableXnPlatform" : true,
 "assignCompanyType" : 0,
 "assignCompanyId" : "String",
 "assignCompanyName" : "String",
 "distance" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
