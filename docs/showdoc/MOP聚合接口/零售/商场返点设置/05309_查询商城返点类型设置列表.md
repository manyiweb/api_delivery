# 查询商城返点类型设置列表
 

**请求URL：** 
- `/config/rebateReward/list`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|type|是|Integer| 商场返点设置类型： 0-所有商品 1-指定分类 2-指定品牌|
|companyId|是|String| 门店id|
|sword|否|String||
|tokenId|否|String||
|id|否|String||
|orderField|否|String| 排序字段|
|orderSort|否|String| 排序方式|
|searchBeans|否|List| 高级筛选条件|
|--typeCode|否|String||
|--typeName|否|String||
|--dataType|否|String||
|--isSingle|否|String||
|--isLikeSearch|否|String||
|--items|否|List||
|--current|否|Object||
|----itemName|否|String||
|----itemValue|否|String||
|----minValue|否|String||
|----maxValue|否|String||
|----isCustom|否|String||
|----isRange|否|String||
|----isSelect|否|String||
|--sword|否|String||
|--pageIndex|否|Integer||
|--pageSize|否|Integer||
|--curPageNum|否|Integer||
|--totalPage|否|Integer||
|--totalCount|否|Integer||
|status|否|Integer| 状态|
|pageIndex|否|Integer| 页号|
|pageSize|否|Integer| 页大小|
|orderField|否|String| 商品排序字段|
|orderSort|否|String| 商品排序方式 desc 倒序 asc 正序|
