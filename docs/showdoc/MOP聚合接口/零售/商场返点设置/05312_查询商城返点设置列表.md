# 查询商城返点设置列表

**请求URL：** 
- `/config/rebateRewardDetail/list`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|rebateRewardTypeId|是|Long| 商场返点类型id|

### 请求参数Json格式
 
```
{
 "rebateRewardTypeId" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|array| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


#### data

|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|number| id|
|companyId|是|String| 门店id|
|type|是|String| 返点类型|
|value|是|String| 返点值|
|beginDate|是|Date| 开始时间|
|endDate|是|Date| 结束时间|


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
