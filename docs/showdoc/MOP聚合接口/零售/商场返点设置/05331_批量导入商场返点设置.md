# 批量导入商场返点设置
 

**请求URL：** 
- `/file/config/rebateReward/import`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|file|是|binary|文件|

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|dataSource|否|List||
|downloadURL|否|String| 错误数据下载地址|
|totalCount|否|Long| 总数|
|successCount|否|Long| 成功数|
|errorCount|否|Long| 错误数|


### 返回参数Json格式
 
```
{
 "dataSource" : null,
 "downloadURL" : "String",
 "totalCount" : 0,
 "successCount" : 0,
 "errorCount" : 0
}
```
