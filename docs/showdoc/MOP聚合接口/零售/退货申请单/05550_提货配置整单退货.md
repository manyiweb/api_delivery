# 提货配置整单退货
 

**请求URL：** 
- `/app/Business/Refund/RefundPayByOrder `

**请求方式：**
- undefined
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|是|String| 订单id|
|orderNo|否|String| 订单编号|
|payType|是|String| 支付类型|
|deliveryId|是|String| 提货单id|

###请求参数Json格式
 
```
{
 "orderId" : "String",
 "orderNo" : "String",
 "payType" : "String",
 "deliveryId" : "String"
}
```
