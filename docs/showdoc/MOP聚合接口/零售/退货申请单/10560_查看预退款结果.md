# 查看预退款结果
 

**请求URL：** 
- `/app/Business/prefund/Detail`

**请求方式：**
- undefined
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||
|pageIndex|否|Integer||
|pageSize|否|Integer||
|orderField|否|String||
|orderSort|否|String||
|sword|否|String||

### 请求参数Json格式
 
```
{
 "id" : 0,
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String",
 "sword" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long||
|--refundNo|否|String| 退货单号|
|--refundStatus|否|String| 退货单-退货状态编码： fail失败 paying退款中 refund已退款|
|--refundMoney|否|Double| 总金额|
|--requestJson|否|String| 请求参数|
|--payMoney|否|Double| 总数量|
|--orderId|否|String| 关联销售订单表dorder 订单id|
|--orderNo|否|String| 销售单号|
|--companyId|否|String| 门店商户id,与商户表syscompany相关联|
|--companyName|否|String| 门店商户名称|
|--tradeNo|否|String| 交易单号|
|--partRefund|否|Boolean| 是否部分退|
|--authJson|否|String| 授权信息|
|--dgatheringId|否|String| 收银流水id|
|--createId|否|String||
|--createName|否|String||
|--createDate|否|DateTime||
|--modifyId|否|String||
|--modifyName|否|String||
|--modifyDate|否|DateTime||
|--dbKey|否|Integer||
|--groupId|否|String||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
