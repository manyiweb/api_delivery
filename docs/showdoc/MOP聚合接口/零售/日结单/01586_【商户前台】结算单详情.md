# 结算单详情
 

**请求URL：** 
- `/hr/statement/detail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
无参数

|data|否|Object| 主数据|
|--id|否|String| id|
|--companyId|否|String| 门店ID|
|--companyName|否|String| 门店名称|

|--checkingAmount|否|Double| 对账金额|
|--diffCollectionChecking|否|Double| 差异金额|

|----methodName|否|String| 名称|
|----companyId|否|String| 门店id|

|----fid|否|String| 交接班标识|

|----startTime|否|DateTime| 开班时间|

|----serviceCardTotal|否|Double| 购物卡充值|
|----createDate|否|DateTime| 创建时间|

|----wxOrderTotal|否|Double| 微商城订单金额总计|
|----businessTotal|否|Double| 门店营业总额|
|----orderMoneyTotal|否|Double| 线下订单金额|
|----refudnmoneyTotal|否|Double| 线下退货金额|
|----wxRefudnmoneyTotal|否|Double| 线上退货金额|
|----savingsTotal|否|Double| 储蓄卡消费总金额|
|----equityDataTotal|否|Double| 权益有效期充值|

|----dhItems|否|List||
|------fid|否|String||

|------mid|否|String| 交接班标识，与dhandover关联|
|------linNum|否|Integer| 行号|

|------dbKey|否|Integer| 分库标识|
|------groupId|否|String| 品牌商id|
|----reDataList|否|List| 充值记录明细|
|----businessData|否|Map| 门店营业总额明细|
|----reDataJson|否|String| 充值明细json格式字符串|
|----savingsList|否|List| 储蓄卡消费金额|
|----equityDataList|否|List| 权益有效期充值|
|----startTimeStr|否|String||
|----endTimeStr|否|String||
|----entitysTotal|否|Double| 实体卡券消费金额|
|----entitysList|否|List| 实体卡券消费|
|----entityRechargeTotal|否|Double| 实体卡充值金额|
|----entityRechargeDataList|否|List| 实体卡充值|
|----entityRechargeJson|否|String||
|----moneyTotalWithoutRechargeTotal|否|Double| 门店实收金额(排除储值卡充值)|
|----hdType|否|Integer| 0按门店 1按导购|
|----dbKey|否|Integer| 分库标识|
|----groupId|否|String| 品牌商id|
|--statementSn|否|String| 单据编码|
|--typeName|否|String| 单据类型|
|--createDate|否|String| 单据日期|
|--finishDate|否|String| 结算日期|
