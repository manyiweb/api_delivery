# 回款类型-列表
 

**请求URL：** 
- `/hr/statement/transferMethod/list `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|sword|否|String||
|companyId|否|String||
|pageIndex|否|Integer| 页号|
|pageSize|否|Integer| 页大小|

###请求参数Json格式
 
```
{
 "sword" : "String",
 "companyId" : "String",
 "pageIndex" : 0,
 "pageSize" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long| id|
|--modifyId|否|String| 修改人id|
|--modifyName|否|String| 修改人|
|--modifyDate|否|DateTime| 修改时间|
|--createId|否|String| 修改人id|
|--createName|否|String| 修改人|
|--createDate|否|DateTime| 创建时间|
|--del|否|Boolean| 是否删除|
|--sort|否|Long| 排序|
|--methodName|否|String| 名称|
|--companyId|否|String| 门店id|
|--companyName|否|String| 门店名称|
|--dbKey|否|Integer| 分库标识|
|--groupId|否|String| 品牌商id|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "modifyId" : "String",
```
