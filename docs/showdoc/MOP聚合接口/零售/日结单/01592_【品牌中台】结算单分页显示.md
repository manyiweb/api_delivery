# 结算单分页显示
 

**请求URL：** 
- `/hr/statement/list `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|sword|否|String||
|pageIndex|否|Integer| 页号|
|pageSize|否|Integer| 页大小|

###请求参数Json格式
 
```
{
 "sword" : "String",
 "pageIndex" : 0,
 "pageSize" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long| id|
|--modifyId|否|String| 修改人id|
|--modifyName|否|String| 修改人|
|--modifyDate|否|DateTime| 修改时间|
|--createId|否|String| 修改人id|
|--createName|否|String| 修改人|
|--createDate|否|DateTime| 创建时间|
|--companyId|否|String| 门店ID|
|--companyName|否|String| 门店名称|
|--statementSn|否|String| 单据编码|
|--statementType|否|Integer| 单据类型|
|--typeName|否|String| 单据类型名称|
|--statementStatus|否|Integer| 单据状态|
|--statusName|否|String| 状态名称|
|--remark|否|String| 备注|
|--finishDate|否|DateTime| 结算日期|
|--collectionAmount|否|Double| 系统收款金额|
|--checkingAmount|否|Double| 对账金额|
|--diffCollectionChecking|否|Double| 差异金额|
|--preCashBalance|否|Double| 现金上期结存|
|--cashBalance|否|Double| 现金本期结存|
|--adjustCashBalance|否|Double| 本期调整金额|
|--transferAmount|否|Double| 现金回款金额|
|--groupId|否|String| 品牌商id|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
