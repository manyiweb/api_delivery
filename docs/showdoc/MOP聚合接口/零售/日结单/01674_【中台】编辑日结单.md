# 修改日结单
 

**请求URL：** 
- `/hr/statement/generate/edit`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|否|String||
|id|否|String| id|
|specifyDate|是|DateTime| 指定结算日期|
|adjustCashBalance|否|Double| 本期调整金额|
|remark|否|String| 备注|
|isAudit|是|Integer| 提交审核|
|dailyStatementIncomeList|否|List| 收款情况|
|--payTypeCode|否|String| 收款方式|
|--checkingAmount|否|Double| 对账单金额|
|--remarks|否|String| 行备注|
|--customPayQuantity|否|Double| 自定义收银系统收款数量|
|--checkingQuantity|否|Double| 对账单数量|
|statementTransferList|否|List| 现金回款情况|
|--id|否|Long| id|
|--modifyId|否|String| 修改人id|
|--modifyName|否|String| 修改人|
|--modifyDate|否|DateTime| 修改时间|
|--createId|否|String| 修改人id|
|--createName|否|String| 修改人|
|--createDate|否|DateTime| 创建时间|
|--transferMethodId|否|Long| 回款类型(statement_transfer_method)关联|
|--transferAmount|否|Double| 回款金额|
|--transferMethodName|否|String| 回款类型名称|
|--remark|否|String| 备注|
|--remitter|否|String| 回款人|
|--statementId|否|Long| 结算单id|
|--dbKey|否|Integer| 分库标识|
|--groupId|否|String| 品牌商id|

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|
