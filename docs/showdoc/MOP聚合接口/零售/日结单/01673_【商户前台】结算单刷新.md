# 结算单刷新
 

**请求URL：** 
- `/hr/statement/generate/refresh `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
```
{"id":"563295492132906256","tokenId":"b536b4c3174b4c628bdad5eef1b05f1f"}
```

|----statusInfo|否|String| 状态描述|
