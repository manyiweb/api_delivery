# 保存门店日结设置

**请求URL：** 
- `/hr/statement/setting/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 门店id|
|openCustom|否|Integer| 是否开启自定义结算|
|customDate|否|DateTime| 自定义结算日期|

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "openCustom" : 0,
 "customDate" : "DateTime"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
