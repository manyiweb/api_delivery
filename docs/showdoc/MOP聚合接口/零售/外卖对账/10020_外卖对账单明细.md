# 外卖对账单明细

**请求URL：** 
- `/hr/reconciliation/takeout/detail/list/{source}`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|result|否|List| 核对结果 0:相符 1:短款 2:长款|
|id|否|String||
|pageSize|否|Integer||
|pageNo|否|Integer||
|sortField|否|String||
|sortDirection|否|String||
|viewId|否|String||

### 请求参数Json格式
 
```
{
 "result" : null,
 "id" : "String",
 "pageSize" : 0,
 "pageNo" : 0,
 "sortField" : "String",
 "sortDirection" : "String",
 "viewId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--content|否|List||
|----platformTransCode|否|String|平台单号 |
|----thirdPartyTransCode|否|String|第三方单号 |
|----orderType|否|String|订单类型 |
|----companyId|否|String|门店id |
|----companyName|否|String|门店名称 |
|----orderDate|否|DateTime|下单时间 |
|----payAmount|否|Double|实收金额 |
|----result|否|Integer|0相符 1短款 2长款 |
|----resultName|否|String||
|--pageSize|否|Integer||
|--pageNo|否|Integer||
|--total|否|Long||
|--totalPage|否|Integer||
|--hasNextPage|否|Boolean||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
