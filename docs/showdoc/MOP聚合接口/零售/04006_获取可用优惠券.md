# 获取可用优惠券

**请求URL：** 
- `/app/shopping/cart/available/coupons `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|specifyCouponType|否|Integer| 指定优惠券类型 现金券/折扣券1 兑换券2 运费券3 其他不过滤|
|shopCartKey|否|String| 如果是立即购买输入对应的立即购买cartKey|

###请求参数Json格式
 
```
{
 "specifyCouponType" : 0,
 "shopCartKey" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--coupons|否|List| 可用优惠券|
|----couponId|否|String| 优惠券ID|
|----coupnsCode|否|String| 优惠券编码|
|----title|否|String| 优惠券标题|
|----price|否|Double| 优惠券金额|
|----detail|否|String| 优惠券描述|
|----useLimitAmt|否|Double| 优惠券使用最低限额|
|----useLimit|否|Integer| 使用限制 0不可叠加使用(默认) 1可叠加使用 2可叠加使用(阶梯)|
|----beginDate|否|String| 优惠券使用有效时间范围 - 开始时间|
|----endDate|否|String| 优惠券使用有效时间范围 - 结束时间|
|----couponType|否|Integer| 商品券类型，取值：0 - 现金券，1 - 折扣券，2 - 兑换券 ,3 - 运费券|
|----couponTypeName|否|String| 商品券类型，取值：0 - 现金券，1 - 折扣券，2 - 兑换券 ,3 - 运费券|
|----discount|否|Double| 折扣券-折扣率|
|----ticketType|否|String| 优惠券类型，取值：T001 - 商品券，T002 - 服务券|
|----ticketTypeName|否|String| 优惠券类型，取值：T001 - 商品券，T002 - 服务券|
|----couponSku|否|String| 优惠券唯一码|
|----selectedStatus|否|Integer| 是否选中Item 0-否 1-选中|
|----couponCanUseQty|否|Integer| 优惠券可叠加数量|
|----errorMsg|否|String| 错误信息|
|----itemKey|否|String| 新版兑换券有值|
|----available|否|Boolean| 优惠券是否可用|
|----memberPriceAvailable|否|Boolean| 是否会员价不可用|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
