# 提货点列表
 

**请求URL：** 
- `/app/company/pickuplocation/list `

**请求方式：**
- ALL
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String||

###请求参数Json格式
 
```
{
 "companyId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--pickupLocationList|否|List| 提货点|
|----id|否|Long||
|----province|否|String| 省|
|----city|否|String| 市|
|----district|否|String| 区|
|----pickupLocationName|否|String| 提货点名称|
|----pickupLocation|否|String| 提货点地址|
|----fullPickupLocation|否|String| 完整提货点地址|
|----locationDefault|否|Boolean| 是否默认|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : {
 "pickupLocationList" : [{
 "id" : 0,
 "province" : "String",
 "city" : "String",
 "district" : "String",
 "pickupLocationName" : "String",
 "pickupLocation" : "String",
 "fullPickupLocation" : "String",
 "locationDefault" : true
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
