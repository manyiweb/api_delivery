# 批量配送 - 销售订单 - 配送商品 导入

**请求URL：** 
- `/file/import/dorder/items/import `

**请求方式：**
- POST
- FormData


###请求参数<业务参数>
 
无参数


###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--dataSource|否|List||
|----id|否|String||
|----oitemId|否|String| 订单明细行标识|
|----orderNo|否|String| 单据编码|
|----itemCode|否|String| 商品编码|
|----skuBarcode|否|String| SKU码|
|----itemName|否|String| 商品名称|
|----deliveryNowQuantity|否|Double| 现配数量|
|----expressCompany|否|String| 物流商|
|----expressNumber|否|String| 物流单号|
|----msg|否|String| 反馈信息|
|----status|否|Integer||
|----statusName|否|String||
|----barcode|否|List||
|----cellStyleMap|否|Map||
|--downloadURL|否|String| 错误数据下载地址|
|--totalCount|否|Long| 总数|
|--successCount|否|Long| 成功数|
|--errorCount|否|Long| 错误数|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|

}
