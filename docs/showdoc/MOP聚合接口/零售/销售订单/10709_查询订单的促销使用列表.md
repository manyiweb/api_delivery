# 查询订单的促销使用列表
 

**请求URL：** 
- `/retail/app/Business/order/promotionUseList`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|是|String| 订单id|

### 请求参数Json格式
 
```
{
 "orderId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--planId|否|String| 促销id|
|--planName|否|String| 促销名称|
|--planCode|否|String| 促销编码|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "planId" : "String",
 "planName" : "String",
 "planCode" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
