# 销售订单 批量配送

**请求URL：** 
- `/retail/app/Business/batchDeliveryOrder `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderItems|否|List| 商品明细|
|--orderId|否|String| 订单id|
|--distributorId|否|String||
|--oItemId|否|String||
|--quantity|否|Double||
|--itemUnitRate|否|Double| 单位换算比率|
|--itemUnit|否|String| 单位|
|--barcodes|否|String||
|proxyDelivery|否|Integer| 是否为代发订单 1是0否 1供应商代发 2品牌代发|
|courier|否|String| 联系人|
|expressCompany|否|String| 快递公司名称|
|expressNumber|否|String| 快递单号|

###请求参数Json格式
 
```
{
 "orderItems" : [{
 "orderId" : "String",
 "distributorId" : "String",
 "oItemId" : "String",
 "quantity" : 0,
 "itemUnitRate" : 0,
 "itemUnit" : "String",
 "barcodes" : "String"
 }],
 "proxyDelivery" : 0,
 "courier" : "String",
 "expressCompany" : "String",
 "expressNumber" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--totalQty|否|Integer| 总数|
|--successQty|否|Integer| 成功数|
|--failQty|否|Integer| 失败数|
|--successOrders|否|List| 成功列表|
|----id|否|Long| 总部代发订单标识|
|----orderNo|否|String| 总部订单编码|
|----fail|否|Integer| 是否失败|
|----errorMsg|否|String| 错误信息|
|--failOrders|否|List| shi白|
|----id|否|Long| 总部代发订单标识|
|----orderNo|否|String| 总部订单编码|
|----fail|否|Integer| 是否失败|
|----errorMsg|否|String| 错误信息|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
