# 查询订单的优惠券使用列表
 

**请求URL：** 
- `/app/Business/order/couponUseList `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Object| id|

###请求参数Json格式
 
```
{
 "id" : null
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--couponCode|否|String|优惠券编码 |
|--couponName|否|String|优惠券名称 |
|--couponTypeName|否|String|优惠券类型名称 |
|--number|否|Integer|优惠券数量 |
|--returned|否|Boolean|是否已退回 |
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : [{
 "couponCode" : "String",
 "couponName" : "String",
 "couponTypeName" : "String",
 "number" : 0,
 "returned" : true
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
