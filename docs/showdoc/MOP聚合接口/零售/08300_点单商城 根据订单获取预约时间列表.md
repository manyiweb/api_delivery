# 点单商城 根据订单获取预约时间列表
 

**请求URL：** 
- `/appc/shopping/reserve/timelist/order`

**请求方式：**
- ALL
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|否|String| 订单id|
|replaceSysNo|否|String| 用于支持点单商城访问会员商城接口|

### 请求参数Json格式
 
```
{
 "orderId" : "String",
 "replaceSysNo" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--frontData|否|List||
|----reserveDateFormat|否|String||
|----reserveDate|否|DateTime||
|----allDay|否|Boolean||
|----reserveTimes|否|List||
|------reserveTimeRange|否|String||
|------reserveDate|否|String||
|------reserveDateFormat|否|String||
|------rangBegin|否|Object||
|------rangEnd|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "frontData" : [{
 "reserveDateFormat" : "String",
 "reserveDate" : "DateTime",
 "allDay" : true,
 "reserveTimes" : [{
 "reserveTimeRange" : "String",
 "reserveDate" : "String",
 "reserveDateFormat" : "String",
 "rangBegin" : null,
 "rangEnd" : null
 }]
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
