# 保存优惠设置

**请求URL：** 
- `/config/b2b/fastWayDiscount/update `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|isInherit|否|Integer| 是否继承品牌设置|
|companyId|否|String| 门店id|
|customDiscountWayList|否|List| 行优惠/整单优惠 列表|
|--isOpen|否|Integer| 是否开启 1是 2否|
|--id|否|Long| 行优惠/整单优惠 每一项的id|
|--sort|否|Long| 排序|
|fastWayDiscountList|否|List||
|--id|否|Long| 快捷优惠 每一项的id|
|--fastWayDiscountType|否|Integer| 优惠类型 1、固定金额 2、固定折扣|
|--discountValue|否|Double| 优惠值（金额/折扣）|
|--discountRemark|否|String| 优惠说明|
|--sort|否|Long| 排序|
|--isEffective|否|boolen| 是否开启有效期（默认不开启 false）|
|--effectiveStartDate|否|date| 有效期开始时间|
|--effectiveEndDate|否|date| 有效期结束时间|
|--notAccumulationOtherCoupon|否|boolen| 不可叠加其他优惠(优惠券、促销、平台券) 使用|
|deleteFastWayDiscountIds|否|List| 删除的 快捷优惠|

###请求参数Json格式
 
```
{
 "isInherit" : 0,
 "companyId" : "String",
 "customDiscountWayList" : [{
 "isOpen" : 0,
 "id" : 0,
 "sort" : 0
 }],
 "fastWayDiscountList" : [{
 "id" : 0,
 "fastWayDiscountType" : 0,
 "discountValue" : 0,
 "discountRemark" : "String",
 "sort" : 0
 }],
 "deleteFastWayDiscountIds" : null
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
