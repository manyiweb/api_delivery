# 获取便捷优惠编码

**请求URL：** 
- `/config/b2b/fastWayDiscount/getNewFastWayDiscountCode `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|否|String||
|companyId|否|String| 门店id|
|customDiscountWayId|否|Long| 快捷优惠id|
|isInherit|否|Integer||

###请求参数Json格式
 
```
{
 "tokenId" : "String",
 "companyId" : "String",
 "customDiscountWayId" : 0,
 "isInherit" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--fastWayDiscountCode|否|String| 优惠编码|
|--sort|否|Long| 排序|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : {
 "fastWayDiscountCode" : "String",
 "sort" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
