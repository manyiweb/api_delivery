# 零售预警记录列表
 接口前缀为：/retail-order-front

**请求URL：** 
- `/retail/monitor/record/list/{source}`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|keyword|否|String| 订单编号|
|status|否|List| 传输类型|
|conditionType|否|List| 商户|
|createDate|否|Object|执行时间 |
|--start|否|DateTime||
|--end|否|DateTime||
|id|否|String||
|pageSize|否|Integer||
|pageNo|否|Integer||
|sortField|否|String||
|sortDirection|否|String||
|viewId|否|String||

### 请求参数Json格式
 
```
{
 "keyword" : "String",
 "status" : null,
 "conditionType" : null,
 "createDate" : {
 "start" : "DateTime",
 "end" : "DateTime"
 },
 "id" : "String",
 "pageSize" : 0,
 "pageNo" : 0,
 "sortField" : "String",
 "sortDirection" : "String",
 "viewId" : "String"
}
```
