# 保存零售预警配置

**请求URL：** 
- `/retail/monitor/money/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 主键|
|open|否|Boolean| 启用状态 0 1|
|memberType|是|String| 全部 all 指定等级 grade|
|dayTimesFlag|否|Integer| 单日消费次数计算开关|
|dayTimes|否|Integer| 单日消费次数|
|dayNumFlag|否|Boolean| 单日消费金额计算开关|
|dayNum|否|Double| 单日消费金额 元|
|monthTimesFlag|否|Boolean| 自然月消费次数计算开关|
|monthTimes|否|Integer| 自然月消费次数|
|monthNumFlag|否|Boolean| 自然月消费金额计算开关|
|monthNum|否|Double| 自然月消费金额 元|
|onceNumFlag|否|Boolean| 单次消费金额计算开关|
|onceNum|否|Double| 单次消费金额 元|
|warnType|否|String| 仅预警 warn 预警并停用会员forbid|
|memberConfig|否|List||
|--id|否|Long| 主配置id|
|--configId|否|String| 主配置id|
|--gradeId|否|String| 等级id|
|--gradeName|否|String| 等级名称|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "open" : true,
 "memberType" : "String",
 "dayTimesFlag" : 0,
 "dayTimes" : 0,
 "dayNumFlag" : true,
 "dayNum" : 0,
 "monthTimesFlag" : true,
 "monthTimes" : 0,
 "monthNumFlag" : true,
 "monthNum" : 0,
 "onceNumFlag" : true,
 "onceNum" : 0,
 "warnType" : "String",
 "memberConfig" : [{
 "id" : 0,
 "configId" : "String",
 "gradeId" : "String",
 "gradeName" : "String"
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
