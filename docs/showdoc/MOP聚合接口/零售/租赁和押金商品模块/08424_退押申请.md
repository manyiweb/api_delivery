# 退押申请
 

**请求URL：** 
- `retail-order-front/appc/cashPledge/refund/apply`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|refundAmount|是|Double| 退款金额|
|companyId|是|String| 门店id|
|refundReason|否|String| 退款原因|
|itemReqList|否|List| 押金单|
|--totalRefundAmount|是|Double| 退款金额|
|--refundAmount|是|Double| 退款单价|
|--id|否|Long| 主键|
|--itemId|否|String| 商品id|
|--specId|否|String| 规格id|
|--itemName|否|String| 商品名称|
|--skuBarcode|否|String| sku|
|--quantity|否|Double| 退款数量|

### 请求参数Json格式
 
```
{
 "refundAmount" : 0,
 "companyId" : "String",
 "refundReason" : "String",
 "itemReqList" : [{
 "totalRefundAmount" : 0,
 "refundAmount" : 0,
 "id" : 0,
 "itemId" : "String",
 "specId" : "String",
 "itemName" : "String",
 "skuBarcode" : "String",
 "quantity" : 0
 }]
}
```

|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--pageIndex|否|Integer||
|--pageSize|否|Integer||
|--pageCount|否|Integer||
|--totalCount|否|Long||
|--first|否|Boolean||
|--last|否|Boolean||
|--content|否|List||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||

 },
