# 押金金额汇总信息
 

**请求URL：** 
- `/retail-order-front/appc/cashPledge/summary/info`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
无参数


### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--amount|否|Double| 押金余额|
|--totalAmount|否|Double| 总押金|
|--refundAmount|否|Double| 退还的押金|
|--cashPledgeCompanyList|否|List| 门店押金信息|
|----companyName|否|String| 门店名称|
|----itemList|否|List| 商品信息|
|------itemName|否|String| 商品名称|
|------quantity|否|Double| 数量|
|------amount|否|Double| 金额|
|----balance|否|Double| 余额|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "amount" : 0,
 "totalAmount" : 0,
 "refundAmount" : 0,
 "cashPledgeCompanyList" : [{
 "companyName" : "String",
 "itemList" : [{
 "itemName" : "String",
 "quantity" : 0,
 "amount" : 0
 }],
 "balance" : 0
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
