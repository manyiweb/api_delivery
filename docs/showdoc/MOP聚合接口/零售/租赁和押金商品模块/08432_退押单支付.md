# 退押单支付
 

**请求URL：** 
- `retail/app/Business/cash/pledge/pay`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long| 退款金额|
|payType|是|String| 线下退款cashPay 充值到购物卡noSourceCashPledge|
|remark|是|String| 备注|
|refundDetail|否|List||
|--id|否|Long||
|--refundRecordId|否|Long||
|--memberId|否|String||
|--refundItemId|否|String||
|--pledgeRecordId|否|Long||
|--pledgeDetailId|否|Long||
|--companyId|否|String||
|--refundAmount|否|Double||
|--totalRefundAmount|否|Double||
|--itemId|否|String||
|--specId|否|String||
|--itemName|否|String||
|--quantity|否|Long||
|--createId|否|String||
|--createName|否|String||
|--createDate|否|DateTime||
|--modifyId|否|String||
|--modifyName|否|String||
|--modifyDate|否|DateTime||
|--dbKey|否|Integer||
|--groupId|否|String||
