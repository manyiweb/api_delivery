# 查询-电商外卖配送时间

**请求URL：** 
- `/appc/shopping/cart/getEmallTakeDates`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|shopCartKey|否|String| 如果是立即购买输入对应的立即购买cartKey|
|replaceSysNo|否|String| 用于支持点单商城访问会员商城接口|
|pageType|否|Integer| 页面类型|
|localShopCartInfo|否|Object| 购物车信息|
|--takeCardNo|否|String| 桌号|
|--pickupName|否|String| 提货人姓名|
|--pickupPhone|否|String| 提货人手机号|

### 请求参数Json格式
 
```
{
 "shopCartKey" : "String",
 "replaceSysNo" : "String",
 "pageType" : 0,
 "localShopCartInfo" : {
 "takeCardNo" : "String",
 "pickupName" : "String",
 "pickupPhone" : "String"
 }
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--sameCityDeliveryTimeSet|否|Boolean| 是否设置配送时间|
|--leadTimeRemark|否|String| 配货说明|
|--takeDates|否|List| 提货配送时间|
|----takeDate|否|String| 提货配送日期|
|----takeTimeQuantums|否|String| 提货配送时间段|
|----showTakeDate|否|String| 提货配送时间显示|
|--frontData|否|List| 提货配送时间（新格式）|
|----reserveDateFormat|否|String||
|----reserveDate|否|DateTime||
|----allDay|否|Boolean||
|----reserveTimes|否|List||
|------reserveTimeRange|否|String||
|------reserveDate|否|String||
|------reserveDateFormat|否|String||
|------rangBegin|否|Object||
|------rangEnd|否|Object||
|------customReserveTimeRange|否|String||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "sameCityDeliveryTimeSet" : true,
 "leadTimeRemark" : "String",
 "takeDates" : [{
 "takeDate" : "String",
 "takeTimeQuantums" : "String",
 "showTakeDate" : "String"
 }],
 "frontData" : [{
 "reserveDateFormat" : "String",
 "reserveDate" : "DateTime",
 "allDay" : true,
 "reserveTimes" : [{
 "reserveTimeRange" : "String",
 "reserveDate" : "String",
 "reserveDateFormat" : "String",
 "rangBegin" : null,
 "rangEnd" : null,
 "customReserveTimeRange" : "String"
 }]
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
