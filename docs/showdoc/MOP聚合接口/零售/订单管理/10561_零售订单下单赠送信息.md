# 零售订单下单赠送信息
 

**请求URL：** 
- `/retail-order-front/order/placement/gift/info`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|是|String| 订单id|

### 请求参数Json格式
 
```
{
 "orderId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--giftInfoList|否|List| 赠送信息列表|
|----giftType|否|Integer| 赠送类型 0：积分 1：成长值 2：优惠券|
|----giftTypeDesc|否|String| 赠送类型描述|
|----channel|否|String| 渠道|
|----name|否|String| 名称|
|----num|否|Double| 数量|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "giftInfoList" : [{
 "giftType" : 0,
 "giftTypeDesc" : "String",
 "channel" : "String",
 "name" : "String",
 "num" : 0
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
