# 代发商品的代发门店列表

**请求URL：** 
- `/app/sales/hq/product/companys `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|String| id|

###请求参数Json格式
 
```
{
 "id" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--companyId|否|String| 门店标识|
|--companyCode|否|String| 门店编码|
|--companyName|否|String| 门店名称|
|--itemIds|否|List| 适用的商品|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : [{
 "companyId" : "String",
 "companyCode" : "String",
 "companyName" : "String",
 "itemIds" : null
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
