# 获得打印记录
 

**请求URL：** 
- `/retail/refund/printer/get `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|refundId|否|String| 订单ID|

###请求参数Json格式
 
```
{
 "refundId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--recordId|否|Long| 打印记录|
|--refundId|否|String| 订单ID|
|--refundNo|否|String| 订单号|
|--printedDate|否|DateTime| 最后打印时间|
|--countOfPrint|否|Integer| 打印次数|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "recordId" : 0,
 "refundId" : "String",
 "refundNo" : "String",
 "printedDate" : "DateTime",
 "countOfPrint" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
