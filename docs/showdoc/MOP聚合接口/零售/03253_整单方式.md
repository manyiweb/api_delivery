# 整单方式
 

**请求URL：** 
- `/app/shopping/cart/listCustomDiscountWay `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|sword|否|String||
|companyId|否|String||
|tokenId|否|String||
|pageIndex|否|Integer| 页号|
|pageSize|否|Integer| 页大小|
|orderField|否|String| 商品排序字段|
|orderSort|否|String| 商品排序方式 desc 倒序 asc 正序|

###请求参数Json格式
 
```
{
 "sword" : "String",
 "companyId" : "String",
 "tokenId" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--customDiscountType|否|Integer| 行优惠方式|
|--customDiscountName|否|String| 优惠方式名称|
|--fastWayDiscountLists|否|List| 快捷优惠，只有整单优惠才有 其它情况为null|
|----id|否|Long||
|----companyId|否|String| 门店id|
|----customDiscountWayId|否|Long| 关联 custom_discount_way|
|----fastWayDiscountCode|否|String| 优惠编码|
|----fastWayDiscountType|否|Integer| 优惠类型 1、固定金额 2、固定折扣|
|----fastWayDiscountTypeName|否|Integer||
|----discountValue|否|Double| 优惠值|
|----discountRemark|否|String| 优惠说明|
|----sort|否|Long| 排序|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : [{
 "customDiscountType" : 0,
 "customDiscountName" : "String",
 "fastWayDiscountLists" : [{
 "id" : 0,
 "companyId" : "String",
 "customDiscountWayId" : 0,
 "fastWayDiscountCode" : "String",
 "fastWayDiscountType" : 0,
 "fastWayDiscountTypeName" : 0,
 "discountValue" : 0,
 "discountRemark" : "String",
 "sort" : 0
 }]
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
