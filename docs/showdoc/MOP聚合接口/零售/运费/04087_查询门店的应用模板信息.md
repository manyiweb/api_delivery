# 查询门店的应用模板信息
 

**请求URL：** 
- `retail/sales/express/fee/template/apply/getApplyInfo `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|String| id|

###请求参数Json格式
 
```
{
 "id" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--applyId|否|Long|应用id |
|--calculateType|否|Integer|计费方式 1/按商品数量/重量 2/按订单金额 |
|--templates|否|List|模板信息列表 |
|----id|否|Long|模板id |
|----templateCode|否|String|模板编码 |
|----templateName|否|String|模板名称 |
|----calculateType|否|Integer|计费方式 1/按商品数量 2/按商品重量 3/按订单金额 |
|----isActive|否|Boolean|活跃状态 |
|----createDate|否|DateTime|创建时间 |
|----modifyDate|否|DateTime|更新时间 |
|----createName|否|String|创建人 |
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : {
 "applyId" : 0,
 "calculateType" : 0,
 "templates" : [{
 "id" : 0,
 "templateCode" : "String",
 "templateName" : "String",
 "calculateType" : 0,
 "isActive" : true,
 "createDate" : "DateTime",
 "modifyDate" : "DateTime",
 "createName" : "String"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
