# 运费说明详情
 

**请求URL：** 
- `/app/freightset/info `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
无参数


###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--freightExplain|否|String| 运费说明|
|--todayFreightExplain|否|String| 当日达运费说明|
|--tomorrowFreightExplain|否|String| 次日达运费说明|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "freightExplain" : "String",
 "todayFreightExplain" : "String",
 "tomorrowFreightExplain" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
