# 保存应用
 

**请求URL：** 
- `retail/sales/express/fee/template/apply/save `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String|门店id |
|calculateType|否|Integer|计费方式， 1、按商品数量/重量 2、按订单金额 |
|applyTemplates|否|List|应用的模板列表 |
|--templateId|否|Long|模板id |
|--type|否|Integer|应用目标类型，只有按商品计费才有，1:所有、2:商品、3:类别|品牌|系列 |
|--appointItems|否|List|模板指定的商品/类别/品牌/系列列表，只有type等于2或3才有 |
|----applyItemId|否|String|商品、类别id，品牌、序列code |
|----applyItemName|否|String|商品/类别/品牌/序列 名称 |
|----applyItemCode|否|String|如果指定商品就是商品编码，如果是指定类别|品牌|系列，则1:类型，2:品牌，3:系列 |
|----applyItemSku|否|String|商品sku，如果指定商品则填写 |
|----typeCode|否|String|分类编码，如果指定商品则填写 |
|----brandCode|否|String|品牌编码，如果指定商品则填写 |
|----seriesCode|否|String|系列编码，如果指定商品则填写 |
|--excludeItemEnable|否|Boolean|是否启用排除商品，只有type为3才能是true |
|--excludeItems|否|List|排除商品列表，只有type等于3才有 |
|----itemId|否|String|商品id |
|----itemName|否|String|商品名称 |
|----itemCode|否|String|商品编码 |
|----itemSku|否|String|商品sku |
|----unit|否|String|计量单位 |
|----retailPrice|否|Double|零售价 |

###请求参数Json格式
 
```
{
 "companyId" : "String",
 "calculateType" : 0,
 "applyTemplates" : [{
 "templateId" : 0,
 "type" : 0,
 "appointItems" : [{
 "applyItemId" : "String",
 "applyItemName" : "String",
 "applyItemCode" : "String",
 "applyItemSku" : "String",
 "typeCode" : "String",
 "brandCode" : "String",
 "seriesCode" : "String"
 }],
 "excludeItemEnable" : true,
 "excludeItems" : [{
 "itemId" : "String",
 "itemName" : "String",
 "itemCode" : "String",
 "itemSku" : "String",
 "unit" : "String",
 "retailPrice" : 0
 }]
 }]
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{

}
```
