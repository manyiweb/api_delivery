# 点单商城获取发票信息

**请求URL：** 
- `/hr/invoice/myinvoice/list/v2`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 发票id|
|orderId|否|String| 订单id 用于查询单个订单发票信息|
|pageIndex|否|Integer||
|pageSize|否|Integer||
|orderField|否|String||
|orderSort|否|String||

### 请求参数Json格式
 
```
{
 "id" : 0,
 "orderId" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--pageIndex|否|Integer||
|--pageSize|否|Integer||
|--pageCount|否|Integer||
|--totalCount|否|Long||
|--first|否|Boolean||
|--last|否|Boolean||
|--content|否|List||
|----id|否|Long| 发票id|
|----invoiceType|否|String| 发票类型 SPECIAL("普通发票"), GENERAL("增值税专用发票");|
|----invoiceDate|否|DateTime| 开票日期|
|----status|否|String| 发票状态|
|----statusName|否|String| 发票状态|
|----orderNumber|否|Long| 订单数|
|----invoiceAmount|否|Double| 发票金额|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "pageIndex" : 0,
 "pageSize" : 0,
 "pageCount" : 0,
 "totalCount" : 0,
 "first" : true,
 "last" : true,
 "content" : [{
 "id" : 0,
 "invoiceType" : "String",
 "invoiceDate" : "DateTime",
 "status" : "String",
 "statusName" : "String",
 "orderNumber" : 0,
 "invoiceAmount" : 0
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
