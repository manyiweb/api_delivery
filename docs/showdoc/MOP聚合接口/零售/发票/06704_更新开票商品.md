# 更新开票商品

**请求URL：** 
- `/hr/retail/recharge/invoice/updateInvoiceItem`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|retailOrderInvoiceId|否|Long| 发票订单id|
|replaceItemId|否|String| 替换商品id|
|replaceItemUnit|否|String| 替换商品单位|

### 请求参数Json格式
 
```
{
 "retailOrderInvoiceId" : 0,
 "replaceItemId" : "String",
 "replaceItemUnit" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
