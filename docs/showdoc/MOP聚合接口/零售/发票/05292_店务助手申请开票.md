# 店务助手开票
 

**请求URL：** 
- `/hr/retail/invoice/company/batchApply `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|applyType|否|Integer| 申请类型 默认蓝票 1 红冲2|
|invoiceType|否|String|发票类型 SPECIAL("普通发票"), GENERAL("增值税专用发票");|
|titleType|否|String|抬头类型 PERSONAL("个人") ENTERPRISE("单位")|
|invoiceTitle|否|String|发票抬头 |
|taxNo|否|String|税号 |
|openAccountBank|否|String|开户银行 |
|bankAccount|否|String|银行账号 |
|companyAddress|否|String|企业地址 |
|companyPhone|否|String|企业电话 |
|status|否|String|发票状态 前端不用传|
|noticePhone|否|String|通知手机号 |
|noticeEmail|否|String|通知邮箱 |
|orderIds|否|List| 订单列表|
|refundOrderIds|否|List| 退货订单列表|
|companyId|否|String|门店id |

###请求参数Json格式
 
```
{
 "applyType" : 0,
 "invoiceType" : "String",
 "titleType" : "String",
 "invoiceTitle" : "String",
 "taxNo" : "String",
 "openAccountBank" : "String",
 "bankAccount" : "String",
 "companyAddress" : "String",
 "companyPhone" : "String",
 "status" : "String",
 "noticePhone" : "String",
 "noticeEmail" : "String",
 "orderIds" : null,
 "refundOrderIds" : null,
 "companyId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--successCount|否|Integer||
|--errorCount|否|Integer||
|--errorInfoList|否|List||
|----msg|否|String||
|----orderNo|否|String||
|----fullErrorMsg|否|String||
|--invoiceId|否|Long|此次开票id |
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "successCount" : 0,
 "errorCount" : 0,
 "errorInfoList" : [{
 "msg" : "String",
 "orderNo" : "String",
 "fullErrorMsg" : "String"
 }],
 "invoiceId" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
