# 获取充值开票替换商品配置

**请求URL：** 
- `/hr/retail/recharge/invoice/getRechargeInvoiceConfig`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
无参数


### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--enableOrderItem|否|Boolean| 启用订单开票明细可替换商品|
|--enableRechargeInvoice|否|Boolean| 启用购物卡充值开票|
|--rechargeInvoiceType|否|Integer| 充值开票类型 1、按消费订单开票 2、按充值流水开票|
|--enableRechargeItem|否|Boolean| 启用充值开票明细可替换商品|
|--rechargeItems|否|List| 充值开票商品|
|----itemId|否|String| 商品id|
|----itemName|否|String| 商品名称|
|----unit|否|String| 单位|
|----isDefault|否|Boolean| 是否是默认|
|----unitGroup|否|Object| 单位组信息|
|------quantity|否|Double||
|------itemUnit|否|String||
|------itemQuantity|否|Double||
|------unitRate|否|Double||
|------unitGroupId|否|Long||
|------unitGroupName|否|String||
|------errcode|否|Integer||

|--------expressFee|否|Double||

|--------unitGroupId|否|Object||
|----------lowestSetBit|否|Integer||
|------baseUnitId|否|String||

|--orderItems|否|List| 订单开票商品|
|----itemId|否|String| 商品id|
|----itemName|否|String| 商品名称|
|----unit|否|String| 单位|
