# 批量发票

**请求URL：** 
- `/hr/retail/invoice/batchApply`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|applyType|否|Integer| 申请类型 默认蓝票 1 红冲2|
|invoiceType|是|String|发票类型 SPECIAL("普通发票"), GENERAL("增值税专用发票");|
|titleType|是|String|抬头类型 PERSONAL("个人") ENTERPRISE("单位")|
|invoiceTitle|是|String|发票抬头 |
|taxNo|否|String|税号 |
|openAccountBank|否|String|开户银行 |
|bankAccount|否|String|银行账号 |
|companyAddress|否|String|企业地址 |
|companyPhone|否|String|企业电话 |
|status|否|String|发票状态 前端不用传|
|noticePhone|否|String|通知手机号 |
|noticeEmail|否|String|通知邮箱 |
|orderIds|否|List| 订单列表|
|refundOrderIds|否|List| 退货订单列表|
|companyId|否|String|门店id |
|makeOutType|否|String|开票类型，see |
|billingType|否|Integer| 开票类型 0：按单开票 1：合并开票|
|invoiceApplyOrderType|否|Integer| 开票订单类型 0：基于订单开票 1：无订单开票|
|remark|否|String| 备注|
|invoiceApplyItems|否|List| 无订单开票商品信息|
|--itemId|否|String| 商品id|
|--quantity|否|Double| 数量|
|--amount|否|Double| 金额|
|--unit|否|String| 单位|
|orderAmountList|否|List| 开票订单金额明细，原先的orderIds字段照传|
|--orderId|否|String| 订单id|
|--currentInvoiceAmount|否|Double| 本次开票金额|
|--itemId|否|String| 替换商品id 自定义整单汇总不传|
|--itemName|否|String| 替换商品名称|
|--quantity|否|Double| 替换商品数量|
|--unit|否|String| 替换商品单位|
|--replaceType|否|String|替换类型 none 不替换 one只替换成一个商品 custom 自定义 order自定义整单汇总|
|--replaceTaxCode|否|String| 汇总开票项目税收分类编码 自定义整单汇总用|
|--replaceTaxRate|否|Double| 汇总开票项目税率 自定义整单汇总用|
|outOrderNo|否|String| 外部单号|
|replaceType|否|String|替换类型 none 不替换 one只替换成一个商品 custom 自定义 order自定义整单汇总|
|invoiceChannel|否|Integer| 开票渠道 0：小程序开票 1：扫码开票 2：门店开票|
