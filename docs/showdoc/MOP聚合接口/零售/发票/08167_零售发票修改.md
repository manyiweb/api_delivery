# 零售发票表添加或修改

**请求URL：** 
- `/hr/retail/invoice/updateInvoice`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long|id |
|invoiceType|是|String|发票类型 |
|titleType|是|String|抬头类型 |
|invoiceTitle|是|String|发票抬头 |
|taxNo|否|String|税号 |
|companyPhone|否|String|企业电话 |
|noticePhone|否|String|通知手机号 |
|noticeEmail|否|String|通知邮箱 |
|openAccountBank|否|String|开户银行 |
|bankAccount|否|String|银行账号 |
|companyAddress|否|String|企业地址 |
|remark|否|String|备注 |

### 请求参数Json格式
 
```
{
 "id" : 0,
 "invoiceType" : "String",
 "titleType" : "String",
 "invoiceTitle" : "String",
 "taxNo" : "String",
 "companyPhone" : "String",
 "noticePhone" : "String",
 "noticeEmail" : "String",
 "openAccountBank" : "String",
 "bankAccount" : "String",
 "companyAddress" : "String",
 "remark" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--successCount|否|Integer||
|--errorCount|否|Integer||
|--errorInfoList|否|List||
|----msg|否|String||
|----orderNo|否|String||
|----fullErrorMsg|否|String||
|--orderIds|否|List||
|--invoiceId|否|Long|此次开票id |
|--invoiceNo|否|String| 发票号码|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "successCount" : 0,
 "errorCount" : 0,
 "errorInfoList" : [{
 "msg" : "String",
 "orderNo" : "String",
 "fullErrorMsg" : "String"
 }],
 "orderIds" : null,
 "invoiceId" : 0,
 "invoiceNo" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
