# 批量更新开票申请状态

**请求URL：** 
- `/hr/retail/invoice/batchUpdate`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|invoiceIds|否|List| 退货订单列表|
|invoiceStatus|否|String|发票状态 |
|remark|否|String|备注 |

### 请求参数Json格式
 
```
{
 "invoiceIds" : null,
 "invoiceStatus" : "String",
 "remark" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--invoiceNo|否|String| 发票号|
|--error|否|String| 失败原因|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "invoiceNo" : "String",
 "error" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
