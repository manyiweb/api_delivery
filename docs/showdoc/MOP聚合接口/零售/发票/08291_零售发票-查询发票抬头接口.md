# 零售发票-查询发票抬头接口
 

**请求URL：** 
- `/hr/retail/invoice/getInvoiceTitle`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|enterpriseName|否|String| 公司名称|

### 请求参数Json格式
 
```
{
 "enterpriseName" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--openInvoiceAbility|否|Boolean| 是否开启发票能力, 没开启后续都不用继续调用|
|--invoiceTitles|否|List| 发票抬头列表|
|----taxpayerNum|否|String| 企业纳税人识别号|
|----enterpriseName|否|String| 企业名称|
|----address|否|String| 地址|
|----telephone|否|String| 电话|
|----bankName|否|String| 开户行|
|----bankAccount|否|String| 银行账号|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "openInvoiceAbility" : true,
 "invoiceTitles" : [{
 "taxpayerNum" : "String",
 "enterpriseName" : "String",
 "address" : "String",
 "telephone" : "String",
 "bankName" : "String",
 "bankAccount" : "String"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
