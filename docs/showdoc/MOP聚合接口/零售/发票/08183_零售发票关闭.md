# 零售发票关闭

**请求URL：** 
- `/hr/retail/invoice/closeInvoice`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long|id |
|invoiceType|是|String|发票类型 |
|titleType|是|String|抬头类型 |
|invoiceTitle|是|String|发票抬头 |
|taxNo|否|String|税号 |
|companyPhone|否|String|企业电话 |
|noticePhone|否|String|通知手机号 |
|noticeEmail|否|String|通知邮箱 |

### 请求参数Json格式
 
```
{
 "id" : 0,
 "invoiceType" : "String",
 "titleType" : "String",
 "invoiceTitle" : "String",
 "taxNo" : "String",
 "companyPhone" : "String",
 "noticePhone" : "String",
 "noticeEmail" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
