# 无订单开票 关联订单

**请求URL：** 
- `/hr/retail/invoice/bindOrder`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|retailInvoiceId|是|Long| 发票id|
|orderList|是|List| 关联的订单|
|--orderId|否|String| 订单id|
|--currentInvoiceAmount|否|Double| 本次开票金额|

### 请求参数Json格式
 
```
{
 "retailInvoiceId" : 0,
 "orderList" : [{
 "orderId" : "String",
 "currentInvoiceAmount" : 0
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
