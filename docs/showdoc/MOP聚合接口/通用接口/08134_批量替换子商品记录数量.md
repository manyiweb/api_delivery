# 批量替换子商品记录数量

**请求URL：** 
- `/b2b/billmaterials/batch/replaceRecord`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|specId|否|String| 商品规格id|
|replaceSpecId|否|String| 替换商品specId|
|multiply|否|Double| 数量倍数|
|produce|否|Boolean| 物料清单类型 -生产|
|template|否|Boolean| 物料清单类型 -模板|
|fix|否|Boolean| 物料清单类型 -固定|
|replaceType|是|Integer| 替换商品包含 0-仅子商品 1-仅替代料 2子商品+替代料|

### 请求参数Json格式
 
```
{
 "specId" : "String",
 "replaceSpecId" : "String",
 "multiply" : 0,
 "produce" : true,
 "template" : true,
 "fix" : true,
 "replaceType" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Integer||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : 0,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
