# 重新转换错误的经纬度
 

**请求URL：** 
- `/config/mallSameCityDelivery/init/initErrorLogLat `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|groupId|是|String| 品牌id|
|errorDataType|是|Integer| 1 会员商城圆形 2 会员商城自定义 3 点餐商城圆形 4 点餐商城自定义|
|errorIds|是|List| 错误的ids|

###请求参数Json格式
 
```
{
 "companyIds" : null,
 "groupId" : "String",
 "type" : 0,
 "errorDataType" : 0,
 "errorIds" : null
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--mallCustomErrorData|否|List| 会员商城自定义坐标失败的数据|
|----id|否|String| 失败的id|
|----location|否|String| 失败的坐标|
|----errorType|否|String| 失败的类型|
|----errorDistributionType|否|Integer| 失败的配送类型 0 圆形 1 自定义|
|--mallCustomRadiusData|否|List| 会员商城圆形坐标失败的数据|
|----id|否|String| 失败的id|
|----location|否|String| 失败的坐标|
|----errorType|否|String| 失败的类型|
|----errorDistributionType|否|Integer| 失败的配送类型 0 圆形 1 自定义|
|--mealMallCustomErrorData|否|List| 点餐商城商城圆形坐标失败的数据|
|----id|否|String| 失败的id|
|----location|否|String| 失败的坐标|
|----errorType|否|String| 失败的类型|
|----errorDistributionType|否|Integer| 失败的配送类型 0 圆形 1 自定义|
|--mealMallCustomRadiusData|否|List| 点餐商城商城圆形坐标失败的数据|
|----id|否|String| 失败的id|
|----location|否|String| 失败的坐标|
|----errorType|否|String| 失败的类型|
|----errorDistributionType|否|Integer| 失败的配送类型 0 圆形 1 自定义|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
