# 通用导入 - 品牌编码/品牌名称/折扣(%)
 

**请求URL：** 
- `/file/import/common/product/brand/rate `

**请求方式：**
- POST
- FormData


###请求参数<业务参数>
 
无参数


###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--dataSource|否|List||
|----discountRate|否|Double| 折扣率|
|----brandId|否|String| 品牌标识|
|----brandCode|否|String| 品牌编码|
|----brandName|否|String| 品牌名称|
|----status|否|Integer| 状态 1通用0不通过|
|----statusName|否|String| 状态名称|
|----msg|否|String| 错误描述|
|--downloadURL|否|String| 错误数据下载地址|
|--totalCount|否|Long| 总数|
|--successCount|否|Long| 成功数|
|--errorCount|否|Long| 错误数|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : {
 "dataSource" : [{
 "discountRate" : 0,
 "brandId" : "String",
 "brandCode" : "String",
 "brandName" : "String",
 "status" : 0,
 "statusName" : "String",
 "msg" : "String"
 }],
 "downloadURL" : "String",
 "totalCount" : 0,
 "successCount" : 0,
 "errorCount" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
