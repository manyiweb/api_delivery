# 购物车“确认订单”警告

**请求URL：** 
- `/b2b/shopping/cart/order/getWarning`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|shopCartKey|否|String| 如果是立即购买输入对应的立即购买cartKey|

### 请求参数Json格式
 
```
{
 "shopCartKey" : "String"
}
```
