# 科目表排序

**请求URL：** 
- `/config/subjectTable/sort`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|sortType|否|Integer| 排序类型 1置顶|
|ids|是|List||
|down|是|Boolean||
|companyId|否|String||

### 请求参数Json格式
 
```
{
 "sortType" : 0,
 "ids" : null,
 "down" : true,
 "companyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
