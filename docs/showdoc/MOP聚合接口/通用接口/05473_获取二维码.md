# 获取二维码
 

**请求URL：** 
- `/wx/common/qrCode/getQrCdoe`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|qrCodeId|是|Long| 二维码id|
|groupId|是|Long| 品牌标识|

### 请求参数Json格式
 
```
{
 "qrCodeId" : 0,
 "groupId" ：""
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long||
|--action|否|String| 行为|
|--body|否|String| 参数体|
|--imageUrl|否|String| 二维码图片|
|--companyId|否|String| 门店标识|
|--groupId|否|String| 品牌标识|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "action" : "String",
 "body" : "String",
 "imageUrl" : "String",
 "companyId" : "String",
 "groupId" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
