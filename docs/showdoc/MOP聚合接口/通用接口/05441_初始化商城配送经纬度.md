# 初始化商城配送经纬度
 

**请求URL：** 
- `/config/mallSameCityDelivery/init/initMallLogAndLat `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyIds|是|List| 门店id列表|
|groupId|是|String| 品牌id|
|type|否|Integer| 0 会员商城 1 点餐商城 2 所有|


###请求参数Json格式
 
```
{
 "companyIds" : null,
 "groupId" : "String",
 "type" : 0,
 "errorDataType" : 0,
 "errorIds" : null
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
