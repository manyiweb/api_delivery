# 提货配送单-更新快递信息

**请求URL：** 
- `/app/Business/order/updateDeliveryExpressInfo `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|deliveryId|是|String| 提货单id|
|expressCompany|否|String| 快递公司名称|
|expressNumber|否|String| 快递单号|

###请求参数Json格式
 
```
{
 "deliveryId" : "String",
 "expressCompany" : "String",
 "expressNumber" : "String"
}
```
