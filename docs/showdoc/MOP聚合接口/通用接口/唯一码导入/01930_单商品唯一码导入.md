# 

**请求URL：** 
- `/product/uniquecode/import `

**请求方式：**
- POST
- FormData


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|itemId|否|String| 商品档案ID|
|specId|否|String| 商品规格ID|
|docType|否|String| 单据类型，取值： AllotOrder("调拨申请单"),AllotOrder_OUT("调拨申请单_发货"),AllotOrder_In("调拨申请单_收货"),DOrder("销售订单"),DRefund("销售退货单"),Delivery("提货配送单"),WhsIn("入库单"), WhsOut("出库单"),B2BDOrder("订货订单"),B2BDOrder_OUT("订货订单_发货"),B2BDOrder_IN("订货订单_收货"),DGoodsInOrder_IN("采购订单_收货"),DCheckVouch("盘点");|
|tokenId|否|String| 登录标识|
|file|否|Object| 导入文件|

###请求参数Json格式
 
```
{
 "itemId" : "String",
 "specId" : "String",
 "docType" : "String",
 "tokenId" : "String",
 "file" : null
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--barcodes|否|List| 商品唯一码数据|
|----barcode|否|String| 唯一码|
|----attachBarcode|否|String| 附加码|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : {
 "barcodes" : [{
 "barcode" : "String",
 "attachBarcode" : "String"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
