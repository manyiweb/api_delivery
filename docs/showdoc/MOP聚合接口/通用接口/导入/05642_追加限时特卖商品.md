# 追加限时特卖商品

**请求URL：** 
- `/file/product/item/flashSaleProduct/import `

**请求方式：**
- POST
- FormData


###请求参数<业务参数>
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|是|String| token|
|file|是|file| 文件|
|ruleId|是|String| 规则id|



###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--dataSource|否|List||
|--downloadURL|否|String| 错误数据下载地址|
|--totalCount|否|Long| 总数|
|--successCount|否|Long| 成功数|
|--errorCount|否|Long| 错误数|
|--code|否|Integer||
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "dataSource" : null,
 "downloadURL" : "String",
 "totalCount" : 0,
 "successCount" : 0,
 "errorCount" : 0,
 "code" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
