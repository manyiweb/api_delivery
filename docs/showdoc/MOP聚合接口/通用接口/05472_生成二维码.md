# 生成二维码
 

**请求URL：** 
- `/wx/common/qrCode/createQrCdoe`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|action|是|String| 小程序页面|
|body|是|String| 参数体|
|companyId|是|String| 门店标识|
|wxSn|是|String| 微信标识|
|bizId|否|String| 业务标识|

### 请求参数Json格式
 
```
{
 "action" : "String",
 "body" : "String",
 "companyId" : "String",
 "wxSn" : "String",
 "bizId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long||
|--action|否|String| 小程序页面|
|--body|否|String| 参数体|
|--imageUrl|否|String| 二维码图片|
|--companyId|否|String| 门店标识|
|--groupId|否|String| 品牌标识|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "action" : "/pages/luckDraw/luckDraw",
 "body" : "{"isSwitchStores":true,"duUrl":true,"url":"/pages/luckDraw/luckDraw?id=2785318005744727950"}",
 "imageUrl" : "String",
 "companyId" : "String",
 "groupId" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
