# 获取科目表详情

**请求URL：** 
- `/config/subjectTable/detail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 主键id|

### 请求参数Json格式
 
```
{
 "id" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--subjectCode|否|String| 科目编码|
|--subjectName|否|String| 科目名称|
|--subjectNickname|否|String| 科目别名|
|--status|否|Integer| 活跃状态 0停用 1启用|
|--parentId|否|Long| 父级id|
|--parentSubjectName|否|String| 父级名称|
|--parentSubjectCode|否|String| 父级编码|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "subjectCode" : "String",
 "subjectName" : "String",
 "subjectNickname" : "String",
 "status" : 0,
 "parentId" : 0,
 "parentSubjectName" : "String",
 "parentSubjectCode" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
