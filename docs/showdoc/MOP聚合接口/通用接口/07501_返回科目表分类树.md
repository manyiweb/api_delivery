# 返回科目表分类树

**请求URL：** 
- `/config/subjectTable/list/tree`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
无参数


### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Integer| 主键id|
|--subjectName|否|String| 科目名称|
|--subjectCode|否|String| 科目编码|
|--parentId|否|Long| 父级id|
|--children|否|List| 子类|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "subjectName" : "String",
 "subjectCode" : "String",
 "parentId" : 0,
 "children" : null
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
