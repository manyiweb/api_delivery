# 商户档案

**请求URL：** 
- `/hr/sysCompanySearch/list`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|keyword|否|String| 关键字|
|merchantsAreafCodes|否|String| 所属区域|
|distributorCode|否|List| 所属经销商|
|bossName|否|List|商户运营者 |
|createId|否|List| 创建人|
|applyName|否|List| 申请人|
|createDate|否|Object| 创建日期|
|--start|否|DateTime||
|--end|否|DateTime||
|auditDate|否|Object| 审核日期|
|--start|否|DateTime||
|--end|否|DateTime||
|id|否|String||
|pageSize|否|Integer||
|pageNo|否|Integer||
|sortField|否|String||
|sortDirection|否|String||
