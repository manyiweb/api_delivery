# 修改配置

**请求URL：** 
- `/api/core/app/SysConfig/SetSysConfig`

**请求方式：**
- POST
- RequestBody

### 返回示例
```
{
 "ErrorCode": "",
 "ResultString": "操作成功",
 "ResultInt": 0
}
```

###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|configList|否|Array| 配置|
|key|否|String| 配置项|
|value|否|String| 配置值|

###请求参数Json格式
 
```
{
	"configList":[
	 {
 "key":"jpush.appkey",
 "value":"aab338a5343b584120bd5984"
		
		},
		{
		 "key":"jpush.masterSecret",
		 "value":"ad80c996fd92b8046463861e"
		}
 ],
	"tokenId":"af9423950e084648ac12a016fe26ed43"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|ResultInt|否|Int| 处理结果|
|ResultString|否|String| 消息|
|ErrorCode|否|String| 错误代码|


###返回参数Json格式
 
```
{
 "ErrorCode": "",
 "ResultString": "操作成功",
 "ResultInt": 0
}
```
