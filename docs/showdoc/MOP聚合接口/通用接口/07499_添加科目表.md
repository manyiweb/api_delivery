# 添加科目表

**请求URL：** 
- `/config/subjectTable/add`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 主键id|
|subjectCode|否|String| 科目编码|
|subjectName|否|String| 科目名称|
|subjectNickname|否|String| 科目别名|
|status|否|Integer| 启用状态|
|parentId|否|Long| 父级id (最顶层传 -1)|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "subjectCode" : "String",
 "subjectName" : "String",
 "subjectNickname" : "String",
 "status" : 0,
 "parentId" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
