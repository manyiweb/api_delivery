# 查询报表
 
 ** Datatable id ：** 
- `quickbi-shell-page-manage-list-datatable`

**请求URL：** 
- `/quickbi/quickBiShellPage/manage/query`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|String||
|keyword|否|String| 关键字|
|isActive|否|Boolean| 是否活跃|
|createUserName|否|String| 创建人|
|createDateRange|否|Object| 创建时间|
|--start|否|DateTime||
|--end|否|DateTime||
|modifyUserName|否|String| 修改人|
|modifyDateRange|否|Object| 修改时间|
|--start|否|DateTime||
|--end|否|DateTime||
|pageNo|否|Integer| 页码|
|pageSize|否|Integer| 每页大小|
|sortField|否|String| 排序字段|
|sortDirection|否|Enum| 排序方式|

### 请求参数Json格式
 
```
{
 "id" : "String",
 "keyword" : "String",
 "isActive" : true,
 "createUserName" : "String",
 "createDateRange" : {
 "start" : "DateTime",
 "end" : "DateTime"
 },
 "modifyUserName" : "String",
 "modifyDateRange" : {
 "start" : "DateTime",
 "end" : "DateTime"
 },
 "pageNo" : 0,
 "pageSize" : 0,
 "sortField" : "String",
 "sortDirection" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--content|否|List||
|----id|否|String||
|----reportName|否|String| 报表名称|
|----isActive|否|Boolean| 表报是否活跃|
|----createName|否|String| 创建人|
|----createDate|否|DateTime| 创建时间|
|----modifyName|否|String| 修改人|
|----modifyDate|否|DateTime| 修改时间|
|--pageSize|否|Integer||
|--pageNo|否|Integer||
|--total|否|Long||
|--totalPage|否|Integer||
|--hasNextPage|否|Boolean||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
