# 更新报表
 

**请求URL：** 
- `/quickbi/quickBiShellPage/manage/update`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|String||
|reportName|是|String| 报表名称|
|isActive|是|Boolean| 表报是否活跃|
|link|是|String| 报表链接|
|allowAllUserAccess|是|Boolean| 是否全部用户可访问|
|accessUserRoles|是|List| 指定的用户角色|
|--roleId|是|String| 用户角色ID|
|--roleCode|是|String| 用户角色编码|
|--roleName|是|String| 用户角色名称|

### 请求参数Json格式
 
```
{
 "id" : "String",
 "reportName" : "String",
 "isActive" : true,
 "link" : "String",
 "allowAllUserAccess" : true,
 "accessUserRoles" : [{
 "roleId" : "String",
 "roleCode" : "String",
 "roleName" : "String"
 }]
}
```
