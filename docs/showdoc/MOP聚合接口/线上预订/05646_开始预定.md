# 开始预定
 

**请求URL：** 
- `/online/reserve/doReserve `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String|门店id |
|reserveDate|否|DateTime|预约提货时间 |
|cardNos|否|List|卡号集合 |

###请求参数Json格式
 
```
{
 "companyId" : "String",
 "reserveDate" : "DateTime",
 "cardNos" : null
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--orderId|否|String| 订单id|
|--orderNo|否|String| 订单编号|
|--queueNumber|否|String| 取餐码|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "orderId" : "String",
 "orderNo" : "String",
 "queueNumber" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
