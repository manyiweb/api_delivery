# 获取视图列表

**请求URL：** 
- `/config/exportView/list`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|String||

### 请求参数Json格式
 
```
{
 "id" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--id|否|String| 主键id|
|--userId|否|String| 用户id|
|--groupId|否|String||
|--datatableId|否|String||
|--exportId|否|String| 导出任务id|
|--title|否|String| 标题|
|--fields|否|List| 字段|
|----fieldName|否|String||
|----fieldCode|否|String||
|----alias|否|String||
|----width|否|String||
|--isSystemView|否|Boolean| 是否系统默认视图|
|--isUserSelect|否|Boolean| 是否用户选择|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "id" : "String",
 "userId" : "String",
 "groupId" : "String",
 "datatableId" : "String",
 "exportId" : "String",
 "title" : "String",
 "fields" : [{
 "fieldName" : "String",
 "fieldCode" : "String",
 "alias" : "String",
 "width" : "String"
 }],
 "isSystemView" : true,
 "isUserSelect" : true
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
