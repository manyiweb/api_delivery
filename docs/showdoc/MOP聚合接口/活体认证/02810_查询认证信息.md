# 查询认证信息

**请求URL：** 
- `/hr/staff/information `

**请求方式：**
- POST
- FormData


###请求参数<业务参数>
 
无参数


###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--information|否|Object| 个人认证信息|
|----name|否|String| 姓名|
|----idCard|否|String| 身份证|
|----gender|否|String| 性别|
|----address|否|String| 地址|
|----certFront|否|String| 身份证正面（人像面）|
|----certBack|否|String| 身份证背面（国徽面）|
|----personalUploadAuth|否|Integer| 个人身份上传认证 0未上传 1已上传|
|--bankCardInfoDTO|否|Object| 银行账号信息|
|----id|否|Long| ID|
|----bankCardNo|否|String| 银行卡号|
|----custId|否|String| 客户号|
|----bankCardMobile|否|String| 银行卡预留手机号|
|----flowIndex|否|Integer| 跳转标记,若为5:隐藏超链接与弹框，若为3或4:"马上开户超链接",跳转绑定银行卡页面，其它或为nul：账户ID展示"马上开户超链接",且跳转验证手机页面|
|----companyName|否|String| 企业名称|
|----creditCode|否|String| 统一社会信用代码|
|----authName|否|String| 认证名称|
|----createMobile|否|String| 通联注册手机号|
|----cnapsName|否|String| 支行名称|
|----bankBranchId|否|Long| 支行id|
|----headBankId|否|Long| 总行id|
|----participantAlias|否|String| 总行参与者别名|
|----userCode|否|String| 用户账号|
|--lkUserType|否|Integer| 链客用户类型;1:创客,2:个体工商户|
|--individualBusinessFlowIndex|否|Integer| 个体工商户跳转标记,1:展示开户按钮,2:提示联系管理员完成企业认证,3:展示提现按钮|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
