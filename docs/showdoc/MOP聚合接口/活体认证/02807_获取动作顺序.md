# 获取动作顺序

**请求URL：** 
- `/hr/staff/getactionsequence `

**请求方式：**
- POST
- FormData


###请求参数<业务参数>
 
无参数


###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--ActionSequence|否|String| 动作顺序(2,1 or 1,2) 。1代表张嘴，2代表闭眼。 |
|--RequestId|否|String||
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : {
 "ActionSequence" : "String",
 "RequestId" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
