# 后台任务列表

**请求URL：** 
- `/api/taskcenter/task/instance/list`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|pageIndex|否|Integer| 页号|
|pageSize|否|Integer| 页大小|
|id|否|Long| id|

### 请求参数Json格式
 
```
{
 "pageIndex" : 0,
 "pageSize" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--pageIndex|否|Integer| 页码|
|--pageSize|否|Integer| 显示记录数|
|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|--first|否|Boolean| 首页|
|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|
|----taskId|否|String| 任务ID|
|----taskName|否|String| 任务名称|
|----taskInstanceId|否|String| 任务实例ID|
|----result|否|String| 执行结果信息|
|----resultData|否|Object| 执行结果信息|
|------downloadUrl|否|String| 附件地址|
|------totalQty|否|Long| 总数量|
|------failQty|否|Long| 失败数量|
|------successQty|否|Long| 成功数量|
|----processorType|否|Integer| 1导入 2导出|
|----statusName|否|String| 状态名称|
|----status|否|String| 状态 1-等待派发; 2-等待Worker接收; 3-运行中; 4-失败; 5-成功; 9-取消, 10-手动停止|
|----createDate|否|Object| 创建时间|
|----finishedDate|否|Object| 完成时间|
|msg|否|String| 消息|
|code|否|String| 业务代码|
