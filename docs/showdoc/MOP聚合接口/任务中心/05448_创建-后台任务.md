# 创建-后台任务

**请求URL：** 
- `/task-center-front/daemon/task/create`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|taskName|是|String| 任务名称|
|taskType|是|Integer| 任务类型:1-导入;2-导出;3-业务|
|businessType|是|Integer| 业务类型|
|params|否|Object| 输入参数|
|attachment|否|Object| 输入文件OSS路径|
|remark|否|String| 备注|

### 请求参数Json格式
 
```
{
 "taskName" : "String",
 "taskType" : 0,
 "businessType" : 0,
 "params" : null,
 "attachment" : null,
 "remark" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|String| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : "String",
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
