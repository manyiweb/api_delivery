# 

**请求URL：** 
- `/api/taskcenter-server/task/instance/run`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|taskId|否|Long| 任务id, 不同导出任务有不同id|
|taskInstanceParam|否|Map| 导出任务参数|
|fileName|否|String| 导入文件名称|
|fileFullUrl|否|String| 导入文件url|
|fileSize|否|Long| 导入文件大小|

### 请求参数Json格式
 
```
{
 "taskId" : 0,
 "taskInstanceParam" : null,
 "fileName" : "String",
 "fileFullUrl" : "String",
 "fileSize" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Long| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|


### 返回参数Json格式
 
```
{
 "data" : 0,
 "msg" : "String",
 "code" : "String"
}
```
