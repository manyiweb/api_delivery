# 分页查询多语言字典



 
##### 简要描述

- 用户注册接口

##### 请求URL
- ` /api/manage/app/dict/multilang/page`
 
##### 请求方式
- POST 

##### 参数

|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|menuId |是 |string |菜单id |

##### 参数示例 

``` 
{
 "menuId": "demoData",
 "sword": "",
 "pageIndex": 1,
 "pageSize": 10
}
```

##### 返回参数说明 

|参数名|类型|说明|
|:----- |:-----|----- |
|dictCode |string |字典编码 |
|dictNameCn |string |字典编码 |
|dictNameCn |string |简体中文 |
|dictNameHk |string |繁体中文 |
|dictNameEn |string |英文 |
|description |string |描述 |
