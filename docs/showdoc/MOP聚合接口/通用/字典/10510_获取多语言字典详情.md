# 获取多语言字典详情
 

**请求URL：** 
- `/app/dict/multilang/get`

**请求方式：** 
- `POST`
- `RequestBody`


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long||

### 请求参数Json格式
 
```
{
 "id":0
}
```

### 响应参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long| 主键ID|
|--dictCode|否|String| 字典编码|
|--dictNameCn|否|String| 简体中文|
|--dictNameHk|否|String| 繁体中文|
|--dictNameEn|否|String| 英文|
|--description|否|String| 描述|
|--firstLevelMenuName|否|String| 第一级菜单名称|
|--secondLevelMenuName|否|String| 第二级菜单名称|
|--thirdLevelMenuName|否|String| 第三级菜单名称|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 响应参数Json格式
 
```
{
 "data":{
 "id":0,
 "dictCode":"String",
 "dictNameCn":"String",
 "dictNameHk":"String",
 "dictNameEn":"String",
 "description":"String",
 "firstLevelMenuName":"String",
 "secondLevelMenuName":"String",
 "thirdLevelMenuName":"String"
 },
 "msg":"String",
 "code":"String",
 "exceptionStackInfo":"String",
 "traceId":"String"
}
```
