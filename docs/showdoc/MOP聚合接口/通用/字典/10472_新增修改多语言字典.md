# 创建多语言字典
 

**请求URL：** 
- `/app/dict/multilang/save`

**请求方式：** 
- `POST`
- `RequestBody`


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 主键ID|
|sysNo|否|String| 平台|
|dictCode|是|String| 字典编码|
|dictNameCn|是|String| 简体中文|
|dictNameHk|是|String| 繁体中文|
|dictNameEn|是|String| 英文|
|description|否|String| 描述|
|menuId|否|String| 菜单ID|

### 请求参数Json格式
 
```
{
 "id":0,
 "sysNo":"String",
 "dictCode":"String",
 "dictNameCn":"String",
 "dictNameHk":"String",
 "dictNameEn":"String",
 "description":"String",
 "menuId":"String"
}
```

### 响应参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 响应参数Json格式
 
```
{
 "data":null,
 "msg":"String",
 "code":"String",
 "exceptionStackInfo":"String",
 "traceId":"String"
}
```
