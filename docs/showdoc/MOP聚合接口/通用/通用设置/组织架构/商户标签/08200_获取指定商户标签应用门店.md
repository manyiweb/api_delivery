# 获取指定商户标签应用门店

**请求URL：** 
- `/hr/company/label/getLabelApplyCompany `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 商户标签id|
|sword|否|String| 搜索关键字|
|pageIndex|否|Integer||
|pageSize|否|Integer||
|orderField|否|String||
|orderSort|否|String||

###请求参数Json格式
 
```
{
 "id" : 0,
 "sword" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--pageIndex|否|Integer||
|--pageSize|否|Integer||
|--pageCount|否|Integer||
|--totalCount|否|Long||
|--first|否|Boolean||
|--last|否|Boolean||
|--content|否|List||
|----companyId|否|String| 门店id|
|----companyCode|否|String| 门店编码|
|----companyName|否|String| 门店名称|
|----companyLabelCompId|否|Long| 门店标签应用中间表id|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


###返回参数Json格式
 
```
{
 "data" : {
 "pageIndex" : 0,
 "pageSize" : 0,
 "pageCount" : 0,
 "totalCount" : 0,
 "first" : true,
 "last" : true,
 "content" : [{
 "companyId" : "String",
 "companyCode" : "String",
 "companyName" : "String",
 "companyLabelCompId" : 0
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
