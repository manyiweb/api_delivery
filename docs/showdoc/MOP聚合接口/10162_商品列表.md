# 创建转储单

**请求URL：** 
- `/product/allot/create/dumpSpecInfo`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|list|否|List| 规格id|
|dumpType|否|Integer| 创建类型|

### 请求参数Json格式
 
```
{
 "list" : null,
 "dumpType" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--specId|否|String| 规格id|
|--itemId|否|String| 商品id|
|--itemName|否|String| 商品名称|
|--itemCode|否|String| 商品名称|
|--skuBarCode|否|String| 规格编码|
|--materialProdWorkShopId|否|Long| 配料车间id|
|--materialProdWorkShopName|否|String| 配料车间名称|
|--onHandQty|否|Double| 当前车间库存|
|--materialOnHandQty|否|Double| 领料车间库存|
|--needQuantity|否|Double| 绣球量|
|--dumpQuantity|否|Double| 已转储数量|
|--unit|否|String||
|--circulationWorkshops|否|List| 扭转车间|
|----factoryWorkshopId|否|Long| 工厂生产车间id|
|----prodWorkshopId|否|Long| 生产车间id|
|----prodWorkshopNo|否|String| 生产车间编码|
|----prodWorkshopName|否|String| 生产车间名称|
|----specId|否|String||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
