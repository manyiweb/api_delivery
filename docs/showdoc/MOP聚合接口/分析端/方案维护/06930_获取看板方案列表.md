# 获取看板方案列表
 
** datatable_id：** 
- report_analytics_dashboard_scheme_list

**请求URL：** 
- `/report/dashboard/scheme/list`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|keyword|否|String| 关键字|
|id|否|String| ID|
|pageSize|否|Integer| 分页大小|
|pageIndex|否|Integer| 分页|

### 请求参数Json格式
 
```
{
 "keyword" : "String",
 "id" : "String",
 "pageSize" : 0,
 "pageIndex" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--content|否|List||
|----id|否|String||
|----name|否|String| 方案名称|
|----schemeCode|否|String| 看板方案编码|
|----industrySolutionId|否|Long| 看板方案对应行业解决方案ID|
|----industrySolutionName|否|String| 看板方案对应行业解决方案名称|
|----industrySolutionDefault|否|Boolean| 是否对应的行业解决方案的默认方案|
|----groupApplyCount|否|Long| 品牌应用数量|
|----createId|否|String| 创建人id|
|----createName|否|String| 创建人|
|----createDate|否|DateTime| 创建时间|
|----modifyId|否|String| 修改人id|
|----modifyName|否|String| 修改人|
|----modifyDate|否|DateTime| 修改时间|
|--pageSize|否|Integer||
|--pageNo|否|Integer||
|--total|否|Long||
|--totalPage|否|Integer||
|--hasNextPage|否|Boolean||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
