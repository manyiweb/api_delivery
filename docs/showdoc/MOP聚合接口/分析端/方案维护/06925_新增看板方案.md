# 新增看板方案
 

**请求URL：** 
- `/report/dashboard/scheme/add`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|recordList|否|List| 看板方案绑定的看板页面列表|
|--groupCode|否|String| 品牌id|
|--groupName|否|String| 品牌名称|
|--groupShortName|否|String| 品牌简称|
|--industry|否|String| 品牌行业|
|--industrySolutionId|否|String| 品牌行业解决方案id|
|--industrySolutionName|否|String| 品牌行业解决方案名称|
|--groupId|是|String| 品牌id|
|schemeId|是|String||
|name|是|String| 看板方案名称|
|industrySolutionId|是|Long| 看板方案对应行业解决方案ID|
|industrySolutionName|是|String| 看板方案对应行业解决方案名称|
|industrySolutionDefault|是|Boolean| 是否对应的行业解决方案的默认方案|
|pageInfos|是|List| 看板方案绑定的看板页面列表|
|--pageId|是|String| 页面ID 如果是 businessScenario 为QBI时 pageId 可以为空|
|--businessScenario|是|Enum| 业务场景 RETAIL("零售"), B2B("订货"), SUPPLY("供销"), MEMBER("会员"), QBI("QBI")|
|--pageAlias|是|String| 页签别名|
|indexPageInfos|否|List| 看板方案绑定的首页列表|
|--pageId|否|String| 页面ID|
|--platform|否|Enum| 平台编号 mgd:品牌端、 merchant:商户端|
|--pageCode|否|String| 页面编码|
|--pageName|否|String| 看板页面名称|

```
 "name" : "String",
 "industrySolutionId" : 0,
 "industrySolutionName" : "String",
 "industrySolutionDefault" : true,

 "pageId" : "String",

 "pageAlias" : "String"
 }],
 "indexPageInfos" : [{
 "pageId" : "String",
 "platform" : 0,
 "pageCode" : "String",
 "pageName" : "String"
 }]
}
```

|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
