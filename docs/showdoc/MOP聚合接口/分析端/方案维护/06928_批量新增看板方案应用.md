# 批量新增看板方案应用
 

**请求URL：** 
- `/report/dashboard/scheme/batchAddDashboardSchemeGroupApply`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|groupInfoList|是|List| 看板方案绑定的看板页面列表|
|--groupCode|否|String| 品牌id|
|--groupName|否|String| 品牌名称|
|--groupShortName|否|String| 品牌简称|
|--industry|否|String| 品牌行业|
|--industrySolutionId|否|String| 品牌行业解决方案id|
|--industrySolutionName|否|String| 品牌行业解决方案名称|
|--groupId|是|String| 品牌id|
|schemeId|是|String| 看板方案id|

### 请求参数Json格式
 
```
{
 "groupInfoList" : [{
 "groupCode" : "String",
 "groupName" : "String",
 "groupShortName" : "String",
 "industry" : "String",
 "industrySolutionId" : "String",
 "industrySolutionName" : "String",
 "groupId" : "String"
 }],
 "schemeId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
