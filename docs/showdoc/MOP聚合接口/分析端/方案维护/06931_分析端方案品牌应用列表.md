# 分析端方案品牌应用列表
 
 ** datatable_id ：** 
- report_analytics_dashboard_scheme_apply_list

**请求URL：** 
- `/report/dashboard/scheme/apply/list`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|keyword|否|String||
|schemeId|否|String| 方案ID[必传]|
|pageSize|否|Integer| 分页大小|
|pageIndex|否|Integer| 分页|

### 请求参数Json格式
 
```
{
 "keyword" : "String",
 "schemeId" : "String",
 "pageSize" : 0,
 "pageIndex" : 0
}
```

|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--content|否|List||
|----id|否|String||
|----groupId|否|String| 品牌ID|
|----groupCode|否|String| 品牌编码|
|----groupName|否|String| 品牌名称|
|----groupShortName|否|String| 品牌简称|
|----industry|否|String| 品牌行业|
|----industrySolutionId|否|String| 品牌行业解决方案id|
|----industrySolutionName|否|String| 品牌行业解决方案名称|
|--pageSize|否|Integer||
|--pageNo|否|Integer||
|--total|否|Long||
|--totalPage|否|Integer||
|--hasNextPage|否|Boolean||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
