# 获取看板方案详情
 

**请求URL：** 
- `/report/dashboard/scheme/detail/{schemeId}`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|schemeId|否|String| |

### 请求参数Json格式
 
```
{
 "schemeId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|String| 看板方案ID|
|--name|否|String| 看板方案名称|
|--schemeCode|否|String| 看板方案编码|
|--industrySolutionId|否|Long| 看板方案对应行业解决方案ID|
|--industrySolutionName|否|String| 看板方案对应行业解决方案名称|
|--industrySolutionDefault|否|Boolean| 是否对应的行业解决方案的默认方案|
|--pageInfos|否|List| 看板方案绑定的看板页面列表|
|----pageId|否|String| 页面ID|
|----pageCode|否|String| 页面编码|
|----businessScenario|否|Enum| 业务场景 RETAIL("零售"), B2B("订货"), SUPPLY("供销"), MEMBER("会员")|
|----pageName|否|String| 看板页面名称|
|----pageAlias|否|String| 页签别名|
|--indexPageInfos|否|List| 看板方案绑定的看板首页页面列表|
|----pageId|否|String| 页面ID|
|----platform|否|Enum| 平台编号 mgd:品牌端、 merchant:商户端|
|----pageCode|否|String| 页面编码|
|----pageName|否|String| 看板页面名称|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||

```
 "industrySolutionId" : 0,

 "pageInfos" : [{
 "pageId" : "String",
 "pageCode" : "String",
 "businessScenario" : 0,
 "pageName" : "String",
 "pageAlias" : "String"
 }],
 "indexPageInfos" : [{
 "pageId" : "String",
 "platform" : 0,
 "pageCode" : "String",
 "pageName" : "String"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
