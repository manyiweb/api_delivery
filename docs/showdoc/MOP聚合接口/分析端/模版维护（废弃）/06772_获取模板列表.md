# 获取模板列表

**请求URL：** 
- `/report/analytics/dashboard/template/maintenance/list`

** Datatable信息：** 
- ID: report_analytics_dashboard_template_list
- 服务：reabam-report

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|keyword|否|String| 关键字|
|id|否|String| ID|
|pageSize|否|Integer| 分页大小|
|pageIndex|否|Integer| 分页|

### 请求参数Json格式
 
```
{
 "keyword" : "String",
 "id" : "String",
 "pageSize" : 0,
 "pageIndex" : 0
}
```

```

|参数名|必选|类型|说明|

|--content|否|List||
|----templateId|否|String| ID|
|----name|否|String| 模板名称|
|----templateCode|否|String| 模板编码|
|----applyCount|否|Long| 应用品牌数量|
|----createId|否|String| 创建人id|
|----createName|否|String| 创建人|
|----createDate|否|DateTime| 创建时间|
|--pageSize|否|Integer||
|--pageNo|否|Integer||
|--total|否|Long||
|--totalPage|否|Integer||
|--hasNextPage|否|Boolean||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
