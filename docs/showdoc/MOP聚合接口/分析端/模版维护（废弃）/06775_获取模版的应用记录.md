# 获取模版的应用记录
 

**请求URL：** 
- `/report/analytics/dashboard/template/apply/listByTemplateId`

** Datatable信息：** 
- ID: report_analytics_dashboard_template_apply_list
- 服务：reabam-report


**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|keyword|否|String||
|templateId|否|String| 模版ID[必传]|
|pageSize|否|Integer| 分页大小|
|pageIndex|否|Integer| 分页|

### 请求参数Json格式
 
```
{
 "keyword" : "String",
 "templateId" : "String",
 "pageSize" : 0,
 "pageIndex" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--content|否|List||
|----id|否|String||
|----groupCode|否|String| 品牌id|
|----groupName|否|String| 品牌名称|
|----groupShortName|否|String| 品牌简称|
|----industry|否|String| 品牌行业|
|----groupId|否|String| 品牌id|
|--pageSize|否|Integer||
|--pageNo|否|Integer||
|--total|否|Long||
|--totalPage|否|Integer||
|--hasNextPage|否|Boolean||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "content" : [{
 "id" : "String",
 "groupCode" : "String",
 "groupName" : "String",
 "groupShortName" : "String",
 "industry" : "String",
 "groupId" : "String"
 }],
 "pageSize" : 0,
 "pageNo" : 0,
 "total" : 0,
 "totalPage" : 0,
 "hasNextPage" : true
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
