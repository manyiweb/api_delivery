# 柱状图看板查询
 

**请求URL：** 
- `/report/analytics/dashboard/histogramBoard/query`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|templateId|是|String| 模板id|
|labelGroupName|是|String| 标签组名称|
|labelName|是|String| 标签名称|
|params|是|Map| 参数|

### 请求参数Json格式
 
```
{
 "templateId" : "String",
 "labelGroupName" : "String",
 "labelName" : "String",
 "params" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--rows|否|List| 行数据|
|----dimensionName|否|String| 维度名称|
|----mainStatisticsData|否|String| 主统计数据|
|----additionalStatisticsData|否|String| 附加统计数据|
|--additionalAggregateResultUnit|否|String| 附加聚合结果单位|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "rows" : [{
 "dimensionName" : "String",
 "mainStatisticsData" : "String",
 "additionalStatisticsData" : "String"
 }],
 "additionalAggregateResultUnit" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
