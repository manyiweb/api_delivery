# 表格看板查询
 

**请求URL：** 
- `/report/analytics/dashboard/table/query`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|templateId|是|String| 模板id|
|labelGroupName|是|String| 标签组名称|
|labelName|是|String| 标签名称|
|isAdditionalTable|是|Boolean| 是否查询附加表格|
|params|是|Map| 参数|
|sortColumnName|否|String| 排序字段|
|asc|否|Boolean| 是否升序|

### 请求参数Json格式
 
```
{
 "templateId" : "String",
 "labelGroupName" : "String",
 "labelName" : "String",
 "isAdditionalTable" : true,
 "params" : null,
 "sortColumnName" : "String",
 "asc" : true
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--columnDefinitions|否|List| 列定义|
|----columnName|是|String| 字段名称|
|----alias|是|String| 字段展示别名|
|----sortable|是|Boolean| 是否可排序|
|----aligningType|是|Enum| 对齐方式 LEFT("左对齐"), CENTER("居中对齐"), RIGHT("右对齐");|
|----displayFormat|是|Enum| 数字类型格式化方式 INTEGER("整数"), KEEP_TWO_DECIMALS("保留两位小数");|
|--dataRows|否|List| 数据行|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "columnDefinitions" : [{
 "columnName" : "String",
 "alias" : "String",
 "sortable" : true,
 "aligningType" : 0,
 "displayFormat" : 0
 }],
 "dataRows" : null
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
