# 获取当前用户品牌的指标看板定义

**请求URL：** 
- `/report/analytics/dashboard/display/definition`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
无参数


### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|String| 模板ID|
|--name|否|String| 模板名称|
|--templateCode|否|String| 模板编码|
|--indicatorBoardDefinition|否|Object| 指标看板定义|
|----name|否|String| 指标看板名称|
|----displayDescription|否|Boolean| 是否显示指标看板描述|
|----description|否|String| 指标看板描述|
|----labelGroupDefinitions|否|List| 指标看板标签组列表|
|------labelGroupName|否|String| 标签组名称|
|------labelList|否|List| 标签列表|
|--doughnutBoardDefinition|否|Object| 环形图看板定义|
|----name|否|String| 环形图看板名称|
|----displayDescription|否|Boolean| 是否显示指标看板描述|
|----description|否|String| 指标看板描述|
|----labelList|否|List| 环形图看板标签列表|
|--tableDashboardDefinition|否|Object| 列表看板定义|
|----name|否|String| 列表看板名称|
|----displayDescription|否|Boolean| 是否显示列表看板描述|
|----description|否|String| 列表看板描述|
|----labelGroupDefinitions|否|List| 列表看板标签组列表|
|------labelGroupName|否|String| 列表看板标签组名称|
|------labelList|否|List| 标签列表|
|--histogramBoardDefinition|否|Object| 柱状图看板定义|
|----name|否|String| 柱状图看板名称|
|----displayDescription|否|Boolean| 是否显示柱状图看板描述|
|----description|否|String| 柱状图看板描述|
|----labelGroupDefinitions|否|List| 标签组列表|
|------labelGroupName|否|String| 列表看板标签组名称|
|------labelList|否|List| 标签列表|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
