# 指标看板查询
 

**请求URL：** 
- `/report/analytics/dashboard/indicatorBoard/query`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|templateId|是|String| 模板ID|
|labelGroupName|是|String| 标签组名称|
|labelName|是|String| 标签名称|
|paramsOfNow|是|Map| 当前时间参数|
|paramsOfPass|是|Map| 比较时间参数|
|paramsOfLastYear|是|Map| 比较去年同期参数|

### 请求参数Json格式
 
```
{
 "templateId" : "String",
 "labelGroupName" : "String",
 "labelName" : "String",
 "paramsOfNow" : null,
 "paramsOfPass" : null,
 "paramsOfLastYear" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--topicName|否|String| 主题名称|
|--displayYearOnYear|否|Boolean| 是否显示同环比|
|--valueOfNow|否|String| 当前时间段数据|
|--valueOfPass|否|String| 环比上一时间段数据|
|--valueOfLastYear|否|String| 同比去年数据|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "topicName" : "String",
 "displayYearOnYear" : true,
 "valueOfNow" : "String",
 "valueOfPass" : "String",
 "valueOfLastYear" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
