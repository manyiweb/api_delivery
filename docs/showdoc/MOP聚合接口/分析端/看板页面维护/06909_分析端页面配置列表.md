# 分析端页面配置列表

**Datatable id：**
- `report_analytics_dashboard_page_list`

**请求URL：** 
- `/report/analytics/maintenance/dashboard/page/list`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|keyword|否|String| 关键字|
|id|否|String| ID|
|pageTypes|否|List| 页面类型 APP WEB|
|staffId|否|String||
|businessScenario|否|Enum| 业务场景|
|createDateRange|否|Object| 创建时间|
|--start|否|DateTime||
|--end|否|DateTime||
|pageSize|否|Integer| 分页大小|
|pageIndex|否|Integer| 分页|

### 请求参数Json格式
 
```
{
 "keyword" : "String",
 "id" : "String",
 "pageTypes" : null,
 "staffId" : "String",
 "businessScenario" : 0,
 "createDateRange" : {
 "start" : "DateTime",
 "end" : "DateTime"
 },
 "pageSize" : 0,
 "pageIndex" : 0
}
```
