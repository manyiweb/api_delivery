# 复制分析端页面配置
 

**请求URL：** 
- `/report/analytics/maintenance/dashboard/page/copy`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|pageId|是|String| 页面id|
|name|是|String| 页面名称|
|pageType|是|Enum| 页面类型 APP("移动端"), WEB("网页端");|
|businessScenario|是|Enum| 业务场景 RETAIL("零售"), B2B("订货"), SUPPLY("供应"), MEMBER("会员"), QBI("QBI");|

### 请求参数Json格式
 
```
{
 "pageId" : "String",
 "name" : "String",
 "pageType" : 0,
 "businessScenario" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
