# 解析表达式
 

**请求URL：** 
- `/report/analytics/dataset/expression/parse`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|expression|是|String| 表达式|

### 请求参数Json格式
 
```
{
 "expression" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--parameterList|否|List| 条件参数列表|
|----parameterName|否|String| 参数名称|
|----isEnvironmentVariable|否|Boolean| 参数类型|
|--sliceParamList|否|List| 动态SQL片段参数列表|
|--columnList|否|List| 字段列表|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "parameterList" : [{
 "parameterName" : "String",
 "isEnvironmentVariable" : true
 }],
 "sliceParamList" : null,
 "columnList" : null
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
