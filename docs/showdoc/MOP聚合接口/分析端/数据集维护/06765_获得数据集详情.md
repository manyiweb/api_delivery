# 获得数据集详情
 

**请求URL：** 
- `/report/analytics/dataset/maintenance/detail`

**请求方式：** 
- `POST`
- `RequestBody`


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|datasetId|是|String| 数据集id|

### 请求参数Json格式
 
```
{
 "datasetId":"String"
}
```

### 响应参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|String| 数据集ID|
|--datasetCode|否|String| 数据集编码|
|--datasetTag|否|String| 数据集标签|
|--name|否|String| 数据集名称|
|--assignDatasource|否|Integer| 数据源类型|
|--openToAiAgent|否|Boolean| 是否开放给AI Agent|
|--aiPromptDescription|否|String| AI提示词描述|
|--assignDatasourceName|否|String| 数据源名称|
|--datasetExpression|否|String| 数据集表达式|
|--parameters|否|List| 参数列表|
|----name|否|String| 参数名称|
|----dataType|否|Object| 数据类型|
|------desc|否|String||
|----defaultValue|否|String| 参数值|
|----require|否|Boolean| 必填|
|----isEnvironmentVariable|否|Boolean| 环境变量参数|
|----description|否|String| 参数描述|
|--columns|否|List| 字段列表|
|----columnName|否|String| 字段名称|
|----alias|否|String| 别名|
|----dataType|否|Object| 数据类型|
|------desc|否|String||
|----effectType|否|Object| 作用类型|
|----defaultAggregateType|否|Object| 默认聚合类型|
|------funcName|否|String||
|------desc|否|String||
|----numberDisplayFormat|否|Object| 数字类型格式化方式|
|------desc|否|String| 描述|
|----sortable|否|Boolean| 是否支持排序|
|----description|否|String| 字段描述|
|--sqlSliceParameters|否|List| SQL片段参数列表|
|--datasetRefreshTaskId|否|Long| 数据集刷新任务ID|
|--datasetRefreshTaskName|否|String| 数据集刷新任务名称|
|--createName|否|String| 创建人|
|--createDate|否|DateTime| 创建时间|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
