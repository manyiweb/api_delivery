# 创建数据集
 

**请求URL：** 
- `/report/analytics/dataset/maintenance/create`

**请求方式：** 
- `POST`
- `RequestBody`


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|datasetId|是|String| 数据集ID|
|datasetTag|是|String| 数据集标签|
|name|是|String| 数据集名称|
|assignDatasource|是|Integer| 数据源 指定数据源 0-默认ADB 1-数据服务ADB 2-StarRocks 3-动态数据源|
|datasetExpression|是|String| 数据集表达式|
|columns|是|List| 数据集字段|
|--columnName|是|String| 字段名称|
|--alias|是|String| 别名|
|--dataType|是|Object| 数据类型 取值: TEXT, NUMBER, DATE, BOOLEAN|
|----desc|否|String||
|--effectType|是|Object| 作用类型 取值： DIMENSIONALITY-维度, MEASUREMENT-度量|
|--defaultAggregateType|是|Object| 默认聚合类型 取值： SUM-求和, AVG-平均值, MAX-最大值, MIN-最小值, COUNT-计数, COUNT_DISTINCT-去重计数|
|----funcName|否|String||
|----desc|否|String||
|--numberDisplayFormat|是|Object| 数字类型格式化方式 取值：INTEGER-整数, KEEP_TWO_DECIMALS-保留两位小数|
|----desc|否|String| 描述|
|--sortable|是|Boolean| 是否支持排序 取值： true-支持, false-不支持|
|--description|否|String| 字段描述|
|parameters|是|List| 数据集参数|
|--name|是|String| 参数名称|
|--dataType|是|Object| 数据类型 取值: TEXT, NUMBER, DATE, BOOLEAN|
|----desc|否|String||
|--isEnvironmentVariable|是|Boolean| 是否环境变量|
|--defaultValue|否|String| 参数值|
|--require|是|Boolean| 必填|
|--description|否|String| 参数描述|
|datasetRefreshTaskId|否|Long| 数据集刷新任务ID|
|datasetRefreshTaskName|否|String| 数据集刷新任务名称|
|openToAiAgent|否|Boolean| 是否开放给AI Agent|
|aiPromptDescription|否|String| AI提示词描述|
