# 获取数据集的列信息
 

**请求URL：** 
- `/report/analytics/dataset/expression/columns/{datasetId}`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|datasetId|否|String| |

### 请求参数Json格式
 
```
{
 "datasetId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--columns|否|List| 字段列表|
|----columnName|是|String| 字段名称|
|----alias|是|String| 别名|
|----dataType|是|Enum| 数据类型 取值: TEXT, NUMBER, DATE, BOOLEAN|
|----effectType|是|Enum| 作用类型 取值： DIMENSIONALITY-维度, MEASUREMENT-度量|
|----defaultAggregateType|是|Enum| 默认聚合类型 取值： SUM-求和, AVG-平均值, MAX-最大值, MIN-最小值, COUNT-计数, COUNT_DISTINCT-去重计数|
|----sortable|是|Boolean| 是否支持排序 取值： true-支持, false-不支持|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "columns" : [{
 "columnName" : "String",
 "alias" : "String",
 "dataType" : 0,
 "effectType" : 0,
 "defaultAggregateType" : 0,
 "sortable" : true
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
