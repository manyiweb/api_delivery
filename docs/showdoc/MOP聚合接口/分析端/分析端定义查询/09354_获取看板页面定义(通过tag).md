# 获取看板页面定义(通过tag)

**请求URL：** 
- `/report/analytics/dashboard/display/page/definition/tag/{tag}`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tag|否|String||

### 请求参数Json格式
 
```
{
 "tag" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|String| 模板ID|
|--pageType|否|Enum| 页面类型 APP WEB|
|--tag|否|String| 标签|
|--name|否|String| 模板名称|
|--pageCode|否|String| 页面编码|
|--componentDefinitions|否|List| 指标看板组件定义|
|----componentId|否|String| 看板组件ID|
|----name|否|String| 标题|
|----displayName|否|Boolean| 是否展现看板标题|
|----description|否|String| 看板描述|
|----displayDescription|否|Boolean| 是否展现看板描述|
|----type|否|Enum| 类型 DOUGHNUT, HISTOGRAM, INDICATOR, TABLE, TITLE , GOAL, TREND|
|----componentAlias|否|String| 组件别名|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "id" : "String",
 "pageType" : 0,
 "tag" : "String",
 "name" : "String",
 "pageCode" : "String",
 "componentDefinitions" : [{
 "componentId" : "String",
 "name" : "String",
 "displayName" : true,
 "description" : "String",
 "displayDescription" : true,
 "type" : 0,
 "componentAlias" : "String"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
