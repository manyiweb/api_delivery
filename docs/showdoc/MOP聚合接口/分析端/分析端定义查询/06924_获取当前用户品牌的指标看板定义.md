# 获取页面的定义信息

**请求URL：** 
- `/report/analytics/dashboard/display/page/definition/{pageId}`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|pageId|否|String||

### 请求参数Json格式
 
```
{
 "pageId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|String| 模板ID|
|--pageType|否|Enum| 页面类型 APP WEB|
|--name|否|String| 模板名称|
|--pageCode|否|String| 页面编码|
|--componentDefinitions|否|List| 指标看板组件定义|
|----componentId|否|String| 看板组件ID|
|----type|否|Enum| 类型 DOUGHNUT, HISTOGRAM, INDICATOR, TABLE, TITLE , GOAL, TREND|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "id" : "String",
 "pageType" : 0,
 "name" : "String",
 "pageCode" : "String",
 "componentDefinitions" : [{
 "componentId" : "String",
 "type" : 0
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```

### 注意不同的 type 类型输出的定义是动态的，以下是不同type形态下的 componentDefinition 对象字段

|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|----name|否|String| 看板名称|
|----aligningType|否|Enum| 对齐方式 LEFT("左对齐"), CENTER("居中对齐"), RIGHT("右对齐");|
|----displayDescription|否|Boolean| 是否展现看板描述|
|----description|否|String| 看板描述|
|----componentId|否|String| 看板组件ID|
|----type|否|Enum| 类型 DOUGHNUT, HISTOGRAM, INDICATOR, TABLE, TITLE|
|----componentAlias|否|String|组件别名|
