# 查询可用的商户组

**请求URL：** 
- `/hr/sysCompanySearch/listAvailableSchaincompany`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
无参数


### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--chainId|否|String| 商户组ID|
|--cName|否|String| 商户组名称|
|--status|否|Integer| 状态 1启用 0停用|
|--cCode|否|String| 编码|
|--companyQuantity|否|Long| 门店数量|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "chainId" : "String",
 "cName" : "String",
 "status" : 0,
 "cCode" : "String",
 "companyQuantity" : 0
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
