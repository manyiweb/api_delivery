# 门店列表
 

**请求URL：** 
- `/hr/sysCompanySearch/listCompany`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|keyword|否|String| 关键字|
|chainId|否|String| 门店分组ID|
|merchantsTypeCode|否|String| 门店类型编码|
|merchantsAreaPath|否|String| 门店区域路径|
|pageSize|否|Integer| 分页大小|
|pageIndex|否|Integer| 分页页码|

### 请求参数Json格式
 
```
{
 "keyword" : "String",
 "chainId" : "String",
 "merchantsTypeCode" : "String",
 "merchantsAreaPath" : "String",
 "pageSize" : 0,
 "pageIndex" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--content|否|List||
|----companyId|否|String||
|----companyCode|否|String||
|----companyName|否|String||
|--pageSize|否|Integer||
|--pageNo|否|Integer||
|--total|否|Long||
|--totalPage|否|Integer||
|--hasNextPage|否|Boolean||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "content" : [{
 "companyId" : "String",
 "companyCode" : "String",
 "companyName" : "String"
 }],
 "pageSize" : 0,
 "pageNo" : 0,
 "total" : 0,
 "totalPage" : 0,
 "hasNextPage" : true
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
