# 获取用户选择的门店筛选条件
 

**请求URL：** 
- `/report/analysis/company-selection-condition/obtain`

**请求方式：**
- Get
- FormData


### 请求参数<业务参数>
 
无参数


### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--userId|否|String| 用户ID|
|--groupId|否|String| 品牌ID|
|--MerchantsTypeConditions|否|List| 门店类型条件列表|
|----typeCode|是|String| 门店类型编码|
|----typeName|是|String| 门店类型名称|
|--companyChainConditions|否|List| 门店分组条件列表|
|----chainId|是|String| 门店分组ID|
|----chainName|是|String| 门店分组名称|
|--companyLabelConditions|否|List| 门店标签条件列表|
|----labelId|是|Long| 门店标签ID|
|----labelName|是|String| 门店标签名称|
|--merchantsAreaCondition|否|Object| 门店区域条件|
|----merchantsAreaName|是|String| 门店区域名称|
|----merchantsAreaPath|是|String| 门店区域路径|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "userId" : "String",
 "groupId" : "String",
 "MerchantsTypeConditions" : [{
 "typeCode" : "String",
 "typeName" : "String"
 }],
 "companyChainConditions" : [{
 "chainId" : "String",
 "chainName" : "String"
 }],
 "companyLabelConditions" : [{
 "labelId" : 0,
 "labelName" : "String"
 }],
 "merchantsAreaCondition" : {
 "merchantsAreaName" : "String",
 "merchantsAreaPath" : "String"
 }
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
