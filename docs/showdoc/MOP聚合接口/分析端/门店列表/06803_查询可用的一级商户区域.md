# 查询可用的一级商户区域

**请求URL：** 
- `/hr/sysCompanySearch/listAvailableFirstLevelMerchantArea`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
无参数


### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--id|否|Long||
|--code|否|String| 区域编码|
|--name|否|String| 区域名称|
|--status|否|Object| 是否启用 1 - 启用，0 - 不停用|
|--statusName|否|String| 状态中文名 启用，停用|
|--parentId|否|Long| 上级区域id|
|--orderNo|否|Integer| 排序号|
|--fName|否|String| 全区域名称|
|--fCode|否|String| 全区域编码|
|--fPath|否|String| 全区域id|
|--companyQuantity|否|Long| 区域下的门店数量|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "id" : 0,
 "code" : "String",
 "name" : "String",
 "status" : null,
 "statusName" : "String",
 "parentId" : 0,
 "orderNo" : 0,
 "fName" : "String",
 "fCode" : "String",
 "fPath" : "String",
 "companyQuantity" : 0
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
