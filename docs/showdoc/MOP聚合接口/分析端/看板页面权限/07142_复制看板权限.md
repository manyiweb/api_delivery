# 复制看板权限
 

**请求URL：** 
- `/report/dashboard/permission/copyPermission`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|dashboardPageId|是|String| 看板ID|
|roleId|是|String| 角色Id|
|copyToRoleIds|是|List| 应用的角色ID列表|

### 请求参数Json格式
 
```
{
 "dashboardPageId" : "String",
 "roleId" : "String",
 "copyToRoleIds" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
