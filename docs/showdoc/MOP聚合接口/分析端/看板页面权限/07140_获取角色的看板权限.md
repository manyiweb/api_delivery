# 获取角色的看板权限
 

**请求URL：** 
- `/report/dashboard/permission/getPermission`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|roleId|是|String| 角色Id|
|dashboardPageId|是|String| 看板ID|

### 请求参数Json格式
 
```
{
 "roleId" : "String",
 "dashboardPageId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--dashboardPageId|否|String| 看板页面id|
|--dashboardPageName|否|String| 看板页面名称|
|--permissionTags|否|List| 看板页面模块权限详情|
|----componentAlias|是|String| 组件别名|
|----hasPermission|否|Boolean| 是否有权限|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "dashboardPageId" : "String",
 "dashboardPageName" : "String",
 "permissionTags" : [{
 "componentAlias" : "String",
 "hasPermission" : true
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
