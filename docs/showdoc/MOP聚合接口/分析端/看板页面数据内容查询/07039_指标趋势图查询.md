# 指标趋势图查询
 

**请求URL：** 
- `/report/analytics/dashboard/indicatorTendencyBoard/query/tendencyChart`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|pageId|是|String| 页面ID|
|componentId|是|String| 组件ID|
|labelGroupName|是|String| 标签组名称|
|labelName|是|String| 标签名称|
|topicName|是|String| 主题名称|
|dateDimension|是|Enum| 日期维度类型 HOUR("按小时"), WEEK_DAY("按星期"), DAY("按日"), WEEK_OF_YEAR("按周");|
|paramsOfNow|是|Map| 当前时间参数|
|paramsOfPass|是|Map| 比较时间参数|

### 请求参数Json格式
 
```
{
 "pageId" : "String",
 "componentId" : "String",
 "labelGroupName" : "String",
 "labelName" : "String",
 "topicName" : "String",
 "dateDimension" : 0,
 "paramsOfNow" : null,
 "paramsOfPass" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--chartPointItems|否|List| 趋势图节点数据列表|
|----dimension|否|String| 维度|
|----currentData|否|Object| 当前数据|
|----chainData|否|Object| 环比数据|
|--displayFormat|否|Enum| 数字显示格式 INTEGER-整数 KEEP_ONE_DECIMALS-保留一位小数 KEEP_TWO_DECIMALS-保留两位小数 PERCENTAGE_KEY_ONE_DECIMALS-百分比保留一位小数 PERCENTAGE_KEY_TWO_DECIMALS-百分比保留两位小数|
|--datasetId|否|String| 数据集ID|
|--lastRefreshTime|否|DateTime| 数据集名称|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "chartPointItems" : [{
 "dimension" : "String",
 "currentData" : null,
 "chainData" : null
 }],
 "displayFormat" : 0,
 "datasetId" : "String",
 "lastRefreshTime" : "DateTime"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
