# 指标看板查询
 

**请求URL：** 
- `/report/analytics/dashboard/indicatorBoard/query`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|pageId|是|String| 页面ID|
|componentId|是|String| 组件ID|
|labelGroupName|是|String| 标签组名称|
|labelName|是|String| 标签名称|
|paramsOfNow|是|Map| 当前时间参数|
|paramsOfPass|是|Map| 比较时间参数|
|paramsOfLastYear|是|Map| 比较去年同期参数|

### 请求参数Json格式
 
```
{
 "pageId" : "String",
 "componentId" : "String",
 "labelGroupName" : "String",
 "labelName" : "String",
 "paramsOfNow" : null,
 "paramsOfPass" : null,
 "paramsOfLastYear" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--topicName|否|String| 主题名称|
|--displayYearOnYear|否|Boolean| 是否显示同环比|
|--valueOfNow|否|Double| 当前时间段数据|
|--valueOfPass|否|Double| 环比上一时间段数据|
|--valueOfLastYear|否|Double| 同比去年数据|
|--comparisonType|否|Enum| 比较类型 PERCENTAGE-百分比 DIFFERENCE-差值|
|--forwardPage|否|Object| 跳转页面|
|----forwardPageId|是|String| 跳转页面ID|
|----forwardPageName|是|String| 跳转页面名称|
|----tag|否|String| 关联标签|
|--displayFormat|否|Enum| 数字显示格式 INTEGER-整数 KEEP_ONE_DECIMALS-保留一位小数 KEEP_TWO_DECIMALS-保留两位小数 PERCENTAGE_KEY_ONE_DECIMALS-百分比保留一位小数 PERCENTAGE_KEY_TWO_DECIMALS-百分比保留两位小数|
|--datasetId|否|String| 数据集ID|
|--lastRefreshTime|否|DateTime| 数据集名称|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "topicName" : "String",
 "displayYearOnYear" : true,
 "valueOfNow" : 0,
 "valueOfPass" : 0,
 "valueOfLastYear" : 0,
 "comparisonType" : 0,
 "forwardPage" : {
 "forwardPageId" : "String",
 "forwardPageName" : "String",
 "tag" : "String"
 },
 "displayFormat" : 0,
 "datasetId" : "String",
 "lastRefreshTime" : "DateTime"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
