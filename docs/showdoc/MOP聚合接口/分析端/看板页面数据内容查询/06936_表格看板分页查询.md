# 表格看板分页查询
 

**请求URL：** 
- `/report/analytics/dashboard/table/queryPage`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|pageIndex|是|Integer| 分页参数|
|pageSize|是|Integer| 分页参数|
|pageId|是|String| 页面id|
|componentId|是|String| 组件id|
|labelGroupName|是|String| 标签组名称|
|labelName|是|String| 标签名称|
|params|是|Map| 参数|
|sortColumnName|否|String| 排序字段|
|asc|否|Boolean| 是否升序|

### 请求参数Json格式
 
```
{
 "pageIndex" : 0,
 "pageSize" : 0,
 "pageId" : "String",
 "componentId" : "String",
 "labelGroupName" : "String",
 "labelName" : "String",
 "params" : null,
 "sortColumnName" : "String",
 "asc" : true
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--columnDefinitions|否|List| 列定义|
|----columnName|是|String| 字段名称|
|----display|否|Boolean| 是否显示|
|----alias|是|String| 字段展示别名|
|----sortable|是|Boolean| 是否可排序|
|----aligningType|是|Enum| 对齐方式 LEFT("左对齐"), CENTER("居中对齐"), RIGHT("右对齐");|
|----displayFormat|是|Enum| 展示格式 INTEGER("整数"), KEEP_ONE_DECIMALS("保留一位小数"), KEEP_TWO_DECIMALS("保留两位小数"), PERCENTAGE_KEY_ONE_DECIMALS("百分比保留一位小数"), PERCENTAGE_KEY_TWO_DECIMALS("百分比保留两位小数");|
|--dataRows|否|List| 数据行|
|--pageSize|否|Integer| 分页大小|
|--pageIndex|否|Integer| 当前页码|
|--totalElements|否|Long| 总记录数|
|--totalPages|否|Long| 总页数|
|--forwardPage|否|Object| 跳转页面|
|----forwardPageId|是|String| 跳转页面ID|
|----forwardPageName|是|String| 跳转页面名称|
|----tag|否|String| 关联标签|
|--forwardParameters|否|List| 跳转参数|
|----columnName|是|String| 取参字段|
|----forwardParamName|是|String| 跳转参数名称|
|--datasetId|否|String| 数据集ID|
|--lastRefreshTime|否|DateTime| 数据集名称|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
