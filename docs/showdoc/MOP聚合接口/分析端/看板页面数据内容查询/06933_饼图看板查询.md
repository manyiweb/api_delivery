# 饼图看板查询
 

**请求URL：** 
- `/report/analytics/dashboard/doughnutBoard/query`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|pageId|是|String| 页面ID|
|componentId|是|String| 组件ID|
|labelName|是|String| 标签名称|
|params|是|Map| 参数|

### 请求参数Json格式
 
```
{
 "pageId" : "String",
 "componentId" : "String",
 "labelName" : "String",
 "params" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--firstChart|否|Object| 第一个环形图|
|----doughnutChartValues|否|List| 所有维度数据|
|------dimensionalityName|否|String| 维度名称|
|------mainStatisticValue|否|String| 主要统计数据|
|------additionalStatisticValue|否|String| 附加统计数据|
|----additionalAggregateResultUnit|否|String| 附加聚合结果单位|
|----datasetId|否|String| 数据集ID|
|----lastRefreshTime|否|DateTime| 数据集名称|
|--secondChart|否|Object| 第二个环形图|
|----doughnutChartValues|否|List| 所有维度数据|
|------dimensionalityName|否|String| 维度名称|
|------mainStatisticValue|否|String| 主要统计数据|
|------additionalStatisticValue|否|String| 附加统计数据|
|----additionalAggregateResultUnit|否|String| 附加聚合结果单位|
|----datasetId|否|String| 数据集ID|
|----lastRefreshTime|否|DateTime| 数据集名称|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
