# 目标图组件查询
 

**请求URL：** 
- `/report/analytics/dashboard/goalChartComponent/query`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|pageId|是|String| 页面ID|
|componentId|是|String| 组件ID|
|params|是|Map| 参数|

### 请求参数Json格式
 
```
{
 "pageId" : "String",
 "componentId" : "String",
 "params" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--result|否|Object| 查询结果|
|--metricColumn|否|String| 度量字段|
|--displayFormat|是|Enum| 数字显示格式 INTEGER-整数 KEEP_ONE_DECIMALS-保留一位小数 KEEP_TWO_DECIMALS-保留两位小数 PERCENTAGE_KEY_ONE_DECIMALS-百分比保留一位小数 PERCENTAGE_KEY_TWO_DECIMALS-百分比保留两位小数|
|--datasetId|否|String| 数据集ID|
|--lastRefreshTime|否|DateTime| 数据集名称|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "result" : null,
 "metricColumn" : "String",
 "displayFormat" : 0,
 "datasetId" : "String",
 "lastRefreshTime" : "DateTime"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
