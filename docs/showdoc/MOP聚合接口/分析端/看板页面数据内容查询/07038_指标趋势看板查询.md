# 指标趋势看板查询
 

**请求URL：** 
- `/report/analytics/dashboard/indicatorTendencyBoard/query/indicatorItem`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|pageId|是|String| 页面ID|
|componentId|是|String| 组件ID|
|labelGroupName|是|String| 标签组名称|
|labelName|是|String| 标签名称|
|params|是|Map| 参数|

### 请求参数Json格式
 
```
{
 "pageId" : "String",
 "componentId" : "String",
 "labelGroupName" : "String",
 "labelName" : "String",
 "params" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--topicName|否|String| 主题名称|
|--indicatorValue|否|Object| 指标数据|
|--associatedTag|否|String| 关联标签|
|--displayFormat|否|Enum| 数字显示格式 INTEGER-整数 KEEP_ONE_DECIMALS-保留一位小数 KEEP_TWO_DECIMALS-保留两位小数 PERCENTAGE_KEY_ONE_DECIMALS-百分比保留一位小数 PERCENTAGE_KEY_TWO_DECIMALS-百分比保留两位小数|
|--displayTimeTendency|否|Boolean| 是否展示时间趋势|
|--datasetId|否|String| 数据集ID|
|--lastRefreshTime|否|DateTime| 数据集名称|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "topicName" : "String",
 "indicatorValue" : null,
 "associatedTag" : "String",
 "displayFormat" : 0,
 "displayTimeTendency" : true,
 "datasetId" : "String",
 "lastRefreshTime" : "DateTime"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
