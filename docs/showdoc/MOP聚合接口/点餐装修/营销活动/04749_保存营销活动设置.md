# 保存营销活动设置

**请求URL：** 
- `/config/meal/marketingActivities/save `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|list|否|List| 列表封装（跳转链接 + 链接类型）|
|--recordId|否|Long||
|--linkValue|否|String| 跳转链接/房间号|
|--linkType|否|String| 链接类型|
|--sourceId|否|String| 微页面id|
|deleteIds|否|List||

###请求参数Json格式
 
```
{
 "list" : [{
 "recordId" : 0,
 "linkValue" : "String",
 "linkType" : "String",
 "sourceId" : "String"
 }],
 "deleteIds" : null
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--recordId|否|Long||
|--linkValue|否|String| 跳转链接/房间号|
|--linkType|否|String| 链接类型|
|--linkTypeCname|否|String| 链接类型（中文）|
|--sourceId|否|String| 微页面id|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : [{
 "recordId" : 0,
 "linkValue" : "String",
 "linkType" : "String",
 "linkTypeCname" : "String",
 "sourceId" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
