# 

**请求URL：** 
- `/config/view/list`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|String|datatableId|

### 请求参数Json格式
 
```
{
 "id" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|id|否|String|视图id|
|userId|否|String|用户id|
|title|否|String|视图名称|


### 返回参数Json格式
 
```
{
 "data" : [{
 "id" : "String",
 "userId" : "String",
 "title" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
