# 获取试图列表的字段

**请求URL：** 
- `/config/produce/view/listField`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|moduleType|是|String| produce_plan 生产计划|

### 请求参数Json格式
 
```
{
 "moduleType" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--columnFieldName|否|String||
|--hasPermission|否|Boolean||
|--innerColumn|否|Boolean||
|--alias|否|String||
|--sequenceNumber|否|Integer||
|--displayable|否|Boolean||
|--filterPropertiesName|否|String||
|--columnWidth|否|String||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "columnFieldName" : "String",
 "hasPermission" : true,
 "innerColumn" : true,
 "alias" : "String",
 "sequenceNumber" : 0,
 "displayable" : true,
 "filterPropertiesName" : "String",
 "columnWidth" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
