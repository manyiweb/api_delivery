# 视图详情

**请求URL：** 
- `/config/view/detail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|String|视图id|

### 请求参数Json格式
 
```
{
 "id" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|id|否|String|视图id|
|userId|否|String|用户id|
|groupId|否|String|品牌id|
|datatableId|否|String|datatableId|
|isSystemView|否|Boolean|是否系统视图|
|title|否|String|视图名称|
|conditions|否|List|视图条件列表|
|--selectCode|否|String|条件编码|
|--selectName|否|String|条件名称|
|--selectType|否|String|条件类型，参考datatable条件字段的类型|
|--type|否|String|条件的类型，从config/view/condition/types接口获取，无需参数|
|--keyword|否|String|查询关键字|
|--selects|否|List|查询包含的条件列表|
|--startTime|否|Date|查询的开始时间|
|--endTime|否|Date|查询的结束时间|
|fields|否|List|展示字段|
|--fieldName|否|String|字段名称|
|--fieldCode|否|String|字段编码|
|--alias|否|String|别名|
|--width|否|String|宽度|
|--statusSelections|否|List||
|----statusName|否|String||
|summaryFields|否|List|展示字段|
|--fieldName|否|String|字段名称|
|--fieldCode|否|String|字段编码|
|--alias|否|String|别名|
|--width|否|String|宽度|
