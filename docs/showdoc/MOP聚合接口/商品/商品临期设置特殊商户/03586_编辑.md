# 编辑

**请求URL：** 
- `/warehouse/logiNearExpireItemComp/edit `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|logiNearExpireItemId|否|Long| 商品临期设置id|
|addCompanyIds|否|List| 商户|
|--id|否|String| id|
|--expireDay|否|Integer| 临期天数|
|delIds|否|List| 删除|

###请求参数Json格式
 
```
{
 "logiNearExpireItemId" : 0,
 "addCompanyIds" : [{
 "id" : "String",
 "expireDay" : 0
 }],
 "delIds" : null
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Long| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : 0,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
