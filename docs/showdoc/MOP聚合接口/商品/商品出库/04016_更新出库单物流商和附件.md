# 更新出库单物流商和附件
 

**请求URL：** 
- `/product/whsOut/updateLogistics `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|whsOutId|否|Long| 出库通知单id|
|logisticsProviders|否|String| 物流商|
|logisticsNumber|否|String| 物流单号|
|addAttachmentIds|否|List| 添加发货附件ids|
|deleteAttachmentIds|否|List| 删除发货附件ids|

###请求参数Json格式
 
```
{
 "whsOutId" : 0,
 "logisticsProviders" : "String",
 "logisticsNumber" : "String",
 "addAttachmentIds" : null,
 "deleteAttachmentIds" : null
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
