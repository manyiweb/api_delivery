# 商品规格应用商户数据导入
 

**请求URL：** 
- `/file/mitemSpecComp/import/{type} `

**请求方式：**
- POST
- FormData


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|file|是|文件流| 导入模板|
|type|是|String| 零售上下架 - retailStatus ;订货上下架 - orderStatus;商城上下架 - mallStatus|

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--totalCount|否|Integer| 总条数|
|--errorCount|否|Integer| 失败条数|
|--successCount|否|Integer| 成功条数|
|--downloadURL|否|String| 下载地址条数|
|msg|否|String| 消息|
|code|否|String| 业务代码|


###返回参数Json格式
 
```
{
 "data" : {
 "totalCount" : 0,
 "errorCount" : 0,
 "successCount" : 0,
 "downloadURL" : "String"
 },
 "msg" : "String",
 "code" : "String"
}
```
