# 获取商品规格应用商户数据
 

**请求URL：** 
- `/product/mitemSpecComp/get `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|mcId|否|String| 商品应用商户id|
|platformType|否|String| 平台类型 retail-零售, mall-商城, orderGoods-订货, order-点餐|

###请求参数Json格式
 
```
{
 "mcId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--itemCode|否|String| 商品编码|
|--itemName|否|String| 商品名称|
|--lines|否|List| 明细|
|----id|否|Long||
|----retailStatus|否|Object| 零售上下架状态 1 - 上架, 0 - 下架|
|----orderStatus|否|Object| 订货上下架状态 1 - 上架, 0 - 下架|
|----mallStatus|否|Object| 商城上下架状态 1 - 上架, 0 - 下架|
|----itemName|否|String| 商品名称|
|----specName|否|String| 商品规格名称|
|----specId|否|String| 商品规格id|
|----retailStatusHand|否|int| 零售是否手工下架 1-是，0-否|
|----mallStatusHand|否|int| 商城是否手工下架 1-是，0-否|
|----orderStatusHand|否|int| 订货是否手工下架 1-是，0-否|
|----orderShelvesHand|否|int| 点餐是否手工下架 1-是，0-否|
|--isEnableMultiple|否|Integer| 是否启用按规格上下架 1 - 启用,0 - 不启用|
|--mitemComp|否|object| 门店商品应用数据|
|----mcId|否|long| 门店商品应用id|
|----itemId|否|string| 商品id|
|----companyId|否|int| 门店id|
|----isShelves|否|int| 是否上架 1是 0否|
|----orderStatus|否|int| 订货状态,1 - 是,0 - 否|
|----mallStatus|否|int| 商城状态,1 - 是,0 - 否|
|----orderShelves|否|int| 点餐上下架,1 - 是,0 - 否|
|----isEnableMultiple|否|int| 是否启用按规格上下架,1启用 0不启用|
|----shelvesHand|否|int| 零售-是否手工下架 1 - 是,0 - 否|
|----mallStatusHand|否|int| 商城-是否手工下架 1 - 是,0 - 否|
|----orderStatusHand|否|int| 订货-是否手工下架 1 - 是,0 - 否|
|----orderShelvesHand|否|int| 点餐-是否手工下架 1 - 是,0 - 否|
|--mitemCompUpperLowerShelfTimeList|否|list| 门店商品有效期数据|
|----id|否|long| 主键|
|----mcId|否|long| 门店商品应用id|
|----platformType|否|String| 平台类型 retail-零售, mall-商城, orderGoods-订货, order-点餐|
|----onShelfValidityPeriodBegin|否|date| 上架有效期开始时间|
|----onShelfValidityPeriodEnd|否|date| 上架有效期结束时间|
|----onShelfTime|否|String| 上架有效期时间段|
|----validityPeriodStatus|否|int| 有效期启用状态,1启用 0不启用|
|----timeSlotStatus|否|int| 时间段启用状态,1启用 0不启用|
|msg|否|String| 消息|
|code|否|String| 业务代码|

###返回参数Json格式
 
```
{
 "data" : {
 "itemCode" : "String",
 "itemName" : "String",
 "lines" : [{
 "id" : 0,
 "retailStatus" : null,
 "orderStatus" : null,
 "mallStatus" : null,
 "itemName" : "String",
 "specName" : "String",
 "specId" : "String"
 }],
 "isEnableMultiple" : 0
 },
 "msg" : "String",
 "code" : "String"
}
```
