# 维护商品规格应用商户数据App端

**请求URL：** 
- `/product/mitemSpecComp/app/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|lines|否|List| 明细|
|--specId|否|String| 商品规格id 注意：点单商城传主商品id|
|--mallStatus|否|Object| 商城上下架状态 1 - 上架, 0 - 下架 :只有商城上下架时才传|
|mcId|是|String| 商品应用id|
|isEnableMultiple|否|Integer| 是否启用按规格上下架 1 - 启用,0 - 不启用|
|platformType|是|String| 平台编码 mall:商城 ，order:点单 |
|statusHand|否|Integer| 是否手工下架 1-是，0-否 |
|mealShelvesRange|否|Integer|点单上下架范围，null or 0：全部，1：自取，2：外卖 |
|orderShelves|否|Integer|点单上下架 0下架,1上架|

### 请求参数Json格式
 
```
{
 "lines": [
 {
 "specId": "13455ad85ae242b897ee7bfc9c05c1fa",
 "statusHand": 0
 }
 ],
 "mcId": "105782842757",
 "isEnableMultiple": 0,
 "platformType": "order",
 "statusHand": 0,
 "mealShelvesRange": 1,
 "orderShelves": 1,
 "tokenId": "a346741957ba4d5595abaedd15f2a084"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
