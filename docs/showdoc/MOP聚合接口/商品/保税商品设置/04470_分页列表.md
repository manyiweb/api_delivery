# 分页列表

**请求URL：** 
- `/config/mitemTaxRate/page `

**请求方式：**
- POST
- RequestBody

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--pageIndex|否|Integer| 页码|
|--pageSize|否|Integer| 显示记录数|
|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|--first|否|Boolean| 首页|
|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|
|----id|否|Long||
|----itemId|否|String| 商品id,mitem表id|
|----itemCode|否|String| 商品编码|
|----itemName|否|String| 商品名称|
|----vatTaxRate|否|Double| 增值税率|
|----tariffTaxRate|否|Double| 关税税率|
|----consumeTaxRate|否|Double| 消费税率|
|----compositeTaxRate|否|Double| 综合税率|
|----HSCode|否|String| HS编码|
|----customsRecordNo|否|String| 海关备案号|
|----specModel|否|String| 规格型号|
|----customsUOMCode|否|String| 海关计量单位编码|
|----nationalInspectionUOMCode|否|String| 国检计量单位编码|
|----legalFirstUOMCode|否|String| 法定第一计量单位编码|
|----legalFirstQuantity|否|Double| 法定第一数量|
|----legalSecondUOMCode|否|String| 法定第二计量单位编码|
|----legalSecondQuantity|否|Double| 法定第二数量|
|----purposeCode|否|String| 用途编号|
|----originCode|否|String| 产地编码|
|----premium|否|String| 保费|
|----packageTypeCodeOff|否|String| 包装种类代码(关)|
|----packageTypeCodeCheck|否|String| 包装种类代码(检)|
|----grossWeight|否|String| 毛重|
|----netWeight|否|String| 净重|
|----isTypeTaxRate|否|Boolean| 是否使用分类税率，0否1是|
|----typeName|否|String| 商品类型 保税、直邮、完税|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
