# 保存设置

**请求URL：** 
- `/config/mitemTaxRate/save `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|items|否|List||
|--id|否|Long||
|--itemId|否|String| 商品id,mitem表id|
|--isTypeTaxRate|否|Boolean| 是否使用分类税率|
|--HSCode|否|String| HS编码|
|--customsRecordNo|否|String| 海关备案号|
|--specModel|否|String| 规格型号|
|--customsUOMCode|否|String| 海关计量单位编码|
|--nationalInspectionUOMCode|否|String| 国检计量单位编码|
|--legalFirstUOMCode|否|String| 法定第一计量单位编码|
|--legalFirstQuantity|否|Double| 法定第一数量|
|--legalSecondUOMCode|否|String| 法定第二计量单位编码|
|--legalSecondQuantity|否|Double| 法定第二数量|
|--purposeCode|否|String| 用途编号|
|--originCode|否|String| 产地编码|
|--premium|否|String| 保费|
|--packageTypeCodeOff|否|String| 包装种类代码(关)|
|--packageTypeCodeCheck|否|String| 包装种类代码(检)|
|--grossWeight|否|String| 毛重|
|--netWeight|否|String| 净重|
|--typeName|否|String| 商品类型 保税、直邮、完税|

###请求参数Json格式
 
```
{
 "items" : [{
 "id" : 0,
 "itemId" : "String",
 "isTypeTaxRate" : true,
 "HSCode" : "String",
 "customsRecordNo" : "String",
 "specModel" : "String",
 "customsUOMCode" : "String",
 "nationalInspectionUOMCode" : "String",
 "legalFirstUOMCode" : "String",
 "legalFirstQuantity" : 0,
 "legalSecondUOMCode" : "String",
 "legalSecondQuantity" : 0,
 "purposeCode" : "String",
 "originCode" : "String",
 "premium" : "String",
 "packageTypeCodeOff" : "String",
 "packageTypeCodeCheck" : "String",
 "grossWeight" : "String",
 "netWeight" : "String",
 "typeName" : "String"
 }]
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
