# 接收前端导入参数并返回校验结果。

**请求URL：** 
- `/product/item/import/check`

**请求方式：** 
- `POST`
- `FormData`


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|scene|否|String| 导入校验场景编码。|

### 请求参数Json格式
 
```
{
 "scene":"String"
}
```

### 响应参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--scene|否|String| 导入校验场景编码。|
|--totalCount|否|Integer| 校验总行数。|
|--successCount|否|Integer| 校验成功行数。|
|--errorCount|否|Integer| 校验失败行数。|
|--downloadUrl|否|String| 失败数据下载地址。|
|--records|否|List| 明细结果集合。|
|----lineNum|否|Integer| 原始 Excel 行号。|
|----itemCode|否|String| 商品编码。|
|----skuBarcode|否|String| SKU 码。|
|----itemName|否|String| 商品名称。|
|----quantity|否|Double| 导入数量。|
|----success|否|Boolean| 是否校验通过。|
|----message|否|String| 校验反馈信息。|
|----unit|否|String| 商品单位。|
|----price|否|Double| 商品价格。|
|----itemId|否|String| 商品 ID。|
|----specId|否|String| 规格 ID。|
|----bomId|否|String| BOM ID。|
|----seriesCode|否|String| 系列编码。|
|----seriesName|否|String| 系列名称。|
|----itemTypeCode|否|String| 商品大类编码。|
|----itemTypeName|否|String| 商品大类名称。|
|----mTypeCode|否|String| 物料类型编码。|
|----mTypeName|否|String| 物料类型名称。|
|----remark|否|String| 导入备注。|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
