# 商品分组添加详情
 

**请求URL：** 
- `/product/item/group/itemListAdd`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|
|itemGroupName|否|String| 分组名称|
|status|否|Integer| 状态|
|itemGroupType|否|Integer| 商品类型|
|itemGroupDetailDtoList|否|List| 分组详情|
|--itemId|否|String| 商品id|
|--categoryType|否|Integer| 类型 0：类别 1：品牌 2：系列|
|--categoryId|否|String| 类型id|
|--categoryCode|否|String| 类型编码|
|--categoryName|否|String| 类型名称|
|--lineId|否|Integer| 分组id|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "itemGroupName" : "String",
 "status" : 0,
 "itemGroupType" : 0,
 "itemGroupDetailDtoList" : [{
 "itemId" : "String",
 "categoryType" : 0,
 "categoryId" : "String",
 "categoryCode" : "String",
 "categoryName" : "String",
 "lineId" : 0
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
