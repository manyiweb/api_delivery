# 保存设置

**请求URL：** 
- `/config/mitemTypeTaxRate/save `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|itemTypeId|否|String| 商品分类id,mitemtype表id|
|vatTaxRate|否|Double| 增值税率|
|tariffTaxRate|否|Double| 关税税率|
|consumeTaxRate|否|Double| 消费税率|
|compositeTaxRate|否|Double| 综合税率|

###请求参数Json格式
 
```
{
 "itemTypeId" : "String",
 "vatTaxRate" : 0,
 "tariffTaxRate" : 0,
 "consumeTaxRate" : 0,
 "compositeTaxRate" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Long| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : 0,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
