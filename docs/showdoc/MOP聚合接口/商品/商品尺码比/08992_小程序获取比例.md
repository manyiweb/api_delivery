# 小程序获取比例
 

**请求URL：** 
- `/product/item/size/ratio/getByMall`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|itemId|否|String||

### 请求参数Json格式
 
```
{
 "itemId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long|主键 |
|--itemId|否|String|商品id |
|--itemCode|否|String|商品编码 |
|--itemName|否|String|商品名称 |
|--itemType|否|String|商品分类 |
|--unit|否|String|单位 |
|--ratioReqs|否|List||
|----id|否|Long|主键 |
|----specId|否|String|规格二id |
|----skuCode|否|String|规格编码 |
|----specName|否|String|规格编码 |
|----specRatio|否|Double|比例 |
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "itemId" : "String",
 "itemCode" : "String",
 "itemName" : "String",
 "itemType" : "String",
 "unit" : "String",
 "ratioReqs" : [{
 "id" : 0,
 "specId" : "String",
 "skuCode" : "String",
 "specName" : "String",
 "specRatio" : 0
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
