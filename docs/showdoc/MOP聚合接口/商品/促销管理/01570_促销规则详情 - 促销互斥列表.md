# 促销规则详情 - 促销互斥列表

**请求URL：** 
- `/product/proRule/getRuleDetail/mutexs `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|planId|否|String| 促销规则标识|
|pageIndex|否|Integer| 分页页码|
|pageSize|否|Integer| 分页大小|
|sword|否|String| 搜索关键字|

###请求参数Json格式
 
```
{
 "planId" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "sword" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--pageIndex|否|Integer| 页码|
|--pageSize|否|Integer| 显示记录数|
|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|--first|否|Boolean| 首页|
|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|
|----id|否|Long| id|
|----planId|否|String| 促销标识，与rb_marketplan fid关联|
|----mutexPlanId|否|String| 促销互斥标识|
|----mutexPlanCode|否|String| 促销互斥编码|
|----mutexPlanName|否|String| 促销互斥名称|
|----mutexPlanType|否|String| 促销互斥类型|
|----mutexPlanTypeName|否|String| 促销互斥类型描述|
|----createId|否|String| 创建人|
|----createName|否|String| 创建人名称|
|----createDate|否|DateTime| 创建时间|
|----dbKey|否|Integer| 分库标识|
|----groupId|否|String| 品牌商id|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
