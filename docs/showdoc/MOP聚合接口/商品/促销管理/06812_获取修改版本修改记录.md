# 获取修改版本修改记录
 

**请求URL：** 
- `/product/marketVersion/page `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|planId|是|String|业务id |
|businessType|是|Integer|业务类型（1促销规则，2促狭方案3返利规则4返利方案） |


###请求参数Json格式
 
```
{
 "planId" : "String",
 "businessType" : 0,
 "pageIndex" : 0,
 "pageSize" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--pageIndex|否|Integer||
|--pageSize|否|Integer||
|--pageCount|否|Integer||
|--totalCount|否|Long||
|--first|否|Boolean||
|--last|否|Boolean||
|--content|否|List||
|----id|否|Long|id |
|----beforeVersion|否|String|修改前版本 |
|----cruuentVersion|否|String|修改后版本 |
|----planId|否|String|规则id |
|----businessType|否|Integer|业务类型 |
|----versionNum|否|Integer| 版本号|
|----createId|否|String||
|----createName|否|String|修改人名称|
|----createDate|否|DateTime|修改时间|
|----modifyId|否|String||
|----modifyName|否|String||
|----modifyDate|否|DateTime||
|----dbKey|否|Integer||
|----groupId|否|String||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


###返回参数Json格式

 }]
