# 促销规则详情 - 排除类别列表

**请求URL：** 
- `/product/proRule/getRuleDetail/exclGroups `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|planId|否|String| 促销规则标识|
|tokenId|否|String| 用户标识|
|pageIndex|否|Integer| 分页页码|
|pageSize|否|Integer| 分页大小|
|sword|否|String| 搜索关键字|

###请求参数Json格式
 
```
{
 "planId" : "String",
 "tokenId" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "sword" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--pageIndex|否|Integer| 页码|
|--pageSize|否|Integer| 显示记录数|
|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|--first|否|Boolean| 首页|
|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|
|----id|否|Long| id|
|----type|否|Integer| 类型 0分类 1品牌 2系列 3商品档案属性 4商品规格属性|
|----itemId|否|String| 分类/品牌/系列 ID|
|----itemCode|否|String| 分类/品牌/系列 编码|
|----itemName|否|String| 分类/品牌/系列 名称|
|----groupId|否|String| 商户标识|
|----planId|否|String| 促销规则标识|
|----values|否|List| 内容集合|
|----code|否|String||
|----name|否|String||
|----content|否|String| 内容|
|----valueType|否|Integer| 类型|
|----businessId|否|String| 业务id|
|----contentId|否|String| 自定义内容id|
|----ruleValues|否|List| 扩展属性|
|------ruleId|否|String||
|------ruleValue|否|String||
|------ruleValueName|否|String||
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|
