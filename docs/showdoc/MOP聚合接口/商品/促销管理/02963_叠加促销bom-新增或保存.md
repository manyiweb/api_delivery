# 叠加促销bom-新增或保存

**请求URL：** 
- `/product/proRule/planBom/action/save `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|String||
|platform|否|Integer| 应用场景必须为1(订货) 或 2(零售)|
|isActive|否|Integer| 是否活跃必须介于0到1|
|type|否|Integer| 类型必须为1(商品促销) 或 2(订单促销)|
|description|否|String| "促销说明必须长度必须小于1024"|
|name|否|String| 促销名称长度必须小于128|
|planRuleType|否|String|buyGive("满赠"), buyDown("满减"), buyDiscount("满折"), buyAddPrice("加价购"),|
|delPlanIds|否|List| 删除促销id|
|addPlanIds|否|List| 新增促销id|
|dbkey|否|Integer||

###请求参数Json格式
 
```
{
 "id" : "String",
 "platform" : 0,
 "isActive" : 0,
 "type" : 0,
 "description" : "String",
 "name" : "String",
 "delPlanIds" : null,
 "addPlanIds" : null,
 "dbkey" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
