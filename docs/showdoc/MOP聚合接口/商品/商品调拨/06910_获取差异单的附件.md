# 获取差异单的附件

**请求URL：** 
- `/product/diffOrder/attchment/info`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|diffOrderId|是|Long| 差异单ID|


### 请求参数Json格式
 
```
{
 "diffOrderId" : 0
}
```

|--fileUrl|否|String||
|--fileFullUrl|否|String||
