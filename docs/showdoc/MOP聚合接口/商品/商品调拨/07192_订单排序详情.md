# 订单排序详情

**请求URL：** 
- `/product/allot/order/sort/info`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|sortType|是|String| 排序类型 调拨单列表:productAllotList 调拨详情 productAllotDetail 调拨发货:productAllotDelivery|

### 请求参数Json格式
 
```
{
 "sortType" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--sortType|否|String| 排序类型 调拨单列表:productAllotList 调拨详情 productAllotDetail 调拨发货:productAllotDelivery|
|--itemNameSort|否|Integer| 商品名称|
|--itemCodeSort|否|Integer| 商品编码|
|--skuSort|否|Integer| sku|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "sortType" : "String",
 "itemNameSort" : 0,
 "itemCodeSort" : 0,
 "skuSort" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
