# 查询调拨单可发货单据

**请求URL：** 
- `/product/allot/batch/query`

**请求方式：**
- POST
- RequestBody

|whsIds|否|List||
|deliveryDateRange|否|Object||
|--start|否|DateTime||
|--end|否|DateTime||
|orderDateRange|否|Object||
|--start|否|DateTime||
|--end|否|DateTime||
|id|否|String||
|pageSize|否|Integer||
|pageNo|否|Integer||
|sortField|否|String||
|sortDirection|否|String||
|viewId|否|String||
