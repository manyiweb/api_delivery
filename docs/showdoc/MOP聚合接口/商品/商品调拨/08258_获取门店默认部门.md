# 获取门店默认部门

**请求URL：** 
- `/config/company/getCompDefaultDepartment `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 门店id|

###请求参数Json格式
 
```
{
 "companyId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long| 主键|
|--companyId|否|String| 商户id|
|--code|否|String| 部门编码|
|--name|否|String| 部门名称|
|--status|否|Object| 是否启用 1 - 启用，0 - 不停用|
|--statusName|否|String| 状态中文名 启用，停用|
|--parentId|否|Long| 上级部门id|
|--createId|否|String| 创建人id|
|--createName|否|String| 创建人|
|--createDate|否|DateTime| 创建时间|
|--modifyId|否|String| 修改人id|
|--modifyName|否|String| 修改人|
|--modifyDate|否|DateTime| 修改时间|
|--lineNum|否|Integer| 排序号|
|--fName|否|String| 全部门名称|
|--fCode|否|String| 全部门编码|
|--fPath|否|String| 全部门id|
|--isDefault|否|Boolean| 是否默认部门|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


###返回参数Json格式
 
```
{

 "id" : 0,

 "code" : "String",
 "name" : "String",
 "status" : null,

 "createId" : "String",
 "createName" : "String",
 "createDate" : "DateTime",
 "modifyId" : "String",
 "modifyName" : "String",
 "modifyDate" : "DateTime",
 "lineNum" : 0,
 "fName" : "String",
 "fCode" : "String",
 "fPath" : "String",
 "isDefault" : true
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
