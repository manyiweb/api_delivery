# 商品调拨-发货完成

**请求URL：** 
- `/product/allot/order/whsOut/finish `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|是|String| 单据id|

###请求参数Json格式
 
```
{
 "orderId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|ErrorCode|否|Object| ErrorCode|
|ResultString|否|String| 消息|
|ResultInt|否|String| ResultInt|

###返回参数Json格式
 
```
{
 "ErrorCode": "",
 "ResultString": "操作成功",
 "ResultInt": 0
}

```
