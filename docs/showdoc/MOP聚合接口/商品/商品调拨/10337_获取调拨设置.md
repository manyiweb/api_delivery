# 获取调拨设置

**请求URL：** 
- `/product/allot/config/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
无参数


### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--permitAllotRegular|否|Boolean| 允许调拨固定bom 0不允许 1允许，默认允许|
|--companyId|否|String| 门店id或品牌id|
|--pressAllotGroup|否|Boolean| 按调拨组调拨|
|--openAllotCloseReason|否|Boolean| 启用关闭原因 默认不开启|
|--autoConfirmReceive|否|Boolean| 自动确认收货|
|--notOutDifference|否|Boolean| 代发数量=0时|
|--notOutDifferenceAutoType|否|Integer| 代发数量=0时,自动确认收货-类型 0:按天数 1:按时间|
|--autoConfirmReceiveDays|否|Integer| 代发数量=0时,自动确认收货-天数|
|--autoConfirmReceiveTime|否|String| 代发数量=0时,自动确认收货-时间|
|--haveOutDifference|否|Boolean| 代发数量>0时|
|--haveOutDifferenceAutoType|否|Integer| 代发数量>0时,自动确认收货-类型 0:按天数 1:按时间|
|--diffAutoConfirmReceiveDays|否|Integer| 代发数量>0时,自动确认收货-天数|
|--diffAutoConfirmReceiveTime|否|String| 代发数量>0时,自动确认收货-时间|
|--shipRecvProcess|否|Integer| 调拨发货、收货流程 1先发货、后收货 2仅收货|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||

}
