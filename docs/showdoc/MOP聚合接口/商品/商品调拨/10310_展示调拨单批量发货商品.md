# 展示调拨单批量发货商品

**请求URL：** 
- `/product/allot/batch/query/item`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderIds|是|List| 调拨单id|

### 请求参数Json格式
 
```
{
 "orderIds" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--itemId|否|String| 商品id|
|--itemCode|否|String| 商品编码|
|--itemName|否|String| 商品名称|
|--specId|否|String| 规格id|
|--sku|否|String| sku|
|--inv|否|Double| 系统库存|
|--quantity|否|Double| 调拨数量 基本单位|
|--itemQuantity|否|Double| 调拨数量|
|--deliveredNum|否|Double| 已发货数量|
|--itemUnit|否|String| 调拨单位|
|--unit|否|String| 调拨基本单位|
|--unitRate|否|Double| 调拨单位系数|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "itemId" : "String",
 "itemCode" : "String",
 "itemName" : "String",
 "specId" : "String",
 "sku" : "String",
 "inv" : 0,
 "quantity" : 0,
 "itemQuantity" : 0,
 "deliveredNum" : 0,
 "itemUnit" : "String",
 "unit" : "String",
 "unitRate" : 0
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
