# 转储确认

**请求URL：** 
- `/product/allot/dump/cancel`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderItemId|否|String| 调拨明细iid|
|receiveQuantity|否|Double| 数量|
|orderId|否|String| 订单id|
|remark|否|String| 备注|

### 请求参数Json格式
 
```
{
 "orderItemId" : "String",
 "receiveQuantity" : 0,
 "orderId" : "String",
 "remark" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
