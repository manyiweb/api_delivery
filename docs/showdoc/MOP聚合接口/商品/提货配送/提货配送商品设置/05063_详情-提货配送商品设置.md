# 详情-提货配送商品设置

**请求URL：** 
- `/product-manager/delivery/item/setting/info`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 门店标识|

### 请求参数Json格式
 
```
{
 "companyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--inherit|否|Boolean| 是否继承品牌|
|--settingId|否|Long| 主设置id|
|--enable|否|Boolean| 启用按配送方式选择下单商品|
|--deliveryTypeSettings|否|List| 提货配送商品提货配送方式设置|
|----id|否|Long| 主键ID|
|----deliveryItemSettingId|否|Long| 提货配送商品设置id|
|----deliveryType|否|Integer| 提货配送方式|
|----specifiedMode|否|Integer| 指定模式|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : {
 "inherit" : true,
 "settingId" : 0,
 "enable" : true,
 "deliveryTypeSettings" : [{
 "id" : 0,
 "deliveryItemSettingId" : 0,
 "deliveryType" : 0,
 "specifiedMode" : 0
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
