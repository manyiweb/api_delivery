# 更新-提货配送商品设置

**请求URL：** 
- `/delivery/item/setting/update `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 门店标识|
|inherit|否|Boolean| 是否继承品牌|
|enable|否|Boolean| 是否启用按配送方式选择下单商品|
|deliveryType|否|Integer| 提货配送方式|
|specifiedMode|否|Integer| 指定模式|
|deleteDetailIds|否|List| 删除明细id列表|
|addSpecIds|否|List| 更新-指定商品明细列表|
|addItemIds|否|List| 更新-指定商品明细列表 商品级别|
|addClassifications|否|List| 更新-指定分类/品牌/系列明细列表|
|--type|否|Integer| 类型:1-类别;2-品牌;3-系列|
|--typeId|否|String| 类型/品牌/系列标识|
|--distributionType|否|Integer| 配送类型|
|deliveryTypes|否|List| 更新-指定商品 配送类型|
|--itemIds|否|String| 规格id|
|--itemId|否|String| 商品id|
|--distributionType|否|Integer| 配送类型|
|classificationsDeliveryTypes|否|List| 更新-指定分类/品牌/配送类型|
|--type|否|Integer| 类型:1-类别;2-品牌;3-系列|
|--typeId|否|String| 类型/品牌/系列标识|
|--deliveryType|否|Integer| 配送类型|

###请求参数Json格式
 
```
{
 "companyId" : "String",
 "inherit" : true,
 "enable" : true,
 "deliveryType" : 0,
 "specifiedMode" : 0,
 "deleteDetailIds" : null,
 "addSpecIds" : null,
 "addClassifications" : [{
 "type" : 0,
 "typeId" : "String",
 "distributionType" : 0
 }],
 "deliveryTypes" : [{
 "specIds" : "String",
 "distributionType" : 0
 }],
 "classificationsDeliveryTypes" : [{
 "type" : 0,
 "typeId" : "String",
 "deliveryType" : 0
 }]
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|String| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : "String",
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
