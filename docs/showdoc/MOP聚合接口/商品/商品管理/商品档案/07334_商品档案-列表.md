# 商品档案-列表

**请求URL：** 
- `/product/itemSearch/item/comp/list `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|sword|否|String| 关键字|
|companyId|否|String| 门店id|
|ItemTypefCode|否|String| 商品分类编码|
|pageIndex|否|Integer||
|pageSize|否|Integer||
|orderField|否|String||
|orderSort|否|String||

###请求参数Json格式
 
```
{
 "sword" : "String",
 "companyId" : "String",
 "ItemTypefCode" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String"
}
```

|:---- |:---|:----- |----- |
|data|否|Object||
|--pageIndex|否|Integer||
|--pageSize|否|Integer||
|--pageCount|否|Integer||
|--totalCount|否|Long||
|--first|否|Boolean||
|--last|否|Boolean||
|--content|否|List||
|----itemId|否|String| 商品id|
|----itemCode|否|String| 商品编码|
|----itemName|否|String| 商品名称|
|----skuBarcode|否|String| sku|
|----itemTypeId|否|String| 分类id|
|----unit|否|String| 单位|
|----isShelves|否|Integer| 状态|
|----hiddenColumn|否|Boolean| 隐藏列|
|----itemTypeSortId|否|Long| 商品分类排序id|
|----retailSortNum|否|Integer| 排序号|
|----minPrice|否|Double| 最小零售价|
|----maxPrice|否|Double| 最大零售价|
|----salePriceRange|否|Double| 零售区间价|
|----salePrice|否|Double| 零售价|
|----dealPrice|否|Double| 档案价|
|----isMutiSpec|否|Integer| 是否多规格 1是 0否|

|code|否|String||
