# 添加商品资质认证信息
 

**请求URL：** 
- `/product/item/certification/add`

**请求方式：** 
- `POST`
- `RequestBody`


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|certFileInfoList|是|List| 资质文件列表|
|--certFileName|是|String| 资质文件名|
|--certFilePath|是|String| 资质文件路径|
|certExpiryDate|是|DateTime| 资质有效期|
|certType|是|Object| 资质文件类型 BUSINESS_LICENSE、FOOD_OPERATION_LICENSE、CATERING_SERVICE_LICENSE、PRODUCTION_LICENSE、HEALTH_LICENSE、OTHER|
|--description|否|String||
|remark|否|String| 备注|
|itemId|是|String| 商品ID|

### 请求参数Json格式
 
```
{
 "certFileInfoList":[{
 "certFileName":"String",
 "certFilePath":"String"
 }],
 "certExpiryDate":"DateTime",
 "certType":{
 "description":"String"
 },
 "remark":"String",
 "itemId":"String"
}
```

### 响应参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 响应参数Json格式
 
```
{
 "data":null,
 "msg":"String",
 "code":"String",
 "exceptionStackInfo":"String",
 "traceId":"String"
}
```
