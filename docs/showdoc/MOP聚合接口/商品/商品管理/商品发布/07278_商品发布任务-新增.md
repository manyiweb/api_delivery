# 商品发布任务-新增

**请求URL：** 
- `/item/publish/add `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|publishCode|否|String| 编码|
|publishName|否|String| 名称|
|publishRemark|否|String| 备注|

###请求参数Json格式
 
```
{
 "publishCode" : "String",
 "publishName" : "String",
 "publishRemark" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|String||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


###返回参数Json格式
 
```
{
 "data" : "String",
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
