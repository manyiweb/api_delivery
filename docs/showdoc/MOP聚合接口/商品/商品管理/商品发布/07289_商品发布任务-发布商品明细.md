# 商品发布任务-发布商品明细

**请求URL：** 
- `/item/publish/publishItemDetail `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 发布任务id|
|itemTypeId|否|String| 商品分类id|
|sword|否|String| 搜索条件|

###请求参数Json格式
 
```
{
 "id" : 0,
 "itemTypeId" : "String",
 "sword" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--publishItems|否|List| 指定商品信息|
|----id|否|Long| 主键ID|
|----publishTaskId|否|Long| 商品发布任务Id|
|----itemId|否|String| 商品Id|
|----itemCode|否|String| 商品编码|
|----itemName|否|String| 商品名称|
|----itemTypeId|否|String| 商品分类id|
|----sortNum|否|Integer| 排序号|
|----hiddenColumn|否|Boolean| 隐藏列|
|--publishItemTypes|否|List| 指定类别/品牌/系列/档案属性 商品信息集合|
|----type|否|Integer| 商品类型 0-指定类别 1-品牌 2-系列 4-档案属性|
|----lineId|否|Integer| 行id，用于记录是否同一行|
|----basicInfos|否|List| 选择基本信息|
|------id|否|String| id|
|------code|否|String| 编码|
|------name|否|String| 名称|
|----attrValues|否|List| 属性值|
|----valueType|否|Integer| 属性值类型 0-任何值，1-序列，2-业务对象，3-自定义业务对象|
|----content|否|String| 类容，多个英文分号隔开|
|----contentId|否|String| 业务id|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
