# 商品发布任务-获取发布任务

**请求URL：** 
- `/item/publish/getPublishTask `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long||

###请求参数Json格式
 
```
{
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long| 主键id|
|--publishCode|否|String| 编码|
|--publishName|否|String| 编码|
|--publishItemBusinessScenarioCodes|否|List| 商品业务场景编码 RETAIL-零售、B2B-订货、MALL-商城、ORDER-点单|
|--publishItemBusinessScenarioNames|否|List| 商品业务场景名称 零售、订货、商城、点单|
|--publishExecutionMode|否|Integer| 执行模式 0-替换、1-覆盖、2-追加、3-下架、4-移除|
|--publishExecutionTime|否|DateTime| 执行时间|
|--publishExecutionType|否|Integer| 执行方式 0-立即执行，1-定时执行|
|--publishExecutionStatus|否|Integer| 执行状态 :0-未执行、1-已完成、2执行中、3-已取消|
|--publishRemark|否|String| 备注|
|--itemTypeCode|否|Integer| 商品信息类型 0-所有商品、1-指定商品、2-指定类别/品牌/系列/档案属性/规格属性|
|--compTypeCode|否|Integer| 门店信息类型 0-所有门店、1-指定门店、2-指定商户类型/商户组/门店分组/所属区域/档案属性|
|--createId|否|String| 创建人id|
|--createName|否|String| 创建人名称|
|--createDate|否|String| 创建时间|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


###返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,

 "publishName" : "String",
 "publishItemBusinessScenarioCodes" : null,
 "publishItemBusinessScenarioNames" : null,
 "publishExecutionMode" : 0,
 "publishExecutionTime" : "DateTime",
 "publishExecutionType" : 0,
 "publishExecutionStatus" : 0,
 "publishRemark" : "String",
 "itemTypeCode" : 0,
 "compTypeCode" : 0,
 "createId" : "String",
 "createName" : "String",
 "createDate" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
