# 商品发布任务-更新排序号

**请求URL：** 
- `/item/publish/updateSortNum `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 发布任务id|
|publishItemId|否|Long| 发布商品id|
|sortNum|否|Integer| 排序号|

###请求参数Json格式
 
```
{
 "id" : 0,
 "publishItemId" : 0,
 "sortNum" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
