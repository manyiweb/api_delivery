# 商品发布任务-拖拽排序

**请求URL：** 
- `/item/publish/publishItemDragSort `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 任务id|
|ids|否|List||
|down|否|Boolean||

###请求参数Json格式
 
```
{
 "id" : 0,
 "ids" : null,
 "down" : true
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
