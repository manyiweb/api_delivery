# 商品发布任务-列表

**请求URL：** 
- `/product-front/item/publish/list/{source} `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|String||
|pageSize|否|Integer||
|pageNo|否|Integer||
|sortField|否|String||
|sortDirection|否|String||

###请求参数Json格式
 
```
{
 "id" : "String",
 "pageSize" : 0,
 "pageNo" : 0,
 "sortField" : "String",
 "sortDirection" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--content|否|List||
|----id|否|Long||
|----publishCode|否|String| 编码|
|----publishName|否|String| 名称|
|----publishItemBusinessScenarioCode|否|String| 商品业务场景编码 retail-零售、b2b-订货、mall-商城、order-点单|
|----publishItemBusinessScenarioName|否|String| 商品业务场景名称 零售、订货、商城、点单|
|----publishExecutionMode|否|Integer| 执行模式 0-替换、1-覆盖、2-追加、3-下架、4-移除|
|----publishExecutionTime|否|DateTime| 执行时间|
|----publishExecutionType|否|Integer| 执行方式 0-立即执行，1-定时执行|
|----publishExecutionStatus|否|Integer| 执行状态 :0-待执行、1-已完成、2-执行中、3-已取消、4-未发布、5-已撤销|
|----publishRemark|否|String| 备注|
|----createName|否|String| 创建人名称|
|----createDate|否|DateTime| 创建时间|
|--pageSize|否|Integer||
|--pageNo|否|Integer||
|--total|否|Long||
|--totalPage|否|Integer||
|--hasNextPage|否|Boolean||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||

 }],

 },

 "traceId" : "String"
}
