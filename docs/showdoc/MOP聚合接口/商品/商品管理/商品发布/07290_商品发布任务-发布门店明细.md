# 商品发布任务-发布门店明细

**请求URL：** 
- `/item/publish/publishCompDetail `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 发布任务id|

###请求参数Json格式
 
```
{
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--publishComps|否|List| 指定门店信息|
|----id|否|Long| 主键ID|
|----publishTaskId|否|Long| 商品发布任务Id|
|----companyId|否|String| 门店Id|
|----companyCode|否|String| 门店编码|
|----companyName|否|String| 门店名称|
|--publishCompTypes|否|List| 指定商户类型/商户组/门店分组/所属区域/档案属性|
|----type|否|Integer| 门店类型 0-指定商户类型 1-商户组 2-门店分组 3-所属区域 4-档案属性|
|----lineId|否|Integer| 行id，用于记录是否同一行|
|----basicInfos|否|List| 选择基本信息|
|------fid|否|String| 前端需要，无特殊作用和id值一样|
|------id|否|String| id|
|------code|否|String| 编码|
|------name|否|String| 名称|
|----attrValues|否|List| 属性值|
|----valueType|否|Integer| 属性值类型 0-任何值，1-序列，2-业务对象，3-自定义业务对象|
|----content|否|String| 类容，多个英文分号隔开|
|----contentId|否|String| 业务id|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||

```
 "id" : "String",

 "name" : "String"
 }],
 "attrValues" : null,
 "valueType" : 0,
 "content" : "String",
 "contentId" : "String"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
