# 商品分类排序-更新隐藏列

**请求URL：** 
- `/item/type/sort/updateHiddenColumn `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 商品分类排序id|
|hiddenColumn|否|Boolean| 隐藏列|

###请求参数Json格式
 
```
{
 "id" : 0,
 "hiddenColumn" : true
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
