# 商品发布任务-发布商品分类列表

**请求URL：** 
- `/item/publish/publishItemTypeList `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long||

###请求参数Json格式
 
```
{
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--itemTypeId|否|String| 分类id|
|--itemTypeName|否|String| 分类名称|
|--quantity|否|Integer| 数量|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


###返回参数Json格式
 
```
{
 "data" : [{
 "itemTypeId" : "String",
 "itemTypeName" : "String",
 "quantity" : 0
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
