# 商品发布任务-更新商品信息类型

**请求URL：** 
- `/item/publish/updateItemType `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 主键|
|type|否|Integer| 类型 0-所有商品、1-指定商品、2-指定类别/品牌/系列/档案属性/规格属性 || 0-所有门店、1-指定门店、2-指定商户类型/商户组/门店分组/所属区域/档案属性|

###请求参数Json格式
 
```
{
 "id" : 0,
 "type" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
