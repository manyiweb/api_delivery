# 商品发布任务-日志列表

**请求URL：** 
- `/item/publish/publishLogList `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|taskId|否|Long| 发布任务id|

###请求参数Json格式
 
```
{
 "taskId" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--id|否|Long| 主键|
|--taskId|否|Long| 发布任务id|
|--businessScenarioName|否|String| 商品业务场景名称 零售、订货、商城、点单|
|--executionMode|否|Integer| 执行模式 0-替换、1-覆盖、2-追加、3-下架、4-移除|
|--executionTime|否|DateTime| 执行时间|
|--executionType|否|Integer| 执行方式 0-立即执行，1-定时执行|
|--executionStatus|否|Integer| 执行状态 :0-待执行、1-已完成、2-执行中、3-已取消、4-未发布、5-已撤销|
|--remark|否|String| 备注|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


###返回参数Json格式
 
```
{
 "data" : [{
 "id" : 0,
 "taskId" : 0,
 "businessScenarioName" : "String",
 "executionMode" : 0,
 "executionTime" : "DateTime",
 "executionType" : 0,
 "executionStatus" : 0,
 "remark" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
