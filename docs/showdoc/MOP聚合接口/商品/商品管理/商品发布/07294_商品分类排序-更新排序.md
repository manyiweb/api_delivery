# 商品分类排序-更新排序

**请求URL：** 
- `/item/type/sort/updateSortNum `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 门店id|
|itemTypeId|否|String| 商品分类id|
|itemId|否|String| 商品id|
|id|否|Long| 商品排序id|
|sortNum|否|Integer| 排序号|

###请求参数Json格式
 
```
{
 "companyId" : "String",
 "itemTypeId" : "String",
 "itemId" : "String",
 "id" : 0,
 "sortNum" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
