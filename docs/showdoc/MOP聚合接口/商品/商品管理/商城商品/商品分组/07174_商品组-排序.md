# 商品组-排序

**请求URL：** 
- `/product/item/group/sort `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|sortType|否|Integer| 排序类型 1置顶|
|ids|否|List|商品组id|
|down|否|Boolean|true: 向下拖拽；false：向上拖拽|

###请求参数Json格式
 
```
{
 "sortType" : 0,
 "ids" : null,
 "down" : true,
 "companyId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
