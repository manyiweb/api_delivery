# 批量上下架

**请求URL：** 
- `/product/mitemComp/shelf/batchUpdateShelf`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|itemId|是|String| 商品id|
|companyIds|是|List| 门店id|
|isShelves|是|Integer| 零售上下架|
|orderStatus|是|Integer| 订货上下架|
|mallStatus|是|Integer| 商城上下架|
|orderShelves|是|Integer| 点单上下架|
|itemCompShelfTimes|否|List| 上下架有效期|
|--platformType|否|String| 平台类型 retail-零售, mall-商城, orderGoods-订货, order-点单|
|--onShelfValidityPeriodBegin|否|DateTime| 上架有效期开始时间|
|--onShelfValidityPeriodEnd|否|DateTime| 上架有效期结束时间|
|--onShelfTime|否|String| 上架有效期时间段|
|--validityPeriodStatus|否|Integer| 有效期启用状态,1启用 0不启用|
|--timeSlotStatus|否|Integer| 时间段启用状态,1启用 0不启用|

### 请求参数Json格式
 
```
{
 "itemId" : "String",
 "companyIds" : null,
 "isShelves" : 0,
 "orderStatus" : 0,
 "mallStatus" : 0,
 "orderShelves" : 0,
 "itemCompShelfTimes" : [{
 "platformType" : "String",
 "onShelfValidityPeriodBegin" : "DateTime",
 "onShelfValidityPeriodEnd" : "DateTime",
 "onShelfTime" : "String",
 "validityPeriodStatus" : 0,
 "timeSlotStatus" : 0
 }]
}
```

|data|否|Object||

|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
