# 获取商品标签组

**请求URL：** 
- `/product/item/labelGroup`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|itemId|否|String| 商品id|

### 请求参数Json格式
 
```
{
 "itemId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--id|否|Long| 主键|
|--itemId|否|String| 商品id|
|--labelGroupId|否|Long| 标签组id，与表mitem_label_group关联|
|--labelGroupCode|否|String| 标签组编码|
|--labelGroupName|否|String| 标签组名称|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "id" : 0,
 "itemId" : "String",
 "labelGroupId" : 0,
 "labelGroupCode" : "String",
 "labelGroupName" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
