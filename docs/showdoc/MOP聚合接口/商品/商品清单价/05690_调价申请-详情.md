# 调价申请详情

**请求URL：** 
- `/product/price/adjustment/application/detail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|applyId|是|Long| 申请表Id|
|sword|否|String||
|tokenId|否|String||
|id|否|String||
|orderField|否|String| 排序字段|
|orderSort|否|String| 排序方式|
|searchBeans|否|List| 高级筛选条件|
|--typeCode|否|String||
|--typeName|否|String||
|--dataType|否|String||
|--isSingle|否|String||
|--isLikeSearch|否|String||
|--items|否|List||
|--current|否|Object||
|----itemName|否|String||
|----itemValue|否|String||
|----minValue|否|String||
|----maxValue|否|String||
|----isCustom|否|String||
|----isRange|否|String||
|----isSelect|否|String||
|--sword|否|String||
|--pageIndex|否|Integer||
|--pageSize|否|Integer||
|--curPageNum|否|Integer||
|--totalPage|否|Integer||
|--totalCount|否|Integer||
|status|否|Integer| 状态|
|pageIndex|否|Integer| 页号|
|pageSize|否|Integer| 页大小|
|orderField|否|String| 商品排序字段|
|orderSort|否|String| 商品排序方式 desc 倒序 asc 正序|

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--orderInfor|否|Object| 单据信息|
|----applyId|否|Long||
|----applyNo|否|String| 申请编码|
|----applyName|否|String| 申请名称|
|----applyStatus|否|Integer| 申请状态：0-待审核,1-已确认,2-已拒绝|
|----applyStatusName|否|Integer| 申请状态：0-待审核,1-已确认,2-已拒绝|
|----createName|否|String| 创建人|
|----createDate|否|DateTime| 创建时间|
|----priceListId|否|String| 清单Id|
|----priceListName|否|String| 清单名称|
|----remark|否|String| 备注|
|--items|否|Object| 商品信息|
|----pageIndex|否|Integer| 页码|
|----pageSize|否|Integer| 显示记录数|
|----pageCount|否|Integer| 总页数|
|----totalCount|否|Long| 总记录数|
|----first|否|Boolean| 首页|
|----last|否|Boolean| 尾页|
|----content|否|List| 分页数据|
|------applyItemId|否|Long||
|------itemId|否|String| 商品ID|
|------itemCode|否|String| 商品编码|
|------itemName|否|String| 商品名称|
|------skuBarcode|否|String| 条码|
|------specId|否|String| 规格ID|
|------specName|否|String| 规格名称|
|------afterAdjustPrice|否|Double| 调价后清单价|
|------beforeAdjustPrice|否|Double| 调价前清单价|
|------confirmAdjustPrice|否|Double| 审核后清单价|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
