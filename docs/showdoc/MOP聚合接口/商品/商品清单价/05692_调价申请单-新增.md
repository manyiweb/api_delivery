# 新增或修改（修改暂无需求）

**请求URL：** 
- `/product/price/adjustment/application/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|applyId|否|Long| 申请表Id 新增不传|
|applyName|否|String| 申请表名称|
|applyStatus|否|Integer| 申请状态：0-待审核,1-已确认,2-已拒绝|
|priceListId|是|String| 清单Id|
|remark|否|String| 备注|
|companyId|是|String| 门店Id|
|delItemIds|否|List| 删除商品行Id|
|itemSaveReqs|否|List| 商品信息|
|--applyItemId|否|Long| 申请单明细Id 新增不传|
|--itemId|是|String| 商品ID|
|--specId|是|String| 规格ID|
|--afterAdjustPrice|是|Double| 申请价|

### 请求参数Json格式
 
```
{
 "applyId" : 0,
 "applyName" : "String",
 "applyStatus" : 0,
 "priceListId" : "String",
 "remark" : "String",
 "companyId" : "String",
 "delItemIds" : null,
 "itemSaveReqs" : [{
 "applyItemId" : 0,
 "itemId" : "String",
 "specId" : "String",
 "afterAdjustPrice" : 0
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
