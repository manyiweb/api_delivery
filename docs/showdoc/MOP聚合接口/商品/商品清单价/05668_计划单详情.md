# 调价计划单详情

**请求URL：** 
- `/product/batch/price/adjustment/detail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long| id|

### 请求参数Json格式
 
```
{
 "id" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--planId|否|Long| 计划单Id|
|--planNo|否|String| 计划单编码|
|--planName|否|String| 计划单名称|
|--planStatus|否|Integer| 计划单状态|
|--planStatusName|否|String| 计划单状态名称|
|--lastExecuteTime|否|DateTime| 最后执行时间|
|--createDate|否|DateTime| 创建时间|
|--createName|否|String| 创建人|
|--isImmediatelyEffective|否|Integer| 是否立即生效,0-否，1-是|
|--assignSendDate|否|DateTime| 生效日期|
|--assignSendTiem|否|String| 生效时间点|
|--remark|否|String| 调价说明|
|--priceListType|否|Integer| 清单类型,0-品牌价格清单,1-商户价格清单|
|--priceListTypeName|否|String| 清单类型,0-品牌价格清单,1-商户价格清单|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|

```
 "assignSendDate" : "DateTime",
 "assignSendTiem" : "String",
 "remark" : "String",
 "priceListType" : 0,
 "priceListTypeName" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
