# 计划单审核明细列表

**请求URL：** 
- `/product/batch/price/adjustment/accept/detail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long|计划单id|

### 请求参数Json格式
 
```
{
 "id" : 0
}
```
