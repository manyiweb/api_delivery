# 审核

**请求URL：** 
- `/product/price/adjustment/application/audit`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|applyId|是|Long| 申请表Id|
|auditStatus|是|Integer| 审核状态：1-确认,2-拒绝|
|remark|否|String| 备注|
|auditItemReqs|否|List| 有修改过审核后清单价的明细，其他明细可以不传|
|--applyItemId|是|Long| 申请单明细Id|
|--auditAdjustPrice|是|Double| 审核价|

### 请求参数Json格式
 
```
{
 "applyId" : 0,
 "auditStatus" : 0,
 "remark" : "String",
 "auditItemReqs" : [{
 "applyItemId" : 0,
 "auditAdjustPrice" : 0
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
