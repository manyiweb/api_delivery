# 新增或修改计划单

**请求URL：** 
- `/product/batch/price/adjustment/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 计划单 新增不传|
|planName|是|String| 计划单名称|
|priceListType|是|Integer| 清单类型,0-品牌价格清单,1-商户价格清单|
|remark|否|String| 调价说明|
|isImmediatelyEffective|否|Integer| 是否立即生效,默认1,0-否，1-是|
|endDate|否|DateTime| 指定时间|
|delPlanItemIds|否|List| 删除的商品行Id|
|itemReqs|否|List| 商品信息|
|--planItemId|否|Long| 商品行Id 新增不传|
|--itemId|是|String| 商品Id|
|--specId|是|String| 规格Id|
|--afterAdjustPrice|是|Double| 调价后清单价|
|delPlanListIds|否|List| 删除的清单行Id|
|planListIds|否|List| 清单信息Ids|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "planName" : "String",
 "priceListType" : 0,
 "remark" : "String",
 "isImmediatelyEffective" : 0,
 "endDate" : "DateTime",
 "delPlanItemIds" : null,
 "itemReqs" : [{
 "planItemId" : 0,
 "itemId" : "String",
 "specId" : "String",
 "afterAdjustPrice" : 0
 }],
 "delPlanListIds" : null,
 "planListIds" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
