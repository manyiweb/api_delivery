# 下载离线pos商品

**请求URL：** 
- `/offlinePos/downloadOfflineProducts `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|readCache|否|Boolean| 默认文件有缓存,false则不读缓存|

###请求参数Json格式
 
```
{
 "readCache" : true
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--url|否|String| txt文件下载地址|
|--zipUrl|否|String| 压缩文件下载地址|
|--version|否|Long| 版本号|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


###返回参数Json格式
 
```
{
 "data" : {
 "url" : "String",
 "zipUrl" : "String",
 "version" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
