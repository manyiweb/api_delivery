# 特殊商品详情

**请求URL：** 
- `/product-manager/product/pricelist/specialItem/detail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|itemId|是|String| 商品id|
|priceListId|是|String| 清单id|

### 请求参数Json格式
 
```
{
 "itemId" : "String",
 "priceListId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--itemId|否|String| 商品id|
|--itemCode|否|String| 商品编码|
|--itemName|否|String| 商品名称|
|--isMultipleSpecifications|否|Boolean| 是否是多规格|
|--salePrice|否|Double| 零售价|
|--listPrice|否|Double| 清单价|
|--salePriceRange|否|String| 零售价区间|
|--listPriceRange|否|String| 清单价区间|
|--specs|否|List| 多规格列表|
|----specId|否|String| 规格id|
|----specName|否|String| 规格名称|
|----skuBarcode|否|String| sku|
|----listPrice|否|Double| 清单价|
|----remark|否|String||
|----referenceQuantity|否|Double| 参考数量|
|----referencePrice|否|Double| 参考数量小计|
|--colorSizeMap|否|String||
|--referenceQuantity|否|Double| 参考数量|
|--referencePrice|否|Double| 参考数量小计|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||

 }],

}
