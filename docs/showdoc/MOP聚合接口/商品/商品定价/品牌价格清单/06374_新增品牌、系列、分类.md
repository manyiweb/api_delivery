# 新增品牌、系列、分类

**请求URL：** 
- `/product-manager/product/pricelist/category/save `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|priceListId|否|String| 清单id|
|categoryType|否|Integer| 类别类型，1：品牌，2：系列 3：类别|
|categoryId|否|String| 通用指定id 可以是品牌，系列或类别|
|categoryCode|否|String| 通用指定编码 可以是品牌，系列或类别|
|categoryName|否|String| 通用指定名称 可以是品牌，系列或类别|
|rate|否|Double| 折扣|
|id|否|Object| id|

###请求参数Json格式
 
```
{
 "priceListId" : "String",
 "categoryType" : 0,
 "categoryId" : "String",
 "categoryCode" : "String",
 "categoryName" : "String",
 "rate" : 0,
 "id" : null
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
