# 分页查询品牌价格清单 指定品牌、系列、分类列表

**请求URL：** 
- `/product-manager/product/pricelist/category/list `

**请求方式：**
- POST
- RequestBody

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--pageIndex|否|Integer| 页码|
|--pageSize|否|Integer| 显示记录数|
|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|--first|否|Boolean| 首页|
|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|
|----id|否|Long| Id|
|----priceListId|否|String| 清单id|
|----categoryType|否|Integer| 类别类型，1：品牌，2：系列 3：类别|
|----categoryId|否|String| 通用指定id 可以是品牌，系列或类别|
|----categoryCode|否|String| 通用指定编码 可以是品牌，系列或类别|
|----categoryName|否|String| 通用指定名称 可以是品牌，系列或类别|
|----rate|否|Double| 折扣|
|----dbKey|否|Integer| 分库标识|
|----groupId|否|String| 品牌商id|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|
