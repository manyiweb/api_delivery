# 导出

**请求URL：** 
- `/product-manager/product/pricelist/export `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|priceListId|否|String| 清单id|
|type|否|Integer| 0:品牌、系列、分类 1：特殊商品|
|sword|否|String||

###请求参数Json格式
 
```
{
 "priceListId" : "String",
 "type" : 0,
 "sword" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--isTask|否|Boolean| 是否任务模式|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "isTask" : true
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
