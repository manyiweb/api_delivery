# 修改商品清单价

**请求URL：** 
- `/product-manager/product/pricelist/specialItem/updateItem`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|priceListId|否|String| 清单id|
|itemId|否|String| 商品id|
|isMultipleSpecifications|否|Boolean| 是否是多规格|
|listPrice|否|Double| 清单价|
|specs|否|List| 多规格列表|
|--specId|否|String| 规格id|
|--specName|否|String| 规格名称|
|--skuBarcode|否|String| sku|
|--listPrice|否|Double| 清单价|
|--remark|否|String||
|--referenceQuantity|否|Double| 参考数量|
|remark|否|String||
|referenceQuantity|否|Double| 参考数量|

### 请求参数Json格式
 
```
{
 "priceListId" : "String",
 "itemId" : "String",
 "isMultipleSpecifications" : true,
 "listPrice" : 0,
 "specs" : [{
 "specId" : "String",
 "specName" : "String",
 "skuBarcode" : "String",
 "listPrice" : 0,
 "remark" : "String",
 "referenceQuantity" : 0
 }],
 "remark" : "String",
 "referenceQuantity" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
