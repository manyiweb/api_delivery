# 门店保存价格上限清单应用

**请求URL：** 
- `/product/purchase/company/pricecapsList/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String||
|companyPricecapsLists|是|List||
|--id|否|Long||
|--supplierId|否|String||
|--supplierCode|否|String||
|--supplierName|否|String||
|--pricecapsListId|否|Long||
|deleteCompanyPricecapsListIds|否|List||

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "companyPricecapsLists" : [{
 "id" : 0,
 "supplierId" : "String",
 "supplierCode" : "String",
 "supplierName" : "String",
 "pricecapsListId" : 0
 }],
 "deleteCompanyPricecapsListIds" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
