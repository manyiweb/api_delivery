# 门店复制价格上限清单应用

**请求URL：** 
- `/product/purchase/company/pricecapsList/copy`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|copyFromCompanyId|是|String||
|copyToCompanyIds|是|List||

### 请求参数Json格式
 
```
{
 "copyFromCompanyId" : "String",
 "copyToCompanyIds" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
