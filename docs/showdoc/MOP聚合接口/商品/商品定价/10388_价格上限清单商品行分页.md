# 价格上限清单商品行分页

**请求URL：** 
- `/product/pricecapsList/items/page/{source}`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|pricecapsListId|否|Long||
|itemTypefCodes|否|List| 商品分类id|
|brandCodes|否|List| 品牌|
|seriesCodes|否|List| 系列|
|id|否|String||
|pageSize|否|Integer||
|pageNo|否|Integer||
|sortField|否|String||
|sortDirection|否|String||
|viewId|否|String||

### 请求参数Json格式
 
```
{
 "pricecapsListId" : 0,
 "itemTypefCodes" : null,
 "brandCodes" : null,
 "seriesCodes" : null,
 "id" : "String",
 "pageSize" : 0,
 "pageNo" : 0,
 "sortField" : "String",
 "sortDirection" : "String",
 "viewId" : "String"
}
```
