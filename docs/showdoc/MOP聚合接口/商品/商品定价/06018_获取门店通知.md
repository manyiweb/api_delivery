# 获取门店通知

**请求URL：** 
- `/product-task/offlinePos/notice/findCompNotice `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|type|否|String| 通知类型 ListPrice(部分商品价格发生调整)|

###请求参数Json格式
 
```
{
 "type" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--type|否|String| 通知类型|
|--typeName|否|String| 通知类型|
|--companyId|否|String| 门店id 与syscompany表关联|
|--companyCode|否|String| 门店编码|
|--companyName|否|String| 门店名称|
|--version|否|Long| 版本号|
|--status|否|Integer| 状态 -1-失败，0-等待执行，1-执行中，2-成功|
|--sendDate|否|DateTime| 发送时间|
|--executeDate|否|DateTime| 执行时间|
|--completeDate|否|DateTime| 完成时间|
|--result|否|String| 结果|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "type" : "String",
 "typeName" : "String",
 "companyId" : "String",
 "companyCode" : "String",
 "companyName" : "String",
 "version" : 0,
 "status" : 0,
 "sendDate" : "DateTime",
 "executeDate" : "DateTime",
 "completeDate" : "DateTime",
 "result" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
