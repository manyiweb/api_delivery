# 获取仓库价格上限清单配置

**请求URL：** 
- `/product/whs/pricecapsList/getConfig`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|deliveryWhsCompanyId|是|String||
|isInherit|是|Integer||

### 请求参数Json格式
 
```
{
 "deliveryWhsCompanyId" : "String",
 "isInherit" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--isInherit|否|Integer||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "isInherit" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
