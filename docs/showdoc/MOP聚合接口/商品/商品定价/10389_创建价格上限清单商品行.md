# 创建价格上限清单商品行

**请求URL：** 
- `/product/pricecapsList/items/add`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|pricecapsListId|是|Long||
|items|是|List||
|--itemId|是|String||
|--unitGroupId|是|Long||
|--unitPricecapsObjs|是|List||
|----id|否|Long||
|----unitId|否|String||
|----unitName|是|String||
|----maximumPrice|是|Double||

### 请求参数Json格式
 
```
{
 "pricecapsListId" : 0,
 "items" : [{
 "itemId" : "String",
 "unitGroupId" : 0,
 "unitPricecapsObjs" : [{
 "id" : 0,
 "unitId" : "String",
 "unitName" : "String",
 "maximumPrice" : 0
 }]
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
