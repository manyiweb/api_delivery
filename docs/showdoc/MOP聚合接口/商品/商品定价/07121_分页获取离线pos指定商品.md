# 分页获取离线pos指定商品

**请求URL：** 
- `/offlinePos/pageOfflineProducts `

**请求方式：**
- POST
- RequestBody

|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|sword|否|String| 搜索条件|
|fCode|否|String| 商品分类|
|pageIndex|否|Integer||
|pageSize|否|Integer||
|orderField|否|String||
|orderSort|否|String||

 "fCode" : "String",
