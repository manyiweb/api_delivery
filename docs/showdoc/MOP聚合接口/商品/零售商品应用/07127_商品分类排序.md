# 商品分类排序

**请求URL：** 
- `/item/sale/price/item/type/sort`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|itemTypeCodes|否|List| 商品分类编码|
|applyCompanyType|否|Boolean| 应用门店 true:全部门店 false:指定门店|
|fieldType|否|Boolean| 排序规则 true.按建议零售价 false: 按商品编码|
|isDesc|否|Boolean| 排序规则 倒序And升序; true:倒序|
|companyIds|否|List| 门店id|

### 请求参数Json格式
 
```
{
 "itemTypeIds" : null,
 "itemTypeCodes" : null,
 "applyCompanyType" : true,
 "fieldType" : true,
 "isDesc" : true,
 "companyIds" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
