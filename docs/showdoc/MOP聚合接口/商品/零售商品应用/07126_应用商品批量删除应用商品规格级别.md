# 应用商品批量删除应用商品规格级别

**请求URL：** 
- `/item/sale/price/apply/item/batch/del`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|ItemIds|否|List| 商品id|
|companyIds|否|List| 门店id|
|isAllCompany|否|Boolean| 是否全部门店|

### 请求参数Json格式
 
```
{
 "ItemIds" : null,
 "companyIds" : null,
 "isAllCompany" : true
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
