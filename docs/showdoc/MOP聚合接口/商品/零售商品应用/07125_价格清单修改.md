# 价格清单修改

**请求URL：** 
- `/item/sale/price/list/batch/edit`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|batchItemSaleListPriceItemReq|否|List| 请求明细|
|--itemId|是|String| 商品id|
|--specId|是|String| 规格id|
|--listPrice|是|Double| 价格|
|companyIds|否|List| 商户id|
|isAllCompany|否|Boolean| 是否全部门店|

### 请求参数Json格式
 
```
{
 "batchItemSaleListPriceItemReq" : [{
 "itemId" : "String",
 "specId" : "String",
 "listPrice" : 0
 }],
 "companyIds" : null,
 "isAllCompany" : true
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
