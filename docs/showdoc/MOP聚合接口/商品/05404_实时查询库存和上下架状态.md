# 实时查询库存和上下架状态

**请求URL：** 
- `/appc/Product/checkMItemStock`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|itemIds|是|List| itemIds|
|companyId|是|String| companyId|

### 请求参数Json格式
 
```
{
 "itemIds": [
 "03d3660f4bf14af68ad9daf1a1e8c023",
 "0aae1ea9b2ff4be6bb8132f9f789c08d"
 ],
 "tokenId": "775931d97c9f419b9fbb021a329ebf52",
 "companyId": "F3278C2C927F4B28976742C85A79058F"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|dataLine|否|List||
|--itemId|否|String| itemId|
|--onHandQty|否|Double| 库存|
|--isNegativeStock|否|Integer| 是否负库存|
|--isStock|否|Integer| 是否有库存|
|--isShelves|否|Integer| 是否上架|
|--isRemove|否|Integer| 是否移除|


### 返回参数Json格式
 
```
{

 {
 "isNegativeStock": 1,
 "isRemove": 0,
 "isShelves": 1,
 "isStock": 1,
 "itemId": "03d3660f4bf14af68ad9daf1a1e8c023",
 "onHandQty": -79.0
 },
 {
 "isNegativeStock": 1,
 "isRemove": 0,
 "isShelves": 1,
 "isStock": 1,
 "itemId": "0aae1ea9b2ff4be6bb8132f9f789c08d",
 "onHandQty": 1.0
 }
 ]
}
```
