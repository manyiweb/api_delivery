# 详情

**请求URL：** 
- `/config/bondedWarehouseSet/info`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||

### 请求参数Json格式
 
```
{
 "id" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long| ID|
|--whsId|否|String| 仓库id|
|--whsCode|否|String| 仓库编码|
|--whsName|否|String| 仓库名称|
|--customsName|否|String| 海关名称|
|--customsAreaName|否|String| 关区名称|
|--customsAreaCode|否|String| 关区代码|
|--enterpriseCode|否|String| 企业编码|
|--enterpriseName|否|String| 企业名称|
|--enterpriseCustomsRecordNo|否|String| 企业海关备案编号|
|--enterpriseNationalInspectionRecordNo|否|String| 企业国检备案编号|
|--encryptionKey|否|String| 加密KEY|
|--logisticsName|否|String| 物流商名称|
|--logisticsEnterpriseCode|否|String| 物流企业代码|
|--logisticsEnterpriseName|否|String| 物流企业名称|
|--accountBookNo|否|String| 仓库账册编号|
|--secretKey|否|String| 海关密钥key|
|--agentCode|否|String| 公服企业代码|
|msg|否|String||
|code|否|String||
