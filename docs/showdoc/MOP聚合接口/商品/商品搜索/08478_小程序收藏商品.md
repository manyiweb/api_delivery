# 收藏商品

**请求URL：** 
- `product-front/appc/collect/collect`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|itemIdList|是|List| itemIds|
|companyId|否|String| companyId|
|replaceSysNo|否|String| 用于支持点单商城访问会员商城接口|
|isCollect|是|Boolean| 是否收藏|

### 请求参数Json格式
 
```
{
 "itemIdList" : null,
 "companyId" : "String",
 "replaceSysNo" : "String",
 "isCollect" : true
}
```
