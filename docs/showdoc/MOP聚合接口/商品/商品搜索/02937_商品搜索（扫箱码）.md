# 商品搜索（扫箱码）
 

**请求URL：** 
- `/product/rpc/productSearch/search `

**请求方式：**
- ALL
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 商户ID，品牌中台访问时，需要传此参数|
|filterType|否|String| 过滤类型 WhsIn - 入库；WhsOut - 出库；Order - 下单；Refund - 退货；Allot - 调拨；Need - 要货 CheckVouch - 盘点；Inventory - 存货；B2BOrder - 订货单；B2BRefund - 订货退货单；GoodsIn - 采购单（进货单）|
|isActive|否|Integer| 活跃状态 1 - 活跃, 0 - 不活跃|
|orderId|否|String| 单据id|
|orderItemId|否|String| 单据明细行id|
|sword|否|String||
|tokenId|否|String||
|id|否|String||

|orderSort|否|String| 排序方式|

|----itemName|否|String||

|--pageIndex|否|Integer||
|--pageSize|否|Integer||

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|mitemBarcodeResult|否|Object| 商品条码返回信息|
|--barcode|否|String| 搜索条码|
|--attachBarcode|否|String| 唯一码附加码|
|--skuBarcode|否|String| sku码|
|--isUniqueBarcode|否|Integer| 该搜索关键字是否是唯一码条码 1 - 是, 0 - 否|
|--isBoxBarcode|否|Integer| 该搜索关键字是否是箱码 1 - 是, 0 - 否|
|barcodeSearchRuleResult|否|Object| 自定义规则搜索码返回结果|
|--skuBarcode|否|String| sku码|
|--ruleType|否|Integer| 规则类型 1 - 搜索码, 2 - 重量码, 3 - 金额码|
|--quantity|否|Double| 数量|
|firstBaseMitemResult|否|Object| 首个商品信息,当搜索结果只有一个时才返回|
|baseMitemResults|否|Object| 搜索结果|
|--pageIndex|否|Integer| 页码|
|--pageSize|否|Integer| 显示记录数|
|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|--first|否|Boolean| 首页|
|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|
