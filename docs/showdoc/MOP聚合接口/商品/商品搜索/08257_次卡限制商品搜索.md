# 次卡限制商品搜索

**请求URL：** 
- `/product/itemSearch/retail/itemCard/item`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|sword|否|String| 搜索条件|
|cardId|是|String| 实体卡卡id|
|companyId|是|String| 实体卡卡id|
|pageIndex|否|Integer||
|pageSize|否|Integer||
|orderField|否|String||
|orderSort|否|String||

### 请求参数Json格式
 
```
{
 "sword" : "String",
 "cardId" : "String",
 "companyId" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String"
}
```
