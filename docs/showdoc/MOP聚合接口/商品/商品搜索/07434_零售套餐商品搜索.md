# 零售套餐商品搜索

**请求URL：** 
- 服务：`product-front`
- `/product/itemSearch/retail/combo/item `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|sword|否|String| 搜索条件|
|attributesList|否|List| 商品行业属性|
|--code|否|Integer||
|--name|否|String||
|--value|否|String||
|--valueType|否|Integer||
|--itemId|否|String||
|brandCode|否|List| 品牌|
|itemTypefCodes|否|List| 商品全分类编码|
|orgins|否|List| 系列|
|preferredSupplierNames|否|List| 首选供应商|
|seriesCode|否|List| 系列|
|startDate|否|DateTime| 创建时间 开始|
|endDate|否|DateTime| 创建时间 结束|
|pageIndex|否|Integer||
|pageSize|否|Integer||
|orderField|否|String||
|orderSort|否|String||

###请求参数Json格式
 
```
{
 "sword" : "String",
 "attributesList" : [{
 "code" : 0,
 "name" : "String",
 "value" : "String",
 "valueType" : 0,
 "itemId" : "String"
 }],
 "brandCode" : null,
 "itemTypefCodes" : null,
 "orgins" : null,
 "preferredSupplierNames" : null,
 "seriesCode" : null,
 "startDate" : "DateTime",
 "endDate" : "DateTime",
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--pageIndex|否|Integer||
|--pageSize|否|Integer||
|--pageCount|否|Integer||
|--totalCount|否|Long||
|--first|否|Boolean||
|--last|否|Boolean||
|--content|否|List||
|----itemId|否|String| 商品id|
|----itemCode|否|String| 商品编码|
|----itemName|否|String| 商品名称|
|----specId|否|String| 规格id|
|----skuBarcode|否|String| sku|
|----specName|否|String| 规格名称|
|----unit|否|String| 单位|
|----isMutiSpec|否|Integer| 是否多规格 1是 0否 默认否|
|----description|否|String| 规格说明|
|----colourId|否|String| 规格一|
|----colourName|否|String| 规格一名称|
|----sizeId|否|String| 规格二|
|----sizeName|否|String| 规格二名称|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
