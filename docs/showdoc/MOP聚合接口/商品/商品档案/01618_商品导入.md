# 商品导入
 

**请求URL：** 
- `/file/mItem/import `

**请求方式：**
- POST
- FormData


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|file|是|steam| 导入文件(流)|
|companyIds|否|String| 商户id(逗号分隔)|
|specType|是|Number| 导入类型 1 - 多规格, 0 - 单规格|
|optType|是|Number| 导入操作类型 1 - 新增并更新，2 - 仅更新|

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--totalCount|否|Long| 总数|
|--successCount|否|Long| 成功数|
|--errorCount|否|Long| 失败数|
|--fileUrl|否|String| 导出文件相对路径|
|--downloadURL|否|String| 导出文件下载路径|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : {
 "totalCount" : 0,
 "successCount" : 0,
 "errorCount" : 0,
 "fileUrl" : "String",
 "downloadURL" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
