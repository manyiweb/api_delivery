# 商品详情库存信息
 

**请求URL：** 
- `/product/b2b/getInvQtyData`

**请求方式：**
- undefined
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|否|String| tokenId|
|specId|否|String| 商品id|
|filterType|否|String| 筛选类型|
|groupId|否|String| 品牌id|
|companyId|否|String| 门店iD|
|barcode|否|String| 唯一码|
|addressId|否|String| 地址|
|seckillId|否|Long| 秒杀活动id|
|isOffline|否|Boolean| 是否离线购物车|

### 请求参数Json格式
 
```
{
 "tokenId" : "String",
 "specId" : "String",
 "filterType" : "String",
 "groupId" : "String",
 "companyId" : "String",
 "barcode" : "String",
 "addressId" : "String",
 "seckillId" : 0,
 "isOffline" : true
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--invQtyMap|否|Map| 发货仓库存数|
|--companyInvQty|否|Map| 门店库存数|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "invQtyMap" : null,
 "companyInvQty" : null
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
