# 获取商品简单信息
 

**请求URL：** 
- `/product/mitem/detail/simple `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|itemId|是|String| 商品id|

###请求参数Json格式
 
```
{
 "itemId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--itemId|否|String| 商品id|
|--itemCode|否|String| 商品编码|
|--itemName|否|String| 商品名称|
|--isActive|否|Integer| 活跃状态 1 - 启用, 0 - 停用|
|--createName|否|String| 创建人|
|--creatorName|否|String| 创建人|
|--createDate|否|DateTime| 创建时间|
|msg|否|String| 消息|
|code|否|String| 业务代码|


###返回参数Json格式
 
```
{
 "data" : {
 "itemId" : "String",
 "itemCode" : "String",
 "itemName" : "String",
 "isActive" : 0,
 "createName" : "String",
 "creatorName" : "String",
 "createDate" : "DateTime"
 },
 "msg" : "String",
 "code" : "String"
}
```
