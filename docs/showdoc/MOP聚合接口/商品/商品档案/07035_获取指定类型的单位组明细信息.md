# 获取指定类型的单位组明细信息

**请求URL：** 
- `/product/unit_group/type/get_details`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long| 单位组id|
|itemId|是|String| 商品id|
|type|是|String| 类型 check_vouch:盘点|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "itemId" : "String",
 "type" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--id|否|Long||
|--unitId|否|String||
|--unitName|否|String||
|--num|否|Double||
|--lineNum|否|Long||
|--mid|否|Long||
|--baseUnitId|否|String||
|--baseUnitName|否|String||
|--itemId|否|String||
|--dbKey|否|Integer||
|--groupId|否|String||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "id" : 0,
 "unitId" : "String",
 "unitName" : "String",
 "num" : 0,
 "lineNum" : 0,
 "mid" : 0,
 "baseUnitId" : "String",
 "baseUnitName" : "String",
 "itemId" : "String",
 "dbKey" : 0,
 "groupId" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
