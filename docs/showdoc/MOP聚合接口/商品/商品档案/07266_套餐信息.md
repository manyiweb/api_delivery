# 套餐信息
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|packageItems |否|List||
|--id|否|Long| 主键|
|--itemId|否|String| 商品id|
|--groupName|是|String| 分组名称|
|--groupType|是|Integer| 分组类型 1固定类型 2可选搭配 3任选搭配|
|--itemMinBreed|否|Integer| 商品最小品种数|
|--itemMaxBreed|否|Integer| 商品最大品种数|
|--cannotSelectTheSameProduct|否|Boolean| 不能选择相同商品 true是 false否|
|--retailComboGroupItems|是|List| 零售套餐组商品|
|----id|否|Long| 主键|
|----retailComboGroupId|否|Long| 零售套餐组id，与表retail_combo_group关联|
|----itemId|否|String| 商品id，与表mitem关联|
|----itemCode|否|String| 商品编码|
|----itemName|否|String| 商品编码|
|----specId|否|String| 规格id，与表mitemspec关联|
|----skuBarcode|否|String| sku|
|----quantity|否|Double| 数量|
|----unit|否|String| 单位|
|----salePrice|否|Double| 参考零售价|
|----comboExecutionUnitPrice|否|Double| 套餐执行单价|
|----markUp|否|Double| 加价|
|----reduceThePrice|否|Double| 减价|
|----imgUrl|否|String| 商品图片|
|----specName|否|String| 规格名称|
|----itemLabelGroups|否|List||
|------id|否|Long| 主键标识|
|------labelGroupCode|否|String| 标签组编码|
|------labelGroupName|否|String| 标签组名称|
|------lineNum|否|Long| 行号|
|------status|否|Integer| 活跃状态(0-停用,1-启用)|
|------isMultiple|否|Integer| 是否允许多选(0-单选;1-多选)|
|------mustSelect|否|Boolean| 是否必选|
|------labelGroups|否|List| 点单标签|
|--------fid|否|String| id|
|--------version|否|Integer| 版本|
|--------labelCode|否|String| 标签编码|
|--------labelName|否|String| 标签名称|
|--------labelPrice|否|Double| 标签零售价|
|--------isLabelPrice|否|Integer| 是否开启标签零售价|
|--------isAllShop|否|Integer| 是否所有商品|
|--------lineNum|否|Integer| 行号|
|--------isActive|否|Integer| 是否启用|
|--------isDefault|否|Integer| 是否标签组默认标签|
|--------enableChangeFactor|否|Boolean| 是否允许变动数量|
|--------maxFactor|否|Double| 最多添加数量|
