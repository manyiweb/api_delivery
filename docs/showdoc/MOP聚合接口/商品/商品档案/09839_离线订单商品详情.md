# 商品详情
 

**请求URL：** 
- `/product/b2b/getProductOfflineData`

**请求方式：**
- undefined
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|否|String| tokenId|
|specId|否|String| 商品id|
|filterType|否|String| 筛选类型|
|groupId|否|String| 品牌id|
|companyId|否|String| 门店iD|
|barcode|否|String| 唯一码|
|addressId|否|String| 地址|
|seckillId|否|Long| 秒杀活动id|
|isOffline|否|Boolean| 是否离线购物车|
