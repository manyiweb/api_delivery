# 拉新渠道码导出
 

**请求URL：** 
- `http://fat-mgr.reabam.com:58090/api/taskcenter-server/task/instance/run`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
 |参数|类型|描述|
|:-------|:-------|:-------|
| appId | number| 取值：100011 |
| taskId | number| 取值：290159 |
| taskInstanceParam |object | 请求参数 |
| -- boolAllCompany|Boolean|是否所有门店，取值：true/false |
| -- companyIds|List|门店id列表 |
| -- platformTypes|List|小程序类型，取值：0 - 会员端（商城版）, 1- 会员端（点单版）|
| tokenId | string| 无 |


### 请求参数Json格式
 
```
{
 "appId": 100011,
 "taskId": 290158,
 "taskInstanceParam": {
	 "boolAllCompany" : false,
	 "companyIds" : [],
	 "platformTypes" : []
 },
 "tokenId": "0875ed34882149f09d95b154e064eda4"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--taskInstanceId|否|Long| 任务实例ID|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data": {
 "taskInstanceId": 3186628,
 "isTask": 1
 },
 "msg": null,
 "code": "200",
 "success": true
}
```
