# 内部购物卡充值请求
 

**请求URL：** 
- `/retail/app/Business/Member/CardTopUp/internalChannel`

**请求方式：**
- undefined
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|memberId|是|String| 会员id|
|companyId|是|String| 门店id|
|coId|否|String| 充值项id，没有不传|
|cardType|否|String| 充值类型 ShoppingCard：购物卡， EntityCard：实体卡 不传默认购物卡|
|rechargeAmount|否|Double| 充值余额|
|giftAmount|否|Double| 赠送余额|
|payType|是|String| 支付编码|
|remark|是|String| 备注|
|cardId|否|String||

### 请求参数Json格式
 
```
{
 "memberId" : "String",
 "companyId" : "String",
 "coId" : "String",
 "cardType" : "String",
 "rechargeAmount" : 0,
 "giftAmount" : 0,
 "payType" : "String",
 "remark" : "String",
 "cardId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
