# 小程序-获取签到活动信息（含奖励规则）

**请求URL：** 
- `/activity/signin/member/info`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||
|sword|否|String||

### 请求参数Json格式
 
```
{
 "id" : 0,
 "sword" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long| 活动id|
|--activityName|否|String| 活动名称|
|--activityRule|否|String| 规则说明|
|--cycleType|否|Integer| 签到周期 0=不限制 1=自然周 2=自然月 3=自然年|
|--checkInRequirement|否|Integer| 签到要求 0=连续签到 1=累计签到|
|--rewardGrantType|否|Integer| 奖励发放规则 0=只发一次 1=循环发放|
|--validityType|否|Integer| 有效期类型 0=长期有效 1=固定有效期|
|--beginDate|否|DateTime| 有效期开始|
|--endDate|否|DateTime| 有效期结束|
|--pageTitle|否|String| 页面标题|
|--topBgImg|否|String| 顶部背景图|
|--bottomBgColor|否|String| 底部背景色|
|--showMyPoint|否|Boolean| 是否显示我的积分|
|--showMyGrowth|否|Boolean| 是否显示我的成长值|
|--showMyCoupon|否|Boolean| 是否显示我的优惠券|
|--enableShare|否|Boolean| 是否允许分享|
|--shareTitle|否|String| 分享标题|
|--shareImg|否|String| 分享图片|
|--rewardList|否|List| 签到奖励规则列表|
|----requiredDays|是|Integer| 连续/累计签到天数|
|----enableRewardPoint|否|Boolean| 是否开启奖励积分|
|----rewardPoint|否|Integer| 奖励积分|
|----enableRewardGrowth|否|Boolean| 是否开启奖励成长值|
|----rewardGrowth|否|Integer| 奖励成长值|
|----enableRewardCoupon|否|Boolean| 是否开启奖励优惠券|
|----rewardImg|否|String| 奖励图片|
|----couponList|否|List| 奖励优惠券列表|
|------couponId|是|String| 优惠券id|
|------couponCode|否|String| 优惠券编码|
|------couponName|是|String| 优惠券名称|
|------couponNum|是|Integer| 发放数量|
|--memberSigninInfo|否|Object| 会员签到信息|
|----totalDays|否|Integer| 累计签到天数|
|----continuousDays|否|Integer| 连续签到天数|
|----todaySigned|否|Boolean| 今日是否已签到|
|----lastSigninDate|否|DateTime| 最后签到日期|
|--memberRightsInfo|否|Object| 会员权益信息|
|----integral|否|Double| 积分|
|----growth|否|Double| 成长值|
|----couponNum|否|Long| 优惠券数量|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
