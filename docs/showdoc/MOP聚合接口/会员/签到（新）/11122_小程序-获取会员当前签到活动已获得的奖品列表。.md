# 小程序-获取会员当前签到活动已获得的奖品列表。


**请求URL：** 
- `/activity/signin/member/reward/list`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|activityId|否|Long| 活动ID|
|pageIndex|否|Integer||
|pageSize|否|Integer||
|orderField|否|String||
|orderSort|否|String||

### 请求参数Json格式
 
```
{
 "activityId" : 0,
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--pageIndex|否|Integer||
|--pageSize|否|Integer||
|--pageCount|否|Integer||
|--totalCount|否|Long||
|--first|否|Boolean||
|--last|否|Boolean||
|--content|否|List||
|----id|否|Long| 主键|
|----activityId|否|Long| 活动id|
|----memberId|否|String| 会员id|
|----prizeType|否|Integer| 奖品类型 0积分 1成长值 2优惠券|
|----prizeName|否|String| 奖品名称|
|----prizeNum|否|Integer| 奖品数量|
|----getDate|否|DateTime| 领取时间|
|----dbKey|否|Integer||
|----groupId|否|String||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "pageIndex" : 0,
 "pageSize" : 0,
 "pageCount" : 0,
 "totalCount" : 0,
 "first" : true,
 "last" : true,
 "content" : [{
 "id" : 0,
 "activityId" : 0,
 "memberId" : "String",
 "prizeType" : 0,
 "prizeName" : "String",
 "prizeNum" : 0,
 "getDate" : "DateTime",
 "dbKey" : 0,
 "groupId" : "String"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
