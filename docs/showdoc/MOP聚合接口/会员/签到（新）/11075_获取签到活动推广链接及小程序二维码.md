# 获取签到活动推广链接及小程序二维码

**请求URL：** 
- `/activity/signin/qrcode`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|appId|否|String| 小程序appId，不传则取品牌默认点单小程序|
|id|是|Long||

### 请求参数Json格式
 
```
{
 "appId" : "String",
 "id" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--path|否|String| 小程序页面路径|
|--qrcodeUrl|否|String| 二维码图片链接|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "path" : "String",
 "qrcodeUrl" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
