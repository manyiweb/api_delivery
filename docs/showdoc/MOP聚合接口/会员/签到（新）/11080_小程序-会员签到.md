# 小程序-会员签到

**请求URL：** 
- `/activity/signin/member/signin`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|activityId|否|Long| 活动ID|

### 请求参数Json格式
 
```
{
 "activityId" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--success|否|Boolean| 是否签到成功|
|--message|否|String| 提示信息|
|--totalDays|否|Integer| 累计签到天数|
|--continuousDays|否|Integer| 当前连续签到天数|
|--rewardPoint|否|Integer| 本次获得积分|
|--rewardGrowth|否|Integer| 本次获得成长值|
|--couponList|否|List| 本次获得的优惠券列表|
|----couponId|否|String| 优惠券id|
|----couponCode|否|String| 优惠券编码|
|----couponName|否|String| 优惠券名称|
|----couponNum|否|Integer| 发放数量|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "success" : true,
 "message" : "String",
 "totalDays" : 0,
 "continuousDays" : 0,
 "rewardPoint" : 0,
 "rewardGrowth" : 0,
 "couponList" : [{
 "couponId" : "String",
 "couponCode" : "String",
 "couponName" : "String",
 "couponNum" : 0
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
