# 查询指定月份已签到的天数

**请求URL：** 
- `/activity/signin/month/days`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|activityId|否|Long| 活动ID|
|month|否|Integer| 月份（1-12）|
|year|否|Integer| 年份（可选，默认当前年份）|

### 请求参数Json格式
 
```
{
 "activityId" : 0,
 "month" : 0,
 "year" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--signinDays|否|List| 已签到的日期列表（天数，1-31）|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "signinDays" : null
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
