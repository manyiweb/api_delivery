# 查询订单消费返券信息
 用于小程序订单详情页面展示，支持前端轮询查询
 由于返券活动是异步处理的，前端需要轮询此接口获取最新的返券结果
 

**请求URL：** 
- `/activity/coupon/back/order/coupon`

**请求方式：**
- POST
- RequestBody
