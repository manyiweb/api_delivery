# 新增 保存活动
 

**请求URL：** 
- `/activity/coupon/back/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|
|activityName|是|String| 活动名称|
|startDate|是|DateTime| 开始时间|
|endDate|是|DateTime| 结束时间|
|cycleType|否|Integer| 0：每日 1：每周 2：每月|
|days|否|String| 日期, 1,2,3,4,5|
|timeType|否|Integer| 时间类型 0:全天 1:自定义|
|timeRange|否|String| 时间区间数组|
|couponId|是|String| 参与用券id|
|isActive|否|Integer| 活跃状态 0 1|
|isAllComp|否|Integer| 应用门店 0所有 1指定|
|rule|否|String| 活动规则|
|restrictionType|否|Integer| 限制类型 0：不限制次数 1：限制次数 2：限制次数的参与周期|
|frequency|否|Integer| 领取次数|
|cycleDay|否|Integer| 多少天可再领取|
|couponList|否|List| 优惠券集合|
|--couponId|否|String| 优惠券id|
|--coupnsCode|否|String| 券编码|
|--couponName|否|String| 券名称|
|--quantity|否|Integer| 券名称|
|companyIds|否|List| 优惠券id|
