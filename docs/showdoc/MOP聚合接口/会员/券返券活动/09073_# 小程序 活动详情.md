# 小程序 活动详情
 

**请求URL：** 
- `/activity/appc/coupon/back/detail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||
|pageIndex|否|Integer||
|pageSize|否|Integer||
|orderField|否|String||
|orderSort|否|String||
|sword|否|String||

### 请求参数Json格式
 
```
{
 "id" : 0,
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String",
 "sword" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long||
|--activityNo|否|String| 活动编码|
|--activityName|否|String| 活动名称|
|--couponId|否|String| 优惠券id|
|--couponName|否|String| 优惠券名称|
|--startDate|否|DateTime| 开始时间|
|--endDate|否|DateTime| 结束时间|
|--isActive|否|Integer| 活跃状态 0 1|
|--isAllComp|否|Integer| 应用门店 0所有 1指定|
|--rule|否|String| 活动规则|
|--createId|否|String||
|--createName|否|String||
|--createDate|否|DateTime||
|--modifyId|否|String||
|--modifyName|否|String||
|--modifyDate|否|DateTime||
|--dbKey|否|Integer||
|--groupId|否|String||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
