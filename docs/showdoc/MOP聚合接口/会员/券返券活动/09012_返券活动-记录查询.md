# 返券活动-记录查询
 datatableId:coupon_back_record_list

服务activity
datatable服务 http://fat-mgr.reabam.com:58090/api///config/datatable/user/definition/getDatatableDefinition/reabam-activity
**请求URL：** 
- `/activity/coupon/back/record/list/{source}`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|keyword|否|String| 关键词(模糊搜索)|
|couponName|否|List| 搜索优惠券/券包编码、名称|
|giveDate|否|Object| 返券时间|
|--start|否|DateTime||
|--end|否|DateTime||
|id|否|String||
|pageSize|否|Integer||
|pageNo|否|Integer||
|sortField|否|String||
|sortDirection|否|String||
|viewId|否|String||
