# 活动详情
 

**请求URL：** 
- `/activity/coupon/back/detail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||
|pageIndex|否|Integer||
|pageSize|否|Integer||
|orderField|否|String||
|orderSort|否|String||
|sword|否|String||

### 请求参数Json格式
 
```
{
 "id" : 0,
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String",
 "sword" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long| id|
|--activityName|否|String| 活动名称|
|--activityNo|否|String| 活动名称|
|--startDate|否|DateTime| 开始时间|
|--endDate|否|DateTime| 结束时间|
|--activityType|否|String| 活动类型 coupon(优惠券)|
|--isActive|否|Integer| 活跃状态 0 1|
|--statusDesc|否|String| 活动状态描述|
|--couponId|否|String| 参与券id|
|--couponName|否|String| 参与券名称|
|--isAllComp|否|Integer| 应用门店 0所有 1指定|
|--couponList|否|List| 优惠券列表|
|----couponId|否|String| 优惠券id|
|----coupnsCode|否|String| 券编码|
|----couponName|否|String| 券名称|
|----quantity|否|Integer| 券名称|
|--companyList|否|List| 门店列表|
|----companyId|否|String| 门店id|
|----companyCode|否|String| 商户编码|
|----companyName|否|String| 商户名称|
|--errorMsg|否|String| 不可用原因|
|--createId|否|String||
|--createName|否|String||
|--createDate|否|DateTime||
|--modifyId|否|String||
|--modifyName|否|String||
|--modifyDate|否|DateTime||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
