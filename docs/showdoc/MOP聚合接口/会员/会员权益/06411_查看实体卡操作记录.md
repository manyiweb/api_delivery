# 查看实体卡操作记录
 

**请求URL：** 
- `/mem/card/operation/list`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|cardId|是|String| 实体卡Id|
|updateType|否|String| 卡号查询方式 0全部 1按规则 2 导入|
|operationType|是|String| add("追加"),
 * price("修改售价"),
 * date("修改有效期"),
 * balance("修改余额"),
 * delete("删除"),
 * write("写卡"),
 * untie("解绑"),

 * updateStatus("修改活跃状态")|
|startDate|否|DateTime| 开始日期|
|endDate|否|DateTime| 结束日期|
|addType|否|String| 	auto("追加"), importCard("导入");|

|----isSelect|否|String||
|--current|否|Object||
|----itemName|否|String||
