# 实体卡手动输入校验
 

**请求URL：** 
- `/mem/manual/input/cardno`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|fid|是|String| 实体卡id|
|cardList|是|List| 卡信息|
|--cardNo|是|String| 会员id|
|--password|是|String| 实体卡id(服务卡、购物卡操作时可不传)|

### 请求参数Json格式
 
```
{
 "fid" : "String",
 "cardList" : [{
 "cardNo" : "String",
 "password" : "String"
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--cardNo|否|String| 会员id|
|--errMsg|否|String| 实体卡id(服务卡、购物卡操作时可不传)|
|--status|否|Integer| 成功状态 0 1|
|--statusName|否|String| 是否成功|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "cardNo" : "String",
 "errMsg" : "String",
 "status" : 0,
 "statusName" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
