# 卡券退货 卡号列表
 

**请求URL：** 
- `/mem/super/card/refund/cardList`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 主键id|
|keyword|否|String||
|pageIndex|否|Integer||
|pageSize|否|Integer||
|orderField|否|String||
|orderSort|否|String||

### 请求参数Json格式
 
```
{
 "id" : 0,
 "keyword" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--pageIndex|否|Integer| 页码|
|--pageSize|否|Integer| 显示记录数|
|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|--first|否|Boolean| 首页|
|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|
|----id|否|Long| 主键id|
|----applyId|否|Long| 账单id|
|----cardId|否|String||
|----cardName|否|String| 卡券名称|
|----cardNo|否|String| 卡券编号|
|----type|否|Integer| 类型 1销售 2 退货|
|----status|否|Integer||
|----denomination|否|Double| 面额|
|----balance|否|Double| 余额|
|----minUse|否|Double| 最低使用金额|
|----salesAdvice|否|Double| 建议售价|
|----startData|否|DateTime| 开始日期|
|----endData|否|DateTime| 结束日期|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
