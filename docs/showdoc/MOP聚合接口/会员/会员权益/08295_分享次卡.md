# 分享次卡

**请求URL：** 
- `/mem/entitycard/share/add`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|memberId|是|String| 共享会员id|
|toMemberPhone|是|String| 被共享会员手机号|
|shareType|是|String| 共享方式 all全部共享,part指定部分共享|
|partCardId|否|List| 新换的实体卡券号|

### 请求参数Json格式
 
```
{
 "memberId" : "String",
 "toMemberPhone" : "String",
 "shareType" : "String",
 "partCardId" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--fid|否|String| 门店id|
|--companyName|否|String| 门店名称|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "fid" : "String",
 "companyName" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
