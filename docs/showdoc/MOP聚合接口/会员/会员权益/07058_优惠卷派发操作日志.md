# 优惠卷派发操作日志

**请求URL：** 
- `/mem/coupon/hanle/log`
- `服务`-member
**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|couponId|是|String| 优惠券id|
|pageIndex|否|Integer||
|pageSize|否|Integer||
|tokenId|否|String||
### 请求参数Json格式
 
```
{
 "couponId" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "tokenId":""
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--pageIndex|否|Integer||
|--pageSize|否|Integer||
|--pageCount|否|Integer||
|--totalCount|否|Long||
|--first|否|Boolean||
|--last|否|Boolean||
|--content|否|List||
|----handler|否|String| 操作人|
|----handleTime|否|DateTime| 操作时间|
|----status|否|Integer| 操作状态 1-执行中 2-已完成|
|----statusName|否|String| 操作状态中文 执行中，已完成|
|----handleDetailUrl|否|String| 操作明细|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "pageIndex" : 0,
 "pageSize" : 0,
 "pageCount" : 0,
 "totalCount" : 0,
 "first" : true,
 "last" : true,
 "content" : [{
 "handler" : "String",
 "handleTime" : "DateTime",
 "status" : 0,
 "statusName" : "String",
 "handleDetailUrl" : "String"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
