# *
 优惠券二维码
 

**请求URL：** 
- `/file/export/coupon/qrcode `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|couponId|否|String| 优惠券ID|
|wxSn|否|String| 微信标识|
|isHyaline|否|Integer| 是否需要透明底色，为1时生成透明底色的二维码|

###请求参数Json格式
 
```
{
 "couponId" : "String",
 "wxSn" : "String",
 "isHyaline" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--url|否|String| 二维码地址|
|--randomCode|否|String| 随机码(优惠券码)|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : {
 "url" : "String",
 "randomCode" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
