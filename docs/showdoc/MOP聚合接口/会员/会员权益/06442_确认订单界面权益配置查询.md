# 确认订单界面权益配置查询

**请求URL：** 
- `/config/mall/order/confirm/get`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
无参数


### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--payMemberEnable|否|Boolean|是否启用付费会员 |
|--backgroundUrl|否|String||
|--activityExplain|否|String|活动说明 |
|--showBenefitExplain|否|Boolean|显示权益说明入口 |
|--memberBenefitSalesId|否|Long|关联权益有效期id |
|--memberBenefitSalesCode|否|String|关联权益有效期编码 |
|--showBenefitActivityPrice|否|Boolean|显示权益卡划线价 |
|--buttonWord|否|String|按钮文案 |
|--buttonColor|否|String|按钮颜色 |
|--buyProcess|否|String|购买流程 pay("直接支付"), choose("先选权益再支付");|
|--showUploadFlag|否|Boolean| 是否显示上传附件入口|
|--uploadTips|否|String| 上传附件提示文案|
|--showOtherRemarkFlag|否|Boolean| 是否启用其他备注|
|--otherRemarkName|否|String| 其他备注别名|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||

```
 "buyProcess" : "String",
 "showUploadFlag" : true,
 "uploadTips" : "String",
 "showOtherRemarkFlag" : true,
 "otherRemarkName" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
