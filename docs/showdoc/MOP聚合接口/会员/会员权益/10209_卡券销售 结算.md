# 结算
 

**请求URL：** 
- `/mem/super/card/settle`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long| 代发订单标识|
|status|是|Boolean| 受理状态 YA受理 YR拒绝受理|
|payType|是|String| 支付方式编码|
|payTypeName|否|String| 支付方式名称|
|imgUrl|否|String| 附件|
|settleDate|否|DateTime| 结算时间|
|remark|否|String| 备注|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "status" : true,
 "payType" : "String",
 "payTypeName" : "String",
 "imgUrl" : "String",
 "settleDate" : "DateTime",
 "remark" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
