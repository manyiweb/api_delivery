# 修改非统一售价实体卡券 日期、售价
 

**请求URL：** 
- `/mem/updateMentityCards`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|updateCard|否|List| 规则
 |
|--updateRule|否|Object| 规则
 |
|----cardId|是|String| 实体卡Id|
|----left|否|String| 前缀|
|----startCode|否|String| 起始流水号|
|----centerNum|否|String| 流水号位数|
|----endCode|否|String| 结束流水号|
|----num|否|Long| 数量|
|----flagId|否|String| 标志id|
|----needNotSale|否|Boolean| 标志id|
|----ruleType|否|String| 规则方式 1为旧规则startCode那种 2为新规则leftCardNo这种 默认1 3 只有起始号和结束号（startCode endCode）|
|----leftCardNo|否|String| 新规则查询方式 卡号字符前缀|
|----rightCardNo|否|String| 新规则 卡号字符后缀|
|----centerCardNoStart|否|String| 新规则 卡号中间起始流水号|
|----centerCardNoEnd|否|String| 新规则 卡号中间结束流水号|
|----operationType|否|String| add("追加"), price("修改售价/面额"), date("修改有效期"),balance(余额)，delete(删除）|
|----superMemberId|否|String| add("追加"), price("修改售价/面额"), date("修改有效期"),balance(余额)，delete(删除）|
|----cardSuperSalesApplyId|否|String| 卡券销售id|
|----cardType|否|String| 充值卡类型 EntityCard实体卡 ShoppingCard 购物车|
|----updateType|否|String| 充值卡类型 EntityCard实体卡 ShoppingCard 购物车|
|----sword|否|String||
|----tokenId|否|String||
|----id|否|String||
|----orderField|否|String||
|----orderSort|否|String||
|----searchBeans|否|List||
|------typeCode|否|String||
|------typeName|否|String||
|------dataType|否|String||
|------isSingle|否|String||
|------isLikeSearch|否|String||
|------items|否|List||
|--------itemName|否|String||
|--------itemValue|否|String||
|--------minValue|否|String||
|--------maxValue|否|String||
|--------isCustom|否|String||
|--------isRange|否|String||
|--------isSelect|否|String||
|------current|否|Object||
|--------itemName|否|String||
|--------itemValue|否|String||
|--------minValue|否|String||
|--------maxValue|否|String||
|--------isCustom|否|String||
|--------isRange|否|String||
|--------isSelect|否|String||
|------sword|否|String||
|------pageIndex|否|Integer||
|------pageSize|否|Integer||
|------curPageNum|否|Integer||
|------totalPage|否|Integer||
|------totalCount|否|Integer||
|----status|否|Integer||
|----pageIndex|否|Integer||
|----pageSize|否|Integer||
|----orderField|否|String||
|----orderSort|否|String||
|--flagId|否|String| 规则|
|--cardId|是|String| 实体卡Id|
|--updateType|是|String| 卡号查询方式 0全部 1按规则 2 导入 3手动输入|
|--startDate|否|DateTime| 有效期从|
|--endDate|否|DateTime| 有效期止|
|--denomination|否|Double| 建议面额|
|--salesAdvice|否|Double| 建议售价|
|--operationType|是|String| add("追加"), price("修改售价/面额"), date("修改有效期"),balance(余额)，delete(删除）,untie(解绑）|
|--rechargeBalance|否|Double| 充值余额|
|--giftBalance|否|Double| 赠送余额|
|--cardNos|否|List| 删除输入的卡号
 |
|--reason|否|String| 原因|
