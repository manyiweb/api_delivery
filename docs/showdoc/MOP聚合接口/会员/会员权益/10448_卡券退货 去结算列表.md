# 卡券退货 去结算列表
 

**请求URL：** 
- `/mem/super/card/refund/toSettle/list`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 主键id|
|keyword|否|String||
|companyIds|否|List| 门店列表|
|pageIndex|否|Integer||
|pageSize|否|Integer||
|orderField|否|String||
|orderSort|否|String||

### 请求参数Json格式
 
```
{
 "id" : 0,
 "keyword" : "String",
 "companyIds" : null,
 "pageIndex" : 0,
 "pageSize" : 0,

}
```
