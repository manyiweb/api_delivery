# 新建卡券销售,(草稿重新申请也是这个接口 传id）
 

**请求URL：** 
- `/mem/super/card/apply`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 主键id|
|applyTypeCode|是|String| 单据类型|
|applyTypeName|否|String| 单据类型名称|
|status|否|String| 单据状态|
|statusName|否|String| 单据状态描述|
|settleStatus|否|Integer| 结算状态|
|companyId|是|String| 门店id|
|companyCode|否|String| 商户编码|
|companyName|否|String| 商户名称|
|superMemberId|是|String| 企业会员id|
|superMemberName|否|String| 企业会员名称|
|superMemberPhone|否|String| 企业会员名称|
|cardCode|否|String| 卡券编号|
|cardType|否|String| 卡券类型|
|cardName|否|String| 卡券名称|
|mid|是|String| 卡券档案id|
|cardNum|否|Long| 卡号数量|
|remark|否|String| 备注|
|cardAddType|否|Integer| 生成卡类型 1按规则 2 导入|
|isDraft|否|Boolean| 是否草稿|
|flagId|否|String| 导入标志id|
|addRule|否|Object| 卡号规则|
|--left|否|String| 前缀|
|--centerNum|否|Long| 流水位数|
|--center|否|Long| 起始流水号|
|--rightNum|否|Long| 随机位数|
|--validationPasswordSet|否|Integer| 密码设置 为0时 随机码位数 为1时密码|
|--passwordValue|否|String| 密码|
|--denomination|否|Double| 面额|
|--minUse|否|Double| 最低限额|
|--startDate|否|DateTime| 开始日期|
|--endDate|否|DateTime| 结束日期|
|--quantity|否|Long| 数量|
|--salesAdvice|否|Double| 售价|
|--isMinUse|否|String| 是否最低限额|
