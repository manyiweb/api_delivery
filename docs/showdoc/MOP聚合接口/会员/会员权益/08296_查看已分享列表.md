# 查看已分享列表

**请求URL：** 
- `/mem/entitycard/share/list`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|memberId|是|String| 共享会员id|
|pageIndex|否|Integer||
|pageSize|否|Integer||
|orderField|否|String||
|orderSort|否|String||

### 请求参数Json格式
 
```
{
 "memberId" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--pageIndex|否|Integer||
|--pageSize|否|Integer||
|--pageCount|否|Integer||
|--totalCount|否|Long||
|--first|否|Boolean||
|--last|否|Boolean||
|--content|否|List||
	|--id|否|Long| 主键标识|
	|--shareMemberId|否|String| 共享会员id|
	|--shareMemberName|否|String| 共享会员名称|
	|--shareToMemberId|否|String| 被共享会员id|
	|--shareToMemberPhone|否|String| 被共享会员手机号|
	|--shareToMemberName|否|String| 被共享会员名称|
	|--shareType|否|String| 共享方式 all全部共享,part指定部分共享|
	|--status|否|String| 共享状态 Y N|
	|--createId|否|String||
	|--createName|否|String||
	|--createDate|否|DateTime||
	|--modifyId|否|String||
	|--modifyName|否|String||
	|--modifyDate|否|DateTime||
	|--dbKey|否|Integer||
	|--groupId|否|String||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "pageIndex" : 0,
 "pageSize" : 0,
 "pageCount" : 0,
 "totalCount" : 0,
 "first" : true,
 "last" : true,
 "content" : null
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
