# 次卡使用流水
 

**请求URL：** 
- `/mem/timesCard/comsume/detail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
无参数


### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|pageIndex|否|Integer||
|pageSize|否|Integer||
|pageCount|否|Integer||
|totalCount|否|Long||
|first|否|Boolean||
|last|否|Boolean||
|content|否|List||
	--cardId|否|String| 储值卡标识|
	|--cardNo|否|String| 储值卡名称|
	|--money|否|Double| 消费金额|
	|--balance|否|Double| 余额|
	|--orderId|否|String| 订单标识|
	|--orderNo|否|String| 订单编码|
	|--memberId|否|String| 会员标识|
	|--memberName|否|String| 会员名称|
	|--createId|否|String| 创建人ID|
	|--createName|否|String| 创建人名称|
	|--createDate|否|DateTime| 创建时间|
	|--remark|否|String| 备注（系统生成）|
	|--manualRemark|否|String| 手工备注|
	|--companyId|否|String| 门店商户ID，与商户表syscompany相关联|
	|--typeCode|否|String| 储值卡类型 ShoppingCard 购物卡 ServiceCard 服务卡|
	|--typeName|否|String| 储值卡类型名称|
	|--docType|否|String| 消费类型 decrease减少 add增加|
	|--rechargeMoney|否|Double| 消费充值金额|
	|--giftMoney|否|Double| 消费赠送金额|
	|--rechargeBalance|否|Double| 充值余额|
	|--giftBalance|否|Double| 赠送余额|
	|--rechargeCoefficient|否|Double| 充值系数|
	|--giftCoefficient|否|Double| 赠送系数|
	|--sourceOrderItemId|否|String| 来源单据商品id|
	|--reserveDate|否|DateTime| 预定日期，该实体卡券是用于哪天的预定的|
	|--transCode|否|String| 流水号|
	|--reason|否|String| 原因|
	|--refundStatus|否|String| 退款状态|
	|--dgatheringId|否|String| 收银行id(第一个版本主要用在第三方实体卡券的场景)|
	|--useTimes|否|Integer| 次卡使用次数|
	|--beforeRechargeBalance|否|Double| 变更赠送金额|
	|--beforeGiftBalance|否|Double| 变更赠送金额|
	|--beforeBalance|否|Double| 变更赠送金额|
	|--orderStatusName|否|String| 收银行id(第一个版本主要用在第三方实体卡券的场景)|
