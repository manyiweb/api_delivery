# *
 优惠券唯一码二维码
 

**请求URL：** 
- `/file/export/coupon/qrcode/unique `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|quantity|是|Integer| 获取二维码数量|
|companyId|是|String| 门店标识|
|couponId|是|String| 优惠券ID|
|wxSn|是|String| 微信标识|
|isHyaline|是|int| 是否需要透明底色，1是0否，默认0|


###请求参数Json格式
 
```
{
 "quantity" : 0,
 "companyId" : "String",
 "couponId" : "String",
 "wxSn" : "String",
 "isHyaline" : "int"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--url|否|String| 二维码地址|
|msg|否|String| 消息|
|code|否|String| 业务代码|


###返回参数Json格式
 
```
{
 "data" : {
 "url" : "String"
 },
 "msg" : "String",
 "code" : "String"
}
```
