# 非统一售价实体卡券修改导入
 

**请求URL：** 
- `/mem/entitycard/cardNo/balance/import`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|file|否|Object| 文件
 |
|cardId|否|String| 实体卡id
 |
|flagId|否|String| 标志id
 |

### 请求参数Json格式
 
```
{
 "file" : null,
 "cardId" : "String",
 "flagId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|flagId|否|String| 标志id|
|totalCount|否|Long||
|successCount|否|Long||
|errorCount|否|Long||
|fileUrl|否|String||
|downloadURL|否|String||
|data|否|List||
|isTask|否|Boolean||
|code|否|Integer||


### 返回参数Json格式
 
```
{
 "flagId" : "String",
 "totalCount" : 0,
 "successCount" : 0,
 "errorCount" : 0,
 "fileUrl" : "String",
 "downloadURL" : "String",
 "data" : null,
 "isTask" : true,
 "code" : 0
}
```
