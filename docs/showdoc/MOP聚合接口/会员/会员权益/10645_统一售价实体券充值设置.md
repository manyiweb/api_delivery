# 统一售价实体券充值设置
 

**请求URL：** 
- `/mem/entitlementcard/update/recharge/set`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|cardType|否|String| 充值卡类型 EntityCard实体卡 ShoppingCard 购物车|
|fid|是|String| 实体卡id|
|entityCardList|否|List||
|--cardType|否|String| 充值卡类型 EntityCard实体卡 ShoppingCard 购物车|
|--fid|是|String| 实体卡id|
|--businessType|否|String| 业务类型编码|
|--businessTypeName|否|String| 业务类型名称|
|--rechargeAmount|否|Double| 充值金额|
|--giftAmount|否|Double| 赠送金额|
|shoppingCardSet|否|Object||
|--rechargeAmount|否|Double| 充值金额|
|--giftAmount|否|Double| 赠送金额|

### 请求参数Json格式
 
```
{
 "cardType" : "String",
 "fid" : "String",
 "entityCardList" : [{
 "cardType" : "String",
 "fid" : "String",
 "businessType" : "String",
 "businessTypeName" : "String",
 "rechargeAmount" : 0,
 "giftAmount" : 0
 }],
 "shoppingCardSet" : {
 "rechargeAmount" : 0,
 "giftAmount" : 0
 }
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
