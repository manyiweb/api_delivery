# 品牌端 保存橱窗

**请求URL：** 
- `/mem/entitycard/showcase/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long||
|showcaseName|是|String| 橱窗名称|
|status|是|String| 状态 N Y|
|entitycardId|是|String| 礼品卡id|
|advUrl|否|String| 橱窗广告图|
|groupList|否|List| 分组|
|--id|否|Long||
|--showcaseGroupName|否|String| 橱窗名称|
|--sortNo|否|Integer| 排序编号|
|--imageList|否|List| 封面图|
|--isDelete|否|Boolean| 是否删除|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "showcaseName" : "String",
 "status" : "String",
 "entitycardId" : "String",
 "advUrl" : "String",
 "groupList" : [{
 "id" : 0,
 "showcaseGroupName" : "String",
 "sortNo" : 0,
 "imageList" : null,
 "isDelete" : true
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
