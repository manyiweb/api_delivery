- `/mem/entitycard/give/receive`

**请求方式：**
- POST
- RequestBody

|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||分享记录id
|pageIndex|否|Integer||
|pageSize|否|Integer||
|orderField|否|String||
|orderSort|否|String||
|sword|否|String||

```
{
 "id" : 0,

}
```
