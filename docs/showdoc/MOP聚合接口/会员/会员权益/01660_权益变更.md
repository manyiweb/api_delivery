# 权益变更 修改会员权益有效期
 

**请求URL：** 
- `/mem/member/benefits/adjustDay `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|isAdd|否|Integer|1增加 0减少|
|day|否|Integer|天数|
|remark|否|String|备注|
|memberId|否|String|用户id|

###请求参数Json格式
 
```
{
 "isAdd" : 0,
 "day" : 0,
 "remark" : "String",
 "memberId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String"
}
```
