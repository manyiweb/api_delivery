# 查询非统一售价实体券充值设置
 

**请求URL：** 
- `/mem/entitlementcard/cards/recharge/set`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|cardId|是|String| 新换的实体卡券号|
|cardType|是|String| 充值卡类型 EntityCard实体卡 ShoppingCard 购物车|

### 请求参数Json格式
 
```
{
 "cardId" : "String",
 "cardType" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--id|否|Long||
|--mid|否|String||
|--cardType|否|String||
|--cardId|否|String||
|--cardNo|否|String||
|--businessType|否|String||
|--businessTypeName|否|String||
|--rechargeAmount|否|Double||
|--giftAmount|否|Double||
|--dbKey|否|Integer||
|--groupId|否|String||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
