# 会员权益短信验证

**请求URL：** 
- `/app/System/SendMsg`

**请求方式：**
- RequestBody


### 请求参数<业务参数>
 
无参数


### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|openId|是|String|微信小程序标识码|
|mobile|是|String|手机号码|
|msgType|是|String|发送消息类型|
|wxSn|是|String||
|groupId|是|String|品牌id|


### 返回参数Json格式
 
```
{
 "ErrorCode": "",
 "ResultString": "",
 "ResultInt": 0
}
```
