# 礼品卡橱窗详情

**请求URL：** 
- `/appc/mem/entitycard/showcase/detail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||
|pageIndex|否|Integer||
|pageSize|否|Integer||
|orderField|否|String||
|orderSort|否|String||
|sword|否|String||

### 请求参数Json格式
 
```
{
 "id" : 0,
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String",
 "sword" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long||
|--showcaseNo|否|String| 橱窗编码|
|--showcaseName|否|String| 橱窗名称|
|--status|否|String| 状态 N Y|
|--entitycardId|否|String| 礼品卡id|
|--entitycardNo|否|String| 礼品卡编号|
|--entitycardName|否|String| 礼品卡名称|
|--advUrl|否|String| 橱窗广告图|
|--createDate|否|DateTime| 创建时间|
|--createName|否|String| 创建人|
|--modifyDate|否|DateTime| 修改时间|
|--modifyName|否|String| 修改人|
|--qrcodeUrl|否|String| 小程序二维码|
|--groupList|否|List| 橱窗分组|
|----id|否|Long||
|----showcaseId|否|String| 橱窗id|
|----showcaseGroupName|否|String| 橱窗名称|
|----sortNo|否|Integer| 排序编号|
|----imageList|否|List| 封面图|
|--enableFlag|否|Boolean| 是否可用|
|--errorMsg|否|String| 不可用原因|
|--buyInstructions|否|String| 购买须知|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
