# 导出非统一售价实体卡操作记录

**请求URL：** 
- `/file/mem/operation/export`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|fId|是|String| 实体卡券id|
|operationType|是|String| add("追加"), price("修改售价"), date("修改有效期")，balance("修改余额")|
|addType|否|String| 	auto("追加"), importCard("导入");|
|logIds|否|List| 日志id|

### 请求参数Json格式
 
```
{
 "fId" : "String",
 "operationType" : "String",
 "addType" : "String",
 "logIds" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--downloadURL|否|String| 错误数据下载地址|
|--totalCount|否|Long| 总数|
|--successCount|否|Long| 成功数|
|--errorCount|否|Long| 错误数|
|--code|否|Integer||
|--isTask|否|Boolean||
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : {
 "downloadURL" : "String",
 "totalCount" : 0,
 "successCount" : 0,
 "errorCount" : 0,
 "code" : 0,
 "isTask" : true
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
