# 赠送内容详情

**请求URL：** 
- `/mem/entitycard/give/detail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||
|pageIndex|否|Integer||
|pageSize|否|Integer||
|orderField|否|String||
|orderSort|否|String||
|sword|否|String||

### 请求参数Json格式
 
```
{
 "id" : 0,
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String",
 "sword" : "String"
}
```

|--id|否|Long| 主键标识|

|--giveToMemberPhone|否|String| 被共享会员手机号|
|--giveToMemberName|否|String| 被共享会员名称|
|--giveStatus|否|Integer| 共享状态 Y N|
|--createId|否|String| 创建人id|
|--createName|否|String| 创建人|
|--createDate|否|DateTime| 创建时间|
|--modifyId|否|String| 修改人id|
|--modifyName|否|String| 修改人|
|--modifyDate|否|DateTime| 修改时间|
|--imgUrlFull|否|String| 封面|
|--cardName|否|String| 共享状态 Y N|
|--balance|否|Double| 金额|
|--giveMemberPhone|否|String| 共享人手机号|
|--giveContent|否|String| 分享语|
|--status|否|Integer| 0已失效|
|--isSelf|否|Boolean| 0已失效|
