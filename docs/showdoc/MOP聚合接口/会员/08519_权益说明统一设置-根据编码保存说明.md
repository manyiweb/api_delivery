# 权益说明统一设置-根据编码保存说明
 

**请求URL：** 
- `/mem/benefit/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|code|是|String| 编码 MemberIntro 等级说明、IntegralInstructions 积分说明、CouponIntro 优惠券说明、CardoptionsInstructions 储值须知、StoreActivityInstructions 储值活动说明、GiftCardPurchaseInstructions 礼品卡购买须知|
|data|否|String| 内容|

### 请求参数Json格式
 
```
{
 "code" : "String",
 "data" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--data|否|String| 数据|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "data" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
