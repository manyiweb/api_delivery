# 创客基本信息

**请求URL：** 
- `/hr/staff/lk/info `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|staffId|否|String| 用户id|
|tokenId|否|String| 令牌|

###请求参数Json格式
 
```
{
 "staffId" : "String",
 "tokenId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--fID|否|String| 用户id|
|--HeadImage|否|String| 用户头像|
|--userCode|否|String| 手机号码|
|--userName|否|String| 创客姓名|
|--staffCode|否|String| 创客编号|
|--authGender|否|String| 性别|
|--urgentUserPhone|否|String| 紧急联系人号码|
|--urgentUserName|否|String| 紧急联系人|
|--createName|否|String| 创建人|
|--createDate|否|DateTime| 注册日期|
|--regAgreement|否|Integer| 是否阅读并勾选协议（1是 0否）|
|--isGroupUser|否|Integer| 商户用户|
|--isgroupactive|否|Integer| 活跃状态 1是 0否|
|--statusName|否|String| 活跃状态名|
|--remark|否|String| 备注|
|--position|否|String| 职位|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
