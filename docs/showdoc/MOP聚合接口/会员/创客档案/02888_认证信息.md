# 创客认证信息

**请求URL：** 
- `/hr/staff/lk/authenticationInfo `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|staffId|否|String| 用户id|
|tokenId|否|String| 令牌|

###请求参数Json格式
 
```
{
 "staffId" : "String",
 "tokenId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--sgId|否|String| ID|
|--authName|否|String| 创客真实姓名|
|--authIdCard|否|String| 创客身份证号码|
|--authAddress|否|String| 创客地址|
|--authGender|否|String| 性别|
|--authIdCardPersonUrl|否|String| 身份证正面|
|--authIdCardNationalUrl|否|String| 身份证背面|
|--authenticationDate|否|DateTime| 签署/认证时间|
|--authentication|否|Integer| 是否已认证（1 是，0否）|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : {
 "sgId" : "String",
 "authName" : "String",
 "authIdCard" : "String",
 "authAddress" : "String",
 "authGender" : "String",
 "authIdCardPersonUrl" : "String",
 "authIdCardNationalUrl" : "String",
 "authenticationDate" : "DateTime",
 "authentication" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
