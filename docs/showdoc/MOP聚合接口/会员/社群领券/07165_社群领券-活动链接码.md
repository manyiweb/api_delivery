# 社群领券-活动链接码

**请求URL：** 
- `/activity/society/extension/info`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|appId|否|String| 小程序appId，没传按原逻辑来|
|id|是|Long||
|sword|否|String||

### 请求参数Json格式
 
```
{
 "appId" : "String",
 "id" : 0,
 "sword" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--path|否|String| 小程序路径|
|--qrcodeUrl|否|String| 二维码链接|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "path" : "String",
 "qrcodeUrl" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
