# 社群领券-活动详情

**请求URL：** 
- `/activity/society/detail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||
|sword|否|String||

### 请求参数Json格式
 
```
{
 "id" : 0,
 "sword" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long| id|
|--activityCode|否|String| 活动编码|
|--activityName|否|String| 活动名称|
|--beginDate|否|DateTime| 有效期开始|
|--endDate|否|DateTime| 有效期结束|
|--isActive|否|Boolean| 活跃状态|
|--activityRule|否|String| 活动规则|
|--restrictionType|否|Integer| 限制类型 0：不限制次数 1：限制次数 2：限制次数的参与周期|
|--frequency|否|Integer| 领取次数|
|--cycleDay|否|Integer| 多少天可再领取|
|--enableShare|否|Boolean| 能否分享|
|--shareTitle|否|String| 分享标题|
|--shareImg|否|String| 分享图片|
|--shareImgFull|否|String| 分享图片|
|--createDate|否|DateTime| 创建时间|
|--createName|否|String| 创建人|
|--societyGiftList|否|List| 礼品列表|
|----giftType|是|Integer| 礼品类型 0：优惠券 1：券包|
|----giftId|是|String| 礼品id|
|----giftCode|否|String| 礼品编码|
|----giftName|是|String| 礼品名称|
|----giftNum|是|Integer| 礼品数量|
|--societyDecoration|否|Object| 装修|
|----imageUrl|否|String| 活动主图|
|----imageUrlFull|否|String| 活动主图全路径|
|----backgroundColor|否|String| 背景色|
|----buttonColor|否|String| 按钮底色|
|----buttonWordColor|否|String| 按钮文字底色|
|--alreadyReceive|否|Boolean| 是否已领取完|
|--activeStatusName|否|String| 活动状态|
|--enableGradeSet|否|Boolean| 是否指定会员等级可领取|
|--gradeIds|否|List| 等级id列表|
|--enableCycleSet|否|Boolean| 是否启用周期设置|
|--cycleType|否|Integer| 周期类型 0：每日 1：每周 2：每月|
|--days|否|String| 日期 每周就是1234567，每月就是12345678910......|
|--exclusionDates|否|List| 排除日期列表|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
