# 会员笔记 分类tap
 

**请求URL：** 
- `/config/decorate/membernote/notetype `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 匿名场景情况下传|
|groupId|否|String| 匿名场景情况下传|

###请求参数Json格式
 
```
{
 "companyId" : "String",
 "groupId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--noteTypeModules|否|List||
|----title|否|String||
|----mallModules|否|List||
|------id|否|Long||
|------title|否|String| 模块名称、标题名|
|------code|否|String| 模块编码|
|------typographyStyles|否|String| 排版样式|
|------position|否|String| 显示位置|
|------subPosition|否|String| 扩展显示位置|
|------imageGap|否|Object| 图片间隙|
|------createId|否|String| 创建人id|
|------createName|否|String| 创建人|
|------createDate|否|DateTime| 创建时间|
|------modifyId|否|String| 修改人id|
|------modifyName|否|String| 修改人|
|------modifyDate|否|DateTime| 修改时间|
|------companyId|否|String| 商户id|
|------lineNo|否|Object| 排序号|
|------height|否|Integer| 高度|
|------width|否|Integer| 宽度|
|------color|否|String| 颜色/背景色 例如#F9F9F9|
|------mallType|否|String| 商城装修类型|
|------stencilId|否|String| 模版id|
|------showNumber|否|Integer| 展示数量|
|------fontColor|否|String| 字体色|
|------isHiddenBorder|否|Object| 是否隐藏边框 0 - 否, 1 - 是|
|------isShowShopCartShortcutIcon|否|Object| 是否显示购物车快捷图标 0 - 不显示, 1 - 显示 注意：导购助手用该字段做“是否可分享商品”|
|------isShowMoq|否|Integer| 是否显示显示起订量 0 - 不显示, 1 - 显示|
|------isShowCountdown|否|Integer| 显示倒计时|
|------isShowMsrp|否|Integer| 是否显示显示建议零售价 0 - 不显示, 1 - 显示|
|------bizId|否|String| 业务与id|
|------backgroundImageUrl|否|String| 背景图|
|------orderShowCount|否|Integer| 展示的订单数量|
|------shareTerm|否|String|分享术语 |
|------mallModuleTypeId|否|Long| 关联mall_module_type表 不一定有值，当存在分类时才有值，可参考M0073模块|
|------size|否|Integer| 存在一行n个商品时，此数量为真实数量而不是展示数量|
|------mallModuleFunctions|否|List||
|------dbKey|否|Integer| 分库标识|
|------groupId|否|String| 品牌商id|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
