# 新增/编辑智能标签设置

**请求URL：** 
- `/config/sys/tag/tagSettingSave `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|否|String||
|tagSettingId|否|Long| 新增不需要传，编辑时传|
|tagName|否|String| 标签名称|
|isActive|否|Integer| 是否启用 1启用 0停用|
|tagConditionList|否|List| 标签条件列表|
|--conditionInfoType|否|Integer| 条件详情类型 1、性别 2、年龄 3、宝宝月龄 4、本月生日 5、注册日期 20、消费次数 21、消费金额 22、客单价 23、未消费时长 24、线上消费次数 25、购买品牌次数 26、购买分类次数 27、购买分类金额 30、充值次数 31、充值金额 32、购物卡余额 33、服务卡余额 34、实体卡余额 40、邀请新会员数 50、购买商品档案属性次数 51、购买商品档案属性金额 60、购买商品规格属性次数 61、购买商品规格属性金额 70、购买品牌金额 80、购买商品次数 90、购买商品时长|
|--rangeBegin|否|String| 范围 开始|
|--rangeEnd|否|String| 范围 结束|
|--rangeTime|否|Integer| 范围时间 -1、不限制 1、近七天 2、近一个月 3、近三个月 4、近六个月 5、近一年内 6、自定义时间（只限商品购买次数）|
|--rangeTimeBegin| 否 | Date| 自定义时间开始 |
|--rangeTimeEnd | 否 | Date| 自定义时间结束 |
|--value|否|Integer| 精准值非范围|
|--expandType|否|Integer| 扩展类型 1、品牌 2、分类 20、所有充值 21、储值卡充值 22、实体卡充值 23、权益有效期购买 30、商品档案属性 40、商品规格属性 50、商品 |
|--expands|否|List| 多选框限制|
|----tagSettingItemId|否|Long| 新增不需要传，编辑时传|
|----expandId|否|String| 扩展id (充值类型不需要传)|
|----expendValues | 否 | List | 属性值列表（商品档案属性、商品规格属性） |
|----objId|否|String| 业务对象ID（只用于商品或规格属性）|
|deleteTagSettingIds|否|List| 需要删除的|

###请求参数Json格式
 
```
{
 "tokenId" : "String",
 "tagSettingId" : 0,
 "tagName" : "String",
 "isActive" : 0,
 "tagConditionList" : [{
 "conditionInfoType" : 0,
 "rangeBegin" : "String",
 "rangeEnd" : "String",
 "rangeTime" : 0,
	 "rangeTimeBegin": "2024-01-01 10:00:00",
	 "rangeTimeEnd": "2024-01-01 12:00:00",
 "value" : 0,
 "expandType" : 0,
 "expands" : [{
 "tagSettingItemId" : 0,
 "expandId" : "String",
		 "expendValues":[],
		 "objId" : "String"
 }]
 }],
 "deleteTagSettingIds" : null
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--tagSettingId|否|Long||
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "tagSettingId" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
