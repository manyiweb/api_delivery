# 标签条件列表

**请求URL：** 
- `/config/sys/tag/conditionInfoType `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|否|String||
|conditionGroupType|否|Integer| 条件组类型 0、全部（默认） 1、用户信息 2、消费情况 3、会员权益 4、会员行为|
|sword|否|String||

###请求参数Json格式
 
```
{
 "tokenId" : "String",
 "conditionGroupType" : 0,
 "sword" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--conditionList|否|List||
|----conditionInfoType|否|Integer| 条件编号|
|----conditionInfoTypeName|否|String| 条件名称|
|----conditionGroupName|否|String| 条件分组名称|
|----conditionGroupType|否|Integer| 条件组类型 1、用户信息 2、消费情况 3、会员权益 4、会员行为|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : {
 "conditionList" : [{
 "conditionInfoType" : 0,
 "conditionInfoTypeName" : "String",
 "conditionGroupName" : "String",
 "conditionGroupType" : 0
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
