# 标签设置详情

**请求URL：** 
- `/config/sys/tag/tagSettingInfo `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|否|String||
|tagSettingId|否|Long| 标签设置id|

###请求参数Json格式
 
```
{
 "tokenId" : "String",
 "tagSettingId" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--tagNo|否|String| 标签编号|
|--createDate|否|DateTime| 创建时间|
|--createName|否|String| 创建人|
|--tagSettingId|否|Long| 标签组设置id|
|--tagName|否|String| 标签名称|
|--isActive|否|Integer| 是否启用 1启用 0停用|
|--tagConditionList|否|List| 标签条件列表|
|----conditionGroupType|否|Integer| 条件组类型 1、用户信息 2、消费情况 3、会员权益 4、会员行为|
|----conditionInfoType|否|Integer| 条件详情类型 1、性别 2、年龄 3、宝宝月龄 4、本月生日 5、注册时间 20、消费次数 21、消费金额 22、客单价 23、未消费时长 24、线上消费次数 25、购买品牌次数 26、分类次数 30、充值次数 31、充值金额 40、邀请新会员数 50、购买商品档案属性次数 51、购买商品档案属性金额 60、购买商品规格属性次数 61、购买商品规格属性金额 70、购买品牌金额 80、购买商品次数 90、购买商品时长 |
|----rangeBegin|否|Long| 范围 开始|
|----rangeEnd|否|Long| 范围 结束|
|----rangeTime|否|Integer| 范围时间 -1、不限制 1、近七天 2、近一个月 3、近三个月 4、近六个月 5、近一年内 6、自定义时间|
|----rangeTimeBegin|否|Date| 自定义时间范围 开始|
|----rangeTimeEnd|否|Date| 自定义时间范围 结束|
|----unit|否|Integer| 范围单位 1、次 2、分 3、岁 4、人 5、月 6、天|
|----value|否|Integer| 精准值非范围|
|----expandType|否|Integer| 扩展类型 1、品牌 2、分类 20、所有充值 21、储值卡充值 22、实体卡充值 23、权益有效期购买 30、商品档案属性 40、商品规格属性 50、商品 |
|----expands|否|List| 多选框限制|
|------tagSettingItemId|否|Long| 标签item设置id|
|------expandId|否|String| 扩展id|
|------expandName|否|String| 扩展name (目前展示的有品牌名称 分类名称)|
|------expandValues | 否 | List | 扩展属性值 |
|------valueType | 否 | Integer | 扩展属性值类型 0 任何值 1 序列 2业务对象 |
|------valueContent | 否 | String | 扩展属性内容限定值 |
|------objId|否|String| 业务对象ID|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
