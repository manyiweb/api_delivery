# 查询智能会员标签列表
 

**请求URL：** 
- `/mem/intelligent/member/tag/list`

**请求方式：** 
- `POST`
- `FormData`


### 请求参数<业务参数>
 
无参数


### 响应参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--id|否|Long| 标签分组ID。|
|--tagGroupName|否|String| 标签分组名称。|
|--tags|否|List| 分组下的标签列表。|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 响应参数Json格式
 
```
{
 "data":[{
 "id":0,
 "tagGroupName":"String",
 "tags":null
 }],
 "msg":"String",
 "code":"String",
 "exceptionStackInfo":"String",
 "traceId":"String"
}
```
