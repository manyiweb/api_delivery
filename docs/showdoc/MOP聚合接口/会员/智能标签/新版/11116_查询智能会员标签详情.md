# 查询智能会员标签详情
 

**请求URL：** 
- `/mem/intelligent/member/tag/detail`

**请求方式：** 
- `POST`
- `RequestBody`


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 标签ID。|

### 请求参数Json格式
 
```
{
 "id":0
}
```

### 响应参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long| 标签ID。|
|--memberTagGroupId|否|Long| 会员标签分组ID。|
|--memberTagGroupName|否|String| 会员标签分组名称。|
|--tagName|否|String| 标签名称。|
|--isActive|否|Integer| 是否启用。1 表示启用，0 表示停用。|
|--memberInformationConditionGroupXor|否|Object| 会员信息条件组之间的逻辑关系。|
|----name|否|String||
|----name|否|String||
|--consumptionSituationConditionGroupXor|否|Object| 消费情况条件组之间的逻辑关系。|
|----name|否|String||
|----name|否|String||
|--remark|否|String| 备注。|
|--memberInformationConditionGroups|否|List| 会员信息条件组列表。组与组之间通过 memberInformationConditionGroupXor 定义逻辑关系；每个条件组内部通过自身 xor 字段定义组内条件关系。|
|----id|否|Long| 条件组ID。新增时为空，编辑时传入已有条件组ID。|
|----conditionCategory|否|Object| 条件分类。例如会员信息、消费情况。|
|----xor|否|Object| 组内条件之间的逻辑关系。|
|------name|否|String||
|------name|否|String||
|----conditions|否|List| 条件列表。|
|--consumptionSituationConditionGroups|否|List| 消费情况条件组列表。组与组之间通过 consumptionSituationConditionGroupXor 定义逻辑关系；每个条件组内部通过自身 xor 字段定义组内条件关系。|
|----id|否|Long| 条件组ID。新增时为空，编辑时传入已有条件组ID。|
|----conditionCategory|否|Object| 条件分类。例如会员信息、消费情况。|
|----xor|否|Object| 组内条件之间的逻辑关系。|
|------name|否|String||
|------name|否|String||
|----conditions|否|List| 条件列表。|
|--createId|否|String| 创建人ID。|
|--createName|否|String| 创建人名称。|
|--createDate|否|DateTime| 创建时间。|
|--modifyId|否|String| 修改人ID。|
|--modifyName|否|String| 修改人名称。|
|--modifyDate|否|DateTime| 修改时间。|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
