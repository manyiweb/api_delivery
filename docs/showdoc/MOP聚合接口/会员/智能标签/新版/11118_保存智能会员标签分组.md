# 保存智能会员标签分组
 

**请求URL：** 
- `/mem/intelligent/member/tag/group/save`

**请求方式：** 
- `POST`
- `RequestBody`


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 分组ID。|
|tagGroupName|否|String| 分组名称。|

### 请求参数Json格式
 
```
{
 "id":0,
 "tagGroupName":"String"
}
```

### 响应参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long| 分组ID。|
|--tagGroupName|否|String| 分组名称。|
|--createId|否|String| 创建人ID。|
|--createName|否|String| 创建人名称。|
|--createDate|否|DateTime| 创建时间。|
|--modifyId|否|String| 修改人ID。|
|--modifyName|否|String| 修改人名称。|
|--modifyDate|否|DateTime| 修改时间。|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 响应参数Json格式
 
```
{
 "data":{
 "id":0,
 "tagGroupName":"String",
 "createId":"String",
 "createName":"String",
 "createDate":"DateTime",
 "modifyId":"String",
 "modifyName":"String",
 "modifyDate":"DateTime"
 },
 "msg":"String",
 "code":"String",
 "exceptionStackInfo":"String",
 "traceId":"String"
}
```
