# 保存蛋糕预定商品
 

**请求URL：** 
- `/config/mealMall/cake/reserve/item/add`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 门店id|
|delIds|否|List| 要删除的id|
|cakeReserveItemList|否|List| 预定商品列表|
|--id|否|Long| id|
|--itemId|否|String| 商品id|
|--itemCode|否|String| 商品编码|
|--itemName|否|String| 商品名称|
|--openGreeting|否|Boolean| 是否开启祝福语|
|--isRequired|否|Boolean| 是否必填|

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "delIds" : null,
 "cakeReserveItemList" : [{
 "id" : 0,
 "itemId" : "String",
 "itemCode" : "String",
 "itemName" : "String",
 "openGreeting" : true,
 "isRequired" : true
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
