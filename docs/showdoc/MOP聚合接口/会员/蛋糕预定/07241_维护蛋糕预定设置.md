# 维护蛋糕预定设置

**请求URL：** 
- `/config/cake/meal/set/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 门店标识|
|isInherit|是|Integer| 是否继承品牌店设置（1-继承，0-不继承）|
|mealAccept|是|Integer| 启用预定订单订单受理 1是0否|
|mealRefundAccept|是|Integer| 启用预定订单退款单受理 1是0否|
|wayDelivery|是|Integer| 用餐方式-配送 1开启0停用|
|immediateDelivery|否|Boolean| 是否开启立即配送|
|reserveDelivery|否|Boolean| 是否开启预约配送|
|wayReserve|是|Integer| 开启预约自取 0否 1是|
|immediateTake|否|Boolean| 是否开启立即自取|
|reserveTake|否|Boolean| 是否开启预约自取|
|takes|否|List| 取货方式|
|--takeWay|是|Integer| 点单方式 0堂食 1打包|
|--takeWayName|否|String| 默认用餐方式名称|
|--takeWayAlias|否|String| 点单方式别名|
|--takeOpen|否|Integer| 是否开启 1是0否|
|--takeDefault|是|Integer| 是否为默认值 1是0否|
|--lineId|否|Long| 行号(排序用，允许上移下移)|
|deliverys|否|List| 配送方式|
|--deliveryWay|是|Integer| 外卖方式 1同城配送|
|--deliveryWayName|否|String| 默认用餐方式名称|
|--deliveryWayAlias|否|String| 点单方式别名|
|--deliveryOpen|否|Integer| 是否开启 1是0否|
|--deliveryDefault|是|Integer| 是否为默认值 1是0否|
|--ruleId|否|Long| 点单配送时间规则id|
|--ruleName|否|String| 点单配送时间规则名称|
|--lineId|否|Long| 行号(排序用，允许上移下移)|
|--mealMallSetDeliveryConfig|否|Object| 外卖订单配送时间设置|
|----sameCityDeliveryTimeSet|否|Boolean| 是否设置配送时间|
|----sameCityDeliveryCutTime|否|String| 截单时间|
|----sameCityDeliveryCanChoseDay|否|Integer| 可选配送天数|
|----sameCityDeliveryTimeRange|否|String| 配送时间段|
|----sameCityLeadTimeMinute|否|Integer| 备货时间（分钟）|
|----sameCityTpPlatform|否|Boolean| 启动自动呼叫跑腿|
|----ruleName|否|String| 规则名称（新的）|
|----ruleId|否|Long| 规则id（新的）|
|takeOutAlias|否|String| 外卖别名|
|selfTakeAlias|否|String| 预约自取别名|
|ruleName|否|String| 规则名称（新的）|
|ruleId|否|Long| 规则id（新的）|
|showReserveWarn|否|Boolean| 显示预定提醒标签|
|wayExpress|否|Integer| 用餐方式-快递 0：关闭 1：开启|
|openExpressTime|否|Integer| 是否设置快递配送时间|
|expressRuleId|否|Long| 快递配送时间规则id|
