# 获取商品时间规则应用列表

**请求URL：** 
- `/config/reserve/time/rule/apply/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|deliveryWay|是|Integer| 配送方式 0：到店自提 1：同城配送|
|companyId|是|String||
|sword|否|String||
|tokenId|否|String||
|id|否|String||
|pageIndex|否|Integer||
|pageSize|否|Integer||

### 请求参数Json格式
 
```
{
 "deliveryWay" : 0,
 "companyId" : "String",
 "sword" : "String",
 "tokenId" : "String",
 "id" : "String",
 "pageIndex" : 0,
 "pageSize" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--enableItemTimeRule|否|Boolean| 是否启用按商品配置时间规则|
|--itemType|否|Integer| 应用商品类型 0：指定商品 1：指定类别|
|--dataList|否|Object| 商品或者分类列表|
|----pageIndex|否|Integer||
|----pageSize|否|Integer||
|----pageCount|否|Integer||
|----totalCount|否|Long||
|----first|否|Boolean||
|----last|否|Boolean||
|----content|否|List||
|------id|否|Long| id|
|------enableValidity|是|Boolean| 是否开启有效期|
|------beginDate|否|DateTime| 开始时间|
|------endDate|否|DateTime| 结束时间|
|------deliveryWay|是|Integer| 配送方式 0：到店自提 1：同城配送|
|------itemType|是|Integer| 商品类型 0：商品 1：类别|
|------itemCode|是|String| 商品编码/类别编码|
|------itemName|是|String| 商品名称/类别名称|
|------itemId|是|String| 商品id/类别id|
|------specId|否|String| 规格id|
|------sku|否|String| SKU编码|
|------settingId|是|Long| 规则id|
|------settingName|否|String| 规则名称|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||

 "specId" : "String",
 "sku" : "String",
 "settingId" : 0,
 "settingName" : "String"
 }]
 }
 },
