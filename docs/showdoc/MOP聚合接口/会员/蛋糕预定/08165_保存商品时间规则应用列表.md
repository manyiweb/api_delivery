# 保存商品时间规则应用列表

**请求URL：** 
- `/config/reserve/time/rule/apply/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 门店id|
|enableItemTimeRule|是|Boolean| 是否启用按商品配置时间规则|
|itemType|是|Integer| 应用商品类型 0：指定商品 1：指定类别|
|deliveryWay|是|Integer| 配送方式 0：到店自提 1：同城配送|
|deleteIds|否|List| 要删除的id|
|dataList|是|List| 商品或者分类列表|
|--id|否|Long| id|
|--enableValidity|是|Boolean| 是否开启有效期|
|--beginDate|否|DateTime| 开始时间|
|--endDate|否|DateTime| 结束时间|
|--deliveryWay|是|Integer| 配送方式 0：到店自提 1：同城配送|
|--itemType|是|Integer| 商品类型 0：商品 1：类别|
|--itemCode|是|String| 商品编码/类别编码|
|--itemName|是|String| 商品名称/类别名称|
|--itemId|是|String| 商品id/类别id|
|--specId|否|String| 规格id|
|--sku|否|String| SKU编码|
|--settingId|是|Long| 规则id|
|--settingName|否|String| 规则名称|

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "enableItemTimeRule" : true,
 "itemType" : 0,
 "deliveryWay" : 0,
 "deleteIds" : null,
 "dataList" : [{
 "id" : 0,
 "enableValidity" : true,
 "beginDate" : "DateTime",
 "endDate" : "DateTime",
 "deliveryWay" : 0,
 "itemType" : 0,
 "itemCode" : "String",
 "itemName" : "String",
 "itemId" : "String",
 "specId" : "String",
 "sku" : "String",
 "settingId" : 0,
 "settingName" : "String"
 }]
}
```
