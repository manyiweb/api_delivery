# 已开启祝福数量汇总

**请求URL：** 
- `/config/mealMall/cake/reserve/item/summary`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 门店id|
|inherit|是|Integer| 是否继承品牌 1-继承品牌设置|

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "inherit" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--cakeCount|否|Integer||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "cakeCount" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
