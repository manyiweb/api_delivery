# 预定时间规则设置-新增
 

**请求URL：** 
- `/config/reserve/time/rule/setting/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id，编辑时候传|
|name|是|String| 规则名称|
|active|是|Boolean| 活跃状态|
|deliveryWay|是|Integer| 配送方式 0：到店自提 1：同城配送|
|reserveTimeType|是|Integer| 预约时段 0：全天 1：自定义|
|customReserveTimeType|否|Integer| 自定义预约时段 0：每日重复 1：每周重复|
|reserveTimeList|否|List| 时间范围列表|
|--weekDay|否|List| 周期|
|--reserveTimeRanges|否|List| 时间范围|
|----beginRange|否|String| 开始范围|
|----endRange|否|String| 结束范围|
|----interval|否|Integer| 间隔|
|reserveDurationType|否|Integer| 预约时长类型 0：提前小时/分钟 1：提前多少天 2：在某日期后配送|
|reserveDurationTime|否|Integer| 预约时长|
|reserveDurationTimeType|否|Integer| 预约时长类型 0：小时 1：分钟 2：天|
|reserveDurationDate|否|String| 在什么时间后预约配送|
|cutOffTime|否|String| 截单时间|
|maximumReserveType|否|Integer| 最长预约类型 0：在某某前预约 1：可预约多少天|
|maximumReserveDate|否|String| 在什么时间前预约|
|maximumReserveDay|否|Integer| 可预约多少天|

### 请求参数Json格式
 
```
{
 "id" : 0,

 "active" : true,
 "deliveryWay" : 0,
 "reserveTimeType" : 0,
 "customReserveTimeType" : 0,
 "reserveTimeList" : [{
 "weekDay" : null,
 "reserveTimeRanges" : [{
 "beginRange" : "String",
 "endRange" : "String",
 "interval" : 0
 }]
 }],
 "reserveDurationType" : 0,
 "reserveDurationTime" : 0,
 "reserveDurationTimeType" : 0,
 "reserveDurationDate" : "String",
 "cutOffTime" : "String",
 "maximumReserveType" : 0,
 "maximumReserveDate" : "String",
 "maximumReserveDay" : 0
}
```
