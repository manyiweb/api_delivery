# 智能派券详情

**请求URL：** 
- `/mem/smart/coupon/detail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||
|sword|否|String||

### 请求参数Json格式
 
```
{
 "id" : 0,
 "sword" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long| id|
|--planCode|否|String| 方案编码|
|--planName|否|String| 方案名称|
|--beginDate|否|DateTime| 有效期开始|
|--endDate|否|DateTime| 有效期结束|
|--cycle|否|Integer| 派发周期 0：每日 1：每周 2：每月|
|--day|否|List| 派发日期|
|--time|否|String| 派发时间|
|--isActive|否|Boolean| 活跃状态|
|--remark|否|String| 备注|
|--type|否|Integer| 派发类型 0：立即派发 1：预约派发|
|--giveType|否|Integer| 派发对象类型 0：按条件搜索 1：指定会员 2：全部会员|
|--createName|否|String| 创建人|
|--createDate|否|DateTime| 创建时间|
|--giveCondition|否|Map| 条件|
|--smartCouponDetails|否|List| 派发的优惠券和券包|
|----type|是|Integer| 类型 0：优惠券 1：券包|
|----couponId|是|String| 优惠券、券包id|
|----couponCode|否|String| 优惠券、券包编码|
|----couponName|否|String| 优惠券、券包名称|
|----couponNum|是|Integer| 派发数量|
|--smartCouponDecoration|否|Object| 智能派券装修|
|----advertisingImageUrl|否|String| 广告图片|
|----advertisingImageUrlFull|否|String| 广告图片全路径|
|----backgroundColor|否|String| 背景色|
|----couponTextColor|否|String| 优惠券文字颜色|
|----buttonColor|否|String| 按钮底色|
|----buttonTextColor|否|String| 按钮文字颜色|
|----myCouponTextColor|否|String| 我的优惠券文字颜色|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
