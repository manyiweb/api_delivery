# 查看智能派券领券信息
 

**请求URL：** 
- `/mem/smart/coupon/receive/detail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|batchId|是|Long| 批次id|
|openId|否|String||

### 请求参数Json格式
 
```
{
 "batchId" : 0,
 "openId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long||
|--batchId|否|Long||
|--smartCouponDecoration|否|Object| 装修|
|----advertisingImageUrl|否|String| 广告图片|
|----advertisingImageUrlFull|否|String| 广告图片全路径|
|----backgroundColor|否|String| 背景色|
|----couponTextColor|否|String| 优惠券文字颜色|
|----buttonColor|否|String| 按钮底色|
|----buttonTextColor|否|String| 按钮文字颜色|
|----myCouponTextColor|否|String| 我的优惠券文字颜色|
|--smartCouponDetails|否|List| 智能派券领取的优惠券列表|
|----type|是|Integer| 类型 0：优惠券 1：券包|
|----couponId|是|String| 优惠券、券包id|
|----couponCode|否|String| 优惠券、券包编码|
|----couponName|否|String| 优惠券、券包名称|
|----couponNum|是|Integer| 派发数量|
|----couponType|否|Integer| 优惠券类型|
|----price|否|Double| 售价|
|----useLimitAmt|否|Double| 使用订单的最小金额|
|----discount|否|Double| 折扣|
|----beginDate|否|DateTime| 开始时间|
|----endDate|否|DateTime| 结束时间|
|--alreadyReceived|否|Boolean| 已领取|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
