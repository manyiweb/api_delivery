# 单品代言维护
 

**请求URL：** 
- `/mem/endorsement/edit`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|
|name|是|String| 活动名称|
|beginDate|是|DateTime| 有效期起|
|endDate|是|DateTime| 有效期至|
|status|是|Integer| 活跃状态|
|appGrade|是|Integer| 指定会员等级|
|appGrades|否|List| 应用会员等级,覆盖更新，每次传最新的进来|
|items|否|List| 应用商品|
|--specId|是|String| 规格id|
|--cashBack|是|Integer| 送返现1 是0否|
|--cashbackType|是|Integer| 返现类型 0固定金额 1实收比例|
|--cashbackWay|是|Integer| 返现至 0储值卡 1返现账户 2实体卡|
|--cashbackAmount|是|Double| 返现金额或比例|
|--cashbackEntitycardId|否|String| 返现到实体卡的id，关联mentitycard表|
|delItemIds|否|List| 删除应用商品ID列表，是应用商品的行ID|
|allComp|是|Integer| 是否应用到所有门店|
|appComps|否|List| 应用门店列表，allComp = 1时必填|
|delComps|否|List| 删除应用门店ID列表，是应用门店的行ID|
|fansBuy|是|Integer| 所属下级会员购买有效|
|firstConsum|是|Integer| 仅限首次消费会员购买有效|
|itemRules|否|List| 单品代言商品规则|
|--id|否|Long||
|--type|是|Integer| 0分类 1品牌 2系列 3商品档案属性 4商品规格属性|
|--itemId|否|String| 分类/品牌/系列 ID|
|--name|是|String| 属性名|
|--code|是|String| 属性编码|
|--values|否|List| 属性值列表|
|--valueType|否|Integer| 业务类型属性|
|--businessId|否|String| 业务id|
|--ruleName|是|String| 规则名|
|--ruleValues|是|List| 规则值：如：品牌、系列、类别、序列、任何值、业务对象、自定义业务对象、规格属性1-29|
|----ruleValue|是|String| 规则值：如品牌值、系列值、类别值、序列值、任何值的值、业务员id、自定义业务员id、规格属性填1-29|
|----ruleValueName|否|String| 规则值的名称：如品牌名称，系列名称，业务员名称等等|
|--content|否|String| 内容值,多个值时以分号“;”|
|--contentId|否|String||
|--attrId|否|String||
|delItemRules|否|List| 单品代言商品规则|
|cashbackInfo|否|Object| 规则条件的返现设置|
|--cashBack|是|Integer| 送返现1 是0否|
|--cashbackType|是|Integer| 返现类型 0固定金额 1实收比例|
|--cashbackWay|是|Integer| 返现至 0储值卡 1返现账户 2实体卡|
|--cashbackAmount|是|Double| 返现金额或比例|
|--cashbackEntitycardId|否|String| 返现到实体卡的id，关联mentitycard表|
|excludeItems|否|List| 排除商品|
|delExcludeItems|否|List| 删除的排除商品|
|applyItemType|是|Integer| 商品应用类型：0-指定商品 1-指定分类、品牌、系列、档案属性、规格属性|
|defineCondition|是|Integer| 定义条件关系 0：条件之间为或关系 1：条件之前为且关系|
