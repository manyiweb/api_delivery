# 单品代言 - 应用商品
 

**请求URL：** 
- `/mem/endorsement/items `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 业务ID|
|pageIndex|否|Integer| 分页页码|
|pageSize|否|Integer| 分页大小|
|sword|否|String| 搜索关键字|

###请求参数Json格式
 
```
{
 "id" : 0,
 "pageIndex" : 0,
 "pageSize" : 0,
 "sword" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--pageIndex|否|Integer| 页码|
|--pageSize|否|Integer| 显示记录数|
|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|--first|否|Boolean| 首页|
|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|
|----id|否|Long| id|
|----itemId|否|String| 商品id|
|----itemCode|否|String| 商品编码|
|----itemName|否|String| 商品名称|
|----specId|否|String| 规格id|
|----specName|否|String| 规格名称|
|----itemNameFull|否|String| 完整的商品名称|
|----skuBarcode|否|String| sku码|
|----cashBack|否|Integer| 送返现1 是0否|
|----cashbackType|否|Integer| 返现类型 0固定金额 1实收比例|
|----cashbackTypeName|否|String| 返现类型 名称|
|----cashbackWay|否|Integer| 返现至 0储值卡 1返现账户|
|----cashbackWayName|否|String| 返现至 名称|
|----cashbackAmount|否|Double| 返现金额或比例|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
