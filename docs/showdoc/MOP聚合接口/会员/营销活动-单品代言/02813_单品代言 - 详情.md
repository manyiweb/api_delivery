# 单品代言 - 详情
 

**请求URL：** 
- `/mem/endorsement/detail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long| id|

### 请求参数Json格式
 
```
{
 "id" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long| id|
|--code|否|String| 活动编码|
|--name|否|String| 活动名称|
|--beginDate|否|DateTime| 有效期起|
|--endDate|否|DateTime| 有效期至|
|--status|否|Integer| 活跃状态|
|--statusName|否|String| 活跃状态名称|
|--allComp|否|Integer| 是否应用到所有门店|
|--appGrade|否|Integer| 是否指定会员等级 1是0否|
|--fansBuy|否|Integer| 所属下级会员购买有效|
|--firstConsum|否|Integer| 仅限首次消费会员购买有效|
|--applyItemType|否|Integer| 商品应用类型：0/null-指定商品 1-指定分类、品牌、系列、档案属性、规格属性|
|--defineCondition|否|Integer| 定义条件关系 0：条件之间为或关系 1：条件之前为且关系|
|--createName|否|String| 创建人|
|--createDate|否|DateTime| 创建时间|
|--modifyName|否|String| 修改人名称|
|--modifyDate|否|DateTime| 修改时间|
|--endorsementGrades|否|List| 指定会员等级|
|----id|否|Long| id|
|----gradeId|否|String| 会员等级标识|
|----gradeCode|否|String| 会员等级编码|
|----gradeName|否|String| 会员等级名称|
|--endorsementItemRules|否|List| 规则|
|----id|否|Long||
|----type|是|Integer| 0分类 1品牌 2系列 3商品档案属性 4商品规格属性|
|----itemId|否|String| 分类/品牌/系列 ID|
|----name|是|String| 属性名|
|----code|是|String| 属性编码|
|----values|否|List| 属性值列表|
|----valueType|否|Integer| 业务类型属性|
|----businessId|否|String| 业务id|
|----ruleName|是|String| 规则名|
|----ruleValues|是|List| 规则值：如：品牌、系列、类别、序列、任何值、业务对象、自定义业务对象、规格属性1-29|
|------ruleValue|是|String| 规则值：如品牌值、系列值、类别值、序列值、任何值的值、业务员id、自定义业务员id、规格属性填1-29|
|------ruleValueName|否|String| 规则值的名称：如品牌名称，系列名称，业务员名称等等|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|
