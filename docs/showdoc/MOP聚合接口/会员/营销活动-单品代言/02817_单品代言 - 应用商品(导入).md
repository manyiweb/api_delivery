# 单品代言 - 应用商品(导入)
 

**请求URL：** 
- `/file/mem/endorsement/items/upload `

**请求方式：**
- POST
- FormData


###请求参数<业务参数>
 
无参数


###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--dataSource|否|List||
|----specId|否|String| 商品规格|
|----itemCode|否|String| 商品编码|
|----itemName|否|String| 完整的商品名称|
|----skuBarcode|否|String| sku码|
|----cashBack|否|Integer| 送返现1 是0否|
|----cashbackType|否|Integer| 返现类型 0固定金额 1实收比例|
|----cashbackWay|否|Integer| 返现至 0储值卡 1返现账户|
|----cashbackAmount|否|Double| 返现金额或比例|
|----status|否|Integer||
|----statusName|否|String||
|----msg|否|String||
|--downloadURL|否|String| 错误数据下载地址|
|--totalCount|否|Long| 总数|
|--successCount|否|Long| 成功数|
|--errorCount|否|Long| 错误数|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式

```
 "msg" : "String"
 }],
 "downloadURL" : "String",
 "totalCount" : 0,
 "successCount" : 0,

 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
