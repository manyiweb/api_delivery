# 预添加企业会员
 

**请求URL：** 
- `/mem/super/member/pre/add`

**请求方式：**
- POST
- RequestBody

**服务：**
- member

### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|memberId|是|String||
|priceListId|否|String| 价格清单ID|
|addStatus|是|Integer| 添加状态：0-草稿，1-确认|

### 请求参数Json格式
 
```
{
 "memberId" : "String",
 "priceListId" : "String",
 "addStatus" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
