# 获取会员价

**请求URL：** 
- `/b2b/shopping/cart/getMemberPrice`

**请求方式：** 
- `POST`
- `RequestBody`


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|memberId|否|String| 会员id|
|specIds|否|List||

### 请求参数Json格式
 
```
{
 "memberId":"String",
 "specIds":null
}
```

### 响应参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--memberPrice|否|Double| 会员价格|
|--memberDiscount|否|Double| 会员折扣|
|--itemId|否|String| 商品id|
|--specId|否|String| 规格id|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 响应参数Json格式
 
```
{
 "data":[{
 "memberPrice":0,
 "memberDiscount":0,
 "itemId":"String",
 "specId":"String"
 }],
 "msg":"String",
 "code":"String",
 "exceptionStackInfo":"String",
 "traceId":"String"
}
```
