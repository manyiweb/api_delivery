# 极速版批量查询企业会员价格
 服务 cart-front
 

**请求URL：** 
- `/app/shopping/cart/item/getSuperMemberPrice`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|memberId|是|String||
|docType|是|String||
|specIds|是|List||

### 请求参数Json格式
 
```
{
 "memberId" : "String",
 "docType" : "String",
 "specIds" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Map| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
