# 业务单据查询

**请求URL：** 
- `/config/printer/template/optionName/1list`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
无参数


### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long| Id|
|--applyId|否|Long| 打印id|
|--companyId|否|String| 门店ID|
|--companyCode|否|String| 门店ID|

|--applyStatusName|否|String| 申请状态|
|--createDate|否|DateTime| 创建时间|

|--objItemName|否|String| 会员分组名称（自定义业务对象 objItemName）|
|--printStatus|否|Integer| 是否打印|

|----remark|否|String||

|----referenceQuantity|否|Object||
|----referencePrice|否|Object||
|--settingType|否|Integer| 设置类型(0:按账期设置,1:按固定还款日设置)|
|--settingTypeDesc|否|String| 设置类型描述(0:按账期设置,1:按固定还款日设置)|
|--staffName|否|String| 业务员|
