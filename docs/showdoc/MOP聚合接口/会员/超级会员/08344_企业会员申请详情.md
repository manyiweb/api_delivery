# 企业会员申请详情
 

**请求URL：** 
- `/mem/super/member/apply/detail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long| 规则id|

### 请求参数Json格式
 
```
{
 "id" : 0
}
```
