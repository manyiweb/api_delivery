# 企业会员价格清单-新增
 服务：reabam-product-manager
 全流程：
 1.1、新增品牌价格清单 /product/mitem/addPrice（RPC）
 1.2、编辑品牌价格清单 /product/mitem/updatePrice （RPC）
 2、修改品牌价格清单配置（指定商品or指定品牌、系列、分类） /product/pricelist/config/set
 3.1、新增商品 /product/priceList/batchAdd （RPC）
 3.2、新增品牌、系列、分类 /product/pricelist/category/saveList
 4.1、指定商品修改价格 productsService.addPriceListItem （RPC）
 4.2、指定品牌、系列、分类修改折扣 /product/pricelist/category/save
 4.3、指定品牌、系列、分类新增特殊商品 /product/pricelist/specialItem/save
 4.4、指定品牌、系列、分类修改特殊商品修改价格 /product/pricelist/specialItem/updateItem
 5、新增企业会员价格清单 /config/superMember/priceList/save （RPC）

**请求URL：** 
- `/product/mitem/addSuperMemberPrice`

**请求方式：**
- POST
- RequestBody
