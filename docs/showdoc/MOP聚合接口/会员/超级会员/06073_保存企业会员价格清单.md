# 保存企业会员价格清单
 

**请求URL：** 
- `/config/superMember/priceList/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long||
|memberId|是|String|会员id |
|memberName|否|String|会员名称 |
|memberPhone|是|String|会员名称 |
|priceListId|是|String|价格清单id |
|priceListCode|是|String|价格清单id |
|priceListName|否|String|价格清单名称 |
|validStartTime|是|DateTime|有效开始时间 |
|validEndTime|是|DateTime|有效结束时间 |
|delIds|否|List|删除 |
|enableBusinessType|否|Boolean|按业务类型设置 |
|businessTypeRetail|否|Boolean|应用零售类型 |
|businessTypeBooking|否|Boolean|应用预售类型 |
|businessTypeCredit|否|Boolean|应用赊销类型 |

### 请求参数Json格式
 
```
{
 "id" : 0,
 "memberId" : "String",
 "memberName" : "String",
 "memberPhone" : "String",
 "priceListId" : "String",
 "priceListCode" : "String",
 "priceListName" : "String",
 "validStartTime" : "DateTime",
 "validEndTime" : "DateTime",
 "delIds" : null,
 "enableBusinessType" : true,
 "businessTypeRetail" : true,
 "businessTypeBooking" : true,
 "businessTypeCredit" : true
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
