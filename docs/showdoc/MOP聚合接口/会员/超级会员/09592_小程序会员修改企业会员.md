# 小程序会员申请企业会员

**请求URL：** 
- `/mem/super/member/price/update`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||
|rate|否|Double| 倍率|
|applyType|是|String| 商品类型 item：指定商品 categroy：指定品牌、分类、系列|
|enableSpecialItem|否|Boolean| 是否开启特殊商品|
|useMemberPrice|否|Boolean| 是否使用会员价格清单|
|validStartTime|否|DateTime|有效开始时间 |
|validEndTime|否|DateTime|有效结束时间 |
|priceName|否|String| 价格清单名称|
|remark|否|String| 备注|
|itemList|否|List| 多规格|
|--id|否|Long| id|
|--itemId|否|String| 商品id|
|--basePrice|否|Double| 基础零售价|
|--priceRange|否|String| 价格范围|
|--referenceQuantityRange|否|String| 参考数量|
|--referencePriceRange|否|String| 参考数量金额小计|
|--isOpenMutiUnit|否|Integer| 开启单位组价格清单|
|--skuList|否|List| sku列表|
|----id|否|Long| id|
|----priceListId|否|String| super_member_price_list_apply|
|----itemId|否|String| 商品id|
|----skuId|否|String| 规格id|
|----unitPrice|否|Double| 价格|
|----openSpecPrice|否|Integer| 启用按规格维护价格(企业会员功能)|
|----referenceQuantity|否|Double| 参考数量|
|----referencePrice|否|Double| 参考数量金额小计|
|----isOpenMutiUnit|否|Integer| 开启单位组价格清单|
|categoryList|否|List| 分类|
|--id|否|Long||
|--priceListId|否|String| 清单id|
|--categoryType|否|Integer| 类别类型,1：品牌,2：系列 3：类别|
|--categoryId|否|String| 通用指定id 可以是品牌,系列或类别|
|--categoryCode|否|String| 通用指定编码 可以是品牌,系列或类别|
|--categoryName|否|String| 通用指定名称 可以是品牌,系列或类别|
|--rate|否|Double| 折扣|
|specialList|否|List| 特殊商品|
|--id|否|Long||
|--priceListId|否|String| 清单id|
|--itemId|否|String| 商品id|
|--listPrice|否|Double| 清单价|
|--referenceQuantity|否|Double| 参考数量|
|--referencePrice|否|Double| 参考数量金额小计|
|--remark|否|String| 备注|
|--skuList|否|List||
|----id|否|Long||
|----priceListId|否|String| 清单id|
|----itemId|否|String| 商品id|
|----specId|否|String| 规格id|
|----listPrice|否|Double| 清单价|
|----referenceQuantity|否|Double| 参考数量|
|----referencePrice|否|Double| 参考数量金额小计|
|----remark|否|String| 备注|
