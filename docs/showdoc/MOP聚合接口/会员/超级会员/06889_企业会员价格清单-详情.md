# 企业会员价格清单-详情

**请求URL：** 
- `/product/mitem/superMemberPrice/detail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|superMemberPriceListId|否|Long| 清单id|

### 请求参数Json格式
 
```
{
 "superMemberPriceListId" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--applyType|否|Integer| 商品类型 0：指定商品 1：指定品牌、分类、系列|
|--enableSpecialItem|否|Boolean| 是否开启特殊商品|
|--superMemberPriceListResp|否|Object| 企业会员价格清单|
|----id|否|Long||
|----memberId|否|String| 会员id|
|----memberName|否|String| 会员名称|
|----memberPhone|否|String| 会员名称|
|----priceListId|否|String| 价格清单id|
|----priceListCode|否|String| 价格清单id|
|----priceListName|否|String| 价格清单名称|
|----validStartTime|否|DateTime| 有效开始时间|
|----validEndTime|否|DateTime| 有效结束时间|
|----enableBusinessType|否|Boolean| 按业务类型设置|
|----businessTypeRetail|否|Boolean| 应用零售类型|
|----businessTypeBooking|否|Boolean| 应用预售类型|
|----businessTypeCredit|否|Boolean| 应用赊销类型|
|--rbPricelistdetailRespList|否|List| 指定商品|
|----fid|否|String||
|----version|否|Integer||
|----mid|否|String| 主表ID，与RB_PriceList关联|
|----itemId|否|String| 商品ID|
|----skuid|否|String| 规格Id|
|----unitPrice|否|Double| 价格|
|----createTime|否|DateTime| 创建日期|
|----creatorId|否|String| 创建人|
|----creatorName|否|String| 创建人|
|----basePrice|否|Double| 零售价|
|----openMutiUnit|否|Boolean| 启用单位组清单价设置|
|--rbPricelistSpecialItemResps|否|List| 特殊商品|
|----id|否|Long| Id|
|----priceListId|否|String| 清单id|
|----itemId|否|String| 商品ID|
|----specId|否|String| 规格Id|
|----listPrice|否|Double| 清单价|
|--rbPricelistCategoryResps|否|List| 指定商品|
|----id|否|Long||
|----priceListId|否|String| 清单id|
|----categoryType|否|Integer| 类别类型，1：品牌，2：系列 3：类别|
|----categoryId|否|String| 通用指定id 可以是品牌，系列或类别|
|----categoryCode|否|String| 通用指定编码 可以是品牌，系列或类别|
|----categoryName|否|String| 通用指定名称 可以是品牌，系列或类别|
|----rate|否|Double| 折扣|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
