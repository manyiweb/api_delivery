# 获取可配置页面列表
 

**请求URL：** 
- `/config/activities/share/getDefinitions`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|platformType|否|String| 平台类型 MALL：会员商城 MEAL_MALL：点单商城|
|companyId|是|String||

### 请求参数Json格式
 
```
{
 "platformType" : "String",
 "companyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--id|否|Long||
|--urlTypeCode|否|String| 页面类型编码|
|--urlTypeName|否|String| 页面名称|
|--url|否|String| 页面路径|
|--pageType|否|String| 页面类型|
|--platformType|否|String| 平台类型|
|--isGroup|否|Boolean| 是否是品牌|
|--dbKey|否|Integer||
|--groupId|否|String||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "id" : 0,
 "urlTypeCode" : "String",
 "urlTypeName" : "String",
 "url" : "String",
 "pageType" : "String",
 "platformType" : "String",
 "isGroup" : true,
 "dbKey" : 0,
 "groupId" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
