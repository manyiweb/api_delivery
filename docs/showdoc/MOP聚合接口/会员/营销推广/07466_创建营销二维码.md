# 创建营销二维码
会员服务
**请求URL：** 
- `/mem//create/marketing/qrcode`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|activitiesShareId|否|Long| 营销分享id|
|platformType|否|String| 端口 MALL:商城 MEAL_MALL:点单|
|sceneId|否|Long| 二维码标识|
|isGroup|否|boolen| true：品牌 false：门店 默认为fasle|

### 请求参数Json格式
 
```
{
 "activitiesShareId" : 0,
 "platformType" : "String",
 "sceneId" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long| 业务标识|
|--originalId|否|String| 小程序原始ID|
|--page|否|String| 页面|
|--imgUrl|否|String| 二维码|
|--shoppingType|否|Integer| 0是小程序 1:点单|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "originalId" : "String",
 "page" : "String",
 "imgUrl" : "String",
 "shoppingType" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
