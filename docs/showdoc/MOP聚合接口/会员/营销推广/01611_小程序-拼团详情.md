# 可参团详情
 

**请求URL：** 
- `/appc/groupbuy/found/detail `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
无参数


###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--foundId|否|String| 团购id|
|--leftSecond|否|Long| 剩余时间-秒|
|--leftPersonNum|否|Integer| 还差x人|
|--founderPhone|否|String| 手机号码|
|--followerList|否|List| 参团者|
|----profilePhoto|否|String||
|----isHost|否|Integer||
|--isJoined|否|Integer| 是否参团|
|--maxPurchaseQty|否|Integer| 最大可购买量|
|--limitQty|否|Integer| 限购量|
|--isCountdown|否|Integer| 开始倒计时|
|--orderId|否|String| 订单id|
|--unit|否|String| 基本单位|
|--itemName|否|String| 商品名称|
|--itemId|否|String| 商品id|
|--itemImgUrl|否|String| 商品图片|
|--personNum|否|Integer| 成团人数|
|--personNumMax|否|Integer| 最大成团人数|
|--personNumMin|否|Integer| 最小成团人数|
|--groupPrice|否|Double| 活动价格|
|--originPrice|否|Double| 划线价|
|--groupSaleNum|否|Integer| 已团数量|
|--isExpire|否|Integer| 过期|
|--labelTitle|否|String| 活动标签|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
