# 

**请求URL：** 
- `/groupbuyAct/add`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|activity|是|Object| 拼团活动信息|
|--id|否|Long| 主键|
|--groupbuyName|是|String| 拼团活动名称|
|--groupbuySn|否|String| 活动编号|
|--fromTime|是|DateTime| 开团时间|
|--toTime|是|DateTime| 结束时间|
|--durationSecond|是|Integer| 成团有效期|
|--isShow|是|Integer| 显示凑团(0-不显示 1-显示)|
|--isEnable|是|Integer| 活动状态(0-下架 1-启用)|
|--sort|否|Long| 排序|
|--ruleContent|否|String| 活动规则|
|--createId|否|String| 创建人id|
|--createName|否|String| 创建人|
|--modifyId|否|String| 修改人id|
|--modifyName|否|String| 修改人|
|--createDate|否|DateTime| 创建时间|
|--modifyDate|否|DateTime| 修改时间|
|--autoGroup|否|Boolean| 自动成团|
|--dbKey|否|Integer| 分库标识|
|--groupId|否|String| 品牌商id|
|activityGoodsList|否|List| 拼团活动商品|
|--itemId|是|String| 商品id|
|--personNum|是|Integer| 成团人数|
|--limitNum|是|Integer| 每人限购数|
|--actPrice|否|Double| 拼团价|
|--isCustomSpecPrice|是|Integer| 启用规格拼团价设置|
|--specIdAndPriceMap|否|Map| 自定义规格价|
|isAllCompany|是|Integer| 应用所以门店|
|companyIdList|否|List| 新增门店|
|delCompanyIdList|否|List| 删除门店|
