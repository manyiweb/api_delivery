# 团购购买 - 与立即购买一样， 只是接口地址不一样
 

**请求URL：** 
- `/appc/shopping/cart/item/groupbuy `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|specId|否|String| 规格ID|
|quantity|否|Double| 商品数量|
|labelSet|否|List| 标签ID列表|
|uniqueCodeSet|否|List| 唯一码列表|
|shopCartKey|否|String| 如果是立即购买输入对应的立即购买cartKey|

###请求参数Json格式
 
```
{
 "specId" : "String",
 "quantity" : 0,
 "labelSet" : null,
 "uniqueCodeSet" : null,
 "shopCartKey" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
