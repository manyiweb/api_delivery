# 分页-可参团列表
 

**请求URL：** 
- `/appc/groupbuy/found/list`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|itemId|否|String||
|pageIndex|否|Integer||
|pageSize|否|Integer||
|orderField|否|String||
|orderSort|否|String||

### 请求参数Json格式
 
```
{
 "itemId" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--pageIndex|否|Integer||
|--pageSize|否|Integer||
|--pageCount|否|Integer||
|--totalCount|否|Long||
|--first|否|Boolean||
|--last|否|Boolean||
|--content|否|List||
|----foundId|否|String| 团购id|
|----leftSecond|否|Long| 剩余时间-秒|
|----leftPersonNum|否|Integer| 还差x人|
|----founderPhone|否|String| 手机号码|
|----profilePhoto|否|String| 头像|
|----personNum|否|Integer| 成团人数|
|----nickname|否|String| 团长名称|
|----profilePhotos|否|String| 参团头像 逗号分隔|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "pageIndex" : 0,
 "pageSize" : 0,
 "pageCount" : 0,
 "totalCount" : 0,
 "first" : true,
 "last" : true,
 "content" : [{
 "foundId" : "String",
 "leftSecond" : 0,
 "leftPersonNum" : 0,
 "founderPhone" : "String",
 "profilePhoto" : "String",
 "personNum" : 0,
 "nickname" : "String",
 "profilePhotos" : "String"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
