# Gets signin act.
 

**请求URL：** 
- `/mem/act/getSigninAct `

**请求方式：**
- POST
- FormData


###请求参数<业务参数>
 
无参数


###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--actName|否|String| 活动名称|
|--modifyTime|否|String| 更新时间|
|--modifierName|否|String| 更新人|
|--isGiftPoint|否|Boolean| 开启日签奖励送积分-是 否|
|--giftPointOneDay|否|Integer| 日签奖励积分|
|--signinRule|否|String| 签到奖励规则|
|--list|否|List| 连签奖励|
|----serialDay|否|Integer| 连续签到天数|
|----ruleList|否|List| 赠送规则|
|------giftType|否|Integer| 赠送类型 1-积分； 2-优惠券；3-服务商品|
|------source|否|String| 赠送资源， 积分为赠送积分数， 优惠券为优惠券id逗号隔开， 服务商品为服务商品id， 逗号隔开|
|------isOpen|否|Boolean| 是否启用|
|------sourceName|否|String| 赠送资源名称|
|msg|否|String| 消息|
|code|否|String| 业务代码|


###返回参数Json格式
 
```
{
 "data" : {
 "actName" : "String",
 "modifyTime" : "String",
 "modifierName" : "String",
 "isGiftPoint" : true,
 "giftPointOneDay" : 0,
 "signinRule" : "String",
 "list" : [{
 "serialDay" : 0,
 "ruleList" : [{
 "giftType" : 0,
 "source" : "String",
 "isOpen" : true,
 "sourceName" : "String"
 }]
 }]
 },
 "msg" : "String",
 "code" : "String"
}
```
