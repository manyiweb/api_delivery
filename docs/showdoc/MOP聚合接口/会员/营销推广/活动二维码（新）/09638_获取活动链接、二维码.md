# 获取活动链接、二维码

**请求URL：** 
- `/config/activities/share/v2/getActivitiesShareLink`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||
|sword|否|String||

### 请求参数Json格式
 
```
{
 "id" : 0,
 "sword" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--pageUrl|否|String| 内部链接|
|--externalLink|否|String| 外部链接|
|--imgUrl|否|String| 小程序码|
|--urlLink|否|String| URL Link|
|--shortLink|否|String| Short Link|
|--permanentShortLink|否|String| 永久的Short Link|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "pageUrl" : "String",
 "externalLink" : "String",
 "imgUrl" : "String",
 "urlLink" : "String",
 "shortLink" : "String",
 "permanentShortLink" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
