# 保存活动二维码
 

**请求URL：** 
- `/config/activities/share/v2/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|appId|是|String| 小程序appId|
|channelCode|是|String| 渠道编码|
|channelName|是|String| 渠道名称|
|staffId|否|String| 导购id|
|staffName|否|String| 导购名称|
|id|否|Long| 主键id|
|companyId|否|String| 门店id|
|platformType|否|String| 平台类型：0-会员小程序 1-点单小程序|
|pageType|否|String| 页面类型|
|pageTypeDesc|否|String| 页面类型描述|
|pageTypeContent|否|String| 关联页面内容|
|pageUrl|否|String| 页面链接|
|createId|否|String||
|createName|否|String||
|createDate|否|DateTime||
|modifyId|否|String||
|modifyName|否|String||
|modifyDate|否|DateTime||
|dbKey|否|Integer||
|groupId|否|String||

```
 "appId" : "String",

 "modifyId" : "String",
 "modifyName" : "String",
 "modifyDate" : "DateTime",
 "dbKey" : 0,
 "groupId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
