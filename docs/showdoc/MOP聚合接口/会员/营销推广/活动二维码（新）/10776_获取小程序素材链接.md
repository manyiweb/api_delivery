# 获取小程序素材链接
 

**请求URL：** 
- `/config/activities/share/v2/getMaterialActivitiesShareLink`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|String| id|
|appId|是|String| 小程序appId|
|pageUrl|是|String| 页面路径|

### 请求参数Json格式
 
```
{
 "id" : "String",
 "appId" : "String",
 "pageUrl" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long| id|
|--pageUrl|否|String| 内部链接|
|--externalLink|否|String| 外部链接|
|--imgUrl|否|String| 小程序码|
|--urlLink|否|String| URL Link|
|--shortLink|否|String| Short Link|
|--permanentShortLink|否|String| 永久的Short Link|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "pageUrl" : "String",
 "externalLink" : "String",
 "imgUrl" : "String",
 "urlLink" : "String",
 "shortLink" : "String",
 "permanentShortLink" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
