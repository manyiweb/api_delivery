# 获取营销二维码详情信息
会员服务
**请求URL：** 
- `/mem//get/marketing/qrcode/info`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|activitiesShareId|否|Long| 营销分享id|
|platformType|否|String| 端口 MALL:商城 MEAL_MALL:点单|
|sceneId|否|Long| 二维码标识|

### 请求参数Json格式
 
```
{
 "activitiesShareId" : 0,
 "platformType" : "String",
 "sceneId" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--companyId|否|String| 门店id|
|--platformType|否|String| 平台类型：0-会员小程序 1-点单小程序|
|--pageType|否|String| 页面类型|
|--pageTypeDesc|否|String| 页面类型描述|
|--pageTypeContent|否|String| 关联页面内容|
|--pageUrl|否|String| 页面链接|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "companyId" : "String",
 "platformType" : "String",
 "pageType" : "String",
 "pageTypeDesc" : "String",
 "pageTypeContent" : "String",
 "pageUrl" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
