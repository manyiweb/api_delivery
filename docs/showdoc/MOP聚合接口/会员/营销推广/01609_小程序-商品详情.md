# 小程序-商品详情


 
**简要描述：** 

- 商品详情

**请求URL：** 
- ` /appc/Product/GetDetail `
 
**请求方式：**
- POST 

**返回添加：** 
saleNum - 团购数量
personNum - 参团人数
ruleInfo - 参团规则
pirce - 规格spec对应价格
actEndLeftSecond - 距离活动结束剩余时间（秒）

```
	"groupbuy":{
		"pirce":{
			"ed44e41573ad4d519c7dccd298639449":1
		},
		"ruleInfo":"你好, 拼团",
		"personNum":11,
		"saleNum":0,
		"actEndLeftSecond":1
	},
```
