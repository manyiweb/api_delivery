# 营销活动列表

**请求URL：** 
- `/mem/act/promo `

**请求方式：**
- POST
- FormData


###请求参数<业务参数>
 
可传入分页参数


###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--list|否|List||
|----id|否|String| id|
|----actName|否|String| 活动名称|
|----modifyTime|否|String| 更新时间|
|----modifierName|否|String| 更新人|
|----actType|否|int| 1-签到|
|msg|否|String| 消息|
|code|否|String| 业务代码|


###返回参数Json格式
 
```
{
 "data" : {
 "list" : [{
 "id" : "String",
 "actName" : "String",
 "modifyTime" : "String",
 "modifierName" : "String"
 }]
 },
 "msg" : "String",
 "code" : "String"
}
```
