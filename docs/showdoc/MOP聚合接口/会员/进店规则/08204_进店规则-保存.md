# 进店规则-保存

**请求URL：** 
- `/config/entry/rule/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 主键|
|name|否|String| 规则名称|
|active|否|Boolean| 是否启用|
|levelInfos|否|List| 级别信息|
|enableEntryUrlCompany|否|Boolean| 是否进入链接上面的门店|
|enableLastVisitCompany|否|Boolean| 是否进入上次访问门店|
|enableTimeLimit|否|Boolean| 是否开启时间限制|
|time|否|Integer| 时间|
|timeType|否|Integer| 时间类型 0分钟 1小时 2天|
|enableEntryNearestCompany|否|Boolean| 是否进入最近门店|
|enableEntryExclusiveCompany|否|Boolean| 是否进入专属门店|
|lastRuleType|否|Integer| 兜底进店规则 0：手动选择门店 1：进入指定门店 2：不参与进店|
|lastRuleAssignCompanyId|否|String| 兜底进店规则-进入指定门店id|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "name" : "String",
 "active" : true,
 "levelInfos" : null,
 "enableEntryUrlCompany" : true,
 "enableLastVisitCompany" : true,
 "enableTimeLimit" : true,
 "time" : 0,
 "timeType" : 0,
 "enableEntryNearestCompany" : true,
 "enableEntryExclusiveCompany" : true,
 "lastRuleType" : 0,
 "lastRuleAssignCompanyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||

```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",

}
```
