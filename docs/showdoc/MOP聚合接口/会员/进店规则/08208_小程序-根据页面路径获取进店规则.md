# 小程序-根据页面路径获取进店规则

**请求URL：** 
- `/config/entry/rule/routeByPagePath`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|pagePath|否|String| 小程序|
|id|否|String| 链接id|
|longitude|否|String| 经度|
|latitude|否|String| 纬度|
|getNearestCompany|否|Boolean| 是否获取最近门店|

### 请求参数Json格式
 
```
{
 "pagePath" : "String",
 "id" : "String",
 "longitude" : "String",
 "latitude" : "String",
 "getNearestCompany" : true
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--ruleId|否|Long| 规则id|
|--matchSuccess|否|Boolean| 是否匹配成功|
|--companyId|否|String| 门店id|
|--entryRuleType|否|Integer| 进店规则类型 0:进带有门店参数的链接 1:进上次访问的门店 2:进入最近门店 3:进入会员专属门店 4:兜底规则|
|--lastRuleType|否|Integer| 兜底进店规则 0：手动选择门店 1：进入指定门店 2：不参与进店|
|--lastRuleAssignCompanyId|否|String| 兜底进店规则-进入指定门店id|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "ruleId" : 0,
 "matchSuccess" : true,
 "companyId" : "String",
 "entryRuleType" : 0,
 "lastRuleType" : 0,
 "lastRuleAssignCompanyId" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
