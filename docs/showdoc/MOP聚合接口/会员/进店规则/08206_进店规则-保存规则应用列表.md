# 进店规则-保存规则应用列表

**请求URL：** 
- `/config/entry/rule/apply/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|entryRuleApplyList|否|List| 规则应用集合|
|--id|否|Long||
|--pagePath|否|String| 页面路径|
|--pageName|否|String| 页面名称|
|--ruleId|否|Long| 规则id|
|--ruleName|否|String| 规则名称|
|--modifyName|否|String| 最后修改人|
|--modifyDate|否|DateTime| 最近修改时间|

### 请求参数Json格式
 
```
{
 "entryRuleApplyList" : [{
 "id" : 0,
 "pagePath" : "String",
 "pageName" : "String",
 "ruleId" : 0,
 "ruleName" : "String",
 "modifyName" : "String",
 "modifyDate" : "DateTime"
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
