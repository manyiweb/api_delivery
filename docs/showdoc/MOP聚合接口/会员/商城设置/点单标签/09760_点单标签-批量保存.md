# 点单标签-批量保存

**请求URL：** 
- `/config/itemLabel/batchSave`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|labelGroupId|是|Long| 标签组id|
|itemLabelInfos|是|List| 标签信息|
|--labelCode|是|String| 标签编码|
|--labelName|是|String| 标签名称|
|--labelPrice|是|Double| 标签价|
|--isDefault|是|Integer| 是否默认选中|
|--relatedItems|否|List| 关联商品|
|----itemId|否|String| 商品id|
|----itemCode|否|String| 商品编码 (校验商品报错提示用)|
|----quantity|是|Double| 数量|
|----priceType|是|Integer| 调整方式|
|freeSpecIds|是|List| 应用商品|

### 请求参数Json格式
 
```
{
 "labelGroupId" : 0,
 "itemLabelInfos" : [{
 "labelCode" : "String",
 "labelName" : "String",
 "labelPrice" : 0,
 "isDefault" : 0,
 "relatedItems" : [{
 "itemId" : "String",
 "itemCode" : "String",
 "quantity" : 0,
 "priceType" : 0
 }]
 }],
 "freeSpecIds" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
