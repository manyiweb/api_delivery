# 品牌端-集点卡活动会员集卡信息列表

**请求URL：** 
- `/activity/web/pointCard/member/list/{source}`
- `id=pointcard_gift_list`
- `source=MYSQL`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|keyword|否|String| 关键词(模糊搜索)|
|giftCode|否|List| 优惠(卷、包)编码|
|giftName|否|List| 优惠(卷、包)名称|
|status|否|List| 集点状态 状态 0:未集满 1：已集满 2：已兑换|
|id|否|String||
|pageSize|否|Integer||
|pageNo|否|Integer||
|sortField|否|String||
|sortDirection|否|String||

### 请求参数Json格式
 
```
{
 "keyword" : "String",
 "giftCode" : null,
 "giftName" : null,
 "status" : null,
 "id" : "String",
 "pageSize" : 0,
 "pageNo" : 0,

 "sortDirection" : "String"
}
```
