# 小程序集点卡获取礼品列表
 

**请求URL：** 
- `/activity/appc/pointCard/giftList`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||

### 请求参数Json格式
 
```
{
 "id" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--id|否|Long| 礼物id|
|--giftId|否|String| 礼品id|
|--giftType|否|Integer| 礼品类型 0：优惠券 1：券包|
|--giftName|否|String| 礼品名称|
|--beginDate|否|DateTime| 开始有效期|
|--endDate|否|DateTime| 结束有效期|
|--status|否|Integer| 状态 status 0：可兑换 1：已兑完|
|--couponType|否|Integer| 优惠券类型 0：现金券、1：折扣券、2：兑换券、3：运费券|
|--price|否|Double| 优惠券金额|
|--discount|否|Double| 优惠券折扣|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "id" : 0,
 "giftId" : "String",
 "giftType" : 0,
 "giftName" : "String",
 "beginDate" : "DateTime",
 "endDate" : "DateTime",
 "status" : 0,
 "couponType" : 0,
 "price" : 0,
 "discount" : 0
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
