# 小程序获取集点信息
 

**请求URL：** 
- `/activity/appc/pointCard/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||

### 请求参数Json格式
 
```
{
 "id" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long| 主键|
|--activityCode|否|String| 活动编码|
|--activityName|否|String| 活动名称|
|--activityRule|否|String| 活动规则|
|--beginDate|否|DateTime| 开始日期|
|--endDate|否|DateTime| 结束日期|
|--point|否|Integer| 点数|
|--memberPoints|否|Integer| 会员当前拥有的点数|
|--status|否|Integer| 集点卡状态 0:未开始 1：进行种 2：已结束|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "activityCode" : "String",
 "activityName" : "String",
 "activityRule" : "String",
 "beginDate" : "DateTime",
 "endDate" : "DateTime",
 "point" : 0,
 "memberPoints" : 0,
 "status" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
