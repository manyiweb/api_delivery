# 集点卡-详情

**请求URL：** 
- `/activity/web/pointCard/detail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||
|sword|否|String||

### 请求参数Json格式
 
```
{
 "id" : 0,
 "sword" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--pointCard|否|Object| 集卡点活动-基础信息|
|----id|否|Long||
|----activityCode|否|String| 活动编码|
|----activityName|是|String| 活动名称|
|----beginDate|是|DateTime| 有效期开始|
|----endDate|是|DateTime| 有效期结束|
|----isActive|否|Boolean| 是否启用|
|----activityRule|是|String| 活动规则|
|----point|是|Integer| 集点数|
|----statisticalType|是|Integer| 统计类型 0：按实收金额 1：按下单数量|
|----consumeType|否|Integer| 消费类型 0：满 1：每满|
|----consumeCondition|否|Double| 消费条件 金额或数量|
|----offlineScene|否|Boolean| 线下场景|
|----onlineScene|否|Boolean| 线上场景|
|----itemType|是|Integer| 应用商品类型 0：所有 1：指定|
|----activeCodes|否|String| 活跃状态编码 ATV001-未开始，ATV002-进行中，ATV003-已过期|
|----activeName|否|String| 活跃状态中文|
|----createDate|否|DateTime| 创建时间|
|----createName|否|String| 创建人|
|--pointCardItemList|否|List| 集卡点活动-商品|
|----pointCardId|否|Long| 集点卡id|
|----itemId|否|String| 商品id|
|----skuBarcode|否|String| 商品sku码|
|----specId|否|String| 规格id|
|----itemCode|否|String| 商品编码|
|----itemName|否|String| 商品名称|
|--pointCardGiftList|否|List| 集卡点活动-礼品|
|----id|否|Long| 主键|
|----pointCardId|否|Long| 集点卡id|
|----giftType|否|Integer| 礼品类型 0：优惠券 1：券包|
|----giftId|否|String| 礼品id|
|----giftCode|否|String| 礼品编码|
|----giftName|否|String| 礼品名称|
|----giftNum|否|Integer| 礼品数量|
|--pointCardActivityDecoration|否|Object| 集卡点活动-装修|
|----id|否|String| 主键|
|----pointCardId|否|Long| 集点卡id|
|----activityBackGroundFullUrl|否|String| 活动背景图|
|----pointIconStyle|否|String| 集点图标样式 样式1-001，样式2-002，样式3-003|
|----unLightFullUrl|否|String| 集点图案-未点亮|
|----lightFullUrl|否|String| 集点图案-点亮|
|----pointNum|否|Integer| 单行显示点数|
|----decorationStyle|否|Object| 装饰风格|
|------iconSize|否|Integer| 图标大小|
|------areaWidth|否|Integer| 区域相对宽度|
|------verticalSpace|否|Integer| 集点上下间距|
|------levelSpace|否|Integer| 集点水平(左右)间距|
|----pointCardExchangeFullUrl|否|String| 集中点兑换页-图片|
|----groupId|否|String| 品牌Id|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
