# 品牌端-集点卡活动列表查询

**请求URL：** 
- `/activity/web/pointCard/list/{source}`
- `id=pointcard_active_list`
- `source=MYSQL`
**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|keyword|否|String| 关键词(模糊搜索)|
|isActive|否|List| 是否启用|
|activeCodes|否|List| 活跃状态-编号|
|effectiveDate|否|Object| 有效期|
|--start|否|DateTime|有效期开始|
|--end|否|DateTime|有效期结束|
|id|否|String||
|pageSize|否|Integer||
|pageNo|否|Integer||
|sortField|否|String||
|sortDirection|否|String||

### 请求参数Json格式
 
```
{
 "keyword" : "String",
 "isActive" : null,
 "activeCodes" : null,
 "effectiveDate" : {
 "start" : "DateTime",
 "end" : "DateTime"
 },
 "id" : "String",
 "pageSize" : 0,
 "pageNo" : 0,
 "sortField" : "String",
 "sortDirection" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--content|否|List||
|----id|否|Long| 活动id|
|----activityCode|否|String| 活动编号|
|----activityName|否|String| 活动名称|
|----point|否|Integer| 集点数|
|----beginDate|否|DateTime| 有效期开始|
|----endDate|否|DateTime| 有效期结束|
|----isActive|否|Boolean| 是否启用|
|----isActiveName|否|String| 是否启用-中文|
|----activeStatus|否|String| 活动状态|
|----activeStatusName|否|String| 活动状态-中文|
|----createDate|否|DateTime| 创建时间|
|----createName|否|String| 创建人|
|--pageSize|否|Integer||
|--pageNo|否|Integer||
|--total|否|Long||
|--totalPage|否|Integer||
|--hasNextPage|否|Boolean||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
