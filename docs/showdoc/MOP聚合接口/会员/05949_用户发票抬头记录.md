# 用户发票抬头记录
 

**请求URL：** 
- `/mem/retail/invoice/title/search`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|titleType|否|String|抬头类型，PERSONAL(个人)、ENTERPRISE(单位) |
|memberId|是|String| 会员标识(B端必传)|
|sword|否|String||

|id|否|String||
|orderField|否|String| 排序字段|
|orderSort|否|String| 排序方式|

|--items|否|List||
|----itemName|否|String||
|----itemValue|否|String||
|----minValue|否|String||
|----maxValue|否|String||
|----isCustom|否|String||
|----isRange|否|String||
|----isSelect|否|String||
|--current|否|Object||
|----itemName|否|String||
|----itemValue|否|String||
|----minValue|否|String||
|----maxValue|否|String||
|----isCustom|否|String||

|----isSelect|否|String||

|--pageIndex|否|Integer||
|--pageSize|否|Integer||

|status|否|Integer| 状态|
