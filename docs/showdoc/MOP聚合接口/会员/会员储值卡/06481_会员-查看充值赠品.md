#

@Title: cardTopUp </p>


@Description: 会员-查看充值赠品 </p>
 

**请求URL：** 
- `retail/app/Business/Member/getDcardAction`

**请求方式：**
- undefined
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|cardOrderId|是|String| 服务卡充值id|

### 请求参数Json格式
 
```
{
 "cardOrderId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--id|否|String||
|--orderId|否|String| 订单标识|
|--memberId|否|String| 会员标识|
|--planId|否|String| 来源标识DCardOptions关联|
|--typeCode|否|String| 储值卡类型 ShoppingCard 购物卡 ServiceCard 服务卡|
|--typename|否|String| 储值卡类型名称|
|--giveTypeCode|否|String| 赠送类型 Coupon优惠券,Integral积分,MItem商品,SMemberBenefitBuyOrder会员权益天数 ,MemberGrowth成长值|
|--giveTypeName|否|String| 赠送类型名称|
|--couponId|否|String| 优惠券编码|
|--itemId|否|String| 赠送的商品标识|
|--itemName|否|String| 赠送的商品标识|
|--specId|否|String| 商品规格标识|
|--specName|否|String| 赠送的商品标识|
|--giveCoutn|否|Integer| 赠送数量|
|--giveCount|否|Integer| 赠送数量|
|--memberIntegral|否|Double| 赠送会员积分|
|--memberGrowthValue|否|Double| 赠送的成长值|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|
