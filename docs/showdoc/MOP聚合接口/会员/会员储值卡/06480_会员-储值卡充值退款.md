#

@Title: cardTopUp </p>


@Description: 会员-储值卡充值退款 </p>
 

**请求URL：** 
- `/app/Business/Member/CardTop/refund`

**请求方式：**
- undefined
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|cardOrderId|是|String| 服务卡充值id|
|withdrawGiftFlag|否|Boolean| 是否退回赠品|
|reason|是|String| 原因|
|staffId|否|String| 导购id|
|staffName|否|String| 导购名称|
|forceReverse|否|Boolean| 是否强制撤销,遇到返回错误为：8001时，可以增加此参数进行强制撤销|

### 请求参数Json格式
 
```
{
 "cardOrderId" : "String",
 "withdrawGiftFlag" : true,
 "reason" : "String",
 "staffId" : "String",
 "staffName" : "String",
 "forceReverse" : true
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
