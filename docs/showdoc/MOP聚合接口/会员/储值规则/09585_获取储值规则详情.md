# 获取储值规则详情
 

**请求URL：** 
- `/config/stored/value/rule/detail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||
|sword|否|String||

### 请求参数Json格式
 
```
{
 "id" : 0,
 "sword" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long| id|
|--ruleCode|否|String| 规则编码|
|--ruleName|否|String| 规则名称|
|--effectiveTime|否|Integer| 生效时间 0：长期有效 1：固定时间|
|--beginTime|否|DateTime| 固定时间-开始时间|
|--endTime|否|DateTime| 固定时间-结束时间|
|--cycleType|否|Integer| 活动周期 0：每天 1：每周 2：每月|
|--days|否|String| 日期，1,2,3,4,5....|
|--periodType|否|Integer| 活动时段 0：全天 1：指定时间段|
|--periodRange|否|String| 时间段数组|
|--payAmount|否|Double| 实付金额|
|--rechargeMultiple|否|Integer| 充值倍数|
|--rechargeAmountSet|否|Integer| 充值金额设置 0向上取整 1去除小数|
|--status|否|Boolean| 活跃状态 0：禁用 1：启用|
|--priority|否|Integer| 优先级|
|--remark|否|String| 备注|
|--companyType|否|Integer| 门店类型 0：所有门店 1：指定门店|
|--createDate|否|DateTime| 创建时间|
|--createName|否|DateTime| 创建人|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
