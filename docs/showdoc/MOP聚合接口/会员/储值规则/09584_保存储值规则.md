# 保存储值规则
 

**请求URL：** 
- `/config/stored/value/rule/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long||
|ruleName|是|String| 规则名称|
|effectiveTime|是|Integer| 生效时间 0：长期有效 1：固定时间|
|beginTime|否|DateTime| 固定时间-开始时间|
|endTime|否|DateTime| 固定时间-结束时间|
|cycleType|是|Integer| 活动周期 0：每天 1：每周 2：每月|
|days|否|String| 日期，1,2,3,4,5....|
|periodType|是|Integer| 活动时段 0：全天 1：指定时间段|
|periodRange|否|String| 时间段数组|
|payAmount|是|Double| 实付金额|
|rechargeMultiple|是|Integer| 充值倍数|
|rechargeAmountSet|是|Integer| 充值金额设置 0向上取整 1去除小数|
|status|是|Boolean| 活跃状态 0：禁用 1：启用|
|priority|是|Integer| 优先级|
|remark|否|String| 备注|
|companyType|是|Integer| 门店类型 0：所有门店 1：指定门店|
|companyList|否|List| 门店列表,新增的|
|--companyId|否|String| 门店id|
|--companyCode|否|String| 门店编码|
|--companyName|否|String| 门店名称|
|deleteCompanyIdList|否|List| 要删除的门店id列表|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "ruleName" : "String",
 "effectiveTime" : 0,
 "beginTime" : "DateTime",
 "endTime" : "DateTime",
 "cycleType" : 0,
 "days" : "String",
 "periodType" : 0,
 "periodRange" : "String",
 "payAmount" : 0,
 "rechargeMultiple" : 0,
 "rechargeAmountSet" : 0,
 "status" : true,
 "priority" : 0,
 "remark" : "String",
 "companyType" : 0,
 "companyList" : [{
 "companyId" : "String",
 "companyCode" : "String",
 "companyName" : "String"
 }],
 "deleteCompanyIdList" : null
}
```

|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |

|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
