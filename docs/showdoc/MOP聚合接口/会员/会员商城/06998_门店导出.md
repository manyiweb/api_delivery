# 门店导出

**请求URL：** 
- `/config/assign/share/get/companys/export`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 会员商城设置-门店|
|keyword|否|String| 模糊查询关键字|
|pageIndex|否|Integer||
|pageSize|否|Integer||
|orderField|否|String||
|orderSort|否|String||

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "keyword" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--ErrorCode|否|String| 导出返回错误编码|
|--resultInt|否|Integer| 导出状态0-成功 1-失败|
|--resultString|否|String| 导出返回结果|
|--url|否|String| 导出下载连接|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "ErrorCode" : "String",
 "resultInt" : 0,
 "resultString" : "String",
 "url" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
