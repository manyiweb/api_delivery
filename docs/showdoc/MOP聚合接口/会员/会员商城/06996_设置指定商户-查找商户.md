# 设置指定商户-查找商户

**请求URL：** 
- `/config/assign/share/get/companys`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 会员商城设置-门店|
|keyword|否|String| 模糊查询关键字|
|pageIndex|否|Integer||
|pageSize|否|Integer||
|orderField|否|String||
|orderSort|否|String||

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "keyword" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--pageIndex|否|Integer||
|--pageSize|否|Integer||
|--pageCount|否|Integer||
|--totalCount|否|Long||
|--first|否|Boolean||
|--last|否|Boolean||
|--content|否|List||
|----id|否|Long||
|----companyId|否|String| 门店id|
|----assignCompanyId|否|String| 指定门店id|
|----assignCompanyName|否|String| 指定门店名称|
|----assignCompanyCode|否|String| 指定门店编码|
|----takeNum|否|Integer| 订购量扣减顺序|
|----lineNum|否|Long| 行号|
|----shareItemType|否|Integer| 共享商品类型，0：所有商品，1：指定商品|
|----createId|否|String||
|----createName|否|String||
|----createDate|否|DateTime||
|----modifyId|否|String||
|----modifyName|否|String||
|----modifyDate|否|DateTime||
|----dbKey|否|Integer||
|----groupId|否|String||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
