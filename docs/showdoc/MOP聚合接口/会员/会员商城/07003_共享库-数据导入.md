# 共享库-数据导入

**请求URL：** 
- `/config/assign/share/add/companys/import`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
tokenId
file 文件
companyId String 最外层的门店Id


### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--totalCount|否|Integer| 导入总数量|
|--successCount|否|Integer| 成功导入数量|
|--errorCount|否|Integer| 失败数|
|--dataJson|否|List| 返回数据|
|--downloadURL|否|String| 失败数据下载地址|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "totalCount" : 0,
 "successCount" : 0,
 "errorCount" : 0,
 "dataJson" : null,
 "downloadURL" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
