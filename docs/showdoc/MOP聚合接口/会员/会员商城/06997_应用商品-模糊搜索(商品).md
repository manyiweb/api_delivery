# 应用商品-模糊搜索(商品)
 

**请求URL：** 
- `/config/assign/share/get/items`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 会员商城设置-门店|
|assignCompanyId|否|String| 共享库-门店|
|keyword|否|String| 模糊查询关键字|
|pageIndex|否|Integer||
|pageSize|否|Integer||
|orderField|否|String||
|orderSort|否|String||

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "assignCompanyId" : "String",
 "keyword" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--pageIndex|否|Integer||
|--pageSize|否|Integer||
|--pageCount|否|Integer||
|--totalCount|否|Long||
|--first|否|Boolean||
|--last|否|Boolean||
|--content|否|List||
|----id|否|Long||
|----retailMallStockAssignCompanyId|否|Long| 指定门店表的id|
|----itemId|否|String| 商品id|
|----itemName|否|String| 商品名称|
|----itemCode|否|String| 商品编码|
|----assignCompanyCode|否|String||
|----createId|否|String||
|----createName|否|String||
|----createDate|否|DateTime||
|----modifyId|否|String||
|----modifyName|否|String||
|----modifyDate|否|DateTime||
|----dbKey|否|Integer||
|----groupId|否|String||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
