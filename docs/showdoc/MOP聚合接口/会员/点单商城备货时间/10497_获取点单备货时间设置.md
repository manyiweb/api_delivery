# 获取点单备货时间设置
 

**请求URL：** 
- `/config/mealMall/stockUp/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String||

### 请求参数Json格式
 
```
{
 "companyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--isInherit|否|Boolean| 是否继承品牌|
|--enableItemStockUpTime|否|Boolean| 是否启用按商品配置备货时间|
|--itemType|否|Integer| 应用商品类型 0：指定商品 1：指定SKU 2：指定类别、品牌、系列|
|--items|否|List| 商品列表|
|----itemId|否|String| 商品id|
|----itemCode|否|String| 商品编码|
|----itemName|否|String| 商品名称|
|----specId|否|String| 规格id，可能为空|
|----specName|否|String| 规格名称，可能为空|
|----sku|否|String| sku码|
|----day|否|Integer| 备货天数|
|----hour|否|Integer| 备货小时|
|----minute|否|Integer| 备货分钟|
|--types|否|List| 分类列表|
|----type|否|Integer| 0：类别 1：品牌 2：系列|
|----categoryId|否|String| 类别id|
|----categoryCode|否|String| 类别编码|
|----categoryName|否|String| 类别名称|
|----day|否|Integer| 备货天数|
|----hour|否|Integer| 备货小时|
|----minute|否|Integer| 备货分钟|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
