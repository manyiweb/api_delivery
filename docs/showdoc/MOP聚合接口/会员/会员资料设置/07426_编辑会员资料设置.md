# 编辑会员资料设置
member服务
**请求URL：** 
- `/mem/information/edit`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| ID|
|status|否|Boolean| 活跃状态(1-启用;0-停用)|
|remark|否|String| 备注|
|questions|否|List| 问题列表|
|--id|否|Long| ID|
|--question|否|String| 问题|
|--description|否|String| 问题描述|
|--type|是|String| 问题类型（单选、多选、填空、时间）|
|--requiredField|是|Boolean| 是否必填字段|
|--questionOptions|否|List| 问题选项|
|----id|否|Long| ID|
|----optionContent|否|String| 选项|

### 请求参数Json格式
```
{
 "id" : 0,
 "status" : true,
 "remark" : "String",
 "questions" : [{
 "id" : 0,
 "question" : "String",
 "description" : "String",
 "type" : "String",
 "requiredField" : true,
 "checkType" : "String",
 "onlyImage" : true,
 "questionOptions" : [{
 "id" : 0,
 "optionContent" : "String"
 }]
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
