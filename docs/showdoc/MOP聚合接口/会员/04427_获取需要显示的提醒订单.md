# 获取需要显示的提醒订单

**请求URL：** 
- `/mem/order/notice `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|groupId|否|String| 品牌id|
|companyId|否|String| 门店id|
|orderShowCount|否|Integer| 订单展示数量|

###请求参数Json格式
 
```
{
 "groupId" : "String",
 "companyId" : "String",
 "orderShowCount" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--noticeOrderDtos|否|List| 需要提醒显示的销售订单|
|----phone|否|String| 会员手机号|
|----headImage|否|String| 会员头像|
|----totalMoney|否|Double| 总金额|
|----memberId|否|String| 关联会员表smember 会员id|
|----memberName|否|String| 会员名称|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : {
 "noticeOrderDtos" : [{
 "phone" : "String",
 "headImage" : "String",
 "totalMoney" : 0,
 "memberId" : "String",
 "memberName" : "String"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
