# 拉拽移动积分商品
 

**请求URL：** 
- `/mem/gift/drag `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|rangeGiftIdList|是|array| 拉拽范围积分商品id|
|isDropDown|是|int| 往上移动=0； 往下移动=1|

###请求参数Json格式
 
```
{
 "isDropDown": 0,
 "tokenId":"f17dfccd60724d9ebc9c983eecbe0f9d",
 "rangeGiftIdList": [
 "fd972ecb9f6c4ce1935da66c7520e55f",
 "422645f932ea4fac9fbde4d7025b1f7f",
 "72aa05c3490f4b9eb714d8f42ddaf8c5",
 ],
}
```

{
 "code": "200",
 "data": null,
 "msg": ""
}
