# 千人千面发券-详情
 

**请求URL：** 
- `/activity/thousandFaces/getDetail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||
|sword|否|String||

### 请求参数Json格式
 
```
{
 "id" : 0,
 "sword" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long| id|
|--activityName|否|String| 活动名称|
|--beginDate|否|DateTime| 开始时间|
|--endDate|否|DateTime| 结束时间|
|--isActive|否|Boolean| 是否启用|
|--activeStatusName|否|String| 活动时效|
|--priority|否|Integer| 优先级|
|--enableMemberTag|否|Boolean| 是否启用会员标签|
|--enableMemberSmartTag|否|Boolean| 是否启用会员智能标签|
|--tagRelation|否|Integer| 标签关系 0或 1且|
|--url|否|String| 弹窗显示页面|
|--urlTypeName|否|String| 弹窗显示页面名称|
|--popUpFrequency|否|Integer| 弹窗频率 0：活动期间仅弹窗1次 1：活动期间弹窗n次|
|--popUpIntervalDay|否|Integer| 弹窗间隔天数|
|--popUpTimes|否|Integer| 弹窗总次数|
|--popUpTitle|否|String| 弹窗标题|
|--hideTitle|否|Boolean| 是否隐藏标题|
|--textColor|否|String| 弹窗文字颜色|
|--backgroundImage|否|String| 弹窗背景图|
|--applyCompType|否|Integer| 应用门店类型 0：所有门店 1：指定门店|
|--memberTags|否|List| 会员标签|
|----tagId|否|String| 标签id|
|----tagCode|否|String| 标签编码|
|----tagName|否|String| 标签名称|
|--memberSmartTags|否|List| 会员智能标签|
|----tagId|否|String| 标签id|
|----tagCode|否|String| 标签编码|
|----tagName|否|String| 标签名称|
|--coupons|否|List| 优惠券列表|
|----couponId|否|String| 优惠券id|
|----couponCode|否|String| 优惠券编码|
|----couponName|否|String| 优惠券名称|
|----num|否|Integer| 每人派发数量|
|----totalNum|否|Integer| 派发总数|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
