# 千人千面发券-查询门店列表
 

**请求URL：** 
- `/activity/thousandFaces/getCompanyList`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long||
|orderField|否|String||
|orderSort|否|String||
|tokenId|否|String||
|pageIndex|是|Integer||
|pageSize|是|Integer||
|sword|否|String||

### 请求参数Json格式
 
```
{
 "id" : 0,
 "orderField" : "String",
 "orderSort" : "String",
 "tokenId" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "sword" : "String"
}
```
