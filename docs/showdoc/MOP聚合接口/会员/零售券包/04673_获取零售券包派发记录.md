# 获取零售券包派发记录

**请求URL：** 
- `/mem/ticket/packages/recordlist `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|ticketPackagesId|否|Long||
|pageIndex|否|Integer| 页号|
|pageSize|否|Integer| 页大小|
|orderField|否|String| 商品排序字段|
|orderSort|否|String| 商品排序方式 desc 倒序 asc 正序|

###请求参数Json格式
 
```
{
 "ticketPackagesId" : 0,
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--pageIndex|否|Integer| 页码|
|--pageSize|否|Integer| 显示记录数|
|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|--first|否|Boolean| 首页|
|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|
|----id|否|Long||
|----ticketPackagesId|否|Long| 零售券包id|
|----couponIds|否|String| 领取的券包id|
|----isDel|否|Boolean| 是否删除(0-未删除 1-已删除)|
|----isUse|否|Boolean| 是否已使用(0-未使用 1-已使用)|
|----memberId|否|String| 会员id|
|----memberName|否|String| 会员名称|
|----memberPhone|否|String| 会员手机号|
|----receiveDate|否|DateTime| 领取时间|
|----createId|否|String| 创建人id|
|----createName|否|String| 创建人|
|----createDate|否|DateTime| 创建时间|
|----modifyId|否|String| 修改人id|
|----modifyName|否|String| 修改人|
|----modifyDate|否|DateTime| 修改时间|
|----dbKey|否|Integer| 分库标识|
|----groupId|否|String| 品牌商id|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
