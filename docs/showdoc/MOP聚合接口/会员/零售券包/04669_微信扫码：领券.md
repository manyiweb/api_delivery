# 微信扫码：领券

**请求URL：** 
- `/mem/ticket/packages/getCoupon `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|ticketPackagesQrcodeId|否|Long| 券包二维码记录id|
|openId|否|String| 微信openId|
|channelCode|否|String| 渠道编码|

###请求参数Json格式
 
```
{
 "ticketPackagesQrcodeId" : 0,
 "openId" : "String",
 "channelCode" : "String"
}
```
