# 获取会员领到的券信息

**请求URL：** 
- `/mem/ticket/packages/obtainInfo `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|memberId|否|String| 会员id|
|ticketPackagesId|否|Long| 券包id|

###请求参数Json格式
 
```
{
 "memberId" : "String",
 "ticketPackagesId" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--id|否|Long| 主键id|
|--couponId|否|String| 优惠券id|
|--couponCode|否|String| 优惠券编码|
|--couponName|否|String| 优惠券名称|
|--couponQty|否|Integer| 优惠券数量|
|--obtainQty|否|Integer| 领取到的数量|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : [{
 "id" : 0,
 "couponId" : "String",
 "couponCode" : "String",
 "couponName" : "String",
 "couponQty" : 0,
 "obtainQty" : 0
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
