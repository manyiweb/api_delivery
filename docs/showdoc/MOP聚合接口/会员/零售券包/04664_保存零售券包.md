# 保存零售券包
 

**请求URL：** 
- `/mem/ticket/packages/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|ticketPackagesId|否|Long| 零售券包id ---> 保存的需要传|
|ticketPackagesName|是|String| 券包名称|
|ticketPackagesQty|是|Integer| 券包数量|
|remark|否|String| 备注|
|active|是|Integer| 活跃状态 0：停用 1：启用|
|couponDetails|否|List| 关联的优惠券|
|--id|否|Long| 主键id|
|--couponId|是|String| 优惠券id|
|--couponCode|是|String| 优惠券编码|
|--couponName|是|String| 优惠券名称|
|--couponQty|是|Integer| 优惠券数量|
|--obtainQty|否|Integer| 领取到的数量|
|--ticketPackagesId|否|Long||
|createItem|否|Boolean| 是否创建关联商品|
|item|否|Object| 创建商品请求|
|--itemCode|否|String| 商品编码|
|--itemName|否|String| 商品名称|
|--itemTypeCode|否|String| 商品分类编码|
|--unit|否|String| 单位|
|--skuBarcode|否|String| sku码|
|--salePrice|否|Double| 建议零售价|
|--costPrice|否|Double| 成本价|
|--isActive|否|Integer| 活跃状态|
|--isMutiSpec|否|Integer| 是否多规格|
|--costTypeCode|否|String| 成本计算方法|
|--imageList|否|List| 商品图片|
|--isStock|否|Integer| 库存物料|
|--isSaleItem|否|Integer| 零售物料|
|--isNegativeStock|否|Integer| 负库存|
|--companyIds|否|List| 门店id|

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|
