# 微信扫码: 获取券信息

**请求URL：** 
- `/mem/ticket/packages/detail `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|ticketPackagesQrcodeId|否|Long| 券包二维码记录id|
|openId|否|String| 微信openId|
|channelCode|否|String| 渠道编码|

###请求参数Json格式
 
```
{
 "ticketPackagesQrcodeId" : 0,
 "openId" : "String",
 "channelCode" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--received|否|Boolean| 会员是否领取过券|
|--success|否|Boolean| 用户是否领券成功|
|--unReceiveQty|否|Integer| 优惠券包剩余数量|
|--couponDetails|否|List| 券包包含的券信息|
|----id|否|Long| 主键id|
|----couponId|否|String| 优惠券id|
|----couponCode|否|String| 优惠券编码|
|----couponName|否|String| 优惠券名称|
|----couponQty|否|Integer| 优惠券数量|
|----obtainQty|否|Integer| 领取到的数量|
|--receiveCouponInfos|否|List| 会员领取到的券信息|
|----couponId|否|String| 优惠券标识|
|----couponCode|否|String| 优惠券编码|
|----title|否|String| 优惠券标题|
|----couponType|否|Integer| 优惠券类型 现金券0 折扣券1 兑换券2|
|----couponTypeName|否|String| 优惠券类型名称|
|----detail|否|String| 优惠券描述|
|----useLimitAmt|否|Double| 限额|
|----qty|否|Integer| 优惠券可领取数量|
|----issueQty|否|Integer| 优惠券已领取数量|
|----dateTypeCode|否|String| 有效期计算方式 PeriodTime-固定时间段 FixedDays-固定天数|
|----beginDate|否|String| 开始时间|
|----endDate|否|String| 结束时间|
|----days|否|Integer| 有效期天数|
|----isActive|否|Integer| 是否有效|
|----isAllComp|否|Integer| 是否应用到所有门店|
|----isAllItem|否|Integer| 是否应用到所有商品|
|----discount|否|Double| 优惠折扣 couponType = 1|
|----price|否|Double| 优惠金额 couponType = 0|
|----isGet|否|String| 是否已领取|
|----isUsed|否|Integer| isGet = Y ，是否已使用|
|----isUsedName|否|String| isGet = Y ，是否已使用 描述|
|----usedTime|否|DateTime| isGet = Y ，使用时间|
|----isInvalid|否|Integer| 优惠券是否已失效，失效情况有优惠券停用、过期、已领完|
|----getTime|否|String| 领取时间|
|----otherReceive|否|Integer| 是否被他人领取，1是0否|
|----isUniqueCode|否|Integer| 请求码是否为优惠券唯一码,1是0否|
|----isTimeOut|否|Integer| 是否已到期 1是0否|
|----useLimits|否|List||
|------id|否|Long| id|
|------amount|否|Double| 满金额/满数量|
|------canUseQty|否|Integer| 可使用数量|
|------couponId|否|String| 优惠券ID，与mcoupon表关联|
|------createId|否|String| 创建人|
|------createName|否|String| 创建人名称|
|------createDate|否|DateTime| 创建时间|
|------modifyId|否|String| 修改人标识|
|------modifyName|否|String| 修改人名称|
|------modifyDate|否|DateTime| 修改时间|
|------dbKey|否|Integer| 分库标识|
|------groupId|否|String| 品牌商id|
|----useLimitType|否|Integer| 限制纬度 0按金额 1按数量|
|----obtainQty|否|Integer| 领取该券的数量|
|----useLimit|否|Integer| 使用限制 0不可叠加使用(默认) 1可叠加使用 2可叠加使用(阶梯)|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
