# 零售券包唯一码导出

**请求URL：** 
- `/file/export/ticket/packages/unique/qrcode`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|ticketPackageIds|是|Long| 零售券包id|
|wxSn|否|String| 微信标识|
|isHyaline|否|Integer| 是否需要透明底色，为1时生成透明底色的二维码|
|quantity|否|Integer| 生成的数量|

### 请求参数Json格式
 
```
{
 "ticketPackageIds" : 0,
 "wxSn" : "String",
 "isHyaline" : 0,
 "quantity" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--downloadURL|否|String| 错误数据下载地址|
|--totalCount|否|Long| 总数|
|--successCount|否|Long| 成功数|
|--errorCount|否|Long| 错误数|
|--code|否|Integer||
|--isTask|否|Boolean||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "downloadURL" : "String",
 "totalCount" : 0,
 "successCount" : 0,
 "errorCount" : 0,
 "code" : 0,
 "isTask" : true
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
