# 获取零售券包详情
 

**请求URL：** 
- `/mem/ticket/packages/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|ticketPackagesId|是|Long| 零售券包id|

### 请求参数Json格式
 
```
{
 "ticketPackagesId" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long| 零售券包主键|
|--ticketPackagesCode|否|String| 券包编码|
|--ticketPackagesName|否|String| 券包名称|
|--ticketPackagesQty|否|Integer| 券包数量|
|--status|否|String| 状态|
|--active|否|Integer| 状态 0 停用 1 启用|
|--remark|否|String| 备注|
|--createDate|否|DateTime| 创建时间|
|--createId|否|String| 创建人id|
|--createName|否|String| 创建人|
|--receiveQty|否|Integer| 领取数量|
|--itemId|否|String| 商品id|
|--itemName|否|String| 商品名称|
|--couponDetailList|否|List| 优惠券列表|
|----id|否|Long| 主键id|
|----couponId|是|String| 优惠券id|
|----couponCode|是|String| 优惠券编码|
|----couponName|是|String| 优惠券名称|
|----couponQty|是|Integer| 优惠券数量|
|----obtainQty|否|Integer| 领取到的数量|
|----ticketPackagesId|否|Long||
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|
