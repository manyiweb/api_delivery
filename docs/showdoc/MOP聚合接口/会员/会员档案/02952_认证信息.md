# 认证信息
 

**请求URL：** 
- `/hr/staff/authentication/info `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|否|String||
|staffId|否|String|用户id|

###请求参数Json格式
 
```
{
 "tokenId" : "String",
 "staffId" : "String"
}
```

|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
