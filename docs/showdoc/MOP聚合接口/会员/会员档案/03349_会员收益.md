# 会员收益

**请求URL：** 
- `/mem/member/spokesmancontribution `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|memberId|否|String| 会员id|
|incomeType|否|Integer| 1全部 2带入账 3已入账|
|pageIndex|否|Integer| 页号|
|pageSize|否|Integer| 页大小|
|orderField|否|String| 商品排序字段|
|orderSort|否|String| 商品排序方式 desc 倒序 asc 正序|

###请求参数Json格式
 
```
{
 "memberId" : "String",
 "incomeType" : 0,
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--shoppingAmount|否|Double| 购物卡可用余额|
|--shoppingRechargeAmount|否|Double| 购物卡赠送余额|
|--shoppingGiftAmount|否|Double| 购物卡赠送余额|
|--serviceAmount|否|Double| 服务卡可用余额|
|--serviceRechargeAmount|否|Double| 服务卡充值余额|
|--serviceGiftAmount|否|Double| 服务卡赠送余额|
|--item|否|Object||
|----pageIndex|否|Integer| 页码|
|----pageSize|否|Integer| 显示记录数|
|----pageCount|否|Integer| 总页数|
|----totalCount|否|Long| 总记录数|
|----first|否|Boolean| 首页|
|----last|否|Boolean| 尾页|
|----content|否|List| 分页数据|
|------inChannel|否|String| 渠道|
|------companyName|否|String| 门店|
|------surplusIntegral|否|Double| 剩余积分|
|------cardMoney|否|Double| 返现金额|
|------cashbackStatus|否|Integer| 到账状态 0待入账 1已入账|
|------companyId|否|String||
|------createDate|否|DateTime||
|------behaviorCode|否|String||
|------remark|否|String||
|--hadNoIncomeAmount|否|Double| 待入账金额|
|--hadIncomeAmount|否|Double| 已入账金额|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
