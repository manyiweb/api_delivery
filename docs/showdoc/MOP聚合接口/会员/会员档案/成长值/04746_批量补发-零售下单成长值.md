# 批量补发-零售下单成长值

**请求URL：** 
- `/retail/growthValue/order/supply/again `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderIds|否|List| 待补发订单id|

###请求参数Json格式
 
```
{
 "orderIds" : ["String"]
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--orderId|否|String| 订单id|
|--orderNo|否|String| 订单编号|
|--growthValue|否|Double| 补发成长值|
|--supplyResult|否|Boolean| 是否补发成功|
|--message|否|String| 补发结果信息|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : [{
 "orderId" : "String",
 "orderNo" : "String",
 "growthValue" : 0,
 "supplyResult" : true,
 "message" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
