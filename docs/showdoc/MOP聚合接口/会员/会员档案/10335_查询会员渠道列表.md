# 查询会员渠道列表
 

**请求URL：** 
- `/mem/member/info/getMemberTokenData`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|memberId|否|String||
|openId|否|String||

### 请求参数Json格式
 
```
{
 "memberId" : "String",
 "openId" : "String"
}
```
