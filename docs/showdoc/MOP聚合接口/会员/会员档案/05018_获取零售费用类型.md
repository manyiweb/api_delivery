# 获取零售费用类型

**请求URL：** 
- `/config/appCode/v2/retailCostType/get `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|changeType|否|String| 费用变更方式 add增加 sub减少|

###请求参数Json格式
 
```
{
 "changeType" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--costTypeList|否|List| 费用类型列表|
|----costTypeCode|否|String| 费用类型编码|
|----costTypeName|否|String| 费用类型名称|
|--defaultCostType|否|Object| 费用类型---默认|
|----costTypeCode|否|String| 费用类型编码|
|----costTypeName|否|String| 费用类型名称|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "costTypeList" : [{
 "costTypeCode" : "String",
 "costTypeName" : "String"
 }],
 "defaultCostType" : {
 "costTypeCode" : "String",
 "costTypeName" : "String"
 }
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
