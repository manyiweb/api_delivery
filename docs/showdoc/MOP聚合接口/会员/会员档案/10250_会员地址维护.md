# 会员地址维护
 

**请求URL：** 
- `/reabam-core/app/Business/member/address/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|String| 地址id|
|memberId|是|String| 会员id|
|name|是|String| 姓名|
|phone|是|String| 手机|
|provinceName|是|String| 省|
|cityName|是|String| 市|
|regionName|是|String| 区|
|address|是|String| 详细地址|
|houseNumber|否|String| 门牌号|
|sex|否|Integer| 性别 1男 0女|
|longitude|否|Double| 经度|
|latitude|否|Double| 纬度|
|simpleAddress|否|String| 地址简称|
|isDefault|否|Integer| 是否默认，0否 1是，不传默认为0|
