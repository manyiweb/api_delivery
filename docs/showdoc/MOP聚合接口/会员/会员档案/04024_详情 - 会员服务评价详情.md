# 会员服务评价详情
 

**请求URL：** 
- `/mem/service/detail `

**请求方式：**
- POST
- FormData


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|

###请求参数Json格式
 
```
{
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--comments|否|List||
|----comment|否|String|评价选项 |
|----star|否|Integer|评分 |
|--id|否|Long||
|--companyId|否|String| 门店id|
|--companyName|否|String| 门店名称|
|--memberServiceBuyId|否|Long| 会员服务id|
|--useDate|否|DateTime| 服务使用时间|
|--useTimes|否|Integer| 服务使用次数|
|--comment|否|String| 评价，现用来标识是否已评价，已评价填‘Y’，未评价为空|
|--commentDate|否|DateTime| 评价时间|
|--memberId|否|String| 会员id|
|--createId|否|String| 创建人id|
|--createDate|否|DateTime| 创建时间|
|--createName|否|String| 创建人名称|
|--staffId|否|String| 服务导购id|
|--staffCode|否|String| 服务导购手机号|
|--staffName|否|String| 服务导购|
|--suggest|否|String| 其他建议|
|--remark|否|String| 核销备注|
|--bomType|否|Integer| bom类型：-1-非bom，0-生产bom，1-模板bom，2-固定bom|
|--cardSnapshotId|否|Long| 会员服务卡快照标识|
|--orderIntegral|否|Double| 核销赠送积分|
|--dbKey|否|Integer| 分库标识|
|--groupId|否|String| 品牌商id|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
