# 获取会员交易明细v3

**请求URL：** 
- `/app/Business/member/order/action/page`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|memberId|否|String||
|companyId|否|String||
|type|否|Object| 1-所有 2-待提货 3-退货|
|sword|否|String||
|tokenId|否|String||
|id|否|String||
|orderField|否|String| 排序字段|
|orderSort|否|String| 排序方式|
|searchBeans|否|List| 高级筛选条件|
|status|否|Integer| 状态|
|pageIndex|否|Integer| 页号|
|pageSize|否|Integer| 页大小|
|orderField|否|String| 商品排序字段|
|orderSort|否|String| 商品排序方式 desc 倒序 asc 正序|

|--page|否|Object||

|----pageSize|否|Integer| 显示记录数|
