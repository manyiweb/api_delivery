# 行业平台会员设置 新增/修改
 

**请求URL：** 
- `/mem/wallet/settings/update`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|groupId|是|String| 品牌标识|
|isMultiWallet|否|Boolean| 是否开启多钱包|
|walletTypeCode|否|String| 多钱包类型编码 merchant_type商户类型钱包,merchant_group商户组钱包,franchisee所属加盟商钱包|
|foldingDisplayUnsalableItem|否|Boolean| 启用点单页不可售商品自动折叠显示|
|enableSmartLabel|否|Boolean| 是否启用智能标签能力|
|enableMultiComp|否|Boolean| 是否启用储值余额子账户|
|entityCardIsMultiComp|否|Boolean| 是否启用实体卡余额门店子账户|
|allowUnlimitedGiveCoupon|否|Boolean| 智能派券允许无限制派发即到账|

### 请求参数Json格式
 
```
{
 "groupId" : "String",
 "isMultiWallet" : true,
 "walletTypeCode" : "String",
 "foldingDisplayUnsalableItem" : true,
 "enableSmartLabel" : true,
 "enableMultiComp" : true,
 "entityCardIsMultiComp" : true,
 "allowUnlimitedGiveCoupon" : true
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
