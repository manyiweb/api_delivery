# 获取企业会员属性

**请求URL：** 
- `/mem/super/member/attribute`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|memberId|否|String||

### 请求参数Json格式
 
```
{
 "memberId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--id|否|Long| 主键标识|
|--applyId|否|Long| 申请单id|
|--memberId|否|String| 会员id|
|--code|否|String| 属性（比如1-30）|
|--value|否|String| 属性值|
|--alias|否|String| 别名|
|--valueType|否|Integer| 0 任何值 1 序列|
|--isRequired|否|Boolean| 0 非必填 1 必填|
|--content|否|String| 内容值,多个值时以分号“;”隔开|
|--industryAttrId|否|Long| 行业属性id|
|--createId|否|String||
|--createName|否|String||
|--createDate|否|DateTime||
|--modifyId|否|String||
|--modifyName|否|String||
|--modifyDate|否|DateTime||
|--dbKey|否|Integer||
|--groupId|否|String||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
