# 查询会员生日修改记录

**请求URL：** 
- `/mem/member/birthdate/record/list`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|memberId|否|String| 会员id|
|startDate|否|DateTime||
|endDate|否|DateTime||
|pageIndex|否|Integer||
|pageSize|否|Integer||
