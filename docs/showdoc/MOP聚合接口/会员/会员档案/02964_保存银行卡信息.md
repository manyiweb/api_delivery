# 保存银行卡信息

**请求URL：** 
- `/hr/staff/add/bankcard `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|否|String||
|staffId|否|String|用户id|
|bankCard|否|String| 银行账号|
|bankCardName|否|String| 账户名称|
|bankName|否|String| 开户行号|

###请求参数Json格式
 
```
{
 "tokenId" : "String",
 "staffId" : "String",
 "bankCard" : "String",
 "bankCardName" : "String",
 "bankName" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long| ID|
|--bankCard|否|String| 银行账号|
|--bankCardName|否|String| 账户名称|
|--bankName|否|String| 开户行号|
|--modifyId|否|String| 修改人id|
|--modifyName|否|String| 修改人|
|--modifyDate|否|DateTime| 修改时间|
|--createId|否|String| 创建人id|
|--createName|否|String| 创建人|
|--createDate|否|DateTime| 创建时间|
|--staffId|否|String| 用户id|
|--dbKey|否|Integer| 分库标识|
|--groupId|否|String| 品牌商id|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "bankCard" : "String",
 "bankCardName" : "String",
 "bankName" : "String",
 "modifyId" : "String",
 "modifyName" : "String",
 "modifyDate" : "DateTime",
 "createId" : "String",
 "createName" : "String",
 "createDate" : "DateTime",
 "staffId" : "String",
 "dbKey" : 0,
 "groupId" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
