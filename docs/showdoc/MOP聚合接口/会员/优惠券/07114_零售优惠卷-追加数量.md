# 零售优惠卷-追加数量

**请求URL：** 
- `/mem/coupon/append/coupon/num`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|couponId|是|String| 优惠券id|
|appndNum|否|Integer| 追加优惠卷数量|

### 请求参数Json格式
 
```
{
 "couponId" : "String",
 "appndNum" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
