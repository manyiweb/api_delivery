# 新增保存优惠规则

**请求URL：** 
- `/mem/coupon/rule/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long||
|ruleName|否|String| 规则名称|
|ruleType|是|String| 规则类型 SHARE("同享"),MUTUAL( "互斥"),|
|status|否|Boolean| 状态|
|couponId|是|String| 规则对象id|
|couponReqList|否|List| 优惠券请求|
|--id|否|Long||
|--couponId|否|String| 规则对象id|
|--status|否|Integer| 状态|
|--isDelete|否|Boolean| 是否是删除|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "ruleName" : "String",
 "ruleType" : "String",
 "status" : true,
 "couponId" : "String",
 "couponReqList" : [{
 "id" : 0,
 "couponId" : "String",
 "status" : 0,
 "isDelete" : true
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Long||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : 0,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
