# 优惠规则详情

**请求URL：** 
- `/mem/coupon/rule/detail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||
|pageIndex|否|Integer||
|pageSize|否|Integer||
|orderField|否|String||
|orderSort|否|String||
|sword|否|String||

### 请求参数Json格式
 
```
{
 "id" : 0,
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String",
 "sword" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long||
|--ruleNo|否|String| 规则编码|
|--ruleName|否|String| 规则名称|
|--ruleType|否|String| 规则类型|
|--ruleTypeName|否|String| 规则类型|
|--status|否|Boolean| 状态|
|--couponId|否|String| 规则对象id|
|--couponName|否|String| 规则对象名称|
|--createId|否|String||
|--createName|否|String||
|--createDate|否|DateTime||
|--modifyId|否|String||
|--modifyName|否|String||
|--modifyDate|否|DateTime||
|--couponReqList|否|List| 优惠券|
|----id|否|Long||
|----ruleId|否|Long| 规则编码|
|----couponId|否|String| 规则对象id|
|----couponName|否|String| 对象名称|
|----couponType|否|String| 类型|
|----couponTypeName|否|String| 类型|
|----status|否|String| 状态|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
