# 会员服务卡子账号列表
 

**请求URL：** 
- `/mem/shopping/comp/list`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|memberId|否|String| 会员id|
|pageIndex|否|Integer||
|pageSize|否|Integer||
|orderField|否|String||
|orderSort|否|String||

### 请求参数Json格式
 
```
{
 "memberId" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--pageIndex|否|Integer||
|--pageSize|否|Integer||
|--pageCount|否|Integer||
|--totalCount|否|Long||
|--first|否|Boolean||
|--last|否|Boolean||
|--content|否|List||
|----id|否|Long||
|----amountId|否|String| 总余额记录id|
|----amount|否|Double| 会员储值卡余额,取值自购物卡的合计（shoppingamount serviceamount）|
|----depositAmount|否|Double| 累计充值金额|
|----consumeAmount|否|Double| 累计消费金额|
|----lastDepositAmount|否|Double| 最近一次充值金额|
|----lastDepositDate|否|DateTime| 最近一次充值时间|
|----walletId|否|Long| 钱包id|
|----memberId|否|String| 会员标识id,与smember关联|
|----companyId|否|String| 门店商户id,与商户表syscompany相关联|
|----companyName|否|String| 门店|
|----shoppingAmount|否|Double| 购物卡可用余额|
|----shoppingRechargeAmount|否|Double| 购物卡充值余额|
|----shoppingGiftAmount|否|Double| 购物卡赠送余额|
|----totalCashbackAmount|否|Double| 累计返现金额|
|----totalTakeCashAmount|否|Double| 累计提现金额|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
