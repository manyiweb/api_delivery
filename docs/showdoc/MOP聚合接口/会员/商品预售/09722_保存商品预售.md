# 保存商品预售
 

**请求URL：** 
- `/activity/pre/sale/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|
|activityName|是|String| 活动名称|
|isActive|是|Boolean| 活跃状态|
|activityRule|否|String| 活动规则|
|beginDate|是|DateTime| 开始时间|
|endDate|是|DateTime| 结束时间|
|selWaySelf|是|Boolean| 是否支持到店自取|
|selWayDelivery|是|Boolean| 是否支持同城配送|
|selWayExpress|是|Boolean| 是否支持快递配送|
|deliveryBeginDate|是|DateTime| 提货配送开始时间|
|deliveryEndDate|是|DateTime| 提货配送结束时间|
|limitTotalType|是|Integer| 可参与总次数类型 0：不限 1：限制|
|totalNum|否|Integer| 可参与的总次数|
|limitDayType|是|Integer| 每天可参与次数类型 0：不限 1：限制|
|dayNum|否|Integer| 每天可参与次数|
|limitItemType|是|Integer| 每个用户可购买每个商品个数 0：不限 1：限制|
|itemNum|否|Integer| 每个用户可购买每个商品个数|
|pageTitle|否|String| 页面标题|
|mainImage|否|String| 活动主图|
|shareTitle|否|String| 分享文案|
|shareImage|否|String| 分享图片|
|applyCompType|是|Integer| 应用门店类型 0：所有 1：指定|
|deleteItemIds|否|List| 删除的商品id列表|
|items|否|List| 商品列表|
|--itemId|否|String| 商品id|
|--itemName|否|String| 商品名|
|--sku|否|String| sku|
|--specId|否|String| 商品规格id|
|--specPrice|否|Double| 零售价|
|--preSalePrice|否|Double| 预售价|
|--preSaleStock|否|Integer| 预售商品库存|
|--preSaleVirtualSales|否|Integer| 虚拟销量|
|--preSaleSoldQuantity|否|Integer| 已售数量|
|deleteCompanyIds|否|List| 要删除的门店id|
|companys|否|List| 应用门店列表|
|--companyCode|否|String||
|--companyName|否|String||
|--companyId|否|String||
