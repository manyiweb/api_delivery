# 获取商品预售详情
 

**请求URL：** 
- `/activity/pre/sale/detail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||
|sword|否|String||

### 请求参数Json格式
 
```
{
 "id" : 0,
 "sword" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long| id|
|--activityCode|否|String| 活动编码|
|--activityName|否|String| 活动名称|
|--isActive|否|Boolean| 活跃状态|
|--activityRule|否|String| 活动规则|
|--beginDate|否|DateTime| 开始时间|
|--endDate|否|DateTime| 结束时间|
|--activityStatus|否|String| 活动状态|
|--selWaySelf|否|Boolean| 是否支持到店自取|
|--selWayDelivery|否|Boolean| 是否支持同城配送|
|--selWayExpress|否|Boolean| 是否支持快递配送|
|--deliveryBeginDate|否|DateTime| 提货配送开始时间|
|--deliveryEndDate|否|DateTime| 提货配送结束时间|
|--limitTotalType|否|Integer| 可参与总次数类型 0：不限 1：限制|
|--totalNum|否|Integer| 可参与的总次数|
|--limitDayType|否|Integer| 每天可参与次数类型 0：不限 1：限制|
|--dayNum|否|Integer| 每天可参与次数|
|--limitItemType|否|Integer| 每个用户可购买每个商品个数 0：不限 1：限制|
|--itemNum|否|Integer| 每个用户可购买每个商品个数|
|--pageTitle|否|String| 页面标题|
|--mainImage|否|String| 活动主图|
|--shareTitle|否|String| 分享文案|
|--shareImage|否|String| 分享图片|
|--applyCompType|否|Integer| 应用门店类型 0：所有 1：指定|
|--createName|否|String| 创建人|
|--createDate|否|DateTime| 创建时间|
|--items|否|List| 商品列表|
|----itemId|否|String| 商品id|
|----itemName|否|String| 商品名|
|----sku|否|String| sku|
|----specId|否|String| 商品规格id|
|----specPrice|否|Double| 零售价|
|----preSalePrice|否|Double| 预售价|
|----preSaleStock|否|Integer| 预售商品库存|
|----preSaleVirtualSales|否|Integer| 虚拟销量|
|----preSaleSoldQuantity|否|Integer| 已售数量|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
