# 功能描述: 查询-统计结果
 

**请求URL：** 
- `/mem/questionnaire/analysis `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long||
|pageIndex|否|Integer| 页号|
|pageSize|否|Integer| 页大小|

###请求参数Json格式
 
```
{
 "id" : 0,
 "pageIndex" : 0,
 "pageSize" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--pageIndex|否|Integer| 页码|
|--pageSize|否|Integer| 显示记录数|
|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|--first|否|Boolean| 首页|
|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|
|----id|否|Long| ID|
|----questionnaireId|否|Long| 调查问卷标识|
|----questionnaireNo|否|String| 调查问卷编码|
|----question|否|String| 问题|
|----description|否|String| 问题描述|
|----type|否|String| 问卷类型（单选、多选、填空、时间、地理位置、收集文件/图片、手机号、性别、身份证、电话号码、年龄，其他）|
|----requiredField|否|Boolean| 是否必填字段|
|----questionOptions|否|List| 关联选项|
|------id|否|Long| ID|
|------optionContent|否|String| 选项|
|------submitQuantity|否|Integer| 提交数量|
|------selected|否|Boolean| 是否选中|
|----submitQuantity|否|Integer| 提交数量|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|

 "questionOptions" : [{
 "id" : 0,
 "optionContent" : "String",

 "selected" : true
 }],
 "submitQuantity" : 0
 }]
 },

}
