# 功能描述: 分页-问卷
 

**请求URL：** 
- `/mem/questionnaire/list `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|sword|否|String||

|searchBeans|否|List| 高级筛选条件|
|--typeCode|否|String||
|--typeName|否|String||
|--dataType|否|String||

|--isLikeSearch|否|String||
|--items|否|List||
|----itemName|否|String||
|----itemValue|否|String||
|----minValue|否|String||
|----maxValue|否|String||
|----isCustom|否|String||
|----isRange|否|String||
|----isSelect|否|String||
|--current|否|Object||
|----itemName|否|String||
|----itemValue|否|String||
|----minValue|否|String||
|----maxValue|否|String||
|----isCustom|否|String||
|----isRange|否|String||
|----isSelect|否|String||
|--sword|否|String||
|--pageIndex|否|Integer||

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--pageIndex|否|Integer| 页码|
|--pageSize|否|Integer| 显示记录数|
|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|--first|否|Boolean| 首页|
|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|
|----id|否|Long| ID|
|----questionnaireNo|否|String| 调查问卷编码|
|----title|否|String| 调查问卷名称|
|----status|否|Boolean| 活跃状态(1-启用;0-停用)|
|----enableEditing|否|Boolean| 是否允许编辑|
|----remark|否|String| 备注|
|----modifyId|否|String| 修改人id|
|----modifyName|否|String| 修改人|
|----modifyDate|否|DateTime| 修改时间|
|----createId|否|String| 创建人id|
|----createName|否|String| 创建人|
|----createDate|否|DateTime| 创建时间|
|----questions|否|Object| 问题列表（分页）|
|------pageIndex|否|Integer| 页码|
|------pageSize|否|Integer| 显示记录数|
|------pageCount|否|Integer| 总页数|
|------totalCount|否|Long| 总记录数|
|------first|否|Boolean| 首页|
|------last|否|Boolean| 尾页|
|------content|否|List| 分页数据|
|--------id|否|Long| ID|
|--------questionnaireId|否|Long| 调查问卷标识|
|--------questionnaireNo|否|String| 调查问卷编码|
|--------question|否|String| 问题|
|--------description|否|String| 问题描述|
|--------type|否|String| 问卷类型（单选、多选、填空、时间、地理位置、收集文件/图片、手机号、性别、身份证、电话号码、年龄，其他）|
|--------requiredField|否|Boolean| 是否必填字段|
|--------questionOptions|否|List| 关联选项|
|----------id|否|Long| ID|
|----------optionContent|否|String| 选项|
|----------selected|否|Boolean| 是否选中|
|----enableSubmit|否|Boolean| 是否允许提交|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
