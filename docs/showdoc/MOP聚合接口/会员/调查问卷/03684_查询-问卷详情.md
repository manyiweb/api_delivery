# 查询-问卷详情

**请求URL：** 
- `/mem/questionnaire/detail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long| 模板id|
|orderId|否|String||
|pageIndex|否|Integer||
|pageSize|否|Integer||
|orderField|否|String||
|orderSort|否|String||

### 请求参数Json格式
 
```
{
 "id" : 0,
 "orderId" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long| ID|
|--questionnaireNo|否|String| 调查问卷编码|
|--title|否|String| 调查问卷名称|
|--status|否|Boolean| 活跃状态(1-启用;0-停用)|
|--enableEditing|否|Boolean| 是否允许编辑|
|--remark|否|String| 备注|
|--modifyId|否|String| 修改人id|
|--modifyName|否|String| 修改人|
|--modifyDate|否|DateTime| 修改时间|
|--createId|否|String| 创建人id|
|--createName|否|String| 创建人|
|--createDate|否|DateTime| 创建时间|
|--questions|否|Object| 问题列表（分页）|
|----pageIndex|否|Integer||
|----pageSize|否|Integer||
|----pageCount|否|Integer||
|----totalCount|否|Long||
|----first|否|Boolean||
|----last|否|Boolean||
|----content|否|List||
|------id|否|Long| ID|
|------questionnaireId|否|Long| 调查问卷标识|
|------questionnaireNo|否|String| 调查问卷编码|
|------question|否|String| 问题|
|------description|否|String| 问题描述|
|------type|否|String| 问卷类型（单选、多选、填空、时间、地理位置、收集文件/图片、手机号、性别、身份证、电话号码、年龄，其他）|
|------checkType|否|String| 校验类型：无数据校验(指不校验)、手机号校验、身份证校验、电话号码校验、纯数字|
|------requiredField|否|Boolean| 是否必填字段|
|------questionOptions|否|List| 关联选项|
|--------id|否|Long| ID|
|--------optionContent|否|String| 选项|
|--------submitQuantity|否|Integer| 提交数量|
|--------selected|否|Boolean| 是否选中|
|------submitQuantity|否|Integer| 提交数量|
|------onlyImage|否|Boolean| 提交数量|
|------lineNumber|否|Integer| 行号|
|------answer|否|String| 答案|
|--enableSubmit|否|Boolean| 是否允许提交|
|--enableForceAuthorization|否|Boolean| 提交问卷时候需要授权认证|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
