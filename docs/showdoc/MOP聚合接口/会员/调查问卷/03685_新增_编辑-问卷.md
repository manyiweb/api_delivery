# 新增/编辑-问卷

**请求URL：** 
- `/mem/questionnaire/edit`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| ID|
|title|是|String| 调查问卷名称|
|status|是|Boolean| 活跃状态(1-启用;0-停用)|
|remark|否|String| 备注|
|questions|否|List| 问题列表|
|--id|否|Long| ID|
|--question|否|String| 问题|
|--description|否|String| 问题描述|
|--type|是|String| 问题类型（单选、多选、填空、时间、地理位置、收集文件/图片、手机号、性别、身份证、电话号码、年龄，其他）|
|--requiredField|是|Boolean| 是否必填字段|
|--checkType|否|String| 校验类型：无数据校验(指不校验)、手机号校验、身份证校验、电话号码校验、纯数字|
|--onlyImage|否|Boolean| 仅允许上传图片|
|--questionOptions|否|List| 问题选项|
|----id|否|Long| ID|
|----optionContent|否|String| 选项|
|enableForceAuthorization|否|Boolean| 提交问卷时候需要授权认证|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "title" : "String",
 "status" : true,
 "remark" : "String",
 "questions" : [{
 "id" : 0,
 "question" : "String",
 "description" : "String",
 "type" : "String",
 "requiredField" : true,
 "checkType" : "String",
 "onlyImage" : true,
 "questionOptions" : [{
 "id" : 0,
 "optionContent" : "String"
 }]
 }],
 "enableForceAuthorization" : true
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
