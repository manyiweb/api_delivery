# 生成/查看-问卷二维码

**请求URL：** 
- `/mem/questionnaire/qrCode`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|wxSn|否|String| 小程序wxSn|
|id|是|Object||

### 请求参数Json格式
 
```
{
 "wxSn" : "String",
 "id" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--qrCodeUrl|否|String| 问卷二维码图片url|
|--qrCodeUrlBase64|否|String| 问卷二维码图片base64|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "qrCodeUrl" : "String",
 "qrCodeUrlBase64" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
