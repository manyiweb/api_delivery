# 多小程序管理应用门店

**请求URL：** 
- `/config/multiple/mini/program/company/add`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|appId|是|String| 小程序appId|
|companyList|是|List| 门店列表|
|--companyId|否|String| 门店id|
|--companyCode|否|String| 门店编码|
|--companyName|否|String| 门店名称|

### 请求参数Json格式
 
```
{
 "appId" : "String",
 "companyList" : [{
 "companyId" : "String",
 "companyCode" : "String",
 "companyName" : "String"
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
