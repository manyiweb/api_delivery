# 获取会员标签

**请求URL：** 
- `/mem/member/pos/tags`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|memberId|是|String||


### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--tagNames|否|List| 智能义标签|
|--tags|否|List| 自定义标签|
|----id|否|String||
|----version|否|Integer||
|----code|否|String||
|----content|否|String||
|----lineId|否|Integer||
|----memberId|否|String||
|----companyId|否|String||
|----dbKey|否|Integer||
|----groupId|否|String||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "tagNames" : null,
 "tags" : [{
 "id" : "String",
 "version" : 0,
 "code" : "String",
 "content" : "String",
 "lineId" : 0,
 "memberId" : "String",
 "companyId" : "String",
 "dbKey" : 0,
 "groupId" : "String"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
