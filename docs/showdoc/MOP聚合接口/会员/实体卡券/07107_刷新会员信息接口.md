# 刷新会员信息接口

**请求URL：** 
- `/mem/member/info/refresh`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
无参数


### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--integral|否|Double| 积分信息|
|--couponCount|否|Long| 优惠券数量|
|--cardMoney|否|Double| 会员购物卡余额|
|--cardBagNumbers|否|Double| 卡包数量|
|--memberGrowthValue|否|Double| 会员成长值|
|--backgroundImage|否|String| 个人中心背景图片|
|--timesCardBagNumbers|否|Double| 次卡数量|
|--memberDiscount|否|String| 会员折扣|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "integral" : 0,
 "couponCount" : 0,
 "cardMoney" : 0,
 "cardBagNumbers" : 0,
 "memberGrowthValue" : 0,
 "backgroundImage" : "String",
 "timesCardBagNumbers" : 0,
 "memberDiscount" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
