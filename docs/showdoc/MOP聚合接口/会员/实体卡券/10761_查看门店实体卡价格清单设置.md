# 查看门店实体卡价格清单设置

**请求URL：** 
- `/mem/entitycard/comp/price/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 门店标识|

### 请求参数Json格式
 
```
{
 "companyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--id|否|Long| id|
|--cardId|否|String| 卡档案id|
|--cardName|否|String| 价格清单id|
|--priceListId|否|String| 价格清单id|
|--priceListName|否|String| 价格清单名单|
|--companyId|否|String| 门店id|
|--usePriceDisableDiscount|否|Boolean| 参与促销/行优惠/整单优惠/优惠券/实体券后，不可享受价格清单|
|--createId|否|String||
|--createName|否|String||
|--createDate|否|DateTime||
|--modifyId|否|String||
|--modifyName|否|String||
|--modifyDate|否|DateTime||
|--dbKey|否|Integer||
|--groupId|否|String||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||

```
{

 "id" : 0,
 "cardId" : "String",

 "priceListId" : "String",

 "createDate" : "DateTime",

 "modifyName" : "String",

 "groupId" : "String"
 }],
 "msg" : "String",
 "code" : "String",

 "traceId" : "String"
}
```
