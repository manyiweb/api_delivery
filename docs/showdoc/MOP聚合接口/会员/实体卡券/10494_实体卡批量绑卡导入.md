# 实体卡批量绑卡导入
 

**请求URL：** 
- `/mem/entitycard/batchBindingCard/import`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|fid|否|String|选择的实体卡id|
|file|否|File|要上传的文件|


### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--dataList|否|List| 导入的数据|
|----id|否|String| 会员id|
|----memberName|否|String| 会员名称|
|----phone|否|String| 手机号|
|----cardNo|否|String| 绑定卡号|
|----password|否|String| 验证密码|
|----success|否|Boolean| 是否成功|
|--downloadUrl|否|String| 失败的链接数据|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "dataList" : [{
 "id" : "String",
 "memberName" : "String",
 "phone" : "String",
 "cardNo" : "String",
 "password" : "String",
 "success" : true
 }],
 "downloadUrl" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
