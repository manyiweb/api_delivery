# 实体卡-卡间转账卡号搜索
 

**请求URL：** 
- `/mem/entitycard/money/transfer/card`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|cardNo|否|String| 卡号|
|isElectronic|否|Boolean| 卡号|
|isChange|否|Boolean| 是否用做换旧卡|
|isWrite|否|Boolean| 是否用做写卡|
|isUntie|否|Boolean| 是否用做解绑|
|fromCardId|否|String| 来源卡号id 用作校验|

### 请求参数Json格式
 
```
{
 "cardNo" : "String",
 "isElectronic" : true,
 "isChange" : true,
 "isWrite" : true,
 "isUntie" : true,
 "fromCardId" : "String"
}
```
