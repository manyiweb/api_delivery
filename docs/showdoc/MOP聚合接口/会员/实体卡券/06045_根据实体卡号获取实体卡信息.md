# 根据实体卡号获取实体卡信息
 

**请求URL：** 
- `/mem/entitycard/getCardInfoByCardNo`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|cardNo|否|String| 卡号|
|isElectronic|否|Boolean| 卡号|
|isChange|否|Boolean| 是否用做换旧卡|
|isWrite|否|Boolean| 是否用做写卡|
|isUntie|否|Boolean| 是否用做解绑|
|fromCardId|否|String| 来源卡号id 用作校验|

### 请求参数Json格式
 
```
{
 "cardNo" : "String",
 "isElectronic" : true,
 "isChange" : true,
 "isWrite" : true,
 "isUntie" : true,
 "fromCardId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--fid|否|String| 卡id|
|--cardId|否|String| 卡id|
|--cardName|否|String| 卡名称|
|--cardNo|否|String| 卡号|
|--cardsId|否|String| 卡券号ids|
|--memberId|否|String| 绑定的会员id|
|--balance|否|Double| 余额|
|--rechargeBalance|否|Double| 充值余额|
|--giftBalance|否|Double| 赠送余额|
|--businessType|否|String| 业务类型|
|--businessTypeName|否|String| 业务类型名称|
|--canChange|否|Boolean| 是否允许换旧卡|
|--canMerge|否|Boolean| 是否可以合并卡|
|--canTransfer|否|Boolean| 是否可以卡间转账|
|--isEncrypted|否|Boolean| 是否加密|
|--encryptedContent|否|String| 加密内容|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
