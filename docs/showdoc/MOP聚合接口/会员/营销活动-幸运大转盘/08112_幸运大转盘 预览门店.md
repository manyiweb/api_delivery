# 幸运大转盘 预览门店

**请求URL：** 
- `/mem/activity//company/show`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|MerchantsTypeCodeList|否|List| 门店类型|
|companyGidList|否|List| 商户组|
|distributorCodeList|否|List| 经销商|
|joiningTraderCodeList|否|List| 加盟商|
|companyLabelIdList|否|List| 商户标签|
|merchantsAreafCodeList|否|List| 区域|
|mallOpen|否|Boolean| 1开启 0停用 商城|
|mealMallOpen|否|Boolean| 1开启 0停用 点单|
|whellActivityId|否|Long| 幸运大转盘活动id|
|pageIndex|否|Integer||
|pageSize|否|Integer||
|orderField|否|String||
|orderSort|否|String||
