# 功能描述: 幸运大转盘-获取活动配置详情，包括应用会员等级
 

**请求URL：** 
- `/activity/member/wheel/detail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||
|sword|否|String||

### 请求参数Json格式
 
```
{
 "id" : 0,
 "sword" : "String"
}
```

### 返回参数

|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long| id 主键|
