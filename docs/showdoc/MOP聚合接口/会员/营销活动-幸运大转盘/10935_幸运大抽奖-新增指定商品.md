# 幸运大抽奖-新增指定商品

**请求URL：** 
- `/activity/member/wheel/product/import`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
无参数


### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--downloadURL|否|String| 错误数据下载地址|
|--totalCount|否|Long| 总数|
|--successCount|否|Long| 成功数|
|--errorCount|否|Long| 错误数|
|--code|否|Integer| 执行操作返回的状态|
|--dataSource|否|List| 数据|
|----itemId|否|String||
|----itemCode|否|String||
|----itemName|否|String||
|----sku|否|String||
|----specId|否|String||
|----status|否|Boolean||
|----statusName|否|String||
|----msg|否|String||
|----msgList|否|List||
|----cellStyleMap|否|Map||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "downloadURL" : "String",
 "totalCount" : 0,
 "successCount" : 0,
 "errorCount" : 0,
 "code" : 0,
 "dataSource" : [{
 "itemId" : "String",
 "itemCode" : "String",
 "itemName" : "String",
 "sku" : "String",
 "specId" : "String",
 "status" : true,
 "statusName" : "String",
 "msg" : "String",
 "msgList" : null,
 "cellStyleMap" : null
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
