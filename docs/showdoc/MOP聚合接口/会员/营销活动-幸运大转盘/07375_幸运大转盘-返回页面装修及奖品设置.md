# 功能描述: 幸运大转盘-返回页面装修及奖品设置
 

**请求URL：** 
- `/activity/member/wheel/decoration`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||
|sword|否|String||

### 请求参数Json格式
 
```
{
 "id" : 0,
 "sword" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--wheelId|否|Long| 转盘活动id|
|--amount|否|Long| 抽奖板式格数，默认8个|
|--title|否|String| 抽奖标题|
|--bgImage|否|String| 抽奖背景图|
|--bgImageWidth|否|Integer| 背景图宽度|
|--bgImageHeight|否|Integer| 背景图高度|
|--btnImage|否|String| 抽奖按钮图片|
|--btnImageWidth|否|Integer| 按钮图宽度|
|--btnImageHeight|否|Integer| 按钮图高度|
|--fontColor|否|String| 字体颜色|
|--bgColor|否|String| 背景图颜色|
|--wheelPrizeResps|否|List| 奖品设置|
|----id|否|Long| id 主键|
|----probability|否|Double| 中奖概率|
|----type|否|Integer| 奖品类型编码：0-未中奖；1-积分；2-优惠券；3-服务商品|
|----typeName|否|String| 奖品类型名称|
|----prizeId|否|String| 奖品标识|
|----prizeName|否|String| 奖品名称|
|----prizeAmount|否|Long| 奖品数量|
|----image|否|String| 奖品图片|
|----imageWidth|否|Integer| 奖品图宽度|
|----imageHeight|否|Integer| 奖品图高度|
|--orderAmount|否|Double| 订单消费金额满|
|--ruleType|否|Integer| 活动要求：0-无条件、1-积分抽奖、2-单笔消费满、3-累计消费满、4-购买指定商品|
|--applyItemType|否|Integer| 商品应用类型：1-指定商品 2-指定分类、品牌、系列|
|--money|否|Double| 单笔消费满|
|--totalMoney|否|Double| 累计订单消费满|
|--timeType|否|Integer| 抽奖次数类型：0-每人每天、1-每人|
|--onOffLine|否|Integer| 线上线下标识 1线上 0线下|
|--losingLotteryImage|否|String| 未中奖效果图|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
