# 功能描述: 幸运大转盘-新增/编辑活动
 

**请求URL：** 
- `/activity/member/wheel/edit`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|type|否|Integer| 活动类型 1、会员 2、订货|
|id|否|Long| id|
|name|是|String| 活动名称|
|beginDate|是|DateTime| 有效期起|
|endDate|是|DateTime| 有效期至|
|status|是|Integer| 活跃状态|
|allComp|是|Integer| 是否应用到所有门店 1是0否|
|appComps|否|List| 应用门店列表，allComp = 1时必填|
|delComps|否|List| 删除应用门店ID列表，是应用门店的行ID|
|appGrade|否|Integer| 是否指定等级 1是0否|
|appGrades|否|List| 应用会员等级,覆盖更新，每次传最新的进来|
|rule|否|String| 活动规则|
|points|否|Integer| 每次消耗积分 0表示不消耗积分抽奖|
|orderAmount|否|Double| 订单消费金额满|
|orderTimes|否|Double| 订单次数|
|times|否|Integer| 每日抽奖次数限制 0表示不限制抽奖次数|
|amount|是|Long| 抽奖板式格数，默认8个|
|title|是|String| 抽奖标题|
|bgImage|否|String| 抽奖背景图|
|bgImageWidth|否|Integer| 背景图宽度|
|bgImageHeight|否|Integer| 背景图高度|
|btnImage|否|String| 抽奖按钮图片|
|btnImageWidth|否|Integer| 按钮图宽度|
|btnImageHeight|否|Integer| 按钮图高度|
|fontColor|否|String| 字体颜色|
|bgColor|否|String| 背景图颜色|
|prizes|否|List| 设置的奖品|
|--id|否|Long| id 主键|
|--probability|是|Double| 中奖概率|
|--type|是|Integer| 奖品类型标识，0-无；1-积分；2-优惠券；3-服务商品|
|--prizeId|否|String| 奖品标识|
|--prizeName|是|String| 奖品名称|
|--prizeAmount|否|Long| 奖品数量|
|--image|否|String| 奖品图片|
|--imageWidth|否|Integer| 奖品图宽度|
|--imageHeight|否|Integer| 奖品图高度|
|--prizeBackgroundColor|否|String| 奖品底色|
|ruleType|否|Integer| 活动要求：0-无条件、1-积分抽奖、2-单笔消费满、3-累计消费满、4-购买指定商品|
|applyItemType|否|Integer| 商品应用类型：1-指定商品 2-指定分类、品牌、系列|
|money|否|Double| 单笔消费满|
|totalMoney|否|Double| 累计订单消费满|
|timeType|否|Integer| 抽奖次数类型：0-每人每天可抽、1-每人可抽、2-每人每天可抽奖N次|
|shoppingScene|否|String| 消费场景|
|appProducts|否|List| 指定的商品|
|--sourceId|否|String| 前端用|
|--type|是|Integer| 1-商品 2-品牌 3-类别 4-系列|
|--name|否|String| 名称|
|--code|是|String| 编码|
|--sku|否|String| sku|
|losingLotteryImage|否|String| 未中奖效果图|
|enableFreeDraw|否|Boolean| 是否开启免费抽奖|
|enableOrderDraw|否|Boolean| 是否开启订单抽奖|
|enableIntegralDraw|否|Boolean| 是否开启积分抽奖|
|orderRuleType|否|Integer| 订单消费场景：0-单笔消费金额、1-累计消费金额|
|orderCalculateType|否|Integer| 订单消费计算类型：0-满、1-每满|
|drawLimitType|否|Integer| 抽奖次数限制类型 0：不限制 1：限制|
|drawLimitQuantity|否|Double| 抽奖次数限制数量|
|enableOrderGetLimit|否|Boolean| 是否限制单笔获取抽奖次数|
|orderGetLimitQuantity|否|Double| 单笔最多获取抽奖次数|
|remark|否|String| 备注|
|activityCycle|否|Integer| 活动周期 0：每日 1：每周 2：每月|
|activityDay|否|String| 活动日期|
|activityTimeType|否|Integer| 时间类型 0:全天 1:自定义|
|activityTimeRange|否|String| 时间区间数组|
|priority|否|Integer| 优先级|
|remainingTimesBgColor|否|String| 剩余次数底色|
|remainingTimesTextColor|否|String| 剩余次数文字颜色|
|turntableBottomBaseColor|否|String| 大转盘下底层颜色|
|turntableTopBaseColor|否|String| 大转盘上底层颜色|
|turntablePointerColor|否|String| 转盘指针颜色|
|drawButtonBgColor|否|String| 抽奖按钮底色|
|drawTextColor|否|String| 抽奖文字颜色|
|showMyPoints|否|Integer| 是否显示我的积分：0-否，1-是|
|showMyPrizes|否|Integer| 是否显示我的奖品：0-否，1-是|
|showActivityValidity|否|Integer| 是否显示活动有效期：0-否，1-是|
|pointsPrizesValidityTextColor|否|String| 积分、奖品有效期文字颜色|
