# 口令活动-列表查询
 datatableId:commmand_activity_list

**请求URL：** 
- `/activity/commmand/list/{source}`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|keyword|否|String| 关键词(模糊搜索)|
|activityDate|否|Object| 有效期|
|--start|否|DateTime||
|--end|否|DateTime||
|isActive|否|List| 是否启用|
|activeCodes|否|List| 活跃状态-编号|
|createDate|否|Object| 有效期|
|--start|否|DateTime||
|--end|否|DateTime||
|createId|否|Object| 创建人|
|--start|否|DateTime||
|--end|否|DateTime||
|id|否|String||
|pageSize|否|Integer||
|pageNo|否|Integer||
|sortField|否|String||
|sortDirection|否|String||
|viewId|否|String||
