# 小程序口令活动-详情

**请求URL：** 
- `/activity/appc/commmand/detail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||
|pageIndex|否|Integer||
|pageSize|否|Integer||
|orderField|否|String||
|orderSort|否|String||
|sword|否|String||

### 请求参数Json格式
 
```
{
 "id" : 0,
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String",
 "sword" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--rule|否|Object| 活动规则|
|----id|否|String| 主键|
|----activityId|否|Long| 活动id|
|----rule|否|String| 活动背景图|
|----getCommandRule|否|String| 口令获取说明|

|----buttonImageUrl|否|String| 按钮背景图|
|----buttonBackgroundColor|否|String| 按钮背景色|

|----shareImage|否|String| 分享图|
|----groupId|否|String| 品牌Id|
|--giftList|是|List| 赠品列表|
|----activityId|否|Long| 活动id|
|----giftType|是|String| 奖品类型 Coupon优惠券 Package券包|
|----giftId|是|String| 奖品id|
|----giftNum|是|Integer| 奖品数量|
|----giftName|是|String| 奖品名称|
|--compList|否|List| 门店列表|
|----id|否|Long| id|
|----activityId|否|Long| 活动id|
|----companyId|否|String| 门店id|
|----companyName|否|String| 门店id|
|----companyCode|否|String| 门店id|
|--id|否|Long| id|
|--activityName|是|String| 活动名称|
|--command|是|String| 口令|
|--beginDate|是|DateTime| 有效期起|
|--endDate|是|DateTime| 有效期至|
|--isActive|否|Boolean| 活跃状态|
|--remark|否|String| 备注|
|--allComp|是|Integer| 门店范围 0应用全部门店 1指定门店|
|--totalNumFlag|是|Boolean| 是否限制总库存|
|--totalNum|否|Long| 限制总库存数|
|--cycleNumFlag|是|Boolean| 是否限制周期库存|
|--cycleNum|否|Long| 限制周期库存数|
|--memberTotalTimesFlag|是|Boolean| 是否限制每人总参与次数|
|--totalTimes|否|Long| 限制每人总参与次数|
|--memberCycleTimesFlag|是|Boolean| 是否限制每人周期参与次数|
|--cycleTimes|否|Long| 每人限制周期内参与次数|
|--createId|否|String| 创建人id|
|--createName|否|String| 创建人|
|--createDate|否|DateTime| 创建时间|
|--modifyId|否|String| 修改人id|
|--modifyName|否|String| 修改人|
|--modifyDate|否|DateTime| 修改时间|
|--cycleNumType|否|String| 限制周期类型 day每日 week 每周 month每月|
|--memberCycleNumType|否|String| 限制周期类型 day每日 week 每周 month每月|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
