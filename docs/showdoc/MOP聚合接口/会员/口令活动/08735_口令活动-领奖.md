# 口令活动-领奖

**请求URL：** 
- `/activity/appc/commmand/receive/gift`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|command|是|String| 口令|
|id|是|Long| 口令|

### 请求参数Json格式
 
```
{
 "command" : "String",
 "id" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long| id|
|--activityId|否|Long| 活动id|
|--memberId|否|String| 会员id|
|--memberName|否|String| 会员id|
|--phone|否|String| 手机号|
|--giftNum|否|Long| 已领奖品数量|
|--createId|否|String||
|--createName|否|String||
|--createDate|否|DateTime||
|--modifyId|否|String||
|--modifyName|否|String||
|--modifyDate|否|DateTime||
|--dbKey|否|Integer||
|--groupId|否|String||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
