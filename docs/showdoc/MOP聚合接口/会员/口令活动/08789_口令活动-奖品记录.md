# 口令活动-奖品记录

**请求URL：** 
- `/activity/appc/commmand/receive/record`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||
|pageIndex|否|Integer||
|pageSize|否|Integer||
|orderField|否|String||
|orderSort|否|String||
|sword|否|String||

### 请求参数Json格式
 
```
{
 "id" : 0,
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String",
 "sword" : "String"
}
```

|--giftId|否|String| 礼品id|
|--giftCode|否|String| 礼品编码|
|--giftName|否|String| 礼品名称|
|--giftNum|否|Integer| 实际领取礼品数量|
|--createId|否|String||
|--createName|否|String||
|--createDate|否|DateTime||
|--modifyId|否|String||
|--modifyName|否|String||
|--modifyDate|否|DateTime||
|--dbKey|否|Integer||
|--groupId|否|String||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
