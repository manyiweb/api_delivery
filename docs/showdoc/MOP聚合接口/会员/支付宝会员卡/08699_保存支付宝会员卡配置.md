# 保存支付宝会员卡配置
 

**请求URL：** 
- `/reabam-wx/app/alipay/member/card/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|cardName|是|String| 会员卡名称|
|cardLogoId|是|String| 会员卡logo id|
|cardLogo|是|String| 会员卡logo|
|cardCoverImageId|是|String| 封面图id|
|cardCoverImage|是|String| 封面图|
|enablePhone|否|Boolean| 启用手机号码|
|enableName|否|Boolean| 启用姓名|
|enableNickname|否|Boolean| 启用昵称|
|enableSex|否|Boolean| 启用性别|
|enableBirthday|否|Boolean| 启用生日|

### 请求参数Json格式
 
```
{
 "cardName" : "String",
 "cardLogoId" : "String",
 "cardLogo" : "String",
 "cardCoverImageId" : "String",
 "cardCoverImage" : "String",
 "enablePhone" : true,
 "enableName" : true,
 "enableNickname" : true,
 "enableSex" : true,
 "enableBirthday" : true
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
