# 获取第三方系统配置
 

**请求URL：** 
- `/config/ThSystemDockSet/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 商户id|

### 请求参数Json格式
 
```
{
 "companyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--openThDock|否|Integer| 是否开启第三方对接|
|--thMemberConfig|否|String| 第三方渠道参数|
|--enableThirdCouponVerification|否|Integer| 是否启用第三方优惠券设置|
|--thirdCouponConfig|否|String| 第三方优惠券参数配置|
|--enableExternalCoupon|否|Integer| 是否启用外部优惠券|
|--externalCouponConfig|否|String| 外部优惠券参数配置|
|--thDeliveryUpdateStock|否|Boolean| 订单生成提货配送单时对应商品不扣减库存|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : {
 "openThDock" : 0,
 "thMemberConfig" : "String",
 "enableThirdCouponVerification" : 0,
 "thirdCouponConfig" : "String",
 "enableExternalCoupon" : 0,
 "externalCouponConfig" : "String",
 "thDeliveryUpdateStock" : true
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
