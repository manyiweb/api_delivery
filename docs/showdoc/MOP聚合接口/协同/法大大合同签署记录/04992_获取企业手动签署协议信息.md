# 获取企业手动签署协议信息

**请求URL：** 
- `/hr/fddContractSigningRecord/getCompanyContractInfo `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|returnUrl|是|String| 法大大接口同步通知url|
|id|是|Long| id|

###请求参数Json格式
 
```
{
 "returnUrl" : "String",
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--fddContractUrl|否|String| 法大大合同h5url,仅法大大流程获取合同内容时返回|
|--fddContractId|否|String| 法大大合同编号|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "fddContractUrl" : "String",
 "fddContractId" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
