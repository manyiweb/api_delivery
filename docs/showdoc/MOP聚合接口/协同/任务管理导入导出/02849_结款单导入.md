# 结款单导入

**请求URL：** 
- `/file/import/settlement/exceladd `

**请求方式：**
- POST
- FormData

**模板**
zhifuManageAdd	/Template/支付管理导入模板.xlsx

###请求参数<业务参数>
 
```
表单
tokenId
file
```


###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|--DataLine|否|List| 派单人员对象|
|----taskStatusName|否|String| 项目状态名|
|----taskCode|否|String| 项目单号|
|----typeName|否|String| 项目类型名称|
|----taskName|否|String| 项目名称|
|----commission|否|String| 总结算金额|
|----id|否|String| 主键id|
|----beginTime|否|String| 项目开始时间|
|----endTime|否|String| 项目结束时间|
|----taskStatus|否|String| 项目状态|
|----createName|否|String| 创建人|
|----createDate|否|Date| 创建时间|
|--successCount|否|Integer| 成功导入数量|
|--errorCount|否|Integer| 失败数|
|--downloadURL|否|String| 失败数据下载地址|
|--ResultString|否|String| 操作成功|
|--totalCount|否|Integer| 总数|
