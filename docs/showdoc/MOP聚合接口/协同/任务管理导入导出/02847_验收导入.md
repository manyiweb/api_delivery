# 验收导入

**请求URL：** 
- `/file/import/taskinspected/exceladd `

**请求方式：**
- POST
- FormData

**模板**
inspected	/Template/项目验收导入模板.xlsx

###请求参数<业务参数>
 
```
表单
tokenId
file
taskId
```


###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|--DataLine|否|List| 派单人员对象|
|----fulladdress|否|String| 详细地址|
|----locationName|否|String| 地址名称|
|----locationProvince|否|String| 省|
|----locatioinAddress|否|String| 地址|
|----staff|否|String| 创客名称|
|----remark|否|String| 项目情况说明|
|----inspectedRemark|否|String| 验收说明|
|----taskCode|否|String| 项目编号|
|----statusName|否|String| 项目状态|
|----locationRegion|否|String| 区|
|----inspectedStatusName|否|String| 验收结果|
|----taskName|否|String| 项目名称|
|----id|否|String| 项目地址id|
|----locationCode|否|String| 地点编号|
|----inspectedStatus|否|String| 验收结果编码(1:是;0:否;2:暂不验收)|
|----locationCity|否|String| 市|
|--successCount|否|Integer| 成功导入数量|
|--errorCount|否|Integer| 失败数|
|--downloadURL|否|String| 失败数据下载地址|
|--ResultString|否|String| 操作成功|
|--totalCount|否|Integer| 总数|
