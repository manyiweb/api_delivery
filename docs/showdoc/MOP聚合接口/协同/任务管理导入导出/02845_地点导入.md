# 地点导入

**请求URL：** 
- `/file/import/location/exceladd `

**请求方式：**
- POST
- FormData

**模板**
locationAdd		/Template/地点管理导入模板0613.xlsx

###请求参数<业务参数>
 
```
表单
tokenId
file
```


###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|--totalCount|否|Integer| 导入总数量|
|--successCount|否|Integer| 成功导入数量|
|--errorCount|否|Integer| 失败数|
|--downloadURL|否|String| 失败数据下载地址|
|--ResultString|否|String| 操作成功|


###返回参数Json格式
 
```
{
	"downloadURL": "https://upaiyun.reabam.com/export/地址管理导入失败数据1592200283103(0-4).xlsx",
	"successCount": 0,
	"ErrorCode": "",
	"ResultString": "操作成功",
	"totalCount": 5,
	"errorCount": 5,
	"ResultInt": 0
}
```
