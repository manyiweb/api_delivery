# 项目管理导入 新增

**请求URL：** 
- `/file/import/taskManage/exceladd

**请求方式：**
- POST
- FormData


**模板**
taskManageAdd		/Template/项目管理导入模板.xlsx

###请求参数<业务参数>
 
```
表单
tokenId
file
```


###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|--DataLine|否|List| 派单人员对象|
|--successCount|否|Integer| 成功导入数量|
|--errorCount|否|Integer| 失败数|
|--downloadURL|否|String| 失败数据下载地址|
|--ResultString|否|String| 操作成功|
|--totalCount|否|Integer| 总数|


###返回参数Json格式
 
```
{
	"DataLine": [
	],
	"downloadURL": "",
	"successCount": 2,
	"ErrorCode": "",
	"ResultString": "操作成功",
	"totalCount": 2,
	"errorCount": 0,
	"ResultInt": 0
}
```
