# 目标管理_获取已分配的目标详情

**请求URL：** 
- `/hr/app/missionObjectives/allotList `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 任务目标id|
|salesDate|否|DateTime| 销售天数|

###请求参数Json格式
 
```
{
 "id" : 0,
 "salesDate" : "DateTime"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--guideId|否|String| 导购id|
|--targetPerformance|否|Double| 目标绩效|
|--guideName|否|String||
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : [{
 "guideId" : "String",
 "targetPerformance" : 0,
 "guideName" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
