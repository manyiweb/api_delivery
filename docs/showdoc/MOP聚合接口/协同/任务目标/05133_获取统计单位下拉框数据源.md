# 获取统计单位下拉框数据源
 

**请求URL：** 
- `/hr/missionObjectives/getStatisticalUnitDataSouse`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|targetTypeName|是|String| 目标类型名称|

### 请求参数Json格式
 
```
{
 "targetTypeName" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--id|否|Long| ID|
|--statisticalUnitName|否|String| 统计单位名称|
|--needCheckStaff|否|Boolean| 需要校验用户标记|
|--needCheckCompany|否|Boolean| 需要校验门店标记|
|--needCheckBrand|否|Boolean| 需要校验品牌标记|
|--needCheckCategory|否|Boolean| 需要校验品类标记|
|--needCheckSupplier|否|Boolean| 需要校验供应商标记|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : [{
 "id" : 0,
 "statisticalUnitName" : "String",
 "needCheckStaff" : true,
 "needCheckCompany" : true,
 "needCheckBrand" : true,
 "needCheckCategory" : true,
 "needCheckSupplier" : true
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
