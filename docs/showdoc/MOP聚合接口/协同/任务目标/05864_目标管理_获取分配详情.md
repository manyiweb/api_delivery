# 目标管理_获取分配详情
 

**请求URL：** 
- `/hr/app/missionObjectives/detail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long| id|
|sword|否|String| 指定商品搜索关键字|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "sword" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--info|否|Object||
|----id|否|Long| 任务id|
|----targetDetailId|否|Long| 任务目标明细id|
|----targetCode|否|String| 目标编码|
|----targetName|否|String| 目标名称|
|----generalObjective|否|Double| 目标金额|
|----beginDate|否|DateTime| 开始日期|
|----endDate|否|DateTime| 结束日期|
|----activeState|否|Integer| 活跃状态|
|----activeStateName|否|String| 活跃状态名称|
|----targetTypeName|否|String| 类型|
|----companyName|否|String| 门店名称|
|----status|否|Integer| 状态 1: 进行中 2：未开始 3：已结束|
|----totalPerformance|否|Double| 总业绩|
|----totalAchievingRate|否|Double| 达成率|
|----statusName|否|String||
|--waitAllot|否|Object| 待分配|
|----dateStr|否|String| 日期中文|
|----salesDate|否|DateTime| 销售日期|
|----target|否|Double| 目标|
|----performance|否|Double| 业绩|
|----isAllot|否|Boolean| 是否已分配|
|----achievingRate|否|Double| 达成率|
|--progressList|否|List| 每日目标进度|
|----dateStr|否|String| 日期中文|
|----salesDate|否|DateTime| 销售日期|
|----target|否|Double| 目标|
|----performance|否|Double| 业绩|
|----isAllot|否|Boolean| 是否已分配|
|----achievingRate|否|Double| 达成率|
|--rankList|否|List| 排行榜|
|----guideId|否|String| 目标id|
|----guideName|否|String| 目标名称|
|----achievement|否|Double| 业绩金额|
|----targetAchievement|否|Double| 目标金额|
|----achievementRate|否|Double| 达成率|
|----isAllot|否|Boolean| 是否已分配|
|----rank|否|Integer| 排名|
|--invalidateFlag|否|Boolean| 是否可分配|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|
