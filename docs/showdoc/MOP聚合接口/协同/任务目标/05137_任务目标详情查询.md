# 任务目标详情查询
 

**请求URL：** 
- `/hr/missionObjectives/info`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long| id|

### 请求参数Json格式
 
```
{
 "id" : 0
}
```
