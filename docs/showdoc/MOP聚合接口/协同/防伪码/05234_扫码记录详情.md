# 

**请求URL：** 
- `/hr/antiCounterfeitingCode/findScanRecord `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|sourceId|true|Long| 防伪码id|
|scanType|true|Integer| 类型 会员或者是导购|

###请求参数Json格式
 
```
{
 "sourceId" : 0,
 "scanType" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--id|否|Long| ID|
|--sourceId|否|Long||
|--scanName|否|String| 规格id|
|--scanPhone|否|Integer| 奖励积分|
|--scanUserId|否|String| 扫码人id|
|--scanDate|否|DateTime| 扫码时间|
|--createId|否|String| 创建人id|
|--createName|否|String| 创建人|
|--createDate|否|DateTime| 创建时间|
|--modifyId|否|String| 修改人id|
|--modifyName|否|String| 修改人|
|--modifyDate|否|DateTime| 修改时间|
|--dbKey|否|Integer| 分库标识|
|--groupId|否|String| 品牌商id|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|

 "id" : 0,

 "modifyName" : "String",
 "modifyDate" : "DateTime",

 }],
