# 

**请求URL：** 
- `/hr/antiCounterfeitingCode/scanQrCode `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|code|是|String| 防伪码|

###请求参数Json格式
 
```
{
 "code" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long| id|
|--itemCode|否|String| 商品编码|
|--skuBarcode|否|String| 规格编码|
|--itemName|否|String| 商品名|
|--unit|否|String| 单位|
|--antiCounterfeitingCode|否|String| 防伪码|
|--brandName|否|String| 品牌名|
|--memberScanCount|否|Integer| 会员扫码次数|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "itemCode" : "String",
 "skuBarcode" : "String",
 "itemName" : "String",
 "unit" : "String",
 "antiCounterfeitingCode" : "String",
 "brandName" : "String",
 "memberScanCount" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
