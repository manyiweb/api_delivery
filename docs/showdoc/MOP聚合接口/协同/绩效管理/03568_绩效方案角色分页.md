# 绩效方案角色分页
 

**请求URL：** 
- `/hr/kpiplan/role/action/page `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|String| 方案id|
|pageIndex|否|Integer| 页号|
|pageSize|否|Integer| 页大小|

###请求参数Json格式
 
```
{
 "pageIndex" : 0,
 "pageSize" : 0,
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--pageIndex|否|Integer| 页码|
|--pageSize|否|Integer| 显示记录数|
|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|--first|否|Boolean| 首页|
|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|
|----planId|否|String| 方案Id|
|----roleId|否|String| 角色id|
|----roleName|否|String| 角色名称|
|----roleCode|否|String| 角色编码|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : {
 "pageIndex" : 0,
 "pageSize" : 0,
 "pageCount" : 0,
 "totalCount" : 0,
 "first" : true,
 "last" : true,
 "content" : [{
 "planId" : "String",
 "roleId" : "String",
 "roleName" : "String",
 "roleCode" : "String",
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
