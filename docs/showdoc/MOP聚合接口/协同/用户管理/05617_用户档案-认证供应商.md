# 新增 or 修改

**请求URL：** 
- `/hr/supplier/authentication/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|staffId|是|String| 用户Id|
|supplierInfoList|否|List| 供应商信息|
|--supplierId|否|String| 供应商|
|--status|否|Integer| 状态,取值：1 - 启用；0 - 停用|
|delStaffSupplierId|否|List| 删除：供应商认证用户id|

### 请求参数Json格式
 
```
{
 "staffId" : "String",
 "supplierInfoList" : [{
 "supplierId" : "String",
 "status" : 0
 }],
 "delStaffSupplierId" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
