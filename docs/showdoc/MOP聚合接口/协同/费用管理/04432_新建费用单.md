# 新建费用单
 

**请求URL：** 
- `/finance/cost/add `

**请求方式：**
- POST
- FormData


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|costCode|是|String| 费用编码|
|costTypeCode|是|String| 	费用类别|
|money|是|Double| 金额|
|companyId|是|String| 商户ID|
|postingDate|是|String| 过账日期|
|docTypeCode|是|String| 单据类型|
|remark|否|String| 备注|
|files|否|file| 附件|
|tokenId|是|String| tokenId|

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|ErrorCode|否|String| 错误信息|
|ResultString|否|String| 成功消息|
|ResultInt|否|Int| 消息编码|


###返回参数Json格式
 
```
{
	"ErrorCode":"",
	"ResultString":"操作成功",
	"ResultInt":0
}
```
