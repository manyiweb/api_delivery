# 拆分任务

**请求URL：** 
- `/hr/taskManage/splitOrder `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|taskManageId|否|Long| 任务管理id|
|splitOrderReceiveReqs|否|List| 拆单明细|
|--taskId|否|Long| 任务地点中间表id|
|--receiveId|否|Long| 接收任务id|
|taskRemark|否|String| 任务备注|

###请求参数Json格式
 
```
{
 "taskManageId" : 0,
 "splitOrderReceiveReqs" : [{
 "taskId" : 0,
 "receiveId" : 0
 }],
 "taskRemark" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|String| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : "String",
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
