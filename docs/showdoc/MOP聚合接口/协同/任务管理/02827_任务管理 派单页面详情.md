# 派单页面详情
 

**请求URL：** 
- `/hr/taskManage/dispatch/list`

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|taskId|否|Long| 任务主键 |
|sword|否|String||
|tokenId|否|String||
|pageIndex|否|Integer| 页号|
|pageSize|否|Integer| 页大小|

###请求参数Json格式
 
```
{
 "taskId":"",
 "pageSize":10,
 "pageIndex":1,
 "sword":"",
 "tokenId":""
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--pageIndex|否|Integer| 页码|
|--pageSize|否|Integer| 显示记录数|
|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|--first|否|Boolean| 首页|
|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|
|----id|否|Long| 主键|
|----taskId|否|Long| 任务主表|
|----locationId|否|Long| 地点id|
|----locationCode|否|String| 地点编号|
|----locationName|否|String| 地点简称|
|----locatioinAddress|否|String| 地点详细地址|
|----locationProvince|否|String| 省|
|----locationCity|否|String| 市|
|----locationRegion|否|String| 区|
|----taskDispatchStaffs|否|List| 任务用户|
|------staffCode|否|String| 手机号码|
|------staffId|否|Long| 用户id|
|------staffName|否|String| 用户名|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
