# 任务详情

**请求URL：** 
- `/hr/taskManage/location/detail `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| task_receive id|
|tokenId|否|String| 登录令牌|

###请求参数Json格式
 
```
{
 "id" : 0,
 "tokenId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--schedules|否|List| 状态标识|
|----num|否|Integer| 排序|
|----date|否|String| 时间|
|----title|否|String| 标题|
|----status|否|String| 状态|
|--taskReceiveDetailTaskReceiveDto|否|Object| 任务详情|
|----id|否|Long| task_receive id|
|----taskCode|否|String| 接收任务编号|
|----createName|否|String| 创建人|
|----createDate|否|DateTime| 创建时间|
|----commission|否|Double| 结算佣金|
|----inspectedStatus|否|Integer| 验收结果是否通过（1 是，0 否,2暂不验收）|
|----remark|否|String| 子项目完成情况|
|--taskReceiveDetailTaskManageDto|否|Object| 任务主表|
|----taskName|否|String| 任务名称|
|----taskTypeName|否|String| 任务类型名称|
|----beginCommission|否|Double| 佣金范围 开始|
|----endCommission|否|Double| 佣金范围 结束|
|----locationName|否|String| 地点简称|
|----beginTime|否|DateTime| 任务开始时间|
|----endTime|否|DateTime| 任务结束时间|
|----taskExplain|否|String| 任务说明|
|--tokenId|否|String| 登录令牌|
|--bindBankFlag|否|Boolean| 跳转通联开户界面标记,true显示弹框,false不显示|
|--lkUserType|否|Integer| 链客用户类型;1:创客,2:个体工商户|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
