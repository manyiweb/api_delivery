# 获取积分排行榜数据

**请求URL：** 
- `/reabam-hr/hr/guide/rank/getGuideIntegralRank `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|rankType|否|String| 排名类型 Week周榜 Month月榜 Total总榜|
|pageIndex|否|Integer| 页号|
|pageSize|否|Integer| 页大小|
|orderField|否|String| 商品排序字段|
|orderSort|否|String| 商品排序方式 desc 倒序 asc 正序|

###请求参数Json格式
 
```
{
 "rankType" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--respPage|否|Object| 所有导购积分排行信息|
|----pageIndex|否|Integer| 页码|
|----pageSize|否|Integer| 显示记录数|
|----pageCount|否|Integer| 总页数|
|----totalCount|否|Long| 总记录数|
|----first|否|Boolean| 首页|
|----last|否|Boolean| 尾页|
|----content|否|List| 分页数据|
|------staffId|否|String| 用户id|
|------lastRank|否|Integer| 上次排名|
|------currentRank|否|Integer| 当前排名|
|------rankType|否|String| 排名类型 Week周榜 Month月榜 Total总榜|
|------currentIntegral|否|Double| 当前积分|
|------increaseIntegral|否|Double| 增加积分|
|------userName|否|String| 用户名|
|------headImage|否|String| 图片路径|
|------headImageUrl|否|String| 图片绝对路径|
|--beatUser|否|String| 击败导购百分比|
|--currentRank|否|Integer| 当前排名|
|--lastRank|否|Integer| 上次排名|
|--headImage|否|String| 图片路径|
|--increaseIntegral|否|Double| 增加积分|
|--currentIntegral|否|Double| 当前积分|
|--userName|否|String| 用户名|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式

```
 "data" : {
 "respPage" : {
 "pageIndex" : 0,
 "pageSize" : 0,
 "pageCount" : 0,

 "content" : [{
 "userId" : "String",
 "lastRank" : 0,
 "currentRank" : 0,
 "rankType" : "String",
 "currentIntegral" : 0,
 "increaseIntegral" : 0,
 "userName" : "String",
 "headImage" : "String"
 }]
 },
 "beatUser" : "String",
 "currentRank" : 0,
 "headImage" : "String",
 "increaseIntegral" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
