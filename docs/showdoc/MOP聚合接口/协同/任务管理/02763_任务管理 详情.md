# 详情
 

**请求URL：** 
- `/hr/taskManage/detail `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 主键|
|tokenId|否|String| 登录令牌|
|remark|否|String| 任务情况说明|

###请求参数Json格式
 
```
{
 "id" : 0,
 "tokenId" : "String",
 "remark" : "String"
}
```
