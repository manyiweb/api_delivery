# 派单明细列表

**请求URL：** 
- `前台 /mct/hr/taskManage/receive/list `
- `/hr/taskManage/receive/list `


**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|taskId|否|Long| 任务主键 |
|sword|否|String||
|tokenId|否|String||
|status|否|Integer|子任务状态 0待承揽、1已承揽、2已交付、3已验收、4已结算|
|pageIndex|否|Integer| 页号|
|pageSize|否|Integer| 页大小|

###请求参数Json格式
 
```
{
 "pageIndex":1,
 "pageSize":20,
 "taskId":"820178327920418686",
 "sword":"15603065393",
	"status": 3,
 "tokenId":"75357ef28a35410abcf5b86d305b156f"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--pageIndex|否|Integer| 页码|
|--pageSize|否|Integer| 显示记录数|
|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|--first|否|Boolean| 首页|
|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|
|----id|否|Long| 主键|
|----taskId|否|Long| 任务地点表主键|
|----taskCode|否|String| 任务派单编号|
|----taskCodeTM|否|String| 任务单号|
|----locationId|否|Long| 地点id|
|----locationCode|否|String| 地点编号|
|----locationName|否|String| 地点简称|
|----locatioinProvince|否|String| 省|
|----locationCity|否|String| 市|
|----locationRegion|否|String| 区|
|----locationPerson|否|String| 地点业务负责人|
|----beginCommission|否|Double| 佣金范围 开始|
|----endCommission|否|Double| 佣金范围 结束|
|----commission|否|Double| 结算佣金|
|----inspectedStatus|否|Integer| 验收结果是否通过（1 是，0 否,2暂不验收）|
|----inspectedRemark|否|String| 验证说明|
|----remark|否|String| 备注，项目情况说明|
|----staffCode|否|String| 用户手机号|
|----staffId|否|String| 用户id|
|----staffName|否|String| 用户名|
|----status|否|String| 任务状态 0待承揽、1已承揽、2已交付、3已验收、4已结算|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
