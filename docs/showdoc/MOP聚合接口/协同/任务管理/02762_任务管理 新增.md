# 新增
 

**请求URL：** 
- `前台 /mct/hr/taskManage/add `
- `/hr/taskManage/add `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 主键|
|taskName|否|String| 任务名称|
|activeStatus|否|Integer| 活跃状态 1启用0停用|
|beginTime|否|DateTime| 任务开始时间|
|endTime|否|DateTime| 任务结束时间|
|beginCommission|否|Double| 佣金范围 开始|
|endCommission|否|Double| 佣金范围 结束|
|taskRemark|否|String| 任务备注|
|taskExplain|否|String| 任务说明|
|taskTypeId|否|String| 任务类型id|
|locationIds|否|List| 任务地点id|
|delIds|否|List| 删除任务地点|
|businessDirectorTlAccountId|是|Long| 业务负责人|
|projectMode|是|Integer| 项目模式;1：合伙模式 2：个体模式(平台) 3：居间模式 4：个体模式(企业) 5：代征模式 6：居间(企业)模式|

###请求参数Json格式
 
```
{
 "id" : 0,
 "taskName" : "String",
 "activeStatus" : 0,
 "beginTime" : "DateTime",
 "endTime" : "DateTime",
 "beginCommission" : 0,
 "endCommission" : 0,
 "taskRemark" : "String",
 "taskExplain" : "String",
 "taskTypeId" : "String",
 "taskTypeCode" : "String",
 "taskTypeName" : "String",
 "locationIds" : null,
 "delIds" : null,
 "businessDirectorTlAccountId":0,
 "projectMode":0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
