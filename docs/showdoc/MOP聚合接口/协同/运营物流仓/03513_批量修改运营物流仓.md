# 批量修改运营物流仓

**请求URL：** 
- `/hr/staffLogiWhsStor/updateBatch `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|updateList|是|List| 修改项集合|
|--id|是|Long| 主键id|
|--isActive|是|Integer| 活跃状态;0:失效,1:生效|

###请求参数Json格式
 
```
{
 "updateList" : [{
 "id" : 0,
 "isActive" : 0
 }]
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|String| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : "String",
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
