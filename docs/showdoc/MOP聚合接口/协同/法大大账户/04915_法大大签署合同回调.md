# 法大大签署合同回调

**请求URL：** 
- `/hr/fddContractSigningRecord/signContractCallBack/{groupId}/{enterpriseFlag} `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|transactionId|是|String| 交易号|
|resultCode|是|String| 签章结果代码:3000（签章成功）3001（签章失败）|
|resultDesc|是|String| 签章结果描述|
|downloadUrl|否|String| 下载地址|
|viewpdfUrl|否|String| 查看地址|
|timestamp|是|String| 请求时间yyyyMMddHHmmss|
|msgDigest|是|String| 摘要:Base64(SHA1(app_id +MD5(timestamp)+SHA1(app_secret+transaction_id)))|

###请求参数Json格式
 
```
{
 "transactionId" : "String",
 "contractId" : "String",
 "resultCode" : "String",
 "resultDesc" : "String",
 "downloadUrl" : "String",
 "viewpdfUrl" : "String",
 "timestamp" : "String",
 "msgDigest" : "String"
}
```
