# 法大大实名认证回调

**请求URL：** 
- `/hr/fddAccount/fddAuthCallBack/{groupId} `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|serialNo|是|String| 认证序列号(同步回调为transactionNo)|
|customerId|否|String| 客户编号|
|status|是|String| 个人Status:0：未激活；1：未认证；2：审核通过；3：已提交待审核；4：审核不通过。企业：status:0：未认证；1：管理员资料已提交；2：企业基本资料(没有申请表)已提交；3：已提交待审核；4：审核通过（认证完成）；5：审核不通过；6人工初审通过（认证未完成，还需按提示完成接下来的操作）|
|statusDesc|否|String| 不通过原因描述|
|certStatus|否|String| 0：没有申请证书或者申请证书失败，1：成功申请证书|
|authenticationType|否|String| 帐号类型;1：个人,2：企业|
|timestamp|否|String| 时间戳|
|sign|否|String| Base64(SHA1(app_id +MD5(timestamp)+SHA1(app_secret+authenticationType+certStatus+customerId+serialNo+status+statusDesc)))|

###请求参数Json格式
 
```
{
 "serialNo" : "String",
 "customerId" : "String",
 "status" : "String",
 "statusDesc" : "String",
 "certStatus" : "String",
 "authenticationType" : "String",
 "timestamp" : "String",
 "sign" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|http code|否|String| 业务代码|


###返回参数Json格式
 
```
{
 "200" 
}
```
