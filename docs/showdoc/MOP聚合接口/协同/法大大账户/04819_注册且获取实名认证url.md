# 注册且获取实名认证url

**请求URL：** 
- `/hr/fddAccount/registerAndGetAuthUrl `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|appletFlag|否|Boolean| 小程序标记,true:小程序请求,false非小程序请求|
|returnUrl|是|String| 法大大接口同步通知url|

###请求参数Json格式
 
```
{
 "appletFlag" : true,
 "returnUrl" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|String| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : "String",
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
