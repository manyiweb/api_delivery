# 复制

**请求URL：** 
- `前台 /mct/hr/settlement/copy `
- `/hr/settlement/copy `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 主键|
|tokenId|否|String| 登录令牌|

###请求参数Json格式
 
```
{
 "id" : 0,
 "tokenId" : "String"
}
```

###返回参数

|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--taskManageList|否|List| 任务|

|----fileName|否|String| 文件名称|
