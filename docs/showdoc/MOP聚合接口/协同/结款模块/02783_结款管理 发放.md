# 结款单发放

**请求URL：** 
- `/hr/settlement/grant `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|smsCode|否|String| 短信验证码(招行云支付渠道必填)|
|id|是|Long| 结款单|
|taskReceiveIdList|是|List| 发放id集合|
|transferOutTlAccountId|是|Long| 转出方通联账户|
|jumpUrl|是|String| 跳转地址|
|authType|是|Integer| 1:短信验证码鉴权,2:支付密码鉴权|
|individualTlAccountId|否|Long| 中间方通联账户|

###请求参数Json格式
 
```
{
 "smsCode" : "String",
 "id" : 0,
 "taskReceiveIdList" : null,
 "transferOutTlAccountId" : 0,
 "jumpUrl" : "String",
 "authType" : 0,
 "individualTlAccountId" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|String| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : "String",
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
