# 结款管理 新增
 

**请求URL：** 
- `/hr/settlement/add `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|attachmentIds|否|List| 附件Id|
|remark|否|String| 备注|
|taskIds|是|List| 任务Id|
|tokenId|否|String| 登录令牌|
|projectMode|是|Integer| 项目模式;1：合伙模式 2：个体模式(平台) 3：居间模式 4：个体模式(企业) 5：代征模式 6：居间(企业)模式|
|paymentChannels|是|Integer| 支付渠道;1:通商云,2:招行云|

###请求参数Json格式
 
```
{
 "attachmentIds" : null,
 "remark" : "String",
 "taskIds" : null,
 "tokenId" : "String",
 "projectMode" : 0,
 "paymentChannels" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--staffCodeSet|否|List| 未绑卡用户手机号集合|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "staffCodeSet" : null
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
