# 更新发票信息
 

**请求URL：** 
- `/hr/settlement/invoice/add `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|否|String| 令牌|
|invoiceUrl|否|string| 发票图片地址-多个地址用英文逗号隔开|
|invoiceNumber|否|String| 发票号码|
|settlementId|否|Long| 结款管理主键id|

###请求参数Json格式
 
```
{
 "tokenId" : "String",
 "invoiceUrl" : "List",
 "invoiceNumber" : "String",
 "settlementId" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
