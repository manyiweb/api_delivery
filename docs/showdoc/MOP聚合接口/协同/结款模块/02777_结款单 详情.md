# 详情

**请求URL：** 
- `/hr/settlement/detail `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 主键|
|tokenId|否|String| 登录令牌|

###请求参数Json格式
 
```
{
 "id" : 0,
 "tokenId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--SettlementManage|否|Map| 主表|
|--Schedules|否|List| 状态|
|----num|否|Integer| 排序|
|----date|否|String| 时间|
|----title|否|String| 标题|
|----status|否|String| 状态|
|--attachmentList|否|List| 附件|
|----attachmentId|否|String| 主键标识|
|----fileName|否|String| 文件名称|
|----fileSize|否|Long| 文件大小|
|----fileUrl|否|String| 文件路径|
|----fileFullUrl|否|String| 文件完整路径|
|----fileOrgName|否|String| 文件原名|
|----fileSuffix|否|String| 文件后缀名|
|----sourceId|否|String| 来源单据ID|
|----sourceTable|否|String| 来源单据所属表|
|----companyId|否|String| 门店商户ID，与商户表syscompany相关联|
|----createId|否|String| 创建人ID|
|----createName|否|String| 创建人名称|
|----createDate|否|DateTime| 创建时间|
|----dbKey|否|Integer| 分库标识|
|----groupId|否|String| 品牌商id|
|--msgCodeAuthFlag|否|Boolean| 短信鉴权弹框flag|
|--batchNo|否|String| 批次号|
|--totalNumber|否|Integer| 总条数|
|--successNumber|否|Integer| 成功条数|
|--showRemitButtonFlag|否|Boolean| 打款按钮展示标记|
|--showGrantButtonFlag|否|Boolean| 发放按钮展示标记|
|--showConfirmButtonFlag|否|Boolean| 确认按钮展示标记|
|--showRemitDownloadButtonFlag|否|Boolean| 打款下载电子回单按钮展示标记|
|--showGrantDownloadButtonFlag|否|Boolean| 发放下载电子回单按钮展示标记|
|--showCloseButtonFlag|否|Boolean| 关闭按钮展示标记|
|--showQueryCmbPayCallbackButtonFlag|否|Boolean| 主动获取招行云交易回调按钮展示标记|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
