# 结款单发放发送短信验证码

**请求URL：** 
- `/hr/settlement/grantSendSmsCode `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 结款单|
|taskReceiveIdList|否|List| 发放id集合|
|transferOutTlAccountId|否|Long| 转出方通联账户|
|jumpUrl|否|String| 跳转地址|
|authType|否|Integer| 1:短信验证码鉴权,2:支付密码鉴权|
|individualTlAccountId|否|Long| 中间方通联账户|

###请求参数Json格式
 
```
{
 "id" : 0,
 "taskReceiveIdList" : null,
 "transferOutTlAccountId" : 0,
 "jumpUrl" : "String",
 "authType" : 0,
 "individualTlAccountId" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--needCheckSmsCodeFlag|否|Boolean| 需要校验验证码标记|
|--smsCodePhoneNumber|否|String| 验证码手机号|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "needCheckSmsCodeFlag" : true,
 "smsCodePhoneNumber" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
