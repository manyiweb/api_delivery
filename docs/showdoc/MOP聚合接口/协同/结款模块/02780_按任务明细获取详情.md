# 按任务明细获取详情

**请求URL：** 
- `/hr/settlement/taskdetail/tasklist `

**请求方式：**
- POST
- RequestBody

|参数名|必选|类型|说明|

|sword|否|String||

|id|否|String||

|----isCustom|否|String||
|----isRange|否|String||
|----isSelect|否|String||
|--current|否|Object||
