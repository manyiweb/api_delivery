# 结款单打款

**请求URL：** 
- `/hr/settlement/remit `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|jumpUrl|是|String| 跳转地址|
|authType|是|Integer| 1:短信验证码鉴权,2:支付密码鉴权|
|id|是|Long| id|

###请求参数Json格式
 
```
{
 "jumpUrl" : "String",
 "authType" : 0,
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|String| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : "String",
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
