# 新增推广任务
 

**请求URL：** 
- `/hr/promotion/add `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|promotionTask|否|Object| 主表内容|
|--id|否|Long| 任务主键|
|--taskName|否|String| 任务名称|
|--startTime|否|DateTime| 开始时间|
|--endTime|否|DateTime| 结束时间|
|--effectiveDuration|否|Integer| 有效时长（分)|
|--remark|否|String| 任务说明|
|--status|否|Integer| 活跃状态（1 是 0否）|
|promotionItem|否|Object| 推广商品|
|--addPromotionItem|否|List| 添加商品|
|--delIds|否|List| 删除商品|
|promotionPerson|否|Object| 指派人员|
|--addStaffs|否|List| 添加指派人员|
|----companyId|否|String| 门店id|
|----staffId|否|String| 用户id|
|--delIds|否|List| 删除指派人员|

###请求参数Json格式
 
```
{
 "promotionTask" : {
 "id" : 0,
 "taskName" : "String",
 "startTime" : "DateTime",
 "endTime" : "DateTime",
 "effectiveDuration" : 0,
 "remark" : "String",
 "status" : 0
 },
 "promotionItem" : {
 "addPromotionItem" : null,
 "delIds" : null
 },
 "promotionPerson" : {
 "addStaffs" : [{
 "companyId" : "String",
 "staffId" : "String"
 }],
 "delIds" : null
 }
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
