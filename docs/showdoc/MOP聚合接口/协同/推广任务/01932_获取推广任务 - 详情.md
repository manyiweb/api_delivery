# 获取推广任务
 

**请求URL：** 
- `/hr/promotion/get/task `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|

###请求参数Json格式
 
```
{
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long| 主键|
|--taskCode|否|String| 任务编码|
|--taskName|否|String| 任务名称|
|--startTime|否|DateTime| 开始时间|
|--endTime|否|DateTime| 结束时间|
|--effectiveDuration|否|Integer| 有效时长（分)|
|--remark|否|String| 任务说明|
|--status|否|Integer| 活跃状态（1 是 0否）|
|--statusName|否|String| 活跃状态（1 是 0否）|
|--createId|否|String| 创建人id|
|--createName|否|String| 创建人|
|--createDate|否|DateTime| 创建时间|
|--modifyId|否|String| 修改人id|
|--modifyName|否|String| 修改人|
|--modifyDate|否|DateTime| 修改时间|
|--dbKey|否|Integer| 分库标识|
|--groupId|否|String| 品牌商id|
|--completeRemark|否|String| 备注内容|
|--personStatusName|否|String| 状态|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式

```
 "endTime" : "DateTime",

 "remark" : "String",
 "status" : 0,
 "statusName" : "String",
 "createId" : "String",
 "createName" : "String",
 "createDate" : "DateTime",
 "modifyId" : "String",
 "modifyName" : "String",
 "modifyDate" : "DateTime",
 "dbKey" : 0,
 "groupId" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
