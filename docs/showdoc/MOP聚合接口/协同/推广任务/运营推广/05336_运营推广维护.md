# 新增/编辑运营推广

**请求URL：** 
- `/hr/operation/promotion/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 推广id，新建不传|
|**opPromotion**|否|Object| 主表信息|
|--promotionName|是|String| 推广名称|
|--type|是|Integer| 推广类型，0-商品覆盖率|
|--beginDate|是|DateTime| 推广有效期起|
|--endDate|是|DateTime| 推广有效期至|
|--assignSendTiem|是|String| 每天定时推送时间点|
|--isActive|是|Integer| 活跃状态，0-禁用 1-启用|
|--remark|否|String| 备注|
|--countBeginDate|否|DateTime| 数据开始统计时间|
|--conditionType|否|Integer| 条件类型，0商品数量1实付金额|
|--meetQuantity|否|Double| 订购商品数量满|
|--meetRealAmount|否|Double| 订购实付金额|
|--isSpecifiedItems|否|Integer| 是否指定商品 0-否 1-是|
|**opPromotionItems**|否|Object| 指定商品 信息|
|--specIds|否|List| 添加商品 规格specId|
|--delIds|否|List| 删除商品 指定商品的Id|
|**opPromotionGroups**|否|Object| 指定品牌、类别、系列|
|--addGroups|否|List| 新增指定品牌、系列、分类|
|----type|否|Integer| 类型 0分类 1品牌 2系列|
|----typeId|否|String| 分类/品牌/系列 id|
|--delIds|否|List| 删除指定品牌、系列、分类的Id|
|**opPromotionPerson**|否|Object| 指派人员|
|--addStaffs|否|List| 添加指派人员|
|----staffId|否|String| 用户的fid|
|--delIds|否|List| 删除指派人员的id|
