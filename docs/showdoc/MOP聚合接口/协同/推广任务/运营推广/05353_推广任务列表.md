# 推广任务列表

**请求URL：** 
- `/hr/operation/promotion/task/list`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|sword|否|String||
|tokenId|否|String||
|id|否|String||
|orderField|否|String| 排序字段|
|orderSort|否|String| 排序方式|
|pageIndex|否|Integer| 页号|
|pageSize|否|Integer| 页大小|

### 请求参数Json格式
 
```
{
 "sword" : "String",
 "tokenId" : "String",
 "id" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--pageIndex|否|Integer| 页码|
|--pageSize|否|Integer| 显示记录数|
|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|--first|否|Boolean| 首页|
|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|
|----id|否|Long||
|----promotionId|否|Long| 推广id|
|----promotionName|否|String| 推广名称|
|----countBeginDate|否|DateTime| 数据开始统计时间|
|----coverage|否|Double| 覆盖率|
|----ranking|否|Integer| 覆盖率排名|
|----uncoveredCompany|否|String| 未覆盖门店 List|
|----coveredCompany|否|String| 已覆盖门店 List|
|----promotionInstructions|否|String| 推广说明|
|----createName|否|String| 创建人|
|----createDate|否|DateTime| 创建时间|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
