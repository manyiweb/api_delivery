# 获取二维码内容

**请求URL：** 
- `/hr/appc/promotion/qrcodeinfo `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 任务id|

###请求参数Json格式
 
```
{
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long| 主键|
|--itemId|否|String| 商品id|
|--companyId|否|String| 门店id|
|--taskId|否|Long| 任务id|
|--staffId|否|String| 员工id|
|--imgUrl|否|String| 二维码图片|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "itemId" : "String",
 "companyId" : "String",
 "taskId" : 0,
 "staffId" : "String",
 "imgUrl" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
