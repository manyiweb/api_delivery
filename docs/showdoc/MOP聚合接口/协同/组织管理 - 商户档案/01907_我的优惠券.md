# 商户优惠券列表(我的优惠券)
 

**请求URL：** 
- `/b2b/comp/coupon/list `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 门店标识，中台需要传，其他不用|
|status|否|Integer| 0全部 1未使用 2已使用 3已过期 4历史优惠券(2和3的合体)|
|pageIndex|否|Integer| 分页页码|
|pageSize|否|Integer| 分页大小|
|sword|否|String| 搜索关键字|

###请求参数Json格式
 
```
{
 "companyId" : "String",
 "status" : 0,
 "pageIndex" : 0,
 "pageSize" : 0,
 "sword" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--noUseQty|否|Long| 未使用数量|
|--useQty|否|Long| 已使用数量|
|--timeOutQty|否|Long| 已过期数量|
|--pageData|否|Object||
|----pageIndex|否|Integer| 页码|
|----pageSize|否|Integer| 显示记录数|
|----pageCount|否|Integer| 总页数|
|----totalCount|否|Long| 总记录数|
|----first|否|Boolean| 首页|
|----last|否|Boolean| 尾页|
|----content|否|List| 分页数据|
|------couponGetId|否|String| 优惠券领取标识|
|------couponId|否|String| 优惠券标识|
|------coupnsCode|否|String| 优惠券编码|
|------title|否|String| 优惠券标题|
|------sn|否|String| 优惠券码|
|------discount|否|Double| 折扣券折扣|
|------price|否|Double| 现金券面额|
|------useLimitAmt|否|Double| 使用限制|
|------couponType|否|String| 优惠券类型 0为现金劵，1为折扣劵 ,2为兑换券|
|------couponTypeName|否|String| 优惠券类型 名称|
|------detail|否|String| 详情|
|------beginDate|否|String| 开始时间|
|------endDate|否|String| 结束时间|
|------useTime|否|DateTime| 使用时间|
|------status|否|Integer| 0全部 1未使用 2已使用 3已过期 4历史优惠券(2和3的合体)|
|------statusName|否|String||
|msg|否|String| 消息|
|code|否|String| 业务代码|
