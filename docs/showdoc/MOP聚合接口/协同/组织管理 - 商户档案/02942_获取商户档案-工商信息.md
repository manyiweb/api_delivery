# 查询商户工商信息
 

**请求URL：** 
- `/hr/business/info/list `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|是|String||
|companyId|是|String| 商户id|

###请求参数Json格式
 
```
{
 "tokenId" : "String",
 "companyId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--businessLicenseUrl|否|String| 营业执照有域名|
|--id|否|Long||
|--companyId|否|String| 商户id|
|--creditCode|否|String| 统一社会信用代码|
|--companyName|否|String| 企业名称|
|--legalRepresentative|否|String| 法定代表人|
|--registeredAddress|否|String| 注册地址|
|--businessScope|否|String| 经营范围|
|--businessLicense|否|String| 营业执照|
|--version|否|Integer| 版本号|
|--dbKey|否|Integer| 分库标识|
|--groupId|否|String| 品牌商id|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "businessLicenseUrl" : "String",
 "id" : 0,
 "companyId" : "String",
 "creditCode" : "String",
 "companyName" : "String",
 "legalRepresentative" : "String",
 "registeredAddress" : "String",
 "businessScope" : "String",
 "businessLicense" : "String",
 "version" : 0,
 "dbKey" : 0,
 "groupId" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
