# 品牌商户标签列表 

**请求URL：** 
- `/appc/Company/findCompanyLabelList `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|groupId|否|String||

###请求参数Json格式
 
```
{
 "groupId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--showByLabel|否|Integer| 是否按商户标签分组显示门店列表 1是0否|
|--companyLabels|否|List| 标签数组|
|----id|否|Long| 标签id 调用findCompanyList接口时，需要传该id，参数为数组labelIds|
|----labelName|否|String| 标签名|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : {
 "showByLabel" : 0,
 "companyLabels" : [{
 "id" : 0,
 "labelName" : "String"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
