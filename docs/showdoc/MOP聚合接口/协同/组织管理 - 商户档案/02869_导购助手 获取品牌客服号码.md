# 获取品牌客服号码

**请求URL：** 
- `/hr/appcode/getPhone `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|否|String||
###请求参数Json格式
 
```
{
 "tokenId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--phone|否|String| 扩展配置选项|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : {
 "phone" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
