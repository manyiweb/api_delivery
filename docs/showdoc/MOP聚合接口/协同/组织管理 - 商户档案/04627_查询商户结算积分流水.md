# 查询商户结算积分流水
 

**请求URL：** 
- `/mem/memberIntegral/settlementRecord/list`

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 商户id|
|tokenId|否|String||

###请求参数Json格式
 
```
{
 "companyId" : "String",
 "tokenId" : "String"
}
```

###返回参数
 

|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--records|否|Object| 流水记录|
|----pageIndex|否|Integer| 页码|
|----pageSize|否|Integer| 显示记录数|
|----pageCount|否|Integer| 总页数|
|----totalCount|否|Long| 总记录数|
|----first|否|Boolean| 首页|
|----last|否|Boolean| 尾页|
|----content|否|List| 分页数据|
|------settlementIntegral|否|Double| 本次结算积分|
|------remark|否|String| 变更备注|
|------settlementType|否|Object| 结算类型 0 - 未结算, 1 - 已结算, 2 - 无需结算|
|------type|否|String| 积分变更类型|
|------typeName|否|String| 积分变更类型名称|
|------createName|否|String| 创建人|
|--totalSettlementIntegral|否|Double| 总结算积分余额|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "records" : {
 "pageIndex" : 0,
 "pageSize" : 0,
 "pageCount" : 0,
 "totalCount" : 0,
 "first" : true,
 "last" : true,
 "content" : [{
 "settlementIntegral" : 0,
 "remark" : "String",
 "settlementType" : null,
 "type" : "String",
 "typeName" : "String",
 "createName" : "String"
 }]
 },
 "totalSettlementIntegral" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
