# 编辑门禁设备

**请求URL：** 
- `/config/entranceGuardDevice/edit`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long| id|
|code|是|String| 设备编号|
|companyId|是|String| 商户id|
|scanType|否|Integer| 扫码类型 0 - 按优惠券业务类型，1 - 按会员等级|
|activeStatus|否|Integer| 活跃状态 0 - 停用， 1 - 启用|
|memberGradeList|否|List| 应用的会员等级|
|--memberGradeId|是|String| 会员等级id|
|--memberGradeName|是|String| 会员等级名称|
|retailCouponList|否|List| 应用的优惠券|
|--retailCouponOrderTypeId|是|String| 零售优惠券业务类型id|
|--retailCouponOrderTypeName|是|String| 零售优惠券业务类型名称|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "code" : "String",
 "companyId" : "String",
 "scanType" : 0,
 "activeStatus" : 0,
 "memberGradeList" : [{
 "memberGradeId" : "String",
 "memberGradeName" : "String"
 }],
 "retailCouponList" : [{
 "retailCouponOrderTypeId" : "String",
 "retailCouponOrderTypeName" : "String"
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Long| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : 0,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
