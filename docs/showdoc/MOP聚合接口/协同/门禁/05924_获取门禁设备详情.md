# 获取门禁设备详情

**请求URL：** 
- `/config/entranceGuardDevice/detail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||

### 请求参数Json格式
 
```
{
 "id" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long| id|
|--code|否|String| 设备编号|
|--companyId|否|String| 商户id|
|--companyCode|否|String| 商户编码|
|--companyName|否|String| 商户名称|
|--scanType|否|Integer| 扫码类型 0 - 按优惠券业务类型，1 - 按会员等级|
|--activeStatus|否|Integer| 活跃状态 0 - 停用， 1 - 启用|
|--groupId|否|String| 品牌id|
|--memberGradeList|否|List| 应用的会员等级|
|----entranceGuardDeviceId|否|Long| 门禁设备id|
|----memberGradeId|否|String| 会员等级id|
|----memberGradeName|否|String| 会员等级名称|
|--retailCouponList|否|List| 应用的优惠券|
|----entranceGuardDeviceId|否|Long| 门禁设备id|
|----retailCouponOrderTypeId|否|String| 零售优惠券业务类型id|
|----retailCouponOrderTypeName|否|String| 零售优惠券业务类型名称|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|

 "entranceGuardDeviceId" : 0,

 }],

 "entranceGuardDeviceId" : 0,
 "retailCouponOrderTypeId" : "String",
 "retailCouponOrderTypeName" : "String"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",

}
