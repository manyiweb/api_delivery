# 添加合同

**请求URL：** 
- `/hr/yeahka/add/contract `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|paymentId|否|String| 支付方式编号|
|paymentClassificationId|否|String| 支付方式行业分类编号|
|paymentClassificationLimit|否|String| 封顶值（分为单位，无封顶填0）|
|fee|否|String| 签约扣率百分比（如：0.32）|
|startDate|否|String| 合同生效日期（yyyy-mm-dd）|
|endDate|否|String| 合同过期日期（yyyy-mm-dd）|
|signMan|否|String| 合同签约人|
|signName|否|String| 签购单名称建议使用商户招牌名称|
|signDate|否|String| 合同签署日期|
|autoSign|否|String| 是否自动续签（1是，0否）|
|contact|否|String| 联系人|
|contactTelephone|否|String| 联系人电话|
|pictureOne|否|String| 合同照片【私密区】|
|categoryId|否|String| 额外参数|
|categoryIdSelect|否|List| 额外参数|
|mcc|否|String| 额外参数|
|mccSelect|否|List| 额外参数|
|mchtType|否|String| 额外参数|
|mchtTypeSelect|否|List| 额外参数|
|merchantType|否|String| 额外参数|
|merchantTypeSelect|否|List| 额外参数|
|settlementObject|否|String| 额外参数|
|settlementObjectSelect|否|List| 额外参数|
|merType|否|String| 额外参数|
|merTypeSelect|否|List| 额外参数|
|accountId|否|String| 账户id|
|outContractId|否|String||
|merchantNo|否|String||
|code|否|String||

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |

|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
