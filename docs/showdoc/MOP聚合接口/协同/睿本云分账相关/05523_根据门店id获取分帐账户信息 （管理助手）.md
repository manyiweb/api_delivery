# 根据门店id获取分帐账户信息

**请求URL：** 
- `/hr/split/account/accountInfo `

**请求方式：**
- POST
- FormData


###请求参数<业务参数>
 
无参数


###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--splitAccount|否|Object| 账户信息|
|----id|否|Long||
|----relateAccountId|否|Long| 关联的银行账户id|
|----accountType|否|Integer| 账户类型 1、商户 2、经销商|

|----shopId|否|Long| 分账门店id|

|----accountCode|否|String| 账户编码|
|----accountName|否|String| 账户名称|
|----createName|否|String||
|----createDate|否|DateTime||
|--splitInfo|否|Object| 商户信息|
|----id|否|Long||
|----outMerchantId|否|Long| 机构商户主键|
|----merchantNo|否|String| 系统商户号|
|----merchantName|否|String| 商户名称|

|----businessLicenseStartDate|否|String| 营业执照生效时间|
|----businessLicenseEndDate|否|String| 营业执照过期时间|
|----brandName|否|String| 招牌名称|
|----telephone|否|String| 联系电话|
|----address|否|String| 详细地址|
|----openHours|否|String| 营业时间，多个以小写逗号分开(9:00-12:00,13:00-18:00)|
|----accountType|否|Integer| 结算账户类型（2对私，1对公）|
|----bankNo|否|String| 清算联行号|
|----bankName|否|String| 开户行名称|
|----accountNo|否|String| 银行账户|
|----accountName|否|String| 银行户名|

|----bossName|否|String| 法人姓名|
|----bossIdNo|否|String| 法人证件号码|
|----bossSex|否|Integer| 法人性别（1男，2女）|
|----type|否|Integer| 商户类型：1-个体，2-小微，3-企业。不传默认为2-小微商户。|
|----bossTelephone|否|String| 法人电话|
|----bossStartDate|否|DateTime| 法人身份证有效期|
|----bossEndDate|否|DateTime| 法人身份证结束期|
|----cityId|否|String| 城市id|
|----bossIdCountry|否|String| 证件国区|
|----classification|否|String| 行业分类|
|----contractId|否|Long| 合同id|
|----companyId|否|String| 门店id|
|----accountId|否|Long| 零售账户id|
|----businessLicensePictureImage|否|String| 营业执照照片|
|----businessLicensePicture|否|String| 营业执照照片|
|----bossPositiveImage|否|String| 身份证正面|
|----bossPositive|否|String| 身份证正面|
|----bossBackImage|否|String| 身份证背面|
|----bossBack|否|String| 身份证背面|
|----licencePictureImage|否|String| 经营许可证照片|
|----licencePicture|否|String| 经营许可证照片|
|----createId|否|String| 创建人id|
|----createName|否|String| 创建人|
|----createDate|否|DateTime| 创建时间|
|----modifyId|否|String| 修改人id|

|----groupId|否|String| 品牌商id|
|--splitShop|否|Object| 门店信息|
|----id|否|Long||
|----shopNo|否|String| 门店编号|
|----merchantNo|否|String| 商户编号|
|----openId|否|String| open_id|
|----openKey|否|String| open_key|
|----shopName|否|String| 门店简称|

|----telephone|否|String| 门店电话|
|----openHours|否|String| 营业时间，多个以小写逗号分开(9:00-12:00,13:00-18:00)|
|----address|否|String| 门店详细地址，不含省市区县名称|
|----companyId|否|String| 门店id|
|----contractUrl|否|String| 合同地址|
|----remark|否|String| 信息|
|----status|否|Integer| 状态（0-未开通，1-已开通，2-商户主动关闭，3-待审核，4-冻结，5-注销，6-待签合同）|
|----cityId|否|String| 城市编码|
|----pictureOneImage|否|String| 门店照片1|
|----pictureTwoImage|否|String| 门店照片2|
|----pictureThreeImage|否|String| 门店照片3|
|----pictureOne|否|String| 门店照片1|
|----pictureTwo|否|String| 门店照片2|

|----createId|否|String| 创建人id|

|----createDate|否|DateTime| 创建时间|
|----modifyId|否|String| 修改人id|

|----modifyDate|否|DateTime| 修改时间|

|----groupId|否|String| 品牌商id|
|--splitContract|否|Object| 合同信息|
|----id|否|Long||
|----contractCode|否|String| 合同编号|
|----contractId|否|String| 合同id|
|----outContractId|否|String| 合同外键id|
|----fee|否|String| 合同费率|
|----startDate|否|DateTime| 合同开始时间|
|----endDate|否|DateTime| 合同结束时间|
|----signDate|否|DateTime| 合同签署日期|
|----paymentId|否|Integer| 合同支付方式编号|
|----paymentName|否|String| 合同支付方式名称|
|----paymentClassificationId|否|Integer| 合同支付方式编号|
|----paymentClassificationName|否|String| 合同支付方式名称|
|----paymentClassificationLimit|否|Double| 合同支付方式编号|
|----mccSelect|否|String| 合同行业分类|
|----categoryIdSelect|否|String| 合同城市编码|
|----mchtTypeSelect|否|String| 合同门店分类|
|----signMan|否|String| 签收人|
|----signName|否|String| 合同签署人|
|----autoSign|否|Boolean| 合同是否自动续签|
|----contact|否|String| 合同联系人|
|----contactTelephone|否|String| 合同联系人电话|
|----merchantTypeSelect|否|String| 合同是否为公益类型|
|----settlementObjectSelect|否|String| 合同结算对象|
|----merTypeSelect|否|String| 合同商户类型|
|----pictureOne|否|String| 图片1|
|----pictureOneImage|否|String||
|----createId|否|String| 创建人id|
|----createName|否|String| 创建人|
|----createDate|否|DateTime| 创建时间|
|----modifyId|否|String| 修改人id|
|----modifyName|否|String| 修改人|
|----modifyDate|否|DateTime| 修改时间|
|----dbKey|否|Integer| 分库标识|
|----groupId|否|String| 品牌商id|
|--merchantLinkList|否|List| 关联的接收方|
|----id|否|Long||
|----companyId|否|String| 门店id|
|----shopId|否|Long| 门店id|
|----linkMerchantNo|否|String| 关联的商户编码|
