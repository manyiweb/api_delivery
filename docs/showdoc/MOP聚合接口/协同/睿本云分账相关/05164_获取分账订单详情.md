# 获取分账订单详情

**请求URL：** 
- `retail-pay-manager/pay/retail/split/orderDetail `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|否|String| 订单id|

###请求参数Json格式
 
```
{
 "orderId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--record|否|Object| 订单记录|
|----orderId|否|String| 订单id|
|----orderNo|否|String| 订单编号|
|----distributeNo|否|String| 平台分账单号|
|----inDate|否|DateTime| 入账日期|
|----amount|否|Double| 分账金额|
|----outDistributeNo|否|String| 商户分账单号|
|----status|否|Integer| 分账状态（-1未开始 0分账初始 1分账成功 2分账失败）|
|----failReason|否|String| 失败原因|
|----ruleApplyId|否|Long| 使用分账应用id|
|--retailSplitOrders|否|List| 订单汇总|
|----distributeId|否|String||
|----distributeCode|否|String| 分账方编码|
|----distributeName|否|String| 分账方名称|
|----distributeType|否|Integer| 分账方类型 0：商户 1：经销商|
|----totalAmount|否|Double| 分账总额|
|----itemAmount|否|Double| 商品分账金额|
|----freightAmount|否|Double| 运费分账金额|
|----paymentStatus|否|String| 代付状态|
|----arrivalDate|否|String| 到账时间|
|----merchantNo|否|String| 商户编号|
|--retailSplitOrderDetails|否|List| 订单明细|
|----itemId|否|String| 商品id|
|----itemName|否|String| 商品名称|
|----itemCode|否|String| 商品编码|
|----sku|否|String| 商品sku|
|----distributeId|否|String| 分账方id|
|----distributeCode|否|String| 分账方编码|
|----distributeName|否|String| 分账方名称|
|----distributeType|否|Integer| 分账方类型 0：商户 1：经销商|
|----amount|否|Double| 分账金额|
|----proportion|否|Double| 分账比例|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
