# 查询费率详情

**请求URL：** 
- `/hr/yeahka/contract/payFee `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|paymentId|否|String| 支付id|

###请求参数Json格式
 
```
{
 "paymentId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--pay|否|Object| pay支付方式json数据|
|----paymentTag|否|String| 支付标签（唯一性）|
|----paymentOptionHide|否|String| 添加合同时需要隐藏的选项（多个以小写逗号分开）|
|----paymentIcon|否|String| 支付方式图片url路径|
|----paymentOptionSix|否|String| 合同选项名称6|
|----paymentName|否|String| 付款方式名称|
|----paymentOptionSeven|否|String| 合同选项名称7|
|----paymentOptionOther|否|String| 合同选项名称8|
|----paymentOptionTwo|否|String| 合同选项名称2|
|----paymentOptionOne|否|String| 合同选项名称1|
|----paymentDiscountFee|否|String| 是否开启智能扣率（1是，0否）|
|----paymentType|否|String| 支持的交易类型（多个以小写逗号分开，0现金，1刷卡，2主扫，3被扫，4JSPAY，5预授权）|
|----paymentOptionFive|否|String| 合同选项名称5|
|----paymentOptionNine|否|String| 合同选项名称9|
|----paymentId|否|String| 支付方式编号|
|----paymentOptionThree|否|String| 合同选项名称3|
|----paymentInternalName|否|String| 付款方式名称（内部名称）|
|----paymentOptionFour|否|String| 合同选项名称4|
|----paymentOptionTen|否|String| 合同选项名称10|
|--extraInput|否|List| 合同扩展自定义字段|
|--payFee|否|List| pay_fee支付方式行业分类费率json数据|
|----organizationFee|否|String| 机构的分佣扣率扣率|
|----paymentClassificationLimit|否|String| 商户手续费封顶值，0为不限封顶|
|----organizationFeeType|否|String| 机构的分佣扣率类型(1按签约扣率，2按收单收益)|
|----paymentClassificationMaxFee|否|String| 商户扣率最大值|
|----paymentClassificationMinFee|否|String| 商户扣率最小值|
|----paymentClassificationId|否|String| 行业会类编号|
|----paymentClassificationName|否|String| 行业分类名称|
|--extraInputDto|否|Object||
|----categoryId|否|List| 地区编号|
|------name|否|String| 名称|
|------value|否|List| 值|
|--------name|否|String| 名称|
|--------value|否|List| 值|
|----------code|否|String| 地址编码|
|----------name|否|String| 地址名称|
|----mcc|否|List| mcc选择|
|------name|否|String| 名称|
|------value|否|List| 值|
|----mchtType|否|List| 门店选择|
|------name|否|String| 名称|
|------value|否|String| 值|
|----merchantType|否|List| 是否公益商户类型|
|------name|否|String| 名称|
|------value|否|String| 值|
|----merType|否|List| 商户类型|
|------name|否|String| 名称|
|------value|否|String| 值|
|----settlementObject|否|List| 结算对象|
|------name|否|String| 名称|
|------value|否|String| 值|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
