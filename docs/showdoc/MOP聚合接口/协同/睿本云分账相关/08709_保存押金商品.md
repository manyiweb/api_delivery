# 保存押金商品

**请求URL：** 
- `/b2b/cashPledge/item/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 门店id|
|enableCashPledgeItem|是|Boolean| 是否启用押金商品管理|
|deleteIds|否|List| 要删除的商品id列表|
|cashPledgeItems|否|List| 要保存的商品列表|
|--id|否|Long| 主键|
|--itemId|否|String| 商品id|
|--specId|否|String| 规格id|
|--itemName|否|String| 商品名称|
|--skuBarcode|否|String| sku|
|--isActive|否|Boolean| 是否启用|
|--realPrice|否|Double| 押金单价|

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "enableCashPledgeItem" : true,
 "deleteIds" : null,
 "cashPledgeItems" : [{
 "id" : 0,
 "itemId" : "String",
 "specId" : "String",
 "itemName" : "String",
 "skuBarcode" : "String",
 "isActive" : true,
 "realPrice" : 0
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
