# 创建押金单

**请求URL：** 
- `/b2b/cashpledge/order/createOrder`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|typeId|否|String|单据id |
|typeCode|否|String|单据类型编码 |
|typeName|否|String|单据类型 |
|companyId|否|String| 门店id|
|remark|否|String| 备注|
|cashPledgeItemDtos|否|List| 明细|
|--itemId|否|String|商品id |
|--itemName|否|String|商品名称 |
|--itemCode|否|String|商品名称 |
|--sourceItemId|否|String|关联来源单id |
|--specId|否|String|规格id |
|--skuBarCode|否|String|商品名称 |
|--unit|否|String|单位 |
|--realPrice|否|Double|金额 |
|tokenId|否|String||

### 请求参数Json格式
 
```
{
 "typeId" : "String",
 "typeCode" : "String",
 "typeName" : "String",
 "companyId" : "String",
 "remark" : "String",
 "cashPledgeItemDtos" : [{
 "itemId" : "String",
 "itemName" : "String",
 "itemCode" : "String",
 "sourceItemId" : "String",
 "specId" : "String",
 "skuBarCode" : "String",
 "unit" : "String",
 "realPrice" : 0
 }],
 "tokenId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--orderId|否|Long|单据id |
|--orderCode|否|String|单据编号 |
|--needPayAmount|否|Double| 需要支付的金额|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "orderId" : 0,
 "orderCode" : "String",
 "needPayAmount" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
