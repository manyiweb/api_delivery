# 查询合同支付方式列表接口

**请求URL：** 
- `/hr/yeahka/contract/payList `

**请求方式：**
- POST
- FormData


###请求参数<业务参数>
 
无参数


###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--PaymentId|否|String| 支付方式编号|
|--PaymentType|否|String| 支持的交易类型（多个以小写逗号分开，0现金，1刷卡，2主扫，3被扫，4JSPAY，5预授权）|
|--PaymentTag|否|String| 支付标签|
|--PaymentIcon|否|String| 支付方式图片url路径|
|--PaymentName|否|String| 付款方式名称|
|--PaymentInternalName|否|String| 付款方式名称（内部名称）|
|--PaymentOptionOne|否|String| 支付方式|
|--PaymentOptionTwo|否|String| 支付方式|
|--PaymentOptionThree|否|String| 支付方式|
|--PaymentOptionFour|否|String| 支付方式|
|--PaymentOptionFive|否|String| 支付方式|
|--PaymentOptionSix|否|String| 支付方式|
|--PaymentOptionSeven|否|String| 支付方式|
|--PaymentOptionOther|否|String| 支付方式|
|--PaymentOptionNine|否|String| 支付方式|
|--PaymentOptionTen|否|String| 支付方式|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
