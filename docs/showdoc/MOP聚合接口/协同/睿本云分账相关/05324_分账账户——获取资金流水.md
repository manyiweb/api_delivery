# 获取资金流水

**请求URL：** 
- `/hr/split/account/record/list `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long||
|accountId|否|Long| 账户id|
|status|否|Integer| 状态 -1：待入帐 1：已入帐|
|sword|否|String||
|startDate|否|DateTime| 开始日期|
|endDate|否|DateTime| 结束日期|
|pageIndex|否|Integer| 页号|
|pageSize|否|Integer| 页大小|

###请求参数Json格式
 
```
{
 "id" : 0,
 "accountId" : 0,
 "status" : 0,
 "sword" : "String",
 "startDate" : "DateTime",
 "endDate" : "DateTime",
 "sword" : "String",
 "pageIndex" : 0,
 "pageSize" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--pageIndex|否|Integer| 页码|
|--pageSize|否|Integer| 显示记录数|
|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|--first|否|Boolean| 首页|
|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|
|----id|否|Long||
|----accountId|否|Long| 账户id|
|----status|否|Integer| 流水状态 -1：待入帐 1: 已入帐|
|----orderStatus|否|Integer| 分账订单状态 0：成功 1：失败|
|----merchantOrderNo|否|String| 商户分账订单号|
|----platformOrderNo|否|String| 平台分账订单号|
|----platformTransactionNo|否|String| 平台分账交易号|
|----merchantNo|否|String| 商户编号|
|----amount|否|Double| 分账金额|
|----billDate|否|DateTime| 入账日期|
|----remark|否|Double| 备注|
|----createId|否|String| 创建人id|
|----createName|否|String| 创建人|
|----createDate|否|DateTime| 创建时间|
|----modifyId|否|String| 修改人id|
|----modifyName|否|String| 修改人|
|----modifyDate|否|DateTime| 修改时间|
|----dbKey|否|Integer| 分库标识|
|----groupId|否|String| 品牌商id|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
