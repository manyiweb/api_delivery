# 新增商户

**请求URL：** 
- `/hr/yeahka/merchant/add `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|merchantName|否|String||
|outMerchantId|否|String||
|accountId|否|String|账户id|
|businessLicenseType|否|String| 营业执照类型（1、三证合一，2、非三证合一）|
|businessLicenseNo|否|String| 营业执照编号（系统有唯一性校验），（小微商户不效验，随意传要有值，公司/个体户必传）|
|businessLicensePicture|否|String| 营业执照图片【私密区】（系统返回的图片路径），（小微商户不效验，随意传要有值，公司/个体户必传）|
|businessLicenseStartDate|否|String| 营业执照生效时间（yyyy-mm-dd），（小微商户不效验，随意传要有值，公司/个体户必传）|
|businessLicenseEndDate|否|String| 营业执照过期时间（yyyy-mm-dd），（小微商户不效验，随意传要有值，公司/个体户必传）|
|parentCode|否|String| 主分类编号|
|secondaryCode|否|String| 次级分类编号|
|brandName|否|String| 招牌名称|
|telephone|否|String| 联系电话|
|cityId|否|String| 城市编号|
|address|否|String| 详细地址，不含省市区县名称，长度需要大于5。|
|openHours|否|String| 营业时间，多个以小写逗号分开(9:00-12:00,13:00-18:00)|
|accountType|否|String| 结算账户类型（2对私，1对公）|
|bankNo|否|String| 清算联行号，开户行行号|
|bankName|否|String| 开户行名称|
|accountNo|否|String| 银行账号|
|accountName|否|String| 银行户名|
|bossIdType|否|String| 法人证件类型（1居民身份证,2临时居民身份证,3居民户口簿,4护照,5港澳居民来往内地通行证,6回乡证,7军人证,8武警身份证,9其他法定文件）|
|bossIdNo|否|String| 法人证件号码|
|bossName|否|String| 法人姓名|
|bossSex|否|String| 法人性别（1男，2女）|
|bossIdCountry|否|String| 法人证件国别/地区（中国CHN，香港HKG，澳门MAC，台湾CTN）|
|bossPositive|否|String| 法人身份证正面【私密区】（系统返回的图片路径）|
|bossBack|否|String| 法人身份证背面【私密区】（系统返回的图片路径）|
|bossStartDate|否|String| 法人证件生效时间（yyyy-mm-dd）|
|bossEndDate|否|String| 法人证件过期时间（yyyy-mm-dd）|
|licencePicture|否|String| 许可证图片【私密区】，（小微商户不效验，随意传要有值，公司/个体户必传）|
|accountManagerName|否|String| 客户经理姓名，必须为系统后台的管理员真实姓名|
|logo|否|String| 品牌logo|
|bossTelephone|否|String| 法人电话|
|type|否|String| 商户类型：1-个体，2-小微，3-企业。不传默认为2-小微商户。|
