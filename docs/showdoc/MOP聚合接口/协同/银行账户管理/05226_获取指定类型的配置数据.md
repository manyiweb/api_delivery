# 获取指定类型的配置数据

**请求URL：** 
- `/config/tl/findByTypeCode `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|typeCode|是|String| 类型编码 -BANK_CARD(银行卡)|
|name|否|String| 名称- 模糊查询|

###请求参数Json格式
 
```
{
 "typeCode" : "String"
 "name" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--code|否|String| 编码|
|--name|否|String| 名称|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : [{
 "code" : "String",
 "name" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
