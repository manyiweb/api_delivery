# 生成sign

**请求URL：** 
- `/hr/bankaccount/allinpay/sign `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|param|否|Map| 需要加密的数据|
|type|否|String| 加密类型 setPayPwd 设置密码，updatePhoneByPayPwd 修改绑定手机 signContract 签约 updatePayPwd 修改密码 |

###请求参数Json格式
 
```
{
 "param" : null,
 "type" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|String| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : "String",
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
