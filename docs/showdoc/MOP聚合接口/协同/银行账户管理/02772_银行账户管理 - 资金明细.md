# 银行账户管理 - 资金明细

**请求URL：** 
- `/hr/bankaccount/yunst/queryInExpDetail `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|sendId|否|Long| 对接标识(用户标识)|
|beginDate|否|String| 开始时间 yyyy-MM-dd|
|endDate|否|String| 结束时间 yyyy-MM-dd|
|pageIndex|否|Integer| 分页页码|
|pageSize|否|Integer| 分页大小|
|sword|否|String| 搜索关键字|

###请求参数Json格式
 
```
{
 "sendId" : 0,
 "beginDate" : "String",
 "endDate" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "sword" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--pageIndex|否|Integer| 页码|
|--pageSize|否|Integer| 显示记录数|
|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|--first|否|Boolean| 首页|
|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|
|----tradeNo|否|String| 收支明细流水号|
|----accountSetName|否|String| accountSetName|
|----changeTime|否|String| 变更时间|
|----curAmount|否|Integer| 现有金额|
|----oriAmount|否|Integer| 原始金额|
|----chgAmount|否|Integer| 变更金额|
|----curFreezenAmount|否|Integer| 现有冻结金额|
|----bizOrderNo|否|String| 商户订单号（支付订单）|
|----type|否|String| 类型(文档没有的字段)|
|----extendInfo|否|String| 扩展参数(文档也没有)|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式

```
 "tradeNo" : "String",

 "changeTime" : "String",

 "curFreezenAmount" : 0,
 "bizOrderNo" : "String",
 "type" : "String",

 }]
 },

 "exceptionStackInfo" : "String"
}
```
