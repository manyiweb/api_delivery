# 银行账户详情-认证信息

**请求URL：** 
- `/hr/bankaccount/auth/detail `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|

###请求参数Json格式
 
```
{
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long| 主键|
|--userCode|否|String| 用户标识|
|--userName|否|String| 真实姓名|
|--phone|否|String| 手机号|
|--idCard|否|String| 身份证|
|--sex|否|Integer| 性别 （1男 0女）|
|--address|否|String| 地址|
|--province|否|String| 省|
|--city|否|String| 市|
|--area|否|String| 区|
|--socialCreditCode|否|String| 统一社会信用代码|
|--enterprisePhone|否|String| 企业固话|
|--enterpriseName|否|String| 企业名称|
|--idType|否|Integer| 证件类型（1居民身份证）|
|--idNumber|否|String| 证件号码|
|--bankCode|否|String| 开户银行编码|
|--bankName|否|String| 开户银行名称|
|--bankProvinceName|否|String| 开户银行省份编码|
|--bankProvinceCode|否|String| 开户银行省份名称|
|--bankCityName|否|String| 开户银行县市名称|
|--bankCityCode|否|String| 开户银行县市编码|
|--bankAccount|否|String| 银行对公账户|
|--bankBranchName|否|String| 开户行支行名称|
|--manageId|否|Long| 主表主键|
|--createId|否|String| 创建人id|
|--createName|否|String| 创建人|
|--createDate|否|DateTime| 创建时间|
|--modifyId|否|String| 修改人id|
|--modifyName|否|String| 修改人|
|--modifyDate|否|DateTime| 修改时间|
|--dbKey|否|Integer| 分库标识|
|--groupId|否|String| 品牌商id|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
