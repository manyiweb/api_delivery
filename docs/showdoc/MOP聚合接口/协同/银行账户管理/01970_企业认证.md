# 企业认证
 

**请求URL：** 
- `/hr/bankaccount/enterprise/auth `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|enterpriseName|否|String| 企业名称|
|province|否|String| 企业地址 -省|
|city|否|String| 企业地址 -市|
|area|否|String| 企业地址 -区|
|address|否|String| 企业地址 -详细地址|
|socialCreditCode|否|String| 统一社会信用代码|
|enterprisePhone|否|String| 企业固话|
|legalPersonName|否|String| 法人名称|
|idType|否|Integer| 法人证件类型|
|idNumber|否|String| 法人证件号码|
|legalPersonPhone|否|String| 法人手机号|
|id|否|Long| 主键|

###请求参数Json格式
 
```
{
 "enterpriseName" : "String",
 "province" : "String",
 "city" : "String",
 "area" : "String",
 "address" : "String",
 "socialCreditCode" : "String",
 "enterprisePhone" : "String",
 "legalPersonName" : "String",
 "idType" : 0,
 "idNumber" : "String",
 "legalPersonPhone" : "String",
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
