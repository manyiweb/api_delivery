# 银行账户管理 - 资金明细 - 导出

**请求URL：** 
- `file/hr/bankaccount/yunst/queryInExpDetail/export `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|sendId|否|Long| 对接标识(用户标识)|
|beginDate|否|String| 开始时间 yyyy-MM-dd|
|endDate|否|String| 结束时间 yyyy-MM-dd|

###请求参数Json格式
 
```
{
 "sendId" : 0,
 "beginDate" : "String",
 "endDate" : "String"
}
```

###返回参数
文件流
