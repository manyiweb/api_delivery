# 确认支付（后台+短信验证码确认）
 

**请求URL：** 
- `/hr/yunst/pay `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|sendId|否|Long| 对接标识(用户标识)|
|bizOrderNo|否|String| 支付订单号|
|verificationCode|否|String| 验证码|

###请求参数Json格式
 
```
{
 "sendId" : 0,
 "bizOrderNo" : "String",
 "verificationCode" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--payStatus|否|String| success 成功 pending 进行中|
|--payFailMessage|否|String| 只有 payStatus 为 fail 时有|
|--bizUserId|否|String| 商户系统用户标识|
|--bizOrderNo|否|String| 商户订单号（支付订单）|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : {
 "payStatus" : "String",
 "payFailMessage" : "String",
 "bizUserId" : "String",
 "bizOrderNo" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
