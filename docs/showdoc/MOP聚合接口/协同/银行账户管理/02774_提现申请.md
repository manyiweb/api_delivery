# 提现申请
 

**请求URL：** 
- `/hr/bankaccount/yunst/withdrawApply `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|sendId|否|Long| 对接标识(用户标识)|
|amount|否|Double| 提现金额（元，两位小数）|
|bankCardNo|否|String| 卡号|

###请求参数Json格式
 
```
{
 "sendId" : 0,
 "amount" : 0,
 "bankCardNo" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--bizOrderNo|否|String| 第三方单号|
|--orderNo|否|String| 外部返回的单号|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : {
 "bizOrderNo" : "String",
 "orderNo" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
