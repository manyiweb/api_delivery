# 获取参数配置

**请求URL：** 
- `/hr/bankaccount/accountparame/detail `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
无参数


###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--parame|否|String| 参数|
|--certName|否|String| cer证书名称|
|--pfxName|否|String| pfx证书名称|
|--tlCertName|否|String| TLCert证书名称|
|--feeCalcType|否|Integer| 零售收款手续费-1固定金额 2-固定比例|
|--feeCalcVal|否|Double| 零售收款手续费-金额/比例|
|--distrWithdrawFeeCalcType|否|Integer| 商户账户余额手续费--1固定金额 2-固定比例|
|--distrWithdrawFeeCalcVal|否|Double| 商户账户余额手续费-金额/比例|
|--companyWithdrawFeeCalcType|否|Integer| 经销商账户余额提现手续费--1固定金额 2-固定比例|
|--companyWithdrawFeeCalcVal|否|Double| 经销商账户余额提现手续费-金额/比例|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : {
 "parame" : "String",
 "certName" : "String",
 "pfxName" : "String",
 "tlCertName" : "String",
 "feeCalcType" : 0,
 "feeCalcVal" : 0,
 "distrWithdrawFeeCalcType" : 0,
 "distrWithdrawFeeCalcVal" : 0,
 "companyWithdrawFeeCalcType" : 0,
 "companyWithdrawFeeCalcVal" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
