# 银行账户详情

**请求URL：** 
- `/hr/bankaccount/detail `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|

###请求参数Json格式
 
```
{
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long| 主键|
|--relatedAccountId|否|String| 账户id|
|--relatedAccountCode|否|String| 账户编号|
|--relatedAccountName|否|String| 账户名称|
|--accountTypeCode|否|Integer| 账户类型（0 商户 1经销商）|
|--status|否|Integer| 状态（0停用 1启用）|
|--authType|否|Integer| 认证类型（3个人 2企业）|
|--authStatus|否|Integer| 认证状态（0未认证 1已认证）|
|--accountBalance|否|Double| 账户余额|
|--recordedAmount|否|Double| 待入账金额|
|--externalId|否|String| 外部用户id|
|--sendId|否|Long| 对接用id|
|--statusName|否|String| 状态|
|--authTypeName|否|String| 认证类型|
|--authStatusName|否|String| 认证状态|
|--accountTypeName|否|String| 账户类型（0 商户 1经销商）|
|--step|否|Integer| 流程标识|
|--yunStQueryBalance|否|Object| 账户余额|
|----status|否|Integer| 请求获取余额 状态 1正常 0异常，默认1|
|----errMsg|否|String| 错误日志|
|----allAmount|否|Double| 余额(元)|
|----freezenAmount|否|Double| 冻结金额(元)|
|--waitSplitAmount|否|Double| 待入账金额|
|--withdrawCalcParam|否|Object| 提现计算参数|
|----feeCalcType|否|Integer| 零售收款手续费-1固定金额 2-固定比例|
|----feeCalcVal|否|Double| 零售收款手续费-金额/比例|
|----distrWithdrawFeeCalcType|否|Integer| 商户账户余额手续费--1固定金额 2-固定比例|
|----distrWithdrawFeeCalcVal|否|Double| 商户账户余额手续费-金额/比例|
|----companyWithdrawFeeCalcType|否|Integer| 经销商账户余额提现手续费--1固定金额 2-固定比例|
|----companyWithdrawFeeCalcVal|否|Double| 经销商账户余额提现手续费-金额/比例|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
