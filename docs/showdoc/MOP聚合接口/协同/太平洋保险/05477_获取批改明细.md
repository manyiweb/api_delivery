# 获取批改明细

**请求URL：** 
- `/hr/the/pacific/findCorrectDetail `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|correctId|否|Long| 批改id|
|pageIndex|否|Integer| 页号|
|pageSize|否|Integer| 页大小|
|orderField|否|String| 商品排序字段|
|orderSort|否|String| 商品排序方式 desc 倒序 asc 正序|

###请求参数Json格式
 
```
{
 "correctId" : 0,
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--pageIndex|否|Integer| 页码|
|--pageSize|否|Integer| 显示记录数|
|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|--first|否|Boolean| 首页|
|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|
|----id|否|Long| 主键|
|----insuranceManageId|否|Long| 保单id 关联insurance_manage表|
|----insuranceCorrectId|否|Long| 批改记录id 关联insurance_correct表|
|----branchName|否|String| 被保人公司|
|----credictCode|否|String| 证件号码|
|----credictType|否|String| 证件类型|
|----profession|否|String| 工种|
|----birthday|否|String| 出生日期|
|----changeType|否|Integer| 人员变化类型|
|----personId|否|String| 人员ID|
|----status|否|Integer| 1成功 0失败|
|----message|否|String| 返回信息|
|----name|否|String| 员工姓名|
|----phone|否|String| 手机号|
|----staffId|否|String| 用户id|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
