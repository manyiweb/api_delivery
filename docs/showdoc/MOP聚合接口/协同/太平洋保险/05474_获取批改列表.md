# 获取批改列表

**请求URL：** 
- `/hr/the/pacific/findByInsuranceId `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|insuranceId|否|Long| 保单id|
|id|否|Long| 批改单id|
|pageIndex|否|Integer| 页号|
|pageSize|否|Integer| 页大小|
|orderField|否|String| 商品排序字段|
|orderSort|否|String| 商品排序方式 desc 倒序 asc 正序|

###请求参数Json格式
 
```
{
 "insuranceId" : 0,
 "id" : 0,
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--pageIndex|否|Integer| 页码|
|--pageSize|否|Integer| 显示记录数|
|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|--first|否|Boolean| 首页|
|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|
|----id|否|Long| 批改单id|
|----insuranceManageId|否|Long| 保单id 关联insurance_manage表|
|----correctFileName|否|String| 批改文件名称|
|----correctNum|否|Integer| 批改人数|
|----callbackDate|否|DateTime| 回调时间|
|----callbackStatus|否|Integer| 回调状态|
|----callbackStatusName|否|String| 回调状态|
|----batchNo|否|String| 批改批次号|
|----correctionType|否|Integer| 批单类型（8:批增,2:被保人批改/批换,9:批减）|
|----status|否|Integer| 批改状态|
|----statusName|否|String| 批改状态|
|----createDate|否|DateTime| 创建时间|
|----createName|否|String| 创建人|
|----createId|否|String| 创建人id|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|

 }]
