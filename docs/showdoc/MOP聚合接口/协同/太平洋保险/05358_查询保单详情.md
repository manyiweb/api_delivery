# 查询保单详情

**请求URL：** 
- `/hr/the/pacific/detail `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 保单id|
|pageIndex|否|Integer| 页号|
|pageSize|否|Integer| 页大小|
|orderField|否|String| 商品排序字段|
|orderSort|否|String| 商品排序方式 desc 倒序 asc 正序|

###请求参数Json格式
 
```
{
 "id" : 0,
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--insurance|否|Object| 保单数据|
|----batchNo|否|String| 批次号|
|----insurancePolicyName|否|String| 保单名称|
|----insureMessage|否|String| 投保信息|
|----insureNum|否|String| 保单号|
|----remark|否|String| 备注|
|----status|否|Integer| 保单状态 -1 取消投保，0待投保，1投保中，2部分投保，3已投保|
|----statusName|否|String| 保单状态 -1 取消投保，0待投保，1投保中，2部分投保，3已投保|
|----pushDate|否|DateTime| 推送时间|
|----latelyInsureDate|否|DateTime| 最近投保时间|
|----createName|否|String| 创建人|
|----createDate|否|DateTime| 创建时间|
|----riskName|否|String| 险种名称|
|----totalPremium|否|Double| 总保费|
|----insureSuccessNum|否|Long| 被保成功人数|
|----callbackDate|否|DateTime| 投保回调时间|
|--insuranceDetails|否|Object| 保单明细数据|
|----pageIndex|否|Integer| 页码|
|----pageSize|否|Integer| 显示记录数|
|----pageCount|否|Integer| 总页数|
|----totalCount|否|Long| 总记录数|
|----first|否|Boolean| 首页|
|----last|否|Boolean| 尾页|
|----content|否|List| 分页数据|
|------id|否|Long| 保单明细id|
|------staffId|否|String| 用户id|
|------insuranceManageId|否|Long| 保单id 关联insurance_manage表|
|------phone|否|String| 手机号|
|------branchName|否|String| 被保人公司|
|------employName|否|String| 姓名|
|------employNum|否|Long| 员工编号|
|------certNo|否|String| 身份证号码|
|------workType|否|String| 工种|
|------status|否|Integer| 投保状态 0失败，1成功|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
