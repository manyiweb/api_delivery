# 导入批改明细

**请求URL：** 
- `/file/insurance/correct/importCorrectApplyDetail `

**请求方式：**
- POST
- FormData


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|correctionType|否|Integer| 批单类型 8:批增,2:被保人批改/批换,9:批减|
|insuranceId|否|Long| 保单id|
|tokenId|否|String| 登录标识|
|file|否|Object| 导入文件|

###请求参数Json格式
 
```
{
 "correctionType" : 0,
 "insuranceId" : 0,
 "tokenId" : "String",
 "file" : null
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--dataSource|否|List| 导入数据|
|----status|否|Integer| 是否导入成功,0=成功,1=不成功|
|----msg|否|String| 导入失败信息|
|----branchName|否|String| 被保人公司|
|----credictCode|否|String| 证件号码|
|----credictType|否|String| 证件类型|
|----profession|否|String| 工种|
|----birthday|否|String| 出生日期|
|----changeType|否|Integer| 人员变化类型|
|----personId|否|String| 人员ID|
|----name|否|String| 员工姓名|
|----phone|否|String| 手机号|
|----staffId|否|String| 用户id|
|--fileName|否|String| 文件名称|
|--correctNum|否|Integer| 批改人数|
|--totalCount|否|Long| 总数|
|--successCount|否|Long| 成功数|
|--errorCount|否|Long| 失败数|
|--fileUrl|否|String| 导出文件相对路径|
|--downloadURL|否|String| 导出文件下载路径|
|--data|否|List| 返回数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
