# 导入保单明细

**请求URL：** 
- `/file/insurance/manage/importInsuranceDetail `

**请求方式：**
- POST
- FormData


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|否|String| 登录标识|
|file|否|Object| 导入文件|

###请求参数Json格式
 
```
{
 "tokenId" : "String",
 "file" : null
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--insuranceDetails|否|List| 保单明细数据|
|----branchName|否|String| 被保人公司|
|----phone|否|String| 手机号|
|----employName|否|String| 姓名|
|----employNum|否|Long| 员工编号|
|----certNo|否|String| 身份证号码|
|----workType|否|String| 工种|
|----msg|否|String||
|----isSuccess|否|Boolean||
|----cellStyleMap|否|Map||
|--errorPhones|否|Object| 异常手机号|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "insuranceDetails" : [{
 "branchName" : "String",
 "phone" : "String",
 "employName" : "String",
 "employNum" : 0,
 "certNo" : "String",
 "workType" : "String",
 "msg" : "String",
 "isSuccess" : true,
 "cellStyleMap" : null
 }],
 "errorPhones" : null
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
