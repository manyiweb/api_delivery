# 项目明细分析
 

**请求URL：** 
- `/report/hr/guidemall/project/analysis/business/item `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|否|String||
|taskCode|否|String|项目单号|
|isDownload|否|String| Y下载|

###请求参数Json格式
 
```
{
 "tokenId" : "String",
 "taskCode" : "String",
 "isDownload" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--projectPayAnalysisBusinessItem2Dtos|否|LIst||
|----staffName|否|String| 用户姓名|
|----projectCode|否|String| 项目编码|
|----projectName|否|String| 项目名称|
|----taskCode|否|String| 子项目编码|
|----companyName|否|String| 派单企业|
|----commission|否|Double| 结算金额|
|----totalPayTaxes|否|Double| 纳税金额|
|----receiptDate|否|DateTime| 承揽时间|
|----handoverDate|否|DateTime| 交付时间|
|--url|否|String|导出下载地址|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data":{
 "projectPayAnalysisStaffItemDtos":[
 {
 "staffName":"String",
 "projectCode":"String",
 "projectName":"String",
 "taskCode":"String",
 "companyName":"String",
 "commission":0,
 "totalPayTaxes":0,
 "receiptDate":"DateTime",
 "handoverDate":"DateTime"
 }
 ],
 "url":""
 },
 "msg":"String",
 "code":"String",
 "exceptionStackInfo":"String"
}
```
