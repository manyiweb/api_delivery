# 个人佣金明细
 

**请求URL：** 
- `/report/hr/guidemall/project/analysis/item `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|否|String||
|staffId|否|String|用户id|
|isDownload|否|String| Y下载|

###请求参数Json格式
 
```
{
 "tokenId" : "String",
 "staffId" : "String",
 "isDownload" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--projectPayAnalysisStaffItemDtos|否|List|个人明细数据|
|----projectCode|否|String| 项目单号|
|----projectName|否|String| 项目名称|
|----taskCode|否|String| 子任务编号|
|----commission|否|Double| 结算佣金|
|----receiptDate|否|DateTime| 承接时间|
|----handoverDate|否|DateTime| 交付时间|
|----grantDate|否|DateTime|发放时间|
|----invoiceNumber|否|String| 发票号码|
|----invoiceUrl|否|String| 发票图片|
|--url|否|String|导出下载地址|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
