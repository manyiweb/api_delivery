# 开票汇总分析
 

**请求URL：** 
- `/report/hr/guidemall/invoice/analysis `

**请求方式：**
- POST
- RequestBody

**高级筛选**
{"filterType":"guidemallProjectPayAnalysis","filterSource":"report"}

###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|否|String||
|groupId|否|String| 商户id|
|beginDate|否|String|开始时间|
|endDate|否|String|结束时间|
|companyId|否|String| 商户id|
|staffId|否|String| 用户id|
|idCard|否|String| 身份证号|
|invoiceNumber|否|String| 发票号|
|isDownload|否|String| Y下载|

###请求参数Json格式
 
```
{
 "tokenId" : "String",
 "groupId" : "String",
 "beginDate" : "String",
 "endDate" : "String",
 "taskCode" : "String",
 "companyId" : "String",
 "staffId" : "String",
 "idCard" : "String",
 "invoiceNumber" : "String",
 "isDownload" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Obejct| 主数据|
|--projectInvoiceAnalysisDtos|否|List||
|----invoiceNumber|否|发票号码|
|----taskNumber|否|Integer|子项目数|
|----totalCommission|否|Double|佣金总额|
|----totalPayTaxes|否|Double|纳税总额|
|----projectInvoiceAnalysisItemDtos|否|List||
|------receiptName|否|String|姓名|
|------projectTaskCode|否|String|项目单号|
|------projectName|否|String|项目名称|
|------taskCode|否|String|子项目编号|
|------companyName|否|String|派单企业|
|------commission|否|String|小计 项目佣金|
|------totalPayTaxes|否|String|小计 纳税金额|
|------receiptDate|否|Date|承揽时间|
|------handoverDate|否|Date|交付时间|
|------grantDate|否|DateTime|发放时间|
|--taskNumberAll|否|Integer|子项目总数|
|--totalCommissionAll|否|Double|佣金总额|
|--totalPayTaxesAll|否|Double|纳税总额|
|--url|否|String|导出地址|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
