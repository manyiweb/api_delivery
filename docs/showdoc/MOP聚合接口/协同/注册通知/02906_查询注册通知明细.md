# 查询注册通知明细

**请求URL：** 
- `/hr/regnoticeitem/page `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|ncId|否|Long|主表id|
|tokenId|否|Long|令牌|
|pageIndex|否|Integer| 页号|
|pageSize|否|Integer| 页大小|
|orderField|否|String| 商品排序字段|
|orderSort|否|String| 商品排序方式 desc 倒序 asc 正序|

###请求参数Json格式
 
```
{
 "ncId" : 0,
 "tokenId":"",
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--sendCount|否|Integer| 发送总数|
|--sendSuccessCount|否|Integer| 发送成功数|
|--sendFailCount|否|Integer| 发送失败数|
|--regNoticeItemPageDtoRespPage|否|Object| 明细对象|
|----pageIndex|否|Integer| 页码|
|----pageSize|否|Integer| 显示记录数|
|----pageCount|否|Integer| 总页数|
|----totalCount|否|Long| 总记录数|
|----first|否|Boolean| 首页|
|----last|否|Boolean| 尾页|
|----content|否|List| 分页数据|
|------id|否|Long||
|------userCode|否|String| 手机号|
|------userName|否|String| 用户名|
|------staffCode|否|String| 用户编码|
|------sendResult|否|Integer| 发送结果 0；失败 1；成功|
|------reason|否|String| 原因|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : {
 "sendCount" : 0,
 "sendSuccessCount" : 0,
 "sendFailCount" : 0,
 "regNoticeItemPageDtoRespPage" : {
 "pageIndex" : 0,
 "pageSize" : 0,
 "pageCount" : 0,
 "totalCount" : 0,
 "first" : true,
 "last" : true,
 "content" : [{
 "id" : 0,
 "userCode" : "String",
 "userName" : "String",
 "staffCode" : "String",
 "sendResult" : 0,
 "reason" : "String"
 }]
 }
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
