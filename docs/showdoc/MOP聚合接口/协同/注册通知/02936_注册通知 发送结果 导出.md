# 注册通知 发送结果 导出
 

**请求URL：** 
- `/file/export/regNoticeItem `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|否|Long||
|ncId|否|String||
|pageIndex|否|Integer| 页号|
|pageSize|否|Integer| 页大小|

###请求参数Json格式
 
```
{
 "ncId": 885790292738917438,
 "pageSize": 10,
 "pageIndex": 1,
 "tokenId": "7a083d2b44874a0e8a3eb8d9b5e6f041"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|ErrorCode|否|String| |
|ResultString|否|String| |
|url|否|String| 下载地址|
|ResultInt|否|String| 返回结果 0成功|


###返回参数Json格式
 
```
{
	"ErrorCode": "",
	"ResultString": "操作成功",
	"url": "https://upaiyun.reabam.com/export/用户注册发送结果导出(20200713165331810).xlsx",
	"ResultInt": 0
}
```
