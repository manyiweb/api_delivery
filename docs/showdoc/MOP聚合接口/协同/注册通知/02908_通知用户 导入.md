# 通知用户 导入

**请求URL：** 
- `/file/import/regnotice/staff `

**请求方式：**
- POST
- FormData

**模板**
regNoticeAdd	/Template/注册通知管理导入模板.xlsx

###请求参数<业务参数>
 
```
表单
tokenId
file
```


###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|--DataLine|否|List| 通知对象|
|----userCode|否|String| 手机号码|
|----userName|否|String| 用户名称|
|----userCode|否|String| 用户编号|
|--successCount|否|Integer| 成功导入数量|
|--errorCount|否|Integer| 失败数|
|--downloadURL|否|String| 失败数据下载地址|
|--ResultString|否|String| 操作成功|
|--totalCount|否|Integer| 总数|


###返回参数Json格式
 
```
{
	"DataLine": [
		{
			"staffCode": "",
			"userName": "",
			"userCode": ""
		}
	],
	"downloadURL": "",
	"successCount": 2,
	"ErrorCode": "",
	"ResultString": "操作成功",
	"totalCount": 2,
	"errorCount": 0,
	"ResultInt": 0
}
```
