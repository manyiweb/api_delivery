# 商户等级列表(分页)
 

**请求URL：** 
- `/hr/company/grade/list `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long|id|
|tokenId|否|String| 用户标识|
|pageIndex|否|Integer| 分页页码|
|pageSize|否|Integer| 分页大小|
|sword|否|String| 搜索关键字|

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--pageIndex|否|Integer| 页码|
|--pageSize|否|Integer| 显示记录数|
|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|--first|否|Boolean| 首页|
|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|
|----id|否|Long| id|
|----gradeCode|否|String| 等级编码|
|----gradeName|否|String| 等级名称|
|----gradeLock|否|Integer| 锁定等级|
|----gradeLockName|否|String| 锁定等级|
|----priority|否|Integer| 优先级|
|----createName|否|String| 创建人|
|----createDate|否|DateTime| 创建时间|
|----modifyName|否|String| 修改人名称|
|----modifyDate|否|DateTime| 修改时间|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
