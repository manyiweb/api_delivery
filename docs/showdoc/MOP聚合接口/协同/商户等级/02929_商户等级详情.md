# 商户等级详情
 

**请求URL：** 
- `/hr/company/grade/detail `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|

###请求参数Json格式
 
```
{
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long| id|
|--gradeCode|否|String| 等级编码|
|--gradeName|否|String| 等级名称|
|--gradeLock|否|Integer| 锁定等级|
|--openValidMonth|否|Long| 有效期(月)|
|--validMonth|否|Integer| 有效期(月)|
|--validScroll|否|Integer| 启用滚动有效期 1是0否|
|--openConsume|否|Integer| 开启累计消费金额 1是0否|
|--consumeValidType|否|Integer| 累计消费金额类型 0注册日起 1升级日起|
|--consumeAmount|否|Double| 累计消费金额|
|--openOneConsume|否|Integer| 开启一次性消费金额 1是0否|
|--oneConsumeValidType|否|Integer| 一次性消费类型 0注册日起 1升级日起|
|--oneConsumeAmount|否|Double| 一次性消费金额|
|--openMonthConsume|否|Integer| 开启区间消费 1是0否|
|--monthConsumeMonths|否|Integer| 区间消费月数|
|--monthConsumeAmount|否|Double| 区间消费金额|
|--openInvite|否|Integer| 开启邀请商户消费 1是0否|
|--inviteValidType|否|Integer| 邀请商户消费类型 0注册日起 1升级日起|
|--inviteQuantity|否|Long| 邀请商户人数|
|--inviteConsumeAmount|否|Double| 邀请商户一次性消费金额|
|--priority|否|Integer| 优先级|
|--createName|否|String| 创建人|
|--createDate|否|DateTime| 创建时间|
|--modifyName|否|String| 修改人名称|
|--modifyDate|否|DateTime| 修改时间|
|--conditions|否|List| 关系条件|
|----openConsume|否|Integer| 开启累计消费金额 1是0否|
|----openOneConsume|否|Integer| 开启一次性消费金额 1是0否|
|----openMonthConsume|否|Integer| 开启区间消费 1是0否|
|----openInvite|否|Integer| 开启邀请商户消费 1是0否|
|----createName|否|String| 创建人|
|----createDate|否|DateTime| 创建时间|
|----modifyName|否|String| 修改人名称|
|----modifyDate|否|DateTime| 修改时间|
|--EnableDegradationGrade|否|Boolean| 启用降级等级|
|--degradationGradeId|否|Long| 降级等级标识|
|--degradationGradeName|否|String| 降级等级名称|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
