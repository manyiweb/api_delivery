# 确认注册邀请
 

**请求URL：** 
- `/api/hr/company/invitation/register/confirm`

**请求方式：** 
- `POST`
- `RequestBody`


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|confirm|是|Boolean| 确认 true
 拒绝 false|
|recordId|是|Long| 记录id|

### 请求参数Json格式
 
```
{
 "confirm":true,
 "recordId":0
}
```

### 响应参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 响应参数Json格式
 
```
{
 "data":null,
 "msg":"String",
 "code":"String",
 "exceptionStackInfo":"String",
 "traceId":"String"
}
```
