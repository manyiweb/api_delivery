# 获取邀请注册记录
 

**请求URL：** 
- `/hr/company/invitation/register/query`

**请求方式：** 
- `POST`
- `RequestBody`


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|applyStatus|是|Integer| 申请状态 0-待确认 1-已确认 2-已拒绝|
|pageIndex|否|Integer| 页码|
|pageSize|否|Integer| 每页数量|

### 请求参数Json格式
 
```
{
 "applyStatus":0,
 "pageIndex":0,
 "pageSize":0
}
```

### 响应参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--pageIndex|否|Integer||
|--pageSize|否|Integer||
|--pageCount|否|Integer||
|--totalCount|否|Long||
|--first|否|Boolean||
|--last|否|Boolean||
|--content|否|List||
|----id|否|Long| 主键|
|----applyStatus|否|Integer| 申请状态 0: 申请中, 1: 已确认, 2: 已拒绝|
|----companyName|否|String| 商户名称|
|----companyId|否|String| 商户ID|
|----inviterCompanyId|否|String| 邀请门店ID|
|----applyName|否|String| 申请人|
|----applyPhone|否|String| 申请人手机号|
|----applyTime|否|DateTime| 申请时间|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 响应参数Json格式
 
```
{
 "data":{
 "pageIndex":0,
 "pageSize":0,
 "pageCount":0,
 "totalCount":0,
 "first":true,
 "last":true,
 "content":[{
 "id":0,
 "applyStatus":0,
 "companyName":"String",
 "companyId":"String",
 "inviterCompanyId":"String",
 "applyName":"String",
 "applyPhone":"String",
 "applyTime":"DateTime"
 }]
 },
 "msg":"String",
 "code":"String",
 "exceptionStackInfo":"String",
 "traceId":"String"
}
```
