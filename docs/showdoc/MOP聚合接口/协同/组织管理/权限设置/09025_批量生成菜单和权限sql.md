# 批量生成菜单和权限sql

**请求URL：** 
- `/hr/fun/permission/batchBuildFunctionAndRoleFun`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|filePath|否|String| 文件路径|
|type|否|String| 类型 menu-菜单, fun-功能|
|sysNo|否|String| 平台|
|parentId|否|String| 父级权限编码|
|isAdmin|是|Boolean| 是否只给管理员分配权限 true/false|
|functionTempleSql|否|String| 新增菜单模板sql, 自定义模板填充值|
|roleFunTempleSql|否|String| 分配权限模板sql, 自定义模板填充值|
|functions|是|List| 权限信息|
|--funCode|是|String| 权限编码|
|--funName|是|String| 权限名称|
|--parentId|否|String| 父级权限编码|
|--lineId|否|Integer| 排序号|
|--status|否|String| 状态 Y启用 N停用|
|--isDisplay|否|Integer| 是否隐藏 1是 0否|
|--type|否|String| 类型 menu-菜单, fun-功能 优先级高于外层，如果为空就拿外层的|
|--sysNo|否|String| 平台 优先级高于外层，如果为空就拿外层的|

### 请求参数Json格式
 
```
{
 "filePath" : "String",
 "type" : "String",
 "sysNo" : "String",
 "parentId" : "String",
 "isAdmin" : true,
 "functionTempleSql" : "String",
 "roleFunTempleSql" : "String",
 "functions" : [{
 "funCode" : "String",
 "funName" : "String",
 "parentId" : "String",
 "lineId" : 0,
 "status" : "String",
 "isDisplay" : 0,
 "type" : "String",
 "sysNo" : "String"
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
