# 复制菜单和权限sql

**请求URL：** 
- `/hr/fun/permission/copyFunctionAndRoleFun`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|filePath|否|String| 文件路径|
|copyMode|是|Integer| 复制模式 1复制当前权限和子级权限，2只复制当前权限，3只复制子级权限|
|sourceFuncIds|是|List| 来源菜单id, sfunction表的id（sfunction_cloud跟sfunction的id一般都是一样）|
|targetFuncId|否|String| 目标菜单id（放在哪个菜单下面，空就是最外层）|
|sysNo|否|String| 平台（如果targetFuncId为空则使用sysNo，否则以targetFuncId对应的菜单为准）|
|childLevel|否|Integer| 需要获取多少层级数据，最多10层(当前菜单不算，下一级子菜单是1依次类推)|
|isAdmin|是|Boolean| 是否只给管理员分配权限 true/false|

### 请求参数Json格式
 
```
{
 "filePath" : "String",
 "copyMode" : 0,
 "sourceFuncIds" : null,
 "targetFuncId" : "String",
 "sysNo" : "String",
 "childLevel" : 0,
 "isAdmin" : true
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",

 "traceId" : "String"
}
```
