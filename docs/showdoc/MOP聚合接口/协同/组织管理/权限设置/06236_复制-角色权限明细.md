# 复制-角色权限明细

**请求URL：** 
- `/hr/role/permission/copy`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|roleId|是|String| 源角色Id|
|toRoleIds|是|List| 目标角色Id列表|
|sysNo|是|String| 权限类型(平台标识)|

### 请求参数Json格式
 
```
{
 "roleId" : "String",
 "toRoleIds" : null,
 "sysNo" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|String| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : "String",
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
