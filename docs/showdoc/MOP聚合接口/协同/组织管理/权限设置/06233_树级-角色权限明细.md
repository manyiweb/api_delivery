# 树级-角色权限明细

**请求URL：** 
- `/hr/role/permission/tree`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|roleId|是|String| 角色Id|
|sysNo|是|String| 权限类型(平台标识)|

### 请求参数Json格式
 
```
{
 "roleId" : "String",
 "sysNo" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--fid|否|String| 权限id|
|--ftype|否|String| 权限类型：menu-菜单;fun-非菜单|
|--funCode|否|String| 权限编码|
|--funName|否|String| 权限名称|
|--isDisplay|否|Integer| 是否展示|
|--isSel|否|Integer| 是否选中|
|--parentId|否|String| 父级权限id|
|--items|否|List| 子级权限列表|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : [{
 "fid" : "String",
 "ftype" : "String",
 "funCode" : "String",
 "funName" : "String",
 "isDisplay" : 0,
 "isSel" : 0,
 "parentId" : "String",
 "items" : null
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
