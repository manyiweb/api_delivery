# 注册链客创客类型用户

**请求URL：** 
- `/hr/staff/signInMaker `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|userName|是|String| 姓名|
|userCode|是|String| 手机号码(登录名)|
|msgCode|是|String| 验证码|
|pwd|是|String| 密码|
|companyId|是|String| 门店id|
|groupId|是|String| 品牌id|

###请求参数Json格式
 
```
{
 "userName" : "String",
 "userCode" : "String",
 "msgCode" : "String",
 "pwd" : "String",
 "companyId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|String| 用户id|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : "String",
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
