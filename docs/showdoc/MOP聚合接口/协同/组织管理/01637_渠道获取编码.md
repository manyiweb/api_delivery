# 渠道获取编码


 
**简要描述：** 

- 用户注册接口

**请求URL：** 
- ` http://ht.reabam.com:50006/api/bmg/product/getTableUniqueNo `
 
**请求方式：**
- POST 

**参数：** 
```
{"tableName":"distr","uniqueKey":"channel","prefix":"FL","len":2,"tokenId":"220b32be8e1a4bdbbdbe380222190ba1"}
```
 **返回示例**

``` 
{
 "tableUniqueNo": "FL002",
 "ErrorCode": "",
 "ResultString": "操作成功",
 "ResultInt": 0
}

```
