# 商户复制
 

**请求URL：** 
- `/hr/company/copy`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|formCompanyId|是|String| 被复制门店|
|toCompanyId|是|String| 复制到门店|
|tokenId|否|String| 登录标识|
|copyMitemcomp|否|Boolean|复制应用商品 |
|copyScenarios|否|Boolean|复制场景 |
|copyMallSalePrice|否|Boolean|复制零售价格 |
|copyB2bPrice|否|Boolean|复制订货价格 |
|copyStaffData|否|Boolean|复制运营用户 |
|copyOrderSet|否|Boolean|复制订货配置 |
|copyBusinessType|否|Boolean|复制业务类型 |
|copyB2bReceivableaccount|否|Boolean|复制订货收款账户 |
|copyB2bDeliveryConfig|否|Boolean|复制订货配送方式设置 |
|copyB2bOrderGiveIntegralSetting|否|Boolean|复制订货积分设置 |
|copyB2BPayConfig|否|Boolean|复制支付设置 |
|addChanpinzhuangxiu|否|Boolean|产品装修 |

### 请求参数Json格式
 
```
{
 "formCompanyId" : "String",
 "toCompanyId" : "String",
 "tokenId" : "String",
 "copyMitemcomp" : true,
 "copyScenarios" : true,
 "copyMallSalePrice" : true,
 "copyB2bPrice" : true,
 "copyStaffData" : true,
 "copyOrderSet" : true,
 "copyBusinessType" : true,
 "copyB2bReceivableaccount" : true,
 "copyB2bDeliveryConfig" : true,
 "copyB2bOrderGiveIntegralSetting" : true,
 "copyB2BPayConfig" : true,
 "addChanpinzhuangxiu" : true
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
