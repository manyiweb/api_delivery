# 

**请求URL：** 
- `/hr/distributor/{id} `

**请求方式：**
- POST
- FormData


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long||

###请求参数Json格式
 
```
{
 "id" : 0
}
```

###返回参数
 |参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|distributor|否|Object| 经销商信息|
|--id|否|Long|主键|
|--distrCode|否|String|经销商编号|
|--distrFullName|否|String|经销商全称|
|--distrShortName|否|String|经销商简称|
|--distrCompanyName|否|String|公司名称|
|--distrAddr|否|String|地址|
|--distrPhone|否|String|联系电话|
|--legalPerson|否|String|法人|
|--contractDiscount|否|Integer|合同折扣|
|--isGenTaxpayer|否|Integer|是否一般纳税人|
|--isEnable|否|Integer|活跃状态|
|itemBrandList|否|List| 经销商商品品牌|
|--id|否|Long||
|--itemBrandId|否|String|品牌id|
|--itemBrandName|否|String|品牌名称|
|channelList|否|List| 经销商渠道|
|--id|否|Long||
|--channelId|否|String|渠道id|
|--channelName|否|String|渠道名称|
|invoiceList|否|List| 经销商发票|
|--id|否|Long||
|--invType|否|Integer|1:普通发票 2:增值税发票|
|--invTitle|否|String|发票抬头|
|--invCode|否|String|税号|
|--invRegBname|否|String|开户银行|
|--invRegBaccount|否|String|银行帐户|
|--invRegAddr|否|String|注册地址|
|--invRegPhone|否|String|注册电话|
|--invRegEmail|否|String| 邮箱|
|--invGotoAddr|否|String| 送票地址|
|--invRecName|否|String| 收票人姓名|
|--invRecMobphone|否|String| 收票人手机号|
