# 获取法大大模板文件信息

**请求URL：** 
- `/hr/fddTemplate/getTemplateFileInfo `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|templateType|是|Integer| 模板类型,1:临时合伙协议,2:业务承包合同,3:认证协议|

###请求参数Json格式
 
```
{
 "templateType" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--templateFileUrl|否|String| 模板文件路径|
|--templateFileName|否|String| 模板文件名称|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "templateFileUrl" : "String",
 "templateFileName" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
