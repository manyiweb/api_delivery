# 通过状态统计待承揽、已承揽、已交付、已验收、已结算状态的总条数

**请求URL：** 
- `/hr/taskReceive/countGroupByStatus `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|taskId|是|Long| taskId|

###请求参数Json格式
 
```
{
 "taskId" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--status|否|Integer| 状态：0待承揽、1已承揽、2已交付、3已验收、4已结算、5已关闭（待承揽关闭）、6已关闭（已承揽关闭）|
|--count|否|Integer| 总数|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : [{
 "status" : 0,
 "count" : 0
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
