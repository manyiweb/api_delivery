# 门店分组保存

**请求URL：** 
- `/hr/companygroup/save `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 主键|
|groupNo|否|String| 分组编号|
|groupName|否|String| 分组名称|
|lineId|否|Integer| 排序号|
|status|否|Integer| 状态;0:停用,1:启用|
|statusName|否|String| 状态名称0:停用,1:启用|
|remark|否|String| 备注|
|createId|否|String| 创建人id|
|createName|否|String| 创建人|
|createDate|否|DateTime| 创建时间|
|modifyId|否|String| 修改人id|
|modifyName|否|String| 修改人|
|modifyDate|否|DateTime| 修改时间|
|groupId|否|String| 品牌商id，与品牌商表sysgroup关联|
|dbKey|否|Integer| 分库标识|
|sysChangeDate|否|DateTime| 最后修改时间|
|companyGroupItems|是|List| 明细|
|--id|否|Long| 主键|
|--companyGroupId|否|Long| 分组主键|
|--companyId|否|String| 门店主键|
|--createId|否|String| 创建人id|
|--createName|否|String| 创建人|
|--createDate|否|DateTime| 创建时间|
|--modifyId|否|String| 修改人id|
|--modifyName|否|String| 修改人|
|--modifyDate|否|DateTime| 修改时间|
|--groupId|否|String| 品牌商id，与品牌商表sysgroup关联|
|--dbKey|否|Integer| 分库标识|
|--sysChangeDate|否|DateTime| 最后修改时间|
