# 获取商户组详情

**请求URL：** 
- `/hr/companyGroup/getGroupData`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||
|sword|否|String||

### 请求参数Json格式
 
```
{
 "id" : 0,
 "sword" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long|id |
|--companyGroupCode|否|String|组编码 |
|--companyGroupName|否|String|组名称 |
|--state|否|Boolean|状态 |
|--remark|否|String| 备注|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "companyGroupCode" : "String",
 "companyGroupName" : "String",
 "state" : true,
 "remark" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
