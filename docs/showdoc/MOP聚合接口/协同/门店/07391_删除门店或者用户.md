# 删除门店或者用户

**请求URL：** 
- `/hr/companyGroup/deleteCompanyOrUser`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyGroupId|否|Long|id |
|ids|否|List| 明细ids|
|type|否|Integer| 0删除用户1删除门店|

### 请求参数Json格式
 
```
{
 "companyGroupId" : 0,
 "ids" : null,
 "type" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
