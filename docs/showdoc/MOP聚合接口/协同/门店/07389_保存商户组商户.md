# 保存商户组商户

**请求URL：** 
- `/hr/companyGroup/saveCompanyGroupData`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long|id |
|companyGroupDatas|否|List||
|--id|否|Long||
|--companyGroupId|否|Long| 商户组id|
|--companyId|否|String| 商户id|
|--companyName|否|String| 商户名称|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "companyGroupDatas" : [{
 "id" : 0,
 "companyGroupId" : 0,
 "companyId" : "String",
 "companyName" : "String"
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
