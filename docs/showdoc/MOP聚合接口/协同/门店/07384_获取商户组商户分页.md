# 获取商户组商户分页

**请求URL：** 
- `/hr/companyGroup/getCompanyGroupDataPage`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyGroupId|是|String|商户组id|
|orderField|否|String||
|orderSort|否|String||

|pageIndex|否|Integer||
|pageSize|否|Integer||
