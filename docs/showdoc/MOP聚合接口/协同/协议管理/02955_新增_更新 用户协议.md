# 功能描述: 新增/更新 用户协议
 

**请求URL：** 
- `/config/agreement/edit `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| ID，空表示新增|
|content|否|String| 内容|
|type|否|Integer| 协议类型，0-用户协议;1-隐私政策;2-用户注册协议;3-用户认证协议;4-临时合伙协议;5-业务承包合同;6-会员协议;7-隐私条款;8-购物卡充值协议;9-权益有效期充值协议|
|productType|否|Integer| 产品类型，0-会员商城;1-导购助手;2-导购助手|

###请求参数Json格式
 
```
{
 "id" : 0,
 "content" : "String",
 "type" : 0,
 "productType" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Long| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : 0,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
