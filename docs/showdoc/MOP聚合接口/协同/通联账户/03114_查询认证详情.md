# 查询认证详情

**请求URL：** 
- `/hr/sysstaffTlAccount/queryAuthInfo `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|

###请求参数Json格式
 
```
{
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--custId|否|String| 客户号|
|--authName|否|String| 认证名称|
|--idCardNo|否|String| 身份证号码|
|--createMobile|否|String| 通联注册手机号|
|--companyName|否|String| 企业名称|
|--creditCode|否|String| 统一社会信用代码|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : {
 "custId" : "String",
 "authName" : "String",
 "idCardNo" : "String",
 "createMobile" : "String",
 "companyName" : "String",
 "creditCode" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
