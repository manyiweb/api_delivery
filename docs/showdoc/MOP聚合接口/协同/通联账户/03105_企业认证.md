# 企业认证

**请求URL：** 
- `/hr/sysstaffTlAccount/companyAuth `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long| 主键id|
|companyName|是|String| 企业名称|
|creditCode|是|String| 统一社会信用代码|
|creditCodeDate|是|String| 统一社会信用代码有效期 格式：YYYY-MM-DD|
|authName|是|String| 法人姓名|
|idCardNo|是|String| 身份证号码|
|bankCardNo|是|String| 银行卡号|
|bankBranchId|是|Long| 支行名称主键id|

###请求参数Json格式
 
```
{
 "id" : 1,
 "companyName" : "String",
 "creditCode" : "String",
 "creditCodeDate" : "String",
 "authName" : "String",
 "idCardNo" : "String",
 "bankCardNo" : "String",
 "bankBranchId" : 1
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|String| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : "String",
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
