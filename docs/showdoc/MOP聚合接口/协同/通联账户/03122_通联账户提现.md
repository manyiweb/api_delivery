# 通联账户提现

**请求URL：** 
- `/hr/sysstaffTlAccount/userWithdraw `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderAmount|是|Double| 充值金额|
|id|是|Long| id|

###请求参数Json格式
 
```
{
 "orderAmount" : 0,
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|String| 订单号|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : "String",
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
