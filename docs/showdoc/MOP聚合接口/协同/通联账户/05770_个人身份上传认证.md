# 个人身份上传认证

**请求URL：** 
- `/hr/sysstaffTlAccount/personalIdFileUploadAuth `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 通联电子账户id|
|certFront|否|String| 身份证正面（人像面）|
|certBack|否|String| 身份证背面（国徽面）|

###请求参数Json格式
 
```
{
 "id" : 0,
 "certFront" : "String",
 "certBack" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
