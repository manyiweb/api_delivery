# 注册会员

**请求URL：** 
- `/hr/sysstaffTlAccount/custRegister `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|accountName|否|String| 账户名称，客户类型为M必填|
|accountType|是|Integer| 平台类型 1:创客, 2:平台, 3:个体工商户,4:用工企业|
|staffId|否|String| 关联账户id,个体工商户与用工企业类型必填|
|custType|是|String| 客户类型 U：个人 M：企业|
|mobile|是|String| 注册手机号码|
|smsCode|是|String| 短信验证码|
|smsSeqNo|是|String| 短信发送流水|

###请求参数Json格式
 
```
{
 "accountName" : "String",
 "accountType" : 0,
 "staffId" : "String",
 "custType" : "String",
 "mobile" : "String",
 "smsCode" : "String",
 "smsSeqNo" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--custId|否|String| 客户id|
|--id|否|Long| 主键id|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : {
 "custId" : "String",
 "id" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
