# 注册个体工商户通联电子账户

**请求URL：** 
- `/hr/sysstaffTlAccount/individualBusinessCustRegister `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|groupId|是|String| 品牌id|
|mobile|是|String| 注册手机号码|
|smsCode|是|String| 短信验证码|
|smsSeqNo|是|String| 短信发送流水|
|staffId|是|String| 用户id|

###请求参数Json格式
 
```
{
 "groupId" : "String",
 "mobile" : "String",
 "smsCode" : "String",
 "smsSeqNo" : "String",
 "staffId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--custId|否|String| 客户id|
|--id|否|Long| 主键id|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : {
 "custId" : "String",
 "id" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
