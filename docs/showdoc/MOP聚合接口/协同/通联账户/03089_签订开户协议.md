# 签订开户协议

**请求URL：** 
- `/hr/sysstaffTlAccount/syncagreeinfo `

**请求方式：**
- POST
- RequestBody



###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long| 主键id|

###请求参数Json格式
 
```
{
 "id" : 1
}
```


###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|String| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : "String",
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
