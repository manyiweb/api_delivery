# 工商及法人证件认证

**请求URL：** 
- `/hr/sysstaffTlAccount/idFileUploadAuth `

**请求方式：**
- POST
- RequestBody

**先调用/api/file/upyun/upload图片上传接口；filePath传TlAccount上传图片：**
- POST
- RequestBody

###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long| 主键id|
|corpbuspic|是|String| 营业执照；图片上传至又拍云返回的文件路径|
|certFront|是|String| 身份证正面（人像面）；图片上传至又拍云返回的文件路径|
|certBack|是|String| 身份证背面（国徽面）；图片上传至又拍云返回的文件路径|

###请求参数Json格式
 
```
{
 "id" : 0,
 "corpbuspic" : "String",
 "certFront" : "String",
 "certBack" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|String| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : "String",
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
