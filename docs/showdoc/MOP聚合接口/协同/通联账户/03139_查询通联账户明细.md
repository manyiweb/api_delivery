# 查询通联账户明细

**请求URL：** 
- `/hr/sysstaffTlAccount/queryAcctDetail `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|beginDate|是|String| 开始日期 格式：YYYYMMDD|
|endDate|是|String| 结束日期 最长时间仅支持30天|
|pageIndex|是|String| 起始页数 数字开始页数是 1|
|pageSize|是|String| 每页条数 数字若上送条数大于 100 则取值100|
|id|是|Long| id|

###请求参数Json格式
 
```
{
 "beginDate" : "String",
 "endDate" : "String",
 "pageIndex" : "String",
 "pageSize" : "String",
 "id" : 0
}
```
