# 确认订单

**请求URL：** 
- `/hr/sysstaffTlAccount/orderConfirm `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|value|是|String| 值，提现为返回的订单号，批量转账为返回的批次号|
|type|是|Integer| 类型，1:提现，2:批量转账|
|smsCode|是|String| 短信验证码|

###请求参数Json格式
 
```
{
 "value" : "String",
 "type" : 0,
 "smsCode" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|String| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : "String",
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
