# 

**请求URL：** 
- `/hr/sysstaffTlAccount/queryInfo `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long| id|

###请求参数Json格式
 
```
{
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--custId|否|String| 客户号|
|--accountType|否|Integer| 平台类型 1:创客, 2:平台|
|--associatedAccount|否|String| 关联账号|
|--custType|否|String| 客户类型 U:个人 M:企业|
|--authStatus|否|Integer| 认证状态,1:待认证,2:已认证|
|--frozenAmt|否|Double| 冻结金额|
|--createName|否|String| 创建人|
|--createDate|否|DateTime| 创建时间|
|--skipIndex|否|Integer| 跳转下标;1:隐藏企业认证按钮,2:认证基本信息界面,3:认证上传证照影印件界面,4:跳转认证签订开户协议开户界面|
|--openAcctStatus|否|Integer| 开户状态,1:未开户,2:已开户|
|--staffId|否|String| 关联账户staffId|
|--legalPersonName|否|String| 法人名称|
|--legalPersonIdCardNo|否|String| 法人身份证号码|
|--bankBranchId|否|Long| 企业认证银行支行记录|
|--cnapsName|否|String| 支行名|
|--bankCardNo|否|String| 银行卡号|
|--accountCode|否|String| 账户编码|
|--accountName|否|String| 账户名称|
|--authStatus|否|Integer| 认证状态,1:待认证,2:已认证|
|--amount|否|Double| 账户余额|
|--availableAmount|否|Double| 可用余额|
|--serviceCharge|否|Double| 手续费|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
