# 通联发短信

**请求URL：** 
- `/hr/sysstaffTlAccount/sendMsg `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|phone|是|String| 注册手机号码|
|smsTemplateType|是|String| 短信模板类型 dz01：会员注册|
|smsType|是|String| 短信种类 0：文字短信 2: 语音短信|

###请求参数Json格式
 
```
{
 "phone" : "String",
 "smsTemplateType" : "String",
 "smsType" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|String| 短信流水|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : "String",
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
