# 修改电子账户

**请求URL：** 
- `/hr/sysstaffTlAccount/updateTlAccount `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|accountName|否|String| 账户名称|
|cnapsName|否|String| 支行名称|
|cmbUserId|否|String| 招行云用户账号id|
|cmbEnterpriseBankNo|否|String| 招行云企银编号|
|cmbPayBankCardNo|否|String| 招行云转出卡号|
|headBankId|否|Long| 总行id|
|cmbPayCheckPhoneNumber|否|String| 招行云支付校验手机号|
|id|否|Long| id|

###请求参数Json格式
 
```
{
 "accountName" : "String",
 "cnapsName" : "String",
 "cmbUserId" : "String",
 "cmbEnterpriseBankNo" : "String",
 "cmbPayBankCardNo" : "String",
 "headBankId" : 0,
 "cmbPayCheckPhoneNumber" : "String",
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
