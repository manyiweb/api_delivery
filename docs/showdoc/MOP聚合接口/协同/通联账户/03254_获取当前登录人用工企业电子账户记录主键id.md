# 获取当前登录人用工企业电子账户记录主键id

**请求URL：** 
- `/hr/sysstaffTlAccount/getEmployerId `

**请求方式：**
- POST
- raw


###请求参数<业务参数>
 
无参数


###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Long| 当前登录人用工企业电子账户记录主键id|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : 0,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
