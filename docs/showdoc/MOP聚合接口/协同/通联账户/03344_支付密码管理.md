# 支付密码管理

**请求URL：** 
- `/hr/sysstaffTlAccount/passwordManagement `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|jumpUrl|是|String| 跳转地址 用于电子账户流程结束后跳转应用页面|
|id|是|Long| id|
|resetFlag|否|boolean| 重置密码标志|

###请求参数Json格式
 
```
{
 "jumpUrl" : "String",
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|String| H5URL|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : "String",
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
