# 模糊查询支行名前20条

**请求URL：** 
- `/hr/sysstaffBankBranch/queryListByCnapsNameLike `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|sword|否|String| 模糊搜索|

###请求参数Json格式
 
```
{
 "sword" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--id|否|Long| ID|
|--cnapsName|否|String| 支行名称|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : [{
 "id" : 0,
 "cnapsName" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
