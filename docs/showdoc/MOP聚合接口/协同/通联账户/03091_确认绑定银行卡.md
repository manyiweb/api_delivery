# 确认绑定银行卡

**请求URL：** 
- `/hr/sysstaffTlAccount/bindingBankCard `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|signSeqNo|否|String| 签约流水|
|smsCode|否|String| 签约短信码|
|bankCardNo|否|String| 银行卡号 客户类型 M:法人银行卡 客户类型 U:个人银行卡|
|bankCardMobile|否|String| 银行预留手机号|
|bankBranchId|否|Long| 支行记录id;企业类型电子账户为必填值|
|cnapsName|否|String| 支行名称;个人类型电子账户为必填值|
|headBankId|否|Long| 总行记录id|

###请求参数Json格式
 
```
{
 "signSeqNo" : "String",
 "smsCode" : "String",
 "bankCardNo" : "String",
 "bankCardMobile" : "String",
 "bankBranchId" : 0,
 "cnapsName" : "String",
 "headBankId" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|String| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : "String",
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
