# 查询账户安全详情

**请求URL：** 
- `/hr/sysstaffTlAccount/queryAccountSafeInfo `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long| id|

###请求参数Json格式
 
```
{
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--bankCardNo|否|String| 银行卡号|
|--bankCardMobile|否|String| 银行卡预留手机号|
|--syncagreeinfoStatus|否|Integer| 签约状态,1:未签约,2:已签约|
|--cnapsName|否|String| 支行名称|
|--cnapsNo|否|String| 支付行号|
|--bankCode|否|String| 银行代码|
|--provinceAndCity|否|String| 开户行所在省市|
|--payPwdStatus|否|Integer| 支付密码状态;1:未设密码(展示"设置"),2:已设密码(展示"修改")|
|--cmbUserId|否|String| 招行云用户账号id|
|--cmbEnterpriseBankNo|否|String| 招行云企银编号|
|--cmbPayBankCardNo|否|String| 招行云转出卡号|
|--headBankId|否|Long| 总行id|
|--participantAlias|否|String| 总行名|
|--cmbPayCheckPhoneNumber|否|String| 招行云支付校验手机号|
|--showUpdateMAccountBankInfoFlag|否|Boolean| 修改银行卡号按钮展示标记|
|--showUpdateHeadBankFlag|否|Boolean| 修改总行按钮展示标记|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
