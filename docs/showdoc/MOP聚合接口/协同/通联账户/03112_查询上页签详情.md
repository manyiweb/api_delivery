# 查询上页签详情

**请求URL：** 
- `/hr/sysstaffTlAccount/queryTopInfo `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|

###请求参数Json格式
 
```
{
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--accountCode|否|String| 账户编码|
|--accountName|否|String| 账户名称|
|--authStatus|否|Integer| 认证状态,1:待认证,2:已认证|
|--amount|否|BigDecimal| 账户余额|
|--availableAmount|否|BigDecimal| 可用余额|
|--serviceCharge|否|BigDecimal| 手续费|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : {
 "accountCode" : "String",
 "accountName" : "String",
 "authStatus" : 0,
 "amount" : 0,
 "availableAmount" : 0,
	 "serviceCharge" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
