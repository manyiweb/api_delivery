# 任务中心消息
 

**请求URL：** 
- `/reabam-core/app/MsgCenter/TaskRemind2/List `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|pageIndex|否|Integer| |
|pageSize|否|Integer| |
|tokenId|否|String| |

###请求参数Json格式
 
```
{
 "pageIndex": 1,
 "pageSize": 7,
 "tokenId": "e169fea82a814e79a6d8945b58dcf7d8"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|TotalCount|否|Integer| 总数|
|PageIndex|否|Integer| 开始页数|
|PageSize|否|Integer| 每页大小|
|PageCount|否|Object| 总页数|
|DataLine|否|Object| 主数据|
|--companyId|否|String| 门店商户ID|
|--createDate|否|Date| 创建时间|
|--dbKey|否|Integer| |
|--disable|否|Integer| 是否可视 0是 1否 |
|--groupID|否|String| 品牌id|
|--isSystem|否|Integer| 0 -任务 1系统|
|--orderId|否|String| 单据ID|
|--status|否|String| 状态 |
|--taskIntro|否|String| 任务内容|
|--taskType|否|String| 任务类型 tasktype:调拨受理 DAllotOrder_NA 调拨受理结果DAllotOrder_Results 调拨收货DAllotOrder_YO 订货收货DB2bOrder_YD 预约受理DBookingOrder_NA 预约订单派单DBookingOrder_YA_YA 盘点任务DCheckVouch_NP 进货收货DGoodsInOrder_YO 要货受理结果DNeedOrder_Results收款通知DOrder_Custom 订单受理DOrder_NA 订单配送DOrder_ND 新媒体推广MpPopularize 商品推广PromotionMitem 其他的为系统通知|
|--taskTypeName|否|String| 任务类型名称|
|--terminalType|否|String| 0 -店务助手 1-前台 2-中台|
|--title|否|String| 标题 |
|--trId|否|String| id|
|--userId|否|String| 用户id|
|ErrorCode|否|String| |
|ResultString|否|String| |
|ResultInt|否|Integer| |
