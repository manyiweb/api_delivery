# 消息中心, 未读任务数量, 最多不超过99

**请求URL：** 
- `/app/MsgCenter/TaskRemind/unreadCount`

**请求方式：**
- POST


### 请求参数<业务参数>
 



### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Integer|未读数量，不超过99|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : 0,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
