# 分页查询商户积分记录
 

**请求URL：** 
- `/hr/company/integral/record `

**请求方式：**
- ALL
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|String| 业务ID|
|tokenId|否|String| 用户标识|
|pageIndex|否|Integer| 分页页码|
|pageSize|否|Integer| 分页大小|
|sword|否|String| 搜索关键字|

###请求参数Json格式
 
```
{
 "id" : "String",
 "tokenId" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "sword" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--pageIndex|否|Integer| 页码|
|--pageSize|否|Integer| 显示记录数|
|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|--first|否|Boolean| 首页|
|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|
|----id|否|Long| id|
|----integral|否|Double| 变更积分|
|----channelName|否|String| 渠道编码|
|----channelCode|否|String| 渠道名称|
|----remark|否|String| 备注|
|----createName|否|String| 创建人|
|----createDate|否|DateTime| 创建时间|
|----sourceId|否|String| 来源单标识|
|----sourceCode|否|String| 来源单编码|
|----source|否|String| 来源|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : {
 "pageIndex" : 0,
 "pageSize" : 0,
 "pageCount" : 0,
 "totalCount" : 0,
 "first" : true,
 "last" : true,
 "content" : [{
 "id" : 0,
 "integral" : 0,
 "channelName" : "String",
 "channelCode" : "String",
 "remark" : "String",
 "createName" : "String",
 "createDate" : "DateTime",
 "sourceId" : "String",
 "sourceCode" : "String",
 "source" : "String"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
