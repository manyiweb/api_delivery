# 批量修改企业通联账户关联记录

**请求URL：** 
- `/hr/companyTlAccount/updateBatch `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|updateBatchReqList|是|List| 批量修改集合|
|--id|是|Long| id|
|--status|是|Integer| 启用状态，0启用 1禁用|

###请求参数Json格式
 
```
{
 "updateBatchReqList" : [{
 "id" : 0,
 "status" : 0
 }]
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|String| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : "String",
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
