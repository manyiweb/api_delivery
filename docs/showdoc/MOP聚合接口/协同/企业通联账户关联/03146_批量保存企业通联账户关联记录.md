# 批量保存企业通联账户关联记录

**请求URL：** 
- `/hr/companyTlAccount/addBatch `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tlAccountId|是|Long| id|
|companyIdList|是|List| 门店id集合|

###请求参数Json格式
 
```
{
 "tlAccountId": 11,
 "companyIdList":[
 "000980219c54491b80a8593376413bea",
 "000b50ce835645528772be1818dca968"
 ]
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|String| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : "String",
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
