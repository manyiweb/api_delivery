# 直播码推广 - 获取小程序二维码

**请求URL：** 
- `/app/activity/live/qrcode `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|liveCodePersonId|否|Long| 直播码推广任务指派人员ID|

###请求参数Json格式
 
```
{
 "liveCodePersonId" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--imgUrl|否|String| 二维码|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : {
 "imgUrl" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
