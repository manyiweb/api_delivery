# 高级筛选

欢迎使用ShowDoc！
 
**简要描述：** 

- 高级筛选

**请求URL：** 
- `/api//adv/filters `
 
**请求方式：**
- POST 

**参数：** 

|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|filterType|是|String| 中台推广promotionTask ， app任务中心 task|
|filterSource|是|String|hr|
```
{
 "tokenId":"57be95c72b424320b2311f1dfb17fa71",
 "filterType":"task",
 "filterSource":"hr",
}
```
