# 新增直播码推广任务
 

**请求URL：** 
- `/hr/live/code/add `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|liveCodeTask|否|Object| 主表内容|
|--id|否|Long| 任务主键|
|--taskName|是|String| 任务名称|
|--portType|是|Integer| 应用端口(0会员小程序、1订货助手)|
|--roomCode|是|String| 直播房间码|
|--url|是|String| 上传海报|
|--remark|否|String| 任务说明|
|--status|是|Integer| 活跃状态（1 是 0否）|
|liveCodePerson|是|Object| 指派人员|
|--addStaffs|是|List| 添加指派人员|
|----companyId|是|String| 门店id|
|----staffId|是|String| 用户id|
|--delIds|否|List| 删除指派人员|

###请求参数Json格式
 
```
{
 "liveCodeTask" : {
 "id" : 0,
 "taskName" : "String",
 "portType" : "0",
 "roomCode" : "String",
 "url" : "String",
 "remark" : "String",
 "status" : 0
 },
 "liveCodePerson" : {
 "addStaffs" : [{
 "companyId" : "String",
 "staffId" : "String"
 }],
 "delIds" : null
 }
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
