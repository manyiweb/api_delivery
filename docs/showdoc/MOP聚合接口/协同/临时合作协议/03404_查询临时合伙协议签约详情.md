# 查询临时合伙协议签约详情

**请求URL：** 
- `/hr/interimPartnershipAgreement/queryInfo `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long| id|

###请求参数Json格式
 
```
{
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--otherPartners|否|String| 其它有限合作人|
|--content|否|String| 签约内容|
|--partyBIdCard|否|String| 乙方身份证号码|
|--partyBIdCardAddress|否|String| 乙方身份证地址|
|--firstPartyIdCard|否|String| 甲方身份证号码|
|--partyBPhoneNumber|否|String| 乙方联系电话|
|--id|否|Long| ID|
|--protocolCode|否|String| 协议编码|
|--type|否|Integer| 协议类型,1:临时合伙协议|
|--typeName|否|String| 协议类型名|
|--firstParty|否|String| 甲方|
|--generalPartners|否|String| 普通合伙人(项目合伙业务负责人/个体工商户法人)|
|--economicOrganization|否|String| 经济组织(项目合伙个体工商户)|
|--companyName|否|String| 门店名称(企业)|
|--partyB|否|String| 乙方|
|--createName|否|String| 创建人|
|--createDate|否|DateTime| 创建时间|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
