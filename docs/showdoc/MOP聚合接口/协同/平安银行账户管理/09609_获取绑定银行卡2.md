# 获取绑定银行卡2

**请求URL：** 
- `/hr/pinganbank/applybindbankcardV2/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long|认证信息id|

### 请求参数Json格式
 
```
{
 "id" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long||
|--phone|否|String| 手机号|
|--bankName|否|String| 开户银行名称|
|--cardNo|否|String| 银行卡号|
|--bankType|否|Integer| 银行类型 1：本行 2：他行|
|--bankBranchName|否|String| 开户行支行名称|
|--accountAuthInfoId|否|Long| 认证信息关联主键|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
