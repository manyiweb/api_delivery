# 申请一条提现明细(平安银行)

**请求URL：** 
- `/b2b/Withdraw/pingan/apply`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 商户id|
|withdrawBankName|否|String| 提现银行名|
|withdrawBankCardNum|否|String| 提现银行卡号|
|withdrawBalance|否|Double| 提现金额|
|withdrawServePay|否|Double| 提现所需的服务费|
|withdrawApplyState|否|Integer| 订单申请状态 0为待审核 1为已到账 -1为已拒绝|
|withdrawApplyTime|否|DateTime| 提现申请的时间|
|examineRemark|否|String| 审核备注|
|attachmentPath|否|String| 附件路径|
|accountId|否|Long| 平安银行账号id|
|beginDate|否|DateTime| 范围查询 起始时间|
|endDate|否|DateTime| 范围查询 截至时间|
|pageIndex|否|Integer||
|pageSize|否|Integer||
|orderField|否|String||
|orderSort|否|String||
