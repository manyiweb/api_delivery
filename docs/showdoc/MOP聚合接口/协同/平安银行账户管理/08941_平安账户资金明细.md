# 平安账户资金明细

**请求URL：** 
- `/b2b/datatable/pingan/transfer/record/list/{source}`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|createDate|否|Object| 交易时间|
|--start|否|DateTime||
|--end|否|DateTime||
|keyword|否|String| 订单编号|
|memberCode|否|String| 会员号|
|id|否|String||
|pageSize|否|Integer||
|pageNo|否|Integer||
|sortField|否|String||
|sortDirection|否|String||
|viewId|否|String||

### 请求参数Json格式
 
```
{
 "createDate" : {
 "start" : "DateTime",
 "end" : "DateTime"
 },
 "keyword" : "String",
 "memberCode" : "String",
 "id" : "String",
 "pageSize" : 0,
 "pageNo" : 0,
 "sortField" : "String",
 "sortDirection" : "String",
 "viewId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--content|否|List||
|----id|否|String||
|----transCode|否|String| 交易流水号|
|----transAmount|否|Double| 金额|
|----createDate|否|DateTime| 交易时间|
|----sourceNo|否|String| 来源单号|
|--pageSize|否|Integer||
|--pageNo|否|Integer||
|--total|否|Long||
|--totalPage|否|Integer||
|--hasNextPage|否|Boolean||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
