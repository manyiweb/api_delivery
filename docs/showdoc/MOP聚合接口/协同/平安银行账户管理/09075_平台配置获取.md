# 平台配置获取

**请求URL：** 
- `/config/pingan/platform/get`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
无参数


### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|String| 主键|
|--mainAccountConfigStr|否|String| 平台总配置参数|
|--withdrawConfigStr|否|String| 提现配置参数|
|--groupId|否|String| 品牌id|
|--createId|否|String||
|--createName|否|String||
|--createDate|否|DateTime||
|--modifyId|否|String||
|--modifyName|否|String||
|--modifyDate|否|DateTime||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "id" : "String",
 "mainAccountConfigStr" : "String",
 "withdrawConfigStr" : "String",
 "groupId" : "String",
 "createId" : "String",
 "createName" : "String",
 "createDate" : "DateTime",
 "modifyId" : "String",
 "modifyName" : "String",
 "modifyDate" : "DateTime"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
