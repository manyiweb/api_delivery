# 平安银行批量受理

**请求URL：** 
- `/b2b/Withdraw/pingan/batch/accept`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|List| 记录id|
|status|否|Integer| 受理状态|
|remark|否|String| 备注|
|attachmentIds|否|List| 附件路径id|

### 请求参数Json格式
 
```
{
 "id" : null,
 "status" : 0,
 "remark" : "String",
 "attachmentIds" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
