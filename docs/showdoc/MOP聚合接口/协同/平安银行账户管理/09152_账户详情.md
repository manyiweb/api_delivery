# 账户详情

**请求URL：** 
- `/hr/pinganbank/detail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long||

### 请求参数Json格式
 
```
{
 "id" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long| 主键|
|--relatedAccountId|否|String| 账户id|
|--userId|否|String| 用户标识 （由第三方传入）|
|--pinganUserId|否|String| 平安银行用户标识（由第三方传入）|
|--relatedAccountCode|否|String| 账户编号|
|--relatedAccountName|否|String| 账户名称|
|--accountTypeCode|否|Integer| 账户类型（0 商户 1经销商 2供应商）|
|--status|否|Integer| 状态（0停用 1启用）|
|--authType|否|Integer| 认证类型（3个人 2企业）|
|--authStatus|否|Integer| 认证状态（0未认证 1已认证）|
|--accountBalance|否|Double| 账户余额|
|--recordedAmount|否|Double| 待入账金额|
|--freezeAmount|否|Double| 冻结金额|
|--isFreeze|否|Boolean| 是否冻结|
|--externalId|否|String| 外部用户id|
|--sendId|否|Long| 对接用id|
|--statusName|否|String| 状态|
|--authTypeName|否|String| 认证类型|
|--authStatusName|否|String| 认证状态|
|--accountTypeName|否|String| 账户类型（0 商户 1经销商 2供应商）|
|--step|否|Integer| 流程标识|
|--waitSplitAmount|否|Double| 待入账金额|
|--withdrawCalcParam|否|Object| 提现计算参数|
|----feeCalcType|否|Integer| 零售收款手续费-1固定金额 2-固定比例|
|----feeCalcVal|否|Double| 零售收款手续费-金额/比例|
|----distrWithdrawFeeCalcType|否|Integer| 商户账户余额手续费--1固定金额 2-固定比例|
|----distrWithdrawFeeCalcVal|否|Double| 商户账户余额手续费-金额/比例|
|----companyWithdrawFeeCalcType|否|Integer| 经销商账户余额提现手续费--1固定金额 2-固定比例|
|----companyWithdrawFeeCalcVal|否|Double| 经销商账户余额提现手续费-金额/比例|
|--createName|否|String| 创建人|
|--createDate|否|DateTime| 创建时间|
|--accountAttributeCode|否|String| 账户属性（00 普通子商户, SH 商户子账户）|
|--accountAttributeName|否|String| 账户属性名称|
|--guarantee|否|Double| 保证金|
|--mainAccountDto|否|Object| 主账户信息|
|----mainAccountNo|否|String| 账户|
|----mainAccountReceiveName|否|String| 收款人|
|----mainBankName|否|String| 开户行|
|--isContract|否|Integer| 是否已签约
 1：是；0：否|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
