# 平安银行账户管理-认证
 

**请求URL：** 
- `/hr/pinganbank/account/auth`

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long|主键|
|authType|否|Integer|开户类型（3个体工商户，2企业）|
|companyName|否|String|公司名称|
|companyCardType|否|String|公司证件类型|
|companyCardCode|否|String|公司证件号码|
|storeId|否|String|门店Id|
|storeName|否|String|门店名称|
|legalTag|否|Integer|法人标识（0否，1是）|
|legalPersonName|否|String|法人姓名|
|legalPersonCode|否|String|法人证件号码|
|realMemberName|是|String|会员真实姓名|
|memberIdType|是|int|会员证件类型 1-身份证；3-回乡证；4-中国护照；5-台胞证；19-外国护照；52-组织机构代码证；68-营业执照 ；73-统一社会信用代码|
|memberIdNum|是|String|会员证件号码|
|legalPersonCardType|否|Integer|法人证件类型（01身份证，03回乡证，04中国护照，05台胞证，19外国护照，52组织机构代码证）|

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
