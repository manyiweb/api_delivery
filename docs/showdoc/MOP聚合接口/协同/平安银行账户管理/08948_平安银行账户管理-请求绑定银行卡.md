# 平安银行账户管理-请求绑定银行卡

**请求URL：** 
- `/hr/pinganbank/applybindbankcard`

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long|主键|
|memberAcctNo|是|String|银行对公账号|
|acctOpenBranchName|是|String|开户行名称|
|subAcctOpenBranchName|是|String|开户支行名称|
|bankType|否|Integer|银行类型（1：本行，2：他行）|
|phone|是|String|手机号码|

###请求参数Json格式
 
```
{
 "id" : 0, // 主键
 "memberAcctNo" : "String", // 银行对公账号
 "acctOpenBranchName" : "String", // 开户行名称
 "subAcctOpenBranchName" : "String", // 开户支行名称
 "bankType" : 1, // 银行类型（1：本行，2：他行）
 "phone" : "String" // 手机号码
}

```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
