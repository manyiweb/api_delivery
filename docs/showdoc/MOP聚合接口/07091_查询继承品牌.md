# 查询继承品牌
 

**请求URL：** 
- `/hr/trainCurricula/apply/getInherit`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String||
|type|是|String||

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "type" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--fid|否|String||
|--companyName|否|String||
|--companyId|否|String||
|--isInherit|否|Integer||
|--type|否|String||
|--dbKey|否|Integer||
|--groupId|否|String||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "fid" : "String",
 "companyName" : "String",
 "companyId" : "String",
 "isInherit" : 0,
 "type" : "String",

 "groupId" : "String"
 },
 "msg" : "String",

 "traceId" : "String"
}
```
