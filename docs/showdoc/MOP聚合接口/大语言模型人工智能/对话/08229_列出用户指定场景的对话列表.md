# 列出用户指定场景的对话列表
 List conversations for user in scene

**请求URL：** 
- `/assistant/conversation/listConversationsForUserInScene`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|scene|是|Enum| 对话的场景 COMMON DATA_ANALYSIS
 The scene of the conversation, the value can be: COMMON, DATA_ANALYSIS|

### 请求参数Json格式
 
```
{
 "scene" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--id|否|String| 对话记录的唯一标识|
|--userId|否|String| 用户ID|
|--firstQuestion|否|String| 对话的第一个问题|
|--scene|否|Enum| 对话的场景 COMMON DATA_ANALYSIS|
|--groupId|否|String| 品牌ID|
|--createDate|否|DateTime| 创建日期|
|--lastModifiedDate|否|DateTime| 最后修改日期|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "id" : "String",
 "userId" : "String",
 "firstQuestion" : "String",
 "scene" : 0,
 "groupId" : "String",
 "createDate" : "DateTime",
 "lastModifiedDate" : "DateTime"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
