# 获取用户对话详情
 Get user conversation detail
 

**请求URL：** 
- `/assistant/conversation/getUserConversationDetail/{conversationId}`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|conversationId|否|String|对话ID|

### 请求参数Json格式
 
```
{
 "conversationId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--conversationId|否|String| 对话ID|
|--scene|否|Enum| 对话的场景 COMMON DATA_ANALYSIS|
|--chatRecords|否|List| 聊天记录列表|
|----conversationId|否|String| 会话ID
 Conversation ID|
|----role|否|Enum| 聊天角色，取值范围为：USER, ASSISTANT, FUNCTION_CELL, FUNCTION
 Chatting role, the value can be: USER, ASSISTANT, FUNCTION_CELL, FUNCTION|
|----content|否|String| 聊天内容
 Chatting content|
|----createDate|否|DateTime| 创建时间
 Create time|
|--createDate|否|DateTime| 创建日期|
|--lastModifiedDate|否|DateTime| 最后修改日期|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "conversationId" : "String",
 "scene" : 0,
 "chatRecords" : [{
 "conversationId" : "String",
 "role" : 0,
 "content" : "String",
 "createDate" : "DateTime"
 }],
 "createDate" : "DateTime",
 "lastModifiedDate" : "DateTime"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
