# 聊天接口
 Chat interface
 

**请求URL：** 
- `/assistant/application/chat/talk`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|conversationId|否|String| 会话ID 如果为空则表示新会话|
|scene|是|Enum| 场景枚举，取值范围为 COMMON, DATA_ANALYSIS|
|question|是|String| 问题|

### 请求参数Json格式
 
```
{
 "conversationId" : "String",
 "scene" : 0,
 "question" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--conversationId|否|String| 会话ID|
|--role|否|Enum| 聊天角色，取值范围为：USER, ASSISTANT, FUNCTION_CELL, FUNCTION|
|--content|否|String| 聊天内容|
|--createDate|否|DateTime| 创建时间|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "conversationId" : "String",
 "role" : 0,
 "content" : "String",
 "createDate" : "DateTime"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
