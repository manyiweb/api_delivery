# 列出所有微调数据集
 

**请求URL：** 
- `/reabam-ai/fineTuning/dataset/list`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
无参数


### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--id|否|String||
|--status|否|String| 状态|
|--failureReason|否|String| 失败原因|
|--datesetName|否|String| 数据集名称|
|--datasetPath|否|String| 数据集路径|
|--bucketName|否|String| OSS bucket name|
|--createId|否|String||
|--createName|否|String||
|--createDate|否|DateTime||
|--modifyId|否|String||
|--modifyName|否|String||
|--modifyDate|否|DateTime||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
