# 创建新的大模型配置

**请求URL：** 
- `/assistant/llmWarehouse/create`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|String| LlmDefinition的唯一标识符。|
|name|是|String| LlmDefinition的名称。|
|description|否|String| LlmDefinition的简短描述。|
|accessCredentials|是|Object| LlmDefinition所需的访问凭证。|
|--appId|是|String| 应用程序ID |
|--appKey|是|String| 应用程序密钥 |
|llmConfig|是|Object| LlmDefinition的配置设置。|
|--platformType|是|Enum| 与LlmDefinition关联的平台类型。 取值范围：BAIDU, ALIYUN, OPENAI|

### 请求参数Json格式
 
```
{
 "id" : "String",
 "name" : "String",
 "description" : "String",
 "accessCredentials" : {
 "appId" : "String",
 "appKey" : "String"
 },
 "llmConfig" : {
 "platformType" : 0
 }
}
```

### 阿里云模型
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|model|是|Enum| 模型 The model. QWEN_TURBO, QWEN_PLUS, QWEN_MAX, QWEN_MAX1201, QWEN_MAX_LONGCONTEXT, QWEN_1_5_72B_CHAT, QWEN_1_5_14B_CHAT, QWEN_1_5_7B_CHAT, QWEN_72B_CHAT, QWEN_14B_CHAT, QWEN_7B_CHAT|
|platformType|是|Enum| 与LlmDefinition关联的平台类型。 取值：ALIYUN|


### 返回参数Json格式
 
```
{
 "model" : "QWEN_MAX",
 "platformType" : "ALIYUN"
}
```
