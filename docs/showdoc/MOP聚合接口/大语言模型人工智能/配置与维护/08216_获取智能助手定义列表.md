# 获取智能助手定义列表

**请求URL：** 
- `/assistant/core/definition/warehouse/list`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
无参数


### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--id|否|String| MongoDB的主键，类型为ObjectId|
|--name|否|String| 名称字段|
|--description|否|String| 描述字段|
|--systemPrompt|否|String| 系统提示字段|
|--functions|否|List| 功能代码列表 用于标识该助手支持的功能|
|----functionId|是|String| 功能ID|
|----functionName|是|String| 功能名称|
|----functionCode|是|String| 功能编码|
|--temperature|否|Double| 较高的数值会使输出更加随机，而较低的数值会使其更加集中和确定 默认0.8，范围 (0, 1.0]，不能为0|
|--topP|否|Double| 影响输出文本的多样性，取值越大，生成文本的多样性越强 默认0.8，取值范围 [0, 1.0]|
|--penaltyScore|否|Double| 通过对已生成的token增加惩罚，减少重复生成的现象 值越大表示惩罚越大 默认1.0，取值范围：[1.0, 2.0]|
|--defaultLlmName|否|String| 默认的llm名称|
|--defaultLlmId|否|String| 默认的LlmId字段|
|--commonAssistant|否|Boolean| 是否为通用助手的字段，取值为true或false|
|--sceneAssistants|否|List| 场景助手映射，键为场景枚举，值为场景助手对象|
|----scene|否|Enum| 场景枚举，取值范围为：DATA_ANALYSIS|
|----llmName|否|String| llm名称|
|----llmId|否|String| LlmId 字段|
|----systemPrompt|否|String| 系统提示字段|
|----functions|否|List| 功能代码列表 用于标识该助手支持的功能|
|------functionId|是|String| 功能ID|
|------functionName|是|String| 功能名称|
|------functionCode|是|String| 功能编码|
|----temperature|否|Double| 较高的数值会使输出更加随机，而较低的数值会使其更加集中和确定 默认0.8，范围 (0, 1.0]，不能为0|
|----topP|否|Double| 影响输出文本的多样性，取值越大，生成文本的多样性越强 默认0.8，取值范围 [0, 1.0]|
|----penaltyScore|否|Double| 通过对已生成的token增加惩罚，减少重复生成的现象 值越大表示惩罚越大 默认1.0，取值范围：[1.0, 2.0]|
|--groupIds|否|List| 应用的品牌ID集合，只在非通用助手中有效|
|--createId|否|String| 创建人ID|
|--createName|否|String| 创建人名称|
|--createDate|否|DateTime| 创建时间|
|--modifyId|否|String| 修改人ID|
|--modifyName|否|String| 修改人名称|
|--modifyDate|否|DateTime| 修改时间|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
