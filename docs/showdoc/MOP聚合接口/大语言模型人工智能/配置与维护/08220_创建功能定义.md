# 创建功能定义
 Create function definition
 

**请求URL：** 
- `/assistant/function/dataset/createFunctionDefinition`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|String| ID|
|isEnable|是|Boolean| 是否启用|
|functionType|是|Enum| 功能类型 DYNAMIC_DATA_DATESET, SYSTEM, HTTP_REMOTE|
|category|是|String| 类别|
|friendlyName|是|String| 友好名称|
|functionCode|是|String| 功能代码|
|parameters|是|Object| 参数|
|--type|是|String| 类型 例如：string、number、object、array、boolean、integer|
|--description|否|String| 描述|
|responses|否|Object| 响应|
|--type|是|String| 类型 例如：string、number、object、array、boolean、integer|
|--description|否|String| 描述|
|description|是|String| 描述|
|examples|否|List| 示例|
|--question|是|String| 问题 |
|--confirmationQuestion|否|String| 确认问题的细节信息 例如你问最近订单情况，确认问题可以是：你要查询什么时间段的订单销量？|
|--confirmationInfo|是|String| 确认信息 例如：查询最近一个月的 |
|--argumentJson|是|String| 参数 JSON |
|--resultJson|否|String| 结果 JSON |
|--answerByResult|否|String| 根据结果的答案 例如：我帮你查询到最近一个月的订单销量为1000单，销售总额为10000元 |
|httpRemoteInterface|是|Object| HTTP远程接口|
|--internalInterface|是|Boolean| 是否为内部接口（SpringCloud里面的服务）|
|--url|是|String| 路径|
|dynamicDataDataset|是|Object| 动态数据集查询接口|
|--tag|是|String| 数据集TAG|
|--limit|是|Integer| 返回行数限制 如果-1 则不限制|
