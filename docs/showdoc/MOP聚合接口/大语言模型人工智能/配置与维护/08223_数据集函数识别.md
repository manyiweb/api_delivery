# 数据集函数识别

**请求URL：** 
- `/assistant/function/dataset/datasetFunctionRecognition/{datasetTag}`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|datasetTag|否|String||

### 请求参数Json格式
 
```
{
 "datasetTag" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--datasetId|否|String| 数据集的唯一标识符。|
|--name|否|String| 数据集的名称。|
|--datasetTag|否|String| 数据集的标签，用于标记数据集。|
|--parameters|否|Object| 数据集的参数，这些参数可能包含数据集的一些特性或属性。|
|----type|是|String| 类型 例如：string、number、object、array、boolean、integer|
|----description|否|String| 描述|
|--responses|否|Object| 数据集的响应，这些响应可能包含数据集的一些结果或输出。|
|----type|是|String| 类型 例如：string、number、object、array、boolean、integer|
|----description|否|String| 描述|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "datasetId" : "String",
 "name" : "String",
 "datasetTag" : "String",
 "parameters" : {
 "type" : "String",
 "description" : "String"
 },
 "responses" : {
 "type" : "String",
 "description" : "String"
 }
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
