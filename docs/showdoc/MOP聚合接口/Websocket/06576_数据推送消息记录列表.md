# 数据推送消息记录列表
 
**请求datatable：** 
- ID：`data_dispatch_push_record_list`
- 服务：`reabam-websocket`

**请求URL：** 
- `/websocket/data-dispatch/list/pushRecord`

**请求方式：**
- POST
- RequestBody



### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|taskId|否|String| 任务ID|
|deviceCode|否|String| 设备编码|
|companyIds|否|List| 门店列表|
|statusSet|否|List| 状态 0-等待推送 1-等待重试 2-推送成功 3-推送失败 4-已失效|
|pageSize|否|Integer||
|pageIndex|否|Integer||
|sortFieldName|否|String||
|sortDirection|否|Object||

### 请求参数Json格式
 
```
{
 "taskId" : "String",
 "deviceCode" : "String",
 "companyIds" : null,
 "statusSet" : null,
 "pageSize" : 0,
 "pageIndex" : 0,
 "sortFieldName" : "String",
 "sortDirection" : null
}
```
