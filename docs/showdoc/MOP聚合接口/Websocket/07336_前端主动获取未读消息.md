# 前端主动获取未读消息
 

**请求URL：** 
- `/api/reabam-websocket/websocket/post/message/pullUnreachedMessages`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tags|否|List| 连接标签|
|pullLimit|否|Integer| 拉取最大条目数|

### 请求参数Json格式
 
```
{
 "tags" : null,
 "pullLimit" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--pushId|是|String| 推送ID|
|--type|是|String| 信息类型|
|--sessionId|是|Long| sessionID|
|--action|否|String| 行为|
|--body|否|String| 内容|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "pushId" : "String",
 "type" : "String",
 "sessionId" : 0,
 "action" : "String",
 "body" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
