# 数据推送任务列表

**请求URL：** 
- `/websocket/data-dispatch/list/task`

 
**请求datatable：** 
- ID：`data_dispatch_task_list`
- 服务：`reabam-websocket`


**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|keyword|否|String| 关键字|
|statusSet|否|List| 状态|
|pageSize|否|Integer| 分页大小|
|pageIndex|否|Integer| 分页|
|sortFieldName|否|String| 排序字段|
|sortDirection|否|Object| 排序方向|

### 请求参数Json格式
 
```
{
 "keyword" : "String",
 "statusSet" : null,
 "pageSize" : 0,
 "pageIndex" : 0,
 "sortFieldName" : "String",
 "sortDirection" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--content|否|List||
|----id|否|String| 任务编码|
|----taskName|否|String| 任务名称|
|----description|否|String| 任务描述|
|----redirectType|否|String| 任务信息重定向类型|
|----redirectId|否|String| 任务信息重定向ID|
|----statusName|否|String| 状态名称|
|----dispatchDeviceCount|否|String| 推送成功数量/目标设备数量|
|----startDateTime|否|DateTime| 任务开始时间|
|----expireDateTime|否|DateTime| 任务过期时间|
|----createDateTime|否|DateTime| 创建时间|
|----createUsername|否|String| 创建人|
|--pageSize|否|Integer||
|--pageNo|否|Integer||
|--total|否|Long||
|--totalPage|否|Integer||
|--hasNextPage|否|Boolean||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
