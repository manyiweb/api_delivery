# 重试单条推送失败记录
 

**请求URL：** 
- `/api/reabam-websocket/websocket/data-dispatch/retrySingleRecord`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|recordId|否|String| 推送记录ID|

### 请求参数Json格式
 
```
{
 "recordId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|String||
|--taskId|否|String| 任务ID|
|--deviceCode|否|String| 设备编码|
|--status|否|Integer| 状态 0-等待推送 1-等待重试 2-推送成功 3-推送失败 4-已失效|
|--statusName|否|String| 状态名称|
|--failureReason|否|String| 最后一次失败原因|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : {
 "id" : "String",
 "taskId" : "String",
 "deviceCode" : "String",
 "status" : 0,
 "statusName" : "String",
 "failureReason" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
