# 要货设置-要货数量设置导入

**请求URL：** 
- `/file/needQuantitySetItem/import `

**请求方式：**
- POST
- FormData


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|否|String| 登录标识|
|file|否|Object| 导入文件|

###请求参数Json格式
 
```
{
 "tokenId" : "String",
 "file" : null
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--errorData|否|List| 导入失败信息|
|--entityList|否|List| 校验成功的行|
|----companyId|否|String| 商户id|
|----itemId|否|String| 商品ID|
|----itemCode|否|String| 商品编码|
|----itemName|否|String| 商品名称|
|----skuBarcode|否|String| 条码|
|----specId|否|String| 规格ID|
|----specName|否|String| 规格名称|
|----minQuantity|否|Double| 最小要货量|
|----maxQuantity|否|Double| 最大要货量|
|----upperLimitType|否|Integer| 要货上限类型 0固定数量,1安全库存|
|----canExcess|否|Boolean| 是否可超量要货 1是,0否|
|----modifyName|否|String| 修改人|
|----modifyDate|否|DateTime| 修改时间|
|--totalCount|否|Long| 总数|
|--successCount|否|Long| 成功数|
|--errorCount|否|Long| 失败数|
|--fileUrl|否|String| 导出文件相对路径|
|--downloadURL|否|String| 导出文件下载路径|
|--data|否|List| 返回数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
