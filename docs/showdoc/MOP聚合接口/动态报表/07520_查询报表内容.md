# 查询报表内容
 

**请求URL：** 
- `/report/dynamicReport/query/query/report`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|applyId|是|Long| 动态报表ID|
|viewId|否|String| 视图ID|
|paramMap|否|Map| 参数|
|querySummaryRow|是|Boolean| 是否查询汇总行|
|pageIndex|否|Integer||
|pageSize|否|Integer||
|orderField|否|String||
|orderSort|否|String||

### 请求参数Json格式
 
```
{
 "applyId" : 0,
 "viewId" : "String",
 "paramMap" : null,
 "querySummaryRow" : true,
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--pageData|否|Object| 报表分页数据|
|----pageIndex|否|Integer||
|----pageSize|否|Integer||
|----pageCount|否|Integer||
|----totalCount|否|Long||
|----first|否|Boolean||
|----last|否|Boolean||
|----content|否|List||
|--summaryData|否|Map| 报表汇总数据|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "pageData" : {
 "pageIndex" : 0,
 "pageSize" : 0,
 "pageCount" : 0,
 "totalCount" : 0,
 "first" : true,
 "last" : true,
 "content" : null
 },
 "summaryData" : null
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
