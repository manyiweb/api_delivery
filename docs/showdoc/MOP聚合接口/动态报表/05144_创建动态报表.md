# 创建动态报表
 

**请求URL：** 
- `/report/dynamicReport/manager/create`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|reportId|是|Long| 动态报表ID|
|reportType|是|Integer| 报表分类|
|platformType|是|Integer| 报表应用平台类型,0-中台报表,1-前台报表,2-仓配端报表,3-供应端报表,4-订货端报表|
|menuCode|是|String| 菜单编码|
|menuName|是|String| 菜单名称|
|reportNumber|是|String| 报表编号|
|name|是|String| 报表名称|
|alias|否|String| 报表别名|
|subtitle|是|String| 子标题，即维度名称|
|isChildReport|是|Boolean| 是否为子报表|
|mainReportId|否|Long| 主报表ID|
|reportSQLExpression|是|String| 报表SQL表达式|
|summarySQLExpression|是|String| 报表汇总SQL表达式|
|isEnable|是|Boolean| 是否启用|
|isStandardReport|是|Boolean| 是否标准报表|
|isForwardReport|是|Boolean| 是否为转取报表|
|isSystemReport|是|Boolean| 是否为系统报表|
|systemReportCode|否|String| 系统报表编码|
|isExternalLink|是|Boolean| 是否为外部链接|
|externalLink|否|String| 外部链接地址|
|applyScope|否|Integer| 报表应用范围 0-全部品牌应用 1-指定品牌应用 2-排除品牌应用|
|reportColumns|否|List| 报表字段映射配置|
|--columnName|是|String| 列字段名称|
|--aggregationType|否|Enum| 聚合类型 NONE-无聚合 SUM-求和 AVG-平均值 MAX-最大值 MIN-最小值 COUNT_ALL-总计 COUNT_DISTINCT-去重计数|
|--aggregationDecimal|否|Integer| 聚合保留小数位数|
|--alias|是|String| 映射别名|
|--isVisible|是|Boolean| 是否显示|
|--isOrderField|否|Boolean| 是否排序字段|
|--isEnableForward|是|Boolean| 是否启用转发（钻取）|
|--reportForward|否|Object| 转发配置（钻取）|
|----forwardReportId|否|Long| 跳转的报表|
|----forwardType|是|Integer| 转发类型 0-报表类型 1-页面类型|
|----forwardReportName|否|String| 报表名称|
|----extractColumnName|是|String| 提取的行列字段名称|
|----extractColumnToParameter|否|String| 提取的行列字段转发到目标的参数名称|
|----pageTypeCodeColumnName|否|String| 跳转页面类型字段|
|----forwardConditionParamMapper|否|Map| 转发条件参数映射|
|summaryColumns|否|List| 汇总字段映射配置|
|--columnName|是|String| 列字段名称|
|--aggregationType|否|Enum| 聚合类型 NONE-无聚合 SUM-求和 AVG-平均值 MAX-最大值 MIN-最小值 COUNT_ALL-总计 COUNT_DISTINCT-去重计数|
|--aggregationDecimal|否|Integer| 聚合保留小数位数|
|--alias|是|String| 映射别名|
|--isVisible|是|Boolean| 是否显示|
|--isOrderField|否|Boolean| 是否排序字段|
|--isEnableForward|是|Boolean| 是否启用转发（钻取）|
|--reportForward|否|Object| 转发配置（钻取）|
|----forwardReportId|否|Long| 跳转的报表|
|----forwardType|是|Integer| 转发类型 0-报表类型 1-页面类型|
|----forwardReportName|否|String| 报表名称|
|----extractColumnName|是|String| 提取的行列字段名称|
|----extractColumnToParameter|否|String| 提取的行列字段转发到目标的参数名称|
|----pageTypeCodeColumnName|否|String| 跳转页面类型字段|
|----forwardConditionParamMapper|否|Map| 转发条件参数映射|
|conditions|否|List| 条件参数|
|--conditionName|是|String| 条件参数名称|
|--alias|是|String| 条件参数别名|
|--parameterType|是|Integer| 参数类型 0-文本 1-数值 2-区域 3-日期-年 4-日期-年月 5-日期-年月日 6-日期-年月日时分秒 7-业务对象 8-动态SQL参数 9-环境变量 10-商品分类|
|--isDisplay|否|Boolean| 是否显示（如果非子报表则无效）|
|--objectParameterCode|否|String| 业务对象类型参数Code|
|--sqlParameterCode|否|String| 动态SQL参数Code|
|--objectParameterName|否|String| 业务对象参数名称|
|--sqlParameterName|否|String| 动态SQL参数名称|
|applyGroupIds|否|List| 应用的品牌ID|
|excludeGroupIds|否|List| 排除应用的品牌ID|
|sourceName|否|String| 报表来源-品牌商档案的所有品牌简称|
|sourceId|否|String| 报表来源ID|
|reportDescription|否|String| 报表内容说明|
|dayLimit|否|Integer| 查询天数限制|
|assignDatasource|否|Integer| 指定数据源 0-默认ADB 1-数据服务ADB 2-StarRocks 3-动态数据源|
|openOptimize|是|Boolean| 是否打开语句优化|
