# 获得动态报表菜单
 

**请求URL：** 
- `/report/dynamicReport/menu/getMenus`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|platformType|是|Integer| 报表应用平台类型,0-中台报表,1-前台报表,2-仓配端报表,3-供应端报表,4-订货端报表|

### 请求参数Json格式
 
```
{
 "platformType" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--reportTypeName|否|String| 报表分类名称|
|--reportType|否|Integer| 报表分类ID|
|--pinYin|否|String||
|--pinYinHead|否|String||
|--reportMenuItemList|否|List| 动态报表菜单项|
|----reportId|否|Long| 动态报表ID|
|----applyId|否|Long| 报表应用ID|
|----reportType|否|Integer| 报表类型 0-会员分析 1-指定品牌 2-库存分析 3-零售分析 4-订货分析 5-供应分析 6-协同分析|
|----reportNumber|否|String| 报表编号|
|----isSystemReport|否|Boolean| 是否为系统报表|
|----systemReportCode|否|String| 系统报表编码|
|----isExternalLink|否|Boolean| 是否为外部链接|
|----externalLink|否|String| 外部链接地址|
|----name|否|String| 报表名称|
|----pinYin|否|String||
|----pinYinHead|否|String||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||

 }]
 }],

}
