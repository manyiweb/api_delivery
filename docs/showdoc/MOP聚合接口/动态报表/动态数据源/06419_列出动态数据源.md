# 列出动态数据源
 
 **DatatableId : **
- `list_dynamic_datasource_for_report`

**请求URL：** 
- `/report/datasource/listDynamicDataSources`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|keyword|否|String| 关键字|
|isEnable|否|Boolean| 是否启用|
|pageIndex|否|Integer||
|pageSize|否|Integer||

### 请求参数Json格式
 
```
{
 "keyword" : "String",
 "isEnable" : true,
 "pageIndex" : 0,
 "pageSize" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--content|否|List| 数据内容|
|--pageSize|否|Integer| 分页大小|
|--pageNo|否|Integer| 分页页码|
|--total|否|Long| 数据总数|
|--totalPage|否|Integer| 总页数|
|--hasNextPage|否|Boolean| 是否有下一页|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : {
 "content" : null,
 "pageSize" : 0,
 "pageNo" : 0,
 "total" : 0,
 "totalPage" : 0,
 "hasNextPage" : true
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
