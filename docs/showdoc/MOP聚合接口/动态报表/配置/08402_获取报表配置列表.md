# 获取报表配置列表


**请求URL：** 
- `/report/dynamicReport/config/getReportGroupConfigInfoList/menu`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|menuCode|是|String| 菜单编码|
|platformType|是|Integer| 报表应用平台类型,0-中台报表,1-前台报表,2-仓配端报表,3-供应端报表,4-订货端报表|
|sword|否|String| 过滤条件|

### 请求参数Json格式
 
```
{
 "menuCode" : "String",
 "platformType" : 0,
 "sword" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--reportId|否|Long| 动态报表ID|
|--isStandardReport|否|Boolean| 是否为标准报表|
|--applyId|否|Long| 报表应用ID|
|--reportType|否|Integer| 报表类型 0-会员分析 1-指定品牌 2-库存分析 3-零售分析 4-订货分析 5-供应分析 6-协同分析|
|--reportNumber|否|String| 报表编号|
|--serialNumber|否|Integer| 序号|
|--name|否|String| 报表名称|
|--subtitle|否|String| 子标题，即维度名称|
|--isChildReport|否|Boolean| 是否为子报表|
|--isForwardReport|否|Boolean| 是否转取报表|
|--isActive|否|Boolean| 是否活跃状态|
|--isSystemReport|否|Boolean| 是否系统报表|
|--systemReportCode|否|String| 系统报表编码|
|--isExternalLink|否|Boolean| 是否为外部链接|
|--externalLink|否|String| 外部链接地址|
|--permissionList|否|List| 报表权限|
|----ruleName|否|String| 角色名称|
|----ruleCode|否|String| 角色编码|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
