# 更改报表字段排序(重排)
 

**请求URL：** 
- `/report/dynamicReport/config/reportColumnRearrangement`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|reportId|否|Long| 报表ID|
|columnSettingIds|否|List| 列ID顺序列表|

### 请求参数Json格式
 
```
{
 "reportId" : 0,
 "columnSettingIds" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
