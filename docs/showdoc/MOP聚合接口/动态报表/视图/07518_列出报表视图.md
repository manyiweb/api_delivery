# 列出报表视图
 

**请求URL：** 
- `/report/view/manage/list/{reportId}`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|reportId|否|Long| |

### 请求参数Json格式
 
```
{
 "reportId" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--id|否|String| 视图ID|
|--title|否|String| 视图名称|
|--isSystemView|否|Boolean| 是否为系统视图|
|--createDate|否|DateTime| 创建时间|
|--userDefaultView|否|Boolean| 用户默认视图|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "id" : "String",
 "title" : "String",
 "isSystemView" : true,
 "createDate" : "DateTime",
 "userDefaultView" : true
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
