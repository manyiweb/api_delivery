# 设置用户默认视图
 

**请求URL：** 
- `/report/view/manage/setUserDefaultView`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|userId|是|String| 用户ID|
|reportId|是|Long| 报表ID|
|defaultViewId|是|String| 默认视图ID|
|deleteDefaultViewRecord|是|Boolean| 是否删除默认视图记录，如果删除默认视频配置，则使用标准报表作为默认展示|

### 请求参数Json格式
 
```
{
 "userId" : "String",
 "reportId" : 0,
 "defaultViewId" : "String",
 "deleteDefaultViewRecord" : true
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
