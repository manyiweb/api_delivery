# 获取报表视图详情
 

**请求URL：** 
- `/report/view/manage/detail/{id}`

**请求方式：** 
- `POST`
- `FormData`


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|String| |

### 请求参数Json格式
 
```
{
 "id":"String"
}
```

### 响应参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|String||
|--reportId|否|Long| 报表ID|
|--title|否|String| 视图标题|
|--isSystemView|否|Boolean| 是否为系统视图|
|--ownerUserId|否|String| 视图拥有者|
|--conditions|否|List| 视图条件列表|
|----conditionName|是|String| 条件参数名称|
|----alias|是|String| 条件参数别名|
|----parameterType|是|Integer| 参数类型 0-文本 1-数值 2-区域 3-日期-年 4-日期-年月 5-日期-年月日 6-日期-年月日时分秒 7-业务对象 8-动态SQL参数 9-环境变量 10-商品分类|
|----objectParameterCode|否|String| 业务对象类型参数Code|
|----containAll|是|Boolean| 是否查询全部|
|----values|是|List| 参数值|
|--reportViewColumns|否|List| 视图字段列表|
|----columnName|是|String| 列字段名称|
|----alias|是|String| 映射别名|
|----customAlias|否|String| 用户自定义别名|
|----columnWidth|否|Integer| 列宽|
|----serialNumber|是|Integer| 序号|
|--summaryViewColumns|否|List| 汇总视图字段列表|
|----columnName|是|String| 列字段名称|
|----alias|是|String| 映射别名|
|----customAlias|否|String| 用户自定义别名|
|----columnWidth|否|Integer| 列宽|
|----serialNumber|是|Integer| 序号|
|--pageSize|否|Integer| 分页大小|
|--groupId|否|String| 品牌Id|
|--freezeFirstColumn|否|Boolean| 是否冻结第一列|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
