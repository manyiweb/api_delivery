# 展现动态报表菜单
 

**请求URL：** 
- `/report/dynamicReportTreeMenu/getDynamicReportMenus/{platformType}`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|platformType|否|Integer|平台类型 |

### 请求参数Json格式
 
```
{
 "platformType" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--menuName|否|String| 报表菜单名称|
|--menuCode|否|String| 报表菜单名称|
|--pinYin|否|String| 拼音|
|--pinYinHead|否|String| 拼音首字母|
|--children|否|List| 子节点|
|--reportList|否|List| 动态报表列表|
|----reportId|否|Long| 动态报表ID|
|----applyId|否|Long| 报表应用ID|
|----reportType|否|Integer| 报表类型 0-会员分析 1-指定品牌 2-库存分析 3-零售分析 4-订货分析 5-供应分析 6-协同分析|
|----reportNumber|否|String| 报表编号|
|----isSystemReport|否|Boolean| 是否为系统报表|
|----systemReportCode|否|String| 系统报表编码|
|----isExternalLink|否|Boolean| 是否为外部链接|
|----externalLink|否|String| 外部链接地址|
|----name|否|String| 报表名称|
|----pinYin|否|String||
|----pinYinHead|否|String||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||

```
 "reportNumber" : "String",

 "isExternalLink" : true,
 "externalLink" : "String",
 "name" : "String",
 "pinYin" : "String",
 "pinYinHead" : "String"
 }]
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
