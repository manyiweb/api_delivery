# 修改菜单定义配置
 

**请求URL：** 
- `/report/dynamicReportTreeMenu/updateMenuDefinition`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|menuNodes|否|List| 菜单|
|--menuCode|是|String| 菜单编码|
|--menuName|是|String| 菜单名称|
|--children|否|List| 子菜单|
|----menuCode|否|String| 菜单编码|
|----menuName|否|String| 菜单名称|
|----children|否|List| 子菜单|
|platformType|是|Integer| 平台类型|

### 请求参数Json格式
 
```
{
 "menuNodes" : [{
 "menuCode" : "String",
 "menuName" : "String",
 "children" : [{
 "menuCode" : "String",
 "menuName" : "String",
 "children" : null
 }]
 }],
 "platformType" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
