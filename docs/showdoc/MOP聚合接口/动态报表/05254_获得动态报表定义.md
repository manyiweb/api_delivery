# 获得动态报表定义
 

**请求URL：** 
- `/report/dynamicReport/query/query/definition`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|applyId|是|Long||
|viewId|否|String| 视图|

### 请求参数Json格式
 
```
{
 "applyId" : 0,
 "viewId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--reportId|否|Long| 动态报表ID|
|--applyId|否|Long| 报表应用ID|
|--name|否|String| 报表名称|
|--isStandardReport|否|Boolean| 是否为标准报表|
|--reportNumber|否|String| 报表编码|
|--subtitle|否|String| 子标题，即维度名称|
|--isForwardReport|否|Boolean| 是否为转取报表|
|--sourceName|否|String| 报表来源-品牌商档案的所有品牌简称|
|--sourceId|否|String| 报表来源ID|
|--reportDescription|否|String| 报表内容说明|
|--dayLimit|否|Integer| 查询天数限制|
|--pageSize|否|Integer| 报表展示的分页大小|
|--params|否|List| 参数列表|
|----conditionName|否|String| 条件参数名称|
|----alias|否|String| 条件参数别名|
|----isDisplay|否|Boolean| 是否显示|
|----parameterType|否|Integer| 参数类型 0-文本 1-数值 2-区域 3-日期-年 4-日期-年月 5-日期-年月日 6-日期-年月日时分秒 7-业务对象 8-动态SQL参数 9-环境变量 10-商品分类|
|----objectParameterCode|否|String| 业务对象类型参数Code|
|----isMultiExtendCondition|否|Boolean| 是否为动态多扩展条件 ${parameter:OR} / ${parameter:AND} 条件|
|----values|否|List| 视图条件值列表|
|------readableValue|是|String| 显示参数|
|------value|是|Object| 参数值|
|--reportColumnList|否|List| 报表列字段定义|
|----columnName|否|String| 列字段名称|
|----aggregationType|否|Enum| 聚合类型 NONE-无聚合 SUM-求和 AVG-平均值 MAX-最大值 MIN-最小值 COUNT_ALL-总计 COUNT_DISTINCT-去重计数|
|----alias|否|String| 映射别名|
|----customAlias|否|String| 用户自定义别名(仅视图字段有值)|
|----columnWidth|否|Integer| 列宽(仅视图字段有值)|
|----isVisible|否|Boolean| 是否显示|
|----hasPermission|否|Boolean| 是否有权限|
|----isEnableForward|否|Boolean| 是否启用转发（钻取）|
|----serialNumber|否|Integer| 排序号|
|----reportForward|否|Object| 转发配置（钻取）|
|------forwardReportId|否|Long| 跳转的报表|
|------forwardReportApplyId|否|Long| 跳转报表的应用ID|
|------pageTypeCodeColumnName|否|String| 跳转页面类型判定字段名称|
|------forwardType|否|Integer| 转发类型 0-报表类型 1-页面类型|
|------extractColumnName|否|String| 提取的行列字段名称|
|------extractColumnToParameter|否|String| 提取的行列字段转发到目标的参数名称|
|------forwardParamMapper|否|Map| 转发条件参数映射|
|--summaryColumnList|否|List| 报表汇总列字段定义|
|----columnName|否|String| 列字段名称|
|----aggregationType|否|Enum| 聚合类型 NONE-无聚合 SUM-求和 AVG-平均值 MAX-最大值 MIN-最小值 COUNT_ALL-总计 COUNT_DISTINCT-去重计数|
|----alias|否|String| 映射别名|
|----customAlias|否|String| 用户自定义别名(仅视图字段有值)|
|----columnWidth|否|Integer| 列宽(仅视图字段有值)|
|----isVisible|否|Boolean| 是否显示|
|----hasPermission|否|Boolean| 是否有权限|
|----isEnableForward|否|Boolean| 是否启用转发（钻取）|
|----serialNumber|否|Integer| 排序号|
|----reportForward|否|Object| 转发配置（钻取）|
|------forwardReportId|否|Long| 跳转的报表|
|------forwardReportApplyId|否|Long| 跳转报表的应用ID|
|------pageTypeCodeColumnName|否|String| 跳转页面类型判定字段名称|
|------forwardType|否|Integer| 转发类型 0-报表类型 1-页面类型|
|------extractColumnName|否|String| 提取的行列字段名称|
|------extractColumnToParameter|否|String| 提取的行列字段转发到目标的参数名称|
|------forwardParamMapper|否|Map| 转发条件参数映射|
|--childReportDefinitions|否|List| 获得子报表维度定义|
|----name|否|String| 报表名称|
|----subtitle|否|String| 子标题，即维度名称|
|----applyId|否|Long| 报表应用ID|
|----reportId|否|Long| 报表ID|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
