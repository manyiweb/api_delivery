# 获得提货配送日期信息
 

**请求URL：** 
- `/b2b/shopCart/getOfflineDeliveryDates `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|deliveryType|否|String|配送方式|
|companyId|否|String| 门店id|
|orderTypeId|否|Long| 订货类型id|

###请求参数Json格式
 
```
{
 "deliveryType" : "String",
 "companyId" : "String",
 "orderTypeId" : 0
}
```
###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--isAll|否|Boolean|是否可以选择所有日期 |
|--dates|否|List|可选日期集合 |
|----date|否|Integer|当前日期信息 |
|----week|否|Integer|当前是星期几 |
|----childDates|否|Object|下级日期集合 |
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
	"code":"200",
	"data":{
		"all":false,
		"dates":[{
			"childDates":[{
				"childDates":[{
					"childDates":[],
					"date":5,
					"week":5
				},{
					"childDates":[],
					"date":6,
					"week":6
				},{
					"childDates":[],
					"date":7,
					"week":7
				}],
				"date":5,
				"week":null
			}],
			"date":2023,
			"week":null
		}]
	},
	"exceptionStackInfo":"",
	"msg":"",
	"success":true,
	"traceId":""
}
```
