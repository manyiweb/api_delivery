# 售后单明细
 

**请求URL：** 
- `/b2b/afterSales/order/detail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||
|sword|否|String||

```
{
 "id" : 0,
 "sword" : "String"
```
