# 获取单位组明细信息 (如果是没开启单位组则返回计量单位)

**请求URL：** 
- `/product/unit_group/getDetails2`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|String|主物料的itemId|


### 请求参数Json格式
 
```
{
 "id" : "String",
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--datas|否|List| 单位组详情列表|
|----id|否|Long| 主键id|
|----unitName|否|String| 转换单位名称|
|----num|否|Double| 系数|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "datas" : [{
 "id" : 0,
 "unitName" : "String",
 "num" : 0
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
