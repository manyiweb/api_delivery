# 替代料应用设置新增校验

**请求URL：** 
- `/b2b/billmaterials/item/replace/apply/check`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|billmaterialsItemId|是|String| 子物料明细id|

### 请求参数Json格式
 
```
{
 "billmaterialsItemId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--replaceAreaList|否|List| 应用区域|
|--replaceComList|否|List| 应用门店|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : {
 "replaceAreaList" : null,
 "replaceComList" : null
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
