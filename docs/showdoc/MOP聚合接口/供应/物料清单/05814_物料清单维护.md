# 物料清单维护
 

**请求URL：** 
- `/b2b/billmaterials/maintain`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|否|String||
|fid|否|String||
|specId|否|String||

|--quantity|否|Double||
|--applyType|否|Integer| 应用类型:0（应用门店）,1（应用区域）|

|----quantity|否|Double||
|----isActive|否|Integer||

|----addComps|否|List| 替代商品应用门店|
|------id|否|Long| id|
|------companyId|否|String| 商户标识|
|------companyCode|否|String| 商户编码|
|------companyName|否|String| 商户名称|
|------deductionOrder|否|Integer| 替代商品扣减顺序|
|----addAreas|否|List| 替代商品应用区域|
|------id|否|Long| id|
|------merchantAreaId|否|String| 区域Id|
|------merchantAreaCode|否|String| 区域编码|
|------merchantAreaName|否|String| 区域名称|
|------deductionOrder|否|Integer| 替代商品扣减顺序|
|----delIds|否|List| 删除列表|
|--delIds|否|List| 删除列表|
|delRowIds|否|List||
|typeCode|否|Integer||
|component|否|Integer||
|quantity|否|Integer||
|unitDetailId|否|Long||
|unitName|否|String||
|attachProductSpecIds|否|List| 附加品 商品规格id|
|processingType|否|Integer| 加工类型 0 - 倒冲, 1 - 手工|
|isProduceReceiving|否|Integer| 是否生产收货时扣减原料 0 -否, 1 - 是|
|isAdjust|否|Integer| 是否可支持调整原料 0 -否, 1 - 是|
