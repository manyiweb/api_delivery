# 添加供应商合同信息
 

**请求URL：** 
- `/b2b/supplier/contract/add`

**请求方式：** 
- `POST`
- `RequestBody`


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|contractName|是|String| 合同名称|
|contractFileName|是|String| 合同文件名|
|contractFilePath|是|String| 合同文件路径，存储合同文件在系统中的路径。|
|contractNumber|是|String| 合同编号，用于唯一标识一份合同。|
|contractExpiryDate|是|DateTime| 合同有效期，记录合同的有效截止日期。|
|remark|否|String| 备注信息，可用于记录与合同相关的额外说明。|
|supplierId|是|String| 供应商ID|

### 请求参数Json格式
 
```
{
 "contractName":"String",
 "contractFileName":"String",
 "contractFilePath":"String",
 "contractNumber":"String",
 "contractExpiryDate":"DateTime",
 "remark":"String",
 "supplierId":"String"
}
```

### 响应参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 响应参数Json格式
 
```
{
 "data":null,
 "msg":"String",
 "code":"String",
 "exceptionStackInfo":"String",
 "traceId":"String"
}
```
