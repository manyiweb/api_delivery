# 获取供应商合同列表
 

**请求URL：** 
- `/api/b2b/supplier/contract/list/{supplierId}`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|supplierId|否|String|供应商 ID |

### 请求参数Json格式
 
```
{
 "supplierId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--contractFilePath|否|String| 合同文件路径，存储合同文件在系统中的路径。|
|--contractFileName|否|String| 合同文件名称，存储合同文件的原始名称。|
|--contractNumber|否|String| 合同编号，用于唯一标识一份合同。|
|--contractExpiryDate|否|DateTime| 合同有效期，记录合同的有效截止日期。|
|--certStatusCode|否|String| 合同状态 EXPIRED,AVAILABLE|
|--certStatusName|否|String| 合同状态名称 已过期，生效中|
|--remark|否|String| 备注信息，可用于记录与合同相关的额外说明。|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "contractFilePath" : "String",
 "contractFileName" : "String",
 "contractNumber" : "String",
 "contractExpiryDate" : "DateTime",
 "certStatusCode" : "String",
 "certStatusName" : "String",
 "remark" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
