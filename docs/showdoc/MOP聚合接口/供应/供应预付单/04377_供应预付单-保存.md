# 保存-供应预付单

**请求URL：** 
- `/b2b/supplierDepositOrder/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|
|orderName|否|String| 单据名称|
|saveType|是|Integer| 保存类型 0草稿，1新增|
|supplierId|是|String| 供应商Id|
|companyId|否|String| 门店id|
|typeCode|是|String| 单据类型编码|
|typeName|是|String| 单据类型名称|
|totalMoney|是|Double| 预付金额|
|postingDate|否|DateTime| 过账日期|
|remark|否|String| 备注|
|addAttachmentIds|否|List| 添加附件ids|
|deleteAttachmentIds|否|List| 删除附件ids|
|inGoodOrderIds|否|List| 关联的采购订单id|
|--inGoodOrderId|否|String| 采购订单id|
|--inGoodOrderNo|否|String| 采购订单编码|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "orderName" : "String",
 "saveType" : 0,
 "supplierId" : "String",
 "companyId" : "String",
 "typeCode" : "String",
 "typeName" : "String",
 "totalMoney" : 0,
 "postingDate" : "DateTime",
 "remark" : "String",
 "addAttachmentIds" : null,
 "deleteAttachmentIds" : null,
 "inGoodOrderIds" : [{
 "inGoodOrderId" : "String",
 "inGoodOrderNo" : "String"
 }]
}
```

|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
