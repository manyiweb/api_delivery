# 受理

**请求URL：** 
- `/b2b/supplierDepositOrder/accept `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 业务ID|
|statusCode|否|Integer| 审核状态 1待受理，2已完成，3已拒绝，4已取消|
|remark|否|String| 审核备注|

###请求参数Json格式
 
```
{
 "id" : 0,
 "statusCode" : 0,
 "remark" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
