# 确认转储

**请求URL：** 
- `/product/productionPlan/batch/toDump`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|items|否|List| 商品列表|
|--id|是|Long| 生产计划单id|
|--productionPlanItemId|是|Long| 生产计划单明细ID|
|--specId|否|String||
|--itemId|否|String||
|--receivingQty|是|Double| 收货数量|
|--remark|否|String| 备注|
|--workShopId|否|Long| 流转工作车间id|

### 请求参数Json格式
 
```
{
 "items" : [{
 "id" : 0,
 "productionPlanItemId" : 0,
 "specId" : "String",
 "itemId" : "String",
 "receivingQty" : 0,
 "remark" : "String",
 "workShopId" : 0
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
