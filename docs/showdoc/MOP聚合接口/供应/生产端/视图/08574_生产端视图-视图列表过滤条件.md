# 生产端视图-视图列表过滤条件

**请求URL：** 
- `/config/produce/view/viewListFilterCondition`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|moduleType|是|String| 模块类型 PRODUCE_ORDER-生产端订单|

### 请求参数Json格式
 
```
{
 "moduleType" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--moduleType|否|String| 模块类型|
|--parameters|否|List| 参数|
|----name|否|String||
|----alias|否|String||
|----type|否|Enum||
|----selectorItems|否|List||
|------name|否|String||
|------value|否|String||
|----require|否|Boolean||
|----displayable|否|Boolean||
|----sequenceNumber|否|Integer||
|----multiple|否|Boolean||
|----groupName|否|String||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "moduleType" : "String",
 "parameters" : [{
 "name" : "String",
 "alias" : "String",
 "type" : 0,
 "selectorItems" : [{
 "name" : "String",
 "value" : "String"
 }],
 "require" : true,
 "displayable" : true,
 "sequenceNumber" : 0,
 "multiple" : true,
 "groupName" : "String"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
