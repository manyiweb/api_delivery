# 生产端视图-视图列表过滤条件参数

**请求URL：** 
- `/config/produce/view/viewConditionSelectorItem`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|moduleType|是|String| 模块类型|
|parameterName|是|String| 参数名称|
|keyword|否|String| 关键字|
|pageNo|是|Integer| 页码|

### 请求参数Json格式
 
```
{
 "moduleType" : "String",
 "parameterName" : "String",
 "keyword" : "String",
 "pageNo" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--name|否|String| 名称|
|--value|否|String| 值|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "name" : "String",
 "value" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
