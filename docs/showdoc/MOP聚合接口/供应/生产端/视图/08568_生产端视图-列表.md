# 生产端视图-列表

**请求URL：** 
- `/config/produce/view/list`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|moduleType|是|String| 模块类型 PRODUCE_ORDER-生产端订单|

### 请求参数Json格式
 
```
{
 "moduleType" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--id|否|String| 主键|
|--userId|否|String| 用户id|
|--groupId|否|String| 品牌id|
|--isSystemView|否|Boolean| 是否系统视图|
|--title|否|String| 视图名称|
|--moduleType|否|String| 模块类型|
|--conditions|否|List| 视图条件|
|----selectCode|否|String| 筛选编码|
|----selectName|否|String| 筛选名称|
|----selectType|否|String| 具体筛选类型|
|----type|否|String| 条件类型，全部、包含|
|----keyword|否|String| 筛选关键字|
|----selects|否|List| 筛选选项|
|------name|否|String||
|------value|否|String||
|--userSelected|否|Boolean| 当前用户是否选中|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "id" : "String",
 "userId" : "String",
 "groupId" : "String",
 "isSystemView" : true,
 "title" : "String",
 "moduleType" : "String",
 "conditions" : [{
 "selectCode" : "String",
 "selectName" : "String",
 "selectType" : "String",
 "type" : "String",
 "keyword" : "String",
 "selects" : [{
 "name" : "String",
 "value" : "String"
 }]
 }],
 "userSelected" : true
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
