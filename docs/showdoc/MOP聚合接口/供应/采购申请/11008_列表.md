# 列表

**请求URL：** 
- `/b2b/purchaseApply/list`

**请求方式：** 
- `POST`
- `RequestBody`


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|keyWord|否|String||
|sword|否|String| 兼容旧接口历史字段。|
|status|否|List||
|typeCode|否|List| 业务类型编码由前端透传，当前不在 datatable 面板展示。|
|createDate|否|Object||
|--start|否|DateTime||
|--end|否|DateTime||
|createId|否|List||
