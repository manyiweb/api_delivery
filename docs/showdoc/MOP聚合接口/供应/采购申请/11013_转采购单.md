# 转采购单

**请求URL：** 
- `/b2b/purchaseApply/convert/create`

**请求方式：** 
- `POST`
- `RequestBody`


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String||
|goodsInOrderType|否|String||
|itemList|否|List||
|--applyId|否|Long||
|--applyItemId|否|Long||
|--supplierId|否|String||
|--arrivalDate|否|String||
|--quantity|否|Double||
|--unit|否|String||
|--purchasePrice|否|Double||
|--giftQuantity|否|Double||
|--priceType|否|Integer||
|--amountTotal|否|Double||
|--taxRate|否|Double||
|--afterTaxPrice|否|Double||
|--afterTaxAmount|否|Double||
|--remark|否|String||

### 请求参数Json格式
 
```
{
 "companyId":"String",
 "goodsInOrderType":"String",
 "itemList":[{
 "applyId":0,
 "applyItemId":0,
 "supplierId":"String",
 "arrivalDate":"String",
 "quantity":0,
 "unit":"String",
 "purchasePrice":0,
 "giftQuantity":0,
 "priceType":0,
 "amountTotal":0,
 "taxRate":0,
 "afterTaxPrice":0,
 "afterTaxAmount":0,
 "remark":"String"
 }]
}
```

### 响应参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--orderList|否|List||
|----orderId|否|String||
|----orderNo|否|String||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 响应参数Json格式
 
```
{
 "data":{
 "orderList":[{
 "orderId":"String",
 "orderNo":"String"
 }]
 },
 "msg":"String",
 "code":"String",
 "exceptionStackInfo":"String",
 "traceId":"String"
}
```
