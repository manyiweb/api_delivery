# 转采购商品列表

**请求URL：** 
- `/b2b/purchaseApply/convert/preview`

**请求方式：** 
- `POST`
- `RequestBody`


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|applyIds|否|List||

### 请求参数Json格式
 
```
{
 "applyIds":null
}
```
