# 新增

**请求URL：** 
- `/b2b/purchaseApply/add`

**请求方式：** 
- `POST`
- `RequestBody`


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|applyId|否|String||
|companyId|否|String||
|companyDepartmentId|否|Long||
|typeCode|否|String||
|saveType|否|String||
|remark|否|String||
|tokenId|否|String||
|itemList|否|List||
|--itemId|否|String||
|--specId|否|String||
|--quantity|否|Double||
|--unit|否|String||
|--remark|否|String||
|--lineId|否|Integer||
|--arrivalDate|否|DateTime||

### 请求参数Json格式
 
```
{
 "applyId":"String",
 "companyId":"String",
 "companyDepartmentId":0,
 "typeCode":"String",
 "saveType":"String",
 "remark":"String",
 "tokenId":"String",
 "itemList":[{
 "itemId":"String",
 "specId":"String",
 "quantity":0,
 "unit":"String",
 "remark":"String",
 "lineId":0,
 "arrivalDate":"DateTime"
 }]
}
```

### 响应参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|String||
|--applyNo|否|String||
|--status|否|String||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 响应参数Json格式
 
```
{
 "data":{
 "id":"String",
 "applyNo":"String",
 "status":"String"
 },
 "msg":"String",
 "code":"String",
 "exceptionStackInfo":"String",
 "traceId":"String"
}
```
