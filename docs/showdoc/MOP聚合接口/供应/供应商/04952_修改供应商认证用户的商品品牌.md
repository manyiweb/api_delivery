# 修改供应商认证用户的商品品牌
 

**请求URL：** 
- `/reabam-hr/hr/staff/supplier/brand/updateStaffSupplierItemBrand `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|staffSupplierId|是|Long| 供应商认证用户id|
|itemBrandId|否|List| 商品品牌id|
|delId|否|List| 删除供认证用户的商品品牌id|

###请求参数Json格式
 
```
{
 "staffSupplierId" : 0,
 "itemBrandId" : null,
 "delId" : null
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
