# 获取供应商认证用户的品牌信息

**请求URL：** 
- `/reabam-hr/hr/staff/supplier/brand/findByStaffSupplierId `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|staffSupplierId|是|Long| 供应商认证用户id|

###请求参数Json格式
 
```
{
 "staffSupplierId" : 0,
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--id|否|Long| 主键|
|--staffSupplierId|否|Long| 供应商认证用户id，与sysstaff_supplier表关联|
|--itemBrandId|否|String| 商品品牌ID，与mitembrand表关联|
|--brandCode|否|String| 品牌编码|
|--brandName|否|String| 品牌名称|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : [{
 "id" : 0,
 "staffSupplierId" : 0,
 "itemBrandId" : "String",
 "brandCode" : "String",
 "brandName" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
