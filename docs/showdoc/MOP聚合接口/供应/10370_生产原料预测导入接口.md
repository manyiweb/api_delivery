# 

**请求URL：** 
- `/product/predict_materials/predictImport`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|filePath|否|String| 文件路径|

### 请求参数Json格式
 
```
{
 "filePath" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--materialsDTOList|否|List||
|----billCode|否|String| 物料编码|
|----billName|否|String| 物料名称|
|----fid|否|String| 主键|
|----itemId|否|String| 商品ID|
|----skuBarcode|否|String| sku|
|----specId|否|String| 规格ID|
|----typeCode|否|Integer| 类型编码|
|----typeName|否|String| 类型名称|
|----unitName|否|String| 单位名称|
|----predictNum|否|Double| 计划数量|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "materialsDTOList" : [{
 "billCode" : "String",
 "billName" : "String",
 "fid" : "String",
 "itemId" : "String",
 "skuBarcode" : "String",
 "specId" : "String",
 "typeCode" : 0,
 "typeName" : "String",
 "unitName" : "String",
 "predictNum" : 0
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
