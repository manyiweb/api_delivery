# 工厂端获取运营仓库列表

**请求URL：** 
- `/product/predictMaterials/getWhsId`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|String| 员工ID|

### 请求参数Json格式
 
```
{
 "id" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--items|否|List||
|----whsId|否|String||
|----whsCode|否|String||
|----whsName|否|String||
|----companyId|否|String||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "items" : [{
 "whsId" : "String",
 "whsCode" : "String",
 "whsName" : "String",
 "companyId" : "String"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
