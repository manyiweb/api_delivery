# 采购收货受理

**请求URL：** 
- `/b2b/purchase/accept`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|String|采购收货订单id|
|statusCode|是|String|受理状态码，同采购订单|
|remark|否|String||

### 请求参数Json格式
 
```
{
 "id" : "String",
 "statusCode" : "String",
 "remark" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
