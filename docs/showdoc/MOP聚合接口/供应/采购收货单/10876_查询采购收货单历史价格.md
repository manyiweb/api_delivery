# 查询采购收货单历史价格
 查询某个供应商某个规格的最近7笔采购收货单价格
 

**请求URL：** 
- `/b2b/purchase/goodsInReceipt/historyPrice`

**请求方式：** 
- `POST`
- `RequestBody`


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|specId|是|String| 规格ID|
|supplierId|是|String| 供应商ID|

### 请求参数Json格式
 
```
{
 "specId":"String",
 "supplierId":"String"
}
```

### 响应参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--specId|否|String| 规格ID|
|--purchasePrice|否|Double| 采购价格|
|--itemUnit|否|String| 商品单位|
|--createDate|否|DateTime| 创建时间|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 响应参数Json格式
 
```
{
 "data":[{
 "specId":"String",
 "purchasePrice":0,
 "itemUnit":"String",
 "createDate":"DateTime"
 }],
 "msg":"String",
 "code":"String",
 "exceptionStackInfo":"String",
 "traceId":"String"
}
```
