# 修改结算单详情
 

**请求URL：** 
- `/b2b/supplierBill/update `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|String| 结算单id|
|remark|否|String| 备注|
|attachmentIds|否|array[String]| 附件id|

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|

###请求参数Json格式
 
```
{
 "id" : "String",
 "remark" : "String",
 "attachmentId" : "String"
}
```

###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String"
}
```
