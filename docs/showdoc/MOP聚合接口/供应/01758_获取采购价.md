# 获取采购价
 

**请求URL：** 
- `/product/getPurchasePrice`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|items|否|List| 明细|
|--supplierCode|否|String| 供应商编码（2选1）|
|--supplierId|否|String| 供应商id（2选1）|
|--specId|否|String| 商品规格id|
|--itemId|否|String| 商品id|
|--itemUnit|否|String| 下单单位|
|--itemQuantity|否|Double| 下单数量|
|--unitRate|否|Double| 单位转换率|

### 请求参数Json格式
 
```
{
 "items" : [{
 "supplierCode" : "String",
 "supplierId" : "String",
 "specId" : "String",
 "itemId" : "String",
 "itemUnit" : "String",
 "itemQuantity" : 0,
 "unitRate" : 0
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--specId|否|String| 商品规格id|
|--purchasePrice|否|Double| 采购价|
|--itemUnitPrice|否|Double| 选择单位清单价|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : [{
 "specId" : "String",
 "purchasePrice" : 0,
 "itemUnitPrice" : 0
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
