# 模板设置-商户组分页列表

**请求URL：** 
- `/config/inventory/pageCompGroup`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|inventoryId|是|String| 模板id|
|pageIndex|否|Integer||
|pageSize|否|Integer||
|orderField|否|String||
|orderSort|否|String||

### 请求参数Json格式
 
```
{
 "inventoryId" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--pageIndex|否|Integer||
|--pageSize|否|Integer||
|--pageCount|否|Integer||
|--totalCount|否|Long||
|--first|否|Boolean||
|--last|否|Boolean||
|--content|否|List||
|----id|否|Long| 主键|
|----inventoryId|否|String| 模板id|
|----chainId|否|String| 商户组id|
|----chainCode|否|String| 商户组编码|
|----chainName|否|String| 商户组名称|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "pageIndex" : 0,
 "pageSize" : 0,
 "pageCount" : 0,
 "totalCount" : 0,
 "first" : true,
 "last" : true,
 "content" : [{
 "id" : 0,
 "inventoryId" : "String",
 "chainId" : "String",
 "chainCode" : "String",
 "chainName" : "String"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
