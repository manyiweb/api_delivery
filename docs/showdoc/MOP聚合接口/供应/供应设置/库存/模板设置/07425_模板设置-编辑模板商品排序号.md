# 模板设置-编辑模板商品排序号

**请求URL：** 
- `/config/inventory/updateInventoryItemLineNum `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|String| 主键|
|lineNum|否|Integer| 排序号|

###请求参数Json格式
 
```
{
 "id" : "String",
 "lineNum" : 0
}
```
