# 模板设置-编辑模板商品单位

**请求URL：** 
- `/config/inventory/updateInventoryItemUnit`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|String| 模板商品id|
|unit|是|String| 单位|

### 请求参数Json格式
 
```
{
 "id" : "String",
 "unit" : "String"
}
```
