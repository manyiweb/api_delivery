# 商品属性模板-保存

**请求URL：** 
- `/product/productAttrTemplate/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 主键|
|templateName|是|String| 模板名称|
|active|是|Boolean| 是否启用 true/false|
|isSaleItem|否|Integer| 零售物料|
|isOpenOrderItemAttr|否|Integer| 订单商品属性|
|isMaterial|否|Integer| 订货物料|
|isB2bReturnMaterial|否|Integer| 订货退货物料|
|puritem|否|Integer| 采购物料|
|isProductionMaterials|否|Boolean| 生产物料|
|allotMaterial|否|Boolean| 调拨物料|
|isUnpacking|否|Integer| 拆装主物料|
|disassemblySubMaterial|否|Boolean| 拆装子物料|
|isInventory|否|Integer| 盘点物料|
|isNeedItem|否|Integer| 要货物料|
|isReservation|否|Boolean| 预约服务|
|isPrints|否|Integer| 打印不干胶|
|weighing|否|Integer| 称重物料|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "templateName" : "String",
 "active" : true,
 "isSaleItem" : 0,
 "isOpenOrderItemAttr" : 0,
 "isMaterial" : 0,
 "isB2bReturnMaterial" : 0,
 "puritem" : 0,
 "isProductionMaterials" : true,
 "allotMaterial" : true,
 "isUnpacking" : 0,
 "disassemblySubMaterial" : true,
 "isInventory" : 0,
 "isNeedItem" : 0,
 "isReservation" : true,
 "isPrints" : 0,
 "weighing" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
