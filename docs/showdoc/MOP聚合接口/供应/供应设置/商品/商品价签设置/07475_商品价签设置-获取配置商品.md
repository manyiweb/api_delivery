# 商品价签设置-获取配置商品

**请求URL：** 
- `/config/item/price/tag/config/getConfigItem `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|specIds|否|List| 规格id|
|field|否|String| 字段 productionDate-生产日期 |

###请求参数Json格式
 
```
{
 "specIds" : null,
 "field" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
