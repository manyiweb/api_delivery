# 商品价签设置-保存

**请求URL：** 
- `/config/item/price/tag/config/save `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 价签设置id|
|productType|否|Integer| 指定商品类型 0指定商品 1所有商品|
|specIds|否|List| 规格id|

###请求参数Json格式
 
```
{
 "id" : 0,
 "productType" : 0,
 "specIds" : null
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
