# 生产车间-保存

**请求URL：** 
- `/product/prodWorkshop/prodWorkshopSave`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 主键|
|workshopNo|是|String| 车间编码|
|workshopName|否|String| 车间名称|
|whsId|是|String| 关联仓库id|
|companyId|是|String| 门店id|
|active|是|Boolean| 活跃状态|
|isIngredientWork|是|Boolean| 是否配料车间|
|merchantsProductionLineId|是|Long| 所属生产线线|
|merchantsProductionLineName|是|String| 所属生产线线名称|
|materialWorkShopId|否|Long| 可领车间id|
|materialWorkShopName|否|String| 可领料车间名称|
|openSpecialProductsWorkShop|否|Boolean| 指定特殊车间|
|specialProducts|否|List| 特殊商品列表|
|--id|否|Long| id|
|--itemCode|否|String| 商品编码|
|--itemId|否|String| 商品id|
|--specIds|否|String| 规格id|
|--itemName|否|String| 商品名称|
|--skuBarCode|否|String| 商品sku|
|--materialWorkShopId|否|Long| 领料车间id|
|--materialWorkShopName|否|String| 可领料车间名称|
|visibleRoleIds|否|List| 可视角色id|
