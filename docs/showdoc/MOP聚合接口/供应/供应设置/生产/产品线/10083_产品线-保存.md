# 产品线-保存

**请求URL：** 
- `/product/productLine/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 主键|
|lineCode|是|String| 产品线编码|
|lineName|是|String| 产品线名称|
|isActive|是|Boolean| 活跃状态|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "lineCode" : "String",
 "lineName" : "String",
 "isActive" : true
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
