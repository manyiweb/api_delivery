# 生产计划时间设置-详情

**请求URL：** 
- `/config/proPlanDateConfig/detail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 门店id|

### 请求参数Json格式
 
```
{
 "companyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--isInherit|否|Integer| 是否继承|
|--companyId|否|String| 门店id|
|--dateType|否|Integer| 时间类型 1全天 2自定义时间|
|--customTimes|否|List| 自定义时间范围|
|----customStartTime|否|String| 自定义开始时间|
|----customEndTime|否|String| 自定义结束时间|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "isInherit" : 0,
 "companyId" : "String",
 "dateType" : 0,
 "customTimes" : [{
 "customStartTime" : "String",
 "customEndTime" : "String"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
