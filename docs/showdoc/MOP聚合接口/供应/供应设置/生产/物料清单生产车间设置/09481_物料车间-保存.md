# 物料车间-保存

**请求URL：** 
- `/product/materialWorkshop/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 门店id|
|billMaterialsInfos|是|List| 物料信息|
|--billMaterialsId|是|String| 物料清单id|
|--prodWorkshopId|是|Long| 生产车间|
|--circulationWorkshopIds|是|List| 流转车间|

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "billMaterialsInfos" : [{
 "billMaterialsId" : "String",
 "prodWorkshopId" : 0,
 "circulationWorkshopIds" : null
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
