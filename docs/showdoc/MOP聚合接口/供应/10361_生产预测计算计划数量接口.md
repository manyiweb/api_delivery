# 

**请求URL：** 
- `/product/predict_materials/list`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|items|是|List| 商品信息|
|--billCode|否|String| 物料编码|
|--billName|否|String| 物料名称|
|--fid|否|String| 主键|
|--itemId|否|String| 商品ID|
|--skuBarcode|否|String| sku|
|--specId|否|String| 规格ID|
|--typeCode|否|Integer| 类型编码|
|--typeName|否|String| 类型名称|
|--unitName|否|String| 单位名称|
|--predictNum|否|Double| 计划数量|

### 请求参数Json格式
 
```
{
 "items" : [{
 "billCode" : "String",
 "billName" : "String",
 "fid" : "String",
 "itemId" : "String",
 "skuBarcode" : "String",
 "specId" : "String",
 "typeCode" : 0,
 "typeName" : "String",
 "unitName" : "String",
 "predictNum" : 0
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--items|是|List| 商品信息|
|----fid|否|String| 主键|
|----billmaterialsId|否|String| 主表ID，与billmaterials关联|
|----itemCode|否|String| 类型编码|
|----itemName|否|String| 类型名称|
|----itemId|否|String| 商品ID|
|----skuBarcode|否|String| sku|
|----unitName|否|String| 单位名称|
|----num|否|Double| 数量|
|----specId|否|String| 规格ID|
|----specName|否|String| 规格名称|
|----calculateNum|否|Double| 预测生产数量|
|----purchaseNum|否|Double| 预测采购数量|
|----purchaseUnit|否|String| 采购单位（单位组中最大的）|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
