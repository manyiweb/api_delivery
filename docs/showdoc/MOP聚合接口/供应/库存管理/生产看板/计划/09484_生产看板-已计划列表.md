# 生产看板-已计划列表

**请求URL：** 
- `/product/prodKanban/planList`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|beginProdPlanDate|否|DateTime| 生产计划日-开始|
|endProdPlanDate|否|DateTime| 生产计划日-结束|
|companyId|是|String| 门店id|
|startDeliveryDate|否|DateTime| 交付日期-开始|
|endDeliveryDate|否|DateTime| 交付日期-结束|
|beginCreateDate|否|DateTime| 创建时间-开始|
|endCreateDate|否|DateTime| 创建时间-结束|
|createIds|否|List| 创建人id|
|pageIndex|否|Integer||
|pageSize|否|Integer||
|orderField|否|String||
|orderSort|否|String||

### 请求参数Json格式
 
```
{
 "beginProdPlanDate" : "DateTime",
 "endProdPlanDate" : "DateTime",
 "companyId" : "String",
 "startDeliveryDate" : "DateTime",
 "endDeliveryDate" : "DateTime",
 "beginCreateDate" : "DateTime",
 "endCreateDate" : "DateTime",
 "createIds" : null,
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--pageIndex|否|Integer||
|--pageSize|否|Integer||
|--pageCount|否|Integer||
|--totalCount|否|Long||
|--first|否|Boolean||
|--last|否|Boolean||
|--content|否|List||
|----id|否|Long| 主键|
|----productionPlanNo|否|String| 单据编码|
|----status|否|Integer| 单据状态|
|----statusName|否|String| 单据状态名|
|----productionPlanDate|否|DateTime| 计划生产日|
|----totalQty|否|Double| 数量|
|----totalCostPrice|否|Double| 成本总额|
|----deliveryDate|否|DateTime| 交付日期|
|----createName|否|String| 创建人|
|----createDate|否|DateTime| 创建时间|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
