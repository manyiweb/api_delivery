# 生产看板-已下达详情

**请求URL：** 
- `/product/prodKanban/issuedDetail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|prodWorkshopId|否|Long| 生产车间|
|planItemIds|是|List| 计划明细id|
|prodKanBanPrintStatus|否|Boolean| 生产看板打印状态 false:未打印 true:已打印 null:全部|
|orderField|否|String| 排序字段|
|orderSort|否|String| 排序顺序|

### 请求参数Json格式
 
```
{
 "prodWorkshopId" : 0,
 "planItemIds" : null,
 "prodKanBanPrintStatus" : true,
 "orderField" : "String",
 "orderSort" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--planId|否|Long| 计划单id|
|--planNo|否|String| 计划单号|
|--planItemId|否|Long| 计划明细id|
|--itemId|否|String| 商品id|
|--itemCode|否|String| 商品编码|
|--itemName|否|String| 商品名称|
|--specId|否|String| 规格id|
|--skuBarcode|否|String| sku|
|--pendProdQty|否|Double| 待生产数量|
|--unit|否|String| 单位|
|--prodWorkshopId|否|Long| 生产车间id|
|--prodWorkshopName|否|String| 生产车间名称|
|--productionPlanDate|否|DateTime| 计划生产日|
|--description|否|String| 规格说明|
|--createName|否|String| 创建人|
|--prodKanBanPrintStatus|否|Boolean| 生产看板打印状态|
|--createDate|否|DateTime| 创建时间|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
