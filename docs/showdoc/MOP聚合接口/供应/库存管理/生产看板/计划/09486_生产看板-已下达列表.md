# 生产看板-已下达列表

**请求URL：** 
- `/product/prodKanban/issuedList`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|beginProdPlanDate|否|DateTime| 生产计划日-开始|
|endProdPlanDate|否|DateTime| 生产计划日-结束|
|companyId|是|String| 门店id|
|beginCreateDate|否|DateTime| 创建时间-开始|
|endCreateDate|否|DateTime| 创建时间-结束|
|createIds|否|List| 创建人id|
|pageIndex|否|Integer||
|pageSize|否|Integer||
|orderField|否|String||
|orderSort|否|String||

### 请求参数Json格式
 
```
{
 "beginProdPlanDate" : "DateTime",
 "endProdPlanDate" : "DateTime",
 "companyId" : "String",
 "beginCreateDate" : "DateTime",
 "endCreateDate" : "DateTime",
 "createIds" : null,
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String"
}
```

|----itemId|否|String| 商品id|
|----itemCode|否|String| 商品编码|
|----itemName|否|String| 商品名称|
|----specId|否|String| 规格id|
|----skuBarcode|否|String| sku|
|----quantity|否|Double| 数量|
|----unit|否|String| 单位|
|----prodWorkshopId|否|Long| 生产车间id|
|----prodWorkshopName|否|String| 生产车间名称|
|----b2bOrderCompQuantity|否|Integer| 订货门店数|
