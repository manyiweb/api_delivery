# 生产看板-已下达列表-门店订货明细

**请求URL：** 
- `/product/prodKanban/compB2bOrderDetail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|planId|是|Long| 计划单id|
|specId|是|String| 规格id|

### 请求参数Json格式
 
```
{
 "planId" : 0,
 "specId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--companyId|否|String| 门店id|
|--companyCode|否|String| 门店编码|
|--companyName|否|String| 门店名称|
|--quantity|否|Double| 数量|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "companyId" : "String",
 "companyCode" : "String",
 "companyName" : "String",
 "quantity" : 0
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
