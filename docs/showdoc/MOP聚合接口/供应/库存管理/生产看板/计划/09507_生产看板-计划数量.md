# 生产看板-计划数量

**请求URL：** 
- `/product/prodKanban/kanbanQty`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|beginProdPlanDate|否|DateTime| 生产计划日-开始|
|endProdPlanDate|否|DateTime| 生产计划日-结束|
|companyId|是|String| 门店id|

### 请求参数Json格式
 
```
{
 "beginProdPlanDate" : "DateTime",
 "endProdPlanDate" : "DateTime",
 "companyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--planQty|否|Integer| 已计划数量|
|--issuedQty|否|Integer| 已下发数量|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "planQty" : 0,
 "issuedQty" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
