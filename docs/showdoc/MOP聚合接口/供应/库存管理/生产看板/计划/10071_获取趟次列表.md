# 获取趟次列表

**请求URL：** 
- `/config/product/trip/getTripTimes`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 门店id|

### 请求参数Json格式
 
```
{
 "companyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tripTimeName|否|String| 趟次名称|
|subTripTimeList|否|List| 订单提配时间|
|--startTime|否|String| 开始时间|
|--endTime|否|String| 结束时间|


### 返回参数Json格式
 
```
{
 "tripTimeName" : "String",
 "subTripTimeList" : [{
 "startTime" : "String",
 "endTime" : "String"
 }]
}
```
