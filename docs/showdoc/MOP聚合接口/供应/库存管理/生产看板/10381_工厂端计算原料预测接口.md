# 

**请求URL：** 
- `/product/predictMaterials/list`

**请求方式：**
- ALL
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|items|是|List||
|--id|否|Long| 主键|
|--planId|否|Long| 计划单id|
|--itemId|否|String| 商品id|
|--itemCode|否|String| 商品编码|
|--itemName|否|String| 商品名称|
|--specId|否|String| 规格id|
|--skuBarcode|否|String| sku|
|--qty|否|Double| 数量|
|--unit|否|String| 单位|
|--materialUnitName|否|String| 物料单位|
|--materialUnitRate|否|Double| 物料单位换算率|
|--workshopName|否|String| 生产车间名称|
|--billId|否|String| 物料清单id|
|--productLineId|否|Long| 产品线id|
|--productLineName|否|String| 产品线名称|
|--createName|否|String| 创建人|
|--createDate|否|DateTime| 创建时间|
|--b2bOrderCompQuantity|否|Integer| 订货门店数|
