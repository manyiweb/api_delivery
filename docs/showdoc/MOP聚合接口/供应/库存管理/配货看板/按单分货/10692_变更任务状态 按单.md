# 变更任务状态 按单

**请求URL：** 
- `/b2b/picking/order/changeTaskStatus/order`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long| 拣配单分配任务id|
|status|是|Integer| 分货请求 0 - 同意分货 -1 - 拒绝分货 , 1 - 完成分货|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "status" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
