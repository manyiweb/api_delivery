# 分货详情 按单

**请求URL：** 
- `/b2b/picking/order/split/detail/order`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|splitTaskOrderId|是|Long| 分货任务关联拣配单id|

### 请求参数Json格式
 
```
{
 "splitTaskOrderId" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--companyName|否|String| 下单商户|
|--assignDate|否|DateTime| 分配时间|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "companyName" : "String",
 "assignDate" : "DateTime"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
