# 用户拣配单分配商品列表
 

**请求URL：** 
- `/b2b/picking/order/userItemTask/order`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|pageSize|否|Integer| 分页大小|
|pageNo|否|Integer| 页码|
|id|否|Long||

### 请求参数Json格式
 
```
{
 "pageSize" : 0,
 "pageNo" : 0,
 "id" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--content|否|List||
|----id|否|Long||
|----itemId|否|String| 商品id|
|----itemCode|否|String| 商品编码|
|----itemName|否|String| 商品名称|
|----specId|否|String| 规格id|
|----pendingSplitQuantity|否|Double| 待分货数量|
|----splitQuantity|否|Double| 分货数量|
|----pickingQuantity|否|Double| 拣配数量|
|----taskStatus|否|Integer| 分货状态|
|----taskStatusName|否|String| 状态名称|
|--pageSize|否|Integer||
|--pageNo|否|Integer||
|--total|否|Long||
|--totalPage|否|Integer||
|--hasNextPage|否|Boolean||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```

 "content" : [{
 "id" : 0,
 "itemId" : "String",
 "itemCode" : "String",
 "itemName" : "String",

 "splitQuantity" : 0,
 "pickingQuantity" : 0,
 "taskStatus" : 0,
 "taskStatusName" : "String"
 }],
 "pageSize" : 0,
 "pageNo" : 0,
 "total" : 0,
 "totalPage" : 0,
 "hasNextPage" : true
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
