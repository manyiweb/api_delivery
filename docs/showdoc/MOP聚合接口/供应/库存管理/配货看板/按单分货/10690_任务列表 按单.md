# 任务列表 按单

**请求URL：** 
- `/b2b/picking/order/taskOrderList`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|pageSize|否|Integer| 分页大小|
|pageNo|否|Integer| 页码|
|sword|否|String| 搜索关键字|
|companyId|否|String| 下单商户|
|orderType|否|List| 订单类型|
|createDate|否|Object| 创建时间|
|--start|否|DateTime||
|--end|否|DateTime||
|splitStatus|否|Integer| 分单状态|

### 请求参数Json格式
 
```
{
 "pageSize" : 0,
 "pageNo" : 0,
 "sword" : "String",
 "companyId" : "String",
 "orderType" : null,
 "createDate" : {
 "start" : "DateTime",
 "end" : "DateTime"
 },
 "splitStatus" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--content|否|List||
|----id|否|Long| id|
|----taskId|否|Long| 拣配单分配任务id|
|----pickingOrderNo|否|String| 拣配单号|
|----pickingOrderId|否|String| 拣配id|
|----splitStatus|否|Integer| 分货状态|
|----splitStatusName|否|String| 分货状态名称|
|----pickTypeName|否|String| 单据类型|
|--pageSize|否|Integer||
|--pageNo|否|Integer||
|--total|否|Long||
|--totalPage|否|Integer||
|--hasNextPage|否|Boolean||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "content" : [{
 "id" : 0,
 "taskId" : 0,
 "pickingOrderNo" : "String",
 "pickingOrderId" : "String",
 "splitStatus" : 0,
 "splitStatusName" : "String",
 "pickTypeName" : "String"
 }],
 "pageSize" : 0,
 "pageNo" : 0,
 "total" : 0,
 "totalPage" : 0,
 "hasNextPage" : true
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
