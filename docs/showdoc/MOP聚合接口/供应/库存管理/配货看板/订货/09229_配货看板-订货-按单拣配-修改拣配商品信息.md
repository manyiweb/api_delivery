# 配货看板-订货-按单拣配-修改拣配商品信息

**请求URL：** 
- `/b2b/need/distributionDashboard/updateB2bOrderPickingItem`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderItemId|否|String| 订货明细id|
|distributionUnit|否|String| 配货单位|
|distributionQuantity|否|Double| 配货数量|
|distributionUnitRate|否|Double| 配货单位换算率|

### 请求参数Json格式
 
```
{
 "orderItemId" : "String",
 "distributionUnit" : "String",
 "distributionQuantity" : 0,
 "distributionUnitRate" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
