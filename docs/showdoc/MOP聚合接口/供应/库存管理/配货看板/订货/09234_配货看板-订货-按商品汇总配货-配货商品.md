# 配货看板-订货-按商品汇总配货-配货商品

**请求URL：** 
- `/b2b/need/distributionDashboard/b2bOrderItemPickingItems`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderIds|否|List| 订货单id|
|orderNo|否|String| 订货单号|
|orderDocTypeNames|否|List| 单据类型|
|lineIds|否|List| 订货路线|
|companyIds|否|List| 门店id|
|itemTypefCodes|否|List| 商品分类 路径编码|
|specIds|否|List| 规格id|

### 请求参数Json格式
 
```
{
 "orderIds" : null,
 "orderNo" : "String",
 "orderDocTypeNames" : null,
 "lineIds" : null,
 "companyIds" : null,
 "itemTypefCodes" : null,
 "specIds" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--itemDispatchComps|否|List| 门店信息|
|----companyId|否|String| 门店id|
|----companyName|否|String| 门店名称|
|--itemDispatchSpecList|否|List| 规格信息|
|----compDispatchItemMap|否|Map| 门店配货商品|
|----itemId|否|String| 商品id|
|----itemCode|否|String| 商品编码|
|----itemName|否|String| 商品名称|
|----specId|否|String| 规格id|
|----skuBarcode|否|String| sku|
|----totalQuantity|否|Double| 总数量|
|----totalItemQuantity|否|Double| 单位组总数量|
|----unit|否|String| 单位|
|----itemUnit|否|String| 单位组单位|
|----unitRate|否|Double| 单位换算率|
|----unitGroups|否|List| 单位组信息|
|------unitName|否|String||
|------unitRate|否|Double||
|----pickQuantity|否|Double| 已分配数量|
|----availableQty|否|Double| 可用量|
|----availablePickQty|否|Double| 可拣配数量|
|----unPickQuantity|否|Double| 待拣配数量|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
