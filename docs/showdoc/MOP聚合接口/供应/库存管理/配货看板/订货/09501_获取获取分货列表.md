# 获取获取分货列表
 

**请求URL：** 
- `/b2b/picking/order/getPickingOrderSplitItem`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|否|String||


### 请求参数Json格式
 
```
{
 "orderId" : "String"

}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--id|否|Long||
|--pickingOrderId|否|String|拣配单id |
|--quantity|否|Double|数量 |
|--totalQuantity|否|Double|数量 |
|--pickingQuantity|否|Double|已经拣配数量 |
|--splitQuantity|否|Double|已分配数量 |
|--unit|否|String|基本单位 |
|--itemUnit|否|String|单位 |
|--specId|否|String|规格id |
|--splitBaseQuantity|否|Double|已分配数量 |
|--waitSplitQuantity|否|Double|待分配数量 |
|--companyId|否|String|门店id |
|--companyName|否|String|门店名称 |
|--companyCode|否|String|门店编码 |
|--itemCode|否|String|商品编码 |
|--specName|否|String|规格名称 |
|--itemId|否|String|商品id |
|--itemName|否|String|商品名称 |
|--skuBarCode|否|String|sku编码 |
|--pickingItemId|否|String|拣配明细id |
|--unitList|否|List||
|----itemId|否|String||
|----specId|否|String||
|----unitId|否|String||
|----unitName|否|String||
|----unitRate|否|Double||
|----costExpressFee|否|Double||
|----expressFee|否|Double||
|----isOrder|否|Object||
|----itemUnitPrice|否|Double|单位清单价 |
|----standardUnit|否|Boolean| 是否是标准单位|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
