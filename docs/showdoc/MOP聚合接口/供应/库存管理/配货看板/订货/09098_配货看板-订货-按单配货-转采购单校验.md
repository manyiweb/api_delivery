# 配货看板-订货-按单配货-转采购单校验

**请求URL：** 
- `/b2b/need/distributionDashboard/b2bOrderCoverPurchaseCheck`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderItemIds|是|List| 订货明细id|
|companyId|是|String| 当前门店id|

### 请求参数Json格式
 
```
{
 "orderItemIds" : null,
 "companyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
