# 配货看板-配货商品列表-订货-按单配货

**请求URL：** 
- `/b2b/need/distributionDashboard/b2bOrderDispatchItemList`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|batchDistribution|否|Boolean| 点击批量配货时传true，后面传false，用于清除上次生成的数据|
|orderIds|否|List| 订货单id|
|orderNo|否|String| 订货单号|
|orderDocTypeNames|否|List| 单据类型|
|lineIds|否|List| 订货路线|
|companyIds|否|List| 门店id|
|itemTypefCodes|否|List| 商品分类 路径编码|
|specIds|否|List| 规格id|
|onHandQtyLteZero|否|Boolean| 仅显示配货后库存数小于等于0的记录|
|pageIndex|否|Integer||
|pageSize|否|Integer||
|orderField|否|String||
|orderSort|否|String||

### 请求参数Json格式
 
```
{
 "batchDistribution" : true,
 "orderIds" : null,
 "orderNo" : "String",

 "onHandQtyLteZero" : true,

 "orderSort" : "String"
}
```
