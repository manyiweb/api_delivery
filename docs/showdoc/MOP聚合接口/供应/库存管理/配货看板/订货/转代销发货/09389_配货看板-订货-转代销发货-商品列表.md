# 配货看板-订货-转代销发货-商品列表

**请求URL：** 
- `/b2b/need/distributionDashboard/b2bOrdConvSuppItemLst`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|b2bToSupp|否|Boolean| 点击批量配货时传true，后面传false，用于清除上次生成的数据|
|sword|否|String| 搜索条件|
|orderIds|否|List| 订货单id|

### 请求参数Json格式
 
```
{
 "b2bToSupp" : true,
 "sword" : "String",
 "orderIds" : null
}
```
