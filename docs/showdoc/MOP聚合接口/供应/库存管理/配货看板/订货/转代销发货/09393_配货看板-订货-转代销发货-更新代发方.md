# 配货看板-订货-转代销发货-更新代发方

**请求URL：** 
- `/b2b/need/distributionDashboard/updateB2bOrdConvSuppProxyComp`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderItemId|是|String| 订货明细id|
|proxyCompanyId|是|String| 代发方id|

### 请求参数Json格式
 
```
{
 "orderItemId" : "String",
 "proxyCompanyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
