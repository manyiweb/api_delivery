# 分货
 

**请求URL：** 
- `/b2b/picking/order/splitItem`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|否|String||
|items|否|List||
|--companyId|否|String| 门店id|
|--itemId|否|String| 商品id|
|--specId|否|String| 规格id|
|--quantity|否|String| 总数|
|--orderItemId|否|String| 明细id|
|--splitQuantity|否|Double| 分货数量|
|--splitUnit|否|String| 分货单位|
|--splitRate|否|Double| 分货单位比例|

### 请求参数Json格式
 
```
{
 "orderId" : "String",
 "items" : [{
 "companyId" : "String",
 "itemId" : "String",
 "specId" : "String",
 "quantity" : "String",
 "orderItemId" : "String",
 "splitQuantity" : 0,
 "splitUnit" : "String",
 "splitRate" : 0
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
