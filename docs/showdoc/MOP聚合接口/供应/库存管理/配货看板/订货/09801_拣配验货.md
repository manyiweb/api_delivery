# 拣配验货

**请求URL：** 
- `/b2b/picking/order/inspection`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|否|String| 拣配单id|
|inspectionOrderItems|否|List| 验货明细|
|--splitId|否|Long| 分货单id|
|--quantity|否|Double| 数量|
|--unit|否|String| 单位|
|--rate|否|Double| 单位比例|

### 请求参数Json格式
 
```
{
 "orderId" : "String",
 "inspectionOrderItems" : [{
 "splitId" : 0,
 "quantity" : 0,
 "unit" : "String",
 "rate" : 0
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
