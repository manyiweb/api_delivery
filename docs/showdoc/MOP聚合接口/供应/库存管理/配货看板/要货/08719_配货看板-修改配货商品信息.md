# 配货看板-修改配货商品信息

**请求URL：** 
- `/b2b/need/distributionDashboard/updateDistributionItem`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|niId|否|String| 要货明细id|
|distributionUnit|否|String| 配货单位|
|distributionUnitRate|否|Double| 配货单位换算率，与当前的unit换算，不一定是商品的最小单位|
|distributionQuantity|否|Double| 配货数量|

### 请求参数Json格式
 
```
{
 "niId" : "String",
 "distributionUnit" : "String",
 "distributionUnitRate" : 0,
 "distributionQuantity" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
