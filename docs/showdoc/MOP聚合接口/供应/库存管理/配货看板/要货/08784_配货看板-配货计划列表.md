# 配货看板-配货计划列表

**请求URL：** 
- `/b2b/need/distributionDashboard/distributionPlanList`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|pageIndex|否|Integer||
|pageSize|否|Integer||
|orderField|否|String||
|orderSort|否|String||

### 请求参数Json格式
 
```
{
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--pageIndex|否|Integer||
|--pageSize|否|Integer||
|--pageCount|否|Integer||
|--totalCount|否|Long||
|--first|否|Boolean||
|--last|否|Boolean||
|--content|否|List||
|----id|否|Long| 主键|
|----productionPlanNo|否|String| 计划单号|
|----companyId|否|String| 门店id|
|----companyName|否|String| 门店名称|
|----type|否|Object| 单据类型|
|----typeName|否|String| 单据类型|
|----status|否|Object| 状态|
|----statusName|否|String| 状态名称|
|----companyDepartmentId|否|Long| 部门id|
|----companyDepartmentName|否|String| 部门名称|
|----productionPlanDate|否|DateTime| 计划生产日|
|----totalQty|否|Double| 数量|
|----createDate|否|DateTime| 创建时间|
|----createName|否|String| 创建人|
|----remark|否|String| 备注|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
