# 配货看板-配货商品列表

**请求URL：** 
- `/b2b/need/distributionDashboard/distributionItemList`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|batchDistribution|否|Boolean| 点击批量配货时传true，后面传false，用于清除上次生成的数据|
|needIds|否|List| 要货单id|
|needNo|否|String| 要货单号|
|companyIds|否|List| 门店id|
|typeNames|否|List| 单据类型|
|specIds|否|List| 规格id|
|startNeedDate|否|DateTime| 到货日期-开始|
|endNeedDate|否|DateTime| 到货日期-结束|
|onHandQtyLteZero|否|Boolean| 仅显示配货后库存数小于等于0的记录|
|pageIndex|否|Integer||
|pageSize|否|Integer||
|orderField|否|String||
|orderSort|否|String||

### 请求参数Json格式
 
```
{
 "batchDistribution" : true,
 "needIds" : null,
 "needNo" : "String",
 "companyIds" : null,
 "typeNames" : null,
 "specIds" : null,
 "startNeedDate" : "DateTime",
 "endNeedDate" : "DateTime",
 "onHandQtyLteZero" : true,
 "pageIndex" : 0,
 "pageSize" : 0,
 "orderField" : "String",
 "orderSort" : "String"
}
```
