# 配货看板-状态数量统计

**请求URL：** 
- `/b2b/need/distributionDashboard/distributionDashboardStatusCount`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|needDate|否|Object||
|--start|否|DateTime||
|--end|否|DateTime||
|needNo|否|String||
|typeName|否|List||
|statusList|否|List||
|status|否|String||
|createId|否|List||
|currentLevel|否|List||
|printBatchStatus|否|Integer||
|companyIds|否|List||
|joiningTraderCode|否|List||
|companyGID|否|List||
|merchantsAreafCodes|否|String||
|distributorCode|否|List||
|merchantsTypeCode|否|List||
|id|否|String||
|pageSize|否|Integer||
|pageNo|否|Integer||
|sortField|否|String||
|sortDirection|否|String||
|viewId|否|String||

```
 "needDate" : {

 "viewId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--needStatus|否|String| 状态|
|--quantity|否|Long| 数量|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
