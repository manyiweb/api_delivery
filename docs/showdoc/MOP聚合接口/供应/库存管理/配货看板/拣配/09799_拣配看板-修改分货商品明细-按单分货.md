# 拣配看板-修改分货商品明细-按单分货

**请求URL：** 
- `/b2b/pickingKanban/updatePickedDetail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|whsOutItemId|否|String| 拣货单明细id|
|currSplitQuantity|否|Double| 本次分货数量|
|currSplitUnit|否|String| 本次分货单位|
|currSplitUnitRate|否|Double| 本次分货换算率|

### 请求参数Json格式
 
```
{
 "whsOutItemId" : "String",
 "currSplitQuantity" : 0,
 "currSplitUnit" : "String",
 "currSplitUnitRate" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
