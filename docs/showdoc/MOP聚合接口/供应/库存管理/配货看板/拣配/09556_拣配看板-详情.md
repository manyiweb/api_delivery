# 拣配看板-详情

**请求URL：** 
- `/b2b/pickingKanban/getPickingDetail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|whsOutIds|是|List| 拣配单id|

### 请求参数Json格式
 
```
{
 "whsOutIds" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--itemId|否|String| 商品id|
|--itemCode|否|String| 商品编码|
|--itemName|否|String| 商品名称|
|--specId|否|String| 规格id|
|--skuBarcode|否|String| sku|
|--quantity|否|Double| 数量|
|--unit|否|String| 单位|
|--unitGroupId|否|Long| 单位组标识|
|--unitRate|否|Double| 单位换算率|
|--onPickingQuantity|否|Double| 已拣配数量|
|--unPickQuantity|否|Double| 待拣配数量|
|--unPickUnitQuantity|否|Double| 待拣配单位数量|
|--itemUnit|否|String| 单位|
|--pickTotalQuantity|否|Double| 拣配总数|
|--onHandQty|否|Double| 库存数量|
|--unitGroups|否|List| 单位组信息|
|----itemId|否|String||
|----specId|否|String||
|----unitId|否|String||
|----unitName|否|String||
|----unitRate|否|Double||
|----costExpressFee|否|Double||
|----expressFee|否|Double||
|----isOrder|否|Object||
|----itemUnitPrice|否|Double|单位清单价 |
|----DistributionPickingUnit|否|Boolean||
|----standardUnit|否|Boolean| 是否是标准单位|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
