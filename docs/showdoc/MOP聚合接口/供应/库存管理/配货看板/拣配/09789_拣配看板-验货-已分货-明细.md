# 拣配看板-验货-已分货-明细

**请求URL：** 
- `/b2b/pickingKanban/pickingInspAllocDetail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|splitIdsStr|是|String| 拣配分货ids|

### 请求参数Json格式
 
```
{
 "splitIdsStr" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--id|否|String| 主键|
|--splitIdsStr|否|String| 拣配分货ids|
|--itemId|否|String| 商品id|
|--itemCode|否|String| 商品编码|
|--itemName|否|String| 商品名称|
|--specId|否|String| 规格id|
|--skuBarcode|否|String| sku|
|--totalQty|否|Double| 总数|
|--splitBaseQuantity|否|Double| 已分货数量|
|--unit|否|String| 单位|
|--inspectionQuantity|否|Double| 验货数量|
|--inspectionUnit|否|String| 验货单位|
|--unitRate|否|Double| 验货单位换算率|
|--unitGroupId|否|Long| 单位组标识|
|--inspectionTotalQty|否|Double| 验货总数|
|--unitGroups|否|List| 单位组信息|
|----itemId|否|String||
|----specId|否|String||
|----unitId|否|String||
|----unitName|否|String||
|----unitRate|否|Double||
|----costExpressFee|否|Double||
|----expressFee|否|Double||
|----isOrder|否|Object||
|----itemUnitPrice|否|Double|单位清单价 |
|----standardUnit|否|Boolean| 是否是标准单位|
|--userId|否|String| 用户id|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
