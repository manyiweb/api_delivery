# 拣配看板-已拣货明细-按单分货

**请求URL：** 
- `/b2b/pickingKanban/pickedDetail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|whsOutId|否|String| 捡配单id|

### 请求参数Json格式
 
```
{
 "whsOutId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--whsOutItemId|否|String| 拣货单明细id|
|--whsOutId|否|String| 拣配单Id|
|--itemId|否|String| 商品id|
|--itemCode|否|String| 商品编码|
|--itemName|否|String| 商品名称|
|--specId|否|String| 规格id|
|--skuBarcode|否|String| sku|
|--quantity|否|Double| 数量|
|--unit|否|String| 单位|
|--splitBaseQuantity|否|Double| 已分货数量|
|--unSplitBaseQuantity|否|Double| 待分货数量|
|--currSplitQuantity|否|Double| 本次分货数量|
|--currSplitUnit|否|String| 本次分货单位|
|--currSplitUnitRate|否|Double| 本次分货换算率|
|--totalCurrSplitQuantity|否|Double| 分货总数|
|--unitGroups|否|List| 单位组信息|
|----itemId|否|String||
|----specId|否|String||
|----unitId|否|String||
|----unitName|否|String||
|----unitRate|否|Double||
|----costExpressFee|否|Double||
|----expressFee|否|Double||
|----isOrder|否|Object||
|----itemUnitPrice|否|Double|单位清单价 |
|----standardUnit|否|Boolean| 是否是标准单位|
|--userId|否|String| 用户id|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
