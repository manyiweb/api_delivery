# 拣配看板-分货商品汇总明细

**请求URL：** 
- `/b2b/pickingKanban/pickingAllocationDetail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|whsOutItemIds|是|String| 拣货单明细id|

### 请求参数Json格式
 
```
{
 "whsOutItemIds" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--id|否|String| 主键|
|--whsOutItemIds|否|String| 拣货单明细id|
|--companyId|否|String| 门店id|
|--companyName|否|String| 门店名称|
|--itemId|否|String| 商品id|
|--specId|否|String| 规格id|
|--quantity|否|Double| 数量|
|--unit|否|String| 单位|
|--unitGroupId|否|Long| 单位组标识|
|--unitRate|否|Double| 单位换算率|
|--totalQuantity|否|Double| 总数|
|--splitBaseQuantity|否|Double| 已分货数量|
|--pickingQuantity|否|Double| 已拣配数量|
|--unSplitBaseQuantity|否|Double| 待分货数量|
|--unSplitUnitQuantity|否|Double| 待分货数量|
|--itemUnit|否|String| 默认单位|
|--splitQuantity|否|Double| 分货数量|
|--unitGroups|否|List| 单位组信息|
|----itemId|否|String||
|----specId|否|String||
|----unitId|否|String||
|----unitName|否|String||
|----unitRate|否|Double||
|----costExpressFee|否|Double||
|----expressFee|否|Double||
|----isOrder|否|Object||
|----itemUnitPrice|否|Double|单位清单价 |
|----DistributionPickingUnit|否|Boolean||
|----standardUnit|否|Boolean| 是否是标准单位|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
