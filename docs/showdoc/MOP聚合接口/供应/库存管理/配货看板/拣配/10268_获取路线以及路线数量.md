# 获取路线以及路线数量

**请求URL：** 
- `/b2b/pickingKanban/getPickingOrderLineQuantity`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|whsOutIds|否|List| whsOutId|
|whsOutItemIds|否|List| 明细id列表|
|splitIdsStrs|否|List| 分货列表|
|wmcLineIds|否|List| 路线ids|
|splitType|否|Integer| 0 按单 1 按商品 2按门店|

### 请求参数Json格式
 
```
{
 "whsOutIds" : null,
 "whsOutItemIds" : null,
 "splitIdsStrs" : null,
 "wmcLineIds" : null,
 "splitType" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--wmcLineId|否|Long| 出库单id|
|--wmcLineName|否|String| 路线名称|
|--totalQuantity|否|Double| 总数|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "wmcLineId" : 0,
 "wmcLineName" : "String",
 "totalQuantity" : 0
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
