# 拣配看板-验货-按商品汇总-已分货-明细

**请求URL：** 
- `/b2b/pickingKanban/pickingInspItemAllocDetail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|splitIdsStr|是|String| 分货单id|
|itemId|否|String| 商品id|

### 请求参数Json格式
 
```
{
 "splitIdsStr" : "String",
 "itemId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--id|否|String| id|
|--masterSplitIdsStr|否|String| 原列表汇总分货单id|
|--splitIdsStr|否|String| 分货单id，逗号隔开|
|--companyId|否|String| 门店id|
|--companyName|否|String| 门店名称|
|--totalQuantity|否|Double| 总数|
|--splitBaseQuantity|否|Double| 已分货数量|
|--inspectionQuantity|否|Double| 本次验货数量|
|--inspectionUnit|否|String| 验货单位|
|--inspectionRate|否|Double| 验货单位换算率|
|--inspectionTotalQuantity|否|Double| 验货总数|
|--unit|否|String| 基本单位|
|--unitRate|否|Double| 单位换算率|
|--unitItem|否|String| 单位组单位|
|--unitGroups|否|List| 单位组信息|
|----itemId|否|String||
|----specId|否|String||
|----unitId|否|String||
|----unitName|否|String||
|----unitRate|否|Double||
|----costExpressFee|否|Double||
|----expressFee|否|Double||
|----isOrder|否|Object||
|----itemUnitPrice|否|Double|单位清单价 |
|----distributionPickingUnit|否|Boolean||
|----standardUnit|否|Boolean| 是否是标准单位|
|--userId|否|String| 用户id|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
