# 拣配看板-状态数量统计

**请求URL：** 
- `/b2b/pickingKanban/listCount`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|createDate|否|Object||
|--start|否|DateTime||
|--end|否|DateTime||
|whsOutNo|否|String||
|pickStatusList|否|List||
|printStatusList|否|List||
|companyIds|否|List||
|itemTypefIds|否|List||
|specIds|否|List||
|createIds|否|List||
|pickStatus|否|Integer||
|itemTypeIds|否|List||
|id|否|String||
|pageSize|否|Integer||
|pageNo|否|Integer||
|sortField|否|String||
|sortDirection|否|String||
|viewId|否|String||

### 请求参数Json格式
 
```
{
 "createDate" : {
 "start" : "DateTime",
 "end" : "DateTime"
 },
 "whsOutNo" : "String",
 "pickStatusList" : null,
 "printStatusList" : null,
 "companyIds" : null,
 "itemTypefIds" : null,
 "specIds" : null,
 "createIds" : null,
 "pickStatus" : 0,
 "itemTypeIds" : null,
 "id" : "String",
 "pageSize" : 0,
 "pageNo" : 0,
 "sortField" : "String",
 "sortDirection" : "String",
 "viewId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--pickStatus|否|Integer| 状态|
|--quantity|否|Long| 数量|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "pickStatus" : 0,
 "quantity" : 0
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
