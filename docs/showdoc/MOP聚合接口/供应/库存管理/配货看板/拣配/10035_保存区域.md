# 保存
 

**请求URL：** 
- `/config/distribution/area/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long|分货区 |
|areaCode|否|String|编码 |
|areaName|否|String|分货区名称 |
|isActive|否|Boolean|活跃状态 |
|isDefault|否|Boolean|是否默认 |
|sysChangeDate|否|DateTime|最后修改时间 |

### 请求参数Json格式
 
```
{
 "id" : 0,
 "areaCode" : "String",
 "areaName" : "String",
 "isActive" : true,
 "isDefault" : true,
 "sysChangeDate" : "DateTime"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
