# 拣配看板-分货商品汇总列表

**请求URL：** 
- `/b2b/pickingKanban/pickingAllocationItem`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|createDate|否|Object||
|--start|否|DateTime||
|--end|否|DateTime||
|whsOutNo|否|String||
|pickStatusList|否|List||
|printStatusList|否|List||
|companyIds|否|List||
|itemTypefCodes|否|List||
|specIds|否|List||
|createIds|否|List||
|pickStatus|否|String||
|itemTypeIds|否|List||
|merchantsTypeCode|否|List||

### 请求参数Json格式
 
```
{
 "createDate" : {
 "start" : "DateTime",
 "end" : "DateTime"
 },
 "whsOutNo" : "String",
 "pickStatusList" : null,
 "printStatusList" : null,
 "companyIds" : null,
 "itemTypefCodes" : null,
 "specIds" : null,
 "createIds" : null,
 "pickStatus" : "String",
 "itemTypeIds" : null,
 "merchantsTypeCode" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--pickingItemId|否|String| 拣配单商品id，多个用,隔开|
|--itemId|否|String| 商品id|
|--itemCode|否|String| 商品编码|
|--itemName|否|String| 商品名称|
|--specId|否|String| 规格id|
|--skuBarcode|否|String| sku|
|--quantity|否|Double| 数量|
|--unit|否|String| 单位|
|--totalQuantity|否|Double| 总数|
|--pickingQuantity|否|Double| 已拣配数量|
|--splitBaseQuantity|否|Double| 已分货数量|
|--onHandQty|否|Double| 库存数量|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||

 }],

}
