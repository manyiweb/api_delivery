# 拣配看板-已发货-按商品汇总-明细

**请求URL：** 
- `/b2b/pickingKanban/pickingDeliveryItemDetail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|splitIdsStr|是|String| 分货单id|
|itemId|否|String| 商品id|

### 请求参数Json格式
 
```
{
 "splitIdsStr" : "String",
 "itemId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--companyId|否|String| 门店id|
|--companyName|否|String| 门店名称|
|--totalQuantity|否|Double| 总数|
|--splitBaseQuantity|否|Double| 已分货数量|
|--deliveryQuantity|否|Double| 已发货数量|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "companyId" : "String",
 "companyName" : "String",
 "totalQuantity" : 0,
 "splitBaseQuantity" : 0,
 "deliveryQuantity" : 0
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
