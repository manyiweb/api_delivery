# 获取是否有大客户数量

**请求URL：** 
- `/b2b/picking/order/getHasDiffQuantity`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|whsOutIds|否|List| 出库单ids(pc按单时候传入)|
|whsOutItemIds|否|List| 出库明细ids(pc商品时候传入)|
|taskIds|否|List| 门店任务ids（app端传入）|

### 请求参数Json格式
 
```
{
 "whsOutIds" : null,
 "whsOutItemIds" : null,
 "taskIds" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Boolean||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : true,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
