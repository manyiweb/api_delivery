# 拣配看板-已拣货列表-按单分货

**请求URL：** 
- `/b2b/pickingKanban/pickedList`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|createDate|否|Object||
|--start|否|DateTime||
|--end|否|DateTime||
|whsOutNo|否|String||
|pickStatusList|否|List||
|printStatusList|否|List||
|companyIds|否|List||
|itemTypefCodes|否|List||
|specIds|否|List||
|createIds|否|List||
|pickStatus|否|String||
|itemTypeIds|否|List||
|merchantsTypeCode|否|List||

```
{
 "createDate" : {
 "start" : "DateTime",
 "end" : "DateTime"
 },
 "whsOutNo" : "String",
 "pickStatusList" : null,
```

|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--whsOutId|否|String| 主键|
|--whsOutNo|否|String| 单据编号|
|--whsOutStatus|否|String| 状态编码|
|--whsOutStatusName|否|String| 状态名称|
|--pickTypeName|否|String| 拣配类型名称|
|--pickTypeCode|否|String| 拣配类型编码|
|--totalQuantity|否|Double| 总数量|
|--costAmount|否|Double| 成本总额|
|--companyId|否|String| 门店商户ID|
|--companyName|否|String| 商户名称|
|--printStatus|否|Integer| 打印状态|
|--printName|否|String| 打印状态名称|
|--createName|否|String| 创建人名称|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
