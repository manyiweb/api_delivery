# 拣配看板-发货商品汇总明细

**请求URL：** 
- `/b2b/pickingKanban/getShipmentDetail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|whsOutIds|是|List| 拣配单id|
|pickStatus|否|String| 拣配状态|

### 请求参数Json格式
 
```
{
 "whsOutIds" : null,
 "pickStatus" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--itemId|否|String| 商品id|
|--itemCode|否|String| 商品编码|
|--itemName|否|String| 商品名称|
|--specId|否|String| 规格id|
|--skuBarcode|否|String| sku|
|--quantity|否|Double| 数量|
|--unit|否|String| 单位|
|--totalQuantity|否|Double| 总数|
|--onPickingQuantity|否|Double| 已拣配数量|
|--splitBaseQuantity|否|Double| 已分货数量|
|--pickingQuantity|否|Double| 已发货数量|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "itemId" : "String",
 "itemCode" : "String",
 "itemName" : "String",
 "specId" : "String",
 "skuBarcode" : "String",
 "quantity" : 0,
 "unit" : "String",
 "totalQuantity" : 0,
 "onPickingQuantity" : 0,
 "splitBaseQuantity" : 0,
 "pickingQuantity" : 0
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
