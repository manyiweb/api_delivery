# 批量接收

**请求URL：** 
- `/product/dump/batchReceive`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderItemIds|否|List| 订单id|
|remark|否|String| 备注|
|tokenId|否|String||
|items|否|List| 商品明细|
|--orderItemId|否|String| 明细id|
|--quantity|否|Double| 数量|
|--remark|否|String||

### 请求参数Json格式
 
```
{
 "orderItemIds" : null,
 "remark" : "String",
 "tokenId" : "String",
 "items" : [{
 "orderItemId" : "String",
 "quantity" : 0,
 "remark" : "String"
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
