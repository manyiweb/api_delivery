# 生产端-订单-列表
 注意: 基于店内加工单来处理

**请求URL：** 
- `/produce/order/list`

**请求方式：** 
- `POST`
- `RequestBody`


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|date|否|DateTime| 时间|
|type|否|Integer| 类型 1:待生产 2.生产完成 9.待拍照 10.生产异常|
|staffIds|否|List| 制作师傅|
|mitemType|否|List| 商品类型|
|workshopIds|否|List| 生产车间|
|tripTimeName|否|String| 趟次|
|isPrinted|否|Integer| 是否打印 0否 1是|
|pickupDeliveryTimeStart|否|String| 提配开始时间|
|pickupDeliveryTimeEnd|否|String| 提配结束时间|
|deliveryTimeSlotStart|否|String| 提货配送时间段-开始|
|deliveryTimeSlotEnd|否|String| 提货配送时间段-结束|

### 请求参数Json格式
 
```
{
 "date":"DateTime",
 "type":0,
 "staffIds":null,
 "mitemType":null,
 "workshopIds":null,
 "tripTimeName":"String",
 "isPrinted":0,
 "pickupDeliveryTimeStart":"String",
 "pickupDeliveryTimeEnd":"String",
 "deliveryTimeSlotStart":"String",
 "deliveryTimeSlotEnd":"String"
}
```
