# 分类列表

**请求URL：** 
- `服务：product-front`
- `/app/Business/getItemType `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|filterType|否|String| 类型 Stock(生产端-库存)，Receipt(生产端-收货)|
|optType|否|String||

###请求参数Json格式
 
```
{
 "filterType" : "String",
 "optType" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--ImageUrl|否|String| 图片地址|
|--OrderNo|否|String| 排序号|
|--ParentCode|否|String| 父级编码|
|--ParentId|否|String| 父级id|
|--ParentName|否|String| 父级名称|
|--TypeList|否|List| 次级分类|
|----ImageUrl|否|String| 图片地址|
|----ParentID|否|String| 父级id|
|----TypeCode|否|String| 分类编码|
|----TypeID|否|String| 分类id|
|----TypeName|否|String| 分类名称|
|----fCode|否|String| 编码|
|--fCode|否|String| 编码|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


###返回参数Json格式
 
```
{
 "data" : [{
 "ImageUrl" : "String",
 "OrderNo" : "String",
 "ParentCode" : "String",
 "ParentId" : "String",
 "ParentName" : "String",
 "TypeList" : [{
 "ImageUrl" : "String",
 "ParentID" : "String",
 "TypeCode" : "String",
 "TypeID" : "String",
 "TypeName" : "String",
 "fCode" : "String"
 }],
 "fCode" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
