# 批量领料-确认列表

**请求URL：** 
- `/product/productionPlan/pickingUpMaterialsConfirmList `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|ids|否|List| 计划单id|
|summaryLogic|否|Integer| 汇总逻辑 1-按物料汇总 2-按物料+生产车间汇总|
|outWhsId|否|String| 发货仓id|
|billMaterialsHierarchy|否|Integer| 物料清单层级 1-6|

###请求参数Json格式
 
```
{
 "ids" : null,
 "summaryLogic" : 0,
 "outWhsId" : "String",
 "billMaterialsHierarchy" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--specId|否|String| 规格id|
|--skuBarcode|否|String| sku|
|--unit|否|String| 单位|
|--qty|否|Double| 数量|
|--companyId|否|String| 门店id|
|--companyName|否|String| 门店名称|
|--workshopId|否|Long| 生产车间id|
|--workshopName|否|String| 生产车间名称|
|--billmaterialsId|否|String| 物料id|
|--billCode|否|String| 物料编码|
|--billName|否|String| 物料名称|
|--outWhsStockQty|否|Double| 出库仓库存|
|--companyStockQty|否|Double| 门店库存|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


###返回参数Json格式
 
```
{
 "data" : [{
 "specId" : "String",
 "skuBarcode" : "String",
 "unit" : "String",
 "qty" : 0,
 "companyId" : "String",
 "companyName" : "String",
 "workshopId" : 0,
 "workshopName" : "String",
 "billmaterialsId" : "String",
 "billCode" : "String",
 "billName" : "String",
 "outWhsStockQty" : 0,
 "companyStockQty" : 0
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
