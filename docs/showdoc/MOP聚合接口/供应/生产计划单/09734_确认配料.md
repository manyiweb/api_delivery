# 确认配料

**请求URL：** 
- `/product/dump/confirm/configurationMaterial`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|否|String| 订单id|
|items|否|List| 商品列表|
|--orderItemId|否|String| 调拨明细iid|
|--remark|否|String| 备注|
|--specId|否|String| 规格id|
|--itemId|否|String| 商品id|
|--unit|否|String| 单位|
|--quantity|否|Double| 数量|
|remark|否|String| 备注|

### 请求参数Json格式
 
```
{
 "orderId" : "String",
 "items" : [{
 "orderItemId" : "String",
 "remark" : "String",
 "specId" : "String",
 "itemId" : "String",
 "unit" : "String",
 "quantity" : 0
 }],
 "remark" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
