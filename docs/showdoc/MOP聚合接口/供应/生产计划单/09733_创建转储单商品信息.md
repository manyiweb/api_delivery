# 创建转储单商品信息

**请求URL：** 
- `/product/allot/createdump/specInfo`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|list|是|List|规格id|

### 请求参数Json格式
 
```
{
 "list" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--specId|否|String| 规格id|
|--itemId|否|String| 商品id|
|--itemName|否|String| 商品名称|
|--itemCode|否|String| 商品名称|
|--skuBarCode|否|String| 规格编码|
|--materialProdWorkShopId|否|Long| 配料车间id|
|--materialProdWorkShopName|否|String| 配料车间名称|
|--onHandQty|否|Double| 当前车间库存|
|--materialOnHandQty|否|Double| 领料车间库存|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "specId" : "String",
 "itemId" : "String",
 "itemName" : "String",
 "itemCode" : "String",
 "skuBarCode" : "String",
 "materialProdWorkShopId" : 0,
 "materialProdWorkShopName" : "String",
 "onHandQty" : 0,
 "materialOnHandQty" : 0
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
