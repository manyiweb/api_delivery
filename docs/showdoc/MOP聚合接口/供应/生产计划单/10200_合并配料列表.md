# 合并配料列表
 

**请求URL：** 
- `/product/productionPlan/merge/ingredient/list`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|type|否|Integer| 0当前进度详情 1 上一进度详情|
|productionPlanItemIds|否|List| 规格id|

### 请求参数Json格式
 
```
{
 "type" : 0,
 "productionPlanItemIds" : null
}
```
