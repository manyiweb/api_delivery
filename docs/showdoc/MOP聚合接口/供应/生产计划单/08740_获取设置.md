# 获取设置
 

**请求URL：** 
- `/product/productionPlan/voiceNotification/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 门店id|
|openVoiceNotification|否|Boolean| 开启语音播报|
|equipmentNo|否|String| 设备号|

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "openVoiceNotification" : true,
 "equipmentNo" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--companyId|否|String| 门店id|
|--openVoiceNotification|否|Boolean| 开启语音播报|
|--equipmentNo|否|String| 设备号|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "companyId" : "String",
 "openVoiceNotification" : true,
 "equipmentNo" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
