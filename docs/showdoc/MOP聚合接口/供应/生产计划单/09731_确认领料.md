# 确认领料

**请求URL：** 
- `/product/productionPlan/confirmMaterial`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|specId|否|String||
|remark|否|String||
|items|否|List||
|--specId|否|String| 规格id
|--quantity|否|Double||
|id|是|Long|生产计划单id|

### 请求参数Json格式
 
```
{
 "specId" : "String",
 "remark" : "String",
 "items" : [{
 "specId" : "String",
 "neededQuantity" : 0,
 "onHandQty" : 0,
 "processRate" : 0,
 "quantity" : 0
 }],
 "id" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
