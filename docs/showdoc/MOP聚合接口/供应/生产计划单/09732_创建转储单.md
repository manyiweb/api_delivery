# 创建转储单（或者是批量领料 领取原料）

**请求URL：** 
- `/product/allot/dump/create`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|否|String||
|items|否|List| 商品ids|
|--specId|否|String| 规格id|
|--itemId|否|String| 商品id|
|--materialProdWorkShopId|否|Long| 领料车间id|
|--quantity|否|Double| 数量|
|--productionOrderItemIds|否|List| 生产商品明细id|
|--unit|否|String||
|productionOrderItemIds|否|List| 生产商品明细ids|
|createType|否|Integer| 创建类型|
|circulationWorkShopId|否|Long| 扭转车间|

### 请求参数Json格式
 
```
{
 "tokenId" : "String",
 "items" : [{
 "specId" : "String",
 "itemId" : "String",
 "materialProdWorkShopId" : 0,
 "quantity" : 0,
 "productionOrderItemIds" : null,
 "unit" : "String"
 }],
 "productionOrderItemIds" : null,
 "createType" : 0,
 "circulationWorkShopId" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--orderId|否|String| 订单id|
|--orderNo|否|String| 在途数|
|--type|否|String| 类型|
|--dumpStatus|否|String| 状态|
|--dumpStatusName|否|String| 状态名称|
|--itemName|否|String| 商品名称|
|--itemCode|否|String| 商品编码|
|--skuBarCode|否|String| sku|
|--outQuantity|否|String| 转出数量|
|--receiveQuantity|否|String| 实际接收数量|
|--fromWorkShopName|否|String| 从工作车间名称|
|--toWorkShopName|否|String| 到工作车间名称|
|--orderItemId|否|String| 订单id|
|--invQuantity|否|Double| 订单id|
|--imageUrlFull|否|String| 图片|
|--itemId|否|String||
|--specId|否|String||
|--unit|否|String||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
