# 生产计划单-生产收货

**请求URL：** 
- `/product/productionPlan/receiving`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long| 生产计划单id|
|items|是|List| 商品明细|
|--productionPlanItemId|是|Long| 生产计划单明细ID|
|--receivingQty|是|Double| 收货数量|
|inStoreMachiningIds|否|List| 收货批量新增的店内加工单|
|inStoreMachiningReq|否|Object||
|--producerIds|否|List| 制作师Id（sysstaffgroup）|
|--productionLineId|是|Long| 生产线|
|--remark|否|String| 备注|
|--itemList|是|List| bom商品项|
|----itemId|是|String| 商品id|
|----specId|是|String| 商品规格id|
|----bomId|是|String| bomId|
|----quantity|是|Double| 收货数量|
|----items|否|List| 商品信息|
|------itemId|是|String||
|------specId|是|String||
|------quantity|否|Double||
|------remark|否|String||
|------billmaterialsItemId|否|String||
|--supplierId|否|String| 供应商id|
|--shippingMaterials|否|Boolean| 启用子物料库存不足时，先收货后发料|
|requestParams|否|Map||

### 请求参数Json格式
 
```
{
 "id" : 0,
 "producerId" : "String",
 "items" : [{
 "productionPlanItemId" : 0,
 "receivingQty" : 0
 }],
 "inStoreMachiningIds" : null,
 "inStoreMachiningReq" : {
 "productionLineId" : 0,
 "remark" : "String",
 "itemList" : [{
 "itemId" : "String",
 "specId" : "String",
 "bomId" : "String",
 "quantity" : 0,
 "items" : [{
 "itemId" : "String",
 "specId" : "String",
 "quantity" : 0,
 "remark" : "String",
 "billmaterialsItemId" : "String"
 }]
 }],
 "supplierId" : "String",
 "shippingMaterials" : true
 },
 "requestParams" : null
}
```

|参数名|必选|类型|说明|

|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
