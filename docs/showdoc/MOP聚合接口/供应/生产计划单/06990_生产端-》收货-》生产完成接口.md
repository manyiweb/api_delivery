# 生产端-》收货-》生产完成接口

**请求URL：** 
- `/product/inStoreMachining/receiving/finish`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|bomId|是|String| bomId|
|receiveQty|是|Double| 收货数量（包括了破损出库数量）|
|lossQty|否|Double| 破损出库数量|
|remark|否|String| 备注|
|productionLineId|是|Long| 生产线|
|producerIds|否|List| 制作师Id（sysstaffgroup）|
|shippingMaterials|否|Boolean| 启用子物料库存不足时，先收货后发料|
|needFinishInStoreOrder|否|Boolean| 是否需要将店内加工单状态变为已完成|
|orderType|否|Integer| 0 生产收货 1.订单 2、生产计划|
|attachmentIds|否|List| 附件id|
|addItems|否|List| 添加商品明细|
|--billmaterialsItemId|否|String| 物料明细id|
|--itemId|否|String| 商品id|
|--specId|否|String| 规格id|
|--quantity|否|Double| 数量|

### 请求参数Json格式
 
```
{
 "bomId" : "String",
 "receiveQty" : 0,
 "lossQty" : 0,
 "remark" : "String",
 "productionLineId" : 0,
 "producerIds" : null,
 "shippingMaterials" : true,
 "needFinishInStoreOrder" : true,
 "orderType" : 0,
 "attachmentIds" : null,
 "addItems" : [{
 "billmaterialsItemId" : "String",
 "itemId" : "String",
 "specId" : "String",
 "quantity" : 0
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "id" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
