# 生产计划单-保存

**请求URL：** 
- `/product/productionPlan/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 生产计划单id|
|saveType|是|Integer| 保存类型 0草稿，1新增|
|productionWorkshopId|否|Long| 生产车间id|
|companyDepartmentId|否|Long| 部门id|
|productionPlanDate|是|DateTime| 计划生产日|
|companyId|否|String| 商户Id|
|remark|否|String| 备注|
|prodTimeRange|是|String| 生产时间段|
|items|是|List| 商品明细|
|--specId|是|String| 规格ID|
|--unit|否|String| 单位|
|--qty|是|Double| 数量|
|--receivingQty|否|Double| 收货数量|
|--remark|否|String| 备注|
|--billId|否|String| 物料清单id|
|--lineNum|否|Integer| 排序号|
|--perPotAmount|否|Double| 单锅用量|
|--isAddOrder|否|Boolean| 是否加单|
|--addOrderQty|否|Double| 加单数量|
|--b2bOrderQty|否|Double| 订货数量|
|newProductionWorkshopId|否|Long| 新版工作车间id|
|newProductionWorkshopName|否|String| 新版工作车间|
|newProductionWorkshopCode|否|String| 新版工作车间|
|isAddOrder|否|Boolean| 是否加单|
|planType|否|Integer| 计划单类型 0 原计划单 1预生产|
