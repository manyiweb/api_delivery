# 获取计划单对应的店内加工单附件

**请求URL：** 
- `/product/inStoreMachining/getPlanInStoreMachiningAttachment `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|planId|否|Long| 计划单id|
|specId|否|String| 规格id|

###请求参数Json格式
 
```
{
 "planId" : 0,
 "specId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--attachmentId|否|String| 主键标识|
|--fileName|否|String| 文件名称|
|--fileSize|否|Long| 文件大小|
|--fileUrl|否|String| 文件路径|
|--fileFullUrl|否|String| 文件完整路径|
|--fileOrgName|否|String| 文件原名|
|--fileSuffix|否|String| 文件后缀名|
|--sourceId|否|String| 来源单据ID|
|--sourceTable|否|String| 来源单据所属表|
|--companyId|否|String| 门店商户ID，与商户表syscompany相关联|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


###返回参数Json格式
 
```
{
 "data" : [{
 "attachmentId" : "String",
 "fileName" : "String",
 "fileSize" : 0,
 "fileUrl" : "String",
 "fileFullUrl" : "String",
 "fileOrgName" : "String",
 "fileSuffix" : "String",
 "sourceId" : "String",
 "sourceTable" : "String",
 "companyId" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
