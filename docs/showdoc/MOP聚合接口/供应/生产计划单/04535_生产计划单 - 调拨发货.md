# 生产计划单 - 调拨发货

**请求URL：** 
- `/product/productionPlan/allot/order/whsout `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 生产计划单id|
|items|否|List| 商品明细|
|--productionPlanItemId|否|Long| 生产计划单明细ID|
|--receivingQty|否|Double| 收货数量|
|inStoreMachiningIds|否|List| 收货批量新增的店内加工单|
|inStoreMachiningReq|否|Object||
|--productionLineId|否|Long| 生产线|
|--remark|否|String| 备注|
|--itemList|否|List| bom商品项|
|----itemId|否|String| 商品id|
|----specId|否|String| 商品规格id|
|----bomId|否|String| bomId|
|----quantity|否|Double| 收货数量|
|----items|否|List| 商品信息|
|------itemId|否|String| 商品id|
|------specId|否|String| 商品规格id|
|------quantity|否|Double| 计划数量|
|------remark|否|String| 备注|
|------billmaterialsItemId|否|String| 物料明细ID，与billmaterialsitem关联|
|--supplierId|否|String| 供应商id|
|requestParams|否|Map||

###请求参数Json格式
 
```
{
 "id" : 0,
 "items" : [{
 "productionPlanItemId" : 0,
 "receivingQty" : 0
 }],
 "inStoreMachiningIds" : null,
 "inStoreMachiningReq" : {
 "productionLineId" : 0,
 "remark" : "String",
 "itemList" : [{
 "itemId" : "String",
 "specId" : "String",
 "bomId" : "String",
 "quantity" : 0,
 "items" : [{
 "itemId" : "String",
 "specId" : "String",
 "quantity" : 0,
 "remark" : "String",
 "billmaterialsItemId" : "String"
 }]
 }],
 "supplierId" : "String"
 },
 "requestParams" : null
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",

}
```
