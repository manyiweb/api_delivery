# 生产车间字段

生产车间列表返回的参数

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long| 计划单id|
|--productionPlanNo|否|String| 计划单号|
|--itemId|否|String| 商品id|
|--itemCode|否|String| 商品编码|
|--itemName|否|String| 商品名称|
|--specId|否|String| 规格id|
|--skuBarcode|否|String| sku|
|--qty|否|Double| 计划数量|
|--receivingQty|否|Double| 收货数量|
|--itemImage|否|String| 图片|
|--createName|否|String| 创建人名称|
|--remark|否|String| 备注|
|--unit|否|String| 单位|
|--attachmentQty|否|Integer| 附件数量|
|--colourName|否|String| 规格一名称|
|--sizeName|否|String| 规格二名称|
|--prodTimeRange|否|String| 生产时间段|
|--deliveryRemark|否|String| 收货备注|
|--receiveQuantity|否|Double| 收货数量|
|--dumpQuantity|否|Double| 转储数量|
|--waitReceiveQuantity|否|Double| 待收货数量|
|--waitDumpQuantity|否|Double| 待转储数量|
|--dumpStatus|否|Integer| 转储状态|
|--splitOrderStatus|否|Integer| 拆单状态 1已下推(主单)，2下推子单|
|--invQuantity|否|Double||
|--productionPlanItemId|否|Long||
|--preWorkShopProcessRate|否|Double| 上一车间制作进度|
|--workShopProcessRate|否|Double| 当前车间备货进度|
|--materialStatus|否|Integer|领料状态0未领料1 已领料|
|--materialStatusName|否|String|领料状态|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
