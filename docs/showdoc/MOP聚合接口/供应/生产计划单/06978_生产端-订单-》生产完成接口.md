# 生产端-订单-》生产完成接口
 时间紧急，不新出了，直接套用一下

**请求URL：** 
- `/product/inStoreMachining/produce/receipt/finish`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|planId|是|Long| 计划单Id|
|remark|否|String| 备注|
|producerIds|否|List| 制作师Id（sysstaffgroup）|
|productionLineId|否|Long| 生产线id|
|shippingMaterials|否|Boolean| 启用子物料库存不足时，先收货后发料|
|needFinishInStoreOrder|否|Boolean| 是否需要将店内加工单状态变为已完成|
|receiveQty|否|Double| 收货数量（包括了破损出库数量）|
|lossQty|否|Double| 破损出库数量|
|productionType|否|Integer| 生产类型 0生产配送 1仅生产|
|specId|否|String| 规格id|
|orderType|否|Integer||
|attachmentIds|否|List| 附件id|
|addItems|否|List| 店内加工单商品明细
|--billmaterialsItemId|否|String| 物料明细id|
|--itemId|否|String| 商品id|
|--specId|否|String| 规格id|
|--quantity|否|Double| 数量|

### 请求参数Json格式
 
```
{
 "planId" : 0,
 "remark" : "String",
 "producerIds" : null,
 "productionLineId" : 0,
 "shippingMaterials" : true,
 "needFinishInStoreOrder" : true,
 "receiveQty" : 0,
 "lossQty" : 0,
 "productionType" : 0,
 "specId" : "String",
 "orderType" : 0,
 "attachmentIds" : null,
 "addItems" : [{
 "billmaterialsItemId" : "String",
 "itemId" : "String",
 "specId" : "String",
 "quantity" : 0
 }]
}
```

|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
