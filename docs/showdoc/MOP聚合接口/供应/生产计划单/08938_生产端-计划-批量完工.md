# 生产端-计划-批量完工

**请求URL：** 
- `/product/inStoreMachining/produce/plan/batch/finish`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|planInfos|是|List| 计划单Id|
|--planId|是|Long| 计划单id|
|--receiveQty|否|Double| 收货数量（包括了破损出库数量）|
|--lossQty|否|Double| 破损出库数量|
|remark|否|String| 备注|
|producerIds|否|List| 制作师Id（sysstaffgroup）|
|productionLineId|否|Long| 生产线id|
|shippingMaterials|否|Boolean| 启用子物料库存不足时，先收货后发料|
|needFinishInStoreOrder|否|Boolean| 是否需要将店内加工单状态变为已完成|
|productionType|否|Integer| 生产类型 0生产配送 1仅生产|
|specId|否|String| 规格id|
|orderType|否|Integer| 订单类型|
|attachmentIds|否|List| 附件id|

### 请求参数Json格式
 
```
{
 "planInfos" : [{
 "planId" : 0,
 "receiveQty" : 0,
 "lossQty" : 0
 }],
 "remark" : "String",
 "producerIds" : null,
 "productionLineId" : 0,
 "shippingMaterials" : true,
 "needFinishInStoreOrder" : true,
 "productionType" : 0,
 "specId" : "String",
 "orderType" : 0,
 "attachmentIds" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
