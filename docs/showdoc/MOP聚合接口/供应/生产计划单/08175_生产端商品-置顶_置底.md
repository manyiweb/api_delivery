# 生产端商品-置顶/置底

**请求URL：** 
- `/produce/item/topOrBottomSort `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|sortType|否|Integer| 排序类型 1:置顶 2:置底|
|companyId|否|String| 门店id|
|itemId|否|String| 商品id|
|specId|否|String| 规格id|

###请求参数Json格式
 
```
{
 "sortType" : 0,
 "companyId" : "String",
 "itemId" : "String",
 "specId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
