# 转出单列表

**请求URL：** 
- `/product/allot/dump/list`

**请求方式：** 
- `POST`
- `RequestBody`


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|dumpStatus|否|List| 生产计划单状态|
|date|否|DateTime| 日期|
|newWorkShopId|否|Long| 新生产车间id|
|type|否|Integer| 类型0转入1转|
|orderId|否|String| 订单id|
|orderItemId|否|String||
|productLine|否|List| 产品线|

### 请求参数Json格式
 
```
{
 "dumpStatus":null,
 "date":"DateTime",
 "newWorkShopId":0,
 "type":0,
 "orderId":"String",
 "orderItemId":"String",
 "productLine":null
}
```

### 响应参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--orderId|否|String| 订单id|
|--orderNo|否|String| 在途数|
|--imageUrl|否|String| 在途数|
|--unit|否|String| 在途数|
|--type|否|String| 类型|
|--dumpStatus|否|Integer| 状态|
|--dumpStatusName|否|String| 状态名称|
|--itemName|否|String| 商品名称|
|--itemCode|否|String| 商品编码|
|--skuBarCode|否|String| sku|
|--outQuantity|否|String| 转出数量|
|--receiveQuantity|否|String| 实际接收数量|
|--fromWorkShopName|否|String| 从工作车间名称|
|--toWorkShopName|否|String| 到工作车间名称|
|--orderItemId|否|String| 订单id|
|--itemUnit|否|String| 单位组|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
