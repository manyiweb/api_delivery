# 批量领料-调拨

**请求URL：** 
- `/product/productionPlan/pickingUpMaterialsAllot `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|summaryLogic|否|Integer| 汇总逻辑 1-按物料汇总 2-按物料+生产车间汇总|
|ids|否|List| 计划单id|
|pickingUpMaterialsAllotItems|否|List| 商品明细|
|--specId|否|String| 规格id|
|--unit|否|String| 单位|
|--qty|否|Double| 数量|
|--companyId|否|String| 门店id|
|--workshopId|否|Long| 生产车间id|
|outWhsId|否|String| 发料仓库id|
|arrivedDate|否|DateTime| 到货日期|

###请求参数Json格式
 
```
{
 "summaryLogic" : 0,
 "ids" : null,
 "pickingUpMaterialsAllotItems" : [{
 "specId" : "String",
 "unit" : "String",
 "qty" : 0,
 "companyId" : "String",
 "workshopId" : 0
 }],
 "outWhsId" : "String",
 "arrivedDate" : "DateTime"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
