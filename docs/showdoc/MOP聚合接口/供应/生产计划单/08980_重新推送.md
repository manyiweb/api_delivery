# 重新推送
 生产端重新处理调拨流程

**请求URL：** 
- `/produce/order/reProductInStoreMachineAllot`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|date|是|DateTime| 时间|
|docType|是|String| Plan("计划"),Order("订单"),Receipt("收货")|

### 请求参数Json格式
 
```
{
 "date" : "DateTime",
 "docType" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
