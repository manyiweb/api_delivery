# 订单-计划物料-列表

**请求URL：** 
- `/produce/order/plan/materials/list`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|planId|是|Long| 计划单id|
|billMaterialsId|是|String| 物料id|
|companyId|是|String| 门店id|

### 请求参数Json格式
 
```
{
 "planId" : 0,
 "billMaterialsId" : "String",
 "companyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--id|否|Long| 主键|
|--planId|否|Long| 计划单id，与表production_plan关联|
|--billMaterialsId|否|String| 物料清单id|
|--billMaterialsItemId|否|String| 物料清单明细id|
|--itemId|否|String| 商品id|
|--itemCode|否|String| 商品编码|
|--itemName|否|String| 商品名称|
|--specId|否|String| 规格id|
|--skuBarcode|否|String| sku|
|--specName|否|String| 规格名称|
|--quantity|否|Double| 数量|
|--hasReplaceItem|否|Boolean| 是否有替代商品|
|--imageUrlFull|否|String| 图片地址|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "id" : 0,
 "planId" : 0,
 "billMaterialsId" : "String",
 "billMaterialsItemId" : "String",
 "itemId" : "String",
 "itemCode" : "String",
 "itemName" : "String",
 "specId" : "String",
 "skuBarcode" : "String",
 "specName" : "String",
 "quantity" : 0,
 "hasReplaceItem" : true,
 "imageUrlFull" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
