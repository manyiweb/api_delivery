# 生产端商品-计划列表-批量更新配料状态

**请求URL：** 
- `/produce/item/batchUpdateStatus`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|items|是|List||
|--planId|否|Long| 生产计划单id|
|--specId|否|String| 规格ID|
|--isIngredient|否|Integer| 是否配料 0 取消配料 1配料中|

### 请求参数Json格式
 
```
{
 "items" : [{
 "planId" : 0,
 "specId" : "String",
 "isIngredient" : 0
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
