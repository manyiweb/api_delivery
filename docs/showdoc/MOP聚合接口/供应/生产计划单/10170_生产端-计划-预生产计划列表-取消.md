# 生产端-计划-预生产计划列表-取消

**请求URL：** 
- `/produce/item/cancelPreProdPlan`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|planId|是|Long| 计划单id|
|planItemId|是|Long| 计划明细id|

### 请求参数Json格式
 
```
{
 "planId" : 0,
 "planItemId" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
