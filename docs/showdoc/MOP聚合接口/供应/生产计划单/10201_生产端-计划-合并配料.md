# 生产端-计划-合并配料

**请求URL：** 
- `/product/inStoreMachining/produce/plan/merge/ingredient`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderItemIds|否|List| 计划单Id|
|remark|否|String| 备注|
|producerIds|否|List| 制作师Id（sysstaffgroup）|
|productionLineId|否|Long| 生产线id|
|shippingMaterials|否|Boolean| 启用子物料库存不足时，先收货后发料|
|needFinishInStoreOrder|否|Boolean| 是否需要将店内加工单状态变为已完成|
|productionType|否|Integer| 生产类型 0生产配送 1仅生产|
|specId|否|String| 规格id|
|orderType|否|Integer| 订单类型|
|attachmentIds|否|List| 附件id|

### 请求参数Json格式
 
```
{
 "orderItemIds" : null,
 "remark" : "String",
 "producerIds" : null,
 "productionLineId" : 0,
 "shippingMaterials" : true,
 "needFinishInStoreOrder" : true,
 "productionType" : 0,
 "specId" : "String",
 "orderType" : 0,
 "attachmentIds" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
