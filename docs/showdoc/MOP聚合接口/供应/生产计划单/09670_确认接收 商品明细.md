# 确认接收 商品明细

**请求URL：** 
- `/product/allot/dump/info`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|newWorkShopId|否|Long| 新生产车间id|
|orderId|否|String| 订单id|


### 请求参数Json格式
 
```
{
 "newWorkShopId" : 0,
 "orderId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--orderId|否|String| 订单id|
|--orderNo|否|String| 在途数|
|--type|否|String| 类型|
|--dumpStatus|否|String| 状态|
|--dumpStatusName|否|String| 状态名称|
|--itemName|否|String| 商品名称|
|--itemCode|否|String| 商品编码|
|--skuBarCode|否|String| sku|
|--outQuantity|否|String| 转出数量|
|--receiveQuantity|否|String| 实际接收数量|
|--fromWorkShopName|否|String| 从工作车间名称|
|--toWorkShopName|否|String| 到工作车间名称|
|--orderItemId|否|String| 订单id|
|--invQuantity|否|Double| 订单id|
|--imageUrlFull|否|String| 图片|
|--itemId|否|String||
|--specId|否|String||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
