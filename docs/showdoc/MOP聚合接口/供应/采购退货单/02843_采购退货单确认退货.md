# 采购退货单确认退货

**请求URL：** 
- `/b2b/purchaseReturn/confirm `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|否|String| 单据ID|
|status|否|String| 	受理状态，取值：YT - 已完成|
|remark|否|String| 受理备注|
|itemList|否|List||
|--purchaseReturnItemId|否|String| 单据明细行ID|
|--quantity|否|Double| 数量|
|--batchList|否|List| 批次信息|
|----batchCode|否|String| 批次号|
|----productionDate|否|DateTime| 生产日期|
|----validDays|否|Integer| 保质期|
|----quantity|否|Double| 数量|
|--barcodes|否|List| 商品唯一码|

###请求参数Json格式
 
```
{
 "orderId" : "String",
 "status" : "String",
 "remark" : "String",
 "itemList" : [{
 "purchaseReturnItemId" : "String",
 "quantity" : 0,
 "batchList" : [{
 "batchCode" : "String",
 "productionDate" : "DateTime",
 "validDays" : 0,
 "quantity" : 0
 }],
 "barcodes" : null
 }]
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
