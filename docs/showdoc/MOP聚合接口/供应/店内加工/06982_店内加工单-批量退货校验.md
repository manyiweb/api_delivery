# 店内加工单-批量退货校验

**请求URL：** 
- `/product/inStoreMachining/refund/check `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 门店id|
|ids|否|List| 店内加工单id|

###请求参数Json格式
 
```
{
 "companyId" : "String",
 "ids" : null
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--errorMessages|否|List| 异常信息集合|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


###返回参数Json格式
 
```
{
 "data" : {
 "errorMessages" : null
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
