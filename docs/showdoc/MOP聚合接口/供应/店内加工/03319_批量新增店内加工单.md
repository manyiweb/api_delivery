# 

**请求URL：** 
- `/product/inStoreMachining/saveBatch `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|productionLineId|否|Long| 生产线|
|remark|否|String| 备注|
|itemList|否|List| bom商品项|
|--itemId|否|String| 商品id|
|--specId|否|String| 商品规格id|
|--bomId|否|String| bomId|
|--quantity|否|Double| 收货数量|
|--items|否|List| 商品信息|
|----itemId|否|String| 商品id|
|----specId|否|String| 商品规格id|
|----quantity|否|Double| 计划数量|
|----remark|否|String| 备注|
|----billmaterialsItemId|否|String| 物料明细ID，与billmaterialsitem关联|
|supplierId|否|String| 供应商id|
|shippingMaterials|否|boolean| 启用子物料库存不足时，先收货后发料 true(启用),false(不启用)|

###请求参数Json格式
 
```
{
 "productionLineId" : 0,
 "remark" : "String",
 "itemList" : [{
 "itemId" : "String",
 "specId" : "String",
 "bomId" : "String",
 "quantity" : 0,
 "items" : [{
 "itemId" : "String",
 "specId" : "String",
 "quantity" : 0,
 "remark" : "String",
 "billmaterialsItemId" : "String"
 }]
 }],
 "supplierId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--isTask|否|Boolean| 是否任务模式|
|--itemNames|否|List| 库存不足商品列表|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "isTask" : true,
 "itemNames" : null
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
