# 生产退货
 

**请求URL：** 
- `/product/inStoreMachining/refund `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long| id 单据id|
|items|是|List| 商品信息|
|--inStoreMachiningItemId|是|Long| 明细id|
|--quantity|是|Double| 退货数量|
|--type|是|Integer| 物料类型 0 - 发料, 1 - 成品 |
|--remark|否|String| 备注|

###请求参数Json格式
 
```
{
 "id" : 0,
 "items" : [{
 "inStoreMachiningItemId" : 0,
 "quantity" : 0,
 "remark" : "String"
 }]
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long| id|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : {
 "id" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
