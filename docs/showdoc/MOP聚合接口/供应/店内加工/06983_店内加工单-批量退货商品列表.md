# 店内加工单-批量退货商品列表

**请求URL：** 
- `/product/inStoreMachining/refund/item/list `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|ids|否|List| 店内加工单退货明细集合|

###请求参数Json格式
 
```
{
 "ids" : null
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--id|否|Long| id|
|--orderNo|否|String| 店内加工单单号|
|--orderStatusCode|否|String| 单据状态编码|
|--orderStatusName|否|String| 单据状态名称|
|--itemId|否|String| 商品id|
|--itemCode|否|String| 商品编码|
|--itemName|否|String| 商品名称|
|--specId|否|String| 商品规格id|
|--skuBarcode|否|String| sku码|
|--specName|否|String| 商品规格名称|
|--quantity|否|Double| 计划数量|
|--reQuantity|否|Double| 收货数量|
|--refundQuantity|否|Double| 已退数量|
|--unit|否|String| 单位|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||

 }],
