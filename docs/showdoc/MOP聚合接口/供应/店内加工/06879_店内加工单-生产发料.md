# 店内加工单-生产发料

**请求URL：** 
- `/product/inStoreMachining/materialIssuance `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id 单据id|
|remark|否|String| 备注|
|items|否|List| 发料商品信息|
|--inStoreMachiningItemId|否|Long| 明细id|
|--quantity|否|Double| 发料数量|
|--remark|否|String| 备注|

###请求参数Json格式
 
```
{
 "id" : 0,
 "remark" : "String",
 "items" : [{
 "inStoreMachiningItemId" : 0,
 "quantity" : 0,
 "remark" : "String"
 }]
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


###返回参数Json格式
 
```
{
 "data" : {
 "id" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
