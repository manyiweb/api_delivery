# 店内加工单-批量发料

**请求URL：** 
- `/product/inStoreMachining/batch/materialIssuance `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|ids|否|List| 订单id集合|

###请求参数Json格式
 
```
{
 "ids" : null
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--totalMaterialIssuanceQuantity|否|Integer| 总发料数量|
|--successQuantity|否|Integer| 发料成功数量|
|--failQuantity|否|Integer| 发料失败数量|
|--failMsg|否|List| 发料失败信息|
|--fileOrderNo|否|List| 发料失败单号|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


###返回参数Json格式
 
```
{
 "data" : {
 "totalMaterialIssuanceQuantity" : 0,
 "successQuantity" : 0,
 "failQuantity" : 0,
 "failMsg" : null,
 "fileOrderNo" : null
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
