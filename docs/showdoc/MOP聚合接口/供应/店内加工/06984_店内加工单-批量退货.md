# 店内加工单-批量退货

**请求URL：** 
- `/product/inStoreMachining/batch/refund `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|detailReqs|否|List| 店内加工单退货明细集合|
|--id|否|Long| 店内加工单id|
|--quantity|否|Double| 退货数量|
|--remark|否|String| 备注|

###请求参数Json格式
 
```
{
 "detailReqs" : [{
 "id" : 0,
 "quantity" : 0,
 "remark" : "String"
 }]
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--errorMessages|否|List| 异常信息|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


###返回参数Json格式
 
```
{
 "data" : {
 "errorMessages" : null
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
