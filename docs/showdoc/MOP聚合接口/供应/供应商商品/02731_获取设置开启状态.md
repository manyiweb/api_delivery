# 获取设置状态
 

**请求URL：** 
- `/b2b/supplier/product/status/get `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|supplierId|否|String| 供应商品ID|

###请求参数Json格式
 
```
{
 "supplierId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--status|否|Integer| 是否开启按供应商设置商品，取值： 0 - 否； 1 - 是|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : {
 "status" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
