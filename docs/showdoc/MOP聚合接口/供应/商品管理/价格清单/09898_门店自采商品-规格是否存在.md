# 门店自采商品-规格是否存在

**请求URL：** 
- `/product/compSelfPurchasedItem/specExists`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|specIds|是|List| 规格id|
|companyId|是|String| 门店id|

### 请求参数Json格式
 
```
{
 "specIds": [
 "95db06814dd34ca285f4378418d706d7",
 "5dd1a89b6dcb43909fc2dc9d60bb663e"
 ],
 "companyId": "3c0cd88a2b3347e9bf72c34d8f2b5cd6",
 "tokenId": "06911b1366714cc38810043b42c3521a"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Map||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "code": "200",
 "data": {
 "95db06814dd34ca285f4378418d706d7": 1,
 "5dd1a89b6dcb43909fc2dc9d60bb663e": 1
 },
 "exceptionStackInfo": "",
 "msg": "",
 "success": true,
 "traceId": ""
}
```
