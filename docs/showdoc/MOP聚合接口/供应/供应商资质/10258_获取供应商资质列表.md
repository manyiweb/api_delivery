# 获取供应商资质列表
 

**请求URL：** 
- `/api/b2b/supplier/certification/list/{supplierId}`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|supplierId|否|String|供应商 ID |

### 请求参数Json格式
 
```
{
 "supplierId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--id|否|Long||
|--certType|否|Enum| 资质类型|
|--certTypeName|否|String| 资质类型|
|--certTypeCode|否|String| 资质类型编码 BUSINESS_LICENSE，FOOD_OPERATION_LICENSE，CATERING_SERVICE_LICENSE，PRODUCTION_LICENSE，HEALTH_LICENSE，OTHER|
|--certFilePath|否|String| 资质文件路径|
|--certFileName|否|String| 资质文件名称|
|--certExpiryDate|否|DateTime| 资质有效期|
|--certStatusCode|否|String| 资质状态 EXPIRED,AVAILABLE|
|--certStatusName|否|String| 资质状态名称 已过期，生效中|
|--remark|否|String| 备注|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "id" : 0,
 "certType" : 0,
 "certTypeName" : "String",
 "certTypeCode" : "String",
 "certFilePath" : "String",
 "certFileName" : "String",
 "certExpiryDate" : "DateTime",
 "certStatusCode" : "String",
 "certStatusName" : "String",
 "remark" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
