# 列表-企微企业列表

**请求URL：** 
- `/hr/work/weixin/corp/list`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|bindingStatus|是|List| 企业绑定状态：1-未绑定品牌;2-已绑定品牌;|

### 请求参数Json格式
 
```
{
 "bindingStatus" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--corpId|否|String| 企微企业id|
|--corpName|否|String| 企微企业名称|
|--bindingStatus|否|Integer| 绑定状态：1-未绑定品牌;2-已绑定品牌;|
|--groupId|否|String| 品牌id|
|--groupCode|否|String| 品牌编码|
|--groupName|否|String| 品牌名称|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : [{
 "corpId" : "String",
 "corpName" : "String",
 "bindingStatus" : 0,
 "groupId" : "String",
 "groupCode" : "String",
 "groupName" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
