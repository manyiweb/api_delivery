# 读取定时踢出在线用户设置
 

**请求URL：** 
- `/reabam-manage/app/online/control/getKickOutScheduleSetting`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
无参数


### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--enable|是|Boolean| 是否启用|
|--triggerTime|否|String| 触发时间|
|--sysNoSet|否|List| 踢出的平台号列表|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : {
 "enable" : true,
 "triggerTime" : "String",
 "sysNoSet" : null
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
