# 在线用户导出

**请求URL：** 
- `/app/online/control/listOnlineUsers/export`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|keyword|否|String| 关键字|
|sysNoSet|否|List| 登录端 checkstand,merchant,guide,mgd|
|companyIdSet|否|List| 当前商户|
|pageSize|否|Integer| 分页大小|
|pageIndex|否|Integer| 分页页码|
|sortField|否|String| 排序字段|
|sortDirection|否|Object| 排序方向|

### 请求参数Json格式
 
```
{
 "keyword" : "String",
 "sysNoSet" : null,
 "companyIdSet" : null,
 "pageSize" : 0,
 "pageIndex" : 0,
 "sortField" : "String",
 "sortDirection" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
