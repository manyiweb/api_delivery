# 上报购物车加购记录

**请求URL：** 
- `/shoppingCart/itemAdd`

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|specId|否|String| 商品specId|
|price|否|Double| 商品价钱|
|type|否|Integer| 购物车类型(0零售,1订货)|
|companyId|否|String| 门店|

###请求参数Json格式
 
```
{
 "specId" : "String",
 "price" : 0,
 "type" : 0,
 "companyId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|String| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : "String",
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
