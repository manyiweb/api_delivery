# 上报小程序访问记录

**请求URL：** 
- `/mini/visitMini`

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|是|String| tokenID,用户标识|
|wxSn|是|String| 微信小程序id|
|groupId|是|String| 品牌id|
|type|是|Integer| 小程序类型0零售1订货|
|companyId|是|String| 门店|

###请求参数Json格式
 
```
{
 "tokenId" : "String",
 "wxSn" : "String",
 "groupId" : "String",
 "type" : 0,
 "companyId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|String| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : "String",
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
