# 获取大陆银行城市列表

**请求URL：** 
- `/wx/component/transaction/shop/funds/getCity `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|provinceCode|否|Integer| 省份编码|
|wxSn|否|String| wxSn|

###请求参数Json格式
 
```
{
 "provinceCode" : 0,
 "wxSn" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--cityName|否|String| 城市名称|
|--cityCode|否|Integer| 城市编号(获取支行参数)|
|--bankAddressCode|否|String| 开户银行省市编码|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : [{
 "cityName" : "String",
 "cityCode" : 0,
 "bankAddressCode" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
