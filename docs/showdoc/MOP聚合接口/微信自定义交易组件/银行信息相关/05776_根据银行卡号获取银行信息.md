# 根据银行卡号获取银行信息

**请求URL：** 
- `/wx/component/transaction/shop/funds/getbankbynum `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|accountNumber|否|String| 银行卡号|
|wxSn|否|String| wxSn|

###请求参数Json格式
 
```
{
 "accountNumber" : "String",
 "wxSn" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--accountBank|否|String| 开户银行|
|--bankCode|否|String| 银行编码|
|--bankId|否|String| 银行联号|
|--bankName|否|String| 银行名称（不包括支行）|
|--branchId|否|String| 支行联号|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "accountBank" : "String",
 "bankCode" : "String",
 "bankId" : "String",
 "bankName" : "String",
 "branchId" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
