# 查询支行信息

**请求URL：** 
- `/wx/component/transaction/shop/funds/getSubBranch `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|bankCode|否|String| 银行编码,通过查询银行信息或者搜索银行信息获取|
|cityCode|否|String| 城市编号,通过查询城市列表获取|
|pageIndex|否|Integer| 页码|
|pageSize|否|Integer| 页数|
|wxSn|否|String| wxSn|

###请求参数Json格式
 
```
{
 "bankCode" : "String",
 "cityCode" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "wxSn" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--totalCount|否|Integer| 总数|
|--count|否|Integer| 当前分页数量|
|--accountBank|否|String| 银行名称|
|--accountBankCode|否|String| 银行编码|
|--bankAlias|否|String| 银行别名|
|--bankAliasCode|否|String| 银行别名编码|
|--data|否|Object||
|--errcode|否|Integer| 0成功|
|--errmsg|否|String| 注意这个仅未ok时才有效|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "totalCount" : 0,
 "count" : 0,
 "accountBank" : "String",
 "accountBankCode" : "String",
 "bankAlias" : "String",
 "bankAliasCode" : "String",
 "data" : null,
 "errcode" : 0,
 "errmsg" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
