# 上传文件到微信开发平台

**请求URL：** 
- `/wx/component/transaction/shop/img/upload `

**请求方式：**
- POST
- FormData


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--wxSn|否|String| wx_sn|
|--file|否|File| 要上传的文件|
|--respType|否|String| 响应格式，0:media_id(目前只用于品牌申请品牌和类目)，1：返回链接, 2：返回微信支付media_id图片要求|
|--uploadType|否|String| 0:图片流(resp_type=2需指定filename)，1:图片url|


###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--mediaId|否|String| 开放平台media_id|
|--tempImgUrl|否|String| 图片链接，有访问频率限制，不可用作图床，后果自负|
|--payMediaId|否|String| 微信支付media_id|
|--imgUrl|否|String| 系统图片路径|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "mediaId" : "String",
 "tempImgUrl" : "String",
 "payMediaId" : "String",
 "imgUrl" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
