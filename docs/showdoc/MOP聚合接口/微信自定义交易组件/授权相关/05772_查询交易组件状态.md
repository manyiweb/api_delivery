# 查询交易组件状态

**请求URL：** 
- `/wx/component/transaction/shop/register/check `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|wxSn|否|String| wxSn|

###请求参数Json格式
 
```
{
 "wxSn" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--status|否|Integer| 审核状态, 2: 已接入, 3: 封禁中|
|--rejectReason|否|String| 拒绝原因|
|--accessInfo|否|Object| 接入相关信息|
|----spuAuditSuccess|否|Integer| 上传商品并审核成功，0:未成功，1:成功|
|----ecOrderSuccess|否|Integer| 发起一笔订单并支付成功，0:未成功，1:成功|
|----sendDeliverySuccess|否|Integer| 物流接口调用成功，0:未成功，1:成功|
|----ecAfterSaleSuccess|否|Integer| 售后接口调用成功，0:未成功，1:成功|
|----spuAuditFinished|否|Integer| 商品接口调试完成，0:未完成，1:已完成|
|----ecOrderFinished|否|Integer| 订单接口调试完成，0:未完成，1:已完成|
|----sendDeliveryFinished|否|Integer| 物流接口调试完成，0:未完成，1:已完成|
|----ecAfterSaleFinished|否|Integer| 售后接口调试完成，0:未完成，1:已完成|
|----testApiFinished|否|Integer| 测试完成，0:未完成，1:已完成|
|----deployWxaFinished|否|Integer| 发版完成，0:未完成，1:已完成|
|----openProductTaskFinished|否|Integer| 完成自定义组件全部任务 0:未完成 1:已完成|
|--sceneGroupList|否|List| 场景接入相关|
|----groupId|否|Integer| 场景枚举，1:视频号、公众号场景|
|----name|否|String| 场景名称|
|----status|否|Integer| 审核状态，0:审核中，1:审核完成，2:审核失败，3未审核|
|----reason|否|String| 审核理由|
|----sceneGroupExtList|否|List| 场景相关审核结果|
|------name|否|String||
|------extId|否|Integer| 审核事项id，1:客服售后，2:电商平台|
|------status|否|Integer| 场景相关审核结果，0:审核中，1:审核成功，2:审核失败，3未审核|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
