# 自定义交易组件-品牌审核

**请求URL：** 
- `/wx/component/transaction/spu/shop/audit/brand `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|wxSn|否|String| wxSn|
|license|否|List| 营业执照或组织机构代码证，图片url|
|brandInfo|否|Object| 品牌信息|
|--brandAuditType|否|Integer| 认证类型 1	国内品牌申请 -R 标 2	国内品牌申请 -TM 标 3	海外品牌申请 -R 标 4	海外品牌申请 -TM 标|
|--trademarkType|否|Integer| 商标分类 TrademarkType，字符类型，最长不超过10 1:第1类 2:第2类 以此类推|
|--brandManagementType|否|Integer| 选择品牌经营类型 BrandManagementType，字符类型，最长不超过10 1:自有品牌 2:代理品牌 3:无品牌|
|--commodityOriginType|否|Integer| 商品产地是否进口 1是 2否|
|--brandWording|否|String| 商标/品牌词，字符类型，最长不超过50|
|--saleAuthorization|否|List| 销售授权书（如商持人为自然人，还需提供有其签名的身份证正反面扫描件)，图片url/media_id，图片类型，最多不超过10张|
|--trademarkRegistrationCertificate|否|List| 商标注册证书，图片url/media_id，图片类型，最多不超过1张|
|--trademarkChangeCertificate|否|List| 商标变更证明，图片url/media_id，图片类型，最多不超过5张|
|--trademarkRegistrant|否|String| 商标注册人姓名，字符类型，最长不超过100|
|--trademarkRegistrantNu|否|String| 商标注册号/申请号，最长不超过10|
|--trademarkAuthorizationPeriod|否|String| 商标有效期，yyyy-MM-dd HH:mm:ss，字符类型，最长不超过30|
|--trademarkRegistrationApplication|否|List| 商标注册申请受理通知书，图片url/media_id，图片类型，最多不超过1张|
|--trademarkApplicant|否|String| 商标申请人姓名，字符类型，最长不超过100|
|--trademarkApplicantTime|否|String| 商标申请时间，yyyy-MM-dd HH:mm:ss，字符类型，最长不超过30|
|--importedGoodsForm|否|List| 中华人民共和国海关进口货物报关单，图片url/media_id，图片类型，最多不超过5张 可不传|
|sceneGroupList|否|List| 商品使用场景,1:视频号，3:订单中心|

|code|否|String| 业务代码|
