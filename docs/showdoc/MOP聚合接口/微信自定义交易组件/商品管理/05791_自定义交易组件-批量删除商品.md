# 自定义交易组件-批量删除商品
 

**请求URL：** 
- `/wx/smallstore/product/batch/del `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|items|否|List||
|--productId|否|Long| 小商店商品ID|
|--itemName|否|String| 商品名称|
|wxSn|否|String| 小商店标识|
|wxComponent|否|Boolean| 是否是微信交易组件|

###请求参数Json格式
 
```
{
 "items" : [{
 "productId" : 0,
 "itemName" : "String"
 }],
 "wxSn" : "String",
 "wxComponent" : true
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--totalCount|否|Long| 总数|
|--successCount|否|Long| 成功数|
|--errorCount|否|Long| 错误数|
|--optFailItem|否|List| 操作失败的商品|
|----productId|否|Long| 小商店商品ID|
|----itemId|否|String| 商品标识|
|----itemCode|否|String| 商品编码|
|----itemName|否|String| 商品名称|
|----errMsg|否|String| 失败原因|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "totalCount" : 0,
 "successCount" : 0,
 "errorCount" : 0,
 "optFailItem" : [{
 "productId" : 0,
 "itemId" : "String",
 "itemCode" : "String",
 "itemName" : "String",
 "errMsg" : "String"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
