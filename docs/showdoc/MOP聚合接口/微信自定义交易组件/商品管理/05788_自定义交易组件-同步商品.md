# 自定义交易组件-同步商品

**请求URL：** 
- `/wx/component/transaction/spu/shop/spu/add `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|productId|否|String| 交易组件平台内部商品ID|
|outProductId|否|String| 商家自定义商品ID|
|title|否|String| 标题，字符类型，最少不低于3，最长不超过60。注：1.商品标题只允许汉字、数字、英文字母、特殊字符集；2.商品标题不得仅为数字、字母、特殊字符集或上述三种的组合。|
|path|否|String| 绑定的小程序商品路径|
|directPath|否|String| 商品立即购买链接|
|headImg|否|List| 主图，多张，列表，图片类型，最多不超过9张|
|qualificationPics|否|List| 商品资质图片，图片类型，最多不超过5张|
|descInfo|否|Object| 商品详情信息|
|--desc|否|String| 商品详情图文|
|--imgs|否|List| 商品详情图片，图片类型，最多不超过50张|
|thirdCatId|否|Integer| 第三级类目ID|
|thirdCatName|否|String| 第三级类目名称|
|brandId|否|Integer| 品牌id|
|brandName|否|String| 品牌名称|
|skus|否|List| skus|
|--outProductId|否|String| 商家自定义商品ID|
|--skuId|否|String| 交易组件平台自定义skuID|
|--outSkuId|否|String| 商家自定义skuID|
|--thumbImg|否|String| sku小图|
|--salePrice|否|Double| 卖价格，以分为单位，数字类型，最大不超过10000000（1000万元）|
|--marketPrice|否|Double| 市场价格，以分为单位，数字类型，最大不超过10000000（1000万元）|
|--stockNum|否|Integer| 库存，数字类型，最大不超过10000000（1000万）|
|--barcode|否|String| 条形码|
|--skuCode|否|String| 商品编码，字符类型，最长不超过20|
|--skuAttrs|否|List| 销售属性|
|----attrKey|否|String| 销售属性key（自定义），字符类型，最长不超过40|
|----attrValue|否|String| 销售属性value（自定义），字符类型，最长不超过40，相同 key 下不能超过100个不同value|
|--specId|否|String| 系统规格id|
|sceneGroupList|否|List| 商品使用场景,1:视频号，3:订单中心|
|createTime|否|String||
|companyId|否|String| 门店id|
|wxSn|否|String| wxSn|

|msg|否|String| 消息|
|code|否|String| 业务代码|
