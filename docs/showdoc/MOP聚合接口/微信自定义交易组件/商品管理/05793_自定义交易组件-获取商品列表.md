# 自定义交易组件-获取商品列表
 

**请求URL：** 
- `/wx/smallstore/product/list `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|status|否|Integer| 商品状态0初始值 5上架 6回收站 9逻辑删除 11自主下架 12售磬下架 13违规下架/风控系统下架|
|needEditSpu|否|Integer| 默认0:获取线上数据, 1:获取草稿数据|
|pageIndex|否|Integer||
|pageSize|否|Integer||
|wxSn|否|String| 小商店标识|
|wxComponent|否|Boolean| 是否是微信交易组件|

###请求参数Json格式
 
```
{
 "status" : 0,
 "needEditSpu" : 0,
 "pageIndex" : 0,
 "pageSize" : 0,
 "wxSn" : "String",
 "wxComponent" : true
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--pageIndex|否|Integer| 页码|
|--pageSize|否|Integer| 显示记录数|
|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|--first|否|Boolean| 首页|
|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|
|----productId|否|Long| 商品标识|
|----outProductId|否|String| 商家自定义商品ID|
|----minPrice|否|Long| 商品SKU最小价格（单位：分）|
|----minSalePrice|否|Double| 商品SKU最小价格|
|----status|否|Integer| 商品状态0初始值 5上架 6回收站 9逻辑删除 11自主下架 12售磬下架 13违规下架/风控系统下架|
|----statusName|否|String| 状态名称|
|----editStatus|否|Integer| 商品草稿状态 0初始值 1编辑中 2审核中 3审核失败 4审核成功|
|----editStatusName|否|String| 商品草稿状态|
|----title|否|String| 标题|
|----subTitle|否|String| 副标题|
|----headImg|否|List| 主图,多张,列表|
|----imageUrl|否|String| 主图|
|----path|否|String| 小程序页面路径|
|----itemId|否|String| 商品标识(仅MOP商品存在)|
|----itemCode|否|String| 商品编码(仅MOP商品存在)|
|----optRemark|否|String| 操作备注|
|----modifyName|否|String| 修改人|
|----modifyDate|否|DateTime| 修改时间|
|----id|否|Long| MOP小商店商品行标识|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
