# 人脸信息去绑定
 

**请求URL：** 
- `/mem/face/toBindItem `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|是|String| token|
|pageIndex|是|String| 页码|
|pageSize|是|String| 页数|
|date|是|String| 时间|

###请求参数Json格式
 
```
{"date":"2020-11-26 18:00:28","pageIndex":"1","pageSize":"20","tokenId":"1ef5df888e3f4ed2b674dc9bba2dc876"}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--uid|否|String| 顾客id(第三方数据)|
|--storeId|否|String| 设备数字id(第三方数据)|
|--deviceAutoId|否|String| 分页数据(第三方数据)|
|--channelId|否|String| 通道id(第三方数据)|
|--url|否|String| 到店照片(第三方数据)|
|--sex|否|String| 到店性别。0-女，1-男(第三方数据)|
|--age|否|Integer| 到店年龄(第三方数据)|
|--isvip|否|String| (第三方数据)|
|--createTime|否|String| 抓拍时间(第三方数据)|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
