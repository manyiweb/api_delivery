# 人脸信息配置保存
 

**请求URL：** 
- `/config/smartSet/save `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|是|String| token|
|companyId|是|String| 门店id|
|isInherit|是|int| 是否继承 1 - 继承, 0 - 不继承|
|faceSet|是|String| 人脸参数设置|

###请求参数Json格式
 
```
{"tokenId":"9f1f79c0413a4fbba90e55d36e6d04b6","companyId":"F3278C2C927F4B28976742C85A79058F","isInherit":0,"faceSet":"{\n \"devices\": \"10450\", \n \"storeid\": \"109709\",\n \"time\": \"600\",\n, \n \"num\": \"20\",\n}"}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "code": "200",
 "data": null,
 "exceptionStackInfo": "",
 "monitorRequestId": "",
 "msg": ""
}
```
