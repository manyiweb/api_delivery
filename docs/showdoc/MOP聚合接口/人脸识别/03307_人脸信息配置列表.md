# 人脸信息配置列表
 

**请求URL：** 
- `/config/smartSet/get `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|是|String| token|
|companyId|是|String| 门店id|


###请求参数Json格式
 
```
{"tokenId":"9f1f79c0413a4fbba90e55d36e6d04b6","companyId":"E3F8DC53269C42A8A3AA3D97DD5C7AB4"}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--faceSet|否|String| 人脸设置参数|
|--isInherit|否|Integer| 是否继承 1 - 继承, 0 - 不继承|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "code": "200",
 "data": {
 "faceSet": "{\n \"devices\": \"15587_1\", \n \"storeid\": \"109709\",\n \"time\": \"600\",\n}",
 "isInherit": 0
 },
 "exceptionStackInfo": "",
 "monitorRequestId": "",
 "msg": ""
}
```
