# 根据商品ids拿到物料流转车间

**请求URL：** 
- `/product/materialWorkshop/getCirculationWorkshopBySpecIds`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|list|是|List||

### 请求参数Json格式
 
```
{
 "list" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--factoryWorkshopId|否|Long| 工厂生产车间id|
|--prodWorkshopId|否|Long| 生产车间id|
|--prodWorkshopNo|否|Long| 生产车间编码|
|--prodWorkshopName|否|String| 生产车间名称|
|--specId|否|String||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "factoryWorkshopId" : 0,
 "prodWorkshopId" : 0,
 "prodWorkshopNo" : 0,
 "prodWorkshopName" : "String",
 "specId" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
