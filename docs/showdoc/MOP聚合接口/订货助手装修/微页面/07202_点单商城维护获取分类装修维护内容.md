# 点单商城维护获取分类装修维护内容
 

**请求URL：** 
- `/b2b/decoration/product/classify/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long| id|
|code|是|String| 模块编码|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "code" : "String"
}
```
