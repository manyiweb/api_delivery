# 保存自定义链接

**请求URL：** 
- `/b2b/decoration/link/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|linkType|是|Integer| 链接类型 0：商品 1：会员 2：营销 3：其他|
|urlTypeCode|否|String| 链接类型|
|urlTypeName|是|String| 链接名称|
|url|是|String| 链接路径|
|choose|否|Integer| 是否要选择内容 0：不需要 1：需要|

### 请求参数Json格式
 
```
{
 "linkType" : 0,
 "urlTypeCode" : "String",
 "urlTypeName" : "String",
 "url" : "String",
 "choose" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
