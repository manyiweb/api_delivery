# 根据模块编码，获取对应模块应用的装修框架

**请求URL：** 
- `/b2b/appc/decoration/module/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 微页面id|
|wxSn|否|String| 小程序wxSn|
|companyId|否|String| 门店id|
|groupId|否|String| 品牌id|
|isTemplate|否|Boolean| 用于兼容有模板的模块, 默认为true|
|code|是|String| 模块编码|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "wxSn" : "String",
 "companyId" : "String",
 "groupId" : "String",
 "isTemplate" : true,
 "code" : "String"
}
```
