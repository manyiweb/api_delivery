# 通用模块——获取装修内容

**请求URL：** 
- `/b2b/decoration/module/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 门店id|
|sword|否|String||
|isTemplate|否|Boolean| 传false|
|code|是|String| 模块编码|

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "sword" : "String",
 "isTemplate" : true,
 "code" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|mongoId|否|String| mengodb主键|
|modules|否|List| 装修内容|
|--contentModule|否|Object| 单个模块里面的内容|
|----commonModule|否|Object| 通用模块|
|------isInherit|否|int| 是否继承品牌|
|------loadingImage|否|String| 页面加载加载图片|
|------openOriginPage|否|Boolean| 启用启动页|
|------originPageImage|否|String| 启动页图片url|
|------showStock|否|Boolean| 显示库存数|
|------b2bUnitPrice|否|Boolean| 显示订货单位价|
|------showAdviceSalePrice|否|Object| 显示建议零售价|
|--------isOpen|否|Boolean| 是否开启|
|--------productCategory|否|Boolean| 应用商品分类页面|
|--------searchResultPage|否|Boolean| 应用搜索结果页面|
|--------productGroup|否|Boolean| 应用商品分组页面|
|--------sceneDetail|否|Boolean| 应用场景详情页面|
|--------productDetail|否|Boolean| 应用商品详情页面|
|------showMinimumQuantity|否|Object| 显示起订量|
|--------isOpen|否|Boolean| 是否开启|
|--------productCategory|否|Boolean| 应用商品分类页面|
|--------searchResultPage|否|Boolean| 应用搜索结果页面|
|--------productGroup|否|Boolean| 应用商品分组页面|
|--------sceneDetail|否|Boolean| 应用场景详情页面|
|--------productDetail|否|Boolean| 应用商品详情页面|
|------showApplyInvoiceButtom|否|Object| 显示申请发票按钮|
|--------isOpen|否|Boolean| 是否开启|
|--------orderDetail|否|Boolean| 应用订单详情页面|
|--------confirmOrder|否|Boolean| 应用确认订单页面|
|companyId|否|String| 门店id|
|code|是|String| 模块编码|
