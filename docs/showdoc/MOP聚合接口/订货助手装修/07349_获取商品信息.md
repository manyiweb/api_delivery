# 获取商品信息

**请求URL：** 
- `/b2b/decoration/productInfo/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|itemDtos|是|List| 商品|
|--itemId|否|String| 商品id|
|--specId|否|String| 规格id|
|companyId|是|String| 门店id|

### 请求参数Json格式
 
```
{
 "itemDtos" : [{
 "itemId" : "String",
 "specId" : "String"
 }],
 "companyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--itemId|否|String| 商品id|
|--specId|否|String| 规格id|
|--dealPrice|否|Double| 请单价|
|--salesPrice|否|Double| 零售价|
|--minimumQuantity|否|Double| 起订量|
|--isSellOut|否|Boolean| 是否售罄|
|--unit|否|String| 单位|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "itemId" : "String",
 "specId" : "String",
 "dealPrice" : 0,
 "salesPrice" : 0,
 "minimumQuantity" : 0,
 "isSellOut" : true,
 "unit" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
