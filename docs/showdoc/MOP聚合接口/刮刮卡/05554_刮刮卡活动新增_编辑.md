# 刮刮卡活动新增/编辑

**请求URL：** 
- `/activity/scratchCard/config/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|config|是|Object| 装修|
|--id|否|Long| id|
|--rule|否|String| 活动规则|
|--title|是|String| 活动页面标题|
|--bgImage|否|String| 活动背景图|
|--coverImage|否|String| 封面|
|--drawColor|否|String| 刮奖区颜色|
|--winImage|否|String| 开奖弹幕背景图|
|--SharingWords|否|String| 分享语|
|--sharingImagesPath|否|String| 分享图|
|--showWinRecord|是|Integer| 是否显示中奖记录入口 1是0否|
|--showLeftCount|是|Integer| 是否显示剩余抽奖次数 1是0否|
|--showActivityRule|是|Integer| 是否显示活动规则入口 1是0否|
|--canShare|否|Boolean| 页面允许分享和复制链接|
|id|否|Long| id|
|name|是|String| 活动名称|
|beginDate|是|DateTime| 有效期起|
|endDate|是|DateTime| 有效期至|
|status|是|Integer| 活跃状态|
|cashBeginDate|是|DateTime| 兑奖有效期起|
|cashEndDate|是|DateTime| 兑奖有效期至|
|remark|否|String| 备注|
|rule|是|Object| 规则|
|--id|否|Long| id|
|--maxPlayCount|是|Integer| 活动期间每人最多可参与次数|
|--maxWinCount|是|Integer| 活动期间每人最多可中奖次数|
|--maxDayCount|是|Integer| 每人每天可参与次数|
|--memberLimit|否|Integer| 是否限制会员|
|--memberGradeLimit|否|Integer| 是否限制会员等级|
|--memberTagLimit|否|Integer| 是否限制会员标签|
|--grades|否|List| 指定会员等级code|
|--memberTags|否|List| 指定会员标签code|
|--memberMessage|否|List| 参与抽奖必填项|
|----label|否|String| 值|
|----value|否|String| 中文名|
|----checked|否|Boolean| 是否选取|
|--blacklistLimit|否|Integer| 是否排除会员|
|--blacklist|否|List| 排除会员（手机号）|
|----phone|否|String||
|----memberName|否|String||
|prizes|是|List| 奖品|
|--id|否|Long| id 主键|
|--prizeDetailId|否|Long| 详情id|
|--probability|是|Double| 中奖概率|
|--prizeType|是|Integer| 奖品类型标识，1-谢谢参与；2-积分；3-优惠券；4-服务商品; 5-购买资格|
|--prizeName|否|String| 奖品名称|
|--countLimit|否|Integer| 是否有数量限制|
|--prizeAmount|否|Integer| 奖品数量|
|--rewardAmount|否|Integer| 奖励数量|
|--couponId|否|String| 优惠券id|
|--specId|否|String| 商品id-服务商品|
|--prizeBuyPasses|否|List| 购买资格|
|----companyCode|是|String| 门店编码|
|----items|否|List||
|------id|否|Long| id|
|------itemCode|是|String| 商品编码-原商品|
|------skuBarCode|是|String| SKU 码|
|------prizeAmount|是|Integer| 数量|
|--winningImageUrl|否|String| 中奖图片|
|--enablePrizeLimit|否|Boolean| 是否启用中奖条件限制|
|--prizeLimitType|否|Integer| 中奖条件限制类型 0：会员等级 1：会员标签|
|--grades|否|List| 等级|
|----gradeId|否|String| 等级id|
|----gradeCode|否|String| 等级编码|
|----gradeName|否|String| 等级名称|
|--memberTags|否|List| 会员标签|
|----tagId|否|String| 标签id|
|----tagCode|否|String| 标签编码|
|----tagName|否|String| 标签名称|
|allComp|是|Integer| 是否应用到所有门店 1是0否|
|appComps|否|List| 应用门店列表，allComp = 1时必填|
