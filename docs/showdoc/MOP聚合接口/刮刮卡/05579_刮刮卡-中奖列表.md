# 刮刮卡-中奖列表
 

**请求URL：** 
- `/activity/scratchCard/cash/list`

**请求方式：**
- POST
- RequestBody

|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|activityId|否|Long| 活动id|

|--typeCode|否|String||
|--typeName|否|String||
|--dataType|否|String||
|--isSingle|否|String||
|--isLikeSearch|否|String||

|--current|否|Object||

|----isSelect|否|String||
|--sword|否|String||
|--pageIndex|否|Integer||
|--pageSize|否|Integer||

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--pageIndex|否|Integer| 页码|
|--pageSize|否|Integer| 显示记录数|
|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|--first|否|Boolean| 首页|
|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|
|----id|否|Long| id|
|----recordId|否|Long| 流水id|
|----memberId|否|String| 会员ID|
|----activityId|否|Long| 活动id|
|----activityCode|否|String| 活动编码|
|----activityName|否|String| 活动名称|
|----prizeId|否|Long| 奖项id|
|----prizeType|否|Integer| 奖品类型标识，1-谢谢参与；2-积分；3-优惠券；4-服务商品; 5-购买资格|
|----prizeDetailId|否|Long| 奖项详情id|
|----isCash|否|Integer| 兑现状态：0-未兑奖 1-已兑奖|
|----cashDate|否|DateTime| 兑奖日期|
|----uniqueCode|否|String| 唯一码（中奖码）|
|----uniqueCodeBase64|否|String| 唯一码|
|----imageUrl|否|String| 图片|
|----imageUrlFull|否|String| 图片|
|----createDate|否|DateTime| 中奖时间|
|----companyId|否|String| 可用门店|
|----companyName|否|String| 可用门店名|
|----cashBeginDate|否|DateTime| 兑奖开始时间|
|----cashEndDate|否|DateTime| 兑奖结束时间|
|----rewardAmount|否|Integer| 奖励数量|
|----prizeName|否|String| 奖品名称|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
