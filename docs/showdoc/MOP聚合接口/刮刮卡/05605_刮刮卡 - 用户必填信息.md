# 填写刮刮卡抽奖用户信息
 

**请求URL：** 
- `/activity/scratchCard/draw/getMemberMsgItem`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|activityId|是|Long||

### 请求参数Json格式
 
```
{
 "activityId" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--label|否|String| 值|
|--value|否|String| 中文名|
|--checked|否|Boolean| 是否选取|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : [{
 "label" : "String",
 "value" : "String",
 "checked" : true
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
