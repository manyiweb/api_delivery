# 刮刮卡-活动装修
 

**请求URL：** 
- `/scratchCard/draw/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|activityId|是|Long||

### 请求参数Json格式
 
```
{
 "activityId" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--activityCode|否|String| 活动编号|
|--name|否|String| 活动名称|
|--beginDate|否|DateTime| 有效期起|
|--endDate|否|DateTime| 有效期至|
|--status|否|Integer| 活跃状态|
|--rule|否|String| 活动规则|
|--title|否|String| 活动页面标题|
|--bgImage|否|String| 活动背景图|
|--bgImageFull|否|String| 活动背景图|
|--coverImage|否|String| 封面|
|--coverImageFull|否|String| 封面|
|--winImage|否|String| 开奖页面背景图|
|--winImageFull|否|String| 开奖页面背景图|
|--showWinRecord|否|Integer| 是否显示中奖记录入口 1是0否|
|--showLeftCount|否|Integer| 是否显示剩余抽奖次数 1是0否|
|--showActivityRule|否|Integer| 是否显示活动规则入口 1是0否|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
