# 刮刮卡-校验用户抽奖资格
 

**请求URL：** 
- `/activity/scratchCard/draw/checkUser`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|activityId|是|Long||

### 请求参数Json格式
 
```
{
 "activityId" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--canDraw|否|Boolean| 能否抽奖|
|--needFillMemMsg|否|Boolean| 是否需要填写信息|
|--remainCount|否|Integer| 剩余次数|
|--memberLimit|否|Integer| 适用人群 0：所有 1：仅限会员|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "canDraw" : true,
 "needFillMemMsg" : true,
 "remainCount" : 0,
 "memberLimit" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
