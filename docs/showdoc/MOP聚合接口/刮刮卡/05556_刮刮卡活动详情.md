# 刮刮卡活动详情

**请求URL：** 
- `/activity/scratchCard/config/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||

### 请求参数Json格式
 
```
{
 "id" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long| id|
|--drawn|否|Boolean| 是否有人参与抽奖|
|--activityCode|否|String| 活动编号|
|--name|否|String| 活动名称|

|--endDate|否|DateTime| 有效期至|

|--config|否|Object| 装修|
|----id|否|Long| id|
|----rule|否|String| 活动规则|
|----title|否|String| 活动页面标题|
|----bgImage|否|String| 活动背景图|
|----bgImageFull|否|String| 活动背景图|
|----coverImage|否|String| 封面|

|----showActivityRule|否|Integer| 是否显示活动规则入口 1是0否|

|----prizeName|否|String| 奖品名称|
|----countLimit|否|Integer| 是否有数量限制|

|----useAmount|否|Integer| 已中奖数量|

|----specId|否|String| specId|
|----itemId|否|String| 商品id|
|----itemNameFull|否|String| 全称|
|----prizeBuyPasses|否|List| 购买资格|
|------companyId|否|String||
|------companyCode|否|String||

|------items|否|List||
|--------id|否|Long||
|--------useAmount|否|Integer||
|--------unUseAmount|否|Integer||
|--------PrizeAmount|否|Integer||
|--------prizeAmount|否|Integer||
|--------itemCode|否|String||
|--------itemName|否|String||
|--------skuBarCode|否|String||
|--------specName|否|String||
|--------specId|否|String||
|----enablePrizeLimit|否|Boolean| 是否启用中奖条件限制|
|----prizeLimitType|否|Integer| 中奖条件限制类型 0：会员等级 1：会员标签|
|----grades|否|List| 等级|
|------gradeId|否|String| 等级id|
|------gradeCode|否|String| 等级编码|
|------gradeName|否|String| 等级名称|
|----memberTags|否|List| 会员标签|
|------tagId|否|String| 标签id|
|------tagCode|否|String| 标签编码|
|------tagName|否|String| 标签名称|
|--rule|否|Object| 规则|
|----id|否|Long| id|
|----maxPlayCount|否|Integer| 活动期间每人最多可参与次数|
|----maxWinCount|否|Integer| 活动期间每人最多可中奖次数|
|----maxDayCount|否|Integer| 每人每天可参与次数|
|----memberLimit|否|Integer| 是否限制会员|
|----memberGradeLimit|否|Integer| 是否限制会员等级|
|----memberTagLimit|否|Integer| 是否限制会员标签|
|----blacklistLimit|否|Integer| 是否排除会员|
|----memberMessage|否|List| 参与抽奖必填项|
|------label|否|String| 值|
|------value|否|String| 中文名|
|------checked|否|Boolean| 是否选取|
|----blacklist|否|List| 排除会员（手机号）|
|------lineNo|否|Integer||
|------phone|否|String||
|------memberName|否|String||
|----tags|否|List| 指定会员标签|
|------tagCode|否|String||
|------tagName|否|String||
|----grades|否|List| 指定会员等级|
|------gradeCode|否|String||
|------gradeName|否|String||
|--appCompanys|否|List| 应用门店|
|----companyId|否|String| 门店id|
|----companyCode|否|String| 门店code|
|----companyName|否|String| 门店|
|--createName|否|String| 创建人|
|--createDate|否|DateTime| 创建时间|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
