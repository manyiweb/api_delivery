# 刮刮卡-填写抽奖用户信息

**请求URL：** 
- `/activity/scratchCard/draw/addDrawMemberMsg`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|activityId|是|Long| 活动id|
|userName|否|String| 真实姓名|
|phone|否|String| 手机号|
|idCard|否|String| 身份证号|
|wxNumber|否|String| 微信号|
|qqNumber|否|String| QQ号|
|email|否|String| 邮箱|
|provinceCode|否|String| 省|
|provinceName|否|String| 省|
|cityCode|否|String| CityCode|
|cityName|否|String| 市|
|regionCode|否|String| RegionCode|
|regionName|否|String| 区|
|address|否|String| 详细地址|

### 请求参数Json格式
 
```
{
 "activityId" : 0,
 "userName" : "String",
 "phone" : "String",
 "idCard" : "String",
 "wxNumber" : "String",
 "qqNumber" : "String",
 "email" : "String",
 "provinceCode" : "String",
 "provinceName" : "String",
 "cityCode" : "String",
 "cityName" : "String",
 "regionCode" : "String",
 "regionName" : "String",
 "address" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
