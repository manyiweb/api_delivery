# 刮刮卡抽奖

**请求URL：** 
- `/activity/scratchCard/draw/draw`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|activityId|否|Long||

### 请求参数Json格式
 
```
{
 "activityId" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--isWin|否|Integer| 中奖：0-否 1-是|
|--prizeType|否|Integer| 奖品类型标识，1-谢谢参与；2-积分；3-优惠券；4-服务商品; 5-购买资格|
|--rewardAmount|否|Integer| 奖励数量|
|--prizeImage|否|String| 购买资格商品图片|
|--prizeImageFull|否|String| 购买资格商品图片|
|--prizeName|否|String| 奖品名称|
|--uniqueCode|否|String| 中奖码|
|--unDrawCount|否|Integer| 剩余抽奖次数|
|--winningImageUrl|否|String| 中奖图片|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "isWin" : 0,
 "prizeType" : 0,
 "rewardAmount" : 0,
 "prizeImage" : "String",
 "prizeImageFull" : "String",
 "prizeName" : "String",
 "uniqueCode" : "String",
 "unDrawCount" : 0,
 "winningImageUrl" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
