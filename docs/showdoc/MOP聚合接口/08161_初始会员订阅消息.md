# 初始会员订阅消息

**请求URL：** 
- `/wx/sub/member/message`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|groupIds|否|List| 品牌id|
|memberIds|否|List| 会员id|

### 请求参数Json格式
 
```
{
 "groupIds" : null,
 "memberIds" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--returnCode|否|String| 返回状态码|
|--returnMsg|否|String| 返回信息|
|--mchAppid|否|String| 商户appid|
|--mchId|否|String| 商户号|
|--nonceStr|否|String| 随机字符串|
|--resultCode|否|String| 业务结果|
|--errCode|否|String| 错误代码|
|--errCodeDes|否|String| 错误代码描述|
|--partnerTradeNo|否|String| 商户订单号|
|--paymentNo|否|String| 微信付款单号|
|--paymentTime|否|String| 付款成功时间|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "returnCode" : "String",
 "returnMsg" : "String",
 "mchAppid" : "String",
 "mchId" : "String",
 "nonceStr" : "String",
 "resultCode" : "String",
 "errCode" : "String",
 "errCodeDes" : "String",
 "partnerTradeNo" : "String",
 "paymentNo" : "String",
 "paymentTime" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
