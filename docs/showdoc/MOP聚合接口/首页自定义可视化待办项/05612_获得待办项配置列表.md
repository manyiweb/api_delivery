# 获得待办项配置列表
 

**请求URL：** 
- `/report/logback/manager/showBacklogConfig `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyIdOrGroupId|否|String| 门店或者品牌ID|
|isGroupConfig|否|Boolean| 是否为品牌配置|
|backlogTableCode|否|String| 待办项表编码|

###请求参数Json格式
 
```
{
 "companyIdOrGroupId" : "String",
 "isGroupConfig" : true,
 "backlogTableCode" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--companyId|否|String| 门店ID 或者 品牌ID|
|--inherit|否|Boolean| 继承|
|--backlogTableName|否|String| 待办项表名称|
|--backlogTableCode|否|String| 待办项表编码|
|--warningContent|否|String| 提醒内容|
|--warning_time|否|DateTime| 提醒时间点|
|--isWarningDay|否|Boolean| 是否启用每日做单提醒|
|--conditionDefinitions|否|List| 待办项控制条件|
|----conditionName|否|String| 条件参数名称|
|----conditionCode|否|String| 条件参数编码|
|----type|否|Integer| 条件类型|
|----valueAndNameMap|否|Map| 可选内容键值对（名称对内容）|
|--backlogConfigList|否|List| 待办项配置列表|
|----backlogId|否|Long| 待办项ID|
|----backlogName|否|String| 待办项名称|
|----isActive|否|Boolean| 是否活跃|
|----delayDay|否|Integer| 延迟天数|
|----conditionConfigs|否|List| 条件配置|
|------conditionCode|否|String| 条件参数编码|
|------valueAndNameMap|否|Map| 可选内容键值对（名称对内容）|
|----roles|否|List| 可视角色|
|------roleCode|否|String| 角色编码|
|------roleName|否|String| 角色名称|
|--makeOrderRemind|否|Object| 每日做单提醒配置|
|----id|否|Long| 做单提醒id|
|----status|否|Boolean| 是否启用 true启用 false不启用|
|----remindContent|否|String| 提醒内容|
|----remindDate|否|DateTime| 提醒时间|
|----companyId|否|String| 门店id|
|----backlogTableCode|否|String| 待办项表编码|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|
