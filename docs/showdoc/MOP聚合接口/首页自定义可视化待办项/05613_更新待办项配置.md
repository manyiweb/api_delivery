# 更新待办项配置
 

**请求URL：** 
- `/report/logback/manager/updateBacklogConfig `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyIdOrGroupId|否|String| 门店或者品牌ID|
|isGroupConfig|否|Boolean| 是否为品牌配置|
|backlogTableCode|否|String| 待办项表编码|
|inherit|否|Boolean| 是否继承|
|backlogConfigList|否|List| 待办项配置|
|--backlogId|否|Long| 有就传入做更新，没有就新增|
|--backlogName|否|String| 待办项名称|
|--isActive|否|Boolean| 是否活跃|
|--delayDay|否|Integer| 延迟天数|
|--roles|否|List| 可视角色|
|--conditions|否|List| 条件配置列表|
|----conditionCode|否|String| 条件编码|
|----values|否|List| 条件参数内容|
|makeOrderRemindDTO|否|Object| 每日做单提醒设置|
|--id|否|Long| 做单提醒id|
|--status|否|Boolean| 是否启用 true启用 false不启用|
|--remindContent|否|String| 提醒内容|
|--remindDate|否|DateTime| 提醒时间|
|--companyId|否|String| 门店id|

###请求参数Json格式
 
```
{
 "companyIdOrGroupId" : "String",
 "isGroupConfig" : true,
 "backlogTableCode" : "String",
 "inherit" : true,
 "backlogConfigList" : [{
 "backlogId" : 0,
 "backlogName" : "String",
 "isActive" : true,
 "delayDay" : 0,
 "roles" : null,
 "conditions" : [{
 "conditionCode" : "String",
 "values" : null
 }]
 }],
 "makeOrderRemindDTO" : {
 "id" : 0,
 "status" : true,
 "remindContent" : "String",
 "remindDate" : "DateTime",
 "companyId" : "String"
 }
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
