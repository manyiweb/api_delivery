# 自定义待办

**请求URL：** 
- `/report/backlog/query/custom `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tableCode|否|String| 任务类型|
|remindStartDate|否|DateTime| 提醒开始时间|
|remindEndDate|否|DateTime| 提醒结束时间|
|sword|否|String| 搜索条件|

###请求参数Json格式
 
```
{
 "tableCode" : "String",
 "remindStartDate" : "DateTime",
 "remindEndDate" : "DateTime",
 "sword" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--backlogName|否|String| 待办项名称|
|--tableCode|否|String| 任务类型|
|--tableName|否|String| 任务类型|
|--remindDate|否|DateTime| 提醒日期|
|--orderId|否|String| 订单id|
|--orderNo|否|String| 单据编号|
|--createDate|否|DateTime| 订单创建时间|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : [{
 "backlogName" : "String",
 "tableCode" : "String",
 "tableName" : "String",
 "remindDate" : "DateTime",
 "orderId" : "String",
 "orderNo" : "String",
 "createDate" : "DateTime"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
