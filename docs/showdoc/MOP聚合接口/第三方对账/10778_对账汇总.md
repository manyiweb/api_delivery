# 对账汇总

**请求URL：** 
- `/b2b/reconciliation/detail/summary/list/{source}`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|result|否|String| 核对结果 0全部 1差异|
|resultList|否|List||
|sortType|否|Integer| 排序字段 0 对账日期 1 门店编码|
|sortRule|否|String| 排序规则 ASC DESC|
|id|否|String||
|pageSize|否|Integer||
|pageNo|否|Integer||
|sortField|否|String||
|sortDirection|否|String||
|viewId|否|String||

### 请求参数Json格式
 
```
{
 "result" : "String",
 "resultList" : null,
 "sortType" : 0,
 "sortRule" : "String",
 "id" : "String",
 "pageSize" : 0,
 "pageNo" : 0,
 "sortField" : "String",
 "sortDirection" : "String",
 "viewId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--content|否|List||
|----companyCode|否|String|门店编码 |
|----companyName|否|String|门店名称 |
|----systemAmount|否|Double|系统金额 |
|----platformAmount|否|Double|平台金额 |
|----diffAmount|否|Double|差异金额 |
|----checkResult|否|String|核对结果 |
|--pageSize|否|Integer||
|--pageNo|否|Integer||
|--total|否|Long||
|--totalPage|否|Integer||
|--hasNextPage|否|Boolean||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
