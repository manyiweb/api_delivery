# 获取对账门店映射列表
 

**请求URL：** 
- `/b2b/reconciliation/store/mapping/list`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|payId|否|String| 支付方式id|

### 请求参数Json格式
 
```
{
 "payId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--id|否|Long| 主键ID|
|--groupId|否|String| 品牌id|
|--payId|否|String| 支付方式id|
|--companyId|否|String| 门店id|
|--companyCode|否|String| 门店编码|
|--companyName|否|String| 门店名称|
|--thirdIdentifier|否|String| 第三方唯一标识|
|--createDate|否|DateTime| 创建时间|
|--createName|否|String| 创建人|
|--modifyDate|否|DateTime| 修改时间|
|--modifyName|否|String| 修改人|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "id" : 0,
 "groupId" : "String",
 "payId" : "String",
 "companyId" : "String",
 "companyCode" : "String",
 "companyName" : "String",
 "thirdIdentifier" : "String",
 "createDate" : "DateTime",
 "createName" : "String",
 "modifyDate" : "DateTime",
 "modifyName" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
