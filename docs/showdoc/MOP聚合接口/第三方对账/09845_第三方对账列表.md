# 第三方对账列表

**请求URL：** 
- `/b2b/reconciliation/list/{source}`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|channelType|否|List| 渠道|
|status|否|List| 状态|
|result|否|List| 核对结果|
|orderPayTime|否|Object| 订单支付时间|
|--start|否|DateTime||
|--end|否|DateTime||
|createDate|否|Object| 创建日期|
|--start|否|DateTime||
|--end|否|DateTime||
|id|否|String||
|pageSize|否|Integer||
|pageNo|否|Integer||
|sortField|否|String||
|sortDirection|否|String||
|viewId|否|String||

### 请求参数Json格式
 
```
{
 "channelType" : null,
 "status" : null,
 "result" : null,
 "orderPayTime" : {
 "start" : "DateTime",
 "end" : "DateTime"
 },

 "start" : "DateTime",
 "end" : "DateTime"
 },
 "id" : "String",
 "pageSize" : 0,

}
```

|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |

|--content|否|List||

|----name|否|String|对账名称 |
|----code|否|String|对账编码 |
|----payDate|否|DateTime|订单支付时间 |
|----channelType|否|Integer|对账渠道 0知托付 1招行 2富友 |
|----channelTypeName|否|String||
|----status|否|Integer|0对账中 1已完成 |
|----statusName|否|String||
|----result|否|Integer|0相符 1短款 2 长款 |
|----resultName|否|String||
|----createDate|否|DateTime||
|----createName|否|String||
|--pageSize|否|Integer||
|--pageNo|否|Integer||
|--total|否|Long||
|--totalPage|否|Integer||
|--hasNextPage|否|Boolean||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
