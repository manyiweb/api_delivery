# 新建第三方对账单

**请求URL：** 
- `/b2b/reconciliation/add`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|name|否|String|对账名称 |
|companyType|否|Integer|门店类型 0全部门店 1指定门店 |
|companyList|否|List| 指定门店列表|
|--companyId|否|String| 商户ID|
|--companyCode|否|String| 商户code|
|--companyName|否|String| 商户名称|
|--merchantsTypeName|否|String| 商户名称|
|startPayDate|否|DateTime|订单支付时间--开始时间 |
|endPayDate|否|DateTime| 订单支付时间--结束时间|
|channelType|否|Integer|对账渠道 0知托付 1招行 2富友 |
|reconciliationType|否|Integer|对账方式 对账方式 0 导入第三方流水对账 1 sftp对账 |
|fileUrl|否|String|对账文件url |
|payId|否|String| 支付方式ID|
|payCode|否|String|支付编码 |
|payName|否|String|支付名称 |

### 请求参数Json格式
 
```
{
 "name" : "String",
 "companyType" : 0,
 "companyList" : [{
 "companyId" : "String",
 "companyCode" : "String",
 "companyName" : "String",
 "merchantsTypeName" : "String"
 }],
 "startPayDate" : "DateTime",
 "endPayDate" : "DateTime",
 "channelType" : 0,
 "reconciliationType" : 0,
 "fileUrl" : "String",
 "payId" : "String",
 "payCode" : "String",
 "payName" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Long||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : 0,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
