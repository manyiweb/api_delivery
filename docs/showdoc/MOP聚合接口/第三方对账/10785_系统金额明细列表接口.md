# 系统金额明细列表接口

**请求URL：** 
- `/task/retail/cashier/reconciliation/listSystemAmountDetails/{source}`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|reconciliationId|否|Long| 对账单ID|
|startDate|否|String| 开始时间 (yyyy-MM-dd)|
|endDate|否|String| 结束时间 (yyyy-MM-dd)|
|sortDirection|否|String| 排序方向: ASC 或 DESC，默认 DESC|
|id|否|String||
|pageSize|否|Integer||
|pageNo|否|Integer||
|sortField|否|String||
|sortDirection|否|String||
|viewId|否|String||

### 请求参数Json格式
 
```
{
 "reconciliationId" : 0,
 "startDate" : "String",
 "endDate" : "String",
 "sortDirection" : "String",
 "id" : "String",
 "pageSize" : 0,
 "pageNo" : 0,
 "sortField" : "String",
 "sortDirection" : "String",
 "viewId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--content|否|List||
|----orderNo|否|String| 订单编号|
|----tradeDate|否|DateTime| 支付时间|
|----amount|否|Double| 金额|
|--pageSize|否|Integer||
|--pageNo|否|Integer||
|--total|否|Long||
|--totalPage|否|Integer||
|--hasNextPage|否|Boolean||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "content" : [{
 "orderNo" : "String",
 "tradeDate" : "DateTime",
 "amount" : 0
 }],
 "pageSize" : 0,
 "pageNo" : 0,
 "total" : 0,
 "totalPage" : 0,
 "hasNextPage" : true
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
