# 小程序-个人中心-我的发票模块-门店订单开票列表 根据订单编号和平台券码查订单
 

**请求URL：** 
- `/hr/retail/invoice/orderSearchByNo`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderNo|是|String| 订单id|

### 请求参数Json格式
 
```
{
 "orderNo" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--orderId|否|String| 订单id|
|--orderNo|否|String| 订单编号|
|--companyName|否|String| 门店|
|--createDate|否|DateTime| 创建时间|
|--realMoney|否|Double| 金额|
|--payAmount|否|Double||
|--payType|否|String||
|--message|否|String||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "orderId" : "String",
 "orderNo" : "String",
 "companyName" : "String",
 "createDate" : "DateTime",
 "realMoney" : 0,
 "payAmount" : 0,
 "payType" : "String",
 "message" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
