# 汇总表流数据
 

**请求URL：** 
- `/data-link/audit/streaming/summary`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|dataLinkId|否|String| 数据链ID|
|startTime|否|DateTime| 开始时间|
|endTime|否|DateTime| 结束时间|

### 请求参数Json格式
 
```
{
 "dataLinkId" : "String",
 "startTime" : "DateTime",
 "endTime" : "DateTime"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--startTime|否|DateTime||
|--endTime|否|DateTime||
|--tables|否|List||
|----tableName|否|String| 表名|
|----inputCount|否|Long| 输入记录数|
|----outputCount|否|Long| 输出记录数|
|msg|否|String| 消息|
|code|否|String| 业务代码|


### 返回参数Json格式
 
```
{
 "data" : {
 "startTime" : "DateTime",
 "endTime" : "DateTime",
 "tables" : [{
 "tableName" : "String",
 "inputCount" : 0,
 "outputCount" : 0
 }]
 },
 "msg" : "String",
 "code" : "String"
}
```
