# 查看企业会员关联的公司信息
 

**请求URL：** 
- `/hr/company/member/getMemberCompanyInfo`

**请求方式：** 
- `POST`
- `RequestBody`


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|memberId|是|String| 会员id|

### 请求参数Json格式
 
```
{
 "memberId":"String"
}
```

### 响应参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--fid|否|String| ID|
|--companyCode|否|String| 门店编码|
|--companyName|否|String| 门店名称|
|--companyType|否|String| 门店类型|
|--companyTypeCode|否|String| 门店类型编码|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 响应参数Json格式
 
```
{
 "data":{
 "fid":"String",
 "companyCode":"String",
 "companyName":"String",
 "companyType":"String",
 "companyTypeCode":"String"
 },
 "msg":"String",
 "code":"String",
 "exceptionStackInfo":"String",
 "traceId":"String"
}
```
