# 积分变更

**请求URL：** 
- `/b2b/fundmanagement/integral/change `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|changeType|是|Integer| 变更方式 0增加 1扣减|
|integral|是|Double| 积分|
|remark|是|String| 备注|
|companyId|是|String| 商户id|
|groupId|是|String| 品牌id|

###请求参数Json格式
 
```
{
 "changeType" : 0,
 "integral" : 0,
 "remark" : "String",
 "companyId" : "String",
 "groupId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|String| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : "String",
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
