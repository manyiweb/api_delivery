# 添加快麦打印日志

**请求URL：** 
- `/reabam-client-log/client/log/add `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|level|是|String| 日志打印级别,info(默认),error,warn|
|title|否|String| 日志标题|
|sysNo|否|String| 调用方平台,如iOS、安卓、H5|
|content|是|String| 日志内容|

###请求参数Json格式
 
```
{
 "level" : "String",
 "title" : "String",
 "sysNo" : "String",
 "content" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String"
}
```
