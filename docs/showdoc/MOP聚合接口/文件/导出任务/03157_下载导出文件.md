# 下载导出文件
 

**请求URL：** 
- `/file/export/task/downloadTaskFile `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|taskId|否|Long| 导出任务ID|

###请求参数Json格式
 
```
{
 "taskId" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--protocol|否|String||
|--host|否|String||
|--port|否|Integer||
|--file|否|String||
|--query|否|String||
|--authority|否|String||
|--path|否|String||
|--userInfo|否|String||
|--ref|否|String||
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : {
 "protocol" : "String",
 "host" : "String",
 "port" : 0,
 "file" : "String",
 "query" : "String",
 "authority" : "String",
 "path" : "String",
 "userInfo" : "String",
 "ref" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
