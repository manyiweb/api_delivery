# 批量删除零售代发商品

**请求URL：** 
- `/config/supplier/item/comp/batchRetailSupplierDel `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|delType|否|Integer| 删除类型 1-按商品删除, 2-按品牌删除, 默认 1|
|companyIds|否|List| 代发门店|
|itemIds|否|List| 代发商品|
|brandCodes|否|List| 品牌编码|

###请求参数Json格式
 
```
{
 "delType" : 0,
 "companyIds" : null,
 "itemIds" : null,
 "brandCodes" : null
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|String| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : "String",
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
