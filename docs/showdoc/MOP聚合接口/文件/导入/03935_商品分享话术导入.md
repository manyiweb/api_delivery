# 商品分享话术导入

**请求URL：** 
- `/file/import/product/importMItemShareWords `

**请求方式：**
- POST
- FormData


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|file|是|MultipartFile| 导入文件|
|companyIds|否|String| 商户门店fid,多个用逗号隔开,导入时校验是该门店下商品才更新|


###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--totalCount|否|Integer| 导入总数量|
|--successCount|否|Integer| 成功导入数量|
|--errorCount|否|Integer| 失败数|
|--dataJson|否|List| 返回数据|
|--downloadURL|否|String| 失败数据下载地址|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : {
 "totalCount" : 0,
 "successCount" : 0,
 "errorCount" : 0,
 "dataJson" : null,
 "downloadURL" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
