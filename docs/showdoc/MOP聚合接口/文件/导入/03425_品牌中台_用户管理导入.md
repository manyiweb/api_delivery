# 品牌中台/用户管理导入

**请求URL：** 
- `/file/hr/importUser `

**请求方式：**
- POST
- FormData


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|file|是|MultipartFile| 导入文件|


###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--userInfoResp|否|Object| 用户信息导入返回|
|----totalCount|否|Integer| 导入总数量|
|----successCount|否|Integer| 成功导入数量|
|----errorCount|否|Integer| 失败数|
|--authMerchantResp|否|Object| 认证商户导入返回|
|----totalCount|否|Integer| 导入总数量|
|----successCount|否|Integer| 成功导入数量|
|----errorCount|否|Integer| 失败数|
|--operateMerchantResp|否|Object| 运营商户导入返回|
|----totalCount|否|Integer| 导入总数量|
|----successCount|否|Integer| 成功导入数量|
|----errorCount|否|Integer| 失败数|
|--operateDealerResp|否|Object| 运营经销商导入返回|
|----totalCount|否|Integer| 导入总数量|
|----successCount|否|Integer| 成功导入数量|
|----errorCount|否|Integer| 失败数|
|--downloadURL|否|String| 失败数据下载地址|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|

 },

}
