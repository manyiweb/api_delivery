# 获取视频播放地址
 

**请求URL：** 
- `/file/vod/video/getPlayAddress `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|String| id|

###请求参数Json格式
 
```
{
 "id" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--coverUrl|否|String|视频封面 |
|--duration|否|String|视频时长，单位(秒) |
|--status|否|String|视频状态，Uploading-上传中（初始状态） ,UploadFail-上传失败 ,UploadSucc-上传完成 ,Transcoding-转码中 ,TranscodeFail-转码失败 ,Checking-审核中 ,Blocked-屏蔽 ,Normal-正常 ,ProduceFail-合成失败 |
|--title|否|String|视频标题 |
|--playUrl|否|String|视频url |
|--size|否|Long|视频大小，单位(byte) |
|--format|否|String|视频格式 |
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : {
 "coverUrl" : "String",
 "duration" : "String",
 "status" : "String",
 "title" : "String",
 "playUrl" : "String",
 "size" : 0,
 "format" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
