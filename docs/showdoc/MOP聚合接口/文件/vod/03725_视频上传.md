# 创建视频上传信息，包括上传地址和凭证
 

**请求URL：** 
- `/file/vod/video/createUpload `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|fileName|否|String|文件名，必须带扩展名 |
|title|否|String|标题 |
|coverUrl|否|String|视频封面url |
|description|否|String|视频描述 |
|cateId|否|Long|视频分类id |
|tags|否|String|视频标签，多个用英文逗号隔开 |
|userData|否|String|用户自定义数据，JSON格式 |
|templateGroupId|否|String|转码模板id |
|appId|否|String|应用id，不填默认：app-1000000 |

###请求参数Json格式
 
```
{
 "fileName" : "String",
 "title" : "String",
 "coverUrl" : "String",
 "description" : "String",
 "cateId" : 0,
 "tags" : "String",
 "userData" : "String",
 "templateGroupId" : "String",
 "appId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--endpoint|否|String|OSS区域地址 |
|--bucket|否|String|OSS桶 |
|--fileName|否|String|OSS对象名 |
|--videoId|否|String|视频id |
|--accessKeyId|否|String|上传授权密钥ID |
|--accessKeySecret|否|String|上传授权密钥 |
|--securityToken|否|String|上传授权安全令牌 |
|--expireUTCTime|否|String|UTC格式的过期时间 |
|--expirationSeconds|否|String|过期秒数 |
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : {
 "endpoint" : "String",
 "bucket" : "String",
 "fileName" : "String",
 "videoId" : "String",
 "accessKeyId" : "String",
 "accessKeySecret" : "String",
 "securityToken" : "String",
 "expireUTCTime" : "String",
 "expirationSeconds" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
