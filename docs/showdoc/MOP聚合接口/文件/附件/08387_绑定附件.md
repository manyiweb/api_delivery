# 绑定附件

**请求URL：** 
- `/file/attachment/bindingAttachment `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|attachmentId|否|String| 附件id|
|sourceId|否|String| 来源id|
|sourceTable|否|String| 来源类型|

###请求参数Json格式
 
```
{
 "attachmentId" : "String",
 "sourceId" : "String",
 "sourceTable" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
