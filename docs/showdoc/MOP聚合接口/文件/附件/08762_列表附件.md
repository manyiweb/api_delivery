# 列表附件

**请求URL：** 
- `/file/attachment/getListAttachment`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:--- |----- |
|sourceId|否|String| 来源id|
|sourceTable|否|String| 来源类型 </br>Dpurchase 采购收货、</br>DpurchaseReturn 采购退货、</br>dwhsout 出库、</br>allotOrder 调拨|

### 请求参数Json格式
 
```
{
 "sourceId": "46981676e5c543ddba4abc22a5d11c16",
 "sourceTable": "allotOrder",
 "tokenId": "69dc9326d60f4bc3bff0c8cc2ebacf44"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--id|否|String| 主键标识|
|--fileName|否|String| 文件名称|
|--fileUrl|否|String| 文件路径|
|--fileFullUrl|否|String| 文件完整路径|
|--fileOrgName|否|String| 文件原名|
|--fileSuffix|否|String| 文件后缀名|
|--sourceId|否|String| 来源单据ID|
|--sourceTable|否|String| 来源单据所属表|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
