# 系统区域树列表

**请求URL：** 
- `/file/area/get `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|startLevel|否|Integer|开始层级 |
|endLevel|否|Integer|结束层级，暂时取消，有需要再说 |

###请求参数Json格式
 
```
{
 "startLevel" : 0,
 "endLevel" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--id|否|String|adcode |
|--name|否|String|名称 |
|--level|否|Integer|级别 |
|--children|否|Object||
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : [{
 "id" : "String",
 "name" : "String",
 "level" : 0,
 "children" : null
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
