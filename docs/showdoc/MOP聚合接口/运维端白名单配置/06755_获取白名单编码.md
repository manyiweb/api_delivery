# 获取白名单

**请求URL：** 
- `/manage/function/whiteLit/get`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
无参数


### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--isAllGroup|否|Boolean|是否全网发布 0-否,1-是|
|--whiteListCode|否|String| 白名单编码|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "isAllGroup" : true,
 "whiteListCode" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
