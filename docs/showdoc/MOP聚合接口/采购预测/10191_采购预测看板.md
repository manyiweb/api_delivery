# 采购预测看板
 

**请求URL：** 
- `/api/b2b/procurement-forecast/boardQueryByProductItem`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|keyword|否|String| 关键字|
|brandCodes|否|List| 所属品牌|
|seriesIds|否|List| 所属系列|
|itemTypeCode|否|String| 商品类型|
|placeOfOrigins|否|List| 产地|
|preferredSupplierCodes|否|List| 首选供应商|
|companyId|否|String| 门店|
|purchaseQuantityMoreThanZero|否|Boolean| 采购数量是否大于0|
|pageSize|否|Integer| 分页大小|
|pageNo|否|Integer| 页码|
|id|否|String||
|pageSize|否|Integer||
|pageNo|否|Integer||
|sortField|否|String||
|sortDirection|否|String||
|viewId|否|String||

### 请求参数Json格式
 
```
{
 "keyword" : "String",
 "brandCodes" : null,
 "seriesIds" : null,
 "itemTypeCode" : "String",
 "placeOfOrigins" : null,
 "preferredSupplierCodes" : null,

 "purchaseQuantityMoreThanZero" : true,
 "pageSize" : 0,

 "id" : "String",
 "pageSize" : 0,
 "pageNo" : 0,
 "sortField" : "String",
 "sortDirection" : "String",
 "viewId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--content|否|List||
|----itemId|否|String| 商品ID|
|----specId|否|String| 规格ID|
|----itemName|否|String| 商品名称|
|----specDescription|否|String| 规格描述|
|----transitQty|否|Double| 在途数量|
|----onHandQty|否|Double| 库存数量|
|----plannedPurchaseQty|否|Double| 计划采购数量|
|----preferredSupplierName|否|String| 首选供应商|
|----maxSafeQty|否|Double| 库存上限|
|----minSafeQty|否|Double| 库存下限|
|----usageCountDay|否|Integer| 用量天数|
|----safetyCycleDay|否|Integer| 安全库存周期（天）|
|----addSafetyCycleDay|否|Integer| 追加安全库存周期（天）|
|----lastDealPrice|否|Double| 上次采购价格|
|--pageSize|否|Integer||
|--pageNo|否|Integer||
|--total|否|Long||
|--totalPage|否|Integer||
|--hasNextPage|否|Boolean||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
