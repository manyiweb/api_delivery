# 供应商列表
 

**请求URL：** 
- `/b2b/supplier/datatable/simple_query`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 门店ID|
|pageSize|否|Integer| 分页大小|
|pageNo|否|Integer| 页码|

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "pageSize" : 0,
 "pageNo" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--content|否|List||
|----supplierId|否|String| 供应商ID|
|----supName|否|String| 供应商名称|
|----linkMan|否|String| 联系人|
|----phone|否|String| 手机号|
|--pageSize|否|Integer||
|--pageNo|否|Integer||
|--total|否|Long||
|--totalPage|否|Integer||
|--hasNextPage|否|Boolean||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "content" : [{
 "supplierId" : "String",
 "supName" : "String",
 "linkMan" : "String",
 "phone" : "String"
 }],
 "pageSize" : 0,
 "pageNo" : 0,
 "total" : 0,
 "totalPage" : 0,
 "hasNextPage" : true
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
