# 获取品牌国际化配置
 

**请求URL：** 
- `/hr/sysGroup/internationalizationConfiguration/get`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
无参数


### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long| id|
|--internationalizationType|否|String| 国际化类型|
|--monetarySymbol|否|String| 货币符号|
|--telephoneAreaCode|否|String| 区号|
|--createId|否|String||
|--createName|否|String||
|--createDate|否|DateTime||
|--modifyId|否|String||
|--modifyName|否|String||
|--modifyDate|否|DateTime||
|--dbKey|否|Integer||
|--groupId|否|String||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||

}
