# 保存开交班设置

**请求URL：** 
- `/shift/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 内容id|
|companyId|是|String| 商户ID或品牌ID|
|pattern|是|Integer| 样式0默认1自定义|
|patternGroups|否|List| 样式分组|
|--id|否|Long| 样式组id|
|--companyId|否|String| 商户ID或品牌ID|
|--contentId|否|Long| 内容id|
|--showDetail|否|Integer| 0不展示明细1展示|
|--serialNum|否|Integer| 序号|
|--groupName|否|String| 分组名称|
|--patternDataList|否|List| 样式分组里的字段|
|----id|否|Long| 字段id|
|----field|否|String| 字段名|
|----fieldAlias|否|String| 字段别名|
|----statsWay|否|Integer| 统计方式0减1加|
|----isCustom|否|Boolean| 是否是自定义收银0不是1是|
|--deleteFieldIds|否|List| 需要删除的分组里的字段的id|
|deleteGroupIds|否|List| 需要删除的分组id|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "companyId" : "String",
 "pattern" : 0,
 "patternGroups" : [{
 "id" : 0,
 "companyId" : "String",
 "contentId" : 0,
 "showDetail" : 0,
 "serialNum" : 0,
 "groupName" : "String",
 "patternDataList" : [{
 "id" : 0,
 "field" : "String",
 "fieldAlias" : "String",
 "statsWay" : 0,
 "isCustom" : true
 }],
 "deleteFieldIds" : null
 }],
 "deleteGroupIds" : null
}
```

|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
