# 获取日结单报表

**请求URL：** 
- `/app/Handover/report`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|minDate|是|DateTime||
|maxDate|是|DateTime||
|groupId|是|String||
|companyId|是|String||

### 请求参数Json格式
 
```
{
 "minDate" : "DateTime",
 "maxDate" : "DateTime",
 "groupId" : "String",
 "companyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Map||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
