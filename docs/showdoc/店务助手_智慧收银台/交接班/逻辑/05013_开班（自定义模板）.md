# 开班（自定义模板）

**请求URL：** 
- `/handover/v2/saveHd `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|String| 交接班标识|
|cashierId|否|String| 收银员标识，与sysstaff表关联|
|cashierName|否|String| 收银员名称|
|name|否|String| 交接班名称|
|workTime|否|String| 营业时间|
|startTime|否|DateTime| 开班时间|
|endTime|否|DateTime| 交班时间|
|isHandover|否|Integer| 是否已交班 1是0否|
|standbyMoney|否|Double| 备用金额|
|modifiedDate|否|DateTime||
|companyId|否|String| 门店商户ID，与商户表syscompany相关联|
|companyName|否|String| 门店名称|
|handoverNo|否|String| 班次编号|
|hdType|否|Integer| 0按门店 1按导购|
|handoverScheduleClassGroupAddDto|否|Object| 值班组|
|--scheduleClassGroupName|否|String| 组名|
|--scheduleClassGroupId|否|Long| 组id|

###请求参数Json格式
 
```
{
 "id" : "String",
 "cashierId" : "String",
 "cashierName" : "String",
 "name" : "String",
 "workTime" : "String",
 "startTime" : "DateTime",
 "endTime" : "DateTime",
 "isHandover" : 0,
 "standbyMoney" : 0,
 "modifiedDate" : "DateTime",
 "companyId" : "String",
 "companyName" : "String",
 "handoverNo" : "String",
 "hdType" : 0,
 "handoverScheduleClassGroupAddDto" : {
 "scheduleClassGroupName" : "String",
 "scheduleClassGroupId" : 0
 }
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long||
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "id" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
