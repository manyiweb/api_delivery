# 交接班列表(自定义模板)
 

**请求URL：** 
- `/handover/v2/handoverList `

**请求方式：**
- POST
- FormData

|:---- |:---|:----- |----- |
|sword|否|String||
|tokenId|否|String||
|id|否|String||
|orderField|否|String| 排序字段|
|orderSort|否|String| 排序方式|
|searchBeans|否|List| 高级筛选条件|
|--typeCode|否|String||
|--typeName|否|String||
|--dataType|否|String||

|----itemName|否|String||
|----itemValue|否|String||
|----minValue|否|String||
|----maxValue|否|String||
|----isCustom|否|String||
|----isRange|否|String||
|----isSelect|否|String||
|--current|否|Object||
|----itemName|否|String||
|----itemValue|否|String||
|----minValue|否|String||
|----maxValue|否|String||
|----isCustom|否|String||
|----isRange|否|String||
|----isSelect|否|String||
|--sword|否|String||
|--pageIndex|否|Integer||
|--pageSize|否|Integer||

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--pageIndex|否|Integer| 页码|
|--pageSize|否|Integer| 显示记录数|
|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|--first|否|Boolean| 首页|
|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|
|----id|否|Long||
|----cashierName|否|String| 收银员名称|
|----name|否|String| 交接班名称|
|----workTime|否|String| 营业时间|
|----startTime|否|DateTime| 开班时间|
|----endTime|否|DateTime| 交班时间|
|----finishHandover|否|Boolean| 是否已交班 1是0否|
|----companyId|否|String| 门店商户ID，与商户表syscompany相关联|
|----companyName|否|String| 门店名称|
|----handoverNo|否|String| 班次编号|
|----confirmCashierName|否|String| 收银员名称(交班人)|
|----standbyMoney|否|Double| 备用金额|
|----handoverScheduleUsersStrArr|否|String| 值班人员|
|----scheduleClassEnable|否|Boolean| 启用排班功能|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
