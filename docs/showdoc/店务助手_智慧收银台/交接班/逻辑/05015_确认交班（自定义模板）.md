# 确认交班（自定义模板）

**请求URL：** 
- `/handover/v2/confirmHd `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
无参数


###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--hdGroups|否|List| 自定义内容|
|----id|否|Long||
|----patternGroupName|否|String| 组的名字|
|----serialNum|否|Long| 组的序号|
|----showDetail|否|Integer| 0不展示明细1展示|
|----summaryAmount|否|Double||
|----hdGroupInfos|否|List||
|------summaryType|否|String| 合计类型|
|------summaryName|否|String| 合计名称|
|------summaryRemark|否|String| 合计备注|
|------summaryAmount|否|Double| 合计总额|
|--name|否|String| 交接班名称|
|--workTime|否|String| 营业时间|
|--startTime|否|DateTime| 开班时间|
|--endTime|否|DateTime| 交班时间|
|--finishHandover|否|Boolean| 是否已交班 1是0否|
|--handoverNo|否|String| 班次编号|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "hdGroups" : [{
 "id" : 0,
 "patternGroupName" : "String",
 "serialNum" : 0,
 "showDetail" : 0,
 "summaryAmount" : 0,
 "hdGroupInfos" : [{
 "summaryType" : "String",
 "summaryName" : "String",
 "summaryRemark" : "String",
 "summaryAmount" : 0
 }]
 }],
 "name" : "String",
 "workTime" : "String",
 "startTime" : "DateTime",
 "endTime" : "DateTime",
 "finishHandover" : true,
 "handoverNo" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
