# 根据班次获取当前开班组以及组员
 

**请求URL：** 
- `/handover/v2/getHandoverShiftUser `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|shiftId|否|String||

###请求参数Json格式
 
```
{
 "shiftId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--scheduleClassGroupName|否|String| 组名|
|--scheduleClassGroupId|否|Long| 组id|
|--scheduleClassGroupUserNames|否|List| 组值班人员|
|----userName|否|String| 用户名称|
|----userId|否|String| 用户id|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "scheduleClassGroupName" : "String",
 "scheduleClassGroupId" : 0,
 "scheduleClassGroupUserNames" : [{
 "userName" : "String",
 "userId" : "String"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
