# 获取日结单报表
 

**请求URL：** 
- `/app/Handover/report2`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|minDate|是|DateTime||
|maxDate|是|DateTime||
|groupId|是|String||
|companyId|是|String||

### 请求参数Json格式
 
```
{
 "minDate" : "DateTime",
 "maxDate" : "DateTime",
 "groupId" : "String",
 "companyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--key|否|String||
|--value|否|Object||
|--order|否|Integer||
|--level|否|Integer||
|--money|否|Boolean||
|--discountAmount|否|Object||
|--quantity|否|Long||
|--type|否|String| 类型 title不显示金额 money 金额|
|--index|否|Integer||
|--titleIndex|否|Integer||
|--subList|否|List||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "key" : "String",
 "value" : null,
 "order" : 0,
 "level" : 0,
 "money" : true,
 "discountAmount" : null,
 "quantity" : 0,
 "type" : "String",
 "index" : 0,
 "titleIndex" : 0,
 "subList" : null
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
