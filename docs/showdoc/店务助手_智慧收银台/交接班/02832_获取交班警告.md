# 获取交班警告

**请求URL：** 
- `/app/Handover/v2/warning`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
无参数


### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--status|否|Integer| 是否可交班 1是0否|
|--npOrders|否|List| 未收银的订单数据|
|----id|否|String| 订单标识|
|----orderNo|否|String| 订单编码|
|----createName|否|String| 创建人|
|----createDate|否|DateTime| 创建时间|
|--bdOrders|否|List| 部分收银的订单数据|
|----id|否|String| 订单标识|
|----orderNo|否|String| 订单编码|
|----createName|否|String| 创建人|
|----createDate|否|DateTime| 创建时间|
|--handoverOrders|否|List| 挂单的订单数据|
|----id|否|String| 订单标识|
|----orderNo|否|String| 订单编码|
|----createName|否|String| 创建人|
|----createDate|否|DateTime| 创建时间|
|--notYIAllotOrders|否|List| 未完成的调拨单|
|----id|否|String| 订单标识|
|----orderNo|否|String| 订单编码|
|----createName|否|String| 创建人|
|----createDate|否|DateTime| 创建时间|
|--notMealOrders|否|List| 未出餐的订单|
|----id|否|String| 订单标识|
|----orderNo|否|String| 订单编码|
|----createName|否|String| 创建人|
|----createDate|否|DateTime| 创建时间|
|--notSubmitDailyStatments|否|List| 未提交的门店日结单|
|----id|否|String| 订单标识|
|----orderNo|否|String| 订单编码|
|----createName|否|String| 创建人|
|----createDate|否|DateTime| 创建时间|
|--notIssuingStoreMachining|否|List| 未投料的店内加工单|
|----id|否|Long||
|----orderNo|否|String||
|----orderStatusCode|否|String||
|----orderStatusName|否|String||
|----itemId|否|String||
|----itemCode|否|String||
|----itemName|否|String||
|----specId|否|String||
|----skubarcode|否|String||
|----specName|否|String||
|----quantity|否|Double||
|----reQuantity|否|Double||
|----companyId|否|String||
|----companyName|否|String||
|----createId|否|String||
|----createName|否|String||
|----createDate|否|DateTime||
|----remark|否|String||
|----productionLineName|否|String||
|----outPutValueNum|否|Double||
|----treatMaterialsQuantity|否|Double||
|----alreadyMaterialsQuantity|否|Double||
|----sourceNo|否|String||
|----itemImage|否|String||
|--payErrorOrders|否|List| 未处理的支付异常订单|
|----id|否|String| 订单标识|
|----orderNo|否|String| 订单编码|
|----createName|否|String| 创建人|
|----createDate|否|DateTime| 创建时间|
|--notReceivingGoodsOrders|否|List| 未收货的采购单|
|--notPickupOrder|否|List| 当天待提货订单|
|----id|否|String| 订单标识|
|----orderNo|否|String| 订单编码|
|----createName|否|String| 创建人|
|----createDate|否|DateTime| 创建时间|
|--notReceiptsB2border|否|List| 当天未完成收货的订货单|
|----id|否|String| 订单标识|
|----orderNo|否|String| 订单编码|
|----createName|否|String| 创建人|
|----createDate|否|DateTime| 创建时间|
|--unableExistNotPushOrder|否|Boolean| 对应班次存在未上传订单不允许交班 - 开关，取值：true-是，false-否|
|--openLimitHandover|否|Boolean| 是否开启限制交班|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
