# 查询开交班信息

**请求URL：** 
- `/shift/info`

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 商户ID或品牌ID|

###请求参数Json格式
 
```
{
 "companyId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--pattern|否|Integer| 样式0默认1自定义|
|--id|否|Long| 内容id|
|--allGroups|否|List| 内容对应的所有组|
|----id|否|Long| 分组id|
|----serialNum|否|Integer| 序号|
|----showDetail|否|Integer| 是否展示明细|
|----patternGroupName|否|String| 样式分组名称|
|----fields|否|List| 样式分组对应的所有字段|
|------id|否|Long| 字段id|
|------field|否|String| 字段名|
|------fieldRemark|否|String| 字段备注/外部编码|
|------statsWay|否|Integer| 统计方式0减1加|
|------fieldAlias|否|String| 字段别名|
|------isCustom|否|Integer| 是否是自定义收银0不是1是|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "pattern" : 0,
 "id" : 0,
 "allGroups" : [{
 "id" : 0,
 "serialNum" : 0,
 "showDetail" : 0,
 "patternGroupName" : "String",
 "fields" : [{
 "id" : 0,
 "field" : "String",
 "fieldRemark" : "String",
 "statsWay" : 0,
 "fieldAlias" : "String",
 "isCustom" : 0
 }]
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
