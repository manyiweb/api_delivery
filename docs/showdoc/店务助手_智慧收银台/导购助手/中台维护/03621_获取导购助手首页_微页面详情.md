# 功能描述: 获取导购助手模块设置

**请求URL：** 
- `/config/guidewxa/mallModule/get `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 商户id|
|groupId|否|String| 品牌Id|
|openId|否|String| openId|
|mallModuleType|否|String| 模块类型|
|stencilId|否|String| 模板id|

###请求参数Json格式
 
```
{
 "companyId" : "String",
 "groupId" : "String",
 "openId" : "String",
 "mallModuleType" : "String",
 "stencilId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--title|否|String| 标题|
|--subTitle|否|String| 副标题|
|--isInherit|否|Integer| 是否继承 1 - 继承,0 - 不继承|
|--isActive|否|Integer| 是否开启自定义模板 1 - 开启, 0 - 不开启|
|--modifyDate|否|String| 修改日期|
|--mallModules|否|List| 模块内容|
|----id|否|Long| id|
|----title|否|String| 模块名称、标题名|
|----code|否|String| 模块编码|
|----typographyStyles|否|String| 排版样式|
|----position|否|String| 显示位置|
|----imageGap|否|Object| 图片间隙|
|----height|否|Integer| 高度|
|----width|否|Integer| 宽度|
|----color|否|String| 颜色/背景色 例如#F9F9F9|
|----showNumber|否|Integer| 展示数量|
|----fontColor|否|String| 字体色|
|----isHiddenBorder|否|Object| 是否隐藏边框 0 - 否, 1 - 是|
|----size|否|Integer| 	 * 存在一行n个商品时，此数量为真实数量而不是展示数量|
|----isShowShopCartShortcutIcon|否|Object| 是否显示购物车快捷图标 0 - 不显示, 1 - 显示|
|----isShowMoq|否|Integer| 是否显示显示起订量 0 - 不显示, 1 - 显示|
|----isShowMsrp|否|Integer| 是否显示显示建议零售价 0 - 不显示, 1 - 显示|
|----mallModuleFunctions|否|List| 子模块内容|
|------id|否|String| 功能模块ID|
|------itemName|否|String| 商品名称|
|------itemId|否|String| 商品id|
|------itemCode|否|String| 商品编码|
|------title|否|String| 标题、导航名称|
|------urlTypeCode|否|String| 链接类型编码|
|------urlTypeName|否|String| 链接类型名称|
|------sceneCode|否|String| 场景编码|
|------sceneName|否|String| 场景名称|
|------url|否|String| 跳转链接|
|------imageUrl|否|String| 图片链接|
|------imageUrlFull|否|String| 图片全链接名|
|------sourceId|否|String| 来源id 例如 商品id、场景id|
|------position|否|String| 显示位置|
|------integral|否|Double| 积分|
|------money|否|Double| 金额|
|------salePrice|否|Double| 零售价|
|------dealPrice|否|Double| 零售价|
|------invQty|否|Double| 可兑换数(积分商城设置的可兑换数综合库存得出的最终可兑换数)|
|------onHandQty|否|Double| 库存|
|------bookingQty|否|Double| 订购量|
|------isNegativeStock|否|Integer| 是否开启负库存|
|------isStock|否|Integer| 是否开启库存控制|
|------lineNo|否|Integer| 排序号|
|------unit|否|String| 单位|
|------moq|否|Integer| 起订量|
|------isOutOfStock|否|Integer| 是否缺货|
|------isOpenReserve|否|Integer| 是否预定商品|
|------labelTitle|否|String| 活动标签|
|------labelTitles|否|List| 多个活动标签|
|--isShowCustomerService|否|Integer| 显示客服咨询入口|
|--isLeadFollow|否|Integer| 显示引导关注公众号入口|
|--isAnonymousVisit|否|Integer| 匿名访问|
|--mallModule|否|String| 模块编码|
|--stencilId|否|String| 模板id|
|--lastCacheData|否|String| 最后缓存时间|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
