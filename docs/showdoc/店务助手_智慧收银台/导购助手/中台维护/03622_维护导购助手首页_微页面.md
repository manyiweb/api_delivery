# 功能描述: 维护导购助手模块设置

**请求URL：** 
- `/config/guidewxa/mallModule/preserve `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 商户id|
|title|否|String| 标题名称|
|subTitle|否|String| 二级标题|
|isShowCustomerService|否|Integer| 显示客服咨询入口|
|isLeadFollow|否|Integer| 显示引导关注公众号入口|
|isInherit|否|Integer| 是否继承 1 - 继承, 0 - 不继承|
|isActive|否|Integer| 是否启用 1 - 启用, 0 - 不启用|
|mallModules|否|List| 维护的模块|
|--id|否|Long| id|
|--title|否|String| 模块名称、标题名|
|--code|否|String| 模块编码|
|--typographyStyles|否|String| 排版样式|
|--position|否|String| 显示位置|
|--imageGap|否|Object| 图片间隙|
|--height|否|Integer| 高度|
|--width|否|Integer| 宽度|
|--color|否|String| 颜色/背景色 例如#F9F9F9|
|--showNumber|否|Integer| 展示数量|
|--fontColor|否|String| 字体色|
|--isHiddenBorder|否|Object| 是否隐藏边框 0 - 否, 1 - 是|
|--isShowShopCartShortcutIcon|否|Object| 是否显示购物车快捷图标 0 - 不显示, 1 - 显示|
|--isShowMsrp|否|Integer| 显示建议零售价|
|--isShowMoq|否|Integer| 显示起订量|
|--backgroundImageUrl|否|String| 背景图|
|--orderShowCount|否|Integer| 展示的订单数量|
|--mallModuleFunctions|否|List| 子模块内容|
|----title|否|String| 标题、导航名称|
|----urlTypeCode|否|String| 链接类型编码|
|----url|否|String| 跳转链接|
|----imageUrl|否|String| 图片链接|
|----sourceId|否|String| 来源id 例如 商品id、场景id|
|mallModuleType|否|String| 模块类型|
|stencilId|否|String| 模板id|
|isAnonymousVisit|否|Integer| 匿名访问|
