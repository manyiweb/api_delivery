# 导购助手个人中心 详情

**请求URL：** 
- `/config/guidewxa/center/info `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
无参数


###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--backgroundImage|否|String| 背景图片|
|--backgroundFullImage|否|String||
|--pageTitleName|否|String| 页面标题|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : {
 "backgroundImage" : "String",
 "backgroundFullImage" : "String",
 "pageTitleName" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
