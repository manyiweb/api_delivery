# 导购助手小程序 获取 主题颜色 菜单 商户中心
 

**请求URL：** 
- `/config/guide/wxa/app/decoration `

**请求方式：**
- ALL
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|groupId|否|String||

###请求参数Json格式
 
```
{
 "groupId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--menu|否|Object||
|----enableCustomMenu|否|Boolean||
|----list|否|List||
|------pagePath|否|String||
|------text|否|String||
|------iconPath|否|String||
|------selectedIconPath|否|String||
|------id|否|Long||
|--color|否|Object||
|----enableCustomColor|否|Boolean||
|----color1|否|String||
|----color2|否|String||
|----color3|否|String||
|----color4|否|String||
|--tabBar|否|Object||
|----color|否|String||
|----selectedColor|否|String||
|----list|否|List||
|------pagePath|否|String||
|------text|否|String||
|------iconPath|否|String||
|------selectedIconPath|否|String||
|------id|否|Long||
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
