# 获取零售相关设置

**请求URL：** 
- `/config/retail/set/config/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|groupId|否|String| 品牌商标识|
|companyId|否|String||
|tokenId|否|String||
|openId|否|String||
|functionWhitelistCode|否|String| 功能白名单编码|

### 请求参数Json格式
 
```
{
 "groupId" : "String",
 "companyId" : "String",
 "tokenId" : "String",
 "openId" : "String",
 "functionWhitelistCode" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--enableExternalCoupon|否|Boolean| 实付启用外部优惠券|
|--enableThirdCouponVerification|否|Boolean| 是否启用外部优惠券|
|--stCodes|否|List| 优惠券外部系统code|
|--openThMemberDock|否|Boolean| 开启外部会员|
|--stCode|否|String| 会员外部code|
|--enableCardNo|否|Boolean|是否开启牌号/桌号 |
|--isAutoCardNo|否|Integer|是否手动流水牌号 0 自动 1手动，对应Extvalue5 |
|--cardNoDefaultValue|否|String|手动修改牌号时的初始默认值，对应ExtInfo3 |
|--enableShoppingcardFreeze|否|Boolean| 是否启用储值卡冻结功能|
|--enableMentitycardFreeze|否|Boolean| 是否启用实体卡冻结功能|
|--enableRechargeDecimals|否|Boolean| 充值时支持输入小数后两位|
|--enableEditRechargeAmount|否|Boolean| 充值时支持编辑应付金额|
|--shoppingcardUseMode|否|Integer| 购物卡充值/使用模式 0/null全局 1按专属门店|
|--canRefundChooseWay|否|Boolean| 整单退货退款，允许选择退款方式|
|--proxyItemRefundCompany|否|Integer| 代发商品退货门店，0下单门店，1代发门店|
|--companyRetailInvoice|否|Boolean| 商户前台销售订单申请开票功能开关|
|--companyOrderRemark|否|Boolean| 商户前台销售订单修改行备注功能开关|
|--notSaleOrderChangeAmount|否|Boolean| 未收银销售订单可支持修改商品实收单价|
|--settlementCustomAmountShow|否|Boolean| 新建门店日结单时显示系统记录的自定义收银数量,并支持填写实际数量|
|--openOfflineFastOrder|否|Boolean| 是否开启离线极速订单|
|--enableOfflinePurchaseLimit|否|Boolean| 启用线下商品限购量|
|--enableReserveProduct|否|Boolean| 启用零售预定商品|
|--enableTaxProduct|否|Boolean| 启用保税商品|
|--enableCycleSale|否|Boolean| 启用商品周期购|
|--enableValuationProduct|否|Boolean| 启用商品沽清|
|--speedPromotionCalculateWay|否|Integer| 极速订单 促销计算方式，0/NULL在线计算 1本地计算
 |
|--posMemberNotSelect|否|Boolean| POS不允许手工选择会员下单|
|--closeAutoSelectCoupon|否|Boolean| POS、APP下零售订单不自动带出系统推荐最优优惠券|
|--enableOrderCallExpress|否|Boolean| 是否允许订单呼叫第三方物流|
|--enableNotPaidPresellDelivery|否|Boolean| 是否允许 未收银和部分收银的预售订单配送|
|--cancelMemberService|否|Boolean| 未核销的会员服务是否支持作废|
|--takeOutOrderWriteExpress|否|Boolean| 外卖订单确认送出可填写信息-物流信息|
|--takeOutOrderWriteStaff|否|Boolean| 外卖订单确认送出可填写信息-服务导购|
|--deliveryTemplate|否|Integer| 配送模板样式 1板式1 2板式2|
|--enableAppOrderUploadFile|否|Boolean| APP下单支持添加图片附件（附件只显示在APP端的订单详情）|
|--excludeOtherCompanyMember|否|Boolean| 启用非本门店专属会员无法查看会员详情（针对收银端在线版和APP端）|
|--manualInput|否|Integer| 实体卡卡号输入总开关|
|--queryCardInput|否|Boolean| 卡券管理-查询卡号|
|--mergeCardInput|否|Boolean| 卡券管理-合并卡|
|--changeCardInput|否|Boolean| 购物卡充值-换旧卡|
|--guideMode|否|Integer| 导购模式 0：按订单 1：按商品|
|--writeOffCouponOne|否|Boolean||
|--enableCardDiscount|否|Boolean| 是否启用储值卡支付优惠|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
