# 获取会员商城商城订单设置

**请求URL：** 
- `/config/retail/order/config/get `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|groupId|否|String| 品牌商标识|
|companyId|否|String||
|tokenId|否|String||
|openId|否|String||

###请求参数Json格式
 
```
{
 "groupId" : "String",
 "companyId" : "String",
 "tokenId" : "String",
 "openId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long| 主键|
|--autoReceive|否|Boolean| 自动收货|
|--autoReceivedDays|否|Integer| 自动收货天数|
|--autoCancelTime|否|Integer| 等待付款的商城订单自动取消时间(分钟)|
|--orderPostingDateModifiable|否|Boolean| 新增销售订单界面显示过账日期|
|--refundPostingDateModifiable|否|Boolean| 新增销售退货单界面显示过账日期|
|--openAuthentication|否|Boolean| 活体认证|
|--allowChangeReceivingInfo|否|Boolean| 待配送订单允许修改收货信息|
|--allowChangeDeliveryTime|否|Boolean| 待配送订单允许修改配送时间|
|--createId|否|String| 创建人id|
|--createName|否|String| 创建人|
|--createDate|否|DateTime| 创建时间|
|--modifyId|否|String| 修改人id|
|--modifyName|否|String| 修改人|
|--modifyDate|否|DateTime| 修改时间|
|--dbKey|否|Integer| 分库标识|
|--groupId|否|String| 品牌商id|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "autoReceive" : true,
 "autoReceivedDays" : 0,
 "autoCancelTime" : 0,
 "orderPostingDateModifiable" : true,
 "refundPostingDateModifiable" : true,
 "openAuthentication" : true,
 "allowChangeReceivingInfo" : true,
 "allowChangeDeliveryTime" : true,
 "createId" : "String",
 "createName" : "String",
 "createDate" : "DateTime",
 "modifyId" : "String",
 "modifyName" : "String",
 "modifyDate" : "DateTime",
 "dbKey" : 0,
 "groupId" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
