# 极速订单功能配置前置认证

**请求URL：** 
- `/pos/offline/order/getOfflineOrderSet`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 商户id|

### 请求参数Json格式
 
```
{
 "companyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--enableForceSpeedLineOrder|否|Boolean| 是否强制使用极速版下达线下订单|
|--bookingIsMemberRequired|否|Boolean| 是否必须基于会员做预售单|
|--couponVerification|否|Integer| 优惠券验证开关|
|--integralVerification|否|Integer| 积分验证开关|
|--cardVerification|否|Integer| 储值卡验证开关|
|--memberServiceVerification|否|Integer| 会员服务验证开关|
|--entityCardVerification|否|Integer| 实体卡验证开关|
|--entityVoucherVerification|否|Integer| 实体券验证开关|
|--verificationTypeOffline|否|Integer| 会员验证应用场景-线下|
|--verificationCode|否|Integer| 启用消费验证码|
|--pass|否|Integer| 启用支付密码|
|--qrCode|否|Integer| 启用会员动态二维码|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : {
 "enableForceSpeedLineOrder" : true,
 "bookingIsMemberRequired" : true,
 "couponVerification" : 0,
 "integralVerification" : 0,
 "cardVerification" : 0,
 "memberServiceVerification" : 0,
 "entityCardVerification" : 0,
 "entityVoucherVerification" : 0,
 "verificationTypeOffline" : 0,
 "verificationCode" : 0,
 "pass" : 0,
 "qrCode" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
