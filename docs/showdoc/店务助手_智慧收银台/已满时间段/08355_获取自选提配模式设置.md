# 获取自选提配模式设置
 

**请求URL：** 
- `/config/time/period/getConfig`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
无参数


### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--classifySwitchMode|否|Boolean| 自选提配模式|
|--instantDispensingAlias|否|String| 即时提配别名|
|--reserveDispensingAlias|否|String| 预定提配别名|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "classifySwitchMode" : true,
 "instantDispensingAlias" : "String",
 "reserveDispensingAlias" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
