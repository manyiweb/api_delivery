# 获取某个时间段是否已满

**请求URL：** 
- `/config/time/period/getFull`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 门店id|
|date|是|String| 日期，格式 2024-06-04|
|period|是|String| 时间段 格式为 10:00~11:00|
|mode|否|Integer| 类型 0：即时提配 1：预定提配 不传默认为0|

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "date" : "String",
 "period" : "String",
 "mode" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Boolean||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : true,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
