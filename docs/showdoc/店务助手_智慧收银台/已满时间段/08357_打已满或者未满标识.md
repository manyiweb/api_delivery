# 打已满或者未满标识
 

**请求URL：** 
- `/config/time/period/mark/tag`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|date|是|String| 日期 格式 2024-06-04|
|mode|否|Integer| 0：即时提配 1：预定提配，没传默认为0|
|period|是|String| 时间段|
|isFull|是|Boolean| 是否已满 true为已满，false为未满|

### 请求参数Json格式
 
```
{
 "date" : "String",
 "mode" : 0,
 "period" : "String",
 "isFull" : true
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
