# 根据日期查询时间范围
 

**请求URL：** 
- `/config/time/period/showTimePeriod`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|mode|否|Integer| 0：即时提配 1：预定提配|

### 请求参数Json格式
 
```
{
 "mode" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--timePeriodList|否|List| 时间段|
|----date|否|String|日期|
|----timePeriodList|否|List||
|------period|否|String| 时间段|
|------isFull|否|Boolean| 是否已满|
|------take|否|Boolean| 自提|
|------delivery|否|Boolean| 配送|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "timePeriodList" : [{
 "date" : "String",
 "timePeriodList" : [{
 "period" : "String",
 "isFull" : true,
 "take" : true,
 "delivery" : true
 }]
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
