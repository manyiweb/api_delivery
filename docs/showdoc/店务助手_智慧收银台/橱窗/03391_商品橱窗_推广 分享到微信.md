# 商品橱窗/推广 分享到微信

**请求URL：** 
- `/hr/promotion/qrcode `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|itemId|否|String| 商品id|
|id|否|Long| 任务id|

###请求参数Json格式
 
```
{
 "itemId" : "String",
 "id" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long| 业务标识|
|--originalId|否|String| 小程序原始ID|
|--page|否|String| 页面|
|--imgUrl|否|String| 二维码|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "originalId" : "String",
 "page" : "String",
 "imgUrl" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
