# 保存打印规则设置
 

**请求URL：** 
- `/retail/order/printsetting/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long||
|ruleName|是|String| 规则名称|
|activeStatus|是|Boolean| 活跃状态(0-禁用,1-启用)|
|printCopies|否|Integer| 打印份数|
|isAutoPrint|否|Boolean| 是否自动打印(0-否,1-是)|
|autoPrintType|否|Integer| 自动打印类型(0-全部,1-指定类型)|
|autoPrintSpecifyType|否|String| 自动打印指定类型(0-自提,1-配送(同城+快递))|
|mid|否|Long| 单据类型ID|
|companyId|否|String| 门店标识|
|comboPrint|否|Integer| 套餐商品打印信息 0只打印子商品 1只打印主商品 2打印主商品和子商品|
|printComboItemQuantity|否|String| 订单行表-套餐主商品是否打印数量 1主商品不打印 2子商品不打印|
|printComboItemSalePrice|否|String| 订单行表-套餐主商品是否打印零售价 1主商品不打印 2子商品不打印|
|printComboItemRealPrice|否|String| 订单行表-套餐主商品是否打印实付单价 1主商品不打印 2子商品不打印|
|printComboItemTotalRealPrice|否|String| 订单行表-套餐主商品是否打印行小计 1主商品不打印 2子商品不打印|
|showPeelingWeight|否|String| 订单行表-去皮文案是否显示重量 1显示 2不显示|
|printDocType|是|String| 打印业务类型 SalesOrder订单 SupplyingOrder代发单|
|realPricePayDiscount|否|Boolean| 实付单价含含支付优惠和平台券优惠|
|totalPricePayDiscount|否|Boolean| 行小计含支付优惠和平台券优惠|
|totalDiscountPayDiscount|否|Boolean| 订单优惠总额不含支付优惠和平台券优惠|
|storeShowDetail|否|Boolean| 订单支付表-消费后购物卡余额显示（充值金额、赠送金额）|
|entitycardShowDetail|否|Boolean| 订单支付表-消费后实体卡余额显示（充值金额、赠送金额）|
|payShowPayDiscount|否|Boolean| 订单支付表-含支付优惠和平台券优惠|
|payShowDetail|否|Boolean| 订单支付表-显示（充值金额、赠送金额）|
|refundPayDiscount|否|Boolean| 开启退款金额不含支付和平台券优惠|
|hidePhone|否|Boolean| 手机号脱敏|
|hideCardNoOne|否|Boolean| 卡号1脱敏|
|hideCardNoTwo|否|Boolean| 卡号2脱敏|
|showStoreCardBalance|否|Boolean| 显示消费后购物卡余额|
|showEntityCardBalance|否|Boolean| 显示消费后实体卡余额|
|showEntityCouponBalance|否|Boolean| 显示消费后实体券余额|
|boxPrint|否|Boolean| 是否打印餐盒费 (1-打印, 0-不打印)|
