# 打印规则设置列表

**请求URL：** 
- `/retail/order/printsetting/list/{source}`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|keyword|否|String| 订单编号|
|id|否|String||
|pageSize|否|Integer||
|pageNo|否|Integer||
|sortField|否|String||
|sortDirection|否|String||
|viewId|否|String||

### 请求参数Json格式
 
```
{
 "keyword" : "String",
 "id" : "String",
 "pageSize" : 0,
 "pageNo" : 0,
 "sortField" : "String",
 "sortDirection" : "String",
 "viewId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--content|否|List||
|----id|否|Long| 主键ID|
|----ruleCode|否|String| 规则编码|
|----ruleName|否|String| 规则名称|
|----isDefaultRule|否|Boolean| 是否为默认规则(0-否,1-是)|
|----activeStatus|否|Boolean| 活跃状态(0-禁用,1-启用)|
|----createName|否|String| 创建人|
|----createDate|否|DateTime| 创建时间|
|----modifyDate|否|DateTime| 修改时间|
|--pageSize|否|Integer||
|--pageNo|否|Integer||
|--total|否|Long||
|--totalPage|否|Integer||
|--hasNextPage|否|Boolean||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "content" : [{
 "id" : 0,
 "ruleCode" : "String",
 "ruleName" : "String",
 "isDefaultRule" : true,
 "activeStatus" : true,
 "createName" : "String",
 "createDate" : "DateTime",
 "modifyDate" : "DateTime"
 }],
 "pageSize" : 0,
 "pageNo" : 0,
 "total" : 0,
 "totalPage" : 0,
 "hasNextPage" : true
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
