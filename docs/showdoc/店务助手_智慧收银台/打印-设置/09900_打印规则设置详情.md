# 打印规则设置详情
 

**请求URL：** 
- `/retail/order/printsetting/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long| 单据类型ID|

### 请求参数Json格式
 
```
{
 "id" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long| 规则ID|
|--ruleCode|否|String| 规则编码|
|--ruleName|否|String| 规则名称|
|--activeStatus|否|Boolean| 活跃状态(0-禁用,1-启用)|
|--isDefaultRule|否|Boolean| 是否为默认规则(0-否,1-是)|
|--printCopies|否|Integer| 打印份数|
|--isAutoPrint|否|Boolean| 是否自动打印(0-否,1-是)|
|--autoPrintType|否|Integer| 自动打印类型(0-全部,1-指定类型)|
|--autoPrintSpecifyType|否|String| 自动打印指定类型(0-自提,1-配送(同城+快递)),多个选项用逗号隔开|
|--createName|否|String| 创建人|
|--createDate|否|DateTime| 创建时间|
|--modifyName|否|String| 修改人|
|--modifyDate|否|DateTime| 修改时间|
|--companyId|否|String||
|--comboPrint|否|Integer| 套餐商品打印信息 0只打印子商品 1只打印主商品 2打印主商品和子商品|
|--printComboItemQuantity|否|Integer| 订单行表-套餐主商品是否打印数量 1主商品不打印 2子商品不打印|
|--printComboItemSalePrice|否|Integer| 订单行表-套餐主商品是否打印零售价 1主商品不打印 2子商品不打印|
|--printComboItemRealPrice|否|Integer| 订单行表-套餐主商品是否打印实付单价 1主商品不打印 2子商品不打印|
|--printComboItemTotalRealPrice|否|Integer| 订单行表-套餐主商品是否打印行小计 1主商品不打印 2子商品不打印|
|--showPeelingWeight|否|Integer| 订单行表-去皮文案是否显示重量 1显示 2不显示|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
