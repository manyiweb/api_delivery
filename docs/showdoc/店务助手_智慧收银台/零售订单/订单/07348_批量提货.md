# 批量提货
 服务：retail
 

**请求URL：** 
- `/app/Business/order/batchConfirmDelivery`

**请求方式：**
- undefined
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|params|否|List||
|--items|否|List| 提货商品|
|----orderNo|否|String| 订单编码|
|----oitemId|否|String| 订单行id|
|----itemName|否|String| 商品名称|
|----quality|否|Double| 数量|
|----unit|否|String| 单位|
|--params|否|Map| 接口 /app/Business/Order/DeliveryConfirm 的请求参数|

### 请求参数Json格式
 
```
{
 "params" : [{
 "items" : [{
 "orderNo" : "String",
 "oitemId" : "String",
 "itemName" : "String",
 "quality" : 0,
 "unit" : "String"
 }],
 "params" : null
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--orderNo|否|String| 订单编码|
|--oitemId|否|String| 订单行id|
|--itemName|否|String| 商品名称|
|--success|否|Boolean| 是否成功|
|--msg|否|String| 信息|
|--quality|否|Double| 数量|
|--unit|否|String| 单位|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "orderNo" : "String",
 "oitemId" : "String",
 "itemName" : "String",
 "success" : true,
 "msg" : "String",
 "quality" : 0,
 "unit" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
