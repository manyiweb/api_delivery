# pos仅退运费接口
 

**请求URL：** 
- `/retail/app/Business/refund/expressFee`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|是|String| 订单id|
|expressFee|是|Double| 本次要退的运费|
|payType|是|String| 支付方式|
|cardSId|否|String| 退款的实体卡id|
|remark|否|String| 备注|
|totalExpressFee|否|Double| 总共要退的运费|
|refundExpressCoupon|否|Boolean| 是否退运费券|

### 请求参数Json格式
 
```
{
 "orderId" : "String",
 "expressFee" : 0,
 "payType" : "String",
 "cardSId" : "String",
 "remark" : "String",
 "totalExpressFee" : 0,
 "refundExpressCoupon" : true
}
```
