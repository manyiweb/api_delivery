# 获取会员积分抵扣信息(订金单)
 

**请求URL：** 
- `/pay/member/integral/rule/deposit/deduct`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|depositOrderId|是|Long||
|memberId|是|String||

### 请求参数Json格式
 
```
{
 "depositOrderId" : 0,
 "memberId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--integral|否|Double| 会员可用积分|
|--availableDeductAmount|否|Double| 积分可抵扣金额|
|--status|否|String| 是否启用积分抵扣，取值：Y - 是、N - 否|
|--hasDeductIntegral|否|Double| 已抵扣积分|
|--hasDeductAmount|否|Double| 已抵扣金额|
|--integralCardinalNumber|否|Double| 积分和金额比例计算 - 积分基数|
|--amountCardinalNumber|否|Double| 积分和金额比例计算 - 金额基数|
|--maxIntegralRate|否|Double| 积分和金额比例计算 最大积分抵扣比例|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "integral" : 0,
 "availableDeductAmount" : 0,
 "status" : "String",
 "hasDeductIntegral" : 0,
 "hasDeductAmount" : 0,
 "integralCardinalNumber" : 0,
 "amountCardinalNumber" : 0,
 "maxIntegralRate" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
