# 订单补收银使用订金单

**请求URL：** 
- `/retail-order-front/order/use/depositOrder`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|是|String| 订单id|
|requestId|否|String| 请求id|
|depositOrders|否|List| 订金单列表|
|--retailDepositOrderId|否|Long| 订金单标识|
|--retailDepositOrderNo|否|String| 订金单编号|
|--deductionMoney|否|Double| 抵扣金额|

### 请求参数Json格式
 
```
{
 "orderId" : "String",
 "requestId" : "String",
 "depositOrders" : [{
 "retailDepositOrderId" : 0,
 "retailDepositOrderNo" : "String",
 "deductionMoney" : 0
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--payAmount|否|Double| 待支付金额|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "payAmount" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
