# 详情-订金订单

**请求URL：** 
- `/retail/deposit/order/detail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||

### 请求参数Json格式
 
```
{
 "id" : 0
}
```
