# 列表-退款支付类型

**请求URL：** 
- `/retail/deposit/refund/payType `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|retailDepositOrderId|否|Long| 订金单标识|

###请求参数Json格式
 
```
{
 "retailDepositOrderId" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--code|否|String| 支付方式编码|
|--name|否|String| 支付方式名称|
|--payAmount|否|Double| 最高可退金额|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : [{
 "code" : "String",
 "name" : "String",
 "payAmount" : 0
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
