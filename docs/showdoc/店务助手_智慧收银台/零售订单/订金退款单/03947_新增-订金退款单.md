# 新增-订金退款单

**请求URL：** 
- `/retail/deposit/refund/add `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|retailDepositOrderId|否|Long| 原订金单标识|
|orderDocTypeId|否|String| 单据业务类型标识|
|staffId|否|String| 服务导购标识|
|memberId|否|String| 会员标识|
|refundMoney|否|Double| 退款金额|
|postingDate|否|DateTime| 过账日期|
|attachmentIds|否|List| 附件Id列表|
|payType|否|String| 退款方式编码|
|payTypeName|否|String| 退款方式名称|
|remark|否|String| 备注|

###请求参数Json格式
 
```
{
 "retailDepositOrderId" : 0,
 "orderDocTypeId" : "String",
 "staffId" : "String",
 "memberId" : "String",
 "refundMoney" : 0,
 "postingDate" : "DateTime",
 "attachmentIds" : null,
 "payType" : "String",
 "payTypeName" : "String",
 "remark" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--orderId|否|Long| 零售订金退款单标识|
|--orderType|否|String| 支付订单类型:零售-订金退款单|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : {
 "orderId" : 0,
 "orderType" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
