# 批量获取骑手位置
 

**请求URL：** 
- `/third/party/position/batch `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|list|否|List||

###请求参数Json格式
 
```
{
 "list" : null
}
```
