# 跑腿平台列表

**请求URL：** 
- `/app/order/thirdparty/delivery/config/list`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|type|是|String|要跑腿的订单业务类型，PROXY：代发单，RETAIL：零售订单 |

### 请求参数Json格式
 
```
{
 "type" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--stCode|否|String||
|--alias|否|String||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "stCode" : "String",
 "alias" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
