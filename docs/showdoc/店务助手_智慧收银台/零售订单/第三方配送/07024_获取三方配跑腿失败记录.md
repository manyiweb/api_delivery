# 获取三方配跑腿失败记录
 服务-retail
 

**请求URL：** 
- `/app/order/thirdparty/delivery/detail/v2`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|是|String||

### 请求参数Json格式
 
```
{
 "orderId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--deliveryId|否|Long|配送id |
|--success|否|Boolean| 是否推送成功|
|--msg|否|String| 失败原因(如果是取消，这里也是取消原因)|
|--tpOrderStatus|否|String| 第三方订单状态|
|--tpOrderStatusName|否|String| 第三方订单状态描述|
|--tpDeliveryStatus|否|String| 第三方配送状态|
|--tpDeliveryStatusName|否|String| 第三方配送状态描述|
|--deliverySysType|否|String| 配送商类型 fn蜂鸟 mt美团 其他|
|--deliverySysTypeName|否|String| 配送商类型名称|
|--createDate|否|DateTime|跑腿创建时间 |
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "deliveryId" : 0,
 "success" : true,
 "msg" : "String",
 "tpOrderStatus" : "String",
 "tpOrderStatusName" : "String",
 "tpDeliveryStatus" : "String",
 "tpDeliveryStatusName" : "String",
 "deliverySysType" : "String",
 "deliverySysTypeName" : "String",
 "createDate" : "DateTime"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
