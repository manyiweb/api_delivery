# 订单关联代发单的所有跑腿信息
 

**请求URL：** 
- `/app/order/thirdparty/detail/thirdparty/deliverys`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|否|String| 订单id|
|filterType|否|Integer| 0订单/代发单 1订单 2代发单|

### 请求参数Json格式
 
```
{
 "orderId" : "String",
 "filterType" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--orderType|否|String| retail订单 proxy代发单
 |
|--orderNo|否|String| 总部订单编码|
|--status|否|String| 状态|
|--statusName|否|String| 状态名称|
|--deliveryId|否|Long|配送id |
|--success|否|Boolean| 是否推送成功|
|--msg|否|String| 失败原因(如果是取消，这里也是取消原因)|
|--tpOrderStatus|否|String| 第三方订单状态|
|--tpOrderStatusName|否|String| 第三方订单状态描述|
|--tpDeliveryStatus|否|String| 第三方配送状态|
|--tpDeliveryStatusName|否|String| 第三方配送状态描述|
|--deliverySysType|否|String| 配送商类型 fn蜂鸟 mt美团 其他|
|--deliverySysTypeName|否|String| 配送商类型名称|
|--createDate|否|DateTime|跑腿创建时间 |
|--orderId|否|String| 代发单id或者订单id|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||

 }],

}
