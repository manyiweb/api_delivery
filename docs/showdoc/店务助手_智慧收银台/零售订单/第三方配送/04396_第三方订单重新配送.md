# 第三方配送订单同步
 

**请求URL：** 
- `/app/order/thirdparty/delivery/sync `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|否|String|要跑腿的订单id |
|type|否|String|要跑腿的订单业务类型，PROXY：代发单，RETAIL：零售订单 |
|products|否|List|部分配送的商品信息，该列表为空代表配送整单 |
|--orderItemId|否|String| 商品明细id|
|--quantity|否|Double| 数量|

###请求参数Json格式
 
```
{
 "orderId" : "String",
 "type" : "String",
 "products" : [{
 "orderItemId" : "String",
 "itemName" : "String",
 "quantity" : 0,
 "itemCode" : "String",
 "itemId" : "String",
 "specId" : "String",
 "price" : 0,
 "amount" : 0,
 "unit" : "String",
 "img" : "String",
 "gift" : true
 }]
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
