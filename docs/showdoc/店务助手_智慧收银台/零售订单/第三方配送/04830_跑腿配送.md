# 第三方配送订单同步
 

**请求URL：** 
- `/app/order/thirdparty/delivery/sync`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|是|String|要跑腿的订单id |
|type|是|String|要跑腿的订单业务类型，PROXY：代发单，RETAIL：零售订单 |
|products|否|List|部分配送的商品信息 |
|--orderItemId|否|String||
|--itemName|否|String||
|--quantity|否|Double||
|--itemCode|否|String||
|--itemId|否|String||
|--specId|否|String||
|--price|否|Double||
|--amount|否|Double||
|--unit|否|String||
|--img|否|String||
|--gift|否|Boolean||
|--productType|否|String||
|--productTypeName|否|String||
|--barcodeList|否|List||
|--batchList|否|List||
|cycleSaleOrderItems|否|List|周期id集合 |
|stCode|否|String|跑腿平台标识 |

### 请求参数Json格式
 
```
{
 "orderId" : "String",
 "type" : "String",
 "products" : [{
 "orderItemId" : "String",
 "itemName" : "String",
 "quantity" : 0,
 "itemCode" : "String",
 "itemId" : "String",
 "specId" : "String",
 "price" : 0,
 "amount" : 0,
 "unit" : "String",
 "img" : "String",
 "gift" : true,
 "productType" : "String",
 "productTypeName" : "String",
 "barcodeList" : null,
 "batchList" : null
 }],
 "cycleSaleOrderItems" : null,
 "stCode" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
