# 跑腿参数查询

**请求URL：** 
- `/runningErrands/config/info`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String||

### 请求参数Json格式
 
```
{
 "companyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--enableNewAutoCall|否|Integer| 启动自动呼叫跑腿，取值： 0不启用 1启用|
|--autoCallOrderType|否|Object| 允许自动呼叫跑腿的零售订单类型|
|----mallMinapp|否|Integer||
|----booking|否|Integer||
|----third|否|Integer||
|--autoCallOrderRule|否|Integer| 零售订单 - 自动呼叫跑腿的规则，取值： 1 - 按时间自动呼叫跑腿, 2 - 按制作状态自动呼叫跑腿|
|--autoCallOrderPdStatus|否|Integer| 自动呼叫跑腿的规则 - 零售订单 - 按制作状态自动呼叫跑腿，取值：1 - 已接单，2 - 制作中，3 - 制作完成，4 - 打包完成|
|--autoCallOrderTimeType|否|Integer| 自动呼叫跑腿的规则 - 零售订单 - 按时间自动呼叫跑腿 - 预约配送单 - 类型，取值：1 - 接单后，2 - 预约送达时间之前|
|--autoCallOrderTimeBValue|否|Integer| 自动呼叫跑腿的规则 - 零售订单 - 按时间自动呼叫跑腿 - 预约配送单 - 时间值|
|--autoCallOrderTimeBUnit|否|Integer| 自动呼叫跑腿的规则 - 零售订单 - 按时间自动呼叫跑腿 - 预约配送单 - 时间单位，取值：0 - 小时，1 - 分钟|
|--autoCallOrderTimeIValue|否|Integer| 自动呼叫跑腿的规则 - 零售订单 - 按时间自动呼叫跑腿 - 立即配送单 - 时间值|
|--autoCallOrderTimeIUnit|否|Integer| 自动呼叫跑腿的规则 - 零售订单 - 按时间自动呼叫跑腿 - 立即配送单 - 时间单位，取值：0 - 小时，1 - 分钟|
|--id|否|Long| 主键id|
|--paramConfig|否|String| 参数设置|
|--proxyParamConfig|否|String| 代发跑腿参数设置|
|--companyId|否|String| 门店id|
|--groupId|否|String| 分组id|
|--enabled|否|Integer| 启用手动呼叫 1启用0不启用|
|--enableAutoCall|否|Integer| 启用自动呼叫 1启用0不启用|
|--enableDockOrderCall|否|Integer| 启用外卖订单支持呼叫跑功能(只针对收银端配送模块版式二)|
|--enableHqOrderCall|否|Integer| 启用代发订单操作接单后自动呼叫跑腿 (只针对收银端极速版生产代发接单模块)|
|--pickupLocation|否|Object||
|----enablePickupLocation|否|Boolean| 是否启用骑手取货地点|
|----province|否|String| 省|
|----city|否|String| 市|
|----region|否|String| 区|
|----address|否|String| 详细地址|
|----longitude|否|Double| 经度|
|----latitude|否|Double| 纬度|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
