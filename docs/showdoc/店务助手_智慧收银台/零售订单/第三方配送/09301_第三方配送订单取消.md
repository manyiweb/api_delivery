# 第三方配送订单取消
 

**请求URL：** 
- `/app/order/thirdparty/delivery/cancel`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|是|String|要跑腿的订单id |
|type|是|String|要跑腿的订单业务类型，PROXY：代发单，RETAIL：零售订单 |

### 请求参数Json格式
 
```
{
 "orderId" : "String",
 "type" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
