# 查询配送进度（点单）
 

**请求URL：** 
- `/app/order/thirdparty/delivery/detail/meal`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|deliveryId|是|Long|配送id，订单详情有返回 |
|orderNo|是|String| 订单号|

### 请求参数Json格式
 
```
{
 "deliveryId" : 0,
 "orderNo" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--orderNo|否|String| 订单号|
|--deliveryCompanyName|否|String| 配送门店名称|
|--deliveryCompanyAddress|否|String| 配送门店地址|
|--deliveryCompanyLatitude|否|Double| 配送门店纬度|
|--deliveryCompanyLongitude|否|Double| 配送门店经度|
|--msg|否|String| 错误信息|
|--riderName|否|String| 骑手名称|
|--riderPhone|否|String| 骑手电话|
|--longitude|否|Double| 骑手经度|
|--latitude|否|Double| 骑手纬度|
|--sendTime|否|DateTime| 预计到达时间|
|--deliveredTime|否|DateTime| 实际送达时间|
|--deliverySysType|否|String| 配送商类型|
|--deliverySysTypeName|否|String| 配送商类型名称|
|--receiverLongitude|否|Double| 收货人经度|
|--receiverLatitude|否|Double| 收货人纬度|
|--distance|否|Double| 距离|
|--tpOrderStatus|否|String| 第三方订单状态|
|--tpOrderStatusName|否|String| 第三方订单状态描述|
|--tpDeliveryStatus|否|String| 第三方配送状态|
|--tpDeliveryStatusName|否|String| 第三方配送状态描述|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
