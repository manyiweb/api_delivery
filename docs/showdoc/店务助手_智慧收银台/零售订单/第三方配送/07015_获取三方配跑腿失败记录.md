# 获取三方配跑腿失败记录

**请求URL：** 
- `/app/order/thirdparty/delivery/fail/list`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|是|String||

### 请求参数Json格式
 
```
{
 "orderId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--id|否|Long|id |
|--orderId|否|String|订单id |
|--errorReason|否|String|错误原因 |
|--eventRecordId|否|Long|事件id，重试用 |
|--deliveryId|否|Long|配送id |
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : [{
 "id" : 0,
 "orderId" : "String",
 "errorReason" : "String",
 "eventRecordId" : 0,
 "deliveryId" : 0
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
