# 功能描述: 查询赊销可选择账期列表
 

**请求URL：** 
- `/app/Business/credit/accountPeriod `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|memberId|是|String| 会员ID|

###请求参数Json格式
 
```
{
 "memberId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--creditPeriod|否|Integer| 账期天数（例：2）|
|--creditPeriodStr|否|String| 账期天数（例：2天）|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : [{
 "creditPeriod" : 0,
 "creditPeriodStr" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
