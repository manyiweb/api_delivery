# 地点管理新增
 

**请求URL：** 
- `前台 /mct/hr/location/add`
- `/hr/location/add `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 主键|
|locationCode|否|String| 地点编号|
|locationName|否|String| 地点简称|
|locationProvince|否|String| 所在省|
|locationCity|否|String| 所在市|
|locationRegion|否|String| 所在区|
|locationAddress|否|String| 详细地址|
|locationPerson|否|String| 业务负责人|
|locationPhone|否|String| 联系电话|
|longitude|否|Double| 经度|
|latitude|否|Double| 纬度|
|status|否|Integer| 状态|
|remark|否|String| 备注|

###请求参数Json格式
 
```
{
 "id" : 0,
 "locationCode" : "String",
 "locationName" : "String",
 "locationProvince" : "String",
 "locationCity" : "String",
 "locationRegion" : "String",
 "locationAddress" : "String",
 "locationPerson" : "String",
 "locationPhone" : "String",
 "longitude" : 0,
 "latitude" : 0,
 "status" : 0,
 "remark" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
