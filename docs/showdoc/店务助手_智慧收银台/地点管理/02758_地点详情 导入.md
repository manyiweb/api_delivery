# 地点管理 导入

**请求URL：** 
- `前台 /mct/file/location/exceladd `
- `/file/location/exceladd `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 主键|
|file|是|file| 	|

###请求参数Json格式
 
```
{
 "tokenId" : 0，
 "file":
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|downloadURL|否|String| 错误信息|
|successCount|否|Int| 成功数据数|
|totalCount|否|Int| 数据总数|
|errorCount|否|Int| 错误数据数|




###返回参数Json格式
 
```
{
	"downloadURL": "https://upaiyun.reabam.com/export/地址管理导入失败数据1588922846861(0-1).xlsx",
	"successCount": 0,
	"ErrorCode": "",
	"ResultString": "操作成功",
	"totalCount": 1,
	"errorCount": 1,
	"ResultInt": 0
}
```
