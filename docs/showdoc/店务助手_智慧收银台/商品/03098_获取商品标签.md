# 获取商品标签

**请求URL：** 
- `/app/Product/LabelsByGroup `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|itemId|否|String| 商品标识|
|tokenId|否|String||

###请求参数Json格式
 
```
{
 "itemId" : "String",
 "tokenId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|DataLine|否|List| 主数据|
|--lineNum|否|Long| 行号|
|--isMultiple|否|Integer| 是否允许多选（1-允许；0-不允许）|
|--remark|否|String| 备注|
|--id|否|Long| 标签组主键标识,id为空字符标识该标签无标签组|
|--labelGroupCode|否|String| 标签组编码|
|--labelGroupName|否|String| 标签组名称|
|--status|否|Integer| 是否启用（1-允许；0-不允许）|
|--mustSelect|否|Boolean| 是否必选|
|--labels|否|List| 标签列表|
|----labelId|否|String| 标签ID|
|----isLabelPrice|否|Integer| 是否开启标签零售价|
|----labelGroupCode|否|String| 标签组编码|
|----labelName|否|String| 标签名称|
|----labelGroupId|否|Long| 标签组ID|
|----labelCode|否|String| 标签编码|
|----labelGroupName|否|String| 标签组名称|
|----labelPrice|否|Double| 标签零售价|
|----isDefault|否|Integer| 是否默认标签|
|ErrorCode|否|String| 错误编码|
|ResultString|否|String| 消息|
|ResultInt|否|String| ResultInt|
