# 单规格商品获取点餐标签（按标签组分组）

**请求URL：** 
- `/app/Product/label/group `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|specId|否|String| 规格id|

###请求参数Json格式
 
```
{
 "specId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--id|否|Long| 主键标识|
|--labelGroupCode|否|String| 标签组编码|
|--labelGroupName|否|String| 标签组名称|
|--lineNum|否|Long| 行号|
|--status|否|Integer| 活跃状态(0-停用,1-启用)|
|--isMultiple|否|Integer| 是否允许多选(0-单选;1-多选)|
|--labels|否|List| 点餐标签|
|----fid|否|String| id|
|----version|否|Integer| 版本|
|----labelCode|否|String| 标签编码|
|----labelName|否|String| 标签名称|
|----labelPrice|否|Double| 标签零售价|
|----isLabelPrice|否|Integer| 是否开启标签零售价|
|----isAllShop|否|Integer| 是否所有商品|
|----lineNum|否|Integer| 行号|
|----isActive|否|Integer| 是否启用|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : [{
 "id" : 0,
 "labelGroupCode" : "String",
 "labelGroupName" : "String",
 "lineNum" : 0,
 "status" : 0,
 "isMultiple" : 0,
 "labels" : [{
 "fid" : "String",
 "version" : 0,
 "labelCode" : "String",
 "labelName" : "String",
 "labelPrice" : 0,
 "isLabelPrice" : 0,
 "isAllShop" : 0,
 "lineNum" : 0,
 "isActive" : 0
 }]
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
