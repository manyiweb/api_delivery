# 商品搜索
 

**请求URL：** 
- `/app/productSearch/guide/search `

**请求方式：**
- ALL
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|filterType|否|String| 过滤类型 WhsIn - 入库；WhsOut - 出库；Order - 下单；Refund - 退货；Allot - 调拨；Need - 要货 CheckVouch - 盘点；Inventory - 存货；B2BOrder - 订货单；B2BRefund - 订货退货单；GoodsIn - 采购单（进货单）|
|sword|否|String|搜索关键词|
|orderId|否|String|业务单据ID|
|isShopCart|否|number|是否要查询商品在购物车里的数量返回，默认： 否 , 1 - 是, 0 - 否|
|pageIndex|否|Integer| 页号|
|pageSize|否|Integer| 页大小|

###请求参数Json格式
 
```
{
 "filterType" : "String",
 "sword" : "String",
 "pageIndex" : 0,
 "pageSize" : 0
}
```
