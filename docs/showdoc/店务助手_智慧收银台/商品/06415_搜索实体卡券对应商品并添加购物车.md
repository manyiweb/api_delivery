# 搜索实体卡券对应商品并添加购物车
 

**请求URL：** 
- `retail/app/productSearch/guide/mentityCard/search`

**请求方式：**
- ALL
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |

 CheckVouch - 盘点；Inventory - 存货；B2BOrder - 订货单；B2BRefund - 订货退货单；GoodsIn - 采购单（进货单）|
|isActive|否|Integer| 活跃状态 1 - 活跃, 0 - 不活跃|

|orderItemId|否|String| 单据明细行id|

 |

|----mentityCardsResult|否|Object||
|------mid|否|String||

|----denomination|否|Double| 面额|
