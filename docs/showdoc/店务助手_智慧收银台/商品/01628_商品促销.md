# 商品促销清单

**请求URL：** 
- `/product/promotion `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|itemId|否|String| 商品标识|
|tokenId|否|String||

###请求参数Json格式
 
```
{
 "itemId" : "String",
 "tokenId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--specId|否|String| 规格标识|
|--plans|否|List| 促销列表|
|----projectId|否|String| 促销方案ID|
|----planId|否|String| 促销标识|
|----planType|否|String| 促销类型|
|----planTypeName|否|String| 促销类型名称|
|----planName|否|String| 促销名称|
|----planTitle|否|String| 促销标题|
|----spType|否|String| 促销规则类型|
|----spTypeName|否|String| 促销规则类型描述|
|----itemKey|否|String| 购物车KEY，仅组合促销时返回|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|


###返回参数Json格式
 
```
{
 "data" : [{
 "specId" : "String",
 "plans" : [{
 "projectId" : "String",
 "planId" : "String",
 "planType" : "String",
 "planTypeName" : "String",
 "planName" : "String",
 "planTitle" : "String",
 "spType" : "String",
 "spTypeName" : "String",
 "itemKey" : "String"
 }]
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String"
}
```
