# 储值卡修改余额
 

**请求URL：** 
- `/mem/memberCard/change/balance`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|String| 卡卷号|
|rechargeBalance|否|Double| 充值余额|
|giftBalance|否|Double| 赠送|
|dgatheringAmount|是|Double| 收银流水金额|
|remark|否|String| 赠送|
|type|是|Integer| 1 充值 -1退款|
|cardType|否|String| 卡类型 ShoppingCard("购物卡"),
 ServiceCard("服务卡"),|
|memberId|否|String| 会员标识|

### 请求参数Json格式
 
```
{
 "id" : "String",
 "rechargeBalance" : 0,
 "giftBalance" : 0,
 "dgatheringAmount" : 0,
 "remark" : "String",
 "type" : 0,
 "cardType" : "String",
 "memberId" : "String"
}
```
