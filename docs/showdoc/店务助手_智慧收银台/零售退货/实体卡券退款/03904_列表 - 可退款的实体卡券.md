# 列表 - 可退款的实体卡券

**请求URL：** 
- `retail/app/Business/Refund/EntityCard/list `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|否|String| 零售订单标识|
|cardCode|否|String| 类型：EntityCard-实体卡；EntityCertificate-实体卡券|

###请求参数Json格式
 
```
{
 "orderId" : "String",
 "cardCode" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--cardSId|否|String| 实体卡券标识|
|--cardNo|否|String| 实体卡券号|
|--cardName|否|String| 实体卡券名称|
|--refundableMoney|否|Double| 可退款金额|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : [{
 "cardSId" : "String",
 "cardNo" : "String",
 "cardName" : "String",
 "refundableMoney" : 0
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
