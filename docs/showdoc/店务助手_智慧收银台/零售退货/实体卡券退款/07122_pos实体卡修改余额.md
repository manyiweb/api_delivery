# pos实体卡修改余额
 

**请求URL：** 
- `/mem/entitycard/change/balance`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|String| 卡卷号|
|rechargeBalance|否|Double| 充值余额|
|giftBalance|否|Double| 赠送|
|dgatheringAmount|是|Double| 收银流水金额|
|remark|否|String| 赠送|
|type|是|Integer| 1 充值 -1退款|

### 请求参数Json格式
 
```
{
 "id" : "String",
 "rechargeBalance" : 0,
 "giftBalance" : 0,
 "dgatheringAmount" : 0,
 "remark" : "String",
 "type" : 0
}
```
