#

@Title: </p>


@Description: 合并退款计算 </p>
 

**请求URL：** 合并退款计算
- `retail/app/Business/refund/calculate`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|是|String| 订单id|
|refundMoney|是|Double| 退款金额|
|items|是|List||
|--refundId|否|String| 关联销售退货单drefund 退货单id|
|--orderId|否|String| 关联销售订单dorder 订单id|
|--orderItemId|是|String| 关联销售订单明细dorderitem 订单明细id|
|--quantity|否|Double| 数量|
|--itemId|否|String| 关联商品mitem 商品id|
|--specId|否|String| 关联商品规格表mitemspec 商品规格id|
|--refundMoney|是|Double| 退款金额小计|

### 请求参数Json格式
 
```
{
 "orderId" : "String",
 "refundMoney" : 0,
 "items" : [{
 "refundId" : "String",
 "orderId" : "String",
 "orderItemId" : "String",
 "quantity" : 0,
 "itemId" : "String",
 "specId" : "String",
 "refundMoney" : 0
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|是|String| 订单id|
|refundMoney|否|Double| 退款金额|
|payItemList|否|List| 支付方式商品退款列表|
|--payMoney|否|Double| 退款原因|
|--payTypeCode|否|String||
|--items|否|List||
|----refundId|否|String| 关联销售退货单drefund 退货单id|
|----orderId|否|String| 关联销售订单dorder 订单id|
|----orderItemId|是|String| 关联销售订单明细dorderitem 订单明细id|
|----quantity|否|Double| 数量|
|----itemId|否|String| 关联商品mitem 商品id|
|----specId|否|String| 关联商品规格表mitemspec 商品规格id|
|----refundMoney|是|Double| 退款金额小计|


### 返回参数Json格式
 
```
{
 "orderId" : "String",
 "refundMoney" : 0,
 "payItemList" : [{
 "payMoney" : 0,
 "payTypeCode" : "String",
 "items" : [{
 "refundId" : "String",
 "orderId" : "String",
 "orderItemId" : "String",
 "quantity" : 0,
 "itemId" : "String",
 "specId" : "String",
 "refundMoney" : 0
 }]
 }]
}
```
