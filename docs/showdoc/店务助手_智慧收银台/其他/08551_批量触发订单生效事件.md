# 

**请求URL：** 
- `/retail-order-support/app/test/RetailOrderEffectiveEvent`

**请求方式：**
- POST
- RequestBody

|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderIds|否|List|订单id列表|

### 请求参数Json格式
 
```
{
 "orderIds" : null
}
```

|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||

{
