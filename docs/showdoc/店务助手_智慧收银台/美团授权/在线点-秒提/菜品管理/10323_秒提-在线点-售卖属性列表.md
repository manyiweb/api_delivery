# 秒提-在线点-售卖属性列表

**请求URL：** 
- `/dock/mt/miaoti/saleList/{source}`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|keyword|否|String||
|startTime|否|Object||
|--start|否|DateTime||
|--end|否|DateTime||
|shelfStatus|否|Integer| 过滤条件 1-上架 0-下架|
|id|否|String||
|pageSize|否|Integer||
|pageNo|否|Integer||
|sortField|否|String||
|sortDirection|否|String||
|viewId|否|String||

### 请求参数Json格式
 
```
{
 "keyword" : "String",
 "startTime" : {
 "start" : "DateTime",
 "end" : "DateTime"
 },
 "shelfStatus" : 0,
 "id" : "String",
 "pageSize" : 0,
 "pageNo" : 0,
 "sortField" : "String",
 "sortDirection" : "String",
 "viewId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--content|否|List||
|----id|否|Long| 主键id|
|----saleAttributeCode|否|String| 售卖属性编码|
|----saleAttributeValue|否|String| 售卖属性名称|
|----rank|否|Integer| 售卖属性排序|
|----createName|否|String| 创建人|
|----createDate|否|DateTime| 创建时间|
|----modifyDate|否|DateTime| 修改时间|
|--pageSize|否|Integer||
|--pageNo|否|Integer||
|--total|否|Long||
|--totalPage|否|Integer||
|--hasNextPage|否|Boolean||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式

```
{
 "data" : {
 "content" : [{
 "id" : 0,

 }],
 "pageSize" : 0,

 },

}
```
