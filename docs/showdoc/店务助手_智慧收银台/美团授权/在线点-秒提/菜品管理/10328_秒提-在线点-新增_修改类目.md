# 秒提-在线点-类目 新增/更新类目

**请求URL：** 
- `/dock/mt/miaoti/category/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否(更新必选)|Long| 主键ID|
|backgroundCategoryId|是|String| 类目编码|
|backgroundCategoryName|是|String| 类目名称|
|rank|是|Integer| 类目排序|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "backgroundCategoryId" : "String",
 "backgroundCategoryName" : "String",
 "rank" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long| 主键ID|
|--backgroundCategoryId|否|String| 类目编码|
|--backgroundCategoryName|否|String| 类目名称|
|--rank|否|Integer| 类目排序|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "backgroundCategoryId" : "String",
 "backgroundCategoryName" : "String",
 "rank" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
