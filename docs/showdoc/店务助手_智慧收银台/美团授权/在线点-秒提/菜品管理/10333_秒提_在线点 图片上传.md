# 秒提-在线点 图片上传

**请求URL：** 
- `/dock/mt/miaoti/product/uploadImage`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|pictureUrlList|是|List| 图片url|
|--pictureUrl|是|String| 图片url|

### 请求参数Json格式
 
```
{
 "pictureUrlList" : [{
 "pictureUrl" : "String"
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--miaotiProductPictureUrlRespList|否|List| 响应列表|
|----pictureUrl|否|String| 图片url|
|----uploadResult|否|String| 上传结果|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "miaotiProductPictureUrlRespList" : [{
 "pictureUrl" : "String",
 "uploadResult" : "String"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
