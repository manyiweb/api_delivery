# 秒提-在线点-商品sku价格列表V2-所有分组商品

**请求URL：** 
- `/dock/mt/miaoti/product/menu/template/all`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|templateId|是|Long| 菜谱模板id|

### 请求参数Json格式
 
```
{
 "templateId" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--miaotiMenuTemplateV2DTOList|否|List| 所有商品|
|----id|否|Long| 主键id|
|----spuCode|否|String| 商品编码|
|----templateName|否|String| 商品名称|
|----type|否|String| 商品类型|
|----backgroundCategoryName|否|String| 商品类目|
|----skuPriceList|否|List| sku和价格列表|
|------vendorSkuId|否|String| sku编码|
|------vendorSkuName|否|String| sku名称|
|------price|否|Double| 价格|
|------qty|否|Integer| 库存数收银端请求才会返回，其他端为空|
|------qtyDesc|否|String| 库存数描述|
|------compProductId|否|String| 商家id|
|----createDate|否|DateTime| 创建时间|
|----openCustomPrice|否|Integer| 是否开启自主定价 0-否 1-是|
|----stockStatus|否|Integer| 库存状态（1=有限库存，2=无限库存）|
|--soldOutCount|否|Integer| 售罄数量|
|--categoryCountMap|否|Map| 菜谱类目数量|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
