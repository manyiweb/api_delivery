# 秒提-在线点-商品组商品表列表

**请求URL：** 
- `/dock/mt/miaoti/product/menu/template/product/list/{source}`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|keyword|否|String||
|startTime|否|Object||
|--start|否|DateTime||
|--end|否|DateTime||
|mid|否|String||
|id|否|String||
|id|否|String||
|pageSize|否|Integer||
|pageNo|否|Integer||
|sortField|否|String||
|sortDirection|否|String||
|viewId|否|String||

```
{
 "keyword" : "String",
 "startTime" : {
 "start" : "DateTime",

 },

```
