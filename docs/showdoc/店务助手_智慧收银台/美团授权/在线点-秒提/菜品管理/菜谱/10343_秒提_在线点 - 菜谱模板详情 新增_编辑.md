# 秒提/在线点 - 菜谱模板详情 新增/编辑
 

**请求URL：** 
- `/dock/mt/miaoti/product/menu/template/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 模板ID（编辑时必填）|
|templateName|否|String| 模板名称|
|description|否|String| 模板描述|
|rank|否|Integer| 排序（数字越小越靠前）|
|status|否|Integer| 活跃状态（0=停用，1=活跃）|
|categorys|否|List| 类目(覆盖)|
|--id|否|Long| 类目ID（编辑时必填）|
|--backgroundCategoryId|否|String| 类目编码|
|--backgroundCategoryName|否|String| 类目名称|
|--rank|否|Integer| 排序（数字越小越靠前）|
|--groupType|否|Integer| 分组类型（1=普通，2=餐具）|
|--top|否|Integer| 是否置顶（0=否，1=是）|
|--description|否|String| 分组描述|
|--hide|否|Integer| 是否隐藏（0=显示，1=隐藏）|
|--delVendorSpuIds|否|List| 移除的商品|
|--products|否|List| 应用商品(覆盖)|
|----vendorSpuId|否|String| 商品编码|
|----skus|否|List||
|------vendorSkuId|否|String| SKU编码|
|------price|否|Double| 自定义价格（单位：元）|
|------openCustomPrice|否|Integer| 是否开启自定义价格（0=否，1=是）|
|comp|否|Object||
|--companyIds|否|List| 新增的应用门店（门店存在则跳过）|
|--delCompanyIds|否|List| 删除的应用门店|
