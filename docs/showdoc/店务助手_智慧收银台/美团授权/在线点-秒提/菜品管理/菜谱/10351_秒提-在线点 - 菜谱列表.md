# 秒提-在线点 菜谱列表

**请求URL：** 
- `/dock/mt/miaoti/menuList/{source}`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|keyword|否|String||
|startTime|否|Object||
|--start|否|DateTime||
|--end|否|DateTime||

### 请求参数Json格式
 
```
{
 "keyword" : "String",
 "startTime" : {
 "start" : "DateTime",
 "end" : "DateTime"
 }
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--content|否|List||
|----id|否|Long| 主键id|
|----templateCode|否|String| 模板编码|
|----templateName|否|String| 模板名称|
|----description|否|String| 模板描述|
|----rank|否|Integer| 排序|
|----status|否|Integer| 活跃状态 1-启用 0-禁用|
|----createName|否|String| 创建人|
|----createDate|否|String| 创建时间|
|--pageSize|否|Integer||
|--pageNo|否|Integer||
|--total|否|Long||
|--totalPage|否|Integer||
|--hasNextPage|否|Boolean||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "content" : [{
 "id" : 0,
 "templateCode" : "String",
 "templateName" : "String",
 "description" : "String",
 "rank" : 0,
 "status" : 0,
 "createName" : "String",
 "createDate" : "String"
 }],
 "pageSize" : 0,
 "pageNo" : 0,
 "total" : 0,
 "totalPage" : 0,
 "hasNextPage" : true
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
