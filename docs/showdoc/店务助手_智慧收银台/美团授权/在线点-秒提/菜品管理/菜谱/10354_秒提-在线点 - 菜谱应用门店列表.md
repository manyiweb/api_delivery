# 秒提-在线点-菜谱应用门店列表

**请求URL：** 
- `/dock/mt/miaoti/product/menu/template/comp/list/{source}`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|keyword|否|String||
|startTime|否|Object||
|--start|否|DateTime||
|--end|否|DateTime||
|id|否|Long||

### 请求参数Json格式
 
```
{
 "keyword" : "String",
 "startTime" : {
 "start" : "DateTime",
 "end" : "DateTime"
 },
 "id" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--content|否|List||
|----id|否|Long| 关联ID|
|----templateId|否|Long| 模板ID|
|----companyId|否|String| 门店ID|
|----companyName|否|String| 门店名称|
|----companyCode|否|String| 门店编码|
|----createName|否|String| 创建人|
|----createDate|否|DateTime| 创建时间|
|--pageSize|否|Integer||
|--pageNo|否|Integer||
|--total|否|Long||
|--totalPage|否|Integer||
|--hasNextPage|否|Boolean||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "content" : [{
 "id" : 0,
 "templateId" : 0,
 "companyId" : "String",
 "companyName" : "String",
 "companyCode" : "String",
 "createName" : "String",
 "createDate" : "DateTime"
 }],
 "pageSize" : 0,
 "pageNo" : 0,
 "total" : 0,
 "totalPage" : 0,
 "hasNextPage" : true
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
