# 秒提-在线点-下发历史详情列表

**请求URL：** 
- `/dock/mt/miaoti/task/detail/list/{source}`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|keyword|否|String||
|executeStatus|否|Integer||
|startTime|否|Object||
|--start|否|DateTime||
|--end|否|DateTime||
|menuTaskId|否|Long| 关联任务id|
|templateId|否|Long| 关联模板id|
|id|否|String||
|pageSize|否|Integer||
|pageNo|否|Integer||
|sortField|否|String||
|sortDirection|否|String||
|viewId|否|String||

### 请求参数Json格式
 
```
{
 "keyword" : "String",
 "executeStatus" : 0,
 "startTime" : {
 "start" : "DateTime",
 "end" : "DateTime"
 },
 "menuTaskId" : 0,
 "templateId" : 0,
 "id" : "String",
 "pageSize" : 0,
 "pageNo" : 0,
 "sortField" : "String",
 "sortDirection" : "String",
 "viewId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--content|否|List||
|----id|否|Long| 主键ID|
|----templateId|否|Long| 关联模板ID（关联miaoti_menu_template.id）|
|----menuTaskId|否|Long| 关联任务ID（关联miaoti_menu_task.task_id）|
|----companyId|否|String| 门店ID|
|----companyCode|否|String| 门店编码|
|----companyName|否|String| 门店名称|
|----executeTime|否|DateTime| 执行时间|
|----executeStatus|否|String| 执行状态（0=等待执行，1=执行成功，2=执行失败）|
|----description|否|String| 描述（失败时填写原因）|
|--pageSize|否|Integer||
|--pageNo|否|Integer||
|--total|否|Long||
|--totalPage|否|Integer||
|--hasNextPage|否|Boolean||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||

```
 }],

 },

 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
