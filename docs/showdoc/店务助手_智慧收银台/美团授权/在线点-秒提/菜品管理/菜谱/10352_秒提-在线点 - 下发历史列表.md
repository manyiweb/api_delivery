# 秒提-在线点-下发历史列表

**请求URL：** 
- `/dock/mt/miaoti/taskList/{source}`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|keyword|否|String||
|startTime|否|Object||
|--start|否|DateTime||
|--end|否|DateTime||

### 请求参数Json格式
 
```
{
 "keyword" : "String",
 "startTime" : {
 "start" : "DateTime",
 "end" : "DateTime"
 }
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--content|否|List||
|----id|否|Long| 主键id|
|----taskId|否|String| 任务编码|
|----sendTime|否|DateTime| 下发时间|
|----createName|否|String| 操作人|
|----productCount|否|Integer| 下发商品数量|
|----companyCount|否|Integer| 下发门店数量|
|----executeCount|否|Integer| 已执行门店数|
|--pageSize|否|Integer||
|--pageNo|否|Integer||
|--total|否|Long||
|--totalPage|否|Integer||
|--hasNextPage|否|Boolean||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "content" : [{
 "id" : 0,
 "taskId" : "String",
 "sendTime" : "DateTime",
 "createName" : "String",
 "productCount" : 0,
 "companyCount" : 0,
 "executeCount" : 0
 }],
 "pageSize" : 0,
 "pageNo" : 0,
 "total" : 0,
 "totalPage" : 0,
 "hasNextPage" : true
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
