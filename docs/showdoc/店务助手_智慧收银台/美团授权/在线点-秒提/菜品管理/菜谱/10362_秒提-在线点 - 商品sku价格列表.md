# 秒提-在线点-商品sku价格列表

**请求URL：** 
- `/dock/mt/miaoti/product/menu/template/sku/price/list`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|vendorSpuId|是|String| 商品id|
|templateId|否|Long| 模板id|

### 请求参数Json格式
 
```
{
 "vendorSpuId" : "String",
 "templateId" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--skuPriceList|否|List| 商品价格列表|
|----vendorSkuId|否|String| sku编码|
|----vendorSkuName|否|String| sku名称|
|----price|否|Double| 价格|
|--vendorSpurId|否|String| 商品id|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "skuPriceList" : [{
 "vendorSkuId" : "String",
 "vendorSkuName" : "String",
 "price" : 0
 }],
 "vendorSpurId" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
