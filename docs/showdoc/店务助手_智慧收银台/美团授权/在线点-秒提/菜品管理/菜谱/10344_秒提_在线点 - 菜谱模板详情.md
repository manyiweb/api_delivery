# 秒提/在线点 - 菜谱模板详情
 

**请求URL：** 
- `/dock/mt/miaoti/product/menu/template/detail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long||
|sword|否|String||

### 请求参数Json格式
 
```
{
 "id" : 0,
 "sword" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long| 模板ID|
|--templateCode|否|String| 模板编码|
|--templateName|否|String| 模板名称|
|--description|否|String| 模板描述|
|--rank|否|Integer| 排序（数字越小越靠前）|
|--status|否|Integer| 活跃状态（0=停用，1=活跃）|
|--createDate|否|DateTime| 创建时间|
|--modifyDate|否|DateTime| 修改时间|
|--categorys|否|List| 类目(覆盖)|
|----id|否|Long| 类目ID|
|----templateId|否|Long| 关联模板ID|
|----backgroundCategoryId|否|String| 类目编码|
|----backgroundCategoryName|否|String| 类目名称|
|----rank|否|Integer| 排序（数字越小越靠前）|
|----groupType|否|Integer| 分组类型（1=普通，2=餐具）|
|----top|否|Integer| 是否置顶（0=否，1=是）|
|----description|否|String| 分组描述|
|----hide|否|Integer| 是否隐藏（0=显示，1=隐藏）|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||

}
