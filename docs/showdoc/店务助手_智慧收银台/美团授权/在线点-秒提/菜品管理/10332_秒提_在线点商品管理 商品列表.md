# 秒提-获取商品列表

**请求URL：** 
- `/dock/mt/miaoti/product/getList/{source}`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|keyword|否|String||
|startTime|否|Object||
|--start|否|DateTime||
|--end|否|DateTime||
|categoryName|否|String||
|type|否|Integer| 商品类型 1普通商品 2固定套餐 3餐具|
|shelfStatus|否|Integer| 过滤状态|
|id|否|String||
|pageSize|否|Integer||
|pageNo|否|Integer||
|sortField|否|String||
|sortDirection|否|String||
|viewId|否|String||

### 请求参数Json格式
 
```
{
 "keyword" : "String",
 "startTime" : {
 "start" : "DateTime",
 "end" : "DateTime"
 },
 "categoryName" : "String",
 "type" : 0,
 "shelfStatus" : 0,
 "id" : "String",
 "pageSize" : 0,
 "pageNo" : 0,
 "sortField" : "String",
 "sortDirection" : "String",
 "viewId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--content|否|List||
|----id|否|Long| 主键id|
|----vendorSpuId|否|String| 商品编码|
|----name|否|String| 商品名称|
|----type|否|String| 商品类型 1=普通商品，2=固定套餐，3=餐具|
|----backgroundCategoryName|否|String| 类目名称|
|----createName|否|String| 创建人|
|----createDate|否|DateTime| 创建时间|
|----auditFail|否|String| 是否审核失败 1-失败 0-成功|
|----failDescription|否|String| 审核失败原因|
|--pageSize|否|Integer||
|--pageNo|否|Integer||
|--total|否|Long||
|--totalPage|否|Integer||
|--hasNextPage|否|Boolean||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
