# 秒提-在线点-批量更新门店库存

**请求URL：** 
- `/dock/mt/miaoti/product/batch/update/stock`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|miaotiProductSkuStockReqList|否|List||
|--vendorShopId|否|String| 门店id|
|--vendorSpuId|否|String| 商品id|
|--vendorSkuId|否|String| 商品sku id|
|--stock|否|Integer| 库存数量 置满就填9999 ，售罄就填0|
|--productScope|否|Integer| 商品类型 0-品牌商品 1-门店商品|

### 请求参数Json格式
 
```
{
 "miaotiProductSkuStockReqList" : [{
 "vendorShopId" : "String",
 "vendorSpuId" : "String",
 "vendorSkuId" : "String",
 "stock" : 0,
 "productScope" : 0
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
