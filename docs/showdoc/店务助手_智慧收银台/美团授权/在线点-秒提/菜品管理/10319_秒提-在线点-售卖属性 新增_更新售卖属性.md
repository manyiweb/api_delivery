# 秒提-在线点-售卖属性 新增/更新售卖属性

**请求URL：** 
- `/dock/mt/miaoti/saleattr/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否（更新必选）|Long| id|
|saleAttributeCode|是|String| 售卖属性编码|
|saleAttributeValue|是|String| 售卖属性名称|
|rank|否|Integer| 售卖属性排序,默认填 1 即可|
|shelfStatus|否|Integer| 全国上下架状态,1:上架,0:下架|
|type|否|Integer| 附加售卖属性或标准售卖属性 1：标准售卖属性|
|useMemberPoint|否|Boolean| 是否可用会员积分抵扣 true:可用 false:不可用|
|description|否|String| 描述|
|source|否|Integer| 数据来源 1-品牌自建 2-品牌下发 3-门店自建|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "saleAttributeCode" : "String",
 "saleAttributeValue" : "String",
 "rank" : 0,
 "shelfStatus" : 0,
 "type" : 0,
 "useMemberPoint" : true,
 "description" : "String",
 "source" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--saleAttributeCode|否|String| 售卖属性编码|
|--saleAttributeValue|否|String| 售卖属性名称|
|--shelfStatus|否|Integer| 全国上下架状态 1：上架，0：下架。默认填 1 即可，表示售卖属性全国上架|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "saleAttributeCode" : "String",
 "saleAttributeValue" : "String",
 "shelfStatus" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
