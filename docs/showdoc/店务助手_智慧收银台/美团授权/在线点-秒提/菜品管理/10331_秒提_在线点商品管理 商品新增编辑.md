# 秒提/在线点商品管理 商品新增编辑
 

**请求URL：** 
- `/dock/mt/miaoti/product/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 主键ID（更新时使用）|
|vendorSpuId|是|String| 商品唯一编码|
|name|是|String| 商品名称|
|type|否|Integer| 商品类型（1=普通商品，2=固定套餐，3=餐具）|
|brief|否|String| 商品简述|
|description|否|String| 商品描述|
|material|否|String| 主要原料|
|shelfStatus|是|Integer| 上下架状态（0=下架，1=上架）|
|useMemberPoint|是|Boolean| 是否支持积分抵扣（false=否，true=是）|
|stockStatus|是|Integer| 库存状态（1=有限库存，2=无限库存）|
|source|否|Integer| 数据来源（1=品牌自建，2=品牌下发，3=门店自建）|
|backgroundCategoryId|否|String| 类目id|
|backgroundCategoryName|否|String| 类目名称|
|pictureList|否|List| 商品图片列表|
|--pictureType|否|Integer| 图片类型（1=头像图片，2=描述图片）|
|--pictureUrl|否|String| 图片URL地址|
|--sort|否|Integer| 排序（数字越小越靠前）|
|skuList|是|List| SKU列表|
|--vendorSkuId|否|String| SKU唯一编码|
|--price|是|Double| 售价|
|--memberPrice|否|Double| 会员价|
|--shelfStatus|否|Integer| 上下架状态（0=下架，1=上架）|
|--source|否|Integer| 数据来源（1=品牌自建，2=品牌下发，3=门店自建）|
|--saleAttributeList|否|List| SKU售卖属性列表|
|----attributeGroupName|否|String| 属性组名称|
|----attributeGroupCode|否|String| 属性组编码|
|----attributeName|否|String| 属性名称|
|----attributeCode|否|String| 属性编码|
|--isDefault|否|Boolean| 是否为默认商品|
|--vendorId|否|String| 商家id|
|--compProductId|是|String| 关联商品ID|
|saleAttributeGroupList|否|List| 售卖属性组列表|
|--attributeGroupCode|否|String| 属性组编码（如“TEMP”）|
|--attributeGroupName|否|String| 属性组名称（如“温度”）|
|--rank|否|Integer| 排序（数字越小越靠前）|
|--attributeValueList|否|List| 售卖属性值列表|
|----displayOrder|否|Integer| 展示顺序|
|----attributeCode|否|String| 属性编码|
|----attributeName|否|String| 属性名称|
|premiumGroupList|否|List| 配料属性组列表|
|--premiumGroupCode|否|String| 配料组编码（如“MILK”）|
|--premiumGroupName|否|String| 配料组名称（如“添加牛奶”）|
|--rank|否|Integer| 排序（数字越小越靠前）|
|--chooseMultiPremium|否|Boolean| 是否支持多选配料（0=否，1=是）|
|--multiChoosePremium|否|Boolean| 是否支持多份配料（0=否，1=是）|
|--premiumValueList|否|List| 配料属性值列表|
|----displayOrder|否|Integer| 展示顺序（对应map的key）|
|----premiumCode|否|String| 配料编码（如“qzn”）|
|----premiumName|否|String| 配料名称（如“去脂牛奶”）|
|auditFail|否|Integer| 是否审核失败 1-失败 0-成功|
|failDescription|否|String| 审核失败原因|
|hide|否|Boolean| 是否隐藏 true隐藏 false显示|
