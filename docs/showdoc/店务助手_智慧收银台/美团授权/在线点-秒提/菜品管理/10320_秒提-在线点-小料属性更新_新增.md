# 秒提-在线点-新增/更新小料属性

**请求URL：** 
- `/dock/mt/miaoti/premium/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| id|
|premiumCode|是|String| 配料编码|
|premiumValue|是|String| 配料名称|
|price|是|Double| 价格|
|unit|是|String| 计量单位|
|unitCode|是|Long| 计量单位编码|
|rank|否|Integer| 排序|
|shelfStatus|否|Integer| 上下架状态 0：下架 1：上架|
|useMemberPoint|否|Boolean| 是否可用会员积分抵扣 true:可用 false:不可用|
|type|否|Integer| 类型，默认为1|
|description|否|String| 描述|
|source|否|Integer| 数据来源 1-品牌自建 2-品牌下发 3-门店自建|

### 请求参数Json格式
 
```
{
 "id" : 0,
 "premiumCode" : "String",
 "premiumValue" : "String",
 "price" : 0,
 "unit" : "String",
 "unitCode" : 0,
 "rank" : 0,
 "shelfStatus" : 0,
 "useMemberPoint" : true,
 "type" : 0,
 "description" : "String",
 "source" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--premiumCode|否|String| 配料编码|
|--premiumValue|否|String| 配料名称|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "premiumCode" : "String",
 "premiumValue" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
