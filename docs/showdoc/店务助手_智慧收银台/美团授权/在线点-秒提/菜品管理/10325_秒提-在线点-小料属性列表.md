# 秒提-在线点-小料属性列表

**请求URL：** 
- `/dock/mt/miaoti/premiumList/{source}`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|keyword|否|String||
|startTime|否|Object||
|--start|否|DateTime||
|--end|否|DateTime||
|shelfStatus|否|Integer| 过滤条件 1-上架 0-下架|
|id|否|String||
|pageSize|否|Integer||
|pageNo|否|Integer||
|sortField|否|String||
|sortDirection|否|String||
|viewId|否|String||

### 请求参数Json格式
 
```
{
 "keyword" : "String",
 "startTime" : {
 "start" : "DateTime",
 "end" : "DateTime"
 },
 "shelfStatus" : 0,
 "id" : "String",
 "pageSize" : 0,
 "pageNo" : 0,
 "sortField" : "String",
 "sortDirection" : "String",
 "viewId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--content|否|List||
|----id|否|Long| 主键id|
|----premiumCode|否|String| 配料编码 唯一、不为空|
|----premiumValue|否|String| 配料名称|
|----rank|否|Integer| 排序 默认为1即可|
|----description|否|String| 描述|
|----shelfStatus|否|Integer| 全国上下架状态 1：上架 0：下架 默认为1|
|----unit|否|String| 单位|
|----unitCode|否|String| 单位|
|----price|否|Double| 价格|
|----memberPrice|否|Long| 会员价|
|----useMemberPoint|否|Boolean| 是否可以用会员积分抵扣 true：可以 false：不可以|
|----type|否|Integer| 配料类型|
|----source|否|Integer| 数据来源 1：品牌自建 2：品牌下发 3：门店自建 默认为1|
|----vendorShopId|否|String| 厂商门店id source==2 或 source==3时必填|
|----tradeMarkCode|否|String| 售卖属性标识 source==2 是必填。 值为模板配料属性id|
|----createName|否|String| 创建人|
|----createDate|否|DateTime| 创建时间|
|----modifyDate|否|DateTime| 修改时间|
|--pageSize|否|Integer||
|--pageNo|否|Integer||
|--total|否|Long||
|--totalPage|否|Integer||
|--hasNextPage|否|Boolean||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
