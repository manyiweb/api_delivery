# 秒提-在线点-售卖属性详情

**请求URL：** 
- `/dock/mt/miaoti/saleattr/detail`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|Long| 售卖属性id|

### 请求参数Json格式
 
```
{
 "id" : 0
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long||
|--saleAttributeCode|否|String| 售卖属性编码|
|--saleAttributeValue|否|String| 售卖属性名称|
|--shelfStatus|否|Integer| 上下架状态 0：下架 1：上架|
|--rank|否|Integer| 售卖属性排序,默认填 1 即可|
|--type|否|Integer| 附加售卖属性或标准售卖属性 1：标准售卖属性|
|--useMemberPoint|否|Boolean| 是否可用会员积分抵扣 true:可用 false:不可用|
|--description|否|String| 描述|
|--source|否|Integer| 数据来源|
|--createId|否|String||
|--createName|否|String||
|--createDate|否|DateTime||
|--modifyId|否|String||
|--modifyName|否|String||
|--modifyDate|否|DateTime||
|--dbKey|否|Integer||
|--groupId|否|String||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||

 },
