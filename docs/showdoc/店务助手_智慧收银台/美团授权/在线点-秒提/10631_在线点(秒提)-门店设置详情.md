# 秒提-在线点-门店设置详情

**请求URL：** 
- `/dock/mt/miaoti/store/query`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 门店id|

### 请求参数Json格式
 
```
{
 "companyId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--companyId|是|String| 门店id|
|--operateStatus|否|Integer| 营业状态|
|--businessHours|否|List| 营业时间段|
|----weekDay|否|Enum| 星期|
|----businessHoursInfos|否|List| 营业时间段(多个用;隔开)|
|------startTime|否|String||
|------endTime|否|String||
|--book|否|Integer| 是否支持预约|
|--bookCycle|否|String| 预约周期|
|--bookHours|否|List| 预约时间段|
|----weekDay|否|Enum| 星期|
|----businessHoursInfos|否|List| 营业时间段(多个用;隔开)|
|------startTime|否|String||
|------endTime|否|String||
|--stockTime|否|String| 备货时间|
|--openMiaoti|否|Boolean| 是否开启秒提业务|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "companyId" : "String",
 "operateStatus" : 0,
 "businessHours" : [{
 "weekDay" : 0,
 "businessHoursInfos" : [{

 "endTime" : "String"
 }]
 }],
 "book" : 0,
 "bookCycle" : "String",
 "bookHours" : [{
 "weekDay" : 0,
 "businessHoursInfos" : [{
 "startTime" : "String",
 "endTime" : "String"
 }]
 }],
 "stockTime" : "String",
 "openMiaoti" : true
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
