# 优惠券预校验

**请求URL：** 
- `/app/pay/group/coupon/prepare `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|groupCouponSku|否|String| 团购券SKU|
|orderId|否|String| 订单ID|

###请求参数Json格式
 
```
{
 "groupCouponSku" : "String",
 "orderId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--available|否|Boolean| 购物车是否适用的商品|
|--msg|否|String| 不可用的原因|
|--availableAmount|否|Double| 优惠券可使用金额|
|--groupCouponId|否|String| 团购券ID|
|--groupCouponSku|否|String| 团购券SKU|
|--groupCouponName|否|String| 团购券名称|
|--groupCouponBuyPrice|否|Double| 团购券购买价|
|--groupCouponFacePrice|否|Double| 团购券面额|
|--groupCouponCostPrice|否|Double| 团购券成本价|
|--groupCouponType|否|Integer| 团购券类型 0套餐券1代金券|
|--beginTime|否|DateTime| 项目开始时间|
|--endTime|否|DateTime| 有效期至|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "available" : true,
 "msg" : "String",
 "availableAmount" : 0,
 "groupCouponId" : "String",
 "groupCouponSku" : "String",
 "groupCouponName" : "String",
 "groupCouponBuyPrice" : 0,
 "groupCouponFacePrice" : 0,
 "groupCouponCostPrice" : 0,
 "groupCouponType" : 0,
 "beginTime" : "DateTime",
 "endTime" : "DateTime"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
