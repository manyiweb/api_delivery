# 抖音券预支付

**请求URL：** 
- `/app/pay/douyin/groupon/prepare `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|groupCouponSku|否|String| 团购券SKU|
|orderId|否|String| 订单ID|
|groupCouponUseQty|否|Integer| 使用张数（不填默认为1）|

###请求参数Json格式
 
```
{
 "groupCouponSku" : "String",
 "orderId" : "String",
 "groupCouponUseQty" : 0
}
```
