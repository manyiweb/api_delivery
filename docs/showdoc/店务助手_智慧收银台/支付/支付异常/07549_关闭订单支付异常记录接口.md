# 关闭订单支付异常记录接口



 
##### 简要描述

- 关闭订单支付异常记录接口

##### 请求URL
- ` /retail-pay-front/pay/error/close `
 
##### 请求方式
- POST 

##### 参数

|参数|类型|描述|
|:-------|:-------|:-------|
| tokenId | string| 无 |
| traceNo | string| 无 |
| companyId | string| 无 |

##### 请求示例 
 ``` 
 {
 "tokenId": "f11fd13385b34d4498d8e9f58a436515",
 "traceNo": "2023112718325311596911179",
 "companyId": "E3F8DC53269C42A8A3AA3D97DD5C7AB4"
} 

 ```

##### 返回示例 

 ``` 
 {
 "code": "200",
 "data": null,
 "exceptionStackInfo": "",
 "msg": "",
 "success": true,
 "traceId": ""
} 

 ```

##### 返回参数说明 

|参数|类型|描述|
|:-------|:-------|:-------|
| code | string| 无 |
| - data |object | 无 |
| exceptionStackInfo | string| 无 |
| msg | string| 无 |
| success | boolean| 无 |
| traceId | string| 无 |
