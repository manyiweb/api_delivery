# 查看线下收银配置
 

**请求URL：** 
- `/config/retail/config/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|payType|否|String| 必传 支付类型 反扫BcQrCodePay 刷卡 CardPay|
|offlineCashierType|否|Integer| 	线下收银类型 0：订单收银 1：充值收银|

### 请求参数Json格式
 
```
{
 "payType" : "String",
 "offlineCashierType" : 0
}
```
