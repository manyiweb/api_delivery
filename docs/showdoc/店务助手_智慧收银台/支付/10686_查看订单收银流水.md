#

@Title: redepositPay </p>


@Description: 查看订单收银流水</p>
 

**请求URL：** 
- `/app/pay/order/dgathering`

**请求方式：**
- undefined
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|否|String| 订单ID|

### 请求参数Json格式
 
```
{
 "orderId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--id|否|String| 收银表主键id|
|--orderNo|否|String| 订单号|
|--payer|否|String| 支付类型（编码）|
|--payAmount|否|Double| 金额|
|--tradeNo|否|String| 外部订单号|
|--payTypeName|否|String| 支付类型|
|--payType|否|String| 支付类型编码|
|--channelNo|否|String| 渠道编码|
|--channelName|否|String| 渠道|
|--needRefundAmount|否|Double| 该支付方式需要退款的金额|
|--refundTradeNo|否|String| 退款单号|
|--externalNo|否|String| 外部传来的订单号|
|--orderType|否|String| 订单类型|
|--transactionId|否|String| 第三方支付单号，比如：微信支付订单号|
|--payDate|否|DateTime| 第三方支付单号，比如：微信支付订单号|
|--commitTime|否|String| 第三方支付单号，比如：微信支付订单号|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||

 }],

}
