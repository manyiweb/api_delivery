# 刷新接口

**请求URL：** 
- `/app/pay/gathering/refresh`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|gatheringId|否|String| 收银id|
|requestId|否|String| 收银支付请求id|
|groupId|否|String| 品牌id|

### 请求参数Json格式
 
```
{
 "gatheringId" : "String",
 "requestId" : "String",
 "groupId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--payStatus|否|Integer| 0处理中 1成功 2失败|
|--payMsg|否|String| 支付信息|
|--traceNo|否|String| 支付单号(MOP给第三方)|
|--outTraceNo|否|String| 第三方支付单号(第三方给MOP)|
|--channelTradeNo|否|String|通道订单号，微信订单号、支付宝订单号等 |
|--mchId|否|String|微信商户号|
|--wxSn|否|String|微信账号|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "payStatus" : 0,
 "payMsg" : "String",
 "traceNo" : "String",
 "outTraceNo" : "String",
 "channelTradeNo" : "String",
 "mchId" : "String",
 "wxSn" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
