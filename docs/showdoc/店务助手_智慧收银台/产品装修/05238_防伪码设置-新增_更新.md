# 防伪码设置-新增/更新

**请求URL：** 
- `/config/mall/antiFakeCode/edit`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long||
|type|是|Integer| 类型 1-会员商城|
|title|否|String| 标题|
|backgroundColor|否|String| 背景色,默认白色|
|backgroundImageUrl|是|String| 背景图|
|reScanButtonColor|是|String| 重新扫码按钮颜色|
|reScanButtonFontColor|是|String| 重新扫码按钮文字颜色|
|companyId|是|String| 商户id|
|items|否|List| 防伪码组件配置|
|--id|否|Long||
|--antiFakeCodeId|否|Long| 主表id|
|--moduleCode|是|Integer| 模块类型|
|--lineNo|是|Integer| 行号|
|--adUrl|否|String| 广告位链接|
|--adType|否|Integer| 广告类型：1-图片 2-视频|
|--fieldType|否|Integer| 字段类型|
|--position|否|Integer| 显示位置：1-靠左、2-居中、3-靠右边|
|--text|否|String| 文本|
|--fontColor|否|String| 字体颜色|
|--fontSize|否|Integer| 字体大小|
|--space|否|Integer| 上下间距|

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
