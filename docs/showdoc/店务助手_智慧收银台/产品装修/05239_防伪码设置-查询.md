# 防伪码设置-查询

**请求URL：** 
- `/config/mall/antiFakeCode/get`
- `/config/mall/antiFakeCode/getFromCache`（小程序用，读取缓存数据）

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|type|是|Integer|防伪码类型：1-会员商城|

### 请求参数Json格式
 
```
{
 "tokenId": "fb4d5dfeecf0482db234d0dc2928e62f",
 "companyId": "0d6fb49917b14b0483c55526ba52d937",
 "type": 1
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long||
|--type|否|Integer| 类型 1-会员商城|
|--title|否|String| 标题|
|--backgroundColor|否|String| 背景色|
|--backgroundImageUrl|否|String| 背景图|
|--reScanButtonColor|否|String| 重新扫码按钮颜色|
|--reScanButtonFontColor|否|String| 重新扫码按钮文字颜色|
|--items|否|List| 防伪码组件配置|
|----id|否|Long||
|----antiFakeCodeId|否|Long| 模块id|
|----moduleCode|否|Integer| 模块编码|
|----lineNo|否|Integer| 行号|
|----adUrl|否|String| 广告位链接|
|----adType|否|Integer| 广告类型：1-图片 2-视频|
|----fieldType|否|Integer| 字段类型|
|----fieldName|否|String| 字段名|
|----position|否|Integer| 显示位置：靠左、居中、靠右边|
|----text|否|String| 文本|
|----fontColor|否|String| 字体颜色|
|----fontSize|否|Integer| 字号|
|----space|否|Integer| 上下间距|
|----adUrlFull|否|String| 拼接好前缀的 url|
|--backgroundImageFullUrl|否|String| 拼接好的背景图链接|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
