# 查询产品装修详情
 

**请求URL：** 
- `/app/productDecoration/find `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|是|String| token|
|type|是|String| 产品装修类型 Member_Add("添加会员"),Member_Certification("会员认证"),Confirm_Dorder("下单收银")|

###请求参数Json格式
 
```
{
 "tokenId" : "String",
 "type" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long| id|
|--code|否|String| 字段编码|
|--name|否|String| 字段名称|
|--isRequired|否|Integer| 是否必填 1 - 必填, 0 - 不必填|
|msg|否|String| 消息|
|code|否|String| 业务代码|


###返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "code" : "String",
 "name" : "String",
 "isRequired" : 0
 },
 "msg" : "String",
 "code" : "String"
}
```
