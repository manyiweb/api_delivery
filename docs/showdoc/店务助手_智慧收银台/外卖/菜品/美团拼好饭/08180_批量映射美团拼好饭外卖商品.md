# 批量映射美团拼好饭外卖商品
 

**请求URL：** 
- `/dock/phf/product/batch/bind`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 门店ID|
|mtProducts|否|List| 美团商品|
|--specId|否|String| 商品规格ID|
|--itemId|否|String| 商品标识|
|--mtProduct|否|Object| 美团商品|
|----mtItemId|是|Long| 美团菜品id|
|----mtItemName|是|String| 美团菜名|
|----mtItemType|否|String| 美团菜分类|
|----appFoodCode|是|String| 美团菜分类|
|----mtPrice|否|Double| 外卖菜品单价|
|----mtSpecId|是|Long| 美团sku id|
|----mtSpuId|否|Long| 美团spu id|
|----mtUnit|否|String| 美团sku单位|
|----mtItemNameFull|否|String| 美团完整菜名|
|----mtBind|否|Boolean| 是否已绑定|
|ignoreBind|否|Boolean| 是否忽略已绑定|

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "mtProducts" : [{
 "specId" : "String",
 "itemId" : "String",
 "mtProduct" : {
 "mtItemId" : 0,
 "mtItemName" : "String",
 "mtItemType" : "String",
 "mtPrice" : 0,
 "mtSpecId" : 0,
 "mtSpuId" : 0,
 "mtUnit" : "String",
 "mtItemNameFull" : "String",
 "mtBind" : true
 }
 }],
 "ignoreBind" : true
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
