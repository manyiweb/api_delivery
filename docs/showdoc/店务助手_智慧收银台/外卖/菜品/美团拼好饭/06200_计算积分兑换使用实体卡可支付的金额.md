# 计算积分兑换使用实体卡可支付的金额
 

**请求URL：** 
- `retail-pay-front/app/entityCardPay/gift/entityCardPayCalculate `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|cardNo|否|String| 卡号|
|specId|否|String| 规格id|

###请求参数Json格式
 
```
{
 "cardNo" : "String",
 "specId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--cardId|否|String| 卡ID|
|--cardNo|否|String| 卡号|
|--denomination|否|String| 面额|
|--enableDiscount|否|Boolean| 是否启用折扣|
|--enableDiscountExpressFee|否|Boolean| 是否允许抵扣运费|
|--isAllItem|否|Integer| 是否是指定商品|
|--isAllComp|否|Integer| 所有门店|
|--discountAmount|否|Double| 折扣金额|
|--payAmount|否|Double| 可支付金额|
|--cardType|否|String| 实体卡券类型|
|--isMinUse|否|Integer| 是否启用最低使用金额|
|--minUse|否|Double| 最低使用金额|
|--balance|否|Double| 余额|
|--remark|否|String| 唯一码备注（实体卡券号备注）|
|--isFreeze|否|Boolean| 是否被冻结|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "cardId" : "String",
 "cardNo" : "String",
 "denomination" : "String",
 "enableDiscount" : true,
 "enableDiscountExpressFee" : true,
 "isAllItem" : 0,
 "isAllComp" : 0,
 "discountAmount" : 0,
 "payAmount" : 0,
 "cardType" : "String",
 "isMinUse" : 0,
 "minUse" : 0,
 "balance" : 0,
 "remark" : "String",
 "isFreeze" : true
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
