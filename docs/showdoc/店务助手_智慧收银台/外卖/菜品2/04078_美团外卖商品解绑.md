# 美团商品解绑
 

**请求URL：** 
- `/dock/product/release/bind`

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|ids|否|List| 商品行ID列表(批量)|
|companyId|否|String| 门店id|
|ifAllUnBind|否|Integer| 是否一件解绑 1——>是 2——>否|

###请求参数Json格式
 
```
{
 "id" : 0,
 "ids" : [11,22],
 "companyId" : "String",
 "ifAllUnBind" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
