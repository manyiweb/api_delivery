# 批量映射美团外卖商品
 

**请求URL：** 
- `/dock/product/batch/bind`

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 门店ID|
|mtProducts|否|List| 美团商品|
|--specId|否|String| 商品规格ID|
|--itemId|否|String| 商品标识|
|--mtProduct|否|Object| 美团商品|
|----mtItemId|否|Long| 美团菜品id|
|----mtEpItemId|否|String| 美团erp菜品id|
|----mtItemName|否|String| 美团菜名|
|----mtItemType|否|String| 美团菜分类|
|----mtPrice|否|Double| 外卖菜品单价|
|----mtSpecId|否|Long| 美团sku id|
|----mtEpSpecId|否|String| 美团erp sku id|
|----mtEpSpecName|否|String| 美团sku名称|
|----mtUnit|否|String| 美团sku单位|
|----mtItemNameFull|否|String| 美团完整菜名|

###请求参数Json格式
 
```
{
 "companyId" : "String",
 "mtProducts" : [{
 "specId" : "String",
 "itemId" : "String",
 "mtProduct" : {
 "mtItemId" : 0,
 "mtEpItemId" : "String",
 "mtItemName" : "String",
 "mtItemType" : "String",
 "mtPrice" : 0,
 "mtSpecId" : 0,
 "mtEpSpecId" : "String",
 "mtEpSpecName" : "String",
 "mtUnit" : "String",
 "mtItemNameFull" : "String"
 }
 }]
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
