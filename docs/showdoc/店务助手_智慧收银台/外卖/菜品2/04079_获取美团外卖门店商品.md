# 获取美团外卖门店商品
 

**请求URL：** 
- `/dock/product/mt/list `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String||

###请求参数Json格式
 
```
{
 "companyId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--mtItemId|否|Long| 美团菜品id|
|--mtEpItemId|否|String| 美团erp菜品id|
|--mtItemName|否|String| 美团菜名|
|--mtItemType|否|String| 美团菜分类|
|--mtPrice|否|Double| 外卖菜品单价|
|--mtSpecId|否|Long| 美团sku id|
|--mtEpSpecId|否|String| 美团erp sku id|
|--mtEpSpecName|否|String| 美团sku名称|
|--mtUnit|否|String| 美团sku单位|
|--mtItemNameFull|否|String| 美团完整菜名|
|--mtBind|否|Boolean| 是否已绑定|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : [{
 "mtItemId" : 0,
 "mtEpItemId" : "String",
 "mtItemName" : "String",
 "mtItemType" : "String",
 "mtPrice" : 0,
 "mtSpecId" : 0,
 "mtEpSpecId" : "String",
 "mtEpSpecName" : "String",
 "mtUnit" : "String",
 "mtItemNameFull" : "String",
 "mtBind" : true
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
