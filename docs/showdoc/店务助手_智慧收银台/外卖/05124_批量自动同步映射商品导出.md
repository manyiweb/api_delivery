# 批量自动同步映射商品导出
 

**请求URL：** 
- `/file/dock/product/mapping/sync/export`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|syncItems|否|List||
|--companyId|否|String| 门店ID|
|--companyCode|否|String| 门店名称|
|--companyName|否|String| 门店名称|
|--successful|否|Boolean| 是否执行成功|
|--errorMsg|否|String| 失败原因|
|--mappingProductNames|否|List| 同步成功的菜品名称(返回商品+规格名称)|
|--delMappingProductNames|否|List| 删除失效的菜品映射关系(返回商品+规格名称)|
|--notMappingProductNames|否|List| 未映射的商品列表|

### 请求参数Json格式
 
```
{
 "syncItems" : [{
 "companyId" : "String",
 "companyCode" : "String",
 "companyName" : "String",
 "successful" : true,
 "errorMsg" : "String",
 "mappingProductNames" : null,
 "delMappingProductNames" : null,
 "notMappingProductNames" : null
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
