# 美团订单回调
 

**请求URL：** 
- `/dock/mt/order/callback`

**请求方式：**
- ALL
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|developerId|否|Integer||
|ePoiId|否|String||
|sign|否|String||
|order|否|Object||
|--orderId|否|Long| 订单Id|
|--orderIdView|否|Long| 订单展示Id|
|--caution|否|String| 备注|
|--cityId|否|Long| 	城市Id|
|--ctime|否|Long| 订单创建时间|
|--utime|否|Long| 订单更新时间|
|--daySeq|否|String| 门店当天的订单流水号|
|--deliveryTime|否|Long| 用户预计送达时间，“立即送达”时为0|
|--detail|否|List| 订单菜品详情|
|--ePoiId|否|String| 三方的门店Id|
|--extras|否|List| 订单扩展信息|
|--hasInvoiced|否|Integer| 是否需要发票|
|--invoiceTitle|否|String| 发票抬头|
|--taxpayerId|否|String| 发票税号|
|--isFavorites|否|Boolean| 用户是否收藏此门店|
|--isPoiFirstOrder|否|Boolean| 用户是否第一次在此门店点餐|
|--isThirdShipping|否|Integer| 是否第三方配送|
|--latitude|否|Double| 订餐地址纬度|
|--longitude|否|Double| 订餐地址经度|
|--dinnersNumber|否|Integer| 用餐人数|
|--logisticsCode|否|Integer| 配送方式码|
|--originalPrice|否|Double| 订单原价|
|--payType|否|Integer| 	支付类型|
|--pickType|否|Integer| 取餐类型|
|--poiAddress|否|String| 门店地址|
|--poiName|否|String| 门店名称|
|--poiPhone|否|String| 商家电话|
|--poiReceiveDetail|否|String| 商家对账详情|
|--recipientAddress|否|String| 收货人地址|
|--recipientName|否|String| 收货人姓名|
|--recipientPhone|否|String| 收货人电话|
|--backupRecipientPhone|否|String| 备份隐私号|
|--shipperPhone|否|String| 配送员电话|
|--shippingFee|否|Double| 配送费|
|--status|否|Integer| 订单状态|
|--total|否|Double| 	订单总价|
|--quantity|否|Integer| 菜品份数|
|--avg_send_time|否|Double| 餐厅平均送餐时间，单位为秒|
|--orderTagList|否|String| 订单业务打标枚举，即业务身份|
|--incmpCode|否|Integer| 降级标识|
|--inmcpModules|否|List| 	降级模块|
