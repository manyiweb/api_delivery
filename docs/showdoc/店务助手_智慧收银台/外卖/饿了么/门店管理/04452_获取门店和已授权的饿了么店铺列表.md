# 获取门店和已授权的饿了么店铺列表

**请求URL：** 
- `/dock/ele/shop/list `

**请求方式：**
- POST
- RequestBody

|--current|否|Object||
|----itemName|否|String||

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--pageIndex|否|Integer| 页码|
|--pageSize|否|Integer| 显示记录数|
|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|--first|否|Boolean| 首页|
|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|
|----companyId|否|String| 门店id|
|----companyCode|否|String| 门店编码|
|----companyName|否|String| 门店名称|
|----city|否|String| 城市|
|----eleShopId|否|Long| 饿了么店铺id|
|----eleShopName|否|String| 饿了么店铺名称|

|code|否|String| 业务代码|
