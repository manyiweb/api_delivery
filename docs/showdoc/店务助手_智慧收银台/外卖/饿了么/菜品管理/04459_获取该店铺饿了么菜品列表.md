# 获取改店铺饿了么菜品列表

**请求URL：** 
- `/dock/ele/product/list `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 门店id|
|offset|是|Long| 分页起始（从0开始）|
|limit|否|Long| 一页个数 (若不传默认20)|

###请求参数Json格式
 
```
{
 "companyId" : "String",
 "offset" : 0,
 "limit" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--eleItemId|否|Long| 饿了么商品id|
|--eleItemFullName|否|String| 商品名称+规格|
|--eleItemName|否|String| 饿了么商品名称|
|--eleCategoryId|否|Long| 饿了么商品分类id|
|--eleSpecId|否|Long| 饿了么商品规格id|
|--eleSpecName|否|String| 饿了么商品规格名称|
|--unit|否|String| 商品单位|
|--price|否|Double| 销售价|
|--stock|否|Integer| 库存量|
|--maxStock|否|Integer| 最大库存量|
|--meterials|否|List| 原料|
|----id|否|Long| 原料id|
|----name|否|String| 原料名称|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : [{
 "eleItemId" : 0,
 "eleItemFullName" : "String",
 "eleItemName" : "String",
 "eleCategoryId" : 0,
 "eleSpecId" : 0,
 "eleSpecName" : "String",
 "unit" : "String",
 "price" : 0,
 "stock" : 0,
 "maxStock" : 0,
 "meterials" : [{
 "id" : 0,
 "name" : "String"
 }]
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
