# 店铺商品与饿了么商品进行关联

**请求URL：** 
- `/dock/ele/product/bind `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 门店id|
|bindProduct|否|List| 待绑定商品|
|--itemId|否|String| 商品id|
|--specId|否|String| 商品规格id|
|--eleProducts|否|Object| 需要绑定的饿了么商品|
|----eleItemId|否|Long| 饿了么商品id|
|----eleItemFullName|否|String| 商品名称+规格|
|----eleItemName|否|String| 饿了么商品名称|
|----eleCategoryId|否|Long| 饿了么商品分类|
|----eleSpecId|否|Long| 饿了么商品规格id|
|----eleSpecName|否|String| 饿了么商品规格名称|
|----unit|否|String| 商品单位|
|----price|否|Double| 销售价|
|----ifBind|否|Boolean| 是否已绑定|

###请求参数Json格式
 
```
{
 "companyId" : "String",
 "bindProduct" : [{
 "itemId" : "String",
 "specId" : "String",
 "eleProducts" : {
 "eleItemId" : 0,
 "eleItemFullName" : "String",
 "eleItemName" : "String",
 "eleCategoryId" : 0,
 "eleSpecId" : 0,
 "eleSpecName" : "String",
 "unit" : "String",
 "price" : 0,
 "ifBind" : true
 }
 }]
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
