# 通用三方商户授权
 

**请求URL：** 
- `/dock/third/merchant/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 门店id|
|merchantId|是|String| 商户id|
|merchantName|否|String| 商户id|
|token|否|String| token|
|expireIn|否|DateTime| token|
|platformType|是|String| 平台 douyinRetail 抖音即时零售|

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "merchantId" : "String",
 "merchantName" : "String",
 "token" : "String",
 "expireIn" : "DateTime",
 "platformType" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
