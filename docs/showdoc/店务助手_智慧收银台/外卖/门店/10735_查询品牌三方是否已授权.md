# 查询品牌三方是否已授权

**请求URL：** 
- `/dock/third/merchant/get`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|platformType|否|String| 平台 gaode 高德|

### 请求参数Json格式
 
```
{
 "platformType" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long||
|--merchantId|否|String| 商户id |
|--merchantName|否|String| 账号名|
|--platformType|否|String| 平台类型|
|--platformName|否|String| 平台类型名称|
|--accessToken|否|String| access_token|
|--expiresIn|否|DateTime| 过期时间|
|--refreshToken|否|String| refresh_token|
|--refreshExpiresIn|否|DateTime| 刷新授权过期时间|
|--isActive|否|Integer| 是否生效 1：生效 0：不生效|
|--tokenRefreshTime|否|Integer| 剩余可刷新次数|
|--createId|否|String||
|--createName|否|String||
|--createDate|否|DateTime||
|--modifyId|否|String||
|--modifyName|否|String||
|--modifyDate|否|DateTime||
|--dbKey|否|Integer||
|--groupId|否|String||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
