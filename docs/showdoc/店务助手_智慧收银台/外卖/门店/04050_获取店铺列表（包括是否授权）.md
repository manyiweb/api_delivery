# 获取店铺列表（包括是否授权，按业务id获取）
 

**请求URL：** 
- `/dock/comp/list/business`

**请求方式：**
- POST
- RequestBody

|----isRange|否|String||
|----isSelect|否|String||
|--current|否|Object||
|----itemName|否|String||
