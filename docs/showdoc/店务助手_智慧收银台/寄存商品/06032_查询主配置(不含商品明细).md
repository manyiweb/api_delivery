# 查询主配置(不含商品明细)
 

**请求URL：** 
- `/config/deposit/item/getSetting`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|是|String| id|

### 请求参数Json格式
 
```
{
 "id" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--id|否|Long||
|--companyId|否|String|门店id |
|--enableDepositServer|否|Boolean|是否启用寄存服务 |
|--assignType|否|Integer|指定类型，1：指定商品，2：指定分类、品牌、系列 |
|--createId|否|String| 创建人id|
|--createName|否|String| 创建人|
|--createDate|否|DateTime| 创建时间|
|--modifyId|否|String| 修改人id|
|--modifyName|否|String| 修改人|
|--modifyDate|否|DateTime| 修改时间|
|--dbKey|否|Integer| 分库标识|
|--groupId|否|String| 品牌商id|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "companyId" : "String",
 "enableDepositServer" : true,
 "assignType" : 0,
 "createId" : "String",
 "createName" : "String",
 "createDate" : "DateTime",
 "modifyId" : "String",
 "modifyName" : "String",
 "modifyDate" : "DateTime",
 "dbKey" : 0,
 "groupId" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
