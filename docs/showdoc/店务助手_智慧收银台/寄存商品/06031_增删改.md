# 增删改
 

**请求URL：** 
- `/config/deposit/item/saveOrUpdate`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String|门店id |
|enableDepositServer|是|Boolean|是否启用寄存服务 |
|assignType|是|Integer|指定类型，1：指定商品，2：指定分类、品牌、系列 |
|appoints|否|List|指定商品时集合 |
|--itemId|否|String|商品id |
|--specId|否|String|规格id |
|--sku|否|String|sku |
|--itemCode|否|String|商品编码 |
|--itemName|否|String|商品名称 |
|ranges|否|List|指定分类、品牌、系列的集合 |
|--type|否|Integer|指定类型，1：品牌、2：分类、3：系列 |
|--itemId|否|String|指定id |
|--itemCode|否|String|指定编码 |
|--itemName|否|String|指定名称 |
|delAppointIds|否|List|要删除的指定商品行id集合 |
|delRangeIds|否|List|要删除的指定分类、品牌、系列行id集合 |

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "enableDepositServer" : true,
 "assignType" : 0,
 "appoints" : [{
 "itemId" : "String",
 "specId" : "String",
 "sku" : "String",
 "itemCode" : "String",
 "itemName" : "String"
 }],
 "ranges" : [{
 "type" : 0,
 "itemId" : "String",
 "itemCode" : "String",
 "itemName" : "String"
 }],
 "delAppointIds" : null,
 "delRangeIds" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
