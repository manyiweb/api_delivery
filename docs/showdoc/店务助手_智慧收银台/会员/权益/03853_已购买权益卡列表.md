# 已购买权益卡列表
 

**请求URL：** 
- `/app/memberEntitleCard/buyCardList `

**请求方式：**
- ALL
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|memberId|否|String| 会员id|
|type|否|Integer| 购买权益卡类型 1、生效 0、失效|

###请求参数Json格式
 
```
{
 "memberId" : "String",
 "type" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--specId|否|String| 规格id|
|--cardName|否|String| 权益卡名称|
|--cardNo|否|String| 权益卡名称|
|--cardPicUrl|否|String| 权益卡封面图|
|--day|否|Integer| 剩余有效天数|
|--accountId|否|Long| 权益卡账户id|
|--cardId|否|Long| 权益卡id|
|--expireDate|否|DateTime| 失效日期|
|--effectiveDate|否|DateTime| 生效日期|
|--active|否|Boolean| 是否启用|
|--enableConsumeLimit|否|Boolean| 是否开启消费限额|
|--consumeLimit|否|Double| 消费余额限制|
|--consumeLimitType|否|Integer| 消费类型|
|--residueAmount|否|Double| 剩余消费金额|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : [{
 "specId" : "String",
 "cardName" : "String",
 "cardNo" : "String",
 "cardPicUrl" : "String",
 "day" : 0,
 "accountId" : 0,
 "cardId" : 0,
 "expireDate" : "DateTime",
 "effectiveDate" : "DateTime",
 "active" : true,
 "enableConsumeLimit" : true,
 "consumeLimit" : 0,
 "consumeLimitType" : 0,
 "residueAmount" : 0
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
