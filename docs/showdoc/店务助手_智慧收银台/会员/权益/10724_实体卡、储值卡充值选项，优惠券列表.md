# 实体卡、储值卡充值选项，优惠券列表

**请求URL：** 
- `/mem/benefit/card/entityCoupon`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|String||
|orderField|否|String||
|orderSort|否|String||
|tokenId|否|String||
|pageIndex|是|Integer||
|pageSize|是|Integer||
|sword|否|String||

### 请求参数Json格式
 
```
{
 "id" : "String",
 "orderField" : "String",
 "orderSort" : "String",
 "tokenId" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "sword" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--pageIndex|否|Integer||
|--pageSize|否|Integer||
|--pageCount|否|Integer||
|--totalCount|否|Long||
|--first|否|Boolean||
|--last|否|Boolean||
|--content|否|List||
|----entityCouponId|否|String| 电子券ID|
|----entityCouponName|否|String| 电子券名称|
|----qty|否|Integer| 电子券数量|
|----useLimitAmt|否|Double| 优惠券使用最低限额|
|----beginDate|否|DateTime| 电子券使用有效时间范围 - 开始时间|
|----endDate|否|DateTime| 电子券使用有效时间范围 - 结束时间|
|----validType|否|String| 有效期类型|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "pageIndex" : 0,
 "pageSize" : 0,
 "pageCount" : 0,
 "totalCount" : 0,
 "first" : true,
 "last" : true,
 "content" : [{
 "entityCouponId" : "String",
 "entityCouponName" : "String",
 "qty" : 0,
 "useLimitAmt" : 0,
 "beginDate" : "DateTime",
 "endDate" : "DateTime",
 "validType" : "String"
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
