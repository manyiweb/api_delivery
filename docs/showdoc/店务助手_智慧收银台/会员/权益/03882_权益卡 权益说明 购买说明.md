# 权益卡 权益说明 购买说明
 

**请求URL：** 
- `/app/memberEntitleCard/cardIntroduction `

**请求方式：**
- ALL
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|cardId|否|Long| 权益卡id|

###请求参数Json格式
 
```
{
 "cardId" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--cardId|否|Long| 权益卡id|
|--cardPicUrl|否|String| 权益卡封面图|
|--cardDescription|否|String| 权益说明|
|--buyDescription|否|String| 购买说明|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : {
 "cardId" : 0,
 "cardPicUrl" : "String",
 "cardDescription" : "String",
 "buyDescription" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
