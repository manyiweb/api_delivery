# 计算实体券充值到实体卡金额
 

**请求URL：** 
- `/mem/calculate/recharge/admount`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|cardId|否|String| 选择的实体券id|
|cardNo|否|String| 选择的实体券卡号|
|rechargeCardId|是|String| 充值的实体卡|

### 请求参数Json格式
 
```
{
 "cardId" : "String",
 "cardNo" : "String",
 "rechargeCardId" : "String"
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--cardId|否|String| 实体券id|
|--cardNo|否|String| 实体券卡号|
|--cardName|否|String| 实体券名称|
|--denomination|否|Double| 面额|
|--startDate|否|DateTime| 有效期|
|--endDate|否|DateTime| 有效期|
|--totalAmount|否|Double| 总金额|
|--rechargeAmount|否|Double| 充值金额|
|--giftAmount|否|Double| 赠送金额|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "cardId" : "String",
 "cardNo" : "String",
 "cardName" : "String",
 "denomination" : 0,
 "startDate" : "DateTime",
 "endDate" : "DateTime",
 "totalAmount" : 0,
 "rechargeAmount" : 0,
 "giftAmount" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
