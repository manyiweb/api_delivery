# 实体券一键核销查询
 

**请求URL：** 
- `/app/entityCardPay/entityCoupon/scan`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|cardNo|是|String| 卡号|

### 请求参数Json格式
 
```
{
 "cardNo" : "String"
}
```
