# 保存门店实体卡价格清单设置

**请求URL：** 
- `/mem/entitycard/comp/price/save`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String| 门店id|
|open|否|Boolean| 是否开启|
|saveReqList|否|List| 门店实体卡列表|
|--id|否|Long| id|
|--priceListId|否|String| 价格清单id|
|--cardId|否|String| 卡档案id|
|--cardName|否|String| 价格清单id|
|--priceListName|否|String| 价格清单名单|
|--companyId|否|String| 门店id|
|--usePriceDisableDiscount|否|Boolean| 参与促销/行优惠/整单优惠/优惠券/实体券后，不可享受价格清单|

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "open" : true,
 "saveReqList" : [{
 "id" : 0,
 "priceListId" : "String",
 "cardId" : "String",
 "cardName" : "String",
 "priceListName" : "String",
 "companyId" : "String",
 "usePriceDisableDiscount" : true
 }]
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
