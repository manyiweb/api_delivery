# 获取会员笔记详细信息（中台）

**请求URL：** 
- `/community/member/note/manage/getNoteDetail `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|memberNoteId|否|Long| 会员笔记id|

###请求参数Json格式
 
```
{
 "memberNoteId" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--title|否|String| 标题|
|--memberName|否|String| 会员用户名|
|--reviewStatus|否|String| 审核状态|
|--companyName|否|String| 门店|
|--creationDate|否|String| 发布时间|
|--detailDto|否|Object| 详细信息|
|----memberNoteNo|否|String||
|----title|否|String||
|----category|否|String||
|----memberName|否|String||
|----companyName|否|String||
|----reviewStatus|否|String||
|----creationDate|否|String||
|----isActive|否|String||
|----reviewDtos|否|List| 审核信息|
|------reviewManName|否|String| 审批人|
|------reviewTime|否|String| 审批时间|
|------reviewStatus|否|String| 审批状态|
|------remark|否|String| 审核备注|
|--contentDto|否|Object| 笔记内容|
|----content|否|String| 会员笔记内容|
|----mideaUrls|否|List| 视频或图片url|
|----noteType|否|Integer| 笔记类型(1——>图片 2——>视频)|
|----bindItemDtos|否|List| 关联商品|
|------id|否|Long| 序号|
|------itemId|否|String| 商品id|
|------itemName|否|String| 商品名称|
|------itemCode|否|String| 商品编码|
|------specId|否|String| 规格id|
|------specName|否|String| 规格名称|
|------skuBarcode|否|String| 规格商品码|
|----sum|否|Object| 统计信息|
|------likeCount|否|Long||
|------favourCount|否|Long||
|------commentCount|否|Long||
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
