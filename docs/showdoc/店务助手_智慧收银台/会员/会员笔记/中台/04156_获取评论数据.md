# 获取评论数据

**请求URL：** 
- `/community/member/note/manage/getComments `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|memberNoteId|否|Long| 会员笔记编号|
|tokenId|否|String| 用户标识|
|pageIndex|否|Integer| 分页页码|
|pageSize|否|Integer| 分页大小|
|sword|否|String| 搜索关键字|

###请求参数Json格式
 
```
{
 "memberNoteId" : 0,
 "tokenId" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "sword" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--pageIndex|否|Integer| 页码|
|--pageSize|否|Integer| 显示记录数|
|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|--first|否|Boolean| 首页|
|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|
|----commentUsername|否|String| 评论人|
|----commentContent|否|String| 评论内容|
|----commentTime|否|String| 评论时间|
|----replyUsername|否|String| 被评论人名字|
|----replyContent|否|String| 被评论内容|
|----replyTime|否|String| 被评论内容发布时间|
|----commentLikeCount|否|Long| 评论点赞数|
|----flag|否|Integer| 标识评论和回复 0评论 1回复|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : {
 "pageIndex" : 0,
 "pageSize" : 0,
 "pageCount" : 0,
 "totalCount" : 0,
 "first" : true,
 "last" : true,
 "content" : [{
 "commentUsername" : "String",
 "commentContent" : "String",
 "commentTime" : "String",
 "replyUsername" : "String",
 "replyContent" : "String",
 "replyTime" : "String",
 "commentLikeCount" : 0,
 "flag" : 0
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
