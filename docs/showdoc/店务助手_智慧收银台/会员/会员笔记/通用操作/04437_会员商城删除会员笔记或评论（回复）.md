# 会员商城删除会员笔记或评论（回复）

**请求URL：** 
- `/community/member/note/manage/delete `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|delType|否|Integer| 删除操作类型 1删除会员笔记 2删除评论或回复|
|memberId|否|String| 笔记作者会员id|
|id|否|Long| 评论id|
|flag|否|Integer| 标记评论还是回复|

###请求参数Json格式
 
```
{
 "delType" : 0,
 "memberId" : "String",
 "id" : 0,
 "flag" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
