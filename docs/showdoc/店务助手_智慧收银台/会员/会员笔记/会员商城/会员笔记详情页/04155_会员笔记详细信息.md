# 会员笔记详细信息

**请求URL：** 
- `/community/member/note/myNotesDetail`

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|memberNoteId|是|Long| 会员笔记id|

###请求参数Json格式
 
```
{
 "memberNoteId" : 0,
 "from" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--memberNoteId|否|Long| 会员笔记id|
|--memberId|否|String| 笔记作者会员id|
|--userName|否|String| 会员名字|
|--headImage|否|String| 会员头像|
|--videoUrl|否|String| 视频url|
|--category|否|String| 分类名字|
|--title|否|String| 标题|
|--content|否|String| 会员笔记内容|
|--creationDate|否|String| 创建时间|
|--photos|否|List| 图片url|
|--reviewStatus|否|Integer| 审批状态(0待审核 1审批通过 2审批不通过)|
|--remark|否|String| 备注|
|--ifLike|否|Integer| 是否点赞|
|--ifFavour|否|Integer| 是否收藏|
|--ifAuthor|否|Boolean| 是否作者|
|--likeCount|否|Long| 点赞数|
|--favourCount|否|Long| 收藏数|
|--commentCount|否|Long| 评论总数|
|--authorization|否|Integer| 是否有权限查看(默认有)|
|--ifShare|否|Boolean| 分享能否可见|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "memberNoteId" : 0,
 "memberId" : "String",
 "userName" : "String",
 "headImage" : "String",
 "videoUrl" : "String",
 "category" : "String",
 "title" : "String",
 "content" : "String",
 "creationDate" : "String",
 "photos" : null,
 "reviewStatus" : 0,
 "remark" : "String",
 "ifLike" : 0,
 "ifFavour" : 0,
 "ifAuthor" : true,
 "likeCount" : 0,
 "favourCount" : 0,
 "commentCount" : 0,
 "authorization" : 0,
 "ifShare" : true
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
