# 获取商品详情

**请求URL：** 
- `/community/member/note/productDetail `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|memberNoteId|是|Long| 会员笔记id|

###请求参数Json格式
 
```
{
 "memberNoteId" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--itemId|否|String| 商品id|
|--itemName|否|String| 商品名字|
|--headImage|否|String| 商品图片|
|--specId|否|String| 商品规格id|
|--specName|否|String| 商品名字|
|--salePrice|否|Double| 商品销售价|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : [{
 "itemId" : "String",
 "itemName" : "String",
 "headImage" : "String",
 "specId" : "String",
 "specName" : "String",
 "salePrice" : 0
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
