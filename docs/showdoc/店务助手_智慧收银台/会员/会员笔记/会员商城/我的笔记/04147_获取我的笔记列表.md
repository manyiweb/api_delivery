# 获取我的笔记

**请求URL：** 
- `/community/member/note/myNotes `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|searchType|否|Integer| 搜索类型1.笔记 2.点赞 3.收藏 4.未审核|
|sword|否|String||
|tokenId|否|String||
|id|否|String||
|orderField|否|String| 排序字段|
|orderSort|否|String| 排序方式|
|searchBeans|否|List| 高级筛选条件|
|--typeCode|否|String||
|--typeName|否|String||
|--dataType|否|String||
|--isSingle|否|String||
|--isLikeSearch|否|String||
|--items|否|List||
|----itemName|否|String||
|----itemValue|否|String||
|----minValue|否|String||
|----maxValue|否|String||
|----isCustom|否|String||
|----isRange|否|String||
|----isSelect|否|String||
|--current|否|Object||
|----itemName|否|String||
|----itemValue|否|String||
|----minValue|否|String||
|----maxValue|否|String||
|----isCustom|否|String||
|----isRange|否|String||
|----isSelect|否|String||
|--sword|否|String||
|--pageIndex|否|Integer||
|--pageSize|否|Integer||
|--curPageNum|否|Integer||
|--totalPage|否|Integer||
|--totalCount|否|Integer||
|status|否|Integer| 状态|
|pageIndex|否|Integer| 页号|
|pageSize|否|Integer| 页大小|
|orderField|否|String| 商品排序字段|
|orderSort|否|String| 商品排序方式 desc 倒序 asc 正序|

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--pageIndex|否|Integer| 页码|
|--pageSize|否|Integer| 显示记录数|
|--pageCount|否|Integer| 总页数|
|--totalCount|否|Long| 总记录数|
|--first|否|Boolean| 首页|
|--last|否|Boolean| 尾页|
|--content|否|List| 分页数据|
|----memberNoteId|否|Long| 会员笔记id|
|----memberNoteNo|否|String| 会员笔记编号|
|----headImage|否|String| 会员头像|
|----title|否|String| 标题|
|----photo|否|String| 图片url|
|----noteVideo|否|String| 视频url|
|----noteType|否|Integer| 笔记类型|
|----userName|否|String| 会员名字|
|----likeCount|否|Long| 点赞数|
|----reviewStatus|否|Integer| 审批状态码(0待审核 1审批通过 2审批不通过)|
|----reviewStatusString|否|String| 审批状态（含义）|
|----createDate|否|DateTime| 创建时间|
|----createDateString|否|String| 创建时间字符串格式|
|----ifLike|否|Integer| 是否点赞|
|----authorization|否|Integer| 会员权限 0仅自己可见 1所有人可见|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|
