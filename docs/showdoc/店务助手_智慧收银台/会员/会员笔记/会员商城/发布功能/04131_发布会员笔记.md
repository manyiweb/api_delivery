# 发布会员笔记

**请求URL：** 
- `/community/member/note/publish `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|title|否|String| 会员笔记标题|
|content|否|String| 会员笔记内容|
|categoryId|否|Long| 会员笔记分类id|
|category|否|String| 分类|
|companyId|否|String| 门店|
|companyName|否|String| 门店名称|
|isDraft|否|Integer| 是否为草稿|
|noteType|否|Integer| 笔记类型(1——>图片 2——>视频)|
|longitude|否|Double| 经度|
|latitude|否|Double| 纬度|
|location|否|String| 定位地址|
|photos|否|List| 图片url|
|noteVideo|否|String| 视频url|
|mitems|否|List| 关联商品|
|--itemId|否|String| 商品id|
|--specId|否|String| 商品规格id|
|--specName|否|String| 商品规格名字|
|--itemName|否|String| 商品名字|

###请求参数Json格式
 
```
{
 "title" : "String",
 "content" : "String",
 "categoryId" : 0,
 "category" : "String",
 "companyId" : "String",
 "companyName" : "String",
 "isDraft" : 0,
 "noteType" : 0,
 "longitude" : 0,
 "latitude" : 0,
 "location" : "String",
 "photos" : null,
 "noteVideo" : "String",
 "mitems" : [{
 "itemId" : "String",
 "specId" : "String",
 "specName" : "String",
 "itemName" : "String"
 }]
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|String| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : "String",
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
