# 回复评论

**请求URL：** 
- `/community/member/note/reply `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|memberNoteId|否|String| 会员笔记id|
|commentId|否|Long| 所属评论id|
|replyContent|否|String| 回复内容|
|replyToMemberId|否|String| 回复对象id|
|replyToUsername|否|String| 回复对象名字|
|replyToContent|否|String| 回复对象的内容|
|replyToTime|否|String| 回复对象创建时间|
|flag|否|Integer| 区分评论和回复标识 0评论 1回复|

###请求参数Json格式
 
```
{
 "memberNoteNo" : "String",
 "commentId" : 0,
 "replyContent" : "String",
 "replyToMemberId" : "String",
 "replyToUsername" : "String",
 "replyToContent" : "String",
 "replyToTime" : "String",
 "flag" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
