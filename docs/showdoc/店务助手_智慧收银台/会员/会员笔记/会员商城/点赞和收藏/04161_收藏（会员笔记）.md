# 收藏

**请求URL：** 
- `/community/member/note/favour `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|ifFavour|否|Integer| 是否收藏|
|favourCount|否|Integer| 点赞数|
|memberNoteId|否|Long| 会员笔记id|

###请求参数Json格式
 
```
{
 "ifFavour" : 0,
 "favourCount" : 0,
 "memberNoteId" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--favourCount|否|Integer| 收藏数|
|--ifFavour|否|Integer| 是否收藏|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : {
 "favourCount" : 0,
 "ifFavour" : 0
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
