# 扫码入会
 

**请求URL：** 
- `/app/Company/GetReadMemberQrCode `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|tokenId|是|String| 用户标识|

###请求参数Json格式
 
```
{
	"tokenId" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|qrCodeBase64|否|String| 二维码Base64编码|
|qrCodeUrl|否|String| 二维码url|
|qrCodeType|否|String| 二维码类型，Wx-公众号；WxApp-小程序|
|ErrorCode|否|String| 错误编码|
|ResultString|否|String| 返回信息|
|ResultInt|否|Integer| 返回状态|


###返回参数Json格式
 
```
{
	"qrCodeBase64": "String",
	"qrCodeUrl": "String",
	"qrCodeType": "String",
	"ErrorCode": "",
	"ResultString": "String",
	"ResultInt": 0
}
```
