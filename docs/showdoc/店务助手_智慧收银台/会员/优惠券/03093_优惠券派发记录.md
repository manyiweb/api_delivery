# 功能描述: 优惠券派发记录
 

**请求URL：** 
- `/app/Business/member/couponGet/list `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|searchBeans|否|List| 高级筛选条件|
|--typeCode|否|String||
|--typeName|否|String||
|--dataType|否|String||
|--isSingle|否|String||
|--isLikeSearch|否|String||
|--items|否|List||
|----itemName|否|String||
|----itemValue|否|String||
|----minValue|否|String||
|----maxValue|否|String||
|----isCustom|否|String||
|----isRange|否|String||
|----isSelect|否|String||
|--current|否|Object||
|----itemName|否|String||
|----itemValue|否|String||
|----minValue|否|String||
|----maxValue|否|String||
|----isCustom|否|String||
|----isRange|否|String||
|----isSelect|否|String||
|--sword|否|String||
|--pageIndex|否|Integer||
|--pageSize|否|Integer||
|--curPageNum|否|Integer||
|--totalPage|否|Integer||
|--totalCount|否|Integer||
|tokenId|否|String| 用户标识|
|pageIndex|否|Integer| 分页页码|
|pageSize|否|Integer| 分页大小|
|couponId|否|String| 优惠券主键标识|
|sword|否|String| 搜索关键字-支持会员名称及电话|
|swordGive|否|String| 搜索关键字-支持派发人名称及电话|

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|TotalCount|否|Object| 主数据|

|--DataLine|否|Object||
|----sn|否|String| 优惠券号码|
|----getTime|否|DateTime| 派发时间|
|----useTime|否|DateTime| 使用时间|
|----id|否|String| 会员主键标识|
|----cardNo|否|String| 会员卡号|

|----phone|否|String| 会员手机号|

|----staffPhone|否|String| 派发人手机号|

|code|否|String| 业务代码|
