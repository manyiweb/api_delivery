# 获取会员拥有的券列表

**请求URL：** 
- `/thirdParty/coupon/getMemberCouponList `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|否|String| 门店id|
|phone|否|String| 会员手机号|
|type|否|String| 类型|
|pageIndex|否|Integer| 页号|
|pageSize|否|Integer| 页大小|

###请求参数Json格式
 
```
{
 "companyId" : "String",
 "phone" : "String",
 "type" : "String",
 "pageIndex" : 0,
 "pageSize" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--couponId|否|String| 优惠券id|
|--couponSku|否|String| 优惠券SN|
|--couponName|否|String| 优惠券名称|
|--couponType|否|Integer| 优惠券类型|
|--couponTypeName|否|String| 优惠券类型名称|
|--detail|否|String| 详情|
|--beginDate|否|DateTime| 开始时间|
|--endDate|否|DateTime| 结束时间|
|--couponReducedPrice|否|Double| 现金券-优惠金额|
|--discount|否|Double| 折扣券-折扣|
|--openDma|否|Integer| 折扣券-是否限制最高可优惠金额|
|--discountMaxAmount|否|Double| 折扣券-最高可优惠金额|
|--isAllItem|否|Integer| 优惠券应用商品模式：0-指定商品;1-应用所有商品;2-排除商品;3-指定类别、品牌、系列;|
|--applySpecIds|否|Object| 优惠券可用spedId|
|--useLimit|否|Integer| 叠加规则：0-不可叠加使用(默认);1-可叠加使用;2-可叠加使用(阶梯)|
|--useLimitType|否|Integer| 叠加规则维度：0-按金额;1-按数量|
|--superimposedRule|否|Object| 叠加规则明细|
|----amount|否|Double| 达标数量/金额|
|----canUserQuantity|否|Integer| 优惠券可使用数量|
|--need|否|Double| 最低使用金额或数量|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|

 "useLimitType" : 0,
 "superimposedRule" : {
 "amount" : 0,
 "canUserQuantity" : 0
 },

 }],

 "code" : "String",
