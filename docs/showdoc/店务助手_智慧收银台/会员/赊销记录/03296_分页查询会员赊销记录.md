# 功能描述: 分页查询会员赊销记录
 

**请求URL：** 
- `/app/Business/Member/credit `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|String| 业务ID|
|tokenId|否|String| 用户标识|
|pageIndex|否|Integer| 分页页码|
|pageSize|否|Integer| 分页大小|
|sword|否|String| 搜索关键字|

###请求参数Json格式
 
```
{
 "id" : "String",
 "tokenId" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
 "sword" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--debtAmount|否|Double| 待回款金额|
|--creditAmount|否|Double| 授信金额|
|--AccumulatedCreditAmount|否|Double| 累计赊销总额|
|--creditRecords|否|Object| 赊销记录（分页）|
|----pageIndex|否|Integer| 页码|
|----pageSize|否|Integer| 显示记录数|
|----pageCount|否|Integer| 总页数|
|----totalCount|否|Long| 总记录数|
|----first|否|Boolean| 首页|
|----last|否|Boolean| 尾页|
|----content|否|List| 分页数据|
|------companyId|否|String| 门店ID|
|------companyName|否|String| 门店名称|
|------creditAmount|否|Double| 赊销金额（单元：元，保留2位小数）|
|------paidAmount|否|Double| 已还款金额（单元：元，保留2位小数）|
|------debtAmount|否|Double| 待还款金额（单元：元，保留2位小数）|
|------repaymentDate|否|DateTime| 回款日期|
|------status|否|Boolean| 状态（true—已清；false-未清）|
|------sourceId|否|String| 来源单号|
|------createDate|否|DateTime| 创建时间|
|------remarks|否|String| 备注|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
