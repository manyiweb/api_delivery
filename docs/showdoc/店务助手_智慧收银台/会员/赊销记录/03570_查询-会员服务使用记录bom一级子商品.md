# 功能描述: 查询会员服务使用记录bom一级子商品
 

**请求URL：** 
- `/app/Business/member/findMemberServiceUseRecord/bomItem `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|recordId|否|Long| 使用记录标识|
|specId|否|String| 规格ID|
|usedTimes|否|Integer| 使用次数|

###请求参数Json格式
 
```
{
 "recordId" : 0,
 "specId" : "String",
 "usedTimes" : 0
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List| 主数据|
|--itemId|否|String| 商品标识|
|--itemName|否|String| 商品名称|
|--specId|否|String| 规格ID|
|--specName|否|String| 规格名称|
|--quantity|否|Double| 数量|
|--headImageFull|否|String| 图片|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|


###返回参数Json格式
 
```
{
 "data" : [{
 "itemId" : "String",
 "itemName" : "String",
 "specId" : "String",
 "specName" : "String",
 "quantity" : 0,
 "headImageFull" : "String"
 }],
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String"
}
```
