# 判断会员是否已认证

**请求URL：** 
- `/mem/member/info/isCertified `

**请求方式：**
- POST
- RequestBody


###请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|memberId|否|String| 会员id|
|action|否|String| 行为 CardRecharge("储值充值"),MemberBenifit("权益有效期充值"),DepositOrder("新增订金单")|

###请求参数Json格式
 
```
{
 "memberId" : "String",
 "action" : "String"
}
```

###返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object| 主数据|
|--isCertified|否|Boolean| 是否认证 true已认证 false未认证|
|--describe|否|String| 提示|
|msg|否|String| 消息|
|code|否|String| 业务代码|
|exceptionStackInfo|否|String| 异常堆栈信息|
|monitorRequestId|否|String| 请求监控ID|
|traceId|否|String| 链路跟踪id|


###返回参数Json格式
 
```
{
 "data" : {
 "isCertified" : true,
 "describe" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "monitorRequestId" : "String",
 "traceId" : "String"
}
```
