# 编辑机器码信息(品牌端编辑+下发)
 服务：retail-order-front
 

**请求URL：** 
- `/pos/machine/add`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|id|否|Long| 主键|
|companyId|是|String| 门店id|
|machineNo|是|String| 设备号|
|localPrint|否|Boolean| 本机接单打印|
|scanCodeBoxPrint|否|Boolean| 启用扫码盒扫码|
|speedCash|否|Boolean| 极速收银|
|productCache|否|Boolean| 商品缓存|a

### 请求参数Json格式
 
```
{
 "id" : 0,
 "companyId" : "String",
 "machineNo" : "String",
 "localPrint" : true,
 "scanCodeBoxPrint" : true,
 "speedCash" : true,
 "productCache" : true
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
