# 新增/编辑机器码信息
 服务：retail-order-front
 

**请求URL：** 
- `/pos/machine/add`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|logIn|否|Boolean| 是否是登录后首次调用(清理打印日志)|
|posMachinePrinters|否|List| 打印机|
|--id|否|Long| 主键|
|--machineId|否|Long| pos_machine|
|--lineNo|否|Integer| 序号|
|--printerType|否|Integer| 打印机类型：0-网络、 1-USB、 2-蓝牙|
|--ip|否|String| ip地址|
|--scene|否|String| 打印场景（多个）|
|id|否|Long| 主键|
|lastReportingTime|否|DateTime| 最后上报时间|
|companyId|否|String| 门店id|
|companyCode|否|String| 门店编码|
|companyName|否|String| 门店名称|
|machineNo|否|String| 设备号|
|status|否|Integer| 运行状态：0-离线、1-在线|
|localPrint|否|Boolean| 本机接单打印|
|switchLocalPrint|否|Boolean| 切换本地打印|
|scanCodeBoxPrint|否|Boolean| 启用扫码盒扫码|
|speedCash|否|Boolean| 极速收银|
|productCache|否|Boolean| 商品缓存|
|mealTakeCodePrefix|否|String| 取餐码/牌号前缀字母|
|mealTakeCodeStart|否|String| 取餐码开始数字|
|mealTakeCodeEnd|否|String| 取餐码结束数字|
|mealTakeCodeNum|否|String| 取餐码当前数字|
|queueNumberBoardIp|否|String| 叫号屏ip地址|
|queueNumberBoardStatus|否|Boolean| 叫号屏连接状态|
|usbScaleName|否|String| USB串口电子秤名称|
|bluetoothScaleName|否|String| 蓝牙电子秤名称|
|multiTerminalPrintStatus|否|Boolean| 多终端打印设备类型：0-主设备 1-子设备|
|multiTerminalPrintType|否|Integer| 多终端打印设备类型|
|multiTerminalPrintIp|否|String| 多终端打印主设备ip|
