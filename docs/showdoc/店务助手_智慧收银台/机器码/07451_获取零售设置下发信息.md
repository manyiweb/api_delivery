# 获取零售设置下发信息
 

**请求URL：** 
- `/app/Business/Retail/Set`

**请求方式：**
- POST
- FormData


### 请求参数<业务参数>
 
无参数


### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--id|否|Long||
|--companyId|否|String||
|--groupId|否|String||
|--createId|否|String||
|--createName|否|String||
|--createDate|否|DateTime||
|--modifyId|否|String||
|--modifyName|否|String||
|--modifyDate|否|DateTime||
|--posMachineSets|否|List||
|----machineNo|否|String| 设备号|
|----localPrint|否|Boolean| 本机接单打印|
|----scanCodeBoxPrint|否|Boolean| 启用扫码盒扫码|
|----speedCash|否|Boolean| 极速收银|
|----productCache|否|Boolean| 商品缓存|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "id" : 0,
 "companyId" : "String",
 "groupId" : "String",
 "createId" : "String",
 "createName" : "String",
 "createDate" : "DateTime",
 "modifyId" : "String",
 "modifyName" : "String",
 "modifyDate" : "DateTime",
 "posMachineSets" : [{
 "machineNo" : "String",
 "localPrint" : true,
 "scanCodeBoxPrint" : true,
 "speedCash" : true,
 "productCache" : true
 }]
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
