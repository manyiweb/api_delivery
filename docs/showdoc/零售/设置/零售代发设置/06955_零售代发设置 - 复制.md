# 零售代发设置 - 复制

**请求URL：** 
- `/retail/proxysupplier/copy`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|companyId|是|String||
|toCompanyIds|是|List||

### 请求参数Json格式
 
```
{
 "companyId" : "String",
 "toCompanyIds" : null
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--openTake|否|Boolean||
|--openTransferOrder|否|Boolean||
|--companyId|否|String||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : {
 "openTake" : true,
 "openTransferOrder" : true,
 "companyId" : "String"
 },
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
