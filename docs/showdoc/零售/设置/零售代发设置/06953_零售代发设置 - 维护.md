# 零售代发设置 - 维护

**请求URL：** 
- `/retail/proxysupplier/edit`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|openTake|否|Boolean| 开启代发到店自提|
|openProxyDeliveryWay|否|Boolean| 开启提货、配送代发方式|
|productionTakeWay|否|Integer| 自提生产方式(0仅生产1生产并配送)|
|productionDeliveryWay|否|Integer| 提货配送生产方式(0仅生产1生产并配送)|
|openTransferOrder|否|Boolean| 开启转单|
|openDefaultComp|否|Boolean| 开启品牌默认当前门店作为代发门店|
|companyId|否|String| 门店id|
|consignSales|否|Integer| 寄售设置 0 采购价=结算比例*订单实收单价 1 采购价=结算比例*供应商维护的清单价(如果没维护采购价格清单则取订单的实收单价)|
|notAcceptAfterToday|否|Boolean| 控制提货配送时间大于当天不支持接单|
|openTurnProxyDeliveryWay|否|Boolean| 开启转单提货配送代发方式|
|turnProductionTakeWay|否|Integer| 转单自提生产方式(0生产并配送 1仅生产)|
|turnProductionDeliveryWay|否|Integer| 转单提货配送生产方式(0生产并配送 1仅生产)|
|notRepeatedOrderRemind|否|Boolean| 控制未接订单重复提醒|
|voiceRepeatInterval|否|Integer| 语音重复间隔(分钟), 1-120分钟|
|waitTransferOrderRemind|否|Boolean| 控制待调拨收货订单提醒|
|transferOrderTemplate|否|Integer| 调拨收货版式 0 版式一 1 版式2|
