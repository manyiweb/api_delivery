# 订单-订单详情信息

**请求URL：** 
- `/app/Business/Order/DetailItems`

**请求方式：**
- undefined
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|是|String| 订单id|
|sword|否|String| 搜索关键字 对销售订单商品进行筛选|
|dockOrder|否|Boolean| 请求类型|
|needCombo|否|Boolean| 是否需要返回套餐商品格式|

### 请求参数Json格式
 
```
{
 "orderId" : "String",
 "sword" : "String",
 "dockOrder" : true,
 "needCombo" : true
}
```
