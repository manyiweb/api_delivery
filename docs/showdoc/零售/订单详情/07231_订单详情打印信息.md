# 订单打印信息

**请求URL：** 
- `/retail-order-front/app/Business/Order/getOrderPrintInfo`

**请求方式：**
- undefined
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|是|String| 订单id|
|sword|否|String| 搜索关键字 对销售订单商品进行筛选|
|dockOrder|否|Boolean| 请求类型|

### 请求参数Json格式
 
```
{
 "orderId" : "String",
 "sword" : "String",
 "dockOrder" : true
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--receiptTemplate|否|String| 打印模板|
|--receiptRemark|否|String| 打印备注|
|--isCookReceipt|否|String| 是否零售结算后打印 N Y|
|--printImg|否|String| 打印图片|
|--printImgWidth|否|String| 打印图片 宽度|
|--printImgHigh|否|String| 打印图片 高度|
|--printDate|否|String| 打印时间|
|--houchuPrinters|否|List| 后厨打印|
|----id|否|Long||
|----masterPrinterName|否|String| 主打印机名称|
|----masterPrinterIp|否|String| 主打印机ip|
|----secondaryPrinterName|否|String| 副打印名称|
|----secondaryPrinterIp|否|String| 副打印机ip|
|----isAllItem|否|Object| 是否应用所有商品 0 - 指定商品,1 - 应用所有商品,2 - 指定分类|
|----printerMode|否|Object| 打印模式 0 - 整单打印,1 - 单品打印|
|----lineId|否|Object| 行号|
|----companyId|否|String| 商户id|
|----createId|否|String| 创建人id|
|----createName|否|String| 创建人|
|----createDate|否|DateTime| 创建时间|
|----modifyId|否|String| 修改人id|
|----modifyName|否|String| 修改人|
|----modifyDate|否|DateTime| 修改时间|
|----useCase|否|String| 使用场景，多选， 逗号隔开|
|----useCases|否|List| 使用场景与是否选择map|
|----items|否|List||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
