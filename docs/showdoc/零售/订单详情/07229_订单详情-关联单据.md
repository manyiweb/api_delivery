# 订单-关联单据

**请求URL：** 
- `/retail-order-front/app/Business/Order/getOrderDetailSourceOrder`

**请求方式：**
- undefined
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|orderId|是|String| 订单id|
|sword|否|String| 搜索关键字 对销售订单商品进行筛选|
|dockOrder|否|Boolean| 请求类型|

### 请求参数Json格式
 
```
{
 "orderId" : "String",
 "sword" : "String",
 "dockOrder" : true
}
```
