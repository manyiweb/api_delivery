# 图形认证发送短信验证码

**请求URL：** 
- `/sms/together/send`

**请求方式：**
- ALL
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|mobile|是|String| 接收短信的手机号|
|groupId|否|String| 品牌id|
|platform|否|Enum| 平台 0 - h5, 1 - ios , 2 - 安卓|
|aliGraphicVerificationReq|否|Object| 阿里云图形验证信息|
|--lotNumber|是|String| 验证流水号|
|--captchaOutput|是|String| 验证输出信息|
|--passToken|是|String| 验证通过标识|
|--genTime|是|String| 验证通过时间戳|
|--captchaId|是|String| 验证ID|

### 请求参数Json格式
 
```
{
 "mobile" : "String",
 "groupId" : "String",
 "platform" : 0,
 "aliGraphicVerificationReq" : {
 "lotNumber" : "String",
 "captchaOutput" : "String",
 "passToken" : "String",
 "genTime" : "String",
 "captchaId" : "String"
 }
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||


### 返回参数Json格式
 
```
{
 "data" : null,
 "msg" : "String",
 "code" : "String",
 "exceptionStackInfo" : "String",
 "traceId" : "String"
}
```
