# 切换端口

**请求URL：** 
- `api/reabam-manage-login/user/change/platform`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|platform|是|String||平台号

### 请求参数Json格式
 
```
{
 "platform" : "String"
}
```
