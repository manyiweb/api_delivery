# 登录

**请求URL：** 
- `/api/manage-login/user/login`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|mobile|否|String| 登录账号|
|staffCode|否|String| 登录工号|
|groupCode|否|String| 登录品牌|
|loginWord|否|String| 登录密码|
|loginType|否|String| 登录类型|
|appType|否|String| 登录app类型|
|appVersion|否|String| 登录app版本|
|groupId|否|String| groupId|
|regAgreement|否|Integer| 如果为移动导购 判断用户是否签署过注册协议 0未勾选 1勾选|
|jpushRegId|否|String| 极光推送id|
|systemVersion|否|String| 系统版本号|
|clientVersion|否|String| 客户端版本号|
|tokenId|否|String| tokenId|
|authorization|否|String| 授权信息|
|clientType|否|String| 客户端类型|
|memberAuthorization|否|Object| 会员授权信息|
|--openId|否|String| openId|
|--sessionKey|否|String| sessionKey|
|externalAuthorization|否|Object| 外部授权信息|
|--principal|否|String| 主体 一般是账号|
|--credential|否|String| 凭证 一般是密码|
|smsVerification|否|Object| 短信验证码信息|
|--code|否|String| 验证码|
|internationalizationType|否|String| 版本类型 0 - 国内版 , 1 - 国际版|
|acceptLanguage|否|String| 语言|
