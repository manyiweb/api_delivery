# 获取可登录品牌列表

**请求URL：** 
- `api/reabam-manage/staff/group/login/list`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
无参数


### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|List||
|--sgId|否|String| id|
|--groupId|否|String| 品牌id|
|--status|否|Integer| 品牌的用户状态|
|--statusName|否|String| 品牌的用户状态|
|--isActive|否|Integer| 品牌的用户状态|
|--roleCode|否|String| 角色编码|
|--roleName|否|String| 角色名称|
|--brandLogo|否|String| 品牌logo|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||

```
 "sgId" : "String",

 "roleName" : "String",
 "brandLogo" : "String"
 }],
 "msg" : "String",

}
```
