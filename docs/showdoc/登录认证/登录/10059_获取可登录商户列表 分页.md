# 获取可登录商户列表 分页
 这个接口用于获取app 或者小程序 上用户可以登录的认证商户

**请求URL：** 
- `/api/reabam-manage/staff/comp/login/page`

**请求方式：**
- POST
- RequestBody


### 请求参数<业务参数>
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|loginName|是|String| 登录账号|
|groupId|否|String| 品牌id|
|platform|是|String| 平台|
|sword|否|String||
|tokenId|否|String||
|pageIndex|否|Integer||
|pageSize|否|Integer||

### 请求参数Json格式
 
```
{
 "loginName" : "String",
 "groupId" : "String",
 "platform" : "String",
 "sword" : "String",
 "tokenId" : "String",
 "pageIndex" : 0,
 "pageSize" : 0,
}
```

### 返回参数
 
|参数名|必选|类型|说明|
|:---- |:---|:----- |----- |
|data|否|Object||
|--pageIndex|否|Integer||
|--pageSize|否|Integer||
|--pageCount|否|Integer||
|--totalCount|否|Long||
|--first|否|Boolean||
|--last|否|Boolean||
|--content|否|List||
|----groupId|否|String| 品牌id|
|----groupCode|否|String| 品牌编码|
|----groupName|否|String| 商户名称|
|----companyId|否|String| 商户id|
|----companyCode|否|String| 商户编码|
|----companyName|否|String| 品牌名称|
|----isActive|否|Integer| 当前商户|
|----city|否|String| 省市区 城市|
|----province|否|String| 省市区 区|
|----userTypeName|否|String| 角色名称|
|----userType|否|String| 角色|
|----statusName|否|String| 活跃状态 名称|
|----status|否|String| 活跃状态|
|----brandLogo|否|String| 商户logo|
|msg|否|String||
|code|否|String||
|exceptionStackInfo|否|String||
|traceId|否|String||
